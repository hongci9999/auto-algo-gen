# 수열 합 구하기
*javascript · 구현 · 보통 · 배열, 시뮬레이션*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리해야 합니다. 전체 입력을 받아 파싱하는 방식을 사용하세요.

## 문제

어떤 수열 $A$가 주어졌을 때, 문제에서 제시하는 규칙에 따라 새로운 값들을 계산하고 그 합을 구해야 합니다. 

수열 $A = [a_1, a_2, ..., a_N]$이 있습니다. 이 수열의 각 요소 $a_i$는 다음 값을 가지도록 업데이트됩니다. $$a'_i = a_i + 	ext{다음 값}$$ 

여기서 '다음 값'은 다음과 같이 정의됩니다:
1. 만약 $i < N$이라면, $	ext{다음 값} = a_{i+1}$입니다.
2. 만약 $i = N$이라면, $	ext{다음 값} = 0$입니다.

따라서 새로운 수열 $A'$의 각 요소는 다음과 같이 계산됩니다:
$$a'_i = egin{cases} a_i + a_{i+1} & (1 	ext{부터 } N-1 	ext{까지}) \ a_N + 0 & (i=N) 	ext{ 즉, } a'_N = a_N 	ext{입니다.} ing
$$ 

만약 원래 수열 $A$가 $[a_1, a_2, ..., a_N]$이라면, 새로운 수열 $A'$는 $[a_1+a_2, a_2+a_3, ..., a_{N-1}+a_N, a_N]$이 됩니다.

최종적으로 계산된 수열 $A'$의 모든 요소들의 합 $	ext{Sum}(A')$을 구하시오.

## 입력

첫 번째 줄에는 정수 N (1 ≤ N ≤ 10^5)이 주어집니다. 
두 번째 줄에는 공백으로 구분된 N개의 정수 $a_1, a_2, ..., a_N$이 순서대로 주어집니다.

## 출력

새로운 수열 $A'$의 모든 요소들의 합 $	ext{Sum}(A')$을 하나의 정수로 출력합니다.

## 제약 조건

1 ≤ N ≤ 10^5
$|a_i| 	ext{은 } 10^9 	ext{ 이하입니다. (합계가 long long 범위에 들어갈 수 있음)}
시간 복잡도는 O(N)이 권장됩니다.

## 예제 1

**입력**
```
5
1 2 3 4 5
```

**출력**
```
25
```

*새로운 수열 A'는 [1+2, 2+3, 3+4, 4+5, 5] = [3, 5, 7, 9, 5]가 됩니다. 합은 3+5+7+9+5 = 29입니다.*

## 예제 2

**입력**
```
3
10 -5 2
```

**출력**
```
17
```

*새로운 수열 A'는 [10+(-5), (-5)+2, 2] = [5, -3, 2]가 됩니다. 합은 5+(-3)+2 = 4입니다.*

## 힌트

- 수열 $A'$의 합을 직접 계산하는 것이 아니라, 각 항의 개별적인 패턴을 찾아야 합니다.
- 수학적 전개나 간소화된 공식이 있는지 확인해보세요. 모든 $a_i$가 몇 번씩 사용되는지 분석해봅시다.


## 알고리즘 요약

원래 수열 $A$의 합 $	ext{Sum}(A)$와 최종 수열 $A'$의 합 $	ext{Sum}(A')$ 사이의 관계를 파악합니다. $a_i$가 $A'$의 총합에 몇 번, 그리고 어떤 방식으로 기여하는지 분석하여 시간 복잡도를 O(N)으로 유지하면서 계산할 수 있습니다.

## 풀이 해설

풀이 해설: 이 문제는 직접적으로 새로운 수열 A'를 구성한 후 합을 구하는 방식보다, 각 요소 $a_i$가 최종 합에 몇 번 기여하는지 분석하여 시간 복잡도를 최적화하는 것이 핵심입니다.

1. **A'의 정의 재확인:**
   $$A' = [a_1+a_2, a_2+a_3, ..., a_{N-1}+a_N, a_N]$$
2. **총합 계산 (Sum(A')):**
   $$	ext{Sum}(A') = (a_1+a_2) + (a_2+a_3) + ... + (a_{N-1}+a_N) + a_N$$ 
3. **$a_i$의 기여도 분석:**
   * $a_1$: 첫 번째 항에서만 사용됩니다. $ightarrow 1$회
   * $a_2$: 첫 번째와 두 번째 항에서 사용됩니다. $ightarrow 2$회
   * $a_3$: 두 번째와 세 번째 항에서 사용됩니다. $ightarrow 2$회
   * ...
   * $a_{N-1}$: $(N-2)$번째와 $(N-1)$번째 항에서 사용됩니다. $ightarrow 2$회
   * $a_N$: 마지막 항과 마지막 요소로 독립적으로 포함됩니다. $ightarrow a_{N-1}$의 끝자리 + 독립된 $a_N$. 총 $2$번 (혹은 처음 정의에 따라 주의 필요)
4. **정확한 전개 및 합산:**
   $$	ext{Sum}(A') = a_1 + 2 	imes a_2 + 2 	imes a_3 + ... + 2 	imes a_{N-1} + (a_N + a_N)$$ 
   (주의: 마지막 항 $a'_N$은 단순히 $a_N$입니다. 이 $a_N$이 독립적으로 더해지므로, 위 식을 수정해야 합니다.)
   $$A' = [a_1+a_2] + [(a_2+a_3) + ... + (a_{N-1}+a_N)] + [a_N]$$
   $$	ext{Sum}(A') = a_1 + 2 	imes a_2 + 2 	imes a_3 + ... + 2 	imes a_{N-1} + 2 	imes a_N$$ 
   (잠시만요, $a'_i$를 다시 정의된 규칙에 맞춰 전개합시다.)
   $$	ext{Sum}(A') = (a_1+a_2) + (a_2+a_3) + ... + (a_{N-1}+a_N) + a_N$$ 
   $a_1$: 1번
   $a_2$: 2번
   ... 
   $a_{N-1}$: 2번
   $a_N$: (마지막 항의 $a_{N-1}+a_N$) $+ a_N$. 즉, 총 2번.
5. **최종 공식:**
   $$	ext{Sum}(A') = a_1 + 2 	imes (a_2 + a_3 + ... + a_{N-1}) + 2 	imes a_N$$ 
6. **계산 단계:**
   * $	ext{Total Sum} = a_1$를 초기화합니다.
   * $i=2$부터 $N-1$까지, $	ext{Total Sum} += 2 	imes a_i$를 반복합니다.
   * 마지막으로, $	ext{Total Sum} += 2 	imes a_N$을 합니다. (만약 N=1인 경우, 합은 $a_1$이 됩니다.)
7. **시간 복잡도:** O(N)의 순회만 필요하므로 매우 빠릅니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수
 */
function solve() {
    const fs = require('fs');
    // 동기 방식으로 전체 입력 읽기 (테스트 환경에 적합)
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) {
        console.log(0);
        return;
    }

    // 첫 줄은 N (숫자로 변환하지 않아도 됨)
    const N = parseInt(input[0].trim());
    
    // 두 번째 줄의 배열 a_i
    // BigInt를 사용하여 오버플로우 방지 (문제 제약 조건 고려)
    let A = input[1].trim().split(/\s+/).map(BigInt);

    if (N === 0) {
        console.log(0);
        return;
    }
    
    // N=1인 경우: A'는 [a_1]이므로 합은 a_1
    if (N === 1) {
        console.log(A[0].toString());
        return;
    }

    // Sum(A') = a_1 + 2 * (a_2 + ... + a_{N-1}) + 2 * a_N 
    // 단, N이 1 이상일 때만 유효하며, 위 공식은 N >= 3을 가정한 형태이므로 재정비 필요.

    let totalSum = BigInt(0);

    // 1. 첫 번째 요소 a_1 (인덱스 0)
    totalSum += A[0];

    // 2. 중간 요소들 a_2부터 a_{N-1}까지 (인덱스 1부터 N-2까지). 이들은 2배의 기여를 합니다.
    for (let i = 1; i <= N - 2; i++) {
        totalSum += 2n * A[i];
    }
    
    // 3. 마지막 요소 a_N (인덱스 N-1)
    // a_N는 두 번 기여합니다 (A'_{N-1}의 끝자리 + 독립적인 A'_N). 
    totalSum += 2n * A[N - 1];

    console.log(totalSum.toString());
}

solve();
```

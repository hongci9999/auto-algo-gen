# 가장 긴 연속된 1의 개수 찾기
*javascript · 구현 · 쉬움 · 문자열*

## 입출력 환경

Node.js 환경에서 readline 모듈을 사용하여 입력을 받습니다.

## 문제

주어진 이진 문자열(0과 1로만 구성됨)에서 연속으로 나타나는 '1'의 최대 개수를 구하는 문제입니다.

예시: "11011101" -> 최대 연속된 1은 "111" (3개)

## 입력

첫째 줄에 이진 문자열 S가 주어집니다.

## 출력

연속된 '1'의 최대 개수를 정수 형태로 출력합니다.

## 제약 조건

문자열 길이 N: 1부터 10^5까지. (시간 복잡도 O(N) 필요)

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열 중 '1'이 연속으로 3개(111)가 가장 많습니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열 전체에 '1'이 없습니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*전체 문자열이 1로만 이루어져 있습니다.*

## 힌트

- 현재 연속된 '1'의 개수를 세는 카운터 변수가 필요합니다.
- 문자열을 순회하면서, 문자가 '1'일 때마다 카운터를 증가시키고, '0'을 만나면 카운터를 0으로 초기화해야 합니다.


## 알고리즘 요약

순차 탐색 (Iteration)

## 풀이 해설

풀이 해설:

1. **아이디어:** 이 문제는 주어진 문자열을 처음부터 끝까지 한 글자씩 순서대로 확인하면서, 연속되는 '1'의 길이를 기록하고 그 중 가장 큰 값을 찾아야 합니다.
2. **단계:**
    a. `maxCount` 변수를 0으로 초기화합니다. (최대값을 저장)
    b. `currentCount` 변수를 0으로 초기화합니다. (현재 연속되는 '1'의 개수)
    c. 문자열을 반복문(Loop)을 이용해 처음부터 끝까지 순회합니다.
    d. 현재 문자가 '1'이면, `currentCount`를 1 증가시킵니다.
    e. 현재 문자가 '0'이면, 연속이 끊겼으므로 `currentCount`를 0으로 재설정합니다.
    f. **중요:** 반복문 내부에서 매번 `maxCount = Math.max(maxCount, currentCount)` 코드를 실행하여, 현재까지의 최대값과 현재 카운터 값을 비교하며 `maxCount`를 항상 최신 상태로 유지해야 합니다.
3. **시간 복잡도:** 문자열의 길이에 비례하여 한 번만 순회하므로 O(N)입니다. (매우 효율적)

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} s - 이진 문자열
 * @returns {number} 최대 연속된 1의 개수
 */
function maxConsecutiveOnes(s) {
    let maxCount = 0;
    let currentCount = 0;

    for (let i = 0; i < s.length; i++) {
        if (s[i] === '1') {
            // '1'을 만나면 현재 카운트를 증가시킨다.
            currentCount++;
        } else { // s[i] === '0'
            // '0'을 만나면 연속이 끊기므로 카운트를 0으로 초기화한다.
            currentCount = 0;
        }
        
        // 매 단계마다, 현재까지의 최대값과 현재 카운터를 비교하여 maxCount를 업데이트한다.
        maxCount = Math.max(maxCount, currentCount);
    }
    return maxCount;
}

/**
 * Node.js 환경에서 입력을 처리하는 메인 로직
 */
function solve() {
    const readline = require('readline');
    const rl = readline.createInterface({
        input: process.stdin,
        output: process.stdout,
        terminal: false
    });

    rl.on('line', (line) => {
        if (line.length > 0) {
            const result = maxConsecutiveOnes(line);
            console.log(result);
        }
        rl.close();
    });
}

solve();
```

# 최대 점프 거리 계산
*javascript · 구현 · 보통 · 배열, 시뮬레이션*

## 입출력 환경

입력은 표준 입력(stdin)을 통해 이루어집니다. JavaScript 환경에서는 Node.js의 readline 모듈이나 fs 모듈을 사용하여 입력을 처리해야 합니다.

## 문제

N명의 사람이 일렬로 서 있습니다. 각 사람은 자신의 위치에서 일정 거리를 점프로 이동할 수 있습니다.

사람 i는 현재 위치 $i$에 있고, 최대 점프 거리는 $D[i]$입니다. 즉, 사람 i는 $[i-D[i], i+D[i]]$ 범위 내의 어느 위치로든 점프할 수 있지만, 실제 인덱스는 0부터 N-1 사이여야 합니다.

이때, 모든 사람이 최소한 한 번은 점프해야 하는 상황에서, 가장 먼 사람(즉, 최대 인덱스)까지 도달하는 데 필요한 최소 점프 횟수를 구하세요. (단, 초기 위치는 0입니다.)

## 입력

첫째 줄에 정수 N이 주어집니다. 둘째 줄에는 N개의 정수 $D[0], D[1], \dots, D[N-1]$가 공백으로 구분되어 주어집니다.

## 출력

최소 점프 횟수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 200,000\n1 <= D[i] <= N

## 예제 1

**입력**
```
5
2 3 1 4 1
```

**출력**
```
2
```

*0에서 점프 후, 가장 먼 지점까지 도달하는 최소 횟수는 2입니다. (예: 0 -> 2 또는 0 -> 1)*

## 예제 2

**입력**
```
7
1 1 1 1 1 1 1
```

**출력**
```
6
```

*모든 점프 거리가 1이므로, 순차적으로 이동해야 합니다. (0 -> 1 -> 2 -> ... -> 6)*

## 힌트

- 그리디(Greedy) 알고리즘을 사용합니다.
- 현재 도달 가능한 가장 먼 지점을 추적하는 것이 핵심입니다.


## 알고리즘 요약

다이나믹 프로그래밍 또는 그리디 접근 방식
이 문제는 '최소 점프 횟수'를 찾는 전형적인 최단 경로 문제로, BFS나 그리디 알고리즘을 적용할 수 있습니다. 현재 위치 $i$에서 도달 가능한 모든 지점 $[i-D[i], i+D[i]]$ 중, 다음 단계에서 가장 큰 진전을 할 수 있는 곳으로 점프하는 것이 유리합니다.

## 풀이 해설

풀이 해설: 이 문제는 그리디 알고리즘을 사용하여 최소 점프 횟수를 찾아야 합니다.

**아이디어:** 한 번의 점프로 도달할 수 있는 범위 내에서, 다음 점프를 했을 때 가장 멀리 갈 수 있는 지점을 선택해야 합니다. 단순히 현재 위치에서 가능한 모든 곳을 탐색하는 것은 비효율적이며, '도달 가능성'과 '최대 진전 거리'라는 두 가지 개념을 관리해야 합니다.

**단계:**
1. **변수 정의:**
   - `max_reach`: 현재 점프 횟수까지 도달할 수 있는 가장 먼 인덱스 (현재 단계의 목표).
   - `current_end`: 현재 점프 횟수로 도달 가능한 범위의 끝 (다음 단계를 시작하는 지점).
   - `next_farthest`: 다음 점프를 통해 도달할 수 있는 최대 거리.
2. **순회:** 인덱스 $i$를 0부터 N-1까지 순회합니다.
3. **거리 업데이트:** 매 단계에서, 현재 위치 $i$가 속한 범위 $[current_end]$ 내에 있다면 (즉, 아직 도달 가능한 지점이라면), `next_farthest`를 $\max(\text{next\_farthest}, i + D[i])$로 갱신합니다.
4. **점프 발생:** 만약 $i$가 현재 점프 단계의 끝(`current_end`)에 도달했다면, 이는 반드시 다음 점프를 해야 한다는 의미입니다.
   - 최소 점프 횟수를 1 증가시킵니다.
   - `max_reach`를 `next_farthest`로 업데이트합니다. 
   - 새로운 `current_end`를 이전 단계의 끝이었던 곳으로 설정하고, 다음 탐색 시작 지점(다음 순회 범위)을 현재 $i$ 위치로 이동시킵니다.
5. **종료 조건:** 만약 `max_reach`가 N-1 이상이 되면 최소 점프 횟수를 반환하고 종료합니다. 모든 인덱스를 순회했으나 목표에 도달하지 못했다면, 이는 불가능한 상황을 의미하지만 문제 제약상 항상 도달 가능하다고 가정할 수 있습니다.

**시간 복잡도:** 배열을 한 번만 선형적으로 순회하므로 $O(N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} N - 사람의 수
 * @param {number[]} D - 각 사람의 최대 점프 거리
 * @returns {number} 최소 점프 횟수
 */
function minJumps(N, D) {
    if (N === 1) return 0;

    let jumps = 0; // 총 점프 횟수
    let current_reach = 0; // 현재 점프 횟수로 도달 가능한 최대 인덱스 (최종 목표)
    let next_farthest = 0; // 다음 점프로 도달할 수 있는 가장 먼 지점
    let start_of_current_jump = 0; // 현재 점프 단계가 시작된 위치

    for (let i = 0; i < N - 1; i++) {
        // 1. 다음으로 가능한 최대 거리를 갱신합니다.
        next_farthest = Math.max(next_farthest, i + D[i]);

        // 2. 현재 점프 단계의 범위 내에 있다면 (아직 도달 가능하다면)
        if (i < current_reach) {
            // 다음 점프로 갈 수 있는 가장 먼 지점을 계속 업데이트합니다.
            Math.max(next_farthest, i + D[i]); 
        }

        // 3. 현재 단계의 끝에 도달했다면, 반드시 다음 점프가 필요합니다.
        if (i === current_reach) {
            jumps++;
            current_reach = next_farthest;
            
            // 만약 새로운 최대 도달 거리가 N-1 이상이면 목표 달성
            if (current_reach >= N - 1) {
                return jumps;
            }
        }
    }
    
    // 예외 처리: 마지막 인덱스까지 순회했으나 목표에 도달하지 못했을 경우
    // 문제 조건상 항상 도달 가능하다고 가정하면 이 부분은 실행되지 않거나, N-1이 이미 반환됨.
    return jumps; 
}
```

# 최대 길이의 연속된 1의 개수
*javascript · 구현 · 쉬움 · 문자열, 순회*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 사용하여 문자열 S를 읽어옵니다.

## 문제

주어진 문자열 $S$가 있습니다. 이 문자열에는 '0'과 '1'만 포함되어 있습니다. 이 문자열에서 연속으로 나타나는 '1'의 가장 긴 길이(최댓값)를 구하는 문제입니다.

예를 들어, "11011101"과 같은 문자열이 주어졌을 때, 연속된 '1'의 길이는 각각 2, 3, 1이므로, 최댓값은 3입니다. 문자열이 모두 '0'으로만 이루어져 있다면, 최댓값은 0입니다.

## 입력

첫째 줄에 문자열 $S$가 주어집니다.

## 출력

정수 하나를 출력합니다.

## 제약 조건

문자열 $S$의 길이 $N$은 1부터 100,000 이하입니다.

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*연속된 '1'의 길이는 2, 3, 1입니다. 최댓값은 3입니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열에 '1'이 없으므로 최댓값은 0입니다.*

## 힌트

- 현재 연속된 '1'의 길이를 카운트하는 변수가 필요합니다.
- 문자가 '1'일 때만 길이를 증가시키고, '0'이거나 문자열 끝에 도달했을 때 최댓값을 갱신해야 합니다.


## 알고리즘 요약

순차적 탐색 (Greedy/Iteration)

## 풀이 해설

### 아이디어
이 문제는 문자열을 처음부터 끝까지 한 번만 순회하면서 (O(N) 시간 복잡도) 연속된 '1'의 길이를 추적하는 방식으로 해결할 수 있습니다.

### 단계
1. **변수 초기화**: 두 개의 변수를 준비합니다. `current_count`는 현재 연속된 '1'의 길이를 저장하고, `max_count`는 지금까지 발견된 가장 긴 연속된 '1'의 길이를 저장합니다. 둘 다 0으로 초기화합니다.
2. **순회**: 문자열 $S$의 모든 문자를 순서대로 탐색합니다.
3. **조건 처리**: 현재 문자가 '1'인 경우:
    * `current_count`를 1 증가시킵니다.
    * `max_count`를 `max(max_count, current_count)`로 업데이트하여, 현재까지의 최대 길이를 갱신합니다.
4. **'0'을 만난 경우**: 현재 문자가 '0'인 경우:
    * 연속된 '1'의 흐름이 끊어졌으므로, `current_count`를 0으로 리셋합니다.
5. **결과**: 순회가 끝난 후, `max_count`에 저장된 값이 우리가 찾고자 하는 최대 길이입니다. (만약 문자열 전체가 '1'로만 이루어져도 마지막 갱신 과정에서 최대 길이가 정확하게 기록됩니다.)

### 시간 복잡도
문자열의 길이 $N$에 비례하여 한 번만 순회하므로, 시간 복잡도는 $O(N)$입니다. 공간 복잡도는 추가적인 자료구조를 사용하지 않으므로 $O(1)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} S - '0'과 '1'로만 이루어진 문자열
 * @returns {number} 연속된 '1'의 최대 길이
 */
function solve(S) {
    let maxCount = 0;  // 지금까지 발견된 최대 길이
    let currentCount = 0; // 현재 연속된 '1'의 길이

    for (let i = 0; i < S.length; i++) {
        if (S[i] === '1') {
            // '1'을 만나면 현재 카운트를 증가시키고 최대값 갱신
            currentCount++;
            maxCount = Math.max(maxCount, currentCount);
        } else { // S[i] === '0'
            // '0'을 만나면 연속성이 끊기므로 카운트를 0으로 리셋
            currentCount = 0;
        }
    }
    
    return maxCount;
}

// --- Node.js 입출력 처리 --- 

// 실제 코딩 테스트 환경에서는 아래와 같이 표준 입력을 처리합니다.
// 예시: readline 모듈을 사용하거나, fs.readFileSync(0)를 사용합니다.

const fs = require('fs');

// 표준 입력(stdin) 전체를 읽어옵니다.
let input;
try { 
    // 0은 표준 입력 파일 디스크립터를 의미합니다.
    input = fs.readFileSync(0, 'utf8').trim();
} catch (e) {
    // 테스트 환경에서 에러가 날 경우 대비
    // 이 부분은 실제 실행 환경에 맞춰 수정해야 합니다.
    input = ""; 
}

if (input) {
    const result = solve(input);
    console.log(result);
}
```

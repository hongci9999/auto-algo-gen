# 친구들의 생일 파티
*javascript · 구현 · 보통 · 배열, 정렬, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리합니다. 전체 입력이 들어오면 한 번에 처리하는 것이 효율적입니다.

## 문제

여러 친구들이 모여서 생일 파티를 합니다. 각 친구는 태어난 날짜와 그에 따른 기념품을 가지고 있습니다. 여러분은 이 정보들을 받아서, 생일 순서대로 정렬하고, 같은 날 생일인 친구들은 특별한 방식으로 처리해야 합니다.

각 친구의 정보는 `[날짜(YYYYMMDD), 이름, 기념품]` 형식으로 주어집니다. 여기서 '날짜'는 연도-월-일 형태의 숫자입니다. 모든 날짜는 8자리 정수형이라고 가정합니다.

요구사항은 다음과 같습니다:
1. 친구들을 생일이 빠른 순서대로 (오름차순) 정렬해야 합니다.
2. 만약 같은 날 생일인 친구들이 여러 명 있다면, 이들은 한 그룹으로 묶여야 하며, 각 친구의 기념품에 '축하'라는 문구가 포함되도록 수정해야 합니다. 즉, 해당 친구의 원래 기념품 뒤에 공백과 함께 "(Group Gift)"을 추가하는 것입니다.
3. 최종 결과는 `[날짜, 이름, 변경된_기념품]` 형식의 배열 형태로 출력되어야 하며, 같은 날 생일인 경우에도 개별적인 항목으로 유지해야 합니다 (예: [20240101, 김철수, 축하(Group Gift)]).

주의사항:
- 만약 특정 친구가 유일한 생일 그룹에 속한다면, 기념품은 변경되지 않습니다.
- 출력 순서는 오직 날짜 기준의 오름차순이어야 합니다.

## 입력

첫 줄에는 친구들의 수 N이 주어집니다. 이후 N개의 줄 각각에 '날짜 이름 기념품' 형식으로 데이터가 공백으로 구분되어 입력됩니다. (예: 20240101 김철수 케이크)

## 출력

각 행마다 날짜, 이름, 변경된 기념품을 순서대로 출력합니다. 모든 항목은 문자열로 처리해야 합니다.

## 제약 조건

N의 범위는 1부터 50까지입니다. 날짜는 8자리 정수형으로 주어집니다. 이름과 기념품은 영문/한글 조합이며 공백을 포함할 수 있습니다.

## 예제 1

**입력**
```
4
20240101 김철수 케이크
20240101 이영희 쿠키
20240315 박지민 꽃다발
20240315 최현우 와인
```

**출력**
```
20240101 김철수 축하(Group Gift)
20240101 이영희 축하(Group Gift)
20240315 박지민 축하(Group Gift)
20240315 최현우 축하(Group Gift)
```

*날짜가 같은 그룹은 모두 기념품에 '(Group Gift)'이 추가됩니다.*

## 예제 2

**입력**
```
3
20240520 홍길동 운동화
20240610 김민지 목걸이
20240707 이지은 책
```

**출력**
```
20240520 홍길동 운동화
20240610 김민지 목걸이
20240707 이지은 책
```

*모든 날짜가 다르므로 기념품 변경 없이 순서대로 출력됩니다.*

## 힌트

- 먼저 모든 데이터를 배열에 저장합니다.
- 날짜를 기준으로 정렬하는 것이 핵심입니다. JavaScript의 sort() 메소드를 활용하세요.


## 알고리즘 요약

1. 입력 받은 친구들의 정보를 구조화된 객체 배열로 만듭니다.
2. 이 배열을 '날짜' 필드를 기준으로 오름차순 정렬합니다.
3. 정렬된 배열을 순회하면서, 현재 날짜와 다음 항목의 날짜가 같은지 확인하여 그룹을 찾습니다.
4. 같은 날짜를 가진 친구들(그룹)은 해당 친구들의 기념품 정보를 수정하고, 홀로 떨어진 친구는 기존 기념품을 유지합니다.
5. 최종적으로 수정된 데이터를 순서대로 출력합니다.

## 풀이 해설

이 문제는 주어진 여러 친구의 생일 정보들을 처리하고 특정 조건에 따라 데이터를 변환하는 '구현' 문제입니다.

**아이디어:** 핵심은 날짜 기준으로 정렬한 후, 그룹별로 기념품 변경 여부를 판단하는 것입니다. 단순히 배열을 순회하며 같은 날짜를 만나는지 확인하는 로직이 필요합니다.

**단계:**
1. **데이터 구조화 및 입력 처리:** 먼저 입력을 받고, 각 친구의 데이터를 {날짜: string, 이름: string, 기념품: string} 형태의 객체 배열로 저장합니다.
2. **정렬 (Sort):** 이 객체 배열을 날짜(숫자 비교)를 기준으로 오름차순 정렬합니다. 이렇게 해야 생일 순서대로 처리할 수 있습니다.
3. **그룹화 및 변환:** 정렬된 배열을 처음부터 끝까지 순회합니다. 현재 인덱스 `i`의 친구가 속한 그룹이 몇 명인지 파악해야 합니다. 만약 다음 항목 `i+1`의 날짜도 같고, 그 다음 항목 `i+2`의 날짜도 같다면, 이들은 같은 그룹입니다.
    - **그룹 크기 확인:** 현재 인덱스 `i`부터 시작하여 연속적으로 동일한 날짜를 가진 친구들의 개수(GroupSize)를 계산합니다.
    - **조건 적용:** GroupSize가 1보다 크다면 (즉, 2명 이상이라면), 해당 그룹에 속하는 모든 친구의 기념품을 "축하(Group Gift)"으로 수정합니다. 그렇지 않다면 아무것도 변경하지 않습니다.
4. **출력:** 변환이 완료된 배열의 데이터를 요구사항에 맞는 형식으로 순차적으로 출력합니다.

**시간 복잡도:** 데이터 입력 및 구조화는 $O(N)$입니다. 정렬 과정은 $O(N 	imes 	ext{log} N)$이며, 그룹 탐색 및 변환 과정 역시 한 번의 배열 순회로 $O(N)$이므로, 전체 시간 복잡도는 정렬에 의해 결정되는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 표준 입력을 처리하는 함수
 */
function solve() {
    const fs = require('fs');
    // 전체 입력 문자열을 한 번에 읽어옵니다.
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim();
    } catch (e) {
        // 테스트 환경에서 파일 시스템 접근이 제한될 경우 대비
        return; 
    }

    if (!input) return;

    const lines = input.split('\n');
    const N = parseInt(lines[0].trim());
    let rawData = [];

    // 1. 데이터 구조화 및 입력 처리
    for (let i = 1; i <= N; i++) {
        const line = lines[i].trim();
        if (!line) continue;
        
        // 공백으로 분리하되, 기념품이 공백을 포함할 수 있으므로 주의 깊은 파싱이 필요함.
        // 문제 조건에 따라 '날짜 이름 기념품' 순서로 3개의 요소가 있다고 가정하고 처리합니다.
        const parts = line.split(' ');
        if (parts.length < 3) continue; 

        const date = parts[0];
        // 이름은 두 번째 요소부터, 기념품은 마지막 요소를 제외한 나머지를 재조합하거나, 
        // 문제의 예제 입력 형태(날짜 공백 이름 공백 기념품)를 엄격히 따른다고 가정합니다.
        // 여기서는 가장 간단하게 3개의 토큰으로 분리된다고 가정하고 진행합니다.

        const name = parts[1];
        let gift = '';
        // 만약 기념품이 여러 공백을 포함할 수 있다면, 이 파싱은 복잡해집니다. 
        // 하지만 일반적인 코딩테스트에서는 세 개의 필드가 명확히 분리된다고 가정하는 경우가 많으므로,
        // 예제와 동일하게 3개의 토큰으로 간주합니다.
        gift = parts[2];

        rawData.push({ date: date, name: name, gift: gift });
    }

    let processedData = [...rawData]; // 원본을 수정하지 않기 위해 복사

    // 2. 정렬 (날짜 기준 오름차순)
    processedData.sort((a, b) => {
        // 날짜는 YYYYMMDD 형식의 숫자이므로 숫자로 비교합니다.
        return parseInt(a.date) - parseInt(b.date);
    });

    const N_total = processedData.length;
    let i = 0;
    while (i < N_total) {
        const current_date = processedData[i].date;
        let groupSize = 1;
        let j = i + 1;

        // 3. 그룹 크기 확인 및 변환
        while (j < N_total && processedData[j].date === current_date) {
            groupSize++;
            j++;
        }

        if (groupSize > 1) {
            // 같은 날짜를 가진 그룹이므로 기념품을 수정합니다.
            for (let k = i; k < i + groupSize; k++) {
                const friend = processedData[k];
                friend.gift = `${friend.gift} 축하(Group Gift)`;
            }
        }
        // 다음 탐색 위치로 이동합니다.
        i += groupSize;
    }

    // 4. 출력
    const result = processedData.map(friend => 
        `${friend.date} ${friend.name} ${friend.gift}`
    );

    console.log(result.join('\n'));
}

solve();
```

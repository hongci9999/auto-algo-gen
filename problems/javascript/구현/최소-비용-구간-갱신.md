# 최소 비용 구간 갱신
*javascript · 구현 · 보통 · 배열, 누적합*

## 입출력 환경

JavaScript 환경에서는 표준 입력 전체를 읽어 파싱해야 합니다. 예시 코드에서 사용된 방식으로 배열로 받는다고 가정합니다.

## 문제

N개의 방이 일렬로 늘어서 있습니다. 각 방에는 초기 상태의 '값'이 부여되어 있으며, 이 값은 1부터 N까지 순서대로 주어집니다.

당신은 이 방들 중 연속된 구간 $[L, R]$을 선택하여 모든 방의 값을 $K$만큼 증가시킬 수 있습니다. 이때 비용은 (구간 길이) $	imes K$ 입니다.

하지만 단순히 값을 증가시키는 것 외에, 어떤 방의 값 $A[i]$가 특정 임계값 $T$ 이상이 되면 그 방의 값은 자동으로 $1$로 초기화됩니다. 이 현상을 '클리핑'이라고 합니다.

당신은 최대 $	ext{Cost}$를 초과하지 않는 범위 내에서, 주어진 비용을 사용하여 최대한 많은 횟수의 구간 $[L, R]$ 갱신 작업을 수행하려고 합니다. 각 작업마다 증가량 $K$와 구간 $[L, R]$이 주어집니다.

주어진 모든 작업 $(K_i, L_i, R_i)$를 순서대로 처리했을 때, 최종적으로 방 배열의 합을 최대화하는 것이 목표입니다.

## 입력

첫째 줄에 정수 $N$ (방의 개수)이 주어집니다. 
둘째 줄에 총 작업 횟수 $M$이 주어집니다.
세 번째 줄부터 $M$개의 줄이 이어지며, 각 줄에는 하나의 작업을 나타냅니다. 형식은 $K_i$, $L_i$, $R_i$입니다. ($1 	ext{ <= } K_i 	ext{ <= } 10^3$, $1 	ext{ <= } L_i 	ext{ <= } R_i 	ext{ <= } N$)

## 출력

최종적으로 방 배열의 원소들의 합을 최대화하는 정수 값을 출력합니다.

## 제약 조건

N: 1부터 10,000까지. M: 1부터 50까지. $K_i$: 1부터 1,000까지. 시간 복잡도는 $O(M 	imes N)$ 또는 그 이하가 요구됩니다. (실제로는 시뮬레이션으로 충분)

## 예제 1

**입력**
```
5
3
1 1 2
2 3 4
1 1 5
```

**출력**
```
17
```

*초기: [1, 2, 3, 4, 5]. 1. (K=1, L=1, R=2): [2, 3, 3, 4, 5] -> [2, 3, 3, 4, 5]. (클리핑 없음). 2. (K=2, L=3, R=4): [2, 3, 5, 6, 5] -> [2, 3, 1, 1, 5]. 3. (K=1, L=1, R=5): [3, 4, 2, 2, 6] -> [3, 4, 2, 2, 1]. 최종 합: 12.*

## 예제 2

**입력**
```
3
2
3 1 3
1 1 1
```

**출력**
```
7
```

*초기: [1, 2, 3]. 1. (K=3, L=1, R=3): [4, 5, 6] -> [1, 1, 1]. 2. (K=1, L=1, R=1): [2, 1, 1] -> [2, 1, 1]. 최종 합: 4.*

## 힌트

- 방의 초기 값은 $A[i] = i$ 입니다.
- 구간 $[L, R]$에 $K$를 더한 후, 각 원소 $A'[i]$가 임계값 $T=5$ 이상이면 $1$로 재설정됩니다. (문제에서 명시된 클리핑 임계값이 5라고 가정하고 풀이합니다.)
- 모든 작업을 순서대로 시뮬레이션하며 배열을 업데이트해야 합니다.


## 알고리즘 요약

주어진 초기 배열과 작업 목록을 이용하여, 각 작업을 순차적으로 적용하는 시뮬레이션을 수행합니다. 핵심은 구간 $[L, R]$의 모든 원소에 $K$를 더한 후, 클리핑 규칙(값 $	ext{>= } T ightarrow 1$)을 정확히 적용하여 배열 상태를 업데이트하는 것입니다.

## 풀이 해설

이 문제는 주어진 작업들을 순서대로 처리하며 배열의 변화를 추적하는 시뮬레이션 문제입니다. 

**1. 초기 설정:** 방 배열 $A$는 크기가 $N$이며, $A[i] = i+1$ (0-indexed 기준)로 초기화됩니다.

**2. 작업 처리 루프:** 주어진 $M$개의 작업을 순서대로 반복합니다. 각 작업 $(K, L, R)$에 대해 다음 단계를 수행합니다:
    a. **증가 적용:** 구간 $[L, R]$ (1-indexed)의 모든 원소 $A[i]$에 $K$를 더합니다. 즉, $A[i] = A[i] + K$.
    b. **클리핑 적용:** 증가된 값 $A'[i]$가 임계값 $T=5$ 이상인 경우, 해당 값을 $1$로 재설정합니다. (문제의 예제와 제약 조건을 고려하여 클리핑 임계값을 5로 고정하여 사용했습니다.)
    c. **배열 업데이트:** 최종적으로 수정된 배열 상태를 다음 작업에 사용합니다.

**3. 최종 결과:** 모든 작업을 처리한 후, 배열 $A$의 모든 원소를 합산하면 됩니다.

**시간 복잡도:** $M$개의 작업을 처리하며, 각 작업마다 최대 $N$개의 요소를 순회합니다. 따라서 전체 시간 복잡도는 $O(M 	imes N)$입니다. (주어진 제약 조건 하에서 충분히 효율적입니다.)

## 참고 코드 (javascript)

```javascript
/**
 * JavaScript 환경에서 표준 입력 처리를 가정하고 작성되었습니다.
 * 실제 코딩 테스트에서는 Node.js의 'readline' 모듈 등을 사용하여 입력을 처리해야 합니다.
 */
function solve(inputLines) {
    // 1. 입력 파싱
    const N = parseInt(inputLines[0].trim()); // 방 개수
    if (N === 0) return 0;
    const M = parseInt(inputLines[1].trim()); // 작업 횟수
    
    // 초기 배열 설정: A[i]는 i+1 (1-indexed 개념)
    let arr = [];
    for (let i = 0; i < N; i++) {
        arr.push(i + 1);
    }
    
    // 클리핑 임계값 T 설정 (문제 설명 및 예시를 바탕으로 가정)
    const CLIPPING_THRESHOLD = 5;

    let currentLineIndex = 2;
    
    // 2. 작업 시뮬레이션 처리
    for (let m = 0; m < M; m++) {
        if (currentLineIndex >= inputLines.length) break;
        const line = inputLines[currentLineIndex].trim();
        if (!line) { currentLineIndex++; continue; }
        
        const [K_str, L_str, R_str] = line.split(' ').map(s => s.trim());
        const K = parseInt(K_str);
        const L = parseInt(L_str); // 1-indexed 시작
        const R = parseInt(R_str); // 1-indexed 끝
        currentLineIndex++;
        
        // 배열 인덱스는 0부터 시작하므로, L-1과 R-1을 사용합니다.
        const startIdx = L - 1;
        const endIdx = Math.min(R - 1, N - 1);
        
        // a. 증가 적용 및 b. 클리핑 적용 (동시에 처리)
        for (let i = startIdx; i <= endIdx; i++) {
            let newValue = arr[i] + K;
            if (newValue >= CLIPPING_THRESHOLD) {
                arr[i] = 1;
            } else {
                arr[i] = newValue;
            }
        }
    }

    // 3. 최종 합 계산
    let totalSum = arr.reduce((acc, val) => acc + val, 0);
    return totalSum;
}
```

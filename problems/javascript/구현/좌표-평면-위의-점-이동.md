# 좌표 평면 위의 점 이동
*javascript · 구현 · 보통 · 좌표계, 시뮬레이션*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 모든 입력은 문자열로 처리하고 파싱해야 합니다.

## 문제

2차원 좌표 평면 위에 N개의 점이 있습니다. 각 점 $(x_i, y_i)$는 가로축과 세로축에 대한 거리를 이용하여 움직일 수 있습니다. 점을 이동시키는 방식은 다음과 같습니다.

1. **가로 이동:** 현재 위치의 $y$ 좌표와 같은 높이에 있는 모든 점들을 한 번에 묶어, 이 묶음 전체를 가로 방향으로 1칸씩 이동시킵니다. (모든 $x$좌표에 +1 또는 -1을 적용할 수 있습니다.)
2. **세로 이동:** 현재 위치의 $x$ 좌표와 같은 높이에 있는 모든 점들을 한 번에 묶어, 이 묶음 전체를 세로 방향으로 1칸씩 이동시킵니다. (모든 $y$좌표에 +1 또는 -1을 적용할 수 있습니다.)

주어진 N개의 점들에 대해 최대 몇 번의 '이동' 연산을 수행해야 모든 점들의 좌표가 동일해질 수 있는지 구하세요. 이때, 한 번의 이동은 묶여서 동시에 움직이는 것을 의미합니다.

*주의: 모든 점들이 $(x', y')$라는 같은 좌표에 위치하려면, 모든 $x'$ 값과 모든 $y'$ 값이 같아야 합니다.*

## 입력

첫 번째 줄에 정수 N이 주어집니다. 다음 N줄에는 각 점의 초기 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어진 형식입니다.

## 출력

모든 점들이 동일한 좌표를 갖기 위해 필요한 최소 이동 횟수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 50
-1000 <= $x_i, y_i$ <= 1000

## 예제 1

**입력**
```
3
1 2
1 4
3 2
```

**출력**
```
2
```

*점 (1, 2)와 (3, 2)를 가로 이동(x+1)시켜 (2, 2), (4, 2)가 됩니다. 이후 모든 점을 세로 이동(-1)시키면 모두 같은 좌표에 위치합니다.*

## 예제 2

**입력**
```
4
0 0
1 1
0 1
1 0
```

**출력**
```
1
```

*점들을 가로 이동(x+1)시키면 (1, 0), (2, 1), (1, 1), (2, 0)이 됩니다. 이때 모든 점들의 x 좌표가 같지 않으므로 실패합니다.
최소한의 이동은 모든 점을 한 번에 움직여서 가능한 최소값으로 접근해야 합니다. 여기서는 모두 (1, 1)로 모일 수 있습니다. (x+1), (y-1) 연산이 필요합니다.*

## 예제 3

**입력**
```
2
5 5
5 5
```

**출력**
```
0
```

*이미 모든 점들이 같은 좌표에 위치하므로 이동 횟수는 0입니다.*

## 힌트

- 최종적으로 모든 점의 좌표가 $(X, Y)$로 같아진다고 가정하고 접근해 보세요.
- 이동 연산은 특정 $x$ 또는 $y$ 값에 속한 모든 점을 동시에 움직입니다. 이는 곧 '평균'이나 '기준점'으로 수렴하는 문제입니다.


## 알고리즘 요약

최종적으로 모든 점이 같은 좌표 $(X, Y)$에 도달하려면, 각 점의 초기 좌표 $(x_i, y_i)$가 각각 $X$와 $Y$로 이동해야 합니다. 가로/세로 이동 횟수의 합을 최소화하는 문제가 됩니다.

## 풀이 해설

핵심 아이디어는 모든 점이 최종적으로 하나의 동일한 좌표 $(X, Y)$에 모인다고 가정하고, 필요한 최소 이동 횟수를 구하는 것입니다.

1. **필요 조건 분석:** 주어진 $N$개의 점들 $\{(x_1, y_1), \dots, (x_N, y_N)\}$이 모두 $(X, Y)$로 모이려면,
    a) 모든 초기 $x_i$ 값은 최종 목표 $X$까지의 거리가 최소가 되어야 합니다.
    b) 모든 초기 $y_i$ 값은 최종 목표 $Y$까지의 거리가 최소가 되어야 합니다.

2. **최소 이동 횟수:** 주어진 수열 $S = \{s_1, s_2, \dots, s_N\}$을 특정 값 $T$로 모두 모으는 데 필요한 최소 이동 거리는 $\sum |s_i - T|$를 최소화하는 것입니다. 이는 통계적으로 **중앙값(Median)**으로 목표 $T$를 설정했을 때 달성됩니다.
    - 가로 이동에 대한 최소 횟수: 모든 초기 $x_i$ 값들을 정렬하여 중앙값을 찾고, 이 중앙값으로부터의 거리를 모두 합산합니다. (실제로는 단순히 $|x_{max} - x_{min}|$과 같은 범위가 아님을 주의해야 합니다.)
    - **오류 수정:** 문제에서 정의된 '이동'은 묶음을 한 번에 움직이는 것이므로, 전체 $x$ 좌표의 최소값과 최대값 사이의 거리를 줄여야 합니다.
    - 가장 간단한 시나리오는 모든 점들이 최종적으로 $(X, Y)$에 모인다는 것입니다. 이때 필요한 총 이동 횟수는 $\sum |x_i - X| + \sum |y_i - Y|$가 아닙니다. 왜냐하면 가로/세로 이동은 독립적이기 때문입니다.
    - **정확한 접근:** 모든 점의 $x$ 좌표를 모았을 때, 이들을 하나의 값 $X$로 모으려면 최소 $\max(x) - 	ext{median}(x)$와 관련이 있습니다. 하지만 문제 조건 상 '가로 이동'은 특정 $y$ 레벨에 있는 점들만 영향을 받고, '세로 이동'은 특정 $x$ 레벨에 있는 점들만 영향을 받습니다.
    - **재해석 및 단순화:** 이 문제는 모든 점들을 하나의 좌표 $(X, Y)$로 수렴시키는 최소의 총 거리를 구하는 문제로 해석해야 하며, 가장 간단한 형태는 모든 $x_i$가 $X$로 모이고, 모든 $y_i$가 $Y$로 모이는 것입니다. 만약 이동이 자유로운 평면이라면, $\sum |x_i - X| + \sum |y_i - Y|$를 최소화하는 것이 맞습니다.
    - **최종 결론 (문제 의도 반영):** 이 문제는 모든 점들을 $(X, Y)$로 모으기 위해 필요한 $x$ 축 방향의 총 이동 거리와 $y$ 축 방향의 총 이동 거리를 합산한 값이 최소가 되는 지점을 찾아야 합니다. 따라서, 독립적으로 $x$ 좌표들의 중앙값과 $y$ 좌표들의 중앙값을 구하여 그 합을 답으로 합니다.

3. **단계별 풀이:**
    a) 모든 $x_i$ 값을 리스트로 추출하고 오름차순 정렬합니다.
    b) 필요한 최소 이동 횟수 $\text{Cost}_x$: 정렬된 $x$ 값들의 중앙값(Median)을 구하여, 각 $x_i$와 중앙값의 차이 절댓값 합 $\sum |x_i - 	ext{Median}(x)|$를 계산합니다.
    c) 모든 $y_i$ 값을 리스트로 추출하고 오름차순 정렬합니다.
    d) 필요한 최소 이동 횟수 $\text{Cost}_y$: 정렬된 $y$ 값들의 중앙값(Median)을 구하여, 각 $y_i$와 중앙값의 차이 절댓값 합 $\sum |y_i - 	ext{Median}(y)|$를 계산합니다.
    e) 최종 답은 $\text{Cost}_x + \text{Cost}_y$입니다. (실제 이동 횟수 자체가 거리의 합과 동일하다고 가정)

4. **시간 복잡도:** $N$개의 점이 있으므로, $X$ 좌표 정렬 및 중앙값 계산에 $O(N 	imes 	ext{log} N)$이 걸리고, $Y$ 좌표에 대해서도 마찬가지입니다. 따라서 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * JavaScript 환경에서 표준 입력을 처리하는 헬퍼 함수입니다.
 */
function solve() {
    const fs = require('fs');
    // Node.js의 경우 /dev/stdin 또는 실제 파일 경로를 사용합니다.
    let input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0] === '') return;

    const N = parseInt(input[0].trim());
    if (N === 0) {
        console.log(0);
        return;
    }

    let xCoords = [];
    let yCoords = [];

    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (!line) continue;
        const [x, y] = line.split(' ').map(Number);
        xCoords.push(x);
        yCoords.push(y);
    }

    /**
     * 주어진 배열의 중앙값(Median)을 구하고, 그 중앙값으로부터 모든 요소까지의 거리 합(Cost)을 반환합니다.
     * @param {number[]} arr - 좌표 값들의 배열
     * @returns {bigint} 최소 이동 비용
     */
    function calculateMinCost(arr) {
        // 1. 정렬 (O(N log N))
        const sortedArr = [...arr].sort((a, b) => a - b);
        
        // 2. 중앙값 찾기 (Median)
        // 배열 크기가 N일 때, 인덱스 Math.floor((N-1)/2)가 중앙값을 제공합니다.
        const medianIndex = Math.floor((sortedArr.length - 1) / 2);
        const median = sortedArr[medianIndex];

        // 3. 비용 계산 (O(N))
        let totalCost = 0;
        for (const val of arr) {
            totalCost += Math.abs(val - median);
        }
        return BigInt(totalCost);
    }

    // X 좌표에 대한 최소 이동 비용 계산
    const costX = calculateMinCost(xCoords);
    
    // Y 좌표에 대한 최소 이동 비용 계산
    const costY = calculateMinCost(yCoords);

    // 최종 답은 두 독립적인 축의 최소 이동 횟수의 합
    console.log((costX + costY).toString());
}

solve();
```

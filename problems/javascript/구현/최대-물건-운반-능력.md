# 최대 물건 운반 능력
*javascript · 구현 · 보통 · 배열, 시뮬레이션*

## 입출력 환경

JavaScript 환경에서는 일반적으로 JSON 객체 형태로 모든 데이터를 받는다고 가정합니다. 실제 입력은 {N: number, K: number, weights: array<number>, stops: array<number>}와 같은 구조일 것입니다.

## 문제

당신은 컨베이어 벨트 위에 놓인 다양한 물건들을 옮기는 로봇을 조종합니다. 각 물건은 고유의 무게를 가지고 있습니다. 이 물건들은 한 줄로 나란히 놓여 있으며, 당신은 최대 $K$개의 물건까지 동시에 운반할 수 있습니다.

로봇이 지나가는 경로에는 여러 개의 '정지 지점'과 '운반 구역'이 존재합니다. 정지 지점에 도착하면 로봇은 잠시 멈추고, 그 지점에서 현재 가지고 있는 모든 물건을 내려놓아야 합니다. 운반 구역에서는 최대 $K$개의 물건을 집어 옮길 수 있습니다.

당신이 지나가야 하는 전체 경로는 다음과 같이 구성됩니다:
*   **$[1, N]$**: 전체 경로의 길이입니다.
*   **물건들 (Weight)**: `weights[i]`는 $i$번째 위치에 놓인 물건의 무게입니다. 이 배열은 0부터 $N-1$까지 정의되어 있습니다.
*   **정지 지점 (Stop)**: `stops` 배열에는 정지 지점의 인덱스(배열 기준)들이 포함됩니다. 로봇은 반드시 이 모든 지점을 지나가야 하며, 도착할 때마다 물건을 내려놓습니다.
*   **운반 능력 (Capacity)**: 최대 $K$개의 물건을 운반할 수 있습니다.

로봇이 처음 시작하는 위치는 0입니다. 목표는 로봇이 모든 정지 지점을 순서대로 지나가면서, 각 구역에서 최대한 많은 무게의 물건을 모아 최종적으로 **모든** 정지 지점에 도착했을 때 남아있는 최대 총 무게를 계산하는 것입니다. 단, 한 번에 운반할 수 있는 개수는 $K$개로 제한됩니다.

운반은 순차적으로 진행되며, 현재 위치에서 다음 정지 지점까지의 구간을 거치면서 물건들을 줍거나 내려놓는 과정을 반복합니다.

## 입력

첫째 줄에 정수 $N$과 최대 운반 개수 $K$가 주어집니다. (1 <= N <= 100, 1 <= K <= 10)

## 출력

로봇이 모든 정지 지점을 지나간 후 남아있는 최대 총 무게를 출력합니다.

## 제약 조건

N: 1부터 100까지
K: 1부터 10까지
weights: N개의 양의 정수 (1 <= weights[i] <= 10)
stops: 정지 지점 인덱스 배열. 반드시 0을 포함하며, 오름차순으로 주어집니다.
시간 복잡도는 $O(N 	imes K^2)$ 이하를 목표로 합니다.

## 예제 1

**입력**
```
N=5, K=2, weights=[10, 3, 8, 4, 6], stops=[0, 2, 4]
```

**출력**
```
27
```

*정지 지점(0)에서 [10] 무게의 물건을 가지고 시작. 다음 정지 지점(2)까지 이동하며 [3]과 [8] 중 최대 합계 2개를 선택하여 운반 (총 무게 11). 도착 후 내려놓음. 마지막 구간에서 남은 총 무게는 27.*

## 예제 2

**입력**
```
N=6, K=3, weights=[5, 5, 5, 5, 5, 5], stops=[0, 2, 4]
```

**출력**
```
45
```

*정지 지점(0)에서 [5] 무게의 물건을 가지고 시작. 다음 정지 지점(2)까지 이동하며 최대 3개 선택 (총 무게 15). 도착 후 내려놓음. 마지막 구간에서 남은 총 무게는 45.*

## 힌트

- 이 문제는 동적 계획법(DP) 또는 그리디 알고리즘으로 접근할 수 있습니다.
- 각 정지 지점 사이의 운반 과정에서 '최대 가치'를 찾는 것이 핵심입니다.


## 알고리즘 요약

DP/Greedy 조합: 이 문제는 구간별로 최적의 선택을 반복해야 합니다. 각 구간 $[stops[i], stops[i+1]]$에 대해, 해당 구간에 존재하는 물건들 중 $K$개 이하로 최대 무게를 가진 조합을 찾아야 합니다. 전체 과정은 정지 지점의 개수만큼 DP 상태 전이를 수행합니다.

## 풀이 해설

이 문제는 순차적으로 진행되는 '최대 가치 선택' 문제입니다. 로봇은 각 정지 지점을 지나갈 때마다, 그 구간에 놓인 물건들 중 최대 $K$개까지 골라 운반해야 합니다.

**1. 문제 정의 및 단계 설정:**
우리는 `stops` 배열의 인덱스를 따라 순차적으로 진행합니다. 현재 위치 $S_{i}$에서 다음 정지 지점 $S_{i+1}$로 이동하는 구간을 처리해야 합니다. 이 과정은 독립적인 최적화 문제입니다.

**2. 한 구간에서의 최대 무게 선택 (핵심 부분):**
$S_i$부터 $S_{i+1}-1$까지의 물건들(weights 배열 기준) 중에서, 가장 무거운 물건들을 골라야 합니다. 왜냐하면 이 물건들은 다음 정지 지점까지 운반되어 누적 무게에 기여하기 때문입니다.

만약 현재 구간 $[start, end]$가 주어지고, $K$개의 물건을 선택해야 한다면, 단순히 가장 무거운 $K$개를 고르면 됩니다. 이는 **그리디(Greedy) 방식**으로 해결됩니다. 해당 구간의 모든 물건 무게를 추출하여 내림차순 정렬한 뒤, 상위 $	ext{min}(K, 	ext{길이})$개의 합을 구하면 됩니다.

**3. 전체 프로세스:**
총 운반 무게는 각 정지 지점 사이의 최대 선택 무게들을 모두 더한 값입니다. (문제 조건에 따라, 최종적으로 모든 정지 지점에서 내려놓은 후 남아있는 '최대 총 무게'를 계산합니다.)

*   $i=0$: 첫 번째 구간 시작. $stops[0]$부터 $stops[1]-1$까지의 물건 중 최대 $	ext{min}(K, 	ext{길이})$개의 합을 구하여 총합에 더합니다.
*   $i=1$: 두 번째 구간. $stops[1]$부터 $stops[2]-1$까지의 물건 중 최대 $	ext{min}(K, 	ext{길이})$개의 합을 구하여 총합에 더합니다.
*   ... 반복하여 모든 정지 지점 사이의 운반 무게를 모두 합산합니다.

**4. 시간 복잡도:**
정지 지점의 개수를 $M$이라고 할 때, 루프는 $M-1$번 실행됩니다. 각 구간 $[S_i, S_{i+1}-1]$의 길이를 $L_i$라고 하면, 해당 구간에서 물건들을 추출하여 정렬하는 데 $O(L_i 	imes 	ext{log}(L_i))$ 시간이 걸립니다. 전체 시간 복잡도는 모든 $L_i$를 합한 총 길이 $N$과 $	ext{log}$ 항을 고려할 때, 최악의 경우 $O(N 	imes 	ext{log} N)$ 정도가 됩니다. (제약 조건에 맞춰 구현 가능합니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} N - 전체 경로 길이
 * @param {number} K - 최대 운반 개수
 * @param {number[]} weights - 물건 무게 배열
 * @param {number[]} stops - 정지 지점 인덱스 배열 (오름차순, 0 포함)
 * @returns {number} 최종적으로 모을 수 있는 최대 총 무게
 */
const solve = (N, K, weights, stops) => {
    let totalMaxWeight = 0;
    // 정지 지점의 개수만큼 반복하며 구간을 순회합니다.
    for (let i = 0; i < stops.length - 1; i++) {
        const startIdx = stops[i];
        const endIdxExclusive = stops[i + 1]; // 다음 정지 지점 바로 전까지가 운반 구역입니다.
        
        // [startIdx, endIdxExclusive - 1] 구간의 물건 무게를 수집합니다.
        let currentWeights = [];
        for (let j = startIdx; j < endIdxExclusive; j++) {
            currentWeights.push(weights[j]);
        }

        // 그리디 접근: 가장 무거운 K개를 선택해야 합니다.
        // 1. 무게 배열을 내림차순으로 정렬합니다.
        currentWeights.sort((a, b) => b - a);

        // 2. 실제로 운반 가능한 물건 개수와 구간의 길이를 비교하여 최소값을 선택합니다.
        const countToTake = Math.min(K, currentWeights.length);
        
        // 3. 상위 'countToTake'개의 합을 구하여 총 무게에 더합니다.
        let segmentWeight = 0;
        for (let k = 0; k < countToTake; k++) {
            segmentWeight += currentWeights[k];
        }
        
        totalMaxWeight += segmentWeight;
    }
    return totalMaxWeight;
};

// 테스트 케이스 실행 예시 (실제 환경에서는 입력을 받습니다)
/*
console.log(solve(5, 2, [10, 3, 8, 4, 6], [0, 2, 4])); // 기대값: 27
console.log(solve(6, 3, [5, 5, 5, 5, 5, 5], [0, 2, 4])); // 기대값: 45
*/
```

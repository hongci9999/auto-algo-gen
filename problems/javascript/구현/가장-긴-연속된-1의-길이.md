# 가장 긴 연속된 1의 길이
*javascript · 구현 · 보통 · 문자열, 순회*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 전체 입력이 끝날 때까지 처리하거나, 한 줄만 받는다고 가정합니다.

## 문제

주어진 문자열 $S$가 있습니다. 이 문자열에는 '0'과 '1'만 포함되어 있습니다.
당신은 문자열 $S$에서 연속으로 나타나는 '1'의 가장 긴 길이(최댓값)를 찾아야 합니다.

예시: S = "11011101"
연속된 1의 길이는 각각 2, 3, 1 입니다. 이 중 최댓값은 3입니다.

## 입력

첫째 줄에 문자열 $S$가 주어집니다.

## 출력

정수 하나를 출력합니다.

## 제약 조건

문자열 $S$의 길이 $N$은 2 이상 100,000 이하입니다. (시간 복잡도는 O(N)을 목표로 합니다.)

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*가장 긴 연속된 '1'의 구간은 "111"로 길이 3입니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열에 '1'이 포함되지 않아 최대 길이는 0입니다.*

## 힌트

- 현재 계산 중인 연속된 '1'의 길이를 변수로 유지하세요.
- 만약 문자가 '0'이라면, 현재 카운트를 초기화해야 합니다.


## 알고리즘 요약

순회(Iteration) 및 상태 변수 관리. 문자열을 처음부터 끝까지 순회하면서, 만날 때마다 연속되는 '1'의 개수를 세고, 그 값이 현재까지 기록된 최댓값보다 크면 갱신합니다.

## 풀이 해설

문제는 문자열 전체를 한 번만 지나가면서(O(N) 시간 복잡도) 가장 긴 연속된 '1'의 길이를 찾는 문제입니다.

**아이디어:** 두 개의 변수를 사용합니다. `currentLength`는 현재 순회 중인 위치까지 연속되는 '1'의 길이, `maxLength`는 지금까지 발견한 최대 연속 '1'의 길이입니다.

**단계:**
1. 초기화: `currentLength = 0`, `maxLength = 0`으로 설정합니다.
2. 순회: 문자열 $S$의 첫 글자부터 마지막 글자까지 반복합니다.
3. 로직 처리:
   - 만약 현재 문자가 '1'이라면, `currentLength`를 1 증가시킵니다.
   - 만약 현재 문자가 '0'이라면, 연속이 끊겼으므로 `currentLength`를 다시 0으로 초기화합니다.
4. 최댓값 갱신: 반복문 내부의 매 단계마다, `maxLength = Math.max(maxLength, currentLength)`를 수행하여 최대 길이를 항상 업데이트 해줍니다.
5. 종료: 순회가 끝나면 `maxLength`에 저장된 값이 정답입니다.

**시간 복잡도:** 문자열을 한 번만 순회하므로 O(N)입니다. 공간 복잡도는 추가 변수만 사용하므로 O(1)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 받기 위해 readline 모듈을 사용합니다.
 */
const fs = require('fs');

function solve() {
    // 동기적으로 모든 입력 데이터를 읽어옵니다. (테스트 환경 가정)
    // 실제 코딩 테스트에서는 process.stdin나 readline을 사용하는 것이 일반적입니다.
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim();
    } catch (e) {
        // 파일 시스템 접근이 불가능할 경우를 대비하여 빈 문자열 처리
        console.log(0);
        return;
    }

    if (!input || input.length === 0) {
        console.log(0); 
        return;
    }

    let maxLength = 0; // 지금까지 발견한 최대 길이
    let currentLength = 0; // 현재 연속된 '1'의 길이

    for (let i = 0; i < input.length; i++) {
        const char = input[i];
        if (char === '1') {
            currentLength++;
        } else { // char === '0'
            // 연속이 끊기면 현재 길이를 초기화합니다.
            currentLength = 0;
        }
        // 매 단계마다 최대값을 갱신합니다.
        maxLength = Math.max(maxLength, currentLength);
    }

    console.log(maxLength);
}

solve();
```

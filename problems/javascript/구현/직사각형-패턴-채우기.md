# 직사각형 패턴 채우기
*javascript · 구현 · 보통 · 구현, 배열*

## 입출력 환경

JavaScript 환경에서 표준 입력을 받기 위해 Node.js의 `readline` 모듈 또는 유사한 스트림 처리 방식을 사용해야 합니다. 전체 입력을 배열로 읽어 처리하는 것이 가장 효율적입니다.

## 문제

당신은 격자 형태의 직사각형 모양의 공간을 채우는 작업을 합니다. 이 공간은 N개의 행과 M개의 열로 이루어져 있습니다. 각 칸에는 0 또는 1 중 하나의 값이 들어갑니다.

주어진 N x M 크기의 2차원 배열 `grid`가 있습니다. 이 격자 안에는 '직사각형 패턴'이라고 불리는 특정 패턴이 존재합니다. 이 패턴은 가로 또는 세로로 연속되는 1의 블록들로 이루어져 있으며, 최소한 2x2 크기 이상의 사각형 영역을 완전히 덮는 형태를 갖습니다. 

당신의 목표는 이 `grid`에서 가장 큰 직사각형 패턴의 크기(가장 긴 변의 길이)를 찾는 것입니다. 크기는 가로 길이와 세로 길이 중 큰 값으로 정의합니다. 만약 패턴이 존재하지 않는다면 0을 반환합니다.

## 입력

첫 번째 줄에 N과 M (N <= M)이 공백으로 구분되어 주어집니다. (N: 행의 개수, M: 열의 개수)
두 번째 줄부터 N줄에 걸쳐 M개의 정수(0 또는 1)가 공백으로 구분되어 주어집니다. 이가 grid의 값입니다.

## 출력

가장 큰 직사각형 패턴의 크기(가로 길이와 세로 길이 중 큰 값)를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10; 1 <= M <= 100; 그리드 값은 0 또는 1입니다.

## 예제 1

**입력**
```
3 4
1 1 0 0
1 1 1 0
1 1 1 0
```

**출력**
```
3
```

*2x3 크기의 직사각형 패턴(2행, 3열)이 존재하며, 최대 크기는 3입니다.*

## 예제 2

**입력**
```
2 2
1 1
1 1
```

**출력**
```
2
```

*2x2 크기의 패턴이 존재하며, 최대 크기는 2입니다.*

## 예제 3

**입력**
```
3 3
1 0 0
0 0 0
0 0 0
```

**출력**
```
0
```

*2x2 이상의 패턴이 존재하지 않습니다.*

## 힌트

- 최소 2x2 조건을 만족하는 사각형을 찾아야 합니다.
- DP를 사용하여 현재 위치까지 연속되는 1의 길이를 추적하는 것이 유리합니다.


## 알고리즘 요약

이 문제는 최소 2x2 이상의 직사각형 패턴을 찾는 문제입니다. 이 조건을 만족하는 가장 큰 직사각형의 크기(max(가로, 세로))를 구해야 합니다. DP(Dynamic Programming)를 활용하여 각 칸을 오른쪽 아래 끝점으로 하는 직사각형의 크기를 추적할 수 있습니다. 특히, 각 칸 `(r, c)`에서 시작하여 위로 연속되는 1의 길이(`height`)와 왼쪽으로 연속되는 1의 길이(`width`)를 계산하고, 이 값을 바탕으로 가능한 모든 직사각형 영역의 최대 크기를 갱신합니다. 가장 간단한 방법은, 모든 가능한 직사각형의 경계를 탐색하는 것입니다. 하지만 제약 조건(N<=10, M<=100)을 고려할 때, O(N^2 * M) 또는 O(N * M^2) 정도의 복잡도를 가진 방법도 가능합니다. 여기서는 각 칸을 우하단 꼭짓점으로 하여 최대 사각형을 찾는 방식을 사용합니다.

## 풀이 해설

### 아이디어
주어진 문제는 N x M 격자에서 최소 2x2 이상의 1로 채워진 직사각형 패턴 중 가장 큰 크기(가로 길이와 세로 길이 중 큰 값)를 찾는 것입니다. 이 문제를 풀기 위해, 우리는 각 칸 `(r, c)`를 직사각형 패턴의 우하단 꼭짓점으로 가정하고, 이 위치에서 시작할 수 있는 가장 큰 직사각형의 크기를 계산할 것입니다.

### 단계
1. **DP 배열 정의**: 먼저, `dp[r][c]`를 정의합니다. 이 값은 `(r, c)`를 우하단 꼭짓점으로 하는 최대 크기의 직사각형이 아닌, **(r, c)를 포함하는 가장 큰 직사각형의 높이(세로 길이)**가 아니라, **(r, c)를 우하단 꼭짓점으로 하는 직사각형 패턴의 최대 가로 길이**를 나타내는 것이 아니라, **(r, c)에 1이 연속하는 세로 길이(height)**와 **가장 큰 사각형의 크기**를 동시에 추적하는 것이 복잡합니다. 가장 간단한 접근은, 각 칸에서 시작하여 위로 연속되는 1의 길이(`height`)를 계산하는 것입니다.
2. **Height 계산**: `height[r][c]` 배열을 사용하여, `grid[r][c]`를 포함하여 위로 연속되는 1의 개수를 계산합니다. 만약 `grid[r][c] == 0`이면 `height[r][c] = 0`입니다. 그렇지 않다면 `height[r][c] = height[r-1][c] + 1`입니다.
3. **사각형 탐색 (가로 길이 고정)**: 이제 `height` 배열을 이용합니다. 특정 행 `r`과 특정 열 `c`를 고정했다고 가정합시다. `height[r][c]`가 높이를 결정합니다. 이 높이를 유지하면서, `r`행을 따라 좌우로 이동하며 연속되는 1의 블록을 찾습니다. 실제로, 이 문제를 풀기 위해서는, 모든 가능한 직사각형의 모든 경계가 1인지 확인해야 합니다.
4. **최적화된 탐색**: 우리는 모든 행 `r`에 대해, 마치 스택을 이용하는 'Largest Rectangle in Histogram' 문제처럼 접근할 수 있습니다. 각 행 `r`에서 `height[r]` 배열(즉, `height[r][0]`부터 `height[r][M-1]`까지)을 히스토그램으로 간주합니다. 이 히스토그램에서 가장 넓은 직사각형 면적을 찾을 수 있습니다. 하지만 우리는 면적이 아니라, 크기 `max(가로, 세로)`를 최대화해야 합니다.
5. **최종 로직**: 최대 크기를 저장할 변수 `max_size`를 0으로 초기화합니다. 모든 행 `r`과 모든 열 `c`에 대해 반복합니다. 만약 `grid[r][c] == 1`이라면, `height[r][c]`를 계산합니다. 그다음, 이 높이 `H = height[r][c]`를 고정하고, 이 높이를 유지하면서 좌우로 확장할 수 있는 최대 가로 길이 `W`를 찾습니다. 즉, `W`는 `c`를 중심으로 좌우로 이동하면서 `height[r][c-k] >= H`이고 `height[r][c+k] >= H`를 만족하는 가장 큰 $k$의 값입니다. 

실제 구현에서는, `max_size`를 0으로 초기화하고, 모든 행 `r`과 모든 열 `c`에 대해 반복하며, 현재 위치가 직사각형의 우하단 꼭짓점일 때, 가능한 모든 가로 길이 $W$와 세로 길이 $H$를 탐색합니다. 이 탐색은 너무 복잡하므로, 가장 효율적인 방법은 다음과 같습니다:

- **최대 사각형 영역 찾기**: 모든 `r`과 `c`에 대해, `(r, c)`를 우하단 꼭짓점으로 하는 직사각형의 높이 $H$와 가로 길이 $W$를 결정합니다. 이 때, $H$는 `height[r][c]`가 최소값으로 제한하고, $W$는 $	ext{min}(	ext{height}[r][c], 	ext{height}[r][c-1], 	ext{height}[r][c-2], 	ext{height}[r][c-3])$ 등이 아닌, 직사각형의 모든 칸이 1을 유지해야 합니다.
- **간소화된 탐색**: $O(N 	imes M^2)$ 또는 $O(N^2 	imes M)$ 복잡도로 모든 가능한 직사각형을 탐색합니다. $N 	imes M$ 칸 중, 모든 칸 $r_1, r_2, c_1, c_2$를 선택하여 직사각형을 만듭니다. 이 방법은 너무 느립니다.

**결론적으로, 가장 간단하고 제약 조건을 만족하는 방법은 다음과 같습니다.**
1. `height[r][c]`를 계산합니다 (위로 연속되는 1의 길이).
2. 모든 행 `r`에 대해, 이 `height[r]` 배열을 히스토그램으로 간주하고, 이 히스토그램에서 가장 넓은 직사각형 면적을 찾는 일반적인 알고리즘을 사용합니다. 이 알고리즘은 각 높이 $h$에 대해, $h$를 높이로 가지는 가장 넓은 직사각형의 너비 $w$를 찾습니다.
3. 이 과정에서 얻는 직사각형의 크기 $	ext{max}(	ext{가로 } w, 	ext{세로 } h)$를 계산하여 최대값을 갱신합니다.

(참고: 'Largest Rectangle in Histogram' 문제는 면적을 구하지만, 여기서는 $	ext{max}(w, h)$를 최대화하는 것이 목표이므로, 이 알고리즘의 결과를 활용합니다.)

### 시간 복잡도
시간 복잡도는 $O(N 	imes M)$입니다. 각 행에 대해 $O(M)$ 시간이 소요되는 'Largest Rectangle in Histogram'과 유사한 탐색을 $N$번 수행하기 때문입니다. (실제 구현에서는 스택을 이용해 $O(M)$으로 처리 가능).

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[][]} grid N x M 격자 (0 또는 1)
 * @returns {number} 최대 크기
 */
function solve(grid) {
    const N = grid.length;
    if (N === 0) return 0;
    const M = grid[0].length;
    if (M === 0) return 0;

    // height[r][c]: (r, c)를 포함하여 위로 연속되는 1의 길이
    const height = Array(N).fill(0).map(() => Array(M).fill(0));
    for (let r = 0; r < N; r++) {
        for (let c = 0; c < M; c++) {
            if (grid[r][c] === 1) {
                height[r][c] = (r > 0 ? height[r - 1][c] : 0) + 1;
            }
        }
    }

    let maxSize = 0;

    // 모든 행 r에 대해 히스토그램을 처리
    for (let r = 0; r < N; r++) {
        const h = height[r];
        
        // 스택을 이용한 Largest Rectangle in Histogram의 변형 (O(M))
        // 스택에는 인덱스만 저장합니다.
        const stack = []; 
        // 이전 높이 (height[r][i-1])를 저장하여 계산에 사용합니다.
        let prevHeight = 0;
        
        for (let c = 0; c <= M; c++) {
            // c == M 인 경우, 모든 스택을 비우기 위해 0 높이를 사용합니다.
            const currentHeight = (c === M) ? 0 : h[c];

            // 현재 높이보다 큰 높이들을 스택에서 제거하고 계산
            while (stack.length > 0 && h[stack[stack.length - 1]] >= currentHeight) {
                const heightIndex = stack.pop();
                const currentHeightValue = h[heightIndex];
                
                // 직사각형의 너비: 현재 인덱스(c)와 스택의 맨 위 인덱스(stack.length > 0 ? stack[stack.length - 1] : -1) 사이의 길이
                // 너비는 c - 1 - (stack.length > 0 ? stack[stack.length - 1] : -1)로 계산됩니다.
                // 정확한 너비는 (현재 위치 c) - (스택의 맨 위 인덱스) - 1 입니다.
                const width = stack.length === 0 ? c : c - stack[stack.length - 1] - 1;
                
                // 최대 크기 갱신: max(가로, 세로)
                maxSize = Math.max(maxSize, Math.max(currentHeightValue, width));
            }
            
            if (c < M) {
                stack.push(c);
            }
        }
    }

    return maxSize; 
}

// --- 입출력 처리 예시 (Node.js 환경) ---
function solveIO() {
    const fs = require('fs');
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length === 0) {
        console.log(0);
        return;
    }

    // 첫 줄: N M
    const [N, M] = input[0].split(' ').map(Number);
    if (N === 0 || M === 0) {
        console.log(0);
        return;
    }

    // 그리드 데이터
    const grid = [];
    for (let i = 1; i <= N; i++) {
        grid.push(input[i].split(' ').map(Number));
    }

    const result = solve(grid);
    console.log(result);
}
```

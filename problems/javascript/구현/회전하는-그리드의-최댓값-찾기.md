# 회전하는 그리드의 최댓값 찾기
*javascript · 구현 · 보통 · 그리드 탐색, 시뮬레이션*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받을 수 있습니다. 첫 줄에 N이, 다음 N줄에 그리드 데이터가 순차적으로 주어집니다.

## 문제

N x N 크기의 그리드가 주어지고, 이 그리드의 각 칸에는 0 또는 1의 값이 들어 있습니다. 그리드는 시계 방향으로 한 칸씩 순환하며 회전합니다. 매 초마다 그리드는 한 번 회전하며, 현재 시간에 나타나는 최댓값(가장 큰 숫자의 합)을 구하는 문제입니다.

다만, '최댓값'은 단순히 1의 개수가 아니라, 특정 패턴을 의미합니다. 즉, 그리드에서 **좌상단부터 우하단으로 이어지는 대각선 방향**의 연속된 1들의 최대 길이입니다. 이 최대 길이를 매 초마다 구해야 합니다.

회전 과정에서 발생하는 모든 시점의 최댓값을 찾아야 하며, 가장 큰 값을 반환합니다.

## 입력

첫 번째 줄에 N (그리드 크기)이 주어집니다. 다음 N줄에 걸쳐 0과 1로 이루어진 문자열(또는 숫자) 형태의 그리드 값이 주어집니다.

## 출력

회전하는 과정에서 발견되는 모든 대각선 연속 1들의 최대 길이 중 가장 큰 값을 정수 형태로 출력합니다.

## 제약 조건

N은 2부터 10까지의 값입니다. (작은 크기로 시뮬레이션 가능)

## 예제 1

**입력**
```
3
101
011
110
```

**출력**
```
2
```

*초기 상태에서 최대 대각선 길이는 2입니다. 회전해도 2를 초과하지 않습니다.*

## 예제 2

**입력**
```
4
1100
1100
0011
0111
```

**출력**
```
3
```

*회전하는 과정 중, 특정 시점의 대각선 길이 최대값이 3이 됩니다.*

## 힌트

- 그리드의 회전 변환 규칙을 정확히 이해해야 합니다.
- 대각선 길이는 (i+j)로 정의되는 주대각선 방향으로 탐색합니다.


## 알고리즘 요약

시뮬레이션 + 그리드 전치/변환: 1. 초기 상태의 최대 대각선 길이(좌상->우하)를 계산합니다. 2. 매 스텝마다 그리드를 시계방향으로 회전시키고, 새로운 그리드에서 다시 최대 대각선 길이를 계산합니다. 3. 이 과정이 N번 반복될 때까지 최대값을 갱신하며 결과를 반환합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. **아이디어**: 그리드가 N x N 크기로 주기적으로 회전하는 과정을 시뮬레이션하고, 각 상태에서 좌상단(i=0, j=0)부터 우하단(i=N-1, j=N-1)으로 뻗어나가는 대각선 상의 연속된 '1'들의 최대 길이를 찾는 문제입니다.

2. **단계**: 
    a. **회전 구현 (Rotate)**: N x N 그리드를 시계 방향으로 회전시키는 함수를 만듭니다. 원소 `(r, c)`는 새 위치 `(c, N-1-r)`로 이동합니다. 이 과정을 한 번 수행하는 것이 핵심입니다.
    b. **최대 대각선 길이 계산 (FindMaxDiagonal)**: 주어진 그리드에서 모든 칸을 순회하며, 각 칸 `(i, j)`가 시작점이라고 가정하고 오른쪽 아래 방향으로 연속된 '1'의 길이를 측정합니다. 이 중 최댓값을 반환합니다.
    c. **시뮬레이션**: 초기 그리드를 저장한 후, 최대값을 기록할 변수를 초기화합니다. N번 반복하며 (회전 횟수 = 0부터 N-1까지):
        i. 현재 그리드에서 `FindMaxDiagonal`을 호출하여 최댓값을 구하고, 전역 최대값과 비교해 갱신합니다.
        ii. 그리드를 한 번 회전시킵니다.

3. **시간 복잡도**: 
    - 그리드의 크기는 N x N입니다. (N <= 10)
    - `FindMaxDiagonal` 함수는 모든 칸을 탐색하므로 O(N^2) 시간이 걸립니다.
    - 회전 과정은 총 N번 반복됩니다.
    - 따라서 전체 시간 복잡도는 $O(N 	imes N^2) = O(N^3)$ 입니다. N이 매우 작으므로 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string[][]} initialGrid - 초기 N x N 그리드 (문자열 배열 형태)
 * @returns {number} 회전 과정에서 발견되는 최대 대각선 길이
 */
const solve = (initialGrid) => {
    let grid = initialGrid.map(row => [...row]); // 깊은 복사
    const N = initialGrid.length;
    let globalMax = 0;

    // 1. 대각선 최대 길이 계산 함수
    const findMaxDiagonal = (currentGrid) => {
        let maxLen = 0;
        for (let r = 0; r < N; r++) {
            for (let c = 0; c < N; c++) {
                if (currentGrid[r][c] === '1') {
                    // 현재 칸 (r, c)를 시작점으로 하여 오른쪽 아래 대각선 탐색
                    let currentLen = 0;
                    let row = r;
                    let col = c;
                    while (row < N && col < N && currentGrid[row][col] === '1') {
                        currentLen++;
                        row++;
                        col++;
                    }
                    maxLen = Math.max(maxLen, currentLen);
                }
            }
        }
        return maxLen;
    };

    // 2. 그리드 회전 함수 (시계 방향)
    const rotateGrid = (currentGrid) => {
        let newGrid = Array(N).fill(0).map(() => Array(N).fill(''));
        for (let r = 0; r < N; r++) {
            for (let c = 0; c < N; c++) {
                // 원소 (r, c) -> 새 위치 (c, N - 1 - r)
                newGrid[c][N - 1 - r] = currentGrid[r][c];
            }
        }
        return newGrid;
    };

    // 3. 시뮬레이션: 최대 N번 회전하며 탐색
    for (let i = 0; i < N; i++) {
        // 현재 그리드에서 최대 대각선 길이 계산
        const currentMax = findMaxDiagonal(grid);
        globalMax = Math.max(globalMax, currentMax);

        // 다음 스텝을 위해 회전 (마지막 루프에서는 더 이상 필요 없음)
        if (i < N - 1) {
            grid = rotateGrid(grid);
        }
    }

    return globalMax;
};

// --- 입출력 처리 예시 ---
const processInput = (inputString) => {
    const lines = inputString.trim().split('\n');
    if (lines.length === 0) return null;
    
    const N = parseInt(lines[0].trim());
    let initialGrid = [];
    for (let i = 1; i <= N; i++) {
        // 문자열을 '1'과 '0'의 배열로 변환하여 저장하는 것이 안전함
        initialGrid.push(lines[i].trim().split('')); 
    }
    return initialGrid;
};
```

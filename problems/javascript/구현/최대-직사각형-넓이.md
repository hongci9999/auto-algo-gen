# 최대 직사각형 넓이
*javascript · 구현 · 보통 · 배열, 누적합*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리하며, 전체 입력을 문자열로 받고 파싱하는 방식을 사용합니다.

## 문제

주어진 N개의 정수로 이루어진 그리드(Grid)가 있습니다. 이 그리드는 높이가 1인 막대들이 나란히 놓여진 형태라고 생각할 수 있습니다. 각 칸의 값은 해당 위치의 막대 높이를 의미합니다.

만약 이 그리드의 한 부분 직사각형을 선택한다면, 그 직사각형의 넓이는 '가장 낮은 곳의 높이'에 의해 결정됩니다. 즉, 직사각형의 높이는 선택된 모든 열(column) 중에서 가장 작은 값과 같고, 너비는 선택된 열의 개수와 같습니다.

여러분이 할 수 있는 것은 그리드 내에서 가능한 모든 직사각형을 탐색하고, 그중 최대 넓이를 구하는 것입니다. 

단, 주어진 입력은 N개의 독립적인 막대 높이 리스트일 뿐이며, 이들은 이미 1층짜리 단면만을 나타냅니다. 따라서 선택된 연속된 구간 $[L, R]$을 가진 직사각형의 높이는 $\min(height[L], height[L+1], ..., height[R])$이고, 넓이는 $R - L + 1$입니다.

## 입력

첫째 줄에 정수 N (막대 개수)이 주어집니다. 
둘째 줄에 공백으로 구분된 N개의 정수(height[0], height[1], ..., height[N-1])가 순서대로 주어집니다.

## 출력

최대 직사각형 넓이 크기를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 200,000
1 <= heights[i] <= 100,000

## 예제 1

**입력**
```
5\n2 3 5 7 10
```

**출력**
```
14
```

*높이가 2인 막대부터 시작하여 높이가 최소인 구간을 찾으면, [2, 3, 5, 7]의 최소가 2이고 너비가 4이므로 넓이는 8입니다. 하지만 실제로 가장 큰 것은 7과 10을 포함하는 부분 직사각형이며, 최대는 2, 3, 5, 7 중 min(2, 3, 5, 7)=2로 인해 계산되지만, 이 문제의 의도는 '높이가 최소인 구간'이 아닌 연속된 막대 배열에서 가능한 모든 구간 $[L, R]$을 탐색하는 것입니다. 최대는 [3, 5, 7] (min=3, 너비=3) 또는 다른 조합입니다. 주어진 예제에서는 [2, 3, 5, 7, 10] 전체 중 min(2)=2이고 넓이는 5이므로 10이 아닙니다. 최대는 [3, 5, 7] (min=3, 너비=3) 혹은 다른 조합입니다. 가장 큰 직사각형은 높이가 2인 막대부터 시작하여 그 옆으로 확장하는 것입니다.*

## 예제 2

**입력**
```
4\n1 1 1 1
```

**출력**
```
4
```

*모든 막대의 높이가 1이므로, 전체 구간을 선택했을 때 넓이는 4입니다.*

## 힌트

- 가장 낮은 곳의 높이에 의해 직사각형의 높이가 결정된다는 점에 주목하세요.
- 시간 복잡도를 O(N^2)로 풀면 시간 초과가 발생할 수 있습니다. 더 효율적인 방법을 찾아야 합니다.


## 알고리즘 요약

이 문제는 'Largest Rectangle in Histogram' 문제입니다. 모든 가능한 구간 $[L, R]$을 탐색하는 것은 $O(N^2)$의 시간이 걸리지만, 이는 시간 복잡도 제한을 초과할 가능성이 높습니다.

효율적인 풀이 방법은 스택(Stack) 자료구조를 활용하는 것입니다. 각 막대 $height[i]$에 대해, 이 막대가 '높이'가 되는 직사각형의 가장 넓은 너비를 찾습니다.

1. **왼쪽 경계 (L):** $height[i]$보다 작거나 같은 높이를 가진 첫 번째 막대의 인덱스입니다. (즉, 왼쪽으로 확장할 수 있는 끝 지점)
2. **오른쪽 경계 (R):** $height[i]$보다 작거나 같은 높이를 가진 첫 번째 막대의 인덱스입니다. (즉, 오른쪽으로 확장할 수 있는 시작 지점)

막대 $i$를 기준으로 직사각형 넓이는 $	ext{Area} = height[i] 	imes (	ext{R} - 1) - (	ext{L} + 1) + 1$ 이 됩니다. 스택을 사용하여 왼쪽과 오른쪽 경계를 $O(N)$ 시간 내에 계산할 수 있습니다.

## 풀이 해설

문제에서 주어진 것은 연속된 막대 높이 배열입니다. 우리가 찾는 직사각형 넓이는 특정 구간 $[L, R]$의 최소 높이를 $h_{	ext{min}}$으로 하고, 넓이를 $(R-L+1) 	imes h_{	ext{min}}$ 으로 정의하는 것과 같습니다.

$O(N^2)$ 방식으로 모든 구간을 탐색하면 시간 초과가 발생할 수 있으므로, 스택 기반의 $O(N)$ 알고리즘인 'Largest Rectangle in Histogram' 접근 방식을 사용합니다.

**아이디어:** 각 막대 $height[i]$를 직사각형의 '높이'로 가정하고, 이 높이를 유지하면서 최대한 넓게 펼칠 수 있는 너비($W$)를 찾는 것입니다. 이때 $W$는 왼쪽으로 확장할 수 있는 최대 거리와 오른쪽으로 확장할 수 있는 최대 거리를 곱하여 얻습니다.

**단계 (스택 사용):**
1. **왼쪽 경계 계산:** 배열을 순회하며 스택에 인덱스를 저장합니다. 현재 막대 $i$의 높이가 스택 최상단에 있는 막대의 높이보다 작다면, 스택 최상단의 막대는 오른쪽에서 더 이상 확장할 수 없다는 의미이므로 처리합니다.
2. **처리 로직:** 스택에서 꺼낸 인덱스 $j$가 현재 막대 $i$의 왼쪽 경계를 결정하고, 배열의 끝(또는 다음으로 작은 막대)이 오른쪽 경계를 결정하게 됩니다. 
3. 계산된 넓이는 $	ext{Area} = height[j] 	imes (i - 1 - (	ext{스택 최상단 인덱스}) )$ 와 같은 방식으로 계산됩니다.

가장 간단한 구현은 '다음 작거나 같은 원소'를 찾는 것입니다. 이 과정을 스택으로 효율적으로 수행하면 시간 복잡도를 $O(N)$로 줄일 수 있습니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} heights - 막대 높이 배열
 * @returns {number} 최대 직사각형 넓이
 */
function largestRectangleArea(heights) {
    const stack = []; // 스택에 인덱스 저장
    let maxArea = 0;
    const N = heights.length;

    // 한 번의 순회로 처리하기 위해 heights 배열 끝에 높이 0을 추가 (가상의 경계)
    const extendedHeights = [...heights, 0]; 
    const M = extendedHeights.length; 

    for (let i = 0; i < M; i++) {
        // 현재 막대(i)의 높이가 스택 최상단에 있는 막대의 높이보다 낮거나 같을 때까지 처리
        while (stack.length > 0 && extendedHeights[stack[stack.length - 1]] >= extendedHeights[i]) {
            const height = extendedHeights[stack.pop()]; // 현재 넓이를 계산할 높이
            
            // 오른쪽 경계: i (현재 낮은 막대의 인덱스)
            // 왼쪽 경계: 스택이 비었거나, 스택 최상단 인덱스 + 1
            const rightBoundary = i;
            let leftBoundary = stack.length === 0 ? 0 : stack[stack.length - 1] + 1;
            
            // 넓이 계산: 높이 * (오른쪽 경계 - 왼쪽 경계 + 1)
            const width = rightBoundary - leftBoundary;
            maxArea = Math.max(maxArea, height * width);
        }
        // 현재 인덱스를 스택에 푸시
        stack.push(i);
    }
    return maxArea;
}
```

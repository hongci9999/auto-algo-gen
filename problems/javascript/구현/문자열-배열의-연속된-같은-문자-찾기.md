# 문자열 배열의 연속된 같은 문자 찾기
*javascript · 구현 · 보통 · 문자열, 배열, 구현*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리해야 합니다. 전체 입력을 받은 후 처리하는 방식을 사용하세요.

## 문제

N개의 문자열이 배열로 주어집니다. 각 문자열은 알파벳으로만 구성되어 있습니다. 이 배열에서, 길이가 2 이상인 연속된 문자열들이 같은 문자로 시작하거나 같은 문자로 끝나는 경우의 최대 개수를 구하는 문제입니다.

예를 들어, 배열이 ["apple", "banana", "apricot"]라면:
- "apple"과 "banana"는 첫 글자('a'와 'b')가 다르므로 연속된 쌍으로 카운트할 수 없습니다.
- "banana"와 "apricot"는 마지막 글자('a'와 't')가 다르므로 카운트할 수 없습니다.

따라서 최대 연속 개수는 1입니다. (단, 문제에서 요구하는 '연속된' 정의가 명확하지 않으므로, 이 문제는 인접한 요소 간의 조건을 만족하는 최대 길이의 연속된 서브 배열의 길이를 구하는 것으로 해석합니다.)

## 입력

첫째 줄에 정수 N이 주어지며, 다음 N줄에 각각 문자열이 한 줄씩 주어집니다.

## 출력

최대 연속된 같은 문자 조건을 만족하는 연속된 문자열의 최대 개수를 정수로 출력합니다.

## 제약 조건

1 ≤ N ≤ 100,000
문자열의 길이: 1 이상 50
시간 복잡도: O(N) 또는 O(N log N) 이하

## 예제 1

**입력**
```
5
apple
apricot
banana
bandana
cat
```

**출력**
```
2
```

*"apple"과 "apricot"는 첫 글자('a')가 같아 2개 연속 가능.*

## 예제 2

**입력**
```
3
xyz
abcd
efg
```

**출력**
```
1
```

*모든 문자열의 첫 글자가 달라, 최대 연속 길이는 1입니다.*

## 힌트

- 인접한 두 문자열을 비교할 때 만족해야 하는 조건(시작 문자 또는 끝 문자)을 명확히 정의하세요.
- 이 문제는 전형적인 '가장 긴 연속 부분 배열' 문제와 유사합니다.
- 배열 순회 시, 조건을 만족하는 연속된 구간의 길이를 카운트하고 최대값을 갱신해야 합니다.


## 알고리즘 요약

이 문제는 주어진 배열을 순차적으로 탐색하며, 조건을 만족하는 연속된 부분 배열의 길이를 찾는 문제입니다. 인접한 두 문자열 `S[i]`와 `S[i+1]`을 비교하여, 다음 조건 중 하나를 만족하는지 확인합니다: 1. `S[i]`와 `S[i+1]`의 첫 글자가 같거나, 2. `S[i]`와 `S[i+1]`의 마지막 글자가 같습니다. 이 조건을 만족하면 현재 카운트를 1 증가시키고, 그렇지 않으면 카운트를 0으로 리셋합니다. 최대 카운트를 유지합니다.

## 풀이 해설

### 아이디어
주어진 문자열 배열에서, 인접한 문자열들이 특정 조건을 만족하는 최대 길이의 연속된 부분 배열을 찾는 문제입니다. 여기서 조건이란, 두 문자열 $S_i$와 $S_{i+1}$가 '같은 문자로 시작하거나 같은 문자로 끝나는' 경우를 말합니다.

### 단계
1. **초기화**: 최대 길이(`max_len`)를 1로 설정합니다. (N >= 1이므로 최소한 1개는 가능합니다.) 현재 연속된 길이를 나타내는 변수(`current_len`)를 1로 설정합니다.
2. **순회**: 배열을 $i=0$부터 $N-2$까지 순회합니다 (인접한 쌍을 비교하기 위함).
3. **조건 확인**: $S_i$와 $S_{i+1}$을 비교합니다. 다음 중 하나라도 참이면 조건을 만족합니다:
    * $S_i[0] === S_{i+1}[0]$ (첫 글자가 같음)
    * $S_i[S_i.length - 1] === S_{i+1}[S_{i+1}.length - 1]$ (마지막 글자가 같음)
4. **카운트 갱신**: 
    * **만족할 경우**: `current_len`을 1 증가시킵니다. (두 문자열의 쌍이 조건을 만족하며, 이는 기존의 연속된 길이를 1 증가시킴을 의미합니다.)
    * **만족하지 않을 경우**: `current_len`을 1로 초기화합니다. (연속성이 깨졌으므로, 다음 비교부터 다시 1부터 시작해야 합니다.)
5. **최대값 갱신**: 매 단계마다 `max_len = max(max_len, current_len)`을 수행하여 최대 길이를 갱신합니다.
6. **결과 반환**: 순회가 끝난 후 `max_len`을 반환합니다.

### 시간 복잡도
배열의 크기 $N$에 대해 한 번만 순회하므로, 시간 복잡도는 $O(N)$입니다. 공간 복잡도는 상수 공간 $O(1)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string[]} words - 문자열 배열
 * @returns {number} 최대 연속 길이
 */
const solve = (words) => {
    const N = words.length;
    if (N === 0) return 0;
    
    // 최소 길이는 1이므로 초기화
    let maxLen = 1;
    let currentLen = 1;

    for (let i = 0; i < N - 1; i++) {
        const s1 = words[i];
        const s2 = words[i + 1];
        
        // 조건 1: 첫 글자가 같은지
        const startsMatch = s1[0] === s2[0];
        
        // 조건 2: 마지막 글자가 같은지
        const endsMatch = s1[s1.length - 1] === s2[s2.length - 1];
        
        if (startsMatch || endsMatch) {
            // 조건을 만족하면 연속 길이 증가
            currentLen++;
        } else {
            // 조건을 만족하지 못하면 연속성이 깨지므로 초기화
            currentLen = 1;
        }
        
        // 최대 길이 갱신
        maxLen = Math.max(maxLen, currentLen);
    }

    return maxLen;
};

// --- 입출력 처리 (Node.js 기준) ---
const readline = require('readline');

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
    terminal: false
});

let lines = [];
rl.on('line', (line) => {
    lines.push(line);
});

rl.on('close', () => {
    if (lines.length === 0) {
        console.log(0);
        return;
    }
    
    // 첫 줄은 N (크기)이고, 나머지 줄이 words
    const N = parseInt(lines[0].trim());
    const wordsArray = lines.slice(1, N + 1);
    
    const result = solve(wordsArray);
    console.log(result);
});
```

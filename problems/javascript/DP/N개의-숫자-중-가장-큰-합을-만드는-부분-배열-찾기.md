# N개의 숫자 중 가장 큰 합을 만드는 부분 배열 찾기
*javascript · DP · 보통 · DP, 배열*

## 입출력 환경

JavaScript 환경에서 입력은 보통 문자열 형태로 한 줄에 공백으로 구분되어 들어옵니다. 배열 형태로 가정하고 처리합니다.

## 문제

정수 배열 `arr`가 주어집니다. 이 배열의 연속된 부분 배열 중 합이 가장 큰 것을 찾아 그 합을 반환하는 문제입니다.

(문제의 예시: `arr = [1, -2, 3, -1, 5]`일 때, 가장 큰 합을 가지는 부분 배열은 `[3, -1, 5]`이고, 그 합은 7입니다.)

## 입력

배열 arr의 크기 N (1 <= N <= 100,000)와 배열의 요소 arr[i] (-10^9 <= arr[i] <= 10^9)가 순서대로 주어집니다.

## 출력

가장 큰 합을 가지는 부분 배열의 합 (Long Long 타입으로 처리해야 할 수 있음).

## 제약 조건

N <= 100,000. 시간 복잡도는 O(N)이 요구됩니다.

## 예제 1

**입력**
```
[1, -2, 3, -1, 5]
```

**출력**
```
7
```

*부분 배열 [3, -1, 5]의 합이 가장 크다.*

## 예제 2

**입력**
```
[-2, -3, -1, -5]
```

**출력**
```
-1
```

*모두 음수일 때도 가장 큰 합(최소한의 손해)을 찾아야 한다.*

## 힌트

- 가장 큰 합을 가지는 부분 배열은 반드시 연속적이어야 합니다.
- 이전까지의 누적합을 관리하며 현재까지의 최대 합을 갱신하는 방식(Kadane's Algorithm)을 고려해보세요.


## 알고리즘 요약

Kadane의 알고리즘 (Maximum Subarray Problem 해결법). 배열을 순회하면서 현재까지의 최대 합과 전역 최대 합을 각각 갱신합니다.

## 풀이 해설

이 문제는 '최대 부분 배열 합 문제(Maximum Subarray Problem)'로 알려져 있으며, Kadane의 알고리즘을 사용하면 O(N) 시간에 풀 수 있습니다.

**아이디어:** 배열을 순회하면서, 현재 위치 `i`까지의 부분 배열 합을 계산합니다. 이때, 부분 배열 합을 계산할 때 이전의 합이 이미 음수라면, 그 합은 현재 위치에서 시작하는 것이 더 유리할 수 있습니다. 즉, 현재까지의 누적 합이 음수라면, 그 합은 초기화(0으로 리셋)하고 현재 요소부터 새로 시작하는 것이 최적입니다.

**단계:**
1. `current_max`: 현재 위치까지의 최대 연속 부분 배열 합을 저장하는 변수입니다. (초기값: 0)
2. `global_max`: 배열 전체를 탐색하면서 발견한 최대 부분 배열 합을 저장하는 변수입니다. (초기값: 배열의 첫 요소 또는 매우 작은 값)
3. 배열을 처음부터 끝까지 순회합니다.
4. 각 요소 `arr[i]`에 대해, `current_max`를 `current_max + arr[i]`로 업데이트합니다.
5. 만약 `current_max`가 `arr[i]`보다 작거나 같다면 (즉, 이전까지의 누적 합을 더하는 것이 이득이 아니거나 0보다 작다는 의미), `current_max`를 `arr[i]`로 재설정합니다. (Kadane의 핵심 로직: 합이 음수가 되면 리셋하고 현재 요소부터 시작)
6. `global_max`를 `Math.max(global_max, current_max)`로 갱신합니다.
7. 모든 요소에 대해 반복한 후, `global_max`가 최종 답입니다.

**시간 복잡도:** 배열을 한 번만 순회하므로 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} arr
 * @returns {number}
 */
function maxSubArraySum(arr) {
    if (arr === null || arr.length === 0) {
        return 0;
    }

    // global_max는 전체 배열의 최대 합을 저장합니다.
    // 초기값을 가장 작은 값으로 설정하거나, 배열의 첫 요소를 사용합니다.
    let global_max = arr[0];
    
    // current_max는 현재 위치까지의 연속된 최대 합을 저장합니다.
    let current_max = arr[0];

    for (let i = 1; i < arr.length; i++) {
        // 1. 현재 요소 arr[i]를 current_max에 더한 값과, 
        // 2. arr[i] 자체 중 더 큰 값을 current_max로 선택합니다.
        // (즉, 이전까지의 합이 음수라면, 아예 리셋하고 arr[i]부터 새로 시작하는 것이 유리함)
        current_max = Math.max(arr[i], current_max + arr[i]);
        
        // 3. 전역 최대 합을 갱신합니다.
        global_max = Math.max(global_max, current_max);
    }

    return global_max;
}

// 테스트 예시:
// console.log(maxSubArraySum([1, -2, 3, -1, 5])); // 7
// console.log(maxSubArraySum([-2, -3, -1, -5])); // -1
// console.log(maxSubArraySum([5, 4, 3, 2, 1])); // 15
```

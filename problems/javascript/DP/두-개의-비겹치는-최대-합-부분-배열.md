# 두 개의 비겹치는 최대 합 부분 배열
*javascript · DP · 보통 · 배열, DP, Kadane's Algorithm*

## 입출력 환경

Node.js 환경에서 표준 입력을 받으며, 모든 입력은 한 번에 처리하는 방식으로 가정합니다.

## 문제

정수 원소로 이루어진 배열 A가 주어집니다. 이 배열에서 두 개의 비겹치는 (non-overlapping) 연속된 부분 배열을 선택하여, 그 두 부분 배열의 합이 최대가 되도록 하는 최댓값을 구하는 문제입니다.

즉, $0 	ext{부터 } N-1$까지의 인덱스 중에서, 첫 번째 범위 $[i, j]$와 두 번째 범위 $[k, l]$를 선택하되, $j < k$ (혹은 $l < i$) 조건을 만족해야 합니다. 목표는 $\max(\	ext{Sum}(A[i..j]) + \text{Sum}(A[k..l]))$를 찾는 것입니다.

## 입력

첫 번째 줄에 정수 N이 주어지고, 다음 줄에 공백으로 구분된 N개의 정수 원소들이 순서대로 주어집니다. (배열 A)

## 출력

최대 합을 구한 정수 값 하나를 출력합니다.

## 제약 조건

1 <= N <= 10^5
-1, 1 <= A[i] <= 10^9

## 예제 1

**입력**
```
4
1 2 3 4
```

**출력**
```
9
```

*최대 합을 주는 두 부분 배열은 [1, 2]와 [3, 4]가 아닙니다. (합: 2+7=9). [1, 2]를 선택하면 최대 뒤쪽 합은 [3, 4]=7이므로 총 합은 9입니다.*

## 예제 2

**입력**
```
5
-1 5 -2 6 3
```

**출력**
```
14
```

*최대 합을 주는 두 부분 배열은 [5]와 [6, 3] 입니다. (합: 5 + 9 = 14). 비겹치는 조건과 최대값 계산이 중요합니다.*

## 힌트

- 문제를 '분할 지점'을 기준으로 나누어 생각해보세요.
- 하나의 배열에서 연속된 부분 배열의 최댓값을 구하는 문제는 Kadane's Algorithm과 관련이 깊습니다.


## 알고리즘 요약

효율적인 분할 정복 및 DP 접근법입니다. 모든 가능한 '분할 지점' $k$를 순회하며, 그 지점을 기준으로 왼쪽($A[0..k]$)에서 얻을 수 있는 최대 부분 배열 합과 오른쪽($A[k+1..N-1]$)에서 얻을 수 있는 최대 부분 배열 합을 각각 계산합니다. 이 두 값을 더한 값이 전체 결과의 후보가 됩니다. 이를 모든 $k$에 대해 수행하고 최댓값을 찾습니다.

## 풀이 해설

### 아이디어
이 문제는 본질적으로 배열 A를 분할하는 지점을 찾는 문제입니다. 만약 배열을 인덱스 $k$와 $k+1$ 사이에서 나눈다고 가정하면, 최대 합은 (A[0]부터 A[k]까지의 최대 부분 배열 합) + (A[k+1]부터 A[N-1]까지의 최대 부분 배열 합)이 됩니다.

따라서 우리는 모든 가능한 분할 지점 $k$에 대해 이 합을 계산하고 최댓값을 취해야 합니다. 시간 복잡도를 $O(N^2)$로 만들지 않기 위해, 각 영역에서 얻을 수 있는 '최대 부분 배열 합'을 미리 전처리해 놓아야 합니다.

### 단계별 풀이
1. **LeftMax (왼쪽 최대 합) 계산:** $	ext{leftMax}[i]$를 배열 $A$의 인덱스 0부터 $i$까지에서 얻을 수 있는 최대 부분 배열 합으로 정의합니다. 이를 0부터 $N-1$까지 순차적으로 계산할 수 있습니다. 이 과정은 Kadane's Algorithm과 유사하게 진행됩니다.
2. **RightMax (오른쪽 최대 합) 계산:** $	ext{rightMax}[i]$를 배열 $A$의 인덱스 $i$부터 $N-1$까지에서 얻을 수 있는 최대 부분 배열 합으로 정의합니다. 이를 $N-1$부터 0까지 역순으로 계산하여 채웁니다.
3. **최종 결과 도출:** 두 비겹치는 부분을 가진다는 것은, 어느 지점 $k$를 경계로 나눈다고 볼 수 있습니다. 즉, 첫 번째 부분은 $[i..j]$이고, 두 번째 부분은 $[k..l]$이며, $j < k$입니다.
   우리는 모든 인덱스 $k=1$부터 $N-1$까지를 기준으로 분할을 시도합니다. 최적의 합은 $\max_{0 	ext{부터 } N-2} (	ext{leftMax}[k] + 	ext{rightMax}[k+1])$가 됩니다.
4. **시간 복잡도:** LeftMax와 RightMax 배열을 각각 $O(N)$ 시간에 계산하고, 마지막 순회 역시 $O(N)$ 시간이 걸리므로 전체 시간 복잡도는 $O(N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수 (공백으로 구분된 정수 배열을 가정)
 * 실제 제출 환경에 맞게 입력 로직을 수정해야 할 수 있습니다.
 */
function solve() {
    const fs = require('fs');
    // 예시를 위해 동기 방식으로 모든 입력을 읽고 처리합니다. (실제 테스트 케이스 구조에 따라 변경 필요)
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim().split('\n');
    } catch (e) {
        // 테스트 환경이 아닌 경우 대비
        console.error("입력 파일을 읽는 데 실패했습니다.");
        return;
    }

    if (input.length === 0) return;

    const N = parseInt(input[0].trim());
    const A = input[1].trim().split(/\s+/).map(Number);

    if (N < 2) {
        console.log("Error: 최소 2개 이상의 원소가 필요합니다.");
        return;
    }

    // 1. leftMax[i]: A[0...i] 범위에서 얻을 수 있는 최대 부분 배열 합
    const leftMax = new Array(N).fill(-Infinity);
    let currentMaxSum = 0; // 현재까지의 부분합
    let overallMax = -Infinity; // 누적된 최대값

    for (let i = 0; i < N; i++) {
        // Kadane's Algorithm 기반으로, A[i]를 포함하는 최대 합을 구하고 이를 leftMax에 저장합니다.
        currentMaxSum += A[i];
        if (currentMaxSum < A[i]) { // 현재 부분합이 이전까지의 합보다 작아지면 리셋 (새로운 시작)
             currentMaxSum = A[i];
        }
        // leftMax는 '최대' 값을 저장해야 하므로, 현재 위치 i에서 끝나는 최대값과 전체 누적된 최대값을 비교해야 합니다.
        leftMax[i] = Math.max(overallMax, currentMaxSum);
        overallMax = leftMax[i];
    }

    // 2. rightMax[i]: A[i...N-1] 범위에서 얻을 수 있는 최대 부분 배열 합
    const rightMax = new Array(N).fill(-Infinity);
    let currentMaxSumR = 0;
    let overallMaxR = -Infinity; // 오른쪽 끝에서부터의 누적 최대값

    for (let i = N - 1; i >= 0; i--) {
        // Kadane's Algorithm 역방향 적용
        currentMaxSumR += A[i];
        if (currentMaxSumR < A[i]) { // 현재 부분합이 다음까지의 합보다 작아지면 리셋
            currentMaxSumR = A[i];
        }
        // rightMax는 '최대' 값을 저장해야 하므로, 현재 위치 i에서 시작하는 최대값과 전체 누적된 최대값을 비교합니다.
        rightMax[i] = Math.max(overallMaxR, currentMaxSumR);
        overallMaxR = rightMax[i];
    }

    // 3. 최종 결과 도출: 모든 가능한 분할 지점 k를 순회 (k=0부터 N-2까지)
    let maxTotalSum = -Infinity;

    for (let k = 0; k < N - 1; k++) {
        // 왼쪽 최대 합(leftMax[k])과 오른쪽 최대 합(rightMax[k+1])을 더합니다.
        const currentTotalSum = leftMax[k] + rightMax[k+1];
        maxTotalSum = Math.max(maxTotalSum, currentTotalSum);
    }

    console.log(maxTotalSum);
}

solve();
```

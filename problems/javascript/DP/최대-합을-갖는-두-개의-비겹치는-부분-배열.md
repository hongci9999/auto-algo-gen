# 최대 합을 갖는 두 개의 비겹치는 부분 배열
*javascript · DP · 보통 · DP, 부분합, Kadane*

## 입출력 환경

Node.js 환경에서 모든 입력을 한 번에 받고 처리한다고 가정합니다. 입력은 한 줄씩 들어오며, 첫 줄은 N, 두 번째 줄은 배열 요소입니다.

## 문제

정수 배열 `arr`가 주어집니다. 이 배열에서 서로 겹치지 않는 (non-overlapping) 두 개의 부분 배열을 선택할 수 있습니다. 각 부분 배열의 합을 구했을 때, 그 두 합의 총합을 최대로 만드는 값을 찾으세요.

부분 배열은 최소한 하나의 요소를 포함해야 하며, 배열의 시작부터 끝까지 모두 사용해야 할 필요는 없습니다.

## 입력

첫 번째 줄에 정수 N (배열의 길이)이 주어집니다. 두 번째 줄에 공백으로 구분된 N개의 정수 `arr`가 주어집니다.

## 출력

최대 합을 갖는 두 부분 배열의 총합을 한 정수로 출력합니다.

## 제약 조건

N의 범위: 1 < N ≤ 100,000. 배열 요소의 값: -10^9 ≤ arr[i] ≤ 10^9. 시간 제한: O(N) 또는 O(N log N) 이하.

## 예제 1

**입력**
```
5
1 -1 5 -2 3
```

**출력**
```
7
```

*배열을 [1]과 [5, -2, 3]으로 분할하여 합 1 + 6 = 7을 얻습니다. (최대값)*

## 예제 2

**입력**
```
4
1 2 3 4
```

**출력**
```
10
```

*배열을 [1, 2]와 [3, 4]로 분할하여 합 3 + 7 = 10을 얻습니다. (최대값)*

## 힌트

- 단일 배열에서 최대 부분 배열 합을 구하는 알고리즘 (Kadane's Algorithm)을 떠올려보세요.
- 두 개의 부분 배열이 존재한다는 것은, 배열을 적어도 하나의 지점에서 '분할'할 수 있다는 의미입니다.


## 알고리즘 요약

이 문제는 배열을 분할하는 지점(Split Point)을 기준으로, 왼쪽에서 최대 부분 배열 합을 찾고, 오른쪽에서 최대 부분 배열 합을 찾아 그 합을 최대화하는 방식으로 접근합니다. 이는 전형적인 DP 또는 Prefix/Suffix 최적화 문제입니다.

## 풀이 해설

풀이 해설: 아이디어
1. 문제의 핵심은 배열을 분할하는 지점 `k`를 찾는 것입니다. 두 부분 배열 A와 B가 있다고 할 때, A는 인덱스 0부터 `k`까지의 범위에서, B는 인덱스 `k+1`부터 N-1까지의 범위에서 가장 큰 합을 가져야 합니다.
2. 따라서, 우리는 모든 가능한 분할 지점 `k`에 대해, 'A의 최대 합'과 'B의 최대 합'의 합을 구하고 그 최댓값을 찾아야 합니다.

단계
1. **Prefix Max Sum 배열 계산 (Left Pass):** `leftMax[i]`를 '배열의 0부터 i까지의 범위에서 얻을 수 있는 최대 부분 배열 합'으로 정의합니다. 이를 효율적으로 계산하기 위해, `leftMax[i]`는 `leftMax[i-1]`과 `arr[i]`를 활용하여 갱신할 수 있습니다. (이때, Kadane's 알고리즘의 원리가 적용됩니다.)
2. **Suffix Max Sum 배열 계산 (Right Pass):** `rightMax[i]`를 '배열의 i부터 N-1까지의 범위에서 얻을 수 있는 최대 부분 배열 합'으로 정의합니다. 이 역시 오른쪽에서 왼쪽으로 순회하며 Kadane's 원리를 응용하여 계산합니다.
3. **최대 합 계산:** 최종 답은 모든 가능한 분할 지점 `k`에 대해 `leftMax[k] + rightMax[k+1]`을 계산하고 그 최댓값입니다. (분할 지점은 0부터 N-2까지 가능합니다.)

시간 복잡도: 배열을 세 번 순회(왼쪽 최대 합 계산, 오른쪽 최대 합 계산, 최종 합 계산)하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} arr - 입력 배열
 * @returns {number} - 최대 합
 */
const solve = (arr) => {
    const N = arr.length;
    if (N < 2) return 0;

    // 1. 왼쪽 최대 부분 배열 합 (Prefix Max Sum)
    // leftMax[i]: arr[0...i]에서 나올 수 있는 최대 부분 배열 합
    const leftMax = new Array(N);
    let currentMax = 0; // 현재까지의 연속 합
    let overallMax = -Infinity; // 0부터 i까지의 최대 합

    for (let i = 0; i < N; i++) {
        // Kadane's 원리: 현재 합을 갱신하거나, 0부터 새로 시작하는 것이 더 큰지 비교
        currentMax = Math.max(arr[i], currentMax + arr[i]);
        leftMax[i] = Math.max(leftMax[i - 1] || -Infinity, currentMax);
    }

    // 2. 오른쪽 최대 부분 배열 합 (Suffix Max Sum)
    // rightMax[i]: arr[i...N-1]에서 나올 수 있는 최대 부분 배열 합
    const rightMax = new Array(N);
    let currentMaxRight = 0;
    let overallMaxRight = -Infinity;

    for (let i = N - 1; i >= 0; i--) {
        // Kadane's 원리: 오른쪽에서 연속 합 갱신
        currentMaxRight = Math.max(arr[i], currentMaxRight + arr[i]);
        rightMax[i] = Math.max(rightMax[i + 1] || -Infinity, currentMaxRight);
    }

    // 3. 최대 합 계산 (최적의 분할 지점 k 찾기)
    let maxTotalSum = -Infinity;

    // 분할 지점 k는 arr[k]와 arr[k+1] 사이입니다. k는 0부터 N-2까지 가능합니다.
    for (let k = 0; k < N - 1; k++) {
        // leftMax[k]: 0부터 k까지의 최대 합
        // rightMax[k+1]: k+1부터 N-1까지의 최대 합
        const currentTotalSum = leftMax[k] + rightMax[k + 1];
        maxTotalSum = Math.max(maxTotalSum, currentTotalSum);
    }

    return maxTotalSum;
};

// Node.js 입력 처리 시뮬레이션
const processInput = (input) => {
    const lines = input.trim().split('\n');
    if (lines.length < 2) return 0;
    
    // 첫 줄은 N (실제로는 사용 안 함)
    const N = parseInt(lines[0].trim());
    // 두 번째 줄이 배열 arr
    const arr = lines[1].trim().split(/\s+/).map(Number);
    
    return solve(arr);
};
```

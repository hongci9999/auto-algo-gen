# 주식 가격 변동에 따른 최대 수익 계산
*javascript · DP · 보통 · DP, 주식, 최대값*

## 입출력 환경

JavaScript 환경에서 배열을 인자로 받습니다.

## 문제

당신은 주식 시장의 트레이더가 되어, 주식의 일별 가격 변동을 관찰합니다. 주식은 하루에 한 번만 사고, 하루에 한 번만 팔 수 있습니다. 하지만 이 문제에서는 더 까다로운 규칙이 적용됩니다. 즉, 하루에 최대 두 번의 거래가 가능하며, 사고파는 행위는 연속적으로 이루어져야 합니다. 예를 들어, '매수 -> 매도' 또는 '매수 -> 매도 -> 매수 -> 매도'와 같이 이루어져야 합니다. 당신의 목표는 주어진 기간 동안의 최대 수익을 얻는 것입니다.

주어진 가격 배열 `prices`는 N개의 날짜에 대한 주식 가격을 나타냅니다. (N은 1 이상)

규칙:
1. 거래는 항상 '매수(Buy) -> 매도(Sell)' 순서로 이루어져야 합니다.
2. 하루에 최대 2번의 거래가 가능하며, 2번의 거래는 연속적인 '매수-매도' 쌍이어야 합니다. (즉, 최대 2개의 독립적인 거래 쌍이 가능합니다.)

예시: [1, 5, 2, 7]
- 첫 번째 거래: 1에 매수, 5에 매도 (수익: 4)
- 두 번째 거래: 2에 매수, 7에 매도 (수익: 5)
- 총 수익: 4 + 5 = 9

*주의: 문제에서 요구하는 것은 최대 2개의 독립적인 거래 쌍을 찾는 것입니다. 각 거래 쌍은 [buy_day, sell_day]로 정의되며, buy_day < sell_day 여야 합니다. 최대 2개의 거래 쌍의 합으로 최대 수익을 구하세요.

## 입력

주식 가격을 나타내는 정수 배열 (JavaScript 배열 형태로 제공됨)

## 출력

최대 수익을 나타내는 정수 (Number)

## 제약 조건

가격 배열 `prices`의 길이 N은 1부터 10^5까지입니다. 각 가격은 1 이상 10^5 이하입니다. 시간 복잡도는 O(N) 또는 O(N log N) 수준이어야 합니다.

## 예제 1

**입력**
```
[1, 5, 2, 7]
```

**출력**
```
9
```

*최대 수익은 (5-1) + (7-2) = 9입니다.*

## 예제 2

**입력**
```
[7, 1, 5, 3, 6]
```

**출력**
```
8
```

*최대 수익은 (5-1) + (6-3) = 8입니다.*

## 예제 3

**입력**
```
[1, 2, 3, 4]
```

**출력**
```
6
```

*최대 수익은 (2-1) + (4-3) = 3 + 1 = 4가 아니라, (2-1) + (4-3)을 넘어선 최대 수익은 (4-1) = 3, (2-1) + (4-3) = 3이므로, 최대는 3입니다. (수정: [1, 2, 3, 4]의 최대 수익은 3입니다. 하나의 거래만 하는 것이 가장 좋습니다.)*

## 힌트

- 이 문제는 DP(Dynamic Programming)를 사용하여 풀이할 수 있습니다.
- 최대 2개의 거래를 한다는 제약 조건이 중요합니다. 이는 4가지 상태를 추적해야 함을 의미합니다.


## 알고리즘 요약

DP 접근 방식: 이 문제는 '최대 2개의 거래'라는 제약 조건이 붙은 주식 문제로, 일반적인 최대 수익 문제(하나의 거래)를 확장한 형태입니다. DP 배열을 사용하여 각 날짜까지의 최대 수익을 계산합니다. 상태를 정의할 때, '매수만 한 상태', '매도까지 마친 상태 (거래 1 완료)', '두 번째 매수 상태', '두 번째 매도 상태 (거래 2 완료)'와 같이 최대 2개의 거래를 모두 고려하여 상태 전이(Transition)를 정의합니다. 시간 복잡도는 O(N)이 되어야 합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 '최대 2개의 독립적인 거래 쌍'을 찾아 최대 수익을 구하는 문제입니다. 일반적인 '한 번의 거래' 문제는 `max(prices[i] - prices[j])`를 찾는 것이지만, 여기서는 두 번의 거래를 고려해야 합니다.

DP 상태 정의: 우리는 각 날짜 `i`까지의 최대 수익을 4가지 상태로 추적합니다.
1. `buy1[i]`: i일까지 첫 번째 거래를 위해 매수만 한 상태의 최대 수익 (즉, -prices[i]가 최대화됨)
2. `sell1[i]`: i일까지 첫 번째 거래를 완료하여 매도까지 마친 상태의 최대 수익.
3. `buy2[i]`: i일까지 두 번째 거래를 위해 매수만 한 상태의 최대 수익.
4. `sell2[i]`: i일까지 두 번째 거래를 완료하여 매도까지 마친 상태의 최대 수익 (최종 결과).

단계별 전이 (Transition):
- `buy1[i]`: 오늘 가격 `prices[i]`에 매수하는 경우, 이전 상태보다 `prices[i]`만큼 손해를 봅니다. 따라서 `buy1[i] = max(buy1[i-1], -prices[i])`
- `sell1[i]`: 오늘 가격 `prices[i]`에 매도하는 경우, 이전 상태 `buy1[i-1]`에 `prices[i]`를 더합니다. 또한, 이전 날짜까지 매도까지 마친 상태를 유지할 수도 있습니다. 따라서 `sell1[i] = max(sell1[i-1], buy1[i-1] + prices[i])`
- `buy2[i]`: 오늘 가격 `prices[i]`에 두 번째 매수하는 경우, 이전의 최대 수익 `sell1[i-1]`에서 `prices[i]`를 뺍니다. 따라서 `buy2[i] = max(buy2[i-1], sell1[i-1] - prices[i])`
- `sell2[i]`: 오늘 가격 `prices[i]`에 두 번째 매도하는 경우, 이전 상태 `buy2[i-1]`에 `prices[i]`를 더합니다. 또한, 이전 날짜까지 최대 수익을 유지할 수도 있습니다. 따라서 `sell2[i] = max(sell2[i-1], buy2[i-1] + prices[i])`

최종 결과: 최종적으로 최대 수익은 `sell2[N-1]`에 저장됩니다. (만약 N=1이라면 0입니다.)

시간 복잡도: 모든 상태가 O(N)으로 계산되므로, 총 시간 복잡도는 O(N)입니다. 메모리 복잡도는 O(1)로 최적화하여 구현할 수 있습니다 (배열 대신 변수만 사용).

참고: 실제 코딩 테스트 환경에서는 배열 대신 변수만 사용하여 O(1) 공간 복잡도를 유지하는 것이 일반적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} prices - 주식 가격 배열
 * @return {number} - 최대 수익
 */
const maxProfit = (prices) => {
    const N = prices.length;
    if (N <= 1) {
        return 0;
    }

    // DP 상태 초기화 (변수만 사용하여 O(1) 공간 복잡도 달성)
    // buy1: 첫 번째 매수 상태 (최대 수익이 아닌, 최소 매수 비용을 추적하는 것이 직관적)
    // sell1: 첫 번째 매도 완료 상태
    // buy2: 두 번째 매수 상태
    // sell2: 두 번째 매도 완료 상태 (최종 결과)

    // 초기값 설정:
    // 1. buy1: 첫날 매수해야 하므로, -prices[0]으로 시작합니다. (최소 비용 = -prices[0])
    let buy1 = -prices[0]; 
    // 2. sell1: 아무 거래도 없으므로 0으로 시작합니다.
    let sell1 = 0;
    // 3. buy2: 두 번째 매수 시, 이전까지의 최대 수익(sell1)에서 가격을 빼야 하므로, -	ext{Infinity}로 초기화하여 첫 거래가 우선되게 합니다.
    //    (실제로는 sell1이 0이므로, 0 - prices[0]이 될 수 있지만, buy2는 sell1에 의존하므로 초기화가 까다롭습니다. -	ext{Infinity}가 가장 안전합니다.)
    let buy2 = -Infinity; 
    // 4. sell2: 아무 거래도 없으므로 0으로 시작합니다.
    let sell2 = 0;

    for (let i = 1; i < N; i++) {
        const price = prices[i];

        // sell2 업데이트: 오늘 매도하는 것이 이전 최대값보다 좋은지 비교
        // max(이전 sell2, (buy2 상태 + 오늘 가격))
        sell2 = Math.max(sell2, buy2 + price);
        
        // buy2 업데이트: 오늘 매수하는 것이 이전 상태보다 좋은지 비교
        // max(이전 buy2, (sell1 상태 - 오늘 가격))
        buy2 = Math.max(buy2, sell1 - price);
        
        // sell1 업데이트: 오늘 매도하는 것이 이전 최대값보다 좋은지 비교
        // max(이전 sell1, (buy1 상태 + 오늘 가격))
        sell1 = Math.max(sell1, buy1 + price);
        
        // buy1 업데이트: 오늘 매수하는 것이 이전 상태보다 좋은지 비교
        // max(이전 buy1, -오늘 가격)
        buy1 = Math.max(buy1, -price);
    }

    // 최종적으로 최대 수익은 sell2에 저장됩니다.
    return sell2;
};

// 예제 테스트
const test1 = [1, 5, 2, 7]; // 기대값: 9
console.log(`[${test1}] 결과: ${maxProfit(test1)}`);

const test2 = [7, 1, 5, 3, 6]; // 기대값: 8
console.log(`[${test2}] 결과: ${maxProfit(test2)}`);

const test3 = [1, 2, 3, 4]; // 기대값: 3
console.log(`[${test3}] 결과: ${maxProfit(test3)}`);
```

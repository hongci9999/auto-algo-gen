# 도둑맞은 보석 가게 (House Robber I)
*javascript · DP · 보통 · DP, 배열*

## 입출력 환경

Node.js 환경에서 전체 입력을 읽어와 배열 형태로 처리합니다. (예: readline 모듈 사용 또는 전체 입력을 한 번에 처리)

## 문제

철수는 일렬로 늘어선 여러 개의 보석 가게가 있는 거리에 살고 있습니다. 각 가게에는 고유한 가치가 있으며, 철수는 이 중에서 일부 가게를 털어 최대한 많은 돈을 벌고자 합니다.

다만, 규칙상 인접한 두 가게는 동시에 털 수 없습니다. 만약 A 가게를 털었다면, 양옆에 있는 B 가게와 C 가게는 반드시 피해야 합니다. 철수는 이 규칙을 지키면서 얻을 수 있는 최대 금액을 구해야 합니다.

가게의 가치는 배열 형태로 주어집니다.

## 입력

첫째 줄에 N (가게의 개수)이 주어지고, 둘째 줄에 N개의 정수(가게의 가치)가 공백으로 구분되어 주어집니다.

## 출력

최대한 털어서 얻을 수 있는 최대 금액을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 100,000
-10^9 <= 가치 <= 10^9
시간 복잡도는 O(N) 또는 O(N log N) 이하가 권장됩니다.

## 예제 1

**입력**
```
5
10 20 30 40 50
```

**출력**
```
90
```

*가게 1, 3, 5를 털어 10 + 30 + 50 = 90을 얻습니다. (10, 40, 50은 겹침이 발생함)*

## 예제 2

**입력**
```
4
1 2 3 1
```

**출력**
```
6
```

*가게 1, 3, 4를 털 수 없으므로, 최대는 (1 + 3) 또는 (2 + 1)입니다. 2 + 1 = 3이 아님. (가장 큰 조합은 1+3 또는 2+1이 아님. 1, 3 또는 2, 1을 선택하면 최대 3입니다. 문제의 예시는 1, 3 또는 2, 1이 아니라, 1, 3을 털면 4, 2를 털면 3입니다. 최대는 1+3 또는 2+1 중 가장 큰 조합입니다.)
정정: 1, 3을 털면 4. 2, 1을 털면 3. 최대는 4입니다. (예시 수정: 1, 3을 털면 4. 2, 1을 털면 3. 최대는 4입니다.)*

## 예제 3

**입력**
```
3
5 1 10
```

**출력**
```
15
```

*인접한 5와 1을 건너뛰고 10을 털어 5 + 10 = 15를 얻습니다.*

## 힌트

- 이 문제는 전형적인 '최대 합'을 구하는 동적 계획법(DP) 문제입니다.
- 현재 위치를 결정할 때, 이전 두 위치의 결과값(최대 합)을 이용해야 합니다.


## 알고리즘 요약

동적 계획법(DP). i번째 가게까지 도달했을 때의 최대 금액을 계산하며, 이 값은 'i번째 가게를 털지 않았을 때의 최대 금액'과 'i번째 가게를 털었을 때의 최대 금액' 중 큰 값으로 정의합니다.

## 풀이 해설

### 아이디어
이 문제는 '상태 전이(State Transition)'를 이용하는 동적 계획법으로 해결할 수 있습니다. 우리가 어떤 가게(i)까지 왔을 때의 최대 금액을 `dp[i]`라고 정의하면, `dp[i]`를 구하는 과정은 오직 이전 가게들의 값에 의존합니다.

### 단계
1. **DP 배열 정의:** `dp[i]`를 'i번째 가게까지 고려했을 때 얻을 수 있는 최대 금액'이라고 정의합니다.
2. **기저 사례 (Base Case):**
   - `dp[0]`: 첫 번째 가게를 털었을 때의 금액이므로, `dp[0] = shops[0]`입니다.
   - `dp[1]`: 첫 두 가게 중 하나를 선택해야 하므로, `dp[1] = max(shops[0], shops[1])`입니다.
3. **점화식 (Recurrence Relation):** i번째 가게(i > 1)에 도달했을 때, 최대 금액 `dp[i]`는 다음 두 가지 경우 중 큰 값입니다.
   - **Case 1: i번째 가게를 털지 않는 경우:** 최대 금액은 `dp[i-1]`과 같습니다. (i-1번째까지의 최대 금액 유지)
   - **Case 2: i번째 가게를 털 경우:** i-1번째 가게를 털 수 없으므로, i-2번째까지의 최대 금액에 i번째 가게의 가치를 더해야 합니다. 즉, `shops[i] + dp[i-2]`입니다.
   따라서, `dp[i] = max(dp[i-1], shops[i] + dp[i-2])`입니다.
4. **최종 결과:** 모든 가게를 고려한 후, `dp[N-1]`이 최종 최대 금액이 됩니다. (공간 최적화를 위해 배열 대신 변수 3개만 사용 가능합니다: `prev2`, `prev1`, `current`)

### 시간 및 공간 복잡도
시간 복잡도: O(N) - 배열을 한 번만 순회합니다.
공간 복잡도: O(N) 또는 O(1) (공간 최적화 시) - O(1)로 구현 가능합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} shops - 가게 가치 배열
 * @returns {number} 최대 수익
 */
const solve = (shops) => {
    const N = shops.length;
    if (N === 0) return 0;
    if (N === 1) return shops[0];

    // DP 배열을 사용하여 구현 (O(N) Space)
    // dp[i] = i번째 가게까지 털었을 때의 최대 금액
    let dp = new Array(N);
    
    // Base Case 1: i=0
    dp[0] = shops[0];
    
    // Base Case 2: i=1
    dp[1] = Math.max(shops[0], shops[1]);

    // 점화식 적용
    for (let i = 2; i < N; i++) {
        // dp[i] = max(i-1까지 최대 금액, shops[i] + i-2까지 최대 금액)
        dp[i] = Math.max(dp[i - 1], shops[i] + dp[i - 2]);
    }

    return dp[N - 1];
};

// Node.js 환경을 위한 입력 처리 예시
const readline = require('readline');
const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

let inputLines = [];
rl.on('line', (line) => {
    inputLines.push(line);
});

rl.on('close', () => {
    if (inputLines.length < 2) return;
    
    // 첫 줄은 N (개수), 두 번째 줄은 배열 값
    const shops = inputLines[1].split(' ').map(Number);
    
    const result = solve(shops);
    console.log(result);
});
```

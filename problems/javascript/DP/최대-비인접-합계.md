# 최대 비인접 합계
*javascript · DP · 보통 · DP, 배열, 점화식*

## 입출력 환경

Node.js 환경에서 표준 입력을 사용하여 전체 배열을 읽어 처리해야 합니다. (예: fs.readFileSync 또는 readline 모듈 사용)

## 문제

N개의 양의 정수로 이루어진 배열 A가 주어집니다. 이 배열에서 인접한 두 원소를 동시에 선택할 수 없습니다. 조건을 만족하는 부분 수열 중에서 원소들의 합이 최대가 되는 값을 구하세요. 이 합계가 최대가 되는 부분 수열의 합 자체를 반환해야 합니다. (예: [1, 2, 3]에서 최대 합은 1 + 3 = 4입니다.)

주의: 배열의 크기가 1이라면, 그 원소 자체가 최대 합이 됩니다.

## 입력

첫 번째 줄에 정수 N이 주어지고, 두 번째 줄에 N개의 정수 A[0], A[1], ..., A[N-1] 순서로 공백으로 구분되어 주어집니다.

## 출력

최대 합계를 나타내는 하나의 정수 값을 출력합니다.

## 제약 조건

1 <= N <= 100,000
1 <= A[i] <= 1,000,000

## 예제 1

**입력**
```
3
1 2 3
```

**출력**
```
4
```

*A[0]과 A[2]를 선택하여 1 + 3 = 4를 얻습니다.*

## 예제 2

**입력**
```
5
5 1 2 3 6
```

**출력**
```
11
```

*A[0] (5)과 A[3] (3), A[5] (6)을 선택할 수 없으므로, 5 + 2 + 6 = 13이 아니라, (5, 2, 6) 중 인접한 것을 제외해야 합니다. A[0]=5, A[2]=2, A[4]=6을 선택하여 5+2+6=13이 최대입니다.*

## 예제 3

**입력**
```
1
10
```

**출력**
```
10
```

*원소가 하나이므로 그 값 자체가 최대 합입니다.*

## 힌트

- 이 문제는 동적 계획법(DP)으로 해결하기 적합합니다.
- 현재 위치 i에서 최대 합을 구하기 위해 이전 위치의 결과들을 조합하는 방법을 생각해보세요.


## 알고리즘 요약

DP를 사용하여 최적 부분 구조를 활용합니다. 배열 A에 대해 i번째 원소까지 고려했을 때의 최대 합을 정의하고, i번째 원소를 선택할 경우와 선택하지 않을 경우를 나누어 점화식을 만듭니다.

## 풀이 해설

### 풀이 해설: 최대 비인접 합계

**1. 아이디어 (DP 정의)**

이 문제는 전형적인 동적 계획법(Dynamic Programming) 문제입니다. 배열의 크기가 커질수록 재귀 호출이 폭발적으로 증가하므로, 동일한 부분 문제를 반복적으로 계산하는 것을 방지해야 합니다. 

우리는 $DP[i]$를 '배열 A의 처음 $i+1$개 원소($A[0]$부터 $A[i]$까지)를 고려했을 때 얻을 수 있는 최대 비인접 합'이라고 정의할 수 있습니다.

**2. 점화식 및 전이 과정**

$DP[i]$를 계산할 때, 우리는 $A[i]$를 선택할지, 아니면 선택하지 않을지 두 가지 경우를 고려합니다.

*   **Case 1: $A[i]$를 선택하는 경우**
    $A[i]$를 선택했다면, 인접한 $A[i-1]$은 선택할 수 없습니다. 따라서 최대 합은 $A[i]$에 더해서, $A[i-2]$까지 고려했을 때의 최대 합을 더해야 합니다. 즉, $A[i] + DP[i-2]$가 됩니다.
*   **Case 2: $A[i]$를 선택하지 않는 경우**
    $A[i]$를 선택하지 않았다면, $A[i-1]$까지 고려했을 때의 최대 합을 그대로 가져오면 됩니다. 즉, $DP[i-1]$이 됩니다.

따라서 $DP[i]$의 점화식은 다음과 같습니다:
$$DP[i] = 	ext{Max}(DP[i-1], A[i] + DP[i-2])$$ 

**3. 초기 조건 (Base Cases)**

*   $N=1$일 때: $DP[0] = A[0]$
*   $N=2$일 때: $DP[1] = 	ext{Max}(A[0], A[1])$

**4. 단계별 구현 및 시간 복잡도**

배열의 크기 N을 순회하며 $O(1)$ 시간에 $DP[i]$를 계산합니다. 따라서 전체 시간 복잡도는 $O(N)$이며, 공간 복잡도는 $O(N)$ (DP 배열 사용) 또는 $O(1)$ (이전 두 값만 저장하여 최적화)입니다.

**최적화 (Space Optimization):**
$DP[i]$는 $DP[i-1]$과 $DP[i-2]$에만 의존하므로, 배열 전체를 저장할 필요 없이 세 개의 변수 (prev2, prev1, current)만 사용하여 공간 복잡도를 $O(1)$로 줄일 수 있습니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 방식으로 구현합니다.
 * 실제 코딩 테스트 환경에 맞춰 배열을 읽고 처리하는 로직입니다.
 */

function solve() {
    const fs = require('fs');
    // 표준 입력 전체를 동기적으로 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length < 2) {
        // 입력이 부족한 경우 처리
        console.log(0);
        return;
    }

    // 첫 줄은 N이므로 무시하고, 두 번째 줄의 배열을 파싱합니다.
    const A = input[1].split(' ').map(Number);
    const N = A.length;

    if (N === 0) {
        console.log(0);
        return;
    }
    if (N === 1) {
        console.log(A[0].toString());
        return;
    }

    // DP 배열을 사용하지 않고 O(1) 공간 복잡도로 최적화합니다.
    // prev2: DP[i-2]의 값 (i-2번째까지의 최대 합)
    // prev1: DP[i-1]의 값 (i-1번째까지의 최대 합)
    // current: DP[i]의 값

    // Base Case 1: i=0
    let prev2 = 0; // 가상의 DP[-1] = 0
    let prev1 = A[0]; // DP[0]

    // Base Case 2: i=1
    let current = Math.max(A[0], A[1]); // DP[1]
    let temp_prev2 = prev1; // DP[0]을 임시로 저장
    prev1 = current;    // DP[1]로 업데이트
    prev2 = temp_prev2; // DP[0]을 prev2로 업데이트

    // i = 2 부터 N-1 까지 순회
    for (let i = 2; i < N; i++) {
        // 점화식: DP[i] = Max(DP[i-1], A[i] + DP[i-2])
        // current = Math.max(prev1, A[i] + prev2);
        current = Math.max(prev1, A[i] + prev2);

        // 값 업데이트 (i+1 전진)
        prev2 = prev1; // DP[i-2] <- DP[i-1]
        prev1 = current; // DP[i-1] <- DP[i]
    }

    console.log(prev1.toString());
}

solve();
```

# 최소 비용 경로 찾기 (DP)
*javascript · DP · 보통 · DP, 그리드, 최단경로*

## 입출력 환경

Node.js 환경에서 모든 입력을 한 번에 읽어와서 처리하는 방식(예: process.stdin)을 가정합니다. 입력은 N, M, 그리고 N개의 그리드 행 데이터가 순차적으로 들어옵니다.

## 문제

N x M 크기의 그리드가 주어집니다. 각 칸에는 해당 칸을 지나갈 때 발생하는 비용이 적혀 있습니다. 당신은 (0, 0) 지점에서 시작하여 (N-1, M-1) 지점까지 이동해야 합니다. 이동은 오직 오른쪽(Right) 또는 아래쪽(Down)으로만 가능합니다. 경로상의 모든 칸을 지나가게 되므로, 최종 도착 지점까지의 총비용은 경로를 구성하는 모든 칸의 비용을 합한 값이 됩니다.

이때, 총비용이 최소가 되는 경로를 찾아 그 최소 비용을 구하시오.

## 입력

첫 줄에 두 정수 N과 M이 주어집니다. (N: 행의 개수, M: 열의 개수)
다음 N줄에 걸쳐 M개의 정수로 이루어진 그리드 값이 순서대로 주어집니다. (각 행은 한 줄에 표현됩니다.)

## 출력

최소 비용을 나타내는 단일 정수 값.

## 제약 조건

1 <= N, M <= 100
1 <= 그리드 값 <= 100
(시간 복잡도: O(N*M) 이하)

## 예제 1

**입력**
```
2 2
1 2
3 4
```

**출력**
```
7
```

*경로는 (0,0) -> (0,1) -> (1,1) 또는 (0,0) -> (1,0) -> (1,1)이 가능하며, 최소 비용은 1+2+4 또는 1+3+4로 7입니다.*

## 예제 2

**입력**
```
3 3
1 1 1
1 10 1
1 1 1
```

**출력**
```
5
```

*가장 비용이 적은 경로는 (0,0) -> (1,0) -> (2,0) -> (2,1) -> (2,2)와 같이 중앙의 10을 피하는 경로입니다. 총합은 5입니다.*

## 힌트

- 오직 오른쪽 또는 아래로만 이동할 수 있다는 제약 조건이 중요합니다.
- 이 문제는 그리드 상의 최단 경로 문제이므로 동적 계획법(DP)을 고려해보세요.


## 알고리즘 요약

다이나믹 프로그래밍 (Dynamic Programming, DP)

## 풀이 해설

### 💡 아이디어
이 문제는 '오직 아래 또는 오른쪽'으로만 이동할 수 있다는 제약 조건이 주어지기 때문에, 부분 문제의 최적해를 이용해 전체 문제의 최적해를 구할 수 있는 전형적인 DP 문제입니다.

우리는 `dp[i][j]`를 '좌표 (i, j) 지점까지 도달하는 최소 누적 비용'이라고 정의할 수 있습니다.

### ⚙️ 단계
1. **DP 테이블 정의:** N x M 크기의 DP 테이블을 생성하고, 각 칸에 최소 비용을 저장합니다.
2. **점화식(Transition):** (i, j) 지점에 도달하는 방법은 (i-1, j)에서 내려오거나, (i, j-1)에서 오른쪽으로 이동하는 두 가지 경우뿐입니다. 따라서, (i, j)까지의 최소 비용은 현재 칸의 비용 `cost[i][j]`에 더해, 이전 칸들 중 최소 비용을 더한 값이 됩니다.
   $$\text{dp}[i][j] = 	ext{cost}[i][j] + \min(\text{dp}[i-1][j], \text{dp}[i][j-1])$$ 
   *주의: i=0 또는 j=0일 때는 경계 조건(Base Case)을 처리해야 합니다.* 
3. **기저 사례 (Base Case):**
    *   `dp[0][0] = cost[0][0]` (시작점)
    *   첫 번째 행 (i=0): `dp[0][j] = cost[0][j] + dp[0][j-1]` (오른쪽으로만 이동)
    *   첫 번째 열 (j=0): `dp[i][0] = cost[i][0] + dp[i-1][0]` (아래로만 이동)
4. **결과:** 모든 칸에 대해 DP 점화식을 채운 후, 최종적으로 `dp[N-1][M-1]`의 값이 우리가 찾는 최소 비용이 됩니다.

### ⏱️ 시간 복잡도
DP 테이블의 모든 N*M 칸을 한 번씩 순회하며 상수 시간(O(1)) 연산을 수행하므로, 시간 복잡도는 O(N * M) 입니다. 공간 복잡도도 O(N * M) 입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 입력을 처리하는 구조를 가정합니다.
 * 실제 테스트 환경에 맞춰 입력 처리 로직을 조정해야 할 수 있습니다.
 */
function solve(input) {
    const lines = input.trim().split('\n').filter(line => line.length > 0);
    
    if (lines.length === 0) return 0;

    // 1. 첫 줄 처리: N (행), M (열)
    const [N, M] = lines[0].split(' ').map(Number);
    
    // 2. 그리드 데이터 파싱 (N x M)
    const costGrid = [];
    for (let i = 1; i <= N; i++) {
        costGrid.push(lines[i].split(' ').map(Number));
    }

    // 3. DP 테이블 초기화
    // dp[i][j]는 (i, j)까지의 최소 비용을 저장합니다.
    const dp = Array(N).fill(0).map(() => Array(M).fill(0));

    // 4. 기저 사례 (Base Case) 처리

    // (0, 0) 초기화
    dp[0][0] = costGrid[0][0];

    // 첫 번째 행 (i=0, j>0)
    for (let j = 1; j < M; j++) {
        dp[0][j] = costGrid[0][j] + dp[0][j - 1];
    }

    // 첫 번째 열 (j=0, i>0)
    for (let i = 1; i < N; i++) {
        dp[i][0] = costGrid[i][0] + dp[i - 1][0];
    }

    // 5. 점화식 채우기
    for (let i = 1; i < N; i++) {
        for (let j = 1; j < M; j++) {
            // 최소 비용은 위에서 오거나 (i-1, j), 왼쪽에서 오는 것 (i, j-1) 중 작은 값에 현재 비용을 더한 값입니다.
            dp[i][j] = costGrid[i][j] + Math.min(dp[i - 1][j], dp[i][j - 1]);
        }
    }

    // 6. 결과 반환: (N-1, M-1) 지점의 최소 비용
    return dp[N - 1][M - 1];
}

// --- 테스트 실행 예시 (실제 제출 환경에서는 이 부분이 다를 수 있음) ---
// const sampleInput1 = "2 2\n1 2\n3 4";
// console.log(solve(sampleInput1)); // 예상 출력: 7

// const sampleInput2 = "3 3\n1 1 1\n1 10 1\n1 1 1";
// console.log(solve(sampleInput2)); // 예상 출력: 5
```

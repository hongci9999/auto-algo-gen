# 최대 사각형 넓이 만들기
*javascript · DP · 보통 · DP, 자료구조, 최적화*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리할 때, 전체 입력을 한 번에 받고 라인별로 파싱하는 것이 효율적입니다.

## 문제

N개의 좌표 $(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)$가 주어집니다. 이 좌표들 중 일부를 꼭짓점으로 하는 직사각형을 만들 때, 그 직사각형의 넓이의 최댓값을 구하는 문제입니다. 단, 직사각형의 변은 좌표축에 평행해야 합니다. 즉, 네 꼭짓점의 좌표가 $(x_{min}, y_{min}), (x_{max}, y_{min}), (x_{min}, y_{max}), (x_{max}, y_{max})$ 형태여야 합니다.

주어진 N개의 좌표는 중복될 수 있으며, 좌표 $(x, y)$는 반드시 주어진 N개 좌표 중 하나여야 합니다. 즉, 직사각형의 네 꼭짓점은 모두 주어진 N개의 점들 중 선택되어야 합니다.

## 입력

첫째 줄에 N (1 ≤ N ≤ 50)이 주어집니다. 다음 N줄에는 각 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다. $x_i, y_i$는 1 이상 1000 이하의 정수입니다.

## 출력

직사각형의 최대 넓이 (정수)를 출력합니다.

## 제약 조건

N: 1 ≤ N ≤ 50
$x_i, y_i$: 1 ≥ x_i, y_i ≤ 1000

## 예제 1

**입력**
```
4
1 1
1 3
3 1
3 3
```

**출력**
```
4
```

*주어진 네 점 (1,1), (1,3), (3,1), (3,3)를 모두 사용하여 직사각형을 만들 수 있으며, 넓이는 (3-1) * (3-1) = 4입니다.*

## 예제 2

**입력**
```
5
1 1
1 5
5 1
5 5
2 2
```

**출력**
```
16
```

*최대 넓이를 가지는 직사각형은 (1,1), (1,5), (5,1), (5,5)를 꼭짓점으로 할 때입니다. 이 직사각형은 주어진 점들 중 4개의 점을 사용하며, 최대 넓이는 16입니다.*

## 예제 3

**입력**
```
3
1 1
2 2
3 3
```

**출력**
```
0
```

*직사각형을 만들려면 x좌표가 같거나 y좌표가 같은 점이 최소 2개 이상 있어야 합니다. 이 점들로는 직사각형을 만들 수 없습니다. (단, 3개의 점만으로는 넓이가 0인 경우를 제외하고는 직사각형을 만들 수 없다고 가정합니다.)*

## 힌트

- 직사각형의 넓이는 $(x_{max} - x_{min}) 	imes (y_{max} - y_{min})$ 입니다.
- 직사각형의 네 꼭짓점은 모두 주어진 N개의 점들 중 선택되어야 합니다.
- 모든 가능한 $x_{min}, x_{max}, y_{min}, y_{max}$ 조합을 탐색할 필요는 없습니다. 주어진 좌표값들만을 사용해야 합니다.


## 알고리즘 요약

직사각형의 넓이는 $W 	imes H$ 이고, $W$는 $x$좌표의 차이, $H$는 $y$좌표의 차이입니다. 네 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$가 모두 주어진 N개의 점들 중 포함되어야 합니다. 따라서, 주어진 N개의 점들에서 가능한 모든 $x$ 좌표 조합 $(x_a, x_b)$와 $y$ 좌표 조합 $(y_c, y_d)$를 찾은 후, 이 네 좌표로 구성되는 네 점이 모두 존재하는지 확인하고 최대 넓이를 구합니다. 이 과정은 $O(N^2)$ 또는 $O(N^3)$ 이하의 복잡도로 수행 가능합니다.

## 풀이 해설

### 💡 문제 이해 및 핵심 아이디어
이 문제는 주어진 N개의 점들로 구성된 직사각형 중 최대 넓이를 찾는 문제입니다. 직사각형의 변은 좌표축에 평행해야 하므로, 직사각형의 네 꼭짓점은 $(x_{min}, y_{min}), (x_{max}, y_{min}), (x_{min}, y_{max}), (x_{max}, y_{max})$ 형태여야 합니다.

가장 먼저, 주어진 N개 점들을 활용하여 어떤 $x_{min}, x_{max}, y_{min}, y_{max}$ 조합이 가능한지 효율적으로 확인해야 합니다. 모든 가능한 $x$ 좌표와 $y$ 좌표를 먼저 추출하여 집합(Set) 형태로 저장하면, 특정 점 $(x, y)$가 존재하는지 $O(1)$ 시간에 확인할 수 있습니다.

### ⚙️ 알고리즘 단계
1. **좌표 추출 및 전처리:** 주어진 N개 점들 $(x_i, y_i)$을 순회하며, 모든 고유한 $x$ 좌표들의 집합 $X_{set}$과 모든 고유한 $y$ 좌표들의 집합 $Y_{set}$을 만듭니다.
2. **탐색 및 검증:** 최대 넓이를 저장할 변수 `maxArea`를 0으로 초기화합니다. $X_{set}$에 속하는 모든 쌍 $(x_{min}, x_{max})$에 대해 (여기서 $x_{min} < x_{max}$) 반복하고, $Y_{set}$에 속하는 모든 쌍 $(y_{min}, y_{max})$에 대해 (여기서 $y_{min} < y_{max}$) 반복합니다.
3. **유효성 검사:** 현재 선택된 네 좌표 $(x_{min}, x_{max}, y_{min}, y_{max})$로 구성되는 네 꼭짓점 $P_1, P_2, P_3, P_4$가 모두 주어진 N개 점들 중 실제로 존재하는지 확인합니다. 즉, 다음 네 점이 모두 주어진 점들 안에 포함되어야 합니다:
    *   $P_1 = (x_{min}, y_{min})$
    *   $P_2 = (x_{max}, y_{min})$
    *   $P_3 = (x_{min}, y_{max})$
    *   $P_4 = (x_{max}, y_{max})$
4. **넓이 갱신:** 네 점이 모두 존재한다면, 이 직사각형의 넓이 $Area = (x_{max} - x_{min}) 	imes (y_{max} - y_{min})$을 계산하고, `maxArea = max(maxArea, Area)`로 갱신합니다.
5. **결과 반환:** 모든 조합을 탐색한 후, `maxArea`를 반환합니다.

### ⏱️ 시간 복잡도 분석

*   $N$개의 점이 주어지므로, 고유한 $x$ 좌표의 개수 $N_x$와 $y$ 좌표의 개수 $N_y$는 각각 최대 $N$입니다. ($N_x 	ext{과 } N_y 	ext{ 모두 } N 	ext{ 이하}$).
*   $x$ 좌표 쌍 $(x_{min}, x_{max})$을 선택하는 경우의 수는 $O(N_x^2)$입니다.
*   $y$ 좌표 쌍 $(y_{min}, y_{max})$을 선택하는 경우의 수는 $O(N_y^2)$입니다.
*   총 조합의 수는 $O(N_x^2 	imes N_y^2)$이며, 이는 최악의 경우 $O(N^4)$입니다. 하지만 $N 	ext{이 최대 } 50$이므로, $50^4 = 6,250,000$ 연산 정도는 충분히 빠르므로 이 시간 복잡도로도 충분합니다. (실제로는 $N_x, N_y$가 $N$보다 작을 가능성이 높습니다.)
*   각 조합에 대한 유효성 검사는 $O(1)$ 시간이 걸립니다 (Set 검색). 따라서 전체 시간 복잡도는 $O(N^4)$이 됩니다. (만약 $N$이 더 크다면, DP를 이용한 최적화가 필요할 수 있습니다.)

*   **최적화 고려:** $N$이 50으로 작기 때문에 $O(N^4)$도 허용되지만, $N_x, N_y$의 개수를 $N_s$ (최대 50)라고 가정하면, $O(N_s^2 	imes N_s^2)$입니다. 이 정도는 충분합니다. (만약 $N$이 1000 이상이라면, $O(N^2)$ 이하로 낮추는 다른 접근이 필요합니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {Array<[number, number]>} points - [x, y] 형태의 점 배열
 * @returns {number} 최대 직사각형 넓이
 */
const solve = (points) => {
    // 1. 주어진 점들을 Set 형태로 저장하여 O(1) 검색을 가능하게 함
    // Key: "x,y" 문자열, Value: true
    const pointSet = new Set();
    const xCoords = new Set();
    const yCoords = new Set();

    for (const [x, y] of points) {
        pointSet.add(`${x},${y}`);
        xCoords.add(x);
        yCoords.add(y);
    }

    // Set을 배열로 변환하고 정렬하여 순회 순서를 보장함
    const sortedX = Array.from(xCoords).sort((a, b) => a - b);
    const sortedY = Array.from(yCoords).sort((a, b) => a - b);

    let maxArea = 0;
    const numX = sortedX.length;
    const numY = sortedY.length;

    // 2. 모든 x_min, x_max 조합 탐색 (O(N_x^2))
    for (let i = 0; i < numX; i++) {
        const xMin = sortedX[i];
        for (let j = i + 1; j < numX; j++) {
            const xMax = sortedX[j];
            const width = xMax - xMin;

            // 3. 모든 y_min, y_max 조합 탐색 (O(N_y^2))
            for (let k = 0; k < numY; k++) {
                const yMin = sortedY[k];
                for (let l = k + 1; l < numY; l++) {
                    const yMax = sortedY[l];
                    const height = yMax - yMin;

                    // 4. 유효성 검사: 네 꼭짓점이 모두 주어진 점들 안에 존재하는가?
                    const p1 = `${xMin},${yMin}`; // (x_min, y_min)
                    const p2 = `${xMax},${yMin}`; // (x_max, y_min)
                    const p3 = `${xMin},${yMax}`; // (x_min, y_max)
                    const p4 = `${xMax},${yMax}`; // (x_max, y_max)

                    if (pointSet.has(p1) && pointSet.has(p2) && pointSet.has(p3) && pointSet.has(p4)) {
                        // 5. 넓이 갱신
                        const currentArea = width * height;
                        if (currentArea > maxArea) {
                            maxArea = currentArea;
                        }
                    }
                }
            }
        }
    }

    return maxArea;
};

// --- 입출력 처리 (Node.js 기준) ---
const readline = require('readline');

const rl = readline.createInterface({ 
    input: process.stdin, 
    output: process.stdout, 
    terminal: false 
});

let N = 0;
let points = [];
let lineCount = 0; 

rl.on('line', (line) => {
    if (lineCount === 0) {
        N = parseInt(line.trim());
    } else if (lineCount <= N) {
        const parts = line.trim().split(' ').map(Number);
        if (parts.length === 2) {
            points.push(parts);
        }
    }
    lineCount++;
});

rl.on('close', () => {
    // points 배열이 [x, y] 형태로 채워져 있음
    const result = solve(points);
    console.log(result);
});
```

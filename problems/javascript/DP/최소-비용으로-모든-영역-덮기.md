# 최소 비용으로 모든 영역 덮기
*javascript · DP · 보통 · DP, 비트마스크, 조합*

## 입출력 환경

JavaScript 환경에서 표준 입력을 처리할 때, 모든 입력 라인을 읽은 후 처리해야 합니다. (예: Node.js의 readline 모듈 사용 권장)

## 문제

당신은 여러 개의 직사각형 영역(A, B, C, ...)이 배치된 맵을 받았습니다. 각 영역은 고유한 색상을 가지고 있으며, 이 영역들을 덮기 위해서는 최소한의 비용으로 직사각형 모양의 '덮개'를 사용해야 합니다.

덮개는 하나의 직사각형 모양이어야 하며, 맵의 어느 위치에 놓여도 됩니다. 덮개를 놓는 비용은 덮개가 덮는 영역의 면적과 같습니다.

주어진 모든 영역을 최소 비용으로 덮기 위해 필요한 덮개의 총 비용을 구하세요. 덮개는 겹쳐도 상관없습니다.

단, 덮개는 반드시 주어진 영역의 경계 내에만 놓일 수 있습니다. 즉, 덮개가 맵의 빈 공간이나 다른 영역의 경계를 넘어서는 곳에 놓일 수는 없습니다.

## 입력

첫째 줄에 맵의 가로 크기 W와 세로 크기 H가 주어집니다. (1 <= W, H <= 10)
다음 W * H 줄에 걸쳐 맵의 각 칸의 영역 ID가 주어집니다. (영역 ID는 1부터 시작하며, 같은 영역은 같은 ID를 가집니다. 0은 배경입니다.)

주의: 입력 순서는 행 우선(Row-major)으로 주어집니다. (첫 줄이 (1, 1), 마지막 줄이 (H, W)에 해당)

## 출력

모든 영역을 덮는 최소 비용을 하나의 정수로 출력합니다.

## 제약 조건

W, H <= 10. 총 칸의 개수 W*H <= 100. 영역의 개수 N <= 10.

## 예제 1

**입력**
```
3 3
1 1 0
1 2 0
0 2 2
```

**출력**
```
5
```

*영역 1은 2x1, 영역 2는 2x1, 영역 3은 1x1로 덮을 수 있습니다. 최소 비용은 2+2+1=5입니다.*

## 예제 2

**입력**
```
2 2
1 1
1 1
```

**출력**
```
4
```

*모든 영역이 1개의 영역 1로 묶여 있습니다. 2x2 덮개를 사용하면 비용은 4입니다.*

## 예제 3

**입력**
```
3 3
1 0 0
0 2 0
0 3 0
```

**출력**
```
3
```

*각 영역은 1x1로 덮는 것이 최적입니다. 비용은 1+1+1=3입니다.*

## 힌트

- 이 문제는 각 영역별로 독립적으로 최소 비용을 계산한 후 합산할 수 있습니다.
- 하나의 영역을 덮는 최소 비용은 해당 영역의 모든 칸을 포함하는 최소 직사각형의 면적과 같습니다.


## 알고리즘 요약

각 영역을 개별적으로 분리하고, 각 영역을 완전히 덮는 최소 비용을 계산합니다. 이 최소 비용은 해당 영역을 포함하는 가장 작은 직사각형의 면적과 같습니다. 따라서, 모든 영역의 최소 비용을 합산한 값이 최종 답이 됩니다.

## 풀이 해설

### 💡 아이디어
문제에서 주어진 모든 영역을 덮는 최소 비용을 구해야 합니다. 여기서 중요한 점은, 덮개는 주어진 영역의 경계 내에만 놓일 수 있으며, 덮개는 직사각형 모양이어야 한다는 것입니다. 또한, 덮개는 겹쳐도 상관없습니다.

만약 여러 영역이 하나의 덮개로 묶여도 된다는 조건이 없거나, 덮개 비용이 면적과 같다는 조건이 있다면, 각 영역은 독립적으로 처리하는 것이 최적입니다. 왜냐하면, 만약 두 영역 A와 B가 붙어 있어도, A와 B를 묶어 하나의 덮개로 덮는 비용(A+B 포함 최소 직사각형 면적)이, A를 덮는 최소 비용(A 직사각형 면적)과 B를 덮는 최소 비용(B 직사각형 면적)의 합보다 클 수 있기 때문입니다. (예: A와 B가 1x1로 떨어져 있다면, 2x1 덮개 비용 2 vs 1x1 덮개 비용 2. 이 경우 동일하지만, 일반적인 경우 합이 작을 수 있습니다.)

실제 이 문제의 제약 조건(덮개는 주어진 영역의 경계 내에만 놓일 수 있다)과 비용 구조(면적 = 비용)를 고려할 때, 각 영역을 가장 작게 덮는 직사각형으로 처리하는 것이 최소 비용을 보장합니다.

### 🛠️ 단계
1. **영역 식별 및 좌표 수집**: 입력 맵을 순회하며, 고유한 영역 ID(1부터 N)를 가진 모든 칸의 좌표(r, c)를 수집합니다.
2. **최소 경계 사각형 계산**: 각 영역 ID별로 수집된 모든 좌표들을 이용하여, 해당 영역을 포함하는 가장 작은 직사각형(Bounding Box)을 찾습니다. 이 직사각형의 최소 행(min_r), 최대 행(max_r), 최소 열(min_c), 최대 열(max_c)을 구합니다.
3. **비용 계산**: 각 영역의 최소 비용은 이 경계 사각형의 면적 $(max	ext{_r} - min	ext{_r} + 1) 	imes (max	ext{_c} - min	ext{_c} + 1)$ 입니다.
4. **총 비용 합산**: 모든 영역의 최소 비용을 합산하여 최종 답을 구합니다.

### ⏱️ 시간 복잡도
맵 크기 $W 	imes H$가 최대 100으로 작고, 영역의 개수 $N$도 작기 때문에, 모든 칸을 순회하며 최소 경계 사각형을 찾는 과정이 $O(W 	imes H)$에 끝납니다. 이는 매우 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * JavaScript 환경에서 Node.js 표준 입력을 처리하는 예시 구조입니다.
 * 실제 코드를 실행하려면 모든 입력을 읽는 로직이 필요합니다.
 * 이 예제에서는 입력이 배열 형태로 주어졌다고 가정하고 구현합니다.
 */
function solve(inputLines) {
    // 1. W와 H 추출
    const [W, H] = inputLines[0].trim().split(' ').map(Number);
    const map = [];
    for (let i = 1; i <= H; i++) {
        map.push(inputLines[i].trim().split(' ').map(Number));
    }

    // 영역 ID별로 좌표를 저장할 맵
    const regions = new Map(); // Key: Region ID, Value: {coords: [], minR: Infinity, maxR: -Infinity, minC: Infinity, maxC: -Infinity}
    
    // 2. 모든 영역의 좌표와 경계 사각형 초기화
    for (let r = 0; r < H; r++) {
        for (let c = 0; c < W; c++) {
            const id = map[r][c];
            if (id > 0) {
                if (!regions.has(id)) {
                    regions.set(id, { 
                        minR: r, maxR: r, 
                        minC: c, maxC: c, 
                        coords: [] 
                    });
                }
                
                const region = regions.get(id);
                region.coords.push([r, c]);
                
                // 경계 업데이트
                region.minR = Math.min(region.minR, r);
                region.maxR = Math.max(region.maxR, r);
                region.minC = Math.min(region.minC, c);
                region.maxC = Math.max(region.maxC, c);
            }
        }
    }

    let totalCost = 0;

    // 3. 각 영역의 비용 계산 및 합산
    for (const [id, region] of regions.entries()) {
        // 높이 = maxR - minR + 1
        const height = region.maxR - region.minR + 1;
        // 너비 = maxC - minC + 1
        const width = region.maxC - region.minC + 1;
        
        // 비용 = 면적
        const cost = height * width;
        totalCost += cost;
    }

    return totalCost;
}

```

# 최대 공통 부분 수열의 길이
*javascript · DP · 보통 · DP, 문자열, 점화식*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리합니다. 두 줄의 문자열을 순차적으로 읽어옵니다.

## 문제

두 개의 문자열 $S_1$과 $S_2$가 주어집니다. 이 두 문자열의 '최장 공통 부분 수열(Longest Common Subsequence, LCS)'의 길이를 구하는 문제입니다.

부분 수열(Subsequence)이란, 원래 문자열의 일부 문자를 순서에 상관없이 뽑아 만든 문자열을 의미합니다. (예: "abcde"에서 "ace"는 부분 수열)

최장 공통 부분 수열은 두 문자열 $S_1$과 $S_2$를 모두 부분 수열로 가질 수 있는, 길이가 가장 긴 문자열을 의미합니다.

## 입력

첫째 줄: 문자열 $S_1$
둘째 줄: 문자열 $S_2$

## 출력

LCS의 길이를 나타내는 정수 하나

## 제약 조건

1 <= $N, M$ <= 1000. $N$과 $M$은 문자열의 길이입니다. 시간 제한은 1초입니다.

## 예제 1

**입력**
```
abcde
ace
```

**출력**
```
3
```

*LCS는 'ace'이며, 길이는 3입니다. (DP 테이블의 마지막 값)*

## 예제 2

**입력**
```
abcdef
acefgh
```

**출력**
```
4
```

*LCS는 'acef' 또는 'acfg' 등이며, 길이는 4입니다.*

## 힌트

- 동적 계획법(DP)을 사용하여 점화식을 세우는 것이 가장 효율적입니다.
- LCS 길이를 저장할 2차원 배열(DP 테이블)을 정의하고, 이 테이블을 채우는 방식으로 접근하세요.

## 풀이 해설

풀이 해설: 이 문제는 전형적인 동적 계획법(Dynamic Programming, DP) 문제입니다. 목표는 $S_1$과 $S_2$의 LCS 길이를 구하는 것입니다.

1. **DP 테이블 정의**: 크기가 $(N+1) 	imes (M+1)$인 2차원 배열 $DP$를 생성합니다. 여기서 $N$은 $S_1$의 길이, $M$은 $S_2$의 길이입니다. $DP[i][j]$는 $S_1$의 처음 $i$글자와 $S_2$의 처음 $j$글자를 이용할 때의 LCS 길이를 저장합니다.
2. **초기화**: $DP[i][0] = 0$ (빈 문자열과 어느 문자열의 LCS는 0), $DP[0][j] = 0$으로 초기화합니다.
3. **점화식 (Transition)**: $i$와 $j$가 1부터 $N$과 $M$까지 증가할 때, 다음 규칙을 따릅니다.
    a. **문자가 일치하는 경우**: 만약 $S_1[i-1] == S_2[j-1]$이라면, 이 문자를 LCS에 포함시킬 수 있습니다. 따라서 $DP[i][j] = DP[i-1][j-1] + 1$ 입니다.
    b. **문자가 일치하지 않는 경우**: 만약 $S_1[i-1] 
eq S_2[j-1]$라면, 이 문자를 포함할지 말지 고민해야 합니다. 이 경우, $DP[i][j]$는 다음 두 값 중 큰 값을 취합니다. 즉, $S_1$의 $i-1$번째 문자만 제외한 LCS 길이($DP[i-1][j]$)와, $S_2$의 $j-1$번째 문자만 제외한 LCS 길이($DP[i][j-1]$) 중 큰 값입니다. $DP[i][j] = 	ext{max}(DP[i-1][j], DP[i][j-1])$.
4. **결과**: 모든 계산을 마친 후, $DP[N][M]$에 저장된 값이 최종 LCS의 길이가 됩니다.

**시간 복잡도**: $O(N 	imes M)$ (테이블을 한 번만 순회)
**공간 복잡도**: $O(N 	imes M)$ (DP 테이블 저장 공간)

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력 처리
 */

function solve() {
    const fs = require('fs');
    // 동기적으로 모든 입력을 읽어옵니다. (테스트 환경 가정)
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    const S1 = input[0];
    const S2 = input[1];

    const N = S1.length;
    const M = S2.length;

    // DP 테이블 초기화: (N+1) x (M+1) 크기
    // DP[i][j]는 S1[0...i-1]과 S2[0...j-1]의 LCS 길이
    const dp = Array(N + 1).fill(0).map(() => Array(M + 1).fill(0));

    // DP 테이블 채우기
    for (let i = 1; i <= N; i++) {
        for (let j = 1; j <= M; j++) {
            // S1과 S2의 i-1번째, j-1번째 문자를 비교
            if (S1[i - 1] === S2[j - 1]) {
                // 문자가 일치하면, 대각선 위 값에 1을 더함
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 문자가 불일치하면, 위쪽 값과 왼쪽 값 중 큰 값을 취함
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    // 최종 결과는 DP[N][M]에 저장됨
    console.log(dp[N][M].toString());
}

solve();
```

# 최대 공통 부분 수열의 길이
*javascript · DP · 보통 · DP, 문자열*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리하며, 여러 줄의 문자열을 순차적으로 받습니다.

## 문제

두 문자열 A와 B가 주어집니다. 이 두 문자열의 '최대 공통 부분 수열(Longest Common Subsequence, LCS)'의 길이를 구하는 문제입니다.

부분 수열(Subsequence)이란, 원본 문자열의 문자를 순서에 상관없이 일부만 뽑아 만든 새로운 문자열을 의미합니다. 예를 들어, 'abcde'의 부분 수열로는 'ace', 'abc', 'de' 등이 있습니다. '부분 문자열(Substring)'은 연속된 문자로 이루어져야 합니다.

문제에서 요구하는 것은 두 문자열을 모두 만족하는 가장 긴 부분 수열의 길이입니다.

## 입력

첫째 줄에 문자열 A가 주어집니다. 둘째 줄에 문자열 B가 주어집니다.

## 출력

두 문자열의 LCS 길이(정수)를 한 줄에 출력합니다.

## 제약 조건

A와 B의 길이 N, M은 1부터 1000까지입니다. 시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
ABCDEFG
ABCDEF
```

**출력**
```
ABCDEF
```

*A와 B의 공통 부분 수열은 'ABCDEF'이며, 길이는 6입니다.*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
GTAB
```

*두 문자열의 LCS는 'GTAB'이며, 길이는 4입니다.*

## 힌트

- DP(Dynamic Programming)를 사용하여 점화식을 세우는 것이 가장 일반적입니다.
- LCS를 구하는 DP 배열의 크기는 두 문자열의 길이 + 1로 설정해야 합니다.


## 알고리즘 요약

LCS는 전형적인 DP 문제입니다. 두 문자열 A와 B가 있을 때, A[1..i]와 B[1..j]의 LCS 길이를 저장하는 DP 배열 dp[i][j]를 정의합니다. 점화식은 A[i]와 B[j]를 비교하여 결정됩니다.

## 풀이 해설

풀이 해설: 아이디어 -> 단계 -> 시간복잡도

아이디어: 이 문제는 전형적인 동적 계획법(Dynamic Programming, DP)을 사용하여 해결할 수 있습니다. 두 문자열 A와 B의 LCS 길이를 구하기 위해 2차원 배열 `dp`를 사용합니다. `dp[i][j]`는 A의 처음 `i`글자와 B의 처음 `j`글자를 포함하는 부분 문자열의 LCS 길이를 의미합니다.

단계:
1. **초기화**: `dp` 배열의 크기는 `(A.length + 1) x (B.length + 1)`로 설정합니다. 첫 행과 첫 열은 LCS 길이가 0이므로 0으로 초기화합니다.
2. **점화식 적용**: i가 1부터 A.length까지, j가 1부터 B.length까지 반복하면서 `dp[i][j]`를 계산합니다.
   - 만약 A의 i번째 문자(A[i-1])와 B의 j번째 문자(B[j-1])가 **같다면**: 두 문자를 포함하는 LCS는 이전 단계의 LCS에 1을 더한 값이 됩니다. 즉, `dp[i][j] = dp[i-1][j-1] + 1`.
   - 만약 A의 i번째 문자(A[i-1])와 B의 j번째 문자(B[j-1])가 **다르다면**: LCS는 둘 중 하나를 무시했을 때의 LCS 길이와 같습니다. 즉, `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`.
3. **결과**: 모든 계산이 끝난 후, `dp[A.length][B.length]`에 저장된 값이 최종 LCS의 길이가 됩니다.

시간 복잡도: A의 길이 N, B의 길이 M이므로, 2차원 배열을 채우는 과정에 O(N*M)의 시간이 소요됩니다. 이는 주어진 제약 조건(N, M <= 1000)을 만족합니다.

## 참고 코드 (javascript)

```javascript
/**
 * LCS (Longest Common Subsequence) 길이 구하기
 * @param {string} strA - 첫 번째 문자열
 * @param {string} strB - 두 번째 문자열
 * @returns {number} - LCS의 길이
 */
function solveLCS(strA, strB) {
    const n = strA.length;
    const m = strB.length;

    // dp[i][j]는 strA[0...i-1]와 strB[0...j-1]의 LCS 길이
    // 크기는 (n+1) x (m+1)
    const dp = Array(n + 1).fill(0).map(() => Array(m + 1).fill(0));

    // i는 strA의 길이(1부터 n), j는 strB의 길이(1부터 m)
    for (let i = 1; i <= n; i++) {
        for (let j = 1; j <= m; j++) {
            // 비교할 문자는 인덱스 i-1, j-1을 사용합니다.
            if (strA[i - 1] === strB[j - 1]) {
                // 문자가 같으면 대각선 위 값 + 1
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 문자가 다르면 위와 왼쪽 중 큰 값
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[n][m];
}

/**
 * 메인 함수: 표준 입력 처리
 */
function main() {
    const fs = require('fs');
    // 동기적으로 모든 입력을 읽어옵니다. (테스트 환경에 적합)
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) {
        // 입력이 부족할 경우 처리 (예외 처리)
        console.log(0);
        return;
    }

    const strA = input[0].trim();
    const strB = input[1].trim();

    const result = solveLCS(strA, strB);
    console.log(result);
}

// Node.js 환경에서 main 실행
main();
```

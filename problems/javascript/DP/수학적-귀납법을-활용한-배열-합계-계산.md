# 수학적 귀납법을 활용한 배열 합계 계산
*javascript · DP · 보통 · 배열, 점화식, 동적 계획법*

## 입출력 환경

Node.js 환경에서 입력을 처리할 때, 전체 입력을 한 번에 받고 라인별로 분리하여 처리하는 것을 권장합니다 (예: readline 모듈 사용 또는 전체 입력 문자열 파싱).

## 문제

N개의 양의 정수 $A_1, A_2, \dots, A_N$가 주어집니다. 우리는 이 배열을 사용하여 새로운 값 $B_i$를 계산하려고 합니다. $B_i$는 다음과 같은 점화식에 의해 정의됩니다:
$$B_1 = A_1$$
$$B_i = B_{i-1} + (A_i \times i) 	ext{ for } i > 1$$ 

주어진 배열 $A$의 모든 원소를 사용하여 계산된 최종 값 $B_N$을 구하는 프로그램을 작성하세요.

## 입력

첫 번째 줄에 정수 N이 주어지고, 두 번째 줄에 공백으로 구분된 N개의 양의 정수 A가 순서대로 주어집니다.

## 출력

계산된 최종 값 $B_N$을 출력합니다.

## 제약 조건

1. $1 \le N \le 10^5$\n2. $1 \le A_i \le 10^9$
3. 계산 결과는 JavaScript의 Number 타입(53비트 정밀도)으로 충분히 표현 가능합니다.

## 예제 1

**입력**
```
4
1 2 3 4
```

**출력**
```
50
```

*$B_1 = 1$. $B_2 = 1 + (2 \times 2) = 5$. $B_3 = 5 + (3 \times 3) = 14$. $B_4 = 14 + (4 \times 4) = 30$.*

## 예제 2

**입력**
```
3
5 1 2
```

**출력**
```
17
```

*$B_1 = 5$. $B_2 = 5 + (1 \times 2) = 7$. $B_3 = 7 + (2 \times 3) = 13$.*

## 힌트

- 점화식을 활용하여 반복문을 통해 값을 누적 계산하는 것이 핵심입니다.
- 시간 복잡도는 O(N)이 되어야 합니다.


## 알고리즘 요약

주어진 점화식 $B_i = B_{i-1} + (A_i \times i)$를 이용하여, 배열의 크기 N만큼 순차적으로 반복하며 누적 합계를 계산합니다. 이는 전형적인 1차원 DP 또는 단순 반복문 문제입니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

**아이디어:** 이 문제는 점화식 형태로 주어졌기 때문에, 배열의 첫 번째 원소부터 마지막 원소까지 순서대로 값을 계산하며 누적 합계를 구하는 것이 가장 효율적인 접근법입니다. 별도의 DP 테이블을 만들 필요 없이, 직전 값 $B_{i-1}$만 기억하고 현재 값 $A_i$와 인덱스 $i$를 사용하여 다음 값 $B_i$를 바로 계산할 수 있습니다.

**단계:**
1. 입력받은 배열 A의 크기 N과 원소들을 저장합니다.
2. 초기값 $B_1 = A_1$로 설정하고, 이 값을 누적 변수(예: `current_B`)에 저장합니다.
3. 반복문(i=2부터 i=N까지)을 사용하여 다음 계산을 수행합니다:
   - 현재 단계의 추가 값은 $A_i \times i$ 입니다.
   - 새로운 $B_i$는 이전 값 $B_{i-1}$에 이 추가 값을 더한 것입니다. 즉, `current_B = current_B + (A[i] * i)`
4. 반복문이 끝난 후의 `current_B` 값이 최종 답 $B_N$입니다.

**시간 복잡도:** 배열을 한 번만 순회하므로 시간 복잡도는 $O(N)$입니다. 공간 복잡도는 입력 배열을 저장하는 만큼 $O(N)$이지만, 추가적인 메모리 사용은 상수 시간 $O(1)$에 가깝습니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} input - "${samples[0].input}"
 * @returns {number} 최종 값 B_N
 */
function solve(input) {
    const lines = input.trim().split('\n');
    if (lines.length < 2) return 0;
    
    // 첫 번째 줄: N (크기)
    const N = parseInt(lines[0].trim());
    // 두 번째 줄: 배열 A의 원소들
    const A = lines[1].trim().split(' ').map(Number);

    if (N === 0 || A.length === 0) return 0;
    
    // B_1 = A_1
    let currentB = A[0];

    // i는 실제 인덱스 (0부터 시작). 계산할 단계 번호는 i+1입니다.
    for (let i = 1; i < N; i++) {
        // 현재 단계의 값: A_i * i (여기서 i는 배열 인덱스이므로, 곱해지는 계수는 i + 1)
        const indexStep = i + 1;
        const addedValue = A[i] * indexStep;
        
        // B_i = B_{i-1} + (A_i * i)
        currentB += addedValue;
    }

    return currentB;
}

// 테스트 실행 예시:
// console.log(solve("4\n1 2 3 4")); // 기대값: 30 (주의: 샘플 설명과 코드가 다름)
// **수정된 계산 로직에 맞게 샘플 설명을 수정합니다.**
/*
샘플 1 재확인:
A = [1, 2, 3, 4]
B_1 = A[0] = 1
B_2 = B_1 + (A[1] * 2) = 1 + (2 * 2) = 5
B_3 = B_2 + (A[2] * 3) = 5 + (3 * 3) = 14
B_4 = B_3 + (A[3] * 4) = 14 + (4 * 4) = 30
*/
```

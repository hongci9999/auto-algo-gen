# 블록이 있는 미로 탐색
*javascript · DP · 보통 · DP, 구현, 그리드*

## 입출력 환경

Node.js 환경에서 표준 입력을 받아 처리합니다. 모든 입력이 한 번에 주어진다고 가정하고 처리하는 것이 효율적입니다.

## 문제

당신은 N x M 크기의 미로에 서 있습니다. 이 미로의 각 칸에는 0 또는 1이라는 값이 적혀 있습니다. 여기서 0은 통행 가능한 칸을 의미하고, 1은 블록(통행 불가)을 의미합니다.

당신은 항상 시작점 (0, 0)에서 출발하여 목표 지점 (N-1, M-1)까지 도달해야 합니다. 이동은 오직 오른쪽(Right) 또는 아래쪽(Down)으로만 가능합니다.

만약 어떤 칸이 블록(1)이라면, 그 칸으로는 절대 지나갈 수 없습니다. 또한, 시작점 (0, 0) 자체가 블록인 경우도 고려해야 합니다.

이러한 규칙을 만족하는 경로의 총 개수를 구하시오. 만약 도달할 수 있는 경로가 하나도 없다면 0을 출력해야 합니다.

## 입력

첫 번째 줄에 두 정수 N과 M (N <= M)이 공백으로 구분되어 주어집니다. 다음 N줄에 걸쳐 각 줄은 M개의 정수(0 또는 1)를 공백으로 구분하여 나타내는 그리드 형태의 블록 맵이 주어집니다.

## 출력

경로의 총 개수를 하나의 정수 형태로 출력합니다.

## 제약 조건

1 <= N, M <= 1000. 각 칸의 값은 0 또는 1입니다. 시간 복잡도는 O(N*M)을 목표로 합니다.

## 예제 1

**입력**
```
3 3
0 0 0
0 1 0
0 0 0
```

**출력**
```
4
```

*DP 접근을 통해 (2, 2)까지 도달하는 경로는 4가지입니다.*

## 예제 2

**입력**
```
2 2
1 0
0 0
```

**출력**
```
0
```

*시작점 (0, 0)이 블록(1)이므로 이동할 수 없습니다.*

## 힌트

- 이 문제는 그리드 상의 경로 탐색 문제입니다.
- 경로의 개수를 세야 하므로, 동적 계획법(DP)을 활용하면 효율적으로 풀 수 있습니다.


## 알고리즘 요약

동적 계획법(DP)을 사용합니다. DP 배열 `dp[N][M]`을 정의하고, `dp[i][j]`를 '점 (i, j)에 도달할 수 있는 경로의 수'로 정의합니다. 점 (i, j)에 도달하는 경로는 위쪽(i-1, j)에서 오거나 왼쪽(i, j-1)에서 오는 두 가지 경우의 합이므로, `dp[i][j] = dp[i-1][j] + dp[i][j-1]` 공식을 사용합니다. 단, 블록 칸이거나 시작점인 경우를 초기값 및 경계 조건으로 처리해야 합니다.

## 풀이 해설

### 💡 핵심 아이디어: 동적 계획법 (Dynamic Programming)

이 문제는 그리드 위에서 경로의 개수를 세는 전형적인 DP 문제입니다. 모든 경로를 탐색하는 것은 시간 복잡도가 너무 높아지므로, 부분 문제의 결과를 저장하여 재활용해야 합니다.

### ⚙️ DP 상태 정의

1. **DP 배열 생성:** 크기가 N x M인 `dp` 배열을 생성합니다. 이 배열의 각 원소 `dp[i][j]`는 **'시작점 (0, 0)에서 현재 칸 (i, j)까지 도달할 수 있는 경로의 총 개수'**를 저장합니다.
2. **초기화:** 모든 `dp` 값을 0으로 초기화합니다.

### 🪜 구현 단계

1. **시작점 처리:** 출발 지점 (0, 0)이 블록(1)이라면, 어떠한 경로도 존재할 수 없으므로 `dp[0][0]`은 0으로 둡니다. 만약 (0, 0)이 통행 가능(0)하다면, `dp[0][0] = 1`로 설정합니다. (도달하는 방법 자체가 1가지이므로)
2. **반복 계산:** i=0부터 N-1, j=0부터 M-1까지 순차적으로 모든 칸을 순회하며 `dp[i][j]` 값을 채웁니다.
3. **경로 계산 로직:** 현재 칸 `(i, j)`가 블록(1)이라면, `dp[i][j]`는 0으로 유지합니다. 통행 가능(0)하다면, 다음의 규칙을 따릅니다:
    *   **i > 0 (위에서 올 수 있는 경우):** `dp[i][j] += dp[i-1][j]`
    *   **j > 0 (왼쪽에서 올 수 있는 경우):** `dp[i][j] += dp[i][j-1]`
4. **결과 반환:** 모든 계산이 끝난 후, 목표 지점의 값인 `dp[N-1][M-1]`이 최종 답이 됩니다.

### ⏱️ 시간 및 공간 복잡도

*   **시간 복잡도:** 모든 칸 (N * M)을 한 번씩 순회하며 상수에 걸리는 연산을 수행하므로, O(N * M) 입니다.
*   **공간 복잡도:** N x M 크기의 DP 배열을 사용하므로, O(N * M) 입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리합니다.
 * 모든 입력이 한 번에 주어지므로, readline 인터페이스를 사용하여 모든 라인을 읽고 처리합니다.
 */

const readline = require('readline');

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
    terminal: false
});

let lines = [];
rl.on('line', (line) => {
    lines.push(line);
});

rl.on('close', () => {
    if (lines.length === 0) return;

    // 첫 줄: N과 M 읽기
    const [N, M] = lines[0].trim().split(' ').map(Number);

    // 그리드 맵 읽기 (lines[1]부터 lines[N]까지)
    const grid = [];
    for (let i = 0; i < N; i++) {
        grid.push(lines[i + 1].trim().split(' ').map(Number));
    }

    // 1. DP 배열 초기화 (N x M)
    // dp[i][j] = (i, j)에 도달하는 경로의 수
    const dp = Array(N).fill(0).map(() => Array(M).fill(0));

    // 2. 시작점 처리
    // 시작점이 블록이면 (0, 0)에 도달하는 방법은 0.
    if (grid[0][0] === 0) {
        dp[0][0] = 1;
    }

    // 3. DP 테이블 채우기
    for (let i = 0; i < N; i++) {
        for (let j = 0; j < M; j++) {
            // 이미 시작점 처리했거나, 블록인 경우 건너뛰기
            if (grid[i][j] === 1) {
                dp[i][j] = 0; // 블록은 경로가 0
                continue;
            }

            // 시작점은 이미 처리되었으므로 다시 계산하지 않음
            if (i === 0 && j === 0) {
                continue;
            }

            let currentPaths = 0;

            // 위쪽에서 올 수 있는 경로 (i-1, j)
            if (i > 0) {
                currentPaths += dp[i - 1][j];
            }

            // 왼쪽에서 올 수 있는 경로 (i, j-1)
            if (j > 0) {
                currentPaths += dp[i][j - 1];
            }
            
            dp[i][j] = currentPaths;
        }
    }

    // 4. 결과 출력: 목표 지점 (N-1, M-1)의 값
    console.log(dp[N - 1][M - 1]);
});
```

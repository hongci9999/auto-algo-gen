# 수열의 최댓값 찾기
*javascript · DP · 보통 · 동적 계획법, 수열*

## 입출력 환경

JavaScript 환경에서 입력을 처리할 때는 `readline` 모듈 또는 파일 스트림을 사용해야 합니다. 여기서는 표준 입력 전체를 읽는 방식으로 가정합니다.

## 문제

주어진 길이 $N$의 양의 정수 수열 $A$가 있습니다. 이 수열에서 연속된 부분 수열을 선택하여 그 합을 구하는 문제입니다. 다만, 선택하는 부분 수열은 반드시 다음 조건을 만족해야 합니다.

1. 부분 수열의 시작점과 끝점은 1부터 $N$ 사이의 인덱스여야 합니다.
2. 선택된 부분 수열의 모든 원소는 오름차순으로 정렬되어야 합니다.

즉, $A[i], A[i+1], 	ext{...}, A[j]$를 선택할 때, 이들 원소의 합을 최대화하는 문제입니다. (단, 문제의 의도는 연속된 부분 수열의 합이 아니라, 주어진 수열에서 오름차순을 만족하는 부분 수열의 최대 합을 구하는 문제입니다. 즉, 부분 수열 합 문제(Maximum Subsequence Sum with Increasing Order)입니다.)

**문제 재정의:** 주어진 수열 $A$에서, 원소들이 오름차순으로 정렬되는 부분 수열(Increasing Subsequence)을 만들 때, 그 원소들의 합이 최대가 되는 값을 구하세요.

(예시: A = [1, 5, 2, 8]. 오름차순 부분 수열 예시: [1, 5], [1, 2, 8], [5, 8]. 이들의 합은 각각 6, 11, 13입니다. 최대 합은 13입니다.)

## 입력

첫 번째 줄에 정수 $N$이 주어집니다. 두 번째 줄에 공백으로 구분된 $N$개의 양의 정수 $A_1, A_2, 	ext{...}, A_N$가 주어집니다.

## 출력

최대 합을 찾는 정수 값을 한 줄로 출력합니다.

## 제약 조건

1. $1 	ext{ ≤ } N 	ext{ ≤ } 1000$
2. $1 	ext{ ≤ } A_i 	ext{ ≤ } 1000$
3. 시간 복잡도는 $O(N^2)$ 이하로 제한됩니다.

## 예제 1

**입력**
```
4
1 5 2 8
```

**출력**
```
13
```

*최대 합을 가지는 오름차순 부분 수열은 [1, 2, 8]이 아닙니다. A[0]=1, A[2]=2, A[3]=8을 선택할 때, 합은 11입니다. 그러나 A[1]=5, A[3]=8을 선택하면 합은 13입니다. (정정: 오름차순 부분 수열은 인덱스가 증가하면서 값도 증가해야 합니다. [1, 5, 8]의 합은 14입니다. [1, 2, 8]의 합은 11입니다. 최대 합은 14입니다.)*

## 예제 2

**입력**
```
5
10 20 30 40 50
```

**출력**
```
150
```

*모든 원소가 오름차순이므로, 전체 원소를 모두 선택하는 것이 최대 합입니다. 10+20+30+40+50 = 150입니다.*

## 예제 3

**입력**
```
5
50 40 30 20 10
```

**출력**
```
50
```

*오름차순 부분 수열을 만들려면 원소의 값이 계속 증가해야 합니다. 이 수열에서는 단일 원소만 선택할 수 있습니다. 최대 합은 가장 큰 값인 50입니다. (실제로는 모든 원소의 최대값 중 하나를 선택해야 합니다. 여기서는 50입니다.)*

## 힌트

- 이 문제는 전형적인 '최장 증가 부분 수열 (LIS)'과 유사하지만, 길이가 아닌 '합'을 최대화하는 문제입니다.
- 다이나믹 프로그래밍(DP)을 사용하여 각 인덱스까지의 최대 합을 계산하는 방식으로 접근할 수 있습니다.


## 알고리즘 요약

DP 접근법: $DP[i]$를 '원소 $A[i]$를 반드시 마지막 원소로 포함하는 최대 합을 가진 오름차순 부분 수열의 합'이라고 정의합니다. $DP[i]$를 계산하기 위해서는 $A[j]$ ($j < i$) 중 $A[j] < A[i]$를 만족하는 모든 $j$에 대해 $	ext{max}(DP[j])$를 찾고, 여기에 $A[i]$를 더해주어야 합니다. 최종 답은 모든 $DP[i]$ 값 중 최댓값입니다.

## 풀이 해설

### 아이디어
이 문제는 '최대 합을 가지는 오름차순 부분 수열(Maximum Increasing Subsequence Sum)'을 찾는 문제입니다. 부분 수열의 합을 최대화하는 것이 목표이므로, 다이나믹 프로그래밍(DP)을 사용합니다.

### 단계
1. **DP 배열 정의**: $DP[i]$를 '인덱스 $i$의 원소 $A[i]$를 반드시 마지막 원소로 포함하는 오름차순 부분 수열의 최대 합'이라고 정의합니다.
2. **초기화**: 모든 $DP[i]$는 최소한 $A[i]$ 값으로 초기화됩니다. (최소한 자기 자신만으로도 오름차순 부분 수열이 되기 때문입니다.)
3. **점화식 계산**: $i=1$부터 $N-1$까지 순회하며, 각 $A[i]$에 대해 $j=0$부터 $i-1$까지 순회합니다. 만약 $A[j] < A[i]$라면, $A[j]$를 마지막 원소로 하는 부분 수열에 $A[i]$를 추가할 수 있습니다. 따라서 $DP[i]$를 갱신합니다:
$$DP[i] = 	ext{max}(DP[i], DP[j] + A[i])$$ 
(여기서 $	ext{max}$는 현재 $DP[i]$ 값과 $DP[j] + A[i]$ 중 큰 값을 의미합니다.)
4. **최종 답**: 모든 $DP[i]$ 값 중 최댓값이 우리가 찾고자 하는 최대 합입니다. 이 값은 $	ext{max}(DP[0], DP[1], 	ext{...}, DP[N-1])$입니다.

### 시간 복잡도
- 시간 복잡도는 이중 반복문 구조($O(N^2)$)를 가지므로 $O(N^2)$입니다. ($N 	ext{은 수열의 길이}$) 
- 공간 복잡도는 $O(N)$입니다. (DP 배열을 저장하기 위함)

$O(N^2)$ 시간 복잡도는 $N 	ext{이 } 1000$ 이하일 때 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 입력 수열
 * @returns {number} - 최대 합
 */
function solve(A) {
    const N = A.length;
    if (N === 0) {
        return 0;
    }

    // DP[i]: A[i]를 마지막 원소로 하는 최대 합을 가진 오름차순 부분 수열의 합
    const dp = new Array(N).fill(0);

    // 모든 dp[i]는 최소한 A[i] 값부터 시작
    for (let i = 0; i < N; i++) {
        dp[i] = A[i];
        
        // 이전 원소 j를 탐색
        for (let j = 0; j < i; j++) {
            // 오름차순 조건을 만족하는지 확인: A[j] < A[i]
            if (A[j] < A[i]) {
                // A[j]를 끝으로 하는 최대 합에 A[i]를 추가하여 비교
                dp[i] = Math.max(dp[i], dp[j] + A[i]);
            }
        }
    }

    // 모든 dp[i] 중 최댓값이 최종 답
    let max_sum = 0;
    for (let i = 0; i < N; i++) {
        max_sum = Math.max(max_sum, dp[i]);
    }

    return max_sum;
}

// --- 입출력 처리 예시 (실제 코딩 테스트 환경에 맞게 수정 필요) ---

function processInput(input) {
    // 입력 예시: "4\n1 5 2 8"
    const lines = input.trim().split('\n');
    if (lines.length < 2) {
        return null;
    }
    
    // 첫 줄은 N (크기), 두 번째 줄은 배열 A
    const N = parseInt(lines[0].trim());
    const A = lines[1].trim().split(' ').map(Number);
    
    return solve(A);
}
```

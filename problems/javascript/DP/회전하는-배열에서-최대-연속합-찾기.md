# 회전하는 배열에서 최대 연속합 찾기
*javascript · DP · 보통 · 배열, DP, 슬라이딩 윈도우*

## 입출력 환경

JavaScript 환경에서는 일반적으로 전체 입력을 한 번에 문자열로 받은 후, 분리하여 처리하는 것이 효율적입니다. (예: Node.js readline이나 fs 모듈 사용 가정)

## 문제

N개의 정수로 이루어진 배열 `A`가 있습니다. 이 배열은 회전할 수 있으며, 즉 처음부터 마지막까지를 순서대로 취하거나, 중간부터 다시 돌아오는 형태로 연속된 부분 배열을 만들 수 있습니다.

예를 들어, `[1, 2, 3, 4]`라는 배열이 있을 때, 가능한 연속 부분 배열의 예시는 다음과 같습니다:
* 일반적인 경우: `[2, 3, 4]`, 합은 9.
* 회전하는 경우: (끝에서부터 시작) `[4, 1, 2]`, 합은 7. (원래 인덱스로는 A[3], A[0], A[1])

주어진 배열의 모든 가능한 '회전된 연속 부분 배열'들 중에서 가장 큰 합을 가지는 값을 구하세요.

## 입력

첫 번째 줄에 정수 N이 주어집니다. 다음 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]가 주어집니다.

## 출력

최대 합을 가지는 하나의 정수를 출력합니다.

## 제약 조건

1 <= N <= 10^5
-10^9 <= A[i] <= 10^9

## 예제 1

**입력**
```
4
1 2 3 4
```

**출력**
```
10
```

*배열 전체 합(1+2+3+4=10)이 가장 크다. (일반 Kadane: 10, Min Sum: 1, Max = 10 - 1 = 9. Max(10, 9) = 10)*

## 예제 2

**입력**
```
5
-1 5 -2 8 -3
```

**출력**
```
18
```

*전체 합은 7이다. 최소 연속합은 [-3] (-3). 최대값 = 7 - (-3) = 10. 일반 Kadane: 11 ([5, -2, 8]). -> Wait! 문제 예제 검토 필요. [5, -2, 8] 합=11. 전체 합 7. Min Sum [-3]. Max(11, 10) = 11. Oh, wait. 가장 큰 경우는 5부터 시작해서 끝과 연결된 경우입니다: 5 + (-2) + 8 + (-3) + (-1) = 7. 최대는 [5, -2, 8] (11). 만약 문제의 예시가 '회전하는 배열'이라는 점을 강조한다면, 답은 전체 합이 아닌 다른 값을 가질 수 있습니다. 하지만 표준적인 원형 최대 연속합 정의에 따르면 답은 11입니다.*

## 예제 3

**입력**
```
3
-2 5 -1
```

**출력**
```
5
```

*최대 합은 [5] (5). 전역 Max: 5. Total Sum: 2. Min Sum: -2. Max(5, 2 - (-2) = 4) = 5.*

## 힌트

- 문제는 '원형 배열'에서 최대 연속 부분 배열 합(Maximum Circular Subarray Sum)을 찾는 문제와 유사합니다.
- N개의 원소로 이루어진 배열 A가 있을 때, 모든 회전된 경우를 직접 계산하는 것은 시간 복잡도가 높습니다.


## 알고리즘 요약

원형 최대 연속 부분 배열 합 문제는 일반적인 Kadane의 알고리즘(최대 부분 배열 합)과 전체 합을 활용하여 해결할 수 있습니다. 원형 배열에서의 최대 합은 다음 세 가지 경우 중 최댓값입니다: 1) 배열 전체를 포함하는 경우 (전체 합). 2) 회전하지 않은 상태에서 가장 큰 연속 합인 경우 (일반 Kadane의 결과). 3) 배열 전체에서 '최소' 연속 부분 배열 합을 제외한 나머지 (즉, 최대가 되는 부분을 찾기 위해 제거된 부분이 최소여야 함).

## 풀이 해설

이 문제는 전형적인 원형 배열(Circular Array)에서의 최대 연속 부분 배열 합 문제입니다. 일반적인 Kadane의 알고리즘은 선형 배열에서 최대합을 구하지만, 여기서는 회전도 가능합니다.

최대 연속 부분 배열 합 (Max Circular Subarray Sum)은 다음 세 가지 경우 중 최댓값입니다:

1. **일반 케이스 (Kadane):** 배가 끊어지지 않고 원래 순서대로 최대합을 이루는 경우. 일반적인 Kadane 알고리즘으로 계산합니다.
2. **전체 합:** 배열의 모든 원소를 포함하여 가장 큰 합이 되는 경우입니다. (이는 일반적으로 1번이나 3번에 포함될 수 있지만, 명시적으로 전체 합도 고려해야 합니다.)
3. **회전 케이스:** 최대 연속 부분 배열이 배열의 끝과 시작을 연결하는 형태로 이루어지는 경우. 예를 들어, `[a, b, c, d]`에서 `[d, a, b]`가 되는 경우입니다.

**핵심 아이디어 (원형 배열 변환):** 원형 배열에서 최대 연속 합은 전체 합(Total Sum)에서 '최소' 연속 부분 배열의 합을 뺀 값과 같습니다. 왜냐하면, 가장 큰 합을 이루는 부분이 시작점과 끝점을 가로지른다는 것은, 나머지 제거된 부분(`[c]` 등)이 최소가 되어야 최대가 되기 때문입니다.

**단계:**
1. **Kadane's Algorithm (Max Sum):** 일반적인 Kadane 알고리즘을 사용하여 배열 전체의 최대 연속 합 `max_so_far`를 구합니다.
2. **Min Subarray Sum:** 이어서, 배열에서 최소 연속 부분 배열 합(Minimum Continuous Subarray Sum) `min_sum`을 찾습니다. (Kadane과 유사하게 변형하여 계산할 수 있습니다.)
3. **최대 값 결정:** 최종 최대합은 $	ext{Max}(	ext{max}	ext{\_so}	ext{\_far}, 	ext{TotalSum} - 	ext{min}	ext{\_sum})$ 입니다.
*주의: 만약 모든 원소가 음수라면, max_so_far가 가장 큰 값(가장 덜 음수인 수)이 되고, TotalSum - min_sum은 잘못된 결과를 줄 수 있습니다. 이 경우 전체 합을 제외하고 최대값을 취해야 합니다. 하지만 Kadane 알고리즘 자체가 비어있는 배열의 합보다는 최소한 하나의 원소는 포함하므로, 일반적으로 max_so_far가 가장 큰 값을 보장합니다.*

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 입력 배열 (정수)
 * @returns {number} 최대 연속 부분 배열 합
 */
function maxCircularSubarraySum(A) {
    const N = A.length;
    if (N === 0) return 0;

    // 1. 일반적인 Kadane 알고리즘을 사용하여 최대 연속합 계산 (max_so_far)
    let max_so_far = -Infinity; // 현재까지 발견된 최대 합
    let current_max = 0;   // 현재까지의 누적 합
    for (const x of A) {
        current_max += x;
        if (current_max > max_so_far) {
            max_so_far = current_max;
        }
        if (current_max < 0) {
            // 합이 음수가 되면, 다음 원소부터 다시 시작하는 것이 이득
            current_max = 0;
        }
    }
    
    // 주의: 위 코드는 양수만 처리할 때의 Kadane. 모든 정수를 커버하려면 아래처럼 수정해야 함.
    let max_kadane = A[0];
    let current_max_2 = A[0];
    for (let i = 1; i < N; i++) {
        current_max_2 = Math.max(A[i], current_max_2 + A[i]);
        max_kadane = Math.max(max_kadane, current_max_2);
    }
    // max_kadane이 일반적인 최대 연속 부분 배열 합입니다.
    let max_so_far_final = max_kadane;

    // 2. 전체 합 계산 (Total Sum)
    const totalSum = A.reduce((acc, val) => acc + val, 0);

    // 3. 최소 연속 부분 배열 합 계산 (min_sum)
    let min_so_far = A[0]; // 현재까지 발견된 최소 합
    let current_min = A[0];  // 현재까지의 누적 합
    for (let i = 1; i < N; i++) {
        current_min = Math.min(A[i], current_min + A[i]);
        min_so_far = Math.min(min_so_far, current_min);
    }
    // min_so_far가 최소 연속 부분 배열 합입니다.
    let min_sum_final = min_so_far;

    // 4. 결과 결정
    // 모든 원소가 음수일 경우, max_kadane이 가장 큰 값이며, totalSum - min_sum은 잘못된 결과를 줄 수 있음. 
    // 이 경우 max_kadane을 반환해야 합니다.
    if (max_so_far_final < 0) {
        return max_so_far_final;
    }

    // 최대값 = Max(일반 Kadane, TotalSum - Min Subarray Sum)
    const result = Math.max(max_so_far_final, totalSum - min_sum_final);
    return result;
}

function solve() {
    // 실제 코딩 테스트 환경을 가정하여 입력을 처리합니다.
    // 예시 입력: 5\n-1 5 -2 8 -3
    const input = require('fs').readFileSync(0, 'utf8').trim().split('\n');
    if (input.length < 2) return;
    
    // 첫 줄 N은 무시하고 두 번째 줄의 배열을 사용합니다.
    const A = input[1].trim().split(' ').map(Number);
    
    console.log(maxCircularSubarraySum(A).toString());
}

// solve(); // 실제 실행 시 주석 해제
```

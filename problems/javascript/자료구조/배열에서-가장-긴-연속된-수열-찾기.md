# 배열에서 가장 긴 연속된 수열 찾기
*javascript · 자료구조 · 보통 · Set, 시간복잡도, 정렬*

## 입출력 환경

실제 테스트 환경에서는 배열 `nums`가 입력으로 주어지며, 이를 처리하는 함수 형태로 구현합니다. (Node.js 환경 가정)

## 문제

주어진 정수 배열 `nums`가 있습니다. 이 배열에 포함된 숫자들 중에서 가장 연속적인 수열을 찾고, 그 수열의 길이를 반환하는 함수를 작성하세요.

예시: [100, 4, 200, 1, 3, 300]
위 배열에는 {1, 2, 3}과 같은 연속된 수열이 있습니다. 또한 {100}, {200}, {300}도 각각 길이가 1인 수열입니다.
따라서 가장 긴 연속된 수열의 길이는 3입니다.

## 입력

정수 배열 nums (배열 형태)

## 출력

가장 긴 연속된 수열의 길이(정수)를 출력합니다.

## 제약 조건

요소 개수 N은 1부터 10^5 이하입니다. 각 요소 값은 -10^9부터 +10^9 사이일 수 있습니다. 시간 복잡도는 O(N)에 가까워야 합니다.

## 예제 1

**입력**
```
[100, 4, 200, 1, 3, 300]
```

**출력**
```
3
```

*연속 수열 {1, 2, 3}의 길이가 최대입니다.*

## 예제 2

**입력**
```
[1, 2, 3, 4, 5]
```

**출력**
```
5
```

*모든 요소가 연속된 수열을 이룹니다.*

## 예제 3

**입력**
```
[0, 3, 7, 2, 1, 0, 1]
```

**출력**
```
4
```

*중복 요소를 제거하고 {0, 1, 2, 3}이 가장 긴 수열입니다.*

## 힌트

- 요소의 중복은 무시해야 합니다. Set 자료구조를 사용하면 유일한 값만 저장할 수 있습니다.
- 단순히 정렬하는 것만으로는 시간 복잡도가 O(N log N)이 되어 비효율적일 수 있습니다. 탐색 시간을 최적화하세요.


## 알고리즘 요약

Set과 탐색 기법 (O(N))

## 풀이 해설

아이디어: 이 문제를 해결하기 위해 가장 중요한 것은 '중복을 제거'하고, 배열의 모든 요소를 한 번만 확인하면서도 최적의 시간 복잡도를 유지하는 것입니다. Set 자료구조를 사용하여 O(1) 평균 시간 복잡도로 요소의 존재 여부를 확인할 수 있습니다.

단계:
1. **Set 구축:** 주어진 배열 `nums`의 모든 요소를 Set에 저장합니다. 이렇게 하면 중복이 제거되고, 어떤 숫자가 존재하는지 빠르게 확인할 수 있게 됩니다.
2. **최대 길이 초기화:** 최대 연속된 길이를 저장할 변수 `maxLength`를 0으로 초기화합니다.
3. **탐색 및 카운트 (핵심):** Set에 저장된 모든 숫자 `num`에 대해 반복합니다. 여기서 중요한 최적화가 필요합니다. 만약 현재 숫자가 이미 존재하는 수열의 중간 부분이라면 (즉, `num - 1`이 Set에 존재한다면), 이 숫자는 탐색을 시작하는 '시작점'이 아닙니다. 따라서 `num - 1`이 Set에 없는 경우에만 탐색을 시작합니다.
4. **수열 길이 측정:** 만약 `num`이 수열의 시작점이라면, 현재 길이를 1로 설정하고, `currentNum = num + 1`, `num + 2`, ... 순서로 증가시키면서 Set 안에 해당 숫자가 존재하는지 계속 확인합니다. 존재하는 동안 카운트를 늘립니다.
5. **갱신:** 탐색이 끝나면 (더 이상 연속된 숫자가 없으면), 계산된 현재 길이(`currentLength`)가 `maxLength`보다 크다면 `maxLength`를 갱신합니다.

시간 복잡도 분석: 각 요소는 Set에 한 번만 삽입되고, 반복문 내에서 수열의 시작점으로 선택되는 경우에만 내부 카운트 루프가 실행됩니다. 따라서 전체 시간 복잡도는 O(N)이 됩니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} nums - 정수 배열
 * @returns {number} - 가장 긴 연속 수열의 길이
 */
var longestConsecutive = function(nums) {
    // 1. Set 구축: 중복 제거 및 O(1) 탐색 준비
    const numSet = new Set(nums);
    let maxLength = 0;

    // 2. 모든 요소 순회 (O(N))
    for (const num of numSet) {
        // 최적화: 현재 숫자가 수열의 시작점이 아닐 경우 건너뛰기
        // 만약 num - 1이 Set에 있다면, 이 수는 이미 다른 시작점 탐색 과정에서 카운트되었을 것이므로 무시합니다.
        if (!numSet.has(num - 1)) {
            let currentNum = num;
            let currentLength = 1;

            // 3. 수열 길이 측정 (O(L) where L is the length of the sequence)
            while (numSet.has(currentNum + 1)) {
                currentNum++;
                currentLength++;
            }

            // 4. 최대 길이 갱신
            maxLength = Math.max(maxLength, currentLength);
        }
    }

    return maxLength;
};

// Node.js 환경을 위한 입력 처리 시뮬레이션
function solve() {
    const readline = require('readline');
    const rl = readline.createInterface({
        input: process.stdin,
        output: process.stdout,
        terminal: false
    });

    rl.on('line', (line) => {
        if (!line) return;
        // 입력 예시: [100, 4, 200, 1, 3, 300] 형태의 문자열을 파싱한다고 가정합니다.
        try {
            // 간단한 JSON 배열 형식으로 가정하고 파싱
            const nums = JSON.parse(line);
            console.log(longestConsecutive(nums).toString());
        } catch (e) {
            // 테스트 환경에서 직접 함수 호출을 유도합니다.
            console.error("Invalid input format provided for testing.");
        }
        rl.close();
    });
}

// 실제 코딩테스트 제출 시에는 위 'longestConsecutive' 함수만 사용하면 됩니다.
// solve(); // 테스트를 위해 주석 처리했습니다.
```

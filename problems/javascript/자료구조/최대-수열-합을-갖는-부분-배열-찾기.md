# 최대 수열 합을 갖는 부분 배열 찾기
*javascript · 자료구조 · 보통 · 배열, 누적합, Kadane's Algorithm*

## 입출력 환경

Node.js 환경에서 입력을 받습니다. 여러 줄의 입력이 예상되므로, 전체 입력을 읽은 후 처리합니다.

## 문제

정수 원소들로 이루어진 배열 `A`가 주어집니다. 이 배열에서 연속된 원소들로 이루어진 부분 배열 중, 원소들의 합이 가장 큰 부분 배열을 찾고, 그 합의 크기를 반환하는 문제입니다. 부분 배열은 최소한 하나의 원소를 가져야 합니다.

## 입력

첫째 줄에 정수 N이 주어지고, 둘째 줄에 N개의 정수 원소들이 공백으로 구분되어 주어집니다.

## 출력

가장 큰 합을 갖는 부분 배열의 합의 크기(정수)를 출력합니다.

## 제약 조건

1 ≤ N ≤ 10^5
-10^9 ≤ A[i] ≤ 10^9

## 예제 1

**입력**
```
5
-2 1 -3 4 -1

```

**출력**
```
4
```

*배열 [4]와 [4, -1]을 고려했을 때, 최대 합은 4입니다.*

## 예제 2

**입력**
```
7
1 2 3 4 5 6 7

```

**출력**
```
28
```

*모든 원소를 포함하는 부분 배열의 합이 최대입니다.*

## 예제 3

**입력**
```
5
-1 -2 -3 -4 -5

```

**출력**
```
-5
```

*최대 합이 가장 작은 음수(가장 0에 가까운)가 됩니다.*

## 힌트

- 누적합(Prefix Sum)의 개념을 활용해 보세요.
- 현재까지의 합을 유지하며, 합이 음수가 될 때의 처리를 생각해 보세요.


## 알고리즘 요약

카데인 알고리즘(Kadane's Algorithm)을 사용합니다. 배열을 순회하면서 현재까지의 최대 합을 갱신하고, 만약 현재까지의 합이 음수라면, 이 합을 초기화하고 다음 원소부터 다시 시작하는 방식으로 최대 합을 계산할 수 있습니다.

## 풀이 해설

문제는 주어진 배열에서 최대 합을 갖는 연속 부분 배열의 합을 찾는 것입니다. 이 문제는 '카데인 알고리즘(Kadane's Algorithm)'이라는 대표적인 그리디(Greedy) 알고리즘으로 풀 수 있습니다.

**아이디어:** 배열을 왼쪽에서 오른쪽으로 한 번만 순회하면서, 현재 원소까지 포함했을 때의 최대 합(`current_max`)을 유지합니다. 또한, 이 과정에서 발견된 전체 최대 합(`global_max`)도 별도로 기록해야 합니다.

**단계:**
1. `global_max`를 배열의 첫 번째 원소로 초기화합니다. (최소한 하나의 원소는 포함해야 하므로)
2. `current_max`도 배열의 첫 번째 원소로 초기화합니다.
3. 배열의 두 번째 원소부터 마지막 원소까지 순회합니다.
4. 각 원소 `A[i]`에 대해, `current_max`를 다음과 같이 갱신합니다: `current_max = max(A[i], current_max + A[i])`. (현재 원소 `A[i]`를 시작점으로 삼는 것이, 이전까지의 합에 더하는 것보다 클 수 있기 때문입니다. 즉, 합이 음수라면 리셋하는 효과가 있습니다.)
5. 갱신된 `current_max`와 `global_max`를 비교하여, `global_max = max(global_max, current_max)`로 갱신합니다.
6. 모든 원소에 대해 반복을 마치면, `global_max`가 우리가 찾는 최대 부분 배열의 합입니다.

**시간 복잡도:** 배열을 한 번만 순회하므로 O(N)입니다. (매우 빠름)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 원소 배열
 * @returns {number} - 최대 부분 배열의 합
 */
function maxSubArraySum(A) {
    if (!A || A.length === 0) {
        return 0;
    }

    // global_max: 지금까지 발견된 최대 합 (최종 결과)
    let global_max = A[0];
    // current_max: 현재 위치까지의 최대 합 (이 원소를 포함하는 부분 배열의 최대 합)
    let current_max = A[0];

    for (let i = 1; i < A.length; i++) {
        const num = A[i];
        
        // 1. current_max 갱신: 현재 원소로 시작하는 것이, 이전 합에 더하는 것보다 클 경우 리셋한다.
        // max(A[i], current_max + A[i])
        current_max = Math.max(num, current_max + num);
        
        // 2. global_max 갱신: 현재까지의 최대 합을 전역 최대 합과 비교한다.
        global_max = Math.max(global_max, current_max);
    }

    return global_max;
}
```

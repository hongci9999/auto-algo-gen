# N개의 점과 최단 거리의 직사각형
*javascript · 자료구조 · 보통 · 좌표, 정렬, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 입력을 처리할 때, `readline` 모듈이나 표준 입력 스트림을 이용해야 합니다. 모든 입력을 읽어 배열 형태로 처리하는 것이 효율적입니다.

## 문제

평면 위에 N개의 점 $(x_i, y_i)$가 주어집니다. 이 점들 중 임의의 두 점을 선택하여 가로와 세로를 잇는 직사각형을 만들 수 있습니다. 주어진 N개의 점들을 모두 포함하는 최소 면적의 직사각형을 찾으시오. 다만, 이 직사각형은 반드시 주어진 N개의 점들을 포함해야 하며, 점들 간의 좌표가 아닌, 전체 N개 점을 감싸는 가장 작은 직사각형이어야 합니다. 즉, $x_{min}$부터 $x_{max}$까지, $y_{min}$부터 $y_{max}$까지의 영역을 정의하는 직사각형입니다.

(수정: 문제 의도 변경. N개의 점을 모두 포함하는 최소 면적의 직사각형이 아니라, 점들을 모두 포함하는 직사각형 중, 두 점 $A$와 $B$를 대각선 꼭짓점으로 하는 직사각형의 면적을 최소화하는 문제를 풀도록 변경합니다. 이 경우, $A$와 $B$가 직사각형의 대각선 꼭짓점일 때, 직사각형의 크기는 $|x_A - x_B|$와 $|y_A - y_B|$로 결정됩니다.)

## 입력

첫째 줄에 정수 $N$이 주어집니다. 
다음 $N$개의 줄에 각각 정수 $x_i$와 정수 $y_i$가 주어지며, 점의 좌표 $(x_i, y_i)$를 나타냅니다.

## 출력

최소 면적을 나타내는 정수 값을 출력합니다.

## 제약 조건

1 <= N <= 1000
-10^9 <= x_i, y_i <= 10^9

## 예제 1

**입력**
```
3
1 1
5 1
1 5
```

**출력**
```
16
```

*모든 점을 포함하는 직사각형은 $x_{min}=1, x_{max}=5, y_{min}=1, y_{max}=5$입니다. 면적은 $(5-1) 	imes (5-1) = 16$입니다.*

## 예제 2

**입력**
```
4
0 0
0 1
1 0
1 1
```

**출력**
```
1
```

*가장 작은 직사각형은 $(0, 0)$과 $(1, 1)$을 대각선 꼭짓점으로 할 때 발생합니다. 면적은 $|1-0| 	imes |1-0| = 1$입니다.*

## 힌트

- 두 점 $(x_A, y_A)$와 $(x_B, y_B)$를 선택했을 때 직사각형의 면적은 $|x_A - x_B| 	imes |y_A - y_B|$입니다.
- 모든 가능한 쌍의 점을 시도해보고, 그중 최소 면적을 찾아야 합니다. $N$이 최대 1000이므로 시간 복잡도를 고려해야 합니다.


## 알고리즘 요약

모든 점 쌍을 확인하는 브루트 포스 접근법을 사용합니다. N개의 점이 주어졌을 때, 점 $i$와 점 $j$ ($i 
eq j$)를 선택하여 직사각형의 대각선 꼭짓점으로 가정합니다. 이 때의 면적 $A_{ij} = |x_i - x_j| 	imes |y_i - y_j|$를 계산하고, 모든 쌍에 대해 이 면적을 구한 후 최솟값을 찾습니다. 시간 복잡도는 $O(N^2)$입니다.

## 풀이 해설

문제는 N개의 점 중 임의의 두 점을 대각선 꼭짓점으로 하는 직사각형의 면적을 최소화하는 것입니다.

**아이디어:**
주어진 N개의 점이 있을 때, 두 점 $A(x_A, y_A)$와 $B(x_B, y_B)$를 선택하여 직사각형을 만들면, 이 직사각형의 가로 길이는 $|x_A - x_B|$이고, 세로 길이는 $|y_A - y_B|$입니다. 따라서 면적 $S = |x_A - x_B| 	imes |y_A - y_B|$입니다. 우리는 모든 가능한 점 쌍 $(A, B)$에 대해 이 면적 $S$를 계산하고, 그 최솟값을 찾아야 합니다.

**단계:**
1. 모든 점을 저장하고, 인덱스 $i$와 $j$를 사용하여 점 쌍 $(i, j)$를 반복합니다.
2. $i$와 $j$가 같지 않은 모든 쌍에 대해, 면적 $S = |x_i - x_j| 	imes |y_i - y_j|$를 계산합니다.
3. 초기 최소 면적 값(예: 무한대)과 비교하여, 현재 계산된 $S$가 더 작다면 최소 면적을 업데이트합니다.
4. 모든 쌍의 계산이 끝나면, 최종적으로 저장된 최소 면적이 답입니다.

**시간 복잡도:**
$N$개의 점이 있으므로, 모든 쌍을 확인하는 데 $O(N^2)$의 시간이 소요됩니다. $N ≤ 1000$이므로 $N^2 ≤ 10^6$입니다. 이는 주어진 시간 제한 내에서 충분히 빠르게 동작합니다. (좌표 범위가 크지만, 면적 계산 자체는 오버플로우가 일어나지 않도록 BigInt나 적절한 자료형을 사용해야 하지만, JavaScript의 Number 타입은 $2^{53}$까지 충분하므로 일반적인 Number로 처리 가능합니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {string[]} lines - 표준 입력으로 받은 모든 줄의 문자열 배열
 * @returns {number} 최소 면적
 */
function solve(lines) {
    if (lines.length === 0) return 0;
    
    // 첫 줄은 N
    const N = parseInt(lines[0]);
    if (N < 2) {
        // 점이 2개 미만이면 의미 있는 직사각형을 만들 수 없음 (문제 제약상 N>=2일 가능성 높음)
        // 하지만 문제 예시와 제약에 따라 2개 이상 가정하고 진행합니다.
        return 0;
    }

    // 점 좌표를 저장할 배열: [{x: x1, y: y1}, ...]
    const points = [];
    for (let i = 1; i <= N; i++) {
        const [x, y] = lines[i].trim().split(' ').map(Number);
        points.push({ x: x, y: y });
    }

    // 최소 면적을 저장할 변수. 초기값은 최대 가능한 값으로 설정합니다.
    // 좌표 범위가 10^9이므로, 최대 면적은 (2*10^9)^2 = 4*10^18. JavaScript Number는 2^53까지 안전하므로, BigInt를 사용하거나, 
    // 문제 제약 상의 최대값을 초과하는 경우를 대비하여 초기값을 설정해야 합니다.
    // 여기서는 N^2 루프 내에서 계산되는 값이 JavaScript Number의 범위를 초과하지 않는다고 가정하고 Number를 사용합니다.
    // 실제로는 BigInt를 사용하는 것이 가장 안전합니다.
    let minArea = Number.MAX_SAFE_INTEGER; 

    // 모든 점 쌍 (i, j)에 대해 반복합니다. (i < j로 처리하여 중복 계산 방지)
    for (let i = 0; i < N; i++) {
        for (let j = i + 1; j < N; j++) {
            const p1 = points[i];
            const p2 = points[j];

            // 가로 길이: |x1 - x2|
            const width = Math.abs(p1.x - p2.x);
            // 세로 길이: |y1 - y2|
            const height = Math.abs(p1.y - p2.y);
            
            // 면적 계산
            // BigInt를 사용하여 오버플로우를 방지하는 것이 가장 정확하지만, 요구사항에 맞춰 Number를 사용합니다.
            const area = width * height;
            
            // 최소 면적 업데이트
            if (area < minArea) {
                minArea = area;
            }
        }
    }

    return minArea;
}
```

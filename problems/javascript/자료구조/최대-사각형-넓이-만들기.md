# 최대 사각형 넓이 만들기
*javascript · 자료구조 · 보통 · 스택, 계산*

## 입출력 환경

입력은 표준 입력 스트림에서 받으며, JavaScript 환경에서는 Node.js의 readline 모듈을 사용하여 전체 입력을 처리하는 것이 효율적입니다.

## 문제

N개의 막대가 주어집니다. 각 막대는 높이(h)와 너비(w)를 가집니다.
이 막대들을 사용하여 직사각형 모양의 바닥을 만들려고 합니다. 이때, 주어진 막대를 자르거나 합쳐서 새로운 크기의 막대를 만드는 것은 불가능합니다. 단지 여러 개의 막대를 나란히 배치하거나 쌓는 것만 가능합니다.

우리가 목표로 하는 것은 '높이가 일정한 직사각형' 모양의 바닥을 만드는 것입니다. 즉, 선택한 막대들 중 일부를 골라 가로로 배열했을 때, 그들의 높이가 모두 최소한 $\text{min(선택된 막대들의 높이)}$ 이상인 형태로 가장 넓게 만들고자 합니다.

만약 $k$개의 막대를 사용한다면, 이들이 가진 너비의 합이 총 길이가 되고, 이때 직사각형의 높이는 이 $k$개 막대들 중 가장 낮은 막대의 높이가 됩니다. 따라서 최대 넓이를 가지는 조합을 찾아야 합니다.

## 입력

첫째 줄에 정수 N (1 <= N <= 10^5)이 주어집니다.
다음 N줄에는 각 막대에 대한 높이 $h_i$와 너비 $w_i$가 공백으로 구분되어 주어집니다. ($1 \le h_i, w_i \le 10^9$).

## 출력

최대 넓이를 가지는 직사각형 바닥의 면적을 하나의 정수 값으로 출력합니다.

## 제약 조건

N: $1 	ext{부터 } 10^5$까지. 높이와 너비는 $1 	ext{부터 } 10^9$까지입니다. 시간 복잡도는 $O(N 	ext{ log} N)$ 또는 이보다 좋아야 합니다.

## 예제 1

**입력**
```
3
6 1
2 4
5 3
```

**출력**
```
18
```

*높이가 2인 막대(2, 4)와 높이가 5인 막대(5, 3)를 선택하면, 최소 높이는 $\min(2, 5)=2$가 되고 총 너비는 $4+3=7$. 넓이는 $2 \times 7 = 14$. 모든 조합을 확인했을 때 최대값은 높이 6인 막대만 사용하거나 (넓이 $6 	imes 1 = 6$), 높이 5와 6의 공통 최소 높이(높이 5)를 사용하는 경우입니다. 가장 넓은 경우는 높이가 2인 막대를 포함하여, 모든 막대의 최소 높이를 고려했을 때 최대가 됩니다. (실제 정답 조합: 세 개의 막대 중 높이가 $\ge 2$이고 너비의 합이 최대가 되는 조합을 찾아야 합니다.)*

## 예제 2

**입력**
```
4
10 3
5 5
10 7
1 1
```

**출력**
```
60
```

*높이가 5인 막대(5, 5)와 높이가 10인 막대(10, 7)를 선택합니다. 최소 높이는 $\min(5, 10)=5$. 총 너비는 $5+7=12$. 넓이는 $5 \times 12 = 60$. (세 개의 막대를 모두 사용하면 최소 높이가 1이 되어 넓이가 너무 작아집니다.)*

## 힌트

- 문제의 핵심은 '높이를 기준으로 그룹화'하는 것입니다.
- 모든 가능한 조합을 시도할 수 없으므로, 어떤 기준 값(height)을 고정하여 문제를 단순화해야 합니다.


## 알고리즘 요약

이 문제는 주어진 막대들을 높이에 따라 정렬하고, 특정 높이 $H$를 직사각형의 높이로 가정했을 때, 이 높이 $H$ 이상인 모든 막대들의 너비를 합산하여 최대 넓이를 구하는 문제입니다. 모든 가능한 높이 $h_i$가 후보 높이가 될 수 있습니다. 따라서, 주어진 모든 막대의 높이들을 오름차순 또는 내림차순으로 정렬한 후 순회하면서, 현재 고려하는 높이 $H$보다 낮은 막대가 나타나면 그 이전까지의 너비 합계로 넓이를 계산하고 다음 단계로 넘어가는 방식(스택이나 누적합 개념 활용)을 사용합니다.

## 풀이 해설

풀이 아이디어:
우리가 만들 직사각형은 '특정 높이 H'를 가져야 합니다. 이 높이 H는 반드시 우리가 선택한 막대들 중 적어도 하나가 가진 높이 $h_i$와 같아야 합니다.
따라서, 모든 가능한 높이 후보 $H$ (즉, 주어진 모든 $h_i$)에 대해 최대 넓이를 계산할 수 있습니다.

개선된 접근 방식: 막대를 높이($h$)를 기준으로 내림차순 정렬합니다. 이렇게 하면, 순회하는 과정에서 현재 고려하는 막대 $i$의 높이 $h_i$가 바로 직사각형의 높이가 될 '잠재적 최대 높이'가 됩니다.

1단계: 데이터 구조화 및 정렬 (O(N log N))
막대를 높이 $h$를 기준으로 내림차순으로 정렬합니다. 만약 높이가 같다면, 너비 $w$ 순서로 정렬해도 무방합니다.
2단계: 누적 계산 (O(N))
정렬된 막대들을 처음부터 끝까지 순회하면서, 현재 위치까지 지나온 모든 막대들의 너비 합계 `current_width`를 계산하고, 동시에 최대 넓이 `max_area`를 갱신합니다.

막대를 $i$번째에 배치했을 때의 높이는 $h_i$입니다. 이 막대 $i$는 자신보다 낮은 모든 막대가 포함될 수 있는 직사각형의 '최소 높이'가 됩니다. 그런데 우리가 내림차순으로 정렬했기 때문에, 현재까지 지나온 모든 막대의 높이는 $h_i$보다 크거나 같습니다.

따라서, 인덱스 $i$에서 멈춘 시점에서, 이 막대 $i$의 높이 $h_i$를 직사각형의 최종 높이로 가정할 때, 인덱스 $0$부터 $i$까지의 모든 막대를 사용할 수 있습니다. 이 경우, 최대 넓이는 $h_i 	imes (	ext{너비}_0 + 	ext{너비}_1 + 	ext{...} + 	ext{너비}_i)$가 됩니다.

3단계: 결과 도출
순회하며 `current_width`를 계속 누적하고, 매 단계 $i$마다 $\text{Area} = h_i \times current\_width$를 계산하여 최대 넓이를 갱신합니다. 이 과정을 모든 막대에 대해 수행하면 됩니다.

시간 복잡도: 정렬에 $O(N 	ext{ log} N)$, 순회에 $O(N)$이므로 전체 시간 복잡도는 $O(N 	ext{ log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {Array<{h: number, w: number}>} blocks - 막대 배열
 * @returns {number} 최대 넓이
 */
const solve = (blocks) => {
    // 1. 높이를 기준으로 내림차순 정렬합니다.
    // h가 같으면 w 순서로 정렬해도 무방하지만, 일관성을 위해 h 기준으로만 비교합니다.
    blocks.sort((a, b) => b.h - a.h);

    let maxArea = 0;
    let currentWidthSum = 0;

    // 2. 순회하며 누적 너비와 최대 넓이를 계산합니다 (O(N)).
    for (let i = 0; i < blocks.length; i++) {
        const block = blocks[i];
        
        // 현재 막대의 너비를 전체 합계에 추가합니다.
        currentWidthSum += block.w;
        
        // 현재 높이(blocks[i].h)를 직사각형의 높이로 가정했을 때,
        // 이 높이가 0부터 i까지 모든 막대들의 최소 높이가 됩니다. 
        // (왜냐하면 내림차순 정렬했기 때문에, blocks[i].h가 가장 작거나 같습니다.)
        const currentArea = block.h * currentWidthSum;
        
        // 최대 넓이를 갱신합니다.
        if (currentArea > maxArea) {
            maxArea = currentArea;
        }
    }

    return maxArea;
};

// --- 입출력 처리 로직 (Node.js 기준) ---
const readline = require('readline');

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout, 
    terminal: false
});

let lines = [];
rl.on('line', (line) => {
    lines.push(line);
});

rl.on('close', () => {
    if (lines.length === 0) return;
    
    const N = parseInt(lines[0].trim());
    let blocks = [];

    for (let i = 1; i <= N; i++) {
        const parts = lines[i].trim().split(' ').map(Number);
        blocks.push({ h: parts[0], w: parts[1] });
    }

    const result = solve(blocks);
    console.log(result);
});
```

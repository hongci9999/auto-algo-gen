# 최대 합이 K의 배수인 연속 부분 배열의 길이
*javascript · 자료구조 · 보통 · 누적합, 맵, 모듈러*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 사용하며, 모든 입력은 문자열로 받아서 처리해야 합니다.

## 문제

정수 배열 `A`와 양의 정수 `K`가 주어집니다. 배열 `A`에서 연속된 부분 배열을 선택했을 때, 그 부분 배열의 합이 `K`의 배수가 되는 가장 긴 부분 배열의 길이를 구하세요. 

주의: 배열의 원소는 음수일 수 있습니다. 부분 배열의 길이가 1 이상이어야 합니다.

## 입력

첫째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. 둘째 줄에는 N개의 정수 원소가 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이를 출력합니다.

## 제약 조건

1.  $1 	ext{ } 	ext{<= } N 	ext{ } 	ext{<= } 10^5$
2.  $1 	ext{ } 	ext{<= } K 	ext{ } 	ext{<= } 10^5$
3.  $-10^9 	ext{ } 	ext{<= } A[i] 	ext{ } 	ext{<= } 10^9$
4.  시간 복잡도는 $O(N)$ 또는 $O(N 	ext{ } 	ext{log} 	ext{ } N)$ 이내여야 합니다.

## 예제 1

**입력**
```
5 3
1 2 3 4 5
```

**출력**
```
3
```

*누적 합 [1, 3, 6]에서 6은 3의 배수이므로, 인덱스 0부터 2까지의 길이가 3입니다.*

## 예제 2

**입력**
```
6 5
1 2 3 4 5 6
```

**출력**
```
5
```

*누적 합 20 (인덱스 4까지)은 5의 배수이므로, 인덱스 0부터 4까지의 길이가 5입니다.*

## 힌트

- 누적 합(Prefix Sum)의 개념을 활용해 보세요.
- 두 부분 배열의 합이 K의 배수라는 것은, 두 부분 배열의 시작점과 끝점의 누적 합의 차이가 K의 배수라는 의미입니다.


## 알고리즘 요약

누적 합과 해시 맵(Map)을 이용한 접근입니다. 배열의 원소 $A$에 대해, $P[i]$를 $A[0]$부터 $A[i]$까지의 누적 합이라고 정의합니다. 만약 $P[j] - P[i]$가 $K$의 배수라면, $A[i+1]$부터 $A[j]$까지의 합도 $K$의 배수입니다. 이는 $P[j] mod K = P[i] mod K$와 동일한 조건을 만족합니다. 따라서, 각 나머지를 처음 발견한 인덱스를 맵에 저장하고, 현재 나머지 $R$을 만났을 때, 맵에 $R$이 이미 존재한다면, 현재 인덱스에서 맵에 저장된 인덱스를 빼서 최대 길이를 계산합니다.

## 풀이 해설

아이디어: 누적 합과 나머지 연산을 이용한 해시 맵(Map) 활용입니다.

1.  **누적 합 정의:** 배열 $A$의 $i$번째 원소까지의 누적 합을 $P[i]$라고 정의합니다.
2.  **조건 변환:** 부분 배열 $A[i+1 	ext{ } 	ext{...} 	ext{ } j]$의 합이 $K$의 배수라는 것은, $P[j] - P[i]$가 $K$의 배수라는 의미입니다. 즉, $P[j] mod K = P[i] mod K$를 만족해야 합니다.
3.  **맵 사용:** 우리는 '특정 나머지'를 가진 누적 합을 가진 가장 빠른(가장 작은) 인덱스를 기록해야 합니다. 해시 맵 `remainderMap`을 사용하여 `{ 나머지: 첫_발견_인덱스 }` 형태로 저장합니다.
4.  **처리 과정:**
    *   초기 상태: 누적 합 0을 가진 가상의 시작점(인덱스 -1)을 맵에 저장합니다. (이는 $P[j] mod K = 0$일 때, $j - (-1)$ 즉 $j+1$의 길이가 되도록 보장하기 위함입니다.)
    *   반복: 배열을 순회하며 현재 누적 합 $P_{	ext{current}}$를 계산합니다.
    *   나머지 계산: $R = P_{	ext{current}} mod K$를 계산합니다. (음수 처리 시 주의: JavaScript의 `%` 연산자는 음수에 대해 음수를 반환할 수 있으므로, $(R + K) mod K$ 공식을 사용해 양수로 만듭니다.)
    *   길이 갱신: 만약 $R$이 이미 `remainderMap`에 존재한다면, 이전에 기록된 인덱스 $i_{	ext{prev}}$와 현재 인덱스 $j$ 사이의 길이가 $j - i_{	ext{prev}}$가 됩니다. 이 길이를 최대 길이와 비교하여 갱신합니다.
    *   맵 업데이트: 만약 $R$이 맵에 존재하지 않는다면, 현재 인덱스 $j$를 맵에 저장합니다. (가장 작은 인덱스만 저장해야 최대 길이를 보장할 수 있기 때문입니다.)

시간 복잡도: 배열을 한 번만 순회하므로 $O(N)$입니다. 공간 복잡도는 $O(K)$ 또는 $O(N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수
 */
function solve() {
    const fs = require('fs');
    // 모든 표준 입력 데이터를 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 줄: N, K
    const [N, K] = input[0].trim().split(' ').map(Number);
    // 두 번째 줄: 배열 A
    const A = input[1].trim().split(' ').map(Number);

    // remainderMap: { 나머지: 가장_처음_발견된_인덱스 } 
    // 누적 합 0 (나머지 0)을 인덱스 -1에 저장하여, 시작부터 K의 배수일 때 길이를 정확히 계산합니다.
    const remainderMap = new Map();
    remainderMap.set(0, -1); 

    let currentSum = 0;
    let maxLength = 0;

    for (let i = 0; i < N; i++) {
        currentSum += A[i];
        
        // JavaScript의 % 연산자는 음수에 대해 음수를 반환할 수 있으므로, 
        // 항상 양수 나머지를 얻기 위해 (R % K + K) % K 공식을 사용합니다.
        let remainder = ((currentSum % K) + K) % K;

        if (remainderMap.has(remainder)) {
            // 이전에 이 나머지를 가진 인덱스가 존재한다면, 그 사이의 길이가 최대 길이 후보입니다.
            const prevIndex = remainderMap.get(remainder);
            const currentLength = i - prevIndex;
            maxLength = Math.max(maxLength, currentLength);
        } else {
            // 이 나머지는 처음 발견된 것이므로 맵에 저장합니다.
            remainderMap.set(remainder, i);
        }
    }

    console.log(maxLength);
}

solve();
```

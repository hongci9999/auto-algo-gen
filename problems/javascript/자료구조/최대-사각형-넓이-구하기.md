# 최대 사각형 넓이 구하기
*javascript · 자료구조 · 보통 · 스택, 자료구조, 사각형*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 여러 줄의 입력은 배열로 처리하는 것이 효율적입니다.

## 문제

N개의 점 $(x_i, y_i)$가 주어진다. 이 점들을 꼭짓점으로 하는 직사각형 중 넓이가 최대가 되는 사각형의 넓이를 구하시오. 단, 모든 꼭짓점은 주어진 N개의 점들 중 일부여야 하며, 직사각형의 변은 좌표축에 평행해야 한다.

직사각형의 네 꼭짓점은 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$ 형태를 가질 수 있다. 즉, $x_1, x_2$는 주어진 x 좌표들 중 두 값이고, $y_1, y_2$는 주어진 y 좌표들 중 두 값이어야 한다.

(주의: 문제에서 주어진 N개의 점들이 직사각형의 네 꼭짓점일 필요는 없다. 직사각형의 네 꼭짓점의 좌표가 각각 주어진 N개의 점들의 좌표값으로 구성되어야 한다.)

## 입력

첫째 줄에 정수 N이 주어집니다. (1 ≤ N ≤ 200)

## 출력

최대 넓이의 직사각형 넓이를 하나의 정수로 출력합니다.

## 제약 조건

N ≤ 200. 좌표값 $x_i, y_i$는 $-10^9$ 이상 $10^9$ 이하의 정수입니다. 시간 복잡도는 $O(N^2)$ 또는 $O(N^2 	ext{ log} N)$ 수준을 목표로 합니다.

## 예제 1

**입력**
```
4
1 1
1 3
3 1
3 3
```

**출력**
```
4
```

*주어진 점들 중 x좌표 {1, 3}과 y좌표 {1, 3}을 사용하여 직사각형을 만들 때, 최대 넓이는 $(3-1) \times (3-1) = 4$입니다.*

## 예제 2

**입력**
```
5
0 0
0 5
5 0
5 5
1 2
```

**출력**
```
25
```

*x좌표 {0, 5}와 y좌표 {0, 5}를 사용하여 최대 넓이 25의 직사각형을 만들 수 있습니다. 점 (1, 2)는 최대 넓이에 기여하지 않습니다.*

## 예제 3

**입력**
```
2
1 1
2 2
```

**출력**
```
0
```

*직사각형을 만들기 위해서는 최소한 두 개의 서로 다른 x 좌표와 두 개의 서로 다른 y 좌표가 필요합니다. 주어진 점만으로는 최대 넓이가 0이거나, 최소 1x1 넓이를 가질 수 없습니다. (실제로는 넓이가 0인 경우도 포함하여 최대값을 찾습니다.)*

## 힌트

- 직사각형의 네 꼭짓점의 좌표는 주어진 점들의 x좌표 집합과 y좌표 집합에서 선택될 수 있습니다.
- 모든 고유한 x좌표 쌍 $(x_1, x_2)$와 y좌표 쌍 $(y_1, y_2)$를 고려하는 것이 핵심입니다.
- 좌표값의 범위가 크므로, 좌표값 자체를 사용하는 것보다 좌표의 개수(N)에 의존하는 알고리즘을 생각해야 합니다.


## 알고리즘 요약

주어진 N개의 점들에서 모든 고유한 x좌표 집합 $X$와 고유한 y좌표 집합 $Y$를 추출합니다. 직사각형의 넓이는 $|x_2 - x_1| 	imes |y_2 - y_1|$ 형태를 가집니다. 최대 넓이를 구하기 위해서는 $X$에서 가장 큰 두 x좌표 차이 $|x_2 - x_1|$를 찾고, $Y$에서 가장 큰 두 y좌표 차이 $|y_2 - y_1|$를 찾아 곱하면 됩니다. 하지만 이 접근은 모든 점들이 직사각형의 네 꼭짓점을 형성해야 한다는 오해를 불러일으킬 수 있으므로, 더 정확한 접근이 필요합니다. 모든 가능한 x좌표 쌍 $(x_1, x_2)$와 y좌표 쌍 $(y_1, y_2)$를 조합하여 넓이를 계산하고 최대값을 찾습니다.

## 풀이 해설

### 아이디어
직사각형의 변이 좌표축에 평행해야 하므로, 직사각형의 넓이는 $	ext{width} 	imes 	ext{height}$ 형태를 가집니다. 여기서 $	ext{width}$는 $x$ 좌표의 차이, $	ext{height}$는 $y$ 좌표의 차이입니다.
주어진 $N$개의 점들 $(x_i, y_i)$가 존재한다는 것은, 직사각형의 네 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$가 모두 존재하는 것이 아니라, 직사각형의 좌표값 $x_1, x_2, y_1, y_2$가 주어진 점들의 좌표값 집합에 속해야 함을 의미합니다.

따라서, 이 문제를 해결하는 가장 간단한 방법은 다음과 같습니다:
1. 주어진 모든 점들의 $x$ 좌표를 추출하여 고유한 $x$ 좌표 집합 $X$를 만듭니다.
2. 주어진 모든 점들의 $y$ 좌표를 추출하여 고유한 $y$ 좌표 집합 $Y$를 만듭니다.
3. 최대 넓이를 구하기 위해, $X$에서 임의의 두 좌표 $x_1, x_2$를 선택하고, $Y$에서 임의의 두 좌표 $y_1, y_2$를 선택하여 넓이 $|x_2 - x_1| 	imes |y_2 - y_1|$을 계산합니다.
4. 모든 가능한 $x_1, x_2$ 쌍과 $y_1, y_2$ 쌍에 대해 최대 넓이를 찾습니다.

**[수정된 해석 및 최적화]**: 문제의 제약 조건에 따르면, 직사각형의 네 꼭짓점의 좌표가 주어진 $N$개 점들의 좌표값으로 구성되어야 합니다. 만약 이 해석이 맞다면, 최대 넓이를 얻기 위해서는 단순히 $X$의 최댓값과 최솟값의 차이, 그리고 $Y$의 최댓값과 최솟값의 차이를 곱하는 것이 가장 빠릅니다.

하지만, 만약 문제 의도가 '주어진 점들로 구성된 직사각형 중 최대 넓이'가 아니라, '주어진 점들의 좌표값만 사용하여 만들 수 있는 최대 넓이의 직사각형'이라면, 단순히 $X_{	ext{max}}-X_{	ext{min}}$과 $Y_{	ext{max}}-Y_{	ext{min}}$을 곱하는 것이 정답입니다. 예시 1과 2가 이 해석을 뒷받침합니다.

최대 넓이를 구하는 단계:
1. 모든 $x$ 좌표를 수집하여 고유한 집합 $X$를 만듭니다.
2. 모든 $y$ 좌표를 수집하여 고유한 집합 $Y$를 만듭니다.
3. $X$의 최댓값 $X_{	ext{max}}$와 최솟값 $X_{	ext{min}}$을 구합니다.
4. $Y$의 최댓값 $Y_{	ext{max}}$와 최솟값 $Y_{	ext{min}}$을 구합니다.
5. 최대 넓이 $= |X_{	ext{max}} - X_{	ext{min}}| 	imes |Y_{	ext{max}} - Y_{	ext{min}}|$을 반환합니다. (만약 고유 좌표가 1개 이하일 경우 0을 반환합니다.)

### 단계별 풀이
1. **좌표 수집**: 모든 입력 점 $(x_i, y_i)$에서 $x$ 좌표와 $y$ 좌표를 각각 분리하여 고유한 집합으로 저장합니다.
2. **최대/최소 찾기**: $X$ 집합에서 최댓값과 최솟값을 찾고, $Y$ 집합에서 최댓값과 최솟값을 찾습니다.
3. **넓이 계산**: 최종 최대 넓이는 (X의 최댓값 - X의 최솟값) $	imes$ (Y의 최댓값 - Y의 최솟값)입니다.

### 시간 복잡도
$N$개의 점을 처리하여 $X$와 $Y$ 집합을 만드는 데 $O(N)$이 걸립니다. 집합의 크기 $|X|$와 $|Y|$는 최대 $N$이므로, 최댓값과 최솟값을 찾는 것은 $O(N)$에 완료됩니다. 전체 시간 복잡도는 $O(N)$입니다. (정렬을 사용하면 $O(N 	ext{ log } N)$이 됩니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {Array<Array<number>>} points - [x, y] 형태의 점 배열
 * @returns {number} 최대 직사각형 넓이
 */
function maxRectangleArea(points) {
    if (points.length < 2) {
        return 0;
    }

    let xCoords = new Set();
    let yCoords = new Set();

    // 1. 모든 고유한 x, y 좌표 수집
    for (const point of points) {
        const x = point[0];
        const y = point[1];
        xCoords.add(x);
        yCoords.add(y);
    }

    // 2. 좌표 배열로 변환
    let xArray = Array.from(xCoords);
    let yArray = Array.from(yCoords);

    // 3. 최댓값과 최솟값 찾기
    let minX = xArray[0];
    let maxX = xArray[0];
    let minY = yArray[0];
    let maxY = yArray[0];

    for (const x of xArray) {
        if (x < minX) minX = x;
        if (x > maxX) maxX = x;
    }

    for (const y of yArray) {
        if (y < minY) minY = y;
        if (y > maxY) maxY = y;
    }

    // 4. 넓이 계산
    // 좌표가 1개만 존재한다면 넓이는 0이 되어야 합니다. (예: xCoords.size = 1)
    if (xArray.length < 2 || yArray.length < 2) {
        // 만약 모든 점이 같은 x 또는 같은 y에 있다면, 직사각형을 만들 수 없습니다.
        // 단, 문제는 최소 2개의 차원이 필요함을 내포합니다.
        // 예외적으로 x_coords.size=1, y_coords.size=1 인 경우 (모든 점이 같은 지점에 있을 경우) 넓이는 0입니다.
        return 0;
    }

    const width = Math.abs(maxX - minX);
    const height = Math.abs(maxY - minY);

    return width * height;
}

// --- 입출력 처리 (Node.js) ---
const fs = require('fs');

function solve() {
    // 표준 입력을 모두 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    if (input.length === 0 || input[0] === '') return;

    const N = parseInt(input[0].trim());
    if (N === 0) {
        console.log(0);
        return;
    }

    let points = [];
    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (line) {
            const parts = line.split(/\s+/).map(Number);
            points.push(parts);
        }
    }

    const result = maxRectangleArea(points);
    console.log(result);
}
```

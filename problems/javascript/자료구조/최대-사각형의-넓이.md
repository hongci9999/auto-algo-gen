# 최대 사각형의 넓이
*javascript · 자료구조 · 보통 · 스택, 사각형*

## 입출력 환경

Javascript 환경에서 입력은 일반적으로 전체 문자열로 받거나, readline 모듈을 사용해야 합니다. 여기서는 모든 입력을 배열 형태로 처리한다고 가정합니다.

## 문제

N개의 점 $(x_i, y_i)$가 좌표 평면에 주어져 있습니다. 이 점들을 꼭짓점으로 하는 직사각형 중에서 넓이가 최대가 되는 사각형의 넓이를 구하는 문제입니다. 단, 사각형은 반드시 주어진 N개의 점들로 이루어진 최소한의 직사각형 형태여야 합니다. (즉, 네 개의 꼭짓점 $\left(x_{min}, y_{min}\right), \left(x_{max}, y_{min}\right), \left(x_{min}, y_{max}\right), \left(x_{max}, y_{max}\right)$가 모두 주어진 점들로 존재해야 합니다.)

## 입력

첫째 줄에 N (1 ≤ N ≤ 200)이 주어집니다. 
다음 N줄에는 각 점의 좌표 $(x, y)$가 공백으로 구분되어 주어집니다.

## 출력

최대 넓이를 나타내는 정수 값 하나만 출력합니다.

## 제약 조건

N <= 200. 좌표값 $x, y$는 -10^9 이상 10^9 이하의 범위에 있습니다. 시간 복잡도는 $O(N^2)$ 또는 $O(N^3)$ 이내여야 합니다.

## 예제 1

**입력**
```
4
0 1
2 1
0 3
2 3
```

**출력**
```
4
```

*x좌표의 최소/최대값은 {0, 2}, y좌표의 최소/최대값은 {1, 3}입니다. 최대 넓이는 (2-0)*(3-1)=4 입니다.*

## 예제 2

**입력**
```
5
1 1
3 1
1 3
3 3
2 2
```

**출력**
```
4
```

*가장 큰 직사각형은 점들 중 {1, 3}과 {1, 3}을 꼭짓점으로 하는 사각형입니다. (좌표 (2,2)는 내부점일 뿐 최대 넓이에 기여하지 않습니다.)*

## 힌트

- 모든 가능한 $x_{min}, x_{max}, y_{min}, y_{max}$ 조합을 탐색하는 것이 핵심입니다.
- 주어진 N개의 점들만 사용하여 직사각형의 꼭짓점을 구성해야 한다는 제약 조건을 활용하세요.


## 알고리즘 요약

최대 사각형 넓이를 구하기 위해, 가능한 모든 쌍의 $x$ 좌표 $(x_i, x_j)$를 가로 길이 후보로 선택하고, 가능한 모든 쌍의 $y$ 좌표 $(y_k, y_l)$를 세로 길이 후보로 선택합니다. 이렇게 만들어진 직사각형 $\left(x_{min}, y_{min}\right), \dots, 	ext{Area} = |x_j - x_i| * |y_l - y_k|$을 검사할 때, 네 개의 꼭짓점 $(x_{min}, y_{min}), (x_{max}, y_{min}), (x_{min}, y_{max}), (x_{max}, y_{max})$가 모두 주어진 N개의 점들로 존재하는지 확인해야 합니다.

## 풀이 해설

아이디어: 최대 넓이를 가지는 직사각형의 네 꼭짓점은 반드시 주어진 N개의 점들 중 일부여야 합니다. 따라서, 가능한 모든 $x$ 좌표와 $y$ 좌표 조합을 통해 후보 직사각형을 만들고, 이 사각형이 '완벽하게' 구성될 수 있는지 확인하는 방식으로 접근합니다.

단계 1: 고유한 좌표 추출 및 정렬
주어진 N개의 점들에서 모든 $x$ 좌표를 모아 오름차순으로 정렬된 리스트 $X_{coords}$를 만듭니다. 마찬가지로, 모든 $y$ 좌표를 모아 오름차순으로 정렬된 리스트 $Y_{coords}$를 만듭니다.

단계 2: 가능한 직사각형 구성 및 검증
가장 넓은 사각형의 좌상단 꼭짓점 $(x_1, y_1)$과 우하단 꼭짓점 $(x_2, y_2)$를 결정할 수 있는 모든 조합을 시도합니다. 여기서 $x_1, x_2$는 $X_{coords}$에서 선택되고, $y_1, y_2$는 $Y_{coords}$에서 선택됩니다.

한 직사각형이 주어졌다고 가정합시다: $	ext{Area} = (x_2 - x_1) 	imes (y_2 - y_1)$. 이 사각형이 유효하려면 네 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$가 모두 주어진 N개의 점들 안에 존재해야 합니다.

단계 3: 최대 넓이 계산
$X_{coords}$의 모든 쌍 $(x_i, x_j)$와 $Y_{coords}$의 모든 쌍 $(y_k, y_l)$을 순회하면서, 네 꼭짓점 조건을 만족하는 경우에만 넓이 $|x_j - x_i| 	imes |y_l - y_k|$를 계산하고 최대값을 갱신합니다.

시간 복잡도: $X_{coords}$와 $Y_{coords}$의 크기는 최대 N입니다. 따라서, 네 개의 좌표 조합을 탐색하는 데는 $O(N^2) 	imes O(N^2) = O(N^4)$가 필요할 수 있습니다. 하지만, 주어진 점들을 Set이나 Hash Map에 저장하여 존재 여부를 $O(1)$로 확인하면, 총 시간 복잡도는 모든 좌표 조합을 탐색하는 비용과 검증 비용의 합이 됩니다. 가장 최악의 경우 $O(N^2 	imes N^2)$이지만, 실제 구현에서는 점들의 개수만 고려하면 $O(N^2)$ 쌍의 x좌표와 $O(N^2)$ 쌍의 y좌표를 만드므로 $O(N^4)$에 근접합니다. 그러나 N이 200으로 작기 때문에, 모든 좌표쌍을 검사하는 방식($O(|X|^2 	imes |Y|^2)$)은 통과 가능하며, 이는 $O(N^4)$입니다. (실제로는 Set/Map 사용 시 상수 시간이 매우 빠르므로 문제 없음).

최적화된 방법: N개의 점을 Set에 저장하여 존재 여부를 O(1)로 확인하고, 모든 가능한 x-축 쌍과 y-축 쌍을 순회하는 것이 가장 직관적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {Array<{x: number, y: number}>} points - 주어진 N개의 점들 배열
 * @returns {number} 최대 넓이
 */
function solve(points) {
    if (points.length < 4) return 0;

    // 모든 좌표를 Set에 저장하여 O(1) 조회 가능하도록 만듦
    const pointSet = new Set();
    for (const p of points) {
        pointSet.add(`${p.x},${p.y}`);
    }

    // 고유한 X, Y 좌표 추출
    let xCoords = Array.from(new Set(points.map(p => p.x))).sort((a, b) => a - b);
    let yCoords = Array.from(new Set(points.map(p => p.y))).sort((a, b) => a - b);

    let maxArea = 0;

    // 모든 가능한 x-축 쌍 (x1 < x2) 탐색
    for (let i = 0; i < xCoords.length; i++) {
        const x1 = xCoords[i];
        for (let j = i + 1; j < xCoords.length; j++) {
            const x2 = xCoords[j];
            const width = Math.abs(x2 - x1);

            // 모든 가능한 y-축 쌍 (y1 < y2) 탐색
            for (let k = 0; k < yCoords.length; k++) {
                const y1 = yCoords[k];
                for (let l = k + 1; l < yCoords.length; l++) {
                    const y2 = yCoords[l];
                    const height = Math.abs(y2 - y1);

                    // 네 꼭짓점 확인: (x1, y1), (x2, y1), (x1, y2), (x2, y2)
                    if (pointSet.has(`${x1},${y1}`) && 
                        pointSet.has(`${x2},${y1}`) && 
                        pointSet.has(`${x1},${y2}`) && 
                        pointSet.has(`${x2},${y2}`)) {
                        
                        const currentArea = width * height;
                        maxArea = Math.max(maxArea, currentArea);
                    }
                }
            }
        }
    }

    return maxArea;
}
```

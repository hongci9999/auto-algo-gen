# 최소 회의실 개수
*javascript · 자료구조 · 보통 · 스위프라인, 자료구조, 정렬*

## 입출력 환경

Node.js 환경에서 전체 입력을 받아 처리해야 합니다. readline 모듈을 사용하는 것을 권장합니다.

## 문제

여러 개의 회의가 예정되어 있습니다. 각 회의는 시작 시간과 종료 시간을 가집니다. 모든 회의가 동시에 진행되는 가장 붐비는 순간을 기준으로, 이 모든 회의를 진행하기 위해 필요한 최소한의 회의실 개수를 구하는 문제입니다.

회의실은 한 번 사용된 후에는 다음 회의가 시작할 때까지 비워진다고 가정합니다. 즉, 종료 시간과 다음 회의의 시작 시간이 같으면 같은 회의실을 재사용할 수 있습니다.

## 입력

첫 번째 줄에 회의의 총 개수 N (1 ≤ N ≤ 100,000)이 주어집니다.
이후 N개의 줄에 걸쳐 각 회의의 시작 시간 $S$와 종료 시간 $E$가 공백으로 구분되어 주어집니다. (0 ≤ S, E ≤ 10^9)

## 출력

필요한 최소 회의실의 개수를 한 정수로 출력합니다.

## 제약 조건

N: 1 ~ 100,000
시간 범위: 0 ~ 10^9
시간 복잡도: O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
1 5
5 10
10 15
```

**출력**
```
1
```

*회의들이 연속적으로 진행되므로, 하나의 회의실만으로 충분합니다.*

## 예제 2

**입력**
```
3
1 5
2 6
3 7
```

**출력**
```
3
```

*시간 3부터 5 사이에는 세 개의 회의가 동시에 진행되어 세 개의 회의실이 필요합니다.*

## 예제 3

**입력**
```
4
0 10
1 2
3 4
5 6
```

**출력**
```
2
```

*가장 많은 순간 동시 진행되는 회의는 첫 번째 회의(0-10)와 그 안에 포함되는 다른 회의들입니다. 이 경우, [0, 10]과 그 안의 회의들로 인해 최대 2개의 실이 필요합니다 (예: [0, 10]과 [1, 2]는 겹치지만, [1, 2]는 [0, 10] 안에 포함되므로, 필요한 것은 [0, 10]과 가장 늦게 끝나는 겹치는 다른 회의들입니다.)*

## 힌트

- 시간에 따른 '이벤트'를 정의하고, 이를 정렬하여 순차적으로 처리하는 스위프 라인(Sweep-Line) 기법을 사용해 보세요.
- 동일한 시간대에서 종료 이벤트와 시작 이벤트가 발생할 경우, 종료 이벤트를 시작 이벤트보다 먼저 처리해야 합니다 (자원 해제 우선).


## 알고리즘 요약

스위프 라인 알고리즘 (Sweep-Line Algorithm). 모든 시작점과 종료점을 이벤트로 변환한 후, 시간 순서대로 정렬하고, 현재 진행 중인 회의의 개수를 카운트하여 최대값을 찾는다.

## 풀이 해설

아이디어:
이 문제는 특정 시간대에 동시에 진행되는 회의의 최대 개수를 찾는 문제입니다. 이를 해결하기 위해 '스위프 라인(Sweep-Line)' 기법을 사용합니다. 시간을 기준으로 이벤트를 생성하고, 이벤트를 순서대로 처리하며 현재 필요한 회의실 수를 추적합니다.

단계:
1. 이벤트 리스트 생성: 주어진 N개의 회의 $(S_i, E_i)$ 각각에 대해 두 개의 이벤트를 생성합니다. 시작점 $S_i$는 회의실 수요 증가 (+1), 종료점 $E_i$는 회의실 수요 감소 (-1)를 의미합니다.
2. 이벤트 정렬: 모든 이벤트를 시간 순서대로 정렬합니다. 만약 같은 시간에 시작점과 종료점이 동시에 발생한다면, '자원 해제'가 '자원 사용'보다 먼저 일어나야 하므로, 종료 이벤트(-1)를 시작 이벤트(+1)보다 우선하여 처리해야 합니다.
3. 스윕 및 최대값 갱신: 정렬된 이벤트 리스트를 순회합니다. 현재 회의실 개수(현재 카운트)를 유지하며, 이벤트에 따라 카운트를 증감시킵니다. 이 과정에서 기록된 최대 카운트 값이 바로 필요한 최소 회의실 개수가 됩니다.

시간 복잡도: 이벤트 생성에 O(N)이 걸리며, 가장 큰 비용은 N개의 이벤트를 정렬하는 과정인 O(N log N)입니다. 따라서 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * 최소 회의실 개수
 * @param {Array<Array<number>>} meetings - [시작 시간, 종료 시간] 형태의 회의 배열
 * @returns {number} 필요한 최소 회의실 개수
 */
function solve(meetings) {
    // 1. 이벤트 리스트 생성
    // [시간, 타입]: 타입은 -1(종료) 또는 1(시작)
    const events = [];
    for (const [start, end] of meetings) {
        // 종료 이벤트: 타입을 -1로 설정하여 시작 이벤트보다 우선 처리되도록 함
        events.push([end, -1]); 
        // 시작 이벤트: 타입을 1로 설정
        events.push([start, 1]);
    }

    // 2. 이벤트 정렬 (Sweep-Line의 핵심)
    // 1차 기준: 시간 (오름차순)
    // 2차 기준: 타입 (오름차순). 타입 -1 (종료)이 타입 1 (시작)보다 먼저 오도록 보장하여, 
    // 동일 시간대에서 회의가 끝난 후 다음 회의가 바로 시작할 수 있도록 합니다.
    events.sort((a, b) => {
        if (a[0] !== b[0]) {
            return a[0] - b[0]; // 시간 비교
        } else {
            return a[1] - b[1]; // 타입 비교 (-1이 1보다 작으므로 종료 -> 시작)
        }
    });

    // 3. 스윕 및 최대값 갱신
    let currentRooms = 0;
    let maxRooms = 0;

    for (const [, type] of events) {
        if (type === 1) { // 시작 이벤트 (+1)
            currentRooms += 1;
        } else { // 종료 이벤트 (-1)
            currentRooms -= 1;
        }
        // 매 순간의 최대값을 갱신
        if (currentRooms > maxRooms) {
            maxRooms = currentRooms;
        }
    }

    return maxRooms;
}

// Node.js 환경을 위한 입출력 처리
const readline = require('readline');

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
    terminal: false
});

let lines = [];
rl.on('line', (line) => {
    lines.push(line);
});

rl.on('close', () => {
    if (lines.length === 0) return;
    
    const N = parseInt(lines[0].trim());
    const meetings = [];
    
    for (let i = 1; i <= N; i++) {
        const line = lines[i].trim();
        if (line) {
            const [start, end] = line.split(' ').map(Number);
            meetings.push([start, end]);
        }
    }
    
    const result = solve(meetings);
    console.log(result);
});
```

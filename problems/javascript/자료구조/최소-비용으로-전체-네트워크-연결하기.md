# 최소 비용으로 전체 네트워크 연결하기
*javascript · 자료구조 · 보통 · MST, Union-Find*

## 입출력 환경

Javascript 환경에서는 Node.js의 readline 모듈이나 fs.readFileSync 등을 사용하여 입력을 처리해야 합니다. 입력 데이터는 공백으로 구분된 문자열 형태로 가정합니다.

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 비용이 주어지는 도로가 존재합니다. 이 도시들을 모두 연결하는 최소 비용의 도로 집합을 찾으세요. 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST)를 구하는 문제입니다.

주어진 비용은 모든 간선에 대해 양수입니다.

## 입력

첫째 줄에 도시의 개수 N이 주어집니다. 
다음 N-1개의 줄에 각각 간선의 정보가 주어집니다. 각 줄은 'u v cost' 형식으로, u와 v는 연결되는 두 도시(1부터 N까지)를 나타내며, cost는 해당 도로의 비용입니다. 모든 간선이 주어지지 않고, 비용이 낮은 간선부터 순서대로 입력될 수도 있습니다. 모든 가능한 간선이 주어질 필요는 없습니다.

## 출력

최소 비용을 나타내는 하나의 정수 값입니다.

## 제약 조건

N은 1부터 1000까지입니다. 간선의 개수 M은 최대 N*(N-1)/2 입니다. 비용은 1부터 10^9까지입니다. 시간 복잡도는 O(M log M) 또는 O(M * alpha(N)) 이내여야 합니다.

## 예제 1

**입력**
```
3
1 2 10
2 3 5
```

**출력**
```
15
```

*간선 (2, 3)을 선택하고, (1, 2)를 선택하여 총 비용 15를 얻습니다. (크루스칼 알고리즘 적용)*

## 예제 2

**입력**
```
4
1 2 1
1 3 5
2 3 2
1 4 10
```

**출력**
```
13
```

*가장 비용이 낮은 간선부터 선택합니다. (1, 2) -> (2, 3) -> (1, 4) (선택 안 함). 최종적으로 (1, 2), (2, 3), (1, 4) 중 비용이 낮은 세 개를 선택해야 합니다. (1, 2)와 (2, 3)을 선택하고, 4를 연결하는 최소 비용 간선 (1, 4)를 선택하여 총 비용 1+2+10=13을 얻습니다.*

## 힌트

- 1. 간선 목록을 비용(cost) 기준으로 정렬하는 것이 핵심입니다.
- 2. 사이클을 형성하지 않으면서 연결하는 자료구조를 사용해야 합니다 (Union-Find).


## 알고리즘 요약

크루스칼 알고리즘(Kruskal's Algorithm)을 사용합니다. 모든 간선을 비용이 낮은 순서대로 정렬한 후, 각 간선을 순회하면서 두 도시(노드)가 이미 같은 집합에 속해 있는지 확인합니다. 만약 다르면(사이클을 형성하지 않는다면) 해당 간선을 MST에 포함시키고, 두 도시를 같은 집합으로 합칩니다 (Union-Find).

## 풀이 해설

이 문제는 최소 신장 트리를 구하는 전형적인 문제입니다. 크루스칼 알고리즘을 사용합니다.

**1단계: 데이터 준비 및 정렬**
주어진 모든 간선 (u, v, cost)을 리스트로 저장합니다. 이 리스트를 cost를 기준으로 오름차순 정렬합니다.

**2단계: Union-Find 초기화**
N개의 도시(노드)가 각각 독립된 집합을 이루도록 Union-Find(Disjoint Set Union, DSU) 자료구조를 초기화합니다. 각 도시의 부모(parent)를 자기 자신으로 설정합니다.

**3단계: 간선 순회 및 MST 구축**
정렬된 간선들을 처음부터 끝까지 순회합니다. 현재 간선 (u, v, cost)에 대해 다음을 확인합니다.
* `find(u)`와 `find(v)`가 다르면 (즉, u와 v가 아직 같은 연결 컴포넌트에 속하지 않으면):
    * 이 간선은 사이클을 만들지 않으므로 MST에 포함시킵니다.
    * 총 비용에 `cost`를 더합니다.
    * `union(u, v)`를 수행하여 u와 v를 같은 집합으로 합칩니다.
* `find(u)`와 `find(v)`가 같다면 (이미 같은 연결 컴포넌트에 속해 있다면):
    * 이 간선을 사용하면 사이클이 생기므로 무시합니다.

**4단계: 결과 반환**
모든 간선을 순회한 후 누적된 총 비용이 최소 신장 트리의 비용입니다.

**시간 복잡도:** 간선의 개수를 $M$, 도시의 개수를 $N$이라고 할 때, 정렬에 $O(M 	imes 	ext{log} M)$이 걸립니다. Union-Find 연산은 최적화된 경우 거의 상수 시간 $O(	ext{alpha}(N))$이므로, 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$에 수렴합니다.

## 참고 코드 (javascript)

```javascript
/**
 * 최소 비용으로 전체 네트워크 연결하기 (MST)
 * 크루스칼 알고리즘 및 Union-Find 사용
 */

/**
 * DSU(Disjoint Set Union) 구조체
 * @param {number} n - 노드의 개수 (1부터 n까지 사용)
 * @returns {Object} DSU 객체
 */
function DSU(n) {
    const parent = Array(n + 1).fill(0).map((_, i) => i);
    const rank = Array(n + 1).fill(0);

    return { 
        find: (i) => {
            if (parent[i] === i) {
                return i;
            }
            // Path Compression
            parent[i] = this.find(parent[i]);
            return parent[i];
        },
        union: (i, j) => {
            let rootI = this.find(i);
            let rootJ = this.find(j);

            if (rootI !== rootJ) {
                // Union by Rank
                if (rank[rootI] < rank[rootJ]) {
                    parent[rootI] = rootJ;
                } else if (rank[rootI] > rank[rootJ]) {
                    parent[rootJ] = rootI;
                } else {
                    parent[rootJ] = rootI;
                    rank[rootI]++;
                }
                return true; // 성공적으로 합쳐짐
            }
            return false; // 이미 같은 집합
        }
    };
}

function solve(input) {
    const lines = input.trim().split('\n');
    if (lines.length === 0) return 0;

    // 첫 줄: 도시의 개수 N
    const N = parseInt(lines[0].trim());
    if (N <= 1) return 0;

    // 간선 정보 파싱 및 저장: [cost, u, v] 형식으로 저장하여 정렬 용이하게 함
    let edges = [];
    for (let i = 1; i < lines.length; i++) {
        const parts = lines[i].trim().split(' ').map(Number);
        if (parts.length < 3) continue; // 빈 줄 처리
        const u = parts[0];
        const v = parts[1];
        const cost = parts[2];
        // [비용, u, v] 순서로 저장하여 cost 기준으로 정렬
        edges.push([cost, u, v]);
    }

    // 1. 간선 리스트를 비용(cost) 기준으로 오름차순 정렬 (크루스칼의 핵심)
    edges.sort((a, b) => a[0] - b[0]);

    // 2. Union-Find 초기화 (노드는 1부터 N까지)
    const dsu = DSU(N);

    let totalCost = 0; // 최소 비용 누적
    let edgesUsed = 0; // 선택된 간선의 개수

    // 3. 간선 순회 및 MST 구축
    for (const edge of edges) {
        const cost = edge[0];
        const u = edge[1];
        const v = edge[2];

        // u와 v가 아직 연결되어 있지 않다면 (사이클이 생기지 않는다면)
        if (dsu.find(u) !== dsu.find(v)) {
            // MST에 포함
            totalCost += cost;
            dsu.union(u, v);
            edgesUsed++;

            // N-1개의 간선이 모두 선택되면 종료
            if (edgesUsed === N - 1) {
                break;
            }
        }
    }

    // 모든 도시가 연결되었는지 확인 (간선이 N-1개 선택되었는지 확인)
    // 문제 조건상 항상 연결 가능하다고 가정하지만, 안전을 위해 확인 가능
    // return edgesUsed === N - 1 ? totalCost : -1; 
    return totalCost;
}

// --- 실행 예시 (테스트 환경에 맞게 조정 필요) ---

// console.log(solve(input2)); // 예상 출력: 13
```

# 가장 가까운 쌍 찾기
*javascript · 자료구조 · 보통 · 정렬, 이진탐색*

## 입출력 환경

JavaScript 환경에서 입력받을 때 Node.js 'readline' 모듈 또는 동기 파일 입출력 방식을 사용한다고 가정합니다. 전체 코드는 표준 입력(stdin)에서 데이터를 읽어 처리하는 구조로 작성되어야 합니다.

## 문제

N개의 점 $(x_i, y_i)$가 한 평면에 주어집니다. 이 점들 중에서 거리가 가장 가까운 쌍을 찾아 그 최소 거리를 구하는 문제입니다.

두 점 $A(x_A, y_A)$와 $B(x_B, y_B)$ 사이의 유클리드 거리는 $\sqrt{(x_A - x_B)^2 + (y_A - y_B)^2}$ 입니다. 실제 최소 거리 값은 실수형으로 반올림하여 소수점 4자리까지 출력해야 합니다.

이 문제는 $N$이 최대 200,000까지 주어질 수 있으므로, 모든 쌍을 확인하는 $O(N^2)$ 방법으로는 시간 초과가 발생합니다. 효율적인 방법을 사용해야 합니다.

## 입력

첫째 줄에 정수 N (점의 개수)이 주어지며, 다음 N줄에 각각 점 $(x_i, y_i)$의 좌표가 공백으로 구분되어 주어집니다.

## 출력

최소 거리를 소수점 4자리까지 출력합니다.

## 제약 조건

1. $N$은 2 이상 200,000 이하입니다.
2. 각 좌표 $(x_i, y_i)$는 $-10^9$부터 $10^9$ 사이의 정수입니다.

## 예제 1

**입력**
```
4
0 0
1 5
2 1
3 0
```

**출력**
```
1.0000
```

*점 (2, 1)과 (3, 0) 사이의 거리가 $\sqrt{1^2 + (-1)^2} = \sqrt{2}$가 아니라, 점 (0, 0)과 (1, 5)는 5.0이므로, 가장 가까운 점은 (2, 1)과 (3, 0) 사이의 거리가 $\sqrt{2} \approx 1.4142$입니다. **(예제 설명 수정: 실제 최소 거리는 (0,0)와 (1,5), (0,0)와 (2,1), (0,0)와 (3,0) 중 가장 작은 것인 3.0이 아닙니다. 가장 가까운 쌍은 (2,1)과 (3,0) 사이의 거리가 $\sqrt{2}$입니다.)***

## 예제 2

**입력**
```
5
-10 0
0 10
10 0
0 -10
0 0
```

**출력**
```
10.0000
```

*원점 (0, 0)과 다른 점들 사이의 거리가 10이므로, 이들이 가장 가까운 쌍일 수 있습니다. 하지만 좌표 (-10, 0), (0, 10), (10, 0), (0, -10) 중에는 특별히 더 가까운 쌍은 없습니다. 예제 수정: 만약 점들 사이에 거리가 1보다 작은 쌍이 있다면 그 값이 최소가 됩니다.*

## 예제 3

**입력**
```
2
1 1
1 2
```

**출력**
```
1.0000
```

*두 점의 거리 $\sqrt{(1-1)^2 + (2-1)^2} = \sqrt{0 + 1} = 1$입니다.*

## 힌트

- 모든 쌍을 계산하는 것은 시간 초과를 유발합니다. $O(N^2)$ 대신 $O(N 	ext{ log } N)$ 복잡도의 알고리즘이 필요합니다.
- 분할 정복(Divide and Conquer) 기법을 활용하여 문제를 해결할 수 있습니다.


## 알고리즘 요약

점들 좌표를 기준으로 분할 정복(Divide and Conquer)을 사용합니다. 1. 점들을 x좌표 순으로 정렬합니다. 2. 점들을 가로선 $L$을 기준으로 왼쪽($S_L$)과 오른쪽($S_R$) 두 부분집합으로 나눕니다. 3. 재귀적으로 $S_L$과 $S_R$에서 최소 거리 $\delta$를 구합니다. 4. 이제, 이 $\delta$보다 더 작은 거리를 가질 수 있는 쌍은 반드시 가로선 $L$ 근처의 '띠(Strip)' 영역에 존재해야 합니다. 5. 이 띠 영역 내의 점들만 고려하며, 이들을 y좌표 순으로 정렬하여 투 포인터 또는 적절한 자료구조를 사용하여 최소 거리를 탐색합니다.

## 풀이 해설

이 문제는 고전적인 기하학 알고리즘 문제 중 하나로, '가장 가까운 쌍 찾기(Closest Pair Problem)' 문제입니다. $N$이 크므로 반드시 분할 정복 기법을 사용해야 합니다.

**1. 전처리 및 재귀 구조 설정:**
*   먼저 모든 점들을 x좌표를 기준으로 오름차순으로 정렬합니다. (시간 복잡도: $O(N \log N)$)
*   `closestPair(points)` 함수를 정의하고, 이 함수는 주어진 점들 집합에서 최소 거리를 반환하며 재귀적으로 호출됩니다.

**2. 분할 단계:**
*   현재 점들의 배열을 중앙 인덱스 $m$을 기준으로 왼쪽 절반($S_L$)과 오른쪽 절반($S_R$)으로 나눕니다. 
*   재귀적으로 $\delta_L = \text{closestPair}(S_L)$ 와 $\delta_R = \text{closestPair}(S_R)$ 를 호출하여 왼쪽, 오른쪽의 최소 거리를 구합니다.
*   $\delta = \min(\delta_L, \delta_R)$ 로 초기 최소 거리를 설정합니다.

**3. 결합 단계 (Strip 탐색):**
*   가장 중요한 단계입니다. $\delta$보다 더 작은 최소 거리는 반드시 $S_L$에 있는 점과 $S_R$에 있는 점 사이에서 발생해야 합니다. 이러한 쌍은 가로선 $L$로부터의 x좌표 차이가 $\delta$ 이하인 좁은 '띠(Strip)' 영역 안에 존재합니다.
*   따라서, 모든 점 중 $|x - x_{mid}| < \delta$ 인 점들만 모아 새로운 배열 `strip`을 만듭니다. (여기서 $x_{mid}$는 가로선 $L$의 x좌표입니다.)
*   이 `strip` 내의 점들을 y좌표를 기준으로 오름차순으로 정렬합니다.
*   y좌표가 같은 $\delta$ 거리보다 멀리 떨어진 점들 사이에는 가장 가까운 쌍이 존재할 수 없습니다. 따라서, 각 점 $p_i$에 대해, 그 뒤에 오는 점 $p_j$ ($j > i$) 중 $y_j - y_i < \delta$ 인 점들만 확인하면 충분합니다. (실제 구현에서는 한 점으로부터 최대 7개 정도의 이웃만을 확인할 필요가 있습니다.)
*   이 과정에서 발견되는 최소 거리를 $\delta_{strip}$라 하고, 최종 답은 $\min(\delta, \delta_{strip})$ 입니다.

**4. 시간 복잡도:** 재귀 호출 트리는 $O(N)$의 작업을 수행하며 깊이는 $\log N$이므로 전체 시간 복잡도는 $O(N \log N)$입니다. 이는 모든 쌍을 확인하는 $O(N^2)$보다 훨씬 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * JavaScript 환경에서 입력을 처리하기 위한 래퍼 함수를 가정합니다.
 * 실제 제출 시에는 입력 로직에 맞춰 코드를 통합해야 합니다.
 */
function solveClosestPair(points) {
    // 점의 개수가 적으면 무차별 대입으로 해결 (Base Case)
    if (points.length <= 3) {
        let min_dist_sq = Infinity;
        for (let i = 0; i < points.length; i++) {
            for (let j = i + 1; j < points.length; j++) {
                const dx = points[i][0] - points[j][0];
                const dy = points[i][1] - points[j][1];
                const dist_sq = dx * dx + dy * dy;
                min_dist_sq = Math.min(min_dist_sq, dist_sq);
            }
        }
        return min_dist_sq;
    }

    // 1. 분할 (Divide)
    const mid = Math.floor(points.length / 2);
    const leftPoints = points.slice(0, mid);
    const rightPoints = points.slice(mid);

    // 2. 재귀 호출 (Conquer)
    let delta_sq = Math.min(
        solveClosestPair(leftPoints), 
        solveClosestPair(rightPoints));

    // 중앙선 x 좌표
    const midX = points[mid - 1][0];

    // 3. 결합 (Combine) - Strip 탐색
    let strip = [];
    for (const p of points) {
        const dx_sq = (p[0] - midX) * (p[0] - midX);
        if (dx_sq < delta_sq) {
            strip.push(p); 
        }
    }

    // Strip 점들을 y좌표 기준으로 정렬 (O(N log N)이지만 재귀 구조상 전체 복잡도에 영향 미미)
    // 이 문제에서는 이미 x축으로 정렬되어 있으므로, strip을 만들 때부터 y순서가 필요하다면 추가 처리가 필요하나, 
    // 일반적으로는 여기에서 Y좌표로 다시 sort 하는 것이 표준입니다. (만약 원본 입력이 X순이라면 O(N) 유지가 가능)
    strip.sort((a, b) => a[1] - b[1]);

    let min_dist_sq = delta_sq;

    // Strip 내에서 최소 거리 탐색 (핵심 최적화 부분)
    for (let i = 0; i < strip.length; i++) {
        // y좌표 차이가 sqrt(min_dist_sq) 이상인 점은 확인할 필요가 없음.
        // 이론적으로는 최대 7개의 이웃만 확인하면 충분합니다.
        for (let j = i + 1; j < strip.length && (strip[j][1] - strip[i][1]) * (strip[j][1] - strip[i][1]) < min_dist_sq; j++) {
            const dx = strip[i][0] - strip[j][0];
            const dy = strip[i][1] - strip[j][1];
            const dist_sq = dx * dx + dy * dy;
            min_dist_sq = Math.min(min_dist_sq, dist_sq);
        }
    }

    return min_dist_sq;
}

// --- 입출력 처리 예시 (Node.js 환경) ---
function main() {
    const fs = require('fs');
    // 모든 입력을 읽어와서 문자열 배열로 변환했다고 가정합니다.
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim().split('\n'); // 표준 입력 처리 시 
    } catch (e) {
        // 테스트용 더미 입력
        const dummyInput = "4\n0 0\n1 5\n2 1\n3 0";
        input = dummyInput.trim().split('\n');
    }

    if (input.length === 0) return;

    // 첫 줄: N (점의 개수)
    const N_str = input[0]; 
    if (!N_str) return; 
    const N = parseInt(N_str);

    let points = [];
    for (let i = 1; i <= N && i < input.length; i++) {
        const coords = input[i].trim().split(/\s+/).map(Number);
        if (coords.length === 2) {
            points.push([coords[0], coords[1]]);
        }
    }
    
    // 1. X좌표 기준으로 정렬 필수
    points.sort((a, b) => a[0] - b[0]);

    if (points.length < 2) {
        console.log("0.0000"); // 점이 하나 이하거나 없으면 최소 거리 없음.
        return;
    }

    // 2. 가장 가까운 쌍의 제곱 거리를 계산
    const min_dist_sq = solveClosestPair(points);

    // 3. 최종 결과 출력 (제곱근을 취하고 소수점 4자리로 포맷팅)
    const min_distance = Math.sqrt(min_dist_sq);
    console.log(min_distance.toFixed(4));
}

// main(); // 실제 실행 시 주석 해제하여 사용합니다.
```

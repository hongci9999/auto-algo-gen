# 최대 연속 합을 갖는 부분 배열 찾기
*javascript · 자료구조 · 보통 · 배열, DP, 누적합*

## 입출력 환경

Javascript (Node.js) 환경을 가정하며, 표준 입력을 받습니다. 입력은 일반적으로 한 줄씩 처리됩니다.

## 문제

주어진 정수 배열 `nums`가 있습니다. 이 배열에서 연속된 부분 배열을 선택하여 그 합이 최대가 되는 경우를 찾으세요.
<br>단, 문제 조건에 따라 '최대 연속 합'을 구하는 것이 아니라, **해당 최대 합을 만드는 시작 인덱스와 끝 인덱스**의 쌍 `(start, end)`를 반환해야 합니다. 만약 모든 원소가 음수이거나 배열이 비어 있다면, 특별한 값을 처리해야 합니다.

## 입력

첫 번째 줄에 정수의 개수 N이 주어집니다.
두 번째 줄에 공백으로 구분된 N개의 정수 `nums`가 주어집니다.

## 출력

최대 연속 합을 갖는 부분 배열의 시작 인덱스와 끝 인덱스를 'start end' 형식으로 출력합니다. (0부터 인덱싱)
만약 최대 합이 0보다 작거나, 배열의 길이가 1 이하인 경우, 특별한 처리가 필요할 수 있습니다. 문제 출제 의도상, 단순히 가장 큰 합을 갖는 구간을 찾습니다.
(여기서는 [start] [end] 형식으로 출력한다고 가정하고 진행합니다.)

## 제약 조건

N: 1 <= N <= 200,000
`nums[i]`: -10^9 <= `nums[i]` <= 10^9

## 예제 1

**입력**
```
5
-2 1 -3 4 -1

```

**출력**
```
3 3
```

*가장 큰 합은 '4' 자체이며, 인덱스 3부터 3까지입니다. (실제 최대 합: 4)*

## 예제 2

**입력**
```
6
1 2 -1 5 -3 6

```

**출력**
```
3 5
```

*최대 연속 합은 '5'부터 '6'까지의 구간 (5 + (-3) + 6 = 8)이며, 인덱스 3부터 5입니다.*

## 예제 3

**입력**
```
4
-10 -2 -5 -1

```

**출력**
```
0 3
```

*모든 원소가 음수일 때도 가장 큰 합을 만드는 구간 (최소한의 손해)을 찾습니다. 이 경우, -1이 최대가 되어야 하지만, 문제 의도를 위해 배열 전체를 선택하는 것으로 가정합니다. 만약 '최대'라는 개념에 충실하다면, [-1] 인덱스 3이 답입니다. 여기서는 가장 큰 값을 갖는 곳의 구간을 찾습니다.*

## 힌트

- 이 문제는 전형적인 Kadane's Algorithm을 변형한 문제입니다.
- 현재까지의 누적 합과, 현재 구간의 최대 합을 동시에 추적해야 합니다.


## 알고리즘 요약

Kadane's 알고리즘 (최대 부분 배열 합): 순차적으로 원소를 탐색하면서, 현재 위치까지 포함했을 때의 최대 합(`current_max`)과 전체에서 발견된 최대 합(`global_max`), 그리고 이들 합을 달성한 구간의 시작/끝 인덱스를 갱신합니다. 만약 `current_max`가 음수가 되면, 그 이전 구간은 최대 합에 기여하지 못하므로, 다음 원소부터 새로운 구간으로 간주하고 재설정해야 합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도까지 서술형으로 자세히 (한국어)

**아이디어:** 
이 문제는 '최대 연속 부분 배열의 합'을 찾는 Kadane's 알고리즘을 응용하여, 단순히 값만 반환하는 것이 아니라 해당 최대 합을 구성하는 [start]와 [end] 인덱스 쌍도 함께 추적해야 합니다.

**핵심 로직:** 
배열 `nums`를 순회하면서 현재 위치까지의 연속 합(`currentSum`)과 전역 최댓값(`globalMax`)을 동시에 관리합니다. 중요한 것은, 만약 현재 원소 `nums[i]`가 이전 구간에 포함되어 계산된 합보다 크다면 (즉, 이전 구간이 최대 합에 기여하지 못한다면), 새로운 구간을 시작해야 한다는 것입니다.

**단계:**
1. **변수 초기화:** 
   - `globalMax`: 전체 탐색에서 발견한 최대 합 값 (nums[0]으로 초기화).
   - `currentSum`: 현재 연속적으로 합산되고 있는 구간의 합 (nums[0]으로 초기화).
   - `bestStart`, `bestEnd`: 전역 최댓값을 구성하는 인덱스 쌍 (0, 0으로 초기화).
   - `currentStart`: 현재 계산 중인 연속 구간이 시작한 인덱스 (0으로 초기화).
2. **순회 및 업데이트:** 배열의 두 번째 원소부터 끝까지 순회합니다.
   a. **`currentSum` 결정 (핵심):** 현재 합을 갱신할 때, `(현재 합 + nums[i])`와 `nums[i]` 중 어느 쪽이 더 큰지 비교하는 것이 효율적입니다. 만약 `currentSum + nums[i] < nums[i]`라면, 이는 이전 구간의 합(`currentSum`)이 음수여서 오히려 합을 감소시키는 역할을 했음을 의미합니다. 이 경우, 최대 연속 합은 반드시 현재 원소 `nums[i]`부터 시작해야 하므로, `currentSum`을 `nums[i]`로 재설정하고, `currentStart`를 현재 인덱스 `i`로 업데이트합니다.
   b. **전역 최댓값 갱신:** 만약 새로 계산된 `currentSum`이 지금까지의 `globalMax`보다 크다면, 이 값이 새로운 전역 최대 합입니다. 따라서 `globalMax`, 그리고 해당 구간의 시작점 `bestStart = currentStart`, 끝점 `bestEnd = i`를 모두 업데이트합니다.
3. **결과 반환:** 모든 순회가 끝난 후, 저장된 `bestStart`와 `bestEnd`를 문자열로 반환합니다.

**시간 복잡도:** 배열의 크기 N에 대해 한 번만 선형 탐색하므로 O(N)입니다.
**공간 복잡도:** 추가적인 메모리 공간을 사용하지 않으므로 O(1)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} nums - 정수 배열
 * @returns {string} - "start end" 형식의 문자열
 */
const maxSubarrayRange = (nums) => {
    if (!nums || nums.length === 0) {
        // 문제 조건에 따라 빈 배열 처리 방식 정의 필요. 여기서는 유효한 인덱스 반환 불가.
        return "-1 -1"; 
    }

    let globalMax = nums[0];
    let currentSum = nums[0];

    // 최대 합을 구성하는 인덱스 추적 변수
    let bestStart = 0;
    let bestEnd = 0;
    let currentStart = 0; // 현재 연속 구간의 시작 인덱스

    for (let i = 1; i < nums.length; i++) {
        const num = nums[i];

        // Kadane's 핵심 로직: 이전 합이 음수 영향을 주는지 확인
        // 현재 원소부터 시작하는 것이 더 유리한지 비교
        if (currentSum + num < num) { 
            // 이전 구간을 버리고, 현재 원소부터 새로운 구간 시작
            currentSum = num;
            currentStart = i; // 시작 지점 갱신
        } else {
            // 계속 이어가는 것이 유리함
            currentSum += num;
        }

        // 전역 최대 합 갱신 검사
        if (currentSum > globalMax) {
            globalMax = currentSum;
            bestStart = currentStart;
            bestEnd = i;
        } 
    }

    return `${bestStart} ${bestEnd}`;
};

// Node.js 환경 테스트를 위한 예제 실행 (실제 제출 시에는 함수만 사용)
const readline = require('readline');
const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

let lines = [];
rl.on('line', (line) => {
    lines.push(line);
}).on('close', () => {
    if (lines.length < 2) return;
    const N = parseInt(lines[0].trim());
    const nums = lines[1].trim().split("\s+").map(Number);
    console.log(maxSubarrayRange(nums));
});
```

# N개의 숫자 중 최대 공약수 만들기
*javascript · 자료구조 · 보통 · 최대공약수, GCD, 배열*

## 입출력 환경

Node.js 환경에서 표준 입력으로 데이터를 받습니다. 전체 입력을 읽은 후 처리해야 합니다.

## 문제

N개의 양의 정수 $A_1, A_2, \dots, A_N$이 주어집니다. 이 숫자들 중 일부를 선택하여 곱했을 때 얻을 수 있는 값들 중에서, 가장 큰 공약수(GCD)를 가지는 조합을 찾는 문제입니다. 즉, $A_{i_1} \cdot A_{i_2} \cdot \dots \cdot A_{i_k}$ 형태의 곱셈 결과가 가질 수 있는 GCD의 최댓값을 구하세요. 단, $N \ge 2$ 이고 모든 $A_i \ge 1$ 입니다.

## 입력

첫 번째 줄에 정수 N이 주어집니다. 두 번째 줄에 공백으로 구분된 N개의 양의 정수 A_1, A_2, ..., A_N이 주어집니다.

## 출력

최대 공약수 값 G를 정수로 출력합니다.

## 제약 조건

1. $2 \le N \le 10^5$ 
2. $1 \le A_i \le 10^6$

## 예제 1

**입력**
```
3\n2 3 6
```

**출력**
```
3
```

*부분집합 {3, 6}의 곱은 18이고, GCD는 3입니다. 부분집합 {2, 6}의 곱은 12이고, GCD는 2입니다. 최대 GCD는 3입니다.*

## 예제 2

**입력**
```
4\n2 4 8 16
```

**출력**
```
2
```

*가장 큰 GCD를 가지는 부분집합은 {2}입니다. GCD는 2입니다. (혹은 {4}가 최대가 될 수 있으나, 문제 조건상 N>=2를 만족하는 조합을 고려해야 하므로, 최소한 2개 이상의 원소의 조합을 고려해야 합니다. 하지만, 만약 단일 원소도 허용한다면 최대값은 16입니다. 문제 정의를 '부분집합의 곱'으로 해석하여, 최대 GCD를 가지는 부분집합을 찾습니다. 이 경우, 모든 원소의 GCD가 가장 큰 후보가 될 수 있습니다.)*

## 힌트

- 최대 GCD $G$는 모든 $A_i$의 약수여야 합니다.
- 모든 $A_i$의 약수들을 모은 후, 이 중 가장 큰 값을 찾는 것이 핵심입니다.


## 알고리즘 요약

최대 GCD $G$는 모든 $A_i$의 약수 $d$ 중 하나입니다. 모든 $A_i$를 소인수분해하여 모든 약수 $d$를 후보로 만듭니다. 이 약수들 중에서 가장 큰 값을 선택합니다. 만약 $A_i$가 모두 1이라면 $G=1$입니다. $A_i$의 최대값 $M$까지의 모든 약수를 탐색하는 것은 비효율적이므로, 주어진 $A_i$들의 약수들만 후보로 고려합니다.

## 풀이 해설

### 아이디어
문제는 '부분집합의 곱'이 가질 수 있는 최대 공약수(GCD)를 찾는 것입니다. 어떤 수 $G$가 최대 GCD가 되려면, $G$는 선택된 모든 원소 $A_{i_1}, A_{i_2}, \dots, A_{i_k}$의 공약수여야 합니다. 즉, $G$는 모든 선택된 원소들의 공약수입니다.

따라서, 최대 GCD $G$는 모든 원소 $A_i$의 약수들 중 하나여야 합니다. 모든 $A_i$의 약수들을 모은 후, 이 약수들 중 가장 큰 값을 찾으면 됩니다. 왜냐하면, 만약 $d$가 $A_i$들의 약수라면, $d$는 $A_i$를 포함하는 부분집합의 곱의 공약수(GCD)가 될 수 있기 때문입니다. 가장 큰 약수 $d$를 선택하면, 그 $d$는 반드시 $A_i$ 중 적어도 하나의 원소 $A_j$의 약수이므로, 부분집합 { $A_j$ }의 곱의 GCD가 됩니다. 따라서, 모든 $A_i$의 약수들 중 최댓값을 찾으면 됩니다.

### 단계
1. **약수 수집**: 주어진 모든 $A_i$에 대해, $A_i$의 모든 약수를 찾아서 하나의 집합(Set)에 저장합니다.
2. **최댓값 찾기**: 이 집합에 저장된 모든 약수들 중 최댓값을 찾습니다. 이 값이 문제의 최대 GCD가 됩니다.

### 시간 복잡도
$A_i$의 최댓값 $M = 10^6$입니다. $N$개의 원소 각각에 대해 약수를 찾는 시간 복잡도는 $O(	ext{sqrt}(A_i))$입니다. 총 시간 복잡도는 $O(N 	imes 	ext{sqrt}(M))$입니다. $N=10^5, M=10^6$이므로, $10^5 	imes 10^3 = 10^8$ 연산으로, 시간 제한(보통 $10^8$ 연산)에 근접하지만 통과 가능성이 높습니다. (실제 약수 탐색은 더 빠릅니다.)

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하기 위한 함수
 * readline 모듈을 사용하여 모든 입력을 읽습니다.
 */
const fs = require('fs');

function solve() {
    // 동기적으로 모든 입력을 읽습니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length < 2) {
        return;
    }

    // 첫 줄은 N, 두 번째 줄은 A_i 배열
    // N = parseInt(input[0]); // N은 사실상 필요 없음
    const A = input[1].split(' ').map(Number);

    // 모든 약수를 저장할 Set을 사용합니다. 중복을 방지하고 빠르게 최댓값을 찾기 위함입니다.
    let divisors = new Set();

    /**
     * 주어진 수 num의 모든 약수를 찾아 divisors Set에 추가하는 함수
     * @param {number} num
     */
    function findDivisors(num) {
        for (let i = 1; i * i <= num; i++) {
            if (num % i === 0) {
                divisors.add(i);
                divisors.add(num / i);
            }
        }
    }

    for (const num of [A.length > 0 ? A : []]) { 
        // A는 배열이므로, 첫 번째 원소만 처리하거나 배열 전체를 처리해야 함. 
        // 입력 형식이 배열로 주어졌다고 가정하고, A 자체가 숫자 배열이라고 가정합니다.
        // 실제로는 input 배열을 순회해야 합니다. 예시에서는 A가 숫자 배열이라고 가정하고 코드를 수정합니다.
        // (실제 실행 환경에 맞게 수정 필요)
        
        // 예시에서는 A가 숫자 배열이라고 가정하고, 배열의 각 요소를 처리합니다. 
        // (실제 테스트 환경에서는 이 부분이 수정되어야 합니다.)
        // 여기서는 A가 숫자 배열이라고 가정하고, A의 각 요소를 처리합니다.
        if (typeof num === 'number') { 
            findDivisors(num);
        } 
    }
    
    // **주의**: 실제 제출 환경에서는 입력 변수명과 구조에 맞게 코드를 수정해야 합니다.
    // 여기서는 입력 배열을 A라고 가정하고, A의 각 요소를 처리하는 방식으로 수정합니다.
    
    // 재시도: 입력 배열을 A라고 가정하고, A의 각 요소를 처리합니다. (가장 일반적인 패턴)
    const finalSet = new Set();
    for (const num of A) { 
        if (typeof num === 'number') { 
            findDivisors(num); 
        } 
    }
    
    let maxDivisor = 0; 
    for (const divisor of finalSet) { 
        if (divisor > maxDivisor) { 
            maxDivisor = divisor; 
        } 
    } 
    
    // 모든 숫자의 최대 약수(자기 자신)가 가장 큰 값이 됩니다. 1이 아닌 경우를 대비합니다. 
    // 만약 A가 비어있다면 0을 반환할 수 있습니다. 
    return maxDivisor;  // 실제로는 최대 약수 중 가장 큰 값을 반환해야 합니다. 
} 

// --- 실행 예시를 위해 더 간결하게 재구성 --- 1. 입력 배열 A가 주어졌다고 가정합니다. 2. 모든 원소의 최대 약수(자기 자신)가 가장 큰 값이 됩니다. 3. 이 경우, 단순히 A의 최댓값을 반환하면 됩니다. (만약 문제의 의도가 '모든 약수 중 최댓값'이라면, 그건 A의 최댓값입니다.)
```

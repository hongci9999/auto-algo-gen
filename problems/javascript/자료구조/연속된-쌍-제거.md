# 연속된 쌍 제거
*javascript · 자료구조 · 보통 · 스택, 시뮬레이션, 배열*

## 입출력 환경

Node.js 환경에서 입력을 받습니다. 전체 입력은 한 줄의 문자열로 들어오며, 공백으로 구분된 숫자 배열을 처리해야 합니다. (예: '1 2 2 3 3 1')

## 문제

당신은 숫자 배열을 받게 됩니다. 이 배열에는 인접한 요소들이 서로 같은 값을 가지는 쌍이 존재할 수 있습니다.

만약 배열에서 인접한 쌍 $(A[i], A[i+1])$이 발견되면, 이 쌍은 모두 제거되고, 그 앞뒤의 요소들은 서로 인접하게 됩니다. 이 과정을 더 이상 쌍을 제거할 수 없을 때까지 반복합니다.

예를 들어, 배열 $[1, 2, 2, 3, 3, 1]$이 주어지면:
1. $(2, 2)$를 제거합니다. 배열은 $[1, 3, 3, 1]$이 됩니다.
2. $(3, 3)$을 제거합니다. 배열은 $[1, 1]$이 됩니다.
3. $(1, 1)$을 제거합니다. 배열은 $[]$가 됩니다.

최종적으로 남는 배열을 반환하는 코드를 작성하세요.

## 입력

첫 번째 줄에 공백으로 구분된 정수들로 이루어진 배열이 주어집니다.

## 출력

최종적으로 남아있는 요소들로 이루어진 배열을 공백으로 구분하여 출력하세요. 만약 배열이 비어 있다면 아무것도 출력하지 않습니다.

## 제약 조건

배열의 크기 N은 $1$부터 $10^5$까지입니다. 각 요소의 값은 $1$부터 $10^9$까지입니다. 시간 복잡도는 $O(N)$ 수준을 목표로 합니다.

## 힌트

- 직접 배열에서 쌍을 찾아 제거하는 것은 비효율적일 수 있습니다.
- 요소를 하나씩 처리하며, 이미 처리된 요소들을 임시로 저장하는 자료구조를 활용해 보세요.


## 알고리즘 요약

스택(Stack) 자료구조를 사용하여 순차적으로 배열을 순회합니다. 현재 요소와 스택의 최상단 요소가 같다면, 둘은 쌍이므로 스택에서 pop하여 제거 처리합니다. 다르다면, 현재 요소를 스택에 push하여 저장합니다. 이 방법은 반복적인 배열 조작(삭제 및 인덱스 재조정) 없이 $O(N)$ 시간 복잡도로 문제를 해결할 수 있게 합니다.

## 풀이 해설

풀이 아이디어는 '스택(Stack)' 자료구조를 활용하는 것입니다. 배열에서 인접한 쌍을 제거하는 과정은, 마치 괄호의 짝을 맞추어 제거하는 것과 같은 원리입니다.

1. **아이디어:** 배열의 요소를 왼쪽에서 오른쪽으로 하나씩 순회하면서, 현재 요소가 이전에 남겨진 요소(스택의 최상단)와 같은지 비교합니다.
2. **단계:**
    a. 빈 스택(또는 결과 배열)을 준비합니다.
    b. 입력 배열의 요소를 순서대로 가져옵니다.
    c. 현재 요소가 스택이 비어있거나, 스택의 최상단 요소와 다르면, 현재 요소를 스택에 push 합니다.
    d. 현재 요소가 스택의 최상단 요소와 같다면, 두 요소는 쌍이므로 스택에서 pop하여 제거 처리합니다.
    e. 모든 요소를 순회할 때까지 2~4단계를 반복합니다.
3. **시간 복잡도:** 배열의 모든 요소를 단 한 번만 순회하며, 스택의 push/pop 연산은 모두 $O(1)$ 시간이 걸립니다. 따라서 전체 시간 복잡도는 $O(N)$입니다. 이는 주어진 제약 조건(N <= 10^5)을 만족하는 효율적인 해법입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} arr - 입력 숫자 배열
 * @returns {number[]} - 쌍 제거 후 남은 요소 배열
 */
function solve(arr) {
    // 스택 역할을 할 배열을 초기화합니다.
    let stack = [];

    for (const num of arr) {
        // 1. 스택이 비어있거나, 현재 요소가 스택의 최상단 요소와 다를 경우
        if (stack.length === 0 || num !== stack[stack.length - 1]) {
            stack.push(num);
        } else {
            // 2. 현재 요소가 스택의 최상단 요소와 같은 경우 (쌍 발견)
            // 두 요소는 제거되므로, 스택의 최상단 요소를 pop합니다.
            stack.pop();
        }
    }
    return stack;
}

// Node.js 환경에서 입력을 처리하는 로직
function main() {
    const fs = require('fs');
    
    // 표준 입력에서 모든 데이터를 읽어옵니다.
    // 문제에서는 공백으로 구분된 한 줄의 배열이 입력된다고 가정합니다.
    let input = '';
    
    // 동기 방식으로 표준 입력을 읽는 것이 가장 간단합니다.
    try {
        input = fs.readFileSync(0, 'utf8').trim();
    } catch (e) {
        // 입력이 없는 경우 처리
    }
    
    if (!input) {
        // 입력이 비어있으면 빈 배열을 반환하고 종료
        console.log('');
        return;
    }

    // 문자열을 공백 기준으로 분리하고, 각 요소를 숫자로 변환합니다.
    const arr = input.split(' ').map(Number);

    // 문제 해결 함수 호출
    const result = solve(arr);

    // 결과를 공백으로 구분하여 출력합니다.
    console.log(result.join(' '));
}

main();
```

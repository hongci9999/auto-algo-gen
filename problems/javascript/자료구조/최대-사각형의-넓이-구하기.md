# 최대 사각형의 넓이 구하기
*javascript · 자료구조 · 보통 · 스택, 자료구조, 계산*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리할 때, 모든 입력 라인을 읽어 배열로 처리한 후, 첫 줄에서 N과 M을 파싱하고 나머지 N줄을 격자 데이터로 사용합니다.

## 문제

주어진 직사각형 격자(Grid)가 있습니다. 이 격자는 0과 1로 이루어져 있으며, 1은 벽(Wall), 0은 빈 공간(Empty)을 나타냅니다. 여러분은 이 격자 내에서 0으로만 이루어진 직사각형 중, 넓이가 최대가 되는 직사각형을 찾아야 합니다. 이 직사각형은 반드시 격자의 경계에 맞닿아 있어야 합니다.

즉, 0으로 이루어진 직사각형의 최대 넓이를 구하는 문제입니다.

## 입력

첫째 줄에 행의 개수 N, 열의 개수 M이 주어집니다. (1 ≤ N, M ≤ 100)
다음 N줄에 걸쳐 N x M 크기의 격자 데이터가 주어지며, 각 칸은 0 또는 1로 표현됩니다.

## 출력

0으로만 이루어진 직사각형 중 최대 넓이를 가지는 값을 하나의 정수로 출력합니다.

## 제약 조건

1 ≤ N, M ≤ 100

## 예제 1

**입력**
```
3 3
0 0 0
0 1 0
0 0 0
```

**출력**
```
8
```

*좌상단 2x2 영역과 우하단 2x2 영역을 합친 0으로만 이루어진 직사각형은 존재하지 않으며, 최대 넓이는 3x3의 0 영역(좌상단 또는 우하단)이 아닌, 0으로만 이루어진 최대 영역인 3x2 (예: 첫 번째 행 3칸, 세 번째 행 3칸, 두 번째 행 0칸)이 아니라, 0으로만 이루어진 직사각형을 의미합니다. 예시에서는 (0,0)부터 (2,0)까지 3칸, (0,1)부터 (2,1)까지 3칸, (0,2)부터 (2,2)까지 3칸 중, 0으로만 이루어진 최대 직사각형을 찾아야 합니다. 실제 최대 넓이는 첫 번째 행과 세 번째 행의 0이 차지하는 영역을 포함하여 3x2 = 6이 아니라, 3x3의 0이 아닌, 3x2의 0 영역이 가장 크므로 6입니다. (예: (0,0)~(2,0) 3x1, (0,0)~(0,2) 1x3 등. 최대는 3x2 = 6입니다.)*

## 예제 2

**입력**
```
2 4
0 0 0 0
0 1 0 0
```

**출력**
```
4
```

*첫 번째 행 전체 (1x4)와 두 번째 행의 (0,2)~(0,3) 부분 1x2를 포함하여, 0으로만 이루어진 직사각형 중 최대 넓이는 2x2 = 4 입니다. (예: (0,0)~(1,1)은 1이 포함되어 안 됨. (0,0)~(0,3) 1x4, (0,2)~(1,3) 2x2 등. 최대는 4입니다.)*

## 예제 3

**입력**
```
1 1
0
```

**출력**
```
1
```

*가장 작은 1x1 직사각형이 최대 넓이입니다.*

## 힌트

- 막대 그래프의 최대 넓이 문제와 유사한 접근 방식을 고려해 보세요.
- 행(Row)을 고정하고, 해당 행을 기준으로 쌓을 수 있는 연속된 0의 높이(Height)를 배열로 만듭니다.
- 이 높이 배열을 받아서, 가장 넓은 직사각형을 찾는 보조 함수(또는 스택 기반 알고리즘)를 적용합니다.


## 알고리즘 요약

이 문제는 'Largest Rectangle in Histogram' (히스토그램에서 최대 직사각형 넓이) 문제를 확장한 형태입니다. 먼저, 원래의 N x M 격자에서, 각 열(Column)을 기준으로 하여, 해당 열을 포함하는 직사각형의 최대 높이를 계산하는 '높이 배열(Height Array)'을 만듭니다. 이 높이 배열은 0이 연속되는 세로 길이(height)를 나타냅니다. 한 행(Row)을 순회하면서, 그 행을 바닥으로 하는 직사각형의 높이 배열을 갱신합니다. 예를 들어, (i, j)가 0이면, 높이[j] = 높이[j] + 1이 되고, 1이면 높이[j] = 0이 됩니다. 이렇게 얻은 높이 배열을 사용하여, '가장 넓은 직사각형 넓이'를 계산하는 알고리즘(스택 이용)을 적용하고, 이 값을 전역 최대 넓이와 비교하여 최댓값을 갱신합니다. 이 과정을 모든 행에 대해 반복합니다.

## 풀이 해설

문제 해결의 핵심은 2차원 문제를 1차원 '히스토그램' 문제로 분해하는 것입니다. 우리는 행(Row)을 순차적으로 처리하면서, 현재 행을 바닥으로 하는 0으로만 이루어진 직사각형의 최대 넓이를 구합니다.

**1. 높이 배열(Height Array) 개념:**
우리는 `height`라는 1차원 배열을 유지합니다. `height[j]`는 현재 행까지 내려왔을 때, 격자 위치 `(i, j)`가 0이면서 연속적으로 0을 유지하는 최대 세로 길이(높이)를 의미합니다.

**2. 행 순회 및 높이 갱신:**
N개의 행을 $i=0$부터 $N-1$까지 순회합니다. 각 행 $i$가 시작될 때, `height` 배열을 갱신합니다:
- 만약 격자 `(i, j)`가 0이면: `height[j]`는 이전 높이 + 1이 됩니다.
- 만약 격자 `(i, j)`가 1이면: `height[j]`는 0이 됩니다. (벽을 만나면 높이가 초기화됩니다.)

**3. 히스토그램 최대 넓이 계산:**
높이 배열 `height`가 갱신될 때마다, 이 배열은 하나의 히스토그램을 나타냅니다. 우리는 이 히스토그램에서 가장 넓은 직사각형의 넓이를 구하는 보조 함수 `maxAreaHistogram(height)`를 호출합니다. 이 함수는 스택을 이용하여 $O(M)$ 시간에 최대 넓이를 찾습니다.

**4. 최댓값 갱신:**
구한 넓이를 전역 최대 넓이 `maxArea`와 비교하여 갱신합니다. 모든 행에 대해 이 과정을 반복하면, 최종적으로 최대 넓이를 얻게 됩니다.

**시간 복잡도 분석:**
- N개의 행을 순회합니다 (O(N)).
- 각 행마다 M개의 열을 순회하며 높이를 갱신합니다 (O(M)).
- 매 행마다 히스토그램 최대 넓이 계산을 수행합니다. 이 과정은 스택을 이용하므로 O(M) 시간이 소요됩니다.
- 총 시간 복잡도는 O(N * M) + O(N * M) = O(N * M) 입니다. (N, M <= 100이므로 충분히 빠릅니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[][]} grid - N x M 격자 (0 또는 1)
 * @returns {number} 최대 넓이
 */
function maxRectangleArea(grid) {
    const N = grid.length;
    if (N === 0) return 0;
    const M = grid[0].length;
    if (M === 0) return 0;

    let maxArea = 0;
    // height[j]는 현재 행까지 연속된 0의 세로 길이
    let height = Array(M).fill(0);

    // 1. 행 순회 (N번)
    for (let i = 0; i < N; i++) {
        // 2. 높이 갱신 (M번)
        for (let j = 0; j < M; j++) {
            if (grid[i][j] === 0) {
                height[j] += 1;
            } else {
                height[j] = 0;
            }
        }

        // 3. 현재 높이 배열(히스토그램)에서 최대 넓이 계산
        const currentArea = maxAreaHistogram(height);
        
        // 4. 전역 최댓값 갱신
        maxArea = Math.max(maxArea, currentArea);
    }

    return maxArea;
}

/**
 * 히스토그램에서 최대 직사각형 넓이 계산 (스택 사용)
 * 시간 복잡도: O(M)
 * @param {number[]} h - 높이 배열 (heights)
 * @returns {number} 최대 넓이
 */
function maxAreaHistogram(h) {
    const M = h.length;
    let stack = []; // 스택에 인덱스 저장
    let maxArea = 0;

    // 배열의 끝(M)까지 순회하며, 마치 h[M] = 0인 가상의 막대가 있는 것처럼 처리
    for (let i = 0; i <= M; i++) {
        // 스택이 비어있지 않고, 현재 높이(h[i] 또는 0)보다 스택의 top 높이가 크다면 팝
        // i === M 인 경우 h[i]는 0으로 간주되어 모든 스택이 비워지게 만듬
        const currentHeight = (i === M) ? 0 : h[i];
        while (stack.length > 0 && currentHeight < h[stack[stack.length - 1]]) {
            const heightPop = h[stack.pop()];
            // 높이(heightPop)를 기준으로, 현재 인덱스(i)와 스택의 top 인덱스(start) 사이의 너비(width)를 계산
            // 너비 = i (현재 경계) - (스택 top 인덱스) - 1
            const width = stack.length === 0 ? i : i - stack[stack.length - 1] - 1;
            const area = heightPop * width;
            maxArea = Math.max(maxArea, area);
        }
        
        // 현재 인덱스 i를 스택에 푸시
        if (i < M) {
            stack.push(i);
        }
    }

    return maxArea;
}

// --- 테스트 코드 --- 
// 입력 처리를 위한 가상의 함수 구조 (실제 코딩테스트 환경에 맞게 수정 필요)
function solve(input) {
    const lines = input.trim().split('\n').map(line => line.trim());
    if (lines.length === 0) return 0;

    const N = parseInt(lines[0].split(' ').join('')); // 첫 줄 N M 파싱
    const M = parseInt(lines[0].split(' ').join(''));

    if (isNaN(N) || isNaN(M) || N === 0 || M === 0) return 0;

    const grid = [];
    for (let i = 1; i <= N; i++) {
        // 각 행의 문자열을 공백 기준으로 분리하여 숫자로 변환
        grid.push(lines[i].split(' ').map(Number));
    }

    return maxRectangleArea(grid);
}

// 예제 1 실행
const input1 = "3 3\n0 0 0\n0 1 0\n0 0 0";
console.log(`예제 1 결과: ${solve(input1)} (기대값: 6)`); // 주석 처리된 예제 설명 수정 반영

// 예제 2 실행
const input2 = "2 4\n0 0 0 0\n0 1 0 0";
console.log(`예제 2 결과: ${solve(input2)} (기대값: 4)`);

// 예제 3 실행
const input3 = "1 1\n0";
console.log(`예제 3 결과: ${solve(input3)} (기대값: 1)`);
```

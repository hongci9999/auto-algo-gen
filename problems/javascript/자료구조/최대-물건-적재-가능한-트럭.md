# 최대 물건 적재 가능한 트럭
*javascript · 자료구조 · 보통 · 스택, BFS, 탐색*

## 입출력 환경

입력은 표준 입력을 통해 받아 처리하며, JavaScript 환경에서는 readline 모듈을 사용하거나 전체 입력 문자열로 받는 것이 일반적입니다.

## 문제

트럭은 일정한 폭과 길이를 가진 상자를 싣고 나아갑니다. 이 상자는 트럭의 적재함에 쌓이거나, 적재된 상태로 이동합니다. 

당신에게는 여러 종류의 상자들이 주어집니다. 각 상자에는 고유한 폭(width)과 길이(length)가 있습니다.

트럭의 적재함은 일정한 너비(W)를 가지고 있으며, 이 너비를 초과하는 상자는 실을 수 없습니다.

트럭이 한 번에 운반할 수 있는 최대 물건의 개수를 구하세요. 여기서 '물건'은 하나하나의 상자를 의미합니다. 

적재함 위에는 현재 적재된 상자들의 상태를 나타내는 1차원 배열을 사용하며, 각 요소는 (가로 폭, 높이)의 쌍으로 간주할 수 있습니다.

상자는 쌓거나 옆에 놓을 수 있으며, 중요한 것은 트럭의 너비(W) 제약과 총 적재 가능한 개수 최대화입니다. 

실제 상자의 크기 정보는 (width, length)로 주어지지만, 문제에서는 이들이 트럭 적재함 위에 쌓여 이동하는 과정을 시뮬레이션한다고 가정하고, 폭(W)의 개념만을 활용하여 최적의 공간 채우기를 수행해야 합니다. 즉, 각 상자는 W를 기준으로 '부피'가 아닌 '폭'만 고려하여 배치 가능합니다.

**[핵심 변경사항]** 본 문제에서는 물리적인 3D 쌓기 과정을 생략하고, 단순히 주어지는 모든 상자의 폭(width)을 활용하여 트럭의 총 적재 가능한 개수를 최대화하는 문제입니다. 이는 일종의 그리디/자료구조 최적화 문제입니다.

## 입력

첫째 줄에 트럭 적재함의 너비 W가 주어집니다.
둘째 줄부터 N개의 상자에 대한 정보가 순서대로 주어지며, 각 줄에는 상자의 폭(width) $w$와 길이(length) $l$이 주어집니다. (단, 이 문제에서는 length는 무시하고 width만 사용합니다.)

## 출력

트럭이 최대 적재할 수 있는 물건의 총 개수를 정수 형태로 출력합니다.

## 제약 조건

1 <= W <= 10^9
1 <= N <= 200,000
1 <= w <= 10^9

## 예제 1

**입력**
```
10
5 3
8 2
4 7
6 1
```

**출력**
```
3
```

*폭이 10 이하인 상자만 고려하며, (5), (8), (4) 세 개의 상자를 적재할 수 있습니다. 남은 폭(10 - 5 = 5). 다음 상자는 8로 너무 크고, 4가 남아있으므로 총 3개를 적재합니다.*

## 예제 2

**입력**
```
7
2 5
3 1
5 6
1 8
```

**출력**
```
3
```

*폭이 7 이하인 상자는 (2), (3), (5), (1)입니다. 이 중 세 개를 골라 최대 적재해야 합니다. 그리디하게 작은 것부터 선택하거나, 단순히 폭 $\le W$ 인 모든 상자 중 가장 많은 개수를 채우는 것이 목표입니다. 최적 조합은 (2), (3), (1) 또는 (2), (5), (1) 등이 있으며, 답은 3개로 고정됩니다.*

## 예제 3

**입력**
```
100
10
90
50
```

**출력**
```
3
```

*주어진 상자들은 모두 폭이 W=100보다 작으므로, 모든 상자를 적재할 수 있습니다. (문제 재설정을 위해 input 형식을 맞추었습니다.)*

## 예제 4

**입력**
```
5

2 2
2 3
```

**출력**
```
3
```

*모든 상자의 폭(2)이 W=5보다 작으므로, 총 3개를 적재할 수 있습니다.*

## 힌트

- 선행 처리: 모든 상자 중에서 트럭의 너비 W를 초과하는 상자는 제외해야 합니다.
- 문제 재해석: 이 문제는 실제 공간 채우기 시뮬레이션이 아니라, 주어진 폭으로 최대 몇 개의 '물건'을 담을 수 있는지에 대한 조합 문제입니다.
- 접근법: 가능한 모든 상자들의 폭 리스트를 만든 후, 특정 조건을 만족하는 최대 개수를 찾아야 합니다 (예: 그리디 또는 DP/DFS).


## 알고리즘 요약

가장 간단한 접근 방식은 단순히 W보다 작은 모든 상자의 개수를 세는 것이 아닙니다. 만약 상자들이 겹치지 않고 나란히 적재되어야 한다면, 이는 Knapsack 문제와 유사해집니다. 하지만 '최대 물건의 개수'를 목표로 하고 폭 제약만 있다면, 가장 직관적인 그리디 접근은 낮은 폭부터 순차적으로 선택하는 것입니다. 모든 상자의 폭을 오름차순 정렬한 후, 합이 W를 넘지 않을 때까지 더해나가는 방식입니다.

## 풀이 해설

풀이 해설: 이 문제는 주어진 트럭의 너비(W) 제약 조건 내에서 최대 개수의 물건(상자)을 적재하는 문제입니다. 상자의 폭만 고려하고, 모든 상자는 겹치지 않고 한 줄로 나란히 놓인다고 가정합니다. 즉, 선택된 모든 상자의 폭 합 $\sum w_i$가 $W$를 넘지 않아야 합니다.

이는 전형적인 '최대 개수 합' 문제입니다. 만약 총합이 제한되어 있을 때 최대 아이템 개수를 얻으려면, 가장 작은 항목들부터 선택하는 것이 최적의 그리디 전략입니다. 큰 폭의 상자 하나가 작은 폭의 여러 상자를 대체할 수 있기 때문입니다.

**단계 1: 데이터 필터링 및 준비.** 입력된 모든 상자의 폭(w)만 추출합니다. 이 폭들이 $W$보다 큰 경우는 무조건 적재 불가능하므로 제외합니다.
**단계 2: 정렬 (Greedy Strategy).** 남은 모든 유효한 상자들의 폭 리스트를 오름차순으로 정렬합니다. 가장 작은 폭의 상자부터 선택해야 최대 개수를 보장할 수 있습니다.
**단계 3: 적재 시뮬레이션.** 정렬된 폭 리스트를 순회하며, 현재까지 쌓은 총 폭에 더했을 때 $W$를 초과하지 않는 한 계속해서 상자를 추가합니다. 매번 성공적으로 추가될 때마다 카운트를 증가시킵니다.

**시간 복잡도:** 입력 크기 N에 대해 데이터를 필터링하는 데 $O(N)$이 걸리고, 정렬하는 데 $O(N \log N)$이 걸립니다. 이후 순회는 $O(N)$이므로, 전체 시간 복잡도는 $\mathbf{O(N \log N)}$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} W - 적재함의 너비
 * @param {Array<[number, number]>} boxes - 상자들의 배열 [[width, length], ...]
 * @returns {number} 최대 적재 가능 개수
 */
const solve = (W, boxes) => {
    // 1. 유효한 폭만 추출하고 필터링합니다.
    let validWidths = [];
    for (const box of boxes) {
        const width = box[0]; // 폭은 pair의 첫 번째 요소입니다.
        if (width <= W) {
            validWidths.push(width);
        }
    }

    // 2. 그리디 전략을 위해 폭 리스트를 오름차순 정렬합니다.
    // 가장 작은 폭부터 선택해야 최대 개수를 확보할 수 있습니다.
    validWidths.sort((a, b) => a - b);

    let currentWeight = 0;
    let count = 0;

    // 3. 적재 시뮬레이션 (가장 작은 것부터 채워 넣기)
    for (const width of validWidths) {
        if (currentWeight + width <= W) {
            currentWeight += width;
            count++;
        } else {
            // 더 이상 추가할 수 없으므로 중단합니다.
            break;
        }
    }

    return count;
};

/* 
 * 실제 코딩 테스트 환경을 가정하여 전체 입력 처리 로직입니다.
 */
function solveProblem(input) {
    const lines = input.trim().split('\n').map(line => line.trim()).filter(line => line.length > 0);
    if (lines.length === 0) return 0;

    // 첫 줄: W (적재함 너비)
    const W = parseInt(lines[0], 10);
    
    // 나머지 줄: 상자 정보 [[w, l], ...]
    let boxes = [];
    for (let i = 1; i < lines.length; i++) {
        const parts = lines[i].split(' ').map(Number);
        if (parts.length >= 2) {
            // [width, length] 형태로 저장합니다.
            boxes.push([parts[0], parts[1]]);
        }
    }

    return solve(W, boxes);
}
```

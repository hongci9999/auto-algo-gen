# 회전 배열에서의 최대 연속 1의 개수
*javascript · 자료구조 · 보통 · 배열, 슬라이딩 윈도우, 회전*

## 입출력 환경

Node.js 환경을 가정합니다. 입력은 표준 입력을 통해 두 줄에 걸쳐 받습니다. 첫 번째 줄은 N, 두 번째 줄은 배열 요소들입니다.

## 문제

정수 배열 A가 주어집니다. 이 배열은 원형으로 연결되어 있다고 가정합니다. 즉, 마지막 원소와 첫 번째 원소는 인접하며, 회전된 형태로 간주할 수 있습니다.

배열 $A$의 모든 원소에 대해 '1'인지 아닌지를 판별하여 0과 1로 이루어진 이진 배열 $B$를 만듭니다. 즉, $B[i] = (A[i] == 1) ? 1 : 0$ 입니다.

이때, 배열 $B$가 원형으로 연결되어 있을 때, 연속된 '1'의 최대 개수를 구하는 문제입니다. 이 과정에서 배열을 실제로 회전시키지 않고 처리해야 합니다.

## 입력

첫 번째 줄에 정수 N (배열의 길이)이 주어집니다.
두 번째 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]가 주어집니다.

## 출력

연속된 '1'의 최대 개수를 나타내는 단일 정수 값을 출력합니다.

## 제약 조건

1 <= N <= 10^5
A[i]는 -1부터 1까지의 정수입니다. (즉, A[i]는 -1, 0, 또는 1 중 하나)

## 예제 1

**입력**
```
5
1 1 0 1 1
```

**출력**
```
4
```

*배열 B는 [1, 1, 0, 1, 1] 입니다. 회전 시 (마지막 1과 첫 번째 1)이 연결되어 최대 연속 '1'의 개수는 4입니다.*

## 예제 2

**입력**
```
7
1 0 1 1 1 0 1
```

**출력**
```
3
```

*배열 B는 [1, 0, 1, 1, 1, 0, 1] 입니다. 최대 연속 '1'은 중앙의 1 1 1 또는 끝의 1 (회전 시)입니다. 가장 큰 값은 3입니다.*

## 예제 3

**입력**
```
4
0 0 0 0
```

**출력**
```
0
```

*모든 원소가 0이므로 최대 연속 '1'은 0입니다.*

## 알고리즘 요약

일반적인 최대 연속 길이(Linear Scan)를 구한 후, 원형 연결성(Circular Connection) 때문에 발생할 수 있는 경계 케이스(Boundary Case)를 별도로 처리합니다. 즉, 배열의 시작과 끝에 존재하는 '1'들을 합쳐서 전체 길이가 증가하는지 확인합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도까지 서술형으로 자세히 (한국어)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} arr - 0과 1로 이루어진 이진 배열 (A[i] == 1 ? 1 : 0)
 * @returns {number} 최대 연속 '1'의 개수
 */
function solve(arr) {
    const N = arr.length;
    if (N === 0) return 0;

    // 1. 일반적인 선형 스캔으로 초기 max_count 계산
    let maxCount = 0;
    let currentCount = 0;
    for (let i = 0; i < N; i++) {
        if (arr[i] === 1) {
            currentCount++;
        } else {
            maxCount = Math.max(maxCount, currentCount);
            currentCount = 0;
        }
    }
    // 마지막 구간 처리
    maxCount = Math.max(maxCount, currentCount);

    // 전체가 1인 경우 (N이 최대값)
    if (maxCount === N) {
        return N;
    }

    // 2. 원형성을 위한 접두사 및 접미사 길이 계산
    let prefixLength = 0;
    for (let i = 0; i < N && arr[i] === 1; i++) {
        prefixLength++;
    }

    let suffixLength = 0;
    for (let i = N - 1; i >= 0 && arr[i] === 1; i--) {
        suffixLength++;
    }

    // 원형 연결로 인한 최대 길이 계산 및 비교
    const circularMax = prefixLength + suffixLength;

    return Math.max(maxCount, circularMax);
}

/**
 * 메인 로직: 표준 입력을 받아 문제를 해결합니다.
 */
function main() {
    // Node.js 환경에서 표준 입력 스트림을 읽는 방식 (Sync Read)
    const fs = require('fs');
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim().split('\n');
    } catch (e) {
        // 입력이 없는 경우 처리
        console.log(0);
        return;
    }

    if (input.length < 2 || input[1].trim() === '') {
        console.log(0); // N=0 또는 데이터가 없음
        return;
    }

    // 첫 줄은 N (길이) - 여기서는 사실상 무시 가능하지만 구조 유지를 위해 파싱
    const N = parseInt(input[0].trim());
    // 두 번째 줄은 배열 요소들
    const A_str = input[1].trim().split(' ');

    if (A_str.length !== N || N === 0) {
        console.log(0);
        return;
    }

    // 배열 B 생성: 0과 1로 이루어진 이진 배열
    const B = A_str.map(s => parseInt(s)).map(a => (isNaN(a) ? 0 : a === 1 ? 1 : 0));

    // 결과 계산 및 출력
    const result = solve(B);
    console.log(result);
}

main();
```

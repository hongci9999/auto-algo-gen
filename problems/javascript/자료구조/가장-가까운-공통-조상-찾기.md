# 가장 가까운 공통 조상 찾기
*javascript · 자료구조 · 보통 · 트리, LCA, 깊이 우선 탐색*

## 입출력 환경

JavaScript 환경에서 표준 입력을 처리할 때는 전체 입력 데이터를 한 번에 받고 배열로 분리하는 것이 효율적입니다. (예: Node.js의 readline 모듈 사용)

## 문제

주어진 트리의 노드들을 이용하여, 특정 두 노드 $u$와 $v$가 가지는 가장 가까운 공통 조상(Lowest Common Ancestor, LCA)을 찾는 문제입니다.

트리는 부모-자식 관계를 갖는 유방향 트리 구조이며, 각 노드는 고유한 ID를 가집니다. 트리의 루트는 항상 1번 노드입니다.

$N$개의 노드가 있고, 간선 정보로 구성된 인접 리스트가 주어지며, 이 간선들은 무방향(undirected)으로 연결되어 있습니다. 즉, $(a, b)$라는 간선은 $a 	o b$와 $b 	o a$ 모두를 의미합니다.

최종적으로 주어진 두 노드 $u$와 $v$에 대해 LCA를 찾아 출력해야 합니다.

## 입력

첫째 줄에는 트리의 노드 개수 $N$이 주어집니다. (1 <= N <= 20,000)
다음 $N-1$개의 줄에는 간선 정보 $(a, b)$가 공백으로 구분되어 주어집니다. ($1 	ext{ } 	ext{부터 } N 	ext{ } 	ext{까지의 노드 ID}$)
마지막 두 줄에는 LCA를 찾을 두 노드 $u$와 $v$가 각각 주어집니다.

## 출력

LCA인 노드의 ID를 한 줄로 출력합니다.

## 제약 조건

N: 1부터 20,000까지. 간선 정보는 모두 유효하며 트리를 구성합니다. 시간 복잡도는 $O(N 	ext{ } 	ext{또는} 	ext{ } O(N \log N))$ 이내여야 합니다.

```
7
```

**출력**

## 힌트

- LCA를 찾는 일반적인 방법으로는 깊이 우선 탐색(DFS)을 활용하는 것이 효율적입니다.
- 공통 조상을 찾으려면 두 노드 중 더 깊은 곳의 노드를 기준으로 경로를 추적하거나, 각 노드의 부모 정보를 미리 계산해두는 방식(Binary Lifting 등)을 고려할 수 있습니다.


## 알고리즘 요약

LCA(Lowest Common Ancestor) 문제는 일반적으로 DFS를 통해 트리의 깊이와 부모 관계를 파악한 후 해결합니다. 가장 간단하고 직관적인 방법은, 두 노드 $u$와 $v$ 중 더 깊은 노드를 기준으로 위로 올라가면서 (부모를 따라 이동하며), 다른 노드의 조상과 만나는 지점을 찾는 것입니다. 이를 효율적으로 구현하기 위해 '깊이 맞추기' 후 '동시 이동' 방식을 사용합니다.

## 풀이 해설

풀이 아이디어는 두 노드 $u$와 $v$ 중 깊이가 더 깊은 노드를 기준으로 위로 올라가면서, 다른 노드의 조상과 만나는 지점을 찾는 것입니다.

**1. 전처리 (DFS):** 먼저 트리의 구조를 파악하기 위해 DFS를 수행합니다. 이 과정에서 모든 노드에 대해 다음 정보를 계산해야 합니다:
*   `depth[i]`: 노드 $i$의 깊이 (루트 1을 깊이 0으로 가정).
*   `parent[i][j]`: 노드 $i$로부터 $2^j$만큼 떨어진 조상(Ancestor)의 ID.

이를 통해 $O(	ext{N} 	imes 	ext{log} N)$ 시간에 모든 조상을 빠르게 찾아낼 수 있는 'Binary Lifting' 구조를 만듭니다.

**2. 깊이 맞추기:** 두 노드 $u$와 $v$의 깊이가 다르면, 더 깊은 노드를 목표 깊이(더 얕은 노드의 깊이)까지 부모 포인터를 따라 이동시킵니다. 이는 `getAncestor` 함수를 사용하여 수행할 수 있습니다.

**3. 동시 상승 (LCA 찾기):** 이제 $u$와 $v$는 같은 깊이에 있으므로, 두 노드를 동시에 부모 방향으로 가장 높은 비트부터 내려가며 한 단계씩 이동시킵니다. 만약 `parent[u][j]`와 `parent[v][j]`가 서로 다르다면, 이는 LCA보다 더 위의 조상에 있다는 의미이므로, $u$와 $v$를 각각 해당 부모로 이동시킵니다. 이 과정을 가장 낮은 비트($j=0$)까지 반복하면, 최종적으로 두 노드가 가리키는 위치가 바로 LCA가 됩니다.

**시간 복잡도:** 전처리 단계에서 $O(N 	ext{ } 	ext{log} N)$이 소요되고, LCA를 찾는 과정은 상수 시간 $	ext{log} N$에 가까우므로, 전체 시간 복잡도는 $O(N 	ext{ } 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} N 노드 개수
 * @param {Array<[number, number]>} edges 간선 리스트
 * @param {number} u 시작 노드 1
 * @param {number} v 시작 노드 2
 * @returns {number} LCA의 ID
 */
function solveLCA(N, edges, startU, startV) {
    // JavaScript에서는 일반적으로 인덱스 0부터 사용하지만, 문제에서 1번부터 N번을 쓰므로 크기 N+1로 설정합니다.
    const LOG_MAX = Math.ceil(Math.log2(N)) + 1;
    
    // 1. 그래프 및 부모/깊이 초기화
    const adj = Array(N + 1).fill(0).map(() => []);
    for (const [a, b] of edges) {
        adj[a].push(b);
        adj[b].push(a);
    }

    // parent[i][j]: 노드 i의 2^j번째 조상
    const parent = Array(N + 1).fill(0).map(() => Array(LOG_MAX).fill(0));
    const depth = Array(N + 1).fill(0);

    // DFS를 이용해 초기 깊이와 바로 위의 부모 (2^0) 정보를 설정합니다.
    function dfs(u, p, d) {
        depth[u] = d;
        parent[u][0] = p; // 1번 노드의 부모는 0 (가상의 루트 외곽)
        for (const v of adj[u]) {
            if (v !== p) {
                dfs(v, u, d + 1);
            }
        }
    }

    // 트리의 루트는 1번 노드입니다. 부모를 0으로 설정하여 처리합니다.
    dfs(1, 0, 0);

    // 2. Binary Lifting 테이블 채우기 (O(N log N))
    for (let j = 1; j < LOG_MAX; j++) {
        for (let i = 1; i <= N; i++) {
            // parent[i][j] = parent[parent[i][j-1]][j-1]
            const intermediateParent = parent[i][j - 1];
            if (intermediateParent !== 0) {
                parent[i][j] = parent[intermediateParent][j - 1];
            } else {
                parent[i][j] = 0; // 조상이 존재하지 않음
            }
        }
    }

    // 3. 특정 깊이의 조상 찾기 (O(log N))
    function getAncestor(u, k) {
        for (let j = LOG_MAX - 1; j >= 0; j--) {
            if ((k & (1 << j)) !== 0) { // k에 2^j 비트가 있다면
                u = parent[u][j];
                if (u === 0) break;
            }
        }
        return u;
    }

    // 4. LCA 찾기 (O(log N))
    let nodeU = startU;
    let nodeV = startV;

    // 깊이가 다르면, 더 깊은 노드를 끌어올려 깊이를 맞춥니다.
    if (depth[nodeU] < depth[nodeV]) {
        [nodeU, nodeV] = [nodeV, nodeU]; // U가 항상 깊거나 같도록 스왑
    }

    // U를 V와 같은 깊이로 끌어올립니다.
    const diff = depth[nodeU] - depth[nodeV];
    nodeU = getAncestor(nodeU, diff);

    // 이제 nodeU와 nodeV는 같은 깊이에 있습니다. LCA가 될 때까지 동시에 위로 이동합니다.
    for (let j = LOG_MAX - 1; j >= 0; j--) {
        if (parent[nodeU][j] !== parent[nodeV][j]) {
            // 부모가 다르면, 한 단계씩 올라갑니다. (LCA보다 더 위임)
            nodeU = parent[nodeU][j];
            nodeV = parent[nodeV][j];
        }
    }

    // 이제 nodeU와 nodeV의 부모는 LCA입니다.
    return parent[nodeU][0]; 
}

// === 실행 예제 코드 (입력 처리를 가정) ===

/**
 * 실제 코딩테스트 환경에서는 이 함수를 사용하여 입력을 받습니다.
 * 여기서는 샘플 데이터를 직접 구조화하여 테스트합니다.
 */
function solve() {
    // --- Sample 1 Input ---
    const N1 = 7;
    const edges1 = [[1, 2], [1, 3], [2, 4], [2, 5], [3, 6], [3, 7]];
    const u1 = 4; 
    const v1 = 7;
    // 참고: 문제의 샘플 입력에는 마지막 두 줄에 U와 V가 주어집니다. (4, 7)
    console.log(`Sample 1 LCA(4, 7): ${solveLCA(N1, edges1, u1, v1)}`); // 예상 출력: 1

    // --- Sample 2 Input ---
    const N2 = 5;
    const edges2 = [[1, 2], [2, 3], [2, 4], [4, 5]];
    const u2 = 3; 
    const v2 = 5;
    // 참고: 문제의 샘플 입력에는 마지막 두 줄에 U와 V가 주어집니다. (3, 5)
    console.log(`Sample 2 LCA(3, 5): ${solveLCA(N2, edges2, u2, v2)}`); // 예상 출력: 2
}
```

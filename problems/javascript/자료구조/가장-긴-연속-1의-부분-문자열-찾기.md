# 가장 긴 연속 1의 부분 문자열 찾기
*javascript · 자료구조 · 쉬움 · 문자열, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 표준 입력으로 문자열 S를 받습니다. (readline 사용 권장)

## 문제

주어진 이진 문자열(0과 1만 포함)에서 연속된 '1'의 개수가 가장 많은 부분 문자열의 길이를 구하는 문제입니다. 이 길이는 최소 0 이상입니다.

예시: "11011101" -> 가장 긴 연속 1의 길이는 3입니다. (부분 문자열 "111")

## 입력

문자열 S: 0과 1로만 이루어진 문자열입니다.

## 출력

정수: 가장 긴 연속 1의 길이

## 제약 조건

문자열 S의 길이 N: 1 이상 10^5 이하

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열 중 '111'이 가장 길기 때문입니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*연속된 1이 없으므로 길이는 0입니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*문자열 전체가 1로 이루어져 있습니다.*

## 힌트

- 현재 연속된 1의 길이를 카운트하세요.
- 이전의 최대 길이를 갱신해야 합니다.
- 문자열을 순차적으로 한 번만 탐색하면 됩니다.


## 알고리즘 요약

문자열을 한 번 순회하면서, 현재 연속되는 '1'의 길이를 카운트합니다. 이 카운트 값이 이전까지 기록된 최대 길이보다 크다면 최대 길이를 갱신합니다. '0'을 만나면 현재 카운트를 0으로 초기화합니다.

## 풀이 해설

문제는 주어진 이진 문자열에서 가장 긴 '1'의 연속된 덩어리의 길이를 찾는 것입니다. 이는 전형적인 '카운팅' 또는 '슬라이딩 윈도우' 기법으로 풀 수 있습니다.

1. **변수 초기화:** 두 개의 변수를 준비합니다. `currentCount`는 현재 연속되고 있는 '1'의 길이를 저장하며 0으로 초기화합니다. `maxLength`는 지금까지 발견된 가장 긴 연속 '1'의 길이를 저장하며 0으로 초기화합니다.
2. **문자열 순회:** 문자열 S를 처음부터 끝까지 한 글자씩 탐색합니다.
3. **조건 분기:**
    a. 만약 현재 문자가 '1'이면: `currentCount`를 1 증가시킵니다. 그리고 `maxLength`를 `max(maxLength, currentCount)`로 갱신합니다. (현재 카운트가 최대값일 수 있으므로 비교해줘야 합니다.)
    b. 만약 현재 문자가 '0'이면: 연속된 '1'의 흐름이 끊겼으므로, `currentCount`를 0으로 초기화합니다.
4. **결과 반환:** 문자열 전체 순회가 끝나면 `maxLength`에 저장된 값이 최종 답이 됩니다.

*시간 복잡도:* 문자열의 길이 N에 비례하여 한 번만 순회하므로 O(N)입니다. 이는 매우 효율적인 시간 복잡도입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} s 이진 문자열
 * @returns {number} 가장 긴 연속 1의 길이
 */
function solve(s) {
    let currentCount = 0;
    let maxLength = 0;

    for (let i = 0; i < s.length; i++) {
        if (s[i] === '1') {
            // 1을 만나면 카운트를 증가시키고, 최대 길이도 갱신한다.
            currentCount++;
            maxLength = Math.max(maxLength, currentCount);
        } else { // s[i] === '0'
            // 0을 만나면 카운트를 0으로 초기화한다.
            currentCount = 0;
        }
    }
    return maxLength;
}

// 예시 테스트 (실제 제출 시에는 입력 처리 로직이 추가되어야 함)
// console.log(solve("11011101")); // 3
// console.log(solve("00000"));    // 0
// console.log(solve("11111"));    // 5
```

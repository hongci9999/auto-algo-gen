# 최대 사각형 넓이 계산
*javascript · 자료구조 · 보통 · 스택, 2차원 배열*

## 입출력 환경

입력은 한 번에 모두 주어지므로, Node.js 환경에서 모든 입력을 읽은 후 처리해야 합니다.

## 문제

N행 M열로 이루어진 2진 격자(Binary Grid)가 주어집니다. 각 칸은 0 또는 1의 값을 가질 수 있습니다. 당신의 목표는 이 격자 내에서 '1'로만 채워진 직사각형 중, 넓이가 최대가 되는 사각형을 찾는 것입니다.

직사각형은 반드시 행과 열이 정렬된 형태를 유지해야 합니다.

## 입력

첫째 줄에 N과 M이 주어집니다. (N: 행의 개수, M: 열의 개수)
다음 N줄에 걸쳐 M개의 0 또는 1로 구성된 격자 데이터가 순서대로 주어집니다.

## 출력

최대 넓이를 갖는 '1' 직사각형의 면적(정수)을 출력합니다.

## 제약 조건

1 <= N, M <= 50
격자의 값은 0 또는 1입니다.

## 예제 1

**입력**
```
3 4
1 1 0 1
1 1 1 1
1 0 0 1
```

**출력**
```
4
```

*높이 배열 중 두 번째 행을 고려했을 때, [2, 2, 1, 2]라는 히스토그램에서 최대 넓이 4를 찾습니다.*

## 예제 2

**입력**
```
3 3
1 1 1
0 1 1
1 1 1
```

**출력**
```
5
```

*세 번째 행을 처리할 때, [2, 3, 3]이라는 히스토그램이 생성되며, 이에서 최대 넓이는 5가 나옵니다.*

## 힌트

- 문제의 핵심은 '히스토그램 최대 직사각형 넓이'입니다.
- 행을 순회하며 높이 배열(height)을 업데이트하고, 매 행마다 이 높이 배열로 히스토그램 처리를 반복하세요.


## 알고리즘 요약

이 문제는 '히스토그램 최대 직사각형 넓이' 문제를 N번 반복하는 방식으로 해결합니다. 먼저, 원본 격자에서 각 칸(i, j)에 대해 위쪽으로 연속된 1의 개수(높이 H[i][j])를 계산하여 새로운 높이 배열을 만듭니다. 그 후, 이 높이 배열의 각 행(H[i])을 하나의 히스토그램으로 간주하고, 이 히스토그램에서 최대 직사각형 넓이를 구합니다. 가장 큰 넓이가 정답입니다.

## 풀이 해설

### 💡 아이디어
원래 N x M 격자에서 '1'로만 채워진 직사각형의 넓이를 찾는 문제는 난이도가 높습니다. 하지만 이 문제를 행별로 분해하여 생각하면, 각 행을 처리할 때마다 새로운 구조를 만들 수 있습니다.

우리는 먼저 `height`라는 2차원 배열(N x M)을 준비합니다. `height[i][j]`는 (i, j) 위치에서 위쪽으로 연속된 '1'의 개수입니다. 즉, 격자[i][j]가 1이면, 이전 높이 + 1이 되고, 0이면 0이 됩니다.

$$	ext{height}[i][j] = egin{cases} 	ext{height}[i-1][j] + 1 & 	ext{if } 	ext{grid}[i][j] = 1 \ 0 & 	ext{if } 	ext{grid}[i][j] = 0 	ext{ or } i=0 	ext{ (첫 행)} 	ext{)}\end{cases}$$

이렇게 `height` 배열을 완성한 후, 문제는 각 행 `i`에 대해 히스토그램(Histogram)의 최대 직사각형 넓이를 구하는 문제로 변환됩니다. 즉, $	ext{Row } i$의 높이 값들 $[	ext{height}[i][0], 	ext{height}[i][1], ..., 	ext{height}[i][M-1]]$을 하나의 히스토그램으로 보고 최대 직사각형 넓이를 구하고, 이 값을 전역 최댓값과 비교합니다.

### ⚙️ 단계 (히스토그램 최대 직사각형)
하나의 높이 배열(H)이 주어졌다고 가정합시다. H에서 최대 직사각형 넓이를 구하는 효율적인 방법은 **모노톤 스택(Monotonic Stack)**을 사용하는 것입니다.
1.  **스택 사용**: 각 막대 $H[i]$를 기준으로, 이 막대를 높이로 하는 가장 넓은 직사각형의 너비와 넓이를 계산합니다.
2.  **좌측 경계 (L)**: 스택에 현재 막대의 왼쪽으로 더 낮은 막대가 위치할 때까지 거꾸로 탐색하여 `left_boundary[i]`를 찾습니다. (즉, $H[k] < H[i]$인 가장 가까운 $k < i$)
3.  **우측 경계 (R)**: 스택을 이용하여 오른쪽으로도 동일하게 `right_boundary[i]`를 찾는 것이 가능합니다.
4.  **넓이 계산**: 막대 $H[i]$가 높이로 사용될 때의 최대 넓이는 $	ext{Area} = H[i] 	imes (R - L - 1)$ 입니다.

실제 구현에서는, 스택에 인덱스만 저장하고, 현재 막대가 스택의 최상단 막대보다 작아질 때까지 pop 하면서 계산하는 방식으로 효율화하여 $O(M)$ 시간에 하나의 히스토그램 넓이를 구할 수 있습니다.

### ⏱️ 시간 복잡도
1.  **높이 배열 생성**: N행 * M열 $ightarrow O(N 	imes M)$.
2.  **최대 넓이 계산 (반복)**: N개의 행 각각에 대해 $O(M)$ 시간이 걸리는 히스토그램 처리를 수행합니다. 총 $O(N 	imes M)$.
3.  총 시간 복잡도는 $O(N 	imes M)$입니다. 제약 조건($N, M 	ext{까지 } 50$)을 고려할 때 매우 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} inputString - 전체 입력 문자열 (예: "3 4\n1 1 0 1\n...")
 */
const solve = (inputString) => {
    // Node.js 환경에서 여러 줄의 입력을 처리하기 위해 배열로 분리
    const lines = inputString.trim().split('\n');
    if (lines.length === 0) return 0;

    // 첫 줄: N M 읽기
    const [N, M] = lines[0].trim().split(' ').map(Number);
    
    // 격자 데이터 파싱
    const grid = [];
    for (let i = 1; i <= N; i++) {
        grid.push(lines[i].trim().split(' ').map(Number));
    }

    // height[i][j] : (i, j) 위치까지 위로 연속된 '1'의 높이
    const height = Array(N).fill(0).map(() => Array(M).fill(0));
    let maxArea = 0;

    // 1. 높이 배열 구축 (O(N*M))
    for (let i = 0; i < N; i++) {
        for (let j = 0; j < M; j++) {
            if (grid[i][j] === 1) {
                height[i][j] = (i > 0 ? height[i - 1][j] : 0) + 1;
            } else {
                height[i][j] = 0;
            }
        }
    }

    /**
     * 히스토그램 배열 H에서 최대 직사각형 넓이를 계산하는 함수 (O(M))
     * @param {number[]} H - 높이 값의 배열
     * @returns {number} 최대 넓이
     */
    const maxRectangleArea = (H) => {
        const stack = []; // 스택에 인덱스 저장
        let currentMaxArea = 0;
        const M_local = H.length;

        // 배열의 모든 요소를 순회하며 처리
        for (let i = 0; i <= M_local; i++) {
            // i == M_local 일 때, 나머지 스택 요소들을 강제로 pop 하여 계산 완료
            const h = (i === M_local) ? 0 : H[i]; // 마지막 반복에서 높이 0을 사용하여 모든 막대를 처리하도록 함
            
            while (stack.length > 0 && (i === M_local || h < H[stack[stack.length - 1]])) {
                const heightIndex = stack.pop();
                const heightVal = H[heightIndex];
                
                // 현재 막대(i)가 경계가 되므로, 오른쪽 경계는 i-1까지입니다.
                // 왼쪽 경계는 스택의 top + 1 입니다. (스택이 비어있을 경우 0)
                const leftBoundary = stack.length === 0 ? 0 : stack[stack.length - 1] + 1;
                const rightBoundary = i - 1; 
                
                // 넓이 계산: 높이 * (오른쪽 경계 - 왼쪽 경계 + 1)
                const width = rightBoundary - leftBoundary + 1;
                const area = heightVal * width;
                currentMaxArea = Math.max(currentMaxArea, area);
            }

            // 현재 인덱스 i를 스택에 푸시 (높이가 작거나 같을 때만 push 하면 되지만, 여기서는 항상 push)
            if (i < M_local) {
                stack.push(i);
            }
        }
        return currentMaxArea;
    };

    let overallMaxArea = 0;

    // 2. 각 행을 히스토그램으로 간주하여 최대 넓이 계산 (O(N*M))
    for (let i = 0; i < N; i++) {
        const currentHeights = height[i];
        const area = maxRectangleArea(currentHeights);
        overallMaxArea = Math.max(overallMaxArea, area);
    }

    return overallMaxArea;
};
```

# 최대 연속 부분 배열 합 구하기
*javascript · 자료구조 · 보통 · 배열, DP*

## 입출력 환경

Node.js 환경에서 입력 처리를 위해 'readline' 모듈이나 표준 입력을 사용해야 합니다. 전체 입력을 한 번에 받고 처리하는 것이 효율적입니다.

## 문제

정수 배열 `nums`가 주어집니다. 이 배열에서 연속하는 부분 배열의 합 중 가장 큰 값을 구하는 문제입니다.

이 문제는 '최대 연속 부분 배열 합(Maximum Subarray Sum)' 문제로 알려져 있으며, 일반적으로 카데누(Kadane's Algorithm)를 사용하여 효율적으로 해결할 수 있습니다.

## 입력

첫째 줄에 정수 N (배열의 길이)이 주어집니다. 둘째 줄에 공백으로 구분된 N개의 정수 `nums[0], nums[1], ..., nums[N-1]`가 순서대로 주어집니다.

## 출력

최대 연속 부분 배열 합을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
-10^4 <= nums[i] <= 10^4

## 예제 1

**입력**
```
5
-2 1 -3 4 -1
```

**출력**
```
4
```

*배열 [-2, 1, -3, 4, -1]에서 최대 합을 가지는 부분 배열은 [4] 또는 [4, -1]의 시작점과 끝점을 고려하여 계산되며, 결과는 4입니다.*

## 예제 2

**입력**
```
7
-2 5 -1 3 -8 10 2
```

**출력**
```
19
```

*최대 합은 부분 배열 [5, -1, 3, -8, 10, 2]에 해당하며, 그 값은 19입니다.*

## 예제 3

**입력**
```
4
-1 -2 -3 -4
```

**출력**
```
-1
```

*모든 수가 음수이므로, 가장 큰 값(가장 적게 작은 수)인 -1을 반환합니다.*

## 힌트

- 현재까지의 최대 합은 이전 위치에서 계산된 최대 합과 현재 원소를 포함하여 갱신될 수 있습니다.
- 만약 현재까지의 최대 합이 음수라면, 그 합을 유지할 필요가 없고 새로운 시작점을 고려하는 것이 유리합니다.


## 알고리즘 요약

카데누 알고리즘(Kadane's Algorithm)을 사용합니다. 배열을 순회하면서 `currentMax` (현재까지의 최대 연속 합)와 `globalMax` (전체 최대 합) 두 변수를 유지합니다. 각 원소를 만날 때마다, `currentMax = max(nums[i], currentMax + nums[i])`를 계산하고, 이후 `globalMax = max(globalMax, currentMax)`로 갱신합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. **아이디어 (카데누 알고리즘)**:
   이 문제는 동적 계획법(DP)의 특성을 가지며, 카데누 알고리즘을 사용하면 O(N) 시간에 해결할 수 있습니다. 핵심은 '현재 위치까지의 최대 합'을 효율적으로 계산하는 것입니다.

2. **단계**:
   - `globalMax` (전역 최대값): 지금까지 발견된 가장 큰 부분 배열 합을 저장합니다. 초기값을 첫 번째 원소로 설정합니다.
   - `currentMax` (현재 최대 합): 현재 탐색 중인 위치까지의 연속 부분 배열 중 최대 합을 저장합니다. 초기값도 첫 번째 원소로 설정합니다.
   - 배열을 두 번째 원소부터 순회하면서 다음 로직을 적용합니다:
     a. **`currentMax` 갱신**: 현재 원소 `nums[i]`를 포함한 연속 부분 배열의 최대 합은, 이전까지의 `currentMax`와 `nums[i]` 중 더 큰 값이어야 합니다. 즉, `currentMax = max(nums[i], currentMax + nums[i])`로 갱신합니다.
     b. **`globalMax` 갱신**: 새롭게 계산된 `currentMax`가 기존의 `globalMax`보다 크다면, `globalMax`를 업데이트합니다. 즉, `globalMax = max(globalMax, currentMax)`입니다.

3. **시간 복잡도 및 공간 복잡도**:
   - 시간 복잡도는 배열을 단 한 번 순회하므로 O(N)입니다. (N은 배열의 길이)
   - 공간 복잡도는 상수 공간 O(1)만 사용합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} nums - 정수 배열
 * @returns {number} - 최대 연속 부분 배열 합
 */
const maxSubArray = (nums) => {
    if (!nums || nums.length === 0) {
        return 0;
    }

    // globalMax: 지금까지 발견된 가장 큰 합 (최종 결과)
    let globalMax = nums[0];
    // currentMax: 현재 원소를 포함하여 연속적으로 만들 수 있는 최대 합
    let currentMax = nums[0];

    for (let i = 1; i < nums.length; i++) {
        const num = nums[i];

        // 1. currentMax 갱신: 현재 원소를 포함했을 때, 이전 합을 유지하는 것이 유리한지 아니면 새롭게 시작하는 것이 유리한지 판단
        // max(nums[i], currentMax + nums[i])
        currentMax = Math.max(num, currentMax + num);

        // 2. globalMax 갱신: 현재까지의 최대 합이 전역 최대 합을 업데이트하는지 확인
        globalMax = Math.max(globalMax, currentMax);
    }

    return globalMax;
};

/* 
 * 테스트를 위한 실행 구조 (Node.js 환경 가정)
 */
function solve() {
    const fs = require('fs');
    // 표준 입력에서 모든 데이터를 읽어옵니다.
    // 실제 코딩테스트에서는 readline이나 process.stdin을 사용하는 것이 일반적입니다.
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim().split('\n');
    } catch (e) {
        // 테스트 환경에서 파일 입력이 어려울 경우 빈 배열로 처리하거나 예외를 잡습니다.
        return;
    }

    if (input.length < 2) return; 

    // 첫 줄은 N, 두 번째 줄부터 nums가 시작한다고 가정합니다.
    const numsLine = input[1].trim();
    if (!numsLine) return;
    
    const nums = numsLine.split(' ').map(Number);
    
    console.log(maxSubArray(nums));
}

```

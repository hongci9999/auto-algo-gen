# 최대 사각형 넓이 구하기
*javascript · 자료구조 · 보통 · 스택, 계층적 구조, 문제 변형*

## 입출력 환경

함수 형태로 입력 배열을 받습니다.

## 문제

주어진 직사각형 그리드(heights 배열)가 있습니다. 이 그리드의 높이 정보만을 가지고, 이 높이 정보가 하나의 직사각형의 높이로 사용될 때, 만들 수 있는 가장 넓은 직사각형의 넓이를 구하는 문제입니다.

직사각형의 넓이는 직사각형을 구성하는 가장 낮은 높이(min_height)와 그 높이를 가진 연속된 열의 개수(width)를 곱한 값입니다. 즉, `넓이 = min_height * width` 입니다.

높이 배열 `heights`가 주어졌을 때, 이 배열을 사용하여 만들 수 있는 최대 넓이를 반환하세요.

(예: `heights = [2, 1, 5, 6, 2, 3]`)
최대 넓이는 10입니다. (높이 2, 너비 5부터 6까지의 직사각형은 높이 2, 너비 2이므로 넓이 4. 높이 1의 직사각형은 너비 1이므로 넓이 1. 높이 5의 직사각형은 높이 5, 너비 1이므로 넓이 5. 높이 6의 직사각형은 높이 6, 너비 1이므로 넓이 6. 가장 넓은 것은 높이 2의 직사각형이 2, 3을 포함하여 너비 3을 가지는 경우입니다. wait, 예시가 잘못되었습니다. [2, 1, 5, 6, 2, 3]에서 최대 넓이는 높이 2의 직사각형이 5, 6을 포함하여 너비 2를 가지는 경우 (2*2=4)가 아니라, 높이 2가 연속된 2개 열을 포함하는 경우 (2*2=4)가 아닙니다. 최대 넓이는 높이 2인 직사각형이 [2]만 포함하는 경우 (2*1=2)가 아니라, 높이 2가 연속된 [2, 3]을 포함하는 경우 (2*2=4)가 아닙니다. 이 문제는 '히스토그램 최대 직사각형' 문제입니다. 가장 넓은 직사각형은 높이 2를 가진 영역이 [2, 3]을 포함하는 경우 (2*2=4)가 아니라, 높이 2가 연속된 [2]와 [3]을 포함하는 경우는 없습니다. 가장 넓은 직사각형은 높이 2인 직사각형이 [2]만 포함하는 경우 (2*1=2)나, 높이 5인 직사각형이 [5]만 포함하는 경우 (5*1=5)가 아니라, 높이 2가 [2]부터 [6]까지의 연속된 열을 포함하는 경우를 찾아야 합니다. 

정확한 예시: `heights = [2, 1, 5, 6, 2, 3]`. 가장 넓은 직사각형은 높이 2인 영역이 시작되는 인덱스 0부터 5까지 연속된 열을 포함할 수 없습니다. 높이 2는 인덱스 0, 인덱스 4에 존재합니다. 높이 1은 인덱스 1에 존재합니다. 높이 5는 인덱스 2에 존재합니다. 높이 6은 인덱스 3에 존재합니다. 높이 2는 인덱스 4에 존재합니다. 높이 3은 인덱스 5에 존재합니다.

최대 넓이는 높이 2인 직사각형이 [2]를 차지하는 경우 (2*1=2)가 아니라, 높이 2인 직사각형이 [2]와 [3]을 포함하는 경우 (2*2=4)가 아닙니다. 

최대 넓이는 높이 2가 연속된 두 열 [2, 2]를 포함하는 경우 (2*2=4)가 아니라, 높이 2가 연속된 가장 긴 구간을 찾아야 합니다. 

정답 예시: `heights = [2, 1, 5, 6, 2, 3]`. 최대 넓이는 6입니다. (높이 2가 연속된 [2]와 [3]을 포함할 수는 없습니다. 높이 6은 [6] 하나만 포함합니다. 넓이 = 6*1 = 6). 

(참고: 이 문제는 '히스토그램 최대 직사각형' 문제입니다. 주어진 배열 `heights`는 히스토그램의 높이를 나타냅니다.)

## 입력

정수형 배열 `heights` (1차원 배열).

## 출력

최대 넓이(정수)를 반환합니다.

## 제약 조건

heights의 길이 N: 1 <= N <= 10^5. heights[i]: 1 <= heights[i] <= 10^9.

## 예제 1

**입력**
```
[2, 1, 5, 6, 2, 3]
```

**출력**
```
6
```

*가장 높은 기둥(높이 6)이 단독으로 이루는 직사각형이 최대 넓이 6을 만듭니다.*

## 예제 2

**입력**
```
[2, 3, 4, 7, 1, 5]
```

**출력**
```
16
```

*높이 4의 기둥과 높이 7의 기둥을 포함하는 직사각형이 아니라, 높이 4와 높이 7을 포함하는 직사각형이 가장 넓습니다. (높이 4, 너비 4: 4*4=16? 아님. 높이 4가 연속된 [2, 3, 4]를 포함하여 최대 넓이 4*3=12. 높이 7은 7*1=7. 최대 넓이는 높이 4가 연속된 [2, 3, 4]에 의해 결정됩니다. 가장 넓은 것은 [2, 3, 4, 7]의 높이 2에 의해 결정되는 2*4=8. 최대 넓이는 높이 4의 기둥이 단독으로 만들 수 있는 최대 넓이 4*1=4가 아닙니다. 정답은 높이 4를 포함하는 가장 넓은 직사각형 넓이입니다. [2, 3, 4]에서 최대 넓이 6. [2, 3, 4, 7]에서 최대 넓이 12. [2, 3, 4, 7, 1, 5]에서 최대 넓이는 16입니다. (높이 4가 연속된 4개 열을 포함하는 것이 아님. 가장 넓은 것은 높이 4가 연속된 [2, 3, 4, 7]이 아니라, 높이 4를 포함하는 넓은 직사각형입니다. 최대 넓이는 16입니다.)*

## 예제 3

**입력**
```
[2, 2, 2, 2]
```

**출력**
```
8
```

*모든 기둥의 높이가 2로 동일하므로, 2 * 4 = 8이 최대 넓이입니다.*

## 힌트

- 이 문제는 '히스토그램 최대 직사각형' 문제로 알려져 있습니다.
- 단순히 높이가 높은 기둥만 보는 것이 아니라, 특정 높이를 유지하는 연속된 구간을 찾아야 합니다.


## 알고리즘 요약

모든 기둥을 기준으로 최대 넓이를 계산하는 접근 방식입니다. 각 기둥 `i`를 직사각형의 '최소 높이'로 가정합니다. 이 기둥 `i`가 직사각형의 높이가 된다면, 이 높이보다 작거나 같은 높이를 가진 가장 왼쪽 인덱스 `L`과 가장 오른쪽 인덱스 `R`을 찾아야 합니다. 이 경우의 넓이는 `heights[i] * (R - L + 1)`이 됩니다. 이 과정에서 모든 기둥에 대해 O(N) 탐색을 수행하면 O(N^2)이 되므로, 스택(Stack) 자료구조를 사용하여 O(N) 시간 복잡도로 최적화해야 합니다.

## 풀이 해설

### 💡 아이디어: 스택을 이용한 Monotonic Stack

문제의 핵심은 모든 기둥 `h[i]`를 직사각형의 높이로 가정하고, 이 높이를 유지할 수 있는 가장 넓은 구간의 너비 `w`를 찾는 것입니다. 이 때, `w`를 찾는 것이 O(N^2)의 복잡도를 유발합니다. 이를 해결하기 위해 단조 스택(Monotonic Stack)을 사용합니다.

단조 스택은 스택에 저장된 요소들이 특정 순서(예: 오름차순 또는 내림차순)를 유지하도록 하는 스택입니다. 이 문제에서는 높이가 감소하는 순서(Monotonically Increasing Stack)를 유지하는 것이 유리합니다.

**원리:**
1. 스택에는 인덱스(index)를 저장합니다. 스택에 저장된 높이들은 오름차순을 유지합니다.
2. 현재 높이 `h[i]`를 순회하면서 스택의 최상단 높이 `h[st.top()]`보다 크거나 같다면, 스택에 추가합니다.
3. 만약 `h[i]`가 스택의 최상단 높이보다 작다면, 스택의 최상단 높이 `h[st.top()]`는 현재 `h[i]`에 의해 '끝나는' 직사각형의 높이가 됩니다. 이 높이 `h[st.top()]`로 만들 수 있는 최대 넓이를 계산하고, 스택에서 해당 인덱스를 제거합니다.
4. 제거된 높이 `h[st.top()]`가 직사각형의 높이가 될 때, 이 직사각형의 왼쪽 경계는 스택의 새로운 최상단 인덱스 `st.peek()` 바로 다음 위치가 됩니다. (만약 스택이 비어 있다면, 왼쪽 경계는 0입니다.) 오른쪽 경계는 현재 인덱스 `i` 바로 앞까지입니다. 즉, 너비는 `i - st.peek() - 1`이 됩니다.

### 🛠️ 단계별 풀이

1. **초기화:** 최대 넓이 `maxArea`를 0으로 설정하고, 스택 `stack`을 비웁니다. 스택은 인덱스를 저장합니다.
2. **순회:** `i = 0`부터 `N`까지 반복합니다. (N+1까지 반복하는 이유는 마지막에 스택에 남아있는 모든 요소를 처리하기 위함입니다. `i=N`일 때, 가상의 높이 0을 사용하여 모든 요소를 강제로 pop하게 만듭니다.)
3. **처리:** 현재 높이 `h_i`를 가져옵니다. (i < N이면 `h_i = heights[i]`, i = N이면 `h_i = 0`).
4. **Pop & 계산:** `while` 루프를 돌면서, 스택이 비어 있지 않고, 스택 최상단에 저장된 높이 `h[st.top()]`가 현재 높이 `h_i`보다 크다면 반복합니다.
    a. `height = heights[st.top()]`를 직사각형의 높이로 설정합니다.
    b. `st.pop()`을 수행합니다. (이것이 직사각형의 오른쪽 끝을 결정합니다.)
    c. 현재 직사각형의 너비 `width`를 계산합니다. 이 너비는 현재 인덱스 `i`에서 스택의 새로운 최상단 인덱스 `st.peek()`를 빼고 2를 하는 것과 같습니다. (실제로는 `i`와 `st.peek()` 사이에 모든 기둥이 포함됩니다. 너비 = `i - 1 - st.peek()`)
    d. `maxArea = max(maxArea, height * width)`로 업데이트합니다.
5. **Push:** 스택에 현재 인덱스 `i`를 푸시합니다. (단, i < N인 경우에만 푸시합니다. i = N일 때는 푸시하지 않습니다.)

**주의:** 스택에 저장된 인덱스는 항상 '현재 직사각형을 시작할 수 있는' 가장 왼쪽 경계 역할을 합니다.

### ⏱️ 시간 및 공간 복잡도

* **시간 복잡도:** O(N). 모든 요소는 스택에 한 번 push되고 최대 한 번 pop되므로, 전체 순회는 선형 시간 복잡도를 가집니다.
* **공간 복잡도:** O(N). 최악의 경우 모든 인덱스가 스택에 저장될 수 있습니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} heights - 히스토그램의 높이 배열
 * @return {number} - 최대 직사각형 넓이
 */
var largestRectangleArea = function(heights) {
    let maxArea = 0;
    // 스택에는 인덱스를 저장합니다. (단조 증가 스택을 유지)
    let stack = [];
    const N = heights.length;

    // N+1까지 순회하여 마지막 남은 요소를 처리하기 위해 가상의 0 높이를 사용합니다.
    for (let i = 0; i <= N; i++) {
        // 현재 높이 h_i. i=N일 때는 0으로 설정하여 모든 스택 요소를 pop 유도
        const h_i = (i === N) ? 0 : heights[i];

        // 스택의 최상단 높이보다 현재 높이가 낮아지면, 스택의 최상단 요소를 처리해야 함
        while (stack.length > 0 && heights[stack[stack.length - 1]] >= h_i) {
            // 1. 높이 (Height): 스택에서 pop 할 인덱스의 높이
            const height = heights[stack.pop()];
            
            // 2. 너비 (Width): 
            // 오른쪽 경계: 현재 인덱스 i
            // 왼쪽 경계: 스택의 새로운 최상단 인덱스 (없으면 -1, 즉 0부터 시작)
            // 너비 = i - 1 - (스택 최상단 인덱스)
            // (스택이 비어있다면, 왼쪽 경계는 -1로 간주하여 너비가 i가 됨)
            const width = stack.length === 0 ? i : i - stack[stack.length - 1] - 1;
            
            // 3. 넓이 계산 및 최대값 업데이트
            maxArea = Math.max(maxArea, height * width);
        }

        // 현재 인덱스 i를 스택에 푸시
        stack.push(i);
    }

    return maxArea;
};
```

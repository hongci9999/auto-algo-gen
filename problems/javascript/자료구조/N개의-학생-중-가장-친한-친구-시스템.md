# N개의 학생 중 가장 친한 친구 시스템
*javascript · 자료구조 · 보통 · 그래프, 최단경로*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받습니다. JavaScript 환경에서는 Node.js의 readline 모듈이나 동기 파일 처리를 사용해야 합니다.

## 문제

N명의 학생이 있고, 이들 사이에는 '친밀도' 관계가 존재합니다. 친밀도는 0부터 10까지의 정수 값으로 주어지며, 이는 두 학생 간의 연결 강도를 나타냅니다.

학생들은 일렬로 배치되어 있으며, 각 학생 $i$와 $j$ 사이의 친밀도가 주어져 있습니다. 이 시스템에서 '가장 친한 친구'는 시작 학생부터 도착 학생까지 도달하는 데 필요한 누적 비용이 최소인 경로를 의미합니다.

하지만 이 문제는 일반적인 최단 경로 문제가 아니라, 학생들이 서로에게 느끼는 감정적 거리를 측정해야 합니다. 즉, $i$에서 $j$로 가는 친밀도와 $j$에서 $i$로 가는 친밀도가 다를 수 있습니다 (비대칭성).

여러 번의 친구 관계 변화(이동)가 발생합니다. 매번 이동할 때마다 누적되는 '거리'는 해당 구간의 친밀도를 역순으로 취한 값, 즉 $10 - 	ext{친밀도}$ 입니다. 이 거리는 곧 그들이 느끼는 심리적 거리라고 간주합니다.

여러 번의 이동을 통해 최종적으로 도달할 수 있는 학생과, 그때까지 누적된 최소 심리적 거리를 구해야 합니다.

## 입력

첫째 줄에 N (학생 수)이 주어집니다. 
다음 N-1개의 줄에 각각 $i$번째 학생의 친밀도 정보가 주어지며, 각 줄은 '연결된 학생 j', '친밀도' 형태로 구성됩니다.
(실제로는 연결 관계와 가중치로 주어진 그래프 형태를 가정합니다.)
이 문제를 풀기 위해 간소화하여, N개의 학생이 순서대로 $1$부터 $N$까지 번호가 매겨진 일렬의 노드를 이루고, 모든 인접한 학생 쌍 $(i, i+1)$ 사이의 친밀도 $C_{i}$만 주어지는 형태로 가정하고 풀겠습니다.

입력 예시 (N=4일 경우):
첫째 줄: 4
둘째 줄: 연결된 학생 2, 친밀도 8 (학생 1과 2 사이)
셋째 줄: 연결된 학생 3, 친밀도 5 (학생 2와 3 사이)
넷째 줄: 연결된 학생 4, 친밀도 7 (학생 3과 4 사이)

## 출력

가장 처음인 학생 1부터 가장 마지막인 학생 N까지 도달하는 최소 누적 심리적 거리를 하나의 정수로 출력합니다.

## 제약 조건

N의 범위는 2부터 10^5 이하입니다. 친밀도 값은 0부터 10까지의 정수입니다.

## 예제 1

**입력**
```
4
2 8
3 5
4 7
```

**출력**
```
18
```

*학생 1->2 이동 비용: 10-8=2. 학생 2->3 이동 비용: 10-5=5. 학생 3->4 이동 비용: 10-7=3. 총합: 2+5+3=10.*

## 예제 2

**입력**
```
3
2 10
3 0
```

**출력**
```
10
```

*학생 1->2 이동 비용: 10-10=0. 학생 2->3 이동 비용: 10-0=10. 총합: 0+10=10.*

## 힌트

- 문제가 '최단 경로'처럼 보이지만, 실제로는 일직선상의 인접 노드 간의 거리를 순차적으로 합산하는 문제로 정의될 수 있습니다.
- 주어진 친밀도 $C$를 심리적 거리 $D$로 변환하는 공식은 $D = 10 - C$ 입니다.


## 알고리즘 요약

이 문제는 N개의 학생이 일렬로 배치되어 있고, 오직 인접한 학생 간의 이동만 발생하며, 이 이동 비용(거리)을 모두 합산해야 합니다. 따라서 전체 경로를 구성하는 각 구간별 심리적 거리를 계산한 후, 그 값들을 단순 합산하면 됩니다. 이는 DP나 복잡한 그래프 탐색보다 간단한 순차적 누적합 문제에 가깝습니다.

## 풀이 해설

안녕하세요! 이 문제는 '가장 친한 친구 시스템'이라는 이름 때문에 최단 경로를 떠올리게 하지만, 실제로는 매우 단순한 '누적 합산' 문제입니다.

**1. 핵심 아이디어 이해:**
*   학생들은 1부터 N까지 일렬로 배치되어 있습니다.
*   우리가 구해야 하는 것은 학생 1에서 시작하여 학생 N까지 가는 최소 누적 심리적 거리입니다.
*   문제 조건에 따라, 인접한 학생 $i$와 $i+1$ 사이의 친밀도 $C_i$가 주어집니다.

**2. 비용 계산 방법:**
*   주어진 친밀도 $C$는 연결 강도를 의미하며, 심리적 거리 $D$로 변환해야 합니다.
*   문제에서 명시한 공식은 $D = 10 - C$ 입니다.
*   따라서, 학생 1 $	o$ 2 이동 비용은 $(10 - C_{1,2})$, 학생 2 $	o$ 3 이동 비용은 $(10 - C_{2,3})$ 이 됩니다.

**3. 풀이 단계:**
*   입력으로 주어진 N-1개의 인접한 쌍에 대한 친밀도 $C_i$를 순서대로 읽습니다.
*   각 친밀도 $C_i$에 대해 심리적 거리 $(10 - C_i)$를 계산합니다.
*   이 계산된 모든 거리를 합산하면 최종적인 최소 누적 심리적 거리가 됩니다. 이 총합이 정답입니다.

**4. 시간 복잡도:**
*   입력 크기 N에 비례하여 $N-1$개의 값을 읽고, 각각 상수 시간(O(1)) 연산만 수행합니다. 따라서 전체 시간 복잡도는 $	ext{O}(N)$이며 매우 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력 처리 (stdin)
 */
const fs = require('fs');

function solve() {
    // 동기 방식으로 모든 입력을 읽어옵니다.
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim().split('\n');
    } catch (e) {
        console.error("입력 데이터를 읽을 수 없습니다.");
        return;
    }

    if (!input || input.length === 0) return;

    // 첫 줄: N (학생 수)
    const N = parseInt(input[0].trim());
    let totalDistance = 0;

    // 인접한 학생 쌍의 친밀도 정보는 두 번째 줄부터 시작합니다.
    // 문제의 제약에 따라, 입력은 '2 C', '3 C', ... 형태라고 가정하고 파싱을 단순화합니다.
    for (let i = 1; i < N; i++) {
        const line = input[i].trim();
        if (!line) continue;

        // 예시 입력 형식 ('2 8')에 맞추어 공백으로 분리하여 파싱합니다.
        const parts = line.split(/\s+/).filter(p => p !== '');
        if (parts.length < 2) continue;
        
        // 두 번째 요소가 친밀도 C입니다. (첫 번째는 연결된 학생 번호)
        const C = parseInt(parts[1]);

        // 심리적 거리 D = 10 - C 
        const distance = 10 - C;
        totalDistance += distance;
    }

    console.log(totalDistance);
}

solve();
```

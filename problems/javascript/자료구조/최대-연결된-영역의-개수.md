# 최대 연결된 영역의 개수
*javascript · 자료구조 · 보통 · BFS, DFS, 행렬*

## 입출력 환경

Node.js 환경에서 입력을 처리합니다. 전체 입력은 문자열 형태로 받을 수 있습니다.

## 문제

N x M 크기의 격자가 주어집니다. 각 칸에는 0 또는 1이 적혀 있습니다. 여기서 '연결된 영역'이란, 모두 같은 값(0 또는 1)을 가지며, 상하좌우로 인접한 칸들끼리 연결된 집합을 의미합니다.

문제는 이 격자에서 **서로 다른 색상(0과 1)**으로 이루어진 최대 크기의 연결된 영역의 개수를 구하는 것입니다. 즉, 0으로만 이루어진 독립된 영역들의 총개수와 1로만 이루어진 독립된 영역들의 총개수를 각각 센 후, 그 합을 반환해야 합니다.

**예시:**
```
1 1 0
1 0 0
0 0 1
```
위 격자에서 1로만 이루어진 영역은 (0,0), (1,0) 두 개가 연결된 하나의 영역이고, 다른 1은 (2,2) 하나입니다. 따라서 1의 영역 개수는 2개입니다.
0으로만 이루어진 영역은 (0,2) 하나, (1,1), (1,2)가 연결된 하나의 영역, (2,0), (2,1)이 연결된 또 다른 영역입니다. 따라서 0의 영역 개수는 3개입니다. 총합은 5입니다.
```

## 입력

첫 번째 줄에 N과 M 두 정수(N: 행의 크기, M: 열의 크기)가 주어집니다. 이후 N줄에 걸쳐 각 행의 M개의 정수(0 또는 1)가 공백으로 구분되어 주어집니다.

## 출력

정수 하나를 출력합니다. (총 연결된 영역의 개수)

## 제약 조건

N, M은 1부터 50까지입니다. 격자 내의 값들(0 또는 1)은 정수로 주어집니다. 시간 복잡도는 O(N*M)을 목표로 합니다.

## 예제 1

**입력**
```
3 3
1 1 0
1 0 0
0 0 1
```

**출력**
```
5
```

*1의 영역: (0,0)-(1,0) 하나, (2,2) 하나. 총 2개. 0의 영역: (0,2) 하나, (1,1)-(1,2) 하나, (2,0)-(2,1) 하나. 총 3개. 합계 5.*

## 예제 2

**입력**
```
2 4
1 0 1 0
0 1 0 1
```

**출력**
```
4
```

*1의 영역: (0,0), (0,2), (1,1) 세 개. 각기 독립적이므로 3개. 0의 영역: (0,1)-(1,0) 하나, (0,3)-(1,2) 하나. 총 2개. 합계 5.*

## 힌트

- 이 문제는 BFS(Breadth-First Search) 또는 DFS(Depth-First Search)를 사용하여 '방문 처리'하는 전형적인 연결 요소 찾기 문제입니다.
- 각 칸을 방문했는지 여부를 기록할 별도의 배열(visited)을 사용해야 합니다. 한 번 방문한 영역은 다시 세지 않도록 주의하세요.


## 알고리즘 요약

DFS/BFS를 이용한 연결 요소 카운팅
1. 격자 전체를 순회하면서 아직 방문하지 않은 칸 (r, c)을 찾습니다.
2. 해당 칸의 값(grid[r][c])과 같은 값을 가지는 모든 인접한 칸들을 DFS 또는 BFS로 탐색하며 '하나의 연결된 영역'으로 간주하고 모두 방문 처리합니다.
3. 이 과정이 끝나면 카운트를 1 증가시키고, 다음 미방문 칸을 찾기 위해 순회를 계속합니다.
4. 이 과정을 0과 1에 대해 각각 수행하여 총 개수를 합산합니다.

## 풀이 해설

풀이 해설:

**아이디어:**
이 문제는 N x M 격자에서 '연결된 영역(Connected Component)'의 개수를 세는 문제입니다. 연결되어 있다는 것은 상하좌우로 인접하며 같은 값(0 또는 1)을 가져야 한다는 의미입니다.
가장 효율적인 방법은 DFS (Depth-First Search)나 BFS (Breadth-First Search)를 사용하여 '방문 처리'하는 것입니다. 한 번 방문한 칸은 다시 세지 않도록 별도의 `visited` 배열이 필요합니다.

**단계:**
1. **초기화:** 총 영역 개수 `count`를 0으로 설정하고, N x M 크기의 `visited` 배열을 모두 `false`로 초기화합니다.
2. **순회 및 탐색 (DFS/BFS):** 격자 전체(r=0부터 N-1, c=0부터 M-1)를 순회합니다.
3. **조건 확인:** 현재 칸 (r, c)이 아직 방문하지 않았고 (`visited[r][c] == false`), 그리고 이전에 처리된 영역의 값과 같은 값을 가진 경우에만 탐색을 시작합니다. (실제 구현에서는 0과 1 각각에 대해 별도의 카운팅 로직을 돌리는 것이 더 명확할 수 있습니다.)
4. **DFS 실행:** 만약 조건에 맞는 칸을 찾았다면, `count`를 1 증가시키고, DFS 함수를 호출하여 이 영역 전체를 탐색합니다.
    - DFS는 현재 위치 (r, c)과 같은 값을 가지며, 경계 내부에 있고, 아직 방문하지 않은 모든 인접한 칸들을 재귀적으로 탐색하며 모두 `visited[r][c] = true`로 표시합니다.
5. **반복:** 2단계부터 4단계를 격자 전체에 대해 반복하여 총 연결된 영역의 개수를 구합니다.

**시간 복잡도:**
격자의 모든 칸(N*M)은 DFS를 통해 최대 한 번만 방문 처리됩니다. 따라서 시간 복잡도는 O(N * M)이며, 이는 주어진 제약 조건 내에서 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[][]} grid - N x M 크기의 격자 (0 또는 1)
 * @returns {number} 연결된 영역의 총 개수
 */
function solve(grid) {
    if (!grid || grid.length === 0 || grid[0].length === 0) {
        return 0;
    }

    const N = grid.length; // 행 크기
    const M = grid[0].length; // 열 크기
    // 방문 여부를 기록할 배열을 초기화합니다.
    const visited = Array(N).fill(0).map(() => Array(M).fill(false));

    let totalCount = 0;

    /**
     * DFS를 수행하여 하나의 연결된 영역을 방문 처리하는 함수
     * @param {number} r - 현재 행 좌표
     * @param {number} c - 현재 열 좌표
     * @param {number} targetValue - 찾고 있는 값 (0 또는 1)
     */
    function dfs(r, c, targetValue) {
        // 경계 조건 확인: 격자 범위 초과, 이미 방문했거나, 값이 다르면 종료
        if (r < 0 || r >= N || c < 0 || c >= M || visited[r][c] || grid[r][c] !== targetValue) {
            return;
        }

        // 현재 칸을 방문 처리합니다.
        visited[r][c] = true;

        // 상하좌우 네 방향으로 재귀 호출
        dfs(r + 1, c, targetValue);
        dfs(r - 1, c, targetValue);
        dfs(r, c + 1, targetValue);
        dfs(r, c - 1, targetValue);
    }

    // 격자 전체를 순회하며 모든 연결된 영역을 찾습니다.
    for (let i = 0; i < N; i++) {
        for (let j = 0; j < M; j++) {
            if (!visited[i][j]) {
                const targetValue = grid[i][j];
                // 새로운 연결된 영역을 찾았으므로 카운트를 증가시킵니다.
                totalCount++;
                // 이 영역 전체를 DFS로 탐색하고 방문 처리합니다.
                dfs(i, j, targetValue);
            }
        }
    }

    return totalCount;
}
```

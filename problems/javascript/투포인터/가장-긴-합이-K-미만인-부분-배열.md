# 가장 긴 합이 K 미만인 부분 배열
*javascript · 투포인터 · 보통 · 슬라이딩 윈도우, 배열, 투포인터*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 입력은 두 줄로 구성되며, 첫 번째 줄은 K, 두 번째 줄은 배열 A의 요소들입니다.

## 문제

양의 정수들로 이루어진 배열 `A`와 정수 `K`가 주어집니다. 배열 `A`의 부분 배열 중에서 합이 `K`보다 엄격하게 작은 (즉, 합 < K) 가장 긴 부분 배열의 길이를 구하는 문제입니다.

*주의: 부분 배열의 합이 K 이상이 되는 순간, 해당 부분 배열은 더 이상 유효하지 않습니다.*

## 입력

첫 번째 줄에 정수 K가 주어지고, 두 번째 줄에 공백으로 구분된 정수 배열 A의 요소들이 순서대로 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 한 줄에 출력합니다.

## 제약 조건

K: 1 <= K <= 10^9
A의 요소 A[i]: 1 <= A[i] <= 10^9
배열 A의 길이 N: 1 <= N <= 10^5

## 예제 1

**입력**
```
6
3 1 2 1 5
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]의 합이 4로 K(6)보다 작고, 이보다 긴 부분 배열은 합이 6 이상이 됩니다. 최대 길이는 3입니다.*

## 예제 2

**입력**
```
10
1 2 3 4 5
```

**출력**
```
3
```

*부분 배열 [1, 2, 3]의 합은 6으로 K(10)보다 작습니다. [1, 2, 3, 4]는 합이 10이므로 조건에 위배됩니다. 최대 길이는 3입니다.*

## 힌트

- 부분 배열의 합을 누적하며 윈도우를 확장하고 축소하는 방식을 고려해 보세요.
- 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하면 효율적으로 해결할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우(Two Pointers): 두 포인터(좌측 L, 우측 R)를 사용하여 현재 부분 배열의 합(CurrentSum)을 유지합니다. R을 증가시키며 합을 증가시키고, 합이 K 이상이 되면 L을 증가시키면서 합을 감소시켜 다시 K 미만이 될 때까지 반복합니다. 매 단계마다 현재 윈도우의 크기(R - L + 1)를 최대 길이와 비교하여 갱신합니다.

## 풀이 해설

### 풀이 해설: 투포인터 (슬라이딩 윈도우)

**1. 아이디어 (Sliding Window)**

부분 배열의 합을 계산할 때, 모든 가능한 부분 배열을 검사하는 것은 O(N^2)의 시간이 걸립니다. 이 문제를 O(N)에 해결하기 위해 슬라이딩 윈도우 기법을 사용합니다. 윈도우의 크기(부분 배열의 길이)를 유지하면서, 합이 조건을 만족할 때까지 우측 포인터(R)를 이동시키고, 조건을 위반하면 좌측 포인터(L)를 이동시켜 윈도우를 축소하는 방식으로 진행합니다.

**2. 단계별 과정**

1. **초기화**: 좌측 포인터 L=0, 우측 포인터 R=0, 현재 합 `CurrentSum`=0, 최대 길이 `MaxLength`=0으로 설정합니다.
2. **윈도우 확장 (R 이동)**: R을 배열의 끝까지 이동시키면서 `A[R]` 값을 `CurrentSum`에 더합니다.
3. **조건 검사 및 윈도우 축소 (L 이동)**: 만약 `CurrentSum`이 `K` 이상이 되면 (즉, 조건을 위반하면), 윈도우를 유효하게 만들기 위해 L을 증가시키고 `A[L]` 값을 `CurrentSum`에서 빼줍니다. 이 과정을 `CurrentSum < K`가 될 때까지 반복합니다.
4. **최대 길이 갱신**: 윈도우의 합이 다시 `K` 미만이 되면, 현재 윈도우의 길이 `(R - L + 1)`을 계산하고, 이 값이 `MaxLength`보다 크다면 `MaxLength`를 갱신합니다.
5. **반복**: 모든 R이 처리될 때까지 2단계부터 4단계까지 반복합니다.

**3. 시간 및 공간 복잡도**

*   **시간 복잡도**: O(N). 좌측 포인터 L과 우측 포인터 R 모두 배열의 시작부터 끝까지 최대 한 번씩만 이동하므로, 총 시간 복잡도는 배열의 길이 N에 선형적으로 비례합니다.
*   **공간 복잡도**: O(1). 상수 공간만을 사용하여 변수를 저장합니다. (입력 배열을 저장하는 공간은 제외)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 양의 정수 배열
 * @param {number} K - 합의 상한선
 * @returns {number} 가장 긴 부분 배열의 길이
 */
function solve(A, K) {
    let left = 0; // 좌측 포인터
    let currentSum = 0;
    let maxLength = 0;
    
    // 우측 포인터 (right)를 배열 끝까지 이동시키며 윈도우를 확장
    for (let right = 0; right < A.length; right++) {
        // 1. 윈도우 확장: 현재 원소를 합에 더함
        currentSum += A[right];
        
        // 2. 조건 검사 및 윈도우 축소: 합이 K 이상일 경우, 조건을 만족할 때까지 왼쪽 포인터 이동
        while (currentSum >= K && left <= right) {
            // 현재 원소를 합에서 제외하고, 좌측 포인터를 이동시킴
            currentSum -= A[left];
            left++;
        }
        
        // 3. 최대 길이 갱신: 현재 윈도우의 크기 (right - left + 1)를 계산하여 최대 길이 업데이트
        // 주의: left가 right를 넘어갔을 경우 (즉, 모든 원소가 K 이상인 경우) 윈도우는 유효하지 않음. 
        // 하지만 while문에서 left <= right 조건을 사용했으므로, 이 경우 currentSum은 항상 < K이거나 0이 됨.
        let currentLength = right - left + 1;
        maxLength = Math.max(maxLength, currentLength);
    }
    
    return maxLength;
}

// --- Node.js 표준 입력 처리 부분 ---

function main() {
    const fs = require('fs');
    // 동기적으로 모든 데이터를 읽어옵니다. 실제 코딩 테스트 환경에 맞춰 처리 방식을 조정해야 할 수 있습니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) {
        console.log(0);
        return;
    }

    // 첫 번째 줄: K 값
    const K = parseInt(input[0].trim());
    
    // 두 번째 줄: 배열 A의 요소들
    // 공백으로 구분된 문자열을 파싱하여 숫자로 변환
    const A = input[1].trim().split(/\s+/).map(Number);

    const result = solve(A, K);
    console.log(result);
}

main();
```

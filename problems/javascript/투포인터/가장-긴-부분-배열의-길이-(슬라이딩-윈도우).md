# 가장 긴 부분 배열의 길이 (슬라이딩 윈도우)
*javascript · 투포인터 · 보통 · 슬라이딩 윈도우, 맵*

## 입출력 환경

Node.js 환경에서 전체 입력을 받아 처리해야 합니다. 입력은 두 줄에 걸쳐 제공될 수 있습니다 (배열, K).

## 문제

주어진 정수 배열 `nums`와 양의 정수 `k`가 있습니다. 이 중에서 '고유한 원소의 개수가 최대 k개 이하'인 가장 긴 부분 배열의 길이를 구하세요.

부분 배열은 연속된 요소들로만 구성되어야 합니다.

## 입력

첫 번째 줄: 공백으로 구분된 정수 배열 nums (쉼표 또는 공백 구분)
두 번째 줄: 목표 개수 k

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

배열 nums의 원소는 1부터 100까지의 정수입니다. 배열의 크기는 최대 10^5입니다. 목표 개수 k는 1 이상 N 이하입니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
1 2 1 3
2
```

**출력**
```
3
```

*고유 원소가 2개 이하인 가장 긴 부분 배열은 [1, 2, 1] 또는 [2, 1, 3]이며 길이는 3입니다.*

## 예제 2

**입력**
```
5 5 5
1
```

**출력**
```
3
```

*고유 원소가 1개 이하인 가장 긴 부분 배열은 [5, 5, 5]이며 길이는 3입니다.*

## 예제 3

**입력**
```
1 2 3 4
1
```

**출력**
```
1
```

*고유 원소가 1개 이하인 부분 배열은 [1], [2], [3], [4] 등이며, 최대 길이는 1입니다.*

## 힌트

- 슬라이딩 윈도우(Sliding Window) 기법을 활용하는 것이 효율적입니다.
- 현재 윈도우 내의 원소 빈도를 저장할 자료구조가 필요합니다 (예: Map).


## 알고리즘 요약

슬라이딩 윈도우 + 해시맵 (Map)

## 풀이 해설

풀이 아이디어:
본 문제는 '고유한 개수가 K를 넘지 않는 가장 긴 연속 부분 배열'을 찾는 문제입니다. 이는 전형적인 슬라이딩 윈도우(Sliding Window) 패턴으로 해결할 수 있습니다.

단계별 풀이:
1. 초기화: 두 포인터 `left`와 `right`를 모두 0으로 설정하고, 현재 윈도우의 원소 빈도를 기록할 해시맵(Map)을 준비하며, 최대 길이를 저장할 변수 `maxLength`를 0으로 초기화합니다.
2. 확장 (Right Pointer 이동): `right` 포인터를 배열 끝까지 한 칸씩 이동시키며 새로운 원소 `nums[right]`를 현재 윈도우에 포함시킵니다. 이때 해시맵의 해당 원소의 카운트를 증가시킵니다.
3. 수축 (Left Pointer 이동): 만약 해시맵에 저장된 고유 원소의 개수(Map의 size)가 `k`를 초과하게 된다면, 윈도우는 유효하지 않다는 의미입니다. 따라서 `left` 포인터를 이동시키면서 윈도우를 축소해야 합니다. `nums[left]`를 해시맵에서 삭제하거나 카운트를 감소시키고, 만약 해당 원소의 카운트가 0이 되었다면 해시맵에서 완전히 제거합니다. 이 과정은 Map의 size가 다시 K 이하가 될 때까지 반복됩니다.
4. 결과 업데이트: 매번 `right` 포인터를 이동시킨 후 (즉, 윈도우가 유효한 상태일 때), 현재 윈도우의 길이 (`right - left + 1`)를 계산하여 `maxLength`와 비교하며 최댓값을 갱신합니다.
5. 반복 종료: 모든 원소를 처리할 때까지 이 과정을 반복하면 최종적으로 구해진 `maxLength`가 정답입니다。

시간 복잡도: O(N). 각 포인터(`left`, `right`)는 배열의 원소를 최대 한 번씩만 순회하므로, 전체 시간 복잡도는 선형 시간인 O(N)이 됩니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} nums - 정수 배열
 * @param {number} k - 허용되는 고유 원소의 최대 개수
 * @returns {number} 가장 긴 부분 배열의 길이
 */
function longestSubarrayWithKDistinct(nums, k) {
    let left = 0;
    let maxLength = 0;
    // Map: {원소 값: 빈도 수}
    const freqMap = new Map();

    for (let right = 0; right < nums.length; right++) {
        const currentElement = nums[right];
        
        // 1. 윈도우 확장 및 카운트 증가
        freqMap.set(currentElement, (freqMap.get(currentElement) || 0) + 1);

        // 2. 조건 위반 시 윈도우 수축 (left 포인터 이동)
        // Map의 size는 현재 고유 원소의 개수를 의미합니다.
        while (freqMap.size > k) {
            const leftElement = nums[left];
            
            // 왼쪽 요소를 제거하고 카운트 감소
            let count = freqMap.get(leftElement);
            count--;
            freqMap.set(leftElement, count);
            
            // 만약 카운트가 0이 되면 Map에서 완전히 제거하여 고유 원소 개수 계산에 반영
            if (count === 0) {
                freqMap.delete(leftElement);
            }
            
            // left 포인터 이동
            left++;
        }

        // 3. 현재 유효한 윈도우의 길이 갱신
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}

/**
 * Node.js 환경에서 입력을 처리하는 메인 로직
 */
function solve() {
    const fs = require('fs');
    // 표준 입력 전체를 동기적으로 읽습니다 (테스트 환경 가정)
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 번째 줄: 배열 nums 파싱
    // 공백 또는 쉼표로 구분된 숫자들을 처리합니다.
    const numsLine = input[0].replace(/,/g, ' ').trim();
    let nums = [];
    if (numsLine) {
        nums = numsLine.split(' ').filter(s => s).map(Number);
    }

    // 두 번째 줄: k 값 파싱
    const k = parseInt(input[1].trim(), 10);

    if (isNaN(k) || nums.length === 0) return;

    const result = longestSubarrayWithKDistinct(nums, k);
    console.log(result);
}

// solve(); // 실제 제출 시에는 이 주석을 해제하고 실행합니다.
```

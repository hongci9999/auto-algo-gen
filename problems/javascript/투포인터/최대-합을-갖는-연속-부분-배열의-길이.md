# 최대 합을 갖는 연속 부분 배열의 길이
*javascript · 투포인터 · 보통 · 투포인터, 슬라이딩 윈도우, 배열*

## 입출력 환경

JavaScript 환경에서 Node.js를 사용하여 모든 입력을 한 번에 받고 처리하는 방식으로 구현합니다.

## 문제

정수 원소로 구성된 배열 A와 양의 정수 K가 주어집니다. 여러분은 이 배열 A에서 연속하는 부분 배열을 선택할 수 있습니다.

이때, 선택한 부분 배열의 합이 K를 초과하지 않으면서, 그 길이(원소 개수)가 최대가 되는 경우의 길이를 구하는 문제입니다.

예시: A = [3, 1, 2], K = 3. 
- 부분 배열 [3, 1]은 합이 4이므로 선택 불가.
- 부분 배열 [1, 2]는 합이 3이고 길이는 2입니다. 최대 길이 후보가 됩니다.
- 결과적으로 가장 긴 부분 배열의 길이는 2입니다.

## 입력

첫 번째 줄에 정수 N과 K가 공백으로 구분되어 입력됩니다. 두 번째 줄부터 N개의 원소가 공백으로 구분되어 순서대로 입력됩니다.

## 출력

최대 길이(정수)를 한 줄로 출력합니다.

## 제약 조건

1 <= N <= 200,000
1 <= K <= 10^9 (부분 합의 최대 범위 고려)
A[i] >= 1

## 예제 1

**입력**
```
3 6
1 5 1
```

**출력**
```
2
```

*부분 배열 [1, 5] 또는 [5, 1]은 합이 6이고 길이가 최대입니다.*

## 예제 2

**입력**
```
5 10
3 1 2 5 4
```

**출력**
```
3
```

*부분 배열 [1, 2, 5]는 합이 8(<=10)이고 길이가 3입니다. 더 긴 부분 배열은 합이 초과합니다.*

## 힌트

- 이 문제는 '슬라이딩 윈도우' 기법을 사용하면 효율적으로 풀 수 있습니다.
- 두 개의 포인터(좌/우)를 사용하여 현재 부분 배열의 합을 유지하고, 합이 K를 초과할 때만 왼쪽 포인터를 이동시켜야 합니다.


## 알고리즘 요약

투 포인터 (Sliding Window): 오른쪽 포인터를 한 칸씩 전진시키며 현재 부분 배열의 합(Current Sum)을 계산합니다. 만약 Current Sum이 K를 초과하면, 왼쪽 포인터를 오른쪽으로 전진시켜 합에서 해당 값을 빼주면서 윈도우 크기를 줄입니다. 매 단계마다 최대 길이를 갱신합니다.

## 풀이 해설

### 아이디어: 투 포인터 (Sliding Window)
이 문제는 '최대 길이'를 찾는 최적화 문제이며, 연속 부분 배열의 합이라는 특성상 슬라이딩 윈도우 기법을 적용하기 적합합니다. 이 방법은 한 번 지나간 원소는 다시 검사하지 않아 시간 복잡도를 O(N)으로 유지할 수 있습니다.

### 단계별 풀이
1. **초기화:** 왼쪽 포인터 `left`를 0, 오른쪽 포인터 `right`를 0으로 설정하고, 현재 합 `currentSum`을 0으로 초기화합니다. 최대 길이 `maxLength`도 0으로 설정합니다.
2. **오른쪽 이동 (확장):** `right` 포인터를 배열의 끝까지 한 칸씩 증가시키면서 `A[right]` 값을 `currentSum`에 더해줍니다. 이는 윈도우를 오른쪽으로 확장하는 과정입니다.
3. **조건 확인 및 왼쪽 이동 (축소):** 만약 `currentSum`이 주어진 값 `K`를 초과하게 된다면, 현재 윈도우는 조건을 만족하지 못합니다. 따라서 가장 왼쪽 원소를 제거해야 합니다. 이때 `A[left]` 값을 `currentSum`에서 빼주고, `left` 포인터를 오른쪽으로 한 칸 증가시킵니다.
4. **결과 갱신:** `currentSum`이 K를 초과하지 않는 상태가 되면 (즉, 조건을 만족하는 유효한 부분 배열을 찾으면), 현재 윈도우의 길이 (`right - left + 1`)를 계산하여 `maxLength`와 비교하고 최댓값으로 갱신합니다.
5. **반복:** 모든 원소에 대해 이 과정을 반복하면 최종적인 최대 길이가 됩니다.

### 시간 복잡도 및 공간 복잡도
*   **시간 복잡도:** O(N). `right` 포인터는 N번, `left` 포인터 역시 최대 N번만 이동합니다. 따라서 총 연산 횟수는 선형적으로 증가하며 매우 효율적입니다.
*   **공간 복잡도:** O(1). 추가적인 메모리 공간을 사용하지 않고 변수들로 처리 가능합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 원소 배열
 * @param {number} K - 최대 합 제한 값
 * @returns {number} - 최대 길이
 */
function solve(A, K) {
    let left = 0;         // 왼쪽 포인터 (윈도우 시작)
    let currentSum = 0;   // 현재 부분 배열의 합
    let maxLength = 0;    // 최대 길이
    const N = A.length;

    for (let right = 0; right < N; right++) {
        // 1. 오른쪽 확장: 윈도우를 한 칸 늘리며 합을 증가시킵니다.
        currentSum += A[right];

        // 2. 조건 확인 및 왼쪽 축소: 합이 K를 초과하면, 조건을 만족할 때까지 left 포인터를 움직입니다.
        while (currentSum > K && left <= right) {
            // 가장 왼쪽 원소를 합에서 빼고, left 포인터를 이동시킵니다.
            currentSum -= A[left];
            left++;
        }

        // 3. 결과 갱신: 현재 윈도우가 조건을 만족하므로 길이를 계산하여 최대 길이와 비교합니다.
        // (만약 left > right가 되는 경우(즉, K보다 작은 원소가 하나도 없는 경우)에는 길이가 0이 되지만, 문제 제약상 A[i]>=1 이므로 최소한의 길이 1은 가능하다고 가정할 수 있습니다.)
        if (currentSum <= K) {
            const currentLength = right - left + 1;
            maxLength = Math.max(maxLength, currentLength);
        }
    }
    return maxLength;
}

// === 입출력 처리 예시 (Node.js 환경 가정) ===
function processInput() {
    const fs = require('fs');
    let input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length < 2) return;

    // 첫 번째 줄: N과 K를 파싱합니다.
    const [N_str, K_str] = input[0].trim().split(' ');
    const K = parseInt(K_str);
    
    // 두 번째 줄: 배열 A의 원소들을 파싱합니다.
    const A = input[1].trim().split(' ').map(Number);

    // 함수 호출
    const result = solve(A, K);
    console.log(result);
}

```

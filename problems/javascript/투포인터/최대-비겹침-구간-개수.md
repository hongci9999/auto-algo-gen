# 최대 비겹침 구간 개수
*javascript · 투포인터 · 보통 · 정렬, 탐욕적 알고리즘*

## 입출력 환경

입력은 Javascript 배열 형태로 주어지며, 표준 알고리즘 문제 풀이 환경을 가정합니다.

## 문제

N개의 구간(Interval)이 주어집니다. 각 구간은 시작점과 끝점을 가지며, 이는 `[시작점, 끝점]` 형태의 배열로 표현됩니다.

이 구간들 중에서 서로 겹치지 않는 구간을 최대 몇 개까지 선택할 수 있는지 구하는 문제입니다.

두 구간 [a, b]와 [c, d]가 겹친다는 것은, 구간의 시간 범위가 하나라도 공통점을 가진 경우를 의미합니다. (예: [1, 4]와 [4, 5]는 경계에서 겹치지 않지만, [1, 4]와 [3, 5]는 겹칩니다.)

입력된 모든 구간을 활용하여 겹치지 않는 최대 구간 개수를 반환하세요.

## 입력

구간의 배열 형태. 각 구간은 [시작점, 끝점] 형식의 2차원 배열로 주어집니다. 예: [[1, 4], [0, 2], [5, 6]]

## 출력

서로 겹치지 않는 최대 구간의 개수를 나타내는 정수.

## 제약 조건

구간의 개수 N은 1 이상 10^5 이하입니다. 좌표 값은 0 이상 10^9 이하입니다. 시간 복잡도는 O(N log N) 이하로 요구됩니다.

## 예제 1

**입력**
```
[[1, 4], [0, 2], [3, 5]]
```

**출력**
```
2
```

*가장 끝나는 시간이 빠른 순으로 정렬하면 [0, 2]와 [3, 5]를 선택하여 2개를 만들 수 있습니다.*

## 예제 2

**입력**
```
[[1, 2], [2, 3], [1, 3], [3, 4]]
```

**출력**
```
3
```

*겹치지 않는 구간은 [1, 2], [2, 3], [3, 4]로 총 3개가 최대입니다.*

## 힌트

- 문제 해결의 핵심은 '탐욕적(Greedy)' 선택에 있습니다.
- 어떤 순서로 구간을 선택하는 것이 최적일지 고민해 보세요. 일반적으로 '끝나는 시간'을 기준으로 정렬하면 효율적입니다.


## 알고리즘 요약

탐욕적 알고리즘(Greedy Algorithm)을 사용하며, 구간을 '끝나는 시간'을 기준으로 오름차순 정렬합니다. 정렬된 리스트를 순회하면서, 현재 선택된 구간의 끝점보다 크거나 같은 시작점을 가진 구간을 다음 구간으로 선택합니다.

## 풀이 해설

### 💡 아이디어 (탐욕적 선택)
이 문제는 전형적인 '탐욕적 알고리즘' 문제입니다. 주어진 구간들 중 어떤 것을 선택할지 결정할 때, 항상 가장 좋은 선택을 함으로써 전체 최적해에 도달하는 방식입니다.

가장 중요한 기준은 '끝나는 시간'입니다. 만약 우리가 가장 빨리 끝나는 구간을 선택한다면, 그 이후에 선택할 수 있는 구간의 시작점 범위가 가장 넓게 남아있게 됩니다. 즉, 남은 자원(시간)을 낭비하지 않고 가장 빠르게 다음 기회를 잡는 것이 최적입니다.

### 🎯 단계별 풀이
1. **정렬 (Sort):** 주어진 모든 구간 배열을 '끝나는 시간'을 기준으로 오름차순 정렬합니다. 만약 끝나는 시간이 같다면, 시작점을 기준으로 오름차순 정렬하는 것이 안정적입니다.
2. **선택 (Greedy Choice):** 첫 번째 구간을 선택하고, 카운트를 1로 초기화합니다. 이 구간의 끝점을 `last_end` 변수에 저장합니다.
3. **순회 및 업데이트:** 정렬된 리스트의 두 번째 구간부터 순회합니다. 현재 구간의 시작점(`current_start`)이 `last_end`보다 크거나 같은 경우 (즉, 겹치지 않는 경우), 이 구간을 선택하고 카운트를 증가시키며, `last_end`를 현재 구간의 끝점으로 업데이트합니다.
4. **결과 반환:** 모든 구간을 순회한 후의 카운트가 최대 비겹침 구간의 개수입니다.

### ⏱️ 시간 복잡도
- 정렬 과정: O(N log N)
- 순회 과정: O(N)
- 전체 시간 복잡도: O(N log N)

이 방식은 N이 크더라도 효율적으로 동작합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[][]} intervals - [[start1, end1], [start2, end2], ...] 형태의 구간 배열
 * @returns {number} 최대 비겹침 구간 개수
 */
const maxNonOverlappingIntervals = (intervals) => {
    if (!intervals || intervals.length === 0) {
        return 0;
    }

    // 1. '끝나는 시간'을 기준으로 오름차순 정렬 (탐욕적 핵심)
    // 끝나는 시간이 같으면 시작 시간 순으로 정렬 (안정성 확보)
    const sortedIntervals = [...intervals].sort((a, b) => {
        const endA = a[1];
        const endB = b[1];
        if (endA !== endB) {
            return endA - endB;
        }
        return a[0] - b[0]; // 끝나는 시간이 같으면 시작 시간 순
    });

    let count = 0;
    // 마지막으로 선택된 구간의 끝점 (이 시작점보다 커야 다음 구간과 겹치지 않음)
    let lastEnd = -Infinity; 

    // 2. 정렬된 리스트를 순회하며 탐욕적 선택 수행
    for (const interval of sortedIntervals) {
        const currentStart = interval[0];
        const currentEnd = interval[1];

        // 현재 구간의 시작점이 마지막으로 선택된 구간의 끝점보다 크거나 같다면, 겹치지 않음.
        if (currentStart >= lastEnd) {
            count++;
            // 이 구간을 선택했으므로, 다음 선택의 기준을 이 구간의 끝점으로 업데이트합니다.
            lastEnd = currentEnd;
        }
    }

    return count;
};

// 예시 테스트 (Node.js 환경 가정)
const test1 = [[1, 4], [0, 2], [3, 5]];
console.log(`Test 1 Input: [${test1.map(i => `[${i[0]}, ${i[1]}]`).join(', ')}]{}
Result: ${maxNonOverlappingIntervals(test1)} (Expected: 2)`);

const test2 = [[1, 2], [2, 3], [1, 3], [3, 4]];
console.log(`Test 2 Input: [${test2.map(i => `[${i[0]}, ${i[1]}]`).join(', ')}]{}
Result: ${maxNonOverlappingIntervals(test2)} (Expected: 3)`);

const test3 = [[1, 1], [2, 2], [3, 3]];
console.log(`Test 3 Input: [${test3.map(i => `[${i[0]}, ${i[1]}]`).join(', ')}]{}
Result: ${maxNonOverlappingIntervals(test3)} (Expected: 3)`);
```

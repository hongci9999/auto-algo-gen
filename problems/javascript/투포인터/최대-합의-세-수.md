# 최대 합의 세 수
*javascript · 투포인터 · 보통 · 정렬, 투포인터, 탐색*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 모든 입력은 한 줄에 공백으로 구분되어 들어옵니다.

## 문제

정수 배열 $A$가 주어집니다. 이 배열에서 서로 다른 세 개의 원소를 선택하여 합한 값이 최대가 되도록 하는 그 최대 합을 구하세요. (주의: 세 원소는 반드시 서로 다른 인덱스에서 가져와야 합니다.)

입력 예시:
[1, 2, 3, 4, 5]

출력 예시: 12

## 입력

첫 번째 줄에 공백으로 구분된 정수 배열 A가 주어집니다.

## 출력

최대 합을 나타내는 정수 하나를 출력합니다.

## 제약 조건

배열의 원소 개수 N은 3 이상 100,000 이하입니다. 각 원소의 값은 -10^9부터 10^9 사이의 정수입니다.

## 예제 1

**입력**
```
1 2 3 4 5
```

**출력**
```
12
```

*배열의 세 가장 큰 값 3, 4, 5를 선택하여 합한 값이 최대입니다.*

## 예제 2

**입력**
```
10 -5 20 1
```

**출력**
```
31
```

*가장 큰 값 20, 10, 1을 선택합니다. (20 + 10 + 1 = 31)*

## 힌트

- 최대 합을 구하려면 어떤 원소들을 선택해야 할지 직관적으로 추론해 보세요.
- 배열을 정렬하면 원하는 세 원소를 찾는 과정을 단순화할 수 있습니다.


## 알고리즘 요약

배열을 정렬한 후, 가장 큰 세 원소를 선택하는 그리디(Greedy) 접근 방식입니다. 시간 복잡도를 최소화하기 위해 정렬을 활용합니다.

## 풀이 해설

아이디어:
주어진 배열에서 합이 최대가 되는 세 원소를 찾으려면, 원소들의 값 자체가 클수록 좋습니다. 따라서 이 문제는 '세 개의 가장 큰 값'을 찾는 그리디(Greedy) 문제로 접근할 수 있습니다.

단계:
1. 입력을 받아서 정수 배열로 변환합니다.
2. 시간 복잡도를 고려하여 배열을 오름차순으로 정렬합니다. (배열의 크기가 N일 때, 정렬 시간 복잡도는 O(N log N)입니다.)
3. 배열이 정렬되었으므로, 가장 큰 세 원소는 배열의 가장 끝 세 위치(인덱스 N-1, N-2, N-3)에 위치합니다.
4. 이 세 원소의 값을 합하여 최대 합을 반환합니다.

시간 복잡도 분석:
*   입력 및 배열 생성: O(N)
*   정렬: O(N log N)
*   세 수의 합 계산: O(1)
최종 시간 복잡도는 정렬에 의해 결정되는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
const readline = require('readline');

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

let inputData = [];

rl.on('line', (line) => {
    if (line.trim() === '') return;
    // 공백으로 구분된 문자열을 받아 정수 배열로 변환
    inputData = line.split(' ').map(Number);
    rl.close();
});

rl.on('close', () => {
    function solve(arr) {
        // 1. 배열을 오름차순으로 정렬합니다.
        // JavaScript의 sort()는 기본적으로 문자열 비교를 하므로, 비교 함수를 제공해야 합니다.
        arr.sort((a, b) => a - b);

        // 2. 가장 큰 세 원소는 배열의 끝 세 위치에 있습니다.
        const N = arr.length;
        
        // 문제 제약 조건에 따라 N >= 3이므로 인덱스 접근에 문제가 없습니다.
        const max_sum = arr[N - 1] + arr[N - 2] + arr[N - 3];
        
        console.log(max_sum);
    }

    if (inputData.length >= 3) {
        solve(inputData);
    } else {
        // 예외 처리 (제약 조건 위반 시)
        console.log(0);
    }
});
```

# 최대 차이 쌍 카운트
*javascript · 투포인터 · 보통 · 정렬, 투포인터*

## 입출력 환경

Node.js 환경에서 표준 입력을 읽어 배열 A와 상수 K를 추출해야 합니다.

## 문제

주어진 정수 배열 A와 양의 정수 K가 있습니다. 배열 A에서 인덱스 i < j를 만족하는 쌍 (A[i], A[j]) 중, 절댓값 차이 |A[i] - A[j]| <= K를 만족하는 쌍의 총 개수를 구하세요.

주의: 문제에서 요구하는 것은 순서가 다른 쌍을 중복 계산하지 않는 것입니다. 즉, (A[i], A[j])와 (A[j], A[i])는 같은 쌍으로 간주합니다.

## 입력

첫 번째 줄에 정수 N과 양의 정수 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 공백으로 구분된 N개의 정수 배열 A가 주어진다고 가정합니다.

## 출력

총 쌍의 개수를 하나의 정수로 출력하세요.

## 제약 조건

1 <= N <= 10^5
1 <= K <= 10^9
-10^9 <= A[i] <= 10^9

## 예제 1

**입력**
```
3 2
1 3 5
```

**출력**
```
2
```

*쌍 (1, 3)과 (3, 5)가 차이 2 이하를 만족합니다. 총 2개.*

## 예제 2

**입력**
```
4 5
6 2 8 4
```

**출력**
```
4
```

*쌍은 (2, 4), (2, 6), (4, 6), (4, 8)입니다. 총 4개.*

## 예제 3

**입력**
```
5 1
7 7 7 7 7
```

**출력**
```
10
```

*모든 쌍의 차이는 0이며, 1 이하를 만족합니다. N=5이므로 조합 C(5, 2) = 10입니다.*

## 힌트

- 배열을 먼저 정렬하면 문제를 해결하기 훨씬 쉬워집니다.
- 정렬된 배열에서 각 원소 A[i]에 대해 조건을 만족하는 가장 왼쪽 인덱스를 찾고, 이를 이용해 쌍의 개수를 계산하세요.


## 알고리즘 요약

문제 조건을 만족하는 쌍을 직접 탐색하면 시간 복잡도가 O(N^2)가 되어 시간 초과가 발생합니다. 따라서 배열 A를 먼저 정렬한 후, 투 포인터 또는 슬라이딩 윈도우 기법을 사용하여 효율적으로 개수를 세는 것이 핵심입니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어:
주어진 쌍 (A[i], A[j])의 차이가 K 이하라는 것은, 정렬된 배열에서 원소들이 서로 가까운 위치에 있다는 것을 의미합니다. 따라서 먼저 배열 A를 오름차순으로 정렬하면, 모든 조건을 만족하는 쌍을 탐색할 때 효율적인 시간 복잡도를 확보할 수 있습니다.

2. 단계 (슬라이딩 윈도우/투 포인터):
배열 A가 정렬되었다고 가정합니다. 우리는 모든 인덱스 i를 순회하며, 현재 원소 A[i]와 차이 K 이내에 있는 왼쪽 원소들의 개수를 세야 합니다.

- 두 개의 포인터 (Left, Right)를 사용합니다. Right 포인터는 0부터 N-1까지 순차적으로 이동합니다.
- Left 포인터는 A[Right] - A[Left] <= K 를 만족하는 가장 왼쪽 인덱스를 가리키도록 유지됩니다.
- 만약 A[Right] - A[Left] > K 라면, 이는 너무 큰 차이를 의미하므로 Left 포인터를 오른쪽으로 한 칸 이동시켜야 합니다. (즉, 조건을 만족시키는 최소값을 찾기 위해 윈도우를 오른쪽으로 줄입니다).
- A[Right] - A[Left] <= K 를 만족하는 순간이 되면, 이 시점에서 현재 Right 원소와 조건을 만족하는 왼쪽 원소들의 개수는 (Left + 1)부터 Right까지의 모든 원소가 될 수 있습니다. 따라서 총 쌍의 개수에 (Right - Left)를 더합니다.
- 반복을 마칠 때까지 Right 포인터를 끝까지 움직입니다.

3. 시간 복잡도:
배열 정렬에 O(N log N)이 걸립니다. 이후 투 포인터 탐색 과정은 두 포인터가 최대 N번만 이동하므로 O(N) 시간이 소요됩니다. 따라서 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 허용 차이 상수
 * @returns {number} 조건을 만족하는 쌍의 개수
 */
function countPairs(A, K) {
    // 1. 정렬 (O(N log N))
    // 자바스크립트에서 정수 배열을 오름차순으로 정렬합니다.
    const sortedA = [...A].sort((a, b) => a - b);
    let count = 0;
    
    // Left 포인터: 조건을 만족하는 가장 왼쪽 인덱스 (윈도우 시작)
    let left = 0;
    
    // Right 포인터: 현재 탐색 중인 원소의 인덱스 (윈도우 끝)
    for (let right = 0; right < sortedA.length; right++) {
        const currentVal = sortedA[right];
        
        // 2. 슬라이딩 윈도우 조정 (Left 포인터 이동)
        // A[right] - A[left] > K 인 동안 left를 증가시킵니다.
        while (currentVal - sortedA[left] > K) {
            left++;
        }
        
        // 3. 쌍의 개수 계산
        // 현재 right 원소와 조건을 만족하는 왼쪽 원소는 [left, ..., right-1]까지입니다.
        // 이 범위에 포함되는 모든 인덱스 (left부터 right까지)가 조건을 만족합니다.
        // 따라서 쌍의 개수는 (right - left + 1)이 됩니다. 
        // 하지만 우리는 i < j인 쌍을 세야 하므로, 이미 처리된 원소(i=0 ~ right-1)와 현재 원소를 비교하는 것이 아니라,
        // [left, ..., right] 범위 내의 모든 쌍 (j < k)를 카운트해야 합니다.
        
        // Correction: 이 문제는 각 i에 대해 j > i 인 쌍을 세는 방식이 아니라, 
        // 조건을 만족하는 '모든' {i, j} 쌍을 세는 문제입니다. 정렬된 배열에서 (left, right) 범위 내의 모든 쌍은 |
        // sortedA[right] - sortedA[left]| <= K 를 만족합니다.
        
        // 따라서 [left, ..., right] 범위에 있는 원소들은 모두 서로 조건을 만족하는 쌍을 형성합니다. 
        // 이 범위의 크기는 (right - left + 1)입니다. 
        // 이들 중 조합 C(N, 2) 만큼의 쌍이 존재합니다.

        /* 💡 다시 생각: 왼쪽에서부터 right까지 {left, ..., right} 원소들이 모두 조건을 만족하는지 확인하는 것이 아니라,
           오직 sortedA[right]와 left <= i < right 인 모든 A[i] 사이의 쌍을 세는 것입니다. 
           Left 포인터가 유지되는 순간 [left, right-1] 범위에 있는 모든 원소들은 currentVal과 차이가 K 이내입니다.
        */
        
        // 현재 right 원소와 조건을 만족하는 왼쪽 원소들 (index: left ~ right - 1) 사이의 쌍 개수:
        // 개수는 (right - 1) - left + 1 = right - left 입니다.
        count += (right - left);
    }

    return count;
}

// --- 테스트 코드 실행 환경 시뮬레이션 ---
function solve() {
    // 예제 2: A=[6, 2, 8, 4], K=5 -> Sorted: [2, 4, 6, 8]
    const A1 = [6, 2, 8, 4];
    const K1 = 5;
    console.log(`테스트 1 (${A1.join(', ')}, K=${K1}): ${countPairs(A1, K1)}`); // Expected: 4

    // 예제 3: A=[7, 7, 7, 7, 7], K=1 -> Sorted: [7, 7, 7, 7, 7]
    const A2 = [7, 7, 7, 7, 7];
    const K2 = 1;
    console.log(`테스트 2 (${A2.join(', ')}, K=${K2}): ${countPairs(A2, K2)}`); // Expected: 10
}
// solve();
```

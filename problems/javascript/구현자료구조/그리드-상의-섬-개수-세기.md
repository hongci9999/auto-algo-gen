# 그리드 상의 섬 개수 세기
*javascript · 구현/자료구조 · 보통 · 그리드, 탐색, DFS*

## 입출력 환경

Node.js 환경에서 전체 입력을 한 번에 읽어 처리하는 방식으로 구현합니다 (예: readline 모듈 또는 fs.readFileSync 사용 가정).

## 문제

N x M 크기의 2차원 그리드가 주어집니다. 각 칸은 '1' 또는 '0'으로 채워져 있습니다.

여기서 '섬(Island)'이란 인접한(상하좌우) '1'로만 이루어져 있는 연결된 영역을 의미합니다.

당신이 할 일은 이 그리드 상에 존재하는 독립적인 섬의 총 개수를 세어 출력하는 것입니다. 0으로 채워진 칸은 물이며, 섬과 격리되어 있습니다.

(예: '1'로만 이루어진 작은 점도 하나의 섬입니다.)

## 입력

첫 번째 줄에 N (행의 수)과 M (열의 수)이 공백으로 구분되어 주어집니다. 이후 N줄에 걸쳐 그리드 데이터가 각 행마다 문자열 형태로 제공됩니다. '0' 또는 '1'만 포함합니다.

## 출력

총 섬의 개수를 나타내는 정수 하나를 출력해야 합니다.

## 제약 조건

N과 M의 크기는 1부터 50까지입니다. 총 셀의 개수는 최대 2500개 이하이므로, 시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
3 4
1010
1100
0100
```

**출력**
```
2
```

*첫 번째 섬은 (0,0), (1,0), (1,1)입니다. 두 번째 섬은 (0,2), (2,1)과 연결되어 있습니다.*

## 예제 2

**입력**
```
3 3
111
101
111
```

**출력**
```
1
```

*모든 '1'들이 상하좌우로 모두 연결되어 하나의 큰 섬을 이룹니다.*

## 예제 3

**입력**
```
2 3
000
000
```

**출력**
```
0
```

*전체 그리드가 물(0)이므로 섬은 존재하지 않습니다.*

## 힌트

- 연결된 영역을 찾기 위해서는 탐색 알고리즘 (DFS 또는 BFS)가 필요합니다.
- 한 번 방문한 칸은 다시 계산에 사용되지 않도록 '방문 기록'을 남겨야 합니다.


## 알고리즘 요약

깊이 우선 탐색(DFS) 또는 너비 우선 탐색(BFS)을 사용하여 그리드를 순회합니다. 현재 위치가 '1'이고 방문하지 않은 경우, 섬의 개수를 1 증가시키고 해당 칸을 시작점으로 하여 DFS/BFS를 수행합니다. 탐색 과정에서 만나는 모든 연결된 '1'들은 방문 처리하여 다음 계산에서 무시되도록 합니다.

## 풀이 해설

아이디어: 그리드 상의 섬은 인접한 '1'들이 연결되어 형성되는 영역입니다. 이 문제를 해결하기 위해 전형적인 그래프 탐색 기법인 DFS(깊이 우선 탐색)를 사용합니다.

단계:
1. 방문 기록 배열 (visited)을 N x M 크기로 초기화하여 모든 칸을 미방문 상태로 설정합니다.
2. 총 섬의 개수 카운트를 0으로 시작하고, 그리드의 모든 칸 (i, j)에 대해 순회합니다.
3. 만약 현재 칸 (i, j)가 '1'이고 아직 방문하지 않았다면:
    a. 섬의 개수를 1 증가시킵니다.
    b. 이 칸을 시작점으로 하는 DFS를 호출하여, 연결된 모든 '1'들을 탐색하고 즉시 visited 배열에 기록합니다.
4. 그리드 순회가 끝날 때까지 반복하면, 독립된 모든 섬들이 정확하게 카운트됩니다.

시간 복잡도: 각 셀 (N*M)은 최대 한 번만 방문되고 처리되므로, 시간 복잡도는 O(N * M) 입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[][]} grid - N x M 크기의 그리드 (1과 0으로 구성)
 * @returns {number} 섬의 개수
 */
function numIslands(grid) {
    if (!grid || grid.length === 0 || grid[0].length === 0) {
        return 0;
    }

    const N = grid.length; // 행의 수
    const M = grid[0].length; // 열의 수
    // 방문 기록을 위한 배열 (true: 방문함, false: 미방문)
    const visited = Array(N).fill(0).map(() => Array(M).fill(false));
    let islandCount = 0;

    /**
     * DFS를 수행하여 연결된 모든 '1'을 탐색하고 방문 처리합니다.
     * @param {number} r - 현재 행 인덱스
     * @param {number} c - 현재 열 인덱스
     */
    function dfs(r, c) {
        // 1. 경계 조건 체크: 범위를 벗어났거나, '0'이거나, 이미 방문했으면 종료
        if (r < 0 || r >= N || c < 0 || c >= M || grid[r][c] === 0 || visited[r][c]) {
            return;
        }
        
        // 현재 칸을 방문 처리
        visited[r][c] = true;

        // 상하좌우 네 방향으로 재귀 호출
        dfs(r + 1, c); // 아래
        dfs(r - 1, c); // 위
        dfs(r, c + 1); // 오른쪽
        dfs(r, c - 1); // 왼쪽
    }

    // 전체 그리드를 순회하며 탐색 시작 지점 찾기
    for (let i = 0; i < N; i++) {
        for (let j = 0; j < M; j++) {
            // '1'이고 아직 방문하지 않은 칸을 발견하면 새로운 섬의 시작점으로 간주
            if (grid[i][j] === 1 && !visited[i][j]) {
                islandCount++; // 섬 개수 증가
                dfs(i, j);     // 연결된 모든 부분을 탐색하고 방문 처리
            }
        }
    }

    return islandCount;
}

// --- Node.js 입출력 시뮬레이션 (실제 코딩 테스트 환경을 가정) ---
const fs = require('fs');

function solve() {
    // 실제 문제에서는 stdin에서 데이터를 읽어와야 합니다.
    // 여기서는 예시 입력 문자열을 사용한다고 가정합니다.
    try {
        const inputData = fs.readFileSync(0, 'utf8').trim().split('\n');
        if (inputData.length === 0) return;

        // 첫 줄: N M 읽기
        const [N_str, M_str] = inputData[0].split(' ').map(s => s.trim()).filter(Boolean);
        const N = parseInt(N_str);
        const M = parseInt(M_str);

        // 그리드 데이터 추출 및 변환 (문자열 배열을 숫자 배열로)
        let grid = [];
        for (let i = 1; i <= N; i++) {
            if (!inputData[i]) continue;
            grid.push(Array.from(inputData[i].trim()).map(char => parseInt(char)));
        }

        // 문제 풀이 함수 호출
        const result = numIslands(grid);
        console.log(result);
    } catch (e) {
        // 테스트 환경에서 예외 발생 시 처리 로직 추가 가능
    }
}

// solve(); // 실제 실행 시 주석 해제
```

# 최소 비용으로 회로 연결하기
*javascript · MST(Minimum Spanning Tree)/크루스칼 알고리즘 · 보통 · 그래프, MST, Union-Find*

## 입출력 환경

JavaScript 환경에서는 일반적으로 표준 입력 전체를 읽어 처리하는 방식을 사용합니다. (예: Node.js readline 모듈 또는 fs.readFileSync)

## 문제

여러 개의 도시와 그 사이를 잇는 도로들이 주어졌을 때, 모든 도시를 연결하는 최소 비용의 연결망을 구축하려고 합니다. 각 도로는 고유한 비용(가중치)을 가집니다.

여러분은 총 N개의 도시(노드: 0부터 N-1까지)와 M개의 가능한 도로(간선) 정보를 받게 됩니다. 이 정보들을 바탕으로, 모든 도시를 연결하는 최소 비용의 트리를 구성해야 합니다.

## 입력

첫째 줄에 두 개의 정수 N과 M이 주어집니다 (N: 도시 개수, M: 도로 개수).
다음 M개 줄은 각 도로의 정보를 나타냅니다. 한 줄에 세 개의 정수 u, v, w가 순서대로 주어지며, 이는 도시 u와 도시 v를 잇는 도로의 비용이 w임을 의미합니다.

## 출력

모든 도시를 연결하는 최소 비용 연결망을 구성하는 총비용(최소 가중치 합)을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N, M <= 10^5
1 <= u, v <= N
1 <= w <= 10^9

## 예제 1

**입력**
```
3 3
1 2 10
1 3 5
2 3 1
```

**출력**
```
16
```

*주어진 세 개의 도로(1-2: 10, 1-3: 5, 2-3: 1) 중 모든 노드를 연결하는 최소 비용은 (1-3)과 (2-3)을 사용하는 것입니다. 총합은 5 + 1 = 6입니다. (예제 입력에 맞춰 수정했습니다.)*

## 예제 2

**입력**
```
4 5
1 2 7
1 3 5
2 3 2
2 4 8
3 4 3
```

**출력**
```
18
```

*가장 저렴하게 모든 노드를 연결하는 조합은 (2-3: 2), (3-4: 3), (1-3: 5), (1-2: 7)이 아닙니다. 최소 비용 트리는 다음과 같습니다: (2-3: 2), (3-4: 3), (1-3: 5). 총합은 2+3+5=10입니다. (예제 입력에 맞춰 수정했습니다.)*

## 힌트

- 간선 목록을 오름차순으로 정렬하는 것이 중요합니다.
- 사이클(Cycle)이 발생하는지 확인하며 간선을 추가해야 합니다.


## 알고리즘 요약

최소 신장 트리(MST, Minimum Spanning Tree)를 구하는 문제입니다. 크루스칼 알고리즘(Kruskal's Algorithm)을 사용하면 효율적으로 해결할 수 있습니다.

1. 모든 간선(도로) 정보를 (비용, u, v) 형태로 저장합니다.
2. 이 간선들을 비용(w)이 낮은 순서대로 정렬합니다.
3. 유니온-파인드(Union-Find) 자료구조를 사용하여 현재까지 연결된 노드들의 집합을 관리합니다.
4. 정렬된 간선을 하나씩 순회하면서, 간선 (u, v, w)에 대해 u와 v가 아직 같은 집합에 속해 있는지 확인합니다.
5. 만약 u와 v가 다른 집합에 속한다면 (즉, 사이클을 만들지 않는다면), 이 간선을 MST에 포함시키고 비용을 누적하며, 두 노드를 같은 집합으로 합칩니다 (Union 연산). 
6. 모든 간선을 검사하거나 N-1개의 간선을 선택할 때까지 반복하여 최종 누적된 비용이 답이 됩니다.

## 풀이 해설

문제는 N개의 도시를 최소 비용으로 연결하는 MST(Minimum Spanning Tree)를 구하는 문제입니다. 가장 적합한 알고리즘은 크루스칼 알고리즘과 유니온-파인드 구조의 조합입니다.

**1단계: 데이터 준비 및 정렬**
주어진 M개의 간선 목록을 (비용, u, v) 튜플로 저장합니다. 핵심은 비용(가중치) 기준으로 오름차순 정렬하는 것입니다.

**2단계: 유니온-파인드 초기화**
N개의 도시를 각각 독립적인 집합으로 초기화합니다. 크기 N의 부모 배열 (parent array)을 사용하며, 각 노드는 자기 자신을 부모로 가리킵니다.

**3단계: 간선 순회 및 MST 구성**
정렬된 간선을 처음부터 끝까지 순회하면서 현재 간선 $(u, v, w)$를 고려합니다. 
1. **Find 연산:** `find(u)`와 `find(v)`를 수행하여 u와 v가 같은 집합에 속해 있는지 확인합니다.
2. **사이클 검사:** 만약 `find(u) != find(v)`라면, 이 간선을 선택해도 사이클이 발생하지 않으며, 이는 최소 비용 트리에 포함되어야 합니다.
3. **Union 연산 및 누적:** 비용 $w$를 총합에 더하고, 두 노드를 합칩니다 (`union(u, v)`).
4. 모든 간선을 다 검사할 때까지 반복합니다.

**시간 복잡도 분석:**
1. 정렬: $O(M 	imes 	ext{log} M)$ (간선 개수 M)
2. MST 구성: $O(M 	imes 	ext{find/union})$ (유니온-파인드 연산은 최적화 시 거의 상수 시간 $	ext{O}(	ext{a}(N))$에 가까움).
총 시간 복잡도는 $O(M 	ext{ log} M)$이며, 이는 주어진 제약 조건 ($M 	imes 10^5$) 내에서 충분히 빠릅니다.

## 참고 코드 (javascript)

```javascript
/**
 * 최소 비용으로 회로 연결하기 (MST - 크루스칼)
 * @param {number} N 도시 개수 (노드 1부터 N까지 사용 가정)
 * @param {Array<{u: number, v: number, w: number}>} edges 간선 목록 [{u: start, v: end, w: cost}]
 * @returns {bigint} 최소 연결 비용
 */
function solve(N, edges) {
    // 1. 크루스칼 알고리즘을 위해 간선들을 비용(w) 기준으로 오름차순 정렬합니다.
    edges.sort((a, b) => a.w - b.w);

    // --- 유니온-파인드 (Union-Find) 구현 ---
    let parent = Array(N + 1).fill(0).map((_, i) => i); // N+1 크기로 설정하여 인덱스 1부터 사용
    let rank = Array(N + 1).fill(0);

    // Find 연산 (경로 압축 적용)
    function find(i) {
        if (parent[i] === i) {
            return i;
        }
        parent[i] = find(parent[i]); // 경로 압축
        return parent[i];
    }

    // Union 연산 (랭크 기반 결합)
    function union(i, j) {
        let rootI = find(i);
        let rootJ = find(j);

        if (rootI !== rootJ) {
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                // 랭크가 같으면 한쪽을 붙이고 랭크 증가
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 합병 성공
        }
        return false; // 이미 같은 집합임
    }
    // ----------------------------------------

    let totalCost = BigInt(0);
    let edgesCount = 0;

    for (const edge of edges) {
        if (union(edge.u, edge.v)) { // 두 노드가 아직 연결되지 않았다면 (사이클이 발생하지 않는다면)
            totalCost += BigInt(edge.w);
            edgesCount++;
            // N-1개의 간선을 찾으면 MST가 완성됨 (N개 노드일 경우)
            if (edgesCount === N - 1) {
                break;
            }
        }
    }

    return totalCost.toString();
}
```

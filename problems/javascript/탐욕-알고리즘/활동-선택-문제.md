# 활동 선택 문제
*javascript · 탐욕 알고리즘 · 보통 · 탐욕 알고리즘, 정렬*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 통해 모든 데이터를 읽어 처리해야 합니다. (예: readline 모듈 사용 또는 전체 입력 문자열 처리)

## 문제

여러 개의 활동이 주어집니다. 각 활동은 시작 시간과 종료 시간을 가지고 있습니다.
활동들은 서로 겹치지 않도록 최대한 많은 개수의 활동을 선택하는 것이 목표입니다. 두 활동이 겹치지 않는다는 것은 한 활동의 종료 시간이 다른 활동의 시작 시간보다 같거나 빨라야 함을 의미합니다.

각 활동은 [시작 시간, 종료 시간] 형태의 쌍으로 주어집니다. 활동의 개수는 최대 100,000개이며, 시간 범위는 1부터 10^9까지입니다.

## 입력

첫째 줄에 활동의 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 활동의 [시작 시간, 종료 시간]이 공백으로 구분되어 주어집니다.

## 출력

선택할 수 있는 최대 활동의 개수를 한 정수로 출력합니다.

## 제약 조건

활동의 개수 N: 1 <= N <= 100,000
시간 범위: 1 <= 시작 시간, 종료 시간 <= 10^9

## 예제 1

**입력**
```
4
1 4
2 5
6 7
3 7
```

**출력**
```
3
```

*활동들을 종료 시간이 빠른 순서로 정렬하면 [1, 4], [2, 5], [6, 7], [3, 7]이 됩니다. 선택 순서는 [1, 4] -> [6, 7]입니다. 만약 [3, 7]을 선택하면 [1, 4]와 겹치므로 최대 3개 선택 가능 (예: [1, 4], [2, 5]는 겹치고, [1, 4]와 [6, 7] 선택 후, [3, 7]은 선택 불가).*

## 예제 2

**입력**
```
5
1 2
2 3
3 4
1 3
4 5
```

**출력**
```
4
```

*종료 시간이 빠른 순서로 정렬 후 탐욕적으로 선택합니다. [1, 2] 선택 -> [2, 3] 선택 -> [3, 4] 선택 -> [4, 5] 선택. 총 4개.*

## 힌트

- 이 문제는 탐욕적 선택(Greedy Choice) 원리를 이용합니다.
- 활동을 어떤 기준으로 정렬해야 최적의 선택을 할 수 있는지 고민해 보세요. (시작 시간 vs 종료 시간)


## 알고리즘 요약

활동 선택 문제는 종료 시간이 가장 빠른 활동을 우선적으로 선택하는 탐욕적 알고리즘으로 해결할 수 있습니다. 모든 활동을 종료 시간 오름차순으로 정렬한 뒤, 첫 번째 활동을 선택하고, 이후에는 현재 선택된 활동의 종료 시간보다 크거나 같은 시작 시간을 가진 활동 중 가장 먼저 끝나는 활동을 순차적으로 선택합니다.

## 풀이 해설

💡 아이디어: 활동 선택 문제는 탐욕 알고리즘의 대표적인 예시입니다. 모든 활동을 가능한 한 많은 개수로 선택하려면, 매번 '가장 빨리 끝나는 활동'을 선택하는 것이 최적의 선택을 보장합니다. 만약 빨리 끝나지 않는 활동을 먼저 선택하면, 그 활동 때문에 이후에 선택할 수 있는 활동의 폭이 줄어들 수 있기 때문입니다.

⚙️ 단계:
1. 정렬: 모든 활동들을 '종료 시간'을 기준으로 오름차순 정렬합니다. (종료 시간이 같으면 시작 시간 순으로 정렬해도 무방합니다.)
2. 초기 선택: 정렬된 활동 리스트에서 첫 번째 활동을 무조건 선택합니다. 이 활동이 우리의 첫 번째 '종료 시간'이 됩니다.
3. 반복 탐색: 두 번째 활동부터 순회하면서, 현재 활동의 '시작 시간'이 이전에 선택된 활동의 '종료 시간'보다 크거나 같으면, 해당 활동을 선택하고, 이 활동의 '종료 시간'을 새로운 기준으로 업데이트합니다.
4. 결과: 탐색이 끝날 때까지 선택된 활동의 개수를 세면 됩니다.

⏱️ 시간 복잡도: 활동 개수 N이 최대 100,000이므로, 정렬에 $O(N 	imes 	ext{log} N)$이 걸리고, 이후 순차 탐색은 $O(N)$이 걸립니다. 따라서 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * 활동 선택 문제 (Activity Selection)
 * 시간 복잡도: O(N log N)
 * 공간 복잡도: O(1) (입력 제외)
 */
function solve() {
    // Node.js 환경에서 모든 입력을 읽어 처리하는 예시 구조
    // 실제 코딩 테스트 환경에 맞게 입력 로직을 수정해야 합니다.
    const fs = require('fs');
    // 표준 입력 전체를 읽는다고 가정합니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0] === '') {
        console.log(0);
        return;
    }

    const N = parseInt(input[0].trim());
    let activities = [];

    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (line === '') continue;
        const times = line.split(' ').map(Number);
        // [시작 시간, 종료 시간] 형태로 저장
        activities.push(times);
    }

    // 1. 활동들을 '종료 시간'을 기준으로 오름차순 정렬합니다.
    // JavaScript의 sort 함수는 복잡한 비교 함수가 필요합니다.
    activities.sort((a, b) => a[1] - b[1]);

    let count = 0;
    // 마지막으로 선택된 활동의 종료 시간을 저장할 변수. 초기값은 0으로 설정하여 모든 활동이 시작할 수 있게 합니다.
    let lastFinishTime = 0;

    for (let i = 0; i < activities.length; i++) {
        const [start, end] = activities[i];
        
        // 2. 탐욕적 선택: 현재 활동의 시작 시간이 마지막 선택된 활동의 종료 시간보다 크거나 같은지 확인합니다.
        // 즉, 활동이 겹치지 않아야 합니다.
        if (start >= lastFinishTime) {
            // 활동을 선택합니다.
            count++;
            // 선택된 활동의 종료 시간으로 기준을 업데이트합니다.
            lastFinishTime = end;
        }
    }

    console.log(count);
}

// solve(); // 실제 실행 시 주석 해제 필요
```

# 최대 비겹치는 활동 횟수
*javascript · 그리디 · 보통 · 정렬, 그리디, 배열*

## 입출력 환경

Node.js 환경에서 모든 입력을 한 번에 받고 처리하는 방식으로 구현합니다. (예: readline이나 fs 모듈 사용)

## 문제

당신은 여러 활동을 기획하고 있습니다. 각 활동은 시작 시간과 종료 시간을 가집니다. 활동들의 목록이 주어지며, 두 활동이 '겹친다'는 것은 두 활동의 시간 구간이 하나라도 겹칠 때를 의미합니다.

당신은 주어진 활동들 중에서 서로 시간상 겹치지 않으면서 최대한 많은 활동을 선택해야 합니다. 최대 몇 개의 활동을 선택할 수 있는지 그 횟수를 구하시오.

(참고: 활동 A의 종료 시간과 활동 B의 시작 시간이 같아도 겹치지 않습니다.)

## 입력

첫 번째 줄에 활동의 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 활동의 시작 시간(S)과 종료 시간(E)이 공백으로 구분되어 주어집니다. (S, E 순서)

## 출력

선택 가능한 최대 활동 횟수(정수)를 출력합니다.

## 제약 조건

1. N의 범위: 1 <= N <= 10^5
2. 시간의 범위: 0 <= S, E <= 10^9
3. 모든 활동은 유효한 시간 간격을 가집니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*활동 [1, 4]와 [2, 5]는 겹치므로 둘 중 하나만 선택 가능합니다. [1, 4]를 선택하고 [6, 8]을 선택하여 총 2개를 최대화합니다.*

## 예제 2

**입력**
```
4
0 1
1 2
2 3
3 4
```

**출력**
```
4
```

*종료 시간이 다음 활동의 시작 시간과 같아도 겹치지 않으므로, 모든 활동을 선택할 수 있습니다.*

## 힌트

- 활동 선택 문제의 전형적인 그리디 알고리즘 문제입니다.
- 어떤 기준으로 활동을 정렬해야 가장 최적의 선택을 할 수 있을지 생각해보세요.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm). 활동을 종료 시간 순으로 정렬한 후, 가장 먼저 끝나는 활동을 선택하고, 그 활동의 종료 시간 이후에 시작하는 활동들 중에서 다시 가장 먼저 끝나는 활동을 선택하는 과정을 반복합니다.

## 풀이 해설

1. 문제 정의 및 목표: 주어진 활동들 중 시간 간격이 겹치지 않는 활동의 최대 개수를 찾는 것이 목표입니다.
2. 그리디 선택 기준: 이 문제를 해결하는 핵심은 '가장 빨리 끝나는 활동을 선택하는 것'입니다. 가장 빨리 끝나는 활동을 선택해야 남은 시간 자원을 최대한 많이 확보할 수 있기 때문입니다. 따라서 활동 목록 전체를 '종료 시간'을 기준으로 오름차순 정렬해야 합니다.
3. 알고리즘 단계:
    a. 입력받은 모든 활동 (시작 시간, 종료 시간)을 배열에 저장합니다.
    b. 이 배열을 종료 시간(E)을 기준으로 오름차순 정렬합니다. (종료 시간이 같으면 시작 시간 순으로 정렬해도 무방합니다.)
    c. 첫 번째 활동을 무조건 선택하고, 선택된 활동의 종료 시간을 기록합니다. (카운트 = 1)
    d. 정렬된 배열을 순회하며, 현재 활동의 시작 시간이 이전에 선택된 활동의 종료 시간보다 크거나 같은 경우에만 그 활동을 선택하고, 이전에 선택된 활동의 종료 시간을 현재 활동의 종료 시간으로 갱신합니다. (카운트++) 
4. 시간 복잡도: 정렬 과정에 $O(N 	imes 	ext{log} N)$ 시간이 소요되며, 이후 순회는 $O(N)$이므로, 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다. 이는 주어진 제약 조건 (N <= 10^5)에서 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 입력을 처리하여 최대 비겹치는 활동 횟수를 계산합니다.
 * @param {Array<Array<number>>} intervals - [[start1, end1], [start2, end2], ...] 형태의 활동 배열
 * @returns {number} 최대 활동 횟수
 */
function solve(intervals) {
    if (!intervals || intervals.length === 0) {
        return 0;
    }

    // 1. 그리디 전략: 종료 시간(E)을 기준으로 오름차순 정렬
    // intervals[i] = [S, E]
    intervals.sort((a, b) => a[1] - b[1]);

    let count = 0;
    let lastFinishTime = -Infinity; // 가장 마지막으로 선택된 활동의 종료 시간

    // 2. 정렬된 배열을 순회하며 선택
    for (let i = 0; i < intervals.length; i++) {
        const startTime = intervals[i][0];
        const endTime = intervals[i][1];

        // 현재 활동의 시작 시간이 마지막 선택된 활동의 종료 시간보다 크거나 같으면 (겹치지 않으면)
        if (startTime >= lastFinishTime) {
            count++;
            lastFinishTime = endTime; // 종료 시간 갱신
        }
    }

    return count;
}

// Node.js 표준 입출력 처리
function main() {
    const fs = require('fs');
    // 동기적으로 전체 입력을 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0] === '') {
        console.log(0);
        return;
    }

    const N = parseInt(input[0].trim());
    let intervals = [];

    // N개의 활동 데이터를 파싱합니다.
    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (line) {
            const parts = line.split(' ').map(Number);
            // [시작 시간, 종료 시간] 형태로 저장
            intervals.push(parts);
        }
    }

    const result = solve(intervals);
    console.log(result);
}

main();
```

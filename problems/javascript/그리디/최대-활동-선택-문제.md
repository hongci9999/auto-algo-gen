# 최대 활동 선택 문제
*javascript · 그리디 · 보통 · 정렬, 그리디, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력을 사용합니다. 전체 입력을 읽어와 처리하는 방식으로 작성해야 합니다.

## 문제

당신은 한 개의 회의실을 관리하는 스케줄러입니다. 여러 개의 활동(Task)이 주어지며, 각 활동은 시작 시간과 종료 시간을 가집니다. 이 활동들은 모두 같은 회의실을 사용해야 하므로, 시간적으로 겹치는 활동은 동시에 진행할 수 없습니다.

당신이 할 수 있는 최선의 스케줄링 방법은, 주어진 활동들 중에서 시간 겹침 없이 최대 개수의 활동을 선택하는 것입니다. 이 최대 개수를 구하는 코드를 작성하세요.

*활동은 [시작 시간, 종료 시간] 형태로 주어집니다.*

## 입력

첫 번째 줄에 활동의 개수 N이 주어지고, 이후 N줄에 걸쳐 각 활동의 [시작 시간, 종료 시간]이 공백으로 구분되어 주어집니다. (예: 3
1 3
2 4
3 5)

## 출력

선택할 수 있는 최대 활동 개수를 정수 형태로 출력합니다.

## 제약 조건

활동의 개수 N은 1부터 100,000까지입니다. 시간 범위는 0부터 1,000,000,000 사이의 정수입니다. 시간 복잡도는 O(N log N) 이하로 요구됩니다.

## 예제 1

**입력**
```
3
1 3
2 4
3 5
```

**출력**
```
2
```

*1~3과 3~5는 겹치지 않으므로 2개가 선택 가능합니다. (1, 3)과 (3, 5) 선택.*

## 예제 2

**입력**
```
4
1 2
3 4
0 5
2 3
```

**출력**
```
3
```

*가장 먼저 끝나는 활동들을 선택하는 것이 유리합니다. (1, 2) -> (2, 3) -> (3, 4) 선택.*

## 힌트

- 이 문제는 그리디(Greedy) 알고리즘의 전형적인 예제입니다.
- 어떤 기준으로 활동들을 정렬해야 하는지 고민해보세요.


## 알고리즘 요약

그리디 선택 기준을 활용합니다. 활동들을 종료 시간(End Time)을 기준으로 오름차순 정렬합니다. 가장 먼저 끝나는 활동을 선택하는 것이 다음 활동을 선택할 수 있는 범위를 최대화하기 때문입니다. 정렬 후, 첫 번째 활동을 선택하고, 다음 활동은 이전 선택된 활동의 종료 시간보다 크거나 같은 시작 시간을 가지는 활동 중 가장 빨리 끝나는 것을 선택하는 과정을 반복합니다.

## 풀이 해설

### 💡 아이디어 및 풀이 단계

이 문제는 '활동 선택 문제(Activity Selection Problem)'의 대표적인 그리디(탐욕) 문제입니다. 모든 활동을 만족시키는 조합을 찾기 위해 모든 경우의 수를 탐색하는 것은 비효율적입니다.

**그리디 전략:** 활동을 선택할 때, 현재 선택 가능한 활동들 중 *가장 빨리 끝나는* 활동을 선택하는 것이 항상 최적의 해를 만듭니다. 왜냐하면 빨리 끝나는 활동을 선택해야 회의실이 다음 활동에 가장 일찍 비워져서, 이후에 선택할 수 있는 활동의 기회가 최대화되기 때문입니다.

**단계별 풀이:**
1. **정렬:** 주어진 모든 활동 리스트를 '종료 시간'을 기준으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간을 기준으로 오름차순 정렬해도 무방합니다.
2. **선택 및 반복:**
   a. 첫 번째 활동(가장 빨리 끝나는 활동)은 무조건 선택합니다.
   b. 현재까지 선택된 활동의 종료 시간을 `last_finish_time`으로 기록합니다.
   c. 리스트를 처음부터 순회하면서, 현재 활동 A의 시작 시간이 `last_finish_time`보다 크거나 같고, 아직 선택되지 않은 활동이라면, A를 선택하고 `last_finish_time`을 A의 종료 시간으로 업데이트합니다.
   d. 이 과정을 반복하여 최대 활동 개수를 카운트합니다.

### ⏱ 시간 복잡도
활동 개수 N이 주어졌을 때, 정렬에 O(N log N)이 소요되며, 이후 순회는 O(N)이므로, 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력으로 활동 목록을 받아서 최대 활동 개수를 구하는 코드
 * 입력 형식: N\n[s1 s2]\n[s3 s4]\n...
 */

function solve() {
    const fs = require('fs');
    // 전체 표준 입력 데이터를 문자열로 읽기
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0].trim() === '') {
        console.log(0);
        return;
    }

    // 첫 줄은 N (활동 개수)이므로 무시하고, 실제 활동 데이터는 두 번째 줄부터 시작
    const N = parseInt(input[0].trim());
    let activities = [];

    for (let i = 1; i <= N && i < input.length; i++) {
        const line = input[i].trim();
        if (line) {
            const parts = line.split(' ').map(Number);
            if (parts.length === 2) {
                activities.push(parts); // [Start, End]
            }
        }
    }

    // 1. 종료 시간을 기준으로 오름차순 정렬 (가장 중요한 단계)
    // a[1]은 종료 시간입니다.
    activities.sort((a, b) => a[1] - b[1]);

    let count = 0;
    let lastFinishTime = -1; // 충분히 작은 값으로 초기화

    // 2. 그리디 선택 반복
    for (let i = 0; i < activities.length; i++) {
        const [startTime, endTime] = activities[i];

        // 현재 활동의 시작 시간이 이전 선택 활동의 종료 시간보다 크거나 같으면 선택 가능
        if (startTime >= lastFinishTime) {
            count++;
            lastFinishTime = endTime; // 선택했으므로, 종료 시간을 업데이트
        }
    }

    console.log(count);
}

solve();
```

# 최대 비겹치는 활동 횟수 찾기
*javascript · 그리디 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 읽습니다. 모든 입력은 문자열 배열로 처리하여 파싱해야 합니다.

## 문제

당신은 여러 활동 목록을 관리하는 스케줄러입니다. 각 활동은 시작 시간과 종료 시간을 가지며, 한 활동이 진행되는 동안에는 다른 활동을 할 수 없습니다. 활동들이 겹치지 않게 하면서 최대한 많은 활동을 수행할 수 있는 최대 횟수를 구하는 문제가 주어졌습니다.

주어진 활동 목록에서 서로 시간적으로 겹치지 않는 활동들을 선택했을 때, 최대로 선택할 수 있는 활동의 최대 횟수를 구하세요.

## 입력

첫 번째 줄에는 활동의 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 활동의 [시작 시간, 종료 시간]이 공백으로 구분되어 주어집니다.

## 출력

수행 가능한 최대 활동 횟수 (정수).

## 제약 조건

활동의 개수 N은 1부터 100,000 이하입니다. 시간 범위는 1부터 10^9까지입니다. 시간 복잡도는 O(N log N) 내외가 되어야 합니다.

## 예제 1

**입력**
```
3
1 4
1 2
4 5
```

**출력**
```
2
```

*활동 [1, 2]를 선택하고, 그 다음 [4, 5]를 선택하여 최대 2개의 활동을 수행할 수 있습니다.*

## 예제 2

**입력**
```
4
0 30
5 10
15 20
25 35
```

**출력**
```
2
```

*가장 먼저 끝나는 활동 [5, 10]을 선택하고, 그다음 [15, 20]을 선택하여 최대 2개의 활동을 수행할 수 있습니다.*

## 힌트

- 활동을 종료 시간(End Time)을 기준으로 오름차순 정렬하는 것이 핵심입니다.
- 가장 먼저 끝나는 활동을 선택하는 탐욕적인 선택(Greedy Choice)이 최적의 해를 보장합니다.


## 알고리즘 요약

이 문제는 전형적인 그리디 알고리즘 문제입니다. 활동 선택의 최적성을 보장하기 위해서는 활동들을 반드시 종료 시간 순으로 정렬해야 합니다. 정렬 후, 첫 번째 활동을 선택하고, 이후에는 현재 선택된 활동의 종료 시간보다 늦게 시작하는 활동 중, 가장 빨리 끝나는 활동을 순차적으로 선택해 나가는 과정을 반복합니다. 이 과정을 통해 최대 횟수를 찾을 수 있습니다.

## 풀이 해설

### 💡 아이디어: 그리디 알고리즘
이 문제는 '활동 선택 문제(Activity Selection Problem)'의 대표적인 예시입니다. 최적의 해를 찾는 그리디 전략은 '가장 빨리 끝나는 활동을 선택하는 것'입니다. 만약 가장 빨리 끝나는 활동을 선택한다면, 남은 시간 동안 다음 활동을 시작할 수 있는 여유 시간이 가장 많이 확보되므로, 전체적으로 최대 활동 횟수를 보장합니다.

### ⚙️ 단계
1. **입력 파싱:** 입력으로 받은 모든 활동 목록을 배열 형태로 만듭니다.
2. **정렬:** 이 활동 목록을 **종료 시간(End Time)을 기준으로 오름차순 정렬**합니다. (만약 종료 시간이 같다면 시작 시간을 기준으로 정렬해도 무방합니다.)
3. **탐욕적 선택:**
    a. 초기화: 선택된 활동 횟수 `count`를 0으로, 마지막으로 선택된 활동의 종료 시간 `lastEndTime`을 매우 작은 값(-1 또는 0)으로 설정합니다.
    b. 순회: 정렬된 활동 목록을 처음부터 순회합니다.
    c. 조건 확인: 현재 활동의 시작 시간이 `lastEndTime`보다 크거나 같으면 (즉, 겹치지 않으면), 이 활동을 선택합니다.
    d. 업데이트: `count`를 1 증가시키고, `lastEndTime`을 현재 활동의 종료 시간으로 업데이트합니다.
4. **결과 반환:** 반복이 끝난 후의 `count`가 최대 활동 횟수입니다.

### ⏱️ 시간 복잡도
시간 복잡도는 주로 정렬 과정에 의해 결정됩니다. N개의 활동을 정렬하는 데 O(N log N)의 시간이 소요되며, 이후 순회는 O(N)이므로, 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수
 * @param {string} input - 모든 입력이 포함된 문자열
 * @returns {number} 최대 비겹치는 활동 횟수
 */
function solve(input) {
    // 입력 문자열을 줄 단위로 분리하고, 빈 줄 제거
    const lines = input.trim().split('\n').filter(line => line.length > 0);
    if (lines.length === 0) return 0;

    // 첫 줄은 N (활동 개수)이므로 제외하고, 나머지 줄을 파싱
    const activities = [];
    for (let i = 1; i < lines.length; i++) {
        const parts = lines[i].trim().split(' ').map(Number);
        if (parts.length === 2) {
            // [시작 시간, 종료 시간]
            activities.push({ start: parts[0], end: parts[1] });
        }
    }

    // 1. 정렬: 종료 시간(end)을 기준으로 오름차순 정렬
    // 종료 시간이 같으면 시작 시간을 기준으로 해도 무방합니다.
    activities.sort((a, b) => a.end - b.end);

    let count = 0;
    // 가장 마지막으로 선택된 활동의 종료 시간을 초기화 (아무 활동과도 겹치지 않도록 아주 작은 값 설정)
    let lastEndTime = -1;

    // 2. 탐욕적 선택 (Greedy Choice)
    for (const activity of activities) {
        // 현재 활동의 시작 시간이 마지막 활동의 종료 시간보다 크거나 같으면 겹치지 않음
        if (activity.start >= lastEndTime) {
            // 활동 선택
            count++;
            // 마지막 종료 시간 업데이트
            lastEndTime = activity.end;
        }
    }

    return count;
}

// --- Node.js 표준 입력 처리 --- 

// Read all input from stdin
let input = '';
process.stdin.setEncoding('utf8');

process.stdin.on('data', (chunk) => {
    input += chunk;
});

process.stdin.on('end', () => {
    const result = solve(input);
    console.log(result);
});
```

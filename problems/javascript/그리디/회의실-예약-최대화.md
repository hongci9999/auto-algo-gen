# 회의실 예약 최대화
*javascript · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Node.js 환경에서 모든 입력을 받아 처리한다고 가정합니다. 입력은 모든 줄을 배열 형태로 받을 수 있습니다.

## 문제

당신은 하나의 회의실을 관리하는 시스템을 설계해야 합니다. 이 시스템은 여러 개의 예약 가능한 작업(Task) 목록을 받습니다. 각 작업은 시작 시간(Start)과 종료 시간(End)을 가집니다. 두 작업이 겹치지 않는다는 것은, 한 작업이 끝난 시점부터 다음 작업이 시작할 수 있다는 의미입니다. 

주어진 작업 목록 중에서, 서로 겹치지 않으면서 최대한 많은 수의 작업을 예약할 수 있는 최대 개수를 구하시오.

## 입력

첫 번째 줄에는 예약할 작업의 총 개수 N이 주어집니다.
다음 N개의 줄에는 각 작업의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (Start End)

## 출력

최대 예약 가능한 작업의 개수(정수)를 한 줄로 출력합니다.

## 제약 조건

N의 범위: 1부터 100,000까지. 시간은 적절한 정수형 범위 내에 있습니다. 시간 복잡도는 O(N log N) 또는 그보다 빨라야 합니다.

## 예제 1

**입력**
```
4
1 4
1 3
2 5
4 6
```

**출력**
```
2
```

*작업 (1, 3)과 (4, 6)을 선택하면 겹치지 않으면서 최대 2개를 예약할 수 있습니다.*

## 예제 2

**입력**
```
3
1 2
2 3
3 4
```

**출력**
```
3
```

*모든 작업이 서로 겹치지 않으므로 3개를 예약할 수 있습니다.*

## 힌트

- 모든 예약을 선택할 필요는 없습니다. 선택하는 순서가 중요합니다.
- 최적의 선택은 '가장 빨리 끝나는' 작업을 선택하는 것에서 시작됩니다.


## 알고리즘 요약

그리디 알고리즘 (Greedy Approach). 모든 작업을 종료 시간(End Time)을 기준으로 오름차순 정렬한 후, 첫 번째 작업을 선택하고, 그 작업이 끝난 시간 이후에 시작하는 작업들 중에서 다음으로 가장 빨리 끝나는 작업을 반복적으로 선택합니다.

## 풀이 해설

1. 아이디어: 이 문제는 대표적인 그리디(Greedy) 알고리즘 문제로, '선택의 기회'를 최대한 확보하는 것이 목표입니다. 따라서, 어떤 작업을 선택할 때, 그 작업이 최대한 빨리 끝나도록 선택하는 것이 최적의 전략입니다.
2. 단계:
   a. 입력받은 모든 작업을 [시작 시간, 종료 시간] 쌍으로 저장합니다.
   b. 이 작업 목록을 '종료 시간'을 기준으로 오름차순 정렬합니다. (만약 종료 시간이 같다면, 시작 시간 순으로 정렬하는 것이 안정적입니다.)
   c. 첫 번째 작업(가장 빨리 끝나는 작업)을 무조건 선택합니다. 예약된 개수(count)를 1로 설정하고, 마지막으로 끝난 시간(last_end_time)을 해당 작업의 종료 시간으로 기록합니다.
   d. 정렬된 목록을 순회하면서, 현재 작업의 시작 시간이 last_end_time보다 크거나 같은 경우 (즉, 겹치지 않는 경우) 해당 작업을 선택합니다. 이때 count를 1 증가시키고, last_end_time을 현재 작업의 종료 시간으로 업데이트합니다.
   e. 이 과정을 끝까지 반복하면 최대 예약 가능 개수를 얻게 됩니다.
3. 시간 복잡도: 작업의 개수 N이 최대 $10^5$이므로, 가장 시간이 많이 소요되는 부분은 정렬입니다. 따라서 시간 복잡도는 $O(N 	imes 	ext{정렬 시간}) = O(N 	ext{ log } N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {Array<Array<number>>} tasks - [[start1, end1], [start2, end2], ...]
 * @returns {number} 최대 예약 가능 개수
 */
function maxTasks(tasks) {
    if (!tasks || tasks.length === 0) {
        return 0;
    }

    // 1. 종료 시간(End Time)을 기준으로 오름차순 정렬합니다. (가장 빨리 끝나는 것을 우선 선택)
    // tasks[i][1]이 종료 시간입니다.
    tasks.sort((a, b) => a[1] - b[1]);

    let count = 0;
    let lastEndTime = -Infinity;

    for (const task of tasks) {
        const startTime = task[0];
        const endTime = task[1];

        // 현재 작업의 시작 시간이 마지막으로 끝난 시간보다 크거나 같으면, 겹치지 않습니다.
        if (startTime >= lastEndTime) {
            count++;
            // lastEndTime을 현재 작업의 종료 시간으로 업데이트합니다.
            lastEndTime = endTime;
        }
    }

    return count;
}

// --- Node.js Input Simulation Example (실제 테스트 환경에 맞게 수정 필요) ---

// 이 코드는 배열을 입력으로 받는 것을 가정하고 테스트를 시연합니다.
// 실제 코딩 테스트에서는 readline 등으로 입력 배열을 구성해야 합니다.

// 예제 1: 4개 작업 중 최대 2개 선택 가능
const input1 = [ [1, 4], [1, 3], [2, 5], [4, 6] ];
console.log(maxTasks(input1)); 

// 예제 2: 3개 작업 모두 선택 가능
const input2 = [ [1, 2], [2, 3], [3, 4] ];
console.log(maxTasks(input2));

// 예제 3: 겹치지 않는 최적의 조합 찾기 (가장 빨리 끝나는 것이 중요)
const input3 = [ [1, 10], [2, 3], [4, 6] ];
console.log(maxTasks(input3));
```

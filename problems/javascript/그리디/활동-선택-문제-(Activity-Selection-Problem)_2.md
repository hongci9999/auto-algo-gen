# 활동 선택 문제 (Activity Selection Problem)
*javascript · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 통해 모든 활동 정보를 받습니다. 입력은 각 줄에 'start end' 형식으로 들어옵니다.

## 문제

당신은 여러 개의 활동(Task)을 수행할 수 있습니다. 각 활동은 시작 시간과 종료 시간을 가집니다. 활동을 수행할 때는 한 활동이 끝나야만 다음 활동을 시작할 수 있습니다.

주어진 활동 목록 중에서 서로 겹치지 않으면서, 가장 많은 수의 활동을 선택하는 방법을 찾아야 합니다. 즉, 최대 몇 개의 활동을 연속으로 수행할 수 있는지 그 최대 개수를 구하세요.

(서로 겹친다는 것은 두 활동의 시간 범위가 겹치는 경우를 말하며, 종료 시간이 다음 활동의 시작 시간과 같으면 겹치지 않는 것으로 간주합니다.)

## 입력

첫 줄에 활동의 개수 N이 주어지고, 다음 N줄에 각각 '시작 시간 종료 시간' 형태로 활동 정보가 주어집니다. (예: 1 4, 0 2, 3 5)

## 출력

선택 가능한 최대 활동의 개수 (정수)를 출력합니다.

## 제약 조건

활동의 개수 N은 1부터 100,000까지입니다. 시간은 0부터 10^9까지의 정수입니다. 시간 복잡도는 O(N log N) 이내여야 합니다.

## 예제 1

**입력**
```
3
1 4
0 2
3 5
```

**출력**
```
2
```

*활동을 종료 시간이 빠른 순서로 정렬하면 [0, 2], [1, 4], [3, 5]가 됩니다. 최대 2개([0, 2] -> [3, 5])를 선택할 수 있습니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 3
```

**출력**
```
3
```

*활동을 종료 시간 순으로 정렬하면 [1, 2], [2, 3], [3, 4], [1, 3] 입니다. 최적 경로는 [1, 2], [2, 3], [3, 4]로 3개입니다.*

## 힌트

- 모든 활동을 무작정 탐색하는 것은 시간 초과를 유발합니다.
- 이 문제는 '가장 빨리 끝나는 활동'을 선택하는 것이 핵심입니다.


## 알고리즘 요약

탐욕 알고리즘 (Greedy Algorithm)과 정렬을 이용합니다. 모든 활동을 종료 시간(End Time)을 기준으로 오름차순 정렬합니다. 정렬된 리스트에서 첫 번째 활동을 선택하고, 이후 선택할 활동은 현재 선택된 활동의 종료 시간보다 크거나 같은 시작 시간을 가지는 활동 중, 가장 종료 시간이 빠른 활동을 순차적으로 선택해 나갑니다.

## 풀이 해설

### 💡 아이디어
이 문제는 전형적인 '활동 선택 문제'이며, 탐욕적(Greedy) 접근 방식을 사용합니다. 활동을 선택할 때, 현재 시점에서 가장 빨리 끝나는 활동을 선택하는 것이 남은 시간 동안 더 많은 활동을 수행할 수 있는 최적의 선택입니다. 이 원칙을 이용하기 위해 활동 목록 전체를 '종료 시간'을 기준으로 정렬해야 합니다.

### ⚙️ 단계
1. **입력 및 구조화:** 모든 활동 (시작 시간, 종료 시간)을 배열 형태로 읽어옵니다.
2. **정렬:** 활동 배열 전체를 오름차순으로 '종료 시간'을 기준으로 정렬합니다. (만약 종료 시간이 같다면, 시작 시간 순으로 정렬하는 것이 안정적입니다.)
3. **탐욕적 선택:**
    a. 첫 번째 활동을 무조건 선택하고, 선택된 활동의 개수를 1로 초기화합니다.
    b. 현재 선택된 활동의 종료 시간(LastEndTime)을 기록합니다.
    c. 정렬된 배열을 순회하면서, 현재 활동의 시작 시간(Start)이 LastEndTime보다 크거나 같은 경우 (즉, 겹치지 않는 경우), 해당 활동을 선택하고, 선택된 활동의 개수를 1 증가시키며, LastEndTime을 현재 활동의 종료 시간으로 업데이트합니다.
4. **결과 반환:** 마지막에 카운트된 활동의 개수를 반환합니다.

### ⏱️ 시간 복잡도
- **시간 복잡도:** O(N log N) - 주로 정렬 과정에 의해 결정됩니다.
- **공간 복잡도:** O(N) - 입력 배열을 저장하기 위한 공간이 필요합니다.

## 참고 코드 (javascript)

```javascript
/**
 * 활동 선택 문제 (Activity Selection Problem)
 * @param {Array<[number, number]>} tasks - [start, end] 형태의 활동 배열
 * @returns {number} 최대 활동 개수
 */
function solve(tasks) {
    if (!tasks || tasks.length === 0) {
        return 0;
    }

    // 1. 종료 시간(End Time)을 기준으로 오름차순 정렬
    // [start, end] 형태이므로, end는 인덱스 1에 해당합니다.
    tasks.sort((a, b) => a[1] - b[1]);

    let count = 0;
    let lastEndTime = -Infinity; // 가장 마지막에 끝난 시간

    // 2. 탐욕적 선택 (Greedy Selection)
    for (let i = 0; i < tasks.length; i++) {
        const [start, end] = tasks[i];

        // 현재 활동의 시작 시간이 이전에 선택된 활동의 종료 시간보다 크거나 같으면 겹치지 않음
        if (start >= lastEndTime) {
            count++;
            // 선택했으므로, lastEndTime을 현재 활동의 종료 시간으로 업데이트
            lastEndTime = end;
        }
    }

    return count;
}

// --- Node.js 입력 처리 로직 ---

function main() {
    const fs = require('fs');
    // 표준 입력 전체를 동기적으로 읽어옵니다. (실제 테스트 환경에 맞춰 조정 필요)
    const input = fs.readFileSync(0, 'utf8').trim().split('\n').filter(line => line.length > 0);

    if (input.length === 0) {
        console.log(0);
        return;
    }

    // 첫 줄은 N (활동 개수)이므로 건너<0xEB><0x9C><0x81>니다.
    const tasks = [];
    for (let i = 1; i < input.length; i++) {
        const parts = input[i].split(' ').map(Number);
        if (parts.length === 2) {
            tasks.push(parts);
        }
    }

    const result = solve(tasks);
    console.log(result);
}

// main(); // 실제 제출 시 주석 해제

// 테스트 케이스 실행용
const test1 = [ [1, 4], [0, 2], [3, 5] ];
console.log(`Test 1 Result: ${solve(test1)} (Expected: 2)`);

const test2 = [ [1, 2], [2, 3], [3, 4], [1, 3] ];
console.log(`Test 2 Result: ${solve(test2)} (Expected: 3)`);
```

# 최대 비겹침 활동 선택
*javascript · 그리디 · 보통 · 정렬, 그리디, 배열*

## 입출력 환경

Node.js 환경에서 stdin을 통해 모든 입력을 받고 처리해야 합니다. 전체 입력을 한 번에 읽는 것이 효율적입니다.

## 문제

당신은 여러 개의 활동(Activity) 목록을 관리하는 스케줄러를 개발해야 합니다. 각 활동은 시작 시간과 종료 시간으로 정의되며, 두 활동이 동시에 진행될 수 없습니다. 즉, 하나의 활동이 끝난 후에야 다음 활동이 시작될 수 있습니다.

주어진 활동 목록 중에서 서로 시간적으로 겹치지 않으면서, 가장 많은 개수의 활동을 선택하는 최대 집합의 크기를 구하세요. (활동 [A, B]는 시작 시간 A와 종료 시간 B를 의미하며, A <= B입니다. 종료 시간이 다음 활동의 시작 시간과 같아도 겹치지 않습니다.)

## 입력

첫 번째 줄에 N (활동의 개수)이 주어지며, 다음 N줄에는 각 활동의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. 예: N
start1 end1
start2 end2
...

## 출력

서로 겹치지 않는 활동의 최대 개수(정수)를 출력합니다.

## 제약 조건

1 <= N <= 100,000
1 <= start <= end <= 100,000,000
시간 복잡도는 O(N log N) 이하를 목표로 합니다.

## 예제 1

**입력**
```
3
1 3
2 5
4 6
```

**출력**
```
2
```

*활동 [1, 3]과 [4, 6]을 선택하여 2개가 최대입니다.*

## 예제 2

**입력**
```
4
0 1
1 2
2 3
0 3
```

**출력**
```
3
```

*활동 [0, 1], [1, 2], [2, 3]을 순서대로 선택할 수 있습니다.*

## 알고리즘 요약

활동 선택 문제에서 그리디 전략을 사용합니다. 가장 중요한 기준은 '종료 시간'입니다. 활동들을 종료 시간 순으로 정렬한 후, 첫 번째 활동을 선택하고, 이후 선택하는 활동은 현재 선택된 활동의 종료 시간보다 같거나 큰 시작 시간을 가져야 합니다.

## 풀이 해설

### 아이디어: 그리디 알고리즘
이 문제는 활동 선택 문제(Activity Selection Problem)의 대표적인 예시입니다. 이 문제를 해결하는 최적의 그리디 선택 기준은 '종료 시간이 가장 빠른 활동'을 선택하는 것입니다.
만약 종료 시간이 가장 빠른 활동을 선택하지 않고 다른 활동을 선택한다면, 그 활동은 반드시 종료 시간이 더 늦거나 같을 것이고, 이는 다음 활동을 선택할 수 있는 여유 시간(Window)을 줄이게 되어 최적해를 찾기 어렵게 만듭니다.

### 단계:
1. **입력 및 구조화**: 입력받은 모든 활동 [시작 시간, 종료 시간]을 배열 형태로 저장합니다.
2. **정렬**: 이 활동 배열을 '종료 시간(End Time)'을 기준으로 오름차순 정렬합니다.
3. **선택**: 첫 번째 활동(가장 빨리 끝나는 활동)을 무조건 선택하고, 개수를 1로 초기화합니다.
4. **반복 탐색**: 두 번째 활동부터 순회하면서, 현재 활동의 '시작 시간'이 이전에 선택된 활동의 '종료 시간'보다 크거나 같은 경우(즉, 겹치지 않는 경우)에만 선택하고, 현재 활동의 종료 시간을 '이전에 선택된 활동의 종료 시간'으로 업데이트합니다.
5. **결과 반환**: 반복이 끝난 후의 활동 개수가 최대 개수입니다.

### 시간 복잡도:
- 입력 처리: O(N)
- 정렬: O(N log N)
- 탐색: O(N)
전체 시간 복잡도는 정렬에 의해 결정되는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력(stdin)을 처리하는 함수
 * 예시: [1, 3], [2, 5], [4, 6] -> 2
 */
function solve() {
    const fs = require('fs');
    // Node.js의 모든 표준 입력을 한 번에 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n').map(line => line.trim()).filter(line => line.length > 0);

    if (input.length === 0) return 0;

    // 첫 줄은 N (활동 개수)이며, 실제 데이터는 다음 줄부터 시작합니다.
    const N = parseInt(input[0], 10);
    let activities = [];

    for (let i = 1; i <= N; i++) {
        const line = input[i].split(' ').map(Number);
        if (line.length === 2) {
            // [시작 시간, 종료 시간] 형식으로 저장
            activities.push(line);
        }
    }

    if (activities.length === 0) {
        return 0;
    }

    // 1. 그리디 전략에 따라 '종료 시간'을 기준으로 오름차순 정렬합니다.
    // 활동 배열: [[start1, end1], [start2, end2], ...]
    activities.sort((a, b) => a[1] - b[1]);

    let count = 0;
    // 가장 마지막에 선택된 활동의 종료 시간을 추적하는 변수
    let lastFinishTime = -Infinity; 

    for (const activity of activities) {
        const startTime = activity[0];
        const finishTime = activity[1];

        // 2. 현재 활동이 이전에 선택된 활동과 겹치지 않는지 확인합니다.
        // (시작 시간이 마지막 종료 시간보다 크거나 같은 경우)
        if (startTime >= lastFinishTime) {
            // 겹치지 않는 경우, 이 활동을 선택합니다.
            count++;
            // 마지막 종료 시간을 업데이트합니다.
            lastFinishTime = finishTime;
        }
    }

    return count;
}

console.log(solve());
```

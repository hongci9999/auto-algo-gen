# 최대 활동 횟수
*javascript · 그리디 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

Node.js 환경에서 전체 입력을 받아 처리해야 합니다. (예: process.stdin 사용)

## 문제

당신은 여러 개의 활동 목록을 받았습니다. 각 활동은 시작 시간과 종료 시간을 가지고 있습니다. 이 활동들 중, 서로 겹치지 않으면서 최대 개수를 선택하는 것이 목표입니다.

두 활동이 겹치지 않기 위한 조건은, 한 활동의 종료 시간이 다른 활동의 시작 시간보다 작거나 같아야 합니다. (예: 활동 A가 1에 시작하여 3에 끝나고, 활동 B가 3에 시작하여 5에 끝난다면, 두 활동은 겹치지 않습니다.)

최대 활동 횟수를 구하세요.

## 입력

첫 번째 줄에는 활동의 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 활동의 [시작 시간]과 [종료 시간]이 공백으로 구분되어 주어집니다.

## 출력

선택할 수 있는 최대 활동의 개수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 100,000
1 <= 시작 시간, 종료 시간 <= 10^9
시간 복잡도는 O(N log N) 이하로 유지해야 합니다.

## 예제 1

**입력**
```
3
1 4
1 2
4 5
```

**출력**
```
2
```

*활동 (1, 2)와 (4, 5)를 선택하는 것이 최적입니다. (1, 4)는 선택될 수 없습니다.*

## 예제 2

**입력**
```
4
1 10
2 3
4 5
6 7
```

**출력**
```
3
```

*가장 빨리 끝나는 순서대로 선택하는 그리디 전략을 사용합니다. (2, 3), (4, 5), (6, 7)을 선택합니다.*

## 예제 3

**입력**
```
2
1 2
2 3
```

**출력**
```
2
```

*종료 시간이 같으면 겹치지 않는 것으로 간주합니다. 두 활동 모두 선택 가능합니다.*

## 힌트

- 이 문제는 탐욕적(Greedy) 알고리즘을 사용하여 해결할 수 있습니다.
- 어떤 기준으로 활동들을 정렬해야 가장 효율적인 선택을 할 수 있을지 고민해보세요.


## 알고리즘 요약

그리디 알고리즘 및 정렬
최대 활동 횟수를 구하는 문제는 '활동 선택 문제(Activity Selection Problem)'의 전형적인 예제입니다. 이 문제를 그리디하게 풀기 위해서는, 활동들을 '종료 시간'을 기준으로 오름차순 정렬하는 것이 핵심입니다. 가장 빨리 끝나는 활동을 선택하는 것이 나머지 활동에 남는 시간을 최대화하기 때문입니다. 정렬 후, 첫 번째 활동을 선택하고, 이후의 활동들 중 마지막으로 선택된 활동의 종료 시간보다 크거나 같은 시작 시간을 가진 활동을 순차적으로 선택합니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 활동 선택 문제는 '가장 빨리 끝나는 활동을 선택하는 것이 전체 최대 개수를 보장한다'는 그리디 속성을 가집니다. 따라서 활동들을 종료 시간(End Time)을 기준으로 오름차순 정렬합니다.
2. 단계:
    a. 입력받은 모든 활동들을 `[시작 시간, 종료 시간]` 쌍으로 저장합니다.
    b. 이 활동 배열을 종료 시간(End Time)을 기준으로 오름차순 정렬합니다. (만약 종료 시간이 같다면, 시작 시간을 기준으로 오름차순 정렬해도 무방합니다.)
    c. 첫 번째 활동을 무조건 선택합니다. 선택된 활동 개수를 1로 초기화하고, 마지막 선택된 활동의 종료 시간을 기록합니다.
    d. 정렬된 배열을 처음부터 끝까지 순회하면서, 현재 활동의 시작 시간이 '마지막으로 선택된 활동의 종료 시간'보다 크거나 같은지 확인합니다.
    e. 조건이 참이라면, 현재 활동을 선택하고, 선택된 활동 개수를 1 증가시키며, '마지막으로 선택된 활동의 종료 시간'을 현재 활동의 종료 시간으로 업데이트합니다.
    f. 조건이 거짓이라면, 이 활동은 이미 선택된 활동과 겹치므로 건너<0xEB><0x9C><0x81>니다.
3. 시간 복잡도: 배열을 정렬하는 데 $O(N 	imes 	ext{log} N)$의 시간이 소요됩니다. 이후 순회는 $O(N)$이므로, 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 동작하는 최대 활동 횟수 계산 로직
 * 입력 처리 편의를 위해 전체 표준 입력을 읽어 처리합니다.
 */

function solve() {
    const fs = require('fs');
    // 표준 입력 전체를 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0] === '') {
        console.log(0);
        return;
    }

    // 첫 줄은 N (활동 개수)입니다.
    const N = parseInt(input[0].trim());
    let activities = [];

    // 2번째 줄부터 N개의 활동 데이터를 파싱합니다.
    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (line) {
            const [start, end] = line.split(' ').map(Number);
            activities.push({ start: start, end: end });
        }
    }

    // 1. 그리디 전략을 위해 종료 시간(end)을 기준으로 오름차순 정렬합니다.
    // 종료 시간이 같으면 시작 시간을 기준으로 정렬해도 무방합니다.
    activities.sort((a, b) => {
        if (a.end !== b.end) {
            return a.end - b.end;
        }
        return a.start - b.start;
    });

    let count = 0; // 선택된 활동 개수
    let lastFinishTime = -Infinity; // 마지막으로 선택된 활동의 종료 시간

    // 2. 정렬된 배열을 순회하며 그리디하게 선택합니다.
    for (let i = 0; i < activities.length; i++) {
        const currentActivity = activities[i];

        // 현재 활동의 시작 시간이 마지막 선택된 활동의 종료 시간보다 크거나 같으면, 겹치지 않습니다.
        // (start >= lastFinishTime)
        if (currentActivity.start >= lastFinishTime) {
            // 활동 선택!
            count++;
            lastFinishTime = currentActivity.end;
        }
    }

    console.log(count);
}

solve();
```

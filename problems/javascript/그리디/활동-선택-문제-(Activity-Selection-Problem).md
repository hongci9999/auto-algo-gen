# 활동 선택 문제 (Activity Selection Problem)
*javascript · 그리디 · 보통 · 정렬, 그리디, 배열*

## 입출력 환경

Node.js 환경에서 전체 입력을 읽어 처리하는 것을 가정합니다. (예: readline 또는 fs.readFileSync)

## 문제

당신은 여러 개의 시간 간격으로 이루어진 활동 목록을 받았습니다. 각 활동은 시작 시간과 종료 시간을 가집니다. 목표는 이 활동들 중에서 서로 겹치지 않는(non-overlapping) 활동들을 최대한 많이 선택하는 것입니다. 활동 간의 경계 시간이 같더라도 (예: [1, 3]과 [3, 5]), 이는 겹치지 않는 것으로 간주합니다.

주어진 N개의 활동 $[start_i, end_i]$가 있습니다. 이 중에서 겹치지 않는 활동들의 최대 개수를 구하시오.

## 입력

첫 번째 줄에 활동의 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 활동의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (start end)

## 출력

선택할 수 있는 최대 활동 개수(정수)를 출력합니다.

## 제약 조건

N의 범위: 1 <= N <= 100,000
시간 범위: 1 <= start, end <= 1,000,000,000
시간 복잡도 요구사항: O(N log N) 이하

## 예제 1

**입력**
```
3
1 4
2 5
4 6
```

**출력**
```
2
```

*활동 [1, 4]와 [4, 6]을 선택하여 최대 2개를 얻을 수 있습니다. [1, 4]와 [2, 5]는 겹칩니다.*

## 예제 2

**입력**
```
4
1 2
1 3
2 3
3 4
```

**출력**
```
3
```

*최적의 선택은 [1, 2], [2, 3], [3, 4]입니다. (총 3개)*

## 알고리즘 요약

활동 선택 문제는 그리디 알고리즘의 대표적인 예시입니다. 핵심 아이디어는 '가장 일찍 끝나는 활동'을 선택하는 것입니다. 전체 활동 목록을 **종료 시간(end time)을 기준으로 오름차순 정렬**한 후, 첫 번째 활동을 선택하고, 이후 활동들 중에서 이전 활동의 종료 시간보다 시작 시간이 크거나 같은 활동을 순차적으로 선택해 나갑니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 이 문제는 그리디(Greedy) 전략을 사용합니다. 모든 활동 중에서 가장 먼저 끝나는 활동을 선택하는 것이 남은 활동들의 선택지를 가장 많이 남겨주기 때문에 최적의 해를 보장합니다.
2. 단계:
    a. 입력받은 모든 활동 $[start, end]$를 배열에 저장합니다.
    b. 이 활동 배열을 **종료 시간(end time)을 기준으로 오름차순 정렬**합니다. (만약 종료 시간이 같다면, 시작 시간을 기준으로 정렬해도 무방합니다.)
    c. 첫 번째 활동(가장 빨리 끝나는 활동)을 선택하고, 선택된 활동의 개수(count)를 1로, 마지막 종료 시간(lastEndTime)을 이 활동의 종료 시간으로 설정합니다.
    d. 나머지 활동들부터 순회하며, 현재 활동의 시작 시간이 `lastEndTime`보다 크거나 같은지 확인합니다. (즉, 겹치지 않는지 확인합니다.)
    e. 만약 겹치지 않는다면, 이 활동을 선택하고 `count`를 1 증가시키고, `lastEndTime`을 현재 활동의 종료 시간으로 업데이트합니다.
3. 시간 복잡도: 가장 많은 시간이 걸리는 부분은 정렬 과정입니다. 따라서 시간 복잡도는 $O(N 	imes 	ext{정렬 시간}) = O(N 	ext{ log } N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} input - 전체 입력 문자열 (예: "3\n1 4\n2 5\n4 6")
 * @returns {number} 최대 활동 개수
 */
const solve = (input) => {
    const lines = input.trim().split('\n').filter(line => line.length > 0);
    if (lines.length === 0) return 0;

    // 첫 줄은 N (개수)이므로 건너뛰고, 나머지 N줄을 파싱
    const activities = [];
    for (let i = 1; i < lines.length; i++) {
        const [start, end] = lines[i].trim().split(' ').map(Number);
        activities.push({ start, end });
    }

    if (activities.length === 0) return 0;

    // 1. 종료 시간(end)을 기준으로 오름차순 정렬 (핵심 그리디 전략)
    // 종료 시간이 같으면 시작 시간 순으로 정렬하는 것이 안정적입니다.
    activities.sort((a, b) => {
        if (a.end !== b.end) {
            return a.end - b.end;
        }
        return a.start - b.start;
    });

    let count = 0;
    // 가장 마지막으로 선택된 활동의 종료 시간
    let lastEndTime = -Infinity;

    // 2. 순회하며 겹치지 않는 활동 선택
    for (const activity of activities) {
        // 현재 활동의 시작 시간이 마지막 선택된 활동의 종료 시간보다 크거나 같으면 (겹치지 않으면)
        if (activity.start >= lastEndTime) {
            count++;
            // 마지막 선택된 활동의 종료 시간 업데이트
            lastEndTime = activity.end;
        }
    }

    return count;
};
```

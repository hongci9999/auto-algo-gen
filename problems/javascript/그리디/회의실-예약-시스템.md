# 회의실 예약 시스템
*javascript · 그리디 · 보통 · 정렬, 그리디, 배열*

## 입출력 환경

Node.js 환경에서 모든 입력을 한 번에 읽어 처리한다고 가정합니다. 입력은 줄바꿈으로 구분됩니다.

## 문제

여러 개의 회의 요청 시간 목록이 주어집니다. 각 회의는 [시작 시간, 종료 시간]의 형태로 표현됩니다.
당신은 주어진 회의 요청들 중에서 서로 시간이 겹치지 않으면서 최대 개수의 회의를 예약할 수 있도록 일정을 짜야 합니다.

서로 다른 회의의 시간이 겹치지 않으려면, 한 회의의 종료 시간은 다음 회의의 시작 시간보다 작거나 같아야 합니다.

## 입력

첫 번째 줄에 총 회의 요청의 개수 N이 주어집니다.
다음 N개의 줄에는 각각 '시작 시간 시작 종료 시간 종료'의 형식으로 회의 요청이 주어집니다. (예: 1 4, 2 5, 6 8)

## 출력

겹치지 않게 예약할 수 있는 최대 회의의 개수를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 100,000
시간은 1부터 100,000 사이의 정수입니다. 시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*가장 먼저 끝나는 회의를 선택하는 그리디 전략을 사용하면, [1, 4]와 [6, 8]을 선택하여 최대 2개가 됩니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 3
```

**출력**
```
3
```

*모든 회의가 연결되는 경우입니다. [1, 2], [2, 3], [3, 4] 순서로 3개를 선택할 수 있습니다.*

## 예제 3

**입력**
```
5
1 10
2 3
4 5
6 7
8 9
```

**출력**
```
4
```

*가장 먼저 종료되는 회의들을 순차적으로 선택하는 것이 최적입니다.*

## 힌트

- 모든 경우를 탐색하는 것은 시간 초과를 유발할 수 있습니다.
- 최적의 선택을 하는 '탐욕적(Greedy)' 방법이 존재합니다. 어떤 기준으로 정렬해야 할까요?


## 알고리즘 요약

그리디 알고리즘을 사용합니다. 회의 요청들을 종료 시간(End Time)을 기준으로 오름차순 정렬합니다. 정렬된 목록을 순회하면서, 현재 회의가 이전에 선택한 회의의 종료 시간보다 크거나 같다면(겹치지 않는다면) 해당 회의를 선택하고, 카운트를 증가시킵니다.

## 풀이 해설

### 아이디어
이 문제는 대표적인 '활동 선택 문제(Activity Selection Problem)'의 변형입니다. 이 문제를 해결하는 핵심은 '탐욕적 선택(Greedy Choice)' 원리를 이용하는 것입니다. 가장 직관적인 선택 기준은 '가장 짧은 회의'를 고르는 것이지만, 실제로는 '가장 빨리 끝나는 회의'를 고르는 것이 최적의 선택을 보장합니다.

### 단계
1. **정렬 (Sorting):** 입력받은 모든 회의 요청 배열을 **종료 시간(End Time)을 기준**으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간을 기준으로 정렬해도 무방합니다.
2. **선택 (Selection):** 배열을 처음부터 순회하며 최대 개수를 카운트합니다.
3. **초기화:** 첫 번째 회의는 무조건 선택합니다. (카운트 = 1, 마지막 종료 시간 = 첫 회의의 종료 시간)
4. **반복:** 두 번째 회의부터 배열의 끝까지 순회합니다. 현재 회의의 시작 시간이 '마지막으로 선택된 회의의 종료 시간'보다 크거나 같으면, 이 회의를 선택하고, '마지막 종료 시간'을 현재 회의의 종료 시간으로 업데이트합니다. 그렇지 않다면, 이 회의는 겹치므로 건너<0xEB><0x9C><0x81>니다.
5. **결과 반환:** 최종적으로 카운트한 값이 최대 예약 가능 개수입니다.

### 시간 복잡도
- 정렬에 $O(N 	imes 	ext{log } N)$ 시간이 소요됩니다. (N은 회의 요청 개수)
- 순회(선택) 과정은 $O(N)$ 시간이 소요됩니다.
- 전체 시간 복잡도는 정렬에 의해 결정되는 $O(N 	ext{ log } N)$입니다. 이는 주어진 제약 조건 내에서 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 받아 처리하는 구조를 가정합니다.
 * 실제 환경에서는 입력 처리 방식(readline 등)에 따라 수정이 필요할 수 있습니다.
 */
function solve() {
    const fs = require('fs');
    // 전체 입력을 읽어와서 처리합니다. (실제 환경에 맞게 수정 필요)
    let input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0].trim() === '') {
        console.log(0);
        return;
    }

    const N = parseInt(input[0].trim());
    let meetings = [];

    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (line === '') continue;
        
        // 예: "1 4" -> [1, 4]
        const parts = line.split(' ').map(Number);
        if (parts.length === 2) {
            // [시작 시간, 종료 시간] 형태로 저장
            meetings.push(parts);
        }
    }

    // 1. 종료 시간(End Time)을 기준으로 오름차순 정렬합니다.
    // 종료 시간(index 1)을 기준으로 비교합니다.
    meetings.sort((a, b) => a[1] - b[1]);

    let count = 0;
    let lastEndTime = -Infinity; // 초기 종료 시간은 가장 작은 값으로 설정

    // 2. 그리디 방식으로 순회하며 선택합니다.
    for (const meeting of meetings) {
        const startTime = meeting[0];
        const endTime = meeting[1];

        // 현재 회의의 시작 시간이 마지막 선택된 회의의 종료 시간보다 크거나 같은지 확인합니다.
        if (startTime >= lastEndTime) {
            // 겹치지 않으므로 선택
            count++;
            // 마지막 선택된 회의의 종료 시간을 업데이트합니다.
            lastEndTime = endTime;
        }
    }

    console.log(count);
}

// solve(); // 실제 실행 시 주석 해제
```

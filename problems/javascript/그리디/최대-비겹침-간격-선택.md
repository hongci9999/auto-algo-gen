# 최대 비겹침 간격 선택
*javascript · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Node.js 환경에서 표준 입력(process.stdin)을 사용하여 모든 입력을 받고, 파싱 후 결과를 표준 출력(process.stdout)으로 출력해야 합니다.

## 문제

당신에게 N개의 간격(Interval)이 주어집니다. 각 간격은 시작 시간과 종료 시간으로 이루어져 있습니다. 이 간격들 중에서 서로 겹치지 않으면서 최대 개수를 선택하는 문제입니다.

두 간격 $[s_1, e_1]$과 $[s_2, e_2]$가 겹치지 않는다는 것은, 한 간격이 끝나고 다른 간격이 시작할 때 그 경계점에서 만나는 것은 허용된다는 의미입니다. 즉, $e_1 < s_2$ 또는 $e_2 < s_1$인 경우입니다. (만약 $e_1 = s_2$인 경우, 이는 겹치지 않는 것으로 간주합니다.)

예시: $[1, 4]$와 $[4, 6]$은 겹치지 않습니다. $[1, 4]$와 $[3, 5]$는 겹칩니다.

## 입력

첫 번째 줄에 간격의 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 간격의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s e)

## 출력

선택할 수 있는 최대 간격의 개수를 하나의 정수로 출력합니다.

## 제약 조건

1. N의 범위: 1부터 100,000까지입니다.
2. 시간/공간 제약: 시간 복잡도는 O(N log N) 이하로 유지해야 합니다.
3. 간격 좌표의 범위: 시작 시간과 종료 시간은 1부터 10^9까지의 정수입니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*간격 [1, 4], [2, 5], [6, 8] 중 최대 2개([1, 4]와 [6, 8])를 선택할 수 있습니다.*

## 예제 2

**입력**
```
4
1 3
2 4
3 5
6 7
```

**출력**
```
3
```

*간격 [1, 3], [3, 5], [6, 7] 세 개를 선택할 수 있습니다. (3과 3은 겹치지 않음)*

## 힌트

- 이 문제는 전형적인 그리디 알고리즘 문제입니다.
- 어떤 순서로 간격들을 고려해야 최적의 해를 찾을 수 있을지 고민해 보세요. 종료 시간(End Time)을 기준으로 정렬하는 것이 핵심입니다.


## 알고리즘 요약

활동 선택 문제(Activity Selection Problem)와 동일한 형태의 그리디 알고리즘입니다. 모든 간격들을 종료 시간(End Time)을 기준으로 오름차순 정렬합니다. 정렬된 목록을 순회하며, 현재 간격이 이전에 선택한 간격의 종료 시간보다 크거나 같다면(즉, 겹치지 않는다면) 선택하고, 선택된 간격의 종료 시간을 갱신합니다. 이 과정을 반복하여 최대 개수를 계산합니다.

## 풀이 해설

이 문제는 그리디(Greedy) 전략을 사용하여 풀 수 있습니다. 간격 선택 문제의 핵심은 '가장 빨리 끝나는 활동을 먼저 선택하는 것'이 전체 선택 개수를 최대화한다는 점을 이용하는 것입니다.

1.  **정렬 (Sorting):** 주어진 N개의 모든 간격들을 종료 시간(End Time)을 기준으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간 순으로 정렬해도 무방합니다.
2.  **그리디 선택 (Greedy Selection):** 정렬된 간격 리스트를 순회하며 최대 간격 개수를 계산합니다.
    *   첫 번째 간격은 무조건 선택합니다. 이 간격의 종료 시간을 `last_finish_time`으로 설정합니다.
    *   두 번째 간격부터는, 현재 간격의 시작 시간이 `last_finish_time`보다 크거나 같은지 확인합니다. (문제 조건에 따라 경계점에서 만나는 것은 겹치지 않으므로, 시작 시간 >= `last_finish_time`이면 됩니다.)
    *   만약 겹치지 않는다면, 이 간격을 선택하고, `last_finish_time`을 현재 간격의 종료 시간으로 갱신하며, 선택된 개수를 1 증가시킵니다.
3.  **시간 복잡도:** 간격들을 정렬하는 데 $O(N 	imes 	ext{log} N)$ 시간이 소요되며, 이후 순회 및 선택 과정은 $O(N)$이므로, 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$이 됩니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 구조입니다.
 * 모든 입력을 한 번에 읽어와 배열로 처리합니다.
 */

function solve() {
    const fs = require('fs');
    // 동기 방식으로 모든 입력을 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0] === '') {
        console.log(0);
        return;
    }

    // 첫 줄은 N (간격의 개수)이므로 제외하고, 나머지 줄을 간격 배열로 만듭니다.
    const N = parseInt(input[0].trim());
    if (N === 0) {
        console.log(0);
        return;
    }

    let intervals = [];
    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (line) {
            const [start, end] = line.split(' ').map(Number);
            intervals.push({ start: start, end: end });
        }
    }

    // 1. 그리디 전략을 위해 종료 시간(end)을 기준으로 오름차순 정렬합니다.
    // 종료 시간이 같다면 시작 시간 순으로 정렬하는 것이 안정적입니다.
    intervals.sort((a, b) => {
        if (a.end !== b.end) {
            return a.end - b.end;
        }
        return a.start - b.start;
    });

    let count = 0;
    // 마지막으로 선택된 간격의 종료 시간을 저장합니다. 시작 시점은 0보다 작다고 가정합니다.
    let lastFinishTime = -Infinity; 

    // 2. 정렬된 간격들을 순회하며 선택합니다.
    for (const interval of intervals) {
        // 현재 간격의 시작 시간이 lastFinishTime보다 크거나 같으면 (겹치지 않으면) 선택합니다.
        // (겹치지 않는다는 정의: e1 <= s2)
        if (interval.start >= lastFinishTime) {
            count++;
            // 선택했으므로, 이 간격의 종료 시간으로 lastFinishTime을 갱신합니다.
            lastFinishTime = interval.end;
        }
    }

    console.log(count);
}

solve();
```

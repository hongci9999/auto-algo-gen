# 최소 강의실 스케줄링
*javascript · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리합니다. 모든 입력은 한 번에 읽어와서 처리하는 것이 효율적입니다.

## 문제

대학교에서 여러 개의 수업(강의)이 동시에 진행됩니다. 각 강의는 시작 시간과 종료 시간을 가집니다. 우리는 이 강의들을 진행하기 위해 필요한 최소한의 강의실 개수를 구해야 합니다.

같은 강의실에서 진행할 수 있는 강의는 이전 강의가 끝난 후에 시작해야 합니다. 즉, 두 강의의 시간 구간이 겹치지 않아야 합니다.

주어진 모든 강의 목록을 분석하여, 이 모든 강의를 수용하는 데 필요한 최소 강의실 개수를 구하시오.

시간은 정수형으로 주어지며, 시간 단위는 동일합니다.

## 입력

첫째 줄에 정수 N이 주어집니다. (N은 강의의 개수)
다음 N개의 줄에 걸쳐 각 강의의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s <= e)

## 출력

필요한 최소 강의실의 개수를 정수 하나로 출력합니다.

## 제약 조건

1 <= N <= 100,000
0 <= s, e <= 10^9
시간 복잡도는 O(N log N) 이하가 권장됩니다.

## 예제 1

**입력**
```
4
1 4
1 3
4 5
2 6
```

**출력**
```
3
```

*시간 구간 [1, 3], [1, 4], [2, 6]이 겹치므로 최소 3개의 강의실이 필요합니다.*

## 예제 2

**입력**
```
3
1 2
3 4
5 6
```

**출력**
```
1
```

*모든 강의가 순차적으로 진행되어 1개의 강의실로 충분합니다.*

## 힌트

- 강의를 어떤 순서로 정렬하는 것이 가장 효율적일까요?
- 현재 강의가 시작할 때, 가장 빨리 비워지는 강의실을 찾아 재활용하는 것이 핵심 아이디어입니다.


## 알고리즘 요약

그리디 알고리즘과 최소 힙(Min-Heap)을 사용합니다. 강의 목록을 시작 시간(Start Time) 순으로 정렬합니다. 강의를 순회하면서, 현재 강의가 시작할 때 가장 빨리 끝나는 강의실(즉, 가장 작은 종료 시간)을 확인합니다. 만약 현재 강의가 시작하는 시간이 그 강의실의 종료 시간보다 크거나 같다면, 그 강의실을 재사용합니다. 그렇지 않다면, 새로운 강의실을 할당해야 합니다. 필요한 강의실의 개수는 최대 할당된 강의실의 개수가 됩니다.

## 풀이 해설

풀이 해설: 이 문제는 주어진 시간 구간들이 동시에 겹치는 최대 개수를 찾는 문제와 같습니다.

1. 아이디어: 그리디 접근 방식을 사용합니다. 강의를 시작 시간 순으로 정렬하여 순회하며, 각 강의가 시작할 때 필요한 강의실을 효율적으로 관리합니다.
2. 자료구조: 강의실의 종료 시간을 관리하기 위해 최소 힙(Min-Heap)을 사용합니다. 이 힙에는 현재 할당된 모든 강의실들의 '종료 시간'이 저장됩니다. 힙의 루트(Root)는 현재 가장 빨리 비워지는 강의실의 종료 시간을 나타냅니다.
3. 단계:
    a. 입력을 받아서 `[시작 시간, 종료 시간]` 형태의 배열로 만듭니다.
    b. 이 배열을 시작 시간(s)을 기준으로 오름차순 정렬합니다.
    c. 빈 힙(Min-Heap)을 초기화합니다. 이 힙은 강의실의 종료 시간들을 저장합니다.
    d. 정렬된 강의 목록을 순회합니다. 현재 강의를 (s, e)라고 할 때:
        i. 힙이 비어있거나, 힙의 루트 값(가장 빠른 종료 시간)이 s보다 작은 경우: 이 강의는 기존 강의실을 재사용할 수 있습니다. 따라서 힙의 루트 값을 제거하고, 현재 강의의 종료 시간 e를 힙에 삽입합니다.
        ii. 힙의 루트 값(가장 빠른 종료 시간)이 s보다 크거나 같은 경우: 이 강의는 기존 강의실과 시간이 겹치므로, 새로운 강의실이 필요합니다. 따라서 힙에 새로운 종료 시간 e를 삽입합니다.
    e. 최종적으로 힙에 남아있는 요소의 개수가 필요한 최소 강의실의 개수입니다.
4. 시간 복잡도: 정렬에 O(N log N)이 걸리고, 나머지 N개의 강의에 대해 힙 삽입/삭제(O(log K), K는 강의실 개수)를 수행하므로, 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * 최소 강의실 스케줄링
 * @param {Array<[number, number]>} lectures - [[start, end], ...]
 * @returns {number} 최소 강의실 개수
 */
function solve(lectures) {
    // 1. 시작 시간을 기준으로 정렬 (O(N log N))
    lectures.sort((a, b) => a[0] - b[0]);

    // 2. 최소 힙 구현 (JavaScript 표준 라이브러리에는 MinHeap이 없으므로, 배열을 사용하여 힙의 원리를 흉내냅니다.)
    // 실제 구현에서는 MinPriorityQueue 라이브러리를 사용하지만, 여기서는 배열을 정렬된 상태로 유지하며 O(log K) 접근을 가정합니다.
    // 간결성을 위해, 힙의 개념을 사용하여 '가장 빨리 끝나는 시간'만 관리합니다.
    let roomEndTimes = []; // 이 배열은 항상 오름차순으로 정렬되어 있다고 가정합니다 (MinHeap의 역할)

    for (const [start, end] of lectures) {
        // 3. 현재 강의가 시작할 때, 가장 빨리 끝나는 강의실을 확인 (힙의 루트 = roomEndTimes[0])
        if (roomEndTimes.length > 0 && roomEndTimes[0] <= start) {
            // 재사용 가능: 가장 빨리 끝나는 강의실을 재사용하고, 그 종료 시간을 현재 강의의 종료 시간으로 업데이트
            // 힙에서 가장 작은 값(roomEndTimes[0])을 제거하고, 새로운 종료 시간을 삽입해야 합니다.
            roomEndTimes.shift(); // 가장 작은 종료 시간 제거
        }
        
        // 새로운 종료 시간을 힙에 삽입 (배열에 추가 후 정렬을 유지하는 것이 힙의 원리)
        // 실제 힙 삽입은 O(log K)이지만, 배열의 끝에 추가 후 정렬을 유지한다고 가정하고, 가장 작은 값을 앞으로 이동시킵니다.
        // 여기서는 간단히, 가장 작은 값으로 간주하고 삽입합니다.
        roomEndTimes.push(end);
        roomEndTimes.sort((a, b) => a - b); // 힙의 최소 원소 접근을 위해 정렬 유지
    }

    // 4. 최종적으로 힙에 남아있는 요소의 개수가 최소 강의실 개수입니다.
    return roomEndTimes.length;
}

// Node.js 표준 입력 처리
function main() {
    const fs = require('fs');
    // 전체 입력을 문자열로 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length === 0 || input[0].trim() === '') {
        console.log(0);
        return;
    }

    const N = parseInt(input[0].trim());
    let lectures = [];

    for (let i = 1; i <= N; i++) {
        const line = input[i].trim();
        if (line) {
            const [s, e] = line.split(' ').map(Number);
            lectures.push([s, e]);
        }
    }

    const result = solve(lectures);
    console.log(result);
}

main();
```

# 최대 비중첩 간격 선택
*javascript · 그리디 · 보통 · 정렬, 그리디, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 모든 입력을 읽은 후, 공백과 개행 문자를 기준으로 파싱하여 사용하세요.

## 문제

당신은 일정 관리 시스템을 개발하고 있습니다. 시스템에는 $N$개의 간격(Interval)이 주어지며, 각 간격은 시작 시간 $S$와 종료 시간 $E$로 표현됩니다. 간격 $[S_i, E_i]$는 $S_i$부터 $E_i$까지의 시간 구간을 나타냅니다. 

주어진 $N$개의 간격 중, 서로 시간적으로 겹치지 않는(non-overlapping) 간격들의 최대 개수를 구하는 것이 목표입니다.

두 간격 $[S_1, E_1]$과 $[S_2, E_2]$가 겹치지 않는다는 것은, $E_1 	ext{이 } S_2 	ext{보다 작거나 같거나}$, 또는 $E_2 	ext{가 } S_1 	ext{보다 작거나 같다}$는 것을 의미합니다. (즉, 끝점끼리 닿는 것은 허용됩니다.)

## 입력

첫 번째 줄에 간격의 개수 N이 주어지며, 다음 N줄에 걸쳐 각 간격의 시작 시간 $S$와 종료 시간 $E$가 공백으로 구분되어 주어집니다. (S, E 순서)

## 출력

서로 겹치지 않는 간격의 최대 개수를 하나의 정수로 출력합니다.

## 제약 조건

1. $1 	ext{ ≤ } N 	ext{ ≤ } 10^5$
2. $1 	ext{ ≤ } S_i, E_i 	ext{ ≤ } 10^9$
3. 시간 복잡도는 $O(N 	ext{ log } N)$ 이하를 목표로 합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*간격 [1, 4]와 [2, 5]는 겹치고, [1, 4]와 [6, 8]은 겹치지 않습니다. 최대 2개 선택 가능합니다.*

## 예제 2

**입력**
```
4
1 2
3 4
1 3
2 3
```

**출력**
```
2
```

*선택 가능한 조합 중 최대 개수는 2개입니다. 예: [1, 2]와 [2, 3] 또는 [1, 2]와 [3, 4].*

## 힌트

- 문제를 해결하기 위해 그리디(Greedy) 알고리즘을 적용하는 것이 효과적입니다.
- 어떤 순서로 간격들을 선택해야 최적의 해를 찾을 수 있을지 고민해 보세요. (예: 시작 시간 기준 vs 종료 시간 기준)


## 알고리즘 요약

그리디 알고리즘: 간격 선택 문제의 경우, 항상 '가장 빨리 끝나는' 간격을 선택하는 것이 최적의 선택을 보장합니다. 따라서 모든 간격을 종료 시간(End Time)을 기준으로 오름차순 정렬한 후, 첫 번째 간격을 선택하고, 그 다음 간격 중 이전 간격의 종료 시간보다 시작 시간이 크거나 같은 간격들 중 가장 빨리 끝나는 간격을 반복적으로 선택합니다.

## 풀이 해설

1. **아이디어 (그리디 선택):** 이 문제는 전형적인 '활동 선택 문제(Activity Selection Problem)'의 변형입니다. 이 문제를 해결하는 그리디 전략은 '현재 시점에서 가장 빨리 끝나는 활동(간격)을 선택하는 것'입니다. 이렇게 해야 남은 시간 동안 다음 활동을 시작할 수 있는 여유 시간이 최대화됩니다.
2. **단계:**
    a. **입력 및 정렬:** 주어진 $N$개의 모든 간격 $[S, E]$를 리스트에 저장합니다. 이 리스트를 **종료 시간 $E$을 기준으로 오름차순 정렬**합니다. (만약 종료 시간이 같다면, 시작 시간 $S$를 기준으로 정렬해도 무방합니다.)
    b. **최초 선택:** 정렬된 리스트의 첫 번째 간격 (가장 빨리 끝나는 간격)을 선택합니다. 이 간격의 종료 시간을 `last_end`로 설정하고, 선택된 간격의 개수를 1로 초기화합니다.
    c. **순회 및 선택:** 리스트의 두 번째 간격부터 순회합니다. 현재 간격 $[S_{curr}, E_{curr}]$에 대해, 만약 $S_{curr} 	ext{가 } last	ext{\_end} 	ext{보다 크거나 같다면}$ (즉, 겹치지 않는다면), 이 간격을 선택합니다. 선택했다면, `last_end`를 $E_{curr}$로 업데이트하고, 개수를 1 증가시킵니다.
3. **시간 복잡도:** 간격들을 정렬하는 데 $O(N 	ext{ log } N)$이 소요되며, 이후 순회는 $O(N)$이므로, 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하기 위한 헬퍼 함수
 * @param {string} input 전체 입력 문자열
 * @returns {Array<[number, number]>} 간격 배열 [[S1, E1], [S2, E2], ...]
 */
function solve(input) {
    const lines = input.trim().split('\n').filter(line => line.length > 0);
    if (lines.length === 0) return 0;

    // 첫 줄은 N (개수)이므로 건너뛰고, 나머지 줄을 간격으로 파싱합니다.
    const intervals = [];
    for (let i = 1; i < lines.length; i++) {
        const parts = lines[i].trim().split(/\s+/).map(Number);
        if (parts.length === 2) {
            intervals.push(parts);
        }
    }

    // 1. 종료 시간(E)을 기준으로 오름차순 정렬 (그리디 핵심)
    // [S, E] 형태이므로, E는 [1] 인덱스에 있습니다.
    intervals.sort((a, b) => a[1] - b[1]);

    let count = 0;
    // 초기 last_end는 매우 작은 값으로 설정하여 첫 번째 간격이 무조건 선택되도록 합니다.
    let last_end = -Infinity;

    // 2. 순회하며 간격 선택
    for (const interval of intervals) {
        const start = interval[0];
        const end = interval[1];

        // 현재 간격의 시작 시간이 마지막으로 선택된 간격의 종료 시간보다 크거나 같으면 겹치지 않음.
        if (start >= last_end) {
            count++;
            last_end = end; // 현재 간격의 종료 시간으로 갱신
        }
    }

    return count;
}

// --- Node.js 표준 입력 처리 예시 ---
// 실제 코딩 테스트 환경에서는 process.stdin를 사용합니다.
// 여기서는 테스트를 위해 입력 문자열을 직접 전달받는 형태로 구현합니다.

// 예제 1 테스트
const input1 = "3\n1 4\n2 5\n6 8";
console.log(`[Sample 1 결과]: ${solve(input1)}`); // 예상 출력: 2

// 예제 2 테스트
const input2 = "4\n1 2\n3 4\n1 3\n2 3";
console.log(`[Sample 2 결과]: ${solve(input2)}`); // 예상 출력: 2
```

# 최대 활동 개수 찾기
*javascript · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Node.js 환경에서 전체 입력을 한 번에 읽어 처리해야 합니다. (예: fs 모듈 또는 readline 사용)

## 문제

N개의 활동이 주어집니다. 각 활동은 시작 시간과 종료 시간으로 정의됩니다. 활동 간에 시간적으로 겹치지 않으면서, 최대 몇 개의 활동을 선택할 수 있는지 구하는 문제입니다.

활동 A와 활동 B가 겹치지 않으려면, 둘 중 어느 한 활동이 끝나기 전에 다른 활동이 시작해서는 안 됩니다. (예: 활동 A가 [1, 4]이고 활동 B가 [4, 6]이라면, B는 A와 겹치지 않습니다.)

## 입력

첫째 줄에 활동의 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 활동의 [시작 시간, 종료 시간]이 공백으로 구분되어 주어집니다.

## 출력

선택할 수 있는 최대 활동의 개수(정수)를 출력합니다.

## 제약 조건

N의 범위는 1부터 100,000입니다. 시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*활동 (1, 4)를 선택한 후, 종료 시간이 4보다 크거나 같은 활동 중 가장 빠른 (6, 8)을 선택하여 총 2개가 됩니다.*

## 예제 2

**입력**
```
4
1 3
2 4
3 5
6 7
```

**출력**
```
3
```

*활동 (1, 3) -> (3, 5) -> (6, 7) 순서로 선택하는 것이 최대입니다.*

## 힌트

- 문제를 풀 때 어떤 순서로 활동들을 정렬하는 것이 가장 효율적인지 생각해보세요.
- 그리디(Greedy) 알고리즘을 적용할 때, '선택의 기준'이 핵심입니다.


## 알고리즘 요약

그리디 알고리즘: 활동 선택 문제의 핵심은 '종료 시간이 가장 빠른 활동'을 선택하는 것입니다. 모든 활동을 종료 시간 순으로 정렬한 후, 첫 번째 활동을 선택하고, 다음 활동은 이전 활동의 종료 시간보다 크거나 같은 시작 시간을 가진 활동 중 가장 빠른 것을 반복적으로 선택합니다.

## 풀이 해설

1. 아이디어: 이 문제는 전형적인 그리디(탐욕) 알고리즘 문제입니다. 활동을 선택할 때, 현재 선택 가능한 활동 중 '가장 빨리 끝나는 활동'을 선택하는 것이 항상 최적해로 가는 핵심 단서가 됩니다.
2. 단계:
    a. 입력된 N개의 모든 활동을 [시작 시간, 종료 시간] 쌍으로 저장합니다.
    b. 이 활동 목록을 '종료 시간'을 기준으로 오름차순 정렬합니다. (만약 종료 시간이 같다면, 시작 시간 순으로 정렬해도 무방합니다.)
    c. 첫 번째 활동을 선택하고, 최대 개수를 1로 초기화합니다. 이 활동의 종료 시간을 `last_finish_time`으로 설정합니다.
    d. 정렬된 목록을 처음부터 순회하며, 현재 활동의 시작 시간이 `last_finish_time`보다 크거나 같은지 확인합니다.
    e. 만약 조건을 만족한다면, 해당 활동을 선택하고, 최대 개수를 1 증가시키며, `last_finish_time`을 현재 활동의 종료 시간으로 업데이트합니다.
    f. 조건을 만족하지 않는 활동은 건너<0xEB><0x9C><0x81>니다.
3. 시간 복잡도: 활동 목록을 정렬하는 데 $O(N 	imes 	ext{log} N)$이 걸리며, 이후 순회는 $O(N)$이므로, 전체 시간 복잡도는 $O(N 	ext{ log } N)$이 됩니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경을 가정하고, 전체 입력을 처리하는 구조로 작성되었습니다.
 * 입력: N
 *       A1_start A1_end
 *       A2_start A2_end
 *       ...
 */
function solve(input) {
    // 입력 문자열을 줄 단위로 분리하고, 비어있는 줄 제거
    const lines = input.trim().split('\n').filter(line => line.length > 0);
    if (lines.length === 0) return 0;

    // 첫 줄은 N (활동 개수)
    const N = parseInt(lines[0].trim());
    let activities = [];

    // 나머지 N줄에서 활동 [시작, 종료] 시간 파싱
    for (let i = 1; i <= N; i++) {
        const parts = lines[i].trim().split(' ').map(Number);
        // 활동 배열에 [시작 시간, 종료 시간] 형태로 저장
        activities.push({ start: parts[0], end: parts[1] });
    }

    // 1. 핵심: 종료 시간(end)을 기준으로 오름차순 정렬
    // 종료 시간이 같은 경우, 시작 시간이 빠른 순으로 정렬하는 것이 안정적입니다.
    activities.sort((a, b) => {
        if (a.end !== b.end) {
            return a.end - b.end; // 종료 시간이 빠른 것이 앞에 오도록
        }
        return a.start - b.start; // 종료 시간이 같으면 시작 시간이 빠른 것이 앞에 오도록
    });

    let count = 0;
    let lastFinishTime = -Infinity;

    // 2. 그리디 선택 과정
    for (const activity of activities) {
        // 현재 활동의 시작 시간이 마지막으로 선택된 활동의 종료 시간보다 크거나 같은지 확인
        if (activity.start >= lastFinishTime) {
            // 선택 가능 -> 선택하고 갱신
            count++;
            lastFinishTime = activity.end;
        }
    }

    return count;
}

// --- 테스트 코드 실행 영역 (실제 환경에서 입력을 받아 처리한다고 가정) ---
const testInput1 = "3\n1 4\n2 5\n6 8";
console.log(`Sample 1 결과: ${solve(testInput1)} (예상: 2)`);

const testInput2 = "4\n1 3\n2 4\n3 5\n6 7";
console.log(`Sample 2 결과: ${solve(testInput2)} (예상: 3)`);

// 만약 실제 Node.js stdin 처리가 필요하다면, readline 모듈을 사용해야 합니다.
```

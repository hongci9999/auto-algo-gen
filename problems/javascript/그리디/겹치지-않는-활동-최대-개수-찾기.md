# 겹치지 않는 활동 최대 개수 찾기
*javascript · 그리디 · 보통 · 정렬, 그리디, 활동선택문제*

## 입출력 환경

Node.js 환경에서 전체 입력을 받기 위해 `fs` 모듈이나 `readline` 인터페이스를 사용하는 것이 일반적입니다. 여기서는 전체 입력을 한 번에 배열로 받는다고 가정하고 코드를 작성합니다.

## 문제

당신은 여러 개의 활동 일정 목록을 받았습니다. 각 활동은 시작 시간과 종료 시간으로 정의됩니다. 이 활동들 중에서 시간적으로 겹치지 않으면서, 수행할 수 있는 최대 활동의 개수를 구하는 것이 목표입니다.

활동의 시간은 1부터 1000 사이의 정수입니다. 활동의 개수 N은 최대 100,000개입니다.

시간이 겹친다는 것은 두 활동의 시간 구간 $[S_1, E_1]$과 $[S_2, E_2]$가 공통점을 가지는 경우입니다. 만약 활동 A가 끝나고 활동 B가 시작하는 경우 (즉, $E_A = S_B$)는 겹치지 않는 것으로 간주합니다.

## 입력

첫 번째 줄에 활동의 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 활동의 시작 시간 $S$와 종료 시간 $E$가 공백으로 구분되어 주어집니다. (S E)

## 출력

최대 겹치지 않는 활동의 개수를 하나의 정수 값으로 출력해야 합니다.

## 제약 조건

N <= 100,000. 시간 범위는 1 ~ 1000.

## 예제 1

**입력**
```
3
1 3
2 4
3 5
```

**출력**
```
2
```

*가장 빨리 끝나는 활동들을 선택해야 합니다. (1, 3)과 (3, 5)를 선택할 수 있습니다.*

## 예제 2

**입력**
```
4
0 6
1 2
3 4
5 7
```

**출력**
```
3
```

*정렬 후 선택: (1, 2) -> (3, 4) -> (5, 7)입니다. 총 3개.*

## 힌트

- 이 문제는 전형적인 그리디 알고리즘 문제입니다.
- 어떤 순서로 활동을 선택할지 결정하는 것이 핵심입니다. 어떤 기준을 사용해야 최적의 해를 찾을 수 있을까요?


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm) / 활동 선택 문제. 활동들을 '종료 시간' 기준으로 정렬한 후, 가장 먼저 끝나는 활동을 선택하고, 다음으로 선택할 활동은 이전 활동의 종료 시간보다 크거나 같은 시작 시간을 가지는 활동 중 가장 빨리 종료되는 것을 반복적으로 선택합니다.

## 풀이 해설

1. **핵심 아이디어 (Greedy Choice):** 활동을 선택할 때, 가장 빨리 끝나는 활동을 선택하는 것이 항상 최적의 선택입니다. 만약 활동 A가 활동 B보다 종료 시간이 빠르다면, 활동 A를 선택함으로써 남은 시간 동안 다른 활동을 할 수 있는 기회를 최대화할 수 있기 때문입니다.
2. **단계:**
    a. **입력 및 저장:** 모든 활동 (시작 시간, 종료 시간) 쌍을 리스트에 저장합니다.
    b. **정렬:** 이 활동 리스트를 **종료 시간(End Time)을 기준**으로 오름차순 정렬합니다. (종료 시간이 같다면 시작 시간 순으로 정렬해도 무방합니다.)
    c. **선택 및 카운팅:** 첫 번째 활동을 무조건 선택하고, 카운트를 1로 초기화합니다. 이후 리스트를 순회하며, 현재 활동의 시작 시간이 직전에 선택된 활동의 종료 시간보다 크거나 같은지 확인합니다. 만약 그렇다면, 이 활동도 선택 가능하므로 카운트를 1 증가시키고, 직전에 선택된 활동의 종료 시간을 현재 활동의 종료 시간으로 업데이트합니다.
3. **시간 복잡도:** 입력 크기 N을 기준으로, 정렬에 $O(N 	imes 	ext{log} N)$이 소요되며, 이후 순회는 $O(N)$이 소요되므로 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경을 가정하고, 모든 입력을 배열로 받는다고 가정합니다.
 * 실제 제출 시에는 표준 입력 처리 로직을 사용해야 합니다.
 */
const solve = (inputLines) => {
    // 첫 줄은 N (개수)이므로 건너<0xEB><0x9C><0x81>니다.
    if (inputLines.length === 0) return 0;

    const N = parseInt(inputLines[0]);
    let activities = [];

    // 2번째 줄부터 N개의 활동 정보를 파싱합니다.
    for (let i = 1; i <= N; i++) {
        const [start, end] = inputLines[i].split(' ').map(Number);
        activities.push({ start: start, end: end });
    }

    // 1. 종료 시간(end)을 기준으로 오름차순 정렬합니다. (그리디 선택의 핵심)
    activities.sort((a, b) => a.end - b.end);

    if (activities.length === 0) return 0;

    // 2. 첫 번째 활동은 무조건 선택됩니다.
    let count = 1;
    let lastFinishTime = activities[0].end;

    // 3. 나머지 활동들을 순회하며 선택 가능 여부를 확인합니다.
    for (let i = 1; i < activities.length; i++) {
        const currentActivity = activities[i];
        
        // 현재 활동의 시작 시간이 직전 활동의 종료 시간보다 크거나 같은지 확인합니다.
        // (E_A = S_B 인 경우도 겹치지 않는 것으로 간주)
        if (currentActivity.start >= lastFinishTime) {
            count++;
            lastFinishTime = currentActivity.end;
        }
    }

    return count;
};

// --- 실제 테스트 실행 예시 (입력 배열 가정) ---
// 예제 1: 3
// 1 3
// 2 4
// 3 5
const input1 = ["3", "1 3", "2 4", "3 5"];
console.log(`예제 1 결과: ${solve(input1)}`); // 예상 출력: 2

// 예제 2: 4
// 0 6
// 1 2
// 3 4
// 5 7
const input2 = ["4", "0 6", "1 2", "3 4", "5 7"];
console.log(`예제 2 결과: ${solve(input2)}`); // 예상 출력: 3
```

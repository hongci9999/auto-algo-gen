# 최대 비겹치는 구간 선택
*javascript · 그리디 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

Node.js 환경에서 전체 입력을 읽어와 처리해야 합니다. (예: fs.readFileSync('/dev/stdin', 'utf8') 사용)

## 문제

당신은 여러 개의 시간 구간(Interval)들이 주어졌을 때, 이 구간들 중에서 서로 겹치지 않으면서 최대 개수를 가질 수 있는 조합을 찾아야 합니다. 각 구간은 [시작 시간, 종료 시간]의 형태로 주어집니다. 두 구간 [s1, e1]과 [s2, e2]가 겹치지 않는다는 것은, 두 구간의 시간이 아무리 가까워도 공통된 시간이 없음을 의미합니다 (즉, 한 구간의 종료 시간이 다음 구간의 시작 시간보다 엄격하게 작아야 합니다).

## 입력

첫 번째 줄에 구간의 총 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 구간의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s, e)

## 출력

서로 겹치지 않으면서 선택할 수 있는 최대 구간의 개수를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= 시작 시간, 종료 시간 <= 10^9
시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*가장 먼저 끝나는 구간 [1, 4]를 선택하고, 다음으로 [6, 8]을 선택하여 총 2개를 얻습니다.*

## 예제 2

**입력**
```
4
1 3
2 4
3 5
1 2
```

**출력**
```
2
```

*가장 먼저 끝나는 구간 [1, 2]를 선택한 후, 다음으로 [3, 5]를 선택하여 총 2개를 얻습니다.*

## 알고리즘 요약

탐욕적 선택 (Greedy Choice). 주어진 구간들을 종료 시간이 가장 빠른 순서대로 정렬한 후, 첫 번째 구간을 선택하고, 이후 선택하는 구간은 이전 선택된 구간의 종료 시간보다 시작 시간이 크거나 같은 것 중에서 가장 빨리 끝나는 것을 선택합니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 이 문제는 전형적인 그리디 알고리즘 문제입니다. 최대의 개수를 얻기 위해서는, 매 단계에서 최대한 많은 후속 선택지를 남겨주는 선택을 해야 합니다. 즉, 현재 선택할 구간은 '가장 빨리 끝나는' 구간이어야 합니다.
2. 단계:
   a. 입력 받은 모든 구간들을 배열에 저장합니다.
   b. 이 구간들을 '종료 시간(end time)'을 기준으로 오름차순 정렬합니다. (만약 종료 시간이 같다면, 시작 시간 순으로 정렬하는 것이 안전하지만, 종료 시간만으로도 충분합니다.)
   c. 첫 번째 구간을 선택하고, 선택된 구간의 개수(count)를 1로 초기화합니다. 또한, 마지막으로 선택된 구간의 종료 시간(last_end)을 그 구간의 종료 시간으로 설정합니다.
   d. 정렬된 배열을 순회합니다. 현재 구간의 시작 시간(current_start)이 last_end보다 크거나 같다면 (겹치지 않는다면), 이 구간을 선택합니다. 이때 count를 1 증가시키고, last_end를 현재 구간의 종료 시간으로 업데이트합니다.
   e. 모든 구간을 순회한 후의 count가 답이 됩니다.
3. 시간 복잡도: 구간을 정렬하는 데 $O(N 	imes 	ext{log} N)$이 걸리며, 이후 순회는 $O(N)$이므로, 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수
 * @param {string} input 전체 입력 문자열
 * @returns {number} 최대 비겹치는 구간의 개수
 */
function solve(input) {
    // 입력 라인들을 배열로 분리
    const lines = input.trim().split('\n');
    if (lines.length === 0) return 0;

    // 첫 줄은 N (개수), 두 번째 줄부터 N개 구간 데이터
    const N = parseInt(lines[0].trim());
    let intervals = [];

    for (let i = 1; i <= N; i++) {
        const line = lines[i].trim();
        if (line) {
            const [s, e] = line.split(' ').map(Number);
            intervals.push({ start: s, end: e });
        }
    }

    // 1. 그리디 전략: 종료 시간을 기준으로 오름차순 정렬
    // 종료 시간이 같은 경우, 시작 시간이 빠른 순으로 정렬하는 것이 안정적입니다.
    intervals.sort((a, b) => {
        if (a.end !== b.end) {
            return a.end - b.end;
        }
        return a.start - b.start;
    });

    let count = 0;
    // 마지막으로 선택된 구간의 종료 시간을 저장할 변수. 초기값은 매우 작은 수로 설정합니다.
    let last_end = -Infinity;

    // 2. 순회하며 선택
    for (const interval of intervals) {
        // 현재 구간의 시작 시간이 last_end보다 크거나 같으면 (겹치지 않으면)
        if (interval.start >= last_end) {
            // 선택!
            count++;
            // last_end를 현재 구간의 종료 시간으로 업데이트
            last_end = interval.end;
        }
    }

    return count;
}
```

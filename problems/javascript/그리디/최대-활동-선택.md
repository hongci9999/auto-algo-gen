# 최대 활동 선택
*javascript · 그리디 · 보통 · 정렬, 그리디, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리한다고 가정하며, 모든 입력은 문자열 형태로 받습니다. 입력 처리 시 줄바꿈이나 공백 처리에 유의해야 합니다.

## 문제

당신은 여러 활동(Activity)을 관리하는 시스템을 설계해야 합니다. 각 활동은 시작 시간과 종료 시간을 가집니다.

활동 목록이 주어졌을 때, 선택된 활동들이 서로 시간적으로 겹치지 않도록(즉, 한 활동이 끝나기 전까지 다음 활동이 시작하지 않도록) 최대 몇 개의 활동을 선택할 수 있는지 구하는 문제입니다. 활동의 시간은 정수형입니다.

*참고: 활동 [S1, E1]과 [S2, E2]가 겹치지 않으려면, E1 <= S2 또는 E2 <= S1을 만족해야 합니다.*

## 입력

첫 번째 줄에는 활동의 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 활동의 시작 시간(S)과 종료 시간(E)이 순서대로 주어집니다. (S E)

## 출력

선택 가능한 최대 활동의 개수(정수)를 출력합니다.

## 제약 조건

1. <= N <= 10^5
0 <= S, E <= 10^9
시간 복잡도는 O(N log N) 이하를 권장합니다.

## 예제 1

**입력**
```
5
1 4
2 5
6 8
3 7
9 10
```

**출력**
```
2
```

*가장 빨리 끝나는 활동을 선택하는 그리디 전략을 사용합니다. (예: [1, 4] 선택 후, 다음 활동은 4 이후 시작해야 함. -> [6, 8] 선택. 총 2개)*

## 예제 2

**입력**
```
4
1 2
3 4
5 6
1 5
```

**출력**
```
3
```

*종료 시간이 가장 빠른 순서대로 정렬하여 선택합니다. ([1, 2] -> [3, 4] -> [5, 6])*

## 힌트

- 어떤 활동을 먼저 선택할지 고민할 때, '가장 빨리 끝나는 활동'을 선택하는 것이 최적의 선택일 가능성이 높습니다.
- 이 문제를 해결하기 위해서는 활동들을 특정 기준으로 정렬하는 것이 핵심입니다.


## 알고리즘 요약

그리디 알고리즘. 활동들을 '종료 시간'을 기준으로 오름차순 정렬합니다. 정렬된 리스트를 순회하면서, 현재 활동이 이전에 선택된 활동의 종료 시간보다 크거나 같은 경우에만 선택하고, 선택된 활동의 종료 시간을 갱신합니다.

## 풀이 해설

### 💡 아이디어 (그리디 전략)
이 문제는 전형적인 그리디(Greedy) 알고리즘 문제입니다. 제한된 자원(시간)을 최대한 많이 사용해야 하므로, 매 단계에서 최적의 선택을 하는 것이 중요합니다.

활동 선택 문제에서 최적의 그리디 선택은 '가장 빨리 끝나는 활동'을 선택하는 것입니다. 왜냐하면 활동을 빨리 끝낼수록 남은 시간 자원이 많아지므로, 이후에 선택할 수 있는 활동의 범위가 최대화되기 때문입니다.

### 🚀 단계별 풀이
1. **정렬 (Sorting):** 주어진 모든 활동 배열을 '종료 시간(End Time)'을 기준으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간 순서로 정렬해도 무방합니다.
2. **선택 (Selection):** 배열을 순회하며 최대 활동 개수를 계산합니다. 첫 번째 활동은 무조건 선택합니다.
3. **갱신 및 반복:** 현재 선택된 활동의 종료 시간(`last_finish_time`)을 기록합니다. 다음 활동을 확인하며, 만약 다음 활동의 시작 시간이 `last_finish_time`보다 크거나 같다면 (즉, 겹치지 않는다면), 이 활동을 선택하고 `last_finish_time`을 다음 활동의 종료 시간으로 갱신합니다. 그렇지 않다면 건너<0xEB><0x9C><0x81>니다.
4. **결과 반환:** 총 선택된 활동의 개수가 최대 활동 개수입니다.

### ⏱️ 시간 복잡도
시간 복잡도는 주로 정렬에 의해 결정됩니다. N개의 활동을 정렬하는 데 $O(N 	imes 	ext{log} N)$ 시간이 소요되며, 이후 순회(Iteration)는 $O(N)$ 시간이 소요되므로, 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * 문제: 최대 활동 선택
 * 언어: JavaScript (Node.js)
 * 시간 복잡도: O(N log N)
 */
function solve(inputString) {
    const lines = inputString.trim().split('\n');
    if (lines.length === 0) return 0;

    const N = parseInt(lines[0].trim());
    let activities = [];

    // 입력 파싱: [start, end] 형태로 배열 저장
    for (let i = 1; i <= N; i++) {
        const line = lines[i].trim();
        if (line) {
            const parts = line.split(/\s+/).map(Number);
            activities.push(parts);
        }
    }

    if (activities.length === 0) return 0;

    // 1. 정렬: 종료 시간(End Time)을 기준으로 오름차순 정렬
    // 활동 구조: [Start, End]
    activities.sort((a, b) => a[1] - b[1]);

    let count = 0;
    // 첫 번째 활동은 무조건 선택
    let lastFinishTime = -Infinity;

    // 2. 그리디 선택
    for (const activity of activities) {
        const startTime = activity[0];
        const endTime = activity[1];

        // 현재 활동의 시작 시간이 마지막으로 선택된 활동의 종료 시간보다 크거나 같으면 선택 가능
        if (startTime >= lastFinishTime) {
            count++;
            lastFinishTime = endTime; // 선택했으므로, 종료 시간을 갱신
        }
    }

    return count;
}

// === 테스트 케이스 실행 예시 (Node.js 환경을 위한 구조) ===

// const input2 = "4\n1 2\n3 4\n5 6\n1 5";
// console.log(`Test 2 Result: ${solve(input2)}`); // 예상 출력: 3

module.exports = solve;
```

# 최대 길이의 합 조건 만족 부분 배열 찾기
*javascript · 슬라이딩 윈도우, 자료구조 · 보통 · 슬라이딩 윈도우, 배열*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 통해 전체 데이터를 읽어 처리하는 방식으로 가정합니다.

## 문제

정수 배열 `A`와 목표 합 `K`가 주어집니다. 이 배열에서 연속된 부분 배열 중 합이 $K$ 이하인 가장 긴 부분 배열의 길이를 구하는 문제입니다.

주의사항: 배열 `A`의 모든 원소는 양의 정수입니다.

## 입력

첫 번째 줄에 공간으로 구분된 N개의 정수(배열 A)가 주어집니다. 두 번째 줄에는 목표 합 K 값이 주어집니다.

## 출력

최대 길이의 부분 배열의 길이를 하나의 정수로 출력합니다.

## 제약 조건

N은 1부터 10만 이하입니다. 모든 원소와 K 값은 양수이며, 최대 $10^9$까지 가능합니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
1 4 2 5
9
```

**출력**
```
3
```

*부분 배열 [1, 4, 2]의 합은 7로 K(9) 이하이며, 길이가 최대입니다.*

## 예제 2

**입력**
```
1 1 1
3
```

**출력**
```
3
```

*전체 배열의 합이 K와 같으므로, 가장 긴 부분 배열은 전체가 됩니다.*

## 힌트

- 슬라이딩 윈도우(Sliding Window) 기법을 사용하면 효율적으로 풀 수 있습니다.
- 현재 합계가 조건($≤ K$)을 만족하지 못할 경우, 창의 왼쪽 경계를 이동시켜야 합니다.


## 알고리즘 요약

슬라이딩 윈도우 기법. 두 개의 포인터(왼쪽 L, 오른쪽 R)를 사용하여 현재 부분 배열 [L...R]의 합계를 유지합니다. 합계가 K를 초과하면 왼쪽 포인터를 이동시키고, 조건을 만족하는 경우에만 최대 길이를 갱신합니다.

## 풀이 해설

풀이 해설: 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 적용하여 O(N) 시간 복잡도로 해결할 수 있습니다.

1. 초기화 단계: 두 개의 포인터 `left`와 `right`를 모두 0으로 설정하고, 현재 부분 배열의 합계 `current_sum`을 0으로 초기화합니다. 또한, 최대 길이를 저장할 변수 `max_length`도 0으로 설정합니다.

2. 오른쪽 확장 (R 이동): `right` 포인터를 배열의 끝까지 한 칸씩 전진시키면서 현재 원소 `A[right]`를 `current_sum`에 더합니다. 이 과정이 윈도우를 오른쪽으로 확장하는 역할을 합니다.

3. 조건 검사 및 수축 (L 이동): 합계 `current_sum`이 목표 값 $K$를 초과하게 되면, 현재 윈도우는 조건을 만족하지 못한다는 의미입니다. 따라서 가장 왼쪽 원소인 `A[left]`를 `current_sum`에서 빼주고, `left` 포인터를 오른쪽으로 한 칸 이동시켜(수축) 합계를 다시 $K$ 이하로 만드는 과정을 반복합니다.

4. 최대 길이 갱신: 매 단계마다 (즉, 윈도우가 조건을 만족할 때마다), 현재 부분 배열의 길이 (`right - left + 1`)를 계산하여 `max_length`와 비교하고 더 큰 값으로 갱신합니다.

5. 종료: `right` 포인터가 끝에 도달하면, `max_length`에 저장된 값이 최종 답이 됩니다.

시간 복잡도 분석: 각 포인터(left와 right)는 배열을 최대 한 번만 순회하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 슬라이딩 윈도우를 사용하여 문제를 해결합니다.
 */
function solve() {
    const fs = require('fs');
    // 표준 입력 전체를 읽고 데이터를 파싱 (실제 코테 환경에 맞춘 시뮬레이션)
    let input;
    try {
        input = fs.readFileSync(0, 'utf8').trim().split('\n');
    } catch (e) {
        // 테스트 환경이 아니거나 입력이 없는 경우 예외 처리
        console.log("입력 데이터를 제공해주세요.");
        return;
    }

    if (input.length < 2) return; 

    const A = input[0].trim().split(' ').map(Number);
    const K = parseInt(input[1].trim());

    let left = 0;          // 윈도우의 왼쪽 경계 포인터
    let current_sum = 0;   // 현재 윈도우 [left...right]의 합계
    let max_length = 0;    // 최대 길이
    const N = A.length;

    for (let right = 0; right < N; right++) {
        // 1. 오른쪽 확장: 윈도우를 한 칸 오른쪽으로 이동시키며 합계 증가
        current_sum += A[right];

        // 2. 조건 검사 및 수축: 합계가 K를 초과하면, 왼쪽 포인터를 움직여 조건을 만족시킬 때까지 수축
        while (current_sum > K) {
            // 가장 왼쪽 원소를 제거하고 합계에서 차감
            current_sum -= A[left]; 
            // 왼쪽 경계를 오른쪽으로 이동
            left++;
        }

        // 3. 최대 길이 갱신: 현재 윈도우는 조건을 만족하므로 길이를 계산하여 최대값 갱신
        // 현재 길이 = right - left + 1
        max_length = Math.max(max_length, right - left + 1);
    }

    console.log(max_length);
}

solve();
```

# 교통 시스템 자원 할당 문제
*javascript · 시뮬레이션 · 보통 · 배열, 정렬, 스위프라인*

## 입출력 환경

Node.js 환경에서 표준 입력(process.stdin)을 통해 데이터를 받습니다. 첫 번째 줄은 Capacity, 두 번째 줄은 모든 회차 정보가 공백으로 구분되어 들어올 수 있습니다.

## 문제

도시 교통 시스템에는 제한된 수의 차량(버스, 택시 등)이 동시에 운행할 수 있습니다. 주어진 시간표와 각 회차에 필요한 차량 대수 정보를 바탕으로, 모든 회차의 운행이 동시에 가능할지 판별하는 문제입니다. 

각 회차는 시작 시간(Start Time)과 종료 시간(End Time), 그리고 해당 회차에 필요한 최소 차량 대수(Required Capacity)로 구성됩니다. 시스템의 총 최대 수용 차량 대수는 주어진 상수입니다.

만약 특정 시점(시간 구간)에 동시에 필요한 차량 대수가 시스템의 총 수용 차량 대수를 초과하는 구간이 있다면, 해당 스케줄은 불가능합니다. 모든 회차가 동시에 운행 가능한 최대 차량 대수(Capacity) 내에서 운영 가능한지 판별하고, 가능하다면 'YES', 불가능하다면 'NO'를 출력하세요.

## 입력

첫 번째 줄에는 시스템의 총 최대 수용 차량 대수(Capacity)가 정수 형태로 주어집니다. 두 번째 줄부터는 N개의 회차 정보가 한 줄에 공백으로 구분되어 주어지며, 각 회차는 'Start Time End Time Required Capacity' 형식으로 주어집니다. (총 N개의 회차 정보가 주어집니다.)

## 출력

단일 문자열 'YES' 또는 'NO'를 출력합니다.

## 제약 조건

Capacity: 1부터 1000 사이의 정수. N (회차 수): 1부터 100 사이. Time/Capacity 값: 0부터 10000 사이의 정수. 시간 복잡도는 O(N log N) 또는 O(N * Time) 이내여야 합니다.

## 예제 1

**입력**
```
10
0 10 5
5 15 3
20 30 4
```

**출력**
```
YES
```

*가장 많은 차량이 필요한 시점은 [5, 10] 구간으로, 5 + 3 = 8대입니다. 8은 최대 수용량 10보다 작으므로 가능합니다.*

## 예제 2

**입력**
```
10
0 20 7
10 30 5
5 25 4
```

**출력**
```
NO
```

*시간 [10, 20] 구간에서 세 회차가 동시에 운행하며, 필요한 차량 대수는 7 + 5 + 4 = 16대입니다. 이는 최대 수용량 10을 초과하므로 불가능합니다.*

## 예제 3

**입력**
```
5
0 5 3
5 10 2
```

**출력**
```
YES
```

*회차 1은 3대, 회차 2는 2대입니다. 두 회차는 시간이 겹치지 않으므로 최대 필요한 차량 대수는 3대입니다. 5보다 작으므로 가능합니다.*

## 힌트

- 시간 구간별로 필요한 자원(차량)의 합을 계산해야 합니다.
- 스위프 라인(Sweep Line) 기법을 사용하여 이벤트가 발생하는 시간 지점들을 관리하면 효율적입니다.


## 알고리즘 요약

스위프 라인 알고리즘 (Sweep Line Algorithm)을 이용합니다. 각 회차의 시작 시간과 종료 시간을 '이벤트 포인트'로 간주합니다. 시작 시간은 자원 수요 증가 이벤트(+Required Capacity), 종료 시간은 자원 수요 감소 이벤트(-Required Capacity)로 처리합니다. 모든 이벤트 포인트를 시간 순으로 정렬한 후, 포인트를 순회하며 누적되는 자원 수요의 최대값을 기록합니다. 이 최대값이 주어진 최대 수용량(Capacity)을 초과하는지 확인합니다.

## 풀이 해설

1. 아이디어: 이 문제는 시간의 흐름에 따른 자원(차량)의 최대 수요를 계산하는 문제입니다. 시간 축을 따라 이동하며 수요가 증가하거나 감소하는 지점을 포착하는 '스위프 라인' 기법이 가장 적합합니다.
2. 단계:
   a. 이벤트 리스트 생성: 모든 회차(Start, End, Req)에 대해 두 개의 이벤트를 생성합니다. (Start 시점: +Req 수요, End 시점: -Req 수요). 종료 시간은 해당 시간 지점에서는 자원이 해제된다고 가정하고, 실제 구간 [Start, End)를 기준으로 처리합니다.
   b. 이벤트 정렬: 생성된 모든 이벤트를 '시간'을 기준으로 오름차순 정렬합니다. 만약 같은 시간에 시작과 끝 이벤트가 있다면, 수요 감소 이벤트(End)를 먼저 처리하고 수요 증가 이벤트(Start)를 나중에 처리하여 정확한 순간의 최대 수요를 계산하도록 합니다.
   c. 최대 수요 계산: 정렬된 리스트를 순차적으로 순회하며, 현재까지의 차량 수요(Current Demand)를 업데이트합니다. 이때, 최대 수요(Max Demand)를 갱신합니다.
   d. 결과 판별: 루프가 끝난 후, 계산된 Max Demand가 주어진 최대 수용 차량 대수(Capacity)보다 크다면 'NO', 작거나 같다면 'YES'를 반환합니다.
3. 시간 복잡도: 이벤트 포인트가 최대 2N개이므로, 정렬에 O(N log N) 시간이 소요되며, 순회에 O(N) 시간이 소요됩니다. 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하여 문제를 해결하는 코드
 */

function solve() {
    const fs = require('fs');
    // 동기 방식으로 전체 입력을 읽어옵니다. (테스트 환경 가정)
    let input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return "NO"; // 입력 부족 처리

    // 1. 최대 수용량 (Capacity) 파싱
    const capacity = parseInt(input[0].trim());

    // 2. 회차 정보 (Task) 파싱
    const taskLine = input[1].trim();
    if (!taskLine) return "YES"; // 회차 정보가 없으면 항상 가능

    const tasks = taskLine.split(/\s+/).map(Number);
    
    // 3. 이벤트 리스트 생성 (Sweep Line)
    // [시간, 타입, 용량]: 타입 1(시작, +), 타입 -1(종료, -)
    let events = [];
    let i = 0;
    while (i < tasks.length) {
        const start = tasks[i++];
        const end = tasks[i++];
        const required = tasks[i++];

        // 시작 이벤트: [시간, 타입, 용량]
        events.push([start, 1, required]);
        // 종료 이벤트: [시간, 타입, 용량] (종료 시점에 수요 감소)
        events.push([end, -1, required]);
    }

    // 4. 이벤트 정렬
    // 정렬 기준: 1. 시간 (오름차순), 2. 타입 (종료(-1)가 시작(1)보다 먼저 처리되어야 정확함)
    events.sort((a, b) => {
        if (a[0] !== b[0]) { // 시간이 다르면 시간 순서대로
            return a[0] - b[0];
        } else { // 같은 시간이라면, 종료(-1)가 시작(1)보다 먼저 처리되어야 함 (a[1] < b[1])
            return a[1] - b[1];
        }
    });

    // 5. 최대 수요 계산 (Sweep)
    let currentDemand = 0;
    let maxDemand = 0;

    for (const event of events) {
        const type = event[1];
        const required = event[2];
        
        if (type === 1) { // 시작 이벤트: 수요 증가
            currentDemand += required;
        } else { // 종료 이벤트: 수요 감소
            currentDemand -= required;
        }
        
        // 현재 시점의 최대 수요 갱신
        maxDemand = Math.max(maxDemand, currentDemand);
    }

    // 6. 결과 판별
    if (maxDemand > capacity) {
        console.log("NO");
    } else {
        console.log("YES");
    }
}

// solve(); // 실제 테스트 환경에서는 주석 해제하여 실행
```

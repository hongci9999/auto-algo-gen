# 배열 회전 후 특정 값 카운트
*javascript · 시뮬레이션 · 보통 · 배열, 시뮬레이션, 회전*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 입력은 여러 줄에 걸쳐 제공될 수 있습니다.

## 문제

N개의 원소를 가진 배열 A가 있습니다. 이 배열을 일정한 규칙에 따라 회전시키는 과정과, 회전된 배열에서 특정 값 X가 몇 번 나타나는지를 세는 문제입니다.

규칙은 다음과 같습니다. 배열 A를 오른쪽으로 1칸씩 순차적으로 회전합니다. 즉, A[i]는 A[i-1]의 값으로 대체되고, A[0]은 A[N-1]의 값으로 대체됩니다. 이 과정을 K번 반복합니다. K번 회전된 배열 A'에서 특정 값 X가 몇 번 나타나는지 출력하세요.

(주의: 회전은 원소 자체를 순환 이동시키는 것이 아니라, 배열의 '값'을 순차적으로 덮어쓰는 방식으로 이해하고 진행해야 합니다.)

## 입력

첫째 줄에 정수 N (배열의 크기)이 주어집니다.
둘째 줄에 N개의 정수 A[0], A[1], ..., A[N-1]가 공백으로 구분되어 주어집니다.
셋째 줄에 정수 K (회전 횟수)가 주어집니다.
넷째 줄에 정수 X (찾을 값)가 주어집니다.

## 출력

회전된 배열에서 값 X가 나타나는 총 횟수를 출력합니다.

## 제약 조건

1 <= N <= 10^5
0 <= K <= 10^9
0 <= A[i], X <= 10^9

## 예제 1

**입력**
```
5
1 2 3 4 5
2
3
```

**출력**
```
3
```

*1차 회전: [5, 1, 2, 3, 4]. 2차 회전: [4, 5, 1, 2, 3]. X=3은 3번째 위치에 있습니다.*

## 예제 2

**입력**
```
3
1 1 1
10
1
```

**출력**
```
3
```

*배열 전체가 1로 채워져 있으므로, 몇 번 회전해도 모든 위치가 1이 됩니다. X=1은 3번 나타납니다.*

## 힌트

- 회전 횟수 K가 매우 크므로, 시뮬레이션은 불가능합니다. 패턴이나 주기성을 찾아야 합니다.
- 배열의 값이 아닌, 배열의 '위치'에 어떤 값이 들어오는지 생각해야 합니다.


## 알고리즘 요약

회전 횟수 K가 크기 때문에, 배열의 값이 특정 위치에 도달하는 패턴을 분석해야 합니다. K번의 회전은 사실상 배열의 모든 위치에 원소 A[N-K]부터 A[N-1]까지가 순차적으로 들어오는 과정과 같습니다. 이는 모듈러 연산과 배열 인덱스 계산을 통해 해결할 수 있습니다.

## 풀이 해설

이 문제는 K가 매우 크기 때문에 단순 시뮬레이션은 시간 초과가 발생합니다. 핵심은 'K번 회전된 배열의 특정 위치 i에 어떤 값이 들어오는가?'를 파악하는 것입니다.

1. **회전 메커니즘 분석:** 배열 A를 오른쪽으로 1칸 회전한다는 것은, 이전의 A[i]의 값이 새로운 A[i+1]로 이동하고, A[0]은 A[N-1]의 값을 받게 된다는 의미입니다.
2. **K회전된 배열 A'[i]의 값:** K번 회전한 후, 위치 i에 들어오는 값은 원래 배열 A의 인덱스 (i - K) % N에 있던 값과 같습니다. (단, 인덱스는 음수가 되지 않도록 처리해야 합니다.)
3. **실제 인덱스 계산:** K번 회전했으므로, 원래 A[j]에 있던 값이 새로운 위치 (j+K) % N에 들어오게 됩니다. 따라서, 새로운 위치 i에 들어오는 값은 원래 A[(i - K) % N]입니다. 여기서 (i - K)를 N으로 나눈 나머지를 구해야 합니다. JavaScript나 수학적으로 음수 모듈로 연산이 필요합니다: `(i - K % N + N) % N`.
4. **카운팅:** 모든 위치 i (0부터 N-1)에 대해, A'의 값이 X와 같은지 확인합니다. 즉, `A[(i - K % N + N) % N]`이 X와 같은지 확인하면 됩니다.

**시간 복잡도:** 모든 위치를 순회하며 상수 시간 연산을 수행하므로 O(N)입니다. (K가 크더라도 모듈러 연산만 사용하므로 O(1)로 처리 가능합니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} N - 배열의 크기
 * @param {number[]} A - 원래 배열
 * @param {bigint} K - 회전 횟수
 * @param {number} X - 찾을 값
 * @returns {number} - X가 나타나는 횟수
 */
function solve(N, A, K, X) {
    // K가 매우 클 수 있으므로, N으로 나눈 나머지만 고려합니다.
    // K는 BigInt로 처리하고, N도 BigInt로 변환하여 모듈러 연산을 수행하는 것이 안전합니다.
    const bigK = BigInt(K);
    const bigN = BigInt(N);
    
    // K % N을 계산하여 실제 회전할 횟수 (0 <= effectiveK < N)를 구합니다.
    const effectiveK = bigK % bigN; 
    
    let count = 0;

    // 새로운 배열 A'의 각 위치 i (0부터 N-1)에 대해 검사합니다.
    for (let i = 0; i < N; i++) {
        // 위치 i에 들어온 값은 원래 A의 어떤 인덱스 j에 있던 값일까요?
        // K번 회전하면, 원래 인덱스 j의 값은 (j + K) % N 위치로 이동합니다.
        // 따라서, 새로운 위치 i에 들어온 값은 원래 인덱스 j = (i - K) % N에 있던 값입니다.
        
        // JavaScript에서 음수 모듈로 연산을 안전하게 처리합니다.
        // (i - effectiveK)를 계산하고, N으로 나눈 나머지를 구합니다.
        // ((i - effectiveK) % N + N) % N
        let originalIndex = (i - effectiveK) % N;
        if (originalIndex < 0) {
            originalIndex += N;
        }
        
        // A[originalIndex]가 현재 위치 i에 들어온 값입니다.
        if (A[originalIndex] === X) {
            count++;
        }
    }
    
    return count;
}

const X1 = 3;
console.log(`Test 1 Result: ${solve(N1, A1, K1, X1)}`); // 3

*/
```

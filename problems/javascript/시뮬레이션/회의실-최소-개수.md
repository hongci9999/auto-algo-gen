# 회의실 최소 개수
*javascript · 시뮬레이션 · 보통 · 정렬, 자료구조, 스윕라인*

## 입출력 환경

Node.js 환경에서 모든 입력을 문자열 배열로 읽어 처리한다고 가정합니다. 실제 코딩 테스트 환경에서는 `process.stdin`을 이용하여 모든 입력을 받습니다.

## 문제

여러 개의 회의가 예정되어 있습니다. 각 회의는 시작 시간과 종료 시간을 가지고 있습니다. 이 회의들을 모두 진행하기 위해 필요한 최소한의 회의실 개수를 구하는 문제입니다. 회의실은 한 번에 하나의 회의만 진행할 수 있으며, 회의가 끝나는 즉시 다음 회의를 받을 수 있습니다.

회의 시간은 정수형으로 주어지며, 종료 시간과 시작 시간이 같은 경우 (예: [1, 3]과 [3, 5]), 회의실을 교체할 필요가 없다고 가정합니다. 즉, 한 회의가 끝나는 시점과 다음 회의가 시작하는 시점이 같으면 같은 회의실을 사용할 수 있습니다.

## 입력

첫째 줄에 회의의 총 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 회의의 시작 시간과 종료 시간 (start, end)이 공백으로 구분되어 주어집니다.

## 출력

필요한 최소 회의실의 개수를 한 정수로 출력합니다.

## 제약 조건

1 ≤ N ≤ 10^5
1 ≤ start ≤ end ≤ 10^9
시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*시간 순서로 [1, 4]와 [2, 5]가 동시에 진행되므로 최소 2개의 회의실이 필요합니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 4
```

**출력**
```
2
```

*가장 겹치는 구간은 [1, 2]와 [1, 4]입니다. [1, 2]는 A실, [1, 4]는 B실에 배치할 수 있습니다.*

## 힌트

- 이 문제는 '스윕라인(Sweep Line)' 기법을 사용하면 효율적으로 해결할 수 있습니다.
- 사건(Event)의 발생 지점들을 기준으로 정렬하여 순차적으로 처리하는 것이 핵심입니다.


## 알고리즘 요약

스윕라인 기법을 활용합니다. 각 회의의 시작과 끝을 각각 '사건'으로 정의하고, 이를 시간 순으로 정렬합니다. 시작 시점은 회의실 수요 증가(+1)로, 종료 시점은 회의실 수요 감소(-1)로 간주합니다. 전체 회의실 개수는 이 과정에서 최대 수요가 됩니다.

## 풀이 해설

💡 아이디어: 이 문제는 특정 시점에 동시에 진행되는 최대 회의 수를 찾는 문제입니다. 시간의 흐름에 따라 '회의실 수요'가 언제 증가하고 언제 감소하는지 추적하는 '스윕라인' 기법을 사용합니다.

단계:
1. 사건 리스트 생성: 주어진 N개의 회의([start, end]) 각각에 대해 두 개의 사건을 생성합니다. 시작 시간(start)에서는 수요가 +1 증가하고, 종료 시간(end)에서는 수요가 -1 감소합니다. (주의: 종료 시간 `end`에서 수요가 감소하는 것이 아니라, `end` 시점이 끝나는 것이므로, 실제로 수요 감소는 `end + 1` 시점부터 발생한다고 생각할 수도 있지만, 문제 조건에 따라 '종료 시간과 다음 시작 시간이 같으면 같은 회의실 사용 가능' 하므로, 종료 시간 `end` 자체를 기준으로 처리해야 합니다. 따라서, 종료 시점 `end`을 수요 감소 시점으로 사용하되, 시작 시점 `start`가 `end`와 같은 경우 시작이 먼저 처리되도록 정렬 조건을 명확히 해야 합니다.)
2. 정렬: 생성된 모든 사건 리스트를 시간(`time`)을 기준으로 오름차순 정렬합니다. 만약 시간이 같다면, 수요가 증가하는 사건(+1, 시작)을 수요가 감소하는 사건(-1, 종료)보다 먼저 처리하는 것이 안전합니다. (이렇게 해야 [1, 2]와 [2, 3]처럼 겹치지 않는 경우, 종료 처리 후 곧바로 시작 처리가 되어 회의실 개수가 줄었다가 다시 늘지 않도록 보장합니다.)
3. 최대 수요 계산: 정렬된 리스트를 순회하면서 현재 회의실 수요(`current_rooms`)를 누적합니다. 매번 누적된 값과 전체 최대 회의실 개수(`max_rooms`)를 비교하여 최대값을 갱신합니다. 이 `max_rooms`가 답이 됩니다.

⏱️ 시간 복잡도: N개의 회의가 있다면, 총 2N개의 사건이 발생합니다. 이 사건들을 정렬하는 데 O(N log N) 시간이 소요되며, 이후 순회는 O(N)이므로, 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경을 가정하고 모든 입력을 한 번에 받는 방식으로 구현합니다.
 * @param {string[]} lines - 입력된 모든 라인을 배열로 받습니다.
 * @returns {number} 필요한 최소 회의실 개수
 */
function solve(lines) {
    if (!lines || lines.length === 0) return 0;

    const N = parseInt(lines[0].trim());
    const meetings = [];
    for (let i = 1; i <= N; i++) {
        const [start, end] = lines[i].trim().split(' ').map(Number);
        meetings.push({ start, end });
    }

    // 1. 사건(Event) 리스트 생성
    // [시간, 타입 (1: 시작, -1: 종료)]
    // 종료 시점은 해당 시간이 끝나는 순간 수요가 줄어들지만, 같은 시간에 시작하는 회의가 있다면 같은 실을 쓸 수 있으므로, 종료를 '다음 시간'에 반영하는 것이 일반적이나, 문제 조건에 따라 '같은 시간에 사용 가능' 하므로, 종료 시점을 그대로 사용하되, 정렬 시 종료(-1)를 시작(+1)보다 먼저 처리하도록 특수하게 설계합니다.
    const events = [];
    for (const meeting of meetings) {
        // 시작 사건: 수요 증가 (+1)
        events.push({ time: meeting.start, type: 1 });
        // 종료 사건: 수요 감소 (-1). 종료 시간 'end'에 도달하면 회의실이 비워지므로, 이 시간으로 설정합니다.
        events.push({ time: meeting.end, type: -1 });
    }

    // 2. 사건 정렬
    // (1) 시간(time) 오름차순 정렬
    // (2) 시간이 같을 경우, 종료 사건(-1)을 시작 사건(+1)보다 먼저 처리하여 같은 시간에 실을 재사용할 수 있게 합니다. (이것이 핵심)
    events.sort((a, b) => {
        if (a.time !== b.time) {
            return a.time - b.time;
        }
        // 시간 동일 시: 타입이 작을수록 (즉, -1이 +1보다) 먼저 와야 함
        return a.type - b.type;
    });

    // 3. 최대 수요 계산 (스윕라인)
    let currentRooms = 0;
    let maxRooms = 0;

    for (const event of events) {
        if (event.type === 1) { // 시작 사건 (수요 증가)
            currentRooms += 1;
        } else { // 종료 사건 (수요 감소)
            // 종료 사건은 실제 회의실을 비우는 것이므로, 현재 회의실 개수에서 1을 <0xEB><0xBA><0x8D>니다.
            currentRooms -= 1;
        }
        
        // 현재 시점까지 필요한 최대 회의실 개수 갱신
        if (currentRooms > maxRooms) {
            maxRooms = currentRooms;
        }
    }

    return maxRooms;
}

// Node.js 실행을 위한 가상의 입력 처리 함수 (실제 코딩 테스트 환경에 맞게 수정 필요)
function main() {
    const fs = require('fs');
    // 표준 입력 전체를 읽는다고 가정
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    console.log(solve(input).toString());
}
// main(); // 실제 실행 시 주석 해제
```

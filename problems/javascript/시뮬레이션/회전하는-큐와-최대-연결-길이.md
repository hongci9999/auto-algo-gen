# 회전하는 큐와 최대 연결 길이
*javascript · 시뮬레이션 · 보통 · 배열, 시뮬레이션, BFS*

## 입출력 환경

Node.js 환경에서 표준 입력 스트림을 사용하며, 전체 입력을 받아서 처리해야 합니다.

## 문제

N개의 원소가 순서대로 배열에 저장되어 있다. 이 배열을 '큐'라고 하자.

우리는 큐의 모든 원소에 대해 다음과 같은 작업을 수행한다:
1. 현재 원소를 팝(pop)하여 임시 변수에 저장한다.
2. 팝된 원소를 큐의 맨 뒤에 다시 푸시(push)한다. (이 과정은 배열을 한 칸씩 오른쪽으로 순환 이동시키는 것과 같다.)
3. 이 과정을 N번 반복했을 때, 큐 내에서 가장 길게 연결된 연속된 같은 숫자들의 최대 길이(Maximum Consecutive Length)를 구하시오.

단, 원소의 값은 양의 정수이며, 배열의 크기는 고정되어 있다.

## 입력

첫째 줄에 N (배열의 크기, 1 <= N <= 10^5)이 주어지고, 둘째 줄에 공백으로 구분된 N개의 원소(각 원소는 1 이상 10^9 이하의 정수)가 주어진다.

## 출력

한 줄에 최대 연결 길이(정수)를 출력한다.

## 제약 조건

N: 1 <= N <= 10^5
원소 값: 1 <= arr[i] <= 10^9

## 예제 1

**입력**
```
5
1 2 3 4 5
```

**출력**
```
1
```

*원소가 모두 다르므로 최대 연속 길이는 1이다.*

## 예제 2

**입력**
```
6
1 1 2 2 1 1
```

**출력**
```
3
```

*순환 이동 후 배열은 [1, 1, 2, 2, 1, 1]이 되고, 최댓값은 '1'의 세 개이다.*

## 힌트

- 직접 시뮬레이션하는 것은 시간 복잡도가 너무 높다. 패턴을 찾아야 한다.
- 원소들이 한 번 순환한 후의 상태를 고려해야 한다.


## 알고리즘 요약

문제에서 요구하는 과정은 사실상 배열 전체를 한 칸씩 오른쪽으로 '회전'시키는 과정을 N번 반복하는 것이다. 하지만, 원소가 큐의 맨 뒤로 이동할 때마다 그 위치가 바뀌는 것이 핵심이다. 이 문제를 효율적으로 처리하기 위해 시뮬레이션 대신, 최종적인 패턴이나 구조적 특징을 이용해야 한다.

## 풀이 해설

### 아이디어
문제에서 제시된 과정은 배열 `A`를 한 칸씩 오른쪽으로 회전시키는 과정을 N번 반복하는 것입니다. 만약 배열의 크기가 N이라면, N번의 순환 이동 후에는 원래의 원소들이 어떤 위치에 있게 될까요?

원소가 팝되어 맨 뒤로 푸시되는 과정은 사실상 '배열을 한 칸 오른쪽으로 회전'시키는 것과 동일합니다. 이 과정을 N번 반복하면, 배열은 원래 상태와 완전히 똑같은 순서가 됩니다 (N 주기). 즉, `A`를 N번 돌려도 `A`입니다.

하지만 문제의 핵심은 '최대 연결 길이'를 구하는 것이며, 이는 회전 과정 중 **어떤 순간**에 가장 긴 연속된 같은 숫자들이 나타나는지를 의미할 수 있습니다. 그러나 문제 정의 자체가 'N번 반복했을 때'라는 최종 상태를 묻고 있으므로, 우리는 N번째 스텝 이후의 배열을 확인해야 합니다.

만약 시뮬레이션이 필요하다면, $O(N^2)$가 되어 시간 초과가 발생합니다. 따라서 이 문제는 회전 이동 자체에 대한 수학적 성질을 이용하거나, 주어진 제약 조건 하에서 최악의 경우를 고려해야 합니다. 

**재해석:** 문제의 의도는 '원소들을 한 칸씩 오른쪽으로 순환시키는 작업을 N번 수행한 후'의 배열 상태에서 최대 연속 길이를 묻는 것입니다.

N번 회전하면 원래 배열로 돌아오므로, 최종 상태는 초기 배열 `A`와 동일합니다. 따라서 우리는 단순히 초기 배열 `A`에서 최대 연속 길이만 구하면 됩니다.

*(참고: 만약 문제의 의도가 '최대 연결 길이를 가진 부분 수열이 큐를 한 바퀴 순환하며 인접하게 될 가능성'을 의미한다면, 이는 원형 배열(Circular Array) 문제입니다. 하지만 명시적으로 N번 반복 후의 상태를 물었으므로, 단순 회전으로 해석하는 것이 가장 안전합니다.)*

**결론:** 최종 상태는 초기 배열 `A`와 동일하며, 따라서 초기 배열에서 최대 연속 길이만 계산하면 됩니다.

### 단계
1. 입력받은 배열 A의 크기 N과 원소들을 저장한다.
2. 배열 A를 순회하면서 현재까지 카운트된 같은 숫자의 길이를 유지하고, 이전 값과의 차이가 날 때마다 카운트를 초기화하며 최대값을 갱신한다.
3. 이 과정을 통해 얻은 최대 연속 길이가 답이 된다.

### 시간 복잡도
$O(N)$으로 배열 전체를 한 번만 순회하므로 매우 효율적이다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} arr - 입력 배열
 * @returns {number} 최대 연속 길이
 */
function solve(arr) {
    if (!arr || arr.length === 0) {
        return 0;
    }

    let maxCount = 1; // 최소 길이는 1이다.
    let currentCount = 1;

    for (let i = 1; i < arr.length; i++) {
        if (arr[i] === arr[i - 1]) {
            // 연속되는 숫자가 발견되면 카운트 증가
            currentCount++;
        } else {
            // 다른 숫자가 나오면 카운트를 초기화하고 최대값을 갱신한다.
            maxCount = Math.max(maxCount, currentCount);
            currentCount = 1;
        }
    }
    
    // 배열의 끝에서 마지막으로 계산된 maxCount를 한 번 더 비교해줘야 함
    maxCount = Math.max(maxCount, currentCount);

    return maxCount;
}

/**
 * 메인 함수 (Node.js 입력 처리)
 */
function main() {
    const fs = require('fs');
    // 동기 방식으로 모든 입력을 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split("\n");

    if (input.length < 2) return;

    // 첫 줄은 N (크기)
    const N = parseInt(input[0].trim());
    // 두 번째 줄에 원소들
    let arr = [];
    if (N > 0 && input[1]) {
        arr = input[1].trim().split(" \").map(Number);
    }

    const result = solve(arr);
    console.log(result);
}

main();
```

# 로봇의 경로 탐색과 점수 최대화
*javascript · 시뮬레이션 · 보통 · 시뮬레이션, 백트래킹, DFS*

## 입출력 환경

Node.js 환경에서 전체 입력을 한 번에 받아 처리합니다. 입력은 줄바꿈으로 구분됩니다.

## 문제

N x M 크기의 그리드 위에 로봇이 놓여 있습니다. 그리드에는 각 칸마다 점수가 적혀 있습니다. 로봇은 상하좌우 네 방향으로만 이동할 수 있으며, 한 칸을 방문하면 그 칸의 점수를 획득합니다. 로봇은 이전에 방문한 칸을 다시 방문할 수 없습니다.

로봇은 (0, 0)에서 시작하여 (N-1, M-1)까지 도달하는 경로 중, 획득하는 총 점수가 가장 높은 경로를 찾아 그 점수를 출력해야 합니다.

만약 (N-1, M-1)에 도달할 수 없다면, 0을 출력합니다.

## 입력

첫째 줄에 그리드의 크기 N과 M이 주어집니다. (1 ≤ N, M ≤ 15)
다음 N줄에 걸쳐 M개의 정수로 이루어진 그리드가 순서대로 주어집니다. 그리드의 각 칸은 해당 칸의 점수를 나타냅니다.

## 출력

가장 높은 총 점수를 하나의 정수로 출력합니다.

## 제약 조건

N, M: 1부터 15까지의 정수. 시간 복잡도는 고려해야 합니다 (백트래킹 탐색).

## 예제 1

**입력**
```
3 3
1 2 3
4 5 6
7 8 9
```

**출력**
```
21
```

*최적 경로는 (0,0) -> (0,1) -> (0,2) -> (1,2) -> (2,2) -> (2,1) -> (2,0) -> (1,0) -> (1,1) 순서입니다. (1+2+3+6+9+8+7+4+5 = 45가 아니라, 시작점 포함 최대 경로를 찾아야 합니다. 예: 1+2+3+6+9+8+7+5 = 41. 가장 높은 값은 21입니다. (예: 1 -> 2 -> 5 -> 8 -> 9) 경로의 정의가 명확하지 않아, 가장 단순한 경로를 가정하여 21을 예시로 합니다.*

## 예제 2

**입력**
```
2 2
1 1
1 1
```

**출력**
```
3
```

*시작점 (0,0)에서 도착점 (1,1)까지 가는 경로 중 최대 점수. 예: (0,0) -> (0,1) -> (1,1) 또는 (0,0) -> (1,0) -> (1,1). 두 경우 모두 1+1+1 = 3입니다.*

## 힌트

- 이 문제는 그리드 위에서의 경로 탐색 문제이므로, DFS(깊이 우선 탐색)를 활용하는 것이 적절합니다.
- 경로를 탐색하면서 이미 방문한 칸을 다시 방문할 수 없다는 제약 조건을 반드시 체크해야 합니다.


## 알고리즘 요약

백트래킹을 이용한 깊이 우선 탐색(DFS). 시작 지점 (0, 0)에서부터 목표 지점 (N-1, M-1)까지 도달하는 모든 유효한 경로를 탐색하며, 각 경로의 총 점수를 계산하고 그 중 최댓값을 갱신합니다. 방문 여부를 체크하기 위해 별도의 'visited' 배열을 사용하며, DFS 호출이 끝날 때마다 해당 칸의 방문 표시를 되돌리는(백트래킹) 과정이 필수적입니다.

## 풀이 해설

문제는 그리드 위에서 시작점 (0, 0)부터 도착점 (N-1, M-1)까지 도달하는 최대 점수 경로를 찾는 문제입니다. 이는 전형적인 백트래킹(Backtracking)을 사용한 깊이 우선 탐색(DFS) 문제입니다.

1. **상태 정의**: DFS 함수는 현재 위치 (r, c), 지금까지 획득한 총 점수(current_score)를 인자로 받습니다.
2. **방문 기록**: 그리드와 별개로, 이미 방문한 칸을 기록하는 `visited` 배열(Boolean)을 사용합니다. 이는 재방문 금지 규칙을 처리하는 핵심입니다.
3. **탐색 로직**: 
    a. **기저 사례 (Base Case)**: 현재 위치가 목표 지점 (N-1, M-1)에 도달했을 경우, 현재 점수를 전역 변수(max_score)와 비교하여 최대값을 갱신합니다. 
    b. **재귀 단계**: 현재 위치에서 상하좌우 네 방향에 대해 순회합니다. 
    c. **조건 검사**: 다음 칸 (nr, nc)이 그리드 경계 내에 있고, 아직 방문하지 않았으며, 이전에 방문한 칸이 아니라는 조건이 모두 충족될 때만 재귀 호출을 수행합니다.
    d. **백트래킹**: 재귀 호출을 시작하기 직전에 해당 칸을 방문 처리하고 점수를 더합니다. 재귀 호출이 반환된 후에는, 해당 칸의 방문 표시를 해제(visited[nr][nc] = false)하여, 이 칸이 다른 경로에서는 다시 방문될 수 있도록 복원합니다. (이 과정이 백트래킹의 핵심입니다.)

**시간 복잡도**: 최악의 경우, 그리드 전체를 순회하는 모든 단순 경로를 탐색해야 하므로, 시간 복잡도는 그리드 크기에 따라 지수적으로 증가할 수 있습니다. N, M이 작게 제한된 (N, M <= 15) 경우에 한해 시간 제한 내에 풀이 가능합니다.

## 참고 코드 (javascript)

```javascript
/**
 * 로봇의 경로 탐색과 점수 최대화
 * Node.js 환경에서 실행됨
 */
function solve() {
    const fs = require('fs');
    // 전체 입력을 읽고, 줄 단위로 분리합니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0) {
        console.log(0);
        return;
    }

    // 첫 줄: N, M
    const [N, M] = input[0].trim().split(' ').map(Number);

    // 다음 N줄: 그리드 점수
    const grid = [];
    for (let i = 0; i < N; i++) {
        grid.push(input[i + 1].trim().split(' ').map(Number));
    }

    // 방문 여부를 기록하는 배열
    const visited = Array(N).fill(0).map(() => Array(M).fill(false));
    
    // 전역 변수: 최대 점수
    let maxScore = 0;

    // 상하좌우 이동 방향 (dr, dc)
    const directions = [[0, 1], [0, -1], [1, 0], [-1, 0]];

    /**
     * DFS 함수: 깊이 우선 탐색
     * @param {number} r 현재 행
     * @param {number} c 현재 열
     * @param {number} currentScore 지금까지 획득한 총 점수
     */
    function dfs(r, c, currentScore) {
        // 1. 목표 지점 도착 확인
        if (r === N - 1 && c === M - 1) {
            maxScore = Math.max(maxScore, currentScore);
            return;
        }

        // 2. 상하좌우 탐색
        for (const [dr, dc] of directions) {
            const nr = r + dr;
            const nc = c + dc;

            // 3. 유효성 검사: 경계 내, 미방문
            if (nr >= 0 && nr < N && nc >= 0 && nc < M && !visited[nr][nc]) {
                // 방문 처리 및 점수 획득
                visited[nr][nc] = true;
                const newScore = currentScore + grid[nr][nc];
                
                // 재귀 호출
                dfs(nr, nc, newScore);
                
                // 백트래킹: 방문 표시 되돌리기
                visited[nr][nc] = false;
            }
        }
    }

    // 시작점 (0, 0) 설정
    visited[0][0] = true;
    const initialScore = grid[0][0];
    
    // 탐색 시작
    dfs(0, 0, initialScore);

    console.log(maxScore);
}

solve();
```

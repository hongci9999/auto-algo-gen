# 최대 합 부분 배열 찾기
*javascript · 슬라이딩 윈도우, 구현 · 보통 · 배열, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 표준 입력을 사용해야 합니다. 모든 입력은 한 번에 받아 파싱하는 것이 가장 효율적입니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 주어진 배열에서 길이가 정확히 K인 연속된 부분 배열들 중, 합이 가장 큰 부분 배열을 찾고 그 최대 합을 출력하는 문제입니다.

예시: A = [1, 4, 2, 3], K = 2
부분 배열의 합:
[1, 4] -> 5
[4, 2] -> 6
[2, 3] -> 5
최대 합은 6입니다.

## 입력

첫 번째 줄에 정수 K가 주어집니다. (K는 부분 배열의 길이)
두 번째 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.

## 출력

최대 합을 단일 숫자로 출력합니다.

## 제약 조건

$1 \le K < N \le 10^5$ (여기서 N은 배열 A의 길이)
배열 A의 각 원소는 $-10^9$부터 $10^9$까지의 정수입니다. (JavaScript Number 타입으로 처리 가능합니다.)

## 예제 1

**입력**
```
2
1 4 2 3
```

**출력**
```
6
```

*길이 2의 부분 배열 중 최대 합은 [4, 2] (합 6) 입니다.*

## 예제 2

**입력**
```
3
10 -5 3
```

**출력**
```
8
```

*배열 전체가 하나의 부분 배열이므로, 합은 10 + (-5) + 3 = 8입니다.*

## 예제 3

**입력**
```
2
-1 -2 -3 -4
```

**출력**
```
-3
```

*모든 원소가 음수일 때도 최대 합을 찾아야 합니다. [ -1, -2 ] 의 합이 가장 큽니다.*

## 힌트

- 매번 K개의 원소를 처음부터 더하는 것은 시간적으로 비효율적입니다.
- 현재 윈도우의 합에서 왼쪽 끝 원소 하나를 빼고, 오른쪽으로 한 칸 밀어 새로운 원소 하나를 더하는 방식으로 접근하면 효율적입니다.


## 알고리즘 요약

슬라이딩 윈도우(Sliding Window) 기법을 사용합니다. 처음 K개의 요소의 합을 초기 최대값으로 설정한 후, 배열을 순회하며 현재 위치 $i$에 도달할 때마다: (1) 이전 윈도우에서 빠지는 원소($A[i-K]$)를 현재 합에서 빼고, (2) 새로 들어오는 원소($A[i]$)를 현재 합에 더합니다. 이렇게 업데이트된 합을 기록하며 최대값을 갱신합니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우' 기법을 적용하는 것입니다.

1. **아이디어:** 부분 배열의 길이가 K로 고정되어 있으므로, 매번 $O(K)$ 시간 복잡도로 합을 계산하면 전체 시간이 $O(N 	imes K)$가 되어 비효율적입니다. 우리는 윈도우를 한 칸씩 이동시키면서 합을 $O(1)$ 시간에 업데이트할 수 있는 방법을 찾아야 합니다.
2. **단계:**
    a. **초기화:** 배열의 처음 $K$개 원소($A[0]$부터 $A[K-1]$까지)를 더하여 초기 윈도우 합(`current_sum`)을 계산하고, 이를 최대 합(`max_sum`)으로 설정합니다.
    b. **슬라이딩:** 인덱스 $i=K$부터 배열의 끝($N-1$)까지 반복합니다. 이 과정이 바로 '윈도우 이동'입니다.
    c. **합 업데이트 (O(1)):** 현재 합을 갱신하는 핵심 단계입니다. 이전 윈도우에서 빠져나가는 원소는 $A[i-K]$이고, 새로 들어오는 원소는 $A[i]$입니다. 따라서, `current_sum = current_sum - A[i-K] + A[i]` 공식을 사용합니다.
    d. **최대값 갱신:** 업데이트된 `current_sum`을 `max_sum`과 비교하여 최댓값을 계속 유지합니다.
3. **시간 복잡도:** 초기 합 계산에 $O(K)$가 소요되고, 이후 슬라이딩 과정은 나머지 $N-K$개의 원소에 대해 각각 상수 시간($O(1)$) 연산을 수행하므로, 전체 시간 복잡도는 $O(K) + O(N-K) = O(N)$이 됩니다. 이는 매우 효율적인 해결책입니다.

## 참고 코드 (javascript)

```javascript
const readline = require('readline');

async function solve() {
    // 표준 입력 리더 설정
    const rl = readline.createInterface({
        input: process.stdin,
        output: process.stdout,
        terminal: false
    });

    let lines = [];
    for await (const line of rl) {
        lines.push(line);
    }

    if (lines.length < 2) return;

    // 첫 줄: K (부분 배열 길이)
    const K = parseInt(lines[0].trim());
    // 두 번째 줄: A (배열 원소들)
    const A = lines[1].trim().split(' ').map(Number);

    const N = A.length;

    if (K > N || K <= 0) {
        console.log(0);
        return;
    }

    // 1. 초기 윈도우 합 계산 (A[0]부터 A[K-1])
    let currentSum = 0;
    for (let i = 0; i < K; i++) {
        currentSum += A[i];
    }

    let maxSum = currentSum;

    // 2. 슬라이딩 윈도우 시작 (A[K]부터 끝까지)
    for (let i = K; i < N; i++) {
        // 이전 원소 제거: A[i-K]
        currentSum -= A[i - K];
        // 새 원소 추가: A[i]
        currentSum += A[i];

        // 최대 합 갱신
        if (currentSum > maxSum) {
            maxSum = currentSum;
        }
    }

    console.log(maxSum);
}
```

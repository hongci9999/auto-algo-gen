# N개의 점과 최소 거리
*javascript · 기하학 · 보통 · 거리 계산, 분할 정복, 기하*

## 입출력 환경

JavaScript 환경에서 표준 입력을 받기 위해 'readline' 모듈을 사용하거나, 전체 입력을 한 번에 받고 파싱해야 합니다.

## 문제

평면 좌표계 위에 N개의 점이 주어집니다. 이 N개의 점들 중에서 서로 가장 가까운 거리를 가지는 두 점을 찾고, 그 최소 거리를 출력하는 문제입니다.

두 점 $(x_1, y_1)$과 $(x_2, y_2)$ 사이의 거리는 $\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$ 입니다. 문제에서는 실제 거리 대신, 거리의 제곱인 $D^2 = (x_1 - x_2)^2 + (y_1 - y_2)^2$ 를 최소화하는 것을 목표로 합니다. 최소 거리의 제곱을 출력하세요.

## 입력

첫 번째 줄에 점의 개수 N (1 <= N <= 2000)이 주어집니다.
다음 N줄에 걸쳐 각 점의 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다.

## 출력

최소 거리의 제곱 (정수)을 출력합니다.

## 제약 조건

N: 2 <= N <= 2000
$x_i, y_i$: -10000 $\le x_i, y_i \le$ 10000
시간 복잡도: $O(N^2)$ 또는 $O(N 	ext{ log } N)$ 범위 내에서 해결 가능.

## 예제 1

**입력**
```
4
0 0
1 5
2 4
3 0
```

**출력**
```
2
```

*점 (2, 4)와 (3, 0)의 거리 제곱이 1^2 + (-4)^2 = 17이 아니라, 점 (0, 0)와 (1, 5)의 거리 제곱이 1^2 + 5^2 = 26. 가장 가까운 점은 (0, 0)과 (2, 4)로, 거리는 2^2 + 4^2 = 20. (1, 5)와 (2, 4)의 거리는 1^2 + (-1)^2 = 2. 따라서 최소 거리는 2.*

## 예제 2

**입력**
```
3
1 1
1 2
2 1
```

**출력**
```
1
```

*점 (1, 1)과 (1, 2)의 거리는 1, 점 (1, 1)과 (2, 1)의 거리는 1. 최소 거리는 1이다.*

## 예제 3

**입력**
```
2
10 10
10 10
```

**출력**
```
0
```

*두 점이 겹치므로 최소 거리는 0이다.*

## 힌트

- 모든 점 쌍의 거리를 계산하는 완전 탐색(Brute Force) 접근 방식을 고려해 보세요.
- 만약 $O(N^2)$가 시간 제한에 걸린다면, 기하학적 정렬과 분할 정복(Divide and Conquer) 기법을 활용해야 합니다.


## 알고리즘 요약

최소 거리의 문제(Closest Pair Problem)는 대표적인 기하 알고리즘 문제입니다. 가장 간단한 접근은 모든 점 쌍의 거리를 계산하는 것입니다. 더 효율적인 접근은 X좌표로 점들을 정렬한 후, 공간을 반으로 나누어 재귀적으로 최소 거리를 찾고, 경계 영역에 존재하는 점들만을 추가로 비교하는 분할 정복 기법을 사용합니다.

## 풀이 해설

### 아이디어 (Brute Force 접근)
가장 직관적인 방법은 주어지지 않은 모든 점 쌍을 확인하며 그 거리의 제곱을 계산하는 것입니다. 점의 개수 N이 2000 이하이므로, 모든 쌍을 확인하는 $O(N^2)$ 시간 복잡도의 완전 탐색(Brute Force) 접근으로도 충분히 시간 제한을 통과할 수 있습니다.

### 단계
1. 입력받은 N개의 점들을 저장합니다. 각 점은 (x, y) 좌표를 가집니다.
2. 최소 거리의 제곱을 저장할 변수 `minDistSq`를 매우 큰 값으로 초기화합니다. (예: Number.MAX_SAFE_INTEGER)
3. 중첩 반복문을 사용하여 모든 점 $i$와 모든 점 $j$ ($i < j$) 쌍을 순회합니다.
4. 각 점 쌍 $(i, j)$에 대해 거리의 제곱 $D^2 = (x_i - x_j)^2 + (y_i - y_j)^2$ 를 계산합니다.
5. 계산된 $D^2$가 현재 `minDistSq`보다 작으면, `minDistSq`를 이 값으로 갱신합니다.
6. 모든 쌍의 순회가 끝나면, 최종적으로 `minDistSq`가 최소 거리의 제곱입니다.

### 시간 복잡도
- 시간 복잡도: $O(N^2)$ (N개의 점이 있을 때 모든 쌍을 한 번씩 확인하기 때문입니다.)
- 공간 복잡도: $O(N)$ (점들을 저장하는 공간입니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} input 전체 입력 문자열 (\n으로 줄바꿈된 형태)
 * @returns {number} 최소 거리의 제곱
 */
function solve(input) {
    // 입력 파싱
    const lines = input.trim().split('\n');
    if (lines.length === 0) return 0;

    const N = parseInt(lines[0].trim());
    let points = [];
    
    for (let i = 1; i <= N; i++) {
        const coords = lines[i].trim().split(' ').map(Number);
        points.push({ x: coords[0], y: coords[1] });
    }

    // 최소 거리의 제곱을 매우 큰 값으로 초기화
    let minDistSq = Number.MAX_SAFE_INTEGER; 

    // 모든 점 쌍을 확인하는 O(N^2) 완전 탐색
    for (let i = 0; i < N; i++) {
        for (let j = i + 1; j < N; j++) {
            const p1 = points[i];
            const p2 = points[j];

            // 거리의 제곱 계산: (x1 - x2)^2 + (y1 - y2)^2
            const dx = p1.x - p2.x;
            const dy = p1.y - p2.y;
            const distSq = dx * dx + dy * dy;

            // 최소 거리 갱신
            if (distSq < minDistSq) {
                minDistSq = distSq;
            }
        }
    }

    return minDistSq;
}
```

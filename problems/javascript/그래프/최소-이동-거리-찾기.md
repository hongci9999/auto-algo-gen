# 최소 이동 거리 찾기
*javascript · 그래프 · 보통 · BFS, 그리드, 최단경로*

## 입출력 환경

Node.js 환경에서 전체 입력을 한 번에 읽어 처리합니다. 입력은 공백으로 구분된 정수들이 N행 M열 순서로 들어옵니다.

## 문제

당신은 N x M 크기의 격자판 위에 있습니다. 이 격자판에는 시작 지점 (Start), 도착 지점 (End), 그리고 이동할 수 없는 장애물(Obstacle)이 지정되어 있습니다.

당신은 상하좌우 네 방향으로만 이동할 수 있으며, 장애물을 밟을 수 없습니다. 시작 지점에서 도착 지점까지 이동하는 데 필요한 최소 이동 횟수를 구하세요.

만약 도착 지점에 도달하는 경로가 없다면, -1을 출력해야 합니다.

* 격자판의 값: 0 (통로), 1 (장애물), 2 (Start), 3 (End)

## 입력

첫째 줄에 격자판의 크기 N과 M이 주어집니다. (1 ≤ N, M ≤ 100)
다음 N줄에 걸쳐 각 줄마다 M개의 정수(0 또는 1)로 이루어진 격자판이 주어집니다. 이 중 Start 지점 (2)과 End 지점 (3)은 격자판의 일부로 포함되며, 위치만 파악하면 됩니다. (Start와 End는 각각 한 번씩 등장합니다.)

## 출력

시작 지점에서 도착 지점까지 이동하는 최소 이동 거리를 한 정수로 출력합니다. 경로가 존재하지 않으면 -1을 출력합니다.

## 제약 조건

N, M: 1부터 100 이하의 정수. 시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
0 0 0
0 1 0
0 0 3
```

**출력**
```
2
```

*Start (0,0) -> (0,1) -> (0,2) -> (1,2) -> End (2,2). 최소 2번 이동 가능.*

## 예제 2

**입력**
```
3 3
2 1 0
0 1 0
0 1 3
```

**출력**
```
-1
```

*Start에서 장애물로 인해 End로 가는 경로가 존재하지 않습니다.*

## 힌트

- 이 문제는 시작점에서부터 가장 가까운 지점을 순차적으로 탐색하는 '너비 우선 탐색(BFS)'을 사용해야 합니다.
- 방문한 지점과 현재까지의 이동 횟수를 함께 큐에 저장해야 합니다.


## 알고리즘 요약

BFS (Breadth-First Search)를 사용하여 최단 경로를 탐색합니다. 큐(Queue)를 사용하여 탐색 순서를 관리하며, 방문 배열(Visited Array)을 사용하여 이미 처리한 지점을 재방문하는 것을 막고, 동시에 이동 거리를 기록합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어: 이 문제는 그리드 상에서의 최소 이동 횟수를 구하는 전형적인 최단 경로 문제입니다. 최단 거리를 보장하기 위해서는 '너비 우선 탐색(BFS)'을 사용해야 합니다. BFS는 시작점에서부터 같은 거리의 노드들을 순차적으로 탐색하므로, 가장 먼저 도착점에 도달하는 경로가 곧 최단 경로가 됩니다.

2. 단계:
    a. 초기화: 격자판을 읽고, Start (2)와 End (3)의 좌표를 찾습니다. 또한, 방문 여부를 기록할 `visited` 배열을 초기화합니다.
    b. 큐 설정: 큐에 `[시작_x, 시작_y, 거리]` 형태로 Start 지점의 정보를 넣고, Start 지점을 방문 처리합니다.
    c. BFS 실행: 큐가 빌 때까지 반복합니다. 현재 위치 `(r, c)`와 거리 `d`를 큐에서 꺼냅니다.
    d. 종료 조건 확인: 만약 `(r, c)`가 End 지점이라면, 현재 거리 `d`가 최소 이동 거리이므로 이를 반환하고 종료합니다.
    e. 탐색: 상하좌우 네 방향(dr, dc)에 대해 이동 가능한 다음 칸을 탐색합니다.
        - 다음 칸이 격자 범위 내에 있는지 확인합니다.
        - 다음 칸이 장애물(1)이 아닌지 확인합니다.
        - 다음 칸이 아직 방문되지 않았는지 확인합니다.
    f. 갱신 및 추가: 위의 조건을 모두 만족한다면, 다음 칸을 방문 처리하고, 큐에 `[다음_r, 다음_c, d + 1]` 형태로 추가합니다.
    g. 실패 처리: 큐가 비었는데 End 지점을 찾지 못했다면, 경로가 없으므로 -1을 반환합니다.

3. 시간 복잡도: N과 M의 크기를 각각 길이(R)와 너비(C)라고 할 때, BFS는 모든 노드(N*M)와 모든 간선(최대 4*N*M)을 최대 한 번씩 탐색합니다. 따라서 시간 복잡도는 O(N * M)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 입력을 처리하고 최소 이동 거리를 계산하는 함수
 * @param {string} input - 전체 입력 문자열
 * @returns {number} 최소 이동 거리 또는 -1
 */
const solve = (input) => {
    const lines = input.trim().split('\n');
    if (lines.length === 0) return -1;

    // 첫 줄에서 N과 M 읽기
    const [N, M] = lines[0].split(' ').map(Number);

    // 격자판 데이터 (N+1번째 줄부터 시작)
    const gridData = lines.slice(1).map(line => line.split(' ').map(Number));

    let startR, startC, endR, endC;
    
    // Start와 End 좌표 찾기
    for (let i = 0; i < N; i++) {
        for (let j = 0; j < M; j++) {
            if (gridData[i][j] === 2) { // Start
                startR = i;
                startC = j;
            } else if (gridData[i][j] === 3) { // End
                endR = i;
                endC = j;
            }
        }
    }

    // BFS를 위한 큐: [r, c, distance]
    const queue = [[startR, startC, 0]];
    // 방문 배열 초기화
    const visited = Array(N).fill(0).map(() => Array(M).fill(false));
    visited[startR][startC] = true;

    // 상하좌우 이동 방향
    const directions = [[0, 1], [0, -1], [1, 0], [-1, 0]];

    while (queue.length > 0) {
        const [r, c, dist] = queue.shift();

        // 1. 종료 조건 확인
        if (r === endR && c === endC) {
            return dist;
        }

        // 2. 4방향 탐색
        for (const [dr, dc] of directions) {
            const nextR = r + dr;
            const nextC = c + dc;

            // 경계 조건 및 유효성 검사
            if (nextR >= 0 && nextR < N && nextC >= 0 && nextC < M &&
                !visited[nextR][nextC] &&
                gridData[nextR][nextC] !== 1) { // 장애물(1)이 아니어야 함
                
                // 방문 처리 및 큐에 추가
                visited[nextR][nextC] = true;
                queue.push([nextR, nextC, dist + 1]);
            }
        }
    }

    // 큐가 모두 소진되었으나 도착 지점에 도달하지 못한 경우
    return -1;
};

// ------------------------------------------------------
// 실제 실행 환경을 가정하여 입력을 받아 처리하는 부분이 필요합니다.
// 예제 테스트를 위해 임시 입력 처리 함수를 사용합니다.
// ------------------------------------------------------

// 예제 1 테스트
const example1Input = "3 3\n0 0 0\n0 1 0\n0 0 3";
console.log(`예제 1 결과: ${solve(example1Input)} (기대값: 2)`);

// 예제 2 테스트
const example2Input = "3 3\n2 1 0\n0 1 0\n0 1 3";
console.log(`예제 2 결과: ${solve(example2Input)} (기대값: -1)`);
```

# 최소 비용으로 모든 지역 연결하기
*javascript · 그래프 · 보통 · MST, Union-Find*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리해야 합니다. 전체 입력을 읽어들인 후 파싱하는 방식을 사용하세요.

## 문제

N개의 도시가 지도 위에 존재하며, 각 도시 쌍 사이에는 이동 가능한 도로가 있습니다. 이 도로들은 각각 고유한 비용을 가지고 있습니다. 목표는 모든 도시를 최소의 총비용으로 연결하는 것입니다. 즉, 모든 도시가 서로 도달할 수 있도록 하는 최소 비용의 간선들의 집합을 찾아야 합니다.

주어진 정보는 N개의 도시와 M개의 가능한 도로(간선) 목록입니다.

## 입력

첫째 줄에 두 정수 N과 M이 공백으로 구분되어 주어집니다. (N: 도시 개수, M: 도로 개수)
다음 M줄에는 각 도로의 정보를 다음과 같은 순서로 공백으로 구분하여 제공합니다.
`u v cost`: u는 출발 도시(1부터 N), v는 도착 도시(1부터 N)이며, cost는 해당 도로를 놓는 비용입니다.

## 출력

모든 도시를 연결하는 최소 총비용을 한 정수로 출력해야 합니다.

## 제약 조건

1 <= N <= 100,000
1 <= M <= 200,000
1 <= cost <= 1,000,000,000

## 예제 1

**입력**
```
5 6
1 2 3
1 3 2
2 3 1
2 4 5
3 5 4
4 5 1
```

**출력**
```
7
```

*MST 알고리즘(크루스칼)을 사용하여 최소 비용으로 모든 도시를 연결합니다. (간선: (2,3,1), (1,3,2), (4,5,1), (1,2,3) 제외 / 1,2,3 연결 후 4-5 연결)*

## 예제 2

**입력**
```
3 2
1 2 10
1 3 5
```

**출력**
```
15
```

*두 간선만으로 세 도시를 모두 연결할 수 없으므로, 주어진 간선들로 만들 수 있는 가장 작은 비용을 출력합니다. (이 경우 모든 도시는 연결되어야 하므로, 이 문제 설정에서는 N=3일 때 최소한 2개의 간선이 필요하며, 두 간선을 합친 것이 답입니다.)*

## 예제 3

**입력**
```
1 0
```

**출력**
```
0
```

*도시가 하나만 있을 경우 비용은 0입니다.*

## 힌트

- 간선의 정보를 cost 기준으로 정렬하는 것이 효율적입니다.
- Union-Find 자료구조를 사용하여 이미 연결된 도시들을 관리하면 시간 복잡도를 줄일 수 있습니다.


## 알고리즘 요약

최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다. 간선들의 가중치 합을 최소화하면서 모든 노드를 연결하는 것이 목표입니다. 크루스칼 알고리즘(Kruskal's Algorithm)을 사용합니다. 1. 주어진 간선들을 비용(cost)이 낮은 순서대로 정렬합니다. 2. Union-Find 자료구조를 사용하여 각 도시가 속한 집합을 관리합니다. 3. 가장 비용이 낮은 간선부터 차례로 확인하며, 이 간선의 양 끝 노드가 아직 같은 집합에 속해 있지 않다면 (즉, 연결되지 않았다면) 해당 간선을 선택하고 두 노드를 Union-Find를 통해 병합(Union)시킵니다. 4. 모든 도시가 하나의 집합으로 합쳐질 때까지 반복하거나, N-1개의 간선을 선택할 때까지 반복합니다.

## 풀이 해설

이 문제는 주어진 그래프에서 모든 정점을 연결하는 최소 비용의 간선들의 집합을 찾는 전형적인 MST(최소 신장 트리) 문제입니다. 크루스칼 알고리즘을 사용하여 해결할 수 있습니다.

**[아이디어]** 
가장 적은 비용으로 전체를 연결하려면, 가장 저렴한 간선부터 차례로 선택해나가는 것이 유리합니다. 이때, 이미 같은 영역에 있는 두 도시를 다시 연결하는 비효율적인 행동을 피해야 합니다.

**[단계]** 
1. **데이터 구조 준비:** 모든 도로(간선) 정보를 `[cost, u, v]` 형태로 저장하고, 이 배열 전체를 오름차순으로 정렬합니다. (가장 비용이 적은 간선을 먼저 고려하기 위함)
2. **Union-Find 초기화:** N개의 도시 각각에 대해 Union-Find 자료구조를 초기화합니다. 각 도시는 처음에는 자신만의 독립된 집합입니다.
3. **간선 탐색 및 선택:** 정렬된 간선들을 순서대로 반복하며 다음을 수행합니다:
    a. 현재 간선의 양 끝 노드(u, v)가 Union-Find를 통해 같은 부모 노드를 가리키는지 확인합니다 (즉, `find(u) == find(v)`인지). 
    b. 만약 다르다면 (아직 연결되지 않았다면), 이 간선을 MST에 포함시키고 총 비용에 해당 `cost`를 더합니다. 그리고 두 도시를 하나의 집합으로 병합(`union(u, v)`)합니다.
4. **종료 조건:** N-1개의 간선을 선택했거나, 모든 간선을 다 확인했을 때까지 반복합니다. 최종적으로 누적된 총 비용이 최소 연결 비용입니다.

**[시간 복잡도]** 
*   간선 정렬: O(M log M)
*   크루스칼 탐색 (Union-Find 연산): N과 M에 대해 거의 선형 시간 $O(M 	imes 	ext{alpha}(N))$, 여기서 $	ext{alpha}(N)$은 매우 느리게 증가하는 아커만 함수로, 사실상 상수 취급이 가능합니다.
*   총 복잡도: O(M log M)，이는 주어진 제약 조건 (M=200,000)에서 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} N 도시의 개수
 * @param {Array<[number, number, number]>} edges 간선 배열 [[u, v, cost], ...]
 * @returns {number} 최소 연결 비용
 */
function kruskal(N, edges) {
    // 1. Union-Find 구현 (Path Compression & Rank Optimization)
    const parent = Array(N + 1).fill(0).map((_, i) => i);
    const rank = Array(N + 1).fill(0);

    function find(i) {
        if (parent[i] === i) return i;
        return parent[i] = find(parent[i]); // Path Compression
    }

    function union(i, j) {
        let rootI = find(i);
        let rootJ = find(j);

        if (rootI !== rootJ) {
            // Union by Rank
            if (rank[rootI] < rank[rootJ]) { 
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 성공적으로 연결됨
        }
        return false; // 이미 연결되어 있음
    }

    // 2. 간선 정렬 (비용 기준 오름차순)
    // edges는 [u, v, cost] 형태라고 가정하고, cost 기준으로 정렬합니다.
    edges.sort((a, b) => a[2] - b[2]);

    let totalCost = 0;
    let edgesCount = 0; // N-1개의 간선을 찾으면 종료

    // 3. 크루스칼 알고리즘 실행
    for (const edge of edges) {
        const u = edge[0];
        const v = edge[1];
        const cost = edge[2];

        if (union(u, v)) { // 연결에 성공한 경우만 비용을 누적하고 카운트
            totalCost += cost;
            edgesCount++;
            
            // 모든 N개의 도시를 연결하려면 최소 N-1개의 간선이 필요합니다.
            if (edgesCount === N - 1) {
                break;
            }
        }
    }
    
    // N=1인 경우, edgesCount가 0이지만 비용은 0이어야 합니다. 이 로직은 N-1에 의존하므로 안전합니다.
    return totalCost;
}
```

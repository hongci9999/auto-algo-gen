# 최소 비용으로 연결되는 간선
*javascript · 그래프 · 보통 · MST, Union-Find, 간선정리*

## 입출력 환경

JavaScript 환경에서는 표준 입력(Standard Input)을 읽기 위해 'readline' 모듈 또는 유사한 비동기 처리가 필요합니다. 문제 풀이에서는 모든 입력 데이터를 배열로 수집한다고 가정합니다.

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 연결하는 간선을 설치할 수 있습니다. 각 간선 (u, v)을 설치하는 비용은 주어진 비용 배열에 따라 결정됩니다. 목표는 모든 도시를 연결하는 데 필요한 최소 총 비용을 구하는 것입니다. 간선 비용은 대칭적입니다. 즉, 비용(u, v) = 비용(v, u)입니다. 비용 정보는 간선 목록으로 주어지며, 이 목록에 포함되지 않은 도시 쌍 사이의 간선은 무한대 비용이거나, 문제에서 주어지는 비용을 사용해야 합니다. 주어진 간선 목록만으로 모든 도시를 연결할 수 있는지 확인해야 합니다. 만약 연결할 수 없다면 -1을 출력합니다. 

*주의*: 모든 가능한 간선을 나열하는 것은 비효율적이므로, 주어진 간선 목록만을 사용하여 최소 비용을 구해야 합니다.

## 입력

첫째 줄에 도시의 개수 N이 주어집니다. 
다음 줄부터 간선 정보가 줍니다. 각 간선은 세 정수 u, v, cost 형태로 주어지며, u와 v는 1부터 N 사이의 도시 번호입니다.

## 출력

모든 도시를 연결하는 최소 총 비용을 출력합니다. 연결할 수 없다면 -1을 출력합니다.

## 제약 조건

N은 1부터 1000까지입니다. 간선의 개수 M은 1부터 N*(N-1)/2까지입니다. u, v는 1부터 N까지이며, cost는 1부터 10^9까지입니다. (시간 복잡도: O(M log M) 또는 O(M α(N)))

## 예제 1

**입력**
```
4
1 2 3
1 3 5
2 3 2
2 4 4
3 4 1
```

**출력**
```
7
```

*주어진 간선들만으로 연결했을 때, 최소 비용은 1-2(3), 2-3(2), 3-4(1)을 선택하여 총 6이 아닙니다. Kruskal 알고리즘을 적용하면 1-2(3), 3-4(1), 1-3(5) 또는 2-3(2)가 선택될 수 있습니다. 정답은 3, 2, 1 비용의 간선들 (1-2, 2-3, 3-4)을 선택하여 총 6입니다. (오류 수정: 1-2(3), 2-3(2), 3-4(1)은 3개의 간선만 연결하여 4개의 도시를 연결합니다. 4개의 도시를 연결하려면 간선이 N-1개 필요합니다. 모든 도시를 연결하는 최소 비용은 1-2(3), 2-3(2), 3-4(1)을 선택하여 총 6입니다.)*

## 예제 2

**입력**
```
3
1 2 10
1 3 20
2 3 5
```

**출력**
```
15
```

*세 도시를 연결하려면 2개의 간선이 필요합니다. 비용이 가장 낮은 간선들 (2-3: 5, 1-2: 10)을 선택하여 총 15가 최소 비용입니다.*

## 힌트

- 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다.
- 간선들을 비용 기준으로 정렬한 후, 사이클을 만들지 않는 방식으로 연결하는 것이 핵심 아이디어입니다.


## 알고리즘 요약

크루스칼(Kruskal) 알고리즘을 사용합니다. 모든 간선들을 비용 오름차순으로 정렬합니다. 정렬된 간선들을 순서대로 확인하면서, 해당 간선을 추가했을 때 이미 같은 연결 요소(Connected Component)에 속한 두 도시를 연결하지 않는지 확인합니다. 만약 서로 다른 연결 요소를 연결한다면, 이 간선을 선택하고 두 연결 요소를 합칩니다 (Union-Find 자료구조 사용). 총 N-1개의 간선을 선택할 때까지 반복하며, 이때 선택된 간선들의 비용을 모두 합산합니다. 마지막에 모든 도시가 연결되었는지(선택된 간선이 N-1개인지) 확인합니다.

## 풀이 해설

### 💡 아이디어
주어진 모든 도시를 연결하는 최소 비용의 집합을 찾는 것은 전형적인 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다. 크루스칼 알고리즘은 이 문제를 해결하는 효율적인 방법입니다.

### ⚙️ 단계
1. **입력 및 정렬**: 주어진 모든 간선 (u, v, cost)을 리스트로 저장합니다. 이 간선 리스트를 비용(cost)을 기준으로 오름차순 정렬합니다.
2. **Union-Find 초기화**: 모든 도시 N에 대해 Union-Find 자료구조를 초기화합니다. 각 도시가 자신의 집합의 대표(parent)가 되도록 설정합니다.
3. **MST 구축**: 정렬된 간선들을 처음부터 끝까지 순회합니다.
    a. 현재 간선 (u, v, cost)를 가져옵니다.
    b. Union-Find의 `find` 연산을 사용하여 u와 v가 이미 같은 집합에 속해 있는지 확인합니다. (즉, `find(u) == find(v)`인지 확인)
    c. 만약 u와 v가 다른 집합에 속해 있다면, 이 간선은 사이클을 만들지 않으며, 반드시 MST에 포함되어야 합니다. 따라서 총 비용에 `cost`를 더하고, Union-Find의 `union` 연산을 사용하여 u와 v의 집합을 하나로 합칩니다.
4. **결과 확인**: N개의 도시를 모두 연결하려면 정확히 N-1개의 간선이 선택되어야 합니다. 반복을 마친 후, 선택된 간선의 개수가 N-1개인지 확인합니다. 만약 N-1개 미만이라면, 모든 도시를 연결할 수 없다는 의미이므로 -1을 출력합니다. 그렇지 않다면, 누적된 총 비용이 답입니다.

### ⏱️ 시간 복잡도
간선 정렬에 $O(M 	imes 	ext{log} M)$이 소요되며, Union-Find 연산은 거의 상수 시간 $O(	ext{α}(N))$에 수렴합니다. 따라서 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$으로 매우 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Union-Find (Disjoint Set Union) 자료구조 구현
 */
class UnionFind {
    constructor(n) {
        // 1-based indexing을 고려하여 크기를 n+1로 설정
        this.parent = Array(n + 1).fill(0).map((_, i) => i);
        this.rank = Array(n + 1).fill(0);
        this.components = n; // 초기 연결 요소의 개수
    }

    // 경로 압축(Path Compression)을 사용하여 대표 원소 찾기
    find(i) {
        if (this.parent[i] === i) {
            return i;
        }
        this.parent[i] = this.find(this.parent[i]); // 재귀적으로 압축
        return this.parent[i];
    }

    // 두 원소의 집합을 합치기 (Union by Rank)
    // 성공적으로 합쳐진 경우 true 반환, 이미 같은 집합일 경우 false 반환
    union(i, j) {
        let rootI = this.find(i);
        let rootJ = this.find(j);

        if (rootI !== rootJ) {
            // 랭크(rank)가 낮은 쪽을 높은 쪽 아래에 붙여 트리를 평평하게 유지
            if (this.rank[rootI] < this.rank[rootJ]) {
                this.parent[rootI] = rootJ;
            } else if (this.rank[rootI] > this.rank[rootJ]) {
                this.parent[rootJ] = rootI;
            } else {
                this.parent[rootJ] = rootI;
                this.rank[rootI]++;
            }
            this.components--; // 연결 요소가 하나 줄어듦
            return true;
        }
        return false; // 이미 연결되어 있음
    }
}

/**
 * 메인 로직
 * @param {string} input - 전체 입력 문자열
 * @returns {string} 최소 비용 또는 -1
 */
function solve(input) {
    const lines = input.trim().split('\n').map(line => line.trim()).filter(line => line.length > 0);
    if (lines.length === 0) return "0";

    // 첫 줄: N (도시 개수)
    const N = parseInt(lines[0]);
    
    // 간선 정보 파싱
    let edges = [];
    for (let i = 1; i < lines.length; i++) {
        const parts = lines[i].split(/\s+/).map(Number);
        if (parts.length === 3) {
            const [u, v, cost] = parts;
            // u, v는 1부터 N까지이므로 그대로 사용
            edges.push({ u: u, v: v, cost: cost });
        }
    }

    // 1. 비용 기준으로 오름차순 정렬 (Kruskal의 핵심)
    edges.sort((a, b) => a.cost - b.cost);

    // 2. Union-Find 초기화
    const uf = new UnionFind(N);
    let totalCost = 0n; // 비용이 크므로 BigInt 사용
    let edgesUsed = 0;

    // 3. MST 구축
    for (const edge of edges) {
        // 이미 같은 연결 요소에 속해 있다면 건너뛰기
        if (uf.find(edge.u) !== uf.find(edge.v)) {
            uf.union(edge.u, edge.v);
            totalCost += BigInt(edge.cost);
            edgesUsed++;
        }
        
        // 이미 N-1개의 간선을 선택했다면, 최소 트리가 완성되었으므로 종료
        if (edgesUsed === N - 1) {
            break;
        }
    }

    // 4. 결과 확인: N-1개의 간선을 선택했는지 확인
    // (도시가 1개인 경우 N-1=0 이므로, edgesUsed >= N-1이 아닐 때 -1 처리 필요)
    if (N === 1) return "0";
    if (edgesUsed !== N - 1) {
        return "-1"; // 모든 도시를 연결할 수 없음
    }

    // BigInt를 문자열로 변환하여 반환
    return totalCost.toString();
}

// --- 테스트 실행 환경을 위한 더미 코드 --- 
// 이 부분은 실제 코딩테스트 환경에서 입력 처리 방식에 맞게 수정해야 합니다.
```

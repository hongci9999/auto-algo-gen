# 최소 비용으로 길 만들기
*javascript · 그래프 · 보통 · 최단 경로, 다익스트라, 우선순위 큐*

## 입출력 환경

JavaScript 환경에서 표준 입력을 처리할 때는 'readline' 모듈이나 파일 스트림 처리를 사용해야 합니다. 여기서는 입력 전체를 배열로 받는다고 가정합니다.

## 문제

당신은 맵 위에 있는 캐릭터입니다. 이 맵은 그리드 형태로 주어지며, 각 칸(셀)은 이동 비용을 나타냅니다. 당신은 시작점 (0, 0)에서 목표 지점 (N-1, M-1)까지 도달해야 합니다. 이동은 상하좌우 네 방향으로만 가능하며, 인접한 칸으로 이동할 때 발생하는 비용은 해당 칸의 값과 같습니다. 단, 이미 방문한 칸은 다시 지나갈 수 없습니다. 가장 적은 총 비용으로 목표 지점에 도달하는 경로를 찾아야 합니다.

(주의: 이 문제는 비용이 가중치로 작용하는 최소 비용 경로 찾기 문제로, 일반적인 BFS로는 풀기 어려우며, 다익스트라 알고리즘을 사용해야 합니다.)

## 입력

첫째 줄에 정수 N과 M이 주어집니다. (N: 행의 개수, M: 열의 개수)
다음 N줄에 걸쳐 M개의 정수로 이루어진 그리드 맵이 주어집니다. 각 정수는 해당 칸을 지나갈 때 발생하는 비용입니다.

## 출력

가장 적은 총 비용을 찾아 정수 형태로 출력합니다.

## 제약 조건

1 <= N, M <= 100
1 <= 비용 <= 100
시간 복잡도: O(N*M*log(N*M)) 이하

## 예제 1

**입력**
```
3 3
1 3 1
1 1 1
3 2 1
```

**출력**
```
6
```

*최적 경로는 (0,0) -> (1,0) -> (1,1) -> (1,2) -> (2,2) 입니다. 비용 합: 1 + 1 + 1 + 1 + 1 = 5. (오류 수정: (0,0) 시작 비용은 고려하지 않음. (0,0)을 지나기 시작하여, 다음 칸 이동 비용을 합산합니다. 따라서 (1,0) 이동 비용 1 + (1,1) 이동 비용 1 + (1,2) 이동 비용 1 + (2,2) 이동 비용 1 = 4. (0,0)에서 시작하므로, 시작점 비용은 0으로 간주하고, 다음 칸으로 이동할 때의 비용만 누적합니다. 예시 풀이: (0,0) -> (0,1) [비용 3] -> (1,1) [비용 1] -> (2,1) [비용 2] -> (2,2) [비용 1]. 총 비용: 3+1+2+1 = 7. 가장 낮은 경로는 (0,0) -> (1,0) -> (1,1) -> (1,2) -> (2,2). 총 비용: 1 + 1 + 1 + 1 = 4. (문제 정의에 따라, 시작점 비용은 0으로 간주하고, 이동할 때마다 해당 칸의 비용이 누적된다고 가정합니다.)*

## 예제 2

**입력**
```
2 2
1 1
1 1
```

**출력**
```
2
```

*최적 경로는 (0,0) -> (0,1) -> (1,1) 또는 (0,0) -> (1,0) -> (1,1) 입니다. 총 비용: 1 + 1 = 2.*

## 힌트

- 이 문제는 최단 경로 문제이지만, 간선 가중치가 일반적이지 않고, 이동할 때마다 비용이 누적됩니다.
- 방문하지 않은 칸으로의 이동 비용이 가중치 역할을 하므로, 다익스트라 알고리즘(Dijkstra's Algorithm)을 사용하여 최소 비용을 탐색해야 합니다.


## 알고리즘 요약

다익스트라 알고리즘을 사용하여 최소 비용 경로를 찾습니다. 시작점 (0, 0)에서 목표점 (N-1, M-1)까지의 최소 비용을 계산합니다. 우선순위 큐(Min-Heap)를 사용하여 현재까지의 최소 비용이 가장 적은 노드를 우선적으로 탐색합니다. 방문 기록(visited)을 통해 사이클을 방지하고, 거리를 저장하는 배열(dist)을 이용해 비용을 갱신합니다.

## 풀이 해설

### 💡 아이디어
이 문제는 그리드 위에서 출발점부터 도착점까지 이동할 때, 각 칸의 비용을 합산하여 최소 비용을 찾는 문제입니다. 비용이 양수이며, 사이클을 만들 수 없다는 제약 조건이 있지만, 가장 중요한 것은 '최소 비용'을 찾는 최단 경로 문제라는 점입니다. 따라서 가중치가 있는 그래프 탐색 알고리즘인 다익스트라 알고리즘을 사용하는 것이 가장 적합합니다.

### 🚀 단계
1. **초기화**: N x M 크기의 거리 배열 `dist`를 무한대 값으로 초기화하고, 시작점 `dist[0][0]`은 0으로 설정합니다. (시작점 자체는 이동 비용을 발생시키지 않는다고 가정합니다.)
2. **우선순위 큐 (Min-Heap)**: [비용, 행, 열] 형태로 우선순위 큐를 만듭니다. 시작점 (0, 0)을 [0, 0, 0]으로 삽입합니다. (비용이 가장 낮은 순서대로 정렬)
3. **탐색**: 우선순위 큐가 빌 때까지 다음 과정을 반복합니다.
    a. 큐에서 현재까지의 최소 비용 `d`, 위치 `(r, c)`를 추출합니다.
    b. 만약 `d`가 이미 기록된 `dist[r][c]`보다 크다면 (더 비효율적인 경로라면) 건너뜁니다.
    c. 상하좌우 네 방향의 인접 셀 `(nr, nc)`을 확인합니다.
    d. 인접 셀이 맵 범위 내에 있고, 현재까지의 총 비용 `d`에 인접 셀의 비용 `cost[nr][nc]`를 더한 값 `new_cost`가 `dist[nr][nc]`보다 작다면, `dist[nr][nc]`를 `new_cost`로 갱신하고, `[new_cost, nr, nc]`를 우선순위 큐에 삽입합니다.
4. **결과**: 탐색이 완료된 후, `dist[N-1][M-1]`에 저장된 값이 최소 총 비용이 됩니다.

### ⏱️ 시간 복잡도
다익스트라 알고리즘의 시간 복잡도는 O(E log V) 입니다. 여기서 V는 정점(N*M)의 개수, E는 간선(최대 4*N*M)의 개수입니다. 따라서 시간 복잡도는 O(N * M * log(N * M)) 이며, 주어진 제약 조건(N, M <= 100) 내에서 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * 최소 비용으로 길 만들기
 * @param {number[][]} cost - 비용이 기록된 N x M 그리드 맵
 * @param {number} N - 행의 개수
 * @param {number} M - 열의 개수
 * @returns {number} 최소 비용
 */
function solve(cost, N, M) {
    // JavaScript 표준 라이브러리만 사용하기 위해 MinPriorityQueue를 직접 구현하거나 배열을 활용합니다.
    // 여기서는 최소 비용을 기준으로 정렬되는 배열을 큐처럼 사용합니다.
    // [비용, 행, 열]
    let pq = [[0, 0, 0]]; // [비용, r, c]
    
    // 거리 배열 초기화: 모든 값을 무한대로 설정
    const INF = Number.MAX_SAFE_INTEGER;
    let dist = Array(N).fill(0).map(() => Array(M).fill(INF));
    dist[0][0] = 0;

    const directions = [[0, 1], [0, -1], [1, 0], [-1, 0]];

    while (pq.length > 0) {
        // 최소 비용을 가진 노드를 찾기 위해 배열을 정렬하고 팝합니다. (Min-Heap 대체)
        pq.sort((a, b) => a[0] - b[0]);
        let [d, r, c] = pq.shift();

        // 이미 더 낮은 비용으로 방문했거나, 현재 추출된 비용이 기록된 거리보다 크면 무시
        if (d > dist[r][c]) {
            continue;
        }

        // 목표 지점에 도착했으면 바로 반환 (다익스트라의 특성상 첫 도달이 최소 비용)
        if (r === N - 1 && c === M - 1) {
            return d;
        }

        // 상하좌우 네 방향 탐색
        for (const [dr, dc] of directions) {
            const nr = r + dr;
            const nc = c + dc;

            // 맵 범위 체크 및 방문 가능 여부 체크
            if (nr >= 0 && nr < N && nc >= 0 && nc < M) {
                // 새로운 비용 계산: 현재까지의 비용 + 다음 칸의 비용
                // 주의: 시작점 (0,0)의 비용은 0으로 간주하고, 다음 칸 이동 시 비용을 누적합니다.
                const new_cost = d + cost[nr][nc];
                
                // 비용 갱신 및 큐에 추가
                if (new_cost < dist[nr][nc]) {
                    dist[nr][nc] = new_cost;
                    pq.push([new_cost, nr, nc]);
                }
            }
        }
    }

    return dist[N - 1][M - 1]; // 도달 불가능할 경우의 값
}

// ******************************************************************
// 입출력 처리 예시 (실제 코딩테스트 환경에 맞춰 수정 필요)
// ******************************************************************
function solveProblem(input) {
    const lines = input.trim().split('\n').filter(line => line.length > 0);
    if (lines.length === 0) return 0;

    const [N, M] = lines[0].split(' ').map(Number);
    const cost = [];
    for (let i = 1; i <= N; i++) {
        cost.push(lines[i].split(' ').map(Number));
    }

    return solve(cost, N, M);
}

// 테스트 케이스 1
const input1 = "3 3\n1 3 1\n1 1 1\n3 2 1";
console.log(`Test 1 Output: ${solveProblem(input1)} (예상 출력: 4)`);

// 테스트 케이스 2
const input2 = "2 2\n1 1\n1 1";
console.log(`Test 2 Output: ${solveProblem(input2)} (예상 출력: 2)`);
```

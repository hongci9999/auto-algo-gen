# 최소 비용으로 모든 전구 켜기
*javascript · 그래프 · 보통 · DFS, BFS, MST*

## 입출력 환경

JavaScript 환경에서 입력은 일반적으로 표준입력(stdin)을 스트림으로 처리합니다. 모든 입력을 배열로 받아와서 처리해야 합니다.

## 문제

여러 개의 방이 연결된 복도와 그 안에 설치된 전구들이 있습니다. 각 전구는 특정 비용으로 켤 수 있으며, 이 전구를 켜기 위해서는 반드시 인접한 다른 켜진 전구가 있어야 합니다. 즉, 모든 전구를 최소한의 비용으로 켜서 모든 방을 밝게 만드는 것이 목표입니다. 주어진 연결 구조와 전구별 비용을 바탕으로, 모든 전구를 켜는 데 필요한 최소 총 비용을 구하시오.

(주의: 이 문제는 MST(Minimum Spanning Tree) 문제로 접근할 수 있습니다. 전구들을 노드로, 인접한 전구 간의 '연결 비용'을 간선 가중치로 생각합니다.)

## 입력

첫째 줄에 정수 N이 주어지며, 이는 전체 방과 연결된 전구의 개수입니다.
둘째 줄에는 각 전구(노드) i의 고유한 켜는 비용 C[i]가 쉼표로 구분되어 주어진 문자열 형태의 배열이 있습니다. (1 <= C[i] <= 10^9)
이어지는 N-1개의 줄은 연결 정보를 나타냅니다. 각 줄에는 'u v w' 형식으로 세 개의 정수가 주어지며, 이는 u와 v 두 전구 사이에 연결되어 있고, 이 연결을 통해 전구를 하나 더 켜는 데 필요한 비용이 w임을 의미합니다. (1 <= u, v <= N)

## 출력

모든 전구를 켜기 위해 필요한 최소 총 비용을 하나의 정수로 출력하시오.

## 제약 조건

N의 범위: 2 <= N <= 10^5
비용 C[i], w의 범위: 1 <= ... <= 10^9
시간 복잡도: O(E log E) 또는 O(E 	ext{ or } V)

## 예제 1

**입력**
```
4
10,20,30,40
1 2 5
2 3 8
2 4 12
```

**출력**
```
73
```

*전구 자체의 비용 합계 (10+20+30+40=100)에서, 연결 구조(MST)를 통해 중복되는 최소 비용을 빼야 합니다. MST는 5 + 8 + 12 = 25 입니다. 최종 비용은 100 - 25 = 75가 아니라, 문제의 해석에 따라 전구 자체 비용만 합산하는 것이 아닙니다. 여기서는 모든 노드를 연결하는 최소 스패닝 트리의 가중치와 각 노드의 초기 비용을 더해야 합니다. (실제 MST 기반 문제로 접근 시: C1+C2+...+CN + sum(MST edges) - max(connection cost)) -> 잘못된 해석으로 인한 예시입니다. 이 문제는 '전구 자체의 최소 연결 비용'만 구하는 문제입니다.*

## 예제 2

**입력**
```
3
5,8,10
1 2 3
2 3 4
```

**출력**
```
17
```

*노드 1과 2를 연결하는 비용(3)과 노드 2와 3을 연결하는 비용(4)을 합한 값이 최소 비용입니다. (최소 스패닝 트리의 가중치)*

## 힌트

- 이 문제는 모든 전구를 '켜는' 것이 아니라, 모든 전구가 '연결되어 밝게 되는' 최소 비용을 구하는 문제입니다.
- 전구 자체의 켜기 비용은 무시하고, 연결된 간선의 가중치(w)만을 사용합니다. 이는 MST (Minimum Spanning Tree) 문제로 귀결됩니다.


## 알고리즘 요약

주어진 전구와 연결 구조를 그래프로 모델링합니다. 전구들은 노드가 되고, 'u v w'는 u-v 간선에 가중치 w가 부여된 간선이 됩니다. 목표는 모든 전구를 최소 비용으로 연결하는 것이므로, 이 그래프의 MST(Minimum Spanning Tree) 트리를 찾아야 합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도
1. **아이디어**: 주어진 문제는 N개의 노드가 하나로 연결되는 최소 비용을 찾는 전형적인 '최소 스패닝 트리(MST)' 문제입니다. 간선의 가중치 W가 바로 해당 연결에 필요한 추가 비용입니다.
2. **단계 (Kruskal's Algorithm 사용)**:
   a. 모든 연결 정보(u, v, w)를 에지 리스트로 저장합니다.
   b. 이 에지 리스트를 가중치 w 기준으로 오름차순 정렬합니다.
   c. Union-Find 자료구조를 사용하여 최소 비용의 간선을 차례로 선택하며 사이클 발생 여부를 확인합니다.
   d. 가장 작은 가중치의 간선부터 순서대로 추가하되, 이미 같은 노드 그룹에 속한 두 노드를 다시 연결하는 경우(사이클 형성)는 건너<0xEB><0x9C><0x81>니다.
   e. N-1개의 간선을 선택할 때까지 반복하며, 이때 사용된 간선의 가중치를 모두 합산하면 최소 총 비용이 됩니다.
3. **시간 복잡도**: 에지 정렬에 $O(E 	imes 	ext{log} E)$ 시간이 소요되며, Union-Find 연산은 거의 상수 시간($	ext{nearly } O(1)$)에 가까우므로, 전체 시간 복잡도는 $O(E 	ext{ log } E)$입니다. (여기서 $E$는 간선의 수).

## 참고 코드 (javascript)

```javascript
/**
 * Union-Find 구조체 구현
 */
class UnionFind {
    constructor(n) {
        this.parent = Array(n + 1).fill(0).map((_, i) => i);
        this.rank = Array(n + 1).fill(0); 
    }

    // 경로 압축을 사용하여 부모를 찾아 최적화
    find(i) {
        if (this.parent[i] === i) {
            return i;
        }
        this.parent[i] = this.find(this.parent[i]); // Path Compression
        return this.parent[i];
    }

    // 두 원소를 합치고, 랭크를 사용하여 트리를 균형 있게 유지
    union(i, j) {
        let rootI = this.find(i);
        let rootJ = this.find(j);

        if (rootI !== rootJ) {
            // Union by Rank
            if (this.rank[rootI] < this.rank[rootJ]) {
                this.parent[rootI] = rootJ;
            } else if (this.rank[rootI] > this.rank[rootJ]) {
                this.parent[rootJ] = rootI;
            } else {
                this.parent[rootJ] = rootI;
                this.rank[rootI]++;
            }
            return true; // 성공적으로 합쳐짐
        }
        return false; // 이미 같은 그룹임 (사이클)
    }
}

function solve(input) {
    // 입력 파싱을 위해 줄바꿈 문자를 '\n'으로 가정하고 처리합니다.
    const lines = input.trim().split('\n');
    if (lines.length < 2) return 0;

    // N은 노드의 개수입니다. 첫 번째 줄에서 가져옵니다.
    const N = parseInt(lines[0].trim()); 

    // 간선 정보는 lines[2]부터 시작한다고 가정하고 파싱합니다.
    let edges = [];
    for (let i = 1; i < lines.length - 1; i++) {
        const lineParts = lines[i].trim().split(' ');
        if (lineParts.length < 3) continue;
        // u, v는 노드 번호 (1-indexed), w는 비용입니다.
        const u = parseInt(lineParts[0]);
        const v = parseInt(lineParts[1]);
        const w = parseInt(lineParts[2]);
        edges.push({ u, v, w });
    }

    // 1. 에지 리스트를 가중치(w) 기준으로 오름차순 정렬 (Kruskal's)
    edges.sort((a, b) => a.w - b.w);

    // 2. Union-Find 초기화
    const uf = new UnionFind(N); 
    let totalCost = 0;
    let edgesCount = 0;

    // 3. 간선 선택 및 MST 구축
    for (const edge of edges) {
        if (uf.union(edge.u, edge.v)) { // 사이클이 발생하지 않으면 연결 시도
            totalCost += edge.w;
            edgesCount++;
            // N-1개의 간선만 선택되면 트리가 완성된 것이므로 종료
            if (edgesCount === N - 1) {
                break;
            }
        }
    }

    return totalCost; 
}
```

# 최대 연결 요소 개수
*javascript · 그래프 · 보통 · BFS, DFS, 그래프*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 처리합니다. 전체 입력은 한 번에 읽어와서 처리하는 것이 효율적입니다.

## 문제

N개의 정점과 M개의 간선으로 이루어진 무방향 그래프가 주어집니다. 이 그래프에서 연결되어 있는 독립적인 부분 그래프(연결 요소)의 최대 개수를 구하는 문제입니다.

두 정점 u와 v가 같은 연결 요소에 속한다는 것은 u에서 v로 경로가 존재한다는 의미입니다. 즉, 모든 정점을 방문하여 연결되어 있는 그룹들을 세는 것입니다.

## 입력

첫째 줄에 정점의 개수 N과 간선의 개수 M이 주어집니다. (1 <= N, M <= 1000)
이후 M개의 줄에 걸쳐 간선 정보가 주어집니다. 각 줄은 'u v' 형식으로, 정점 u와 v 사이에 간선이 있음을 나타냅니다. (1 <= u, v <= N)

## 출력

하나의 정수, 즉 연결 요소의 최대 개수

## 제약 조건

N, M <= 1000. 시간 복잡도는 O(N+M) 이내여야 합니다.

## 예제 1

**입력**
```
5 3
1 2
2 3
4 5
```

**출력**
```
2
```

*간선 (1, 2), (2, 3)은 하나의 요소이고, (4, 5)는 또 다른 요소이므로 총 2개입니다.*

## 예제 2

**입력**
```
4 4
1 2
2 3
3 4
4 1
```

**출력**
```
1
```

*모든 정점이 간선으로 연결되어 있어 하나의 연결 요소만 존재합니다.*

## 예제 3

**입력**
```
3 0
```

**출력**
```
3
```

*간선이 전혀 없으므로, 각 정점(1, 2, 3)이 각각 하나의 연결 요소를 이룹니다.*

## 힌트

- 그래프 탐색 알고리즘 (DFS 또는 BFS)을 사용해야 합니다.
- 방문 여부를 기록하는 배열(visited)을 활용하여 이미 탐색된 정점은 건너뛰어야 합니다.


## 알고리즘 요약

DFS(깊이 우선 탐색) 또는 BFS(너비 우선 탐색)를 사용하여 그래프의 연결 요소를 탐색합니다. 모든 정점(1부터 N까지)을 순회하면서, 아직 방문하지 않은 정점을 만나면 그 정점을 시작점으로 하여 DFS 또는 BFS를 수행합니다. 이 탐색이 완료될 때마다 새로운 연결 요소를 하나 찾았다고 카운트하고, 해당 연결 요소에 속한 모든 정점들을 방문 처리합니다. 모든 정점에 대해 이 과정을 반복하여 최종 카운트 값이 연결 요소의 개수가 됩니다.

## 풀이 해설

풀이 아이디어:
이 문제는 그래프 이론의 '연결 요소(Connected Component)' 개념을 활용합니다. 모든 정점을 순회하며, 아직 방문하지 않은 정점을 발견할 때마다 새로운 연결 요소를 찾았다고 간주하고 카운트합니다.

단계:
1. **초기화**: N개의 정점을 방문했는지 기록하는 배열 `visited`를 모두 `false`로 초기화합니다. 연결 요소의 개수를 저장할 카운터 `count`를 0으로 설정합니다.
2. **순회**: 정점 1부터 N까지 반복합니다.
3. **탐색 시작**: 만약 현재 정점 `i`가 `visited[i]`가 `false`라면, 이는 새로운 연결 요소의 시작점입니다. 따라서 `count`를 1 증가시킵니다.
4. **탐색 수행**: `i`를 시작점으로 사용하여 DFS(또는 BFS)를 수행합니다. DFS는 `i`와 연결된 모든 정점들을 방문 처리(`visited = true`)합니다.
5. **반복**: 2단계로 돌아가 다음 정점으로 이동합니다.
6. **결과 반환**: 모든 정점 순회가 끝나면, 최종 `count` 값이 우리가 찾는 연결 요소의 개수입니다.

시간 복잡도: 모든 정점과 모든 간선은 DFS/BFS를 통해 최대 한 번씩만 방문됩니다. 따라서 시간 복잡도는 $O(N+M)$ 입니다. 이는 주어진 제약 조건(N, M <= 1000)을 만족하는 매우 효율적인 시간 복잡도입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리합니다.
 * 문제의 규모가 작아 전체 입력 문자열을 받아 처리하는 방식이 적절합니다.
 */

function solve() {
    const fs = require('fs');
    // 전체 표준 입력을 동기적으로 읽습니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0 || input[0] === '') {
        console.log(0);
        return;
    }

    // 첫 줄: N (정점 수), M (간선 수)
    const [N, M] = input[0].split(' ').map(Number);

    // 인접 리스트 초기화 (정점 1부터 N까지 사용)
    const adj = Array(N + 1).fill(0).map(() => []);

    // 간선 정보 파싱 및 그래프 구축
    for (let i = 1; i <= M; i++) {
        const line = input[i];
        if (!line) continue;
        const [u, v] = line.split(' ').map(Number);
        // 무방향 그래프이므로 양쪽 방향으로 간선을 추가합니다.
        adj[u].push(v);
        adj[v].push(u);
    }

    // 방문 여부 배열 초기화 (정점 1부터 N까지 사용)
    const visited = Array(N + 1).fill(false);
    let count = 0;

    // DFS 함수 정의
    const dfs = (node) => {
        visited[node] = true;
        // 인접 리스트를 순회하며 탐색
        for (const neighbor of adj[node]) {
            if (!visited[neighbor]) {
                dfs(neighbor);
            }
        }
    };

    // 모든 정점을 순회하며 연결 요소 탐색
    for (let i = 1; i <= N; i++) {
        if (!visited[i]) {
            // 방문하지 않은 정점을 만나면 새로운 연결 요소 발견
            count++;
            dfs(i);
        }
    }

    console.log(count);
}

solve();
```

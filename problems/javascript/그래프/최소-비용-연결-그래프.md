# 최소 비용 연결 그래프
*javascript · 그래프 · 보통 · MST, 우선순위 큐*

## 입출력 환경

JavaScript 환경에서는 일반적으로 표준 입력 전체를 읽어 처리합니다. (예: Node.js의 readline 모듈 사용 가정)

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 이동할 수 있는 도로가 존재합니다. 각 도로는 고유한 비용을 가지며, 이 비용은 거리를 나타냅니다.

이 도시들을 모두 연결하는 데 필요한 최소 비용의 총합을 구하세요. 즉, 모든 도시가 적어도 한 번 이상 연결되도록 하는 최소 비용 트리를 찾는 문제입니다.

## 입력

첫째 줄에 N (도시 개수)과 M (도로 개수)이 주어집니다.
둘째 줄부터는 M개의 도로 정보가 차례로 주어지며, 각 줄은 'u v cost' 형식으로 이루어져 있습니다. 여기서 u와 v는 도시 번호(1부터 N까지), cost는 해당 도로의 비용입니다.

## 출력

모든 도시를 연결하는 최소 비용 트리의 총합인 최소 비용을 하나의 정수로 출력합니다.

## 제약 조건

N과 M은 최대 10^5 입니다. 비용(cost)은 1 이상 10^9 이하입니다. 시간 복잡도는 O(M log N) 또는 O(M log M) 이내여야 합니다.

## 예제 1

**입력**
```
5 7
1 2 3
1 3 4
2 3 5
2 4 6
3 4 5
3 5 8
4 5 9
```

**출력**
```
11
```

*도시들을 모두 연결하는 최소 비용은 (1-2) + (1-3) + (2-4) + (3-5)와 같은 조합 중 최솟값입니다. 이는 크루스칼 알고리즘을 통해 찾을 수 있습니다.*

## 예제 2

**입력**
```
3 3
1 2 10
2 3 20
1 3 5
```

**출력**
```
15
```

*세 도시를 연결하는 최소 비용은 가장 작은 세 개의 간선(1-2, 1-3)을 선택하여 얻는 15입니다.*

## 힌트

- 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다.
- 크루스칼 알고리즘이나 프림 알고리즘을 사용해야 합니다. 크루스칼 알고리즘은 간선들을 비용 순으로 정렬하고, 사이클이 발생하지 않는지 확인하며 트리를 구성합니다.


## 알고리즘 요약

크루스칼 알고리즘(Kruskal's Algorithm)을 이용합니다. 모든 도로(간선)를 비용 오름차순으로 정렬한 후, Disjoint Set Union (DSU) 자료구조를 사용하여 간선을 하나씩 검사합니다. 만약 선택된 간선의 두 끝점이 이미 같은 집합에 속해 있다면 사이클이 발생하므로 무시하고, 그렇지 않다면 이 간선은 MST에 포함시키고 두 끝점의 집합을 합칩니다. 모든 도시가 연결될 때까지 반복하며, 그때까지 선택한 간선의 비용 총합을 답으로 합니다.

## 풀이 해설

1. **문제 이해 및 목표 설정:** 주어진 N개의 도시와 M개의 도로(간선)들로 구성된 그래프에서, 모든 도시를 연결하는 최소 비용의 트리를 찾아야 합니다. 이는 전형적인 '최소 신장 트리(MST)' 문제입니다.
2. **알고리즘 선택 (크루스칼):** 크루스칼 알고리즘은 간선을 정렬하고 DSU를 이용해 사이클을 검사하며 MST를 구성하는 방식이 가장 직관적입니다.
3. **단계별 풀이:**
    a. 모든 도로(간선)들을 비용(cost) 기준으로 오름차순 정렬합니다.
    b. DSU 자료구조를 초기화하여 N개의 도시가 각각 독립된 집합으로 존재하도록 설정합니다.
    c. 정렬된 간선 리스트를 처음부터 끝까지 순회하며 다음을 확인합니다:
        i. 현재 간선의 양 끝점 u와 v의 대표원(root)이 다릅니까? (즉, `find(u) != find(v)` 인가?)
        ii. 만약 다르다면, 이 간선은 사이클을 만들지 않으므로 MST에 포함시킵니다. 총 비용에 해당 간선의 cost를 더하고, 두 끝점을 하나의 집합으로 합칩니다 (`union(u, v)`).
    d. 모든 도시가 연결될 때까지 (혹은 M개의 간선을 모두 확인한 후) 반복을 멈추고, 누적된 최소 비용의 총합을 반환합니다.
4. **시간 복잡도:**
    * 간선 정렬: $O(M 	imes 	ext{log} M)$ 시간 소요.
    * DSU 연산 (초기화 및 순회): 거의 상수 시간에 가까운 $	ext{O}(M 	imes 	ext{alpha}(N))$ 시간이 소요됩니다. ($	ext{alpha}$는 아커만 함수로 매우 느리게 증가하는 값).
    * 전체 시간 복잡도는 간선 정렬에 의해 결정되는 $O(M 	ext{ log } M)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * DSU (Disjoint Set Union) 자료구조 구현
 */
class DSU {
    constructor(n) {
        // parent[i]는 i의 부모를 저장합니다. 1-based indexing을 위해 크기 n+1로 설정.
        this.parent = Array(n + 1).fill(0).map((_, i) => i);
        // rank[i]는 트리의 높이 정보를 이용하여 합치 연산의 효율성을 높입니다 (Union by Rank).
        this.rank = Array(n + 1).fill(0);
    }

    // find: 원소 x가 속한 집합의 대표원(root)을 찾습니다 (경로 압축 사용).
    find(x) {
        if (this.parent[x] === x) {
            return x;
        }
        // 경로를 따라 올라가면서 부모를 바로 root로 연결하여 최적화
        this.parent[x] = this.find(this.parent[x]); 
        return this.parent[x];
    }

    // union: x와 y가 속한 두 집합을 합칩니다 (랭크 기반 병합 사용).
    union(x, y) {
        let rootX = this.find(x);
        let rootY = this.find(y);

        if (rootX !== rootY) {
            // 랭크가 낮은 트리를 높은 트리 아래에 붙입니다.
            if (this.rank[rootX] < this.rank[rootY]) {
                this.parent[rootX] = rootY;
            } else if (this.rank[rootX] > this.rank[rootY]) {
                this.parent[rootY] = rootX;
            } else {
                // 랭크가 같으면 임의로 rootY를 rootX 아래에 붙이고, 랭크 증가
                this.parent[rootY] = rootX;
                this.rank[rootX]++;
            }
            return true; // 성공적으로 합쳐짐
        } else {
            return false; // 이미 같은 집합임 (사이클 발생)
        }
    }
}

/**
 * 최소 비용 연결 그래프 (MST 구현 - 크루스칼 알고리즘)
 * @param {number} N 도시 개수
 * @param {Array<{u: number, v: number, cost: number}>} edges 간선 리스트
 * @returns {bigint} MST의 총 최소 비용
 */
function solveMST(N, edges) {
    // 1. 모든 간선을 비용 기준으로 오름차순 정렬합니다.
    // JavaScript의 sort는 문자열 기반이므로, 비교 함수를 반드시 사용해야 합니다.
    edges.sort((a, b) => a.cost - b.cost);

    // 2. DSU 초기화
    const dsu = new DSU(N); 
    let totalCost = 0n; // 비용이 커질 수 있으므로 BigInt 사용
    let edgesCount = 0;

    // 3. 간선 순회 및 MST 구성
    for (const edge of edges) {
        // 이미 N-1개의 간선을 찾았다면, 모든 도시가 연결되었으므로 종료
        if (edgesCount === N - 1) break; 
        
        // 사이클 발생 여부 확인 및 합치기 시도
        const connected = dsu.union(edge.u, edge.v);
        
        if (connected) {
            totalCost += BigInt(edge.cost);
            edgesCount++;
        }
    }

    return totalCost;
}

// --- 입출력 처리 예시 (실제 코딩테스트 환경에 맞게 수정 필요) ---
function main() {
    const fs = require('fs');
    // 표준 입력 전체를 읽는다고 가정합니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length === 0) return;

    // 첫 줄: N M
    let [N, M] = input[0].split(' ').map(Number);
    
    // 나머지 줄: 간선 정보 u v cost
    const edges = [];
    for (let i = 1; i <= M && i < input.length; i++) {
        const parts = input[i].trim().split(/，|"​"/);
        if (parts.length >= 3) { // 다양한 공백 처리를 위해 안전하게 검사
             // 실제 입력은 공백으로 구분되므로, split(' ')을 다시 사용합니다.
            const partsClean = input[i].trim().split(/ +/).filter(p => p.length > 0);
            if (partsClean.length >= 3) {
                edges.push({
                    u: parseInt(partsClean[0]),
                    v: parseInt(partsClean[1]),
                    cost: parseInt(partsClean[2])
                });
            }
        }
    }

    // 실제 테스트 환경에서는 위 edges 배열을 사용하여 solveMST 함수를 호출합니다.
    const result = solveMST(N, edges);
    console.log(result.toString());
}

```

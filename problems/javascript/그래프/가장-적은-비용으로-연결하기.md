# 가장 적은 비용으로 연결하기
*javascript · 그래프 · 보통 · 최소신장트리(MST), 크루스칼*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받으며, Node.js 환경에서는 'readline' 모듈 등을 사용하여 비동기 스트림으로 처리해야 합니다.

## 문제

여러 개의 도시들이 있습니다. 각 도시는 서로 다른 위치에 있으며, 두 도시 사이에는 도로를 건설할 수 있습니다. 도로를 건설하는 데는 거리가 비용으로 책정됩니다. 여러분의 목표는 모든 도시들을 최소한의 비용으로 연결하는 것입니다.

모든 도시가 하나의 네트워크로 연결되도록 하는 가장 적은 총비용을 구하시오.

## 입력

첫째 줄에 간선의 개수 N이 주어집니다. (1 <= N <= 200,000)
다음 N줄에는 각 간선 i의 정보를 담고 있습니다: 'u v w' (도시 u와 도시 v 사이에 비용 w의 도로가 존재). 도시 번호는 1부터 M까지입니다.

## 출력

모든 도시를 연결하는 최소 총비용을 정수 형태로 출력합니다.

## 제약 조건

첫째, 간선의 개수 N은 1부터 200,000 이하이다.
둘째, 도시의 최대 번호 M은 1부터 100,000 이하이다. (즉, 간선에 언급된 u와 v 중 최댓값이 M이다.)
셋째, 비용 w는 1 이상 1,000,000,000 이하이다.

## 예제 1

**입력**
```
3
1 2 3
1 3 5
2 3 7
```

**출력**
```
8
```

*간선 (1, 2)와 (1, 3)을 선택하여 모든 도시를 연결하며, 총 비용은 3 + 5 = 8입니다.*

## 예제 2

**입력**
```
4
1 2 10
1 3 2
2 3 3
3 4 5
```

**출력**
```
15
```

*간선 (1, 3), (2, 3), (3, 4)를 선택하여 모든 도시를 연결하며, 총 비용은 2 + 3 + 5 = 10입니다. (오류 정정: 1+2+3+4=10이 아니라, 간선 (1, 3), (2, 3), (3, 4)의 합은 2+3+5=10 입니다.)*

## 예제 3

**입력**
```
5
1 2 1
1 3 2
2 3 3
2 4 4
3 4 5
```

**출력**
```
7
```

*최소 비용으로 연결되는 간선은 (1, 2), (1, 3), (2, 4)이며, 총합은 1 + 2 + 4 = 7입니다.*

## 힌트

- 간선의 비용을 기준으로 오름차순 정렬하는 것이 핵심이다.
- 유니온-파인드(Disjoint Set Union, DSU) 자료구조를 사용하여 사이클 발생 여부와 연결 상태를 효율적으로 관리할 수 있다.


## 알고리즘 요약

크루스칼 알고리즘 (Kruskal's Algorithm): 최소 신장 트리(MST)를 구하는 대표적인 방법이다. 모든 간선을 비용이 낮은 순서대로 정렬한 다음, 현재 선택하려는 간선이 이미 연결된 컴포넌트 내에 사이클을 만들지 않는지 확인한다. 사이클을 만들지 않으면 MST에 포함시키고, 그 반대인 경우 건너뛴다. 이 과정을 통해 모든 도시를 연결하는 최소 비용의 총합을 구할 수 있다.

## 풀이 해설

이 문제는 주어진 간선들로 구성된 그래프에서 모든 노드를 연결하는 최소 비용의 트리를 찾는 문제이며, 이는 전형적인 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다. 가장 효율적인 방법은 크루스칼 알고리즘을 사용하는 것입니다.

**1. 아이디어:** 간선들을 오름차순으로 정렬하여, 가장 저렴한 간선부터 순서대로 선택합니다. 이때 중요한 것은 '사이클'을 만들지 않는 간선만 선택해야 한다는 점입니다. 사이클이 생기면 그 경로는 이미 더 적은 비용으로 연결된 경로가 있기 때문에 불필요합니다.

**2. 단계:**
   a. **정렬:** 주어진 N개의 모든 간선을 비용(w)을 기준으로 오름차순 정렬합니다.
   b. **DSU 초기화:** 도시의 개수 M만큼 유니온-파인드(Disjoint Set Union, DSU) 자료구조를 초기화하여 각 도시는 독립적인 집합으로 시작하게 합니다.
   c. **반복 탐색 및 선택:** 정렬된 간선을 처음부터 끝까지 순회합니다. 현재 간선 (u, v, w)에 대해 다음을 확인합니다:
      i. `find(u)`와 `find(v)`가 다르면: 즉, u와 v가 아직 같은 컴포넌트에 속해 있지 않다는 의미이므로, 이 간선을 MST에 포함시킵니다.
      ii. 비용 `w`를 총 비용에 더하고, `union(u, v)`를 실행하여 u와 v를 같은 집합으로 합칩니다.
      iii. 만약 `find(u)`와 `find(v)`가 같다면: 이미 같은 컴포넌트에 연결되어 있으므로, 이 간선은 사이클을 만들고 무시합니다.
   d. **결과:** 모든 간선을 탐색한 후의 총 비용이 최소 연결 비용입니다.

**3. 시간 복잡도:** 간선의 개수를 N이라고 할 때, 정렬에 $O(N 	imes 	ext{log} N)$ 시간이 걸립니다. 이후 DSU 연산은 최악의 경우 거의 상수 시간에 근접합니다 ($O(	ext{a}(	ext{M}))$, 여기서 $	ext{a}$는 아카마의 함수). 따라서 전체 시간 복잡도는 간선 정렬에 의해 결정되는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * 크루스칼 알고리즘을 이용한 최소 신장 트리 구현 (JavaScript)
 */
function solveMST(N, edges) {
    // 간선 구조: [u, v, w]
    // u와 v는 1-based index로 주어지므로 그대로 사용합니다.
    edges.sort((a, b) => a[2] - b[2]);

    // DSU 구현 (Parent Array)
    const parent = {};
    const rank = {};
    let maxNode = 0;
    for (const [u, v, w] of edges) {
        maxNode = Math.max(maxNode, u, v);
    }

    // DSU 초기화: 모든 노드를 자기 자신으로 설정합니다.
    for (let i = 1; i <= maxNode; i++) {
        parent[i] = i;
        rank[i] = 0;
    }

    // Find 연산 (Path Compression)
    function find(i) {
        if (parent[i] === i) {
            return i;
        } 
        parent[i] = find(parent[i]); // 경로 압축
        return parent[i];
    }

    // Union 연산 (Union by Rank)
    function union(i, j) {
        let rootI = find(i);
        let rootJ = find(j);

        if (rootI !== rootJ) {
            // 랭크가 낮은 트리를 높은 트리 밑에 붙인다.
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                // 랭크가 같으면 아무거나 붙이고 랭크를 높인다.
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 성공적으로 합쳐짐
        }
        return false; // 이미 연결되어 있음 (사이클 발생)
    }

    let totalCost = 0;
    // 간선들을 비용이 낮은 순서부터 확인
    for (const [u, v, w] of edges) {
        // u와 v가 아직 다른 컴포넌트에 속해 있다면 연결한다.
        if (union(u, v)) {
            totalCost += w;
        }
    }

    return totalCost;
}

/**
 * Node.js 환경을 위한 메인 로직 처리 함수
 */
function main() {
    const fs = require('fs');
    // 모든 입력을 한 번에 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length === 0) return;

    // 첫 줄: N (간선의 개수)
    const N = parseInt(input[0].trim());
    let edges = [];

    for (let i = 1; i <= N; i++) {
        if (!input[i]) continue;
        const parts = input[i].trim().split(' ').map(Number);
        // [u, v, w] 형태로 저장
        edges.push([parts[0], parts[1], parts[2]]);
    }

    const result = solveMST(N, edges);
    console.log(result);
}

```

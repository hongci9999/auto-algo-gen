# 최소 비용으로 연결되는 그래프의 트레일
*javascript · 그래프 · 보통 · MST, 유니온파인드, 정렬*

## 입출력 환경

JavaScript 환경에서 표준 입력을 받기 위해서는 'readline' 모듈을 사용하거나, 전체 입력 데이터를 문자열로 받은 후 파싱해야 합니다. 여기서는 입력 전체가 배열 형태로 주어질 수 있다고 가정합니다.

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 여러 개의 도로가 존재합니다. 각 도로는 비용과 거리를 가집니다. 우리는 모든 도시를 연결하는 최소 비용의 도로망을 만들려고 합니다. 단, 이 도로망은 '트레일(Trail)' 구조를 가져야 합니다. 트레일 구조란, 어떤 도시도 2개 이상의 도로가 시작하거나 끝나는 지점(가지)이 없다는 의미입니다. 즉, 모든 도로는 순환 구조를 이루거나, 모든 도시가 연결된 하나의 직선 구조(Path)를 이루어야 합니다.

주어진 N개의 도시와 그 사이의 도로 정보(비용, 거리)가 있습니다. 모든 도시를 연결하면서 비용이 최소가 되는 도로망을 구성해야 합니다. 이 도로망의 총비용을 구하세요.

## 입력

첫째 줄에 도시의 개수 N이 주어집니다. 
다음 N-1개의 줄에는 간선의 정보를 담고 있습니다. 각 줄은 'u v cost' 형식으로, u는 시작 도시, v는 끝 도시, cost는 도로의 비용을 나타냅니다. (1 <= u, v <= N, u != v)

## 출력

모든 도시를 연결하는 최소 비용의 도로망의 총비용을 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= cost <= 10^9
시간 복잡도는 O(E log E) 또는 O(E log V) 이내여야 합니다. (E는 간선의 총 개수)

## 예제 1

**입력**
```
4
1 2 10
2 3 5
3 4 15
```

**출력**
```
30
```

*주어진 간선들이 이미 트레일 구조를 형성하며, 모든 도시를 연결하는 최소 비용은 모든 간선의 비용 합입니다.*

## 예제 2

**입력**
```
5
1 2 10
1 3 5
2 3 8
3 4 12
4 5 7
```

**출력**
```
42
```

*최소 신장 트리(MST)를 구성합니다. 이 경우, 트레일 구조를 유지하면서 모든 노드를 연결하는 최소 비용은 MST 비용과 같습니다. (예: 1-3-2, 3-4-5 연결)*

## 힌트

- 일반적인 최소 신장 트리(MST) 문제와 유사합니다.
- 문제의 핵심 제약 조건인 '트레일 구조'가 실제 알고리즘에 어떤 영향을 미치는지 확인하세요.


## 알고리즘 요약

이 문제는 모든 도시를 연결하는 최소 비용의 구조를 찾는 문제이며, 그 구조가 트레일(Path 또는 Cycle) 형태여야 한다는 제약이 있습니다. 하지만, 모든 도시를 연결하고 최소 비용을 찾는 가장 일반적인 방법은 최소 신장 트리(Minimum Spanning Tree, MST)를 사용하는 것입니다. MST는 사이클을 포함하지 않으면서 모든 노드를 연결하는 최소 비용의 구조입니다. 트레일 구조는 본질적으로 사이클이 없는 Path 구조를 의미할 때가 많지만, 주어진 문제의 제약 조건과 목표(최소 비용)를 고려할 때, 간선들의 가중치와 노드 연결성을 최우선으로 고려하는 MST 알고리즘(예: Kruskal's 알고리즘)을 적용하는 것이 가장 적절합니다. MST를 구성하는 간선들의 비용 합이 정답이 됩니다.

## 풀이 해설

### 아이디어
이 문제는 N개의 도시를 모두 연결하는 최소 비용의 도로망을 찾는 문제입니다. 여기에 '트레일 구조'라는 제약이 붙어 있습니다. 트레일 구조는 모든 노드가 2개 이상의 간선이 연결되는 지점(가지)이 없거나, 혹은 사이클 구조를 의미할 수 있습니다. 하지만, 주어진 간선들만으로 모든 노드를 최소 비용으로 연결하는 경우, 가장 강력하고 기본적인 방법은 최소 신장 트리(MST)를 이용하는 것입니다.

실제로는, 간선들만으로 모든 노드를 연결하는 최소 비용의 구조는 MST를 통해 찾을 수 있으며, 이 MST의 비용이 정답이 됩니다. 트레일 구조라는 제약은 문제의 난이도를 높이는 것처럼 보이지만, 주어진 간선들로 모든 노드를 연결하는 최소 비용 구조는 Kruskal's 알고리즘을 통해 찾는 MST 비용과 동일합니다.

### 단계
1. **간선 정렬:** 주어진 모든 간선들을 비용(cost)을 기준으로 오름차순으로 정렬합니다.
2. **MST 구성 (Kruskal's 알고리즘):** 유니온-파인드(Union-Find) 자료구조를 사용하여 MST를 구성합니다.
3. **순회 및 연결:** 정렬된 간선들을 순회하면서, 현재 간선을 추가했을 때 사이클이 발생하지 않는 경우(즉, 두 끝점 u와 v가 이미 같은 집합에 속해 있지 않은 경우)에만 해당 간선을 선택하고, 두 노드를 연결(Union)합니다. 선택된 간선의 비용을 총 비용에 누적합니다.
4. **결과 반환:** 모든 간선 처리가 끝난 후 누적된 총 비용이 최소 비용입니다.

### 시간 복잡도
간선 개수를 E, 노드 개수를 V라고 할 때, 간선 정렬에 $O(E 	imes 	ext{log} E)$가 걸리며, 유니온-파인드 연산은 거의 상수 시간 $O(	ext{log} V)$에 가까우므로, 전체 시간 복잡도는 $O(E 	imes 	ext{log} E)$가 됩니다. 이는 주어진 제약 조건 내에서 충분히 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Union-Find 자료구조 구현
 * parent[i]: i의 부모 노드
 * rank[i]: i의 집합 크기(또는 깊이)를 관리하여 최적화
 */
class UnionFind {
    constructor(n) {
        this.parent = Array(n + 1).fill(0).map((_, i) => i);
        this.rank = Array(n + 1).fill(0);
    }

    // find(i): i의 대표 원소(Root)를 찾음 (Path Compression 적용)
    find(i) {
        if (this.parent[i] === i) {
            return i;
        }
        this.parent[i] = this.find(this.parent[i]);
        return this.parent[i];
    }

    // union(i, j): i와 j를 연결 (Union by Rank 적용)
    // 두 노드가 이미 같은 집합에 속해 있으면 false 반환
    union(i, j) {
        let rootI = this.find(i);
        let rootJ = this.find(j);

        if (rootI !== rootJ) {
            if (this.rank[rootI] < this.rank[rootJ]) {
                this.parent[rootI] = rootJ;
            } else if (this.rank[rootI] > this.rank[rootJ]) {
                this.parent[rootJ] = rootI;
            } else {
                this.parent[rootJ] = rootI;
                this.rank[rootI]++;
            }
            return true; // 성공적으로 연결됨
        }
        return false; // 이미 같은 집합에 속함 (사이클 발생)
    }
}

function solve(input) {
    // 입력 파싱: 첫 줄은 N, 나머지 줄은 간선 정보
    const lines = input.trim().split('\n');
    if (lines.length === 0) return 0;

    const N = parseInt(lines[0].trim());
    if (N <= 1) return 0;

    let edges = [];
    for (let i = 1; i < lines.length; i++) {
        const line = lines[i].trim();
        if (!line) continue;
        const parts = line.split(' ').map(Number);
        // parts[0] = u, parts[1] = v, parts[2] = cost
        edges.push({ u: parts[0], v: parts[1], cost: parts[2] });
    }

    // 1. 간선을 비용(cost)을 기준으로 오름차순 정렬 (Kruskal's 알고리즘)
    edges.sort((a, b) => a.cost - b.cost);

    // 2. Union-Find 초기화
    const uf = new UnionFind(N);
    let totalCost = 0;
    let edgesCount = 0; // MST는 N-1개의 간선으로 구성되어야 함

    // 3. 간선 순회 및 MST 구성
    for (const edge of edges) {
        // 간선 추가 시 사이클 여부 확인
        if (uf.union(edge.u, edge.v)) { 
            totalCost += edge.cost;
            edgesCount++;
        }
        // 모든 노드가 연결되었다면 (N-1개 간선 선택) 종료
        if (edgesCount === N - 1) {
            break;
        }
    }

    return totalCost; // 최소 비용 반환
}

// 테스트 환경을 위한 예시 입력 함수 (실제 환경에서는 별도의 입력 처리 필요)
function solveTest(input) {
    return solve(input);
}
```

# 최소 비용으로 연결하는 마을
*javascript · 그래프 · 보통 · MST, 프림, 크루스칼*

## 입출력 환경

입력은 표준 입력으로부터 받으며, Node.js 환경에서는 'readline' 모듈 또는 파일 스트림을 사용하여 모든 입력을 처리해야 합니다.

## 문제

N개의 마을이 있습니다. 각 마을 사이에는 도로가 놓여 있으며, 각 도로는 연결된 두 마을을 잇고 특정 비용을 가집니다. 당신은 모든 마을을 연결하는 최소 비용의 도로 네트워크를 구축하려고 합니다. 모든 마을이 연결되어야 하며, 추가적인 비용은 발생하지 않습니다. 주어진 모든 도로 정보 중에서 모든 마을을 연결하는 최소 비용의 조합을 찾아라. 이 비용이 최소가 되도록 하는 방법은 여러 가지가 있을 수 있습니다.

## 입력

첫째 줄에 마을의 개수 N과 도로의 개수 M이 주어집니다. (1 <= N <= 1000, 1 <= M <= N*N/2)
다음 M개의 줄은 각 도로의 정보 (마을 A, 마을 B, 비용 C)를 나타냅니다. (1 <= A, B <= N, 1 <= C <= 10000)

## 출력

모든 마을을 연결하는 최소 비용의 합을 한 정수로 출력하시오.

## 제약 조건

N: 1부터 1000까지
M: 1부터 50만까지
비용 C: 1부터 10000까지

## 예제 1

**입력**
```
4 5
1 2 3
1 3 2
2 3 1
2 4 5
3 4 4
```

**출력**
```
6
```

*가장 저렴한 연결은 (2-3) 1, (1-3) 2, (2-4) 5 또는 (1-2) 3, (2-3) 1, (1-3) 2를 포함하며, 최소 비용은 6이다.*

## 예제 2

**입력**
```
3 3
1 2 10
2 3 20
1 3 5
```

**출력**
```
15
```

*세 마을을 연결하는 최소 비용은 (1-3) 5와 (1-2) 10을 선택하여 15이다.*

## 힌트

- 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST)를 찾는 전형적인 문제입니다.
- 크루스칼 알고리즘이나 프림 알고리즘을 사용하여 해결할 수 있습니다. 크루스칼 알고리즘을 사용하려면 간선들을 비용 순으로 정렬하는 것이 핵심입니다.


## 알고리즘 요약

크루스칼 알고리즘 (Kruskal's Algorithm)을 사용합니다. 1. 주어진 모든 간선(도로)들을 비용(가중치)이 낮은 순서대로 정렬합니다. 2. Union-Find(Disjoint Set Union, DSU) 자료구조를 사용하여 연결 상태를 관리합니다. 3. 정렬된 간선들을 순회하면서, 두 마을(노드)이 이미 같은 집합(연결된 그룹)에 속해 있지 않다면 (즉, 사이클을 만들지 않는다면), 해당 간선을 MST에 포함시키고 두 마을을 같은 집합으로 합칩니다. 4. 이 과정을 N-1개의 간선이 선택되거나, 모든 간선이 처리될 때까지 반복하며, 선택된 간선들의 비용 합을 구합니다.

## 풀이 해설

### 💡 아이디어: 최소 신장 트리 (MST)
주어진 그래프에서 모든 정점(마을)을 연결하는 최소 비용의 간선 집합을 찾는 문제입니다. 이는 전형적인 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다.

### 🛠️ 단계별 풀이 (크루스칼 알고리즘 사용)
1. **데이터 구조 준비:** 모든 간선 (A, B, C)을 리스트로 저장합니다. 또한, 노드 간의 연결 상태를 효율적으로 관리하기 위해 Union-Find(DSU) 자료구조를 사용합니다.
2. **간선 정렬:** 모든 간선들을 비용 C가 낮은 순서대로 오름차순 정렬합니다. (이 단계가 가장 중요합니다.)
3. **MST 구성:** 정렬된 간선들을 처음부터 끝까지 순회합니다.
    a. 현재 간선 (u, v, c)를 가져옵니다.
    b. Union-Find의 `find(u)`와 `find(v)`를 사용하여 u와 v가 이미 같은 연결 그룹에 속해 있는지 확인합니다.
    c. 만약 `find(u)`와 `find(v)`의 결과가 다르면 (즉, 이 간선을 추가해도 사이클이 발생하지 않는다면), 이 간선을 MST에 포함시킵니다. 비용 c를 총 비용에 더하고, Union-Find의 `union(u, v)` 연산을 통해 u와 v를 같은 그룹으로 합칩니다.
4. **결과 반환:** 모든 간선 순회가 끝난 후의 총 비용이 최소 연결 비용이 됩니다.

### ⏱️ 시간 복잡도
- 간선 정렬: $O(M 	imes 	ext{log } M)$ (M은 간선의 수)
- Union-Find 연산: $O(M 	imes 	ext{alpha}(N))$ (여기서 $	ext{alpha}(N)$은 매우 느리게 증가하는 아커만 함수로, 사실상 상수 시간 $O(1)$로 간주합니다.)
- 총 시간 복잡도: $O(M 	imes 	ext{log } M)$ 입니다. (M이 N에 비해 크므로 정렬 시간이 지배적입니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} N - 마을의 개수
 * @param {number} M - 도로의 개수
 * @param {Array<Array<number>>} edges - [u, v, cost] 형식의 간선 리스트
 * @returns {number} 최소 연결 비용
 */
function solveMST(N, M, edges) {
    // 1. 간선 정렬: 비용(세 번째 요소) 기준 오름차순 정렬
    // [u, v, cost] 형태로 저장되어 있다고 가정
    edges.sort((a, b) => a[2] - b[2]);

    // 2. Union-Find (DSU) 구현
    const parent = Array(N + 1).fill(0).map((_, i) => i);
    const rank = Array(N + 1).fill(0);

    // Find 연산 (경로 압축)
    function find(i) {
        if (parent[i] === i) {
            return i;
        }
        parent[i] = find(parent[i]); // 경로 압축
        return parent[i];
    }

    // Union 연산 (랭크 기반 병합)
    function union(i, j) {
        const rootI = find(i);
        const rootJ = find(j);

        if (rootI !== rootJ) {
            // 랭크가 낮은 쪽을 높은 쪽의 부모로 연결
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 합병 성공
        }
        return false; // 이미 연결되어 있음
    }

    // 3. 크루스칼 알고리즘 실행
    let totalCost = 0;
    let edgesCount = 0; // MST에 포함된 간선 수

    for (const edge of edges) {
        const [u, v, cost] = edge;
        
        // 두 노드가 아직 연결되지 않았다면 (사이클을 만들지 않는다면)
        if (union(u, v)) {
            totalCost += cost;
            edgesCount++;
            
            // N개의 노드를 모두 연결하려면 N-1개의 간선이 필요함
            if (edgesCount === N - 1) {
                break;
            }
        }
    }

    return totalCost;
}
```

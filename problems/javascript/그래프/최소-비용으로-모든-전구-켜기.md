# 최소 비용으로 모든 전구 켜기
*javascript · 그래프 · 보통 · 최단경로, Dijkstra, 가중치*

## 입출력 환경

Node.js 환경에서 표준 입력을 읽을 때, 전체 입력을 문자열로 받은 후 적절히 파싱하여 사용하세요.

## 문제

당신은 여러 개의 전구(노드)가 연결된 건물 내부의 배선 담당자입니다. 각 전구 사이에는 배선 비용(가중치)이 책정되어 있습니다. 목표는 시작 전구(노드 0)에서 출발하여, 모든 전구(노드 1부터 N-1까지)를 한 번 이상 지나가서 켜는 것입니다. 모든 전구를 켜는 데 필요한 최소 배선 비용을 구하세요.

단, 전구는 순서에 상관없이 켜지면 되며, 이미 켜진 전구는 다시 지나갈 필요가 없습니다. 이동 경로는 최단 경로를 따라가야 합니다.

## 입력

첫째 줄에 전구의 개수 N (1 <= N <= 15)이 주어집니다.
다음 N-1 줄에는 간선의 정보가 주어집니다. 각 줄은 'u v w' 형식으로, u와 v를 잇는 간선의 가중치 w를 나타냅니다. 간선은 양방향입니다.

## 출력

모든 전구를 켜는 데 필요한 최소 비용을 한 정수로 출력합니다.

## 제약 조건

N: 1 <= N <= 15
간선의 가중치 w: 1 <= w <= 100
시간 복잡도: N이 최대 15이므로, 비트마스크를 활용한 DP 또는 TSP (Traveling Salesman Problem) 접근이 필요합니다. (O(N^2 * 2^N) 정도 허용)

## 예제 1

**입력**
```
3
0 1 3
0 2 2
```

**출력**
```
5
```

*노드 0에서 모든 노드를 거쳐야 하므로, 0 -> 1 -> 2 또는 0 -> 2 -> 1 경로를 고려합니다. 최소 비용은 0-1(3) + 0-2(2) = 5입니다.*

## 예제 2

**입력**
```
4
0 1 1
0 2 1
1 2 1
```

**출력**
```
3
```

*모든 노드를 지나가야 합니다. 0 -> 1 -> 2를 거치는 경로가 최소 비용입니다. (1+1=2) + 0->2(1)을 거치는 것이 아니라, 모든 노드를 포함하는 최소 비용의 트리가 되어야 합니다. (여기서는 0-1-2가 모든 노드를 포함하는 최소 연결 비용입니다.)*

## 힌트

- 이 문제는 전형적인 TSP (Traveling Salesman Problem) 변형 문제입니다.
- N이 최대 15이므로, 비트마스크 DP를 사용하여 '어떤 노드들을 방문했는지' 상태를 관리해야 합니다.


## 알고리즘 요약

이 문제는 '모든 노드를 포함하는 최소 비용의 연결'을 찾는 문제입니다. 먼저, 주어진 간선들로 구성된 그래프에서 모든 노드 쌍 간의 최단 거리를 구해야 합니다 (Floyd-Warshall 또는 다익스트라 반복). 그 후, 이 최단 거리 행렬을 사용하여 비트마스크 DP를 적용합니다. DP 상태는 `dp[mask][i]`로 정의하며, `mask`는 방문한 노드의 집합을, `i`는 현재 위치한 노드를 나타냅니다. 목표는 모든 노드를 방문한 상태(`mask = (1 << N) - 1`)에서 시작 노드 0에서 출발한 최소 비용을 찾는 것입니다.

## 풀이 해설

1. **최단 거리 전처리 (Floyd-Warshall):** 주어진 간선 정보는 부분 그래프를 이룹니다. 먼저, 모든 노드 쌍 $(i, j)$ 사이의 최단 거리를 구해야 합니다. N이 15로 작기 때문에 Floyd-Warshall 알고리즘을 사용하여 모든 노드 쌍 간의 최단 거리 `dist[i][j]`를 계산합니다. 초기화 시, 간선이 없는 거리는 무한대(`Infinity`)로 설정합니다.
2. **DP 정의 및 초기화:** 이 문제는 '모든 노드를 방문하는 최소 비용 경로'를 찾는 문제로, 비트마스크 DP를 사용합니다. 
   - `dp[mask][i]`는 노드 0에서 출발하여 `mask`에 포함된 모든 노드를 방문하고, 현재 노드가 `i`일 때의 최소 비용입니다.
   - 초기 상태: `dp[1 << 0][0] = 0` (노드 0에서 시작, 비용 0).
3. **DP 전이:** 모든 `mask`에 대해 반복합니다. `dp[mask][i]`가 유한한 값을 가질 때, 아직 방문하지 않은 노드 `j`로 이동하는 경우를 고려합니다. 
   - 새로운 마스크: `new_mask = mask | (1 << j)`
   - 비용 업데이트: `dp[new_mask][j] = min(dp[new_mask][j], dp[mask][i] + dist[i][j])`
4. **최종 결과:** 모든 노드를 방문한 최종 상태는 `(1 << N) - 1`입니다. 이 마스크에 대해 모든 노드 `i`에 대해 계산된 `dp[(1 << N) - 1][i]` 값 중 최솟값이 답이 됩니다. (다만, 문제의 제약 조건상 모든 노드를 방문하는 최소 비용의 연결을 찾는 것이므로, 시작점 0에서 모든 노드를 거쳐 돌아오는 것이 아니라, 최소 비용의 스패닝 트리를 구성하는 것과 유사하게 접근할 수 있습니다. 하지만 DP를 사용한다면, 모든 노드를 방문하는 경로의 최소 비용을 구하는 것이 가장 일반적인 해석입니다.)

*주의: 문제의 조건이 '모든 전구를 켜는 데 필요한 최소 배선 비용'이므로, 이는 사실상 모든 노드를 포함하는 최소 스패닝 트리의 총 가중치와 같습니다. 하지만 TSP DP를 적용하는 것이 출제 의도에 가깝습니다. 만약 모든 노드를 포함하는 최소 스패닝 트리의 비용이 답이라면, 모든 노드 쌍의 최단 거리를 구한 후, MST(Minimum Spanning Tree) 알고리즘을 적용해야 합니다. 여기서는 TSP DP를 통해 '모든 노드를 방문하는 최소 경로'로 해석하고 풀이합니다.* (실제 예제 분석 결과, 최소 비용 연결은 MST가 맞습니다. 따라서, 모든 노드 쌍의 최단 거리를 구한 후, 이 그래프 위에서 MST를 구하는 것이 가장 정확한 풀이입니다. 하지만 코딩테스트 환경에서 DP를 요구하는 경향을 반영하여, DP 기반 접근을 유지하되, 최종적으로는 모든 노드를 포함하는 최소 비용의 연결을 찾는다는 관점으로 해석합니다.)

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} N 전구의 개수
 * @param {Array<[number, number, number]>} edges 간선 정보 [[u, v, w], ...]
 * @returns {number} 최소 비용
 */
function solve(N, edges) {
    const INF = 1e9;
    
    // 1. 모든 노드 쌍 간의 최단 거리 계산 (Floyd-Warshall)
    let dist = Array(N).fill(0).map(() => Array(N).fill(INF));
    for (let i = 0; i < N; i++) {
        dist[i][i] = 0;
    }
    
    for (const [u, v, w] of edges) {
        dist[u][v] = Math.min(dist[u][v], w);
        dist[v][u] = Math.min(dist[v][u], w);
    }

    for (let k = 0; k < N; k++) {
        for (let i = 0; i < N; i++) {
            for (let j = 0; j < N; j++) {
                if (dist[i][k] !== INF && dist[k][j] !== INF) {
                    dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
                }
            }
        }
    }

    // 2. 모든 노드를 포함하는 최소 비용의 연결 찾기 (MST 알고리즘 적용)
    // 간선 리스트 생성: (가중치, u, v) 형태로 저장
    let allEdges = [];
    for (let i = 0; i < N; i++) {
        for (let j = i + 1; j < N; j++) {
            if (dist[i][j] !== INF) {
                allEdges.push({ weight: dist[i][j], u: i, v: j });
            }
        }
    }

    // Kruskal's 알고리즘을 사용하여 MST 계산
    allEdges.sort((a, b) => a.weight - b.weight);

    // Union-Find 구조체
    let parent = Array(N).fill(0).map((_, i) => i);
    const find = (i) => {
        if (parent[i] === i) return i;
        parent[i] = find(parent[i]);
        return parent[i];
    };
    const union = (i, j) => {
        let rootI = find(i);
        let rootJ = find(j);
        if (rootI !== rootJ) {
            parent[rootJ] = rootI;
            return true; // 합병 성공
        }
        return false; // 이미 연결됨
    };

    let totalCost = 0;
    let edgesCount = 0;
    
    for (const edge of allEdges) {
        if (union(edge.u, edge.v)) {
            totalCost += edge.weight;
            edgesCount++;
            if (edgesCount === N - 1) break;
        }
    }

    return totalCost;
}
```

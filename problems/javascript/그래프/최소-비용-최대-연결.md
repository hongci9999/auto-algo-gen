# 최소 비용 최대 연결
*javascript · 그래프 · 보통 · MST, Union-Find*

## 입출력 환경

JavaScript 환경에서 입력은 보통 전체 문자열로 받게 되므로, 모든 입력을 배열 형태로 처리한다고 가정합니다. (예: 각 줄을 개별 배열 요소로 분리)

## 문제

주어진 N개의 정점과 E개의 간선이 있습니다. 각 간선은 두 끝점과 그 가중치(비용)를 가집니다.

목표는 모든 정점을 연결하는 최소 비용의 트리를 만드는 것입니다 (최소 신장 트리, Minimum Spanning Tree).

정점들은 1부터 N까지 번호가 매겨져 있습니다. 간선들의 목록은 (u, v, w) 형태로 주어집니다.

## 입력

첫 번째 줄에 정점의 개수 N과 간선의 개수 E가 공백으로 구분되어 주어집니다.
다음 E개의 줄에는 각 간선의 정보 (u, v, w)가 공백으로 구분되어 주어집니다. u와 v는 연결된 두 정점의 번호(1부터 N), w는 해당 간선의 가중치입니다.

## 출력

최소 비용을 구하는 단 하나의 숫자만 출력합니다.

## 제약 조건

1 <= N <= 10^3
1 <= E <= 5000
1 <= w <= 10^9

## 예제 1

**입력**
```
5 6
1 2 3
1 3 4
2 3 7
2 4 5
3 4 8
1 5 10
```

**출력**
```
12
```

*크루스칼 알고리즘을 사용합니다. 간선들을 오름차순으로 정렬하여 연결 가능한 최소 비용의 트리를 찾습니다.*

## 예제 2

**입력**
```
4 4
1 2 10
1 3 5
2 3 7
2 4 8
```

**출력**
```
16
```

*정확한 풀이: 간선들을 가중치 순으로 고려하며 사이클을 만들지 않도록 연결합니다. 선택된 간선들로 모든 정점이 연결되는 최소 비용은 1-3(5), 2-3(7), 그리고 4는 아직 분리되어 있습니다. (2,4)=8. 총합: 5+7+8=20.*

## 예제 3

**입력**
```
3 2
1 2 10
1 3 20
```

**출력**
```
0
```

*정점 3개가 있지만 간선이 두 개만 있어 모든 정점을 연결할 수 없습니다. (MST는 N-1개의 간선이 필요하며, 이는 항상 존재한다고 가정합니다. 만약 연결 불가능한 경우를 처리한다면, 별도의 조건이 주어져야 합니다. 이 문제에서는 '최소 비용'을 구하므로, 주어진 간선들만으로 구성되는 최소 트리의 비용이 답입니다.)*

## 힌트

- 크루스칼 알고리즘(Kruskal's Algorithm)이나 프림 알고리즘(Prim's Algorithm)을 사용하세요.
- Union-Find 자료구조를 사용하여 사이클 여부를 효율적으로 판별할 수 있습니다.


## 알고리즘 요약

최소 신장 트리(MST) 문제입니다. 간선들을 가중치 오름차순으로 정렬한 후, Union-Find 구조를 이용하여 두 끝점이 이미 같은 집합에 속해 있는지를 확인합니다. 만약 다르면 (사이클이 아니면), 해당 간선을 선택하고 비용을 누적하며 두 정점을 같은 집합으로 합칩니다.

## 풀이 해설

### 문제 이해 및 목표
주어진 N개의 정점과 E개의 가중치 간선들 중에서, 모든 정점이 연결되면서 총 비용이 최소가 되는 트리를 찾는 것이 목표입니다. 이는 전형적인 최소 신장 트리(MST) 문제입니다.

### 알고리즘 개요: 크루스칼 알고리즘 (Kruskal's Algorithm)
크루스칼 알고리즘은 간선들을 가중치 순으로 정렬한 후, 사이클을 형성하지 않는 간선을 하나씩 선택해 나가는 방식입니다. 이 방식이 가장 구현하기 쉽고 효율적입니다.

### 단계별 풀이
1. **정렬 (Sorting)**: 모든 E개의 간선을 그들의 가중치(w)를 기준으로 오름차순 정렬합니다. 비용이 낮은 간선부터 먼저 고려해야 합니다.
2. **Union-Find 초기화**: N개의 정점 각각에 대해 Union-Find(Disjoint Set Union, DSU) 구조를 만듭니다. 각 정점을 독립된 집합으로 취급하며, 부모 배열(`parent`)과 집합 크기/랭크 등의 정보를 관리합니다.
3. **탐색 및 선택 (Iteration)**: 정렬된 간선들을 처음부터 끝까지 순회합니다. 현재 간선이 (u, v, w)일 때:
    a. **Find 연산**: `find(u)`와 `find(v)`를 수행하여 u와 v가 같은 집합에 속해 있는지 확인합니다.
    b. **사이클 체크**: 만약 `find(u)`와 `find(v)`의 결과가 다르면 (즉, 같은 집합이 아니라면), 이 간선은 사이클을 만들지 않습니다. 따라서 이 간선을 선택하고 총 비용에 w를 더합니다.
    c. **Union 연산**: 두 정점 u와 v의 집합을 하나로 합칩니다 (`union(u, v)`).
4. **종료**: 모든 간선을 탐색하거나, 혹은 N-1개의 간선이 선택되어 모든 정점이 연결되면 (MST가 완성되면) 반복을 멈추고 누적된 총 비용을 반환합니다.

### 시간 복잡도 분석
*   **정렬**: E개의 간선을 정렬하는 데 $O(E 	imes 	ext{log} E)$ 시간이 걸립니다. (실제로는 $O(E 	ext{ log } E)$)
*   **Union-Find 연산**: DSU를 사용할 경우, find와 union 연산은 거의 상수 시간 $O(	ext{a}(N))$에 근접합니다. 전체적으로 총 간선 수 E에 대해 반복하므로 $O(E 	imes 	ext{a}(N))$입니다.
*   **총 복잡도**: $O(E 	ext{ log } E)$가 지배적이므로, 시간 복잡도는 **$O(E 	ext{ log } E)$** 입니다. (문제 제약 조건 상 $E=5000$이므로 충분히 빠릅니다.)

## 참고 코드 (javascript)

```javascript
/**
 * 크루스칼 알고리즘을 사용하여 최소 신장 트리의 비용을 계산합니다.
 * @param {number} N 정점의 개수 (1부터 N)
 * @param {Array<{u: number, v: number, w: number}>} edges 간선 목록 [{u, v, w}]
 * @returns {number} 최소 연결 비용
 */
function kruskalMST(N, edges) {
    // 1. 간선을 가중치(w) 기준으로 오름차순 정렬
    edges.sort((a, b) => a.w - b.w);

    // Union-Find 구조 초기화
    const parent = Array(N + 1).fill(0).map((_, i) => i); // 1-based indexing
    const rank = Array(N + 1).fill(0);

    // Find 연산 (경로 압축 포함)
    function find(i) {
        if (parent[i] === i) {
            return i;
        }
        parent[i] = find(parent[i]); // 경로 압축
        return parent[i];
    }

    // Union 연산 (랭크 기반 병합)
    function union(i, j) {
        const rootI = find(i);
        const rootJ = find(j);

        if (rootI !== rootJ) {
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 합병 성공
        }
        return false; // 이미 같은 집합에 속함 (사이클 발생)
    }

    let totalCost = 0;
    let edgesCount = 0;

    // 2. 간선 순회 및 MST 구성
    for (const edge of edges) {
        // 사이클 체크 및 합병 시도
        if (union(edge.u, edge.v)) {
            totalCost += edge.w;
            edgesCount++;
            // N-1개의 간선이 선택되면 MST 완성
            if (edgesCount === N - 1) {
                break; 
            }
        }
    }

    // 참고: 만약 edgesCount < N - 1 이면, 정점들이 연결되지 않은 상태입니다.
    return totalCost;
}

/**
 * Main 실행 함수 (입력 처리를 위한 구조)
 * 실제 환경에서는 입력 파싱 로직이 필요합니다.
 */
function solve(input) {
    // 예시: 입력 문자열을 기반으로 N, E 및 간선 배열 생성하는 가상의 과정
    const lines = input.trim().split('\n').filter(line => line.length > 0);
    if (lines.length === 0) return 0;

    // 첫 줄: N E
    const [N, E] = lines[0].split(' ').map(Number);
    
    let edges = [];
    for (let i = 1; i <= E; i++) {
        const [u, v, w] = lines[i].split(' ').map(Number);
        edges.push({ u: u, v: v, w: w });
    }

    return kruskalMST(N, edges);
}
```

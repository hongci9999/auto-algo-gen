# 최대 합을 만족하는 가장 긴 연속 부분 배열 찾기
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 합계*

## 입출력 환경

JavaScript 환경에서는 일반적으로 입력 전체를 문자열로 읽은 후, 필요한 파싱 과정을 거쳐 배열과 K 값을 얻는다고 가정합니다. 예제 코드에서는 함수 형태로 입력이 주어지도록 설계했습니다.

## 문제

정수 배열 `arr`과 정수 `K`가 주어집니다. 이 배열에서 합이 `K` 이하가 되는 가장 긴 연속 부분 배열의 길이를 구하는 문제입니다.

부분 배열의 합이 `K`를 초과하는 순간, 반드시 윈도우를 조정하여 다시 합이 `K` 이하가 되도록 만들어야 합니다.

## 입력

첫 번째 줄에 정수 N이 주어집니다. 다음 줄에 N개의 정수(arr[0], arr[1], ..., arr[N-1])가 공백으로 구분되어 주어집니다. 마지막 줄에 정수 K가 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

N의 범위: 1 <= N <= 10^5
arr[i]의 범위: -1000 <= arr[i] <= 1000
K의 범위: -10^9 <= K <= 10^9

## 예제 1

**입력**
```
arr = [1, 2, 3, 4, 5], K = 9
```

**출력**
```
3
```

*부분 배열 [2, 3, 4]의 합이 9로, 최대 길이는 3입니다.*

## 예제 2

**입력**
```
arr = [5, 0, -2, 3, 1], K = 6
```

**출력**
```
4
```

*부분 배열 [5, 0, -2, 3]의 합이 6으로, 최대 길이는 4입니다.*

## 예제 3

**입력**
```
arr = [10, 5, 2, 7, 8], K = 15
```

**출력**
```
3
```

*부분 배열 [5, 2, 7]의 합이 14로, [2, 7, 8]은 합이 17로 초과되어 최대 길이는 3입니다.*

## 힌트

- 양방향 포인터(Two Pointers) 기법을 사용해 윈도우를 관리해 보세요.
- 현재 합계(Sum)를 유지하며, 합계가 K를 초과할 때만 윈도우의 시작점을 이동시켜야 합니다.


## 알고리즘 요약

슬라이딩 윈도우(Sliding Window) 기법을 사용합니다. 배열의 오른쪽 끝부터 윈도우를 확장하며 현재 합계를 계산합니다. 만약 현재 합계가 주어진 K를 초과하면, 윈도우의 왼쪽 끝을 오른쪽으로 이동시키면서 합계에서 해당 원소를 빼줍니다. 이 과정을 통해 합계가 다시 K 이하가 될 때까지 윈도우를 축소시키고, 매 단계마다 현재 윈도우의 크기(길이)를 최대값과 비교합니다.

## 풀이 해설

💡 아이디어:
이 문제는 합계가 특정 값(K)을 넘지 않는 가장 긴 연속 구간을 찾는 전형적인 슬라이딩 윈도우 문제입니다. 윈도우의 오른쪽 경계(Right Pointer, R)를 한 칸씩 전진시키면서 윈도우를 확장합니다. 이 과정에서 현재 합계(Current Sum)를 계산하고, 만약 Current Sum이 K를 초과하게 되면, 윈도우의 왼쪽 경계(Left Pointer, L)를 전진시켜 윈도우를 축소시키고, Current Sum에서 L에 해당하는 원소를 제거합니다. 이 과정을 반복하며, 윈도우가 유효한 상태(Sum <= K)일 때마다 윈도우의 크기(R - L + 1)를 최대 길이와 비교하여 갱신합니다.

⚙️ 단계:
1. 초기화: `left` 포인터, `right` 포인터, `currentSum`, `maxLength`를 모두 0으로 설정합니다.
2. 순회: `right` 포인터를 배열의 끝까지 순회하며 `currentSum`에 `arr[right]`를 더합니다.
3. 윈도우 축소 (Shrinking): 만약 `currentSum > K`라면, `left` 포인터를 전진시키고, `currentSum`에서 `arr[left]` 값을 <0xEB><0xBA><0x8D>니다. 이 과정을 `currentSum <= K`가 될 때까지 반복합니다. (이 과정에서 `left`는 `right`를 절대 넘어서지 않습니다.)
4. 최대 길이 갱신: 윈도우가 유효한 상태가 되었으므로, 현재 윈도우의 길이 (`right - left + 1`)를 `maxLength`와 비교하여 더 큰 값으로 갱신합니다.
5. 종료: `right` 포인터가 배열 끝에 도달하면 `maxLength`가 최종 답이 됩니다.

⏱️ 시간 복잡도 및 공간 복잡도:
시간 복잡도: O(N). `left` 포인터와 `right` 포인터 모두 배열을 최대 한 번씩만 순회하므로, 전체 시간 복잡도는 선형 시간 O(N)입니다.
공간 복잡도: O(1). 추가적인 메모리 공간은 상수 크기만 사용합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} arr - 정수 배열
 * @param {number} K - 최대 합계 제한 값
 * @returns {number} - 가장 긴 부분 배열의 길이
 */
function solve(arr, K) {
    let left = 0;          // 윈도우의 왼쪽 포인터
    let currentSum = 0;    // 현재 윈도우의 합계
    let maxLength = 0;     // 최대 길이 기록
    const N = arr.length;

    for (let right = 0; right < N; right++) { // right 포인터로 윈도우 확장
        // 1. 합계에 현재 원소 추가
        currentSum += arr[right];

        // 2. 합계가 K를 초과하면 윈도우 축소
        while (currentSum > K) {
            // left 원소를 합계에서 제거하고, left 포인터 이동
            currentSum -= arr[left];
            left++;
        }

        // 3. 윈도우가 유효하면 (Sum <= K), 길이 갱신
        // 현재 윈도우의 크기: right - left + 1
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}

// --- 테스트 케이스 실행 예시 (Node.js 환경 가정) ---

// 예제 1: [1, 2, 3, 4, 5], K = 9 -> 3
let arr1 = [1, 2, 3, 4, 5];
let K1 = 9;
console.log(`[${arr1}] K=${K1}의 최대 길이: ${solve(arr1, K1)}`); // 예상 출력: 3

// 예제 2: [5, 0, -2, 3, 1], K = 6 -> 4
let arr2 = [5, 0, -2, 3, 1];
let K2 = 6;
console.log(`[${arr2}] K=${K2}의 최대 길이: ${solve(arr2, K2)}`); // 예상 출력: 4

// 예제 3: [10, 5, 2, 7, 8], K = 15 -> 3
let arr3 = [10, 5, 2, 7, 8];
let K3 = 15;
console.log(`[${arr3}] K=${K3}의 최대 길이: ${solve(arr3, K3)}`); // 예상 출력: 3
```

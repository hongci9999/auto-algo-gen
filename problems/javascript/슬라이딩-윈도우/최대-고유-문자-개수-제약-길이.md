# 최대 고유 문자 개수 제약 길이
*javascript · 슬라이딩 윈도우 · 보통 · 문자열, 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리합니다. 일반적으로 모든 입력을 읽은 후, 문제 풀이 함수에 인자로 넘기는 방식으로 구현합니다.

## 문제

주어진 문자열 S와 정수 K가 있습니다. 문자열 S의 부분 문자열 중, 고유한 문자(distinct characters)의 개수가 K개 이하인 최대 길이를 구하는 문제입니다.

부분 문자열이란 S의 시작점과 끝점을 지정하여 잘라낸 연속된 문자들의 나열을 의미합니다.

예시: S="abacaba", K=2일 때, "aba"는 고유 문자가 'a', 'b' 두 개이므로 유효합니다. 길이는 3입니다. 이보다 더 긴 유효한 부분 문자열은 없습니다.

## 입력

첫 번째 줄에 문자열 S가 주어지고, 두 번째 줄에 정수 K가 주어집니다.

## 출력

최대 길이 (정수)를 출력합니다.

## 제약 조건

문자열 S의 길이는 1 이상 10^5 이하입니다. 정수 K는 1 이상 26 이하입니다.

## 예제 1

**입력**
```
abacaba
2
```

**출력**
```
3
```

*고유 문자가 2개 이하인 가장 긴 부분 문자열은 "aba" 또는 "aca" (길이 3)입니다.*

## 예제 2

**입력**
```
zzzaazz
2
```

**출력**
```
7
```

*전체 문자열 "zzzaazz"는 고유 문자가 'z', 'a' 두 개이므로 유효하며, 길이가 7입니다.*

## 예제 3

**입력**
```
abcdefg
1
```

**출력**
```
1
```

*고유 문자가 1개인 가장 긴 부분 문자열은 'a', 'b', 'c', ... 등 각각의 문자입니다.*

## 힌트

- 부분 문자열의 최대 길이를 찾는 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 생각해보세요.
- 현재 윈도우 내의 고유 문자 개수를 효율적으로 추적하기 위해 빈도 맵(Frequency Map)을 사용하는 것이 좋습니다.


## 알고리즘 요약

슬라이딩 윈도우와 빈도 맵(Frequency Map)을 사용합니다. 오른쪽 포인터(right)를 이동시키며 윈도우를 확장하고, 현재 윈도우 내의 고유 문자 개수가 K를 초과할 경우, 왼쪽 포인터(left)를 이동시켜 윈도우를 축소합니다. 윈도우가 항상 유효 상태를 유지하도록 관리하며, 매 단계마다 윈도우의 길이를 최대 길이와 비교하여 갱신합니다.

## 풀이 해설

이 문제는 슬라이딩 윈도우 기법을 적용하여 O(N) 시간 복잡도로 해결할 수 있습니다.

**1. 초기화:**
*   `left` 포인터(윈도우 시작)를 0으로 설정합니다.
*   `right` 포인터(윈도우 끝)를 0으로 설정합니다.
*   `max_length`를 0으로 설정합니다.
*   빈도 맵(Map)을 사용하여 현재 윈도우 `[left, right]`에 포함된 문자들의 등장 횟수를 기록합니다.

**2. 윈도우 확장 (Right Pointer 이동):**
*   `right` 포인터를 문자열의 끝까지 이동시키면서 해당 문자를 빈도 맵에 추가하고 횟수를 증가시킵니다.

**3. 윈도우 축소 (Constraint Check):**
*   빈도 맵의 크기(즉, 고유 문자 개수)가 주어진 제약 K를 초과하는지 확인합니다.
*   만약 `Map.size > K`라면, 윈도우는 유효하지 않으므로 왼쪽 포인터(`left`)를 한 칸 이동시킵니다. 
*   `left`가 이동할 때, 해당 문자를 빈도 맵에서 제거하거나 횟수를 1 감소시킵니다. 만약 해당 문자의 횟수가 0이 되면, 맵에서 완전히 제거하여 고유 문자 개수를 정확히 줄여줍니다.
*   이 과정을 `Map.size <= K`가 될 때까지 반복합니다.

**4. 최대 길이 갱신:**
*   윈도우가 항상 유효한 상태를 유지하므로, 매 `right` 단계마다 현재 윈도우의 길이 (`right - left + 1`)를 계산하여 `max_length`와 비교하고 갱신합니다.

**시간 복잡도:** 오른쪽 포인터와 왼쪽 포인터는 각각 문자열의 길이에 비례하여 최대 한 번씩만 이동하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 고유 문자 집합의 크기(최대 26)에 비례하여 O(1)로 일정합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} S - 입력 문자열
 * @param {number} K - 고유 문자 개수 제약
 * @returns {number} - 최대 길이
 */
function solve(S, K) {
    let left = 0;
    let maxLength = 0;
    // Map을 사용하여 문자와 그 빈도를 저장합니다.
    const charFrequency = new Map();

    for (let right = 0; right < S.length; right++) {
        const charRight = S[right];
        
        // 1. 윈도우 확장: 오른쪽 문자를 맵에 추가하고 횟수 증가
        charFrequency.set(charRight, (charFrequency.get(charRight) || 0) + 1);

        // 2. 윈도우 축소: 고유 문자 개수가 K를 초과하는지 확인
        // Map의 크기는 현재 고유 문자의 개수입니다.
        while (charFrequency.size > K) {
            const charLeft = S[left];
            
            // 해당 문자의 횟수를 1 감소
            let count = charFrequency.get(charLeft) - 1;
            charFrequency.set(charLeft, count);
            
            // 횟수가 0이 되면 맵에서 완전히 제거하여 고유 문자 개수를 줄임
            if (count === 0) {
                charFrequency.delete(charLeft);
            }
            
            // 왼쪽 포인터 이동
            left++;
        }

        // 3. 최대 길이 갱신: 현재 윈도우 [left, right]는 항상 유효함
        const currentLength = right - left + 1;
        maxLength = Math.max(maxLength, currentLength);
    }

    return maxLength;
}

// --- 테스트 실행을 위한 로직 (Node.js 환경 가정) ---
function runTest(inputLine) {
    const lines = inputLine.trim().split('\n');
    if (lines.length < 2) return null;
    
    const S = lines[0].trim();
    const K = parseInt(lines[1].trim());
    
    return solve(S, K);
}

// 예시 3: abcdefg, K=1
// console.log("Test 3 Result: " + runTest("abcdefg\n1")); // 기대값: 1
```

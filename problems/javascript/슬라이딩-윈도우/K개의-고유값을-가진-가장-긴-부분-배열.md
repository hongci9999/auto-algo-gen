# K개의 고유값을 가진 가장 긴 부분 배열
*javascript · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조, 배열*

## 입출력 환경

Node.js 환경에서 모든 입력을 읽어와서 처리합니다. 입력은 2줄로 구성되며, 첫 줄은 공백으로 구분된 배열 원소, 두 번째 줄은 K 값입니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 여러분은 배열 A의 부분 배열 중, 고유한(distinct) 원소의 개수가 K개 이하가 되는 가장 긴 부분 배열의 길이를 찾아야 합니다.

예를 들어, 배열 A = [1, 2, 1, 3]이고 K = 2일 때, 부분 배열 [1, 2, 1]은 고유 원소 {1, 2}를 가지므로 길이 3이 가능합니다. 하지만 [1, 2, 1, 3]은 고유 원소 {1, 2, 3}을 가지므로 K=2 조건을 위반합니다. 따라서 최댓값은 3입니다. (참고: 모든 원소가 다를 경우 K가 충분히 크면 배열 전체가 답이 됩니다.)

## 입력

첫 번째 줄에 공백으로 구분된 정수 배열 A의 원소들이 주어집니다. 두 번째 줄에 정수 K가 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

배열 A의 원소 개수 N은 1 이상 10만 이하입니다. 배열 A의 원소 값은 1 이상 10만 이하입니다. K는 1 이상 N 이하입니다.

## 예제 1

**입력**
```
1 2 1 3
2
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]은 고유 원소가 2개이며, 길이가 3입니다. (최댓값)*

## 예제 2

**입력**
```
5 5 5 5
1
```

**출력**
```
4
```

*모든 원소가 같으므로 고유 원소는 1개입니다. 배열 전체가 답입니다.*

## 예제 3

**입력**
```
1 2 3 4
1
```

**출력**
```
1
```

*고유 원소가 1개인 가장 긴 부분 배열은 [1], [2], [3], [4] 중 하나이며, 길이는 1입니다.*

## 힌트

- 슬라이딩 윈도우 기법을 활용하여 O(N)의 시간 복잡도로 해결할 수 있습니다.
- 현재 윈도우 내의 고유 원소 개수를 효율적으로 추적하는 자료구조가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 기법과 해시맵(Map)을 사용합니다. 왼쪽 포인터 L과 오른쪽 포인터 R을 사용하여 윈도우 [L, R]을 확장합니다. 윈도우가 K개의 고유 원소 조건을 만족할 때마다 현재 길이 (R - L + 1)를 최댓값으로 기록합니다. 만약 고유 원소 개수가 K를 초과하면, L을 오른쪽으로 이동시키면서 윈도우를 축소하고, 해시맵에서 해당 원소의 개수를 조정하여 조건을 다시 만족시킬 때까지 반복합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법의 전형적인 예시입니다. 고유 원소 개수를 O(1) 시간 안에 확인하고, 조건 위반 시 윈도우를 빠르게 축소하는 것이 핵심입니다.

단계:
1. 초기화: 왼쪽 포인터 `L = 0`, 오른쪽 포인터 `R = 0`으로 설정하고, 고유 원소의 빈도수 및 개수를 저장할 `Map`을 준비하며, 최대 길이를 `maxLength = 0`으로 초기화합니다.
2. 윈도우 확장 (R 증가): R을 1씩 증가시키며 `A[R]` 원소를 윈도우에 추가합니다. 이 원소의 빈도수를 Map에 업데이트합니다.
3. 조건 검사 및 윈도우 축소 (L 증가): Map의 크기(즉, 고유 원소의 개수)가 K를 초과하는 경우, 조건을 만족시키기 위해 L을 오른쪽으로 이동시켜야 합니다. L이 가리키는 원소 `A[L]`의 빈도수를 감소시킵니다. 만약 이 원소의 빈도수가 0이 된다면, 이는 윈도우에서 해당 원소가 완전히 사라졌음을 의미하므로 Map에서 해당 원소를 제거합니다. L을 1 증가시킵니다.
4. 결과 갱신: 윈도우가 조건을 만족할 때마다 (즉, Map의 크기가 K 이하일 때) 현재 윈도우의 길이 `R - L + 1`을 계산하여 `maxLength`와 비교하고 최댓값을 갱신합니다.
5. 종료: R이 배열의 끝에 도달하면 `maxLength`를 반환합니다.

시간 복잡도: L과 R 포인터는 각각 배열의 시작부터 끝까지 한 번씩만 움직입니다. Map 연산(삽입, 삭제, 조회)은 평균적으로 O(1) 시간이 걸리므로, 전체 시간 복잡도는 O(N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 최대 고유 원소 개수
 * @returns {number} - 가장 긴 부분 배열의 길이
 */
function solve(A, K) {
    let left = 0; // 왼쪽 포인터 (L)
    let maxLength = 0;
    // 윈도우 내 원소의 빈도수를 저장합니다.
    const freqMap = new Map(); 

    for (let right = 0; right < A.length; right++) { // 오른쪽 포인터 (R)로 윈도우 확장
        const currentElement = A[right];
        // 1. 윈도우에 원소 추가 및 빈도수 업데이트
        freqMap.set(currentElement, (freqMap.get(currentElement) || 0) + 1);

        // 2. 조건 위반 시 윈도우 축소
        // 고유 원소의 개수 (Map의 크기)가 K를 초과하면 L을 이동시켜야 함
        while (freqMap.size > K) {
            const elementToRemove = A[left];
            
            // 제거할 원소의 빈도수 감소
            let count = freqMap.get(elementToRemove) - 1;
            freqMap.set(elementToRemove, count);

            // 빈도수가 0이 되면 Map에서 완전히 제거 (고유 원소 개수 감소)
            if (count === 0) {
                freqMap.delete(elementToRemove);
            }
            
            // 왼쪽 포인터 이동
            left++; 
        }

        // 3. 현재 윈도우의 길이가 최대 길이인지 확인
        // 윈도우 [left, right]의 길이는 right - left + 1 입니다.
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}

// --- 입출력 처리 예시 (Node.js 환경 가정) ---

function main() {
    const fs = require('fs');
    // 모든 입력을 한 번에 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 줄: 배열 A의 원소들
    const A = input[0].trim().split(/\s+/).map(Number);
    // 두 번째 줄: K
    const K = parseInt(input[1].trim());

    const result = solve(A, K);
    console.log(result);
}

// main(); // 실제 실행 시 주석 해제
```

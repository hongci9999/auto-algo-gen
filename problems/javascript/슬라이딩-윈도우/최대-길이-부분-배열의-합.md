# 최대 길이 부분 배열의 합
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, Two Pointers*

## 입출력 환경

Node.js 환경에서 전체 입력을 읽은 후, 파싱하여 배열 A와 K를 추출해야 합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어졌을 때, 합이 K보다 작거나 같은 가장 긴 연속 부분 배열의 길이를 구하는 문제입니다. 배열의 모든 원소는 양의 정수입니다.

예시: A = [3, 1, 2, 7], K = 8
부분 배열 [3, 1, 2]의 합은 6이며, 길이는 3입니다. 이는 K=8보다 작습니다.
부분 배열 [1, 2, 7]의 합은 10이며, 이는 K=8보다 큽니다.
따라서 최대 길이는 3입니다.

## 입력

첫 번째 줄에 공백으로 구분된 정수 배열 A의 원소들이 주어지고, 두 번째 줄에 정수 K가 주어집니다.

## 출력

해당 조건을 만족하는 최대 길이의 정수 N을 출력합니다.

## 제약 조건

배열 A의 원소는 1 이상 100 이하의 정수이며, 배열의 크기 N은 1부터 10만 이하입니다. K는 1 이상 100만 이하의 정수입니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
3 1 2 7
8
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합은 6이며, 최대 길이는 3입니다.*

## 예제 2

**입력**
```
1 2 3 4
5
```

**출력**
```
2
```

*합이 5 이하인 가장 긴 부분 배열은 [1, 2] 또는 [2, 3]이며, 길이는 2입니다.*

## 예제 3

**입력**
```
10 20 30
10
```

**출력**
```
1
```

*모든 원소가 10을 초과하므로, 합이 10 이하인 가장 긴 부분 배열은 길이가 1인 [10]입니다.*

## 힌트

- 배열의 시작점(Left Pointer)과 끝점(Right Pointer)을 활용하는 슬라이딩 윈도우 기법을 고려해 보세요.
- 윈도우의 합(Current Sum)을 유지하며, 합이 K를 초과할 경우 윈도우를 어떻게 줄여야 하는지 생각해야 합니다.


## 알고리즘 요약

슬라이딩 윈도우(Sliding Window) 기법을 사용합니다. 두 개의 포인터(left, right)와 현재 합(currentSum) 변수를 유지합니다. 오른쪽 포인터를 이동시키며 윈도우를 확장하고, 합이 K를 초과하면 왼쪽 포인터를 이동시키며 윈도우를 축소하여 조건을 만족시킵니다. 매 단계마다 현재 윈도우의 길이와 최대 길이를 비교하여 업데이트합니다.

## 풀이 해설

풀이 해설: 아이디어
이 문제는 '합이 K 이하인 가장 긴 부분 배열'을 찾는 문제이므로, 슬라이딩 윈도우 기법이 가장 효율적입니다. 윈도우를 오른쪽으로 확장하면서 합을 계산하고, 합이 K를 초과하면 윈도우의 왼쪽 끝을 이동시켜 합을 줄여나가는 과정을 반복합니다.

단계
1. 변수 초기화: `left` 포인터(0), `right` 포인터(0), `currentSum` (0), `maxLength` (0)을 초기화합니다.
2. 윈도우 확장 (Right Pointer 이동): `right` 포인터를 배열의 끝까지 이동시키면서 `currentSum`에 `A[right]`를 더합니다. 이로써 윈도우는 [left, right]가 됩니다.
3. 윈도우 축소 (Condition Check): 만약 `currentSum`이 K를 초과하게 되면, 윈도우가 조건을 위반한 것이므로, `left` 포인터를 이동시키면서 `currentSum`에서 `A[left]` 값을 빼줍니다. 이 과정을 `currentSum <= K`가 될 때까지 반복합니다.
4. 최대 길이 갱신: 윈도우의 합이 K 이하로 유지되는 한, 현재 윈도우의 길이(`right - left + 1`)를 계산하여 `maxLength`와 비교하고 더 큰 값으로 갱신합니다.
5. 반복: 2~4단계를 배열의 끝까지 반복합니다.

시간 복잡도: O(N)
`right` 포인터는 N번만 이동하고, `left` 포인터 역시 최대 N번만 이동합니다. 따라서 각 포인터 이동은 상수 시간이 소요되므로, 전체 시간 복잡도는 O(N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A 배열
 * @param {number} K 최대 합
 * @returns {number} 최대 길이
 */
function solve(A, K) {
    let left = 0;
    let currentSum = 0;
    let maxLength = 0;
    const N = A.length;

    for (let right = 0; right < N; right++) {
        // 1. 윈도우 확장: 오른쪽 포인터를 이동시키며 합을 누적합니다.
        currentSum += A[right];

        // 2. 윈도우 축소: 합이 K를 초과하면 왼쪽 포인터를 이동시키며 합을 줄입니다.
        while (currentSum > K) {
            currentSum -= A[left];
            left++;
        }
        
        // 3. 최대 길이 갱신: 현재 윈도우의 길이를 계산하여 최대 길이와 비교합니다.
        // 윈도우의 길이는 right - left + 1 입니다.
        maxLength = Math.max(maxLength, right - left + 1);
    }
    return maxLength;
}

// Node.js 환경에서 입력을 처리하는 메인 로직
function main() {
    const fs = require('fs');
    // 표준 입력 전체를 동기적으로 읽습니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;
    
    // 첫 번째 줄: 배열 A
    const A = input[0].trim().split(' ').map(Number);
    // 두 번째 줄: K
    const K = parseInt(input[1].trim());

    const result = solve(A, K);
    console.log(result);
}

main();
```

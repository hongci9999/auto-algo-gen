# 최대 길이의 유니크 문자열 부분 배열
*javascript · 슬라이딩 윈도우 · 보통 · 문자열, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 표준 입력으로 단일 문자열 S를 받습니다 (예: process.stdin.on('data', ...)).

## 문제

주어진 문자열 S가 있을 때, 이 문자열에서 모든 문자가 유일한(중복되지 않는) 가장 긴 부분 문자열의 길이를 구하는 문제입니다.

예를 들어, "abcabc"라는 문자열이 주어지면, "abc"는 길이가 3이고 모든 문자가 다릅니다. 하지만 "abca"는 'a'가 중복되므로 유효한 부분이 아닙니다. 따라서 최대 길이는 3입니다.

## 입력

문자열 S (공백 없이 알파벳 또는 영숫자로 구성된 단일 문자열)

## 출력

해당 조건에 맞는 가장 긴 부분 문자열의 길이(정수)

## 제약 조건

문자열 S의 길이 N은 1 이상 10^5 이하입니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
abcabc
```

**출력**
```
3
```

*"abc"가 가장 긴 유니크 부분 배열입니다.*

## 예제 2

**입력**
```
bbbbb
```

**출력**
```
1
```

*모든 문자가 반복되므로 최대 길이는 1입니다.*

## 예제 3

**입력**
```
pwwkew
```

**출력**
```
3
```

*"wke" 또는 "kew"가 가장 긴 유니크 부분 배열입니다.*

## 힌트

- 슬라이딩 윈도우 기법을 사용해야 시간 복잡도를 O(N)으로 줄일 수 있습니다.
- 문자가 중복되었을 때, 왼쪽 포인터(`left`)를 어떻게 이동시켜야 하는지 결정하는 것이 핵심입니다. 단순하게 이전 위치 + 1로만 이동하면 안 됩니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window): 두 개의 포인터(left와 right)를 사용하여 현재 유효한 부분 문자열을 유지합니다. 해시맵(Map)을 이용하여 현재 창에 포함된 문자를 추적하고, 중복 문자가 발견되면 left 포인터를 해당 문자의 이전 위치 다음으로 이동시켜 윈도우를 조정합니다.

## 풀이 해설

아이디어: 이 문제는 전형적인 슬라이딩 윈도우 문제입니다. 우리는 '모든 문자가 유일한' 조건을 만족하는 가장 큰 창(Window)을 찾아야 합니다.

단계:
1. 두 포인터 `left` (시작점)와 `right` (종료점)를 초기화합니다. 또한, 지금까지 발견된 최대 길이를 저장할 변수 `maxLength`를 0으로 초기화합니다.
2. 문자를 저장하고 해당 문자가 마지막으로 나타난 인덱스를 추적하기 위해 JavaScript Map을 사용합니다. 이 Map은 `{문자: 마지막_인덱스}` 형태를 가집니다.
3. `right` 포인터를 문자열의 끝까지 이동시키며 반복합니다. (확장 단계)
4. 현재 문자 `S[right]`가 이미 Map에 존재하는지 확인합니다.
   a) **중복 발견 시:** 만약 `S[right]`이 이전에 등장한 적이 있다면, 이는 유효한 윈도우의 범위를 벗어났다는 의미입니다. 따라서 `left` 포인터는 반드시 해당 문자의 이전 위치(`map.get(S[right])`)보다 한 칸 뒤로 이동해야 합니다. 우리는 `left = Math.max(left, map.get(S[right]) + 1)` 공식을 사용하여 left를 업데이트합니다. (여기서 `Math.max`를 사용하는 이유는, 이전에 발생한 중복으로 인해 이미 `left`가 더 오른쪽으로 이동했을 수 있기 때문에, 단순히 이전 위치보다 한 칸 뒤로만 갈 것이 아니라, 항상 현재의 `left`와 새로 계산된 시작점 중 더 큰 값을 가져야 하기 때문입니다.)
   b) **중복이 아닐 시:** `left` 포인터는 그대로 유지됩니다.
5. Map에 현재 문자 `S[right]`의 최신 인덱스(`right`)를 업데이트합니다.
6. 현재 윈도우의 길이 (`right - left + 1`)를 계산하고, 이 값이 `maxLength`보다 크면 `maxLength`를 갱신합니다.
7. 모든 반복이 끝난 후, 최종 `maxLength`가 답입니다.

시간 복잡도: 각 포인터(`left`, `right`)는 문자열을 한 번만 순회하므로 O(N)의 시간 복잡도를 가집니다. 공간 복잡도는 최악의 경우 알파벳 크기(상수, O(1))에 비례합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} s 주어진 문자열
 * @returns {number} 최대 길이
 */
function lengthOfLongestSubstring(s) {
    if (!s || s.length === 0) return 0;

    // Map을 사용하여 문자와 마지막 등장 인덱스를 저장합니다.
    const charIndexMap = new Map();
    let left = 0; // 왼쪽 포인터 (윈도우 시작)
    let maxLength = 0;

    for (let right = 0; right < s.length; right++) {
        const currentChar = s[right];

        // 1. 현재 문자가 이미 맵에 존재하고, 그 등장 위치가 현재 윈도우 범위(left ~ right-1) 내에 있다면:
        if (charIndexMap.has(currentChar)) {
            const lastSeenIndex = charIndexMap.get(currentChar);
            
            // left 포인터를 중복 문자가 처음 나타난 지점 바로 다음으로 이동시켜 윈도우를 조정합니다.
            // Math.max를 사용하는 이유는, 이미 왼쪽이 오른쪽으로 많이 이동한 상태일 때,
            // 과거의 작은 인덱스로 인해 불필요하게 left가 역행하는 것을 막기 위함입니다.
            left = Math.max(left, lastSeenIndex + 1);
        }

        // 2. 현재 문자의 최신 인덱스를 Map에 업데이트합니다.
        charIndexMap.set(currentChar, right);

        // 3. 현재 윈도우의 길이를 계산하고 최대 길이 갱신
        const currentLength = right - left + 1;
        maxLength = Math.max(maxLength, currentLength);
    }

    return maxLength;
}

// Node.js 환경 시뮬레이션 (실제 테스트 환경에 맞게 입력 처리 필요)
function solve() {
    const input = process.argv[2]; // 명령줄 인자에서 문자열을 가져온다고 가정
    if (!input) return console.log(0);
    console.log(lengthOfLongestSubstring(input).toString());
}

// 테스트 실행 예시: solve();
```

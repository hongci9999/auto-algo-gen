# 최대 합을 갖는 연속 부분 배열
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 탐색*

## 입출력 환경

Node.js 환경에서 전체 입력을 읽고 처리합니다. 입력은 'N K\narr[0] arr[1] ... arr[N-1]' 형태를 가정합니다.

## 문제

어떤 정수 배열 `arr`과 고정된 크기 `K`가 주어집니다. 배열 내에서 크기가 정확히 `K`인 연속된 부분 배열이 존재하며, 이 부분 배열들의 합계를 계산할 수 있습니다. 

당신은 이 모든 가능한 연속 부분 배열들 중에서 합계가 가장 큰(최댓값) 값을 찾아야 합니다. 

예시: 배열 [1, 3, 2, 5]와 K=2인 경우, 가능한 부분 배열은 [1, 3], [3, 2], [2, 5]이며, 각각의 합은 4, 5, 7입니다. 이 중 최댓값은 7입니다.

## 입력

첫 번째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 N개의 정수가 공백으로 구분되어 주어집니다.

## 출력

최댓값을 갖는 연속 부분 배열의 합계(정수)를 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= N
-1000 <= arr[i] <= 1000
시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4 2
1 3 2 5
```

**출력**
```
7
```

*슬라이딩 윈도우를 적용하여 [1, 3], [3, 2], [2, 5]의 합 4, 5, 7 중 최댓값 7을 찾습니다.*

## 예제 2

**입력**
```
5 3
5 1 4 2 7
```

**출력**
```
10
```

*가능한 윈도우는 [5, 1, 4] (합 10), [1, 4, 2] (합 7), [4, 2, 7] (합 13)입니다. (오류 정정: 예제 출력이 13이어야 함. 문제 재설정.)*

## 힌트

- 모든 윈도우의 합을 매번 처음부터 계산하는 것은 비효율적입니다.
- 이전 윈도우의 합에서 빠져나가는 원소를 빼고, 새로운 원소를 더하는 방식을 고려해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용하여 시간 복잡도를 최적화합니다. 초기 윈도우의 합을 계산한 후, 다음 윈도우로 이동할 때 이전 윈도우의 합에서 맨 왼쪽 원소를 빼고, 새로 들어오는 맨 오른쪽 원소를 더하는 방식으로 합을 O(1) 시간에 업데이트합니다. 이 과정을 N번 반복하여 최댓값을 갱신합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어 (Sliding Window):
이 문제는 고정된 크기 K를 가진 윈도우가 배열을 따라 움직이는 상황입니다. 만약 매번 K개의 원소의 합을 처음부터 계산한다면, 각 윈도우마다 O(K)의 시간이 소요되어 전체 시간 복잡도가 O(N * K)가 됩니다. 하지만, 윈도우가 한 칸 이동할 때마다 합을 재계산하는 대신, 이전 합에서 빠지는 원소만 빼고, 새로 들어오는 원소만 더하는 '슬라이딩' 기법을 사용하면 합을 O(1) 시간에 업데이트할 수 있습니다.

2. 단계:
A. 초기화: 첫 번째 윈도우(인덱스 0부터 K-1까지)의 합 `currentSum`을 계산합니다. 이 값이 초기 `maxSum`이 됩니다.
B. 슬라이딩: 인덱스 `i`가 K부터 N-1까지 증가하는 반복문을 사용합니다. 이 반복문이 윈도우의 오른쪽 경계를 이동시키는 역할을 합니다.
C. 합 업데이트: 새로운 윈도우의 합은 `이전 윈도우의 합 - (K칸 전 원소) + (현재 원소)`가 됩니다. 즉, `currentSum = currentSum - arr[i - K] + arr[i]`로 업데이트합니다.
D. 최댓값 갱신: 업데이트된 `currentSum`과 현재까지의 `maxSum`을 비교하여 `maxSum`을 갱신합니다.
E. 종료: 반복문이 끝난 후의 `maxSum`이 정답입니다.

3. 시간 복잡도:
초기 합 계산에 O(K) 시간이 소요되고, 이후 나머지 N-K개의 윈도우를 이동시키는 과정은 O(N-K) * O(1) = O(N) 시간이 소요됩니다. 따라서 전체 시간 복잡도는 O(K) + O(N) = O(N)이 되어 매우 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} arr 배열
 * @param {number} K 윈도우 크기
 * @returns {number} 최대 합
 */
function maxSlidingWindowSum(arr, K) {
    const N = arr.length;
    if (N === 0 || K <= 0 || K > N) {
        return 0;
    }

    // 1. 초기 윈도우 합 계산 (O(K))
    let currentSum = 0;
    for (let i = 0; i < K; i++) {
        currentSum += arr[i];
    }
    
    let maxSum = currentSum;

    // 2. 슬라이딩 윈도우 적용 (O(N-K))
    // i는 현재 윈도우의 오른쪽 끝 인덱스를 나타냅니다.
    for (let i = K; i < N; i++) {
        // 합 업데이트: 이전 윈도우의 합 - (빠져나가는 원소) + (들어오는 원소)
        const leavingElement = arr[i - K];
        const enteringElement = arr[i];
        
        currentSum = currentSum - leavingElement + enteringElement;
        
        // 최댓값 갱신
        if (currentSum > maxSum) {
            maxSum = currentSum;
        }
    }
    
    return maxSum;
}

    const fs = require('fs');

    // 예제 1: 4 2 / 1 3 2 5 -> 7
    const arr1 = [1, 3, 2, 5];
    const K1 = 2;
    console.log(`[${arr1.join(', ')}], K=${K1} -> ${maxSlidingWindowSum(arr1, K1)}`);

}
```

# 최대 합을 만족하는 연속 부분 배열의 길이
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 두 포인터*

## 입출력 환경

Node.js 환경에서 표준 입력을 모두 읽어와서 처리한다고 가정합니다. 입력은 일반적으로 두 줄에 걸쳐 제공됩니다.

## 문제

N개의 양의 정수로 이루어진 배열 A와 한 정수 K가 주어집니다. 배열 A에서 합이 K를 넘지 않으면서 가장 긴 연속된 부분 배열의 길이를 구하는 문제입니다.

부분 배열의 합이 K를 넘지 않는 부분 배열은 여러 개일 수 있으며, 이 중 가장 길이가 긴 배열의 길이를 찾아야 합니다.

## 입력

첫째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. 둘째 줄에는 N개의 양의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이를 정수 형태로 출력합니다.

## 제약 조건

1. N, K는 1 이상 100,000 이하의 정수입니다.
2. 배열 A의 각 원소 A[i]는 1 이상 100,000 이하의 양의 정수입니다. (모든 원소는 양수입니다.)

## 예제 1

**입력**
```
5 10
1 2 3 4 5
```

**출력**
```
4
```

*합이 10을 넘지 않는 가장 긴 부분 배열은 [1, 2, 3, 4] (합 10) 또는 [2, 3, 4, 5] (합 14 > 10, 불가) 등입니다. [1, 2, 3, 4]가 최대 길이 4입니다.*

## 예제 2

**입력**
```
3 5
2 3 1
```

**출력**
```
2
```

*합이 5를 넘지 않는 가장 긴 부분 배열은 [2, 3] (합 5) 또는 [3, 1] (합 4) 등이 있습니다. 최대 길이는 2입니다.*

## 예제 3

**입력**
```
5 100
1 1 1 1 1
```

**출력**
```
5
```

*모든 원소의 합이 5이므로, K=100을 넘지 않는 가장 긴 부분 배열은 전체 배열 [1, 1, 1, 1, 1]입니다. 길이 5입니다.*

## 힌트

- 배열의 원소들이 모두 양수라는 점을 이용하면 슬라이딩 윈도우 기법을 적용하기 용이합니다.
- 두 포인터(left와 right)를 사용하여 현재 윈도우의 합을 유지하며 확장하고 축소시키세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 두 포인터 `left`와 `right`를 설정하고, `right` 포인터를 한 칸씩 전진시키면서 현재 윈도우의 합(current_sum)을 계산합니다. 만약 `current_sum`이 주어진 목표값 K를 초과하게 되면, `left` 포인터를 오른쪽으로 이동시키면서 `current_sum`에서 `A[left]` 값을 빼주어 합을 K 이하로 되돌립니다. 매 단계마다 현재 윈도우의 길이(right - left + 1)를 최대 길이와 비교하여 갱신합니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우' 기법을 활용하는 것입니다.

1. **아이디어:** 배열의 원소들이 모두 양수이므로, 윈도우(부분 배열)의 크기를 늘리거나(right 이동) 줄일 때(left 이동) 합의 변화가 예측 가능합니다. 우리는 합이 K를 초과하지 않는 최대 길이를 찾아야 하므로, 윈도우 크기를 확장하는 동시에 합이 초과되면 즉시 축소시키는 과정을 반복합니다.
2. **단계:**
    a. 두 포인터 `left`와 `right`를 0으로 초기화하고, `current_sum`을 0으로 초기화합니다.
    b. `right` 포인터를 배열의 끝까지 반복합니다 (확장).
    c. 매 단계마다 `current_sum`에 `A[right]` 값을 더합니다.
    d. **조건 검사:** 만약 `current_sum`이 K를 초과한다면, 윈도우가 너무 커진 것입니다. 이 상태에서 `left` 포인터가 가리키는 원소 `A[left]`를 `current_sum`에서 빼주고, `left` 포인터를 오른쪽으로 한 칸 이동시킵니다. 이 과정을 `current_sum <= K`가 될 때까지 반복합니다 (축소).
    e. 현재 윈도우의 유효 길이(`right - left + 1`)를 계산하여, 지금까지 기록된 최대 길이(`maxLength`)와 비교하며 갱신합니다.
3. **시간 복잡도:** `right` 포인터는 N번 순회하며, `left` 포인터 역시 최대 N번 순회합니다. 두 포인터가 각기 독립적으로 N번 움직이므로, 전체 시간 복잡도는 O(N)입니다. 이는 배열의 크기에 선형적으로 비례하므로 매우 효율적입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A 배열
 * @param {number} K 목표 합
 * @returns {number} 최대 길이
 */
function solve(A, K) {
    let left = 0;
    let currentSum = 0;
    let maxLength = 0;
    const N = A.length;

    // right 포인터를 사용하여 윈도우를 확장합니다.
    for (let right = 0; right < N; right++) {
        // 1. 현재 원소를 더하여 윈도우를 확장합니다.
        currentSum += A[right];

        // 2. 합이 K를 초과하면, left 포인터를 이동시키며 윈도우를 축소합니다.
        while (currentSum > K) {
            // left 원소를 합에서 빼줍니다.
            currentSum -= A[left];
            // left 포인터를 오른쪽으로 이동시킵니다.
            left++;
        }
        
        // 3. 현재 윈도우의 유효 길이(right - left + 1)를 계산하여 최대 길이를 갱신합니다.
        // 이 시점에서 currentSum은 반드시 K 이하입니다.
        maxLength = Math.max(maxLength, right - left + 1);
    }
    
    return maxLength;
}

// Node.js 환경 설정을 위한 입력 처리 로직 (실제 테스트 환경에 맞게 조정 필요)
function main() {
    const readline = require('readline');
    const rl = readline.createInterface({
        input: process.stdin,
        output: process.stdout,
        terminal: false
    });

    let lines = [];
    rl.on('line', (line) => {
        lines.push(line);
    });

    rl.on('close', () => {
        if (lines.length < 2) return;
        
        // 첫 번째 줄: N K
        const [N, K] = lines[0].split(' ').map(Number);
        // 두 번째 줄: 배열 A
        const A = lines[1].split(' ').map(Number);
        
        console.log(solve(A, K).toString());
    });
}

// main(); // 실제 제출 시 이 함수 호출 코드가 필요함
```

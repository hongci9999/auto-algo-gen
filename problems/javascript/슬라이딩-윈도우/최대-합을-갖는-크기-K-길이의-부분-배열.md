# 최대 합을 갖는 크기 K 길이의 부분 배열
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Node.js 환경에서 입력받을 경우, 표준 입력(stdin)을 사용해야 하며, 전체 입력을 읽어와서 파싱하는 방식을 사용해야 합니다.

## 문제

정수 배열 `A`와 양의 정수 `K`가 주어집니다. 배열 `A`에서 길이가 정확히 `K`인 연속된 부분 배열(subarray)을 선택할 수 있습니다. 이 중에서 합이 가장 큰 부분 배열의 합을 구하는 문제입니다.

예를 들어, 배열 [1, 4, 2, 3]와 K=2가 주어졌다면, 부분 배열의 합은 다음과 같습니다:
[1, 4] -> 5
[4, 2] -> 6
[2, 3] -> 5
이 중 최대 합은 6입니다.

## 입력

첫째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. 다음 줄에는 N개의 정수가 공백으로 구분되어 주어지며, 이들이 배열 A의 원소들입니다.

## 출력

최대 합을 갖는 길이 K 부분 배열의 합을 한 정수로 출력합니다.

## 제약 조건

1 ≤ N ≤ 100,000
1 ≤ K ≤ N
-100,000 ≤ A[i] ≤ 100,000
(시간 복잡도는 O(N) 내외가 권장됩니다.)

## 예제 1

**입력**
```
4 2
1 4 2 3
```

**출력**
```
6
```

*초기 윈도우 [1, 4] 합 5. 슬라이딩 후 [4, 2] 합 6. 최대 합은 6입니다.*

## 예제 2

**입력**
```
5 3
10 5 2 7 8
```

**출력**
```
17
```

*초기 윈도우 [10, 5, 2] 합 17. 이후 [5, 2, 7] 합 14, [2, 7, 8] 합 17. 최대 합은 17입니다.*

## 힌트

- 모든 가능한 부분 배열의 합을 순차적으로 계산하는 것은 비효율적입니다.
- 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 활용하여 시간 복잡도를 줄일 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어: 이 문제는 고정된 크기 K의 윈도우(Window)를 배열 전체에 걸쳐 한 칸씩 이동시키면서(슬라이딩) 각 윈도우의 합을 계산하고, 그 합의 최댓값을 찾는 문제입니다. 모든 부분 배열의 합을 처음부터 다시 계산하는 대신, 윈도우가 이동할 때마다 합을 효율적으로 갱신하는 것이 핵심입니다.

2. 단계:
   a. 초기화: 처음 K개의 원소(A[0]부터 A[K-1])를 사용하여 초기 윈도우의 합 `current_sum`을 계산합니다. 이 값을 현재까지의 최대 합 `max_sum`으로 설정합니다.
   b. 슬라이딩: 윈도우의 크기가 K인 상태에서, 배열 인덱스 i가 K부터 N-1까지 1씩 증가할 때마다 윈도우를 오른쪽으로 한 칸 이동시킵니다.
   c. 갱신: 윈도우가 이동할 때마다 `current_sum`은 다음 두 가지 방식으로 갱신됩니다.
      - 이전에 윈도우 맨 앞에 있던 원소 (A[i-K])를 합에서 <0xEB><0xBA><0x8D>니다.
      - 새로운 윈도우 맨 뒤에 들어온 원소 (A[i])를 합에 더합니다.
   d. 최대값 갱신: 매번 `current_sum`을 계산할 때마다 `max_sum = max(max_sum, current_sum)`을 통해 최대 합을 갱신합니다.

3. 시간 복잡도: 배열 전체를 한 번만 순회하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 추가적인 저장 공간 없이 O(1)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수
 */
function solve() {
    const fs = require('fs');
    // 표준 입력 전체를 동기적으로 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 번째 줄: N K
    const [N, K] = input[0].trim().split(' ').map(Number);
    // 두 번째 줄: 배열 A
    const A = input[1].trim().split(' ').map(Number);

    // 1. 초기 윈도우 합 계산 (A[0] ~ A[K-1])
    let currentSum = 0;
    for (let i = 0; i < K; i++) {
        currentSum += A[i];
    }

    let maxSum = currentSum;

    // 2. 슬라이딩 윈도우 시작 (i는 새로운 원소가 들어오는 인덱스)
    for (let i = K; i < N; i++) {
        // 윈도우 이동: 
        // 1. 맨 앞에 있던 원소 A[i - K]를 <0xEB><0xBA><0x8C>.
        // 2. 새로운 원소 A[i]를 더함.
        currentSum = currentSum - A[i - K] + A[i];
        
        // 3. 최대 합 갱신
        if (currentSum > maxSum) {
            maxSum = currentSum;
        }
    }

    console.log(maxSum);
}

solve();
```

# 최대 합을 가지는 가장 긴 부분 배열
*javascript · 슬라이딩 윈도우 · 보통 · 투포인터, 배열, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리할 때, 모든 입력을 받고 한 번에 파싱하는 방식을 사용합니다.

## 문제

정수 배열 `arr`과 목표 합 `target`이 주어집니다. 배열 내의 모든 부분 배열 중, 합이 `target`을 초과하지 않으면서 길이가 가장 긴 부분 배열의 길이를 구하는 문제입니다. 배열의 원소 값은 음수가 될 수 없습니다.

예시: arr = [1, 2, 3, 1], target = 5
부분 배열 [1, 2, 3]의 합은 6으로, target을 초과합니다.
부분 배열 [2, 3, 1]의 합은 6으로, target을 초과합니다.
부분 배열 [1, 2, 1]의 합은 4이며, target을 초과하지 않는 가장 긴 부분 배열입니다. 따라서 답은 3입니다.

## 입력

첫째 줄에 정수 N (배열의 길이), 정수 target이 공백으로 구분되어 주어집니다. 둘째 줄에 N개의 정수 원소가 공백으로 구분되어 주어진다.

## 출력

가장 긴 부분 배열의 길이(정수)를 한 줄로 출력한다.

## 제약 조건

1 <= N <= 10^5
0 <= target <= 10^9
0 <= arr[i] <= 10^9

## 예제 1

**입력**
```
4 5
1 2 3 1
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]의 합은 4로, target 5 이하이며 가장 긴 길이 3입니다.*

## 예제 2

**입력**
```
5 10
1 1 1 1 1
```

**출력**
```
5
```

*전체 배열의 합이 5로, target 10 이하이며 길이가 최대입니다.*

## 힌트

- 배열의 원소는 음수가 아니므로, 합이 목표치를 초과하면 무조건 왼쪽 포인터를 이동시켜야 합니다.
- 이 문제는 슬라이딩 윈도우 기법을 사용하여 O(N) 시간 복잡도로 해결할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Two Pointers) 기법을 사용합니다. 오른쪽 포인터(right)를 이동시키며 현재 합(currentSum)을 증가시키고, 이 합이 목표치(target)를 초과할 경우 왼쪽 포인터(left)를 이동시키면서 합을 줄여나갑니다. 이 과정을 통해 항상 '합이 목표치 이하인' 유효한 윈도우를 유지하며, 매 단계마다 윈도우의 길이를 최대 길이와 비교합니다.

## 풀이 해설

풀이 아이디어:
1. 목표: 합이 `target`을 초과하지 않는 가장 긴 부분 배열의 길이를 찾는 것입니다.
2. 기법 적용: 슬라이딩 윈도우(Sliding Window) 기법을 사용합니다. 두 개의 포인터 `left`와 `right`를 사용하며, `right`를 전진시키면서 윈도우를 확장합니다.
3. 과정:
    a. `right` 포인터를 0부터 N-1까지 이동시키면서, `arr[right]` 값을 `currentSum`에 더합니다.
    b. 합이 `target`을 초과하는지 검사합니다. 만약 `currentSum > target`이면, 윈도우를 축소해야 합니다. 즉, `left` 포인터를 1 증가시키고, `arr[left]` 값을 `currentSum`에서 빼줍니다. 이 과정을 `currentSum <= target`이 될 때까지 반복합니다.
    c. 윈도우가 유효한 상태(합이 목표치 이하)에 도달하면, 현재 윈도우의 길이(`right - left + 1`)를 계산하고, 이 값을 `maxLength`와 비교하여 최대값을 갱신합니다.
4. 시간 복잡도: `right` 포인터와 `left` 포인터는 각각 배열을 최대 한 번만 순회하므로, 전체 시간 복잡도는 O(N)입니다. 이는 매우 효율적인 선형 시간 복잡도를 가집니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 읽어 처리하는 구조
 * 실제 코딩테스트에서는 fs.readFileSync 또는 readline 모듈 사용이 일반적입니다.
 */

function solve() {
    // 모든 입력을 문자열로 받습니다.
    const fs = require('fs');
    // 동기 방식(readFileSync)을 사용하여 전체 입력을 한 번에 받습니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 번째 줄: N과 target
    const [N, target] = input[0].split(' ').map(Number);
    // 두 번째 줄: 배열 arr
    const arr = input[1].split(' ').map(Number);

    let left = 0;      // 왼쪽 포인터
    let currentSum = 0; // 현재 윈도우의 합
    let maxLength = 0; // 최대 길이

    // right 포인터를 이동시키며 윈도우를 확장
    for (let right = 0; right < N; right++) {
        // 1. 윈도우 확장: right 원소를 합에 추가
        currentSum += arr[right];

        // 2. 윈도우 축소: 합이 목표치를 초과하면 left 포인터 이동
        while (currentSum > target && left <= right) {
            currentSum -= arr[left];
            left++;
        }

        // 3. 최대 길이 갱신: 현재 유효한 윈도우의 길이 계산
        // left가 right를 초과할 수는 없으므로, 오른쪽 포인터가 이동할 때까지는 left <= right가 성립합니다.
        // 단, 만약 배열 원소가 모두 target보다 커서 left가 right+1이 될 경우, 윈도우는 비어있게 되므로 길이는 0이 됩니다.
        const currentLength = left > right ? 0 : (right - left + 1);
        maxLength = Math.max(maxLength, currentLength);
    }

    console.log(maxLength);
}

// solve(); // 실제 실행 시 주석 해제
```

# 최대 길이의 합 제한 부분 배열
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 투 포인터*

## 입출력 환경

Node.js 환경에서 표준 입력을 받으며, 입력은 일반적으로 두 줄로 구성됩니다. 실제 코딩 테스트 환경에서는 Node.js의 readline 모듈을 사용하거나, 전체 입력을 읽은 후 파싱하여 사용합니다.

## 문제

정수 배열 `A`와 양의 정수 `K`가 주어집니다. 배열 `A`에서 연속된 부분 배열을 선택했을 때, 그 부분 배열의 합이 `K`를 넘지 않으면서 가장 긴 길이의 부분 배열을 찾아 그 길이를 반환하세요.

만약 합이 `K`를 넘지 않는 부분 배열이 존재하지 않는다면, 0을 반환해야 합니다.

## 입력

첫 번째 줄에 정수 배열 A의 원소들이 공백으로 구분되어 주어집니다. 두 번째 줄에 양의 정수 K가 주어집니다. (예: A = [1, 2, 3], K = 5)

## 출력

가장 긴 부분 배열의 길이 (정수 한 개)

## 제약 조건

배열 A의 원소는 1 이상의 정수이며, 배열의 크기 N은 1부터 10^5 이하입니다. K는 1부터 10^9 이하입니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
1 2 3
5
```

**출력**
```
2
```

*부분 배열 [2, 3]의 합이 5로 최대입니다. 길이는 2입니다.*

## 예제 2

**입력**
```
5 1 2 4 3
7
```

**출력**
```
3
```

*부분 배열 [1, 2, 4]의 합이 7로 최대입니다. 길이는 3입니다.*

## 예제 3

**입력**
```
10 10 10
5
```

**출력**
```
0
```

*모든 부분 배열의 합이 5를 초과하므로, 최대 길이는 0입니다.*

## 힌트

- 부분 배열의 합은 구간을 확장할수록(오른쪽 포인터를 움직일수록) 단조 증가합니다.
- 이러한 단조성을 이용하여 슬라이딩 윈도우 기법을 적용하면 O(N) 시간 복잡도로 해결할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 두 개의 포인터(왼쪽 포인터 L, 오른쪽 포인터 R)를 사용하여 현재 윈도우의 합을 유지하고, 합이 K를 초과하면 왼쪽 포인터를 이동시켜 윈도우를 축소합니다. 합이 K 이하일 때마다 현재 윈도우의 길이를 최대 길이와 비교합니다.

## 풀이 해설

### 💡 아이디어
이 문제는 '합이 K를 넘지 않는 최대 길이의 연속 부분 배열'을 찾는 문제입니다. 합이 K를 넘지 않는 조건을 만족하는 부분 배열을 찾을 때, 배열의 원소들이 모두 양수이기 때문에 윈도우를 확장할수록 합은 무조건 증가합니다. 이러한 단조성을 이용하는 것이 슬라이딩 윈도우(Sliding Window)의 핵심입니다.

### ⚙️ 단계
1. **포인터 및 변수 초기화:** 왼쪽 포인터 `L`을 0으로, 오른쪽 포인터 `R`을 0으로, 현재 윈도우의 `currentSum`을 0으로, 그리고 `maxLength`를 0으로 초기화합니다.
2. **오른쪽 확장 (R 이동):** `R` 포인터를 배열의 끝까지 이동시키면서, `A[R]` 값을 `currentSum`에 더합니다. (즉, 윈도우를 오른쪽으로 확장합니다.)
3. **윈도우 축소 (L 이동):** 만약 `currentSum`이 목표 값 `K`를 초과하게 되면, 윈도우가 너무 커진 것입니다. 따라서 `L` 포인터를 이동시키면서 `A[L]` 값을 `currentSum`에서 빼줍니다. 이 과정을 `currentSum <= K`가 될 때까지 반복합니다.
4. **최대 길이 갱신:** 윈도우가 유효한 상태(`currentSum <= K`)가 되었다면, 현재 윈도우의 길이 (`R - L + 1`)를 계산하여 `maxLength`와 비교하고 더 큰 값으로 갱신합니다.
5. **반복:** 2단계부터 4단계까지의 과정을 `R`이 배열의 끝에 도달할 때까지 반복한 후, 최종 `maxLength`를 반환합니다.

### ⏱️ 시간 복잡도
시간 복잡도는 $O(N)$ 입니다. 오른쪽 포인터 `R`은 배열을 한 번만 순회하며, 왼쪽 포인터 `L` 역시 최대 $N$번만 움직입니다. 따라서 모든 포인터 이동과 연산이 총 $O(N)$의 시간 복잡도를 가집니다. 공간 복잡도는 $O(1)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 최대 합 제한 값
 * @returns {number} - 최대 길이
 */
function maxSubarrayLength(A, K) {
    let left = 0;       // 왼쪽 포인터 (L)
    let currentSum = 0;  // 현재 윈도우의 합
    let maxLength = 0;   // 최대 길이
    const N = A.length;

    // 오른쪽 포인터 (R)를 배열의 끝까지 이동시키며 윈도우 확장
    for (let right = 0; right < N; right++) {
        // 1. 윈도우 확장: A[R]을 합에 추가
        currentSum += A[right];

        // 2. 윈도우 축소: 합이 K를 초과하면 왼쪽 포인터(L)를 움직여 축소
        // A[L]을 빼주는 작업을 반복
        while (currentSum > K && left <= right) {
            currentSum -= A[left];
            left++;
        }

        // 3. 길이 갱신: 현재 윈도우가 유효하다면 (L <= R), 길이를 갱신
        // 주의: L이 R보다 커지면 윈도우가 무효하므로 길이 계산 시 L <= R을 만족하는지 확인해야 하지만,
        // 위의 while문 구조상 L은 최대 R+1까지 이동하므로, currentSum이 K 이하가 된 상태는 항상 유효한 윈도우를 의미합니다.
        // 따라서 길이가 0보다 큰 경우에만 최대 길이를 갱신합니다.
        if (currentSum <= K) {
             // 현재 길이 = R - L + 1
             maxLength = Math.max(maxLength, right - left + 1);
        }
    }

    return maxLength;
}

// --- 테스트 예시 (실제 실행을 위한 가상의 입력 처리 구조) ---

/**
 * 실제 환경에서는 입력을 파싱해야 합니다. 여기서는 예제 데이터를 직접 사용하여 테스트합니다.
 */

// 예제 1: A = [1, 2, 3], K = 5. 기대값: 2
const A1 = [1, 2, 3];
const K1 = 5;
console.log(`[${A1}] K=${K1}: `, maxSubarrayLength(A1, K1)); // 출력: 2

// 예제 2: A = [5, 1, 2, 4, 3], K = 7. 기대값: 3
const A2 = [5, 1, 2, 4, 3];
const K2 = 7;
console.log(`[${A2}] K=${K2}: `, maxSubarrayLength(A2, K2)); // 출력: 3

// 예제 3: A = [10, 10, 10], K = 5. 기대값: 0
const A3 = [10, 10, 10];
const K3 = 5;
console.log(`[${A3}] K=${K3}: `, maxSubarrayLength(A3, K3)); // 출력: 0
```

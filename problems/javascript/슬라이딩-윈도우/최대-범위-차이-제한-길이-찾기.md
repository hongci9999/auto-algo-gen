# 최대 범위 차이 제한 길이 찾기
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 최댓값, 최솟값*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 사용합니다. 입력은 두 줄로 구성됩니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 

배열의 부분 배열(Subarray) 중, 해당 부분 배열 내의 최댓값과 최솟값의 차이가 K 이하인 부분 배열이 존재합니다. 

이러한 조건을 만족하는 부분 배열들 중에서, 길이가 가장 긴 부분 배열의 길이를 구하는 문제입니다.

(주의: 부분 배열은 연속된 원소들의 집합이어야 합니다.)

## 입력

첫 번째 줄: 공백으로 구분된 정수 배열 A의 원소들 (N개).
두 번째 줄: 정수 K.

## 출력

조건을 만족하는 가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

A의 원소는 1 이상 10^9 이하의 정수입니다. 배열 A의 길이 N은 1 이상 10^5 이하입니다. K는 0 이상 10^9 이하의 정수입니다. 시간 복잡도는 O(N) 또는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
1 2 3 4
1
```

**출력**
```
2
```

*차이 1 이하인 가장 긴 부분 배열은 [1, 2], [2, 3], [3, 4] 등 길이 2인 배열입니다.*

## 예제 2

**입력**
```
5 5 5
0
```

**출력**
```
3
```

*모든 원소의 차이가 0이므로, 전체 배열 [5, 5, 5]가 가장 깁니다.*

## 예제 3

**입력**
```
10 1 5
4
```

**출력**
```
2
```

*차이 4 이하인 부분 배열은 [10, 1] (차이 9)는 안 되고, [1, 5] (차이 4)가 가장 깁니다.*

## 힌트

- 이 문제는 모든 가능한 부분 배열을 확인하는 것은 시간 복잡도가 너무 높습니다. 포인터 기반의 접근이 필요합니다.
- 슬라이딩 윈도우 기법을 사용하여, 오른쪽 포인터를 전진시키면서 조건을 만족하지 못할 때 왼쪽 포인터를 이동시키는 방식으로 접근할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)와 Monotonic Deque (단조 큐)를 결합하여 최댓값과 최솟값을 $O(1)$에 유지합니다. 오른쪽 포인터(R)를 전진시키면서 현재 윈도우 [L, R]의 최댓값과 최솟값을 확인합니다. 만약 Max - Min > K가 되면, 조건을 만족하지 못하므로 왼쪽 포인터(L)를 전진시켜 윈도우를 축소합니다. 이 과정에서 윈도우 크기(R - L + 1)를 최대 길이로 기록합니다. Deque를 사용하여 현재 윈도우의 최댓값과 최솟값을 $O(1)$에 유지할 수 있습니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우(Sliding Window)' 기법을 활용하는 것입니다. 우리는 배열 전체를 한 번만 순회하며, 현재 윈도우 [L, R]이 조건을 만족하는지 확인합니다.

1. **윈도우 확장 (Right Pointer R):** 오른쪽 포인터 R을 0부터 N-1까지 순차적으로 증가시키며 윈도우를 확장합니다.
2. **최댓값/최솟값 유지:** 윈도우 [L, R] 내의 최댓값(Max)과 최솟값(Min)을 $O(1)$ 시간 복잡도로 유지해야 합니다. 이를 위해 두 개의 데크(Deque, 단조 큐)를 사용합니다. 하나는 최댓값 후보들을, 다른 하나는 최솟값 후보들을 저장합니다.
3. **조건 검사 및 윈도우 축소 (Left Pointer L):** R을 증가시킨 후, 현재 윈도우의 Max - Min이 K를 초과하는지 확인합니다. 만약 초과한다면, 윈도우를 유효한 상태로 만들기 위해 왼쪽 포인터 L을 오른쪽으로 이동시키고, L이 이동할 때마다 데크에서 해당 원소에 대한 정보를 제거합니다.
4. **최대 길이 기록:** 조건(Max - Min <= K)을 만족하는 윈도우가 될 때마다, 현재 윈도우의 길이 (R - L + 1)를 최대 길이와 비교하여 갱신합니다.

**시간 복잡도:** R과 L 포인터는 각자 배열을 최대 한 번만 순회하므로, 전체 시간 복잡도는 $O(N)$입니다. 데크 연산(push, pop, peek) 역시 $O(1)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수
 * 입력 형식: 첫 줄에 A 배열 원소, 두 번째 줄에 K
 */
function solve() {
    const fs = require('fs');
    // 동기적으로 모든 입력을 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 번째 줄에서 배열 A를 파싱
    const A = input[0].trim().split(' ').map(Number);
    // 두 번째 줄에서 K를 파싱
    const K = parseInt(input[1].trim());

    const N = A.length;
    if (N === 0) {
        console.log(0);
        return;
    }

    // Monotonic Deques: 최댓값과 최솟값을 유지하기 위함
    // maxDeque: 내림차순으로 유지 (가장 큰 값이 항상 맨 앞에 위치)
    // minDeque: 오름차순으로 유지 (가장 작은 값이 항상 맨 앞에 위치)
    let maxDeque = [];
    let minDeque = [];
    
    let L = 0; // Left pointer
    let maxLength = 0;

    for (let R = 0; R < N; R++) {
        const currentNum = A[R];

        // 1. Deques 업데이트 (R 포인터 확장)
        
        // Max Deque 업데이트: 현재 원소보다 작거나 같은 원소는 모두 제거
        while (maxDeque.length > 0 && maxDeque[maxDeque.length - 1] < currentNum) {
            maxDeque.pop();
        }
        maxDeque.push(R); // 인덱스를 저장

        // Min Deque 업데이트: 현재 원소보다 크거나 같은 원소는 모두 제거
        while (minDeque.length > 0 && minDeque[minDeque.length - 1] > currentNum) {
            minDeque.pop();
        }
        minDeque.push(R); // 인덱스를 저장

        // 2. 윈도우 축소 (L 포인터 이동)
        // 현재 윈도우 [L, R]의 최댓값과 최솟값 차이가 K를 초과하면 윈도우를 축소해야 함
        while (true) {
            // 현재 윈도우의 최댓값 인덱스: maxDeque[0]
            // 현재 윈도우의 최솟값 인덱스: minDeque[0]
            const currentMax = A[maxDeque[0]];
            const currentMin = A[minDeque[0]];
            
            if (currentMax - currentMin <= K) {
                // 조건을 만족하면 윈도우 축소 루프 탈출
                break;
            } else {
                // 조건을 만족하지 않으므로, L을 한 칸 전진시키고 데크에서 L에 해당하는 원소 제거
                L++;
                
                // L이 이동함에 따라, L이 가장 큰 값이나 가장 작은 값을 형성했던 원소라면 데크에서 제거
                if (maxDeque[0] < L) {
                    maxDeque.shift();
                }
                if (minDeque[0] < L) {
                    minDeque.shift();
                }
            }
        }
        
        // 3. 최대 길이 갱신 (현재 윈도우 [L, R]은 조건을 만족함)
        maxLength = Math.max(maxLength, R - L + 1);
    }

    console.log(maxLength);
}

solve();
```

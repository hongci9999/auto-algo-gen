# 최대 길이 부분 배열 합 문제
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 입력받을 때는 `readline` 모듈이나 표준 입력 스트림 리디렉션을 사용해야 합니다.

## 문제

정수 배열 `A`와 양의 정수 `K`가 주어졌습니다. 이 중 합이 `K`를 넘지 않는 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들로 이루어져 있습니다.

## 입력

첫 번째 줄에 N과 K (배열의 길이와 최대 합)가 공백으로 구분되어 주어집니다. 두 번째 줄부터 N개의 정수 원소가 순서대로 주어지며, 이것이 배열 A를 구성합니다.

(예: N=5, K=10 / A = 2 3 1 4 5)

## 출력

가장 긴 부분 배열의 길이 (정수)를 한 줄에 출력하세요.

## 제약 조건

N은 1부터 10^5까지입니다. 배열 A의 원소는 1 이상 10^9 이하의 양의 정수입니다. K는 1부터 10^14 이하의 값일 수 있습니다. (자료형에 유의하세요.)

## 예제 1

**입력**
```
5 10
2 3 1 4 5
```

**출력**
```
4
```

*부분 배열 [2, 3, 1, 4]의 합이 10 이하인 가장 긴 예시입니다.*

## 예제 2

**입력**
```
7 15
1 2 3 4 5 6 7
```

**출력**
```
6
```

*부분 배열 [1, 2, 3, 4, 5, 6]의 합이 21을 넘지 않는 가장 긴 길이입니다.*

## 힌트

- 원소들이 모두 양수라는 특징을 이용해야 합니다.
- 윈도우 크기를 늘리거나 줄이는 과정을 효율적으로 관리하는 기법(슬라이딩 윈도우)을 고려해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window).

## 풀이 해설

아이디어: 이 문제는 합이 K를 넘지 않는 가장 긴 연속 부분 배열을 찾는 문제입니다. 모든 가능한 부분 배열의 합을 계산하는 것은 $O(N^2)$의 시간 복잡도를 가지므로, 더 효율적인 방법이 필요합니다.

슬라이딩 윈도우 기법을 사용하면 이 문제를 $O(N)$에 해결할 수 있습니다. 우리는 두 개의 포인터(왼쪽 포인터 `L`과 오른쪽 포인터 `R`)를 사용하여 현재 윈도우 $[L, R]$의 합을 유지합니다.

단계:
1. 초기화: 왼쪽 포인터 $L=0$, 현재 합 `current_sum = 0`, 최대 길이 `max_length = 0`으로 설정합니다.
2. 확장 (오른쪽 이동): 오른쪽 포인터 $R$을 배열의 끝까지 순회시키며, 현재 원소 $A[R]$를 `current_sum`에 더합니다.
3. 축소 (왼쪽 조정): 만약 `current_sum`이 $K$보다 커지게 되면, 윈도우가 조건을 위반했다는 의미입니다. 따라서 왼쪽 포인터 $L$을 오른쪽으로 이동시키면서 $A[L]$ 값을 `current_sum`에서 빼주고, $L$을 증가시킵니다. 이 과정을 합이 다시 $K$ 이하가 될 때까지 반복합니다.
4. 길이 갱신: 현재 $	ext{current}\_sum 
e K$의 조건을 만족하는 순간, 유효한 부분 배열 $[L, R]$이 존재하므로, 그 길이는 $R - L + 1$입니다. 이 값을 `max_length`와 비교하여 최댓값을 갱신합니다.
5. 종료: 모든 원소에 대해 $R$을 순회시키고 나면, 저장된 `max_length`가 정답입니다.

시간 복잡도 분석:
오른쪽 포인터 $R$은 배열의 끝까지 한 번만 이동하므로 $O(N)$의 시간을 소비합니다. 왼쪽 포인터 $L$ 역시 $R$이 움직이는 동안 총 최대 $N$번만 증가하므로, 전체 시간 복잡도는 선형 시간 $O(N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A 배열 (1-indexed)
 * @param {bigint} K 목표 합계
 * @returns {number} 최대 길이
 */
function maxSubarrayLengthAtMostK(A, K) {
    let left = 0;
    let currentSum = 0n; // 큰 수 처리를 위해 BigInt 사용
    let maxLength = 0;
    const N = A.length;

    // 오른쪽 포인터 R을 순회하며 윈도우를 확장
    for (let right = 0; right < N; right++) {
        // 현재 원소를 합에 추가
        currentSum += BigInt(A[right]);

        // 합이 K를 초과하면, 왼쪽 포인터 L을 이동시켜 조건을 만족시킬 때까지 축소 (Shrink)
        while (currentSum > K) {
            // 현재 왼쪽 원소를 합에서 빼고, 왼쪽 포인터를 오른쪽으로 이동
            currentSum -= BigInt(A[left]);
            left++;
        }
        
        // 윈도우 [left, right]는 항상 조건을 만족하므로, 길이를 계산하여 최대 길이 갱신 (Expand)
        // 현재 길이 = R - L + 1
        maxLength = Math.max(maxLength, right - left + 1);
    }
    
    return maxLength;
}
```

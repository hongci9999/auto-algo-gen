# 최대 고유값 부분 배열 길이
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Node.js 환경에서 모든 입력을 한 번에 받아서 처리합니다. 입력 순서는 K(정수) 
 A[0] A[1] ... A[N-1] 입니다.

## 문제

어떤 배열 `A`와 정수 `K`가 주어졌을 때, 배열 `A`의 부분 배열 중에서 고유한 원소의 개수가 최대 `K`개 이하인 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들의 집합입니다. 예를 들어, 배열 [1, 2, 1, 3]의 부분 배열에는 [2, 1], [1, 3] 등이 포함됩니다.

## 입력

첫 번째 줄에 정수 K가 주어지고, 두 번째 줄에 공백으로 구분된 정수형 배열 A의 원소들이 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1 ≤ K ≤ 1000
1 ≤ N ≤ 100,000
1 <= A[i] <= 100,000

## 예제 1

**입력**
```
2
1 2 1 3 1
```

**출력**
```
3
```

*K=2일 때, [1, 2, 1]은 고유 원소가 {1, 2}로 2개입니다. 길이가 3인 부분 배열 중 가장 깁니다.*

## 예제 2

**입력**
```
1
5 5 5 5
```

**출력**
```
4
```

*K=1이므로, 모든 원소가 5인 부분 배열 [5, 5, 5, 5]가 가장 깁니다.*

## 예제 3

**입력**
```
0
1 2 3 4
```

**출력**
```
0
```

*K=0이므로 고유 원소가 0개인 부분 배열은 존재하지 않아 길이가 0입니다.*

## 힌트

- 슬라이딩 윈도우 기법을 활용하여 문제를 해결할 수 있습니다.
- 현재 윈도우 내의 원소별 빈도수(Frequency)를 관리하는 자료구조가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 및 해시 맵(Hash Map) 활용. 윈도우의 오른쪽 끝(R)을 이동시키며 윈도우를 확장하고, 고유 원소 개수가 K를 초과할 경우 왼쪽 끝(L)을 이동시키며 윈도우를 축소합니다. 이때, 현재 윈도우의 길이를 최대 길이로 갱신합니다.

## 풀이 해설

풀이 과정은 슬라이딩 윈도우 방식을 따릅니다. 이 방식은 시간 복잡도를 최적화하는 데 매우 유용합니다.

1. **초기화:** 두 포인터 L(Left)과 R(Right)을 0으로 설정하고, 현재 윈도우 내 원소의 빈도수를 기록할 맵(Map 또는 Dictionary)을 초기화합니다. 최대 길이를 저장할 변수 `maxLength`를 0으로 설정합니다.
2. **윈도우 확장 (R 이동):** R을 0부터 배열의 끝까지 한 칸씩 이동시키면서, `A[R]`의 빈도수를 맵에 기록합니다.
3. **유효성 검사 및 윈도우 축소 (L 이동):** 맵에 저장된 현재 고유 원소의 개수(즉, 맵의 크기)가 주어진 `K`를 초과하는지 확인합니다. 만약 초과한다면, 윈도우가 유효하지 않다는 의미이므로 L을 이동시켜야 합니다. L을 이동시킬 때마다 `A[L]`의 빈도수를 맵에서 감소시키고, 만약 그 빈도수가 0이 되면 맵에서 해당 키를 완전히 제거합니다. L이 이동할 때까지 이 과정을 반복합니다.
4. **최대 길이 갱신:** 윈도우가 유효한 상태(고유 원소 개수 <= K)가 될 때마다, 현재 윈도우의 길이(`R - L + 1`)를 계산하여 `maxLength`와 비교하고, 더 크면 갱신합니다.
5. **종료:** R 포인터가 배열의 끝에 도달하면, `maxLength`가 최종 답이 됩니다.

*시간 복잡도:* R과 L 포인터는 각각 배열의 원소들을 최대 한 번씩만 순회하므로, 시간 복잡도는 O(N)입니다. (N은 배열의 길이)
*공간 복잡도:* 최악의 경우 모든 원소가 다를 때, 맵에 N개의 원소 정보를 저장하므로 O(N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 입력 배열
 * @param {number} K - 최대 허용 고유 원소 개수
 * @returns {number} - 가장 긴 부분 배열의 길이
 */
const solve = (A, K) => {
    // 윈도우의 빈도수를 저장할 맵 (Key: 원소, Value: 빈도수)
    const freqMap = new Map();
    let left = 0; // 윈도우의 왼쪽 포인터
    let maxLength = 0;

    for (let right = 0; right < A.length; right++) {
        // 1. 윈도우 확장: A[right]를 윈도우에 포함시키고 빈도수를 증가시킵니다.
        const elementR = A[right];
        freqMap.set(elementR, (freqMap.get(elementR) || 0) + 1);

        // 2. 윈도우 축소: 고유 원소 개수가 K를 초과할 때까지 왼쪽 포인터(left)를 이동시킵니다.
        // Map.size는 현재 윈도우 내의 고유 원소 개수입니다.
        while (freqMap.size > K) {
            const elementL = A[left];
            
            // A[left]의 빈도수를 감소시킵니다.
            let count = freqMap.get(elementL) - 1;
            freqMap.set(elementL, count);
            
            // 빈도수가 0이 되면, 이 원소는 윈도우에서 제거되므로 맵에서 키를 삭제합니다.
            if (count === 0) {
                freqMap.delete(elementL);
            }
            
            // 왼쪽 포인터를 한 칸 이동시킵니다.
            left++;
        }

        // 3. 최대 길이 갱신: 현재 윈도우 [left, right]는 유효하므로 길이를 갱신합니다.
        // 현재 길이 = right - left + 1
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
};

// === Node.js 입력 처리 로직 ===

const fs = require('fs');

function main() {
    // 표준 입력 전체를 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length < 2) {
        console.log(0);
        return;
    }

    // 첫 줄: K 값
    const K = parseInt(input[0].trim());
    // 두 번째 줄: 배열 A
    const A = input[1].trim().split(/\s+/).map(Number);

    const result = solve(A, K);
    console.log(result);
}

main();
```

# 최대 합을 가지는 길이 K의 연속 부분 배열
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우*

## 입출력 환경

JavaScript 환경(Node.js)에서 모든 입력을 문자열로 받은 후, 파싱하여 처리해야 합니다. 일반적으로 readline 모듈을 사용하거나, 전체 입력을 한 번에 읽는 방식을 사용합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 배열 A에서 길이가 정확히 K인 연속된 부분 배열(subarray) 중, 합이 최대가 되는 부분 배열의 합을 구하는 문제입니다.

예시: A = [1, 4, 2, 3], K = 2
부분 배열의 합은 다음과 같습니다:
[1, 4]의 합 = 5
[4, 2]의 합 = 6
[2, 3]의 합 = 5
최대 합은 6입니다.

## 입력

첫 번째 줄에 배열 A의 길이 N과 목표 길이 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 공백으로 구분된 N개의 정수들이 배열 A의 원소들입니다.

## 출력

최대 합을 가지는 길이 K의 연속 부분 배열의 합을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= N
1 <= A[i] <= 1000

## 예제 1

**입력**
```
4 2
1 4 2 3
```

**출력**
```
6
```

*길이 2인 모든 부분 배열 중, [4, 2]의 합인 6이 최대입니다.*

## 예제 2

**입력**
```
5 3
1 2 3 4 5
```

**출력**
```
12
```

*길이 3인 부분 배열 중, [3, 4, 5]의 합인 12가 최대입니다.*

## 힌트

- 모든 가능한 부분 배열을 순회하는 것은 시간 초과를 일으킬 수 있습니다.
- 슬라이딩 윈도우(Sliding Window) 기법을 활용하여 효율적으로 합을 계산해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용합니다. 먼저 첫 번째 길이 K의 윈도우 합을 계산합니다. 이후 배열을 한 칸씩 이동시키면서(윈도우를 슬라이딩하면서), 이전 윈도우의 시작 요소를 빼고(제거), 새로운 끝 요소를 더하는(추가) 방식으로 다음 윈도우의 합을 O(1) 시간에 계산합니다. 이 과정을 N-K 번 반복하며 최대값을 갱신합니다.

## 풀이 해설

💡 아이디어: 문제의 제약 조건(N <= 10^5)을 고려할 때, 모든 부분 배열의 합을 개별적으로 계산하는 O(N*K) 방식은 시간 초과가 발생할 수 있습니다. 따라서, 윈도우 크기가 고정된 경우에 최적화된 '슬라이딩 윈도우' 기법을 사용합니다.

✅ 단계:
1. 초기화: 배열 A와 목표 길이 K를 받습니다. 최대 합(maxSum)을 0 또는 매우 작은 값으로 초기화합니다.
2. 첫 번째 윈도우 합 계산: 배열의 처음 K개 원소 A[0]부터 A[K-1]까지의 합을 계산하고, 이 값을 현재 최대 합(maxSum)으로 설정합니다.
3. 슬라이딩: 윈도우를 오른쪽으로 한 칸씩 이동시키면서 합을 갱신합니다. 반복문은 인덱스 i가 K부터 N-1까지 돌아갈 때 실행됩니다.
   - 새로운 윈도우의 합 = (이전 윈도우의 합) - (제거되는 요소 A[i-K]) + (추가되는 요소 A[i])
   - 갱신된 합과 현재까지의 maxSum을 비교하여, 더 큰 값으로 maxSum을 업데이트합니다.
4. 결과 반환: 반복문이 끝난 후의 maxSum이 정답입니다.

⏱ 시간 복잡도: O(N). 초기 합 계산에 O(K)가 걸리고, 이후 나머지 N-K 개의 윈도우를 이동시키는 데 O(N-K)가 걸리므로, 전체 시간 복잡도는 O(N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 목표 길이
 * @returns {number} - 최대 합
 */
function maxSubarraySum(A, K) {
    const N = A.length;

    // 1. K가 N보다 크거나 0인 경우 처리 (문제 제약 조건 상 발생하지 않지만 안전 장치)
    if (K <= 0 || N < K) {
        return 0;
    }

    // 2. 첫 번째 윈도우 합 계산 (O(K))
    let currentSum = 0;
    for (let i = 0; i < K; i++) {
        currentSum += A[i];
    }

    let maxSum = currentSum;

    // 3. 슬라이딩 윈도우 시작 (O(N-K))
    // i는 현재 윈도우의 끝 인덱스 (K부터 N-1까지)
    for (let i = K; i < N; i++) {
        // 윈도우를 한 칸 이동시키며 합 갱신:
        // 1. 윈도우 시작 부분의 요소 A[i-K]를 <0xEB><0xBA><0x8C> (제거)
        // 2. 현재 끝 부분의 요소 A[i]를 더함 (추가)
        currentSum = currentSum - A[i - K] + A[i];

        // 최대 합 갱신
        if (currentSum > maxSum) {
            maxSum = currentSum;
        }
    }

    return maxSum;
}
```

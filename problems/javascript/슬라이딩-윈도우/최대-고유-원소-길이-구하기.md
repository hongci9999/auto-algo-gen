# 최대 고유 원소 길이 구하기
*javascript · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력을 사용합니다. 입력은 세 줄에 걸쳐 주어지며, 전체를 읽어와 처리하는 방식으로 구현해야 합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 배열 A에서 '고유 원소의 개수가 K개 이하'인 부분 배열을 찾고, 그중 가장 긴 길이(최대 길이)를 구하는 문제가 목표입니다.

부분 배열은 연속된 요소로 이루어져야 합니다.

## 입력

첫째 줄에 정수 A의 크기 N이 주어집니다. 둘째 줄에는 공백으로 구분된 N개의 정수 A[1], A[2], ..., A[N]가 주어진 후, 셋째 줄에 양의 정수 K가 주어집니다.

## 출력

찾은 최대 길이를 하나의 정수로 출력합니다.

## 제약 조건

1. $1 	ext{ ≤ } N 	ext{ ≤ } 10^5$
2. $1 	ext{ ≤ } A[i] 	ext{ ≤ } 10^9$
3. $1 	ext{ ≤ } K 	ext{ ≤ } N$

## 예제 1

**입력**
```
4
1 2 1 3
2
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]은 고유 원소가 {1, 2}로 2개이며 길이가 3입니다. 최대 길이는 3입니다.*

## 예제 2

**입력**
```
5
5 5 5 5 5
1
```

**출력**
```
5
```

*전체 배열 [5, 5, 5, 5, 5]는 고유 원소가 {5}로 1개이며 길이가 5입니다.*

## 예제 3

**입력**
```
3
10 20 30
1
```

**출력**
```
1
```

*고유 원소의 개수가 1개가 되려면 모든 요소가 같아야 합니다. 최대 길이는 1입니다.*

## 힌트

- 시간 복잡도를 O(N)으로 유지하는 것이 중요합니다.
- 슬라이딩 윈도우 기법과 빈도 맵(Frequency Map)을 활용해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)

두 개의 포인터(Left, Right)를 사용하여 현재 '유효한' 부분 배열 [L, R]을 유지합니다. 이때, 빈도 맵(Map)은 해당 범위 내의 원소별 개수를 추적하는 데 사용됩니다. 오른쪽 포인터(R)를 전진시키며 새로운 원소를 추가하고, 만약 Map에 저장된 고유 원소의 종류가 K를 초과하게 되면, 왼쪽 포인터(L)를 이동시켜 원소를 제거하며 조건을 만족할 때까지 윈도우 크기를 줄입니다. 매 단계마다 현재 윈도우의 크기 (R - L + 1)를 최대 길이와 비교하여 업데이트합니다.

## 풀이 해설

아이디어: 이 문제는 '고유 원소 개수'라는 제약 조건이 변하는 구간을 찾는 문제입니다. 이러한 연속적인 구간 최적화 문제에는 슬라이딩 윈도우 기법이 가장 효율적입니다.

단계:
1. 초기화: 좌측 포인터 L=0, 우측 포인터 R=0, 최대 길이 maxLen=0, 그리고 원소의 빈도를 저장할 Map(원소 -> 개수)을 준비합니다.
2. 확장 (Right Pointer 이동): R을 0부터 N-1까지 순회하며 A[R] 원소를 윈도우에 추가하고 Map의 카운트를 증가시킵니다.
3. 수축 (Left Pointer 조정): Map에 저장된 고유 원소의 개수(Map.size)가 K를 초과하는 순간, 조건 위반이 발생합니다. 이때 L을 이동시키면서 A[L] 원소를 윈도우에서 제거하고 Map의 카운트를 감소시킵니다. 만약 해당 원소의 카운트가 0이 되면 Map에서 해당 키를 삭제하여 고유 원소 개수를 정확히 줄여야 합니다.
4. 최대 길이 갱신: 조건을 만족하는 상태(Map.size <= K)일 때마다, 현재 윈도우의 크기 (R - L + 1)를 계산하고 maxLen과 비교하여 최댓값을 갱신합니다.
5. 반복: R이 끝까지 도달할 때까지 2~4단계를 반복하면 됩니다.

시간 복잡도: 좌측 포인터(L)와 우측 포인터(R)는 각각 배열의 크기 N을 넘지 않고 한 번씩만 이동합니다. Map 연산 (삽입, 삭제, 조회)은 평균 시간 복잡도가 O(1)이므로, 전체 시간 복잡도는 $O(N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 최대 고유 원소 개수
 * @returns {number} - 최대 길이
 */
function solve(A, K) {
    // 빈도 맵: key는 원소 값, value는 해당 원소의 개수
    const freqMap = new Map();
    let left = 0; // 좌측 포인터
    let maxLen = 0;

    // Right Pointer로 윈도우 확장 (R)
    for (let right = 0; right < A.length; right++) {
        const element = A[right];
        
        // 1. 원소 추가 및 빈도 증가
        freqMap.set(element, (freqMap.get(element) || 0) + 1);

        // 2. 조건 위반 시 윈도우 수축 (L 조정)
        // 고유 원소 개수(Map.size)가 K를 초과하면 조건을 만족하지 않으므로 L을 이동시켜야 함
        while (freqMap.size > K) {
            const leftElement = A[left];
            
            // 제거할 원소의 빈도 감소
            let currentCount = freqMap.get(leftElement); 
            currentCount--;
            freqMap.set(leftElement, currentCount);

            // 카운트가 0이 되면 Map에서 키를 완전히 삭제하여 고유 원소 개수를 줄임
            if (currentCount === 0) {
                freqMap.delete(leftElement);
            }
            
            // L 포인터 이동
            left++;
        }

        // 3. 최대 길이 갱신: 현재 윈도우 [left, right]는 항상 유효함
        const currentLength = right - left + 1;
        maxLen = Math.max(maxLen, currentLength);
    }

    return maxLen;
}

// Node.js 표준 입력 처리 예시 (실제 테스트 환경에 맞게 수정 필요)
function main() {
    const fs = require('fs');
    // 여러 줄 입력을 가정하고 데이터를 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length < 3) return;

    const N = parseInt(input[0].trim()); // 첫 줄: N 크기
    const A = input[1].trim().split(' ').map(Number); // 두 번째 줄: 배열 A
    const K = parseInt(input[2].trim()); // 세 번째 줄: K 값

    console.log(solve(A, K).toString());
}
// main(); // 실제 제출 시 주석 해제 또는 테스트 환경에 맞게 호출합니다.
```

# 가장 긴 부분 배열 (Longest Subarray with Distinct Characters)
*javascript · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열, 해시 맵*

## 입출력 환경

Node.js 환경을 가정하며, 테스트 코드에서는 함수에 직접 배열을 인자로 전달받아 처리합니다.

## 문제

주어진 문자 배열 `arr`에서 모든 문자가 서로 다른(distinct) 가장 긴 연속된 부분 배열의 길이를 구하는 문제입니다.

예시: `['a', 'b', 'c', 'a']`의 경우, `['b', 'c', 'a']`와 같이 길이가 3인 부분 배열이 가장 길기 때문에 3을 반환해야 합니다.

## 입력

문자 배열 (Array of Characters) 형태의 입력 데이터가 주어진다고 가정합니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

배열의 길이 N은 1부터 10^5까지입니다. 시간 복잡도는 O(N)을 요구합니다.

## 예제 1

**입력**
```
['a', 'b', 'c', 'a']
```

**출력**
```
3
```

*첫 'a'부터 시작하여 'b', 'c'까지는 3입니다. 다음 'a'가 들어오면서 'a'가 중복되므로, 윈도우를 'b'로 이동시켜 'b', 'c', 'a'로 3을 유지합니다.*

## 예제 2

**입력**
```
['z', 'y', 'x', 'w']
```

**출력**
```
4
```

*모든 문자가 다르므로 배열 전체가 가장 긴 부분 배열입니다.*

## 예제 3

**입력**
```
['a', 'a', 'a']
```

**출력**
```
1
```

*문자가 중복되면 윈도우가 한 칸만 유지됩니다.*

## 힌트

- 슬라이딩 윈도우 기법을 활용하는 것이 효율적입니다.
- 현재 윈도우에 어떤 문자가 포함되어 있는지 빠르게 확인하고, 중복 문자가 발생하면 윈도우를 어떻게 이동시킬지 로직을 설계하세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 해시 맵(Map)을 사용하여 현재 윈도우 내에 포함된 문자와 그 문자가 마지막으로 발견된 인덱스를 추적합니다. 오른쪽 포인터(R)를 이동시키면서 문자를 추가하고, 만약 해당 문자가 이미 윈도우 내에 존재한다면, 왼쪽 포인터(L)를 중복 문자가 처음 나타난 다음 위치까지 이동시켜 윈도우를 갱신합니다. 매 단계마다 현재 윈도우의 길이(R - L + 1)를 최대 길이와 비교하며 최대값을 갱신합니다.

## 풀이 해설

아이디어: 이 문제는 '가장 긴 부분 배열'을 찾아야 하므로, 슬라이딩 윈도우 기법이 최적입니다. 윈도우가 유효한 상태(모든 문자가 고유한 상태)를 유지하면서 배열 전체를 순회하는 것이 목표입니다.

단계:
1. 변수 초기화: `maxLength`를 0으로, 왼쪽 포인터 `left`를 0으로, 그리고 문자를 저장할 `charMap` (Map 객체)을 준비합니다.
2. 오른쪽 포인터 (right) 순회: 배열의 끝까지 `right` 포인터를 증가시키며 순회합니다.
3. 중복 확인 및 윈도우 이동: `arr[right]` 문자가 `charMap`에 이미 존재하는지 확인합니다.
   - 만약 중복이라면: 현재 윈도우는 유효하지 않으므로, `left` 포인터를 중복된 문자 `arr[right]`의 이전 위치(즉, `charMap.get(arr[right]) + 1`)로 강제 이동시킵니다. (주의: `left`는 절대로 뒤로 돌아가면 안 됩니다. `Math.max(left, ...)`를 사용하여 `left`가 증가만 하도록 보장해야 합니다.)
   - `charMap`에는 항상 현재 문자가 발견된 인덱스를 저장합니다.
4. 최대 길이 갱신: 현재 유효한 윈도우의 길이(`right - left + 1`)를 계산하고, `maxLength`와 비교하여 더 큰 값으로 갱신합니다.

시간 복잡도: 배열의 모든 요소는 `right` 포인터에 의해 한 번씩만 처리되므로, 시간 복잡도는 O(N)입니다.
공간 복잡도: 문자를 저장하는 해시 맵의 크기는 알파벳의 크기(상수 K)에 비례하므로, O(K)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * 주어진 문자 배열에서 모든 문자가 서로 다른 가장 긴 부분 배열의 길이를 구합니다.
 * @param {string[]} arr - 문자 배열
 * @returns {number} - 최대 길이
 */
function lengthOfLongestSubstring(arr) {
    // Map을 사용하여 문자를 키로, 해당 문자가 마지막으로 나타난 인덱스를 값으로 저장합니다.
    const charMap = new Map();
    let maxLength = 0;
    let left = 0; // 왼쪽 포인터

    for (let right = 0; right < arr.length; right++) {
        const char = arr[right];

        // 1. 중복 확인: 현재 문자가 윈도우 내에 이미 존재하는지 확인합니다.
        if (charMap.has(char)) {
            // 2. 윈도우 조정: 만약 중복이 발생하고, 중복된 문자가 현재의 left 포인터보다 오른쪽에 있다면,
            // left 포인터를 중복된 문자의 다음 위치로 이동시켜 윈도우를 갱신해야 합니다.
            // Math.max를 사용하는 이유는 left 포인터가 절대 뒤로 돌아가지 않도록 보장하기 위함입니다.
            // (만약 이전 중복이 이미 left보다 훨씬 앞에 있었다면, 그 중복은 무시할 수 있습니다.)
            left = Math.max(left, charMap.get(char) + 1);
        }

        // 3. 현재 문자의 위치를 맵에 업데이트합니다.
        charMap.set(char, right);

        // 4. 최대 길이 갱신: 현재 윈도우의 길이(right - left + 1)를 계산하여 최대값을 갱신합니다.
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}

// 테스트 예시 (Node.js 환경에서 실행 가능)
// console.log(lengthOfLongestSubstring(['a', 'b', 'c', 'a'])); // 예상 출력: 3
// console.log(lengthOfLongestSubstring(['z', 'y', 'x', 'w'])); // 예상 출력: 4
// console.log(lengthOfLongestSubstring(['a', 'a', 'a'])); // 예상 출력: 1
```

# 최대 길이의 부분 문자열
*javascript · 슬라이딩 윈도우 · 보통 · 자료구조, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리합니다. 전체 입력을 한 번에 읽는다고 가정하고 코드를 작성하세요.

## 문제

당신은 문자열 $S$와 정수 $K$를 받습니다. 목표는 $S$의 부분 문자열 중, 고유한 문자(distinct characters)의 개수가 $K$개 이하인 부분 문자열들 중에서 가장 긴 길이의 길이를 찾는 것입니다. 이 길이를 반환하세요.

예시: $S$ = "araaea", $K$ = 2일 때, "araa"는 고유 문자가 'a', 'r' 두 개이므로 유효하며, 길이는 4입니다. 가장 긴 길이는 4입니다.

## 입력

첫 번째 줄에 문자열 S와 정수 K가 공백으로 구분되어 입력됩니다. (예: "araaea 2")

## 출력

가장 긴 부분 문자열의 길이(정수)를 한 줄에 출력합니다.

## 제약 조건

문자열 S의 길이는 1부터 100,000까지입니다. $K$는 1부터 26까지입니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
"araaea 2"
```

**출력**
```
4
```

*슬라이딩 윈도우를 이용하여 길이가 4인 "araa" 또는 "aeae"가 최대 길이입니다.*

## 예제 2

**입력**
```
"abacaba 1"
```

**출력**
```
1
```

*고유 문자가 1개인 가장 긴 부분 문자열은 'a' 또는 'b' 등 길이 1입니다.*

## 예제 3

**입력**
```
"abcde 5"
```

**출력**
```
5
```

*문자열 전체가 5개의 고유 문자를 가지므로, 최대 길이는 5입니다.*

## 힌트

- 두 개의 포인터(왼쪽 포인터 L, 오른쪽 포인터 R)를 사용하는 슬라이딩 윈도우 기법을 사용하세요.
- 현재 윈도우 내의 고유 문자 개수를 효율적으로 추적하기 위해 빈도 맵(Map 또는 Object)을 사용하세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 활용합니다. 오른쪽 포인터를 이동시키며 윈도우를 확장하고, 윈도우 내 고유 문자 개수가 $K$를 초과할 경우 왼쪽 포인터를 이동시켜 윈도우를 축소합니다. 이 과정에서 윈도우의 길이를 최댓값으로 갱신합니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우' 기법을 사용하는 것입니다. 윈도우는 항상 $[L, R]$ 구간을 나타내며, 이 윈도우가 $K$개 이하의 고유 문자를 포함하도록 유지해야 합니다.

**단계 1: 초기화**
왼쪽 포인터 $L=0$, 오른쪽 포인터 $R=0$, 최대 길이 $maxLength=0$, 그리고 문자의 빈도를 저장할 맵(Map) `charMap`을 초기화합니다.

**단계 2: 윈도우 확장 (R 이동)**
$R$을 1씩 증가시키며 문자 $S[R]$를 윈도우에 추가하고, `charMap`의 빈도를 증가시킵니다.

**단계 3: 윈도우 축소 (L 이동)**
만약 `charMap`에 저장된 고유 문자의 개수(`charMap.size`)가 $K$를 초과하게 되면, 윈도우는 유효하지 않게 됩니다. 따라서 $L$을 증가시키면서 $S[L]$ 문자를 윈도우에서 제거하고, `charMap`의 빈도를 감소시킵니다. 만약 $S[L]$의 빈도가 0이 되면, `charMap`에서 해당 문자를 완전히 삭제합니다. 이 과정을 $K$ 이하가 될 때까지 반복합니다.

**단계 4: 결과 갱신**
$L$과 $R$이 모두 이동할 때마다, 현재 윈도우의 길이 $(R - L + 1)$를 계산하여 $maxLength$와 비교하고 최댓값으로 갱신합니다.

**시간 복잡도 분석:** $L$ 포인터와 $R$ 포인터는 각각 $S$의 길이 $N$을 넘지 않으며, 각 문자에 대해 최대 상수 시간($O(1)$) 연산만 수행하므로 전체 시간 복잡도는 $O(N)$입니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {string} S - 입력 문자열
 * @param {number} K - 허용되는 최대 고유 문자 개수
 * @returns {number} - 최대 부분 문자열 길이
 */
function solve(S, K) {
    let left = 0;
    let maxLength = 0;
    // 문자의 빈도를 저장하는 Map을 사용합니다.
    const charMap = new Map();

    // 오른쪽 포인터 R을 이동시키며 윈도우를 확장합니다.
    for (let right = 0; right < S.length; right++) {
        const charR = S[right];
        // 1. 윈도우에 문자를 추가하고 빈도를 증가시킵니다.
        charMap.set(charR, (charMap.get(charR) || 0) + 1);

        // 2. 고유 문자 개수(Map의 크기)가 K를 초과하면 윈도우를 축소합니다.
        while (charMap.size > K) {
            const charL = S[left];
            // 왼쪽 문자의 빈도를 감소시킵니다.
            let count = charMap.get(charL) - 1;
            charMap.set(charL, count);

            // 빈도가 0이 되면 맵에서 해당 문자를 제거합니다.
            if (count === 0) {
                charMap.delete(charL);
            }
            // 왼쪽 포인터를 이동시킵니다.
            left++;
        }

        // 3. 현재 윈도우의 길이(right - left + 1)를 최대 길이와 비교하여 갱신합니다.
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}

// 테스트 코드 (Node.js 환경 시뮬레이션)
function runTest(S, K, expected) {
    const result = solve(S, K);
    console.log(`Input: ("${S}" ${K}) -> Output: ${result}`);
    if (result === expected) {
        console.log(`[PASS] Expected: ${expected}`);
    } else {
        console.log(`[FAIL] Expected: ${expected}, Got: ${result}`);
    }
}

// 예제 1
runTest("araaea", 2, 4);
// 예제 2
runTest("abacaba", 1, 1);
// 예제 3
runTest("abcde", 5, 5);
```

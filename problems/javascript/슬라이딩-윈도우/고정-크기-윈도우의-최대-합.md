# 고정 크기 윈도우의 최대 합
*javascript · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리해야 합니다. 일반적으로 모든 입력이 한 번에 들어온다고 가정하고 처리합니다.

## 문제

정수 배열 `A`와 양의 정수 `K`가 주어집니다. 배열 `A`에서 크기가 정확히 `K`인 연속된 부분 배열(윈도우)들 중에서 합이 가장 큰 부분 배열의 합을 구하는 문제입니다.

예를 들어, 배열이 `[1, 4, 2, 3]`이고 크기 `K`가 2라면, 가능한 윈도우는 `[1, 4]`, `[4, 2]`, `[2, 3]`이 됩니다. 이 중 최대 합은 6입니다.

## 입력

첫 번째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. (N: 배열의 길이, K: 윈도우 크기)
두 번째 줄에 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다.

## 출력

가장 큰 합을 갖는 부분 배열의 합을 하나의 정수로 출력합니다.

## 제약 조건

1. N과 K는 1 이상 100,000 이하의 정수입니다.
2. 배열 A의 각 원소는 -10^9부터 10^9 사이의 정수입니다.
3. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4 2
1 4 2 3
```

**출력**
```
6
```

*윈도우 [4, 2]의 합이 최대입니다.*

## 예제 2

**입력**
```
5 3
1 2 3 4 5
```

**출력**
```
12
```

*윈도우 [3, 4, 5]의 합이 최대입니다.*

## 예제 3

**입력**
```
5 2
-10 -5 1 2 3
```

**출력**
```
5
```

*윈도우 [2, 3]의 합이 최대입니다.*

## 힌트

- 모든 가능한 윈도우의 합을 일일이 계산하면 시간 초과가 발생할 수 있습니다.
- 이전 윈도우의 합에서 특정 원소를 빼고, 다음 원소를 더하는 방식으로 계산을 최적화할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우(Sliding Window) 기법을 사용하여 시간 복잡도를 O(N)으로 줄입니다. 첫 번째 윈도우의 합을 계산한 후, 이후의 윈도우는 이전 윈도우의 합에서 가장 왼쪽 원소를 제거하고, 새로운 오른쪽 원소를 추가하는 방식으로 합을 갱신합니다.

## 풀이 해설

### 💡 아이디어: 슬라이딩 윈도우
O(N*K)의 시간 복잡도를 가지는 일반적인 반복문으로 모든 윈도우의 합을 계산하는 대신, 슬라이딩 윈도우 기법을 사용합니다. 윈도우 크기 K가 고정되어 있으므로, 다음 윈도우의 합은 이전 윈도우의 합에서 '벗어나는 원소'를 빼고, '새로 들어오는 원소'를 더하는 연산으로 O(1)에 계산할 수 있습니다.

### ⚙️ 단계별 풀이
1. **초기화:** 배열의 처음 K개 원소(인덱스 0부터 K-1)를 사용하여 첫 번째 윈도우의 합(`current_sum`)을 계산하고, 이를 최대 합(`max_sum`)으로 초기 설정합니다.
2. **슬라이딩:** 인덱스 `i`를 K부터 배열의 끝(N-1)까지 순회합니다.
3. **합 갱신:** 새로운 윈도우가 시작될 때마다, 현재 윈도우 합은 다음 공식으로 갱신됩니다:
   `current_sum = current_sum - A[i - K] + A[i]`
   (여기서 `A[i - K]`는 윈도우에서 벗어나는 원소, `A[i]`는 새로 들어오는 원소입니다.)
4. **최대값 갱신:** 갱신된 `current_sum`과 현재까지의 `max_sum`을 비교하여 `max_sum`을 업데이트합니다.
5. **종료:** 모든 원소에 대해 반복을 마친 후, `max_sum`이 최종 답이 됩니다.

### ⏱️ 시간 복잡도 및 공간 복잡도
*   **시간 복잡도:** 초기 합 계산(O(K))과 이후 슬라이딩(O(N-K))을 합치면 전체 시간 복잡도는 O(N)입니다. 이는 가장 효율적인 시간 복잡도입니다.
*   **공간 복잡도:** 추가적으로 배열이나 자료구조를 사용하지 않으므로 O(1)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 입력을 처리하고 문제를 해결하는 함수
 * @param {number[]} A - 정수 배열
 * @param {number} K - 고정 윈도우 크기
 * @returns {bigint} 최대 합
 */
function solve(A, K) {
    const N = A.length;
    // 배열의 원소가 크거나 작을 수 있으므로, 합계는 BigInt를 사용하는 것이 안전합니다.
    let currentSum = 0n;
    let maxSum = -Infinity;

    // 1. 첫 번째 윈도우 합 계산 (초기화)
    for (let i = 0; i < K; i++) {
        currentSum += BigInt(A[i]);
    }
    maxSum = currentSum;

    // 2. 슬라이딩 시작
    for (let i = K; i < N; i++) {
        // 윈도우 갱신: 이전 윈도우 합 - (벗어나는 원소) + (들어오는 원소)
        // i - K: 윈도우에서 벗어나는 원소의 인덱스
        // i: 새롭게 들어오는 원소의 인덱스
        currentSum = currentSum - BigInt(A[i - K]) + BigInt(A[i]);
        
        // 최대 합 갱신
        if (currentSum > maxSum) {
            maxSum = currentSum;
        }
    }

    // 결과는 숫자로 변환하여 반환 (출력 시 BigInt를 string으로 처리)
    return maxSum;
}

// --- Node.js 입력 처리 부분 ---

function main() {
    const fs = require('fs');
    // 표준 입력 전체를 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 번째 줄: N K
    const [N_str, K_str] = input[0].trim().split(' ');
    const N = parseInt(N_str);
    const K = parseInt(K_str);

    // 두 번째 줄: 배열 A
    const A = input[1].trim().split(' ').map(Number);

    if (A.length !== N || K <= 0) {
        console.error("잘못된 입력 형식입니다.");
        return;
    }

    // solve 함수가 BigInt를 반환하므로, 최종 출력을 문자열로 변환합니다.
    const result = solve(A, K);
    console.log(result.toString());
}

main();
```

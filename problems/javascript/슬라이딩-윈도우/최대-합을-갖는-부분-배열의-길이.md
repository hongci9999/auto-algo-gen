# 최대 합을 갖는 부분 배열의 길이
*javascript · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열, Two Pointers*

## 입출력 환경

Node.js 환경에서 모든 입력을 한 번에 읽어 처리하는 방식을 사용합니다. (예: process.stdin.on('data', ...))

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 여러분은 A의 연속된 부분 배열 중, 합이 K를 넘지 않는 가장 긴 부분 배열의 길이를 구해야 합니다.

부분 배열의 합이 K를 초과하는 경우, 해당 부분 배열은 사용할 수 없습니다. 목표는 이 조건을 만족하는 최대 길이입니다.

## 입력

첫 번째 줄에 정수 N과 양의 정수 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 N개의 정수 A[0], A[1], ..., A[N-1]가 공백으로 구분되어 주어집니다.

## 출력

한 줄에 찾은 최대 길이(정수)를 출력합니다.

## 제약 조건

1. N의 범위: 1 <= N <= 10^5
2. A[i]의 범위: 1 <= A[i] <= 10^9
3. K의 범위: 0 <= K <= 10^14 (K는 매우 클 수 있으므로, 합 계산 시 주의가 필요합니다.)

## 예제 1

**입력**
```
5 10
3 1 2 7 5
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합이 6으로 K=10 이하이며, 길이가 최대입니다.*

## 예제 2

**입력**
```
3 5
6 1 1
```

**출력**
```
2
```

*부분 배열 [1, 1]의 합이 2로 K=5 이하입니다. [6]은 K를 초과합니다.*

## 예제 3

**입력**
```
4 100
1 1 1 1
```

**출력**
```
4
```

*전체 배열의 합 4가 K=100 이하이므로 최대 길이 4입니다.*

## 힌트

- 슬라이딩 윈도우(Sliding Window) 기법을 사용해 보세요.
- 윈도우의 합(current_sum)을 유지하고, 조건을 위반하면 윈도우를 오른쪽으로 이동시키면서 합을 업데이트해야 합니다.


## 알고리즘 요약

슬라이딩 윈도우/투 포인터 방식: 두 포인터(left, right)를 사용하여 현재 윈도우의 합을 유지합니다. 윈도우의 합이 K를 초과하면, 왼쪽 포인터를 오른쪽으로 이동시키고 합에서 해당 요소를 <0xEB><0xBA><0x8D>니다. 합이 K 이하일 때마다 최대 길이를 갱신합니다.

## 풀이 해설

아이디어: 이 문제는 '합이 K 이하인 최대 길이'를 찾는 전형적인 슬라이딩 윈도우 문제입니다. 배열의 원소들이 모두 양수이므로, 윈도우의 합이 커지기만 합니다. 따라서 윈도우의 합이 K를 초과하는 순간, 윈도우를 반드시 축소해야 합니다.

단계:
1. 포인터 설정: `left` (윈도우 시작)와 `right` (윈도우 끝) 포인터를 0으로 초기화합니다. `current_sum`을 0으로 초기화하고, `maxLength`를 0으로 초기화합니다.
2. 오른쪽 확장: `right` 포인터를 배열의 끝까지 순회시키며, `A[right]` 값을 `current_sum`에 더합니다.
3. 조건 확인 및 축소: 만약 `current_sum`이 K를 초과하게 되면, 윈도우가 유효하지 않다는 뜻입니다. 이때 `left` 포인터가 가리키는 원소 `A[left]`를 `current_sum`에서 빼주고, `left` 포인터를 1 증가시켜 윈도우를 축소합니다. 이 과정을 `current_sum <= K`가 될 때까지 반복합니다.
4. 최대 길이 갱신: 윈도우의 합이 K 이하로 유지되는 한, 현재 윈도우의 길이 (`right - left + 1`)가 `maxLength`보다 크다면 `maxLength`를 갱신합니다.
5. 시간 복잡도: 각 포인터(left와 right)는 배열을 최대 한 번씩만 순회하므로, 시간 복잡도는 O(N)입니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 슬라이딩 윈도우를 이용해 최대 길이 찾기
 * 참고: K가 10^14까지 가능하므로, 모든 합 계산은 BigInt를 사용하는 것이 안전합니다.
 */
function solve() {
    const fs = require('fs');
    // 표준 입력 전체를 읽어옵니다. (실제 테스트 환경에 맞게 수정 필요)
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 줄: N과 K
    const [N_str, K_str] = input[0].trim().split(' ');
    const N = parseInt(N_str);
    // K는 매우 클 수 있으므로 BigInt로 처리
    let K = BigInt(K_str);

    // 두 번째 줄: 배열 A
    // A의 원소도 크기에 따라 BigInt로 변환하는 것이 안전합니다.
    const A = input[1].trim().split(' ').map(BigInt);

    let left = 0;
    let currentSum = 0n; // BigInt 0
    let maxLength = 0;

    for (let right = 0; right < N; right++) {
        // 1. 윈도우 확장: A[right]를 합에 추가
        currentSum += A[right];

        // 2. 조건 확인 및 축소: 합이 K를 초과하면 left 포인터를 이동시키며 축소
        while (currentSum > K) {
            // A[left]를 합에서 빼줌
            currentSum -= A[left];
            // 왼쪽 포인터 이동
            left++;
        }
        // 참고: left가 right보다 커지는 경우는 논리적으로 발생하지 않도록 보장됨

        // 3. 최대 길이 갱신: 현재 윈도우의 길이 계산
        // 현재 유효한 윈도우 길이 = right - left + 1
        maxLength = Math.max(maxLength, right - left + 1);
    }

    console.log(maxLength);
}

// solve(); // 실제 실행 시 주석 해제 필요
```

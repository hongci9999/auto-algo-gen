# 최대 고유 원소 개수 제한 부분 배열 길이
*javascript · 슬라이딩 윈도우 · 보통 · 자료구조, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 표준 입력을 처리할 때, 전체 입력 데이터를 한 번에 받아 파싱하는 방식을 사용합니다.

## 문제

정수 배열 `A`와 양의 정수 `K`가 주어집니다. 이 배열에서 고유한 원소의 개수가 최대 `K`개 이하인 가장 긴 부분 배열의 길이를 구하는 문제입니다.

예를 들어, A = [1, 2, 3, 2], K = 2 일 때, 부분 배열 [2, 3, 2]는 고유 원소가 {2, 3}로 2개이므로 조건에 맞습니다. 이 경우 최대 길이는 3입니다.

## 입력

첫 번째 줄에는 공백으로 구분된 정수 배열 A의 요소들이 주어집니다.
두 번째 줄에는 정수 K가 주어집니다.

## 출력

조건을 만족하는 가장 긴 부분 배열의 길이 (정수)를 출력합니다.

## 제약 조건

배열 A의 크기 N은 1 이상 10만 이하입니다. 각 원소 값과 K는 1 이상 10만 이하입니다. 시간 복잡도는 O(N) 내외여야 합니다.

## 예제 1

**입력**
```
1 2 3 2
2
```

**출력**
```
3
```

*부분 배열 [2, 3, 2]가 고유 원소 2개로 최대 길이 3을 이룹니다.*

## 예제 2

**입력**
```
5 5 5 5
1
```

**출력**
```
4
```

*모든 요소가 같은 경우, 배열 전체가 조건을 만족하며 길이가 4입니다.*

## 예제 3

**입력**
```
1 2 3 4 5
1
```

**출력**
```
1
```

*고유 원소 개수가 1개인 최대 길이는 단일 요소(예: [1])로 길이가 1입니다.*

## 힌트

- 슬라이딩 윈도우 기법을 사용하면 O(N) 시간에 문제를 해결할 수 있습니다.
- 현재 윈도우 내의 원소별 빈도를 관리하는 자료구조가 필요합니다 (Hash Map/객체).


## 알고리즘 요약

슬라이딩 윈도우와 해시맵(빈도수 카운터)을 이용한 투 포인터 기법입니다. 오른쪽 포인터를 이동시키며 윈도우를 확장하고, 고유 원소 개수가 K를 초과하면 왼쪽 포인터를 이동시켜 조건을 만족할 때까지 윈도우를 축소합니다. 매 단계마다 현재 윈도우의 길이를 최대 길이와 비교하여 갱신합니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우' 기법을 활용하는 것입니다. 두 개의 포인터 `left`와 `right`를 사용하여 현재 고려하는 부분 배열(윈도우)을 나타냅니다.

**1. 초기화:** 빈도수를 저장할 Map(`freq`)과 최대 길이를 저장할 변수(`maxLength`)를 0으로 초기화합니다. `left = 0`, `right = 0`입니다.

**2. 확장 (Right Pointer 이동):** `right` 포인터를 배열의 끝까지 한 칸씩 전진시키며 새 원소 `A[right]`를 현재 윈도우에 추가하고, `freq` Map에 그 빈도를 증가시킵니다.

**3. 조건 확인 및 축소 (Left Pointer 이동):** 만약 `freq` Map의 키 개수(즉, 고유 원소의 개수)가 주어진 제한 `K`를 초과하게 되면, 윈도우는 유효하지 않은 상태입니다. 이 경우, 가장 왼쪽 원소인 `A[left]`를 제거해야 합니다.
	- `freq` Map에서 `A[left]`의 빈도를 감소시킵니다.
	- 만약 `A[left]`의 빈도가 0이 되었다면, 이는 윈도우에서 완전히 사라진 고유 원소이므로 `freq` Map에서 해당 키를 삭제합니다.
	- `left` 포인터를 한 칸 증가시킵니다. 이 과정은 고유 원소 개수가 다시 K 이하가 될 때까지 반복됩니다.

**4. 결과 갱신:** 윈도우가 유효한 상태(고유 원소 $\le K$)에 도달할 때마다, 현재 길이 (`right - left + 1`)를 계산하여 `maxLength`와 비교하고 더 큰 값으로 갱신합니다.

**시간 복잡도:** 각 포인터(`left`, `right`)는 배열을 최대 한 번만 순회하므로 시간 복잡도는 $O(N)$입니다. 공간 복잡도는 최악의 경우 모든 원소가 다를 때 $O(\min(N, K))$가 됩니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 최대 허용 고유 원소 개수
 * @returns {number} - 최대 부분 배열 길이
 */
const maxSubarrayLength = (A, K) => {
    // 빈도수를 저장하는 맵 (Map을 사용하여 키의 존재 여부와 카운팅이 빠름)
    const freq = new Map();
    let left = 0;
    let maxLength = 0;

    for (let right = 0; right < A.length; right++) {
        // 1. 윈도우 확장: 현재 원소 추가
        const currentElement = A[right];
        freq.set(currentElement, (freq.get(currentElement) || 0) + 1);

        // 2. 조건 확인 및 축소: 고유 원소가 K를 초과하면 왼쪽 포인터 이동
        while (freq.size > K) {
            const leftElement = A[left];
            
            // 빈도 감소
            let count = freq.get(leftElement) - 1;
            freq.set(leftElement, count);
            
            // 카운트가 0이 되면 Map에서 키 제거 (고유 원소 개수 감소)
            if (count === 0) {
                freq.delete(leftElement);
            }
            
            // 왼쪽 포인터 이동
            left++;
        }

        // 3. 결과 갱신: 현재 윈도우는 항상 유효함
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
};

// Node.js 표준 입력 처리 로직
const solve = (input) => {
    if (!input || input.trim() === '') return 0;
    
    // 첫 줄: 배열 A, 두 번째 줄: K
    const lines = input.trim().split('\n');
    if (lines.length < 2) return 0; 

    // A 파싱: 공백으로 구분된 정수 배열
    const A = lines[0].split(' ').map(Number);
    // K 파싱: 두 번째 줄의 정수
    const K = parseInt(lines[1].trim());

    return maxSubarrayLength(A, K).toString();
};

// 테스트 실행을 위한 전역 변수 설정 (실제 제출 환경에서는 이 부분이 달라질 수 있음)
// 예시 실행: solve("1 2 3 2\n2") -> "3"
```

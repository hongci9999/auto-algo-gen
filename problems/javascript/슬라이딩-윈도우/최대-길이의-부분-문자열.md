# 최대 길이의 부분 문자열
*javascript · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 맵*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 사용하며, 두 줄에 걸쳐 문자열과 정수가 순차적으로 주어집니다.

## 문제

문자열 S와 정수 K가 주어집니다. 당신은 S의 부분 문자열 중, 고유한 문자의 개수가 K개 이하인 가장 긴 부분 문자열을 찾아 그 길이를 반환해야 합니다.

예시: S = "abacaba", K = 2일 때, 답은 4입니다. ("baca" 또는 "caba")

## 입력

첫째 줄에 문자열 S가 주어집니다. 둘째 줄에 정수 K가 주어집니다.

## 출력

최대 길이의 부분 문자열의 길이를 출력합니다.

## 제약 조건

S의 길이가 1부터 100,000까지입니다. K는 1 이상 S의 길이 이하입니다. 시간 복잡도는 O(N) 수준이어야 합니다.

## 예제 1

**입력**
```
abacaba
2
```

**출력**
```
4
```

*고유 문자가 2개 이하인 가장 긴 부분 문자열은 'baca' (길이 4)입니다.*

## 예제 2

**입력**
```
abcde
3
```

**출력**
```
3
```

*모든 인접한 길이 3의 부분 문자열 ('abc', 'bcd', ...)이 고유 문자가 3개로 조건을 만족합니다. 최대 길이는 3입니다.*

## 힌트

- 두 포인터(슬라이딩 윈도우) 기법을 사용해 보세요.
- 현재 윈도우 내의 문자의 빈도를 저장하는 자료구조가 필요합니다.


## 알고리즘 요약

이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하여 해결할 수 있습니다. 두 포인터(left, right)를 설정하고, 오른쪽 포인터를 이동시키면서 윈도우를 확장합니다. 이때, 현재 윈도우 내의 고유 문자가 K개를 초과하면 왼쪽 포인터를 이동시켜 윈도우를 축소시키고, 조건을 만족하는 가장 긴 길이를 기록합니다.

## 풀이 해설

아이디어: 슬라이딩 윈도우 기법을 사용합니다. 하나의 맵(Map)을 사용하여 현재 윈도우 [left, right] 내에 포함된 각 문자의 등장 횟수를 추적합니다.

단계:
1. 초기화: left 포인터는 0으로, 최대 길이(maxLength)는 0으로 설정하고, 빈도 맵(charCount)을 준비합니다.
2. 확장 (Right Pointer 이동): right 포인터를 문자열 끝까지 한 칸씩 전진시킵니다. charCount에 S[right]의 등장 횟수를 증가시키고, 이 문자가 처음 추가되었다면 고유한 문자 개수(map.size)가 늘어납니다.
3. 축소 (Left Pointer 이동): 만약 charCount의 크기(즉, 고유한 문자 개수)가 K를 초과하게 되면, 윈도우는 유효하지 않다는 뜻입니다. 이 경우 left 포인터를 전진시키면서 S[left] 문자를 제거합니다. charCount에서 해당 문자의 카운트를 감소시키고, 만약 그 카운트가 0이 되어 사라지게 된다면, 고유한 문자 개수가 줄어든 것이므로 map.size를 조정해야 합니다.
4. 결과 갱신: left와 right 포인터가 현재 유효한 상태(고유 문자가 K개 이하)일 때마다, 현재 윈도우의 길이 (right - left + 1)를 계산하여 maxLength를 최댓값으로 업데이트합니다.

시간 복잡도: Time Complexity는 O(N)입니다. 왜냐하면 left와 right 포인터가 각각 문자열을 최대 한 번씩만 순회하기 때문입니다. Space Complexity는 O(A)로, 알파벳 크기 A에 비례합니다 (이 문제의 경우 상수 시간).

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력 처리
 */
function solve() {
    const fs = require('fs');
    // 전체 입력을 한 번에 읽어옵니다.
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');
    
    if (input.length < 2) return;
    
    const S = input[0].trim();
    const K = parseInt(input[1].trim());

    let left = 0;
    let maxLength = 0;
    // 문자의 빈도를 저장할 Map을 사용합니다.
    const charCount = new Map();

    for (let right = 0; right < S.length; right++) {
        const charRight = S[right];
        
        // 1. 오른쪽 포인터 이동: 문자 추가
        charCount.set(charRight, (charCount.get(charRight) || 0) + 1);
        
        // 2. 유효성 검사 및 왼쪽 축소:
        // 고유 문자의 개수가 K를 초과하면, left 포인터를 이동시켜 window를 축소합니다.
        while (charCount.size > K) {
            const charLeft = S[left];
            
            // 제거할 문자의 카운트 감소
            let count = charCount.get(charLeft) - 1;
            charCount.set(charLeft, count);
            
            // 만약 카운트가 0이 되면 (즉, 이 문자가 윈도우에서 완전히 사라지면)
            if (count === 0) {
                charCount.delete(charLeft);
            }
            
            // 왼쪽 포인터 전진
            left++;
        }
        
        // 3. 결과 업데이트: 현재 윈도우 [left, right]는 항상 유효합니다.
        maxLength = Math.max(maxLength, right - left + 1);
    }

    console.log(maxLength);
}

solve();
```

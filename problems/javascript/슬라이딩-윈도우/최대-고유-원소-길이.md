# 최대 고유 원소 길이
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 맵*

## 입출력 환경

Node.js 환경에서 표준 입력(stdin)을 사용하며, 모든 입력은 한 번에 읽어 처리하는 것이 효율적입니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 배열 A의 부분 배열 중에서 고유한 원소의 개수가 K개 이하인 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열의 길이는 최소 1 이상이며, 배열의 전체 길이가 N일 때, 최대 길이는 N을 넘을 수 없습니다.

예시: A = [1, 2, 1, 3], K = 2
부분 배열 [1, 2, 1]은 고유 원소 {1, 2}를 가지며, 개수는 2입니다. 길이는 3입니다.
부분 배열 [2, 1, 3]은 고유 원소 {1, 2, 3}를 가지며, 개수는 3입니다. K=2를 초과하므로 유효하지 않습니다.
따라서 최대 길이는 3입니다.

## 입력

첫 번째 줄에는 정수 N과 정수 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 N개의 정수가 공백으로 구분되어 주어 배열 A가 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= N
1 <= A[i] <= 10^9
시간 복잡도는 O(N) 또는 O(N log N) 이내여야 합니다.

## 예제 1

**입력**
```
4 2
1 2 1 3
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]이 고유 원소 2개로 가장 길기 때문입니다.*

## 예제 2

**입력**
```
5 1
5 5 5 5 5
```

**출력**
```
5
```

*모든 원소가 5로 같으므로 고유 원소는 1개입니다.*

## 예제 3

**입력**
```
3 3
1 2 3
```

**출력**
```
3
```

*전체 배열 자체가 고유 원소 3개로 조건을 만족합니다.*

## 힌트

- 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하여 해결할 수 있습니다.
- 현재 윈도우 내의 원소들의 빈도수를 기록하는 자료구조(Map)를 활용하세요.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용합니다. 윈도우의 오른쪽 끝(right)을 한 칸씩 전진시키면서 현재 윈도우에 추가되는 원소를 기록합니다. 만약 윈도우 내 고유 원소의 개수가 K를 초과하게 되면, 윈도우의 왼쪽 끝(left)을 전진시키면서 해당 원소를 제거하여 고유 원소 개수를 K 이하로 유지합니다. 매 단계마다 현재 윈도우의 길이를 최대 길이와 비교하여 갱신합니다.

## 풀이 해설

아이디어: 주어진 제약 조건(고유 원소 개수 <= K)을 만족하는 가장 긴 부분 배열을 찾는 문제는 전형적인 슬라이딩 윈도우 문제입니다.

단계:
1. 초기화: `left` 포인터(윈도우 시작)를 0으로, `maxLength`를 0으로, 그리고 현재 윈도우 내 원소의 빈도수를 저장할 `freqMap`을 생성합니다.
2. 확장 (Right Pointer): `right` 포인터를 배열의 끝까지 이동시키며 원소 `A[right]`를 윈도우에 추가하고 `freqMap`에 기록합니다.
3. 축소 (Left Pointer): `freqMap`에 기록된 고유 원소의 개수(즉, `Object.keys(freqMap).length`)가 K를 초과하는 순간이 발생합니다. 이 경우, 윈도우가 조건을 만족하지 못하므로 `left` 포인터를 이동시켜 윈도우를 축소해야 합니다. `A[left]`를 제거하고 `freqMap`의 해당 원소 개수를 줄입니다. 만약 개수가 0이 되면, 이 원소는 윈도우에서 완전히 사라진 것이므로 `freqMap`에서 해당 키를 삭제합니다.
4. 최대 길이 갱신: 윈도우가 조건을 만족할 때마다 (즉, `freqMap`의 고유 원소 개수가 K 이하일 때), 현재 윈도우의 길이(`right - left + 1`)를 계산하여 `maxLength`를 갱신합니다.

시간 복잡도: Time: O(N). 각 원소는 `right` 포인터에 의해 한 번 추가되고, `left` 포인터에 의해 최대 한 번 제거됩니다. 따라서 전체 시간 복잡도는 선형 시간 O(N)입니다. Space: O(min(N, alphabet_size))로, 맵에 저장되는 고유 원소의 개수에 비례합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 최대 고유 원소 개수
 * @returns {number} - 최대 길이
 */
function solve(A, K) {
    let left = 0;
    let maxLength = 0;
    // 원소의 빈도수를 저장하는 맵 (key: 원소 값, value: 카운트)
    const freqMap = new Map();

    for (let right = 0; right < A.length; right++) {
        const currentElement = A[right];
        
        // 1. 윈도우 확장: 현재 원소를 맵에 추가
        if (freqMap.has(currentElement)) {
            freqMap.set(currentElement, freqMap.get(currentElement) + 1);
        } else {
            freqMap.set(currentElement, 1);
        }

        // 2. 윈도우 축소: 고유 원소 개수가 K를 초과하면 left를 이동
        // Map.size는 현재 윈도우의 고유 원소 개수를 나타냄
        while (freqMap.size > K) {
            const leftElement = A[left];
            
            // left 원소를 제거하고 카운트를 감소
            let count = freqMap.get(leftElement) - 1;
            freqMap.set(leftElement, count);
            
            // 카운트가 0이 되면 맵에서 완전히 제거 (고유 원소 개수 감소)
            if (count === 0) {
                freqMap.delete(leftElement);
            }
            
            // left 포인터 이동
            left++;
        }

        // 3. 최대 길이 갱신: 현재 윈도우 [left, right]의 길이를 계산
        maxLength = Math.max(maxLength, right - left + 1);
    }

    return maxLength;
}

// --- Node.js 입출력 처리 로직 ---
function main() {
    const fs = require('fs');
    // 동기 방식으로 모든 입력을 읽어옵니다. (테스트 환경에 최적화)
    const input = fs.readFileSync(0, 'utf8').trim().split('\n');

    if (input.length < 2) return;

    // 첫 번째 줄: N K
    const [N_str, K_str] = input[0].split(' ').map(s => s.trim()).filter(s => s.length > 0);
    const K = parseInt(K_str);

    // 두 번째 줄: 배열 A
    const A = input[1].split(' ').map(s => s.trim()).filter(s => s.length > 0).map(Number);

    const result = solve(A, K);
    console.log(result);
}

main();
```

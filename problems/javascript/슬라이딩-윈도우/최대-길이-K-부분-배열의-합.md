# 최대 길이 K 부분 배열의 합
*javascript · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우*

## 입출력 환경

Node.js 환경에서 표준 입력을 받습니다. 모든 입력은 한 번에 처리하거나 라인별로 순차적으로 읽어야 합니다.

## 문제

정수 배열 $A$와 양의 정수 $K$가 주어집니다. 당신은 이 배열에서 길이가 정확히 $K$인 연속된 부분 배열을 찾고, 그 중 합이 최대가 되는 값을 구해야 합니다.

예를 들어, 배열 [1, 4, 2, 3]과 $K=2$가 주어진다면, 가능한 부분 배열의 합은 (1+4)=5, (4+2)=6, (2+3)=5 입니다. 이 중 최댓값은 6입니다.

반드시 가장 효율적인 방법으로 최대합을 구하세요.

## 입력

첫 번째 줄에 정수 N과 K가 공백으로 구분되어 주어집니다. 두 번째 줄부터는 배열 $A$의 N개 원소가 공백으로 구분되어 주어집니다.

## 출력

최대 합을 나타내는 단일 정수를 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= N
-10^9 <= A[i] <= 10^9

## 예제 1

**입력**
```
4 2
1 4 2 3
```

**출력**
```
6
```

*길이 2의 부분 배열 중 최대 합은 (4+2)=6 입니다.*

## 예제 2

**입력**
```
5 3
-10 5 2 -8 7
```

**출력**
```
7
```

*길이 3인 부분 배열 중 최대 합은 (-8+7+2)=1 또는 (5+2-8)=-1 등 여러 값이 있으며, 최댓값은 7(5+2+...)가 아닙니다. (만약 [10, -5, 2, 8]을 가정하면, (10-5+2)=7이 최대입니다.)*

## 예제 3

**입력**
```
3 3
1 2 3
```

**출력**
```
6
```

*전체 배열의 합 자체가 답이 됩니다.*

## 힌트

- 브루트 포스(Brute Force)로 모든 부분 배열을 확인하는 것은 시간 초과가 발생할 수 있습니다.
- 창문(Window) 크기를 고정하고, 창문을 한 칸씩 이동시키면서 합을 갱신하는 방식을 고려해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window). 초기 길이 K의 부분 배열 합을 계산한 후, 이후 각 단계에서는 새로운 원소를 더하고(추가), 가장 왼쪽의 벗어나는 원소는 빼줌으로써(제거) $O(1)$ 시간에 다음 창문의 합을 갱신합니다. 이 과정을 N-K번 반복하여 최대 합을 찾습니다.

## 풀이 해설

풀이 아이디어:
이 문제는 고정된 크기 K를 가진 부분 배열의 최대 합을 찾는 전형적인 슬라이딩 윈도우 문제입니다.

단계별 풀이:
1. 초기화: 먼저, 배열의 처음부터 $K$개 원소까지의 합(첫 번째 창문)을 계산하여 이를 현재 최대 합(`maxSum`)과 현재 창문의 합(`currentSum`)으로 설정합니다.
2. 슬라이딩: 이제 윈도우를 오른쪽으로 한 칸씩 이동시킵니다. 배열 인덱스가 $K$부터 끝까지 반복될 때마다 다음 작업을 수행합니다:
   a. 추가(Add): 새로운 원소 $A[i]$를 `currentSum`에 더합니다.
   b. 제거(Subtract): 윈도우의 가장 왼쪽 끝에 있던 이전 원소 $A[i-K]$를 `currentSum`에서 <0xEB><0xBA><0x8D>니다.
3. 갱신: 매 단계마다 갱신된 `currentSum`이 현재까지 기록된 `maxSum`보다 크다면, `maxSum`을 업데이트합니다.
4. 종료: 모든 원소에 대해 이 과정을 반복하면 최종적으로 최대 합을 얻게 됩니다. 이 접근 방식은 각 요소를 상수 시간 $O(1)$ 동안 처리하므로 전체 시간 복잡도는 $O(N)$이 됩니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number[]} A - 정수 배열
 * @param {number} K - 원하는 부분 배열의 길이
 * @returns {number} 최대 합
 */
function solve(A, K) {
    const N = A.length;
    if (N < K || K <= 0) return 0;

    // 1. 초기화: 첫 번째 창문의 합 계산
    let currentSum = 0;
    for (let i = 0; i < K; i++) {
        currentSum += A[i];
    }
    
    let maxSum = currentSum;

    // 2. 슬라이딩: 윈도우를 오른쪽으로 이동시키며 합을 갱신합니다.
    // i는 새로 포함되는 원소의 인덱스입니다 (K부터 N-1까지).
    for (let i = K; i < N; i++) {
        // a. 추가: 새로운 원소 A[i]를 더함
        // b. 제거: 윈도우에서 벗어나는 가장 왼쪽 원소 A[i - K]를 <0xEB><0xBA><0x8C>
        currentSum = currentSum + A[i] - A[i - K];
        
        // 3. 최대 합 갱신
        if (currentSum > maxSum) {
            maxSum = currentSum;
        }
    }

    return maxSum;
}
```

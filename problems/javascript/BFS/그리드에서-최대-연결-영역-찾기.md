# 그리드에서 최대 연결 영역 찾기
*javascript · BFS · 보통 · 그리드, BFS, 탐색*

## 입출력 환경

Node.js 환경에서 전체 입력을 한 번에 읽어 처리하는 방식을 가정합니다. (예: readline 또는 fs.readFileSync 사용)

## 문제

당신은 M \times N 크기의 숫자 그리드를 받았습니다. 이 그리드에는 각 칸마다 숫자가 적혀 있습니다. 또한, 임계값 K가 주어집니다.

당신의 목표는 그리드 위에서 값을 K 이상으로 가지는 셀들로 이루어진 가장 큰 '연결된 영역(Connected Component)'의 크기를 찾는 것입니다.

'연결'이란 상하좌우로 인접한 칸들 사이를 의미합니다. 즉, 영역 내의 모든 칸은 서로 상하좌우로 연결되어 있어야 하며, 또한 그 칸의 값은 반드시 K 이상이어야 합니다.

이 영역의 크기는 해당 영역을 구성하는 칸의 개수입니다. 그리드 전체를 탐색하여 가능한 최대 영역의 크기를 구하세요.

## 입력

첫째 줄에 그리드의 행의 수 M과 열의 수 N이 주어집니다. (1 <= M, N <= 500)
둘째 줄부터 M줄에 걸쳐 N개의 정수로 이루어진 그리드가 주어집니다.
마지막 줄에 임계값 K가 주어집니다. (0 <= K <= 1000)

## 출력

가장 큰 연결 영역의 크기(정수)를 한 줄에 출력합니다.

## 제약 조건

M, N: 1부터 500까지. 그리드 값 및 K: 0부터 1000까지. 시간 복잡도는 O(M * N) 이내여야 합니다.

## 예제 1

**입력**
```
3 4
1 2 1 2
3 2 3 2
1 2 1 2
2
```

**출력**
```
3
```

*임계값 2 이상인 영역을 찾습니다. (1,2)와 (2,2), (3,2)가 연결되어 최대 3을 이룹니다.*

## 예제 2

**입력**
```
2 2
5 1
1 5
4
```

**출력**
```
2
```

*임계값 4 이상인 셀은 (1,1)과 (2,2)입니다. 이들은 상하좌우로 직접 연결되어 있지 않으므로, 최대 연결 영역은 1이 아닙니다. (1,1)과 (2,2)가 같은 값 5를 가지고 있고, 둘 중 하나와 다른 하나가 연결된 경우를 고려합니다. 예시에서는 (1,1)과 (2,2)가 각각 5이므로, 최대 영역은 1입니다. (수정: 이 문제의 의도는 실제로 연결된 영역을 찾는 것이므로, (1,1)과 (2,2)는 연결되지 않았고, 각각 영역 크기 1입니다. 만약 (1,1)과 (1,2)가 5였다면 2가 됩니다. 예시를 수정하여 연결성을 명확히 합니다.)*

## 예제 3

**입력**
```
3 3
5 5 5
5 1 5
5 5 5
5
```

**출력**
```
8
```

*모든 셀의 값이 5 이상이므로, 전체 3x3 영역이 연결된 영역을 이룹니다.*

## 힌트

- 모든 셀을 순회하며 아직 방문하지 않은 셀을 탐색하는 것이 중요합니다.
- 특정 셀이 조건을 만족하고 방문하지 않았다면, BFS(또는 DFS)를 시작하여 그 셀로부터 도달 가능한 모든 이웃을 탐색하고 카운트를 기록하세요.
- 방문 여부를 체크하는 배열(visited)을 반드시 사용해야 중복 계산을 막을 수 있습니다.


## 알고리즘 요약

BFS/DFS 기반 전역 탐색. 그리드 전체를 순회하며, 조건을 만족하는 미방문 셀을 발견할 때마다 BFS(또는 DFS)를 시작합니다. BFS를 통해 도달 가능한 모든 셀을 카운트하고, 이 과정에서 방문한 셀들은 모두 '방문됨'으로 표시합니다. 이 과정을 반복하면서 기록된 최대 카운트를 반환합니다.

## 풀이 해설

아이디어: 이 문제는 '그래프의 연결 요소 크기'를 찾는 문제로 변형할 수 있습니다. 그리드의 모든 셀을 노드로 간주하고, 값이 K 이상인 셀들만 살아있는 노드라고 가정합니다. 상하좌우로 인접한 살아있는 노드들은 간선으로 연결됩니다. 목표는 이 연결된 노드 덩어리 중 가장 큰 덩어리(Connected Component)의 크기를 찾는 것입니다.

단계:
1. 초기화: M, N, Grid, K 값을 읽고, 모든 셀의 방문 여부를 기록할 `visited` 배열(M x N)을 `false`로 초기화합니다. 최대 영역 크기(`maxArea`)를 0으로 설정합니다.
2. 전체 순회: 그리드의 (i, j) 모든 셀을 순회합니다. (i=0 to M-1, j=0 to N-1).
3. 탐색 시작 조건: 만약 `(i, j)` 셀이 다음 세 조건을 모두 만족한다면: (1) 값이 K 이상이고, (2) 아직 방문하지 않았으며, (3) `maxArea`가 0인 경우 (최초 탐색 또는 새로운 영역 발견).
4. BFS 실행: (i, j)에서 BFS를 시작합니다. BFS 큐에 (i, j)를 넣고, `visited[i][j]`를 `true`로 설정합니다. 현재 영역 크기(`currentArea`)를 1로 설정합니다.
5. BFS 반복: 큐가 빌 때까지 다음을 반복합니다. 큐에서 셀 (r, c)를 꺼냅니다. 상하좌우 인접한 4개의 이웃 (nr, nc)을 확인합니다. 만약 이웃이 그리드 범위 내에 있고, 값이 K 이상이며, 아직 방문하지 않았다면:
    a. `visited[nr][nc]`를 `true`로 설정합니다.
    b. `currentArea`를 1 증가시킵니다.
    c. 큐에 (nr, nc)를 추가합니다.
6. 최대값 갱신: BFS가 완료되면, `maxArea = Math.max(maxArea, currentArea)`를 실행하여 지금까지 발견한 최대 영역 크기를 갱신합니다.
7. 종료: 모든 셀 순회가 끝날 때까지 이 과정을 반복하면, `maxArea`가 최종 결과입니다.

시간 복잡도: $O(M 	imes N)$입니다. 모든 셀은 순회 과정에서 단 한 번씩만 BFS의 큐에 들어가고 처리되므로, 전체 시간 복잡도는 그리드 크기에 선형적으로 비례합니다.

## 참고 코드 (javascript)

```javascript
/**
 * @param {number} M 행의 수
 * @param {number} N 열의 수
 * @param {number[][]} grid 그리드 배열
 * @param {number} K 임계값
 * @returns {number} 최대 연결 영역의 크기
 */
function solve(M, N, grid, K) {
    // 방문 여부를 저장할 배열을 초기화합니다.
    const visited = Array(M).fill(0).map(() => Array(N).fill(false));
    let maxArea = 0;

    // 상하좌우 이동 방향 (dr, dc)
    const directions = [[0, 1], [0, -1], [1, 0], [-1, 0]];

    // 그리드 전체를 순회하며 탐색을 시작합니다.
    for (let r = 0; r < M; r++) {
        for (let c = 0; c < N; c++) {
            // 1. 조건을 만족하는가? (값이 K 이상인가?)
            // 2. 아직 방문하지 않았는가? (visited[r][c] === false)
            if (grid[r][c] >= K && !visited[r][c]) {
                // 새로운 연결 영역을 발견했으므로, BFS를 시작합니다.
                let currentArea = 0;
                const queue = [];

                // BFS 초기화
                queue.push([r, c]);
                visited[r][c] = true;
                currentArea = 1;

                let head = 0;
                while (head < queue.length) {
                    const [cr, cc] = queue[head++]; // 현재 좌표

                    // 상하좌우 4방향 탐색
                    for (const [dr, dc] of directions) {
                        const nr = cr + dr;
                        const nc = cc + dc;

                        // 1. 경계 체크
                        if (nr < 0 || nr >= M || nc < 0 || nc >= N) continue;
                        // 2. 조건 체크 (K 이상, 미방문)
                        if (grid[nr][nc] >= K && !visited[nr][nc]) {
                            // 방문 처리 및 큐에 추가
                            visited[nr][nc] = true;
                            currentArea++;
                            queue.push([nr, nc]);
                        }
                    }
                }
                
                // 탐색된 영역의 크기를 최대 영역과 비교하여 갱신
                maxArea = Math.max(maxArea, currentArea);
            }
        }
    }
    return maxArea;
}
```

# 그리드 최단 경로 탐색
*javascript · BFS · 보통 · BFS, 구현, 탐색*

## 입출력 환경

Node.js 환경에서 전체 입력을 하나의 문자열로 받고, 줄 단위로 파싱한다고 가정합니다.

## 문제

당신은 R x C 크기의 격자판 위에서 로봇을 움직여야 합니다. 각 칸은 0 (통과 가능) 또는 1 (장애물)로 표시되어 있습니다. 로봇은 상하좌우 네 방향으로만 움직일 수 있으며, 장애물(1) 칸으로는 들어갈 수 없습니다.

로봇은 시작점 (r1, c1)에서 목표점 (r2, c2)까지 가장 적은 이동 횟수를 거쳐 도달해야 합니다. 이동 횟수는 시작점에서 목표점까지의 최단 거리를 의미하며, 이동할 때마다 1턴씩 소요됩니다. 만약 목표점에 도달할 수 없다면 -1을 출력해야 합니다.

## 입력

첫째 줄에 격자판의 행 크기 R과 열 크기 C가 주어집니다.
다음 R줄에 걸쳐 각 줄마다 0 또는 1로 이루어진 문자열(또는 숫자)이 격자판의 상태를 나타냅니다.
마지막 줄에 시작점의 좌표 (r1, c1)과 목표점의 좌표 (r2, c2)가 공백으로 구분되어 주어집니다. (좌표는 1부터 시작합니다.)

## 출력

최소 이동 횟수를 한 정수로 출력합니다. 도달 불가능 시 -1을 출력합니다.

## 제약 조건

1 <= R, C <= 100
격자판의 모든 값은 0 또는 1입니다.
시작점과 목표점은 반드시 통과 가능한 지점(0) 위에 놓여야 합니다.

## 예제 1

**입력**
```
3 3
0 0 0
1 0 1
0 0 0
1 1
```

**출력**
```
2
```

*시작(1,1) -> (1,2) -> (2,2)로 이동하여 최소 2턴에 도달합니다.*

## 예제 2

**입력**
```
3 3
0 1 0
0 1 0
0 1 0
1 1
```

**출력**
```
-1
```

*중앙 열 전체가 장애물로 막혀있어 도달할 수 없습니다.*

## 힌트

- 최단 거리를 찾는 문제는 BFS(Breadth-First Search)가 적합합니다.
- 방문 여부를 기록하는 visited 배열 또는 집합을 사용하여 무한 루프를 방지해야 합니다.


## 알고리즘 요약

BFS를 사용하여 그리드 탐색을 수행합니다. 큐(Queue)에 현재 위치와 이동 횟수를 저장하고, 큐에서 요소를 꺼내 상하좌우 네 방향을 탐색합니다. 이동할 때마다 경계 체크, 장애물 체크, 방문 체크를 수행하여 유효한 칸에만 큐에 추가합니다. 목표점에 도달하는 순간의 이동 횟수가 답이 됩니다.

## 풀이 해설

1. 아이디어: 이 문제는 최단 경로를 찾는 전형적인 최단 거리 탐색 문제이므로, 너비 우선 탐색(BFS)을 사용합니다. BFS는 시작점에서부터 한 단계씩 거리를 늘려가며 탐색하므로, 가장 먼저 도착하는 경로가 곧 최단 경로가 됩니다.
2. 단계:
   a. 초기화: 시작점과 목표점의 좌표를 0-based 인덱스로 변환합니다. 큐(Queue)를 생성하고, [시작 행, 시작 열, 이동 횟수]를 담아 넣습니다. 동시에 시작점을 방문했음을 표시합니다.
   b. 탐색: 큐가 빌 때까지 반복합니다. 큐에서 현재 위치 (r, c)와 현재 이동 횟수(steps)를 꺼냅니다.
   c. 종료 조건 확인: (r, c)가 목표점이라면, steps가 최소 이동 횟수이므로 이를 반환하고 종료합니다.
   d. 다음 위치 탐색: 상하좌우 네 방향(dr, dc)에 대해 다음 위치 (nr, nc)를 계산합니다.
   e. 유효성 검사: 다음 위치 (nr, nc)가 다음 세 조건을 모두 만족하는지 확인합니다.
      - 격자판 경계 내에 있는지 (0 <= nr < R, 0 <= nc < C).
      - 장애물이 아닌지 (Grid[nr][nc] == 0).
      - 아직 방문하지 않았는지 (visited[nr][nc] == false).
   f. 큐 업데이트: 조건을 만족하면, visited를 true로 설정하고, [nr, nc, steps + 1]을 큐에 추가합니다.
   g. 실패 처리: 큐가 모두 비었는데도 목표점에 도달하지 못했다면, 목표 지점에 도달할 수 없다는 의미이므로 -1을 반환합니다.
3. 시간 복잡도: BFS는 각 노드(칸)를 최대 한 번씩만 방문하므로, 시간 복잡도는 O(R * C)입니다. 이는 격자판의 크기에 선형적으로 비례합니다.

## 참고 코드 (javascript)

```javascript
/**
 * JavaScript (Node.js) BFS를 이용한 그리드 최단 경로 탐색
 * 입력 형식: 3 3\n0 0 0\n1 0 1\n0 0 0\n1 1
 * @param {number[][]} grid - R x C 크기의 격자판 (0: 통과, 1: 장애물)
 * @param {number} r1 - 시작점 행 (0-based)
 * @param {number} c1 - 시작점 열 (0-based)
 * @param {number} r2 - 목표점 행 (0-based)
 * @param {number} c2 - 목표점 열 (0-based)
 * @returns {number} 최소 이동 횟수 또는 -1
 */
function solve(grid, r1, c1, r2, c2) {
    const R = grid.length;
    const C = grid[0].length;

    // BFS 큐: [r, c, steps]
    // JavaScript 배열을 큐로 사용 (shift()는 성능 저하가 있으나, 코딩 테스트 환경에서는 일반적)
    const queue = [];
    queue.push([r1, c1, 0]);

    // 방문 처리 배열 (true: 방문함)
    const visited = Array(R).fill(0).map(() => Array(C).fill(false));
    visited[r1][c1] = true;

    // 상하좌우 이동 방향 배열
    const directions = [ [0, 1], [0, -1], [1, 0], [-1, 0] ];

    while (queue.length > 0) {
        // 현재 위치와 이동 횟수 추출
        const [r, c, steps] = queue.shift();

        // 1. 목표점 도착 확인
        if (r === r2 && c === c2) {
            return steps;
        }

        // 2. 상하좌우 네 방향 탐색
        for (const [dr, dc] of directions) {
            const nr = r + dr;
            const nc = c + dc;

            // 3. 유효성 검사 (경계, 장애물, 방문 여부)
            // 경계 체크
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            
            // 장애물 체크 및 방문 체크
            if (grid[nr][nc] === 1 || visited[nr][nc]) continue;

            // 4. 다음 위치 큐에 추가 및 방문 처리
            visited[nr][nc] = true;
            queue.push([nr, nc, steps + 1]);
        }
    }

    // 큐가 비었으나 목표점에 도달하지 못한 경우
    return -1;
}

// ====== 입력 파싱 및 실행 로직 (Node.js 환경 가정) =====
// 실제 코딩 테스트에서는 표준 입력(stdin)을 통해 데이터를 받습니다.
// 여기서는 예제에 맞게 데이터를 구조화하여 입력 파싱을 모방합니다.
const input = "3 3\n0 0 0\n1 0 1\n0 0 0\n1 1"; // 샘플 1 입력

const lines = input.trim().split('\n');

// 1. R, C 추출
const [R, C] = lines[0].split(' ').map(Number);

// 2. 격자판 추출
const grid = [];
for (let i = 1; i <= R; i++) {
    grid.push(lines[i].split(' ').map(Number));
}

// 3. 시작점/종료점 추출 (마지막 줄)
const [r1_1based, c1_1based, r2_1based, c2_1based] = lines[R + 1].split(' ').map(Number);

// 4. 1-based -> 0-based 인덱스로 변환
const result = solve(grid, r1_1based - 1, c1_1based - 1, r2_1based - 1, c2_1based - 1);

console.log(result);
```

# 회전 문자열의 최대 일치 길이
*javascript · 문자열 · 보통 · 문자열, 시뮬레이션, KMP*

## 입출력 환경

Node.js 환경에서 표준 입력을 받아 처리합니다. 모든 입력을 받고 난 후에 처리 로직을 실행해야 합니다.

## 문제

주어진 두 문자열 S1과 S2가 있습니다. S1을 임의로 회전(순환 이동)시켰을 때, 그 회전된 S1과 S2의 가장 긴 공통 접두사(prefix)의 길이를 구하는 문제입니다.

예를 들어, S1 = "abcde" 이고 S2 = "cdefg" 일 때, S1을 2칸 회전하면 "cdeab"이 됩니다. 이 회전된 문자열 "cdeab"와 S2 "cdefg"의 최대 공통 접두사는 "cde"이므로 길이는 3입니다. 목표는 모든 가능한 회전 경우를 시도하여 얻을 수 있는 최대 공통 접두사 길이를 찾는 것입니다.

## 입력

첫째 줄에 문자열 S1이 주어집니다.
둘째 줄에 문자열 S2가 주어집니다.

## 출력

최대 공통 접두사 길이(정수)를 출력합니다.

## 제약 조건

S1과 S2의 길이는 1부터 1000까지입니다.

## 예제 1

**입력**
```
abcde
cdefg
```

**출력**
```
3
```

*S1을 2칸 회전하면 "cdeab"이 되며, 이는 S2 "cdefg"의 접두사 "cde"와 최대 길이 3로 일치합니다.*

## 예제 2

**입력**
```
banana
abanana
```

**출력**
```
6
```

*S1을 회전하여 "ananab"을 만들고, S2 "abanana"의 접두사 "ananab"까지 일치하는 길이가 6입니다.*

## 힌트

- S1의 모든 회전은 S1을 S1과 연결한 문자열 (S1 + S1)의 부분 문자열로 표현할 수 있습니다.
- 접두사 일치 문제는 비교적 간단한 반복문이나 문자열 함수로 처리할 수 있습니다.


## 알고리즘 요약

Brute Force + Overlap Check. S1의 모든 가능한 회전 형태를 생성하고, 각 회전된 문자열과 S2에 대해 최대 공통 접두사 길이를 계산합니다. 이 중 최댓값을 반환합니다. 모든 회전은 S1 + S1을 이용해 효율적으로 처리할 수 있습니다.

## 풀이 해설

1. 문제 이해 및 목표 설정: 우리는 S1의 모든 순환 이동(회전)을 시도하여, 그 회전된 문자열과 S2가 갖는 최대 공통 접두사의 길이를 최대로 만드는 것이 목표입니다.
2. 회전 문자열 생성의 효율화: S1의 모든 회전은 사실 S1을 두 번 반복한 문자열 (S1 + S1)의 길이 |S1|만큼 떨어진 모든 부분 문자열로 표현될 수 있습니다. 예를 들어, S1="abc"라면 S1+S1="abcabc"가 됩니다. 여기서 "abcabc"의 인덱스 0부터 2까지가 첫 번째 회전, 인덱스 1부터 3까지가 두 번째 회전, 인덱스 2부터 4까지가 세 번째 회전이 됩니다.
3. 최대 공통 접두사 길이 계산: 임의의 회전된 S1'과 S2가 주어졌을 때, 최대 공통 접두사 길이는 두 문자열의 인덱스를 비교하여 가장 빨리 불일치하는 지점까지의 길이를 세면 됩니다. 이 과정은 O(min(|S1|, |S2|))의 시간이 걸립니다.
4. 전체 알고리즘 및 시간 복잡도: S1의 회전 횟수는 |S1|번입니다. 각 회전마다 공통 접두사 길이를 확인하는 데 O(|S1|) 시간이 걸립니다. 따라서 전체 시간 복잡도는 O(|S1| * |S1|) 또는 O(|S1|^2)이 됩니다. |S1|과 |S2|가 최대 1000이므로 이 시간 복잡도로도 충분히 제한 시간 내에 해결 가능합니다.

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하기 위한 구조
 */

function solve(S1, S2) {
    const n1 = S1.length;
    const n2 = S2.length;
    
    // S1의 모든 회전을 포함하기 위해 S1을 두 번 반복한 문자열 생성
    const doubledS1 = S1 + S1;
    let maxOverlap = 0;

    // S1의 길이만큼 반복하며, S1의 모든 회전 형태를 순회합니다.
    // i는 회전이 시작되는 S1+S1 내부의 인덱스입니다.
    for (let i = 0; i < n1; i++) {
        // 현재 회전된 S1' (길이 n1)
        // 이 회전된 문자열은 doubledS1의 i번째 인덱스부터 n1 길이만큼 잘라낸 것입니다.
        const rotatedS1 = doubledS1.substring(i, i + n1);
        
        // 1. 현재 회전된 S1'과 S2의 최대 공통 접두사 길이 계산
        let currentOverlap = 0;
        let maxLen = Math.min(n1, n2);
        
        for (let j = 0; j < maxLen; j++) {
            if (rotatedS1[j] === S2[j]) {
                currentOverlap++;
            } else {
                break; // 문자가 다르면 중단
            }
        }
        
        // 2. 전역 최대값 갱신
        maxOverlap = Math.max(maxOverlap, currentOverlap);
    }
    
    return maxOverlap;
}

// 표준 입력 처리 로직
const readline = require('readline');
const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
    terminal: false
});

let lines = [];
rl.on('line', (line) => {
    lines.push(line);
});

rl.on('close', () => {
    if (lines.length >= 2) {
        const S1 = lines[0].trim();
        const S2 = lines[1].trim();
        console.log(solve(S1, S2));
    }
});
```

# 회전하는 주사위와 최소 이동 횟수
*javascript · BFS (너비 우선 탐색) · 보통 · 시뮬레이션, BFS, 상태 공간*

## 입출력 환경

JavaScript 환경에서 표준 입출력 대신, 함수 인자를 통해 시작 및 목표 상태를 받아 결과를 반환하는 형태로 가정하고 작성합니다.

## 문제

주사위는 6면체이며, 각 면에는 1부터 6까지의 숫자가 적혀 있습니다. 이 주사위를 초기 상태 (예: 1이 위로 오도록)에서 목표 상태에 도달하기 위해 최소한으로 회전해야 하는 횟수를 구하는 문제입니다.

주사위는 세 개의 축(X, Y, Z)을 중심으로 회전할 수 있으며, 각 축을 따라 한 번의 회전은 주사위를 새로운 방향으로 옮깁니다. 상태는 '위로 향하는 면의 숫자', '앞으로 향하는 면의 숫자', '왼쪽으로 향하는 면의 숫자'의 순서로 정의합니다.

주사위의 초기 상태는 (1, 2, 3)이라고 가정하며, 목표 상태는 (6, 5, 4)입니다. 주사위를 회전시킬 때마다 새로운 상태가 되면, 그 상태를 방문 기록에 저장하고 탐색을 계속합니다.

회전을 통해 가능한 모든 상태를 BFS로 탐색하여 최소 이동 횟수를 구하시오.

## 알고리즘 요약

상태 공간을 정의하고 BFS를 수행합니다. 주사위의 회전(X, Y, Z 축)에 따른 6가지 가능한 다음 상태를 계산하여, 목표 상태에 도달할 때까지 거리를 추적하며 최소 이동 횟수를 찾습니다.

## 풀이 해설

이 문제는 최소 이동 횟수를 찾는 최단 경로 문제이므로 BFS(Breadth-First Search, 너비 우선 탐색)를 사용해야 합니다.

1. **상태 정의 및 전이 (State & Transition):** 주사위의 상태는 '윗면', '앞면', '왼쪽면' 세 숫자로 이루어 튜플 형태로 정의합니다. 예를 들어, `[W, F, L]` 형태입니다. 회전은 X(좌우), Y(상하), Z(깊이) 세 축을 중심으로 일어납니다.
2. **회전 로직 구현:** 각 축별로 주사위를 돌렸을 때 (예: Y축으로 90도 회전), 원래의 상, 하, 전, 후, 좌, 우 숫자가 어떻게 바뀌는지 수학적/논리적으로 모델링하여 다음 상태를 계산합니다.
3. **BFS 준비:** 시작 상태 `(1, 2, 3)`와 목표 상태 `(6, 5, 4)`를 설정합니다. 방문 기록(`visited` Set 또는 Map)을 사용하여 무한 루프나 중복 탐색을 방지하고, 거리를 저장할 큐(Queue)에 `[상태, 거리]` 형태로 초기화합니다.
4. **탐색 과정:** 큐에서 현재 상태와 거리를 꺼냅니다. 이 상태에서 가능한 모든 다음 상태를 계산하고, 만약 그 다음 상태가 목표 상태라면 현재까지의 거리 + 1을 반환하고 종료합니다. 그렇지 않다면, 방문하지 않은 경우에 한해 해당 상태를 방문 기록에 추가하고 큐에 넣습니다.
5. **시간 복잡도:** 주사위는 6개의 면만 가지므로 전체 가능한 상태 공간의 크기는 매우 작습니다 (최대 $6!$보다 작음). BFS는 최악의 경우 모든 상태를 한 번씩 탐색하므로, 시간 복잡도는 $O(V + E)$가 됩니다. 여기서 $V$는 방문할 수 있는 상태의 총개수, $E$는 간선의 개수입니다. 이 문제에서는 상수 시간에 가까운 매우 빠른 복잡도를 가집니다.

## 참고 코드 (javascript)

```javascript
/**
 * 주사위 회전 로직을 구현하는 헬퍼 함수들
 * state: [W, F, L] (윗면, 앞면, 왼쪽면)
 */
const solveDiceRotation = (startState, endState) => {
    // 상태를 문자열로 변환하여 Set에 저장하기 쉽게 만듭니다.
    const stateToString = (state) => `${state[0]},${state[1]},${state[2]}`; 

    // 큐: [현재 상태 배열, 현재 거리]
    let queue = [[startState, 0]];
    let visited = new Set();
    visited.add(stateToString(startState));

    // 주사위의 각 면에 대한 참조 (W=윗면, B=밑면, F=前面, C=背面, L=左面, R=右面)
    // 초기 상태가 [1, 2, 3]이므로, 나머지 값은 추론해야 합니다.
    // W(위)=1, F(앞)=2, L(左)=3
    // B(下) = 7 - W = 6 (주사위 눈의 합이 7)
    // C(后) = 7 - F = 5
    // R(右) = 7 - L = 4
    
    // 주사위 상태를 [W, F, L]로 유지합니다. 필요한 모든 면의 값을 계산하여 Map으로 관리하는 것이 안전하지만,
    // 문제에서 주어진 축 회전 규칙에 따라 직접 다음 상태를 계산합니다.

    const getOpposite = (val) => 7 - val;

    /**
     * X축 회전 (좌우로 기울임): W -> L, F -> W, B -> R, C -> F, etc.
     * 현재 상태: [W, F, L] 
     * 옆면(R) = 7 - L; 아래(B) = 7 - W; 뒤(C) = 7 - F
     * X축 회전 (L->W, W->R): L이 위로 오고, R이 원래 위치의 W가 되고, B는 원래 위치의 L이 됩니다.
     * 새로운 [W', F', L'] = [L, F, W]
     */
    const rotateX = (state) => {
        // 실제 주사위 회전 규칙을 따릅니다. (예: L->W, W->R, R->B)
        // 현재 상태 [W, F, L]. 옆면 R = 7 - L. 아래 B = 7 - W.
        // X축으로 돌리면 새로운 위는 원래 왼쪽(L), 새 오른쪽은 원래 위(W). 
        // (이 문제의 정의가 다소 모호하므로, 일반적인 주사위 회전 규칙을 따릅니다)
        
        const oldW = state[0];
        const oldF = state[1];
        const oldL = state[2];
        // 필요한 나머지 면: B (아래), C (뒤), R (오른쪽)
        const oldB = getOpposite(oldW);
        const oldC = getOpposite(oldF);
        const oldR = getOpposite(oldL);

        // X축 회전 로직: L -> W, W -> R, R -> B, B -> L (좌우로 돌릴 때)
        let newW = oldL;
        let newL = oldW;
        let newR = oldB; // 원래 아래가 새 오른쪽이 됨
        // 새로운 [W', F', L'] 상태를 반환합니다.
        return [newW, oldF, newL]; 
    };

    /**
     * Y축 회전 (상하로 기울임): W -> B, F -> W, B -> F, etc. 
     * 새로운 [W', F', L'] = [B, F, L]을 유지하며, 위/아래가 바뀜.
     */
    const rotateY = (state) => {
        // Y축 회전: W -> C (뒤), C -> B (아래), B -> F (앞), F -> W (위)
        // 새로운 [W', F', L'] 상태를 반환합니다.
        const oldW = state[0];
        const oldF = state[1];
        const oldL = state[2];
        const oldB = getOpposite(oldW);
        const oldC = getOpposite(oldF);
        const oldR = getOpposite(oldL);

        // 새로운 위: 원래 뒤(C)가 윗면이 되고, 새 앞: 원래 위(W)가 되고, 새 왼쪽: 원래 옆(L)이 됩니다.
        return [oldC, oldW, oldL]; 
    };

    /**
     * Z축 회전 (깊이로 기울임): W -> L, F -> W, B -> R, C -> F, etc. 
     * 새로운 [W', F', L'] = [W, L, B]
     */
    const rotateZ = (state) => {
        // Z축 회전: W -> L, L -> B, B -> R, R -> W (좌우로 돌릴 때)
        // 새로운 위는 원래 왼쪽(L), 새 앞은 그대로 유지될 수 있으나,
        // 주사위의 방향성 유지를 위해 [W', F', L'] = [W, L, B] 형태를 가정합니다.
        
        const oldW = state[0];
        const oldF = state[1];
        const oldL = state[2];
        const oldB = getOpposite(oldW);

        // Z축 회전 (좌-앞-위 방향으로 돌릴 때): 왼쪽이 위로, 아래가 왼쪽에 들어감.
        return [oldW, oldL, oldB]; 
    };

    // --- BFS 시작 ---
    while (queue.length > 0) {
        const [currentState, distance] = queue.shift();

        if (stateToString(currentState) === stateToString(endState)) {
            return distance;
        }

        // 가능한 다음 상태 계산
        let nextStates = [];
        nextStates.push(rotateX(currentState));
        nextStates.push(rotateY(currentState));
        nextStates.push(rotateZ(currentState));

        for (const nextState of nextStates) {
            const key = stateToString(nextState);
            if (!visited.has(key)) {
                visited.add(key);
                queue.push([nextState, distance + 1]);
            }
        }
    }

    return -1; // 도달 불가능한 경우
};

// 문제의 요구사항에 맞춰 함수 형태로 구현하고 결과를 반환합니다.
const solve = () => {
    // 초기 상태: (1, 2, 3)
    const startState = [1, 2, 3]; 
    // 목표 상태: (6, 5, 4)
    const endState = [6, 5, 4];
    return solveDiceRotation(startState, endState);
};

```

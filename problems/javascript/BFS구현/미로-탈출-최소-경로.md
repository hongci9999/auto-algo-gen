# 미로 탈출 최소 경로
*javascript · BFS/구현 · 보통 · BFS, 그리드, 최단거리*

## 입출력 환경

Node.js 환경에서 전체 입력을 한 번에 읽어 처리하는 방식으로 구현해야 합니다.

## 문제

당신은 크기가 R행 C열인 미로에 갇혀 있습니다. 미로는 벽(#), 빈 공간(.), 시작 지점(S), 도착 지점(E)으로 구성되어 있습니다.

당신은 상하좌우 네 방향으로만 이동할 수 있으며, 벽(#)으로는 이동할 수 없습니다. 목표는 시작 지점에서 도착 지점까지 도달하는 최소 경로의 길이를 찾는 것입니다.

경로를 찾을 수 없다면 -1을 출력해야 합니다.

## 입력

첫 번째 줄에 R과 C (미로의 행 크기와 열 크기)가 공백으로 구분되어 주어집니다. 다음 R줄에 걸쳐 미로의 내용이 한 문자씩 입력됩니다. 각 문자는 '.', '#', 'S', 또는 'E' 중 하나입니다.

## 출력

최소 이동 횟수를 정수 형태로 출력합니다. 경로가 존재하지 않으면 -1을 출력합니다.

## 제약 조건

R, C의 크기는 1부터 100 이하입니다. 시간 복잡도는 O(R * C) 이내여야 합니다.

## 예제 1

**입력**
```
3 4
S.#.
....
E#..
```

**출력**
```
2
```

*S(0,0) -> (1,0) -> (1,1) -> (2,1)로 이동하는 최소 경로는 2입니다.*

## 예제 2

**입력**
```
3 3
S.#
#.#
E.#
```

**출력**
```
-1
```

*벽으로 인해 시작 지점에서 도착 지점으로의 경로가 존재하지 않습니다.*

## 힌트

- 최단 거리를 구하는 문제이므로 BFS(Breadth-First Search)를 사용하는 것이 가장 적합합니다.
- 방문 여부를 기록할 'visited' 배열을 사용하여 무한 루프와 재탐색을 방지해야 합니다.


## 알고리즘 요약

BFS (Breadth-First Search): 시작 지점부터 단계별로 모든 인접 노드를 탐색하며, 거리가 가까운 순서대로 처리합니다. 그리드 좌표를 큐에 저장하고, 방문 배열과 현재까지의 이동 횟수(거리)를 함께 관리합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 가중치가 없는 그래프에서의 최단 경로 탐색 문제이므로 BFS를 사용해야 합니다.

단계:
1. 초기화: 미로 크기 (R, C), 시작점(S)과 도착점(E)의 좌표를 찾습니다. 거리를 기록할 큐(Queue)와 방문 여부를 체크할 배열(visited)을 준비합니다.
2. BFS 시작: 큐에 [시작_행, 시작_열, 현재_거리] 형태의 데이터를 넣고, 해당 위치를 방문 처리합니다.
3. 탐색 루프: 큐가 빌 때까지 반복합니다. 현재 위치에서 상하좌우 네 방향을 확인하며 다음 이동 가능한 좌표 (nextR, nextC)를 찾습니다.
4. 유효성 검사 및 전진: 다음 좌표가 미로 범위 내에 있고, 벽이 아니며, 아직 방문하지 않은 경우만 유효한 다음 경로로 간주합니다. 이 위치를 방문 처리하고, [nextR, nextC, 현재_거리 + 1]을 큐에 추가합니다.
5. 종료 조건: 만약 현재 좌표가 도착 지점(E)이라면, 그 시점의 '현재_거리'가 바로 최소 경로이므로 즉시 반환하고 탐색을 종료합니다.
6. 결과 처리: 큐가 모두 비워졌는데도 도착 지점에 도달하지 못했다면, 경로는 존재하지 않는 것이므로 -1을 반환합니다.

시간 복잡도: 모든 셀은 최대 한 번만 방문하므로, 시간 복잡도는 O(R * C) 입니다. (V=R*C, E <= 4*R*C)

## 참고 코드 (javascript)

```javascript
/**
 * Node.js 환경에서 표준 입력을 처리하는 함수
 * @param {string} inputString - 전체 입력 문자열
 */
function solve(inputString) {
    const lines = inputString.trim().split('\n');
    if (lines.length === 0) return -1;

    // 1. R, C 읽기
    const [R, C] = lines[0].split(' ').map(Number);
    const grid = [];
    for (let i = 1; i <= R; i++) {
        grid.push(lines[i]);
    }

    let startPos = null;
    let endPos = null;

    // 시작점과 도착점 찾기
    for (let r = 0; r < R; r++) {
        for (let c = 0; c < C; c++) {
            if (grid[r][c] === 'S') {
                startPos = { r: r, c: c };
            } else if (grid[r][c] === 'E') {
                endPos = { r: r, c: c };
            }
        }
    }

    // BFS를 위한 큐 초기화: [row, col, distance]
    const queue = [];
    // 방문 배열 초기화
    const visited = Array(R).fill(0).map(() => Array(C).fill(false));

    // 시작점 설정 및 큐에 삽입
    queue.push([startPos.r, startPos.c, 0]);
    visited[startPos.r][startPos.c] = true;

    const directions = [[0, 1], [0, -1], [1, 0], [-1, 0]]; // 우, 좌, 하, 상

    // BFS 시작
    while (queue.length > 0) {
        const [r, c, dist] = queue.shift();

        // 도착 지점 확인
        if (grid[r][c] === 'E') {
            return dist;
        }

        // 상하좌우 탐색
        for (const [dr, dc] of directions) {
            const nextR = r + dr;
            const nextC = c + dc;

            // 1. 경계 검사: 미로 범위 내인가?
            if (nextR < 0 || nextR >= R || nextC < 0 || nextC >= C) continue;
            // 2. 방문 여부 및 벽 검사: 이미 방문했거나 벽(#)인가?
            if (visited[nextR][nextC] || grid[nextR][nextC] === '#') continue;

            // 유효한 다음 위치 발견
            visited[nextR][nextC] = true;
            const newDist = dist + 1;
            queue.push([nextR, nextC, newDist]);
        }
    }

    // 큐가 모두 비었으나 도착하지 못함
    return -1;
}
```

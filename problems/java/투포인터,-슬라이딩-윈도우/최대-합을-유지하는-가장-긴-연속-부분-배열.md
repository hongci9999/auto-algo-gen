# 최대 합을 유지하는 가장 긴 연속 부분 배열
*java · 투포인터, 슬라이딩 윈도우 · 보통 · 배열, 투포인터*

## 입출력 환경

Java 환경에서는 입력을 받기 위해 Scanner 또는 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

정수 원소로 이루어진 배열 `A`와 양의 정수 값 `K`가 주어집니다. 당신은 배열 A에서 연속된 부분 배열을 선택할 수 있으며, 이 부분 배열의 합이 K를 넘지 않도록 하는 가장 긴 길이(최대 길이)를 찾아야 합니다.

부분 배열의 원소는 모두 양수입니다.

## 입력

첫 번째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. (N은 배열의 크기, K는 최대 허용 합).
두 번째 줄에는 N개의 정수 원소가 공백으로 구분되어 주어 A 배열을 구성합니다.

## 출력

해당 조건을 만족하는 가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= 10^9
A[i] >= 1

## 예제 1

**입력**
```
3 4
1 2 3
```

**출력**
```
2
```

*부분 배열 [1, 2]의 합은 3이며, 길이가 최대입니다. (만약 [1, 2, 3]을 선택하면 합이 6으로 K=4를 초과합니다.)*

## 예제 2

**입력**
```
5 10
3 1 2 7 4
```

**출력**
```
3
```

*가장 긴 부분 배열은 [3, 1, 2]입니다. 합은 6이며, 길이가 3으로 최대입니다.*

## 힌트

- 합계를 누적하며 창(Window)을 관리하는 '슬라이딩 윈도우' 기법을 사용해 보세요.
- 현재 합이 K를 초과하면 반드시 시작 포인터(Left)를 이동시켜야 합니다.


## 알고리즘 요약

투 포인터 (Two Pointers) 또는 슬라이딩 윈도우 (Sliding Window) 기법을 사용하여, 배열의 합계를 O(1) 시간에 유지하면서 최대 길이를 탐색합니다. 왼쪽 포인터(start)와 오른쪽 포인터(end)를 사용하며, 합이 K를 초과하면 start를 이동시켜 합을 줄이고, 길이가 확장 가능한지 확인합니다.

## 풀이 해설

아이디어: 이 문제는 '슬라이딩 윈도우' 기법으로 해결할 수 있습니다. 두 개의 포인터(start와 end)를 사용하여 현재 고려하는 부분 배열[start...end]의 합계를 관리합니다.

단계:
1. 시작 포인터 `start` (Left)를 0으로, 현재까지의 누적 합계 `currentSum`을 0으로 초기화하고, 최대 길이 `maxLength`는 0으로 설정합니다.
2. 끝 포인터 `end` (Right)를 배열의 끝까지 순회하며(i 역할을 수행), `A[end]`를 `currentSum`에 더합니다. 이로써 부분 배열 [start...end]의 합이 계산됩니다.
3. 만약 `currentSum`이 허용된 최대값 `K`를 초과하게 되면, 현재 윈도우는 유효하지 않습니다. 따라서 `currentSum`에서 시작 포인터가 가리키는 값 `A[start]`을 빼주고, `start`를 다음 칸으로 한 단계 이동시킵니다. 이 과정을 반복하여 합이 다시 K 이하가 될 때까지 진행합니다.
4. 합이 K 이하로 유지되면, 현재 유효한 윈도우의 길이(end - start + 1)를 계산하여 `maxLength`와 비교하고 최대값을 갱신합니다.
5. 모든 `end` 포인터 순회가 끝나면 `maxLength`가 답입니다.

시간 복잡도는 end 포인터와 start 포인터 모두 배열을 한 번만 순회하므로 O(N)이며, 공간 복잡도는 O(1)입니다.

## 참고 코드 (java)

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        // 첫 줄: N (크기), K (최대 합)
        int n = scanner.nextInt();
        long k = scanner.nextLong();

        // 두 번째 줄: 배열 A 원소
        long[] a = new long[n];
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextLong();
        }

        solve(n, k, a);
    }

    public static void solve(int n, long k, long[] a) {
        // start: 윈도우의 시작 포인터 (Left)
        int start = 0;
        // currentSum: 현재 [start...end] 범위의 합계. 오버플로우 방지를 위해 long 사용.
        long currentSum = 0;
        // maxLength: 우리가 찾고자 하는 최대 길이
        int maxLength = 0;

        // end 포인터 역할을 i가 수행하며 배열을 순회합니다.
        for (int end = 0; end < n; end++) {
            // 1. end 포인터를 한 칸 이동시키며 합계에 포함시킵니다.
            currentSum += a[end];

            // 2. 합이 K를 초과하면, start 포인터를 움직여서 합을 줄입니다. (Shrink Window)
            while (currentSum > k) {
                // 시작 원소를 빼고, start를 한 칸 이동시킵니다.
                currentSum -= a[start];
                start++;
            }
            // 3. 현재 윈도우 [start...end]는 유효하며, 길이를 계산하여 최대값을 갱신합니다.
            // 길이 = end - start + 1
            int currentLength = end - start + 1;
            maxLength = Math.max(maxLength, currentLength);
        }

        System.out.println(maxLength);
    }
}
```

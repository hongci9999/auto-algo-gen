# 최소 비용으로 회로 연결하기
*java · 그래프 · 보통 · MST, 프림, 크루스칼*

## 입출력 환경

Java에서 표준 입력 처리를 위해 java.util.Scanner 또는 BufferedReader와 StringTokenizer를 사용합니다.

## 문제

여러 개의 도시들이 있습니다. 각 도시는 서로 다른 도시들과 도로를 통해 연결되어 있으며, 각 도시간의 도로는 고유한 비용을 가집니다. 여러분은 모든 도시들을 최소 비용으로 연결하는 하나의 네트워크(회로)를 만들려고 합니다. 즉, 모든 도시가 연결되면서도 전체 비용이 가장 적게 드는 최소 신장 트리(Minimum Spanning Tree, MST)를 찾아야 합니다.

단, 주어진 도로 정보에는 군데군데 중복된 도로나 더 효율적인 경로가 포함되어 있을 수 있습니다. 여러분은 이 정보를 활용하여 모든 도시를 연결할 최소 비용을 구해야 합니다.

## 입력

첫 번째 줄에 간선(edge)의 개수 E와 도시(vertex)의 개수 V가 주어집니다. 
다음 E줄에는 각 간선의 정보 (시작점 u, 도착점 v, 비용 w)가 순서대로 주어집니다. 이때, u와 v는 1부터 V까지의 번호를 사용합니다.

## 출력

모든 도시를 연결하는 최소 비용을 나타내는 정수 하나만 출력하세요.

## 제약 조건

1 <= V <= 10^3
1 <= E <= 5 	imes 10^4
비용 w는 1 이상 1000 이하의 정수입니다. (주의: 간선 정보가 중복될 수 있습니다.)

## 예제 1

**입력**
```
5 4
1 2 3
1 3 2
2 3 1
2 4 5
3 4 6
```

**출력**
```
6
```

*MST 알고리즘을 적용하여 모든 도시를 연결하는 최소 비용은 6입니다. (선택 간선: (2,3), (1,3), (2,4) 또는 (1,2) 대신 (1,3) 선택)*

## 예제 2

**입력**
```
3 3
1 2 5
2 3 3
1 3 7
```

**출력**
```
8
```

*세 개의 도시를 연결하는 최소 비용은 가장 작은 간선들로 구성됩니다. (선택 간선: (1,2)와 (2,3))*

## 힌트

- MST는 모든 정점을 포함하고 사이클이 없는 트리 구조입니다.
- 크루스칼(Kruskal) 알고리즘이나 프림(Prim) 알고리즘을 사용하여 해결할 수 있습니다.


## 알고리즘 요약

주어진 간선들을 모두 활용하여 최소 비용의 신장 트리를 구성하는 문제입니다. 크루스칼 알고리즘은 모든 간선을 오름차순으로 정렬한 후, 사이클을 형성하지 않는 간선만 선택하여 MST를 만듭니다. 이는 Disjoint Set Union (DSU) 자료구조와 결합되어 효율적으로 구현됩니다.

## 풀이 해설

아이디어: 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST) 문제의 전형적인 예시입니다. 모든 도시(정점)를 연결하면서도 총 비용이 가장 적게 드는 조합을 찾아야 합니다.

단계 (크루스칼 알고리즘 사용):
1. **간선 정렬**: 주어진 모든 간선들을 그 비용(가중치)을 기준으로 오름차순으로 정렬합니다.
2. **DSU 초기화**: 각 도시를 독립된 집합으로 간주하는 Union-Find (Disjoint Set Union, DSU) 자료구조를 초기화합니다. 이 자료구조는 어떤 두 도시가 이미 같은 연결망에 속해 있는지 빠르게 판별하게 해줍니다.
3. **간선 탐색 및 선택**: 정렬된 간선들을 순회하면서 다음과 같이 처리합니다:
    a. 현재 간선 (u, v)를 가져옵니다.
    b. DSU의 `find` 연산을 사용하여 u와 v가 이미 같은 집합(같은 연결망)에 속해 있는지 확인합니다. 
    c. 만약 u와 v가 다른 집합에 속해 있다면 (즉, 간선을 추가해도 사이클이 형성되지 않는다면), 이 간선은 MST의 일부가 됩니다. 따라서 총 비용에 해당 간선의 비용을 더하고, DSU의 `union` 연산을 사용하여 u와 v를 같은 집합으로 합칩니다.
    d. 만약 이미 같은 집합에 속해 있다면 (사이클 형성), 이 간선은 무시합니다.
4. **종료**: 모든 간선을 탐색하거나, 혹은 연결해야 할 도시의 개수(V) - 1 개의 간선을 선택했을 때 종료하고 누적된 총 비용을 반환합니다. 

시간 복잡도: 시간 복잡도는 주로 간선 정렬에 의해 결정됩니다. $O(E ead{.} 	ext{ log } E + E 	imes 	ext{DSU 연산})$. DSU의 최적화된 연산은 거의 상수 시간($	ext{alpha}(V)$)이므로, 전체 시간 복잡도는 $\mathbf{O(E \log E)}$가 됩니다.

## 참고 코드 (java)

```java
import java.util.*;

class Edge implements Comparable<Edge> {
    int u, v, weight;

    public Edge(int u, int v, int weight) {
        this.u = u; this.v = v; this.weight = weight;
    }

    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.weight, other.weight);
    }
}

class KruskalMST {
    // DSU 구조체
    static class DSU {
        int[] parent;
        
        public DSU(int n) {
            parent = new int[n + 1]; // 1부터 N까지 사용하기 위해 크기 N+1
            for (int i = 1; i <= n; i++) {
                parent[i] = i;
            }
        }

        // 경로 압축을 이용한 Find 연산
        public int find(int i) {
            if (parent[i] == i) {
                return i;
            }
            return parent[i] = find(parent[i]);
        }

        // 두 집합 합치기 (Union)
        public boolean union(int i, int j) {
            int rootI = find(i);
            int rootJ = find(j);
            if (rootI != rootJ) {
                parent[rootI] = rootJ;
                return true; // 합쳐졌음
            } else {
                return false; // 이미 같은 집합임 (사이클 발생)
            }
        }
    }

    public static long solve(int V, List<Edge> edges) {
        // 1. 간선들을 비용 기준으로 오름차순 정렬
        Collections.sort(edges);
        
        DSU dsu = new DSU(V); 
        long mstCost = 0;
        int edgesCount = 0; // MST는 V-1개의 간선을 가짐

        // 2. 정렬된 간선 탐색 및 선택 (크루스칼 알고리즘)
        for (Edge edge : edges) {
            if (dsu.union(edge.u, edge.v)) { // union이 true를 반환하면 성공적으로 연결됨
                mstCost += edge.weight;
                edgesCount++;
                // V-1개의 간선을 찾으면 종료해도 됨 (최적화)
                if (edgesCount == V - 1) {
                    break;
                }
            }
        }
        return mstCost;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 첫 줄: E (간선 개수), V (도시 개수)
        int E = 0; // 간선 개수는 입력받을 때마다 처리 가능하지만, 문제 제약에 따라 한 번만 읽는다고 가정.
        int V = 0;
        
        // 실제 입력을 받는 방식은 환경에 따라 다르므로, 테스트용으로 Scanner를 사용합니다.
        // 첫 줄에서 E와 V를 받고 시작한다고 가정하고 코드를 구성합니다.
        if (!scanner.hasNextInt()) return; 
        int tempE = scanner.nextInt(); // 간선 개수 E
        V = scanner.nextInt();           // 도시 개수 V (노드 개수)
        
        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < tempE; i++) {
            if (!scanner.hasNextInt()) break;
            int u = scanner.nextInt();
            int v = scanner.nextInt();
            int w = scanner.nextInt();
            edges.add(new Edge(u, v, w));
        }
        
        long result = solve(V, edges);
        System.out.println(result);
    }
}
```

# 최대 가중치 경로 탐색
*java · 그래프 · 보통 · DFS, DP, 가중치*

## 입출력 환경

Java의 표준 입출력을 사용합니다. 빠른 입출력을 위해 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

N개의 정점과 M개의 간선으로 이루어진 방향 그래프가 주어집니다. 각 간선은 고유한 가중치를 가지고 있습니다.

이 그래프에서 시작점 $S$에서 끝점 $E$로 가는 경로 중, 모든 간선의 가중치를 합한 총합(총 가중치)이 가장 큰 경로를 찾아 그 최댓값을 반환하는 프로그램을 작성하세요. 단, 사이클은 존재할 수 있으나, 한 정점을 두 번 이상 방문하는 경로는 고려하지 않습니다 (단순 경로만을 허용합니다).

## 입력

첫째 줄에 정점의 개수 N과 간선의 개수 M이 주어집니다.
다음 M개의 줄에는 각 간선 $i$에 대해 시작 정점 $u$, 끝 정점 $v$, 그리고 가중치 $w$가 순서대로 주어집니다. ($1 	ext{부터 } N$까지의 정점을 사용합니다.)

## 출력

최대 총 가중치를 하나의 정수로 출력합니다.

## 제약 조건

N, M <= 50
가중치 $w$: -10^9 ~ 10^9
시간 복잡도: O(N^2 * 2^N) 이하 (실제 테스트 케이스에서는 N이 작게 제한될 수 있음)

## 예제 1

**입력**
```
4 5
1 2 3
1 3 5
2 4 2
3 4 8
1 4 1
```

**출력**
```
16
```

*경로 1 -> 3 -> 4를 선택하면 가중치 합이 5 + 8 = 13입니다. (오류 수정: 예시에서 S=1, E=4가 명확하지 않으므로, 가장 큰 단일 경로 탐색으로 가정하고 1->2->4와 1->3->4를 비교합니다.)
실제 테스트 케이스에 맞춰 시작점과 끝점을 명시해야 하지만, 문제 정의 상 (S에서 E로)의 특성상 S=1, E=N(혹은 특정 값)으로 가정하고 가장 큰 경로를 찾습니다. 예제에서는 1->2->4가 3+2=5, 1->3->4가 5+8=13입니다. 만약 N이 작다면 모든 쌍 (S, E)에 대해 탐색하는 것이 일반적입니다. 여기서는 S=1, E=N으로 가정하고 풀이를 진행합니다.*

## 예제 2

**입력**
```
3 3
1 2 10
2 3 5
1 3 -2
```

**출력**
```
15
```

*S=1에서 E=3으로 가는 경로 중 가장 큰 가중치는 1 -> 2 -> 3 (가중치 합: 10 + 5 = 15) 입니다.*

## 예제 3

**입력**
```
4 4
1 2 1
2 3 1
3 4 1
1 4 1
```

**출력**
```
3
```

*S=1에서 E=4로 가는 단순 경로 중 가장 긴 경로는 1 -> 2 -> 3 -> 4 (가중치 합: 1 + 1 + 1 = 3) 입니다.*

## 힌트

- 단순 경로(Simple Path)를 찾는 문제는 비트마스킹과 DFS/백트래킹을 조합하여 해결하는 것이 일반적입니다.
- N이 작고 사이클이 존재할 때, DP나 플레인 그래프 순회로는 풀기 어렵습니다. 방문 여부를 상태에 포함해야 합니다.


## 알고리즘 요약

상태를 (현재 정점, 방문한 정점 집합)으로 정의하고 깊이 우선 탐색(DFS)을 수행합니다. 방문한 정점 집합은 비트마스크로 표현하여 $O(N 	imes 2^N)$의 상태 공간을 만듭니다. 각 상태에서 다음 가능한 간선으로 이동하며 최대 가중치를 누적합니다.

## 풀이 해설

이 문제는 '단순 경로'를 찾아야 하므로, DFS와 비트마스킹을 활용한 백트래킹(Backtracking) 기법이 필수적입니다.

**아이디어:** 하나의 정점 $S$에서 시작하여 모든 가능한 단순 경로를 탐색하고, 그중 최대 가중치를 찾습니다. '단순'하다는 것은 어떤 정점도 두 번 방문하지 않음을 의미합니다.

**단계 1: 그래프 및 상태 정의:**
먼저 인접 리스트 형태로 그래프를 구성하되, 간선 정보(다음 정점 $v$, 가중치 $w$)를 함께 저장해야 합니다. 또한, DFS의 재귀 호출 시 현재까지 방문한 정점들을 나타내는 '방문 마스크' (bitmask)를 상태에 추가합니다.

**단계 2: DFS 구현:**
DFS 함수 `dfs(현재 정점 u, 현재 가중치 totalWeight, 방문 마스크 mask)`를 정의하고 재귀적으로 호출합니다. 
1. **기저 조건/종료:** 만약 목표 지점 $E$에 도달했다면, `totalWeight`가 현재까지의 최대 가중치보다 크다면 갱신합니다 (문제에서 S와 E가 명확하지 않으므로, 모든 가능한 단순 경로 중 최댓값을 찾는 방식으로 해석하여 구현합니다).
2. **탐색:** 현재 정점 $u$에서 연결된 모든 인접 정점 $v$를 순회합니다.
3. **제약 확인:** 만약 $v$가 이미 `mask`에 포함되어 있다면 (즉, 방문한 적이 있다면), 해당 간선은 무시하고 다음 간선으로 넘어갑니다.
4. **재귀 호출:** 그렇지 않다면, $v$를 새로운 마스크에 추가($mask | (1 	ext{ << } v)$)하고, 가중치를 갱신하여 `dfs(v, totalWeight + w, newMask)`를 재귀 호출합니다.

**단계 3: 최댓값 관리:**
모든 가능한 시작 정점 $S$에 대해 DFS를 초기화하여 최대 경로 가중치를 계산하고 반환합니다. (문제의 의도상 S=1에서 출발하는 것으로 가정할 수 있으나, 일반적인 경우 모든 쌍을 고려해야 합니다.) 

**시간 복잡도:** 상태 공간은 $N 	imes 2^N$이며, 각 상태에서 최대 $N$개의 간선을 확인합니다. 따라서 시간 복잡도는 대략 $O(N^2 	imes 2^N)$ 또는 $O(N 	imes N!)$에 가까워지며, 주어진 제약 조건 (N<=50)을 초과하므로 이 문제는 실제로는 $N$이 매우 작게 제한되는 특수한 경우에 출제됩니다. 그러나 알고리즘적 접근은 위와 같습니다.

## 참고 코드 (java)

```java
import java.util.*;

class Solution {
    // 최대 가중치를 저장할 전역 변수 (혹은 클래스 멤버)
    private long maxWeight = Long.MIN_VALUE;
    private List<Edge>[] adj;
    private int N;

    static class Edge {
        int to; // 도착 정점
        long weight; // 가중치
        public Edge(int to, long weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    /**
     * DFS를 통해 단순 경로의 최대 가중치를 탐색합니다.
     * @param u 현재 정점 (1-based)
     * @param mask 방문한 정점들의 비트마스크
     * @param currentWeight 현재까지 누적된 가중치
     */
    private void dfs(int u, int mask, long currentWeight) {
        // 문제 정의가 S -> E로의 경로를 찾는 것이므로, 만약 특정 목표 정점 E가 있다면 여기서 maxWeight를 갱신해야 합니다.
        // 여기서는 모든 단순 경로 중 최대 가중치를 찾도록 구현합니다 (S=1에서 시작하는 경우).
        maxWeight = Math.max(maxWeight, currentWeight);

        for (Edge edge : adj[u]) {
            int v = edge.to;
            long w = edge.weight;

            // 1-based index를 사용하므로 비트마스크에서 정점 번호에 -1을 해야 합니다.
            // N <= 50 이지만, 문제의 제약 조건과 예시 흐름상 N이 작다고 가정하고 구현합니다 (N<=20 정도가 적절).
            if ((mask & (1 << (v - 1))) == 0) { // v가 아직 방문하지 않았다면
                int newMask = mask | (1 << (v - 1));
                dfs(v, newMask, currentWeight + w);
            }
        }
    }

    public long findMaxWeightPath(int N_nodes, List<int[]> edges) {
        this.N = N_nodes;
        // 정점 번호는 1부터 N까지이므로 크기 N+1로 배열을 만듭니다.
        adj = new ArrayList[N + 1];
        for (int i = 1; i <= N; i++) {
            adj[i] = new ArrayList<>();
        }

        // 그래프 빌드
        for (int[] edge : edges) {
            int u = edge[0];
            int v = edge[1];
            long w = edge[2];
            // 방향 그래프이므로 u -> v 간선만 추가합니다.
            adj[u].add(new Edge(v, w));
        }

        // 초기화: 모든 시작 정점 S에 대해 탐색을 수행할 수 있습니다. 
        // 예제와 문제의 일반적인 의도를 고려하여, 모든 정점을 시작점으로 시도합니다.
        maxWeight = Long.MIN_VALUE;
        for (int startNode = 1; startNode <= N; startNode++) {
            // 초기 마스크는 startNode만 방문한 상태로 설정
            int initialMask = 1 << (startNode - 1);
            dfs(startNode, initialMask, 0); 
        }
        
        return maxWeight == Long.MIN_VALUE ? 0 : maxWeight; // 경로가 없을 경우 0 반환으로 처리할 수도 있습니다.
    }
}
```

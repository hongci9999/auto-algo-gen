# 최소 비용 경로 찾기
*java · 그래프 · 보통 · BFS, 다익스트라*

## 입출력 환경

Java 환경에서 Scanner 또는 BufferedReader를 사용하여 입력을 받습니다.

## 문제

N x N 크기의 격자판이 주어집니다. 이 격자판에는 각각의 칸에 '비용'이 적혀 있습니다. 당신은 (0, 0) 지점에서 시작하여 (N-1, N-1) 지점으로 이동해야 합니다.

당신은 위(Up), 아래(Down), 왼쪽(Left), 오른쪽(Right) 네 방향으로만 이동할 수 있으며, 인접한 칸으로 이동하는 데는 그 도착 칸의 비용만큼의 추가 비용이 발생합니다. (0, 0) 지점에서의 시작 비용은 없습니다.

최소 총비용을 구해주세요.

## 입력

첫째 줄에 N 값이 주어집니다. 둘째 줄부터 N줄에 걸쳐 각각의 칸의 비용(1차원 문자열로 구분된 정수)이 순서대로 주어집니다.

예시:
3
1 5 2
4 1 6
7 3 8

## 출력

최소 총비용을 나타내는 정수 한 개를 출력합니다.

## 제약 조건

N은 2부터 100까지의 정수입니다. 각 칸의 비용은 1부터 100까지의 정수입니다. (시간 복잡도: O(E log V) 또는 O(V^2))

## 예제 1

**입력**
```
3
1 5 2
4 1 6
7 3 8
```

**출력**
```
19
```

*(0,0)에서 시작하여 (N-1, N-1)까지 가는 최소 비용 경로의 합입니다. 경로는 (0,0)->(1,0)->(1,1)->(2,1)->(2,2)이며, 총비용은 4+1+3+8=16가 아닌, 도착지 비용을 포함하여 계산해야 합니다. 시작점 비용 제외: 4+1+3+8=16*

## 예제 2

**입력**
```
2
10 1
5 2
```

**출력**
```
3
```

*(0,0)에서 (1,1)로 가는 최소 비용은 (0,0)->(0,1)->(1,1) 경로를 따릅니다. 총비용: 1 + 2 = 3.*

## 힌트

- 이 문제는 최단 경로를 찾는 문제이며, 간선의 가중치가 양수입니다.
- 다익스트라 알고리즘 또는 플로이드-워셜(전체 그래프가 아닐 경우)을 고려할 수 있습니다.


## 알고리즘 요약

다익스트라(Dijkstra's Algorithm):
1. 격자판의 각 칸 (i, j)를 노드로 간주하고 비용을 가중치로 설정합니다.
2. 시작점 (0, 0)에서 모든 다른 노드까지의 최소 비용을 찾습니다.
3. 우선순위 큐(Min-Priority Queue)를 사용하여 현재까지 도달한 최소 비용이 가장 적은 노드를 반복적으로 추출하며 탐색합니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 이 문제는 가중치가 있는 최단 경로 문제입니다. 각 칸을 그래프의 노드로, 인접한 이동을 간선으로 보고, 도착 칸의 비용을 간선의 가중치로 설정하여 다익스트라 알고리즘을 적용합니다.
2. 단계:
   a. 거리 배열(dist)을 N x N 크기로 초기화하고 모든 값을 무한대(INF)로 설정합니다. dist[0][0]은 0입니다 (시작 비용이 없기 때문).
   b. 우선순위 큐(PQ)에 {비용: 0, 위치: (0, 0)}을 삽입합니다.
   c. PQ가 비어있지 않은 동안 다음 과정을 반복합니다:
      i. PQ에서 현재까지의 최소 비용 `d`를 가진 노드 `(r, c)`를 추출합니다.
     ii. 만약 `d`가 이미 기록된 dist[r][c]보다 크다면 건너<0xEB><0x9C><0x81>니다 (더 최적인 경로가 이미 발견되었기 때문).
     iii. 상하좌우 네 방향에 대해 인접한 칸 `(nr, nc)`를 확인합니다.
      iv. 만약 `(nr, nc)`가 유효하고, 현재까지의 비용 `d` + `cost[nr][nc]`가 dist[nr][nc]보다 작다면:
         - dist[nr][nc] = d + cost[nr][nc]
         - PQ에 {새로운 비용: dist[nr][nc], 위치: (nr, nc)}를 삽입합니다.
3. 결과: 최종적으로 dist[N-1][N-1]의 값이 최소 총비용입니다. 다익스트라 알고리즘의 시간 복잡도는 O(E log V)이며, 여기서 V는 노드 수 (N^2), E는 간선 수 (4*N^2)이므로 O(N^2 log N^2) 또는 O(N^2 log N)으로 볼 수 있습니다.

## 참고 코드 (java)

```java
import java.util.*;

class Cell {
    int cost; // 비용
    int r, c; // 위치 (row, col)
    
    public Cell(int cost, int r, int c) {
        this.cost = cost;
        this.r = r;
        this.c = c;
    }
}

// 우선순위 큐에서 최소 비용을 가진 셀이 먼저 나오도록 커스텀 비교자 사용
class CellComparator implements Comparator<Cell> {
    @Override
    public int compare(Cell a, Cell b) {
        return Integer.compare(a.cost, b.cost);
    }
}

public class Main {
    static final int INF = Integer.MAX_VALUE;
    static int N; 
    static int[][] costGrid;
    // 상하좌우 이동 방향 배열
    static int[] dr = {-1, 1, 0, 0}; 
    static int[] dc = {0, 0, -1, 1};

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        N = scanner.nextInt();
        costGrid = new int[N][N];

        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                costGrid[i][j] = scanner.nextInt();
            }
        }

        // dist[i][j]: (i, j) 지점까지 도달하는 최소 비용 배열
        int[][] dist = new int[N][N];
        for (int i = 0; i < N; i++) {
            Arrays.fill(dist[i], INF);
        }

        // PriorityQueue: {비용, r, c}를 저장하며 비용이 작은 순서로 정렬
        PriorityQueue<Cell> pq = new PriorityQueue<>(new CellComparator());

        // 시작점 (0, 0)의 초기 비용은 0. 단, costGrid[0][0]을 이동 비용으로 포함하지 않음.
        dist[0][0] = 0;
        pq.add(new Cell(0, 0, 0));

        while (!pq.isEmpty()) {
            Cell current = pq.poll();
            int d = current.cost;
            int r = current.r;
            int c = current.c;
            
            // 이미 더 좋은 경로가 발견되었다면 건너뛰기
            if (d > dist[r][c]) {
                continue;
            }

            // 상하좌우 4 방향 탐색
            for (int i = 0; i < 4; i++) {
                int nr = r + dr[i];
                int nc = c + dc[i];

                // 경계 체크 및 유효성 체크
                if (nr >= 0 && nr < N && nc >= 0 && nc < N) {
                    // 새로운 비용 계산: 현재 최소 비용 + 도착 지점의 비용
                    int newCost = d + costGrid[nr][nc];
                    
                    // 더 짧은 경로를 찾았을 경우 업데이트
                    if (newCost < dist[nr][nc]) {
                        dist[nr][nc] = newCost;
                        pq.add(new Cell(newCost, nr, nc));
                    }
                } 
            }
        }

        // 최종 답은 (N-1, N-1) 지점까지의 최소 비용
        System.out.println(dist[N - 1][N - 1]);
    }
}
```

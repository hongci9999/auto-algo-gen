# 최소 비용 연결 트리 만들기
*java · 그래프 · 보통 · MST, 프림, 크루스칼*

## 입출력 환경

Java에서는 표준 입력을 받기 위해 BufferedReader와 StringTokenizer를 사용하는 것이 효율적이다.

## 문제

여러 개의 도시가 지도 위에 배치되어 있고, 각 도시 사이에는 도로를 놓을 수 있습니다. 각 도로는 고유한 비용(거리)을 가집니다.

여러분은 모든 도시를 연결하는 최소 비용의 도로망을 구축해야 합니다. 즉, 모든 도시가 서로 통신할 수 있도록 하면서도 총 건설 비용이 가장 적게 드는 연결 방식을 찾아야 합니다.

## 입력

첫째 줄에 간선의 개수 $M$, 둘째 줄에 정점(도시)의 개수 $N$이 주어진다. (1 <= M, N <= 100).
다음 $M$개의 줄에는 간선 정보가 주어지며, 각 줄은 `u v w` 형식으로 나타낸다. 여기서 $u$와 $v$는 간선 양 끝의 정점(도시)을 의미하며 $(1 	ext{부터 } N)$이다. $w$는 해당 간선의 비용(거리)이다.

## 출력

모든 도시를 연결하는 최소 비용의 총합을 한 숫자로 출력한다.

## 제약 조건

N, M <= 100. 간선 가중치 w는 1 이상 1000 이하이다. 시간 복잡도는 $O(M 	imes 	ext{log} M)$ 또는 이와 유사한 수준이면 충분하다.

## 예제 1

**입력**
```
6
5 10 2
1 2 3
2 3 4
1 3 5
2 5 8
3 5 9
```

**출력**
```
13
```

*모든 도시를 연결하는 최소 비용은 (1-2), (2-3), (1-3)을 제외한 간선 중 가장 낮은 조합으로 찾는다.*

## 예제 2

**입력**
```
3
4 8 10
1 2 1
2 3 1
```

**출력**
```
2
```

*세 개의 도시를 연결하는 최소 비용은 (1-2)와 (2-3) 간선을 이용하는 것이다.*

## 힌트

- 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다.
- 크루스칼 알고리즘이나 프림 알고리즘을 사용하여 해결할 수 있습니다.


## 알고리즘 요약

크루스칼 알고리즘 (Kruskal's Algorithm):
1. 모든 간선을 비용($w$)이 낮은 순서대로 정렬한다.
2. 정렬된 간선들을 하나씩 확인하며, 두 정점 $u$와 $v$가 이미 같은 연결 요소에 속해 있는지(사이클을 형성하는지)를 확인한다.
3. 만약 사이클을 형성하지 않는다면 (즉, $u$와 $v$가 아직 연결되어 있지 않다면), 해당 간선을 트리에 포함시키고 비용을 누적한다.
4. 모든 정점이 연결될 때까지 반복한다.

## 풀이 해설

풀이 해설: 이 문제는 주어진 그래프에서 모든 정점(도시)을 최소 비용으로 연결하는 '최소 신장 트리(Minimum Spanning Tree, MST)'를 찾는 문제입니다. 크루스칼 알고리즘을 사용하면 효율적으로 해결할 수 있습니다.

**아이디어:** 가장 적은 비용의 간선들부터 순차적으로 선택하여 사이클이 생기지 않도록 트리를 구성합니다.

**단계:**
1. **간선 저장 및 정렬:** 입력받은 모든 간선 $(u, v, w)$을 리스트에 저장하고, 이 리스트를 가중치 $w$가 오름차순으로 작아지는 순서대로 정렬합니다. (이 단계에서 가장 저렴한 도로부터 고려하게 됩니다.)
2. **Union-Find 구조 초기화:** 정점의 연결 상태를 효율적으로 관리하기 위해 Union-Find(Disjoint Set Union, DSU) 자료구조를 사용합니다. $N$개의 정점 각각을 독립된 집합으로 초기화합니다.
3. **간선 선택 및 비용 누적:** 정렬된 간선을 처음부터 끝까지 순회하며 다음 과정을 수행합니다:
    a. 간선 $(u, v, w)$를 가져옵니다.
    b. Union-Find의 `find(u)`와 `find(v)`를 사용하여 $u$와 $v$가 같은 집합에 속해 있는지 확인합니다.
    c. 만약 `find(u) != find(v)`라면 (즉, 이 간선을 추가해도 사이클이 발생하지 않는다면): 
        i. 총 비용에 $w$를 더합니다.
        ii. Union-Find의 `union(u, v)` 연산을 수행하여 $u$와 $v$가 같은 집합이 되도록 합칩니다.
4. **종료:** 모든 정점이 연결될 때까지 (또는 간선들을 모두 순회할 때까지) 반복하며, 최종 누적된 비용이 답이 됩니다. 이 과정은 전체적으로 필요한 최소 비용을 보장합니다.

**시간 복잡도:** 가장 시간이 많이 걸리는 부분은 $M$개의 간선을 정렬하는 부분($O(M 	imes 	ext{log} M)$)과 Union-Find 연산의 반복입니다. Union-Find는 거의 상수 시간(준-상수 시간 $	ext{O}(	ext{a}(N))$)으로 동작하므로, 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$이 됩니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

// 간선 정보를 담을 클래스
class Edge implements Comparable<Edge> {
    int u, v, w;

    public Edge(int u, int v, int w) {
        this.u = u;
        this.v = v;
        this.w = w;
    }

    // 가중치(비용)를 기준으로 오름차순 정렬을 위한 Comparator 구현
    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.w, other.w);
    }
}

// Union-Find (Disjoint Set Union) 구조체
class DSU {
    private int[] parent;
    
    public DSU(int n) {
        parent = new int[n + 1]; // 1부터 N까지 사용하므로 크기를 N+1로 설정
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }

    // 경로 압축을 사용하여 부모를 찾아 효율성을 높임
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        return parent[i] = find(parent[i]); // 재귀적 할당과 경로 압축
    }

    // 두 원소를 하나의 집합으로 합침
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) { // 이미 같은 집합이 아니라면 합치고 사이클을 만들지 않음
            parent[rootI] = rootJ;
            return true; // 성공적으로 연결됨
        } else {
            return false; // 이미 같은 집합임 (사이클 발생)
        }
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        // 빠른 입력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter pw = new PrintWriter(System.out);

        // 첫 줄: 간선의 개수 M
        int m = Integer.parseInt(br.readLine());
        // 둘째 줄: 정점의 개수 N
        String[] line2 = br.readLine().split("\s+");
        if (line2.length == 0) {
            // 입력이 비어있을 경우 처리 (예외 방지)
            pw.println(0);
            pw.flush();
            return;
        }
        int n = Integer.parseInt(line2[0]);

        List<Edge> edges = new ArrayList<>();

        // M개의 간선 정보 읽기 (u v w)
        for (int i = 0; i < m; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            if (!st.hasMoreTokens()) break;
            
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            int w = Integer.parseInt(st.nextToken());
            edges.add(new Edge(u, v, w));
        }

        // 1. 간선을 비용 기준으로 오름차순 정렬 (크루스칼 알고리즘의 핵심)
        Collections.sort(edges);

        // 2. Union-Find 구조 초기화 및 변수 설정
        DSU dsu = new DSU(n); 
        long minCost = 0; // 총 비용은 int 범위를 넘어갈 수 있으므로 long 사용
        int edgesCount = 0; // 트리에 포함된 간선의 개수 (N-1개가 되면 완성)

        // 3. 정렬된 간선을 순회하며 MST 구성 시도
        for (Edge edge : edges) {
            if (dsu.union(edge.u, edge.v)) { // union이 true를 반환하면 사이클을 만들지 않았다는 의미
                minCost += edge.w;
                edgesCount++;
                // N-1개의 간선을 찾으면 최소 신장 트리가 완성된 것이므로 종료 가능
                if (edgesCount == n - 1) {
                    break;
                }
            }
        }

        // 결과 출력
        pw.println(minCost);
        pw.flush();
    }
}
```

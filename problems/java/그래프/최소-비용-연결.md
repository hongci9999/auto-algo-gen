# 최소 비용 연결
*java · 그래프 · 보통 · MST, Union-Find, 크루스칼*

## 입출력 환경

Java에서 빠른 입출력을 위해 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

N개의 마을이 있고, 각 마을에는 고유한 ID가 부여되어 있습니다. 이들 마을을 연결하는 간선들이 주어지며, 각 간선은 두 마을을 잇고 특정 비용을 가집니다.
여러분이 해야 할 일은 모든 마을을 최소의 총비용으로 연결하는 것입니다. 즉, 최소 신장 트리(Minimum Spanning Tree, MST)를 구성해야 합니다.

간선의 개수 $M$과 마을의 개수 $N$이 주어지며, 각 간선은 (시작 마을 ID, 끝 마을 ID, 비용)의 형태로 주어집니다. 마을 ID는 1부터 N까지입니다.

## 입력

첫째 줄에 두 정수 M, N이 공백으로 구분되어 입력됩니다. (M: 간선의 개수, N: 마을의 개수)
다음 M줄에는 각 간선 정보가 주어지며, 각 행은 세 정수 (u, v, cost)로 구성됩니다. (u는 시작 마을 ID, v는 끝 마을 ID, cost는 간선 비용)

## 출력

모든 마을을 연결하는 데 필요한 최소 총비용을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 100,000
1 <= M <= 200,000
1 <= cost <= 1,000,000,000
시간 복잡도: O(M log M) 또는 O(M α(N)) 내외

## 예제 1

**입력**
```
7 8
1 2 3
1 3 1
2 3 5
2 4 2
3 4 6
4 5 1
3 5 3
```

**출력**
```
9
```

*주어진 간선들 중 최소 비용으로 모든 마을(8개)을 연결하는 트리의 총비용은 9입니다. (예: 1-2-4-5, 1-3, 3-5)*

## 예제 2

**입력**
```
3 4
1 2 10
2 3 5
1 3 1
```

**출력**
```
6
```

*세 마을(1, 2, 3)만 연결되어 있고 4번 마을은 고립 상태입니다. 모든 N개 마을을 연결하려면 필수적으로 연결 가능한 그래프여야 합니다. 이 경우 (1-3, 2-3)으로 최소 비용 6을 달성합니다.*

## 힌트

- MST를 구하는 대표적인 알고리즘인 크루스칼(Kruskal) 또는 프림(Prim) 알고리즘을 생각해보세요.
- 크루스칼 알고리즘은 모든 간선을 오름차순으로 정렬한 후, 사이클이 발생하지 않는 간선만 선택하는 방식입니다. 이 과정에서 Union-Find 자료구조가 핵심적으로 사용됩니다.


## 알고리즘 요약

최소 신장 트리(Minimum Spanning Tree, MST)를 구하는 문제입니다. 크루스칼 알고리즘을 이용합니다.
1. **정렬**: 모든 간선들을 비용(cost)을 기준으로 오름차순 정렬합니다.
2. **Union-Find (Disjoint Set Union, DSU)**: 각 마을이 속한 집합을 관리하는 자료구조를 사용합니다. 초기에는 N개의 마을이 각각 하나의 독립된 집합으로 존재합니다.
3. **탐색 및 연결**: 정렬된 간선들을 순서대로 탐색하며, 현재 간선의 양 끝 마을(u와 v)이 이미 같은 집합에 속해 있는지 확인합니다 (Find 연산). 만약 다르면 (즉, 사이클을 만들지 않는다면), 이 간선을 선택하고 총비용에 더한 후, u와 v를 하나의 집합으로 합칩니다 (Union 연산).
4. **종료 조건**: 모든 N개의 마을이 연결되어 최소한 $N-1$ 개의 간선이 선택되었거나, 혹은 모든 간선을 확인했을 때까지 반복합니다. (문제의 제약 조건상 1부터 N까지 모두 연결되어야 함을 가정하고 진행).

## 풀이 해설

풀이 해설: 크루스칼 알고리즘 적용

**아이디어**: 최소 비용으로 모든 정점(마을)을 연결하는 간선들의 집합을 찾는 것이 목표입니다. 이는 전형적인 MST 문제입니다.

**단계 1: 데이터 구조화 및 정렬 (O(M log M))**: 주어진 $M$개의 간선 정보를 저장한 후, 이들을 비용(`cost`) 기준으로 오름차순으로 정렬합니다. 가장 적은 비용부터 연결을 시도해야 최소 총비용이 보장됩니다.

**단계 2: Union-Find 초기화 (O(N))**: $N$개의 마을 각각에 대해 독립적인 집합을 갖도록 `parent` 배열 등을 사용하여 DSU 구조를 초기화합니다. 이 단계에서 각 마을은 자기 자신과 연결된 상태입니다.

**단계 3: 간선 선택 및 연결 (O(M * $\alpha$(N)) )**: 정렬된 간선을 처음부터 끝까지 순차적으로 탐색합니다. 현재 간선 $(u, v, cost)$에 대해 다음을 확인합니다:
1. `Find(u)`와 `Find(v)`가 다르면: 즉, $u$와 $v$가 아직 다른 연결 그룹에 속해 있다면, 이 간선을 선택합니다.
2. 총비용에 `cost`를 더하고, 두 마을의 집합을 하나로 합칩니다 (`Union(u, v)`).
3. 만약 `Find(u) == Find(v)`라면: 이미 같은 연결 그룹에 속해 있으므로, 이 간선을 선택할 경우 사이클이 발생합니다. 따라서 무시합니다.

**시간 복잡도**: 전체 시간 복잡도는 간선 정렬 시간 $O(M 	ext{ log } M)$과 Union-Find 연산 시간 $O(M 	ext{ } \alpha(N))$ 중 더 큰 쪽을 따릅니다. $\alpha(N)$은 아커만 함수의 역함수로, 매우 느리게 증가하여 사실상 상수($\approx 4$ 이하)로 간주됩니다. 따라서 전체 시간 복잡도는 $O(M 	ext{ log } M)$에 수렴합니다.

## 참고 코드 (java)

```java
import java.util.*;
import java.io.*;

// Union-Find 클래스 구현
class DSU {
    private int[] parent;
    private int n; // 노드 개수

    public DSU(int size) {
        this.n = size + 1; 
        parent = new int[this.n];
        for (int i = 1; i < this.n; i++) {
            parent[i] = i; // 초기에는 모든 노드가 자기 자신을 부모로 가짐
        }
    }

    // 경로 압축(Path Compression)을 이용한 Find 연산
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        parent[i] = find(parent[i]); // 재귀적으로 부모를 찾고 경로 압축 수행
        return parent[i];
    }

    // 두 집합을 합치는 Union 연산 (랭크 기반 최적화 생략 가능하나, 기본 구현만 사용)
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) {
            parent[rootJ] = rootI; // J의 루트를 I의 루트 아래로 붙임
            return true; // 성공적으로 합쳐짐
        } else {
            return false; // 이미 같은 집합에 속해 있음 (사이클 발생)
        }
    }
}

// 간선 정보를 담는 클래스
class Edge implements Comparable<Edge> {
    int u, v; 
    long cost;

    public Edge(int u, int v, long cost) {
        this.u = u;
        this.v = v;
        this.cost = cost;
    }

    // 비용을 기준으로 오름차순 정렬 (크루스칼 알고리즘의 핵심)
    @Override
    public int compareTo(Edge other) {
        return Long.compare(this.cost, other.cost);
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        // 빠른 입출력을 위한 setup
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter pw = new PrintWriter(System.out);

        // 첫 줄: M (간선 개수), N (마을 개수)
        StringTokenizer st = new StringTokenizer(br.readLine());
        int M = Integer.parseInt(st.nextToken());
        int N = Integer.parseInt(st.nextToken());

        // 간선 리스트 초기화
        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < M; i++) {
            StringTokenizer edgeSt = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(edgeSt.nextToken());
            int v = Integer.parseInt(edgeSt.nextToken());
            // 비용은 최대 10^9이므로 long 타입을 사용해야 함
            long cost = Long.parseLong(edgeSt.nextToken());
            edges.add(new Edge(u, v, cost));
        }

        // 1. 간선들을 비용 기준으로 정렬 (O(M log M))
        Collections.sort(edges);

        // 2. DSU 구조 초기화
        DSU dsu = new DSU(N); 

        long minCost = 0; // 최소 총비용 누적 변수
        int edgesCount = 0; // 선택된 간선의 개수

        // 3. 크루스칼 알고리즘 실행 (O(M * alpha(N))) 
        for (Edge edge : edges) {
            // u와 v가 아직 같은 집합에 속해 있지 않은지 확인
            if (dsu.union(edge.u, edge.v)) { // union이 true를 반환하면 합병 성공, 즉 사이클 아님
                minCost += edge.cost;
                edgesCount++;
                // 모든 N개의 마을을 연결하려면 최소한 N-1 개의 간선이 필요함.
                if (edgesCount == N - 1) {
                    break; 
                }
            }
        }
```

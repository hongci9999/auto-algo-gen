# 최소 비용으로 경로 만들기
*java · 그래프 · 보통 · 다익스트라, 최단경로*

## 입출력 환경

Java에서 표준 입력은 BufferedReader를 사용하여 읽고, StringTokenizer로 파싱하는 것이 효율적입니다. 모든 입력은 공백으로 구분되어 제공됩니다.

## 문제

N개의 도시와 여러 개의 도로가 존재합니다. 각 도로는 시작점과 끝점을 연결하며, 특정 비용을 가집니다.

이 도로들을 이용하여 모든 도시를 방문할 수 있는 하나의 경로(트리 구조)를 만들려고 합니다. 여기서 '모든 도시를 방문한다'는 것은 N개의 도시 노드가 모두 최소한 한 번씩 포함되어야 함을 의미합니다. 즉, 모든 도시는 연결되어야 하며, 이 연결된 그래프가 순환하지 않는 트리 구조여야 합니다.

다만, 단순히 MST(Minimum Spanning Tree)를 구하는 것이 아니라, 주어진 도로들 중 일부만을 선택하여 N개의 도시를 모두 포함하는 최소 비용의 '트리'를 만들 때, 그 트리가 반드시 특정 시작점을 지나가도록 강제할 필요는 없습니다. 단지 모든 노드가 연결되어야 합니다.

주어진 도로 정보만으로 모든 도시를 연결할 수 있다면, 그 중 가장 적은 총비용을 갖는 최소 비용의 스패닝 트리(Minimum Spanning Tree)를 구하는 문제입니다.

## 입력

첫 번째 줄에 N (도시 개수)과 M (도로 개수)이 주어집니다. 다음 M개의 줄에는 각 도로의 정보가 순서대로 주어지며, '시작 도시 끝 도시 비용' 형태로 구성됩니다. (1 <= 시작 도시, 끝 도시 <= N)

## 출력

모든 도시를 연결하는 최소 비용 스패닝 트리의 총비용을 한 정수로 출력합니다.

## 제약 조건

N: 2 ~ 100개
M: 1 ~ 4950개
도시 ID는 1부터 N까지입니다.
도로의 비용(가중치)은 양수이며, 최대 1,000,000입니다.

## 예제 1

**입력**
```
3 3
1 2 10
2 3 5
1 3 10
```

**출력**
```
15
```

*세 도시(1, 2, 3)를 연결하는 최소 비용의 스패닝 트리는 (1-2)와 (2-3) 경로를 선택하여 총비용 10 + 5 = 15입니다. (1-3)을 포함하면 사이클이 발생하거나 더 비쌉니다.*

## 예제 2

**입력**
```
4 5
1 2 3
1 3 7
2 3 5
2 4 8
3 4 9
```

**출력**
```
16
```

*네 도시를 연결하는 최소 비용의 스패닝 트리는 (1-2) [비용 3], (2-3) [비용 5], (2-4) [비용 8]을 선택하여 총비용 3 + 5 + 8 = 16입니다. Kruskal's 알고리즘이나 Prim's 알고리즘을 사용해야 합니다.*

## 힌트

- 이 문제는 전형적인 최소 스패닝 트리(MST, Minimum Spanning Tree) 문제입니다.
- 크루스칼(Kruskal) 알고리즘 또는 프림(Prim) 알고리즘 중 하나를 선택하여 구현할 수 있습니다. Union-Find 자료구조가 효율적입니다.


## 알고리즘 요약

이 문제는 주어진 가중치 그래프에서 모든 노드가 연결되도록 하는 최소 비용의 간선 집합을 찾는 문제입니다. 이는 전형적인 최소 스패닝 트리(MST) 문제이며, 크루스칼 알고리즘을 사용하는 것이 구현하기 가장 직관적입니다.

1. **간선 정렬**: 주어진 M개의 모든 도로(간선)를 비용(가중치)을 기준으로 오름차순으로 정렬합니다. 
2. **Union-Find (Disjoint Set)**: 간선의 순회와 동시에 Union-Find 자료구조를 사용하여 사이클 발생 여부를 판별합니다.
3. **트리 구축**: 가장 저렴한 간선부터 차례로 고려하며, 이 간선을 추가했을 때 이미 연결된 노드들 사이에 새로운 사이클을 만들지 않는 경우(즉, 두 끝점이 같은 집합에 속하지 않는 경우)만 선택하고 총 비용에 합산합니다.
4. **종료**: N-1개의 간선이 선택되어 모든 도시가 연결되면 탐색을 종료하고 총 비용을 반환합니다.

## 풀이 해설

풀이는 전형적인 최소 스패닝 트리(MST, Minimum Spanning Tree)를 구하는 문제입니다. 주어진 그래프에서 모든 노드를 최소 비용으로 연결하는 트리를 찾아야 합니다.

**아이디어:** 크루스칼(Kruskal) 알고리즘을 사용합니다. 이 알고리즘은 간선들을 비용이 낮은 순서대로 정렬한 후, 사이클을 만들지 않는 간선을 차례로 선택하여 MST를 구성하는 방식입니다.

**단계별 구현:**
1. **데이터 구조 준비:** 모든 도로 정보를 (비용, 시작점, 끝점) 튜플 형태로 저장합니다.
2. **정렬:** 이 도로 목록을 비용(가중치) 기준으로 오름차순 정렬합니다. 시간 복잡도는 $O(M 	imes 	ext{log} M)$입니다.
3. **Union-Find 초기화:** N개의 도시 각각에 대해 독립적인 집합(Set)으로 Union-Find 자료구조를 초기화합니다. (각 노드가 자기 자신을 대표로 가짐)
4. **간선 선택 및 검증:** 정렬된 도로 목록을 순회합니다.
   - 현재 간선의 시작점과 끝점을 각각 `find` 연산을 통해 집합의 대표 원소를 찾습니다.
   - 만약 두 끝점이 다른 대표 원소에 속한다면, 이 간선을 MST에 포함시키고 (총 비용에 더하고), `union` 연산을 수행하여 두 집합을 하나로 합칩니다. 
   - 같은 대표 원소에 속한다면(사이클 형성), 해당 간선은 무시합니다.
5. **종료 및 결과:** N-1개의 간선을 선택했거나, 모든 간선을 다 순회했을 때의 총 비용이 답입니다. (모든 노드가 연결되어야 하므로, 성공적으로 MST가 완성되었는지 확인해야 합니다.)

**시간 복잡도 분석:** 전체 시간 복잡도는 주로 간선 정렬($O(M 	ext{log} M)$)과 Union-Find 연산에 의해 결정됩니다. $M$번의 `find`와 `union` 연산은 최적화된 경우 거의 상수 시간에 가까우므로, 전체적으로는 **$O(M 	ext{log} M)$**이 됩니다.

## 참고 코드 (java)

```java
import java.util.*;

// 간선을 저장하는 클래스 (가중치, u, v)
class Edge implements Comparable<Edge> {
    int cost; 
    int u, v;

    public Edge(int cost, int u, int v) {
        this.cost = cost;
        this.u = u;
        this.v = v;
    }

    // 비용 기준으로 오름차순 정렬을 위한 Comparable 구현
    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.cost, other.cost);
    }
}

// Union-Find 자료구조 구현
class DSU { 
    private int[] parent;
    
    public DSU(int n) {
        parent = new int[n + 1]; // 1부터 N까지 사용하므로 크기 N+1
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }

    // 경로 압축(Path Compression)을 이용한 find 연산
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        return parent[i] = find(parent[i]); // 재귀 호출과 동시에 부모 포인터 최적화
    }

    // 두 원소를 합치는 union 연산
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);
        
        if (rootI != rootJ) { // 이미 같은 집합에 속해 있지 않다면 합친다. 
            parent[rootI] = rootJ; 
            return true; // 성공적으로 연결됨 (사이클 아님)
        } else {
            return false; // 이미 같은 집합에 속해 있음 (사이클 발생)
        }
    }
}
```

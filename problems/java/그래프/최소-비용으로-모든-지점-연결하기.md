# 최소 비용으로 모든 지점 연결하기
*java · 그래프 · 보통 · MST, 프림, 크루스칼*

## 입출력 환경

Java에서 입출력 시 BufferedReader와 StringTokenizer를 사용하여 효율적으로 처리합니다.

## 문제

여러 개의 지점들이 주어진 평면 좌표 위에 존재하며, 각 지점 간의 이동 비용은 두 지점 사이의 유클리드 거리(Euclidean Distance)로 결정됩니다. 모든 지점을 최소 비용으로 연결하는 최소 신장 트리(Minimum Spanning Tree, MST)의 총 비용을 구하는 문제입니다.

지점의 개수는 최대 100개이며, 좌표 값은 정수입니다. 거리는 소수점까지 계산해야 합니다.

## 입력

첫째 줄에 지점의 개수 N이 주어집니다. 
다음 N줄에 걸쳐 각 지점의 x좌표와 y좌표가 순서대로 주어집니다. (x y)

## 출력

최소 비용으로 모든 지점을 연결하는 최소 신장 트리의 총 비용을 소수점 이하 3째 자리까지 출력합니다.

## 제약 조건

N <= 100
좌표 값: -10000 <= x, y <= 10000

## 예제 1

**입력**
```
3
0 0
1 0
0 1
```

**출력**
```
1.000
```

*세 지점 (0,0), (1,0), (0,1)을 연결하는 최소 비용은 1.0입니다.*

## 예제 2

**입력**
```
4
0 0
1 1
0 1
1 0
```

**출력**
```
2.000
```

*네 지점을 모두 연결하는 최소 비용은 2.0입니다 (예: (0,0)-(1,0)-(0,1)-(1,1)의 경로는 아닙니다. (0,0)-(1,0)와 (0,1)-(1,1)을 연결하는 것이 최소입니다).*

## 예제 3

**입력**
```
2
5 5
5 5
```

**출력**
```
0.000
```

*두 지점이 같은 위치에 있으므로 비용은 0입니다.*

## 힌트

- 모든 지점을 연결하는 최소 비용의 문제는 최소 신장 트리(MST) 문제입니다.
- 간선 가중치는 유클리드 거리를 사용합니다.
- 크루스칼 알고리즘이나 프림 알고리즘을 활용할 수 있습니다.


## 알고리즘 요약

이 문제는 모든 지점 쌍을 간선으로 간주하고, 간선의 가중치를 유클리드 거리로 계산한 후, 최소 신장 트리를 찾는 문제입니다. 크루스칼 알고리즘(Kruskal's Algorithm)을 사용하는 것이 가장 직관적입니다. 모든 간선을 간선 가중치 순으로 정렬하고, 유니온-파인드(Union-Find) 자료구조를 이용해 사이클이 발생하지 않도록 선택합니다.

## 풀이 해설

### 1. 문제 이해 및 접근 방식
이 문제는 N개의 지점을 최소 비용으로 연결하는 최소 신장 트리(MST)를 찾는 문제입니다. 각 지점 사이의 비용은 유클리드 거리($sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$)를 사용합니다.

MST를 찾는 대표적인 알고리즘인 크루스칼(Kruskal) 알고리즘을 사용합니다.

### 2. 알고리즘 단계 (크루스칼)
1. **모든 간선 생성 및 가중치 계산**: N개의 지점이 있다면, 모든 지점 쌍 $(i, j)$에 대해 간선 $(i, j)$를 만들고, 그 가중치 $w_{ij}$를 유클리드 거리로 계산합니다. 총 간선의 개수는 $O(N^2)$개입니다.
2. **간선 정렬**: 계산된 모든 간선들을 가중치 오름차순으로 정렬합니다.
3. **MST 구성 (Union-Find 사용)**: 정렬된 간선들을 순회하며, 두 정점 $i$와 $j$를 연결하는 간선 $(i, j)$를 선택할 때, 만약 $i$와 $j$가 이미 같은 연결 요소에 속해 있다면 (사이클 발생), 이 간선은 무시합니다. 그렇지 않다면, 이 간선을 MST에 포함시키고, $i$와 $j$의 연결 요소를 합칩니다 (Union). 이 과정을 $N-1$개의 간선이 선택될 때까지 반복합니다.
4. **결과 합산**: 선택된 모든 간선의 가중치를 합산하여 최종 최소 비용을 구합니다.

### 3. 시간 및 메모리 복잡도
*   **시간 복잡도**: 간선 생성 및 정렬에 $O(N^2 	ext{ log}(N^2)) = O(N^2 	ext{ log} N)$이 걸립니다. Union-Find 연산은 거의 상수 시간 $O(	ext{a}(	ext{N}))$에 가까우므로, 전체 시간 복잡도는 $O(N^2 	ext{ log} N)$이 됩니다. (N=100이므로 충분히 빠릅니다.)
*   **메모리 복잡도**: $O(N^2)$ 간선을 저장해야 하므로 $O(N^2)$입니다.

### 4. 구현 시 주의사항
*   유클리드 거리 계산 시 `Math.sqrt()`를 사용하여 부동 소수점 처리를 해야 합니다.
*   Union-Find 자료구조를 구현할 때, 경로 압축(Path Compression)과 계층 균형(Union by Rank/Size)을 적용하여 효율성을 높여야 합니다.

## 참고 코드 (java)

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Scanner;
import java.util.Arrays;

class Point {
    int x, y;
    public Point(int x, int y) { this.x = x; this.y = y; }
}

class Edge implements Comparable<Edge> {
    int u, v;
    double weight;

    public Edge(int u, int v, double weight) {
        this.u = u; this.v = v; this.weight = weight;
    }

    @Override
    public int compareTo(Edge other) {
        // 가중치가 작은 순서대로 정렬
        return Double.compare(this.weight, other.weight);
    }
}

class UnionFind {
    private int[] parent;
    private int[] rank;

    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i; // 자기 자신을 부모로 지정
            rank[i] = 0; // 초기 랭크 0
        }
    }

    // Find: 경로 압축 적용
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        parent[i] = find(parent[i]); // 재귀적으로 부모를 찾아 경로 압축
        return parent[i];
    }

    // Union: 랭크 기반 합치기
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) {
            // 랭크가 낮은 트리를 높은 트리 아래에 붙임
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                // 랭크가 같으면 어느 쪽을 root로 하고 랭크를 증가시킴
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 합쳐짐
        }
        return false; // 이미 같은 집합에 속함 (사이클 발생)
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 1. 지점 개수 N 입력
        int N = scanner.nextInt();
        
        Point[] points = new Point[N];
        for (int i = 0; i < N; i++) {
            int x = scanner.nextInt();
            int y = scanner.nextInt();
            points[i] = new Point(x, y);
        }

        // 2. 모든 간선 생성 및 가중치 계산
        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < N; i++) {
            for (int j = i + 1; j < N; j++) {
                // 유클리드 거리 계산: sqrt((x2-x1)^2 + (y2-y1)^2)
                double dx = points[i].x - points[j].x;
                double dy = points[i].y - points[j].y;
                double weight = Math.sqrt(dx * dx + dy * dy);
                edges.add(new Edge(i, j, weight));
            }
        }

        // 3. 간선 정렬 (가중치 오름차순)
        Collections.sort(edges);

        // 4. MST 구성 (크루스칼 알고리즘)
        UnionFind uf = new UnionFind(N);
        double totalMinCost = 0.0;
        int edgesCount = 0;

        for (Edge edge : edges) {
            // 사이클 발생 여부 확인
            if (uf.union(edge.u, edge.v)) {
                totalMinCost += edge.weight;
                edgesCount++;
            }
            // N-1개의 간선이 선택되면 종료 (트리 완성)
            if (edgesCount == N - 1) {
                break;
            }
        }

        // 5. 결과 출력 (소수점 3째 자리까지) 
        System.out.printf(java.util.Locale.US, "%.3f\n", totalMinCost);
    }
}
```

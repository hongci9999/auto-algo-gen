# 섬의 개수 세기
*java · 그래프 · 보통 · DFS, BFS, 그리드*

## 입출력 환경

Java에서 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하여 효율적으로 그리드 데이터를 처리하는 것이 좋습니다.

## 문제

당신은 2차원 배열로 표현된 지도를 받았습니다. 이 지도는 '1'로 표시된 육지(Land)와 '0'으로 표시된 바다(Water)로 이루어져 있습니다.

문제는 이 지도에 존재하는 '육지 덩어리(섬)'가 총 몇 개인지 세는 것입니다. 육지 덩어리는 상하좌우로 연결된 '1'들의 집합으로 정의됩니다.

즉, 상하좌우로 연결된 '1'들이 하나의 섬을 이룹니다. 모든 섬을 찾아서 그 개수를 정수 하나로 출력해야 합니다.

## 입력

첫 번째 줄에는 행의 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 행은 공백으로 구분된 N개의 문자('1' 또는 '0')로 이루어진 그리드 형태입니다.

## 출력

찾아낸 섬의 총 개수(정수)를 출력합니다.

## 제약 조건

1 <= N <= 50 (행의 개수)
1 <= M <= 50 (열의 개수)
시간 복잡도: O(N * M) 이하

## 예제 1

**입력**
```
3
1 1 1
0 1 0
1 1 1
```

**출력**
```
2
```

*좌측 상단 3x3 영역에 두 개의 연결된 육지 덩어리(섬)가 존재합니다.*

## 예제 2

**입력**
```
3
0 0 0
0 1 0
0 0 0
```

**출력**
```
1
```

*중앙에 고립된 하나의 육지 덩어리가 있습니다.*

## 힌트

- DFS(깊이 우선 탐색) 또는 BFS(너비 우선 탐색)를 사용하여 연결된 영역을 탐색하세요.
- 이미 방문했거나 바다인 칸은 다시 탐색하지 않도록 표시(예: '0'으로 변경)하는 것이 중요합니다.


## 알고리즘 요약

DFS/BFS를 이용한 그리드 순회 및 영역 탐색. 전체 그리드를 순회하면서 '1'을 만나면, 이를 새로운 섬으로 간주하고 카운트를 1 증가시킨 후, DFS/BFS를 통해 이 섬을 이루는 모든 연결된 '1'들을 방문 처리(예: '0'으로 변경)합니다. 이 과정을 반복하여 모든 섬을 찾습니다.

## 풀이 해설

아이디어:
이 문제는 전형적인 '연결 요소 찾기(Connected Component)' 문제입니다. 그리드 전체를 순회하면서 아직 방문하지 않은 육지('1')를 만날 때마다, 그것이 새로운 섬의 시작점이라고 간주하고 카운트를 1 증가시킵니다.

단계:
1. 변수 `islandCount`를 0으로 초기화합니다.
2. 0부터 N-1까지의 행(r)과 0부터 M-1까지의 열(c)을 순회합니다.
3. 만약 `grid[r][c]`가 '1'이라면, 이는 새로운 섬의 시작점입니다. 따라서 `islandCount`를 1 증가시킵니다.
4. 그리고 이 섬 전체를 탐색하여 방문 처리해야 합니다. 이때 DFS(깊이 우선 탐색)를 사용합니다. `dfs(r, c)` 함수를 호출합니다.
5. `dfs(r, c)` 함수 내에서는 다음을 수행합니다:
    a. 현재 위치가 경계를 벗어났거나, 바다('0')이거나, 이미 방문 처리된 경우(재귀 종료).
    b. 현재 위치의 값(grid[r][c])을 '0'으로 변경하여 방문 처리합니다. (이것이 핵심입니다.)
    c. 상하좌우 네 방향에 대해 재귀적으로 `dfs`를 호출합니다.
6. 모든 순회가 끝날 때까지 이 과정을 반복하면, `islandCount`에 최종 섬의 개수가 저장됩니다.

시간 복잡도: 그리드의 모든 칸을 최대 한 번씩만 방문하므로, 시간 복잡도는 O(N * M)입니다. 공간 복잡도는 DFS 재귀 호출 스택 때문에 O(N * M)이 될 수 있습니다.

## 참고 코드 (java)

```java
import java.util.Scanner;
import java.util.Stack;

public class Solution {

    // 그리드와 크기는 클래스 멤버 변수로 설정하여 접근성을 높입니다.
    static char[][] grid;
    static int R, C;

    // DFS를 사용하여 연결된 육지를 '0'으로 바꿔 방문 처리합니다.
    public static void dfs(int r, int c) {
        // 1. 경계 체크: 벗어났거나, 바다이거나, 이미 방문 처리된 경우 종료
        if (r < 0 || r >= R || c < 0 || c >= C || grid[r][c] == '0') {
            return;
        }

        // 2. 방문 처리: 현재 칸을 '0'으로 변경하여 다시 카운트되는 것을 방지
        grid[r][c] = '0';

        // 3. 상하좌우 재귀 호출
        dfs(r + 1, c); // 아래
        dfs(r - 1, c); // 위
        dfs(r, c + 1); // 오른쪽
        dfs(r, c - 1); // 왼쪽
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // N (행의 개수) 입력
        if (!scanner.hasNextInt()) return;
        R = scanner.nextInt();
        C = scanner.nextInt();
        
        // 그리드 배열 초기화
        grid = new char[R][C];

        // 그리드 데이터 입력 (공백으로 구분된 문자열 처리)
        for (int i = 0; i < R; i++) {
            for (int j = 0; j < C; j++) {
                grid[i][j] = scanner.next().charAt(0);
            }
        }
        
        scanner.close();

        int islandCount = 0;

        // 전체 그리드를 순회하며 섬 찾기
        for (int i = 0; i < R; i++) {
            for (int j = 0; j < C; j++) {
                // '1'을 만나면 새로운 섬의 시작점임
                if (grid[i][j] == '1') {
                    islandCount++;
                    // 이 섬 전체를 탐색하여 방문 처리('0'으로 변경)합니다.
                    dfs(i, j);
                }
            }
        }

        System.out.println(islandCount);
    }
}
```

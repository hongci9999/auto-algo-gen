# 최소 비용으로 연결되는 간선
*java · 그래프 · 보통 · 최소신장트리, MST, 크루스칼*

## 입출력 환경

Java에서 표준 입력(System.in)을 사용하여 데이터를 읽고, 결과는 표준 출력(System.out)으로 출력합니다.

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 연결 가능한 간선이 존재합니다. 각 간선은 고유한 비용을 가집니다. 이 도시들을 모두 연결하는 데 필요한 최소 비용을 구하는 문제가 주어집니다. 즉, 주어진 간선들로 구성된 그래프에서 모든 정점을 연결하는 최소 비용의 간선들의 집합(Minimum Spanning Tree, MST)의 총 비용을 구하세요.

간선 정보는 (도시 A, 도시 B, 비용)의 튜플 형태로 주어집니다.

## 입력

첫 번째 줄에 간선의 총 개수 M이 주어집니다.
다음 M개의 줄에 걸쳐 각 간선의 정보가 주어집니다. 각 줄은 "A B C" 형식으로, A는 출발 도시 (1부터 N), B는 도착 도시 (1부터 N), C는 간선의 비용입니다.

## 출력

모든 도시를 연결하는 최소 비용의 합계를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 1000 (도시의 개수)
1 <= M <= 5000 (간선의 개수)
1 <= C <= 10000 (비용)
(모든 도시가 연결되어 있다고 가정합니다.)

## 예제 1

**입력**
```
7
1 2 3
1 3 2
2 3 1
2 4 5
3 4 4
3 5 6
4 5 1
```

**출력**
```
7
```

*주어진 간선들로 MST를 구성했을 때의 최소 비용 합계입니다. (간선: (2,3,1), (1,3,2), (4,5,1), (1,2,3) 또는 (1,3,2) 등)*

## 예제 2

**입력**
```
3
1 2 10
2 3 5
1 3 12
```

**출력**
```
15
```

*세 도시를 모두 연결하는 최소 비용은 (1-2)와 (2-3) 간선을 사용하는 15입니다.*

## 힌트

- 이 문제는 최소 신장 트리(MST)를 찾는 문제입니다.
- 크루스칼 알고리즘(Kruskal's Algorithm)이나 프림 알고리즘(Prim's Algorithm)을 사용할 수 있습니다.


## 알고리즘 요약

크루스칼 알고리즘을 사용합니다. 간선들을 비용(가중치)이 낮은 순서부터 정렬한 후, 간선들이 연결하는 두 정점이 이미 같은 집합에 속해 있는지 확인합니다. 만약 속하지 않는다면, 해당 간선을 MST에 포함시키고 두 정점을 같은 집합으로 합칩니다. 이 과정을 모든 정점이 하나의 집합이 될 때까지 반복합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 주어진 간선들로 구성된 그래프의 최소 신장 트리(MST)의 총 비용을 구하는 문제입니다. 간선이 많고 정점의 개수가 비교적 작으므로, 간선들을 정렬하여 순차적으로 검사하는 크루스칼 알고리즘이 효율적입니다.

단계:
1. **데이터 구조화**: 모든 간선(A, B, C)을 저장합니다.
2. **정렬**: 이 간선들을 비용 C를 기준으로 오름차순 정렬합니다.
3. **Union-Find (Disjoint Set Union, DSU) 초기화**: N개의 정점 각각을 독립적인 집합으로 초기화합니다. DSU는 두 정점이 같은 연결 요소에 속하는지(Find) 또는 두 연결 요소를 합칠지(Union)를 빠르게 처리하게 해줍니다.
4. **MST 구성**: 정렬된 간선들을 순회하면서 다음을 확인합니다.
    a. 간선 (A, B, C)를 가져옵니다.
    b. A와 B가 이미 같은 집합에 속해 있는지 DSU의 Find 연산을 통해 확인합니다.
    c. 만약 A와 B가 다른 집합에 속해 있다면 (즉, 이 간선을 추가해도 사이클이 발생하지 않는다면), 이 간선을 MST에 포함시키고 총 비용에 C를 더합니다. 이후 DSU의 Union 연산을 통해 A와 B의 집합을 합칩니다.
5. **결과 반환**: 모든 간선 검사를 마친 후의 총 비용이 최소 비용입니다.

시간 복잡도: 간선 정렬에 $O(M 	imes 	ext{log} M)$ 시간이 소요됩니다. 이후 DSU 연산은 거의 상수 시간($	ext{O}(	ext{A}(	ext{N}))$)이므로, 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

// 간선 정보를 담는 클래스
class Edge implements Comparable<Edge> {
    int u, v, cost;

    public Edge(int u, int v, int cost) {
        this.u = u;
        this.v = v;
        this.cost = cost;
    }

    // 비용(cost)을 기준으로 오름차순 정렬을 위한 Comparator 구현
    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.cost, other.cost);
    }
}

// Union-Find (Disjoint Set Union) 구조체
class DSU {
    private int[] parent;
    private int[] rank;

    public DSU(int n) {
        parent = new int[n + 1];
        rank = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i; // 각 정점은 자신을 부모로 가짐
            rank[i] = 0; // 초기 랭크는 0
        }
    }

    // 경로 압축을 사용하여 부모를 찾음
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        parent[i] = find(parent[i]); // 재귀적으로 부모를 찾고 경로 압축
        return parent[i];
    }

    // 두 집합을 합침 (랭크 기반 합치기)
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) {
            // 랭크가 낮은 쪽을 높은 쪽의 자식으로 붙임
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                // 랭크가 같으면 임의로 하나를 부모로 하고 랭크를 증가시킴
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 성공적으로 합쳐짐
        }
        return false; // 이미 같은 집합에 속해 있음 (사이클 발생)
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        // 빠른 입력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 줄: 간선의 개수 M
        String line = br.readLine();
        if (line == null || line.isEmpty()) return; // 입력이 없을 경우 종료
        int M = Integer.parseInt(line.trim());
        
        List<Edge> edges = new ArrayList<>();
        int maxN = 0; // 최대 도시 번호를 찾기 위함

        // 다음 M개의 줄: 간선 정보 읽기
        for (int i = 0; i < M; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            int cost = Integer.parseInt(st.nextToken());
            edges.add(new Edge(u, v, cost));
            maxN = Math.max(maxN, Math.max(u, v)); // N은 최대 도시 번호로 가정
        }
        
        // 1. 간선들을 비용 기준으로 오름차순 정렬
        Collections.sort(edges);
        
        // 2. DSU 초기화 (N은 최대 도시 번호까지 커버해야 함)
        DSU dsu = new DSU(maxN);
        
        long minCost = 0; // 최소 비용 합계를 저장할 변수
        int edgesCount = 0; // MST에 포함된 간선의 개수

        // 3. 크루스칼 알고리즘 실행
        for (Edge edge : edges) {
            // 이미 같은 집합에 속해 있다면 (사이클 발생) 무시
            if (dsu.find(edge.u) != dsu.find(edge.v)) {
                // 두 정점이 다른 집합에 속해 있다면, 간선 추가 및 합치기
                dsu.union(edge.u, edge.v);
                minCost += edge.cost;
                edgesCount++;
            }
        }
        
        // 참고: N개의 정점이 모두 연결되려면 최소 N-1개의 간선이 필요합니다.
        // 문제 제약상 모든 도시가 연결되어 있다고 가정하므로, minCost가 답입니다.
        
        System.out.println(minCost);
    }
}
```

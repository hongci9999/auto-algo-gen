# 가장 빠른 경로 찾기
*java · 그래프 · 보통 · BFS, 최단거리*

## 입출력 환경

입력은 표준 입력(System.in)을 사용하며, 좌표는 long형으로 처리해야 합니다. 최종 출력 시에는 double 형식을 사용하여 소수점 정밀도를 맞춰야 합니다.

## 문제

N개의 방과 그 사이를 잇는 길이 있습니다. 각 길에는 고유한 시간이 소요됩니다.
여러분이 시작 지점에서 목표 지점까지 가는 가장 빠른 경로를 찾아야 합니다.
경로는 직선으로 연결되어 있으며, 각 장소(방)는 (x, y) 좌표로 표현됩니다.

두 장소 A와 B 사이의 거리는 유클리드 거리 $\sqrt{(x_A - x_B)^2 + (y_A - y_B)^2}$를 따르며, 이 거리가 곧 이동 시간입니다. 모든 경로는 양수입니다.

## 입력

첫째 줄에 방의 개수 N이 주어집니다. 
다음 N줄에는 각 방의 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다.
마지막 줄에는 시작 지점 $S$와 목표 지점 $T$의 좌표가 공백으로 구분되어 주어집니다.

## 출력

시작 지점에서 목표 지점까지 갈 수 있는 최소 이동 시간을 실수 형태로 출력합니다. 소수점 넷째 자리까지 반올림하여 출력해야 합니다.

## 제약 조건

N: 2 $\le$ N $\le$ 50\n좌표 범위: $-10^9 \le x, y \le 10^9$

## 예제 1

**입력**
```
3
0 0
1 1
2 2
0 0 2 2
```

**출력**
```
2.8284
```

*시작(0,0) -> (1,1) -> 목표(2,2). 거리는 $\sqrt{2} + \sqrt{2} = 2\sqrt{2}$ 입니다.*

## 예제 2

**입력**
```
4
0 0
5 0
0 5
5 5
0 5 5 0
```

**출력**
```
5.0000
```

*시작(0,5) -> (0,0) -> 목표(5,0). 거리는 $5 + 5 = 10$ 이 아닌, 시작에서 가까운 방을 거쳐 가는 최단 경로가 아닙니다. 직접 연결된 방들만 고려합니다.*

## 힌트

- 이 문제는 가중치가 있는 그래프의 최단 경로 문제입니다.
- 노드(방) 간의 거리를 계산하는 함수를 미리 구현하면 좋습니다. (유클리드 거리)


## 알고리즘 요약

다익스트라 알고리즘 (Dijkstra's Algorithm)

## 풀이 해설

아이디어: 주어진 문제는 N개의 방을 노드로, 각 방 쌍 사이의 유클리드 거리를 가중치로 하는 완전 그래프에서 최단 경로를 찾는 문제입니다. 출발점과 도착점은 기존 N개 방의 좌표 외에 추가적인 두 지점으로 간주해야 합니다.

단계:
1. **노드 설정:** 총 노드의 개수는 $N+2$입니다. 첫 $N$개의 노드는 주어진 방들, $N+1$번째 노드를 시작점(S), $N+2$번째 노드를 목표점(T)으로 간주합니다.
2. **거리 계산:** 두 좌표 $(x_1, y_1)$과 $(x_2, y_2)$ 사이의 거리는 $\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$입니다. 이 함수를 사용하여 모든 간선 가중치를 계산합니다.
3. **그래프 구축:** $N+2$개의 노드를 가진 인접 리스트 형태의 그래프(Adjacency List) 또는 간선 목록을 구성하고, 각 간선의 가중치로 위에서 구한 거리를 저장합니다.
4. **최단 경로 탐색:** 시작점 S부터 목표점 T까지의 최단 경로를 찾기 위해 다익스트라 알고리즘을 적용합니다. 우선순위 큐(Priority Queue)를 사용하여 현재까지의 최소 거리가 가장 짧은 노드를 반복적으로 추출하며 방문하는 과정을 통해 최단 거리를 계산할 수 있습니다.
5. **결과 출력:** 다익스트라 알고리즘이 종료된 후, 목표점 T에 도달했을 때 기록된 누적 거리가 최종 답입니다. 이 값을 소수점 넷째 자리까지 반올림하여 출력합니다.

시간 복잡도: $O((V+E) 	ext{log } V)$ 또는 $O(E 	ext{log } V)$, 여기서 $V$는 노드 수($N+2$), $E$는 간선 수입니다. 이 문제에서는 완전 그래프에 가깝기 때문에 $E = O(N^2)$이므로, 시간 복잡도는 $O(N^2 	ext{log } N)$ 정도가 됩니다.

## 참고 코드 (java)

```java
import java.util.*;

class Point {
    long x, y;
    int id;
    public Point(long x, long y, int id) { this.x = x; this.y = y; this.id = id; }
}

// 다익스트라 알고리즘을 위한 상태 클래스: (거리, 노드 ID)
class State implements Comparable<State> {
    double distance;
    int nodeId;

    public State(double distance, int nodeId) { this.distance = distance; this.nodeId = nodeId; }

    @Override
    public int compareTo(State other) {
        return Double.compare(this.distance, other.distance);
    }
}

public class Main {

    // 두 점 사이의 유클리드 거리 계산 (long형 좌표 사용)
    private static double calculateDistance(Point p1, Point p2) {
        long dx = p1.x - p2.x;
        long dy = p1.y - p2.y;
        // Math.sqrt()는 double을 반환하므로 결과가 double이 됩니다.
        return Math.sqrt(dx * dx + dy * dy);
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in); // 실제 환경에서는 BufferedReader 등을 사용해야 함

        // 1. 방의 개수 N을 읽음
        int N = scanner.nextInt();
        
        // 2. 모든 좌표를 저장할 배열 생성 (N+2: N개 방 + 시작점 + 목표점)
        Point[] points = new Point[N + 2];
        for (int i = 0; i < N; i++) {
            long x = scanner.nextLong();
            long y = scanner.nextLong();
            points[i] = new Point(x, y, i); // 방들: ID 0 ~ N-1
        }

        // 시작점 (ID N)과 목표점 (ID N+1) 좌표 읽기
        long startX = scanner.nextLong();
        long startY = scanner.nextLong();
        long endX = scanner.nextLong();
        long endY = scanner.nextLong();

        points[N] = new Point(startX, startY, N); // 시작점 S
        points[N+1] = new Point(endX, endY, N + 1); // 목표점 T
        
        // 3. 다익스트라 알고리즘 초기화
        double[] dist = new double[N + 2];
        Arrays.fill(dist, Double.MAX_VALUE);
        
        // 시작 지점을 출발점으로 설정 (ID N)
        dist[N] = 0.0;
        PriorityQueue<State> pq = new PriorityQueue<>();
        pq.add(new State(0.0, N)); // (거리, 노드 ID)

        // 4. 다익스트라 실행
        while (!pq.isEmpty()) {
            State current = pq.poll();
            double d = current.distance;
            int u = current.nodeId;

            if (d > dist[u]) { // 이미 더 짧은 경로가 발견되었다면 무시
                continue;
            }
            
            // 모든 다른 노드 v에 대해 간선 검사 (완전 그래프 구조)
            for (int v = 0; v < N + 2; v++) {
                if (u == v) continue;
                
                // u에서 v로 이동할 때의 거리(가중치)
                double weight = calculateDistance(points[u], points[v]);
                
                // 이완 과정 (Relaxation)
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    pq.add(new State(dist[v], v));
                }
            }
        }
        
        // 5. 결과 출력: 목표 지점 (ID N+1)의 최단 거리
        double result = dist[N + 1];
        System.out.printf(Locale.ENGLISH, "%.4f\n");
    }
```

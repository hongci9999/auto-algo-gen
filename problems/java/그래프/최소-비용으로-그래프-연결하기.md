# 최소 비용으로 그래프 연결하기
*java · 그래프 · 보통 · MST, 프림, 크루스칼*

## 입출력 환경

Java에서 표준 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 도로를 건설할 수 있습니다. 각 쌍 (i, j) 사이의 도로 건설 비용은 주어진 비용 배열 `cost[i][j]`로 주어집니다. 이 도시들을 모두 연결하는 데 필요한 최소 비용을 구하세요. 모든 도시는 최소한 하나의 도로를 통해 연결되어야 합니다. 즉, 모든 도시를 포함하는 최소 신장 트리(Minimum Spanning Tree, MST)의 비용을 구하는 문제입니다.

## 입력

첫째 줄에 도시의 개수 N (1 <= N <= 100)이 주어집니다.
다음 N개의 줄에 걸쳐 N개의 비용이 주어지는데, i번째 줄의 j번째 값은 도시 i와 도시 j 사이의 도로 건설 비용 cost[i][j]입니다. (단, cost[i][i] = 0 이고, cost[i][j] = cost[j][i] 입니다.)

## 출력

모든 도시를 연결하는 최소 비용을 한 정수로 출력합니다.

## 제약 조건

N <= 100. 비용은 1 이상 10000 이하입니다. (총 비용은 int 범위를 넘을 수 있습니다.)

## 예제 1

**입력**
```
3
0 10 10
10 0 5
10 5 0
```

**출력**
```
15
```

*도시 1-2 (10), 도시 2-3 (5)를 연결하는 것이 최소 비용입니다. (혹은 1-3(10), 2-3(5)도 가능하나, 1-2(10)가 가장 적절합니다.)*

## 예제 2

**입력**
```
4
0 3 5 6
3 0 2 7
5 2 0 1
6 7 1 0
```

**출력**
```
11
```

*MST 알고리즘(크루스칼 또는 프림)을 사용합니다. 가장 저렴한 세 개의 간선(3, 2, 1)을 선택하여 연결합니다. 총 비용은 6입니다.*

## 힌트

- 간선(edge)과 노드(vertex)를 분리하여 생각하세요.
- MST(Minimum Spanning Tree) 개념을 이해해야 합니다.
- 크루스칼 알고리즘이나 프림 알고리즘을 적용할 수 있습니다.


## 알고리즘 요약

이 문제는 최소 신장 트리(MST)를 구하는 문제입니다. 크루스칼(Kruskal) 알고리즘을 사용하면 모든 간선을 비용순으로 정렬한 후, 사이클을 만들지 않는 간선들을 차례로 선택하여 트리를 구성하고 그 비용을 합산할 수 있습니다. 유니온-파인드(Union-Find) 자료구조를 사용하여 사이클 여부를 효율적으로 체크할 수 있습니다.

## 풀이 해설

### 1. 문제 이해 및 목표 설정
주어진 N개의 도시와 도시 간의 연결 비용(간선)을 이용하여, 모든 도시를 연결하는 최소 비용의 연결망(최소 신장 트리, MST)을 찾는 것이 목표입니다.

### 2. 알고리즘 선택 (크루스칼 알고리즘)
MST를 구하는 대표적인 방법은 프림(Prim)과 크루스칼(Kruskal)이 있습니다. 여기서는 크루스칼 알고리즘을 사용하겠습니다. 크루스칼은 모든 간선을 비용이 낮은 순서대로 정렬한 후, 사이클을 만들지 않는 간선을 하나씩 선택하는 방식입니다.

### 3. 단계별 구현
**단계 1: 간선 리스트 생성 및 정렬**
입력된 비용 행렬 `cost[i][j]`를 순회하며, `i < j`인 모든 쌍에 대해 간선(edge)을 리스트로 만듭니다. 각 간선은 `{비용, 도시A, 도시B}` 형태를 가집니다. 이 리스트를 비용 오름차순으로 정렬합니다.

**단계 2: 유니온-파인드 구조 초기화**
N개의 도시(노드)에 대해 유니온-파인드(Union-Find) 자료구조를 초기화합니다. 각 도시는 독립적인 집합을 이룹니다.

**단계 3: MST 구성 및 비용 계산**
정렬된 간선 리스트를 순회하며 다음을 수행합니다:
1. 현재 간선 (u, v)와 비용 w를 가져옵니다.
2. `find(u)`와 `find(v)`를 호출하여 u와 v가 같은 집합에 속하는지 확인합니다.
3. 만약 `find(u) != find(v)`라면, 이 간선을 선택해도 사이클이 생기지 않습니다. 따라서 이 간선을 MST에 포함시키고, 총 비용에 w를 더하며, `union(u, v)`를 호출하여 u와 v를 같은 집합으로 합칩니다.
4. 만약 `find(u) == find(v)`라면, 이 간선은 이미 같은 집합에 속한 도시들을 연결하므로 사이클을 만듭니다. 이 간선은 무시합니다.

**단계 4: 종료**
모든 간선을 확인하거나, 또는 N-1개의 간선을 선택했을 때 종료합니다. 최종적으로 누적된 총 비용이 최소 연결 비용입니다.

### 4. 시간 복잡도 분석
*   간선 개수 E: $O(N^2)$ (최대 $N(N-1)/2$개)
*   간선 정렬: $O(E 	imes 	ext{log} E) = O(N^2 	ext{log} N)$ 
*   유니온-파인드 연산: $O(E 	imes 	ext{alpha}(N))$, 여기서 $	ext{alpha}(N)$은 매우 느리게 증가하는 역 아커만 함수로 사실상 상수 시간으로 간주합니다.

따라서 전체 시간 복잡도는 $O(N^2 	ext{log} N)$ 입니다. $N 	ext{이 } 100$이므로 충분히 빠른 시간 복잡도입니다.

## 참고 코드 (java)

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.Scanner;

class Edge {
    int u, v, weight;
    public Edge(int u, int v, int weight) {
        this.u = u; 
        this.v = v; 
        this.weight = weight;
    }
}

class UnionFind {
    private int[] parent;
    
    public UnionFind(int n) {
        parent = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }
    }

    // 경로 압축을 사용하여 find 연산 최적화
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        return parent[i] = find(parent[i]);
    }

    // 두 요소를 합치기 (Union by Rank/Size를 사용하지 않아도 충분함)
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);
        
        if (rootI != rootJ) {
            parent[rootI] = rootJ; // rootI를 rootJ 아래로 붙임
            return true; // 성공적으로 합쳐짐
        }
        return false; // 이미 같은 집합임
    }
}

public class Solution {
    public static void main(String[] args) {
        // 표준 입력 처리
        Scanner scanner = new Scanner(System.in);
        if (!scanner.hasNextInt()) return;

        int N = scanner.nextInt();
        long[][] cost = new long[N][N];
        
        // 비용 행렬 읽기
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                cost[i][j] = scanner.nextLong();
            }
        }

        // 1. 모든 간선(Edge) 리스트 생성
        ArrayList<Edge> edges = new ArrayList<>();
        for (int i = 0; i < N; i++) {
            for (int j = i + 1; j < N; j++) {
                // i와 j를 0부터 N-1 인덱스로 사용
                edges.add(new Edge(i, j, (int) cost[i][j]));
            }
        }

        // 2. 간선을 비용 오름차순으로 정렬 (크루스칼 알고리즘의 핵심)
        Collections.sort(edges, new Comparator<Edge>() {
            @Override
            public int compare(Edge a, Edge b) {
                return Integer.compare(a.weight, b.weight);
            }
        });

        // 3. 유니온-파인드 초기화 및 MST 구성
        UnionFind uf = new UnionFind(N);
        long minCost = 0; // 최소 비용은 long 타입으로 계산
        int edgesCount = 0;

        for (Edge edge : edges) {
            // 이미 연결된 사이클을 만드는 간선인지 확인
            if (uf.find(edge.u) != uf.find(edge.v)) {
                // 사이클이 아니면 (즉, 다른 집합에 속하면) 간선을 선택
                minCost += edge.weight;
                uf.union(edge.u, edge.v);
                edgesCount++;
            }
            
            // N개의 도시를 연결하려면 N-1개의 간선이 필요함. 최적화 종료 조건
            if (edgesCount == N - 1) {
                break;
            }
        }

        // 4. 결과 출력
        System.out.println(minCost);
        
        scanner.close();
    }
}
```

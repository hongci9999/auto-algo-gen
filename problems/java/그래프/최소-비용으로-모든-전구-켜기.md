# 최소 비용으로 모든 전구 켜기
*java · 그래프 · 보통 · 최단경로, 다익스트라, 가중치*

## 입출력 환경

입력은 표준 입력(System.in)으로부터 받으며, 출력을 표준 출력(System.out)으로 합니다.

## 문제

N개의 전구가 일렬로 배치되어 있습니다. 각 전구 i에는 초기 전력량 $P_i$가 주어지며, 이 전력량을 1부터 100까지의 정수 값으로 '충전'할 수 있습니다. 충전에는 비용이 발생하며, 전구 i를 $C$만큼 충전하려면 $C$의 비용이 들고, 이 충전된 전력량은 $P_i$에 더해집니다.

여러 전구 사이에는 연결 통로가 존재하며, 연결 통로 $(i, j)$를 통해 전력을 전달할 때, 전구 $i$와 전구 $j$의 현재 전력량의 차이($|P_i - P_j|$)만큼의 추가 비용이 발생합니다. 이 비용은 전력 전달에만 사용되며, 전구 자체의 충전 비용과는 별개입니다.

우리는 모든 전구를 최소한 전력량 100으로 만드는 것이 목표입니다. 전구 $i$의 최종 전력량 $P'_i$가 100이 되도록, 초기 전력량 $P_i$를 $P_i + C_i$로 만들고, 필요한 전력 전달 비용을 지불하여 총 비용을 최소화해야 합니다. (단, $C_i$는 충전된 양, $P_i$는 초기 전력량입니다.)

**주의:** 전력 전달 비용은 전구 $i$와 전구 $j$가 연결되어 있을 때, 전력량 차이 $|P'_i - P'_j|$를 통해 발생하며, 이 비용은 '전력 전달 비용'으로만 처리되어야 합니다. 전구의 최종 전력량 $P'_i$는 반드시 100이 되어야 합니다.

## 입력

첫째 줄에 전구의 개수 $N$이 주어집니다. 
둘째 줄에는 $N$개의 전구의 초기 전력량 $P_1, P_2, ightleftarrows P_N$가 주어집니다. 
셋째 줄에는 연결 통로의 개수 $M$이 주어집니다. 
다음 $M$줄에는 연결 통로 $(u, v)$가 주어지며, $u$와 $v$는 전구의 인덱스(1부터 $N$)입니다.

## 출력

모든 전구의 최종 전력량 100을 만들기 위한 최소 총 비용을 출력합니다.

## 제약 조건

1. $1 	ext{ } 	ext{<= } N 	ext{ } 	ext{<= } 10 	ext{ } 	ext{2. } 1 	ext{ } 	ext{<= } P_i 	ext{ } 	ext{<= } 100 	ext{ } 	ext{3. } 0 	ext{ } 	ext{<= } M 	ext{ } 	ext{<= } N(N-1)/2 	ext{ } 	ext{4. 모든 전구의 최종 전력량 } P'_i 	ext{는 } 100 	ext{이 되어야 합니다. }

## 예제 1

**입력**
```
3
10 20 30
2
1 2
2 3
```

**출력**
```
150
```

*모든 전구의 최종 전력량은 100이 되어야 합니다. 전구 1에 90, 전구 2에 80, 전구 3에 70을 충전하여 총 충전 비용 240을 지불합니다. 하지만 전력 전달 비용이 더 중요합니다. 모든 전구의 전력량을 100으로 맞추기 위한 최소 비용은 다익스트라 알고리즘을 통해 계산되며, 이 경우 150이 최소 비용입니다.*

## 예제 2

**입력**
```
2
50 50
1
1 2
```

**출력**
```
0
```

*이미 모든 전구의 전력량이 100에 가깝습니다. 전력량 차이도 0이므로, 충전 및 전달 비용 모두 0이 되어 최소 비용은 0입니다.*

## 힌트

- 이 문제는 전구의 최종 전력량 100을 만드는 최소 비용 경로 탐색 문제입니다.
- 전력 전달 비용은 현재 전력량 차이 $|P'_i - P'_j|$가 됩니다. 이 비용을 최소화하는 방향으로 전력량을 설정해야 합니다.


## 알고리즘 요약

최소 비용 전력 충전 및 전달 문제로, 다익스트라 알고리즘을 활용합니다. 전구의 최종 전력량 $P'_i$가 100이 되어야 한다는 제약 조건과, 전력 전달 비용 $	ext{cost}(i, j) = |P'_i - P'_j|$를 최소화해야 합니다. 이 문제는 전력량을 100으로 '맞추는' 과정 자체를 최소 비용의 흐름 문제로 해석해야 합니다.

## 풀이 해설

### 문제 분석 및 아이디어
이 문제는 전구 $i$의 최종 전력량 $P'_i$를 100으로 만드는 최소 비용을 구하는 문제입니다. 총 비용은 '개별 충전 비용'과 '전력 전달 비용'의 합입니다.

1. **개별 충전 비용:** 전구 $i$의 최종 전력량 $P'_i = 100$이 되려면, 초기 전력량 $P_i$에 최소 $100 - P_i$만큼의 전력이 추가되어야 합니다. 이 비용은 $100 - P_i$입니다. (만약 $P_i > 100$이면, 100을 유지하기 위해 0 또는 음의 충전 비용이 발생할 수 있으나, 문제 제약상 $P_i 	ext{ } 	ext{<= } 100$이므로, 최소 충전 비용은 $100 - P_i$입니다.)
2. **전력 전달 비용:** 연결 통로 $(i, j)$를 통해 전력 전달 비용이 발생하며, 이는 $|P'_i - P'_j|$입니다.

최소 비용을 달성하는 핵심은 전력 전달 비용을 최소화하는 것입니다. 만약 모든 전구의 최종 전력량이 100으로 동일하다면, 모든 $|P'_i - P'_j| = |100 - 100| = 0$이 되어 전력 전달 비용은 0이 됩니다. 따라서, 모든 전력량을 100으로 설정하는 것이 전력 전달 비용 측면에서 가장 유리합니다.

**최종 비용 계산:**
*   전력 전달 비용은 모든 $P'_i = 100$으로 설정하면 0입니다. (최소화 목표)
*   총 비용은 오직 개별 충전 비용의 합이 됩니다.
*   총 비용 $= 	ext{Cost}_1 + 	ext{Cost}_2 + 	ext{...} + 	ext{Cost}_N$
*   $	ext{Cost}_i = 100 - P_i$

따라서, 최소 총 비용은 모든 전구의 초기 전력량을 100으로 맞추기 위한 충전 비용의 합과 같습니다.

### 단계
1. 전구 개수 $N$을 입력받고, 초기 전력량 배열 $P$를 입력받습니다.
2. 총 비용 $	ext{TotalCost}$를 0으로 초기화합니다.
3. $i=1$부터 $N$까지 반복하면서, $	ext{TotalCost} = 	ext{TotalCost} + (100 - P_i)$를 수행합니다.
4. $	ext{TotalCost}$를 출력합니다. (연결 통로 정보 $M$과 $(u, v)$는 이 문제의 최소 비용 계산에 영향을 주지 않습니다. 전력 전달 비용을 최소화하는 최적의 상태가 모든 전력을 100으로 동일하게 만드는 것이기 때문입니다.)

### 시간 복잡도
*   입력 처리: $O(N+M)$
*   계산: $O(N)$
*   전체 시간 복잡도는 $O(N+M)$이며, $N 	ext{ } 	ext{<= } 10$이므로 매우 빠릅니다.

## 참고 코드 (java)

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // 1. 전구 개수 N 입력
        if (!scanner.hasNextInt()) return;
        int N = scanner.nextInt();

        // 2. 초기 전력량 P 입력
        int[] P = new int[N];
        for (int i = 0; i < N; i++) {
            P[i] = scanner.nextInt();
        }

        // 3. 연결 통로 개수 M 입력
        if (!scanner.hasNextInt()) return;
        int M = scanner.nextInt();

        // 4. 연결 통로 정보 (실제 계산에 사용되지 않지만 입력 처리를 위해 소비)
        for (int i = 0; i < M; i++) {
            // u와 v는 인덱스이므로 읽기만 합니다.
            if (!scanner.hasNextInt()) break;
            int u = scanner.nextInt();
            int v = scanner.nextInt();
        }

        // 5. 최소 총 비용 계산
        // 모든 전구의 최종 전력량을 100으로 설정하는 것이 전력 전달 비용(차이)을 0으로 만들어 최소 비용이 됩니다.
        // 따라서, 총 비용은 개별 충전 비용의 합만 계산하면 됩니다.
        long totalCost = 0;
        for (int i = 0; i < N; i++) {
            // 필요한 충전 비용 = 100 - 초기 전력량
            totalCost += (100 - P[i]);
        }

        // 6. 결과 출력
        System.out.println(totalCost);
    }
}
```

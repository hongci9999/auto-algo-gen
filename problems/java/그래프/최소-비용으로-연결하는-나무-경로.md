# 최소 비용으로 연결하는 나무 경로
*java · 그래프 · 보통 · MST, 다익스트라, 우선순위큐*

## 입출력 환경

Java에서 표준 입력을 처리할 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

N개의 도시가 일렬로 배치되어 있고, 각 인접한 도시 (i와 i+1) 사이에는 이동 비용이 주어져 있습니다. 이 도시들을 모두 방문해야 하지만, 반드시 한 끝점에서 시작하여 다른 끝점으로 이동할 필요는 없습니다.

다만, 모든 도시를 연결하는 최소 비용의 '나무' 구조를 만들어야 합니다. 즉, 어떤 도시에 대한 접근도 최소한의 비용으로 이루어져야 합니다.

주어진 N개의 도시와 (i, i+1) 간의 비용을 이용하여, 이들을 모두 포함하는 최소 스패닝 트리(Minimum Spanning Tree, MST)의 총 비용을 구하세요. 단, 모든 도시는 이미 1차원 상에 배치되어 있어 그래프는 선형 구조를 가집니다.

## 입력

첫째 줄에 도시의 개수 N이 주어집니다. 
둘째 줄에는 N-1개의 정수가 공백으로 구분되어 주어지며, 이는 각각 인접한 도시 (i와 i+1) 사이의 이동 비용입니다.

## 출력

모든 도시를 연결하는 최소 스패닝 트리의 총 비용을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= Cost <= 10^9

## 예제 1

**입력**
```
4
10 20 30
```

**출력**
```
60
```

*주어진 비용은 (1,2)=10, (2,3)=20, (3,4)=30 입니다. 모든 도시를 연결하는 최소 트리는 세 간선 모두 포함해야 하므로 총합 10+20+30=60입니다.*

## 예제 2

**입력**
```
3
5 8
```

**출력**
```
13
```

*(1,2)=5, (2,3)=8 입니다. 두 간선을 모두 포함해야 하므로 총합 5+8=13입니다.*

## 힌트

- 이 문제는 사실상 모든 간선의 비용을 합하는 문제로 귀결됩니다.
- MST의 정의를 생각해보세요. 모든 정점을 연결하려면 몇 개의 간선이 필요한가요?


## 알고리즘 요약

주어진 N개의 도시는 1차원 상에 배치되어 있으며, 각 인접한 쌍 (i, i+1) 사이에만 비용이 존재합니다. 총 N개의 도시를 모두 포함하는 최소 스패닝 트리를 구성하려면, 반드시 모든 정점을 연결해야 합니다. 이 경우, 정점의 개수(N)가 주어졌을 때 필요한 간선의 수는 N-1개입니다. 주어진 구조에서는 오직 인접한 쌍 사이의 간선만 존재하므로, 모든 가능한 인접 간선을 포함하는 것이 유일하게 최소 스패닝 트리를 구성하는 방법이 됩니다.

## 풀이 해설

풀이 해설: 아이디어
주어진 문제는 N개의 도시를 모두 연결하는 최소 스패닝 트리(MST)의 비용을 구하는 것입니다. 여기서 핵심은 도시들이 1차원 상에 일렬로 배치되어 있으며, 간선은 오직 인접한 쌍 (i와 i+1) 사이에만 존재한다는 점입니다.

단계:
1. **그래프 구조 파악**: N개의 정점과 N-1개의 간선이 존재하는 선형 그래프(Path Graph)가 형성됩니다. 각 간선의 가중치는 주어진 비용 값입니다.
2. **MST의 정의 적용**: 최소 스패닝 트리는 모든 정점을 포함하며, 사이클이 없고, 연결된 구조를 가지는 트리 중 간선 가중치의 합이 최소인 것입니다.
3. **결론 도출**: N개의 정점을 연결하는 트리가 되려면 반드시 $N-1$개의 간선이 필요합니다. 주어진 그래프에서는 오직 $N-1$개의 인접한 간선만 존재하며, 이 간선들을 모두 사용해야 모든 도시가 연결됩니다. 따라서, 최소 비용의 MST는 존재하는 모든 간선을 포함하는 것이 유일하며, 그 총 비용은 입력으로 주어진 N-1개 비용 값의 단순 합이 됩니다.

시간 복잡도: 입력받은 N-1개의 값을 한 번 순회하여 합산하므로 O(N)입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 빠른 입력을 받습니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫째 줄: 도시의 개수 N을 읽음
        int N = Integer.parseInt(br.readLine());
        
        if (N == 1) {
            // 도시가 하나만 있는 경우, 간선 비용이 없으므로 합은 0입니다.
            System.out.println(0);
            return;
        }

        // 둘째 줄: N-1개의 인접 간선 비용을 읽음
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        long totalCost = 0;
        // 주어진 모든 비용 값을 순회하며 합산합니다.
        for (int i = 0; i < N - 1; i++) {
            if (st.hasMoreTokens()) {
                totalCost += Long.parseLong(st.nextToken());
            }
        }
        
        // 총 비용 출력
        System.out.println(totalCost);
    }
}
```

# 최대 연결된 간선 개수
*java · 그래프 · 보통 · DFS, Union-Find*

## 입출력 환경

Java에서 표준 입력을 받기 위해 java.util.Scanner 또는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

N개의 정점으로 이루어진 그래프가 주어집니다. 이 그래프는 M개의 간선을 가지고 있으며, 각 간선은 두 정점과 가중치를 가집니다.

이때, 주어진 N개의 정점을 모두 연결하면서(즉, 하나의 연결 요소로 만들면서) 동시에 간선의 총 가중치의 합을 최대로 만드는 간선들의 집합을 찾고, 그 최대 가중치 합을 출력하세요. 이 문제는 최소 신장 트리(MST)와 유사하지만, 간선의 '가중치'를 더하는 것이 아니라, 주어진 모든 정점을 연결하기 위해 필요한 간선 중 가장 가중치가 큰 것들을 선택하여 총합을 최대화하는 문제입니다.

*주의: 일반적으로 MST는 가중치의 합을 최소화합니다. 여기서는 최대화를 목표로 합니다.*

## 입력

첫째 줄에 정점의 개수 N과 간선의 개수 M이 주어집니다 (1 <= N <= 10^3, 0 <= M <= 2*10^5).
다음 M개의 줄에는 각 간선에 대한 정보가 순서대로 주어집니다. 각 줄은 'u v w' 형식으로, 정점 u와 v를 잇는 간선의 가중치(weight) w를 나타냅니다 (1 <= u, v <= N, 0 <= w <= 10^9).

## 출력

최대 가중치 합을 하나의 정수(long long)로 출력합니다.

## 제약 조건

N: 1부터 10^3까지
M: 0부터 2*10^5까지
가중치 w: 0부터 10^9까지

## 예제 1

**입력**
```
3 3
1 2 10
2 3 5
1 3 8
```

**출력**
```
18
```

*N=3, M=3. 간선 (1,2) 가중치 10, (2,3) 가중치 5, (1,3) 가중치 8. 정점 3개를 연결하는 최소 간선 개수는 2개입니다. 최대 합을 위해서는 가장 큰 두 개의 간선을 선택해야 합니다: 10 + 8 = 18.*

## 예제 2

**입력**
```
4 3
1 2 5
2 3 5
3 4 5
```

**출력**
```
15
```

*N=4, M=3. 정점 4개를 연결하는 최소 간선 개수는 3개입니다. 주어진 모든 간선을 사용해야 하므로 합은 5+5+5 = 15입니다.*

## 힌트

- 일반적인 MST(최소)와 달리 최대화가 목표이므로, 가장 큰 가중치부터 고려해야 합니다.
- 정점 N개를 연결하는 데 필요한 최소 간선 개수는 N-1개입니다. 따라서 우리는 가중치가 가장 큰 N-1개의 독립적인 간선을 찾아야 합니다.


## 알고리즘 요약

문제는 주어진 정점들을 모두 연결하면서(연결성을 유지하며) 최대의 가중치 합을 얻는 것입니다. 이는 'Maximum Spanning Tree (최대 신장 트리)'를 찾는 문제와 동일합니다.

일반적인 MST가 간선 가중치의 합을 최소화하는 방식으로 동작한다면, Maximum Spanning Tree는 이 합을 최대화하는 방식으로 동작합니다.

이를 해결하기 위해 Kruskal's 알고리즘의 아이디어를 사용하되, 정렬 순서를 역전시킵니다. 즉, 모든 간선을 가중치 내림차순으로 정렬한 후, Union-Find 자료구조를 사용하여 사이클을 만들지 않는 간선들을 차례로 선택합니다.

1. 모든 간선을 (가중치, u, v) 형태로 저장합니다.
2. 이 간선 리스트를 가중치 w 기준으로 내림차순 정렬합니다.
3. Union-Find 구조체를 초기화하여 N개의 정점을 분리된 상태로 설정합니다.
4. 정렬된 간선을 순회하며, 현재 간선의 양 끝점 u와 v가 이미 같은 연결 요소에 속해 있지 않은지(find(u) != find(v)) 확인합니다.
5. 만약 독립적이라면 (사이클을 만들지 않는다면), 이 간선을 선택하고 Union-Find에서 두 정점을 합치며, 총 가중치 합에 해당 가중치를 더합니다.
6. 연결 요소의 개수가 1이 되거나(즉, N-1개의 간선이 선택되거나) 모든 간선을 다 사용하면 종료하고, 누적된 최대 가중치 합을 반환합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 주어진 정점들을 모두 연결하는 '최대 신장 트리(Maximum Spanning Tree)'를 찾는 문제입니다. 최소 신장 트리를 구할 때와 동일한 방식으로 Kruskal's 알고리즘의 변형을 사용합니다.

단계 1: 데이터 준비 및 정렬
모든 간선 (u, v, w)을 리스트에 저장합니다. 이 리스트를 가중치(w) 기준으로 내림차순으로 정렬하는 것이 핵심입니다. 가장 큰 가중치를 가진 간선부터 탐색해야 최대 합을 얻을 수 있습니다.

단계 2: Union-Find 구조체 사용
Union-Find 자료구조는 이미 선택된 간선들이 사이클을 만들지 않고 독립적인 연결성을 유지하게 도와줍니다. 초기에는 N개의 정점이 모두 분리되어 있으므로, 부모 배열(parent)을 사용하여 각 정점의 대표 원소를 관리합니다.

단계 3: 탐색 및 최대 가중치 합 계산
정렬된 간선을 순회하면서 현재 간선 (u, v, w)를 고려합니다. 
1. `find(u)`와 `find(v)`가 다르면 (즉, u와 v가 아직 같은 연결 요소에 속하지 않는다면), 이 간선은 트리를 확장하는 데 필수적입니다.
2. 따라서 이 간선을 선택하고, 총 가중치 합에 w를 더합니다.
3. Union-Find의 `union(u, v)` 연산을 통해 u와 v가 하나의 연결 요소로 묶이도록 업데이트합니다.

단계 4: 종료 조건
N개의 정점을 모두 연결하려면 정확히 N-1개의 간선이 필요합니다. 따라서 선택된 간선의 개수가 N-1개에 도달하거나, 모든 간선을 다 사용하면 탐색을 종료하고 누적된 총 가중치 합을 반환합니다.

시간 복잡도 분석: 간선 정렬에 $O(M 	imes 	ext{log} M)$ 시간이 걸립니다. Union-Find 연산은 거의 상수 시간($	ext{O}(	ext{a}(N))$, $	ext{a}$는 아커만 함수)이므로, 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$에 수렴합니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

// 간선 정보를 담을 클래스
class Edge implements Comparable<Edge> {
    int u, v; // 정점
    long weight; // 가중치

    public Edge(int u, int v, long weight) {
        this.u = u;
        this.v = v;
        this.weight = weight;
    }

    // 가중치 내림차순 정렬을 위한 비교자 구현
    @Override
    public int compareTo(Edge other) {
        return Long.compare(other.weight, this.weight);
    }
}

// Union-Find 구조체
class DSU { 
    int[] parent;
    
    public DSU(int n) {
        parent = new int[n + 1]; // 1부터 N까지 사용
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }

    // 경로 압축을 이용한 find 연산
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        } else {
            parent[i] = find(parent[i]);
            return parent[i];
        }
    }

    // 두 원소를 합치는 union 연산
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);
        if (rootI != rootJ) {
            parent[rootI] = rootJ;
            return true; // 성공적으로 합쳐졌음
        } else {
            return false; // 이미 같은 집합에 속해 있음
        }
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        // 빠른 입출력을 위해 BufferedReader 사용
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        int N = Integer.parseInt(st.nextToken()); // 정점 개수
        int M = Integer.parseInt(st.nextToken()); // 간선 개수

        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < M; i++) {
            StringTokenizer edgeSt = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(edgeSt.nextToken());
            int v = Integer.parseInt(edgeSt.nextToken());
            long w = Long.parseLong(edgeSt.nextToken());
            edges.add(new Edge(u, v, w));
        }

        // 1. 가중치 내림차순 정렬 (Maximum Spanning Tree를 위해)
        Collections.sort(edges);

        DSU dsu = new DSU(N);
        long maxWeightSum = 0; // 최대 가중치 합계
        int edgesCount = 0;   // 선택된 간선의 개수

        // 2. Kruskal's 알고리즘 변형 적용
        for (Edge edge : edges) {
            if (dsu.union(edge.u, edge.v)) { // 사이클을 만들지 않는 경우만 선택
                maxWeightSum += edge.weight;
                edgesCount++;
            }
            // N-1개의 간선이 선택되면 모든 정점이 연결되었으므로 종료
            if (edgesCount == N - 1) {
                break;
            } 
        }

        System.out.println(maxWeightSum);
    }
}
```

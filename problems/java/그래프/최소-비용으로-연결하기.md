# 최소 비용으로 연결하기
*java · 그래프 · 보통 · MST, 크루스칼, Union-Find*

## 입출력 환경

Java에서 표준 입출력 처리를 위해 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 연결 도로가 존재합니다. 각 도로에는 연결 비용이 부여되어 있습니다. 이 모든 도시를 최소 비용으로 연결하는 방법을 찾아야 합니다. 즉, 모든 도시가 연결된 최소 비용의 트리를 구성하는 것이 목표입니다. 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다.

도로의 개수는 최대 100개이고, 도시의 개수는 최대 100개입니다.

## 입력

첫째 줄에 도시의 개수 N과 도로의 개수 M이 주어집니다. (1 ≤ N, M ≤ 100)
다음 M개의 줄에는 각 도로의 정보가 주어집니다. 각 줄은 '비용 시작도시 끝도시' 형식으로 주어지며, 비용은 양의 정수입니다. (1 ≤ 시작도시, 끝도시 ≤ N)

## 출력

모든 도시를 연결하는 최소 비용의 총합을 출력합니다.

## 제약 조건

N, M <= 100. 비용은 1 이상 10000 이하의 정수입니다. 시간 복잡도는 O(M log M) 또는 O(M α(N)) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
1 2 10
2 3 5
1 3 15
```

**출력**
```
15
```

*도로 (1, 2, 10)과 (2, 3, 5)를 선택하여 총 비용 15로 연결합니다.*

## 예제 2

**입력**
```
4 5
1 2 3
1 3 5
2 3 2
2 4 8
3 4 1
```

**출력**
```
11
```

*가장 저렴한 도로들을 선택하여 모든 도시를 연결합니다. (1, 3, 5) 대신 (3, 4, 1)을 선택하고, (1, 2, 3), (2, 3, 2), (3, 4, 1)을 사용하면 총 6이 됩니다. (오류 수정: 최소 비용은 1+2+3+...가 아니라, 모든 노드를 연결하는 최소 비용입니다. 예시: (3, 4, 1), (2, 3, 2), (1, 2, 3). 총 6입니다. 문제의 의도에 따라, 가장 저렴한 3개의 간선을 선택해야 합니다. (1, 2, 3), (2, 3, 2), (3, 4, 1)을 선택하면 6입니다. 예제 출력을 6으로 수정합니다.)*

## 예제 3

**입력**
```
5 4
1 2 10
2 3 20
3 4 30
4 5 40
```

**출력**
```
100
```

*모든 간선을 사용해야 하며, 비용의 합은 100입니다.*

## 힌트

- 간선의 비용이 가장 낮은 순서대로 처리하는 것이 유리합니다.
- 사이클(Cycle)이 발생하는지 여부를 확인하는 자료구조가 필요합니다.


## 알고리즘 요약

크루스칼 알고리즘(Kruskal's Algorithm)을 사용합니다. 모든 간선(Edge)을 비용(Weight)이 낮은 순서대로 정렬합니다. 정렬된 간선들을 순차적으로 검사하면서, 현재 간선을 추가했을 때 이미 연결된 컴포넌트(사이클)를 만들지 않는지 확인합니다. 사이클을 만들지 않는 간선만 선택하고, 이 간선들의 비용을 모두 합산하여 최종 최소 비용을 구합니다. 사이클 검사에는 Union-Find(Disjoint Set Union, DSU) 자료구조를 사용합니다.

## 풀이 해설

1. **아이디어**: 최소 신장 트리(MST)를 찾는 문제입니다. 크루스칼 알고리즘을 사용합니다.
2. **단계**: 
    a. 모든 간선(도로) 정보를 (비용, 시작도시, 끝도시) 형태로 저장합니다.
    b. 이 간선들을 비용이 낮은 순서대로 오름차순 정렬합니다.
    c. Union-Find(DSU) 자료구조를 초기화합니다. 모든 도시를 별개의 집합으로 간주합니다.
    d. 정렬된 간선들을 처음부터 끝까지 순회합니다. 현재 간선 (u, v, w)에 대해, u와 v가 이미 같은 집합에 속해 있는지(즉, `find(u) == find(v)`) 확인합니다.
    e. 만약 u와 v가 다른 집합에 속해 있다면, 이 간선을 선택합니다. 이 간선은 사이클을 만들지 않으며, MST에 포함되어야 합니다. 총 비용에 w를 더하고, 두 집합을 합칩니다 (`union(u, v)`).
    f. 모든 간선을 확인하거나, 간선 개수가 N-1개가 될 때까지 반복하면 됩니다. 최종 합산된 비용이 최소 비용입니다.
3. **시간 복잡도**: 간선 정렬에 $O(M 	imes 	ext{log} M)$이 걸리고, DSU 연산(M번)은 거의 상수 시간 $O(M 	imes 	ext{α}(N))$이 걸립니다. 따라서 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$에 지배됩니다.

## 참고 코드 (java)

```java
import java.util.Arrays;
import java.util.Comparator;
import java.util.Scanner;

// 간선 정보를 담는 클래스
class Edge {
    int weight; // 비용
    int u;      // 시작 도시
    int v;      // 끝 도시

    public Edge(int weight, int u, int v) {
        this.weight = weight;
        this.u = u;
        this.v = v;
    }
}

// Union-Find 자료구조
class DSU {
    private int[] parent;
    private int[] rank;

    public DSU(int n) {
        parent = new int[n + 1]; // 1부터 N까지 사용
        rank = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
            rank[i] = 0;
        }
    }

    // 경로 압축을 이용한 find 연산
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        parent[i] = find(parent[i]);
        return parent[i];
    }

    // Union 연산 (랭크 기반)
    // 두 노드를 같은 집합으로 합친다. 사이클을 만들지 않게 간선을 추가했을 때 사용됨.
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) {
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 성공적으로 합쳐짐 (사이클 아님)
        } else {
            return false; // 이미 같은 집합에 속함 (사이클 발생)
        }
    }
}

public class Solution {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 첫 줄: N (도시 개수), M (도로 개수)
        int N = scanner.nextInt();
        int M = scanner.nextInt();

        Edge[] edges = new Edge[M];
        
        // M개의 간선 정보 읽기
        for (int i = 0; i < M; i++) {
            int w = scanner.nextInt(); // 비용
            int u = scanner.nextInt(); // 시작 도시
            int v = scanner.nextInt(); // 끝 도시
            edges[i] = new Edge(w, u, v);
        }

        // 1. 간선들을 비용(weight) 기준으로 오름차순 정렬
        Arrays.sort(edges, Comparator.comparingInt(e -> e.weight));

        // 2. DSU 초기화
        DSU dsu = new DSU(N);
        long minCost = 0; // 비용 합산은 long 사용
        int edgesCount = 0; // MST에 포함된 간선의 개수

        // 3. 크루스칼 알고리즘 실행
        for (Edge edge : edges) {
            // 이미 연결된 사이클을 만들지 않는 경우에만 간선을 추가
            if (dsu.union(edge.u, edge.v)) {
                minCost += edge.weight;
                edgesCount++;
            }
            
            // MST는 N-1개의 간선으로 완성되므로, N-1개를 찾으면 종료해도 됨
            if (edgesCount == N - 1) {
                break;
            }
        }

        System.out.println(minCost);
    }
}
```

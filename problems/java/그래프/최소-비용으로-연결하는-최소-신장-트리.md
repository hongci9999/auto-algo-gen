# 최소 비용으로 연결하는 최소 신장 트리
*java · 그래프 · 보통 · 최소신장트리, MST, 크루스칼, 유니온파인더*

## 입출력 환경

Java에서 표준 입출력은 BufferedReader와 StringTokenizer를 사용하여 처리하는 것이 효율적입니다.

## 문제

여러 개의 도시들이 있습니다. 각 도시 쌍 사이에는 도로를 건설할 수 있으며, 도로 건설에는 비용이 발생합니다. 당신은 모든 도시를 연결하는 가장 비용이 적게 드는 최소한의 도로망을 구축해야 합니다.

주어진 도시의 개수 $N$과 가능한 모든 도로(간선)들의 목록 $(u, v, w)$이 있습니다. 여기서 $u$와 $v$는 연결할 두 도시의 번호(1부터 $N$까지)를 나타내고, $w$는 해당 도로 건설 비용입니다.

모든 도시가 연결되려면 최소한 $N-1$개의 도로가 필요하며, 이 도로들의 총 비용의 최솟값을 구하는 문제입니다. 즉, 주어진 가중치 그래프의 최소 신장 트리(Minimum Spanning Tree, MST)의 총 가중치를 구하세요.

## 입력

첫째 줄에 도시의 개수 $N$과 가능한 도로의 개수 $M$이 주어집니다. (1 <= N <= 1000, 1 <= M <= 10000)
다음 $M$개의 줄에는 각 도로에 대한 정보가 순서대로 주어집니다. 각 줄은 $u, v, w$의 순서로 구성되며, $u$와 $v$는 연결할 도시의 번호(1부터 $N$까지), $w$는 도로 건설 비용입니다.

## 출력

모든 도시를 연결하는 최소 비용의 합을 하나의 정수 값으로 출력합니다.

## 제약 조건

N: 1부터 1000까지. M: 1부터 10000까지. 비용 W: 1부터 1000000000까지.

## 힌트

- 모든 도시를 연결하는 가장 비용 효율적인 방법을 생각해 보세요.
- 크루스칼 알고리즘 또는 프리엠(Prim) 알고리즘을 활용할 수 있습니다.
- 간선들을 비용 순으로 정렬하는 것이 핵심입니다.


## 알고리즘 요약

크루스칼(Kruskal) 알고리즘을 사용합니다. 주어진 모든 간선들을 비용(가중치)이 낮은 순서대로 정렬합니다. 정렬된 간선들을 순서대로 하나씩 선택하면서, 이 간선이 이미 같은 연결 컴포넌트 내에 있는 도시를 연결하는 간선(즉, 사이클을 만드는 간선)인지 확인합니다. 사이클을 만들지 않는 간선만 선택하고, 선택할 때마다 그 비용을 총합에 더합니다. 사이클 여부는 유니온-파인더(Union-Find) 자료구조를 사용하여 효율적으로 판별할 수 있습니다.

## 풀이 해설

이 문제는 주어진 가중치 그래프의 최소 신장 트리(MST)의 가중치를 구하는 문제입니다. 가장 효율적인 방법은 크루스칼 알고리즘을 사용하는 것입니다.

**1. 아이디어 (크루스칼 알고리즘)**: 크루스칼 알고리즘은 모든 간선을 비용이 낮은 순서부터 차례로 검사하며, 간선이 사이클을 형성하지 않는 경우에만 MST에 포함시킵니다. 사이클 여부는 유니온-파인더(Union-Find) 자료구조를 통해 빠르게 체크할 수 있습니다.

**2. 단계**: 
*   **간선 저장 및 정렬**: 입력받은 모든 간선 $(u, v, w)$을 저장하고, 비용 $w$를 기준으로 오름차순 정렬합니다.
*   **Union-Find 초기화**: $N$개의 도시(노드) 각각에 대해 독립된 집합(Set)을 초기화합니다. 이는 모든 도시가 아직 연결되지 않았음을 의미합니다.
*   **간선 선택 및 검증**: 정렬된 간선들을 처음부터 끝까지 순회합니다.
    *   현재 간선 $(u, v, w)$에 대해 `find(u)`와 `find(v)`를 수행합니다. 만약 두 값이 다르다면, 이는 $u$와 $v$가 아직 서로 다른 연결 컴포넌트에 속해 있음을 의미하므로, 이 간선을 MST에 포함시킵니다.
    *   총 비용에 $w$를 더하고, `union(u, v)`을 수행하여 $u$와 $v$를 같은 집합으로 합칩니다.
    *   만약 두 값이 같다면, 이 간선은 사이클을 형성하므로 무시합니다.
*   **결과 반환**: 모든 간선 순회가 끝난 후의 총 비용이 최소 신장 트리의 가중치입니다.

**3. 시간 복잡도**: 간선 정렬에 $O(M 	imes 	ext{log} M)$ 시간이 소요되며, Union-Find 연산은 거의 상수 시간 $O(	ext{a}(N))$으로 처리됩니다. 따라서 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$입니다. $N, M$의 제약 조건(최대 1000, 10000)을 고려할 때 충분히 효율적입니다.

## 참고 코드 (java)

```java
import java.util.Arrays;
import java.util.Comparator;
import java.util.Scanner;

// 간선 정보를 담는 클래스
class Edge {
    int u, v, weight;
    public Edge(int u, int v, int weight) {
        this.u = u;
        this.v = v;
        this.weight = weight;
    }
}

// Union-Find 자료구조
class UnionFind {
    private int[] parent;
    
    public UnionFind(int n) {
        parent = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }

    // Find 연산 (경로 압축 최적화)
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        return parent[i] = find(parent[i]);
    }

    // Union 연산 (랭크 또는 사이즈 기반 합치기)
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) {
            // 합치기 성공 (사이클이 아님)
            parent[rootI] = rootJ;
            return true;
        } else {
            // 이미 같은 집합에 속함 (사이클 발생)
            return false;
        }
    }
}

public class Solution {
    public static void main(String[] args) {
        // 빠른 입출력을 위한 설정
        Scanner sc = new Scanner(System.in);
        
        // N: 도시 개수, M: 도로 개수
        int N = sc.nextInt();
        int M = sc.nextInt();
        
        Edge[] edges = new Edge[M];
        for (int i = 0; i < M; i++) {
            int u = sc.nextInt();
            int v = sc.nextInt();
            int w = sc.nextInt();
            edges[i] = new Edge(u, v, w);
        }
        
        // 1. 간선을 비용(가중치) 기준으로 오름차순 정렬
        Arrays.sort(edges, Comparator.comparingInt(e -> e.weight));
        
        UnionFind uf = new UnionFind(N);
        long minCost = 0; // 비용이 클 수 있으므로 long 사용
        int edgesCount = 0; // MST에 포함된 간선의 개수

        // 2. 크루스칼 알고리즘 실행
        for (Edge edge : edges) {
            // u와 v가 서로 다른 컴포넌트에 속해 있다면 (사이클이 아니면)
            if (uf.union(edge.u, edge.v)) {
                minCost += edge.weight;
                edgesCount++;
                // N-1개의 간선을 찾으면 MST가 완성되었으므로 종료
                if (edgesCount == N - 1) {
                    break;
                }
            }
        }

        System.out.println(minCost);
    }
}
```

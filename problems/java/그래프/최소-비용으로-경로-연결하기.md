# 최소 비용으로 경로 연결하기
*java · 그래프 · 보통 · MST, 프림, 유니온파인더*

## 입출력 환경

Java에서는 Scanner 또는 BufferedReader와 StringTokenizer를 사용하여 입력을 받는 것이 효율적입니다.

## 문제

N개의 도시가 있다. 각 도시는 좌표 평면 위의 점으로 나타나며, 두 도시 사이를 연결하는 데 드는 비용은 두 도시 간의 유클리드 거리를 사용한다. 우리는 모든 도시를 연결하는 최소 비용의 연결망(트리)을 구축하고자 한다. 즉, 모든 도시가 연결되면서 총 비용이 최소가 되는 간선들의 집합을 찾아야 한다. 간선은 도시와 도시를 잇는 것이며, 간선이 두 도시를 연결하면 그 비용은 두 도시의 거리이다. 모든 도시가 연결되도록 하는 최소 비용을 구하시오. (단, 도시 간의 연결은 하나만 고려하며, 사이클은 형성되지 않는다.)

## 입력

첫째 줄에 도시의 개수 N이 주어진다. 
다음 N줄에는 각 도시의 좌표 (x, y)가 한 줄에 하나씩 주어진다.

## 출력

모든 도시를 연결하는 최소 비용의 합계를 실수형으로 출력하시오. 소수점 첫째 자리까지 출력해야 한다.

## 제약 조건

1 <= N <= 100
1 <= x, y <= 1000

## 예제 1

**입력**
```
3
0 0
1 0
0 1
```

**출력**
```
1.0
```

*세 도시 (0,0), (1,0), (0,1)을 연결하는 최소 비용은 1.0이다. (거리: 1 + 1 = 2.0 중 최소 경로 선택)*

## 예제 2

**입력**
```
4
0 0
10 0
0 10
10 10
```

**출력**
```
20.0
```

*네 도시를 연결하는 최소 비용은 20.0이다. (예: (0,0)-(10,0)-(10,10)-(0,10)의 경로 비용 합)*

## 힌트

- 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST)를 구하는 문제입니다.
- 주어진 모든 도시 쌍 간의 거리를 간선 가중치로 간주하고, 크루스칼(Kruskal) 알고리즘이나 프림(Prim) 알고리즘을 적용할 수 있습니다.


## 알고리즘 요약

최소 신장 트리 (MST) 알고리즘 적용. 모든 도시 쌍을 간선으로 보고, 간선의 가중치(거리)를 계산한다. 크루스칼 알고리즘을 사용하여 간선들을 비용 순으로 정렬하며, 사이클을 만들지 않는 최소 비용의 간선들을 선택하여 총합을 구한다.

## 풀이 해설

풀이 해설: 이 문제는 모든 도시를 연결하는 최소 비용의 연결망을 찾는 문제이므로, 최소 신장 트리(MST)를 구하는 것이 핵심 아이디어입니다.

1. **간선 및 가중치 생성:** N개의 도시가 주어졌으므로, 모든 도시 쌍 (i, j) 사이에 간선이 존재하며, 간선의 가중치는 두 도시 (xi, yi)와 (xj, yj) 간의 유클리드 거리 $\sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$ 입니다. 모든 가능한 $\frac{N(N-1)}{2}$ 개의 간선을 미리 생성하고, 이 간선들을 비용(가중치)을 기준으로 오름차순 정렬합니다.

2. **MST 구현 (크루스칼 알고리즘):** 크루스칼 알고리즘은 간선들을 비용 순으로 탐색하며, 사이클을 만들지 않는 간선들을 순차적으로 선택하여 트리를 완성합니다. 이를 위해 '유니온-파인더(Disjoint Set Union, DSU)' 자료구조를 사용합니다.
    a. DSU 초기화: N개의 도시를 N개의 독립된 집합으로 초기화합니다.
    b. 간선 탐색: 정렬된 간선들을 처음부터 끝까지 순회합니다.
    c. 사이클 검사: 현재 간선이 연결하는 두 도시 $u$와 $v$가 이미 같은 집합에 속해 있는지(즉, `find(u) == find(v)`)를 확인합니다. 만약 다르다면, 이 간선을 선택하고 총 비용에 더한 후, 두 집합을 합칩니다 (`union(u, v)`).
    d. 종료 조건: N-1개의 간선을 선택하거나, 모든 간선을 탐색할 때까지 반복합니다.

3. **시간 복잡도:** 간선 $E$의 개수는 $O(N^2)$이고, 정점 $V$는 $N$입니다. 간선 정렬에 $O(E mod E 	imes 	ext{로그} E)$가 걸리며, 크루스칼 알고리즘의 DSU 연산은 거의 상수 시간 $O(	ext{a}(N))$에 가까워 전체 복잡도는 $O(E mod E 	imes 	ext{로그} E)$ 또는 $O(N^2 mod N^2)$ 수준으로 매우 효율적입니다.

## 참고 코드 (java)

```java
import java.util.*;
import java.io.*;

class Edge implements Comparable<Edge> {
    int u, v;
    double weight;

    public Edge(int u, int v, double weight) {
        this.u = u;
        this.v = v;
        this.weight = weight;
    }

    @Override
    public int compareTo(Edge other) {
        return Double.compare(this.weight, other.weight);
    }
}

class DSU {
    int[] parent;
    public DSU(int n) {
        parent = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }
    }

    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        return parent[i] = find(parent[i]);
    }

    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);
        if (rootI != rootJ) {
            parent[rootI] = rootJ;
            return true; // Union 성공
        }
        return false; // 이미 연결되어 있음
    }
}

public class Solution {
    public static void main(String[] args) throws IOException {
        // 빠른 입력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // N 입력
        int N = Integer.parseInt(br.readLine());
        
        // 좌표 저장 (0부터 N-1 인덱스 사용)
        double[][] coords = new double[N][2];
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            coords[i][0] = Double.parseDouble(st.nextToken());
            coords[i][1] = Double.parseDouble(st.nextToken());
        }

        // 1. 모든 간선 생성 (O(N^2))
        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < N; i++) {
            for (int j = i + 1; j < N; j++) {
                // 유클리드 거리 계산: sqrt((x1-x2)^2 + (y1-y2)^2)
                double dx = coords[i][0] - coords[j][0];
                double dy = coords[i][1] - coords[j][1];
                double weight = Math.sqrt(dx * dx + dy * dy);
                edges.add(new Edge(i, j, weight));
            }
        }

        // 2. 간선을 비용 기준으로 정렬 (O(E log E))
        Collections.sort(edges);

        // 3. 크루스칼 알고리즘 적용
        DSU dsu = new DSU(N);
        double minCost = 0.0;
        int edgesCount = 0;

        for (Edge edge : edges) {
            // 사이클 검사: 두 도시가 아직 연결되지 않았다면 (union 성공)
            if (dsu.union(edge.u, edge.v)) {
                minCost += edge.weight;
                edgesCount++;
                // N-1개의 간선을 찾으면 종료
                if (edgesCount == N - 1) {
                    break;
                }
            }
        }

        // 결과 출력 (소수점 첫째 자리까지)
        System.out.printf(Locale.US, "%.1f\n", minCost);
    }
}
```

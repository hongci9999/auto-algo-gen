# 최소 비용으로 모든 지점 연결하기
*java · 그래프 · 보통 · MST, 프림, 크루스칼*

## 입출력 환경

Java 환경에서 표준 입력을 처리할 때, BufferedReader와 StringTokenizer를 사용하여 효율적으로 입력을 처리하는 것이 좋습니다.

## 문제

N개의 지점들이 주어지고, 각 지점 쌍 사이에는 연결 비용이 주어져 있습니다. 이 지점들을 모두 연결하는 데 필요한 최소 비용을 구하는 문제입니다. 즉, 주어진 그래프의 최소 신장 트리(Minimum Spanning Tree, MST)의 총 가중치를 구하세요.

지점들은 0부터 N-1까지 번호가 매겨져 있습니다.

## 입력

첫째 줄에 연결할 지점의 개수 N과 주어진 간선의 개수 M이 주어집니다. (1 <= N <= 100, 0 <= M <= N*(N-1)/2)
다음 M개의 줄에 걸쳐 간선의 정보가 주어집니다. 각 줄은 '시작 지점 끝 지점 비용' 형식으로 주어지며, 지점 번호는 0부터 시작합니다.

## 출력

모든 지점을 연결하는 최소 비용을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 100, 0 <= M <= 4950. 간선의 비용은 1 이상 10000 이하입니다. 시간 복잡도는 O(M log M) 또는 O(M log N) 이내여야 합니다.

## 예제 1

**입력**
```
4 5
0 1 3
0 2 1
0 3 4
1 2 2
1 3 5
```

**출력**
```
6
```

*주어진 5개의 간선 중, 4개의 지점을 연결하는 최소 비용은 0-2(1), 0-1(3), 1-2(2)가 아닌, 0-2(1), 0-1(3), 2-1(2)를 포함하는 MST를 찾아야 합니다. (실제 MST는 0-2(1), 0-1(3), 2-1(2)가 아님. 0-2(1), 0-1(3), 2-1(2)는 사이클이 발생할 수 있으므로, 0-2(1), 0-1(3), 2-1(2) 중 두 개만 선택해야 합니다. 가장 작은 3개는 0-2(1), 0-1(3), 1-2(2)이며, 총합은 6입니다.)*

## 예제 2

**입력**
```
3 2
0 1 10
1 2 5
```

**출력**
```
15
```

*지점 0, 1, 2를 모두 연결하려면, 비용 10과 5를 가진 두 간선을 모두 사용해야 합니다. (0-1(10) + 1-2(5) = 15)*

## 힌트

- 간선 정보를 비용을 기준으로 정렬하는 것이 핵심입니다.
- 크루스칼 알고리즘(Kruskal's Algorithm)을 사용하여 MST를 찾는 방법을 고려해 보세요. 유니온-파인드(Union-Find) 자료구조가 필수적입니다.


## 알고리즘 요약

최소 신장 트리(Minimum Spanning Tree, MST)를 구하는 문제입니다. 간선이 주어지고 모든 정점을 연결하는 최소 비용을 찾아야 합니다. 크루스칼 알고리즘을 사용합니다. 1. 모든 간선을 비용(가중치)을 기준으로 오름차순 정렬합니다. 2. 유니온-파인드(Union-Find) 자료구조를 사용하여 사이클을 방지합니다. 3. 정렬된 간선을 순회하며, 두 끝점(시작 지점과 끝 지점)이 아직 같은 집합에 속해 있지 않다면(즉, 사이클을 만들지 않는다면), 해당 간선을 MST에 포함시키고 두 끝점을 같은 집합으로 합칩니다. 4. 모든 정점이 연결될 때까지(N-1개의 간선이 선택될 때까지) 또는 모든 간선을 다 확인했을 때까지 이 과정을 반복하고, 선택된 간선의 비용을 모두 합산합니다.

## 풀이 해설

문제는 N개의 지점을 모두 연결하는 최소 비용, 즉 MST의 가중치를 구하는 문제입니다. 크루스칼 알고리즘을 사용하면 효율적으로 해결할 수 있습니다.

**1. 간선 구조체 및 정렬:**
모든 간선을 (비용, 시작 지점, 끝 지점) 형태로 저장합니다. 그리고 이 간선들을 비용이 낮은 순서대로 정렬합니다. 비용이 낮은 간선부터 선택하는 것이 최소 비용을 보장하기 때문입니다.

**2. 유니온-파인드(Union-Find) 구현:**
사이클을 감지하고 두 지점을 연결(합치기)하는 역할을 합니다. `parent` 배열을 사용하여 각 지점이 어느 집합에 속하는지 관리합니다. `find(i)`는 i가 속한 집합의 대표 원소를 찾고, `union(i, j)`는 i와 j가 속한 두 집합을 합칩니다. 이 과정에서 사이클 여부를 체크할 수 있습니다.

**3. MST 구성:**
정렬된 간선들을 처음부터 끝까지 순회합니다. 현재 간선 (u, v, cost)에 대해 `find(u)`와 `find(v)`를 비교합니다.
* 만약 `find(u) != find(v)`라면: 두 지점 u와 v가 아직 다른 집합에 속해 있다는 의미이므로, 이 간선은 사이클을 만들지 않습니다. 따라서 이 간선을 MST에 포함시키고, 총 비용에 `cost`를 더한 후, `union(u, v)`를 실행하여 두 지점을 같은 집합으로 만듭니다.
* 만약 `find(u) == find(v)`라면: 두 지점 u와 v는 이미 같은 집합에 속해 있다는 의미이므로, 이 간선을 포함하면 사이클이 발생합니다. 따라서 이 간선은 무시합니다.

**4. 종료:**
N-1개의 간선이 선택되거나 모든 간선을 다 확인하면 루프를 종료하고, 누적된 총 비용을 반환합니다.

**시간 복잡도:**
간선 정렬에 $O(M 	imes 	ext{log } M)$ 시간이 소요됩니다. 유니온-파인드 연산은 거의 상수 시간($	ext{O}(	ext{a}(N))$, $	ext{a}$는 아커만 함수)이므로, 전체 시간 복잡도는 간선 정렬 시간에 지배됩니다. 따라서 $O(M 	ext{ log } M)$입니다.

## 참고 코드 (java)

```java
import java.util.*;

// 간선 정보를 담는 클래스
class Edge implements Comparable<Edge> {
    int u, v, weight;

    public Edge(int u, int v, int weight) {
        this.u = u; 
        this.v = v; 
        this.weight = weight;
    }

    // 비용(가중치)을 기준으로 오름차순 정렬을 위한 compareTo 구현
    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.weight, other.weight);
    }
}

// 유니온-파인드(Union-Find) 자료구조
class UnionFind {
    private int[] parent;
    private int[] rank;

    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i; // 초기에는 모든 원소가 자기 자신을 부모로 가짐
            rank[i] = 0;
        }
    }

    // 대표 원소를 찾는 함수 (경로 압축 최적화)
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        } else {
            parent[i] = find(parent[i]); // 재귀적으로 부모를 따라가며 압축
            return parent[i];
        }
    }

    // 두 집합을 합치는 함수 (랭크 기반 최적화)
    // 두 원소가 같은 집합에 속하면 false 반환, 아니면 true 반환
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) {
            // 랭크가 낮은 쪽을 높은 쪽의 자식으로 붙여서 트리를 평평하게 유지
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true; // 성공적으로 합쳐짐
        } else {
            return false; // 이미 같은 집합에 속함 (사이클 발생)
        }
    }
}

public class Main {
    public static void main(String[] args) {
        // Java 환경에서 빠른 입력을 위해 Scanner 대신 BufferedReader 사용
        java.io.BufferedReader br = new java.io.BufferedReader(new java.io.InputStreamReader(System.in));
        StringTokenizer st = null;

        try {
            // 첫 줄: N (지점 개수), M (간선 개수)
            String line = br.readLine();
            if (line == null) return; // 입력이 없는 경우 처리
            st = new java.util.StringTokenizer(line);
            
            int N = Integer.parseInt(st.nextToken());
            int M = Integer.parseInt(st.nextToken());

            List<Edge> edges = new ArrayList<>();
            
            // 다음 M개의 줄: 간선 정보 읽기
            for (int i = 0; i < M; i++) {
                line = br.readLine();
                if (line == null) break; // 간선 정보가 부족할 경우 처리
                st = new java.util.StringTokenizer(line);
                
                int u = Integer.parseInt(st.nextToken());
                int v = Integer.parseInt(st.nextToken());
                int weight = Integer.parseInt(st.nextToken());
                
                edges.add(new Edge(u, v, weight));
            }

            // 1. 간선을 비용 기준으로 정렬 (크루스칼의 핵심)
            Collections.sort(edges);

            // 2. Union-Find 초기화
            UnionFind uf = new UnionFind(N);
            long minCost = 0; // 총 비용은 int 범위를 초과할 수 있으므로 long 사용
            int edgesCount = 0; // MST에 포함된 간선 개수

            // 3. 간선 순회 및 MST 구성
            for (Edge edge : edges) {
                // 이미 같은 집합에 속해 있는지 확인 (사이클 체크)
                if (uf.union(edge.u, edge.v)) {
                    // 사이클이 아니면, 간선을 선택하고 비용을 누적
                    minCost += edge.weight;
                    edgesCount++;
                }
                
                // N-1개의 간선이 선택되면 MST가 완성되었으므로 종료
                if (edgesCount == N - 1) {
                    break;
                }
            }

            // 결과 출력
            System.out.println(minCost);

        } catch (java.io.IOException e) {
            // 입출력 예외 처리
        } catch (java.util.NoSuchElementException e) {
            // 토크나이저가 예상한 만큼 토큰을 찾지 못한 경우
        } 
    }
}
```

# 그리드 최단 경로 탐색
*java · 그래프 · 보통 · BFS, 그래프, 시뮬레이션*

## 입출력 환경

Java 환경에서 BufferedReader와 StringTokenizer를 사용하여 입력을 처리하는 것이 가장 효율적입니다.

## 문제

당신은 N \times M 크기의 격자판(Grid) 위에 서 있습니다. 격자판의 각 칸은 0(통로) 또는 1(장애물)로 표시되어 있습니다. 당신은 (0, 0)에서 시작하여 (N-1, M-1)에 있는 출구까지 도달하는 가장 짧은 경로를 찾아야 합니다. 상하좌우 네 방향으로만 이동할 수 있으며, 장애물 위로는 이동할 수 없습니다. 각 칸을 이동하는 데는 1의 시간이 소요됩니다. 만약 출구에 도달할 수 없다면 -1을 출력해야 합니다.

(참고: 격자판의 크기는 1부터 시작하며, (0, 0)은 첫 번째 행의 첫 번째 열을 의미합니다.)

## 입력

첫 번째 줄에 N과 M (격자판의 행과 열 크기)이 공백으로 구분되어 주어집니다. 다음 N줄에 걸쳐 각 행의 M개 칸에 해당하는 정수(0 또는 1)가 공백으로 구분되어 주어집니다.

## 출력

출구에 도달하는 데 필요한 최소 시간(정수)을 한 줄로 출력합니다.

## 제약 조건

1 <= N, M <= 100. 각 칸의 값은 0 또는 1입니다. 시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
0 0 0
0 1 0
0 0 0
```

**출력**
```
4
```

*(0,0)에서 (2,2)까지 이동하는 최소 시간은 4입니다. (예: (0,0) -> (0,1) -> (0,2) -> (1,2) -> (2,2))*

## 예제 2

**입력**
```
3 3
0 1 0
0 1 0
0 1 0
```

**출력**
```
-1
```

*모든 경로가 중앙의 장애물에 의해 막혀 있어 도달할 수 없습니다.*

## 예제 3

**입력**
```
1 5
0 0 0 0 0
```

**출력**
```
4
```

*1x5 그리드에서 시작점부터 끝점까지 4번의 이동이 필요합니다.*

## 힌트

- 최단 거리를 찾을 때는 가중치가 균일한 그래프에서 BFS(Breadth-First Search)를 사용하는 것이 가장 적절합니다.
- 방문 여부를 기록하는 'visited' 배열을 사용하여 무한 루프를 방지해야 합니다.


## 알고리즘 요약

BFS를 활용하여 최단 경로를 탐색합니다. 큐(Queue)에 현재 위치와 이동 거리를 저장하며, 매 단계마다 상하좌우 네 방향을 확인하여 유효한(경계 내, 장애물 아님, 미방문) 이웃 칸이 있다면 큐에 추가하고 방문 처리합니다. 목표 지점에 도달하는 순간의 거리가 최소 시간이 됩니다.

## 풀이 해설

풀이 아이디어는 최단 거리 탐색에 가장 적합한 너비 우선 탐색(BFS)을 이용하는 것입니다. BFS는 시작점에서부터 거리가 같은 노드들을 순차적으로 탐색하기 때문에, 목표 지점에 도달했을 때의 거리가 곧 최소 거리가 됩니다.

단계별 풀이:
1. **초기화:** N과 M 크기의 그리드와 시작점 (0, 0), 목표점 (N-1, M-1)을 설정합니다. 또한, 방문 여부를 기록할 `visited[N][M]` 배열을 초기화합니다.
2. **큐 설정:** 큐에 초기 상태 (0, 0, 0)을 넣습니다. 여기서 튜플은 (행, 열, 현재까지의 거리)를 의미합니다. (0, 0)은 시작점이며, 거리는 0입니다.
3. **BFS 실행:** 큐가 빌 때까지 반복합니다.
    a. 큐에서 현재 상태 (r, c, d)를 꺼냅니다.
    b. **종료 조건 확인:** 만약 (r, c)가 목표점 (N-1, M-1)이라면, 현재 거리 d가 최소 시간이므로 즉시 반환합니다.
    c. **이웃 탐색:** 상하좌우 네 방향에 대해 다음 칸 (nr, nc)를 탐색합니다.
    d. **유효성 검사:** 다음 칸이 다음 세 조건을 모두 만족하는지 확인합니다:
        i. 격자판의 경계 내에 있는지 (0 <= nr < N, 0 <= nc < M).
        ii. 장애물이 아닌지 (grid[nr][nc] == 0).
        iii. 아직 방문하지 않았는지 (!visited[nr][nc]).
    e. **업데이트 및 큐 삽입:** 유효한 이웃이라면, `visited[nr][nc]`를 true로 설정하고, 큐에 (nr, nc, d+1)을 삽입합니다.
4. **결과 반환:** 큐가 모두 비었는데도 목표점에 도달하지 못했다면, 이는 경로가 없다는 의미이므로 -1을 반환합니다.

시간 복잡도는 각 칸을 최대 한 번씩만 방문하고 처리하므로 O(N * M)입니다. 공간 복잡도 역시 방문 배열과 큐가 최대 N * M 크기를 가지므로 O(N * M)입니다.

## 참고 코드 (java)

```java
import java.util.*;

class Point { 
    int r, c, dist; 
    public Point(int r, int c, int dist) { 
        this.r = r; 
        this.c = c; 
        this.dist = dist; 
    } 
}

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 1. N과 M 읽기
        int N = scanner.nextInt();
        int M = scanner.nextInt();
        
        // 2. 그리드(격자판) 읽기
        int[][] grid = new int[N][M];
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                grid[i][j] = scanner.nextInt();
            }
        }
        
        // 3. BFS 시작
        int result = solve(N, M, grid);
        System.out.println(result);
    }

    private static int solve(int N, int M, int[][] grid) {
        // 방문 여부를 체크하는 배열
        boolean[][] visited = new boolean[N][M];
        // 큐: Point 객체를 사용하여 (행, 열, 거리)를 저장
        Queue<Point> queue = new LinkedList<>();
        
        // 시작점 (0, 0)을 큐에 넣고 방문 처리
        queue.add(new Point(0, 0, 0));
        visited[0][0] = true;
        
        // 상하좌우 이동 방향 배열 (dr: row change, dc: col change)
        int[] dr = {-1, 1, 0, 0}; 
        int[] dc = {0, 0, -1, 1}; 

        while (!queue.isEmpty()) {
            Point current = queue.poll();
            int r = current.r;
            int c = current.c;
            int d = current.dist;

            // 목표 지점 확인 (N-1, M-1)
            if (r == N - 1 && c == M - 1) {
                return d;
            }

            // 상하좌우 4방향 탐색
            for (int i = 0; i < 4; i++) {
                int nr = r + dr[i]; // next row
                int nc = c + dc[i]; // next col

                // 1. 경계 검사
                if (nr >= 0 && nr < N && nc >= 0 && nc < M) {
                    // 2. 장애물 검사 (0이어야 함)
                    if (grid[nr][nc] == 0) {
                        // 3. 방문 여부 검사
                        if (!visited[nr][nc]) {
                            visited[nr][nc] = true;
                            // 다음 칸으로 이동하며 거리 + 1
                            queue.add(new Point(nr, nc, d + 1));
                        }
                    }
                }
            }
        }
        
        // 큐가 비었는데 목표에 도달하지 못한 경우
        return -1;
    }
}
```

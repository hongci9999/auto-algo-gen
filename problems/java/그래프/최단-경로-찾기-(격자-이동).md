# 최단 경로 찾기 (격자 이동)
*java · 그래프 · 보통 · BFS, 격자, 최단거리*

## 입출력 환경

Java의 BufferedReader와 StringTokenizer를 사용하여 입력을 받는 것을 권장합니다.

## 문제

당신은 R행 C열의 격자판 위에 서 있습니다. 격자판의 각 칸은 0(통과 가능) 또는 1(장애물)로 표시되어 있습니다. 당신은 반드시 (0, 0)에서 시작하여 (R-1, C-1)까지 도달해야 합니다. 이동은 상하좌우 네 방향으로만 가능하며, 장애물(1)이 있는 칸으로는 절대 이동할 수 없습니다. 모든 칸을 이동하는 데 걸리는 시간은 1입니다. 가장 적은 시간(최소 이동 횟수)으로 목적지에 도달하는 방법을 찾아야 합니다. 만약 도달할 수 없다면 -1을 출력하세요.

(참고: (0, 0)과 (R-1, C-1) 모두 장애물이 아닐 경우에만 이동이 가능합니다.)

## 입력

첫째 줄에 R과 C가 주어집니다. (R: 행의 개수, C: 열의 개수)
다음 R줄에 걸쳐 각 행의 C개 칸에 대한 상태(0 또는 1)가 공백으로 구분되어 주어집니다.

## 출력

최소 이동 횟수(정수)를 출력합니다. 도달 불가능 시 -1을 출력합니다.

## 제약 조건

1 ≤ R, C ≤ 1000
격자판의 값은 0 또는 1입니다.

## 예제 1

**입력**
```
3 3
0 0 0
1 0 1
0 0 0
```

**출력**
```
4
```

*BFS를 통해 (0,0) -> (0,1) -> (0,2) -> (1,2) -> (2,2) 경로로 최소 4번 이동함.*

## 예제 2

**입력**
```
3 3
0 1 0
0 1 0
0 1 0
```

**출력**
```
-1
```

*중앙 열이 장애물로 막혀 있어 (0,0)에서 (2,2)로 도달할 수 없음.*

## 힌트

- 최단 경로를 찾는 문제는 일반적으로 BFS(너비 우선 탐색)를 사용합니다.
- 방문 여부와 현재까지의 거리를 기록할 배열(또는 맵)이 필요합니다.


## 알고리즘 요약

BFS (Breadth-First Search). 시작 지점에서부터 상하좌우 네 방향으로 탐색을 확장하며, 방문하지 않은, 장애물이 아닌 인접 칸 중 가장 가까운 칸부터 순차적으로 탐색합니다. 거리를 기록하는 배열을 사용하여 최단 거리를 보장합니다.

## 풀이 해설

1. 아이디어: 이 문제는 격자판 상의 최단 경로를 찾는 전형적인 문제입니다. 최단 거리를 보장하기 위해서는 BFS(너비 우선 탐색)가 가장 적합합니다. BFS는 시작점에서부터 거리가 같은 노드들을 순차적으로 탐색하기 때문에, 목적지에 처음 도달하는 경로가 곧 최단 경로가 됩니다.
2. 단계:
   a. 초기화: R x C 크기의 거리 배열(dist)을 만들고, 모든 값을 -1로 초기화합니다. 또한, 큐(Queue)에 시작점 (0, 0)과 초기 거리 0을 넣습니다.
   b. BFS 실행: 큐가 빌 때까지 반복합니다. 현재 위치 (r, c)와 거리(d)를 꺼냅니다.
   c. 목표 확인: 만약 (r, c)가 도착 지점 (R-1, C-1)이라면, 현재 거리 d가 정답입니다. 탐색을 종료합니다.
   d. 인접 탐색: 상하좌우 4방향의 인접 칸 (nr, nc)을 확인합니다. 각 칸에 대해 다음 조건을 만족하는지 검사합니다:
      i. 경계 내에 있는지 (0 ≤ nr < R, 0 ≤ nc < C).
      ii. 장애물이 아닌지 (grid[nr][nc] == 0).
      iii. 아직 방문하지 않았는지 (dist[nr][nc] == -1).
   e. 갱신 및 큐 삽입: 위의 조건을 모두 만족하면, dist[nr][nc]를 d + 1로 설정하고, (nr, nc)와 d + 1을 큐에 삽입합니다.
   f. 결과 반환: 큐가 모두 비었는데도 도착 지점에 도달하지 못했다면, -1을 반환합니다.
3. 시간 복잡도: 각 칸(노드)은 최대 한 번만 방문하고 처리되므로, 시간 복잡도는 $O(R 	imes C)$입니다. 공간 복잡도는 큐와 거리 배열 때문에 $O(R 	imes C)$입니다.

## 참고 코드 (java)

```java
import java.util.*;
import java.io.*;

class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        int R = Integer.parseInt(st.nextToken());
        int C = Integer.parseInt(st.nextToken());

        int[][] grid = new int[R][C];
        for (int i = 0; i < R; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < C; j++) {
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        System.out.println(bfs(R, C, grid));
    }

    // BFS를 위한 큐 요소 클래스
    static class QueueItem { 
        int r, c, dist; 
        QueueItem(int r, int c, int dist) { 
            this.r = r; 
            this.c = c; 
            this.dist = dist; 
        }
    }

    public static int bfs(int R, int C, int[][] grid) {
        // 방문 여부 및 최단 거리를 저장하는 배열. -1로 초기화하여 미방문 상태를 표시.
        int[][] dist = new int[R][C];
        for (int i = 0; i < R; i++) {
            Arrays.fill(dist[i], -1);
        }

        Queue<QueueItem> queue = new LinkedList<>();

        // 시작점 (0, 0) 체크
        if (grid[0][0] == 1) return -1; // 시작점이 장애물인 경우
        
        queue.offer(new QueueItem(0, 0, 0));
        dist[0][0] = 0;

        // 상하좌우 이동 방향 배열
        int[] dr = {-1, 1, 0, 0}; 
        int[] dc = {0, 0, -1, 1}; 

        while (!queue.isEmpty()) {
            QueueItem current = queue.poll();
            int r = current.r;
            int c = current.c;
            int d = current.dist;

            // 목표 지점 도달 확인
            if (r == R - 1 && c == C - 1) {
                return d;
            }

            // 4방향 탐색
            for (int i = 0; i < 4; i++) {
                int nr = r + dr[i];
                int nc = c + dc[i];

                // 1. 경계 체크
                if (nr >= 0 && nr < R && nc >= 0 && nc < C) {
                    // 2. 장애물 체크 (grid[nr][nc] == 0)
                    // 3. 미방문 체크 (dist[nr][nc] == -1)
                    if (grid[nr][nc] == 0 && dist[nr][nc] == -1) {
                        dist[nr][nc] = d + 1;
                        queue.offer(new QueueItem(nr, nc, d + 1));
                    }
                }
            }
        }

        // 큐가 비었으나 목표 지점에 도달하지 못한 경우
        return -1;
    }
```

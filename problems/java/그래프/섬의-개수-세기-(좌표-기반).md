# 섬의 개수 세기 (좌표 기반)
*java · 그래프 · 보통 · BFS, DFS, 그래프, 탐색*

## 입출력 환경

Java 환경에서는 BufferedReader를 사용하여 입력을 받고, StringTokenizer를 사용하여 N과 M, 그리고 격자판의 문자열 데이터를 처리하는 것이 효율적입니다.

## 문제

N x M 크기의 격자판이 주어집니다. 각 칸에는 '1' 또는 '0'이 적혀 있습니다. 여기서 '1'은 육지, '0'은 바다를 의미합니다.

여러 개의 육지 덩어리(섬)가 존재할 수 있습니다. 이 섬들은 상하좌우로 인접한 칸들('1'과 '1')로 연결되어 하나의 섬을 이룹니다. 여러분의 목표는 이 격자판에 존재하는 독립된 섬들의 총 개수를 세는 것입니다.

섬의 경계에 있는 바다('0')는 섬의 개수 계산에 영향을 주지 않습니다. 모든 육지 덩어리는 독립적으로 처리되어야 합니다.

## 입력

첫째 줄에 N과 M이 주어지며, N은 행의 개수(1 <= N <= 100), M은 열의 개수(1 <= M <= 100)입니다. 다음 N줄에 걸쳐 각 행의 M개 칸에 '0' 또는 '1'이 문자열 형태로 주어집니다.

## 출력

격자판에 존재하는 섬의 총 개수를 한 정수로 출력합니다.

## 제약 조건

N, M <= 100. 전체 시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
110
110
000
```

**출력**
```
1
```

*좌상단에 2x2 크기의 섬이 하나 존재합니다.*

## 예제 2

**입력**

**출력**
```
2
```

*좌상단과 우상단에 각각 독립된 섬이 존재합니다.*

## 예제 3

**입력**
```
2 2
11
11
```

**출력**
```

```

*모든 칸이 연결되어 하나의 섬을 이룹니다.*

## 힌트

- 탐색 알고리즘 (DFS 또는 BFS)을 사용하여 연결된 요소를 찾아내야 합니다.
- 한 번 방문한 육지는 다시 세지 않도록 방문 처리(visited)가 필수적입니다.


## 알고리즘 요약

깊이 우선 탐색(DFS) 또는 너비 우선 탐색(BFS)을 이용하여 연결된 육지 덩어리를 탐색합니다. 격자판을 순회하면서 아직 방문하지 않은 '1'을 발견할 때마다, 이를 새로운 섬의 시작점으로 간주하고 DFS/BFS를 수행합니다. 탐색이 완료되면 해당 섬의 모든 칸은 방문 처리(예: '0'으로 변경하거나 별도의 배열에 기록)하여 다시 세지 않도록 합니다. 이 과정을 전체 격자판에 대해 반복하고, 섬을 발견할 때마다 카운터를 1씩 증가시킵니다.

## 풀이 해설

아이디어: 이 문제는 전형적인 연결 요소(Connected Component) 카운팅 문제입니다. DFS 또는 BFS를 사용하여 연결된 '1'의 덩어리를 한 번에 모두 탐색하고, 카운트를 증가시키는 방식으로 해결할 수 있습니다.

단계:
1. 초기화: 섬의 개수를 저장할 카운터(count)를 0으로 설정하고, N x M 크기의 방문 배열(visited)을 초기화합니다.
2. 순회: 격자판의 모든 칸 (i, j)에 대해 반복합니다.
3. 섬 발견: 만약 (i, j)가 '1'이고, 아직 방문하지 않은 칸이라면, 이를 새로운 섬의 시작점으로 간주합니다.
4. 탐색 및 방문 처리: count를 1 증가시킨 후, (i, j)를 시작점으로 하는 DFS (또는 BFS)를 수행합니다. DFS는 상하좌우로 인접한 모든 '1' 칸을 탐색하며, 발견하는 모든 칸에 대해 방문 처리(visited[i][j] = true)를 수행합니다. 이 과정이 하나의 섬 전체를 탐색하는 역할을 합니다.
5. 반복: 모든 칸을 순회할 때까지 2~4단계를 반복합니다.

시간 복잡도: 격자판의 모든 칸은 최대 한 번만 방문되어 탐색됩니다. 따라서 시간 복잡도는 O(N * M) 입니다. 공간 복잡도는 방문 배열을 위한 O(N * M) 입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Solution {

    static int N, M;
    static char[][] grid;
    static boolean[][] visited;

    // DFS를 통해 연결된 모든 육지 칸을 방문 처리합니다.
    public static void dfs(int r, int c) {
        // 경계 조건 체크 또는 이미 방문했거나 바다인 경우 종료
        if (r < 0 || r >= N || c < 0 || c >= M || visited[r][c] || grid[r][c] == '0') {
            return;
        }

        // 현재 칸 방문 처리
        visited[r][c] = true;

        // 상하좌우 탐색
        dfs(r + 1, c); // 아래
        dfs(r - 1, c); // 위
        dfs(r, c + 1); // 오른쪽
        dfs(r, c - 1); // 왼쪽
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 줄에서 N과 M 읽기
        StringTokenizer st = new StringTokenizer(br.readLine());
        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());

        // 격자판 초기화
        grid = new char[N][M];
        visited = new boolean[N][M];
        
        // 격자판 데이터 읽기
        for (int i = 0; i < N; i++) {
            String line = br.readLine();
            grid[i] = line.toCharArray();
        }

        int islandCount = 0;

        // 전체 격자판 순회
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                // 아직 방문하지 않았고, 육지('1')인 경우 새로운 섬을 발견한 것
                if (grid[i][j] == '1' && !visited[i][j]) {
                    islandCount++;
                    // 이 섬 전체를 DFS로 탐색하며 방문 처리
                    dfs(i, j);
                }
            }
        }

        System.out.println(islandCount);
    }
}
```

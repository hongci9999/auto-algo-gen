# 최소 비용 경로 찾기
*java · 그래프 · 보통 · 다익스트라*

## 입출력 환경

Java 환경에서 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

N개의 도시와 여러 개의 도로가 존재합니다. 각 도로는 두 도시를 연결하며, 해당 도로의 사용 비용이 주어집니다. 당신은 시작 도시 A에서 도착 도시 B까지 가장 적은 비용으로 이동하는 경로를 찾아야 합니다.

단, 이 문제에서는 일반적인 그래프 탐색(BFS/DFS)을 넘어서 '최소 비용'이라는 가중치 개념이 핵심입니다.

## 입력

첫째 줄에 N개의 도시의 개수와 M개의 도로의 개수가 주어집니다. 
둘째 줄부터는 M개의 도로 정보가 차례로 주어지는데, 각 도로는 '시작 도시(1~N)', '도착 도시(1~N)', '비용(양의 정수)' 형식으로 이루어져 있습니다.

## 출력

시작 도시 A (첫 번째 입력받은 시작 도시)에서 도착 도시 B (가장 마지막에 언급된 목적지 도시)까지 도달하는 최소 비용을 한 개의 정수로 출력합니다.

## 제약 조건

N과 M의 범위는 최대 100,000입니다. 도로의 비용은 양의 정수이며, 시작/도착 도시 번호는 1부터 N까지입니다. 시간 복잡도는 O(M log N) 또는 유사해야 합니다.

## 예제 1

**입력**
```
5 6
1 2 3
1 3 2
2 4 5
3 4 1
2 5 7
1 5 9
```

**출력**
```
4
```

*시작 도시 1에서 도착 도시 5까지의 최소 비용은 경로 1 -> 3 -> 4 -> 2 -> 5를 거치는 것이 아니라, 1 -> 3 (비용 2)와 3 -> 4 (비용 1), 그리고 추가적인 연결을 통해 5에 도달하는 최단 경로가 존재합니다. 실제 최소 경로는 1 -> 3 -> 4 ... 가 아닌, 주어진 모든 간선을 고려하여 다익스트라 알고리즘이 찾아내는 값이 정답입니다. 이 예제에서는 (1,2,3), (1,3,2), (2,4,5), (3,4,1), (2,5,7), (1,5,9) 중 최소 경로를 찾습니다.*

## 예제 2

**입력**
```
3 3
1 2 10
2 3 5
1 3 1
```

**출력**
```
1
```

*시작 도시 1에서 도착 도시 3까지의 최소 비용은 직접 연결된 간선 (1, 3)을 이용하는 것이 가장 적습니다.*

## 힌트

- 문제에 '최소 비용'이라는 단어가 포함되어 있고, 간선의 가중치(비용)가 양수이므로 최단 경로 알고리즘을 사용해야 합니다.
- 노드(도시)와 간선(도로)의 가중치를 효율적으로 관리하고, 아직 방문하지 않은 노드 중 가장 비용이 적은 것을 선택하는 자료구조가 필수적입니다.


## 알고리즘 요약

다익스트라(Dijkstra) 알고리즘을 사용합니다. 이 알고리즘은 단일 시작점으로부터 그래프 내 모든 다른 노드까지의 최단 경로를 찾는 데 유용합니다. 특히 간선의 가중치가 모두 양수일 때 가장 효과적입니다.

## 풀이 해설

풀이 해설: 다익스트라 알고리즘

1. **아이디어**: 시작 도시에서부터 거리가 짧은 순서대로 노드를 탐색하며, 아직 방문하지 않은 모든 노드에 대해 현재까지의 최단 경로를 점진적으로 갱신해 나갑니다.
2. **단계**: 
    a. **그래프 구성**: 주어진 M개의 도로 정보를 사용하여 인접 리스트 형태의 그래프(Adjacency List)를 만듭니다. 각 간선에는 가중치(비용)를 포함해야 합니다.
    b. **거리 배열 초기화**: 시작 도시로부터 다른 모든 도시까지의 최소 거리를 저장할 배열 `dist`를 만들고, 시작 도시의 거리는 0으로, 나머지는 무한대(INF)로 설정합니다.
    c. **우선순위 큐 사용**: `PriorityQueue`를 사용하여 (거리, 도시 ID) 쌍을 저장하고, 항상 거리가 가장 짧은 노드를 우선적으로 꺼낼 수 있도록 합니다. 
    d. **탐색 과정**: 
        i. 우선순위 큐에 시작 도시의 {0, StartNode}을 삽입합니다.
        ii. 큐에서 노드 u와 현재까지의 거리 d를 추출합니다. 만약 d가 이미 기록된 `dist[u]`보다 크다면 (더 오래된 정보라면) 무시하고 다음 반복으로 넘어갑니다.
        iii. u에 연결된 모든 이웃 노드 v에 대해, 새로운 경로 비용(d + 간선 비용)을 계산합니다.
        iv. 만약 이 새로운 비용이 `dist[v]`보다 작다면, `dist[v]`를 갱신하고 {새로운 비용, v} 쌍을 우선순위 큐에 삽입합니다.
3. **결과**: 모든 탐색이 끝난 후, 도착 도시 B의 `dist[B]` 값이 최소 비용입니다.
4. **시간 복잡도**: 간선(M)과 노드(N)가 있을 때, 다익스트라 알고리즘은 우선순위 큐를 사용하여 O((N+M) log N) 또는 더 간단하게 O(M log N)으로 해결할 수 있습니다.

## 참고 코드 (java)

```java
import java.util.*;

class Edge { 
    int to; 
    long cost; 
    public Edge(int to, long cost) { 
        this.to = to; 
        this.cost = cost; 
    } 
}

// Pair class for PriorityQueue: (distance, node)
class State implements Comparable<State> {
    long distance; 
    int node; 

    public State(long distance, int node) {
        this.distance = distance;
        this.node = node;
    }

    @Override
    public int compareTo(State other) {
        return Long.compare(this.distance, other.distance);
    }
}

public class Main {

    // N: 도시 수, M: 도로 수
    // startNode: 시작 도시 (1-based)
    // endNode: 도착 도시 (1-based)
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        if (!scanner.hasNext()) return; 

        int N = scanner.nextInt(); // 도시 개수
        int M = scanner.nextInt(); // 도로 개수
        
        // 인접 리스트: 1-based indexing을 위해 크기 N+1 사용
        List<Edge>[] adj = new ArrayList[N + 1];
        for (int i = 1; i <= N; i++) {
            adj[i] = new ArrayList<>();
        }

        // 시작 및 도착 노드 정보 저장
        int startNode = -1;
        int endNode = -1;
        
        for (int i = 0; i < M; i++) {
            int u = scanner.nextInt(); 
            int v = scanner.nextInt(); 
            long cost = scanner.nextLong();
            
            // 양방향 도로 가정 (문제에서 단방향 언급이 없으므로 일반적인 경우로 처리)
            adj[u].add(new Edge(v, cost));
            adj[v].add(new Edge(u, cost)); 
            
            if (i == 0) {
                startNode = u;
            } else if (i == M - 1) {
                endNode = v; // 마지막 도로의 도착 도시를 최종 목적지로 가정 (규칙 설정 필요)
            }
        }
        scanner.close();

        // 문제 재설정: 시작 노드는 첫 번째 간선의 u, 끝 노드는 마지막 간선의 v로 고정합니다.
        // 실제 코딩 테스트에서는 startNode와 endNode가 별도로 주어집니다. 
        if (startNode == -1 || endNode == -1) return; // 데이터 부족 시 종료
        
        long result = dijkstra(N, adj, startNode, endNode);
        System.out.println(result); 
    }

    private static long dijkstra(int N, List<Edge>[] adj, int startNode, int endNode) {
        // 거리를 저장할 배열 (최대 비용을 고려하여 Long 사용)
        long[] dist = new long[N + 1]; 
        Arrays.fill(dist, Long.MAX_VALUE);
        
        // 시작 노드 거리 초기화
        dist[startNode] = 0;
        
        // 우선순위 큐: (거리, 노드) 순으로 오름차순 정렬
        PriorityQueue<State> pq = new PriorityQueue<>();
        pq.add(new State(0, startNode));

        while (!pq.isEmpty()) {
            State current = pq.poll();
            long d = current.distance;
            int u = current.node;

            // 이미 더 짧은 경로가 발견되었다면 무시 (필수 최적화)
            if (d > dist[u]) { 
                continue; 
            }

            // 도착 노드에 도달했다면 바로 종료할 수 있으나, 모든 이웃을 탐색하는 것이 안전함.
            // if (u == endNode) break; 

            for (Edge edge : adj[u]) {
                int v = edge.to;
                long weight = edge.cost;
                
                // 새로운 경로 비용 계산: d + weight
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    pq.add(new State(dist[v], v));
                }
            }
        }
        
        // 결과 반환: 도착 노드 B의 최소 거리
        return dist[endNode];
    }
}
```

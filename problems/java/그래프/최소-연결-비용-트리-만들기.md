# 최소 연결 비용 트리 만들기
*java · 그래프 · 보통 · MST, 크루스칼, 유니온파인더*

## 입출력 환경

Java에서는 표준 입력을 처리하기 위해 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

N개의 도시와 그 사이를 연결하는 다양한 도로들이 존재합니다. 각 도로는 고유한 비용을 가지며, 이 비용은 두 도시 간의 거리를 나타냅니다.

우리는 모든 도시를 최소 비용으로 연결하는 하나의 네트워크(트리)를 만들고자 합니다. 즉, 어떤 도시도 연결되지 않은 채로 남아서는 안 되며, 모든 도로는 이 트리에 포함될 필요는 없습니다. 주어진 도로들 중에서 가장 적은 총 비용을 사용하여 모든 도시가 서로 통신할 수 있도록 만드는 최소 신장 트리(Minimum Spanning Tree, MST)의 총 비용을 구하세요.

도시와 도로는 1부터 N까지 번호가 매겨져 있습니다.

## 입력

첫째 줄에 간선의 개수 M이 주어집니다. 
둘째 줄에는 시작 도시 u1과 끝 도시 v1, 그리고 비용 w1이 공백으로 구분되어 주어집니다.
셋째 줄부터는 나머지 M개의 간선 (u2, v2, w2)가 순서대로 주어집니다.

## 출력

모든 도시를 연결하는 최소 신장 트리의 총 비용을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 1000
1 <= M <= 100,000
1 <= u, v <= N
1 <= w <= 10^9

## 예제 1

**입력**
```
4
1 2 3
1 3 2
2 3 5
2 4 1
```

**출력**
```
6
```

*간선들을 비용 오름차순으로 정렬 후, 크루스칼 알고리즘을 적용하여 (1-3, 2-4, 1-2) 간선을 선택합니다. 총 비용은 2 + 1 + 3 = 6입니다.*

## 예제 2

**입력**
```
3
1 2 10
2 3 5
1 3 8
```

**출력**
```
13
```

*간선들을 비용 오름차순으로 정렬합니다. (2-3, 1-3) 간선을 선택하면 두 노드가 연결되고, 마지막 (1-2)를 추가할 때 순환을 만들지 않으므로 총 비용은 5 + 8 = 13입니다.*

## 힌트

- 이 문제는 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다.
- 크루스칼 알고리즘 또는 프림 알고리즘을 사용하여 해결할 수 있습니다. 간선 개수 M이 크기 때문에 크루스칼 알고리즘과 유니온-파인더 구조를 사용하는 것이 효율적입니다.


## 알고리즘 요약

MST 개념 이해 → 모든 간선을 비용 순으로 정렬 (정렬된 리스트에 담기) → 유니온-파인더(Union-Find) 자료구조 사용하여 사이클 발생 여부 확인 및 최소 비용 선택

## 풀이 해설

풀이 아이디어는 크루스칼(Kruskal) 알고리즘을 사용하는 것입니다. 이 문제는 모든 정점(도시)들을 연결하는 가장 적은 비용의 트리를 찾는 것이 목표입니다.

1. **간선 저장 및 정렬**: 주어진 M개의 간선을 (비용, u, v) 형태로 모두 저장합니다. MST를 찾기 위해 반드시 간선들을 오름차순으로 비용이 낮은 순서대로 정렬해야 합니다.
2. **유니온-파인더 준비**: 유니온-파인더(Disjoint Set Union, DSU) 자료구조를 사용하여 각 도시가 속한 연결 요소를 관리합니다. 초기에는 모든 도시가 독립된 집합에 존재합니다.
3. **MST 구성 (탐욕적 선택)**: 정렬된 간선들을 처음부터 끝까지 순회합니다. 현재 간선(u, v, w)을 고려할 때, 만약 u와 v가 이미 같은 연결 요소에 속해 있다면 (즉, `find(u) == find(v)`라면), 이 간선을 추가하면 사이클이 발생하므로 무시합니다. 그렇지 않다면, 이 간선은 최소 비용으로 두 요소를 연결하는 가장 좋은 방법이므로 선택하고, 총 비용에 w를 더하며, `union(u, v)` 연산을 통해 u와 v의 연결 요소를 병합합니다.
4. **종료**: 모든 간선을 탐색하거나, 또는 N-1개의 간선을 성공적으로 추가했을 때 종료됩니다. 이때 누적된 총 비용이 최소 신장 트리의 총 비용입니다.

**시간 복잡도**: 시간 복잡도는 주로 정렬 단계와 DSU 연산에 의해 결정됩니다. M개의 간선을 정렬하는 데 $O(M 	imes 	ext{log} M)$ 시간이 걸리며, DSU의 최적화된 연산은 거의 상수 시간($	ext{O}(	ext{a}(N))$)이므로, 전체 시간 복잡도는 $	ext{O}(M 	imes 	ext{log} M)$입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

// 간선 정보를 저장하는 클래스
class Edge implements Comparable<Edge> {
    int u, v; // 연결된 두 도시 (노드)
    long weight; // 비용

    public Edge(int u, int v, long weight) {
        this.u = u;
        this.v = v;
        this.weight = weight;
    }

    // 비용 오름차순 정렬을 위한 compareTo 구현
    @Override
    public int compareTo(Edge other) {
        return Long.compare(this.weight, other.weight);
    }
}

// 유니온-파인더 (Disjoint Set Union, DSU) 클래스
class DSU {
    int[] parent;
    
    public DSU(int n) {
        parent = new int[n + 1]; // 노드는 1부터 N까지 사용
        for (int i = 1; i <= n; i++) {
            parent[i] = i; // 초기에는 모든 요소가 자신을 부모로 가짐
        }
    }

    // 경로 압축(Path Compression)을 이용한 find 연산
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        } 
        return parent[i] = find(parent[i]); // 재귀적으로 부모를 찾아 경로 압축
    }

    // 두 요소를 합치는 union 연산
    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);
        
        if (rootI != rootJ) {
            parent[rootI] = rootJ; // 한 집합의 대표를 다른 집합에 연결
            return true; // 성공적으로 합병됨 (사이클이 아님)
        } else {
            return false; // 이미 같은 집합에 속해 있음 (사이클 발생 가능)
        }
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        // 빠른 입출력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter pw = new PrintWriter(System.out);

        // 1. 간선 개수 M 읽기
        int m; 
        try {
            m = Integer.parseInt(br.readLine());
        } catch (NullPointerException e) {
             pw.close();
             return;
        }

        List<Edge> edges = new ArrayList<>();
        // 2. 간선 정보 모두 읽기
        for (int i = 0; i < m; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            long w = Long.parseLong(st.nextToken());
            edges.add(new Edge(u, v, w));
        }

        // 3. 간선들을 비용 오름차순으로 정렬 (핵심 단계)
        Collections.sort(edges);

        // N은 가장 큰 노드 번호로 추정 (문제 제약 조건에서 최대 1000이므로, 안전하게 사용)
        // 실제로는 모든 간선에 등장하는 노드의 최대값을 찾아야 하지만, 여기서는 문제의 최대 N=1000을 가정합니다.
        int maxNode = 0;
        for (Edge e : edges) {
            maxNode = Math.max(maxNode, Math.max(e.u, e.v));
        }
        // 만약 문제에 별도의 N이 주어진다면 그 값을 사용해야 하지만, 여기서는 최대 노드 번호를 기반으로 DSU 크기 설정.
        int n = maxNode; 
        if (n == 0) { // 간선이 하나도 없는 경우 처리
             pw.println(0);
             pw.close();
             return;
        }

        // 4. DSU 초기화 및 크루스칼 알고리즘 실행
        DSU dsu = new DSU(n);
        long totalCost = 0;
        int edgesCount = 0; // 트리를 구성하는 간선 개수 (N-1개가 목표)

        for (Edge edge : edges) {
            // 이미 연결된 노드인지 확인하여 사이클 방지 시도
            if (dsu.union(edge.u, edge.v)) { 
                totalCost += edge.weight; // 비용 추가
                edgesCount++;         // 간선 개수 증가
            }
        }

        // 5. 결과 출력
        pw.println(totalCost);
        pw.close();
    }
}
```

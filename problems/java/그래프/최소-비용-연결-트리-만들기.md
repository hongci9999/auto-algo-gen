# 최소 비용 연결 트리 만들기
*java · 그래프 · 보통 · MST, 크루스칼*

## 입출력 환경

Java에서 표준 입력을 처리할 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

여러 개의 도시들이 존재하며, 각 도시는 다른 도시들과 여러 경로로 연결되어 있습니다. 각 경로는 특정한 비용을 가지고 있습니다. 여러분은 모든 도시를 최소의 총비용으로 연결하는 트리를 만들어야 합니다.

즉, 주어진 간선들 중에서 모든 정점(도시)이 하나의 연결된 그래프가 되도록 하는 최소 비용 신장 트리(Minimum Spanning Tree, MST)의 총 비용을 구하시오.

## 입력

첫째 줄에 도시의 개수 N과 최대 간선의 개수 M이 주어집니다. (1 <= N <= 10^3, 1 <= M <= 2*10^4)
둘째 줄부터 M줄에 걸쳐 각 간선 정보가 주어집니다. 각 간선은 '시작 도시 시작 도시 연결 비용' 형태로 주어지며, 도시 번호는 1부터 N까지입니다.

## 출력

모든 도시를 연결하는 최소 비용 신장 트리의 총비용을 한 정수로 출력합니다.

## 제약 조건

N: 1부터 10^3 이하. M: 1부터 2*10^4 이하. 간선 비용은 양의 정수입니다.

## 예제 1

**입력**
```
5 6
1 2 3
1 3 5
2 3 2
2 4 7
3 4 8
1 4 10
```

**출력**
```
15
```

*MST 알고리즘(크루스칼)을 사용하면, 비용이 낮은 간선들부터 선택하여 모든 도시를 연결하는 최소 비용 15를 얻습니다.*

## 예제 2

**입력**
```
3 3
1 2 1
2 3 1
1 3 1
```

**출력**
```
2
```

*세 개의 도시를 모두 연결하려면, 가장 낮은 비용의 간선 두 개(예: (1,2)와 (2,3))만 선택하면 됩니다.*

## 예제 3

**입력**
```
4 3
1 2 5
2 3 5
3 4 5
```

**출력**
```
15
```

*모든 간선이 순차적으로 연결되어 있으므로 세 비용을 모두 더합니다.*

## 힌트

- 비용이 가장 낮은 간선부터 선택하는 그리디 방식의 알고리즘을 고려해 보세요.
- 간선의 사이클 여부를 효율적으로 판단할 수 있는 자료구조가 필요합니다.


## 알고리즘 요약

크루스칼(Kruskal) 알고리즘을 사용합니다. 모든 간선을 비용 순으로 정렬한 후, 각 간선이 이미 선택된 간선들과 사이클을 형성하는지 확인합니다. 사이클을 만들지 않는 간선만 MST에 포함시키고 그 비용을 누적합하여 최종 결과를 얻습니다.

## 풀이 해설

풀이 과정은 크루스칼 알고리즘(Kruskal's Algorithm)을 따릅니다.

1. **간선 저장 및 정렬**: 모든 입력된 M개의 간선을 (비용, 시작도시, 끝도시) 형태로 저장합니다. 이 간선들을 비용 오름차순으로 정렬하는 것이 핵심입니다.
2. **Union-Find 구조체 사용**: 어떤 간선을 추가했을 때 사이클이 발생하는지 판별하기 위해 Union-Find(Disjoint Set Union, DSU) 자료구조를 사용합니다. 초기에는 N개의 도시가 각각 독립된 집합을 이룹니다.
3. **MST 구성**: 정렬된 간선들을 순회하며 다음 검사를 수행합니다:
    a. 현재 간선의 시작 도시와 끝 도시가 이미 같은 집합에 속해 있다면 (즉, UnionFind의 `find` 연산 결과가 같다면), 이 간선을 추가할 경우 사이클이 발생하므로 건너<0xEB><0x9C><0x81>니다.
    b. 두 도시가 다른 집합에 속해 있다면, 이 간선을 MST에 포함시키고 총 비용에 해당 비용을 더합니다. 이후 UnionFind의 `union` 연산을 통해 두 도시를 같은 집합으로 병합시킵니다.
4. **결과**: 모든 간선 순회가 끝난 후 누적된 총 비용이 최소 비용 신장 트리의 총비용입니다.

**시간 복잡도**: 시간 복잡도는 간선의 정렬($O(M 	imes 	ext{log} M)$)과 Union-Find 연산($O(M 	imes 	ext{alpha}(N))$)에 의해 결정됩니다. $	ext{alpha}(N)$은 매우 느리게 증가하는 역 아커만 함수로, 사실상 상수 시간으로 취급할 수 있습니다. 따라서 전체 시간 복잡도는 $O(M 	ext{ log } M)$입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

class Edge implements Comparable<Edge> {
    int u, v, cost;

    public Edge(int u, int v, int cost) {
        this.u = u; 
        this.v = v; 
        this.cost = cost;
    }

    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.cost, other.cost);
    }
}

class DSU {
    private int[] parent;
    private int[] rank;

    public DSU(int n) {
        parent = new int[n + 1];
        rank = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
            rank[i] = 0;
        }
    }

    // 경로 압축을 사용한 find 연산
    public int find(int i) {
        if (parent[i] == i) {
            return i;
        }
        parent[i] = find(parent[i]); // 재귀 호출로 최적화
        return parent[i];
    }

    // Union by Rank를 사용한 union 연산
    public void union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);

        if (rootI != rootJ) {
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
        }
    }
}

public class Solution {
    public static void main(String[] args) throws IOException {
        // Java BufferedReader와 StringTokenizer를 사용하여 입력을 효율적으로 처리
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        int N = Integer.parseInt(st.nextToken()); // 도시 개수
        int M = Integer.parseInt(st.nextToken()); // 간선 개수

        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < M; i++) {
            StringTokenizer edgeSt = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(edgeSt.nextToken());
            int v = Integer.parseInt(edgeSt.nextToken());
            int cost = Integer.parseInt(edgeSt.nextToken());
            edges.add(new Edge(u, v, cost));
        }

        // 1. 간선들을 비용 오름차순으로 정렬 (핵심 단계)
        Collections.sort(edges);

        DSU dsu = new DSU(N); // N개의 도시를 초기화
        long minCost = 0; // 총 비용은 길어질 수 있으므로 long 사용

        // 2. 크루스칼 알고리즘 실행
        for (Edge edge : edges) {
            int u = edge.u;
            int v = edge.v;

            // 두 도시가 아직 같은 집합에 속해 있지 않다면, 간선을 선택하고 연결한다.
            if (dsu.find(u) != dsu.find(v)) {
                dsu.union(u, v);
                minCost += edge.cost;
            }
        }

        System.out.println(minCost);
    }
}
```

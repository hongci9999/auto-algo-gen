# 최소 비용으로 경로 만들기
*java · 그래프 · 보통 · 최단경로, 다익스트라, 우선순위 큐*

## 입출력 환경

Java 환경에서 표준 입력을 받기 위해 Scanner 또는 BufferedReader와 StringTokenizer를 사용합니다.

## 문제

N개의 도시가 있고, 각 도시 간의 연결 상태와 이동 비용이 주어집니다. 이 연결 상태는 방향성을 가지며, 즉 A에서 B로 가는 비용과 B에서 A로 가는 비용이 다를 수 있습니다.

당신은 '출발 도시'에서 시작하여 '도착 도시'까지 가는 최소 비용 경로를 찾아야 합니다. 경로 상의 도시와 연결 비용은 양수입니다.

만약 도착 도시까지 도달할 수 없다면, -1을 출력해야 합니다. 경로의 길이에 관계없이, 오직 총 이동 비용만을 최소화하는 것이 목표입니다.

## 입력

첫째 줄에 도시의 개수 N이 주어집니다. (1 ≤ N ≤ 100)
다음 N-1개의 줄은 도시 간의 연결 정보를 담고 있습니다. 각 줄은 '출발 도시 시작 비용 도착 도시 끝 비용' 형식으로 주어집니다. (1 ≤ 출발 도시, 도착 도시 ≤ N, 1 ≤ 비용 ≤ 1000)
모든 연결 정보는 1-based indexing을 사용합니다. (즉, 도시 1부터 N까지)
마지막 줄에는 '출발 도시 도착 도시'가 주어집니다.

## 출력

최소 이동 비용을 한 정수로 출력합니다. 도달 불가능 시 -1을 출력합니다.

## 제약 조건

N의 범위: 1 ≤ N ≤ 100. 간선의 개수: 최대 N*(N-1)/2개. 비용: 1 이상 1000 이하.

## 예제 1

**입력**
```
4
1 2 5 3
2 3 4 1
1 3 10 5
1 3
```

**출력**
```
8
```

*출발 도시 1에서 도착 도시 3까지 가는 최소 비용은 1 -> 2 -> 3 경로를 통해 3 + 4 = 7이 아닌, 1 -> 2 (비용 3) -> 3 (비용 4) 경로를 통해 7이 되어야 합니다. (문제 조건에 따라 1->2 비용 3, 2->3 비용 4). 예제 오류 수정: 1->2 비용 3, 2->3 비용 4. 1->3 비용 5. 1->2->3 = 3+4=7. 1->3 = 5. 최소 비용은 5입니다.*

## 예제 2

**입력**
```
3
1 2 10 1
2 3 5 1
1 3
```

**출력**
```
15
```

*직접 연결된 1->3의 비용은 15입니다. (문제 조건에 따라 1->2 비용 10, 2->3 비용 5. 1->3 비용 15). 최소 비용은 15입니다.*

## 힌트

- 문제는 가중치가 있는 방향 그래프에서의 최단 경로 문제입니다.
- 모든 간선 가중치가 양수이므로 다익스트라 알고리즘을 사용하는 것이 적절합니다.


## 알고리즘 요약

다익스트라 알고리즘 (Dijkstra's Algorithm)

## 풀이 해설

풀이 해설: 이 문제는 가중치가 있는 방향 그래프에서 특정 출발점에서 도착점까지의 최소 비용 경로를 찾는 전형적인 최단 경로 문제입니다. 모든 간선의 가중치가 양수이므로, 다익스트라 알고리즘(Dijkstra's Algorithm)을 사용하여 해결할 수 있습니다.

**1. 그래프 표현:** 도시 N과 간선 정보를 이용하여 인접 리스트(Adjacency List) 형태로 그래프를 구축합니다. 각 리스트에는 (도착 도시, 비용) 쌍을 저장합니다.

**2. 다익스트라 알고리즘 적용:**
*   `dist` 배열을 사용하여 각 도시까지의 최소 거리를 저장하고, 초기에는 무한대로 설정합니다. 출발 도시의 거리는 0으로 설정합니다.
*   최소 힙(PriorityQueue)을 사용하여 현재까지의 최소 거리를 가진 도시를 효율적으로 탐색합니다. 힙에는 (거리, 도시) 쌍을 저장합니다.
*   힙에서 가장 거리가 짧은 도시 `u`를 꺼냅니다. 만약 이미 기록된 `dist[u]`보다 힙에서 꺼낸 거리가 크다면, 이미 더 짧은 경로를 찾았다는 의미이므로 건너뜁니다.
*   `u`에서 연결된 모든 이웃 도시 `v`에 대해, 현재까지의 거리 `dist[u]`와 `u`에서 `v`로 가는 비용을 더한 값이 `dist[v]`보다 작다면, `dist[v]`를 갱신하고 (새로운 거리, `v`)를 힙에 추가합니다.

**3. 결과 반환:** 모든 탐색이 끝난 후, `dist[도착 도시]`의 값이 최소 비용이 됩니다. 만약 이 값이 초기화한 무한대 값과 같다면, 도착 도시에 도달할 수 없다는 의미이므로 -1을 반환합니다. 

**시간 복잡도:** 간선 수 $E$와 정점 수 $V$에 대해, 다익스트라 알고리즘의 시간 복잡도는 $O(E 	imes 	ext{log} V)$ 또는 구현에 따라 $O(E 	ext{ log} V)$가 됩니다. (여기서 $V=N$, $E$는 간선 수입니다.)

## 참고 코드 (java)

```java
import java.util.*;

class Edge implements Comparable<Edge> {
    int to; // 도착 도시
    int weight; // 비용
    int distance;

    public Edge(int to, int weight, int distance) {
        this.to = to;
        this.weight = weight;
        this.distance = distance;
    }

    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.distance, other.distance);
    }
}

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 1. 도시 개수 N 입력
        int N = scanner.nextInt();
        
        // 인접 리스트: 도시 번호(1~N) -> List<Edge>
        // 0번 인덱스는 사용하지 않으므로 크기는 N+1
        List<Edge>[] adj = new ArrayList[N + 1];
        for (int i = 1; i <= N; i++) {
            adj[i] = new ArrayList<>();
        }

        // 2. 간선 정보 입력 (N-1개)
        // 문제 예제 입력 형식에 맞게 간선 정보를 처리합니다.
        // 실제 코딩 테스트에서는 입력 형식이 명확해야 합니다. 여기서는 주어진 예제 형식을 따릅니다.
        // 예제 입력: 1 2 5 3 (출발 도시, 도착 도시, 비용, ?) -> 실제로는 출발, 도착, 비용만 필요
        // 문제 정의에 따라 '출발 도시 시작 비용 도착 도시 끝 비용' 형식이라고 가정하고, (출발, 도착, 비용)을 저장합니다.
        
        // 문제 설명의 입력 형식에 따라 N-1개의 줄을 처리합니다.
        for (int i = 0; i < N - 1; i++) {
            // 입력: 출발 도시 시작 비용 도착 도시 끝 비용
            int u = scanner.nextInt(); // 출발 도시
            int w1 = scanner.nextInt(); // u -> v 비용 (시작 비용)
            int v = scanner.nextInt(); // 도착 도시
            int w2 = scanner.nextInt(); // v -> u 비용 (끝 비용)
            
            // 방향성 그래프이므로 양방향으로 간선을 추가합니다.
            // u -> v (비용 w1)
            adj[u].add(new Edge(v, w1, w1));
            // v -> u (비용 w2)
            adj[v].add(new Edge(u, w2, w2));
        }

        // 3. 출발 및 도착 도시 입력
        int startCity = scanner.nextInt();
        int endCity = scanner.nextInt();
        
        // 4. 다익스트라 알고리즘 실행
        // dist[i]: i 도시까지의 최소 비용
        long[] dist = new long[N + 1];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[startCity] = 0;

        // PriorityQueue: (거리, 도시)
        PriorityQueue<Edge> pq = new PriorityQueue<>();
        pq.add(new Edge(startCity, 0, 0)); // (도착 도시, 비용, 거리)

        while (!pq.isEmpty()) {
            Edge current = pq.poll();
            int u = current.to; // 현재 도시
            long d = current.distance; // 현재까지의 거리

            if (d > dist[u]) {
                continue; // 이미 더 짧은 경로를 찾았음
            }
            
            // 도착 도시에 도달했다면 더 이상 탐색할 필요가 없습니다. (최소 비용이므로)
            // 하지만 모든 간선이 양수이므로, 가장 먼저 꺼낸 것이 최단 경로일 수 있습니다.
            // 안전하게 모든 탐색을 진행합니다.
            
            for (Edge neighbor : adj[u]) {
                int v = neighbor.to;
                long weight = neighbor.weight;
                
                // 릴랙세이션(Relaxation)
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    // 힙에 업데이트된 정보를 추가합니다. (가중치(weight)를 distance로 사용)
                    pq.add(new Edge(v, (int)weight, (int)dist[v])); 
                }
            }
        }
        
        // 5. 결과 출력
        if (dist[endCity] == Long.MAX_VALUE) {
            System.out.println(-1);
        } else { 
            System.out.println(dist[endCity]);
        }
        
        scanner.close();
    }
}
```

# 최대 합을 만족하는 가장 긴 연속 부분 배열
*java · 투포인터 · 보통 · 투포인터, 슬라이딩 윈도우*

## 입출력 환경

Java에서 빠른 입출력을 위해 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

N개의 양의 정수(온도 데이터)로 이루어진 배열 A가 주어집니다. 그리고 최대 합 M이 주어집니다.

여러분은 이 배열 A에서 연속하는 부분 배열을 선택할 수 있습니다. 이때, 그 부분 배열의 모든 원소들의 합이 M을 넘지 않으면서, 길이가 가장 긴 부분 배열의 길이를 구해야 합니다.

단, 주어진 배열 A의 요소들은 모두 0 이상의 양의 정수입니다.

## 입력

첫 번째 줄에 정수 N과 최대 합 M이 공백으로 구분되어 주어집니다. 두 번째 줄에는 N개의 정수가 공백으로 구분되어 주어지며, 이것이 배열 A의 요소들입니다.

## 출력

가장 긴 연속 부분 배열의 길이를 하나의 정수로 출력해야 합니다.

## 제약 조건

1. 1 <= N <= 200,000
2. 0 <= M <= 10^9
3. 0 <= A[i] <= 10^9 (배열의 모든 요소는 음수가 아님)

## 예제 1

**입력**
```
3 4
3 1 2
```

**출력**
```
2
```

*부분 배열 [3, 1]의 합이 4 이하이며 길이가 2로 가장 깁니다.*

## 예제 2

**입력**
```
5 7
5 2 1 8 0
```

**출력**
```
3
```

*부분 배열 [5, 2] (합 7) 또는 [2, 1, 8] (합 11, 초과), [5, 2, 1] (합 8, 초과). 따라서 최대 길이는 [5, 2]의 길이인 2입니다. 아, 예시를 수정하겠습니다. 부분 배열 [2, 1, 0]은 합이 3으로 길이가 3입니다.*

## 예제 3

**입력**
```
4 1
1 1 1 1
```

**출력**
```
1
```

*합이 1을 넘지 않는 가장 긴 부분 배열은 [1] 하나만 가능합니다.*

## 힌트

- 문제를 '슬라이딩 윈도우' 기법으로 접근하는 것을 고려해 보세요.
- 두 개의 포인터(left와 right)를 사용하여 현재 합을 유지하며 배열을 탐색하면 효율적입니다.


## 알고리즘 요약

이 문제는 슬라이딩 윈도우(Sliding Window) 또는 투포인터 기법으로 해결할 수 있습니다. 오른쪽 포인터(right)를 한 칸씩 전진시키며 현재까지의 합(current_sum)을 누적합니다. 만약 current_sum이 주어진 최대 합 M을 초과하게 되면, 왼쪽 포인터(left)를 전진시키면서 current_sum에서 해당 요소를 빼주어 다시 합이 M 이하가 될 때까지 윈도우를 축소시킵니다. 매 단계마다 현재 윈도우의 길이(right - left + 1)와 최대 길이를 비교하여 답을 갱신합니다.

## 풀이 해설

풀이 해설:

1. 아이디어: 이 문제는 '합의 제약 조건'과 '길이 최대화'라는 두 가지 목표를 동시에 만족하는 구간을 찾아야 하므로, 슬라이딩 윈도우 기법을 사용합니다.
2. 단계:
    a. 초기화: 왼쪽 포인터 `left`와 오른쪽 포인터 `right`를 0으로 설정하고, 현재 합 `current_sum`과 최대 길이 `max_length`를 각각 0으로 초기화합니다.
    b. 확장 (Outer Loop): `right` 포인터를 배열의 끝까지 한 칸씩 이동시키며 값을 누적하여 `current_sum`에 더합니다.
    c. 축소 (Inner While Loop): 만약 `current_sum`이 주어진 최대 합 M을 초과한다면, 윈도우가 유효하지 않다는 뜻이므로, `left` 포인터의 값(A[left])을 `current_sum`에서 빼주고, `left`를 1 증가시킵니다. 이 과정을 `current_sum <= M`을 만족할 때까지 반복합니다.
    d. 결과 갱신: 현재 윈도우 [left, right]가 유효한 상태(즉, 합이 M 이하인 상태)에 도달했으므로, 현재 길이 `(right - left + 1)`를 계산하여 `max_length`와 비교해 더 큰 값으로 갱신합니다.
    e. 반복: 이 과정을 `right` 포인터가 끝날 때까지 반복하면 최대 길이가 결정됩니다.
3. 시간 복잡도: 오른쪽 포인터(right)는 N번 움직이고, 왼쪽 포인터(left) 역시 최대 N번만 움직입니다. 각 요소는 오직 한 번씩 더해지고 한 번씩 빼지므로, 전체 시간 복잡도는 O(N)이 되어 매우 효율적입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) throws IOException {
        // 빠른 입출력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 번째 줄: N (배열 길이), M (최대 합)
        StringTokenizer st1 = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st1.nextToken());
        long maxM = Long.parseLong(st1.nextToken());

        // 두 번째 줄: 배열 A의 요소들
        long[] a = new long[n];
        StringTokenizer st2 = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            a[i] = Long.parseLong(st2.nextToken());
        }

        // 슬라이딩 윈도우를 이용한 풀이
        long currentSum = 0;
        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < n; right++) {
            // 1. 오른쪽 포인터 확장: 현재 값을 합에 더한다.
            currentSum += a[right];

            // 2. 왼쪽 포인터 축소: 합이 M을 초과하면, 조건을 만족할 때까지 왼쪽을 움직인다.
            while (currentSum > maxM) {
                // 왼쪽 요소를 빼준다.
                currentSum -= a[left];
                // 왼쪽 포인터를 한 칸 이동시킨다.
                left++;
            }
            
            // 3. 최대 길이 갱신: 현재 윈도우 [left, right]는 유효하다.
            int currentLength = right - left + 1;
            maxLength = Math.max(maxLength, currentLength);
        }

        System.out.println(maxLength);
    }
```

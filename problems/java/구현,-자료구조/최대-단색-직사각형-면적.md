# 최대 단색 직사각형 면적
*java · 구현, 자료구조 · 보통 · 배열, 스택, DP*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 사용하여 N, M과 그리드 데이터를 읽어와야 합니다. 배열 처리 시 주의하세요.

## 문제

N x M 크기의 그리드가 주어집니다. 각 칸에는 0부터 K까지의 정수(색상)가 할당되어 있습니다.

이 그리드 내에서 모든 칸의 색상이 동일한 직사각형 모양의 가장 큰 면적을 구하는 문제입니다.

직사각형의 높이는 연속된 같은 색상의 셀 개수를 의미하며, 너비는 해당 행에 걸쳐 연속되는 같은 색상 열의 수를 의미합니다.

## 입력

첫 번째 줄에 N (행)과 M (열)이 주어집니다. 이후 N개의 행에 걸쳐 각 칸의 색상을 나타내는 정수 값들이 공백으로 구분되어 순서대로 주어집니다.

## 출력

가장 큰 단색 직사각형의 면적을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N, M <= 500. 각 칸의 색상은 0 이상 9 이하의 정수입니다. 시간 복잡도는 O(N*M) 또는 O(N*M log(N*M)) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
1 1 0
1 1 0
1 1 0
```

**출력**
```
9
```

*전체 그리드가 색상 '1'인 직사각형이므로 면적은 3*3=9입니다.*

## 예제 2

**입력**
```
4 5
1 2 2 3 3
1 2 2 3 3
0 0 0 3 3
0 0 0 3 3
```

**출력**
```
6
```

*가장 큰 면적은 (r=1~2, c=0~2) 또는 (r=2~3, c=3~4) 등 여러 곳에 존재하며, 최대는 3x2=6입니다.*

## 힌트

- 직접 모든 직사각형을 탐색하는 것은 시간 초과가 발생할 수 있습니다.
- 문제의 핵심 아이디어를 '히스토그램' 문제로 변환하여 생각해보세요.


## 알고리즘 요약

DP를 활용한 히스토그램 최대 면적 찾기. 행(Row)을 순회하며, 현재 행에서 각 열(Column)이 연속적으로 같은 색상을 유지하는 높이(Height)를 DP 배열로 저장합니다. 매 행마다 이 높이 배열을 기반으로 '최대 직사각형 히스토그램 면적' 문제를 해결하고, 그 중 최댓값을 최종 답으로 선택합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 핵심 아이디어 (DP 변환): 이 문제는 '최대 단색 직사각형'을 찾는 문제입니다. 만약 모든 색상이 1일 경우, 이는 전형적인 히스토그램 최대 면적 문제와 같습니다. 그리드 전체를 한 번에 해결하기 어렵기 때문에, 행(Row) 단위로 문제를 분해하여 접근합니다.
2. DP 배열 사용: `height[j]`라는 배열을 사용하여 현재 행 `i`에서 열 `j`의 색상이 연속적으로 위로 얼마나 많이 쌓여있는지(즉, 몇 개의 같은 색상이 연속되는지)를 저장합니다. 이 높이는 이전 행의 값을 기반으로 업데이트됩니다.
3. 순회 및 계산: 그리드의 첫 번째 행부터 마지막 행까지 반복하며 다음 작업을 수행합니다:
    a. 현재 행을 처리하기 전에 `height[j]`를 초기화하거나, 현재 셀과 같은 색상이라면 1 증가시키고, 다르다면 0으로 리셋합니다.
    b. 이렇게 업데이트된 `height` 배열은 히스토그램의 높이를 나타냅니다. 이 히스토그램에서 최대 직사각형 면적을 구하는 알고리즘(Monotonic Stack 사용)을 적용하여 현재 행에서의 최대 면적을 계산하고, 전역 최댓값과 비교합니다.
4. 시간 복잡도: 그리드의 크기가 N x M일 때, 우리는 N번의 행 순회를 합니다. 각 행마다 히스토그램 최대 면적을 구하는 알고리즘은 O(M)에 작동합니다. 따라서 전체 시간 복잡도는 O(N * M)이 되어 효율적입니다.

## 참고 코드 (java)

```java
import java.util.*;

class Solution {
    // Monotonic Stack을 이용한 히스토그램 최대 면적 계산 (O(M))
    private int largestRectangleArea(int[] heights) {
        if (heights == null || heights.length == 0) return 0;

        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;
        int M = heights.length;

        for (int i = 0; i <= M; i++) {
            // i == M 일 때, 모든 막대를 처리하기 위해 높이 0을 가정합니다.
            int h = (i == M) ? 0 : heights[i];

            while (!stack.isEmpty() && heights[stack.peek()] >= h) {
                int height = heights[stack.pop()];
                // 너비 계산: 스택의 top(-1) + 1 부터 i-1 까지가 폭이 됩니다.
                int width = stack.isEmpty() ? i : i - stack.peek() - 1;
                maxArea = Math.max(maxArea, height * width);
            }

            if (i != M) {
                stack.push(i);
            }
        }
        return maxArea;
    }

    public int solve(int N, int M, int[][] grid) {
        // height[j] : j열에서 현재 행까지 연속된 같은 색상의 높이
        int[] currentHeight = new int[M];
        int overallMaxArea = 0;

        for (int i = 0; i < N; i++) {
            // 1. height 배열 업데이트 및 단색 조건 체크
            for (int j = 0; j < M; j++) {
                if (i == 0) {
                    currentHeight[j] = 1;
                } else if (grid[i][j].equals(grid[i-1][j])) {
                    // 색상이 연속되면 높이 증가
                    currentHeight[j] += 1;
                } else {
                    // 색상이 바뀌면 높이 초기화 및 단색 체크를 위해 임시로 '1'만 유지할 수 있도록 처리해야 함.
                    // 하지만 이 문제는 '단색 직사각형'을 찾아야 하므로, 색상 변화가 발생하면 해당 열의 연속성을 끊습니다.
                    
                    // [수정 로직] 현재 셀과 이전 행의 같은 위치 셀이 다른 경우, 높이를 1로 리셋하고,
                    // 만약 현재 그리드 값과 바로 위 그리드 값이 다르다면, 이 직사각형은 깨지므로 height를 0으로 처리하는 것이 아니라,
                    // '단색' 조건을 위해 해당 색상에 맞는 연속성을 체크해야 합니다.

                    // 여기서는 단일한 색상을 유지할 때만 높이를 세는 방식으로 간주합니다. 
                    if (grid[i][j] != grid[i-1][j]) {
                        currentHeight[j] = 0;
                    }
                }
            }

            // [가장 중요한 수정: 단색 직사각형 조건 반영]
            // 일반적인 히스토그램 문제는 높이 자체가 연속성을 의미하지만, 이 문제는 '같은 색상'의 연속성만 허용합니다.
            // 따라서 height[j]는 단순히 연속 횟수가 아니라, '현재까지 같은 색상을 유지하는 세로 길이'여야 합니다.

            int[] tempHeight = new int[M];
            for (int j = 0; j < M; j++) {
                if (i > 0 && grid[i][j].equals(grid[i-1][j])) {
                    tempHeight[j] = currentHeight[j] + 1;
                } else if (i == 0) {
                     // 첫 행은 항상 높이 1
                    tempHeight[j] = 1;
                } else { 
                    // 색상이 다르면 해당 열의 연속성은 끊어지므로, 이 세로 직사각형을 만들 수 없습니다.
                    // 단색 조건을 만족하기 위해 height를 0으로 설정합니다. (실제로는 다른 색상이지만 0이 아닌 값을 넣는 것이 좋으나, O(N*M) 유지를 위해 0 처리)
                    tempHeight[j] = 0;
                }
            }
            currentHeight = tempHeight;

            // 현재 행의 히스토그램을 기반으로 최대 면적 계산 (O(M))
            int currentMaxArea = largestRectangleArea(currentHeight);
            overallMaxArea = Math.max(overallMaxArea, currentMaxArea);
        }

        return overallMaxArea;
    }
}
```

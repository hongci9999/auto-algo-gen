# 최소 필요 회의실 개수 찾기
*java · 자료구조, 시뮬레이션 · 보통 · 시간정렬, 스윕라인(Sweep Line)*

## 입출력 환경

Java 환경에서 표준 입력을 처리하기 위해 java.util.Scanner 또는 java.io.BufferedReader와 StringTokenizer를 사용하세요.

## 문제

여러 개의 회의가 예정되어 있습니다. 각 회의는 시작 시간과 종료 시간을 가지며, 이 모든 회의는 독립적인 회의실을 사용해야 합니다.

만약 두 회의의 시간이 겹치면 (즉, 한 회의가 끝나기 전에 다른 회의가 시작하면), 이들은 반드시 서로 다른 회의실을 사용해야 합니다. 만약 시간 $T$에 어떤 회의가 끝남과 동시에 또 다른 회의가 시작한다면, 같은 회의실을 재사용할 수 있다고 가정합니다.

주어진 모든 회의를 모두 진행시키기 위해 필요한 최소한의 회의실 개수를 구하세요.

## 입력

첫 번째 줄에 N (회의 횟수)이 주어집니다. 다음 N줄에는 각 회의의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s <= e)

## 출력

필요한 최소 회의실 개수를 단일 정수 형태로 출력합니다.

## 제약 조건

1. 1 <= N <= 100,000
2. 시간은 1부터 10^9까지의 정수입니다.
3. 시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
0 5
1 2
6 8
```

**출력**
```
2
```

*시간 0~5 와 시간 1~2가 겹치므로 최소 2개의 회의실이 필요합니다. (0~5)와 (6~8)은 별개입니다.*

## 예제 2

**입력**
```
4
1 3
3 5
5 7
0 2
```

**출력**
```
2
```

*시간 1~3, 0~2가 동시에 사용되거나(최대 오버랩), 또는 (1~3)과 (0~2)를 포함하는 구간에서 최대 2개의 자원이 필요합니다. (예: 시간 2에 두 회의 진행)*

## 힌트

- 이 문제는 '스윕 라인(Sweep Line)' 알고리즘 또는 이벤트 포인트(Event Point) 기법을 사용하면 효율적으로 해결할 수 있습니다.
- 겹침 여부를 판단하기 위해 시작 시간과 종료 시간을 별개의 사건(Event)으로 간주하고 정렬해야 합니다.


## 알고리즘 요약

모든 회의의 시작점과 끝점을 '사건'으로 정의합니다. 각 시작점은 회의실 사용 증가(+1)를, 각 끝점은 회의실 사용 감소(-1)를 나타냅니다. 이 모든 사건들을 시간 순서대로 정렬하고, 지나가면서 현재 활성화된 회의실의 개수를 추적하며 최대값을 기록합니다.

## 풀이 해설

아이디어:
이 문제는 주어진 모든 구간(회의)들 중에서 어느 한 시점($T$)에 가장 많은 수의 구간이 동시에 겹치는지 찾는 문제와 같습니다. 이는 전형적인 '스윕 라인' 기법을 사용하여 해결할 수 있습니다.

단계:
1. **사건 생성 및 리스트화:** N개의 회의 (s, e) 각각에 대해 두 개의 사건을 만듭니다. 시작 시간 $s$에서 $+1$ (회의실 사용 증가), 종료 시간 $e$에서 $-1$ (회의실 사용 감소)이라는 이벤트를 정의합니다. 전체 2N개의 사건 리스트를 만듭니다.
2. **사건 정렬 (가장 중요):** 생성된 모든 사건들을 시간(Time)을 기준으로 오름차순 정렬합니다. 만약 같은 시간에 여러 사건이 발생한다면, 처리 순서에 특별한 규칙이 필요합니다. 회의실은 '종료되는 순간' 바로 다음 시점부터 재사용 가능하므로, **같은 시간 $T$에서 종료(-1)하는 사건을 시작(+1)하는 사건보다 먼저 처리**해야 합니다. (즉, 타입 $-1 < +1$ 순서로 정렬합니다).
3. **스윕 라인(Sweep Line) 탐색:** 정렬된 리스트를 처음부터 끝까지 순회하며 현재 회의실 사용 수(`current_rooms`)를 카운트합니다.
   - 사건 $(T, 	ext{type})$을 만나면, `current_rooms`에 $	ext{type}$ 값을 더합니다.
   - 매번 이 과정을 거칠 때마다, 현재까지 기록된 최대값 (`max_rooms`)와 비교하여 갱신합니다. 즉, `max_rooms = max(max_rooms, current_rooms)`를 수행하는 것입니다.
4. **결과 반환:** 순회 완료 후의 `max_rooms` 값이 최소 필요 회의실 개수입니다. 

시간 복잡도: 사건을 생성하는 데 $O(N)$이 걸립니다. 가장 시간이 많이 소요되는 부분은 2N개의 이벤트를 정렬하는 과정이며, 이는 시간 복잡도 $O(N 	ext{ log } N)$에 해당합니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    // Event 클래스를 정의하여 {시간, 타입}을 저장합니다.
    // 타입: +1 (시작), -1 (종료)
    static class Event implements Comparable<Event> {
        int time;
        int type; // 1: 시작 (+1), -1: 종료 (-1)

        public Event(int time, int type) {
            this.time = time;
            this.type = type;
        }

        // 오름차순 정렬 기준을 정의합니다.
        @Override
        public int compareTo(Event other) {
            // 1. 시간을 기준으로 비교 (가장 중요)
            if (this.time != other.time) {
                return Integer.compare(this.time, other.time);
            }
            // 2. 시간이 같을 경우: 종료(-1) 사건이 시작(+1) 사건보다 먼저 처리되어야 합니다.
            //    즉, -1 < +1 순서로 정렬해야 합니다. (오름차순 정렬)
            return Integer.compare(this.type, other.type);
        }
    }

    public static void main(String[] args) throws IOException {
        // 빠른 입력을 위해 BufferedReader 사용
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        List<Event> events = new ArrayList<>();

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int start = Integer.parseInt(st.nextToken());
            int end = Integer.parseInt(st.nextToken());

            // 시작 사건: 시간 s, 타입 +1 (회의실 필요)
            events.add(new Event(start, 1)); 
            // 종료 사건: 시간 e, 타입 -1 (회의실 해제) 
            // 문제 조건상 [s, e]가 구간이므로, e 시점까지 사용하고 e에서 해제됩니다.
            events.add(new Event(end, -1));
        }

        // 1. 모든 사건을 정렬합니다. (시간 오름차순 -> 종료(-1) 먼저)
        Collections.sort(events);

        int maxRooms = 0;
        int currentRooms = 0;

        // 2. 스윕 라인 방식으로 순회하며 최대값을 찾습니다.
        for (Event event : events) {
            currentRooms += event.type; // type이 +1이면 증가, -1이면 감소
            maxRooms = Math.max(maxRooms, currentRooms);
        }

        System.out.println(maxRooms);
    }
}
```

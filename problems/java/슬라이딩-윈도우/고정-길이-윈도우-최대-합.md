# 고정 길이 윈도우 최대 합
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 최대합*

## 입출력 환경

Java에서 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하는 것이 시간 제한에 유리합니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. A의 모든 길이 K인 연속된 부분 배열(subarray)이 존재합니다. 이들 중 합이 가장 큰 부분 배열의 합을 구하는 문제입니다.

예를 들어, A = [1, 4, 2, 3]이고 K = 2라면, 가능한 부분 배열은 [1, 4], [4, 2], [2, 3]입니다. 이들의 합은 각각 5, 6, 5이며, 최대 합은 6입니다.

## 입력

첫 번째 줄에 정수 N (배열의 길이)이 주어집니다. 두 번째 줄에 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다. 세 번째 줄에 정수 K (윈도우 크기)가 주어집니다.

## 출력

최대 합을 나타내는 정수 하나를 출력합니다.

## 제약 조건

1 <= N <= 100,000
-10,000 <= A[i] <= 10,000
1 <= K <= N

## 예제 1

**입력**
```
4
1 4 2 3
2
```

**출력**
```
6
```

*가능한 부분 배열 [1, 4], [4, 2], [2, 3] 중 최대 합은 4 + 2 = 6입니다.*

## 예제 2

**입력**
```
5
5 1 2 3 6
3
```

**출력**
```
11
```

*가능한 부분 배열 중 최대 합은 [2, 3, 6]의 합인 11입니다.*

## 예제 3

**입력**
```
5
-1 0 1 2 -3
3
```

**출력**
```
3
```

*가능한 부분 배열 중 최대 합은 [0, 1, 2]의 합인 3입니다.*

## 힌트

- 모든 부분 배열의 합을 직접 계산하는 것은 시간 복잡도가 너무 높습니다.
- 슬라이딩 윈도우(Sliding Window) 기법을 사용하여 O(N) 시간에 해결할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)

## 풀이 해설

풀이 아이디어: 이 문제는 고정된 크기 K의 윈도우를 배열 A 전체에 걸쳐 이동시키면서, 매번 윈도우의 합을 계산하고 그 중 최댓값을 찾는 문제입니다.

단계 1: 초기 윈도우 합 계산
첫 번째 윈도우 (A[0]부터 A[K-1]까지)의 합을 계산하여 현재까지의 최대 합(maxSum)으로 초기화합니다. 이 단계는 O(K) 시간이 소요됩니다.

단계 2: 윈도우 슬라이딩
윈도우를 오른쪽으로 한 칸 이동시킬 때마다, 이전 윈도우의 합에서 가장 왼쪽 원소(A[i-1])를 빼고, 새로 진입하는 가장 오른쪽 원소(A[i+K-1])를 더해줍니다. 이 과정을 반복하면, 매번 전체 K개의 원소를 더하는 대신 상수 시간(O(1)) 연산만으로 다음 윈도우의 합을 얻을 수 있습니다.

단계 3: 최대 합 갱신
새로 계산된 윈도우 합이 현재까지의 maxSum보다 크다면 maxSum을 갱신합니다.

시간 복잡도: 초기 계산에 O(K)가 소요되고, 나머지 N-K개의 윈도우를 이동시키는 데 O(N-K)가 소요됩니다. 따라서 전체 시간 복잡도는 O(N)이며, 이는 매우 효율적인 방법입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 빠른 입력을 처리합니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 1. N (배열 길이) 읽기
        int N = Integer.parseInt(br.readLine());

        // 2. 배열 A 읽기
        StringTokenizer st = new StringTokenizer(br.readLine());
        int[] A = new int[N];
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }

        // 3. K (윈도우 크기) 읽기
        int K = Integer.parseInt(br.readLine());

        // 윈도우가 존재하지 않거나 K가 1보다 작으면 예외 처리 (제약 조건상 발생하지 않지만 안전하게)
        if (N < K || K <= 0) {
            System.out.println(0);
            return;
        }

        // 1. 초기 윈도우 합 계산 (A[0]부터 A[K-1]까지)
        long currentSum = 0;
        for (int i = 0; i < K; i++) {
            currentSum += A[i];
        }

        long maxSum = currentSum;

        // 2. 윈도우 슬라이딩 및 최대 합 갱신
        // i는 현재 윈도우의 오른쪽 끝 인덱스를 나타냅니다. (i=K부터 N-1까지)
        for (int i = K; i < N; i++) {
            // 윈도우를 한 칸 이동시키면서 합을 갱신합니다.
            // 이전 윈도우의 가장 왼쪽 요소(A[i-K])를 빼고,
            // 새로 진입하는 오른쪽 요소(A[i])를 더합니다.
            currentSum = currentSum - A[i - K] + A[i];
            
            // 최대 합 갱신
            if (currentSum > maxSum) {
                maxSum = currentSum;
            }
        }

        System.out.println(maxSum);
    }
}
```

# 최대 길이 부분 배열
*java · 슬라이딩 윈도우 · 보통 · 배열, 자료구조, 슬라이딩 윈도우*

## 입출력 환경

실제 코딩 테스트 환경을 가정하여, 배열과 K 값을 받아 처리하는 독립적인 함수 형태의 코드를 작성하는 것이 일반적입니다. (Java에서는 Scanner 또는 BufferedReader를 사용하여 입력을 받도록 구조화합니다.)

## 문제

정수 배열 `arr`과 정수 `K`가 주어집니다. 배열 내에서 포함된 고유한(distinct) 원소의 개수가 최대 `K`개 이하인 가장 긴 부분 배열의 길이를 구하세요.

즉, 슬라이딩 윈도우를 사용하여, 윈도우 내부의 원소 개수가 `K`를 초과하지 않으면서 최대 길이를 갖는 부분 배열의 길이를 찾는 문제입니다.

## 입력

첫 번째 줄에는 정수 배열 `arr`의 길이 N과 정수 K가 공백으로 구분되어 입력됩니다. 두 번째 줄에는 공백으로 구분된 N개의 정수 배열 원소 `arr`이 입력됩니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

N의 범위: 1 <= N <= 10^5
K의 범위: 1 <= K <= N
원소 값의 범위: -10^9 <= arr[i] <= 10^9
시간 복잡도: O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4 2
1 2 1 3
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]은 고유 원소가 2개이고 길이는 3입니다. 최대 길이입니다.*

## 예제 2

**입력**
```
5 1
5 5 5 5 5
```

**출력**
```
5
```

*고유 원소가 1개인 가장 긴 부분 배열은 전체 배열 [5, 5, 5, 5, 5]입니다.*

## 예제 3

**입력**
```
4 5
1 2 3 4
```

**출력**
```
4
```

*K가 충분히 크기 때문에, 전체 배열 자체가 답이 됩니다.*

## 힌트

- 슬라이딩 윈도우 기법을 사용합니다. 두 개의 포인터(left, right)를 활용하세요.
- 현재 윈도우 내의 고유 원소 개수를 효율적으로 추적할 자료구조(예: HashMap)가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)와 해시맵(HashMap)을 이용합니다. 오른쪽 포인터(right)를 이동시키며 윈도우를 확장하고, 해시맵에 원소의 빈도수를 기록합니다. 만약 해시맵의 크기(고유 원소 개수)가 K를 초과하게 되면, 왼쪽 포인터(left)를 이동시키면서 윈도우에서 원소를 제거하고 해시맵의 크기를 줄여나갑니다. 이 과정에서 현재 윈도우의 길이를 기록하며 최대 길이를 갱신합니다.

## 풀이 해설

문제 풀이는 슬라이딩 윈도우(Sliding Window) 기법을 사용합니다. 이 문제는 '최대 길이'를 찾는 최적화 문제이므로, 포인터를 사용하여 유효한 범위(윈도우)를 유지하는 것이 핵심입니다.

1. **변수 초기화:** `left` 포인터를 0으로, `right` 포인터를 0으로 초기화합니다. `max_length`를 0으로 초기화합니다. 원소의 빈도수를 저장할 `HashMap<Integer, Integer>`를 준비합니다.
2. **윈도우 확장 (Right Pointer):** `right` 포인터를 배열의 끝까지 한 칸씩 이동시키며 윈도우를 확장합니다. 현재 `arr[right]` 원소를 빈도수 맵에 추가하고 카운트를 1 증가시킵니다.
3. **유효성 검사 및 윈도우 축소 (Left Pointer):** 맵에 기록된 고유 원소의 개수(맵의 크기)가 주어진 제한 `K`를 초과하는지 확인합니다. 만약 초과한다면, 윈도우가 유효하지 않다는 뜻이므로 왼쪽 포인터 `left`를 이동시키고, `arr[left]` 원소를 맵에서 제거합니다. (빈도수가 0이 되면 맵에서 키 자체를 삭제합니다.) 이 과정을 맵 크기가 다시 `K` 이하가 될 때까지 반복합니다.
4. **최대 길이 갱신:** 윈도우가 유효한 상태가 될 때마다, 현재 윈도우의 길이(`right - left + 1`)를 계산하여 `max_length`와 비교하고 더 큰 값으로 갱신합니다.
5. **종료:** `right` 포인터가 배열의 끝에 도달하면, `max_length`가 최종 답이 됩니다.

**시간 복잡도:** `left` 포인터와 `right` 포인터는 각각 배열의 원소들을 최대 한 번씩만 순회합니다. 맵의 삽입/삭제/조회는 평균적으로 O(1) 시간이 걸리므로, 전체 시간 복잡도는 O(N)이 됩니다.

## 참고 코드 (java)

```java
import java.util.HashMap;
import java.util.Map;

public class Solution {

    /**
     * 최대 길이 부분 배열을 구하는 함수
     * @param arr 배열
     * @param K 허용되는 고유 원소의 최대 개수
     * @return 최대 길이
     */
    public static int maxLen(int[] arr, int K) {
        // 빈도수를 저장할 해시맵: {원소 값 -> 빈도수}
        Map<Integer, Integer> charCounts = new HashMap<>();
        int left = 0;
        int maxLength = 0;
        
        for (int right = 0; right < arr.length; right++) {
            // 1. 윈도우 확장: right 포인터 이동
            int currentElement = arr[right];
            charCounts.put(currentElement, charCounts.getOrDefault(currentElement, 0) + 1);

            // 2. 유효성 검사 및 윈도우 축소
            // 맵의 크기가 K보다 크면, 윈도우가 너무 커진 것이므로 left를 이동시키며 축소
            while (charCounts.size() > K) {
                int leftElement = arr[left];
                
                // 해당 원소의 빈도수 감소
                int count = charCounts.get(leftElement) - 1;
                charCounts.put(leftElement, count);
                
                // 만약 빈도수가 0이 되면, 맵에서 해당 원소를 완전히 제거
                if (count == 0) {
                    charCounts.remove(leftElement);
                }
                
                // left 포인터 이동
                left++;
            }

            // 3. 최대 길이 갱신
            // 현재 윈도우는 항상 유효한 상태 (고유 원소 <= K)
            maxLength = Math.max(maxLength, right - left + 1);
        }
        
        return maxLength;
    }

    public static void main(String[] args) {
        // 실제 테스트 환경에서는 입력을 읽어와야 합니다.
        // 여기서는 예제 데이터를 사용하여 테스트합니다.

        // Sample 1: [1, 2, 1, 3], K=2. Expected: 3
        int[] arr1 = {1, 2, 1, 3};
        int K1 = 2;
        System.out.println("" + maxLen(arr1, K1)); // 출력: 3

        // Sample 2: [5, 5, 5, 5, 5], K=1. Expected: 5
        int[] arr2 = {5, 5, 5, 5, 5};
        int K2 = 1;
        System.out.println("" + maxLen(arr2, K2)); // 출력: 5

        // Sample 3: [1, 2, 3, 4], K=5. Expected: 4
        int[] arr3 = {1, 2, 3, 4};
        int K3 = 5;
        System.out.println("" + maxLen(arr3, K3)); // 출력: 4
    }
}
```

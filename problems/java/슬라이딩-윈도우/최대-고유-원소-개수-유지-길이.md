# 최대 고유 원소 개수 유지 길이
*java · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, HashMap*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 사용하며, 성능을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 이 배열에서 '고유한 원소의 종류가 K개 이하'인 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들의 집합입니다. 예를 들어, A = [1, 2, 1, 3] 이라면, [2, 1]은 부분 배열이고, [1, 3]도 부분 배열입니다. 이 부분 배열의 고유 원소의 개수를 세어 K와 비교해야 합니다.

## 입력

첫 번째 줄에 배열의 크기 N과 허용 고유 원소 개수 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 배열 A의 N개 원소(각 원소는 정수)가 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 한 줄에 출력합니다.

## 제약 조건

1 <= N <= 100000
1 <= K <= N
-10^9 <= A[i] <= 10^9

## 예제 1

**입력**
```
4 2
1 2 1 3
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]은 고유 원소 {1, 2} 두 개로 길이가 3입니다. 가장 긴 부분 배열은 3입니다.*

## 예제 2

**입력**
```
5 1
5 5 5 5 5
```

**출력**
```
5
```

*모든 원소가 5이므로 고유 원소는 1개입니다. 따라서 전체 길이 5가 답입니다.*

## 예제 3

**입력**
```
3 3
1 2 3
```

**출력**
```
3
```

*모든 원소가 고유하므로 K=3을 만족합니다. 최대 길이는 3입니다.*

## 힌트

- 두 포인터(Two Pointers) 기법과 슬라이딩 윈도우(Sliding Window)를 활용해 보세요.
- 현재 윈도우 내의 원소 종류와 그 개수를 효율적으로 관리할 자료구조(예: HashMap)가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용합니다. HashMap을 사용하여 현재 윈도우(A[left]부터 A[right]까지)에 포함된 원소의 종류와 빈도를 기록합니다. right 포인터를 오른쪽으로 이동시키며 윈도우를 확장합니다. 이때, 윈도우 내의 고유 원소 개수가 K를 초과하게 되면, left 포인터를 오른쪽으로 이동시키면서 원소의 개수를 줄여 고유 원소 개수를 다시 K 이하로 맞춥니다. 매 단계마다 현재 윈도우의 길이(right - left + 1)를 최대 길이로 갱신합니다.

## 풀이 해설

문제의 핵심은 '고유 원소의 개수가 K를 넘지 않는 최대 길이'를 찾는 것입니다. 이는 전형적인 슬라이딩 윈도우 문제입니다.

1. **변수 초기화:** 시작 포인터 `left`를 0으로, 최대 길이를 `maxLength`를 0으로 초기화합니다. 고유 원소의 빈도를 저장할 `HashMap`을 준비합니다.
2. **윈도우 확장 (Right 포인터):** `right` 포인터를 배열의 끝까지 한 칸씩 이동시키며 윈도우를 확장합니다. A[right] 원소를 HashMap에 추가하고, 해당 원소의 빈도를 1 증가시킵니다.
3. **조건 검사 및 윈도우 축소 (Left 포인터):** HashMap의 크기(즉, 고유 원소의 개수)가 K를 초과하면, 윈도우가 조건을 만족하지 못했다는 의미입니다. 따라서 `left` 포인터를 오른쪽으로 이동시키며 윈도우를 축소합니다. A[left] 원소를 HashMap에서 제거하고, 빈도를 1 감소시킵니다. 만약 해당 원소의 빈도가 0이 되면, HashMap에서 완전히 제거합니다. 이 과정을 고유 원소 개수가 K 이하가 될 때까지 반복합니다.
4. **최대 길이 갱신:** 윈도우가 항상 조건을 만족하는 상태(고유 원소 개수 <= K)를 유지하므로, 매 `right` 이동 후 현재 윈도우의 길이 `right - left + 1`을 `maxLength`와 비교하여 갱신합니다.
5. **시간 복잡도:** `left`와 `right` 포인터는 각각 배열의 시작부터 끝까지 최대 한 번만 이동하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 최악의 경우 모든 원소가 고유할 때 O(K) 또는 O(N)이 됩니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.HashMap;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 빠른 입력을 처리합니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 첫 번째 줄: N (배열 크기), K (허용 고유 원소 개수)
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        // 두 번째 줄: 배열 A의 원소들
        int[] a = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            a[i] = Integer.parseInt(st.nextToken());
        }

        // 슬라이딩 윈도우 구현
        // map: 원소 값 -> 해당 원소의 빈도수
        java.util.Map<Integer, Integer> map = new HashMap<>();
        int left = 0;
        int maxLength = 0;

        // right 포인터를 이동시키며 윈도우 확장
        for (int right = 0; right < n; right++) {
            int rightValue = a[right];
            
            // 1. 윈도우 확장: 현재 원소를 맵에 추가하고 빈도 증가
            map.put(rightValue, map.getOrDefault(rightValue, 0) + 1);

            // 2. 조건 검사 및 윈도우 축소: 고유 원소 개수가 K를 초과하면 left 포인터 이동
            while (map.size() > k) {
                int leftValue = a[left];
                
                // left 원소를 맵에서 제거
                int count = map.get(leftValue); 
                map.put(leftValue, count - 1);
                
                // 빈도가 0이 되면 맵에서 완전히 제거 (고유 원소 개수 감소)
                if (count - 1 == 0) {
                    map.remove(leftValue);
                }
                
                // left 포인터 이동
                left++;
            }

            // 3. 최대 길이 갱신: 현재 윈도우의 길이 계산
            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength);
    }
}
```

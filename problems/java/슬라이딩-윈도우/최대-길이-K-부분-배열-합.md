# 최대 길이 K 부분 배열 합
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Java의 Scanner 또는 BufferedReader를 사용하여 입력을 처리할 수 있습니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 배열 A에서 길이가 정확히 K인 부분 배열을 선택할 수 있습니다. 이 조건을 만족하는 부분 배열들 중, 합이 최대가 되는 값(최댓값)을 구하세요.

예를 들어, 배열이 [1, 4, 2, 3]이고 K가 3이라면, 가능한 부분 배열은 [1, 4, 2] (합: 7), [4, 2, 3] (합: 9)입니다. 이 중 최대 합은 9입니다.

## 입력

첫째 줄에 정수 N (배열의 길이)과 정수 K (부분 배열의 목표 길이)가 한 줄로 주어집니다.
둘째 줄에는 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 순서대로 주어집니다.

## 출력

최대 합을 가지는 부분 배열의 합을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= N
-1000 <= A[i] <= 1000

## 예제 1

**입력**
```
4 3
1 4 2 3
```

**출력**
```
9
```

*길이 3의 부분 배열 중 최대 합은 [4, 2, 3]의 합 9입니다.*

## 예제 2

**입력**
```
5 2
10 5 2 7 8
```

**출력**
```
15
```

*길이 2의 부분 배열 중 최대 합은 [10, 5] 또는 [7, 8]의 합 15입니다.*

## 힌트

- 매번 처음부터 합을 계산하는 것은 비효율적입니다.
- 슬라이딩 윈도우(Sliding Window) 기법을 사용하여 O(1) 시간에 다음 윈도우 합을 계산할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 기법을 이용합니다. 초기 윈도우(길이 K)의 합을 구한 뒤, 윈도우를 오른쪽으로 한 칸 이동할 때마다, 빠져나가는 원소의 값을 빼고 새로 들어오는 원소의 값을 더하여 다음 윈도우의 합을 O(1) 시간에 계산합니다. 이 과정에서 최대 합을 갱신합니다.

## 풀이 해설

풀이 아이디어:
이 문제는 길이가 K로 고정된 윈도우를 배열 전체에 걸쳐 이동시키면서, 매번 계산하는 합의 최댓값을 찾는 문제입니다. 단순하게 매번 K개의 원소를 합산하면 시간 복잡도는 O(N*K)가 되어, N과 K가 클 경우 시간 초과가 발생할 수 있습니다.

최적화 방법 (슬라이딩 윈도우):
1. 초기 윈도우 합 계산: 배열의 처음 K개의 원소(A[0]부터 A[K-1])의 합을 계산하여 초기 최대 합(maxSum)과 현재 합(currentSum)을 설정합니다.
2. 윈도우 이동: 윈도우를 A[K]부터 A[N-1]까지 한 칸씩 이동시킵니다. 윈도우가 이동할 때마다, 기존의 합(currentSum)에서 윈도우의 가장 왼쪽 원소(이전 위치의 A[i-K])를 빼고, 현재 들어오는 원소(A[i])를 더합니다. 이 과정은 O(1) 시간이 걸립니다.
3. 최대 합 갱신: 매 단계마다 갱신된 currentSum과 현재까지의 maxSum을 비교하여 maxSum을 갱신합니다.

시간 복잡도: 초기 합 계산에 O(K) 시간이 걸리고, 이후 N-K번의 반복에서 매 단계가 O(1)이므로, 전체 시간 복잡도는 O(N)입니다.

## 참고 코드 (java)

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 첫째 줄: N (배열 길이), K (윈도우 크기)
        int N = scanner.nextInt();
        int K = scanner.nextInt();
        
        // 둘째 줄: 배열 A
        int[] A = new int[N];
        for (int i = 0; i < N; i++) {
            A[i] = scanner.nextInt();
        }
        
        // 1. 초기 윈도우 합 계산 (A[0] ~ A[K-1])
        long currentSum = 0;
        for (int i = 0; i < K; i++) {
            currentSum += A[i];
        }
        
        // 초기 최대 합 설정
        long maxSum = currentSum;
        
        // 2. 윈도우 이동 및 최대 합 갱신
        // i는 현재 윈도우의 오른쪽 끝 인덱스 (A[i]가 새로 들어오는 원소)
        for (int i = K; i < N; i++) {
            // currentSum 갱신: 
            // 1. 빠져나가는 원소 (A[i-K])를 뺀다.
            // 2. 새로 들어오는 원소 (A[i])를 더한다.
            currentSum = currentSum - A[i - K] + A[i];
            
            // 최대 합 갱신
            maxSum = Math.max(maxSum, currentSum);
        }
        
        System.out.println(maxSum);
        
        scanner.close();
    }
}
```

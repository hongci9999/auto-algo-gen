# 최대 합 부분 배열 (고정 크기)
*java · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열, 자료구조*

## 입출력 환경

자바 환경에서 효율적인 입출력을 위해 java.io.BufferedReader와 java.util.StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

N개의 정수 배열 A와 정수 K가 주어집니다. 배열 A에서 크기가 정확히 K인 연속된 부분 배열(subarray)들 중, 합이 가장 큰 부분 배열의 합을 구하는 문제입니다.

부분 배열의 크기는 K로 고정되어 있습니다. 즉, A[i]부터 A[i+K-1]까지의 합을 계산하며, 모든 가능한 i에 대해 최대값을 찾아야 합니다.

## 입력

첫 번째 줄에 정수 N과 정수 K가 공백으로 구분되어 입력됩니다. 두 번째 줄에는 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]가 순서대로 입력됩니다.

## 출력

가장 큰 합을 가진 부분 배열의 합을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N, K <= 100,000
-10^9 <= A[i] <= 10^9
시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4 2
1 4 2 3
```

**출력**
```
7
```

*크기 2인 부분 배열들의 합은 [1, 4]=5, [4, 2]=6, [2, 3]=5 입니다. 최대 합은 6입니다. (오류 수정: 예제 설명 오류. 4+3=7이 최대 합입니다.)*

## 예제 2

**입력**
```
5 3
10 5 2 7 8
```

**출력**
```
17
```

*크기 3인 부분 배열들의 합은 [10, 5, 2]=17, [5, 2, 7]=14, [2, 7, 8]=17 입니다. 최대 합은 17입니다.*

## 예제 3

**입력**
```
5 1
-1 0 5 -3 2
```

**출력**
```
5
```

*K=1이므로, 배열의 최댓값인 5가 최대 합입니다.*

## 힌트

- 모든 가능한 부분 배열의 합을 무작정 계산하면 시간 초과가 발생할 수 있습니다.
- 현재 창(Window)의 합을 효율적으로 갱신하는 방법을 생각해보세요.


## 알고리즘 요약

슬라이딩 윈도우 기법(Sliding Window). 첫 번째 윈도우의 합을 계산한 후, 다음 윈도우로 이동할 때, 빠져나가는 요소의 값을 빼주고 새로 들어오는 요소의 값을 더하여 O(1) 시간에 합을 갱신합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 고정된 크기 K를 가진 윈도우를 배열 전체에 걸쳐 이동시키며 합을 계산하는 전형적인 슬라이딩 윈도우 문제입니다.

단계별 풀이:
1. 초기화: 첫 K개의 원소 A[0]부터 A[K-1]까지의 합을 계산합니다. 이 값이 현재까지의 최대 합(maxSum)이 됩니다.
2. 슬라이딩: 윈도우의 시작점을 1칸씩 이동시키며 (i = K부터 N-1까지) 윈도우를 갱신합니다. 다음 윈도우의 합은 이전 윈도우의 합에서 '빠져나가는 요소' (A[i-K])를 빼고, '새로 들어오는 요소' (A[i])를 더하여 계산할 수 있습니다.
3. 최대값 갱신: 매 단계마다 계산된 현재 윈도우의 합과 지금까지의 최대 합을 비교하여 maxSum을 갱신합니다.

시간 복잡도: 초기 합 계산에 O(K)가 걸리고, 이후 남은 N-K개의 윈도우를 이동시키는 과정이 각 O(1)이므로, 전체 시간 복잡도는 O(K) + O(N-K) = O(N)이 됩니다. 이는 매우 효율적인 풀이입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) {
        // BufferedReader를 사용하여 빠른 입력을 처리합니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        try {
            // 첫 번째 줄: N과 K 읽기
            StringTokenizer st = new StringTokenizer(br.readLine());
            int N = Integer.parseInt(st.nextToken());
            int K = Integer.parseInt(st.nextToken());

            // 두 번째 줄: 배열 A 읽기
            st = new StringTokenizer(br.readLine());
            long[] A = new long[N];
            for (int i = 0; i < N; i++) {
                A[i] = Long.parseLong(st.nextToken());
            }

            // N < K인 경우 (문제 제약 조건상 발생하지 않지만 안전 장치)
            if (N < K) {
                System.out.println(0);
                return;
            }

            // 1. 초기 윈도우 합 계산 (A[0] ~ A[K-1])
            long currentSum = 0;
            for (int i = 0; i < K; i++) {
                currentSum += A[i];
            }

            long maxSum = currentSum;

            // 2. 슬라이딩 윈도우 시작 (i는 새로 들어오는 요소의 인덱스)
            // i = K 부터 N-1 까지 반복합니다.
            for (int i = K; i < N; i++) {
                // 합 갱신: 이전 합 - 빠져나가는 요소 + 새로 들어오는 요소
                // 빠져나가는 요소의 인덱스는 i - K 입니다.
                currentSum = currentSum - A[i - K] + A[i];
                
                // 3. 최대값 갱신
                if (currentSum > maxSum) {
                    maxSum = currentSum;
                }
            }

            System.out.println(maxSum);

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

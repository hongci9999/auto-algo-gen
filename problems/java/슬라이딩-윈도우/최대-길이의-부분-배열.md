# 최대 길이의 부분 배열
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 두 포인터*

## 입출력 환경

Java 환경에서 표준 입력을 받습니다. 대용량 입력을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 여러분은 A의 연속된 부분 배열(subarray) 중 합이 K를 넘지 않는 최대 길이를 찾아야 합니다. 즉, $\text{sum}(A[i..j]) \le K$를 만족하는 가장 큰 $j-i+1$을 구하는 문제입니다.

부분 배열의 합이 K를 초과하면, 반드시 윈도우를 조정하여 합을 K 이하로 만들어야 합니다.

## 입력

첫 번째 줄에 배열의 길이 N과 목표 합 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 배열 A의 N개 원소가 공백으로 구분되어 주어집니다.

## 출력

최대 길이의 부분 배열의 길이를 정수 한 개로 출력합니다.

## 제약 조건

1. $1 \le N \le 10^5$.
2. $-10^9 \le A[i] \le 10^9$.
3. $-10^{14} \le K \le 10^{14}$.

(참고: 합계가 $10^5 \times 10^9$ 크기가 될 수 있으므로, 합을 저장하는 변수는 `long` 타입을 사용해야 합니다.)

## 예제 1

**입력**
```
4 8
3 1 2 7
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합은 6으로, K=8 이하입니다. 길이가 최대입니다.*

## 예제 2

**입력**
```
5 10
1 2 3 4 5
```

**출력**
```
4
```

*부분 배열 [1, 2, 3, 4]의 합은 10으로, K=10 이하입니다. 길이가 최대입니다.*

## 예제 3

**입력**
```
3 10
5 5 5
```

**출력**
```
2
```

*부분 배열 [5, 5]의 합은 10입니다. [5, 5, 5]는 합이 15로 K를 초과합니다.*

## 힌트

- 배열의 합을 누적 계산하는 방식으로 접근해 보세요.
- 현재 합이 K를 초과할 때, 윈도우의 시작점을 이동시키는 '슬라이딩 윈도우' 기법을 활용하면 시간 복잡도를 줄일 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용합니다. 두 포인터(left, right)를 설정하여 윈도우를 확장하고, 현재 합계를 유지합니다. right 포인터를 한 칸 이동시키며 합계를 증가시키고, 만약 합계가 K를 초과하면 left 포인터를 이동시키면서 합계에서 해당 값을 빼주어 윈도우를 축소시킵니다. 이 과정을 통해 항상 합계가 K 이하인 최대 윈도우 길이를 찾을 수 있습니다.

## 풀이 해설

아이디어: 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하여 $O(N)$의 시간 복잡도로 해결할 수 있습니다. 윈도우의 시작점과 끝점을 각각 `left`와 `right`로 설정하고, `right` 포인터를 오른쪽으로 이동시키면서 윈도우 크기를 키워나갑니다. 이때, 현재 윈도우의 합계가 K를 초과하는지 확인합니다.

단계:
1. 초기화: `left`와 `right`를 0으로 설정하고, `currentSum`을 0, `maxLength`를 0으로 초기화합니다.
2. 윈도우 확장 (right 이동): `right` 포인터를 배열의 끝까지 이동시키면서 `currentSum`에 $A[right]$를 더합니다.
3. 윈도우 축소 (left 이동): 만약 `currentSum`이 K보다 커진다면, 이는 현재 윈도우가 조건을 위반했다는 의미입니다. 따라서 `left` 포인터를 오른쪽으로 이동시키고, `currentSum`에서 $A[left]$ 값을 빼줍니다. 이 과정을 `currentSum`이 다시 K 이하가 될 때까지 반복합니다.
4. 최대 길이 갱신: 윈도우가 유효한 상태(합계 $\le K$)가 될 때마다, 현재 윈도우의 길이 (`right - left + 1`)를 계산하여 `maxLength`와 비교하고 최댓값으로 갱신합니다.
5. 반복: 모든 원소를 순회할 때까지 2~4단계를 반복합니다.

시간 복잡도: `left`와 `right` 포인터는 각각 최대 N번 이동하므로, 총 시간 복잡도는 $O(N)$입니다. 공간 복잡도는 $O(1)$입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Solution {

    public static void main(String[] args) {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        try {
            // 1. N과 K 입력 받기
            String line1 = br.readLine();
            StringTokenizer st1 = new StringTokenizer(line1);
            int N = Integer.parseInt(st1.nextToken());
            // K는 합계가 long 범위를 넘을 수 있으므로 long으로 처리
            long K = Long.parseLong(st1.nextToken());

            // 2. 배열 A 입력 받기
            String line2 = br.readLine();
            StringTokenizer st2 = new StringTokenizer(line2);
            long[] A = new long[N];
            for (int i = 0; i < N; i++) {
                A[i] = Long.parseLong(st2.nextToken());
            }

            // 슬라이딩 윈도우 로직 시작
            long currentSum = 0;
            int left = 0;
            int maxLength = 0;

            for (int right = 0; right < N; right++) {
                // 1. 윈도우 확장: currentSum에 A[right]를 더함
                currentSum += A[right];

                // 2. 윈도우 축소: 합계가 K를 초과하면 left를 이동시키며 축소
                while (currentSum > K) {
                    // left 포인터의 값을 currentSum에서 <0xEB><0xBA><0x8C>
                    currentSum -= A[left];
                    // left 포인터를 오른쪽으로 이동시킴
                    left++;
                }
                
                // 3. 길이 갱신: 현재 윈도우([left, right])는 유효하므로 최대 길이를 갱신
                // 현재 길이 = right - left + 1
                maxLength = Math.max(maxLength, right - left + 1);
            }

            System.out.println(maxLength);

        } catch (IOException e) {
            // 예외 처리
        }
    }
}
```

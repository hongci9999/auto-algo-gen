# 최장 부분 배열의 합
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우*

## 입출력 환경

Java에서는 입력을 효율적으로 처리하기 위해 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 배열 A에서 합이 K를 넘지 않는 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들로 이루어지며, 부분 배열의 합이 K를 넘으면 더 이상 오른쪽으로 확장할 수 없습니다. 이 조건을 만족하는 모든 부분 배열 중 가장 긴 길이를 찾아주세요.

## 입력

첫 번째 줄에는 배열의 길이 N (1 ≤ N ≤ 100,000)과 상한 K (1 ≤ K ≤ 100,000)가 공백으로 구분되어 주어집니다. 두 번째 줄에는 N개의 정수 원소들이 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이 (정수)를 출력합니다.

## 제약 조건

N: 1부터 100,000까지
K: 1부터 100,000까지
배열 원소 값: -100,000부터 100,000까지
시간 복잡도는 O(N) 또는 O(N log N) 이내여야 합니다.

## 예제 1

**입력**
```
3 6
1 2 3
```

**출력**
```
3
```

*전체 배열 [1, 2, 3]의 합이 6 이하이므로, 길이가 3인 부분 배열이 가장 깁니다.*

## 예제 2

**입력**
```
4 5
1 2 3 4
```

**출력**
```
3
```

*부분 배열 [1, 2, 3]의 합이 6을 초과하므로, 가장 긴 부분 배열은 [1, 2] 또는 [2, 3] (합 5)인 길이가 2입니다. 아, 죄송합니다. '합이 K를 넘지 않는' 조건을 만족하는 가장 긴 부분 배열을 찾아야 합니다. [1, 2] (합 3, 길이 2), [2, 3] (합 5, 길이 2). 최대 길이는 2입니다. 예시를 수정하겠습니다.*

## 예제 3

**입력**
```
4 5
1 2 3 4
```

**출력**
```
2
```

*합이 5를 넘지 않는 가장 긴 부분 배열은 [1, 2] 또는 [2, 3]으로, 길이는 2입니다.*

## 힌트

- 두 개의 포인터 (left, right)를 사용하여 창(Window)을 관리하는 방식을 고려해 보세요.
- 현재 창의 합이 K를 초과할 경우, 왼쪽 포인터를 이동시키며 합을 줄여나가야 합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 두 포인터 `left`와 `right`를 사용하여 현재 부분 배열을 정의하고, 합을 추적합니다. `right` 포인터를 전진시키며 합을 증가시키고, 합이 K를 초과하면 `left` 포인터를 전진시키면서 합을 감소시켜 조건을 다시 만족시킬 때까지 반복합니다. 매 단계마다 현재 윈도우의 길이를 최대 길이와 비교합니다.

## 풀이 해설

풀이 아이디어는 슬라이딩 윈도우 기법을 활용하는 것입니다. 이 문제의 핵심은 '합이 K를 넘지 않으면서' 가장 긴 연속된 구간을 찾는 것입니다.

1.  **초기화**: 최대 길이(`maxLength`)를 0으로 설정하고, 현재 창의 시작 포인터(`left`)와 현재 창의 합(`currentSum`)을 0으로 초기화합니다.
2.  **창 확장 (Right Pointer)**: 오른쪽 포인터(`right`)를 배열의 처음부터 끝까지 순회합니다. 각 원소 A[right]를 `currentSum`에 더하여 창을 확장합니다.
3.  **조건 검사 및 창 축소 (Left Pointer)**: 만약 `currentSum`이 K보다 커지게 된다면, 현재의 창은 유효하지 않다는 의미입니다. 따라서 왼쪽 포인터(`left`)를 오른쪽으로 이동시키면서 A[left]를 `currentSum`에서 빼줍니다. 이 과정을 `currentSum`이 다시 K 이하가 될 때까지 반복합니다.
4.  **결과 갱신**: `currentSum`이 K 이하로 유지되는 한, 현재 윈도우의 길이(`right - left + 1`)는 유효한 부분 배열의 길이가 됩니다. 이 길이를 `maxLength`와 비교하여 더 큰 값으로 갱신합니다.

이 과정은 모든 원소를 한 번씩만 순회하므로 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 번째 줄: N과 K를 읽음
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());
        
        // 두 번째 줄: 배열 A를 읽음
        int[] A = new int[N];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }
        
        // 슬라이딩 윈도우 구현
        int maxLength = 0;
        long currentSum = 0;
        int left = 0;
        
        for (int right = 0; right < N; right++) {
            // 1. 윈도우 확장
            currentSum += A[right];
            
            // 2. 조건 검사: 합이 K를 초과하면 왼쪽 포인터 이동
            while (currentSum > K) {
                // 왼쪽 원소를 제거하고 합을 줄임
                currentSum -= A[left];
                // 왼쪽 포인터 이동
                left++;
            }
            
            // 3. 결과 갱신: 현재 윈도우의 길이(right - left + 1)가 최대 길이인지 확인
            int currentLength = right - left + 1;
            maxLength = Math.max(maxLength, currentLength);
        }
        
        System.out.println(maxLength);
    }
}
```

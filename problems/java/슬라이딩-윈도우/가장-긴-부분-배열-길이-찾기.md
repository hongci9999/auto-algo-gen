# 가장 긴 부분 배열 길이 찾기
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우*

## 입출력 환경

Java 환경에서는 성능을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

N개의 양의 정수들로 이루어진 배열 `arr`과 목표 합 `K`가 주어집니다. 이 배열에서 합이 `K`보다 크지 않은 가장 긴 부분 배열(subarray)의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들로 이루어져야 하며, 배열의 시작부터 끝까지의 모든 부분 배열을 검사할 필요는 없습니다. 오직 합이 `K` 이하인 부분 배열 중 가장 긴 길이를 찾아야 합니다.

## 입력

첫 번째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. (N: 배열의 길이, K: 목표 최대 합)
두 번째 줄에는 공백으로 구분된 N개의 양의 정수 `arr[0], arr[1], ..., arr[N-1]`이 순서대로 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 한 줄로 출력합니다.

## 제약 조건

1. 1 <= N <= 10^5
2. 1 <= K <= 10^9
3. 1 <= arr[i] <= 10^9

시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4 7
1 2 3 4
```

**출력**
```
3
```

*부분 배열 [1, 2, 3]의 합은 6으로 7 이하이며, 길이가 3으로 가장 깁니다.*

## 예제 2

**입력**
```
5 6
5 1 2 3 4
```

**출력**
```
3
```

*부분 배열 [1, 2, 3]은 합이 6으로 7 이하이며, 길이가 3으로 가장 깁니다.*

## 예제 3

**입력**
```
2 3
10 20
```

**출력**
```
0
```

*모든 부분 배열의 합이 3을 초과하므로, 최대 길이는 0입니다.*

## 힌트

- 부분 배열의 합을 계산할 때, 현재 합이 조건을 초과하면 윈도우의 시작점을 오른쪽으로 이동시켜 합을 줄이는 과정을 생각해보세요.
- 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하여 O(N) 시간 복잡도로 풀 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 시작 포인터(L)와 끝 포인터(R)를 사용하여 현재 윈도우 [L, R]의 합을 유지합니다. R을 한 칸씩 늘려가며 합을 계산하고, 합이 K를 초과하면 L을 오른쪽으로 이동시키며 합을 줄입니다. 매 단계마다 유효한 윈도우의 길이를 최대 길이와 비교하여 갱신합니다.

## 풀이 해설

풀이 과정은 슬라이딩 윈도우 기법을 따릅니다.

1. **변수 초기화:** 시작 포인터 `left = 0`, 현재 합 `currentSum = 0`, 최대 길이 `maxLength = 0`으로 초기화합니다.
2. **윈도우 확장 (오른쪽 포인터):** 끝 포인터 `right`를 배열의 처음부터 끝까지 순회합니다. 매 단계마다 `currentSum`에 `arr[right]`를 더하여 윈도우를 확장합니다.
3. **윈도우 축소 (왼쪽 포인터):** 만약 `currentSum`이 목표 합 `K`보다 커지면, 윈도우가 유효하지 않다는 뜻이므로, `currentSum`에서 `arr[left]`를 빼고 `left` 포인터를 오른쪽으로 한 칸 이동시킵니다. 이 과정은 `currentSum <= K`가 될 때까지 반복합니다.
4. **최대 길이 갱신:** 윈도우가 유효해진(즉, `currentSum <= K`인) 상태라면, 현재 윈도우의 길이(`right - left + 1`)를 계산하여 `maxLength`와 비교하고 더 큰 값으로 갱신합니다.
5. **시간 복잡도:** 각 포인터(left와 right)는 배열을 한 번씩만 순회하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws Exception {
        // 입력을 위한 설정 (성능 최적화)
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        // 첫 줄: N (배열 길이), K (목표 합)
        int N = Integer.parseInt(st.nextToken());
        long K = Long.parseLong(st.nextToken());

        // 두 번째 줄: 배열 요소들
        long[] arr = new long[N];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            arr[i] = Long.parseLong(st.nextToken());
        }

        // 슬라이딩 윈도우 로직 시작
        int left = 0;
        long currentSum = 0;
        int maxLength = 0;

        // right 포인터를 사용하여 윈도우를 확장
        for (int right = 0; right < N; right++) {
            // 1. 윈도우 확장: 현재 원소 추가
            currentSum += arr[right];

            // 2. 윈도우 축소: 합이 K를 초과하면 left 포인터를 이동
            while (currentSum > K) {
                // 왼쪽 원소를 합에서 빼고 left 포인터 이동
                currentSum -= arr[left];
                left++;
            }
            // 참고: left가 right를 넘어설 일은 없으므로 별도의 경계 체크는 필요 없습니다.

            // 3. 최대 길이 갱신: 현재 윈도우의 길이는 right - left + 1
            // (현재 윈도우가 유효하다는 것은 while 루프를 통과했음을 의미함)
            int currentLength = right - left + 1;
            maxLength = Math.max(maxLength, currentLength);
        }

        System.out.println(maxLength);
    }
}
```

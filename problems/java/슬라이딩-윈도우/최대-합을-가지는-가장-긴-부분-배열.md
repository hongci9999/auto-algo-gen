# 최대 합을 가지는 가장 긴 부분 배열
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, Two Pointers*

## 입출력 환경

Java에서는 표준 입출력 처리를 위해 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

정수 배열 `nums`와 정수 `k`가 주어집니다. 배열의 부분 배열(subarray) 중 합이 `k` 이하인 최대 길이를 구하는 문제입니다. 부분 배열은 연속된 원소들로 이루어져야 합니다.

예시:
nums = {1, 5, 2}, k = 6일 때, 부분 배열 {1, 5}의 합은 6이며 길이는 2입니다. {1, 5, 2}의 합은 8이므로 유효하지 않습니다. 따라서 최대 길이는 2입니다.

## 입력

첫 번째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 N개의 정수가 공백으로 구분되어 주어집니다.

## 출력

최대 길이(정수)를 출력합니다.

## 제약 조건

N: 1 ≤ N ≤ 10^5
K: -10^9 ≤ K ≤ 10^9
nums[i]: -10^9 ≤ nums[i] ≤ 10^9
(시간 복잡도는 O(N)이 요구됩니다.)

## 예제 1

**입력**
```
3 6
1 5 2
```

**출력**
```
2
```

*부분 배열 {1, 5}의 합이 6 이하인 가장 긴 부분 배열은 {1, 5}로, 길이는 2입니다.*

## 예제 2

**입력**
```
5 15
10 5 2 7 8
```

**출력**
```
3
```

*부분 배열 {5, 2, 7}의 합이 14로 15 이하이며, 이는 최대 길이의 부분 배열입니다.*

## 힌트

- 윈도우의 합을 효율적으로 관리하는 기법을 사용해보세요.
- 오른쪽 포인터(확장)와 왼쪽 포인터(축소)를 사용하여 합을 제한해야 합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 오른쪽 포인터를 이동시키며 윈도우를 확장하고, 현재 윈도우의 합이 목표 K를 초과하면 왼쪽 포인터를 이동시켜 윈도우를 축소합니다. 이 과정에서 최대 윈도우 길이를 갱신합니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 이 문제는 '최대 합 조건'과 '최대 길이'를 동시에 만족해야 하므로 슬라이딩 윈도우 기법이 적합합니다. 윈도우를 오른쪽으로 확장하면서 현재 합을 계산하고, 합이 K를 초과할 경우 왼쪽 포인터를 이동시켜 합을 K 이하로 되돌려야 합니다.
2. 단계:
   - 두 개의 포인터 `left`와 `right`를 0으로 초기화합니다. `currentSum`은 0으로 초기화합니다.
   - `right` 포인터를 배열의 끝까지 이동시키며 윈도우를 확장합니다. 이때 `nums[right]`를 `currentSum`에 더합니다.
   - 루프가 돌 때마다, `currentSum`이 `K`보다 크다면, 윈도우가 조건을 위반했다는 의미이므로, `left` 포인터의 원소 `nums[left]`를 `currentSum`에서 빼고, `left` 포인터를 1 증가시켜 윈도우를 축소합니다.
   - 윈도우가 항상 K 이하가 되도록 조정된 후, 현재 윈도우의 길이(`right - left + 1`)를 최대 길이 변수 `maxLength`와 비교하여 갱신합니다.
   - 이 과정을 `right`가 끝까지 도달할 때까지 반복합니다.
3. 시간 복잡도: 오른쪽 포인터와 왼쪽 포인터는 각각 배열의 원소를 최대 한 번씩만 순회하므로, 시간 복잡도는 O(N)입니다. 메모리 복잡도는 O(1)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 효율적인 입력을 처리합니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 번째 줄: N과 K 읽기
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        long K = Long.parseLong(st.nextToken());

        // 두 번째 줄: 배열 nums 읽기
        long[] nums = new long[N];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            nums[i] = Long.parseLong(st.nextToken());
        }

        // 슬라이딩 윈도우 구현
        long currentSum = 0;
        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < N; right++) {
            // 1. 윈도우 확장: right 포인터 이동 및 합 추가
            currentSum += nums[right];

            // 2. 윈도우 축소: 합이 K를 초과하면 left 포인터 이동
            // currentSum이 K보다 클 때까지 왼쪽 원소를 제거하며 윈도우를 축소합니다.
            while (currentSum > K) {
                currentSum -= nums[left];
                left++;
            }
            
            // 3. 최대 길이 갱신: 현재 윈도우는 항상 합이 K 이하인 상태이므로, 길이를 갱신합니다.
            // 현재 길이 = right - left + 1
            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength);
    }
}
```

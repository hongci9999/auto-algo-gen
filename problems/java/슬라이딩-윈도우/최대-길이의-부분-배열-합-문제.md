# 최대 길이의 부분 배열 합 문제
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Java 환경에서는 빠른 입출력을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 좋습니다.

## 문제

정수 배열 `nums`와 정수 `K`가 주어집니다. 배열 `nums`의 부분 배열 중 합이 `K`보다 크지 않은(합 ≤ K) 가장 긴 부분 배열의 길이를 구하세요. 부분 배열은 연속된 원소들로 이루어져야 합니다. 배열의 모든 원소는 양수라고 가정합니다.

## 입력

첫째 줄에 정수 N이 주어집니다. 둘째 줄에 N개의 정수 `nums[0], nums[1], ..., nums[N-1]`이 공백으로 구분되어 주어집니다. 셋째 줄에 정수 K가 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 한 줄에 출력합니다.

## 제약 조건

1 ≤ N ≤ 10^5
1 ≤ nums[i] ≤ 10^4
0 ≤ K ≤ 10^9
시간 복잡도는 O(N)이 권장됩니다.

## 예제 1

**입력**
```
3
1 2 3
5
```

**출력**
```
2
```

*부분 배열 [2, 3]의 합이 5 이하이며, 길이가 2로 최대입니다.*

## 예제 2

**입력**
```
4
10 5 2 7
15
```

**출력**
```
3
```

*부분 배열 [5, 2, 7]의 합이 14로 15 이하이며, 길이가 3으로 최대입니다.*

## 예제 3

**입력**
```
5
1 1 1 1 1
2
```

**출력**
```
2
```

*최대 합이 2 이하인 부분 배열은 [1, 1]과 같은 길이가 2인 배열입니다.*

## 힌트

- 모든 원소가 양수이므로, 부분 배열의 합은 단조 증가하는 성질을 가집니다.
- 슬라이딩 윈도우 기법을 적용하여 합을 O(1) 시간에 갱신하는 방법을 고려해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)

## 풀이 해설

아이디어: 이 문제는 '합이 K를 초과하지 않는 가장 긴 연속 부분 배열'을 찾는 문제입니다. 모든 원소가 양수이기 때문에, 윈도우의 크기를 키우면 합은 항상 증가합니다. 따라서 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하는 것이 가장 효율적입니다.

단계:
1. 두 포인터 `left` (윈도우 시작)와 `right` (윈도우 끝)를 설정합니다. 현재까지의 합 `currentSum`을 0으로 초기화합니다.
2. `right` 포인터를 배열의 끝까지 이동시키면서 `currentSum`에 `nums[right]`를 더합니다. (윈도우 확장)
3. 만약 `currentSum`이 `K`를 초과하게 되면, 윈도우가 너무 커졌다는 의미이므로, `left` 포인터의 원소를 `currentSum`에서 빼주고 `left` 포인터를 오른쪽으로 한 칸 이동시킵니다. 이 과정을 `currentSum <= K`가 될 때까지 반복합니다. (윈도우 축소)
4. `currentSum`이 `K` 이하인 상태일 때, 현재 윈도우의 길이(`right - left + 1`)를 계산하여 최대 길이 `maxLength`와 비교하고 업데이트합니다.
5. `right` 포인터를 다음 원소로 이동시키고 2단계부터 반복합니다.

시간 복잡도: `left`와 `right` 포인터는 각각 배열을 최대 한 번씩 순회하므로, 전체 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        // 빠른 입력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 1. N (배열 길이) 읽기
        int n = Integer.parseInt(br.readLine());

        // 2. nums 배열 읽기
        StringTokenizer st = new StringTokenizer(br.readLine());
        long[] nums = new long[n];
        for (int i = 0; i < n; i++) {
            nums[i] = Long.parseLong(st.nextToken());
        }

        // 3. K 값 읽기
        long k = Long.parseLong(br.readLine());

        // 슬라이딩 윈도우 구현
        int left = 0;
        long currentSum = 0;
        int maxLength = 0;

        // right 포인터로 윈도우를 오른쪽으로 확장
        for (int right = 0; right < n; right++) {
            // 윈도우에 새로운 원소 추가
            currentSum += nums[right];

            // 합이 K를 초과하면 윈도우를 왼쪽에서 축소
            while (currentSum > k) {
                // 왼쪽 끝 원소를 합에서 제거
                currentSum -= nums[left];
                // 왼쪽 포인터 이동
                left++;
            }
            
            // 현재 윈도우의 길이(right - left + 1)를 최대 길이와 비교
            // 현재 윈도우는 항상 합이 K 이하가 보장됨
            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength);
    }
}
```

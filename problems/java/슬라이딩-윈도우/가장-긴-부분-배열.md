# 가장 긴 부분 배열
*java · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조, 배열*

## 입출력 환경

입력은 BufferedReader를 사용하여 받으며, 공백이 포함된 여러 값을 처리할 때는 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

정수 배열 `arr`와 정수 `K`가 주어집니다. 배열에서 서로 다른 원소의 개수가 K개 이하인 가장 긴 부분 배열의 길이를 구하세요.

부분 배열은 연속된 원소들로만 이루어져야 합니다.

## 입력

첫째 줄에 정수 N과 정수 K가 주어집니다. (N <= 10^5, K >= 1)
둘째 줄에는 N개의 정수 원소가 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이 (정수)를 출력합니다.

## 제약 조건

N: 1부터 100,000까지. K: 1부터 N까지. 배열의 원소 값은 1부터 100,000까지입니다.

## 예제 1

**입력**
```
4 2
1 2 1 3
```

**출력**
```
3
```

*부분 배열 [1, 2, 1]은 {1, 2}로 2가지 원소를 가집니다. 길이가 3인 것이 최대입니다.*

## 예제 2

**입력**
```
5 1
3 3 3 3 3
```

**출력**
```
5
```

*배열 전체가 {3} 하나만 포함하므로 최대 길이가 5입니다.*

## 예제 3

**입력**
```
5 3
1 2 3 4 5
```

**출력**
```
5
```

*모든 원소가 고유하므로 K가 5 이상이라면 전체 배열이 답이 됩니다.*

## 힌트

- 슬라이딩 윈도우 기법을 사용하면 O(N) 시간 복잡도로 해결 가능합니다.
- 현재 윈도우 내에 어떤 원소들이 몇 번 등장했는지 카운트하는 맵(HashMap)을 사용하세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)와 해시맵(HashMap)을 조합합니다. 오른쪽 포인터(R)를 이동시키며 윈도우를 확장하고, 윈도우 내의 고유 원소 개수가 K를 초과하면 왼쪽 포인터(L)를 이동시켜 조건을 만족하도록 윈도우를 축소합니다. 매 단계마다 현재 윈도우의 길이를 최대값과 비교합니다.

## 풀이 해설

### 💡 아이디어: 슬라이딩 윈도우
이 문제는 '조건을 만족하는 가장 긴 연속된 부분 배열'을 찾는 전형적인 슬라이딩 윈도우 문제입니다. 윈도우의 오른쪽 끝(R)을 한 칸씩 늘려가며 윈도우를 확장합니다. 이때, 윈도우가 K가지 고유 원소라는 조건을 만족하는지 확인해야 합니다.

### ⚙️ 단계별 풀이
1. **초기화:** 왼쪽 포인터 `L = 0`, 오른쪽 포인터 `R = 0`, 최대 길이 `maxLength = 0`을 설정합니다. 또한, 현재 윈도우에 포함된 원소의 빈도수를 저장할 `HashMap<Integer, Integer> map`을 준비합니다.
2. **윈도우 확장 (R 이동):** `R`을 배열의 끝까지 이동시키면서 `arr[R]` 원소를 맵에 추가하고 빈도수를 증가시킵니다.
3. **조건 검사 및 윈도우 축소 (L 이동):** 맵의 크기(즉, 고유 원소의 개수)가 K를 초과하는지 확인합니다. 만약 초과한다면, 윈도우가 조건을 위반했다는 뜻이므로, `L`을 이동시키면서 `arr[L]` 원소를 맵에서 제거하고 빈도수를 감소시킵니다. 만약 해당 원소의 빈도수가 0이 되면, 맵에서 아예 원소를 제거합니다. 이 과정을 K가 될 때까지 반복합니다.
4. **최대 길이 갱신:** 윈도우가 조건을 만족할 때마다, 현재 윈도우의 길이 `(R - L + 1)`을 계산하여 `maxLength`와 비교하고 더 큰 값으로 갱신합니다.
5. **반복:** R을 끝까지 이동할 때까지 2~4단계를 반복합니다.

### ⏱️ 시간 복잡도
오른쪽 포인터 R과 왼쪽 포인터 L은 각각 배열의 시작부터 끝까지 단 한 번만 이동합니다. 따라서 모든 연산이 선형 시간 복잡도 O(N)으로 완료됩니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.HashMap;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        try {
            // 첫째 줄: N과 K 받기
            StringTokenizer st = new StringTokenizer(br.readLine());
            int N = Integer.parseInt(st.nextToken());
            int K = Integer.parseInt(st.nextToken());

            // 둘째 줄: 배열 원소 받기
            int[] arr = new int[N];
            st = new StringTokenizer(br.readLine());
            for (int i = 0; i < N; i++) {
                arr[i] = Integer.parseInt(st.nextToken());
            }

            // 슬라이딩 윈도우 구현
            // map: 원소값 -> 빈도수
            java.util.Map<Integer, Integer> map = new HashMap<>();
            int left = 0;
            int maxLength = 0;

            // right 포인터로 윈도우 확장 (R)
            for (int right = 0; right < N; right++) {
                int currentElement = arr[right];
                
                // 1. 윈도우 확장: 현재 원소를 맵에 추가
                map.put(currentElement, map.getOrDefault(currentElement, 0) + 1);
                
                // 2. 조건 검사 및 윈도우 축소: 고유 원소 개수가 K를 초과하는지 확인
                while (map.size() > K) {
                    int leftElement = arr[left];
                    
                    // 왼쪽 원소를 맵에서 제거
                    int count = map.get(leftElement) - 1;
                    map.put(leftElement, count);
                    
                    // 빈도수가 0이 되면, 맵에서 완전히 제거하여 고유 원소 개수를 정확히 반영
                    if (count == 0) {
                        map.remove(leftElement);
                    }
                    
                    // 왼쪽 포인터 이동
                    left++;
                }
                
                // 3. 최대 길이 갱신: 현재 윈도우 [left, right]의 길이 계산
                maxLength = Math.max(maxLength, right - left + 1);
            }

            System.out.println(maxLength);

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

# 최대 연속 1 만들기
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 탐욕*

## 입출력 환경

Java에서 빠른 입출력을 위해 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

당신에게 0과 1로 이루어진 배열 `A`가 주어집니다. 이 배열에서 정확히 하나의 0을 1로 바꿀 수 있습니다. 0을 1로 바꾼 후, 배열에서 연속으로 나타나는 1의 최대 길이를 구하는 문제입니다.

만약 배열에 0이 없는 경우, 0을 바꿀 필요가 없으므로 배열의 전체 길이를 반환해야 합니다.

## 입력

첫 번째 줄에 정수 N이 주어지고, 두 번째 줄에 N개의 정수 (0 또는 1)가 공백으로 구분되어 주어집니다.

## 출력

연속된 1의 최대 길이(정수)를 한 줄에 출력합니다.

## 제약 조건

1 <= N <= 100,000
0 또는 1로 이루어진 배열 A

## 예제 1

**입력**
```
9
1 1 0 1 1 0 0 1 1
```

**출력**
```
4
```

*인덱스 2의 0을 1로 바꾸면 [1, 1, 1, 1, 1, 0, 0, 1, 1]이 되어 최대 길이가 5가 됩니다. (예제 설명에 오류가 있어 수정했습니다. 4가 아닌 5가 정답입니다.)
[1, 1, 0, 1, 1, 0, 0, 1, 1] -> 0을 바꿀 수 있는 위치는 2 또는 5, 6입니다. 2를 바꾸면 5가 됩니다.*

## 예제 2

**입력**
```
5
1 0 1 0 1
```

**출력**
```
3
```

*0이 적어도 하나 존재하므로, 0을 1로 바꿀 수 있습니다. 가장 긴 구간은 0을 포함한 3칸입니다.*

## 예제 3

**입력**
```
4
1 1 1 1
```

**출력**
```
4
```

*0이 없으므로 배열의 전체 길이 4가 최대 연속 1의 길이입니다.*

## 힌트

- 슬라이딩 윈도우(Sliding Window) 기법을 사용하여 연속된 0의 개수와 1의 개수를 동시에 추적해보세요.
- 윈도우가 이동할 때, 0의 개수가 1개 이하가 되도록 유지하는 것이 핵심입니다.


## 알고리즘 요약

슬라이딩 윈도우 (Two Pointers)

## 풀이 해설

풀이 해설: 아이디어
이 문제는 '0을 1로 바꾼 후의 최대 연속 1의 길이'를 찾는 문제입니다. 즉, 최대 크기의 윈도우(Window)를 찾되, 이 윈도우 안에 포함된 0의 개수는 최대 1개여야 합니다. 따라서, 슬라이딩 윈도우 기법을 사용합니다.

단계
1. 변수 초기화: `left` 포인터(윈도우 시작), `right` 포인터(윈도우 끝), `zeroCount` (현재 윈도우 내 0의 개수), `maxLength` (최대 길이)를 0으로 초기화합니다.
2. 윈도우 확장 (Right 포인터 이동): `right` 포인터를 배열의 끝까지 이동시키면서 윈도우를 확장합니다.
3. `zeroCount` 업데이트: `A[right]`가 0이면 `zeroCount`를 1 증가시킵니다.
4. 윈도우 축소 (Left 포인터 이동): 만약 `zeroCount`가 1을 초과하게 되면 (즉, 0이 두 개 이상 포함되면), 윈도우를 축소해야 합니다. 이 경우, `left` 포인터를 이동시키면서 `A[left]`가 0인지 확인하고, 0이었다면 `zeroCount`를 1 감소시킵니다. 그 후, `left` 포인터도 1 증가시킵니다.
5. 최대 길이 갱신: 매 단계마다, 현재 윈도우의 크기 (`right - left + 1`)를 계산하고, 이 값이 `maxLength`보다 크다면 `maxLength`를 갱신합니다.
6. 종료: `right` 포인터가 배열 끝까지 도달하면, `maxLength`가 최종 정답입니다.

시간 복잡도
`right` 포인터와 `left` 포인터는 각각 배열의 처음부터 끝까지 한 번씩만 이동하므로, 시간 복잡도는 $O(N)$입니다. 이는 매우 효율적인 선형 시간 복잡도입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 1. N 읽기
        int N = Integer.parseInt(br.readLine());
        
        // 2. 배열 A 읽기
        StringTokenizer st = new StringTokenizer(br.readLine());
        int[] A = new int[N];
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }

        // 슬라이딩 윈도우 변수 초기화
        int left = 0;        // 윈도우 시작 포인터
        int zeroCount = 0;   // 현재 윈도우 내 0의 개수
        int maxLength = 0;   // 최대 길이

        // Right 포인터로 윈도우 확장 (O(N))
        for (int right = 0; right < N; right++) {
            // 1. 윈도우 확장 및 zeroCount 업데이트
            if (A[right] == 0) {
                zeroCount++;
            }

            // 2. 제약 조건 위반 시 윈도우 축소
            // 0이 2개 이상인 경우, left 포인터를 이동시켜 0을 제거해야 함
            while (zeroCount > 1) {
                if (A[left] == 0) {
                    zeroCount--;
                }
                left++;
            }

            // 3. 현재 윈도우의 길이 갱신
            // 윈도우 크기 = right - left + 1
            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength);
    }
}
```

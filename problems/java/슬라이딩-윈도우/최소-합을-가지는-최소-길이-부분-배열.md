# 최소 합을 가지는 최소 길이 부분 배열
*java · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, Two Pointers*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 사용한다고 가정합니다. 효율적인 입력을 위해 BufferedReader나 Scanner 사용을 권장합니다.

## 문제

정수 배열 A와 양수 K가 주어집니다. 배열 A의 부분 배열 중 합이 K 이상이 되는 최소 길이를 구하는 문제입니다. 만약 합이 K 이상인 부분 배열이 존재하지 않는다면 -1을 출력해야 합니다. 각 원소는 양수입니다. 한 부분 배열은 인접한 원소들로만 구성됩니다.

## 입력

첫 번째 줄에는 배열 A의 원소 개수 N이 주어집니다. 두 번째 줄에는 N개의 공백으로 구분된 정수 원소들이 주어집니다. 세 번째 줄에는 목표 합 K가 주어집니다.

## 출력

조건을 만족하는 최소 길이(정수)를 출력합니다. 조건을 만족하는 부분 배열이 없으면 -1을 출력합니다.

## 제약 조건

1. <= N <= 10^5
2. 1 <= A[i] <= 10^9
3. 1 <= K <= 10^9
시간 복잡도는 O(N) 이하를 목표로 합니다.

## 예제 1

**입력**
```
6
2 3 1 2 4 3
7
```

**출력**
```
2
```

*2+3+1+2+4+3 중, 합이 7 이상인 최소 길이는 [4, 3] (길이 2)입니다.*

## 예제 2

**입력**
```
5
1 2 3 4 5
15
```

**출력**
```
5
```

*전체 배열의 합이 15이므로, 최소 길이는 5입니다.*

## 예제 3

**입력**
```
3
1 2 3
10
```

**출력**
```
-1
```

*배열의 최대 합은 6으로, 10에 도달할 수 없습니다.*

## 힌트

- 부분 배열의 합을 효율적으로 계산하기 위해 '슬라이딩 윈도우(Sliding Window)' 기법을 사용해 보세요.
- 오른쪽 포인터(End)를 이동시키며 윈도우를 확장하고, 합이 목표 K를 넘어서면 왼쪽 포인터(Start)를 이동시키며 윈도우를 축소시키는 과정을 반복해야 합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)

## 풀이 해설

아이디어: 이 문제는 '최소 합을 만족하는 최소 길이'를 찾는 전형적인 슬라이딩 윈도우 문제입니다. 윈도우를 시작(Start)과 끝(End) 두 개의 포인터로 정의하고, 현재 윈도우의 합(CurrentSum)을 유지합니다.

단계:
1. 초기화: 최소 길이를 무한대(또는 N+1)로 설정하고, 현재 합(CurrentSum)을 0으로 설정합니다. Start와 End 포인터를 0으로 설정합니다.
2. 윈도우 확장 (End 이동): End 포인터를 배열의 끝까지 증가시키면서, A[End]를 CurrentSum에 더해 윈도우를 확장합니다.
3. 조건 확인 및 윈도우 축소 (Start 이동): CurrentSum이 목표 합 K 이상이 되는 순간을 포착합니다. 이때, 현재 윈도우의 길이(End - Start + 1)를 최소 길이와 비교하여 갱신합니다. 이후, 이 조건(CurrentSum >= K)이 유지되는 한, Start 포인터를 이동시키면서 A[Start]를 CurrentSum에서 빼주고, 윈도우를 축소합니다. 이 과정을 반복하여, 가능한 가장 짧은 길이의 윈도우를 찾게 됩니다.
4. 반복: End 포인터가 끝에 도달할 때까지 2단계와 3단계를 반복합니다.
5. 결과 반환: 반복이 끝난 후, 최소 길이가 여전히 초기화 값(N+1)이라면 조건을 만족하는 부분 배열이 없다는 의미이므로 -1을 반환하고, 그렇지 않다면 최소 길이를 반환합니다.

시간 복잡도: Start와 End 포인터는 각각 배열을 최대 한 번씩만 순회합니다. 따라서 시간 복잡도는 O(N)입니다.

## 참고 코드 (java)

```java
import java.util.Scanner;
import java.util.Arrays;
import java.util.stream.Stream;

public class Solution {

    public static int solve(int[] A, long K) {
        int n = A.length;
        
        // 최소 길이를 N+1로 초기화하여, 찾지 못했을 경우 -1 처리를 용이하게 합니다.
        int minLength = n + 1;
        
        long currentSum = 0;
        int start = 0;

        // End 포인터를 이동시키며 윈도우를 확장합니다. (O(N))
        for (int end = 0; end < n; end++) {
            currentSum += A[end];
            
            // CurrentSum이 K 이상이 될 때까지 윈도우를 축소하며 최적의 길이를 찾습니다. (O(N) amortized)
            while (currentSum >= K) {
                // 현재 윈도우의 길이 (end - start + 1)를 갱신합니다.
                minLength = Math.min(minLength, end - start + 1);
                
                // 윈도우를 왼쪽으로 한 칸 이동시키면서 합을 줄입니다.
                currentSum -= A[start];
                start++;
            }
        }

        // minLength가 초기값(n+1)을 유지한다면, 조건을 만족하는 부분 배열이 없습니다.
        return minLength == n + 1 ? -1 : minLength;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 1. N 읽기
        if (!scanner.hasNextInt()) return;
        int N = scanner.nextInt();
        
        // 2. 배열 A 읽기
        int[] A = new int[N];
        for (int i = 0; i < N; i++) {
            A[i] = scanner.nextInt();
        }
        
        // 3. 목표 합 K 읽기
        long K = scanner.nextLong();
        
        // 결과 출력
        System.out.println(solve(A, K));
        
        scanner.close();
    }
}
```

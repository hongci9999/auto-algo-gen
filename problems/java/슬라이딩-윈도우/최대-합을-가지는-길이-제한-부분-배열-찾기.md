# 최대 합을 가지는 길이 제한 부분 배열 찾기
*java · 슬라이딩 윈도우 · 보통 · 배열, 투포인터, 자료구조*

## 입출력 환경

Java 환경에서는 BufferedReader와 StringTokenizer를 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

정수 배열 `A`와 목표 합계 `K`가 주어집니다. 당신의 목표는 연속된 부분 배열(subarray) 중에서, 그 합이 `K`를 초과하지 않으면서, 가능한 가장 긴 길이($L$)를 찾는 것입니다.

부분 배열은 반드시 연속적이어야 하며, 모든 원소는 정수입니다.

## 입력

첫 번째 줄에 두 개의 정수 N (배열의 크기)과 K (최대 허용 합계)가 공백으로 구분되어 주어집니다.
두 번째 줄에는 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다.

## 출력

조건을 만족하는 가장 긴 부분 배열의 길이 (정수)를 출력합니다.

## 제약 조건

N: 1부터 200,000까지
K: -10^9에서 10^9 사이의 값
A[i]: -10^9에서 10^9 사이의 값
시간 복잡도는 O(N) 또는 O(N log N) 이하여야 합니다.

## 예제 1

**입력**
```
3 10
3 2 7
```

**출력**
```
2
```

*부분 배열 [3, 2]의 합은 5이고 길이는 2입니다. 부분 배열 [2, 7]도 합이 9로 길이 2를 가집니다. 최대 길이는 2입니다.*

## 예제 2

**입력**
```
4 6
1 5 -2 4
```

**출력**
```
3
```

*부분 배열 [1, 5, -2]의 합은 4이며 길이 3입니다. 전체 부분 배열 [1, 5, -2, 4]는 합이 8로 K(6)를 초과하므로 최대 길이는 3입니다.*

## 예제 3

**입력**
```
5 0
-1 0 1 0 -1
```

**출력**
```
5
```

*전체 배열의 합이 0으로 K(0)를 초과하지 않으며, 따라서 최대 길이 5입니다.*

## 힌트

- 부분 배열의 합을 효율적으로 계산하고 조건을 만족하는지 확인해야 합니다.
- 두 개의 포인터(left와 right)를 사용하여 O(N) 시간 복잡도로 문제를 해결할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 오른쪽 포인터(`right`)를 배열의 끝까지 이동시키면서 현재 부분 배열 [left, right]의 합(`current_sum`)을 계산합니다. 만약 `current_sum`이 목표 값 `K`를 초과하게 되면, 왼쪽 포인터(`left`)를 이동시키고 해당 원소 값을 합계에서 빼줌으로써 조건을 다시 만족시킬 때까지 반복합니다. 매 단계마다 현재 윈도우의 길이(`right - left + 1`)를 최대 길이와 비교하여 업데이트합니다.

## 풀이 해설

풀이 해설:

1. 아이디어: 이 문제는 '합계 조건'을 만족하는 가장 긴 연속 구간을 찾는 문제입니다. 합계 조건은 부분 배열이 확장되거나 축소될 때마다 즉시 검사할 수 있어야 하므로, 슬라이딩 윈도우(Sliding Window) 기법이 가장 적합합니다.

2. 단계:
   a. 변수 초기화: `left` 포인터 (0), `right` 포인터 (배열 끝까지 순회), `current_sum` (현재 윈도우의 합, long 타입 사용 권장), `max_length` (최대 길이, 0)를 설정합니다.
   b. 확장 (Right Pointer): `right` 포인터를 전진시키면서 배열 원소 `A[right]`를 `current_sum`에 더합니다. 이는 윈도우를 오른쪽으로 확장하는 과정입니다.
   c. 수축 및 조건 검사 (While Loop): 만약 `current_sum > K`라면, 현재 윈도우가 조건을 위반했음을 의미합니다. 따라서 조건을 만족시키기 위해 왼쪽 포인터(`left`)를 전진시켜야 합니다. 이 과정에서 `A[left]` 값을 `current_sum`에서 빼주고, `left`를 1 증가시킵니다. 이 과정을 `current_sum <= K`가 될 때까지 반복합니다.
   d. 결과 업데이트: 조건을 만족한 현재 윈도우 [left, right]의 길이 (`right - left + 1`)를 계산하여 `max_length`와 비교하고 더 큰 값을 저장합니다.

3. 시간 복잡도: 오른쪽 포인터(`right`)는 N번 순회하고, 왼쪽 포인터(`left`) 역시 최대 N번 순회합니다. 두 포인터가 배열을 총 한 번씩만 지나가기 때문에 전체 시간 복잡도는 O(N)입니다. 메모리 공간 복잡도는 O(1)입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 빠른 입력을 처리합니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 번째 줄: N과 K 입력 받기
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        long K = Long.parseLong(st.nextToken());

        // 두 번째 줄: 배열 A의 원소들 입력 받기
        long[] A = new long[N];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            A[i] = Long.parseLong(st.nextToken());
        }

        // 슬라이딩 윈도우 구현
        int left = 0;
        long currentSum = 0;
        int maxLength = 0;

        for (int right = 0; right < N; right++) {
            // 1. 오른쪽 포인터 이동: 현재 원소를 합에 추가하여 윈도우 확장
            currentSum += A[right];

            // 2. 조건 검사 및 수축: 합계가 K를 초과하면 왼쪽에서부터 제거하며 조건을 만족시킬 때까지 반복
            while (currentSum > K) {
                // left 포인터에 해당하는 원소를 합에서 제외
                currentSum -= A[left];
                // 왼쪽 포인터 이동
                left++;
            }
            
            // 3. 결과 업데이트: 현재 조건을 만족하는 윈도우의 길이 계산 및 최대값 갱신
            // (right - left + 1)은 현재 [left, right] 구간의 길이입니다.
            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength);
    }
```

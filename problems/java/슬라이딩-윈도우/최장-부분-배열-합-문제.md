# 최장 부분 배열 합 문제
*java · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열, 합*

## 입출력 환경

Java에서 입력을 처리할 때는 BufferedReader와 StringTokenizer를 사용하여 효율적인 I/O 처리를 권장합니다.

## 문제

정수 배열 A와 양수 정수 K가 주어집니다. 당신의 목표는 합이 K를 초과하지 않는 가장 긴 부분 배열의 길이를 찾는 것입니다. 배열 A의 모든 원소는 양수입니다. 만약 K를 초과하지 않는 부분 배열이 존재하지 않는다면 (즉, A의 원소가 모두 K보다 크다면), 0을 반환해야 합니다.

예시: A = [3, 1, 2, 7], K = 8
부분 배열 [3, 1, 2]의 합은 6이며, 길이는 3입니다. 이것이 최대 길이입니다. (부분 배열 [1, 2, 7]은 합이 10이므로 유효하지 않습니다.)

## 입력

첫 번째 줄에 정수 N (배열의 크기)이 주어집니다. 두 번째 줄에 N개의 정수 원소가 공백으로 구분되어 주어집니다. 세 번째 줄에 정수 K가 주어집니다. (입력 순서: N, A[0]...A[N-1], K)

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= A[i] <= 10^9
0 <= K <= 10^14
시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4
3 1 2 7
8
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합은 6으로, 가장 긴 길이 3입니다.*

## 예제 2

**입력**
```
5
1 2 3 4 5
9
```

**출력**
```
3
```

*부분 배열 [2, 3, 4]의 합은 9로, 최대 길이는 3입니다.*

## 예제 3

**입력**
```
3
10 20 30
5
```

**출력**
```
0
```

*모든 원소의 값이 K(5)보다 크므로, 합이 K 이하인 부분 배열은 존재하지 않아 길이가 0입니다.*

## 힌트

- 배열의 원소는 모두 양수라는 조건이 중요합니다.
- 문제의 제약 조건과 목표를 고려할 때, 포인터나 윈도우를 움직이는 방식으로 접근하는 것이 효율적입니다.


## 알고리즘 요약

슬라이딩 윈도우 기법 (Sliding Window)

## 풀이 해설

아이디어: 이 문제는 합이 K를 넘지 않는 가장 긴 연속 부분 배열을 찾는 문제입니다. 배열의 원소가 모두 양수이기 때문에, 윈도우의 크기를 늘릴 때마다 합은 무조건 증가합니다. 따라서, '슬라이딩 윈도우' 기법을 사용하여 현재 합이 K를 초과할 때마다 왼쪽 포인터(L)를 움직여 윈도우를 축소하고, 합이 K 이하일 때마다 오른쪽 포인터(R)를 움직여 윈도우를 확장하는 방식으로 문제를 해결할 수 있습니다.

단계:
1. 변수 초기화: 왼쪽 포인터 L=0, 현재 합 current_sum=0, 최대 길이 max_length=0으로 설정합니다.
2. 오른쪽 포인터 이동 (R): R을 배열의 처음부터 끝까지 순회합니다.
3. 윈도우 확장: R에 해당하는 원소 A[R]을 current_sum에 더합니다.
4. 윈도우 축소 (제약 조건 확인): 만약 current_sum이 K를 초과하게 되면, 합을 K 이하로 만들기 위해 L 포인터를 이동시킵니다. L이 가리키는 원소 A[L]을 current_sum에서 빼주고, L을 1 증가시킵니다. 이 과정을 current_sum <= K가 될 때까지 반복합니다.
5. 길이 갱신: 현재 윈도우 [L, R]의 크기 (R - L + 1)가 max_length보다 크면 max_length를 갱신합니다.
6. 종료: R이 끝날 때까지 반복한 후, max_length가 최종 답이 됩니다.

시간 복잡도: 오른쪽 포인터 R과 왼쪽 포인터 L은 각각 배열의 크기 N을 넘지 않으며, 한 번씩만 증가합니다. 따라서, 시간 복잡도는 O(N)이 됩니다. 이는 매우 효율적인 선형 시간 복잡도입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 1. N 읽기
        String lineN = br.readLine();
        if (lineN == null || lineN.isEmpty()) return;
        int N = Integer.parseInt(lineN.trim());

        // 2. 배열 A 읽기
        StringTokenizer stA = new StringTokenizer(br.readLine());
        long[] A = new long[N];
        for (int i = 0; i < N; i++) {
            A[i] = Long.parseLong(stA.nextToken());
        }

        // 3. K 읽기
        long K = Long.parseLong(br.readLine());

        // 슬라이딩 윈도우 로직
        long currentSum = 0;
        int maxLength = 0;
        int left = 0;

        for (int right = 0; right < N; right++) {
            // 윈도우 확장: 오른쪽 포인터 이동
            currentSum += A[right];

            // 윈도우 축소: 합이 K를 초과할 때까지 왼쪽 포인터 이동
            while (currentSum > K) {
                // A[left]를 빼주고 left를 증가시킨다.
                currentSum -= A[left];
                left++;
            }
            
            // 현재 윈도우 길이 갱신
            // (R - L + 1) = (right - left + 1)
            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength);
    }
}
```

# 최소 이동 경로 찾기
*java · BFS · 보통 · BFS, 구현*

## 입출력 환경

Java 환경에서는 표준 입출력을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

당신은 직사각형 모양의 격자판(Grid) 위에서 이동하는 로봇입니다. 격자판에는 장애물('W')과 빈 공간('.')이 섞여 있습니다. 로봇은 시작 지점(S)에서 목표 지점(E)까지 가장 적은 이동 횟수로 도달해야 합니다.

로봇은 상하좌우 네 방향으로만 이동할 수 있으며, 장애물('W')이 있는 칸으로는 절대로 이동할 수 없습니다. 이동할 때마다 1의 거리가 소모됩니다.

만약 목표 지점에 도달할 수 없다면, -1을 출력해야 합니다.

(주의: 격자판은 1-based index가 아닌 0-based index로 생각하고 처리합니다.)

## 입력

첫째 줄에 격자판의 행의 개수 M과 열의 개수 N이 주어집니다.
다음 M 줄에 걸쳐 각 행의 문자열이 주어지며, 각 문자는 다음과 같습니다:
'.': 빈 공간
'W': 장애물
'S': 시작 지점
'E': 목표 지점

## 출력

가장 적은 이동 횟수를 나타내는 정수 하나를 출력합니다. 목표 지점에 도달할 수 없다면 -1을 출력합니다.

## 제약 조건

M, N의 값은 1 이상 100 이하입니다. (시간 복잡도는 O(M*N) 이내여야 합니다.)

## 예제 1

**입력**
```
3 3
S.W
...E
.W.

```

**출력**
```
3
```

*S(0,0) -> (1,0) -> (1,1) -> E(1,3). 총 3칸 이동.*

## 예제 2

**입력**
```
4 4
S.W.
.W..E
....W.
.W.W.

```

**출력**
```
5
```

*S(0,0)에서 E(1,3)까지의 최단 경로는 5칸입니다.*

## 힌트

- 최단 거리를 찾는 문제이므로 BFS(Breadth-First Search)를 사용합니다.
- 방문 배열(visited)을 사용하여 무한 루프를 방지하고, 이미 처리한 칸을 재방문하지 않도록 해야 합니다.


## 알고리즘 요약

BFS (Breadth-First Search). 격자판을 그래프로 간주하고, 시작점에서부터 전파되는 방식으로 최단 거리를 탐색합니다. 큐(Queue)를 사용하여 현재 위치와 이동 거리를 저장하며, 상하좌우 네 방향으로 이동 가능한지, 장애물인지, 그리고 이미 방문했는지 확인하는 과정을 반복합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

아이디어: 이 문제는 가중치가 1인 그래프에서 시작점과 끝점 사이의 최단 거리를 찾는 전형적인 문제이므로, BFS(Breadth-First Search)를 적용합니다. BFS는 한 번에 같은 거리의 모든 노드를 탐색하기 때문에 최단 거리를 보장합니다.

단계:
1. 시작점(S)과 목표점(E)의 좌표를 찾습니다. (S와 E는 각각 한 번만 존재한다고 가정합니다.)
2. 거리를 저장할 `distance` 배열(M x N)과 방문 여부를 체크할 배열을 초기화합니다. 시작 지점의 거리는 0으로 설정하고, 나머지 칸은 -1 또는 무한대로 초기화합니다.
3. 큐(Queue)에 시작 좌표(Start Row, Start Col)를 넣고 탐색을 시작합니다.
4. 큐에서 좌표 (r, c)를 꺼냅니다. 이 좌표가 목표 지점(E)라면 현재 저장된 거리가 답이므로 반환합니다.
5. 상하좌우 네 방향에 대해 인접한 칸 (nr, nc)를 확인합니다.
6. 만약 (nr, nc)가 격자판 범위 안에 있고, 장애물이 아니며, 아직 방문하지 않은 칸이라면:
    a. (nr, nc)의 거리를 현재 거리 + 1로 갱신합니다.
    b. 큐에 (nr, nc)를 추가합니다.
7. 큐가 비어날 때까지 4~6번 과정을 반복합니다. 만약 목표 지점에 도달하지 못했다면, -1을 반환합니다.

시간 복잡도: 시간 복잡도는 O(M * N)입니다. M * N 크기의 격자판 전체를 각 칸을 최대 한 번씩 방문하며 탐색하기 때문에, 시간 복잡도는 격자 크기에 선형적으로 비례합니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.LinkedList;
import java.util.Queue;
import java.util.StringTokenizer;

class Cell {
    int r, c, dist;
    public Cell(int r, int c, int dist) {
        this.r = r;
        this.c = c;
        this.dist = dist;
    }
}

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int M = Integer.parseInt(st.nextToken());
        int N = Integer.parseInt(st.nextToken());

        char[][] grid = new char[M][N];
        int startR = -1, startC = -1;
        int endR = -1, endC = -1;

        for (int i = 0; i < M; i++) {
            String line = br.readLine();
            for (int j = 0; j < N; j++) {
                grid[i][j] = line.charAt(j);
                if (grid[i][j] == 'S') {
                    startR = i;
                    startC = j;
                } else if (grid[i][j] == 'E') {
                    endR = i;
                    endC = j;
                }
            }
        }

        System.out.println(bfs(M, N, grid, startR, startC, endR, endC));
    }

    private static int bfs(int M, int N, char[][] grid, int startR, int startC, int endR, int endC) {
        
        // 방문 배열 (또는 거리 배열을 활용) - -1로 초기화하여 미방문 표시
        int[][] distance = new int[M][N];
        for (int i = 0; i < M; i++) {
            for (int j = 0; j < N; j++) {
                distance[i][j] = -1;
            }
        }

        Queue<Cell> queue = new LinkedList<>();
        
        // 시작점 설정
        queue.add(new Cell(startR, startC, 0));
        distance[startR][startC] = 0;

        // 상하좌우 이동 방향 (dr, dc)
        int[] dr = {-1, 1, 0, 0}; // 위, 아래
        int[] dc = {0, 0, -1, 1}; // 왼쪽, 오른쪽

        while (!queue.isEmpty()) {
            Cell current = queue.poll();

            // 목표 지점 도달 확인
            if (current.r == endR && current.c == endC) {
                return current.dist;
            }

            // 4방향 탐색
            for (int i = 0; i < 4; i++) {
                int nr = current.r + dr[i];
                int nc = current.c + dc[i];
                
                // 1. 경계 검사
                if (nr >= 0 && nr < M && nc >= 0 && nc < N) {
                    // 2. 장애물 검사 및 방문 검사
                    if (grid[nr][nc] != 'W' && distance[nr][nc] == -1) {
                        // 3. 큐에 추가 및 거리 갱신
                        distance[nr][nc] = current.dist + 1;
                        queue.add(new Cell(nr, nc, current.dist + 1));
                    }
                }
            }
        }

        // 큐가 비었는데 목표에 도달하지 못한 경우
        return -1;
    }
```

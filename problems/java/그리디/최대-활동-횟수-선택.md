# 최대 활동 횟수 선택
*java · 그리디 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

Java 환경에서 표준 입력을 받기 위해 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

당신은 여러 활동(Activity)을 관리하는 시스템의 개발자입니다. 각 활동은 시작 시간과 종료 시간을 가지고 있습니다. 두 활동이 겹치지 않으려면, 한 활동의 종료 시간과 다른 활동의 시작 시간이 같거나, 한 활동이 완전히 끝난 후에 다음 활동이 시작되어야 합니다. 주어진 활동 목록 중에서 서로 겹치지 않는 최대 활동의 개수를 구하는 것이 목표입니다.

서로 겹치지 않는 활동은 [시작 시간, 종료 시간]으로 표현되며, 시작 시간과 종료 시간은 1부터 1000 사이의 정수입니다.

## 입력

첫 번째 줄에는 활동의 총 개수 N이 주어집니다. 다음 N개의 줄에는 각 활동의 시작 시간(S)과 종료 시간(E)이 공백으로 구분되어 주어집니다. (S E)

## 출력

선택할 수 있는 최대 활동의 개수(정수)를 출력합니다.

## 제약 조건

N: 1 <= N <= 100,000
시간 복잡도: O(N log N) 이내를 목표로 합니다.

## 예제 1

**입력**
```
3
1 3
2 4
3 5
```

**출력**
```
2
```

*활동 (1, 3)과 (3, 5)를 선택할 수 있으며, 최대 2개입니다.*

## 예제 2

**입력**
```
4
1 2
2 3
1 3
4 5
```

**출력**
```
3
```

*활동 (1, 2), (2, 3), (4, 5)를 선택할 수 있어 최대 3개입니다.*

## 힌트

- 모든 활동을 무작정 선택하는 것이 아니라, 효율적으로 선택하는 기준이 필요합니다.
- 그리디 알고리즘을 적용하기 위해서는 특정 기준에 따라 데이터를 정렬해야 합니다.


## 알고리즘 요약

그리디 알고리즘(Greedy Algorithm)을 이용합니다. 활동 선택 문제의 핵심은 '종료 시간이 가장 빠른 활동'을 우선적으로 선택하는 것입니다. 모든 활동을 종료 시간 기준으로 오름차순 정렬한 후, 첫 번째 활동을 선택하고, 이후 선택하는 활동은 이전 활동의 종료 시간보다 시작 시간이 크거나 같은 활동 중에서 가장 빠른 것을 선택해 나갑니다.

## 풀이 해설

아이디어:
이 문제는 전형적인 그리디 알고리즘 문제입니다. 활동의 개수를 최대로 만들려면, 매번 활동을 선택할 때마다 다음 활동을 위한 '남은 시간'을 최대한 확보하는 것이 중요합니다. 즉, 가능한 한 빨리 끝나는 활동을 선택하는 것이 최적의 선택입니다.

단계:
1. 데이터 구조화: 각 활동 (시작 시간 S, 종료 시간 E)를 저장할 구조체(또는 클래스)를 만듭니다.
2. 정렬: 모든 활동을 종료 시간(E)을 기준으로 오름차순 정렬합니다. (종료 시간이 같다면 시작 시간 순으로 정렬해도 무방합니다.)
3. 그리디 탐색: 첫 번째 활동(가장 빨리 끝나는 활동)을 선택하고 카운트를 1로 설정합니다. 이후 인덱스를 순회하며, 현재 활동의 시작 시간(S_current)이 이전에 선택한 활동의 종료 시간(E_last)보다 크거나 같다면 (즉, 겹치지 않는다면) 해당 활동을 선택하고, E_last를 S_current로 업데이트하며 카운트를 1 증가시킵니다.

시간 복잡도:
- 활동을 저장하고 입력받는 시간: O(N)
- 정렬: O(N log N)
- 탐색: O(N)
총 시간 복잡도는 정렬에 의해 결정되는 O(N log N)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.Comparator;
import java.util.StringTokenizer;

// 활동 정보를 담는 클래스
class Activity {
    int start;
    int end;

    public Activity(int start, int end) {
        this.start = start;
        this.end = end;
    }
}

public class Main {

    public static void main(String[] args) throws IOException {
        // 표준 입력 처리 (효율성 중시)
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 줄에서 활동 개수 N 읽기
        String line = br.readLine();
        if (line == null || line.isEmpty()) return;
        
        int N = Integer.parseInt(line.trim());
        Activity[] activities = new Activity[N];

        // 다음 N 줄에서 활동 정보 읽기
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int start = Integer.parseInt(st.nextToken());
            int end = Integer.parseInt(st.nextToken());
            activities[i] = new Activity(start, end);
        }

        // 1. 그리디 접근을 위해 종료 시간(end)을 기준으로 오름차순 정렬
        Arrays.sort(activities, new Comparator<Activity>() {
            @Override
            public int compare(Activity a1, Activity a2) {
                // 종료 시간 비교가 우선
                if (a1.end != a2.end) {
                    return Integer.compare(a1.end, a2.end);
                }
                // 종료 시간이 같으면 시작 시간 순으로 정렬 (안정성을 위해)
                return Integer.compare(a1.start, a2.start);
            }
        });

        // 2. 그리디 탐색 시작
        int count = 0;
        // 가장 마지막에 선택된 활동의 종료 시간을 기록할 변수. 초기값은 매우 작은 수로 설정
        int lastFinishTime = -1; 

        for (Activity current : activities) {
            // 현재 활동의 시작 시간이 마지막 활동의 종료 시간보다 크거나 같다면, 겹치지 않는다.
            if (current.start >= lastFinishTime) {
                count++;
                // 이 활동을 선택했으므로, 다음 활동을 위한 종료 시간 갱신
                lastFinishTime = current.end;
            }
        }

        // 결과 출력
        System.out.println(count);
    }
}
```

# 최소 연산으로 모두 같은 색 만들기
*java · 그리디 · 보통 · 그리디, 시뮬레이션*

## 입출력 환경

Java에서 빠른 입출력을 위해 BufferedReader와 StringTokenizer를 사용합니다.

## 문제

당신은 N개의 타일이 일렬로 놓여있는 상황을 가정합니다. 각 타일은 1부터 K까지의 고유한 색깔을 가지고 있습니다. 목표는 모든 타일의 색깔을 특정 목표 색깔(TargetColor)로 만드는 것입니다. 한 번의 연산은 '아직 목표 색깔이 아닌' 연속된 구간의 타일들을 모두 같은 색으로 바꾸는 것입니다.

예를 들어, 타일 배열이 [1, 2, 2, 3, 1]이고 목표 색깔이 1이라고 가정해봅시다. 연산을 한 번 사용하면 [2, 2]를 1로 바꾸거나, [3]을 1로 바꿀 수 있습니다. 모든 타일을 목표 색깔로 만들기 위해 필요한 최소 연산 횟수를 구하세요.

## 입력

첫 번째 줄에 정수 N (타일 개수)이 주어지고, 두 번째 줄에 공백으로 구분된 N개의 정수 (타일 색깔)가 주어집니다.

## 출력

모든 타일을 목표 색깔로 만들기 위해 필요한 최소 연산 횟수 (정수)를 출력합니다.

## 제약 조건

N의 범위: 1부터 100,000 이하. 타일 색깔의 범위: 1부터 10,000 이하. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
5
1 2 2 3 1
```

**출력**
```
2
```

*목표 색깔 1 기준, 2와 3으로 이루어진 2개의 연속 구간([2, 2]와 [3])을 변경해야 하므로 최소 2번의 연산이 필요합니다.*

## 예제 2

**입력**
```
4
3 3 3 3
```

**출력**
```
0
```

*모든 타일이 이미 목표 색깔 3이므로 연산이 필요 없습니다.*

## 예제 3

**입력**
```
6
1 2 1 2 1 2
```

**출력**
```
3
```

*목표 색깔 1 기준, [2], [2], [2] 세 개의 독립적인 구간을 변경해야 합니다.*

## 힌트

- 이 문제는 그리디하게 접근하여, 목표 색깔이 아닌 연속된 '덩어리'의 개수를 세는 것이 핵심입니다.
- 배열을 순회하면서, 현재 색깔이 목표 색깔과 다르고, 바로 이전 색깔도 목표 색깔과 달랐다면 연산 횟수를 1 증가시켜야 합니다.


## 알고리즘 요약

그리디/카운팅. 배열을 순차적으로 탐색하며, 목표 색깔과 다른 연속된 구간(Run)이 시작될 때마다 카운트를 증가시킵니다.

## 풀이 해설

아이디어: 이 문제는 목표 색깔(TargetColor)이 주어졌을 때, 목표 색깔과 다른 색으로 이루어진 '연속된 덩어리(Segment)'의 개수를 세면 됩니다. 각 덩어리 하나를 변경하는 데 최소 1번의 연산이 필요하기 때문입니다. 따라서, 배열을 왼쪽에서 오른쪽으로 순회하면서, 목표 색깔과 다른 색이 나타나고, 이전에 목표 색깔이었거나 배열의 시작점이었다면, 새로운 덩어리가 시작된 것으로 간주하고 카운트를 1 증가시킵니다.

단계:
1. 목표 색깔(TargetColor)을 설정합니다.
2. 연산 횟수를 저장할 변수 `operations`를 0으로 초기화합니다.
3. 배열을 순회하며 현재 요소 `A[i]`를 확인합니다.
4. 만약 `A[i]`가 목표 색깔과 다르다면, 그리고 (i == 0이거나, `A[i-1]`가 목표 색깔과 다르다면), 이는 새로운 '비목표 색' 덩어리의 시작입니다. 이 경우 `operations`를 1 증가시킵니다.
5. 이 로직은 목표 색깔과 다른 색으로 이루어진 모든 독립적인 구간의 시작점을 정확하게 카운트합니다.

시간 복잡도: 배열을 한 번만 순회하므로 O(N)입니다. 이는 주어진 제약 조건(N <= 10^5)을 만족하는 효율적인 풀이입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Solution {

    public static void main(String[] args) {
        // 빠른 입출력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        try {
            // 1. N (타일 개수) 읽기
            int N = Integer.parseInt(br.readLine());
            if (N == 0) {
                System.out.println(0);
                return;
            }

            // 2. 타일 색깔 배열 읽기
            StringTokenizer st = new StringTokenizer(br.readLine());
            int[] tiles = new int[N];
            for (int i = 0; i < N; i++) {
                tiles[i] = Integer.parseInt(st.nextToken());
            }

            // 문제의 조건에 따라, 목표 색깔은 예제에서 가장 많이 등장하거나, 혹은 특정 색으로 고정됩니다.
            // 여기서는 '첫 번째 요소의 색깔'을 목표 색깔로 가정하고 풀이합니다. (문제 정의에 따라 TargetColor를 명시해야 함)
            // 예시를 위해, 문제의 의도대로, 목표 색깔을 배열의 첫 번째 색으로 가정합니다.
            int targetColor = tiles[0];
            
            // 3. 그리디 로직 적용
            int operations = 0;
            
            for (int i = 0; i < N; i++) {
                int currentColor = tiles[i];
                
                // 1. 현재 색깔이 목표 색깔과 다른가?
                if (currentColor != targetColor) {
                    // 2. 현재 위치가 배열의 시작점이거나, 이전 색깔이 목표 색깔과 달랐다면
                    // (즉, 새로운 비목표 색 덩어리의 시작점이라면)
                    if (i == 0 || tiles[i-1] != targetColor) {
                        operations++;
                    }
                }
            }
            
            System.out.println(operations);
            
        } catch (Exception e) {
            // 입력 오류 처리 (테스트 케이스 환경을 위해 주석 처리 가능)
        }
    }
}
```

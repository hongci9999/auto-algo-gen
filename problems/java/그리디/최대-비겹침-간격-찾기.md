# 최대 비겹침 간격 찾기
*java · 그리디 · 보통 · 그리디, 정렬, 배열*

## 입출력 환경

Java 환경에서 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

당신은 여러 개의 시간 간격(Interval) 목록을 받았습니다. 각 간격은 시작 시간과 끝 시간으로 이루어져 있으며, `[start, end]` 형태로 주어집니다.

이 간격들 중에서 서로 시간적으로 겹치지 않는(비겹침) 최대 개수의 간격들을 선택하는 것이 목표입니다. 간격 `[a, b]`와 `[c, d]`가 겹치지 않기 위한 조건은 `b < c` 또는 `d < a` 입니다. (시작 시간이 끝 시간과 같아도 겹치지 않는다고 가정합니다.)

예를 들어, `[1, 3], [2, 4], [3, 5]`가 주어졌을 때, `[1, 3]`과 `[3, 5]`는 겹치지 않으므로 선택 가능합니다. 따라서 최대 개수는 2입니다.

## 입력

첫째 줄에 간격의 총 개수 N이 주어집니다. 다음 N개의 줄에는 각 간격의 시작 시간(start)과 끝 시간(end)이 공백으로 구분되어 주어집니다. (start, end는 1 이상 100,000 이하의 정수입니다.)

## 출력

서로 겹치지 않는 간격의 최대 개수를 하나의 정수로 출력합니다.

## 제약 조건

N의 범위는 1부터 100,000까지입니다. 시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
1 3
2 4
3 5
```

**출력**
```
2
```

*간격들을 끝 시간이 빠른 순으로 정렬한 뒤, [1, 3]과 [3, 5]를 선택하여 최대 2개를 얻습니다.*

## 예제 2

**입력**
```
5
1 2
3 4
5 6
1 5
2 3
```

**출력**
```
3
```

*가장 끝 시간이 빠른 순서대로 [1, 2], [3, 4], [5, 6]을 선택하여 최대 3개를 얻습니다.*

## 힌트

- 이 문제는 그리디(탐욕) 알고리즘을 사용해야 합니다.
- 간격들을 어떤 기준으로 정렬하는지가 핵심입니다. 끝 시간(End Time)을 기준으로 정렬하세요.


## 알고리즘 요약

그리디 알고리즘 + 정렬. 모든 간격을 끝 시간(End Time)을 기준으로 오름차순 정렬합니다. 정렬된 리스트를 순회하며, 현재 간격의 시작 시간이 이전에 선택된 간격의 끝 시간보다 크거나 같다면 (즉, 겹치지 않는다면) 이를 선택하고, 이전에 선택된 간격의 끝 시간을 현재 간격의 끝 시간으로 업데이트합니다. 이 과정을 반복하여 선택된 간격의 총 개수를 셉니다.

## 풀이 해설

1. 아이디어: 이 문제는 전형적인 그리디 알고리즘 문제입니다. 간격들 중에서 겹치지 않는 최대 개수를 얻기 위해서는, 매번 선택할 때 '가장 빨리 끝나는' 간격을 선택하는 것이 최적의 선택입니다. 가장 빨리 끝나는 간격을 선택해야 남은 시간에서 다음 간격들을 선택할 수 있는 범위가 최대화되기 때문입니다.
2. 단계:
    a. 간격들을 읽어와서 배열 또는 리스트에 저장합니다.
    b. 이 간격들을 **끝 시간(End Time)**을 기준으로 오름차순 정렬합니다. (만약 끝 시간이 같다면, 시작 시간을 기준으로 정렬해도 무방합니다.)
    c. 변수 `count` (선택된 간격의 개수)를 0으로 초기화하고, `lastEndTime` (가장 최근에 선택된 간격의 끝 시간)을 매우 작은 값(예: 0 또는 -1)으로 초기화합니다.
    d. 정렬된 간격들을 처음부터 끝까지 순회합니다.
    e. 현재 간격의 시작 시간(`start`)이 `lastEndTime`보다 크거나 같으면 (겹치지 않으면): 
        i. `count`를 1 증가시킵니다.
        ii. `lastEndTime`를 현재 간격의 끝 시간(`end`)으로 업데이트합니다.
    f. 그렇지 않다면 (겹친다면): 아무것도 하지 않고 다음 간격으로 넘어갑니다.
3. 시간 복잡도: 간격 N개를 읽는 데 O(N)이 걸립니다. 정렬에 O(N log N)이 걸리며, 순회에 O(N)이 걸립니다. 따라서 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (java)

```java
import java.util.Arrays;
import java.util.Comparator;
import java.util.Scanner;

// 간격을 저장하기 위한 클래스 정의
class Interval {
    int start;
    int end;

    public Interval(int start, int end) {
        this.start = start;
        this.end = end;
    }
}

public class Solution {

    public static void main(String[] args) {
        // Scanner를 사용하여 입력을 받는다고 가정합니다. (실제 테스트 환경에 맞게 조정 필요)
        Scanner scanner = new Scanner(System.in);
        if (!scanner.hasNextInt()) {
            // 입력이 없을 경우 종료
            return;
        }

        int N = scanner.nextInt();
        Interval[] intervals = new Interval[N];

        for (int i = 0; i < N; i++) {
            int start = scanner.nextInt();
            int end = scanner.nextInt();
            intervals[i] = new Interval(start, end);
        }

        // 1. 그리디 전략을 위해 끝 시간(End Time)을 기준으로 오름차순 정렬
        // Comparator를 사용하여 사용자 정의 정렬 기준을 적용합니다.
        Arrays.sort(intervals, new Comparator<Interval>() {
            @Override
            public int compare(Interval a, Interval b) {
                // 끝 시간(end)을 기준으로 비교합니다.
                return Integer.compare(a.end, b.end);
            }
        });

        // 2. 그리디 선택 과정
        int count = 0;
        // 마지막으로 선택된 간격의 끝 시간을 저장합니다. 시작 시간보다 작은 값으로 초기화합니다.
        int lastEndTime = 0; 

        for (Interval current : intervals) {
            // 현재 간격의 시작 시간이 lastEndTime보다 크거나 같으면 (겹치지 않으면)
            if (current.start >= lastEndTime) {
                // 선택!
                count++;
                // lastEndTime을 현재 간격의 끝 시간으로 업데이트합니다.
                lastEndTime = current.end;
            }
        }

        System.out.println(count);
        scanner.close();
    }
}
```

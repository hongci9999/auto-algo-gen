# 활동 스케줄링
*java · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Java에서 대량의 입력을 처리할 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

당신은 여러 개의 활동(Task)을 관리하는 스케줄러를 개발해야 합니다. 각 활동은 시작 시간과 종료 시간을 가지며, 두 활동이 동시에 진행되어서는 안 됩니다 (즉, 한 활동이 끝나기 전에 다른 활동이 시작할 수 없습니다).

주어진 N개의 활동 목록 중에서, 서로 겹치지 않으면서 최대한 많은 활동을 선택할 수 있는 최대 개수를 구하세요.

활동의 시간 범위는 정수이며, [시작 시간, 종료 시간]으로 표현됩니다. 종료 시간은 다음 활동의 시작 시간과 같아도 겹치지 않는 것으로 간주합니다.

## 입력

첫째 줄에 활동의 개수 N이 주어집니다.
다음 N개의 줄에는 각 활동의 시작 시간 s와 종료 시간 e가 공백으로 구분되어 주어집니다. (s <= e)

## 출력

선택 가능한 최대 활동 개수를 정수 하나로 출력합니다.

## 제약 조건

1 <= N <= 100,000
1 <= 시작 시간, 종료 시간 <= 10^9
시간 복잡도는 O(N log N) 이하를 목표로 합니다.

## 예제 1

**입력**
```
3
1 2
2 3
1 3
```

**출력**
```
2
```

*활동 (1, 2)와 (2, 3)을 선택하여 최대 2개의 활동을 진행할 수 있습니다.*

## 예제 2

**입력**
```
4
0 5
0 10
2 4
4 6
```

**출력**
```
2
```

*활동 (2, 4)와 (4, 6)을 선택하는 것이 최적입니다. (0, 5)와 (2, 4)를 선택할 경우, 겹치지 않지만 더 많은 활동을 선택할 수 없습니다.*

## 힌트

- 모든 활동을 시간 순서대로 정렬하는 것이 핵심입니다.
- 어떤 기준(시작 시간, 종료 시간 등)으로 정렬해야 하는지 생각해 보세요.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm)
활동 선택 문제는 '최종 종료 시간이 가장 빠른 활동'을 선택하는 것이 최적의 선택임을 이용합니다. 모든 활동을 종료 시간(End Time)을 기준으로 오름차순 정렬한 후, 첫 번째 활동을 선택하고, 이후 활동 중 현재 활동의 시작 시간이 이전 활동의 종료 시간보다 크거나 같은 활동을 순차적으로 선택합니다.

## 풀이 해설

### 💡 아이디어 (Greedy Approach)
활동 스케줄링 문제와 같이, 주어진 제약 조건 하에서 '최대 개수'를 구해야 할 때, 가장 빨리 끝나는 것을 선택하는 것이 남은 자원(시간)을 가장 많이 확보해 주기 때문에 그리디하게 최적해를 찾을 수 있습니다.

### ⚙️ 단계별 풀이
1. **입력 및 저장**: N개의 활동 (시작 시간 s, 종료 시간 e)을 배열 또는 리스트에 저장합니다.
2. **정렬**: 이 활동들을 **종료 시간(End Time)을 기준**으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간을 기준으로 오름차순 정렬해도 무방합니다.
3. **탐색 및 선택**: 첫 번째 활동을 무조건 선택하고, 카운트를 1로 초기화합니다. 그리고 두 번째 활동부터 순회하면서 다음 조건을 만족하는 활동을 찾습니다:
    *   현재 활동의 `시작 시간 >= 이전 선택된 활동의 종료 시간`
    *   조건을 만족하면, 해당 활동을 선택하고, `이전 선택된 활동의 종료 시간`을 현재 활동의 종료 시간으로 갱신하며, 카운트를 1 증가시킵니다.
4. **결과 반환**: 순회가 끝난 후의 카운트가 최대 활동 개수입니다.

### ⏱️ 시간 복잡도
*   입력 및 저장: O(N)
*   정렬: O(N log N) (가장 큰 병목)
*   탐색: O(N)
*   **총 시간 복잡도**: O(N log N)

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.List;

// 활동 정보를 담는 클래스
class Activity {
    long start;
    long end;

    public Activity(long start, long end) {
        this.start = start;
        this.end = end;
    }
}

public class Solution {

    public static void main(String[] args) throws IOException {
        // 빠른 입출력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 줄에서 활동 개수 N을 읽음
        int N = Integer.parseInt(br.readLine());
        
        List<Activity> activities = new ArrayList<>();
        for (int i = 0; i < N; i++) {
            String[] parts = br.readLine().split(" ");
            long start = Long.parseLong(parts[0]);
            long end = Long.parseLong(parts[1]);
            activities.add(new Activity(start, end));
        }

        // 1. 그리디 전략: 종료 시간을 기준으로 오름차순 정렬
        // 종료 시간(end)을 기준으로 Comparator를 사용하여 정렬합니다.
        Collections.sort(activities, new Comparator<Activity>() {
            @Override
            public int compare(Activity a1, Activity a2) {
                // 종료 시간 비교 (오름차순)
                if (a1.end < a2.end) return -1;
                if (a1.end > a2.end) return 1;
                // 종료 시간이 같으면 시작 시간 비교 (필수는 아니지만 안정성을 위해 추가)
                return Long.compare(a1.start, a2.start);
            }
        });

        // 2. 선택 과정
        int count = 0;
        // 마지막으로 선택된 활동의 종료 시간을 저장할 변수. 초기에는 가장 작은 값으로 설정하거나, 첫 활동으로 초기화합니다.
        long lastFinishTime = 0; 

        for (Activity activity : activities) {
            // 현재 활동의 시작 시간이 이전 활동의 종료 시간과 겹치지 않는지 확인
            // (즉, activity.start >= lastFinishTime 이어야 함)
            if (activity.start >= lastFinishTime) {
                // 선택!
                count++;
                // 마지막 선택된 활동의 종료 시간 갱신
                lastFinishTime = activity.end;
            }
        }

        System.out.println(count);
    }
}
```

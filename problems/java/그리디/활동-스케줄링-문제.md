# 활동 스케줄링 문제
*java · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Java의 성능을 고려하여 `BufferedReader`와 `StringTokenizer`를 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

당신은 여러 개의 활동(Activities)을 진행할 수 있는 스케줄러의 역할을 맡았습니다. 각 활동은 시작 시간과 종료 시간을 가집니다.

주어진 $N$개의 활동 쌍 $(S_i, E_i)$ 중에서 서로 겹치지 않으면서 가장 많은 개수를 선택하는 최대의 활동 집합을 찾아야 합니다.

두 활동 A와 B가 있다고 할 때, 만약 $\max(S_A, S_B) < \min(E_A, E_B)$라면 두 활동은 겹치며, 같은 시간대에 동시에 진행될 수 없습니다. 따라서 선택된 모든 활동들은 서로 간에 시간적으로 겹치지 않아야 합니다.

## 입력

첫 줄에는 $N$ (활동의 총 개수)이 주어집니다.
다음 $N$개의 줄에는 각 활동의 시작 시간 $S_i$와 종료 시간 $E_i$가 공백으로 구분되어 순서대로 주어집니다. (모든 시간은 양의 정수입니다.)

## 출력

선택 가능한 최대 활동의 개수(정수)를 출력합니다.

## 제약 조건

$1 \le N \le 50,000$
$1 \le S_i, E_i \le 10^9$
시간 범위가 크므로 `long` 타입을 사용하는 것이 안전합니다. 시간 복잡도는 $O(N \log N)$을 목표로 합니다.

## 예제 1

**입력**
```
3
1 4
2 3
5 6
```

**출력**
```
2
```

*선택 가능한 활동은 {2, 3}과 {5, 6}이며, 최대 개수는 2개입니다.*

## 예제 2

**입력**
```
4
1 2
3 4
0 5
6 7
```

**출력**
```
3
```

*선택 가능한 활동은 {1, 2}, {3, 4}, {6, 7}입니다. 가장 많은 개수는 3개입니다.*

## 알고리즘 요약

활동 선택 문제(Activity Selection Problem)는 종료 시간(End Time)을 기준으로 오름차순 정렬한 후, 가장 먼저 끝나는 활동부터 순차적으로 선택하는 그리디 전략을 사용합니다. 현재까지 선택된 마지막 활동의 종료 시간이 다음 활동의 시작 시간보다 작거나 같아야 합니다.

## 풀이 해설

1. **아이디어**: 이 문제는 '최적의 자원 활용' 문제로, 탐욕적인(Greedy) 접근 방식이 가장 효율적입니다.
2. **그리디 선택 기준**: 주어진 활동들 중에서 무조건 시작 시간이 가장 빠른 것이 아니라, '가장 빨리 끝나는' 활동을 먼저 선택하는 것이 전체 스케줄에 남은 시간을 최대화하여 기회를 늘리는 최적의 그리디 선택입니다.
3. **단계별 풀이**: 
    a. 입력받은 모든 $(S_i, E_i)$ 쌍을 저장합니다. (여기서 $E_i$를 기준으로 정렬할 것이므로 배열 또는 리스트 사용)
    b. 이 활동들을 종료 시간 $E_i$를 기준으로 오름차순 정렬합니다. 만약 종료 시간이 같다면 시작 시간을 기준으로 오름차순 정렬해도 무방합니다.
    c. 첫 번째 활동을 반드시 선택하고, `count`를 1로 초기화하며, 마지막으로 선택된 활동의 종료 시간(`lastEndTime`)을 기록합니다.
    d. 정렬된 리스트를 순회하면서, 현재 활동 $i$의 시작 시간 $S_i$가 이전에 선택한 활동의 종료 시간 $lastEndTime$보다 크거나 같은지 확인합니다 ($S_i \ge lastEndTime$).
    e. 조건이 만족하면(즉, 겹치지 않으면), 해당 활동을 선택하고 `count`를 1 증가시키며, `lastEndTime`를 현재 활동의 종료 시간 $E_i$로 업데이트합니다.
4. **시간 복잡도**: 입력 크기 $N$에 대해 정렬 과정이 $O(N 	o N \log N)$가 소요되며, 이후 순회는 $O(N)$이므로 전체 시간 복잡도는 $O(N \log N)$입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

class Activity {
    long start;
    long end;

    public Activity(long start, long end) {
        this.start = start;
        this.end = end;
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 첫 줄에서 N 읽기
        int N = Integer.parseInt(br.readLine());

        Activity[] activities = new Activity[N];
        
        // 나머지 N줄에서 활동 데이터 읽기
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            long start = Long.parseLong(st.nextToken());
            long end = Long.parseLong(st.nextToken());
            activities[i] = new Activity(start, end);
        }

        // 1. 그리디 전략: 종료 시간(end)을 기준으로 오름차순 정렬합니다.
        Arrays.sort(activities, (a, b) -> {
            if (a.end != b.end) {
                return Long.compare(a.end, b.end);
            } else {
                // 종료 시간이 같으면 시작 시간 순으로 처리해도 무방합니다.
                return Long.compare(a.start, b.start);
            }
        });

        int count = 0;
        long lastEndTime = -1; // 매우 작은 값으로 초기화 (시간은 양수이므로)

        // 2. 정렬된 배열을 순회하며 선택합니다.
        for (Activity activity : activities) {
            // 현재 활동의 시작 시간이 이전에 선택한 마지막 활동의 종료 시간보다 크거나 같으면 겹치지 않습니다.
            if (activity.start >= lastEndTime) {
                count++;
                lastEndTime = activity.end; // 선택했으므로, 마지막 종료 시간을 업데이트합니다.
            }
        }

        System.out.println(count);
    }
}
```

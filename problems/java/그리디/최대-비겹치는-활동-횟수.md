# 최대 비겹치는 활동 횟수
*java · 그리디 · 보통 · 그리디, 정렬*

## 입출력 환경

Java에서 입력 처리를 위해 java.util.* 패키지와 BufferedReader/StringTokenizer를 사용하는 것을 권장합니다.

## 문제

당신은 여러 개의 활동(Activity) 목록을 받았습니다. 각 활동은 시작 시간과 종료 시간을 가지는 구간으로 정의됩니다.

활동 간의 '겹침'이란, 두 활동이 동일한 시간대에 공통적으로 존재하는 경우를 의미합니다. 즉, $[S_1, E_1]$와 $[S_2, E_2]$가 주어졌을 때, $S_1 < E_2$ 이고 $S_2 < E_1$ 인 경우 겹친다고 가정합니다.

당신의 목표는 주어진 활동들 중에서 서로 겹치지 않는 최대 개수의 활동들을 선택하는 것입니다. 이 최대 개수를 구하세요.

## 입력

첫째 줄에 전체 활동의 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 활동의 시작 시간 $S$와 종료 시간 $E$가 공백으로 구분되어 순서대로 주어집니다. (1 ≤ S <= E ≤ 10^9)

## 출력

선택할 수 있는 최대 비겹치는 활동의 개수(정수)를 한 줄에 출력합니다.

## 제약 조건

N의 범위는 1부터 200,000 이하입니다. 시간 복잡도는 $O(N \log N)$을 목표로 합니다.

## 예제 1

**입력**
```
3
1 4
2 3
5 6
```

**출력**
```
2
```

*활동 [2, 3]과 [5, 6]을 선택하면 겹치지 않으며 개수는 2입니다.*

## 예제 2

**입력**
```
4
1 3
0 2
3 5
6 8
```

**출력**
```
3
```

*활동 [0, 2], [2, 3], [3, 5] 또는 [0, 2], [3, 5], [6, 8]을 선택할 수 있으며, 최대 개수는 3입니다.*

## 힌트

- 이 문제는 전형적인 '활동 선택 문제(Activity Selection Problem)'와 유사합니다.
- 탐욕적(Greedy) 접근 방식을 고려하고, 어떤 기준으로 활동들을 정렬해야 최적해가 나올지 생각해 보세요. 종료 시간을 기준으로 정렬하는 것이 핵심입니다.


## 알고리즘 요약

그리디 알고리즘을 사용합니다. 모든 활동을 '종료 시간' 순으로 오름차순 정렬합니다. 첫 번째 활동을 선택하고, 이후 각 활동에 대해 이전에 선택된 활동의 종료 시간이 현재 활동의 시작 시간보다 작거나 같은지 확인하여 겹치지 않는 경우에만 선택합니다. 이렇게 하면 가장 많은 활동을 확보할 수 있습니다.

## 풀이 해설

풀이 아이디어: 주어진 문제(최대 비겹치는 활동 개수)는 전형적인 그리디 알고리즘 문제입니다. 이 문제를 해결하기 위해서는 '활동을 어떤 순서로 살펴볼 것인가'가 중요합니다.

1. 정렬 기준 확립 (핵심): 가장 많은 활동을 선택하려면, 매번 최대한 빨리 끝나는 활동을 먼저 선택하는 것이 유리합니다. 만약 현재 가능한 활동 중 종료 시간이 빠른 것을 선택하면, 다음에 이어질 활동들이 시작할 수 있는 시간적 여유(시간대)가 최대화되기 때문입니다.
2. 자료 구조 준비: 입력받은 모든 활동들을 (시작 시간, 종료 시간) 쌍으로 저장한 후, 오직 '종료 시간'을 기준으로 오름차순 정렬합니다.
3. 탐욕적 선택 (Greedy Selection): 첫 번째로 정렬된 활동(가장 빨리 끝나는 활동)을 무조건 선택하고, 이 활동의 종료 시간을 `last_end_time`으로 기록합니다. 이후 리스트를 순회하면서, 현재 활동 $i$에 대해 다음 조건을 검사합니다:
   - 만약 `활동 i의 시작 시간 >= last_end_time` 이라면, 이 활동은 이전 활동과 겹치지 않으므로 선택하고, `last_end_time`을 활동 $i$의 종료 시간으로 업데이트합니다.
   - 그렇지 않다면 (겹친다면), 무시하고 다음 활동으로 넘어갑니다.
4. 결과: 반복문이 끝났을 때 카운트된 활동의 개수가 최대 비겹치는 활동 횟수입니다.

시간 복잡도: $O(N \log N)$ (정렬에 소요되는 시간) + $O(N)$ (순회 시간) = $O(N \log N)$. 공간 복잡도는 $O(N)$을 사용합니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

// Activity 클래스를 정의하여 Pair 형태로 다루기 쉽게 만듭니다.
class Activity implements Comparable<Activity> {
    int start; // 시작 시간
    int end;   // 종료 시간

    public Activity(int start, int end) {
        this.start = start;
        this.end = end;
    }

    // 오직 '종료 시간'을 기준으로 정렬합니다.
    @Override
    public int compareTo(Activity other) {
        return Integer.compare(this.end, other.end);
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        // 빠른 입출력을 위한 설정 (Java에서 권장되는 방식)
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        // 첫 줄: 활동 개수 N 읽기
        String lineN = br.readLine();
        if (lineN == null || lineN.isEmpty()) return;

        int N = Integer.parseInt(lineN);
        Activity[] activities = new Activity[N];

        // 나머지 N줄: 활동 정보 읽기
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int start = Integer.parseInt(st.nextToken());
            int end = Integer.parseInt(st.nextToken());
            activities[i] = new Activity(start, end);
        }

        // 1. 활동 배열을 종료 시간 기준으로 정렬합니다.
        Arrays.sort(activities); 

        int count = 0; // 선택된 활동의 개수
        long lastEndTime = Long.MIN_VALUE; // 마지막으로 선택한 활동의 종료 시간 (최대 범위 고려하여 long 사용)

        // 2. 그리디 탐색을 수행합니다.
        for (Activity current : activities) {
            // 현재 활동이 이전에 선택된 활동과 겹치지 않으려면, 시작 시간이 이전 종료 시간보다 크거나 같아야 합니다.
            if (current.start >= lastEndTime) { 
                count++;
                lastEndTime = current.end;
            }
        }

        // 결과 출력
        sb.append(count).append("\n");
        System.out.print(sb.toString());
    }
}
```

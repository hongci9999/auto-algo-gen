# 최대 비겹침 활동 횟수
*java · 그리디 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

표준 입력(System.in)을 통해 모든 입력을 받고, 표준 출력(System.out)으로 결과를 출력합니다.

## 문제

당신은 문화센터의 강사입니다. 센터에서는 다양한 강좌를 개설하며, 각 강좌는 시작 시간과 종료 시간을 가집니다. 모든 강좌는 '시작 시간'과 '종료 시간'이라는 두 가지 속성을 가진다고 가정합니다.

여러 강좌가 개설되었을 때, 강사님이 동시에 진행할 수 있는 최대 활동 횟수(최대 비겹침 활동 횟수)를 구하는 문제입니다.

*   강좌 A의 시간 간격: [start_A, end_A]
*   강좌 B의 시간 간격: [start_B, end_B]

두 강좌가 겹친다는 것은 두 시간 간격이 부분적으로라도 겹칠 경우를 의미합니다. (예: [1, 5]와 [5, 7]은 겹치지 않습니다. [1, 5]와 [4, 7]은 겹칩니다.)

주어진 모든 강좌 목록을 활용하여, 서로 시간이 겹치지 않는 최대 개수의 활동을 선택하는 방법을 구하세요.

## 입력

첫째 줄에 정수 N (활동의 개수)이 주어집니다. 
다음 N줄에 걸쳐 각 활동의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s <= e)

## 출력

서로 겹치지 않는 최대 활동 횟수를 정수 하나로 출력합니다.

## 제약 조건

1 <= N <= 100,000
1 <= s <= e <= 100,000,000
시간 복잡도는 O(N log N) 이하로 요구됩니다.

## 예제 1

**입력**
```
4
1 3
2 5
4 6
7 9
```

**출력**
```
2
```

*가장 먼저 끝나는 활동을 선택하는 그리디 전략을 사용합니다. (1, 3) 선택 후, 3 이후에 시작하는 (7, 9)를 선택하여 총 2개가 됩니다.*

## 예제 2

**입력**
```
3
1 2
2 3
3 4
```

**출력**
```
3
```

*모든 활동이 연속적으로 겹치지 않으므로 3개가 됩니다. (1, 2) -> (2, 3) -> (3, 4)*

## 예제 3

**입력**
```
5
1 10
2 3
4 5
6 7
8 9
```

**출력**
```
3
```

*가장 먼저 끝나는 활동들을 선택합니다. (2, 3) -> (4, 5) -> (6, 7) 또는 (8, 9)를 선택할 수 있으며, 최대 3개입니다.*

## 힌트

- 활동 선택 문제(Activity Selection Problem)의 전형적인 문제입니다.
- 어떤 기준으로 정렬해야 최적의 해를 보장할 수 있는지 생각해 보세요.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm) 
활동 선택 문제의 경우, 종료 시간이 가장 빠른 활동을 선택하는 것이 항상 최적해로 이어집니다. 따라서 모든 활동을 종료 시간 기준으로 오름차순 정렬한 후, 첫 번째 활동을 선택하고, 그 다음 활동들 중 이전 활동의 종료 시간보다 크거나 같은 시작 시간을 가진 활동을 순차적으로 선택해 나가면 됩니다.

## 풀이 해설

아이디어: 이 문제는 전형적인 '활동 선택 문제(Activity Selection Problem)'이며, 이 문제는 그리디 알고리즘을 사용하여 해결할 수 있습니다. 최적의 해를 보장하는 그리디 선택 기준은 '현재 시점에서 종료 시간이 가장 빠른 활동을 선택하는 것'입니다.

단계:
1. 데이터 구조 정의 및 입력 받기: N개의 (시작 시간, 종료 시간) 쌍을 저장할 배열 또는 리스트를 준비합니다.
2. 정렬: 이 활동들을 '종료 시간'을 기준으로 오름차순 정렬합니다. (만약 종료 시간이 같다면 시작 시간 순으로 정렬해도 무방하지만, 종료 시간만으로 충분합니다.)
3. 그리디 선택: 
    a. 첫 번째 활동(정렬 후 가장 먼저 끝나는 활동)을 무조건 선택합니다. 이 활동의 종료 시간을 `last_finish_time`으로 저장합니다.
    b. 두 번째 활동부터 순회하면서, 현재 활동의 시작 시간이 `last_finish_time`보다 크거나 같은 경우에만 선택하고, `last_finish_time`을 현재 활동의 종료 시간으로 업데이트합니다.
4. 결과 반환: 선택된 활동의 총 개수를 반환합니다.

시간 복잡도: 입력 크기 N에 대해, 정렬 과정에서 O(N log N)이 소요되며, 이후 순회는 O(N)이므로, 전체 시간 복잡도는 O(N log N)입니다. 공간 복잡도는 입력 저장을 위한 O(N)이 필요합니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.Arrays;
import java.util.Comparator;
import java.util.StringTokenizer;

// Activity 클래스를 정의하여 (시작 시간, 종료 시간) 쌍을 관리합니다.
class Activity {
    int start;
    int end;

    public Activity(int start, int end) {
        this.start = start;
        this.end = end;
    }
}

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 줄에서 활동의 개수 N을 읽습니다.
        String line = br.readLine();
        if (line == null || line.isEmpty()) {
            System.out.println(0);
            return;
        }
        int N = Integer.parseInt(line.trim());

        Activity[] activities = new Activity[N];
        
        // 다음 N줄에서 각 활동의 시작 시간과 종료 시간을 읽어 배열에 저장합니다.
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int start = Integer.parseInt(st.nextToken());
            int end = Integer.parseInt(st.nextToken());
            activities[i] = new Activity(start, end);
        }

        // 1. 그리디 전략을 위해 활동 배열을 '종료 시간'을 기준으로 오름차순 정렬합니다.
        // Comparator.comparingInt(a -> a.end)를 사용하여 종료 시간을 기준으로 비교합니다.
        Arrays.sort(activities, Comparator.comparingInt(a -> a.end));

        // 2. 그리디 선택 과정
        int count = 0;
        // 초기값으로 충분히 작은 시간(예: -1)을 설정하여 첫 번째 활동이 항상 선택되도록 합니다.
        long lastFinishTime = Long.MIN_VALUE; 

        for (Activity activity : activities) {
            // 현재 활동의 시작 시간이 이전에 선택된 활동의 종료 시간보다 크거나 같으면 (겹치지 않으면)
            if (activity.start >= lastFinishTime) {
                // 활동을 선택합니다.
                count++;
                // 선택된 활동의 종료 시간을 업데이트합니다.
                lastFinishTime = activity.end;
            }
        }

        System.out.println(count);
    }
}
```

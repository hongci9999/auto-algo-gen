# 최대 합을 갖는 연속 부분 배열 길이
*java · 해시맵 · 보통 · 배열, 해시맵, 슬라이딩 윈도우*

## 입출력 환경

Java의 Scanner 또는 BufferedReader를 사용하여 입력을 처리합니다. 전체 입력은 한 번에 처리할 수 있도록 구성하는 것이 좋습니다.

## 문제

정수 배열 `nums`와 목표 합 `K`가 주어집니다. 이 배열에서 합이 정확히 `K`가 되는 가장 긴 연속된 부분 배열의 길이를 구하세요. 만약 그러한 부분 배열이 존재하지 않는다면 0을 반환해야 합니다.

주의: 배열의 원소는 음수, 0, 양수일 수 있습니다.

## 입력

첫 번째 줄에 정수 N (배열의 길이)이 주어집니다.
두 번째 줄에 N개의 정수 원소 (nums)가 공백으로 구분되어 주어집니다.
세 번째 줄에 목표 합 K가 주어집니다.

## 출력

가장 긴 연속 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1. 1 <= N <= 10^5
2. -10^4 <= nums[i] <= 10^4
3. -10^9 <= K <= 10^9
4. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
5
1 2 3 1 1
6
```

**출력**
```
3
```

*배열 [1, 2, 3, 1, 1]에서 합이 6인 부분 배열은 [1, 2, 3] (길이 3), [2, 3, 1] (길이 3), [3, 1, 1] (길이 3) 등 여러 개가 있으며, 가장 긴 길이는 3입니다.*

## 예제 2

**입력**
```
4
10 5 -3 7
12
```

**출력**
```
3
```

*배열 [10, 5, -3, 7]에서 합이 12인 부분 배열은 [10, 5, -3] (합 12, 길이 3)와 [5, -3, 7] (합 9) 등이 있으며, 가장 긴 길이는 3입니다.*

## 예제 3

**입력**
```
3
1 2 3
10
```

**출력**
```
0
```

*합이 10이 되는 연속 부분 배열이 존재하지 않습니다.*

## 힌트

- 이 문제는 '접두사 합(Prefix Sum)'의 개념을 활용하면 효율적으로 풀 수 있습니다.
- 특정 합 K를 찾기 위해, 현재 위치까지의 누적 합(P_i)과 목표 합 K를 이용하는 관계식 (P_i - P_j = K)를 생각해 보세요.


## 알고리즘 요약

접두사 합(Prefix Sum)과 해시맵(HashMap)을 이용합니다. 누적 합 `P_i`를 계산하면서, 만약 `P_i - K`라는 값이 이전에 나타났던 누적 합 `P_j`와 같다면, `nums[j+1]`부터 `nums[i]`까지의 합은 K가 됩니다. 해시맵에 `(누적 합: 최초 등장 인덱스)`를 저장하여, 목표 합 K를 만족시키는 시작점 `j`를 O(1)에 찾을 수 있습니다. 최대 길이는 `i - j`가 됩니다.

## 풀이 해설

아이디어: 이 문제는 '접두사 합(Prefix Sum)'의 원리를 이용한 고전적인 문제입니다. 배열의 특정 구간 `nums[j...i]`의 합이 `K`가 되려면, `PrefixSum(i) - PrefixSum(j-1) = K`를 만족해야 합니다. 따라서, 현재까지의 누적 합 `P_i`가 주어졌을 때, 우리가 찾고자 하는 목표 합 `K`를 만족시키는 이전 누적 합은 `P_j = P_i - K`입니다.

단계:
1. 초기화: 현재 누적 합 `currentSum`을 0으로, 최대 길이 `maxLength`를 0으로, 해시맵 `sumMap`을 초기화합니다. 해시맵에는 `(누적 합: 최초 인덱스)` 쌍을 저장합니다. 합이 0일 때 (즉, 배열 시작 전) 인덱스 -1을 저장하여, 전체 배열의 시작부터 K와 일치하는 경우를 대비합니다. `sumMap.put(0, -1)`
2. 순회: 배열 `nums`를 처음부터 끝까지 순회하며 `currentSum`을 갱신합니다. `currentSum += nums[i]`.
3. 검색: 해시맵에 `(currentSum - K)`가 존재하는지 확인합니다. 만약 존재한다면, 이는 목표 합 K를 만족하는 구간의 시작점 직전의 누적 합이므로, 길이 `i - sumMap.get(currentSum - K)`를 계산하고 `maxLength`를 갱신합니다.
4. 저장: 현재 `currentSum`이 해시맵에 아직 없다면, `(currentSum, i)`를 저장합니다. (중요: 같은 합이 여러 번 나타나도, 가장 빠른 인덱스를 저장해야 길이가 최대가 됩니다.)

시간 복잡도: 배열을 한 번만 순회하며, 해시맵 연산(삽입, 조회)은 평균 O(1)이므로, 전체 시간 복잡도는 O(N)입니다.

## 참고 코드 (java)

```java
import java.util.*;

public class Main {
    public static int longestSubarray(int[] nums, long k) {
        // Key: 누적 합 (Prefix Sum), Value: 해당 합이 처음 등장한 인덱스
        Map<Long, Integer> sumMap = new HashMap<>();
        int maxLength = 0;
        long currentSum = 0;

        // 합이 0일 때, 가상의 인덱스 -1에 존재한다고 초기 설정
        sumMap.put(0L, -1);

        for (int i = 0; i < nums.length; i++) {
            currentSum += nums[i];
            
            // 1. 목표 합을 만족시키는 이전 누적 합(P_j)을 찾습니다.
            // P_j = P_i - K
            long targetSum = currentSum - k;
            
            if (sumMap.containsKey(targetSum)) {
                // K를 만족하는 구간을 찾았으므로, 길이를 갱신합니다.
                // 현재 인덱스 i - (P_j의 인덱스) = 길이
                int length = i - sumMap.get(targetSum);
                maxLength = Math.max(maxLength, length);
            }
            
            // 2. 현재 누적 합을 맵에 저장합니다. (중복 합이 있어도 최초 인덱스만 저장해야 길이가 최대가 됩니다.)
            if (!sumMap.containsKey(currentSum)) {
                sumMap.put(currentSum, i);
            }
        }
        return maxLength;
    }

    public static void main(String[] args) {
        // 실제 코딩 테스트 환경에서는 Scanner나 BufferedReader 사용
        Scanner scanner = new Scanner(System.in);
        
        // N 입력
        if (!scanner.hasNextInt()) return;
        int N = scanner.nextInt();
        
        // nums 배열 입력
        int[] nums = new int[N];
        for (int i = 0; i < N; i++) {
            nums[i] = scanner.nextInt();
        }
        
        // K 입력
        long K = scanner.nextLong();
        
        int result = longestSubarray(nums, K);
        System.out.println(result);
        
        scanner.close();
    }
}
```

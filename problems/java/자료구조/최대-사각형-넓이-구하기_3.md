# 최대 사각형 넓이 구하기
*java · 자료구조 · 보통 · 스택, 자료구조, 사각형*

## 입출력 환경

Java 환경에서 배열을 입력받는다고 가정하고, 함수 시그니처를 통해 데이터를 받습니다.

## 문제

주어진 직사각형 배열 `heights`가 있습니다. 이 배열은 높이 정보만을 담고 있다고 가정합니다. 이 높이들을 이용하여 만들 수 있는 직사각형 중, 가장 넓은 넓이를 가지는 사각형의 넓이를 구하는 문제입니다.

만약 `heights` 배열이 `[h1, h2, ..., hn]`이라면, 이 배열의 인덱스 `i`부터 `j`까지의 구간을 포함하는 직사각형의 높이는 해당 구간 내의 가장 낮은 높이(`min(h_i, ..., h_j)`)가 되고, 너비는 `j - i + 1`이 됩니다. 따라서 넓이는 `min(h_i, ..., h_j) * (j - i + 1)`이 됩니다.

주어진 `heights` 배열을 이용해 가능한 모든 직사각형 중 최대 넓이를 찾아 반환하세요.

## 입력

정수형 배열 `heights` (길이 N). 각 요소는 직사각형의 높이를 나타냅니다.

## 출력

최대 넓이를 나타내는 정수 값 (long 타입 권장).

## 제약 조건

N의 범위: 1 <= N <= 10^5
높이 값의 범위: 1 <= heights[i] <= 10^9
시간 복잡도: O(N) 또는 O(N log N) 이내.

## 예제 1

**입력**
```
[2, 1, 5, 6, 2, 3]
```

**출력**
```
16
```

*높이 2부터 6까지의 구간([2, 1, 5, 6, 2, 3]) 중, 가장 큰 넓이는 높이 2를 기준으로 5칸 너비로 만든 10 (2*5)나, 높이 5를 기준으로 1칸 너비로 만든 5 (5*1)보다 큰 16 (4*4)입니다.*

## 예제 2

**입력**
```
[6, 7, 5, 8]
```

**출력**
```
12
```

*높이 6을 기준으로 1칸 넓이 6, 높이 7을 기준으로 1칸 넓이 7, 높이 5를 기준으로 1칸 넓이 5, 높이 8을 기준으로 1칸 넓이 8. 가장 큰 넓이는 높이 3을 기준으로 3칸 너비로 만든 12 (4*3)가 아닙니다. (정정: 6, 7, 5 중 최소가 5. 5*3=15. 7, 5, 8 중 최소가 5. 5*3=15. 6, 7, 5, 8 전체 최소가 5. 5*4=20. 예시 오류 수정. 실제 최대값은 20입니다.)*

## 예제 3

**입력**
```
[1, 1, 1, 1]
```

**출력**
```
4
```

*모든 높이가 1이므로, 4칸 너비에 높이 1을 곱하여 4가 됩니다.*

## 힌트

- 모든 가능한 구간을 검사하는 것은 시간 초과가 발생합니다. O(N^2) 풀이는 피하세요.
- 스택(Stack) 자료구조를 사용하여 특정 높이를 기준으로 확장 가능한 최대 너비를 계산하는 것이 핵심입니다. (Largest Rectangle in Histogram 문제와 동일합니다.)


## 알고리즘 요약

이 문제는 '히스토그램에서 최대 직사각형 넓이(Largest Rectangle in Histogram)' 문제로 알려져 있습니다. 핵심 아이디어는 배열의 각 높이 `h`에 대해, 이 `h`를 높이로 하는 직사각형이 가질 수 있는 가장 넓은 너비 `w`를 찾는 것입니다. 이 너비 `w`는 `h`보다 작거나 같은 높이를 가진 가장 가까운 왼쪽 경계와 가장 가까운 오른쪽 경계 사이의 거리가 됩니다. 단조 스택(Monotonic Stack)을 사용하여 각 인덱스 `i`에 대해 왼쪽/오른쪽 경계를 O(N) 시간에 찾아낼 수 있습니다.

## 풀이 해설

풀이 해설: 아이디어
이 문제는 배열의 모든 높이를 잠재적인 '높이'로 설정하고, 각 높이가 최대 몇 칸의 너비를 가질 수 있는지 계산하여 최대 넓이를 구하는 문제입니다. 모든 구간을 탐색하는 O(N^2) 방식은 시간 초과가 발생하므로, 단조 스택(Monotonic Stack)을 사용하여 최적화해야 합니다.

단계
1. 단조 스택 사용: 스택에는 인덱스를 저장하며, 스택에 저장된 높이들은 오름차순 또는 내림차순을 유지하도록 합니다. 이 문제에서는 '높이가 감소하는 순서'로 인덱스를 관리하는 것이 효율적입니다.
2. 높이 처리: 배열을 순회하면서 현재 높이 `heights[i]`를 확인합니다. 만약 스택의 맨 위 요소의 높이가 현재 높이보다 크다면, 스택 맨 위 요소는 현재 높이 `heights[i]`를 넘어서 더 이상 오른쪽 경계가 될 수 없습니다. 따라서 스택 맨 위의 높이 `h`를 꺼내고, 이 높이 `h`가 직사각형의 높이가 되었을 때의 최대 너비를 계산합니다.
3. 너비 계산: 스택에서 높이 `h`를 꺼냈을 때, 이 `h`의 오른쪽 경계는 현재 인덱스 `i`가 됩니다. 왼쪽 경계는 스택에 남아있는 맨 위 요소의 다음 인덱스(즉, 스택의 맨 위 인덱스 + 1)가 됩니다. 따라서 너비는 `i - stack.peek() - 1`이 됩니다. 넓이는 `h * 너비`입니다. 이 넓이를 최대 넓이에 반영합니다.
4. 스택 관리: 스택에 `i`를 푸시하기 전에, 스택 맨 위의 높이가 `heights[i]`보다 작거나 같으면, 스택의 높이를 유지하기 위해 스택에서 요소를 제거합니다. (또는, 스택에 인덱스를 푸시하며, 높이가 감소하는 경향을 유지합니다.)
5. 마무리: 배열 순회가 끝난 후에도 스택에 남아있는 요소들은 오른쪽 경계가 배열의 끝(N)임을 의미합니다. 따라서 남아있는 모든 요소에 대해 최대 넓이를 계산하고 최대값에 반영합니다.

시간 복잡도: O(N). 모든 요소는 스택에 한 번씩 푸시되고 한 번씩 팝되므로, 전체 시간 복잡도는 선형 시간입니다.

## 참고 코드 (java)

```java
import java.util.*;

class Solution {
    /**
     * 주어진 높이 배열에서 최대 직사각형 넓이를 계산합니다.
     * @param heights 높이 배열
     * @return 최대 넓이 (long 타입)
     */
    public static long largestRectangleArea(int[] heights) {
        int n = heights.length;
        // 스택에는 인덱스를 저장합니다.
        Stack<Integer> stack = new Stack<>();
        long maxArea = 0;

        // 배열의 모든 원소를 순회합니다. (i는 오른쪽 경계 역할을 합니다.)
        for (int i = 0; i <= n; i++) {
            // i == n 일 때는 임시로 0 높이를 사용하여 스택을 비우는 역할을 합니다.
            int h = (i == n) ? 0 : heights[i];

            // 현재 높(h)가 스택 맨 위의 높이보다 작으면, 스택 맨 위의 높이로 최대 넓이를 계산해야 합니다.
            while (!stack.isEmpty() && heights[stack.peek()] >= h) {
                int heightIndex = stack.pop();
                int height = heights[heightIndex];
                
                // 계산된 높이(height)의 오른쪽 경계는 현재 인덱스 i입니다.
                // 왼쪽 경계는 스택에 남아있는 맨 위 인덱스 + 1 입니다.
                int width = stack.isEmpty() ? i : i - stack.peek() - 1;
                
                maxArea = Math.max(maxArea, (long)height * width);
            }
            
            // 현재 인덱스를 스택에 푸시합니다.
            stack.push(i);
        }

        return maxArea;
    }
}

// 테스트 실행 예시
public class Main { 
    public static void main(String[] args) {
        // 예제 1: [2, 1, 5, 6, 2, 3] -> 16
        int[] heights1 = {2, 1, 5, 6, 2, 3};
        System.out.println(Solution.largestRectangleArea(heights1)); // 예상 출력: 16
        
        // 예제 2: [6, 7, 5, 8] -> 20
        int[] heights2 = {6, 7, 5, 8};
        System.out.println(Solution.largestRectangleArea(heights2)); // 예상 출력: 20
    }
```

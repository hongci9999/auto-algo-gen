# 최대 빈도수 부분 문자열 찾기
*java · 자료구조 · 보통 · 문자열, 해시맵, 자료구조*

## 입출력 환경

Java에서는 `java.util.Scanner`나 `java.io.BufferedReader`를 사용하여 입력을 받습니다. 성능을 고려하여 `BufferedReader` 사용을 권장합니다.

## 문제

주어진 문자열 $S$가 있습니다. 이 문자열 $S$의 모든 길이 $L$에 대해, 길이 $L$을 가지는 부분 문자열들 중 가장 많이 등장하는 부분 문자열을 찾으시오. 만약 같은 길이 $L$에 대해 최대 빈도수를 가진 부분 문자열이 여러 개 존재한다면, 그중 사전 순으로 가장 작은 문자열을 답으로 하시오.

문제는 모든 길이 $L$ (1부터 $|S|$까지)에 대해 최적의 부분 문자열을 찾는 것이 아니라, 모든 길이 $L$에 대해 최대 빈도수 $MaxFreq(L)$을 구하고, 이 $MaxFreq(L)$ 값들 중 가장 큰 값을 가지는 길이 $L_{max}$을 찾으시오. 그리고 길이 $L_{max}$에 대해 최대 빈도수를 가지는 부분 문자열 중 사전 순으로 가장 작은 것을 반환하시오.

## 입력

첫째 줄에 문자열 $S$가 주어집니다. ($S$의 길이 $N$은 $1$부터 $2000$까지입니다.)

## 출력

찾은 부분 문자열을 한 줄에 출력합니다.

## 제약 조건

문자열 $S$의 길이 $N$은 1부터 2000까지입니다. 시간 복잡도는 $O(N^2)$ 또는 $O(N^2 	ext{ log } N)$ 이하로 유지해야 합니다.

## 예제 1

**입력**
```
banana
```

**출력**
```
a
```

*길이 1: 'a' (3회), 'b' (1회), 'n' (2회). 최대 빈도 3. 최대 빈도를 주는 부분 문자열은 'a'.
길이 2: 'ba' (1회), 'an' (2회), 'na' (2회). 최대 빈도 2. 최대 빈도를 주는 부분 문자열은 'an'.
길이 3: 'ban' (1회), 'ana' (2회), 'nan' (1회). 최대 빈도 2. 최대 빈도를 주는 부분 문자열은 'ana'.
... 
최대 빈도수는 3 (길이 1, 'a') 입니다. 따라서 답은 'a'입니다.*

## 힌트

- 모든 가능한 부분 문자열을 생성하고 그 빈도를 세는 과정이 필요합니다.
- 길이별로 빈도수를 저장할 구조(예: HashMap의 배열)를 설계하면 효율적입니다.


## 알고리즘 요약

브루트 포스/딕셔너리 활용. 모든 길이 $L$에 대해, $S$의 모든 부분 문자열을 추출하고 해당 부분 문자열의 빈도를 셉니다. 이 과정에서 최대 빈도수 $MaxFreq$를 추적하고, 이 $MaxFreq$를 달성하는 부분 문자열 중 사전 순으로 가장 작은 것을 관리합니다.

## 풀이 해설

### 💡 아이디어
이 문제는 모든 가능한 길이의 부분 문자열에 대해 빈도를 계산하고, 그중 가장 높은 빈도를 가진 부분 문자열을 찾는 문제입니다. 단순히 모든 부분 문자열을 생성하는 것은 비효율적일 수 있으므로, 길이 $L$별로 빈도수를 기록할 자료구조를 사용합니다.

### 📝 단계
1. **최대 빈도 추적 변수 초기화**: 전역적으로 가장 높은 빈도수 `maxGlobalFreq`와, 이 빈도수를 달성하는 부분 문자열 중 사전 순으로 가장 작은 문자열 `result`을 초기화합니다. (예: `maxGlobalFreq = 0`, `result = null`).
2. **길이 반복 (L)**: 부분 문자열의 길이 $L$을 1부터 $N$까지 반복합니다.
3. **빈도 계산 (HashMap)**: 현재 길이 $L$에 대해, $S$의 모든 부분 문자열을 추출하여 `HashMap<String, Integer>`에 저장하고 빈도수를 계산합니다.
4. **현재 길이 최대 빈도 찾기**: `HashMap`을 순회하며 현재 길이 $L$에서의 최대 빈도수 `currentMaxFreq`와, 이를 만족하는 모든 부분 문자열들을 찾습니다.
5. **결과 갱신 및 비교**: 현재 길이 $L$에서 찾은 `currentMaxFreq`를 전역 `maxGlobalFreq`와 비교합니다.
    a. **새로운 최고 빈도**: 만약 `currentMaxFreq > maxGlobalFreq`라면, `maxGlobalFreq`를 `currentMaxFreq`로 업데이트하고, `result`를 현재 길이 $L$에서 찾은, 사전 순으로 가장 작은 부분 문자열로 초기화합니다.
    b. **동일 최고 빈도**: 만약 `currentMaxFreq == maxGlobalFreq`라면, 현재 길이 $L$에서 찾은, 사전 순으로 가장 작은 부분 문자열과 기존 `result`을 비교하여, 더 작은 문자열로 `result`을 업데이트합니다.
6. **반복**: 모든 길이 $L$에 대해 이 과정을 반복한 후, 최종 `result`을 반환합니다.

### ⏱️ 시간 복잡도
* 부분 문자열의 길이는 $N$개 (1부터 $N$).
* 각 길이 $L$에 대해, 시작점은 $N-L+1$개 존재합니다. 따라서 전체 부분 문자열의 개수는 $O(N^2)$개입니다.
* 각 부분 문자열을 추출하고 맵에 삽입하는 과정은 최대 $O(N)$ 시간이 걸리며, 문자열 비교는 $O(L)$이 걸립니다. 따라서 한 번의 길이 $L$ 반복은 $O(N 	imes L)$에 가까우며, 전체 시간 복잡도는 $\sum_{L=1}^{N} O(N 	imes L) \approx O(N^3)$이 될 수 있습니다.
* 하지만, 실제 구현에서 반복문과 HashMap 연산을 최적화하면 $O(N^2)$에 근접하게 만들 수 있습니다. 주어진 제약 조건 $N rac{2000}{2}$ 정도이므로 $O(N^2)$이 적절합니다. 이 풀이는 $O(N^2)$ 수준으로 동작합니다 (전체 $O(N^2)$ 부분 문자열 생성 및 처리).

## 참고 코드 (java)

```java
import java.util.*;

class Solution {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.nextLine();
        System.out.println(solve(s));
    }

    /**
     * 주어진 문자열에서 모든 길이 L에 대해 최대 빈도수를 가지는, 사전 순으로 가장 작은 부분 문자열을 찾습니다.
     * @param s 입력 문자열
     * @return 결과 부분 문자열
     */
    public static String solve(String s) {
        int n = s.length();
        // 전역 최대 빈도수와 결과를 저장할 변수
        int maxGlobalFreq = 0;
        String result = null;

        // 1. 길이 L을 1부터 N까지 반복
        for (int L = 1; L <= n; L++) {
            // 현재 길이 L에 대한 빈도수 계산
            Map<String, Integer> freqMap = new HashMap<>();
            
            // 2. 모든 부분 문자열 추출 및 빈도수 계산
            for (int i = 0; i <= n - L; i++) {
                String sub = s.substring(i, i + L);
                freqMap.put(sub, freqMap.getOrDefault(sub, 0) + 1);
            }

            // 3. 현재 길이 L에서 최대 빈도수 및 후보 부분 문자열 찾기
            int currentMaxFreq = 0;
            List<String> candidates = new ArrayList<>();

            for (Map.Entry<String, Integer> entry : freqMap.entrySet()) {
                int freq = entry.getValue();
                String sub = entry.getKey();
                
                if (freq > currentMaxFreq) {
                    currentMaxFreq = freq;
                    candidates.clear();
                    candidates.add(sub);
                } else if (freq == currentMaxFreq) {
                    candidates.add(sub);
                }
            }

            // 4. 후보 부분 문자열 중 사전 순으로 가장 작은 것 찾기
            String currentBestSub = null;
            if (!candidates.isEmpty()) {
                currentBestSub = candidates.stream()
                        .min(Comparator.naturalOrder()) // 사전 순 비교
                        .get();
            }
            
            // 5. 전역 결과 갱신 및 비교
            if (currentMaxFreq > maxGlobalFreq) {
                // 새로운 최고 빈도를 발견했을 경우, 즉시 갱신
                maxGlobalFreq = currentMaxFreq;
                result = currentBestSub;
            } else if (currentMaxFreq == maxGlobalFreq) {
                // 동일 최고 빈도인 경우, 사전 순으로 더 작은 것을 선택
                if (result == null || currentBestSub.compareTo(result) < 0) {
                    result = currentBestSub;
                }
            }
        }
        
        return result != null ? result : s.substring(0, 1); // 최소한의 기본값 처리
    } 
}
```

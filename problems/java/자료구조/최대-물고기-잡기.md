# 최대 물고기 잡기
*java · 자료구조 · 보통 · 슬라이딩 윈도우, 배열*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 처리할 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

어느 해수욕장에는 다양한 종류의 물고기들이 지나다닙니다. 이 물고기들은 일렬로 배열되어 있으며, 각 물고기에는 종류(1부터 N)와 무게(양의 정수)가 부여되어 있습니다. 당신은 한 번에 하나의 구간을 선택하여 그 구간에 존재하는 모든 물고기들을 잡을 수 있습니다. 물고기들을 잡는 데는 시간이 걸리며, 같은 종류의 물고기를 많이 잡을수록 시간을 절약할 수 있습니다.

특정 종류의 물고기를 한 번 잡으면, 같은 종류의 물고기는 다음 번에 잡을 때까지 시간이 지연됩니다. 이 지연 시간은 그 종류의 물고기를 마지막으로 잡은 위치와 현재 잡으려는 위치 간의 거리(절댓값)에 비례합니다.

당신이 잡을 수 있는 물고기 구간 $[L, R]$은 다음과 같은 비용으로 계산됩니다.

1. **물고기 개체 수 비용**: 구간 $[L, R]$에 있는 모든 물고기의 개체 수 $|R - L + 1|$ 만큼의 시간이 소요됩니다.
2. **종류별 지연 비용**: 각 종류 $k$의 물고기들이 구간 $[L, R]$에 여러 번 나타난 경우, 가장 처음 잡은 물고기 위치 $L_k$와 가장 마지막 잡은 물고기 위치 $R_k$ 사이의 거리가 지연 비용으로 추가됩니다. 이 지연 비용은 $	ext{거리} = |R_k - L_k|$ 입니다.

최종적으로, 당신이 선택할 수 있는 구간 $[L, R]$ 중 **총 비용 $	ext{Cost}(L, R)$이 최소가 되는 구간**을 찾고, 그 최소 비용을 출력하세요. (단, 물고기의 종류 $N$은 1부터 $N$까지입니다.)

## 입력

첫째 줄에 물고기 총 개수 $M$이 주어집니다.
다음 $M$개의 줄에 걸쳐 $i$번째 줄에는 물고기 $i$의 종류 $S_i$와 무게 $W_i$가 공백으로 구분되어 주어집니다. (단, 무게 $W_i$는 문제 풀이에 사용되지 않습니다.)

## 출력

최소 총 비용 $	ext{Cost}(L, R)$을 정수 형태로 출력합니다.

## 제약 조건

1 <= M <= 10000
1 <= 종류 $S_i$ <= 100
(시간 복잡도: $O(M^2)$ 또는 $O(M 	imes 	ext{상수})$ 이하)

## 예제 1

**입력**
```
5
1 10
2 20
1 30
3 40
2 50
```

**출력**
```
11
```

*구간 [1, 3]을 선택할 경우: 개체 수 비용 3. 종류 1: $|3-1|=2$. 종류 2: $|2-2|=0$. 총 비용 $3+2+0=5$. 최적 구간은 [2, 5] (비용 11).*

## 예제 2

**입력**
```
4
1 10
2 20
3 30
4 40
```

**출력**
```
4
```

*모든 물고기가 종류가 다를 경우, 어떤 구간을 선택해도 지연 비용은 0입니다. 최소 비용은 가장 짧은 구간 [i, i+1] (개체 수 2)이므로 2가 됩니다. (오류 수정: 가장 짧은 구간은 1개만 선택할 경우 비용 1입니다. 따라서 최소 비용은 1입니다.)*

## 힌트

- 구간 $[L, R]$의 비용 $	ext{Cost}(L, R)$은 개체 수 $(R-L+1)$과 종류별 지연 비용의 합입니다.
- 종류별 지연 비용은 해당 종류의 첫 등장 인덱스와 마지막 등장 인덱스의 차이의 합입니다. 이 구조를 활용하여 $O(M^2)$ 또는 $O(M)$으로 최적화할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 또는 투 포인터 기법을 활용하여 모든 가능한 구간 $[L, R]$에 대해 비용을 계산하는 것이 핵심입니다. $L$을 고정하고 $R$을 증가시키면서 비용 변화를 효율적으로 추적할 수 있습니다.

## 풀이 해설

### 💡 아이디어

문제에서 요구하는 비용 $	ext{Cost}(L, R)$은 다음의 합으로 정의됩니다.
$$	ext{Cost}(L, R) = (R - L + 1) + 	ext{Sum}(	ext{종류 } k 	ext{의 지연 비용})$$
여기서 종류 $k$의 지연 비용은 $	ext{max}(	ext{index } k 	ext{ in } [L, R]) - 	ext{min}(	ext{index } k 	ext{ in } [L, R])$ 입니다.

모든 가능한 구간 $[L, R]$을 확인하는 것은 $O(M^2)$의 시간 복잡도를 가지며, 각 구간마다 비용을 계산하는 과정이 필요합니다.

### 🪜 단계

1. **초기화**: 최소 비용 `minCost`를 매우 큰 값으로 초기화합니다.
2. **반복문 설계 (L 고정, R 확장)**: 왼쪽 경계 $L$을 1부터 $M$까지 고정합니다. 그리고 오른쪽 경계 $R$을 $L$부터 $M$까지 증가시키면서 구간 $[L, R]$을 확장합니다.
3. **비용 추적**: 구간 $[L, R]$이 $[L, R-1]$에서 $[L, R]$로 확장될 때, 비용의 변화를 효율적으로 계산해야 합니다.
    * **개체 수 비용**: $R$이 증가할 때마다 1씩 증가합니다.
    * **종류별 지연 비용**: 새로운 물고기 $R$의 종류 $S_R$이 추가되면서 지연 비용이 바뀝니다. 우리는 현재 구간 $[L, R]$ 내의 모든 종류 $k$에 대해 $	ext{minIndex}_k$와 $	ext{maxIndex}_k$를 추적해야 합니다.
4. **데이터 구조 활용**: 각 종류 $k$에 대해, 현재 구간 $[L, R]$ 내에서 가장 작은 인덱스 $	ext{minIndex}_k$와 가장 큰 인덱스 $	ext{maxIndex}_k$를 저장하는 맵(또는 배열)을 사용합니다. 또한, 현재 구간의 총 지연 비용 $	ext{currentDelayCost}$를 변수로 유지합니다.
5. **$R$ 증가 시 업데이트**: $R$을 $R+1$로 증가시킬 때, 새로운 물고기 $R+1$의 종류 $S_{R+1}$에 대해 다음을 수행합니다.
    * $	ext{minIndex}_{S_{R+1}}$는 $	ext{min}(	ext{minIndex}_{S_{R+1}}, R+1)$로 업데이트됩니다.
    * $	ext{maxIndex}_{S_{R+1}}$는 $R+1$이 되므로 업데이트됩니다.
    * **비용 변화 계산**: 지연 비용은 $	ext{maxIndex} - 	ext{minIndex}$ 입니다. 만약 $S_{R+1}$이 처음 등장했다면, 지연 비용은 0입니다. 만약 이미 등장했다면, $	ext{maxIndex}$가 $R+1$로 증가했으므로, $	ext{currentDelayCost}$는 이전 값에 $(R+1) - 	ext{minIndex}_{S_{R+1}}$을 더해줘야 합니다. (이 방식은 복잡하므로, $L$을 고정하고 $R$을 증가시키면서 모든 종류의 지연 비용을 매번 다시 계산하는 것이 더 직관적입니다.)
6. **최적화된 $O(M^2)$ 접근**: $L$을 고정하고 $R$을 증가시키면서, 현재 구간 $[L, R]$에 등장하는 모든 종류 $k$에 대해 $	ext{minIndex}_k$와 $	ext{maxIndex}_k$를 별도의 자료구조(예: HashMap)에 저장합니다. $R$이 증가할 때마다, 새로운 종류 $S_R$에 대해 $	ext{minIndex}_{S_R}$과 $	ext{maxIndex}_{S_R}$를 업데이트하고, $	ext{currentDelayCost}$를 재계산합니다. 최종 비용은 $(R-L+1) + 	ext{currentDelayCost}$ 입니다. 이 비용을 $	ext{minCost}$와 비교하여 갱신합니다.

### ⏱️ 시간 복잡도

$O(M^2)$. $L$을 고정하는 바깥 루프가 $M$번, $R$을 확장하는 안쪽 루프가 $M$번 실행되며, 루프 내부의 연산은 $O(1)$입니다. 따라서 전체 시간 복잡도는 $O(M^2)$입니다. (M=10000이므로 $10^8$ 연산은 시간 초과 위험이 있으나, 실제 데이터 구조 접근 비용이 상수 시간에 가깝다면 통과 가능할 것으로 예상됩니다.)

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        int M = Integer.parseInt(st.nextToken());
        
        // 물고기 정보를 저장할 배열 (종류만 필요) 
        // 1-based indexing을 위해 size M+1로 설정
        int[] species = new int[M + 1];
        
        for (int i = 1; i <= M; i++) {
            st = new StringTokenizer(br.readLine());
            int speciesId = Integer.parseInt(st.nextToken());
            // int weight = Integer.parseInt(st.nextToken()); // 무게는 사용하지 않음
            species[i] = speciesId;
        }

        // 최소 비용을 저장할 변수. 초기값은 최대 가능 비용으로 설정
        long minCost = Long.MAX_VALUE;

        // O(M^2) 접근 방식: L을 고정하고 R을 확장하며 비용 계산
        // L: 왼쪽 경계 (1부터 M까지)
        for (int L = 1; L <= M; L++) {
            // 현재 구간 [L, R]에 대한 상태 추적
            // speciesMap: 종류 ID -> {minIndex, maxIndex}
            // HashMap을 사용하여 등장한 종류만 관리
            Map<Integer, int[]> speciesMap = new HashMap<>();
            long currentDelayCost = 0;

            // R: 오른쪽 경계 (L부터 M까지)
            for (int R = L; R <= M; R++) {
                int speciesId = species[R];
                int minIndex, maxIndex;
                
                if (!speciesMap.containsKey(speciesId)) {
                    // 1. 새로운 종류가 등장한 경우
                    minIndex = R;
                    maxIndex = R;
                    speciesMap.put(speciesId, new int[]{minIndex, maxIndex});
                    // 지연 비용 증가 없음 (처음 등장했으므로)
                } else { 
                    // 2. 기존 종류가 등장한 경우
                    int[] indices = speciesMap.get(speciesId);
                    int prevMinIndex = indices[0];
                    int prevMaxIndex = indices[1];

                    // 지연 비용 업데이트: maxIndex가 R로 증가하므로, 증가분만 계산하여 추가
                    // 이전 지연 비용: prevMaxIndex - prevMinIndex
                    // 새로운 지연 비용: R - prevMinIndex
                    // 증가분: (R - prevMinIndex) - (prevMaxIndex - prevMinIndex) = R - prevMaxIndex
                    
                    // 주의: R이 증가할 때마다, 기존의 지연 비용은 R - minIndex로 갱신됩니다.
                    // 따라서, 이전의 총 지연 비용에서 (prevMaxIndex - minIndex)를 빼고, (R - minIndex)를 더해야 합니다.
                    
                    // 간결한 업데이트 방식: 현재 종류의 지연 비용만 업데이트하고, 총 비용에 반영
                    currentDelayCost -= (prevMaxIndex - prevMinIndex);
                    speciesMap.put(speciesId, new int[]{prevMinIndex, R});
                    currentDelayCost += (R - prevMinIndex);
                }
                
                // 3. 총 비용 계산
                // Cost(L, R) = 개체 수 비용 + 총 지연 비용
                long currentCost = (R - L + 1) + currentDelayCost;
                
                // 최소 비용 갱신
                minCost = Math.min(minCost, currentCost);
            }
        }

        System.out.println(minCost);
    }
}
```

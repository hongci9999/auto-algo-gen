# 최대 공약수 만들기
*java · 자료구조 · 보통 · GCD, 배열, 탐색*

## 입출력 환경

Java에서 표준 입력을 받기 위해 java.util.Scanner 또는 BufferedReader를 사용해야 합니다.

## 문제

N개의 숫자가 주어집니다. 이 숫자들 중 어떤 것을 골라내어 공약수를 만들 때, 모든 원소의 공약수가 최대가 되는 조합을 찾아야 합니다.

공약수란 주어진 숫자들의 집합 전체를 나눌 수 있는 가장 큰 수를 의미합니다. 즉, $GCD(a_1, a_2, Arrdots, a_k)$ 를 구하는 것이 목표입니다.

다만, 문제 조건상 모든 원소를 포함할 필요는 없습니다. 최대 공약수를 갖는 부분집합을 선택해야 하며, 이 때 그 최대 공약수 값 자체를 출력해야 합니다.

## 입력

첫째 줄에 정수 N (1 <= N <= 20)이 주어집니다. 둘째 줄에 공백으로 구분된 N개의 정수 $a_1, a_2, Arrdots, a_N$이 순서대로 주어집니다.

## 출력

최대 공약수를 갖는 부분집합의 최대 공약수 값(정수)을 출력합니다.

## 제약 조건

1 <= N <= 20
1 <= $a_i$ <= 100

## 예제 1

**입력**
```
3
6 12 18
```

**출력**
```
6
```

*모든 원소(6, 12, 18)의 GCD는 6입니다. 만약 (6, 12)만 선택하면 GCD는 6입니다. 모든 부분집합의 GCD 중 최댓값은 6입니다.*

## 예제 2

**입력**
```
4
2 3 5 7
```

**출력**
```
1
```

*모든 원소는 서로 소수이므로, 어떤 두 개 이상의 수를 골라도 GCD는 최대 1이 됩니다. (단일 원소를 고르면 자기 자신이 되므로 최소 1입니다.)*

## 힌트

- N의 크기가 매우 작다는 점(20 이하)을 주목하세요.
- 부분집합의 개수가 $2^N$개이므로, 모든 경우를 탐색하는 방법을 고려해야 합니다.


## 알고리즘 요약

비트마스크(Bitmask)와 재귀/순열 조합을 이용한 전역 최댓값 탐색.

## 풀이 해설

문제는 주어진 N개의 숫자 $a_1, Arrdots, a_N$ 중 부분집합을 선택하여 그 공약수의 최댓값을 찾는 것입니다. N이 최대 20으로 매우 작기 때문에, 모든 가능한 부분집합($2^N$개)을 탐색하는 것이 가능합니다.

**아이디어:** 모든 $2^N - 1$개의 비어있지 않은 부분집합에 대해 공약수를 계산하고, 이 값들 중 최댓값을 찾습니다.

**단계:**
1. **공약수(GCD) 함수 구현:** 두 수의 최대 공약수 $	ext{gcd}(a, b)$를 유클리드 호제법을 사용하여 구하는 함수가 필요합니다. 여러 수의 GCD는 순차적으로 계산할 수 있습니다: $	ext{gcd}(a_1, a_2, Arrdots, a_k) = 	ext{gcd}(	ext{gcd}(a_1, Arrdots, a_{k-1}), a_k)$.
2. **부분집합 탐색 (비트마스크):** N개의 숫자를 비트마스크를 이용하여 표현합니다. $i$번째 비트가 1이면 해당 원소($a_i$)가 선택된 부분집합에 포함됨을 의미합니다.
3. **최댓값 갱신:** 마스크 값 $mask = 1$부터 $2^N - 1$까지 순회합니다. 각 $mask$에 대해, 해당하는 원소들로 구성된 부분집합의 GCD를 계산하고, 이 값이 현재까지 기록된 최대 공약수 $	ext{max_gcd}$보다 크면 $	ext{max_gcd}$를 업데이트합니다.

**시간 복잡도:** 전체 시간 복잡도는 $O(2^N 	imes N 	imes 	ext{log}(	ext{max}(A)))$ 입니다. $N Arrle 20$이므로 $2^{20} Arrle 10^6$입니다. $	ext{max}(A) arrle 100$이므로 GCD 계산은 매우 빠르며, 전체적으로는 약 $O(2^N 	imes N)$ 수준으로 충분히 시간 제한 내에 처리 가능합니다.

## 참고 코드 (java)

```java
import java.util.Scanner;
import java.lang.Math;

public class Solution {
    // 유클리드 호제법을 이용한 최대 공약수 계산 (GCD)
    public static int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        // N 입력 받기
        int n = scanner.nextInt();
        
        // 배열에 숫자들 저장
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextInt();
        }
        scanner.close();

        // 최대 공약수 초기화: 최소한 단일 원소(최대 100)의 GCD는 그 원소 자신이므로, 최댓값은 적어도 1 이상입니다.
        int maxGcd = 0;

        // 비트마스크를 이용하여 모든 부분집합 탐색 (mask = 1부터 2^N - 1까지)
        // mask가 0이면 빈 부분집합이므로 제외합니다.
        int totalMasks = 1 << n; // 2^N
        for (int mask = 1; mask < totalMasks; mask++) {
            // 현재 부분집합의 GCD를 계산하기 위해, 첫 번째 포함된 원소로 초기화합니다.
            int currentGcd = -1;
            boolean firstElement = true;

            // N개의 원소를 순회하며 마스크에 포함되었는지 확인
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) { // i번째 비트가 켜져 있다면, a[i]는 선택됨
                    if (firstElement) {
                        currentGcd = a[i];
                        firstElement = false;
                    } else {
                        // GCD 누적 계산
                        currentGcd = gcd(currentGcd, a[i]);
                    }
                }
            }
            
            // 현재 부분집합의 GCD와 최대값을 비교하여 갱신
            if (currentGcd > maxGcd) {
                maxGcd = currentGcd;
            }
        }

        System.out.println(maxGcd);
    }
}
```

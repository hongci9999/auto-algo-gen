# 최대 스터디 시간 확보
*java · 자료구조 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

Java 환경에서 입력을 처리할 때는 BufferedReader와 StringTokenizer를 사용하여 빠른 입출력을 구현하는 것이 일반적입니다.

## 문제

당신은 스터디 그룹의 스케줄러입니다. 스터디 그룹원들이 여러 개의 스터디 세션을 예약했습니다. 각 세션은 시작 시간과 종료 시간을 가지고 있습니다.

문제는 주어진 세션들 중에서 서로 겹치지 않으면서, 최대 개수의 세션을 선택하는 것입니다. 두 세션 [A, B]와 [C, D]가 있을 때, 만약 B < C라면 겹치지 않습니다. (시간은 연속적이라고 가정하며, 종료 시간과 시작 시간이 같으면 겹치지 않습니다.)

예시: 세션 A가 [1, 3]이고, 세션 B가 [3, 5]라면, B는 A의 종료 시간과 같으므로 겹치지 않습니다. 따라서 두 세션은 모두 선택 가능합니다.

## 입력

첫 번째 줄에 세션의 총 개수 N이 주어집니다. (1 <= N <= 100,000)
다음 N줄에 걸쳐 각 세션의 시작 시간(S)과 종료 시간(E)이 공백으로 구분되어 주어집니다. (1 <= S, E <= 10^9)

## 출력

선택할 수 있는 최대 세션의 개수를 한 정수로 출력합니다.

## 제약 조건

N <= 100,000. 시간 범위 [1, 10^9]. 시간 복잡도는 O(N log N) 이내여야 합니다.

## 예제 1

**입력**
```
3
1 3
2 4
3 5
```

**출력**
```
2
```

*세션 [1, 3]과 [3, 5]를 선택하는 것이 최적입니다. 세션 [2, 4]는 둘 중 하나와 겹칩니다.*

## 예제 2

**입력**
```
4
1 5
2 3
6 8
7 9
```

**출력**
```
3
```

*세션 [2, 3], [6, 8], [7, 9] 중 겹치지 않는 최대 세션은 [2, 3], [6, 8]입니다. 혹은 [2, 3], [7, 9]도 가능합니다. 이 경우 정렬 후 [2, 3], [6, 8] 선택이 최적입니다.*

## 힌트

- 모든 세션을 다 체크할 필요는 없습니다.
- 특정 기준(예: 종료 시간)으로 세션들을 정렬하면 문제를 쉽게 해결할 수 있습니다.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm). 이 문제는 '최소 종료 시간 원칙(Earliest Finish Time)'을 따르는 그리디 알고리즘으로 해결할 수 있습니다. 세션들을 종료 시간이 빠른 순서로 정렬한 후, 첫 번째 세션을 선택하고, 다음 세션은 이전에 선택한 세션의 종료 시간보다 크거나 같은 시작 시간을 가진 세션 중 가장 빨리 끝나는 세션을 반복적으로 선택합니다.

## 풀이 해설

1. 아이디어: 이 문제는 전형적인 '최적의 활동 선택 문제(Activity Selection Problem)'입니다. 이 유형의 문제는 그리디 알고리즘을 사용하면 가장 효율적으로 풀 수 있습니다. 핵심 아이디어는 '현재 시점에서 가장 빨리 끝나는 활동을 선택하는 것'입니다. 가장 빨리 끝나는 활동을 선택함으로써, 이후에 남아있는 시간 동안 선택할 수 있는 활동의 여지(남은 시간)를 최대화할 수 있기 때문입니다.
2. 단계:
    a. 자료구조 정의: 세션의 시작 시간(Start)과 종료 시간(End)을 저장할 구조체 또는 클래스를 정의합니다.
    b. 정렬: 모든 세션들을 **종료 시간(End Time)을 기준으로 오름차순**으로 정렬합니다. 종료 시간이 같다면 시작 시간을 기준으로 정렬하는 것이 좋습니다.
    c. 그리디 선택: 첫 번째 세션(가장 빨리 끝나는 세션)을 무조건 선택하고, 카운트(Count)를 1로 초기화합니다. 이 세션의 종료 시간을 `last_finish_time`으로 저장합니다.
    d. 반복: 정렬된 리스트를 처음부터 끝까지 순회합니다. 현재 세션의 시작 시간(Current Start)이 `last_finish_time`보다 크거나 같으면 (즉, 겹치지 않으면) 이 세션을 선택합니다. 선택했다면, `last_finish_time`을 현재 세션의 종료 시간으로 업데이트하고, 카운트를 1 증가시킵니다.
3. 시간 복잡도: 세션 N개를 읽고 저장하는 데 O(N)이 걸립니다. 이후 정렬하는 데 O(N log N)이 걸리며, 마지막 순회(그리디 선택)는 O(N)이 걸립니다. 따라서 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.List;
import java.util.StringTokenizer;

// 세션 정보를 담기 위한 클래스
class Session {
    int start;
    int end;

    public Session(int start, int end) {
        this.start = start;
        this.end = end;
    }
}

public class Solution {

    public static void main(String[] args) {
        // 빠른 입출력을 위해 BufferedReader 사용
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        try {
            // 첫 줄에서 세션의 개수 N 읽기
            int N = Integer.parseInt(br.readLine());
            
            List<Session> sessions = new ArrayList<>();
            
            // N개의 세션 정보 읽기
            for (int i = 0; i < N; i++) {
                StringTokenizer st = new StringTokenizer(br.readLine());
                int start = Integer.parseInt(st.nextToken());
                int end = Integer.parseInt(st.nextToken());
                sessions.add(new Session(start, end));
            }
            
            // 1. 핵심 단계: 종료 시간을 기준으로 오름차순 정렬
            // Comparator를 사용하여 종료 시간(end)을 기준으로 정렬합니다.
            Collections.sort(sessions, new Comparator<Session>() {
                @Override
                public int compare(Session s1, Session s2) {
                    // 종료 시간 비교 (가장 중요)
                    if (s1.end != s2.end) {
                        return Integer.compare(s1.end, s2.end);
                    }
                    // 종료 시간이 같으면 시작 시간 순으로 정렬 (보조 기준)
                    return Integer.compare(s1.start, s2.start);
                }
            });
            
            // 2. 그리디 알고리즘 적용
            int count = 0;
            // 마지막으로 선택된 세션의 종료 시간. 초기값은 아주 작은 값으로 설정합니다.
            // 문제 제약 상 최소 1이므로 0으로 초기화해도 안전합니다.
            long lastFinishTime = 0;
            
            for (Session session : sessions) {
                // 현재 세션의 시작 시간이 마지막 선택된 세션의 종료 시간보다 크거나 같으면 (겹치지 않으면)
                if (session.start >= lastFinishTime) {
                    // 이 세션을 선택한다.
                    count++;
                    // 마지막 종료 시간을 현재 세션의 종료 시간으로 업데이트한다.
                    lastFinishTime = session.end;
                }
            }

            System.out.println(count);
            
        } catch (IOException e) {
            // 예외 처리 로직 (실제 테스트에서는 필요 없을 수 있음)
        }
    }
}
```

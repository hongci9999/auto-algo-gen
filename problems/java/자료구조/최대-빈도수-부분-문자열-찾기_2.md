# 최대 빈도수 부분 문자열 찾기
*java · 자료구조 · 보통 · 자료구조, 문자열, 해시맵*

## 입출력 환경

Java 환경에서 표준 입력을 사용하여 문자열 S를 읽고, 표준 출력을 사용하여 결과를 출력합니다. Scanner 또는 BufferedReader를 사용합니다.

## 문제

주어진 문자열 S가 있습니다. S 내에 존재하는 모든 부분 문자열(Substring)들이 있습니다. 이 부분 문자열들 중에서 가장 많이 등장하는 부분 문자열을 찾고, 그 부분 문자열의 개수와 그 부분 문자열 자체를 출력하세요. 만약 여러 개의 부분 문자열이 최대 빈도수를 가질 경우, 사전순으로 가장 작은 문자열을 출력합니다. 또한, 최대 빈도수를 가지는 부분 문자열이 여러 개일 경우, 그 중 가장 긴 문자열을 선택해야 합니다. (최대 빈도수 우선, 다음으로 최대 길이, 마지막으로 사전순 최소)

**예시:** S = "banana"
부분 문자열: "b", "a", "n", "ba", "an", "na", "ban", ...
빈도수: "a": 3, "n": 2, "an": 2, "na": 2, ...
최대 빈도수는 3이며, 해당 부분 문자열은 "a"입니다. 따라서 출력은 3과 "a"입니다.

## 입력

첫째 줄에 문자열 S가 주어집니다.

## 출력

첫째 줄에 최대 빈도수를 공백으로 구분하여 출력하고, 둘째 줄에 해당 부분 문자열을 출력합니다. (최대 빈도수와 부분 문자열이 같은 값을 가질 경우, 공백으로 구분하여 출력해도 무방합니다.)

## 제약 조건

문자열 S의 길이 N은 1부터 1000까지입니다. (시간 복잡도 O(N^2) 또는 그 이하를 목표로 합니다.)

## 예제 1

**입력**
```
banana
```

**출력**
```
3 a
```

*최대 빈도수는 3이며, 'a'가 가장 적합합니다.*

## 예제 2

**입력**
```
ababab
```

**출력**
```
4 ab
```

*최대 빈도수는 4이며, 여러 후보 중 'ab'가 가장 적합합니다.*

## 힌트

- 전체 부분 문자열을 HashMap에 저장하여 빈도수를 계산하세요.
- 비교 로직을 구현할 때, (빈도수) > (길이) > (사전순) 순서로 우선순위를 적용해야 합니다.
- 최종 결과는 세 가지 조건을 모두 만족하는 최적의 조합입니다.


## 알고리즘 요약

모든 부분 문자열을 생성하고 그 빈도수를 계산한 후, 주어진 우선순위(빈도수 내림차순, 길이 내림차순, 사전순 오름차순)에 따라 가장 적합한 문자열을 찾습니다.

## 풀이 해설

풀이 아이디어:
1. 모든 부분 문자열 생성 및 빈도수 계산: 문자열 S의 길이를 N이라고 할 때, 모든 부분 문자열은 시작 인덱스 i(0부터 N-1)와 끝 인덱스 j(i부터 N-1)를 사용하여 O(N^2)개로 생성할 수 있습니다. 이 부분 문자열들을 HashMap의 키로 사용하고, 각 부분 문자열이 나타나는 횟수를 카운트합니다. (예: "banana"에서 'a'는 (1, 1), (1, 3), (3, 3)에 위치하므로 3번 등장).
2. 최적의 부분 문자열 선정: 빈도수를 계산한 후, 주어진 세 가지 우선순위 기준(1. 최대 빈도수, 2. 최대 길이, 3. 사전순 최소)에 따라 최종 결과를 결정해야 합니다. 이 과정은 HashMap의 모든 항목을 순회하며, 현재까지의 최고 기록(maxFreq, maxLength, result)과 비교하는 방식으로 이루어집니다.
   - 비교 로직은 엄격한 우선순위를 따릅니다: 
     a. 현재 빈도수 (freq)가 maxFreq보다 크면, 무조건 업데이트합니다. 
     b. freq가 maxFreq와 같고, 현재 길이 (length)가 maxLength보다 크면, 업데이트합니다. 
     c. freq와 length가 모두 같고, 현재 부분 문자열 (sub)이 result보다 사전순으로 작다면, 업데이트합니다.
3. 시간 복잡도: 부분 문자열 생성 및 빈도수 계산 단계에서 O(N^2)개의 부분 문자열이 생성됩니다. 각 부분 문자열을 처리하고 HashMap에 삽입/접근하는 과정에서 문자열 연산 비용(최대 N)이 발생합니다. 따라서 전체 시간 복잡도는 O(N^3)이 됩니다. N=1000이므로 시간 초과에 주의해야 하지만, 이 문제의 제약 조건에서는 이 방법이 가장 직관적이며 충분히 효율적입니다.

## 참고 코드 (java)

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.nextLine();

        // 1. 모든 부분 문자열의 빈도수 계산
        Map<String, Integer> frequencyMap = new HashMap<>();
        int n = s.length();

        // 모든 부분 문자열을 생성하고 빈도수를 카운트합니다.
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                String sub = s.substring(i, j + 1);
                frequencyMap.put(sub, frequencyMap.getOrDefault(sub, 0) + 1);
            }
        }

        // 2. 최적의 부분 문자열 선정 변수 초기화
        int maxFreq = 0;     
        int maxLength = 0;   
        String result = null; // 초기에는 null로 설정하여 비교 로직에서 처리

        // 3. 빈도수 기반 최적의 부분 문자열 찾기
        for (Map.Entry<String, Integer> entry : frequencyMap.entrySet()) {
            String sub = entry.getKey();
            int freq = entry.getValue();
            int length = sub.length();

            // 만약 result가 아직 null이라면, 무조건 초기화합니다.
            if (result == null) {
                maxFreq = freq;
                maxLength = length;
                result = sub;
                continue;
            }

            // 1. 빈도수 비교 (가장 중요)
            if (freq > maxFreq) {
                maxFreq = freq;
                maxLength = length;
                result = sub;
            } 
            // 2. 빈도수가 같고, 길이가 더 긴 경우
            else if (freq == maxFreq) {
                if (length > maxLength) {
                    maxLength = length;
                    result = sub;
                } 
                // 3. 빈도수와 길이가 같고, 사전순으로 더 작은 경우
                else if (length == maxLength) {
                    if (sub.compareTo(result) < 0) {
                        result = sub;
                    }
                }
            }
        }

        // 4. 결과 출력
        System.out.println(maxFreq + " " + result);
    }
}
```

# 도서관 대출 시스템 최적화
*java · 자료구조 · 보통 · 스택, 큐, 자료구조, 자료관리*

## 입출력 환경

Java 환경에서는 표준 입력(System.in)을 통해 데이터를 읽고, 결과를 표준 출력(System.out)으로 출력합니다. 입출력 성능을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

어떤 도서관에는 책을 대출/반납하는 시스템이 있습니다. 이 시스템은 책의 고유 ID(정수)와 대출 순서(정수)를 기반으로 작동합니다. 시스템은 다음과 같은 과정을 거칩니다. 

1. **대출(Loan)**: 고객이 책 A를 대출합니다. 이 책 A는 시스템에 기록된 순서대로 대출 가능합니다. 
2. **반납(Return)**: 고객이 책 B를 반납합니다. 이 책 B는 현재 시스템에 있는 책 중 가장 최근에 대출된 책이거나, 혹은 아직 대출되지 않은 책일 수 있습니다. 

문제는 대출 및 반납 과정에서 시스템의 효율성을 측정하는 것입니다. 책의 ID가 주어지면, 이 책이 현재 '대출 가능' 상태인지, '대출 중' 상태인지를 판별해야 합니다. 

*   **대출 가능 상태**: 시스템에 존재하지만, 현재 어떤 고객에게도 대출되지 않은 책. (초기 상태)
*   **대출 중 상태**: 현재 어떤 고객에게나 대출된 책. (최종 상태)
*   **처리 과정**: 책이 대출되면 '대출 중' 상태가 되고, 반납되면 '대출 가능' 상태로 돌아갑니다.

우리는 특정 순서대로의 책 ID 배열을 받습니다. 이 배열은 '대출 시도'와 '반납 시도'를 의미하며, '대출 시도'는 ID가 주어지고 '반납 시도'는 ID가 주어지지만, 실제 로직은 다음과 같이 가정합니다:

1. 주어진 ID는 **대출 시도**입니다. (시스템에 추가)
2. 다음 ID는 **반납 시도**이며, 이 반납되는 책은 현재 '대출 중' 상태인 책들 중 가장 최근에 대출되었던 책입니다. (시스템에서 제거)

즉, 배열의 $i$번째 요소는 대출 시도, $i+1$번째 요소는 그 대출 시도된 책을 반납하는 시도입니다. 이 과정이 반복됩니다. (배열의 크기는 항상 짝수입니다.)

주어진 ID 배열 $A$에 대해, 모든 처리 과정이 끝난 후, 시스템에 남아있는 책들(즉, 대출이 시도되었으나 반납되지 않은 책들)의 ID들을 **오름차순**으로 출력하시오.

## 입력

첫째 줄에 정수 $N$ (총 책 ID의 개수)이 주어집니다. 
다음 $N$개의 정수 $A_1, A_2, \dots, A_N$이 공백으로 구분되어 주어집니다. 이들은 순서대로 대출/반납 과정을 나타냅니다.

## 출력

한 줄에 남아있는 책들의 ID들을 오름차순으로 공백 구분하여 출력합니다. 남아있는 책이 없다면 빈 문자열을 출력합니다.

## 제약 조건

N의 범위는 2부터 100,000 이하이며, 각 ID는 1부터 100,000 이하의 정수입니다. 시간 복잡도는 $O(N)$ 또는 $O(N \log N)$ 이내여야 합니다.

## 힌트

- 문제의 핵심은 '최근 대출된 책'을 관리하는 것입니다.
- 대출 시도는 스택(Stack) 자료구조의 Push와 유사하며, 반납 시도는 Pop과 유사합니다.


## 알고리즘 요약

이 문제는 LIFO(Last In, First Out) 원칙을 따르는 스택(Stack) 자료구조를 활용하여 해결할 수 있습니다. 주어진 배열 $A$는 $A_1$ (대출) $	o A_2$ (반납) $	o A_3$ (대출) $	o A_4$ (반납) $	o \dots$ 와 같이 짝수 단위로 처리됩니다. 즉, $A_{2i-1}$이 대출되고, $A_{2i}$가 반납됩니다. 모든 처리 과정이 끝난 후 스택에 남아있는 요소들이 '대출 중'인 책들입니다. 마지막으로, 이 스택에 남아있는 요소들을 오름차순으로 정렬하여 출력해야 합니다.

## 풀이 해설

1. **아이디어**: 문제에서 주어진 시퀀스는 '대출(A[2i])' $	o$ '반납(A[2i+1])'의 쌍으로 이루어져 있습니다. 여기서 '반납되는 책'은 '가장 최근에 대출된 책'이라고 명시되어 있습니다. 이는 전형적인 스택(Stack)의 LIFO(Last In, First Out) 원칙을 따릅니다. 따라서, 배열을 순회하며 대출 ID를 스택에 넣고, 반납 ID가 주어지면 스택의 최상단(Top) 요소와 비교해야 합니다.

2. **단계**: 
    a. 스택을 사용하여 '대출 중'인 책의 ID를 저장합니다.
    b. 배열 $A$를 인덱스 $i=0$부터 $N-2$까지 2씩 증가시키며 순회합니다. 
    c. **대출 처리 (A[i])**: $A[i]$를 스택에 Push 합니다. (대출 중 책 목록에 추가)
    d. **반납 처리 (A[i+1])**: 스택의 최상단에 있는 요소 $S_{top}$이 반납되는 책 $A[i+1]$과 일치하는지 확인합니다. 만약 $S_{top} == A[i+1]$이면, 이 책은 성공적으로 반납된 것이므로 스택에서 Pop 합니다. (실제 문제 조건에서는 $A[i+1]$이 항상 스택의 최상단과 일치한다고 가정할 수 있습니다. 만약 다르다면 문제의 가정이 모순되거나 복잡해지지만, 주어진 설명에 따라 스택 연산을 따릅니다.)
    e. 모든 쌍 처리가 끝난 후, 스택에 남아있는 모든 요소들이 최종적으로 '대출 중'인 책들입니다.
    f. 스택에 남아있는 요소들을 꺼내어 오름차순으로 정렬한 후, 공백으로 구분하여 출력합니다.

3. **시간 복잡도**: 배열 $A$의 크기 $N$을 한 번 순회하며 각 단계는 $O(1)$의 시간 복잡도를 가집니다. 따라서 총 시간 복잡도는 $O(N)$입니다. 마지막에 스택에 남아있는 $K$개의 요소를 추출하여 정렬하는 과정이 $O(K 	o K 	ext{ log } K)$의 시간을 소요할 수 있지만, $K 	imes 	ext{log } K$는 $N$에 비해 작으므로 전체적으로 $O(N)$ 또는 $O(N 	ext{ log } N)$으로 매우 효율적입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.Stack;
import java.util.ArrayList;
import java.util.Collections;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 빠른 입력을 처리합니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 줄: N (총 책 ID의 개수)
        String lineN = br.readLine();
        if (lineN == null || lineN.isEmpty()) return;
        int N = Integer.parseInt(lineN.trim());
        
        // 두 번째 줄: A 배열 (N개의 ID)
        String lineA = br.readLine();
        if (lineA == null || lineA.isEmpty()) return;
        StringTokenizer st = new StringTokenizer(lineA);
        
        int[] A = new int[N];
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }
        
        // 스택을 사용하여 대출 중인 책 ID를 관리합니다.
        Stack<Integer> stack = new Stack<>();
        
        // 배열 A는 (A[0] 대출, A[1] 반납), (A[2] 대출, A[3] 반납), ... 순서로 처리됩니다.
        // N은 짝수라고 가정합니다. 따라서 N-2까지 반복합니다.
        for (int i = 0; i < N; i += 2) {
            // 1. 대출 시도: A[i]를 스택에 Push 합니다.
            stack.push(A[i]);
            
            // 2. 반납 시도: A[i+1]이 반납됩니다. 스택의 최상단과 일치해야 합니다.
            // 문제 조건에 따라, 반납되는 책은 항상 가장 최근에 대출된 책(스택 Top)입니다.
            if (i + 1 < N) {
                // 스택의 최상단이 A[i+1]과 일치하면 Pop 합니다.
                // (문제의 논리적 전제에 따라, 스택 Top이 반납 ID와 일치하는 것이 일반적입니다.)
                // 여기서는 단순히 스택 Top을 Pop하는 것으로 처리합니다.
                // Stack.peek() == A[i+1] 조건이 만족된다고 가정합니다.
                stack.pop(); 
            }
        }
        
        // 3. 결과 처리: 스택에 남아있는 요소들을 추출하여 오름차순으로 정렬합니다.
        ArrayList<Integer> result = new ArrayList<>(stack);
        Collections.sort(result);
        
        // 4. 출력: 공백으로 구분하여 출력합니다.
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < result.size(); i++) {
            sb.append(result.get(i));
            if (i < result.size() - 1) {
                sb.append(" ");
            }
        }
        System.out.println(sb.toString());
    }
}
```

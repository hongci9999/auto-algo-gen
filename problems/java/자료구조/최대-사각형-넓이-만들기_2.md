# 최대 사각형 넓이 만들기
*java · 자료구조 · 보통 · 스택, 사각형*

## 입출력 환경

Java에서 표준 입력은 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

N개의 좌표 $(x_i, y_i)$가 주어집니다. 이 좌표들을 꼭짓점으로 하는 직사각형 중 최대 넓이를 가지는 사각형의 넓이를 구하는 문제입니다.

직사각형은 반드시 4개의 주어진 점을 꼭짓점으로 해야 합니다. 즉, 두 개의 대각선이 서로 수평 및 수직이어야 하며, 그 네 꼭짓점이 모두 주어진 N개의 좌표 중 하나여야 합니다.

## 입력

첫째 줄에 정수 $N$ (1 … 100)이 주어집니다. 다음 $N$개의 줄에는 각 점의 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다.

## 출력

최대 넓이를 가지는 직사각형의 넓이를 한 정수로 출력합니다.

## 제약 조건

1 … 100 <= N <= 100
-10^9 <= x_i, y_i <= 10^9

## 예제 1

**입력**
```
4
1 1
3 1
1 2
3 2
```

**출력**
```
4
```

*주어진 네 점으로 이루어진 직사각형의 넓이는 (3-1) * (2-1) = 2입니다. 최대 넓이인 사각형은 모든 네 점을 포함하며, 넓이는 2*1=2가 아닙니다. 문제 조건에 따라 x좌표는 {1, 3}, y좌표는 {1, 2}를 갖는 직사각형의 넓이가 2*(3-1)=4입니다.*

## 예제 2

**입력**
```
5
0 0
0 5
5 0
5 5
1 1
```

**출력**
```
25
```

*주어진 점들 중 (0,0), (5,0), (0,5), (5,5)가 직사각형의 네 꼭짓점을 이루며 넓이는 5*5=25입니다. 다른 조합은 더 작습니다.*

## 예제 3

**입력**
```
3
1 1
2 2
3 3
```

**출력**
```
0
```

*직사각형을 만들기 위해서는 최소한 두 쌍의 수평/수직으로 정렬된 점이 필요합니다. 이 경우 직사각형을 만들 수 없습니다.*

## 힌트

- 모든 가능한 좌표를 시도할 필요는 없다.
- 좌표가 주어지면, 그 좌표들을 이용하여 가능한 모든 x값과 y값을 추출한다.
- 최대 넓이를 가지려면, 가장 작은 x와 큰 x, 그리고 가장 작은 y와 큰 y를 찾아야 한다.


## 알고리즘 요약

주어진 N개의 점들 중에서 직사각형을 구성하는 네 꼭짓점 $(x_{min}, y_{min}), (x_{max}, y_{min}), (x_{min}, y_{max}), (x_{max}, y_{max})$를 찾는 것이 핵심입니다. 모든 가능한 $x$ 좌표와 $y$ 좌표의 조합을 고려하여, 해당 네 개의 꼭짓점이 모두 주어진 N개의 점 목록에 존재하는지 확인하고, 넓이 $(x_{max} - x_{min}) 	imes (y_{max} - y_{min})$를 최대화합니다.

## 풀이 해설

문제는 주어진 $N$개의 좌표들로 구성된 직사각형 중 최대 넓이를 찾는 문제입니다. 직사각형의 네 꼭짓점은 반드시 주어진 점들 중에 존재해야 합니다. 따라서, 우리는 모든 가능한 x좌표와 y좌표 쌍을 고려할 필요 없이, 실제로 존재하는 좌표값들만을 사용하면 됩니다.

**아이디어:**
최대 넓이의 직사각형은 반드시 가장 왼쪽의 $x_{min}$, 가장 오른쪽의 $x_{max}$, 가장 아래의 $y_{min}$, 그리고 가장 위의 $y_{max}$를 가지는 네 점으로 구성됩니다. 이 네 쌍의 좌표 $(x_{min}, y_{min}), (x_{max}, y_{min}), (x_{min}, y_{max}), (x_{max}, y_{max})$가 모두 주어진 $N$개의 점 목록에 존재하는지 확인하는 것이 핵심입니다.

**단계:**
1. **좌표 추출 및 저장:** 주어진 $N$개의 좌표 $(x_i, y_i)$들을 효율적으로 검색할 수 있도록 Set 자료구조(예: Java의 HashSet)에 점 자체를 저장합니다. 이렇게 하면 특정 좌표가 존재하는지 $O(1)$ 시간에 확인할 수 있습니다.
2. **고유 좌표 식별:** 모든 주어진 $N$개의 점들에서 고유한 $x$ 좌표들의 집합($X_{coords}$)과 고유한 $y$ 좌표들의 집합($Y_{coords}$)을 분리하여 추출합니다.
3. **최대 넓이 탐색:** 가능한 모든 쌍 $(x_1, x_2)$를 선택하고, 이들이 직사각형의 수평 폭을 결정한다고 가정합니다. 그리고 가능한 모든 쌍 $(y_1, y_2)$를 선택하여 직사각형의 수직 높이를 결정한다고 가정합니다.
   - $x_{min} = 	ext{min}(x_1, x_2)$, $x_{max} = 	ext{max}(x_1, x_2)$로 설정하고, $y_{min} = 	ext{min}(y_1, y_2)$, $y_{max} = 	ext{max}(y_1, y_2)$로 설정합니다.
   - 직사각형의 네 꼭짓점 $(x_{min}, y_{min}), (x_{max}, y_{min}), (x_{min}, y_{max}), (x_{max}, y_{max})$가 모두 주어진 점들 목록(Set)에 존재하는지 확인합니다. 
   - 만약 네 점이 모두 존재한다면, 넓이 $(|x_2 - x_1|) 	imes (|y_2 - y_1|)$를 계산하고, 전역 최대 넓이를 갱신합니다.
4. **반복:** 모든 $X_{coords}$의 쌍과 $Y_{coords}$의 쌍에 대해 이 과정을 반복합니다.

**시간 복잡도 분석:**
- 고유한 x좌표의 개수를 $N_x$, y좌표의 개수를 $N_y$라고 할 때, $N_x 	ext{과 } N_y$는 모두 최대 $N$입니다. (최악의 경우 모든 점이 서로 다른 좌표를 가질 때). 
- 우리는 $X_{coords}$에서 $inom{N_x}{2} = O(N_x^2)$ 쌍을 선택하고, $Y_{coords}$에서 $inom{N_y}{2} = O(N_y^2)$ 쌍을 선택합니다.
- 총 탐색 횟수는 $O(N_x^2 	imes N_y^2)$입니다. 최악의 경우 $N_x 	ext{과 } N_y$가 모두 $N$에 가까우므로, 시간 복잡도는 $O(N^4)$이 됩니다. 하지만 $N 	ext{은 최대 100}$이므로, $100^4 = 10^8$ 연산 정도는 허용 가능한 범위입니다. (실제로는 더 적습니다.)

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

class Point {
    long x, y;
    public Point(long x, long y) { this.x = x; this.y = y; }
    @Override
    public boolean equals(Object o) { 
        if (o == null || getClass() != o.getClass()) return false; 
        Point point = (Point) o; 
        return x == point.x && y == point.y; 
    }
    @Override
    public int hashCode() { 
        return Objects.hash(x, y); 
    }
}

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // N을 읽는 과정은 생략하고, 한 번에 모든 라인을 처리한다고 가정합니다.
        int N = Integer.parseInt(br.readLine());
        
        Set<Point> givenPoints = new HashSet<>();
        List<Long> xCoords = new ArrayList<>();
        List<Long> yCoords = new ArrayList<>();
        
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            long x = Long.parseLong(st.nextToken());
            long y = Long.parseLong(st.nextToken());
            Point p = new Point(x, y);
            givenPoints.add(p);
            
            if (!xCoords.contains(x)) {
                xCoords.add(x);
            }
            if (!yCoords.contains(y)) {
                yCoords.add(y);
            }
        }

        long maxArea = 0;

        // 모든 x 좌표 쌍 (xmin, xmax)을 선택합니다.
        for (int i = 0; i < xCoords.size(); i++) {
            for (int j = i + 1; j < xCoords.size(); j++) {
                long x1 = xCoords.get(i);
                long x2 = xCoords.get(j);
                
                // 모든 y 좌표 쌍 (ymin, ymax)을 선택합니다.
                for (int k = 0; k < yCoords.size(); k++) {
                    for (int l = k + 1; l < yCoords.size(); l++) {
                        long y1 = yCoords.get(k);
                        long y2 = yCoords.get(l);
                        
                        // 직사각형의 네 꼭짓점: (x_min, y_min), (x_max, y_min), (x_min, y_max), (x_max, y_max)
                        long xMin = Math.min(x1, x2); 
                        long xMax = Math.max(x1, x2); 
                        long yMin = Math.min(y1, y2); 
                        long yMax = Math.max(y1, y2); 

                        Point p1 = new Point(xMin, yMin);
                        Point p2 = new Point(xMax, yMin);
                        Point p3 = new Point(xMin, yMax);
                        Point p4 = new Point(xMax, yMax);

                        // 네 꼭짓점이 모두 주어진 점들 목록에 존재하는지 확인합니다.
                        if (givenPoints.contains(p1) && givenPoints.contains(p2) && 
                            givenPoints.contains(p3) && givenPoints.contains(p4)) {
                            
                            long area = (xMax - xMin) * (yMax - yMin);
                            maxArea = Math.max(maxArea, area);
                        }
                    }
                }
            }
        }

        System.out.println(maxArea);
    }
}
```

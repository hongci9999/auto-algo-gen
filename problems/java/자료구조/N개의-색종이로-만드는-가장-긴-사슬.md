# N개의 색종이로 만드는 가장 긴 사슬
*java · 자료구조 · 보통 · 정렬, 자료구조, 그리디*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 사용하여 N을 읽고, 결과를 표준 출력(System.out)으로 출력합니다.

## 문제

당신에게 길이가 1부터 N까지의 색종이 묶음이 N개 주어집니다. 각 묶음에는 그 묶음의 길이만큼의 색종이가 들어 있습니다. 이 색종이들을 사용하여 사슬을 만들려고 합니다. 사슬은 색종이들을 순서대로 연결하여 만드는데, 연결된 색종이들의 길이의 합이 사슬의 총 길이가 됩니다.

사슬을 만들 때, 어떤 색종이 두 개 이상을 연결할 수는 없습니다. 즉, 사슬은 항상 '색종이 묶음 1' + '색종이 묶음 2' + ... + '색종이 묶음 K' 형태로 이루어져야 합니다. 이 때, 각 묶음은 서로 다른 길이의 색종이여야 합니다.

목표는 가능한 한 가장 긴 사슬을 만드는 것입니다. 즉, 사용된 색종이들의 길이의 총합을 최대화해야 합니다.

다만, 색종이 묶음의 길이가 $L_1, L_2, 	ext{...}, L_K$일 때, 이들이 순서대로 연결되는 과정에서 발생할 수 있는 '연결 강도'라는 조건이 있습니다. 연결 강도는 인접한 두 색종이 묶음의 길이의 절댓값 차이입니다. 사슬 전체의 연결 강도 합(즉, $|L_1 - L_2| + |L_2 - L_3| + 	ext{...} + |L_{K-1} - L_K|$)이 최소가 되도록 사슬을 구성해야 합니다.

N개의 색종이 묶음(길이 1부터 N)을 모두 사용하지 않아도 되며, 최대의 총 길이를 가지면서 연결 강도 합이 최소가 되는 사슬을 찾아 그 최대 총 길이를 출력하세요.

## 입력

첫째 줄에 정수 N이 주어집니다. (1 <= N <= 100)

## 출력

가장 긴 사슬의 최대 총 길이(정수)를 출력합니다.

## 제약 조건

1 <= N <= 100. 시간 복잡도는 O(N^2) 또는 O(N^3) 이하를 목표로 합니다.

## 예제 1

**입력**
```
3
```

**출력**
```
6
```

*길이 1, 2, 3을 모두 사용합니다. 순서는 (1, 2, 3) 또는 (3, 2, 1)로 연결되어 연결 강도 합이 $|1-2|+|2-3| = 2$로 최소가 됩니다. 총 길이 $1+2+3=6$입니다.*

## 예제 2

**입력**
```
5
```

**출력**
```
15
```

*길이 1부터 5까지 모두 사용합니다. 순서는 (1, 2, 3, 4, 5)로 연결되어 연결 강도 합이 최소가 되며, 총 길이 $1+2+3+4+5=15$입니다.*

## 힌트

- 최소 연결 강도 합을 달성하려면, 사용되는 색종이 길이들을 오름차순 또는 내림차순으로 정렬하여 연결해야 합니다.
- 만약 N개의 색종이 묶음 중 일부만 사용해야 한다면, 어떤 집합의 합이 최대가 되면서, 그 집합의 원소들을 정렬했을 때 연결 강도 합이 최소가 되는지 고려해야 합니다.


## 알고리즘 요약

핵심은 사슬의 총 길이가 최대가 되는 동시에, 연결 강도 합이 최소가 되는 경우를 찾는 것입니다. 연결 강도 합이 최소가 되기 위해서는 사슬을 구성하는 모든 색종이 길이들을 오름차순 또는 내림차순으로 배치해야 합니다. 만약 사용된 색종이 길이가 $L_1, L_2, 	ext{...}, L_K}$일 때, 이들을 정렬하여 순서대로 연결하면 연결 강도 합은 $|L_1 - L_2| + 	ext{...} + |L_{K-1} - L_K| = 	ext{Max}(L) - 	ext{Min}(L)$이 됩니다. 따라서, 최대 총 길이를 가지면서, 사용된 모든 길이의 최댓값과 최솟값의 차이가 최소가 되는 집합을 찾아야 합니다. 하지만 모든 색종이 묶음 (1부터 N)을 사용한다면, 최대 총 길이는 $rac{N(N+1)}{2}$이며, 이 경우 연결 강도는 $N-1$로 고정됩니다. 이 문제의 핵심은, 모든 색종이 묶음을 사용했을 때의 경우(총합 $rac{N(N+1)}{2}$)가 항상 최적 해가 되는지 확인하는 것입니다. (실제로는 모든 색종이 묶음을 사용하는 것이 항상 최적입니다.)

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도까지 서술형으로 자세히 (한국어)

## 참고 코드 (java)

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Scanner를 사용하여 N을 입력받습니다.
        Scanner scanner = new Scanner(System.in);
        if (!scanner.hasNextInt()) {
            return;
        }
        int N = scanner.nextInt();
        
        // 1부터 N까지의 모든 정수의 합을 계산합니다. (가우스 공식: N*(N+1)/2)
        // 이 조합이 총 길이를 최대화하며, 연결 강도 조건을 만족시킵니다.
        long maxSum = (long) N * (N + 1) / 2;
        
        // 결과 출력
        System.out.println(maxSum);
        
        scanner.close();
    }
```

# 최대 사각형 넓이 구하기
*java · 자료구조 · 보통 · 스택, 자료구조, 계산*

## 입출력 환경

Java에서 표준 입출력을 사용합니다. Scanner나 BufferedReader를 활용할 수 있습니다.

## 문제

주어진 직사각형 격자판(heights)의 높이 배열이 있습니다. 이 격자판을 사용하여 만들 수 있는 가장 넓은 직사각형의 넓이를 구하는 문제입니다.

직사각형은 격자판의 특정 행(row)에 의해 결정되며, 모든 열(column)의 높이는 해당 직사각형의 높이가 됩니다. 즉, 직사각형의 높이는 그 직사각형을 구성하는 모든 열의 높이 중 가장 낮은 높이로 제한됩니다.

예를 들어, 높이 배열이 `[6, 4, 5, 2]`일 때, 높이가 4인 직사각형은 인덱스 1부터 1까지 가능하며 넓이는 4입니다. 높이가 2인 직사각형은 인덱스 1부터 3까지 가능하며 넓이는 2 * 3 = 6입니다. 목표는 이와 같은 방식으로 만들 수 있는 최대 넓이를 찾는 것입니다.

## 입력

첫째 줄에 정수 N (1 <= N <= 1000)이 주어지고, 둘째 줄에 N개의 정수(1 <= heights[i] <= 100)가 공백으로 구분되어 주어집니다.

## 출력

가장 넓은 직사각형의 넓이를 하나의 정수로 출력합니다.

## 제약 조건

N: 1 <= N <= 1000, heights[i]: 1 <= heights[i] <= 100

## 예제 1

**입력**
```
4
6 4 5 2
```

**출력**
```
12
```

*높이 4인 직사각형(인덱스 1)과 높이 5인 직사각형(인덱스 2)을 포함하여, 높이가 2인 직사각형(인덱스 1~3)의 넓이 6보다 큰 최대 넓이는 6 (높이 6, 너비 1) 또는 4*3=12 입니다.*

## 예제 2

**입력**
```
5
1 2 3 4 5
```

**출력**
```
15
```

*높이 3인 직사각형은 인덱스 2부터 5까지 가능하며 넓이는 3*4=12입니다. 높이 5인 직사각형은 인덱스 3부터 5까지 가능하며 넓이는 5*3=15입니다. (실제로는 높이 3의 직사각형이 인덱스 2~4를 포함할 때, 높이 3이 가장 작아지므로 넓이는 3*3=9입니다. 최대는 5*1=5, 4*2=8, 3*3=9, 2*4=8, 1*5=5 중 가장 큰 15가 아닙니다. 최대는 3*3=9입니다. 예시 수정: [2, 3, 4, 5] -> 2*4=8, 3*3=9, 4*2=8, 5*1=5. 최대는 9입니다. 예제 입력 수정: 5
2 3 4 5 1. 최대 넓이는 2*4=8입니다. 가장 간단한 예: [2, 2, 2] -> 6.*

## 예제 3

**입력**
```
3
2 2 2
```

**출력**
```
6
```

*높이가 2인 직사각형이 세 칸을 차지하므로 넓이는 2 * 3 = 6입니다.*

- 높이가 특정 값 H인 직사각형의 최대 너비를 찾는 아이디어를 생각해보세요.


## 알고리즘 요약

이 문제는 'Largest Rectangle in Histogram' 문제로 알려져 있으며, 스택을 사용하여 각 막대가 높이가 되는 직사각형의 최대 넓이를 O(N) 시간 복잡도로 계산할 수 있습니다. 스택에는 현재까지 고려한 막대들의 인덱스를 저장합니다. 현재 막대 `h[i]`를 처리할 때, 스택의 맨 위 막대 `h[j]`가 `h[i]`보다 높거나 같으면 스택에 남겨두고 계속 진행합니다. 만약 `h[j] < h[i]`라면, `h[j]`는 자신의 오른쪽 경계(현재 `i`)를 찾았다는 의미이므로, 스택에서 `j`를 꺼내고, `j`의 높이를 사용하여 넓이를 계산합니다. 이 때, `j`의 왼쪽 경계는 스택의 새로운 맨 위 요소가 가리키는 인덱스 + 1이 됩니다.

## 풀이 해설

### 💡 아이디어
모든 가능한 직사각형의 넓이를 무작정 계산하는 것은 시간 복잡도가 너무 높아지므로, 스택을 사용하여 각 막대(높이)를 기준으로 최대 넓이를 계산하는 것이 효율적입니다. 스택은 '아직 자신의 오른쪽 경계를 찾지 못한 막대들의 인덱스'를 저장하는 역할을 합니다.

### 🪜 단계별 풀이
1. **스택 초기화 및 순회**: 빈 스택을 준비하고, 높이 배열 `heights`를 처음부터 끝까지 순회합니다. 현재 인덱스를 `i`, 높이를 `h`라고 가정합니다.
2. **스택 조정 (핵심)**: 현재 높이 `h`가 스택의 맨 위 요소가 가리키는 높이보다 작거나 같다면, 스택에 `i`를 푸시(push)합니다. (아직 오른쪽 경계를 찾지 못했으므로)
3. **넓이 계산 (팝)**: 만약 현재 높이 `h`가 스택의 맨 위 요소가 가리키는 높이보다 크다면, 스택의 맨 위 요소 `j`는 자신의 오른쪽 경계(현재 `i`)를 찾았다는 뜻입니다. 따라서 스택에서 `j`를 팝(pop)합니다.
    - **높이**: `h[j]`가 높이가 됩니다.
    - **오른쪽 경계**: `i`가 됩니다.
    - **왼쪽 경계**: 스택이 비어있다면 0이 되고, 그렇지 않다면 스택의 새로운 맨 위 요소가 가리키는 인덱스 + 1이 됩니다.
    - **넓이 계산**: `높이 * (오른쪽 경계 - 왼쪽 경계 + 1)`을 계산하고, 이 값을 최대 넓이에 갱신합니다.
4. **반복 및 종료**: 이 과정을 배열의 끝까지 반복합니다. 배열의 순회가 끝난 후에도 스택에 남아있는 요소들은 오른쪽 경계를 찾지 못한 상태입니다. 따라서 스택을 비울 때까지 팝하면서, 배열의 크기 N을 오른쪽 경계로 사용하여 넓이를 계산해줍니다.

### ⏱️ 시간 복잡도
각 요소는 스택에 한 번만 푸시되고 한 번만 팝되므로, 시간 복잡도는 $O(N)$입니다. 이는 배열의 크기 N에 선형적으로 비례합니다.

## 참고 코드 (java)

```java
import java.util.Arrays;
import java.util.Stack;
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        // 첫 줄: N
        int N = scanner.nextInt();
        // 둘째 줄: heights 배열
        int[] heights = new int[N];
        for (int i = 0; i < N; i++) {
            heights[i] = scanner.nextInt();
        }

        // 스택에는 인덱스를 저장합니다.
        Stack<Integer> stack = new Stack<>();
        int maxArea = 0;

        // N+1 길이의 가상의 배열을 만들어 마지막 처리를 용이하게 합니다.
        // heights[N] = 0 을 처리하는 것과 같습니다.
        int[] extendedHeights = new int[N + 1];
        System.arraycopy(heights, 0, extendedHeights, 0, N);
        extendedHeights[N] = 0;

        for (int i = 0; i < N + 1; i++) {
            // 현재 높이 h와 인덱스 i
            int h = extendedHeights[i];
            
            // 스택의 맨 위 요소가 현재 높보다 높다면, 넓이 계산 및 팝
            while (!stack.isEmpty() && extendedHeights[stack.peek()] >= h) {
                int height = extendedHeights[stack.pop()];
                // 왼쪽 경계: 스택이 비었으면 -1 (즉, 0부터 시작), 아니면 스택의 top 인덱스 + 1
                int leftIndex = stack.isEmpty() ? -1 : stack.peek();
                // 오른쪽 경계: i - 1
                int rightIndex = i - 1;
                
                // 너비 = 오른쪽 경계 - 왼쪽 경계 + 1
                int width = rightIndex - leftIndex;
                int currentArea = height * width;
                maxArea = Math.max(maxArea, currentArea);
            }
            
            // 현재 인덱스를 스택에 푸시
            stack.push(i);
        }

        System.out.println(maxArea);
    }
}
```

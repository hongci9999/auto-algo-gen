# 최대 경로 합
*java · DP · 보통 · DP, 그리드, 점화식*

## 입출력 환경

Java에서 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

당신은 N행 M열로 이루어진 격자판 위를 이동하는 로봇입니다. 각 칸에는 고유한 숫자가 적혀 있으며, 이 숫자는 해당 칸을 지나갈 때 획득하는 점수입니다.

로봇은 반드시 왼쪽 상단 (0, 0)에서 시작하여 오른쪽 하단 (N-1, M-1)까지 이동해야 합니다. 이동 규칙은 다음과 같습니다:
1. 이동은 오직 '아래' 또는 '오른쪽' 방향으로만 가능합니다.
2. 로봇이 지나가는 모든 칸의 점수를 합산한 값이 최대가 되도록 경로를 찾는 것이 목표입니다.

N과 M의 크기는 최대 1000이며, 각 칸의 점수는 1 이상 100 이하의 정수입니다.

(참고: 좌표는 (행, 열) 순서로 사용합니다.)

## 입력

첫 줄에 N과 M이 공백으로 구분되어 주어집니다. (N: 행의 수, M: 열의 수)
다음 N줄에 걸쳐 M개의 정수가 공백으로 구분되어 주어지며, 이들이 격자판의 점수 값을 나타냅니다.

## 출력

최대 경로 합을 계산한 하나의 정수 값만 출력합니다.

## 제약 조건

N, M: 1 <= N, M <= 1000
Grid 값: 1 <= Grid[i][j] <= 100

## 예제 1

**입력**
```
3 3
1 2 3
4 5 6
7 8 9
```

**출력**
```
21
```

*최적 경로는 (1, 2) -> (2, 2) -> (2, 3) -> (3, 3)을 거치며, 합은 1+2+5+6+9 = 23이 아닌, (1,1)->(2,1)->(2,2)->(2,3)의 예시를 따릅니다. 실제 최대 경로는 1+2+5+8+9 = 25입니다. (수정: N=3, M=3 기준, 실제 최대 경로는 1+2+5+8+9 = 25입니다.)*

## 예제 2

**입력**
```
2 2
1 10
2 1
```

**출력**
```
13
```

*최적 경로는 (0, 0) -> (0, 1) -> (1, 1)을 거치며, 합은 1+10+1 = 12가 아닙니다. (0, 0) -> (1, 0) -> (1, 1)을 거치는 것이 최대입니다. 1+2+1 = 4. (수정: 1+10+1 = 12입니다. 최대 경로는 1+10+1 = 12입니다.)*

## 힌트

- 이동 제약 조건(아래 또는 오른쪽)은 DP 문제의 전형적인 형태를 만듭니다.
- DP 테이블의 정의(State)와 전이(Transition) 관계를 명확히 정의해야 합니다.


## 알고리즘 요약

동적 계획법(Dynamic Programming, DP)을 사용합니다. DP 테이블 $DP[i][j]$를 '좌상단 (0, 0)에서 (i, j)까지 도달할 수 있는 최대 경로 합'으로 정의합니다. (i, j)에 도달하는 방법은 (i-1, j)에서 내려오거나, (i, j-1)에서 오른쪽으로 오는 두 가지뿐이므로, 점화식은 $DP[i][j] = Grid[i][j] + \max(DP[i-1][j], DP[i][j-1])$가 됩니다. 경계 조건(첫 행, 첫 열) 처리가 중요합니다.

## 풀이 해설

아이디어: 이 문제는 전형적인 DP 문제입니다. 목표 지점 (N-1, M-1)에 도달하는 모든 경로는 반드시 (i-1, j)나 (i, j-1)를 거쳐야 하므로, 점화식을 통해 최적의 해를 점진적으로 계산할 수 있습니다.

단계:
1. DP 테이블 초기화: N x M 크기의 DP 배열을 생성합니다. 이 배열은 (i, j)까지 도달하는 최대 합을 저장합니다.
2. 기저 사례(Base Case) 설정: DP[0][0]은 Grid[0][0]의 값과 같습니다. 첫 번째 행(i=0)과 첫 번째 열(j=0)은 오직 한 방향으로만 도달 가능하므로, 해당 값들을 그대로 채웁니다.
3. 점화식 적용: i > 0, j > 0인 모든 칸에 대해 다음 점화식을 적용합니다.
   $DP[i][j] = Grid[i][j] + \max(DP[i-1][j], DP[i][j-1])$
   (즉, 현재 칸의 값에, 위쪽 칸과 왼쪽 칸 중 더 큰 값의 최대 합을 더합니다.)
4. 결과 반환: 최종적으로 DP[N-1][M-1]에 저장된 값이 최대 경로 합입니다.

시간 복잡도: 모든 $N 	imes M$ 칸에 대해 $O(1)$ 연산을 수행하므로, 총 시간 복잡도는 $O(N \cdot M)$입니다. 공간 복잡도 역시 $O(N \cdot M)$입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());

        // Grid는 점수 값을 저장하는 배열
        int[][] grid = new int[N][M];
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // dp[i][j]는 (0, 0)에서 (i, j)까지의 최대 경로 합을 저장
        long[][] dp = new long[N][M];

        // 1. 기저 사례 설정: (0, 0)
        dp[0][0] = grid[0][0];

        // 2. 첫 번째 행 채우기 (오른쪽으로만 이동 가능)
        for (int j = 1; j < M; j++) {
            dp[0][j] = dp[0][j - 1] + grid[0][j];
        }

        // 3. 첫 번째 열 채우기 (아래로만 이동 가능)
        for (int i = 1; i < N; i++) {
            dp[i][0] = dp[i - 1][0] + grid[i][0];
        }

        // 4. 나머지 칸 채우기 (점화식 적용)
        for (int i = 1; i < N; i++) {
            for (int j = 1; j < M; j++) {
                // 현재 칸의 값 + (위쪽 최대 합, 왼쪽 최대 합 중 큰 값)
                dp[i][j] = grid[i][j] + Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }

        // 결과 출력: 오른쪽 하단 칸의 값
        System.out.println(dp[N - 1][M - 1]);
    }
}
```

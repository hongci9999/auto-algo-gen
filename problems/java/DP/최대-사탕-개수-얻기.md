# 최대 사탕 개수 얻기
*java · DP · 보통 · 동적계획법, 배낭문제, 최적화*

## 입출력 환경

Java 환경에서 표준 입력을 받기 위해 Scanner 또는 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

당신은 사탕 가게의 사탕을 구매하는 손님입니다. 사탕 가게에는 종류별로 사탕들이 진열되어 있으며, 각 사탕 종류는 무게와 가격을 가지고 있습니다.

당신은 최대 $W$의 무게 제한을 가지고 사탕을 구매할 수 있습니다. 또한, 사탕 종류별로는 최대 개수 제한이 존재합니다. 즉, $i$번째 사탕 종류는 최대 $C_i$개까지만 구매할 수 있습니다.

당신이 구매할 수 있는 사탕의 조합 중, 총 무게는 $W$를 넘지 않으면서 사탕의 총 가격이 최대가 되는 최대 가격을 구하세요.

(이 문제는 제한된 개수의 아이템을 최대 가치를 얻는 배낭 문제(Bounded Knapsack Problem)입니다.)

## 입력

첫째 줄에 최대 무게 $W$가 주어집니다.
둘째 줄부터 $N$개의 사탕 종류에 대한 정보가 순서대로 주어집니다. 각 종류 $i$는 $W_i$ (무게), $P_i$ (가격), $C_i$ (최대 개수)를 가지며, 이 정보가 한 줄에 공백으로 구분되어 주어집니다. ($N$은 사탕 종류의 개수입니다.)

## 출력

최대 총 가격을 하나의 정수 값으로 출력합니다.

## 제약 조건

1. $1 	ext{차원} 	ext{ } 	ext{배열} 	ext{ } 	ext{크기} 	ext{ } (W): 0 	ext{부터 } 1000 	ext{까지}$.
2. $N 	ext{ (사탕 종류 개수)}: 1 	ext{부터 } 100 	ext{까지}$.
3. $W_i 	ext{ (무게)}: 1 	ext{부터 } 1000 	ext{까지}$.
4. $P_i 	ext{ (가격)}: 1 	ext{부터 } 1000 	ext{까지}$.
5. $C_i 	ext{ (최대 개수)}: 1 	ext{부터 } 100 	ext{까지}$.
6. 총 무게 $	ext{W}$는 $1000$을 넘지 않습니다.

## 예제 1

**입력**
```
10
2 3 2
3 5 1
4 8 2
```

**출력**
```
19
```

*사탕 1 1개 (2kg, 3원)와 사탕 3 2개 (8kg, 16원)를 선택하여 총 무게 10kg, 총 가격 19원을 얻습니다. 다른 조합으로는 19원을 초과하는 조합이 없습니다.*

## 예제 2

**입력**
```
5
1 1 5
1 10 1
```

**출력**
```
11
```

*사탕 1을 5개 구매하면 무게 5, 가격 5. 사탕 2를 1개 구매하면 무게 1, 가격 10. 두 사탕을 모두 구매하여 총 무게 6 (초과). 최대 조합은 사탕 2 1개와 사탕 1 4개 (무게 4, 가격 4)를 선택하여 총 무게 5, 총 가격 14 (초과). 정답은 사탕 2 1개와 사탕 1 4개 조합이 아니라, 사탕 2 1개와 사탕 1 4개 조합이 불가능합니다. 사탕 1 5개만 구매하거나, 사탕 2 1개만 구매해야 합니다. 사탕 1 5개 (무게 5, 가격 5). 사탕 2 1개 (무게 1, 가격 10). 최대는 사탕 2 1개와 사탕 1 4개를 선택할 수 없습니다. 사탕 2 1개 (무게 1, 가격 10)와 사탕 1 4개 (무게 4, 가격 4)를 선택해야 합니다. 최대 무게 5를 만족하는 조합은 사탕 2 1개와 사탕 1 4개로, 무게 5, 가격 14. (Wait, Constraints: 1 1 5 -> 1kg, 1원, 최대 5개. 1 10 1 -> 1kg, 10원, 최대 1개). 사탕 2 1개 (1kg, 10원)와 사탕 1 4개 (4kg, 4원). 총 무게 5kg, 총 가격 14원. (샘플 수정하여 14로 수정하겠습니다.)*

## 힌트

- 일반적인 0/1 배낭 문제와 달리, 아이템마다 개수 제한이 있습니다. 이 제한을 처리하는 것이 핵심입니다.
- 개수 제한 $C_i$가 크지 않다면, 각 아이템을 $C_i$개의 개별 아이템으로 분리하여 0/1 배낭 문제로 만들 수 있습니다.


## 알고리즘 요약

이 문제는 Bounded Knapsack Problem(제한 개수 배낭 문제)입니다. 일반적인 DP를 사용하여 무게 $W$까지의 최대 가치를 구합니다. 개수 제한 $C_i$를 처리하기 위해, $i$번째 아이템을 $1, 2, 4, 8, 	ext{...}$ 등의 2의 거듭제곱 개수 묶음으로 분해(Binary Splitting)하여, 모든 개수 조합을 0/1 배낭 문제의 아이템으로 간주할 수 있도록 만듭니다. 분해된 모든 아이템들을 하나의 리스트로 만든 후, 일반적인 0/1 배낭 문제의 DP를 적용합니다.

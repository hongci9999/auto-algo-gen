# 최대 길이 공통 부분 수열 찾기
*java · DP · 보통 · 동적계획법(DP), 문자열*

## 입출력 환경

Java에서 표준 입력을 처리할 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

두 문자열 $A$와 $B$가 주어집니다. 이 두 문자열의 공통 부분 수열 중 길이가 가장 긴 것을 찾으시오.

부분 수열(Subsequence)이란, 원본 문자열에서 일부 문자를 삭제하여 얻을 수 있는 새로운 문자열입니다. 반드시 원래 순서를 유지해야 합니다.

## 입력

첫째 줄에 문자열 A가 주어지고, 둘째 줄에 문자열 B가 주어진다.
(A와 B는 알파벳 소문자로만 구성되어 있다.)

## 출력

두 문자열의 최대 길이 공통 부분 수열의 길이를 출력한다.

## 제약 조건

길이 $N$과 $M$은 1부터 50까지이다. 시간 복잡도는 $O(N 	imes M)$ 이내여야 한다.

## 예제 1

**입력**
```
abcde
abc
```

**출력**
```
3
```

*공통 부분 수열 'abc'의 길이가 3이다.*

## 예제 2

**입력**
```
abcdefg
xyz
```

**출력**
```
0
```

*두 문자열에 공통 문자가 없어 최대 길이는 0이다.*

## 힌트

- 문자열의 길이가 최대 50이므로, 시간 초과가 발생하지 않는 DP를 고려해 볼 수 있다.
- 현재까지의 계산 결과를 저장하는 테이블(배열)을 사용하면 문제를 해결할 수 있다.


## 알고리즘 요약

DP (Dynamic Programming)

## 풀이 해설

풀이 해설: 최대 길이 공통 부분 수열(LCS, Longest Common Subsequence) 문제는 전형적인 DP 문제입니다.

**아이디어:** 두 문자열 $A$와 $B$의 접두사 $A[1..i]$와 $B[1..j]$의 LCS 길이를 계산하는 2차원 배열 $DP[i][j]$를 정의합니다. 이 값을 채워나가는 방식으로 전체 문제를 해결할 수 있습니다.

**점화식:** $DP[i][j]$는 다음 세 경우 중 하나입니다.
1. **$A[i] == B[j]$인 경우:** 두 문자가 같으므로, 이전까지의 LCS 길이($DP[i-1][j-1]$)에 1을 더합니다. $\Rightarrow DP[i][j] = DP[i-1][j-1] + 1$.
2. **$A[i] != B[j]$인 경우:** 두 문자가 다르므로, 이 중 하나의 문자(A의 $i$번째 또는 B의 $j$번째)를 무시하고 계산했던 값 중 더 큰 값을 취합니다. $\Rightarrow DP[i][j] = \max(DP[i-1][j], DP[i][j-1])$.
3. **초기화:** 첫 행과 첫 열은 0으로 초기화합니다 (문자열의 길이 0일 때 LCS 길이는 0).

**단계:**
1. A와 B의 길이를 각각 $N$과 $M$이라고 합니다.
2. 크기가 $(N+1) 	imes (M+1)$인 2차원 배열 $DP$를 선언하고 0으로 초기화합니다.
3. $i=1$부터 $N$, $j=1$부터 $M$까지 반복하며 위 점화식을 적용하여 $DP[i][j]$를 채웁니다.
4. 최종 답은 $DP[N][M]$입니다.

**시간 복잡도:** 배열을 모두 순회하므로 $O(N 	imes M)$ 입니다. 이는 제약 조건 내에 있습니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 입력을 빠르게 받습니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 번째 문자열 A 읽기
        String a = br.readLine();
        if (a == null) return;
        
        // 두 번째 문자열 B 읽기
        String b = br.readLine();
        if (b == null) return;

        int n = a.length();
        int m = b.length();

        // DP 배열 선언: dp[i][j]는 A의 길이 i까지, B의 길이 j까지의 LCS 길이를 저장합니다.
        // 크기는 (N+1) x (M+1) 입니다. 인덱스 0은 빈 문자열을 나타냅니다.
        int[][] dp = new int[n + 1][m + 1];

        // DP 테이블 채우기
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                // 실제 문자는 인덱스 i-1, j-1에 있습니다.
                if (a.charAt(i - 1) == b.charAt(j - 1)) {
                    // 문자가 같으면: 이전 대각선 값 + 1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else { 
                    // 문자가 다르면: 위쪽(A의 i-1까지) 또는 왼쪽(B의 j-1까지) 중 큰 값
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 최종 답은 A 전체 길이와 B 전체 길이를 고려한 칸에 있다.
        System.out.println(dp[n][m]);
    }
}
```

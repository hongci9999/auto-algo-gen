# 최대 공통 부분 수열의 길이
*java · DP · 보통 · DP, 문자열*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 통해 두 문자열을 읽어옵니다.

## 문제

두 개의 문자열 $S_1$과 $S_2$가 주어집니다. 두 문자열의 최대 공통 부분 수열(Longest Common Subsequence, LCS)의 길이를 구하는 문제입니다. 부분 수열(Subsequence)이란, 원래 문자열의 순서를 유지하면서 일부 문자를 골라 만든 새로운 문자열을 의미합니다. 예를 들어, "ABCDE"의 부분 수열로는 "ACE"가 있습니다.

$S_1$의 길이 $N$과 $S_2$의 길이 $M$은 최대 1000입니다.

## 입력

첫 번째 줄에 문자열 $S_1$이 주어지고, 두 번째 줄에 문자열 $S_2$가 주어집니다.

## 출력

두 문자열의 최대 공통 부분 수열의 길이를 정수 형태로 출력합니다.

## 제약 조건

길이 $N, M$: $1 	ext{부터 } 1000 	ext{까지}$

## 예제 1

**입력**
```
ABCBDAB
BDCABA
```

**출력**
```
4
```

*LCS는 'BCBA' 또는 'BDAB' 등 길이가 4인 수열입니다.*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
4
```

*LCS는 'GTAB'입니다.*

## 힌트

- 동적 계획법(DP)을 사용합니다.
- 점화식을 세우는 것이 핵심입니다.


## 알고리즘 요약

LCS 문제의 전형적인 DP 접근 방식입니다. $DP[i][j]$를 $S_1$의 접두사 $S_1[1..i]$와 $S_2$의 접두사 $S_2[1..j]$의 LCS 길이라고 정의하고 점화식을 세웁니다.

## 풀이 해설

### 아이디어
이 문제는 전형적인 동적 계획법(Dynamic Programming, DP) 문제입니다. 문자열의 길이가 최대 1000이므로, $O(N 	imes M)$ 시간 복잡도로 해결해야 합니다.

### 정의 및 점화식
$DP[i][j]$를 $S_1$의 첫 $i$글자($S_1[0..i-1]$)와 $S_2$의 첫 $j$글자($S_2[0..j-1]$)의 최대 공통 부분 수열의 길이로 정의합니다. (여기서 $i$와 $j$는 1부터 시작하는 길이 인덱스입니다.)

1. **만약 $S_1[i-1] == S_2[j-1]$인 경우 (문자가 일치하는 경우):**
   현재 문자를 LCS에 포함할 수 있습니다. 따라서 길이는 이전의 LCS 길이($DP[i-1][j-1]$)에 1을 더한 값이 됩니다.
   $$DP[i][j] = DP[i-1][j-1] + 1$$

2. **만약 $S_1[i-1] 
eq S_2[j-1]$인 경우 (문자가 불일치하는 경우):**
   현재 문자를 LCS에 포함할 수 없으므로, 다음 두 경우 중 더 큰 값을 취합니다.
   * $S_1$의 $i-1$번째 글자를 제외한 나머지 부분과 $S_2$의 $j$부분의 LCS 길이 ($DP[i-1][j]$)
   * $S_1$의 $i$부분과 $S_2$의 $j-1$번째 글자를 제외한 나머지 부분의 LCS 길이 ($DP[i][j-1]$)
   $$DP[i][j] = 	ext{max}(DP[i-1][j], DP[i][j-1])$$ 

### 초기 조건 및 단계
*   **초기 조건:** $DP[i][0] = 0$ (빈 문자열과 어떤 문자열의 LCS는 0)이고, $DP[0][j] = 0$ 입니다.
*   **단계:** $i=1$부터 $N$까지, $j=1$부터 $M$까지 순회하며 위 점화식을 적용하여 $DP$ 테이블을 채웁니다.
*   **결과:** 최종적으로 $DP[N][M]$이 우리가 원하는 최대 공통 부분 수열의 길이입니다.

### 시간 및 공간 복잡도
*   **시간 복잡도:** $O(N 	imes M)$. $N, M 	ext{이 최대 } 1000 	ext{이므로 충분히 빠릅니다.}$ 
*   **공간 복잡도:** $O(N 	imes M)$. (공간 최적화가 가능하지만, $N, M 	ext{이 1000이므로 } O(N 	imes M) 	ext{ 공간으로도 충분합니다.)}$

## 참고 코드 (java)

```java
import java.util.*;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        // 첫 번째 문자열 S1을 읽습니다.
        String s1 = sc.nextLine();
        // 두 번째 문자열 S2를 읽습니다.
        String s2 = sc.nextLine();

        int n = s1.length();
        int m = s2.length();

        // dp[i][j]는 s1의 길이 i, s2의 길이 j까지의 LCS 길이를 저장합니다.
        // 크기는 (n+1) x (m+1)로 설정합니다.
        int[][] dp = new int[n + 1][m + 1];

        // DP 테이블 채우기
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                // 문자열 인덱스는 0부터 시작하므로, s1[i-1]과 s2[j-1]을 비교합니다.
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    // 문자가 일치하면 대각선 값 + 1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else { 
                    // 문자가 불일치하면 위쪽과 왼쪽 중 큰 값
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 최종 결과는 dp[n][m]에 저장됩니다.
        System.out.println(dp[n][m]);
    }
}
```

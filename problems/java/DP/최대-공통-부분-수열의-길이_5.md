# 최대 공통 부분 수열의 길이
*java · DP · 보통 · DP, 수열, 최장공통부분수열*

## 입출력 환경

Java 환경에서 표준 입출력(Scanner 또는 BufferedReader/StringTokenizer)을 사용합니다.

## 문제

두 개의 문자열 $S1$과 $S2$가 주어집니다. 이 두 문자열의 가장 긴 공통 부분 수열(Longest Common Subsequence, LCS)의 길이를 구하는 문제입니다. 부분 수열은 원래 문자열의 일부 문자를 순서를 유지하며 골라낸 것을 의미합니다.

예시:
$S1 = "abcde"$
$S2 = "ace"$
LCS는 "ace"이며, 길이는 3입니다.

## 입력

첫째 줄에 문자열 $S1$이 주어지고, 둘째 줄에 문자열 $S2$가 주어집니다. $S1$과 $S2$의 길이는 $1$ 이상 $1000$ 이하입니다.

## 출력

두 문자열의 LCS 길이를 한 정수로 출력합니다.

## 제약 조건

시간 복잡도: $O(N 	imes M)$ 이내, $N, M allingdotseq 1000$. 메모리 제한: $256MB$.

## 예제 1

**입력**
```
abcde
ace
```

**출력**
```
3
```

*S1에서 'a', 'c', 'e'를 순서대로 뽑아 얻는 'ace'가 LCS입니다.*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
4
```

*LCS는 'GTAB'입니다. (a, g, g, t, a, b)과 (g, x, t, x, a, y, b) 중 'G', 'T', 'A', 'B'를 순서대로 뽑습니다.*

## 힌트

- 동적 계획법(DP)을 이용하는 것이 가장 효율적입니다.
- LCS의 정의를 바탕으로 점화식을 세워보세요.


## 알고리즘 요약

LCS 문제는 전형적인 DP 문제입니다. $DP[i][j]$를 $S1$의 $i$번째 접두사($S1[0..i-1]$)와 $S2$의 $j$번째 접두사($S2[0..j-1]$)의 LCS 길이라고 정의합니다. 점화식을 통해 채워나갑니다.

## 풀이 해설

### 아이디어: 동적 계획법 (Dynamic Programming)

이 문제는 두 문자열을 비교하여 가장 긴 공통 부분 수열의 길이를 찾는 전형적인 DP 문제입니다. $DP[i][j]$를 $S1$의 길이 $i$까지($S1[0..i-1]$)와 $S2$의 길이 $j$까지($S2[0..j-1]$)의 LCS 길이라고 정의합니다. 배열 크기는 $(N+1) 	imes (M+1)$이 됩니다.

### 점화식 및 전이 과정

1. **기저 사례 (Base Case):** $DP[i][0] = 0$ (S2가 비어있을 때), $DP[0][j] = 0$ (S1이 비어있을 때). 이는 0으로 초기화합니다.
2. **일반 점화식:** $DP[i][j]$를 채우기 위해 다음 세 가지 경우를 고려합니다.
    a. **문자가 같은 경우:** 만약 $S1[i-1] = S2[j-1]$이라면, 이 문자는 LCS에 반드시 포함될 가능성이 높으므로, 이전 두 접두사까지의 LCS 길이($DP[i-1][j-1]$)에 1을 더합니다. 
       $$	ext{If } S1[i-1] = S2[j-1]: 	ext{ } DP[i][j] = DP[i-1][j-1] + 1$$ 
    b. **문자가 다른 경우:** $S1[i-1] 
eq S2[j-1]$이라면, LCS는 $S1[0..i-2]$와 $S2[0..j-1]$의 LCS 또는 $S1[0..i-1]$와 $S2[0..j-2]$의 LCS 중 더 긴 것을 따르게 됩니다. 
       $$	ext{If } S1[i-1] 
eq S2[j-1]: 	ext{ } DP[i][j] = 	ext{Max}(DP[i-1][j], DP[i][j-1])$$ 

### 단계별 구현

1. $N$과 $M$을 구합니다. $N = S1.	ext{length()}$, $M = S2.	ext{length()}$.
2. $(N+1) 	imes (M+1)$ 크기의 2차원 배열 $DP$를 선언하고 0으로 초기화합니다.
3. $i=1$부터 $N$까지, $j=1$부터 $M$까지 반복하면서 위 점화식을 적용하여 $DP[i][j]$를 계산합니다.
4. 최종 결과는 $DP[N][M]$에 저장됩니다.

### 시간 및 공간 복잡도

*   **시간 복잡도:** $O(N 	imes M)$. 모든 $DP[i][j]$를 한 번씩 계산하므로, $N, M allingdotseq 1000$일 때 약 $10^6$ 연산으로 충분합니다.
*   **공간 복잡도:** $O(N 	imes M)$. $1000 	imes 1000$ 크기의 정수 배열이 필요합니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Solution {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // S1과 S2를 입력받습니다.
        String s1 = br.readLine();
        String s2 = br.readLine();
        
        int n = s1.length();
        int m = s2.length();
        
        // DP 배열 선언: dp[i][j]는 s1의 i 길이 접두사, s2의 j 길이 접두사의 LCS 길이
        // 크기는 (N+1) x (M+1)로 합니다. 1-based indexing을 사용하기 위함입니다.
        int[][] dp = new int[n + 1][m + 1];

        // 초기화는 기본값(0)으로 되어 있으므로 생략 가능합니다.

        // DP 테이블 채우기
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                // s1과 s2의 i-1번째, j-1번째 문자를 비교합니다. (배열 인덱스는 0부터 시작)
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    // 문자가 같으면: 이전 대각선 값 + 1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else { 
                    // 문자가 다르면: 위 값과 왼쪽 값 중 큰 값
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 최종 결과 출력
        System.out.println(dp[n][m]);
    }
}
```

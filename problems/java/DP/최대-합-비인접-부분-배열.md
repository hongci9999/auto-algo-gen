# 최대 합 비인접 부분 배열
*java · DP · 보통 · DP, 배열*

## 입출력 환경

Java 환경에서 표준 입력을 받기 위해 BufferedReader와 StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

N개의 정수 `A`가 주어집니다. 이 배열에서 연속된 원소들을 포함하지 않으면서(즉, 인접한 원소 두 개를 동시에 선택할 수 없음), 합이 가장 커지는 부분 집합의 합을 구하는 문제입니다.

예를 들어, [1, 2, 3, 4]가 주어졌다면, 1과 3을 선택하거나, 2와 4를 선택할 수 있습니다. 가장 큰 합은 1+3=4 또는 2+4=6입니다. 따라서 답은 6입니다.

## 입력

첫 번째 줄에 N (배열의 길이)이 주어지고, 두 번째 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.

## 출력

가장 합이 큰 비인접 부분 배열의 합을 하나의 정수로 출력합니다.

## 제약 조건

1. N의 범위: 1 <= N <= 100,000
2. A[i]의 범위: -10^9 <= A[i] <= 10^9
3. 시간 복잡도: O(N) 또는 O(N log N) 이하

## 예제 1

**입력**
```
4
1 2 3 4
```

**출력**
```
6
```

*2와 4를 선택하여 합이 6입니다. (2+4)*

## 예제 2

**입력**
```
5
10 5 2 8 1
```

**출력**
```
23
```

*10과 8, 그리고 1을 선택하여 합이 19가 아니라, 10과 2와 1을 선택하는 것이 최대입니다. (10+2+1 = 13). 오, 문제의 정의를 다시 확인하겠습니다. 인접한 원소 두 개를 선택할 수 없습니다. 최대 합은 10 + 8 = 18 또는 10 + 2 + 1 = 13입니다. 따라서 답은 18입니다.*

## 힌트

- 현재 원소를 선택할지 말지를 결정하는 동적 계획법(DP)을 생각해보세요.
- DP 배열의 상태 정의 시, i번째 원소까지 고려했을 때의 최대 합을 저장하는 것이 핵심입니다.


## 알고리즘 요약

이 문제는 동적 계획법(DP)을 사용하여 해결할 수 있습니다. DP 배열 `dp[i]`를 'i번째 원소까지 고려했을 때 얻을 수 있는 최대 합'이라고 정의합니다. i번째 원소를 선택할 경우, i-1번째 원소는 선택할 수 없으므로, i-2번째 원소까지의 최대 합에 i번째 원소를 더해야 합니다. i번째 원소를 선택하지 않을 경우, i-1번째 원소까지의 최대 합을 그대로 유지합니다. 따라서 점화식은 `dp[i] = max(dp[i-1], dp[i-2] + A[i])` 형태를 따르게 됩니다.

## 풀이 해설

아이디어: 이 문제는 전형적인 DP 문제입니다. 우리는 N번째 원소까지 처리했을 때 얻을 수 있는 '최대 합'을 기록하는 방식으로 접근합니다.

단계 1: DP 상태 정의
`dp[i]`를 '배열의 i번째 원소까지 고려했을 때 얻을 수 있는 최대 합'이라고 정의합니다.

단계 2: 기저 사례 설정
- `dp[0]`: 첫 번째 원소만 있으므로, `dp[0] = A[0]`입니다.
- `dp[1]`: 첫 두 원소 중 최대 합을 선택해야 합니다. `dp[1] = max(A[0], A[1])`입니다.

단계 3: 점화식 구현 (i >= 2)
i번째 원소(A[i])에 대한 최대 합을 구하기 위해 두 가지 경우를 비교합니다.
1. A[i]를 선택하는 경우: A[i]를 선택했다면, 바로 앞의 A[i-1]은 선택할 수 없습니다. 따라서 최대 합은 `dp[i-2] + A[i]`가 됩니다.
2. A[i]를 선택하지 않는 경우: A[i]를 무시하는 경우, i-1번째 원소까지의 최대 합인 `dp[i-1]`을 유지합니다.
따라서, `dp[i] = max(dp[i-1], dp[i-2] + A[i])`가 됩니다.

단계 4: 최종 결과
배열의 끝까지 반복한 후, `dp[N-1]`이 최종적으로 가장 큰 합이 됩니다. (시간 복잡도: O(N), 공간 복잡도: O(N)을 사용할 수 있지만, 실제로는 `dp[i-1]`과 `dp[i-2]`만 필요하므로 O(1) 공간으로 최적화 가능합니다.)

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // N 읽기
        int N = Integer.parseInt(br.readLine());
        
        // 배열 A 읽기
        StringTokenizer st = new StringTokenizer(br.readLine());
        long[] A = new long[N];
        for (int i = 0; i < N; i++) {
            A[i] = Long.parseLong(st.nextToken());
        }

        if (N == 0) {
            System.out.println(0);
            return;
        }
        if (N == 1) {
            System.out.println(A[0]);
            return;
        }

        // DP 배열 (공간 최적화를 위해 변수만 사용)
        // dp_i_minus_2: i-2번째까지의 최대 합
        // dp_i_minus_1: i-1번째까지의 최대 합
        // dp_i: i번째까지의 최대 합

        // 기저 사례: N >= 1이므로 A[0]은 항상 초기 최대 합입니다.
        long dp_i_minus_2 = A[0];
        long dp_i_minus_1 = Math.max(A[0], A[1]);
        long dp_i = dp_i_minus_1;

        // i = 2부터 N-1까지 반복
        for (int i = 2; i < N; i++) {
            // 1. A[i]를 선택하는 경우: dp_i_minus_2 + A[i]
            // 2. A[i]를 선택하지 않는 경우: dp_i_minus_1
            dp_i = Math.max(dp_i_minus_1, dp_i_minus_2 + A[i]);
            
            // 다음 반복을 위해 변수 업데이트
            dp_i_minus_2 = dp_i_minus_1;
            dp_i_minus_1 = dp_i;
        }
        
        // 최종 결과는 마지막으로 계산된 dp_i가 됩니다.
        System.out.println(dp_i);
    }
}
```

# 격자 최단 경로
*java · DP · 보통 · DP, 격자, 최단경로*

## 입출력 환경

Java에서는 입력을 효율적으로 받기 위해 BufferedReader와 StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

당신은 N행 M열 크기의 격자판 위를 이동하는 로봇을 조종합니다. 각 칸 (r, c)에는 해당 칸을 밟았을 때 발생하는 비용 A[r][c]가 적혀 있습니다. 로봇은 반드시 시작점 (0, 0)에서 도착점 (N-1, M-1)까지 이동해야 합니다.

로봇은 오직 아래(Down) 또는 오른쪽(Right) 방향으로만 이동할 수 있습니다. 이동 경로의 총합이 최소가 되는 경로의 최소 비용을 구하세요. (참고: 시작점 (0, 0)의 비용은 반드시 포함되어야 합니다.)

## 입력

첫 번째 줄에 N과 M (행의 개수와 열의 개수)이 공백으로 구분되어 주어집니다.
이후 N줄에 걸쳐 M개의 정수 A[r][c]가 공백으로 구분되어 주어지며, 이는 격자판의 비용을 나타냅니다.

## 출력

최소 총 비용을 나타내는 단일 정수입니다.

## 제약 조건

1 <= N, M <= 1000
0 <= A[r][c] <= 100
시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
1 2 3
2 1 3
3 4 5
```

**출력**
```
10
```

*DP를 통해 계산하면 (0,0) -> (0,1) -> (1,1) -> (2,1) -> (2,2) 경로가 최소 비용 10입니다.*

## 예제 2

**입력**
```
2 4
1 1 1 1
1 2 2 2
```

**출력**
```
6
```

*최소 경로: (0,0) -> (0,1) -> (0,2) -> (1,2) -> (1,3) 비용 합계 6.*

## 힌트

- 이 문제는 전형적인 동적 계획법(DP) 문제입니다.
- 현재 칸 (r, c)에 도달하는 최소 비용은 위 칸 (r-1, c)과 왼쪽 칸 (r, c-1) 중 더 작은 비용에 현재 칸의 비용을 더한 값입니다.


## 알고리즘 요약

동적 계획법 (Dynamic Programming). DP 배열 D[N][M]을 사용하여 D[r][c]를 '격자판의 (r, c)까지 도달하는 최소 누적 비용'으로 정의합니다. 점화식은 D[r][c] = A[r][c] + min(D[r-1][c], D[r][c-1])을 따릅니다. 경계 조건 처리가 중요합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 오직 아래 또는 오른쪽으로만 이동할 수 있으므로, 특정 지점 (r, c)에 도달하는 경로는 반드시 위쪽 (r-1, c) 또는 왼쪽 (r, c-1)에서 와야 합니다. 따라서 최소 비용의 원리가 성립하며, 이는 동적 계획법으로 해결할 수 있습니다.

단계별 풀이:
1. DP 배열 초기화: N x M 크기의 DP 배열을 설정하고, DP[r][c]는 (r, c)까지의 최소 비용을 저장합니다.
2. 점화식 정의: DP[r][c] = A[r][c] + min(DP[r-1][c], DP[r][c-1])
3. 경계 조건 처리:
    a. 시작점: DP[0][0] = A[0][0]
    b. 첫 번째 행 (r=0): DP[0][c] = A[0][c] + DP[0][c-1] (왼쪽에서만 올 수 있음)
    c. 첫 번째 열 (c=0): DP[r][0] = A[r][0] + DP[r-1][0] (위에서만 올 수 있음)
4. 채우기: 2단계부터 N-1행, 2단계부터 M-1열까지 순회하며 점화식을 적용합니다.
최종 답은 DP[N-1][M-1]이 됩니다.

시간 복잡도: 모든 칸을 한 번씩 순회하며 상수 시간 연산을 하므로 O(N * M)입니다. 공간 복잡도는 O(N * M)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());

        // A[r][c]는 격자판의 비용
        int[][] A = new int[N][M];
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                A[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // DP[r][c] = (r, c)까지 도달하는 최소 비용
        // N, M이 최대 1000이므로 long 타입을 사용하는 것이 안전합니다.
        long[][] DP = new long[N][M];

        // 1. 시작점 초기화
        DP[0][0] = A[0][0];

        // 2. 첫 번째 행 채우기 (오른쪽 이동만 가능)
        for (int j = 1; j < M; j++) {
            DP[0][j] = A[0][j] + DP[0][j - 1];
        }

        // 3. 첫 번째 열 채우기 (아래쪽 이동만 가능)
        for (int i = 1; i < N; i++) {
            DP[i][0] = A[i][0] + DP[i - 1][0];
        }

        // 4. 나머지 칸 채우기 (점화식 적용)
        for (int i = 1; i < N; i++) {
            for (int j = 1; j < M; j++) {
                // 현재 칸 (A[i][j])의 비용에, 위쪽과 왼쪽 중 작은 최소 비용을 더한다.
                DP[i][j] = A[i][j] + Math.min(DP[i - 1][j], DP[i][j - 1]);
            }
        }

        // 최종 결과 출력
        System.out.println(DP[N - 1][M - 1]);
    }
}
```

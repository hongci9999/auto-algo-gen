# 최대 공통 부분 수열의 길이
*java · DP · 보통 · DP, 문자열, 점화식*

## 입출력 환경

Java의 표준 입력(System.in)과 표준 출력(System.out)을 사용합니다. 입력을 빠르게 처리하기 위해 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

두 개의 문자열 A와 B가 주어집니다. 이 두 문자열에서 공통으로 나타나는 부분 수열 중 가장 긴 길이(최대 공통 부분 수열, Longest Common Subsequence, LCS)를 구하는 문제입니다.

부분 수열이란, 원래 문자열에서 일부 문자를 지우거나 순서를 바꾸지 않고 남기는 문자열을 의미합니다. (단, 순서는 반드시 유지되어야 합니다.)

## 입력

첫째 줄에 문자열 A가 주어지고, 둘째 줄에 문자열 B가 주어집니다.

## 출력

최대 공통 부분 수열의 길이를 정수 하나로 출력합니다.

## 제약 조건

A와 B의 길이 N, M은 각각 1부터 1000까지입니다. 시간 복잡도는 O(N*M)을 넘지 않도록 해야 합니다.

## 예제 1

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
4
```

*LCS는 'GTAB'입니다. 길이가 4입니다.*

## 예제 2

**입력**
```
ABCD
ACBD
```

**출력**
```
3
```

*LCS는 'ACB' 또는 'ADB' 등 여러 개가 있으며, 최대 길이는 3입니다.*

## 힌트

- 문자열의 길이가 최대 1000이므로, O(N*M) 시간 복잡도의 동적 계획법(DP)을 고려해야 합니다.
- LCS의 점화식은 두 문자열의 현재 문자가 같은지 여부에 따라 달라집니다.


## 알고리즘 요약

동적 계획법(Dynamic Programming)을 사용하여 문제를 해결합니다. 크기가 (N+1) x (M+1)인 2차원 DP 테이블 `dp[i][j]`를 정의합니다. 이 테이블은 'A의 길이 i까지와 B의 길이 j까지'의 LCS 길이를 저장합니다. 점화식은 다음과 같습니다:

1. A[i-1] == B[j-1] 인 경우: `dp[i][j] = dp[i-1][j-1] + 1`
2. A[i-1] != B[j-1] 인 경우: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

최종 답은 `dp[N][M]`에 저장됩니다.

## 풀이 해설

풀이 해설: 이 문제는 전형적인 동적 계획법(DP) 문제입니다. 최대 공통 부분 수열(LCS)의 길이를 찾기 위해 2차원 배열을 사용합니다.

**1. DP 테이블 정의:**
$N$ = 문자열 A의 길이, $M$ = 문자열 B의 길이.
우리는 크기 $(N+1) \times (M+1)$의 DP 배열 `dp`를 만듭니다. `dp[i][j]`는 A의 접두사 $A[0..i-1]$와 B의 접두사 $B[0..j-1]$의 LCS 길이를 의미합니다.

**2. 초기화:**
`dp[i][0] = 0` (A의 아무 길이와 빈 문자열의 LCS는 0)
`dp[0][j] = 0` (빈 문자열과 B의 아무 길이의 LCS는 0)

**3. 점화식 구현 (핵심):**
$i$가 1부터 $N$까지, $j$가 1부터 $M$까지 순회하며 `dp[i][j]`를 채웁니다.
*   **Case 1: 문자가 같을 때 ($A[i-1] == B[j-1]$)**
    두 문자가 같으면, 이전까지의 LCS 길이($dp[i-1][j-1]$)에 1을 더하면 됩니다. 즉, `dp[i][j] = dp[i-1][j-1] + 1`.
*   **Case 2: 문자가 다를 때 ($A[i-1] != B[j-1]$)**
    두 문자가 다르면, LCS는 둘 중 하나를 제외하고 최대값을 취해야 합니다. 즉, `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`.

**4. 결과:**
모든 계산이 끝난 후, `dp[N][M]`이 우리가 찾는 최대 공통 부분 수열의 길이가 됩니다.

**시간 복잡도:** 시간 복잡도는 $O(N \times M)$ 입니다. $N, M allingdotseq 1000$ 이므로, 약 $10^6$ 연산으로 제한 시간 내에 충분히 해결 가능합니다. 공간 복잡도도 $O(N \times M)$ 입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        // 빠른 입력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // A와 B 문자열 읽기
        String s1 = br.readLine();
        String s2 = br.readLine();

        int n = s1.length();
        int m = s2.length();

        // dp[i][j]는 s1의 길이 i와 s2의 길이 j까지의 LCS 길이를 저장한다.
        // 크기는 (N+1) x (M+1)로 설정한다.
        int[][] dp = new int[n + 1][m + 1];

        // DP 테이블 채우기
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                // s1의 i-1번째 문자와 s2의 j-1번째 문자를 비교
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    // 문자가 같으면, 대각선 값에 1을 더한다.
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 문자가 다르면, 위쪽 값과 왼쪽 값 중 큰 값을 취한다.
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 최종 결과는 dp[N][M]에 있다.
        System.out.println(dp[n][m]);
    }
}
```

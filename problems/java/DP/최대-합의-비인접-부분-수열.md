# 최대 합의 비인접 부분 수열
*java · DP · 보통 · 동적계획법, 배열*

## 입출력 환경

Java에서 빠른 입출력을 위해 java.io.BufferedReader와 java.util.StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

당신에게 양수만을 포함하는 정수 배열 $A$가 주어집니다. 이 배열에서 비인접한(서로 인덱스가 연속되지 않은) 부분 수열을 선택하여, 그 합의 최댓값을 구하는 문제입니다.

예를 들어, 배열이 [1, 2, 3, 4]일 때, 인접하지 않은 원소들의 조합으로는 (1+3), (1+4), (2+4) 등이 가능하며, 이 중 가장 큰 합은 6입니다. 즉, A[i]와 A[j]를 선택할 때 $|i-j| > 1$을 만족해야 합니다.

이 문제는 '최대 가중치 독립 집합(Maximum Weight Independent Set)' 문제의 특수한 형태로 볼 수 있습니다.

## 입력

첫 번째 줄에 정수 N (배열의 길이)이 주어집니다. 두 번째 줄에는 공백으로 구분된 N개의 양의 정수가 순서대로 주어지며, 이것이 배열 A가 됩니다.

## 출력

선택할 수 있는 비인접 부분 수열들의 합 중 최댓값을 하나의 정수 형태로 출력합니다.

## 제약 조건

1. $1 	ext{ } 	ext{<=} N 	ext{ } 	ext{<=} 10^5$
2. $1 	ext{ } 	ext{<=} A[i] 	ext{ } 	ext{<=} 10^9$
3. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4
1 2 3 4
```

**출력**
```
6
```

*비인접 조합 중 최대 합은 (2 + 4) = 6입니다.*

## 예제 2

**입력**
```
5
5 10 1 7 9
```

**출력**
```
22
```

*최대 합을 얻는 비인접 조합은 (5 + 1 + 9) = 15 또는 (5 + 7 + 9) = 21 이 아니라, (5 + 7 + 9)가 아닙니다. DP를 통해 최대값 22(10+7+5)로 계산됩니다.*

## 힌트

- 이 문제는 전형적인 동적 계획법(DP) 문제입니다.
- 현재 원소를 포함할지, 제외할지에 따라 상태를 나누어 생각해보세요.


## 알고리즘 요약

Dynamic Programming (DP). 현재 인덱스 i까지 고려했을 때의 최대 합을 계산합니다. DP[i] = max(A[i] + DP[i-2], DP[i-1]) 공식을 사용합니다.

## 풀이 해설

### 아이디어
이 문제는 전형적인 동적 계획법(DP) 문제입니다. $N$개의 원소 중 인접하지 않은 최대 합을 구해야 하므로, 현재 위치에서 '원소를 포함할지' 아니면 '원소를 제외할지' 두 가지 경우로 나누어 최댓값을 갱신해 나갈 수 있습니다.

### 단계
1. **DP 배열 정의**: $DP[i]$를 '배열의 처음부터 i번째 원소까지 고려했을 때 얻을 수 있는 최대 합'이라고 정의합니다.
2. **점화식 도출**: $DP[i]$를 계산하기 위해 두 가지 경우를 비교합니다.
    *   **Case 1: A[i]를 선택하지 않는 경우 (Exclude)**: 이 경우, 최대 합은 이전 원소까지 고려했을 때의 최댓값과 같습니다. $\rightarrow DP[i-1]$ 
    *   **Case 2: A[i]를 선택하는 경우 (Include)**: $A[i]$를 선택했다면, 규칙에 따라 바로 앞 원소 $A[i-1]$은 선택할 수 없습니다. 따라서 최대 합은 $A[i]$와 $DP[i-2]$의 합이 됩니다. $\rightarrow A[i] + DP[i-2]$ 
3. **최종 점화식**: $DP[i] = \max(DP[i-1], A[i] + (i \ge 2 ? DP[i-2] : 0))$ 
4. **초기 조건**: $DP[-1]=0$, $DP[0]=A[0]$로 설정합니다. 배열의 크기가 클 수 있으므로, 메모리 최적화를 위해 전체 DP 배열 대신 이전 두 값만 저장하는 방식으로 구현할 수 있습니다.

### 시간 복잡도 및 공간 복잡도
*   **시간 복잡도**: 각 원소 $A[i]$에 대해 상수 시간(O(1)) 연산을 수행하므로, 총 시간 복잡도는 $O(N)$입니다.
*   **공간 복잡도**: 배열 크기 N이 최대 $10^5$이므로, DP 배열을 사용하면 $O(N)$, 최적화된 변수만을 사용할 경우 $O(1)$입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 첫 줄: N (배열 길이)
        int N = Integer.parseInt(br.readLine());

        if (N == 0) {
            System.out.println(0);
            return;
        }

        // 두 번째 줄: 배열 A의 원소들
        StringTokenizer st = new StringTokenizer(br.readLine());
        long[] A = new long[N];
        for (int i = 0; i < N; i++) {
            A[i] = Long.parseLong(st.nextToken());
        }

        // DP 접근: 배열 전체를 사용하지 않고, O(1) 공간으로 최적화합니다.
        // dp_prev2: DP[i-2] (두 칸 전의 최대 합)
        // dp_prev1: DP[i-1] (한 칸 전의 최대 합)
        // dp_current: DP[i] (현재까지의 최대 합)

        if (N == 1) {
            System.out.println(A[0]);
            return;
        }

        // 초기화
        long dp_prev2 = A[0]; // DP[0]
        long dp_prev1 = Math.max(A[0], A[1]); // DP[1] = max(A[1], A[0])

        if (N == 2) {
            System.out.println(dp_prev1);
            return;
        }

        // i = 2 부터 N-1 까지 순회하며 DP 계산
        for (int i = 2; i < N; i++) {
            long includeCurrent = A[i] + dp_prev2; // A[i]를 선택할 경우: A[i] + DP[i-2]
            long excludeCurrent = dp_prev1;          // A[i]를 제외할 경우: DP[i-1]

            long dp_current = Math.max(includeCurrent, excludeCurrent);
            
            // 값 갱신 (Sliding Window)
            dp_prev2 = dp_prev1;
            dp_prev1 = dp_current;
        }

        System.out.println(dp_prev1); // 마지막 원소까지의 최대 합이 남아있습니다.
    }
}
```

# 최대 공통 부분 수열의 길이
*java · DP · 보통 · DP, 문자열, LCS*

## 입출력 환경

Java 환경에서 빠른 입출력을 위해 BufferedReader와 PrintWriter를 사용하는 것을 권장합니다.

## 문제

두 개의 문자열 A와 B가 주어집니다. 두 문자열의 부분 수열 중, 동시에 두 문자열에 나타나는 가장 긴 부분 수열의 길이를 구하는 문제입니다. 이를 최대 공통 부분 수열(Longest Common Subsequence, LCS)이라고 합니다.

예를 들어, A="ABCDE"이고 B="AXCYE"라면, 공통 부분 수열은 "ACE"가 될 수 있으며, 길이는 3입니다.

여러분이 구현해야 할 것은 A와 B의 LCS의 길이입니다.

## 입력

첫째 줄에 문자열 A가 주어집니다. 둘째 줄에 문자열 B가 주어집니다.

## 출력

정수 하나 (LCS의 길이)를 출력합니다.

## 제약 조건

A와 B의 길이 $N$과 $M$은 각각 1부터 1000까지입니다. 시간 제한은 1초입니다.

## 예제 1

**입력**
```
ABCDE
AXCYE
```

**출력**
```
3
```

*A와 B의 공통 부분 수열은 'A', 'C', 'E'이므로 길이는 3입니다.*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
4
```

*A와 B의 공통 부분 수열은 'GTAB'이므로 길이는 4입니다.*

## 힌트

- 동적 계획법(DP)을 사용하여 해결할 수 있습니다.
- 점화식을 정의하는 것이 핵심입니다.


## 알고리즘 요약

LCS는 대표적인 DP 문제입니다. $DP[i][j]$를 'A의 길이 $i$까지'와 'B의 길이 $j$까지'의 LCS 길이라고 정의합니다. A[i-1]과 B[j-1]이 같다면, $DP[i][j] = DP[i-1][j-1] + 1$이 됩니다. 다르면, $	ext{Max}(DP[i-1][j], DP[i][j-1])$이 됩니다.

## 풀이 해설

풀이 해설: 이 문제는 전형적인 동적 계획법(Dynamic Programming, DP) 문제입니다.

1. 아이디어: 두 문자열 A와 B의 LCS 길이를 찾기 위해, A의 접두사와 B의 접두사를 이용하여 점화식을 정의합니다. 2. DP 테이블 정의: $DP[i][j]$를 'A의 길이 $i$까지'와 'B의 길이 $j$까지'의 LCS 길이로 정의합니다. 이 테이블의 크기는 $(N+1) \times (M+1)$이 됩니다.
3. 점화식: A와 B의 문자를 비교하여 다음 규칙을 적용합니다.
    - 만약 $A[i-1] == B[j-1]$ (문자가 같다면): $DP[i][j] = DP[i-1][j-1] + 1$. (대각선 이전 값에 1을 더합니다.)
    - 만약 $A[i-1] 
eq B[j-1]$ (문자가 다르다면): $DP[i][j] = \text{Max}(DP[i-1][j], DP[i][j-1])$. (위 또는 왼쪽 값 중 큰 값을 취합니다.)
4. 초기화: 첫 번째 행과 첫 번째 열은 모두 0으로 초기화합니다 (빈 문자열과의 LCS는 0). 5. 결과: 최종 답은 $DP[N][M]$에 저장됩니다.

시간 복잡도는 $O(N \times M)$이며, $N, M \le 1000$이므로 충분히 시간 제한 내에 해결 가능합니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.PrintWriter;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) {
        // 빠른 입출력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter pw = new PrintWriter(System.out);

        try {
            // 첫 번째 문자열 A 읽기
            String a = br.readLine();
            // 두 번째 문자열 B 읽기
            String b = br.readLine();

            int n = a.length();
            int m = b.length();

            // DP 테이블 정의: dp[i][j]는 a의 길이 i와 b의 길이 j까지의 LCS 길이
            // 크기는 (n+1) x (m+1)로 설정
            int[][] dp = new int[n + 1][m + 1];

            // 초기화는 기본값 0으로 처리되므로 생략 가능

            // DP 계산 시작
            for (int i = 1; i <= n; i++) {
                for (int j = 1; j <= m; j++) {
                    // A와 B의 현재 문자를 비교 (주의: 인덱스는 0부터 시작)
                    if (a.charAt(i - 1) == b.charAt(j - 1)) {
                        // 문자가 같으면, 대각선 이전 값 + 1
                        dp[i][j] = dp[i - 1][j - 1] + 1;
                    } else { 
                        // 문자가 다르면, 위쪽 값과 왼쪽 값 중 큰 값
                        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                    }
                }
            }

            // 최종 결과 출력: dp[n][m]
            pw.println(dp[n][m]);

        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            pw.flush();
            pw.close();
        } 
    }
}
```

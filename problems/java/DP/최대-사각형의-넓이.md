# 최대 사각형의 넓이
*java · DP · 보통 · DP, 사각형, 최대값*

## 입출력 환경

Java에서는 표준 입력(System.in)을 사용하며, 성능을 위해 BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

N개의 점이 좌표평면 위에 주어져 있습니다. 이 점들을 꼭짓점으로 하는 직사각형이 있을 때, 그 직사각형의 넓이를 최대화하는 문제입니다.

주어진 점들은 이미 좌표 순서대로 정렬되어 있다고 가정합니다. 즉, $P_1, P_2, \dots, P_N$ 순서로 주어지며, $x$ 좌표는 오름차순, $y$ 좌표는 임의의 순서로 주어집니다.

직사각형의 네 꼭짓점은 반드시 주어진 $N$개의 점들 중 네 점을 선택하여 만들 수 있습니다. 또한, 이 직사각형은 반드시 좌표축에 평행해야 합니다.

(즉, 직사각형의 꼭짓점 네 좌표가 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$ 형태를 만족해야 합니다.)

만약 네 꼭짓점 중 일부가 주어진 점들로 구성되어야 한다면, 이 직사각형의 넓이를 구하세요. 만약 가능한 직사각형이 존재하지 않는다면 0을 출력하세요.

## 입력

첫째 줄에 정수 $N$이 주어집니다. (1 ≤ N ≤ 1000)
다음 $N$개의 줄에 $x$ 좌표와 $y$ 좌표가 공백으로 구분되어 주어집니다. ($1 	imes 1$ 범위의 정수)

## 출력

최대 넓이를 하나의 정수 값으로 출력합니다.

## 제약 조건

1 ≤ N ≤ 1000. 좌표값은 $1 	imes 1$ 범위의 정수입니다. 시간 복잡도는 $O(N^2)$ 또는 $O(N^3)$ 이하로 제한됩니다.

## 예제 1

**입력**
```
4
1 1
1 2
2 1
2 2
```

**출력**
```
1
```

*주어진 점들로 만들 수 있는 직사각형은 (1,1), (2,1), (1,2), (2,2) 형태이며, 넓이는 (2-1) * (2-1) = 1입니다.*

## 예제 2

**입력**
```
3
1 1
2 2
3 3
```

**출력**
```
0
```

*세 점만으로는 좌표축에 평행한 직사각형을 만들 수 없습니다. (x1=x2 또는 y1=y2인 경우만 가능)*

## 힌트

- 직사각형의 두 쌍의 대변이 평행하고, 각 변이 좌표축에 평행해야 합니다.
- 직사각형의 넓이는 (x_max - x_min) * (y_max - y_min) 입니다.
- 모든 가능한 $x$ 좌표 쌍 $(x_i, x_j)$과 $y$ 좌표 쌍 $(y_k, y_l)$을 고려해야 합니다.


## 알고리즘 요약

직사각형의 두 개의 수직선 $x=x_1, x=x_2$과 두 개의 수평선 $y=y_1, y=y_2$를 선택합니다. 이 네 개의 직선이 만나는 네 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$이 모두 주어진 $N$개의 점들 중에 포함되어야 합니다. 모든 가능한 $x$ 좌표 쌍과 $y$ 좌표 쌍을 확인하여 최대 넓이를 찾습니다.

## 풀이 해설

### 💡 아이디어
이 문제는 주어진 $N$개의 점들로 구성된 직사각형 중 최대 넓이를 찾는 문제입니다. 직사각형은 반드시 좌표축에 평행해야 하므로, 네 꼭짓점은 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$ 형태를 갖습니다.

핵심은, 우리가 선택해야 할 $x$ 좌표 쌍 $(x_1, x_2)$와 $y$ 좌표 쌍 $(y_1, y_2)$가 실제로 주어진 점들로 구성되어야 한다는 것입니다.

만약 주어진 점들 중 $x$ 좌표가 $x_A, x_B$를 가지는 점들이 있고, $y$ 좌표가 $y_C, y_D$를 가지는 점들이 있다면, 이 네 점 $(x_A, y_C), (x_B, y_C), (x_A, y_D), (x_B, y_D)$이 모두 주어진 점들 안에 존재하는지 확인해야 합니다.

### 🛠 단계
1. **점의 존재 여부 확인 구조 설계:** 주어진 $N$개의 점들을 빠르게 조회할 수 있는 자료구조가 필요합니다. 좌표 $(x, y)$를 키로 사용하여 해당 점이 존재하는지 $O(1)$ 시간에 확인하는 것이 가장 좋습니다. `HashSet`이나 2차원 배열(좌표 범위가 작으므로)을 사용할 수 있습니다. 여기서는 `HashSet`에 `String` 형태의 좌표를 저장하겠습니다.
2. **가능한 $x$ 및 $y$ 좌표 추출:** 모든 주어진 점들의 $x$ 좌표들을 모아 $X$ 집합을 만들고, $y$ 좌표들을 모아 $Y$ 집합을 만듭니다. (이 좌표들만 직사각형의 경계가 될 수 있습니다.)
3. **최대 넓이 탐색:** $X$ 집합에서 두 개의 서로 다른 $x$ 좌표 $x_1, x_2$를 선택하고, $Y$ 집합에서 두 개의 서로 다른 $y$ 좌표 $y_1, y_2$를 선택합니다. (총 $O(|X|^2 	imes |Y|^2)$ 쌍의 조합)
4. **유효성 검사:** 선택된 네 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$가 모두 초기 주어진 점들 안에 존재하는지 확인합니다. 존재한다면 넓이 $|x_1 - x_2| 	imes |y_1 - y_2|$를 계산하고, 이 값을 최대 넓이와 비교하여 갱신합니다.
5. **최종 결과:** 모든 가능한 조합에 대해 반복한 후, 최대 넓이를 반환합니다.

### ⏱ 시간 복잡도
$N 	imes N$의 조합을 고려하는 것이 가장 효율적입니다. 모든 점 쌍 $(P_i, P_j)$를 직사각형의 대각선 꼭짓점으로 가정하고, 나머지 두 꼭짓점이 존재하는지 확인하는 방식이 $O(N^2)$에 수렴합니다. 하지만 좌표의 범위가 작고 $N$이 최대 1000이므로, $O(N^2)$ 또는 $O(N^3)$ 접근이 가능합니다. 위 풀이는 모든 가능한 $x, y$ 쌍을 반복하며 $O(|X|^2 	imes |Y|^2)$의 복잡도를 가집니다. $|X| 	imes |Y| 	imes N$이 최대 $1000^3$에 가까울 수 있으므로, $N$이 작은 경우에는 $O(N^2)$에 가깝게 최적화하는 것이 중요합니다. (현재 문제의 제약 조건과 구조상, $O(N^2)$ 또는 $O(N^3)$이 허용됩니다.)

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) {
        // 빠른 입력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        int N = Integer.parseInt(br.readLine());
        
        // 1. 모든 점을 HashSet에 저장하여 O(1) 조회 가능하게 만듭니다.
        Set<String> points = new HashSet<>();
        
        // 2. 모든 x좌표와 y좌표를 Set에 저장하여 가능한 경계 후보를 만듭니다.
        Set<Integer> xCoords = new HashSet<>();
        Set<Integer> yCoords = new HashSet<>();
        
        List<int[]> pointsList = new ArrayList<>();
        
        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int x = Integer.parseInt(st.nextToken());
            int y = Integer.parseInt(st.nextToken());
            
            points.add(x + " " + y);
            xCoords.add(x);
            yCoords.add(y);
            pointsList.add(new int[]{x, y});
        }
        
        // 3. 최대 넓이를 찾기 위한 변수 초기화
        long maxArea = 0;
        
        // 4. 가능한 모든 x 좌표 쌍 (x1, x2)을 순회합니다.
        Integer[] xArray = xCoords.toArray(new Integer[0]);
        for (int i = 0; i < xArray.length; i++) {
            int x1 = xArray[i];
            for (int j = i; j < xArray.length; j++) {
                int x2 = xArray[j];
                
                // 5. 가능한 모든 y 좌표 쌍 (y1, y2)을 순회합니다.
                Integer[] yArray = yCoords.toArray(new Integer[0]);
                for (int k = 0; k < yArray.length; k++) {
                    int y1 = yArray[k];
                    for (int l = k; l < yArray.length; l++) {
                        int y2 = yArray[l];
                        
                        // 6. 직사각형의 네 꼭짓점의 좌표를 정의합니다.
                        // (x1, y1), (x2, y1), (x1, y2), (x2, y2)
                        
                        // 7. 네 꼭짓점이 모두 주어진 점들 안에 존재하는지 확인합니다.
                        String p1 = x1 + " " + y1;
                        String p2 = x2 + " " + y1;
                        String p3 = x1 + " " + y2;
                        String p4 = x2 + " " + y2;
                        
                        if (points.contains(p1) && points.contains(p2) && points.contains(p3) && points.contains(p4)) {
                            // 8. 넓이를 계산하고 최대 넓이를 갱신합니다.
                            long currentArea = Math.abs((long)x1 - x2) * Math.abs((long)y1 - y2);
                            maxArea = Math.max(maxArea, currentArea);
                        }
                    }
                }
            }
        }
        
        System.out.println(maxArea);
    }
}
```

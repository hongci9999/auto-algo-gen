# 최소 비용으로 경로 덮기
*java · DP · 보통 · 동적계획법, 경로탐색*

## 입출력 환경

Java 환경에서 BufferedReader와 StringTokenizer를 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

N x M 크기의 격자판이 주어집니다. 이 격자판에는 1로 표시된 칸들(돌)이 존재합니다. 당신은 최소의 비용으로 이 격자판의 모든 1로 표시된 칸을 적어도 한 번씩 지나가야 합니다. 이동은 상하좌우 네 방향으로만 가능하며, 각 칸을 지나갈 때마다 비용이 발생합니다. 비용은 칸 자체의 값에 의해 결정됩니다.

다만, 이 문제의 특성상 '지나간다'는 것은 해당 칸을 방문한다는 의미이며, 한 번 방문한 칸은 다시 방문해도 비용이 추가되지 않습니다. 즉, 방문한 칸을 지나갈 때의 비용은 0입니다. 오직 처음 방문하는 칸에만 비용이 발생합니다.

이 문제에서는 격자판의 칸 값이 곧 그 칸을 '최초로' 방문하는 비용이라고 가정합니다. 모든 1로 표시된 칸을 최소 비용으로 덮는 경로를 찾아야 합니다. (모든 1로 표시된 칸은 반드시 방문해야 합니다.)

## 입력

첫째 줄에 N과 M이 주어집니다. (1 <= N, M <= 15)
다음 N줄에 걸쳐 M개의 정수로 이루어진 격자판이 주어집니다. (0 또는 1)

## 출력

최소 비용을 찾아 출력합니다.

## 제약 조건

1 <= N, M <= 15. 격자판의 값은 0 또는 1입니다. (N*M이 최대 225이지만, 실제 비용이 발생하는 칸은 1로 표시된 칸만 고려합니다.)

## 예제 1

**입력**
```
3 3
1 1 0
1 1 1
0 1 1
```

**출력**
```
8
```

*1로 표시된 7개 칸을 모두 방문해야 합니다. 최소 비용의 연결 구조를 찾아 8이 나옵니다.*

## 예제 2

**입력**
```
2 2
1 1
1 1
```

**출력**
```
4
```

*모든 칸이 1이므로 4개의 칸을 연결하는 최소 비용은 4입니다.*

## 힌트

- 이 문제는 최소 신장 트리(MST)를 구하는 문제로 해석됩니다.
- Prim 또는 Kruskal 알고리즘을 사용하여 MST를 구하면 됩니다.
- 간선 가중치는 두 노드 사이의 최단 경로 비용입니다.


## 알고리즘 요약

이 문제는 모든 '1'로 표시된 칸들을 최소 비용으로 연결하는 경로를 찾는 문제입니다. 1로 표시된 칸들의 개수(K)가 작고(K <= 15), 이 칸들 사이의 이동 비용은 격자판의 값으로 결정됩니다. 따라서, 모든 1로 표시된 칸들을 집합으로 보고, 이들 사이의 연결 비용을 최소화하는 방식으로 접근합니다. 이는 일반적으로 최소 신장 트리(MST) 문제로 해석될 수 있으며, 상태 공간이 작다면 비트마스크 DP를 활용하여 순회하는 방식을 사용합니다.

## 풀이 해설

### 아이디어: 비트마스크 DP와 최소 신장 트리 (MST) 결합

이 문제는 모든 '1'로 표시된 칸(총 K개)을 방문해야 하며, 방문 비용은 최초 방문 시에만 발생합니다. 따라서, K개의 칸을 연결하는 최소 비용의 구조를 찾아야 합니다.

1. **핵심 칸 추출 및 매핑**: 먼저, 격자판 전체에서 '1'로 표시된 모든 칸들의 좌표를 추출합니다. 이 칸들을 $P_1, P_2, \dots, P_K$라고 하겠습니다. 이 칸들이 DP의 노드가 됩니다.
2. **거리 계산**: 임의의 두 칸 $P_i$와 $P_j$ 사이의 최소 이동 비용 $dist(P_i, P_j)$를 계산해야 합니다. 이 거리는 격자판의 값(비용)을 고려한 최단 경로(BFS 또는 다익스트라)로 계산할 수 있습니다. 격자판의 값은 0 또는 1이므로, BFS를 변형하여 최소 비용을 찾습니다.
3. **MST 문제로 변환**: 우리가 찾는 최소 비용 경로는 결국 $K$개의 노드 $P_1, elldots, P_K$를 포함하는 최소 비용의 연결 구조입니다. 이는 MST 문제와 같습니다.
4. **DP 상태 정의**: 일반적인 MST는 Kruskal 또는 Prim 알고리즘으로 풀지만, 격자판이라는 제약 조건과 '경로'의 개념을 도입하기 위해 DP를 사용합니다. 하지만 이 경우, 모든 노드를 연결하는 최소 비용은 단순히 MST로 구하는 것이 가장 정확합니다.

*실제 문제 해석 및 수정*: 이 문제는 $K$개의 칸을 모두 방문하는 최소 비용 경로를 찾는 문제입니다. 모든 칸이 연결되어 있다고 가정할 때, 최소 비용은 $K$개의 칸을 포함하는 최소 스패닝 트리의 총 비용과 같습니다. 즉, 모든 $P_i$를 포함하는 최소 비용의 연결 구조를 찾아야 합니다.

**풀이 단계 (MST 사용)**:
1. **1로 표시된 칸 찾기**: 모든 '1' 칸의 좌표를 찾아 배열에 저장합니다. (K개)
2. **완전 그래프 비용 계산**: 모든 $P_i$ 쌍에 대해 $dist(P_i, P_j)$를 계산합니다. $dist(P_i, P_j)$는 시작점 $P_i$에서 끝점 $P_j$까지의 최소 비용을 BFS/다익스트라를 이용해 구합니다.
3. **MST 계산**: $K$개의 노드를 가진 완전 그래프 $(P_1, elldots, P_K)$를 만들고, 이 그래프의 가중치 $dist(P_i, P_j)$를 사용하여 Prim 또는 Kruskal 알고리즘으로 MST 비용을 계산합니다. 이 비용이 최소 비용입니다.

**시간 복잡도**: $K$는 최대 225이지만, 제약 조건 상 $N, M ellle 15$ 이므로 $K ellle 225$ 입니다. 만약 $K$가 작다고 가정한다면 (예: $K ellle 15$), MST는 $O(K^2 ellor K^2 ellor E elllog E)$로 해결 가능합니다. 하지만 $K$가 크다면 (최대 225), $O(N ellcdot M elllog(N ellcdot M))$ 수준의 복잡도를 가지게 됩니다. $N, M ellle 15$이므로 $N ellcdot M ellle 225$이며, $K$를 노드 수로 하는 MST는 충분히 빠르게 계산 가능합니다. 따라서, 다익스트라(BFS 변형)를 $K$번 실행하여 모든 쌍의 거리를 구한 후, Prim 알고리즘을 적용합니다.

## 참고 코드 (java)

```java
import java.util.*;
import java.io.*;

class Solution {
    static class Cell {
        int r, c, cost;
        public Cell(int r, int c, int cost) {
            this.r = r; this.c = c; this.cost = cost;
        }
    }

    // 다익스트라를 사용하여 (startR, startC)에서 모든 칸까지의 최소 비용 계산
    // 결과는 startR, startC와 같은 배열 크기의 2차원 배열에 저장됨
    private static int[][] dijkstra(int startR, int startC, int N, int M, int[][] grid) {
        int[][] dist = new int[N][M];
        for (int i = 0; i < N; i++) Arrays.fill(dist[i], Integer.MAX_VALUE);

        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));

        // [비용, r, c] 형태로 저장
        dist[startR][startC] = 0;
        pq.add(new int[]{0, startR, startC});

        int[] dr = {0, 0, 1, -1}; 
        int[] dc = {1, -1, 0, 0};

        while (!pq.isEmpty()) {
            int[] current = pq.poll();
            int d = current[0];
            int r = current[1];
            int c = current[2];

            if (d > dist[r][c]) continue;

            for (int i = 0; i < 4; i++) {
                int nr = r + dr[i];
                int nc = c + dc[i];

                if (nr >= 0 && nr < N && nc >= 0 && nc < M) {
                    // 다음 칸의 비용은 0 또는 1
                    int nextCost = grid[nr][nc];
                    int newDist = dist[r][c] + nextCost;

                    if (newDist < dist[nr][nc]) {
                        dist[nr][nc] = newDist;
                        pq.add(new int[]{newDist, nr, nc});
                    }
                }
            }
        }
        return dist;
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        
        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());

        int[][] grid = new int[N][M];
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 1. '1'로 표시된 모든 칸의 좌표를 찾습니다.
        List<int[]> startPoints = new ArrayList<>();
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                if (grid[i][j] == 1) {
                    startPoints.add(new int[]{i, j});
                }
            }
        }

        int K = startPoints.size();
        if (K == 0) {
            System.out.println(0);
            return;
        }

        // 2. 모든 '1' 지점 쌍 사이의 최소 비용을 계산합니다. (K x K 거리 행렬)
        // distMatrix[i][j]는 startPoints[i]에서 startPoints[j]까지의 최소 비용
        int[][] distMatrix = new int[K][K];
        // 각 시작 지점마다 다익스트라를 실행하여 모든 지점까지의 거리를 구합니다.
        for (int i = 0; i < K; i++) {
            int startR = startPoints.get(i)[0];
            int startC = startPoints.get(i)[1];
            // 모든 칸까지의 비용을 계산하는 다익스트라 실행
            int[][] allDist = dijkstra(startR, startC, N, M, grid);

            for (int j = 0; j < K; j++) {
                int endR = startPoints.get(j)[0];
                int endC = startPoints.get(j)[1];
                // startPoints[i]에서 startPoints[j]로의 최소 비용을 저장합니다.
                distMatrix[i][j] = allDist[endR][endC];
            }
        }

        // 3. Prim 알고리즘을 사용하여 K개의 노드를 포함하는 MST 비용을 계산합니다.
        // MST는 모든 1로 표시된 칸들을 최소 비용으로 연결하는 최소 비용의 연결 구조입니다.
        
        int[] minCost = new int[K];
        Arrays.fill(minCost, Integer.MAX_VALUE);
        minCost[0] = 0;

        boolean[] visited = new boolean[K];
        long totalMinCost = 0;

        for (int count = 0; count < K; count++) {
            // 가장 비용이 적게 드는, 아직 방문하지 않은 노드를 선택
            int u = -1; 
            int minD = Integer.MAX_VALUE;
            for (int i = 0; i < K; i++) {
                if (!visited[i] && minCost[i] < minD) {
                    minD = minCost[i];
                    u = i;
                }
            }
            
            if (u == -1) break; // 모든 노드가 처리되었거나 연결 불가능
            
            visited[u] = true;
            totalMinCost += minCost[u];

            // u와 연결된 모든 인접 노드(아직 방문하지 않은 노드)의 최소 비용을 갱신
            for (int v = 0; v < K; v++) {
                if (!visited[v]) {
                    // distMatrix[u][v]는 u -> v 비용, distMatrix[v][u]는 v -> u 비용. 둘 다 동일해야 함.
                    // (다익스트라가 모든 칸을 고려했으므로 대칭성이 보장됨)
                    int weight = distMatrix[u][v];
                    if (weight < minCost[v]) {
                        minCost[v] = weight;
                    }
                }
            }
        }
        
        System.out.println(totalMinCost);
    }
}
```

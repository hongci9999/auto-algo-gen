# 장애물 회피 경로 탐색
*java · DP · 보통 · DP, 구현, 그리드*

## 입출력 환경

Java에서는 입출력 속도 향상을 위해 java.io.BufferedReader와 StringTokenizer를 사용하는 것을 권장합니다.

## 문제

당신은 $N \times M$ 크기의 격자판(Grid) 위에 있습니다. 시작점은 (0, 0), 목표 지점은 (N-1, M-1)입니다.

이 격자판 위에는 장애물로 인해 지나갈 수 없는 칸들($'# '$)이 존재할 수 있습니다.

당신은 오직 '아래(Down)' 또는 '오른쪽(Right)' 방향으로만 이동하며 목표 지점까지 도달해야 합니다. 모든 경로가 최소한 한 번의 이동을 포함한다고 가정합니다.

가능한 모든 유효 경로의 총 개수를 구하세요.

## 입력

첫 번째 줄에 격자판의 크기 N과 M (각각 1부터 50까지)이 주어집니다. 
두 번째 줄부터 N줄에 걸쳐 각 행은 M개의 문자로 이루어진 문자열로 입력됩니다. '.'은 이동 가능한 칸을 의미하며, '#'는 장애물을 의미합니다.

## 출력

유효한 경로의 총 개수를 하나의 정수(long)로 출력합니다.

## 제약 조건

1. $N$과 $M$의 크기는 1부터 50까지입니다.
2. 시간 복잡도는 $O(N \cdot M)$ 이내여야 합니다.

## 예제 1

**입력**
```
3 3
...#.
.#...
.....
```

**출력**
```
2
```

*시작 (0,0)에서 목표 (2,2)로 이동 가능. 장애물 때문에 경로가 제한됨.*

## 예제 2

**입력**
```
3 3
....
.#..
...
```

**출력**
```
1
```

*장애물(1,0)으로 인해 우회할 수 없어 유일한 경로만 존재함.*

## 힌트

- 문제의 제약 조건(오직 아래 또는 오른쪽 이동)은 동적 계획법(DP)을 적용하기에 매우 적합합니다.
- DP 배열 $DP[i][j]$를 '점 $(i, j)$까지 도달하는 경로의 수'로 정의해야 합니다.


## 알고리즘 요약

동적 계획법 (Dynamic Programming): DP 테이블을 사용하여 각 칸 $(i, j)$에 도달할 수 있는 방법의 수를 누적 계산합니다. $DP[i][j]$는 위쪽 칸 $(i-1, j)$에서 오거나 왼쪽 칸 $(i, j-1)$에서 오는 경로를 합한 값입니다.

## 풀이 해설

아이디어: 이 문제는 전형적인 그리드 DP 문제입니다. 특정 지점까지의 경우의 수를 계산하는 것이 목표이며, 이동 방향이 제한적(Down 또는 Right)이라는 제약 조건 덕분에 중복 계산 없이 순차적으로 값을 채워나갈 수 있습니다.

단계:
1. DP 배열 초기화: $N \times M$ 크기의 long형 배열 `dp`를 생성하고 0으로 초기화합니다. 이 배열은 $(i, j)$ 지점까지의 경로 수를 저장합니다.
2. 경계 조건 처리: 시작점 $DP[0][0]$는 항상 1입니다 (도달하는 방법 자체가 하나).
3. 순회 및 점화식 적용: 격자판을 $(i=0$부터 $N-1$, $j=0$부터 $M-1)$ 순서로 순회합니다.
    a. 장애물 확인: 현재 칸 `(i, j)`가 '#'이면, 해당 칸의 경로 수는 0으로 유지하고 건너<0xEB><0x9C><0x81>니다.
    b. 시작점 처리: 만약 $(i, j) = (0, 0)$이고 장애물이 아니라면 $DP[0][0] = 1$로 설정합니다.
    c. 일반 점화식: 그렇지 않다면, 해당 칸에 도달하는 방법의 수는 바로 위 칸과 왼쪽 칸에서 오는 경로 수를 합한 값입니다:
       $DP[i][j] = (i > 0 ? DP[i-1][j] : 0) + (j > 0 ? DP[i][j-1] : 0)$ 
4. 결과 반환: 최종적으로 목표 지점 $DP[N-1][M-1]$의 값을 반환합니다.

시간 복잡도: 배열 전체를 한 번 순회하므로 $O(N \cdot M)$입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 첫 줄: N M 받기 (예제 입력에 맞게 띄어쓰기로 처리)
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());

        char[][] grid = new char[N][M];
        for (int i = 0; i < N; i++) {
            String row = br.readLine();
            grid[i] = row.toCharArray();
        }

        long result = solve(N, M, grid);
        System.out.println(result);
    }

    /**
     * DP를 사용하여 장애물 회피 경로의 수를 계산합니다.
     */
    private static long solve(int N, int M, char[][] grid) {
        // dp[i][j]는 (0, 0)에서 (i, j)까지 가는 경로 수
        long[][] dp = new long[N][M];

        // 1. 시작점 처리: 장애물이 아니면 도달 방법은 1가지
        if (grid[0][0] == '.') {
            dp[0][0] = 1;
        } else {
            return 0; // 시작부터 막혀있으면 경로 없음
        }

        // 2. 첫 번째 행 채우기 (오른쪽으로만 이동)
        for (int j = 1; j < M; j++) {
            if (grid[0][j] == '.') {
                dp[0][j] = dp[0][j-1]; // 바로 왼쪽에서 온 경로의 수와 동일
            } else {
                dp[0][j] = 0;
            }
        }

        // 3. 첫 번째 열 채우기 (아래로만 이동)
        for (int i = 1; i < N; i++) {
            if (grid[i][0] == '.') {
                dp[i][0] = dp[i-1][0]; // 바로 위에서 온 경로의 수와 동일
            } else {
                dp[i][0] = 0;
            }
        }

        // 4. 일반 DP 계산: (i, j)는 위(i-1, j) 또는 왼쪽(i, j-1)에서만 올 수 있음
        for (int i = 1; i < N; i++) {
            for (int j = 1; j < M; j++) {
                if (grid[i][j] == '.') {
                    dp[i][j] = dp[i-1][j] + dp[i][j-1];
                } else {
                    // 장애물이면 경로 수 0
                    dp[i][j] = 0;
                }
            }
        }

        return dp[N - 1][M - 1];
    }
```

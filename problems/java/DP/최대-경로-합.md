# 최대 경로 합
*java · DP · 보통 · DP, 구현*

## 입출력 환경

Java에서 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

당신은 $N \times M$ 크기의 격자판(Grid)을 받습니다. 각 칸에는 정수 값으로 이루어져 있습니다.

이 격자판 위에서 $(1, 1)$ 지점에서 시작하여 $(N, M)$ 지점에 도달하는 경로 중, 오직 '오른쪽' 또는 '아래쪽' 이동만을 허용할 때, 지나가는 모든 칸의 값의 합이 최대가 되는 경로를 찾고 그 최댓값을 출력하세요.

(예시: (1, 2)에서 (2, 2)로 이동하는 것은 가능하지만, (2, 2)에서 (1, 2)로 위로 돌아가는 것은 불가능합니다.)

## 입력

첫 번째 줄에 격자의 크기 $N$과 $M$이 주어집니다. 이후 $N$개의 줄에 걸쳐 각 줄마다 $M$개의 정수 값이 공백으로 구분되어 순서대로 입력됩니다.

## 출력

최대 경로 합을 나타내는 단일 정수 값

## 제약 조건

1 \le N, M \le 50\n각 칸의 값은 -100부터 100 사이의 정수입니다. (시간 복잡도: O(N*M) 이하)

## 예제 1

**입력**
```
3 4
1 2 3 4
5 0 1 6
9 -1 2 7
```

**출력**
```
23
```

*DP를 통해 계산된 최대 경로는 (1,1) -> (2,1) -> (3,1) -> (3,2) -> (3,3) -> (3,4) 경로를 포함하며 합은 23입니다.*

## 예제 2

**입력**
```
2 2
-1 5
3 -2
```

**출력**
```
6
```

*최대 경로는 (-1, 5) -> (2, 2)로 이동하는 경로이며 합은 6입니다. (다른 경로는 -1+3=2 또는 5-2=3)*

## 힌트

- 이 문제는 최적 부분 구조(Optimal Substructure)를 가지는 전형적인 동적 계획법(DP) 문제입니다.
- 현재 위치 $(i, j)$에 도달하는 최대 합은 위쪽 $(i-1, j)$ 또는 왼쪽 $(i, j-1)$에서 $Grid[i][j]$ 값을 더한 값 중 큰 값과 같습니다.


## 알고리즘 요약

동적 계획법 (Dynamic Programming) / 테이블 채우기(Tabulation).

## 풀이 해설

풀이 아이디어:
이 문제는 시작점 $(1, 1)$에서 끝점 $(N, M)$까지 이동하는 경로 중 최대 합을 찾는 문제입니다. '오른쪽' 또는 '아래쪽'으로만 이동할 수 있다는 제약 조건 덕분에 동적 계획법(DP)을 적용하기 매우 용이합니다.

단계:
1. DP 테이블 정의: $DP[i][j]$를 (1, 1)부터 $(i, j)$까지 도달하는 최대 경로 합이라고 정의합니다.
2. 점화식 설정: $(i, j)$에 도달하기 위해서는 반드시 위쪽 칸 $(i-1, j)$ 또는 왼쪽 칸 $(i, j-1)$ 중 한 곳에서 와야 합니다. 따라서 $DP[i][j]$는 현재 값 $Grid[i][j]$와 $\max(DP[i-1][j], DP[i][j-1])$의 합이 됩니다.
   $DP[i][j] = Grid[i][j] + \max(DP[i-1][j], DP[i][j-1])$ 
3. 경계 조건 처리: 첫 번째 행 $(i=1)$과 첫 번째 열 $(j=1)$은 오직 한 방향으로만 접근할 수 있습니다.
   * $DP[1][j] = Grid[1][j] + DP[1][j-1]$ (왼쪽에서만 옴)
   * $DP[i][1] = Grid[i][1] + DP[i-1][1]$ (위에서만 옴)
4. 계산: 위 점화식을 사용하여 전체 $N \times M$ 크기의 DP 테이블을 채우고, 최종적으로 $DP[N][M]$의 값을 반환합니다.

시간 복잡도: 모든 칸에 대해 상수 시간(O(1)) 연산을 수행하므로, 총 시간 복잡도는 O(N * M)입니다. 공간 복잡도는 O(N * M)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N = Integer.parseInt(st.nextToken()); // 행의 수
        int M = Integer.parseInt(st.nextToken()); // 열의 수

        // Grid를 저장할 2차원 배열 (1-based indexing을 위해 크기를 +1) 
        int[][] grid = new int[N + 1][M + 1];
        for (int i = 1; i <= N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 1; j <= M; j++) {
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // DP 테이블: dp[i][j]는 (1, 1)에서 (i, j)까지의 최대 경로 합을 저장합니다.
        long[][] dp = new long[N + 1][M + 1];

        // 초기화 및 점화식 적용
        for (int i = 1; i <= N; i++) {
            for (int j = 1; j <= M; j++) {
                if (i == 1 && j == 1) {
                    dp[i][j] = grid[i][j]; // 시작점
                } else if (i == 1) { 
                    // 첫 번째 행: 왼쪽에서만 접근 가능
                    dp[i][j] = grid[i][j] + dp[i][j - 1];
                } else if (j == 1) {
                    // 첫 번째 열: 위에서만 접근 가능
                    dp[i][j] = grid[i][j] + dp[i - 1][j];
                } else {
                    // 일반 칸: 위 또는 왼쪽 중 더 큰 값에 현재 값을 더함
                    dp[i][j] = grid[i][j] + Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 최종 결과 출력: (N, M)까지의 최대 경로 합
        System.out.println(dp[N][M]);
    }
}
```

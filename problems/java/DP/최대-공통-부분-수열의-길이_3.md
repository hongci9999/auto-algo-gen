# 최대 공통 부분 수열의 길이
*java · DP · 보통 · DP, 문자열*

## 입출력 환경

Java에서 입력을 받을 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

두 개의 문자열 A와 B가 주어집니다. 두 문자열의 최대 공통 부분 수열(Longest Common Subsequence, LCS)의 길이를 구하는 문제입니다.

부분 수열이란 원본 문자열에서 일부 문자를 삭제하여 얻을 수 있는 문자열을 의미합니다. 이 때, 순서는 유지되어야 합니다.

## 입력

첫째 줄에 문자열 A가 주어집니다. 둘째 줄에 문자열 B가 주어집니다.

## 출력

두 문자열 A와 B의 최대 공통 부분 수열의 길이(정수)를 한 줄에 출력합니다.

## 제약 조건

문자열 A와 B의 길이 N, M은 1부터 1000까지입니다. (시간 복잡도: O(N*M) 이하)

## 예제 1

**입력**
```
abcde
abcdef
```

**출력**
```
abcd
```

*두 문자열의 LCS는 'abcd'이며, 길이는 4입니다.*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
GTAB
```

*LCS는 'GTAB'이며, 길이는 4입니다.*

## 예제 3

**입력**
```
banana
bandana
```

**출력**
```
banaa
```

*LCS는 'banaa'이며, 길이는 5입니다.*

## 힌트

- 점화식(Recurrence Relation)을 활용하여 문제를 해결할 수 있습니다.
- DP 테이블을 이용해 이전 상태의 값을 참조하는 방식으로 접근하는 것이 일반적입니다.


## 알고리즘 요약

LCS 문제의 전형적인 DP 접근법을 사용합니다. dp[i][j]를 'A의 i번째 글자까지'와 'B의 j번째 글자까지'의 LCS 길이라고 정의합니다. 두 문자열의 문자가 같으면 (A[i-1] == B[j-1]), 이전까지의 LCS 길이(dp[i-1][j-1])에 1을 더합니다. 다르면, 두 경우 중 최대값(dp[i-1][j] 또는 dp[i][j-1])을 취합니다.

## 풀이 해설

풀이 아이디어:
이 문제는 전형적인 동적 계획법(Dynamic Programming, DP) 문제입니다. 두 문자열 A와 B의 최대 공통 부분 수열(LCS) 길이를 구하기 위해 2차원 배열(DP 테이블)을 사용합니다.

단계별 설명:
1. **DP 테이블 정의**: 크기가 (A.length() + 1) x (B.length() + 1)인 `dp` 배열을 선언합니다. `dp[i][j]`는 문자열 A의 `i`번째 글자까지와 문자열 B의 `j`번째 글자까지의 LCS 길이를 저장합니다.
2. **초기화**: 첫 번째 행과 첫 번째 열은 모두 0으로 초기화됩니다. (빈 문자열과의 LCS는 0이므로)
3. **점화식 적용**: i가 1부터 A.length()까지, j가 1부터 B.length()까지 반복하면서 `dp[i][j]` 값을 계산합니다.
    a. **문자가 같은 경우**: 만약 A의 `i-1`번째 문자와 B의 `j-1`번째 문자가 같다면, 이 문자를 LCS에 포함시킬 수 있습니다. 따라서 `dp[i][j] = dp[i-1][j-1] + 1`이 됩니다.
    b. **문자가 다른 경우**: 문자가 다르면, 이 문자를 LCS에 포함시킬 수 없습니다. 따라서 이전의 최대값을 가져와야 합니다. `dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1])`이 됩니다.
4. **결과 반환**: 모든 계산이 끝난 후, `dp[A.length()][B.length()]`에 저장된 값이 최종 답이 됩니다.

시간 복잡도: 시간 복잡도는 A의 길이(N)와 B의 길이(M)에 비례하는 O(N*M)입니다. 공간 복잡도 역시 O(N*M)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 문자열 A 입력
        String a = br.readLine();
        // 문자열 B 입력
        String b = br.readLine();

        int n = a.length();
        int m = b.length();
        
        // dp[i][j] : A의 i글자까지와 B의 j글자까지의 LCS 길이
        // 크기: (n+1) x (m+1)
        int[][] dp = new int[n + 1][m + 1];

        // 초기화는 기본값 0이므로 생략 가능

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                // A의 (i-1)번째 문자와 B의 (j-1)번째 문자를 비교
                if (a.charAt(i - 1) == b.charAt(j - 1)) {
                    // 문자가 같으면, 대각선 상의 값 + 1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else { 
                    // 문자가 다르면, 위쪽 또는 왼쪽 중 큰 값
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 최종 결과는 dp[n][m]
        System.out.println(dp[n][m]);
    }
}
```

# 그리드 경로 합 최대화
*java · DP · 보통 · DP, 그리드, 경로탐색*

## 입출력 환경

Java 환경에서 입력을 처리할 때는 BufferedReader와 StringTokenizer를 사용하여 빠르고 효율적으로 입력을 받는 것이 좋습니다.

## 문제

당신은 N행 M열 크기의 그리드 위를 움직이는 로봇입니다. 그리드의 각 칸 (i, j)에는 해당 칸의 값 A[i][j]가 적혀 있습니다. 로봇은 반드시 시작점 (0, 0)에서 목표점 (N-1, M-1)까지 도달해야 하며, 이동은 오직 '아래(Down)' 또는 '오른쪽(Right)' 방향으로만 가능합니다.

로봇이 지나가는 모든 칸의 값들을 합한 총합이 최대가 되도록 경로를 선택하는 것이 목표입니다.

주어진 그리드와 크기를 바탕으로, 최대 경로 합을 구하세요.

## 입력

첫 번째 줄에 N과 M (각각 그리드의 행과 열의 크기)이 공백으로 구분되어 주어집니다. 이후 N개의 줄에 걸쳐 M개의 정수 값이 순서대로 주어지며, 이것이 그리드 A[i][j]의 값을 나타냅니다. (A[0][0]부터 A[N-1][M-1]까지 순서로 입력됩니다.)

## 출력

최대 경로 합을 나타내는 단일 정수 값을 출력합니다.

## 제약 조건

1 <= N, M <= 1000
-10^9 <= A[i][j] <= 10^9
시간 복잡도: O(N*M) 이하

## 예제 1

**입력**
```
3 3
1 2 3
5 1 1
2 4 3
```

**출력**
```
13
```

*경로: (0,0) -> (1,0) -> (2,0) -> (2,1) -> (2,2). 합계: 1+5+2+4+3 = 15. (Wait, sample explanation needs correction based on the actual path). 최대 경로는 1 -> 2 -> 3 -> 1 -> 3 (오류). 실제 최대 경로는 (0,0)->(1,0)->(1,1)->(1,2)->(2,2) 또는 (0,0)->(0,1)->(1,1)->(2,1)->(2,2) 입니다. 최대값은 1+5+1+4+3 = 14 입니다.*

## 예제 2

**입력**
```
2 2
1 1
1 1
```

**출력**
```
3
```

*경로 (0,0) -> (0,1) -> (1,1) 또는 (0,0) -> (1,0) -> (1,1). 합계: 1+1+1 = 3.*

## 힌트

- 이 문제는 동적 계획법(DP)으로 해결할 수 있습니다.
- DP 배열을 정의할 때, '어떤 지점까지 도달하는 최대 합'을 저장하도록 설계해야 합니다.


## 알고리즘 요약

동적 계획법 (Dynamic Programming)

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어 (Dynamic Programming):
이 문제는 최적의 경로 합을 찾는 전형적인 DP 문제입니다. 어떤 칸 (i, j)에 도달하는 최대 합을 계산하려면, 이전 칸에서 (i, j)로 올 수 있는 모든 경로 중 최대 합을 가져와야 합니다.

2. DP 정의:
$DP[i][j]$를 '시작점 (0, 0)에서 그리드 칸 (i, j)까지 도달할 수 있는 최대 경로 합'이라고 정의합니다.

3. 점화식 (Recurrence Relation):
(i, j)에 도달하기 위해서는 (i-1, j) (위에서 아래로) 또는 (i, j-1) (왼쪽에서 오른쪽으로) 둘 중 한 칸에서 와야 합니다. 따라서 $DP[i][j]$는 다음 값들의 최대값에 현재 칸의 값 $A[i][j]$를 더한 값이 됩니다.

$DP[i][j] = A[i][j] + \max(DP[i-1][j], DP[i][j-1])$

4. 초기 조건 (Base Cases):
*   $DP[0][0] = A[0][0]$ (시작점)
*   첫 번째 행 (i=0):
    $DP[0][j] = A[0][j] + DP[0][j-1]$ (오른쪽으로만 이동 가능)
*   첫 번째 열 (j=0):
    $DP[i][0] = A[i][0] + DP[i-1][0]$ (아래로만 이동 가능)

5. 단계:
먼저 $N 	imes M$ 크기의 DP 배열을 초기화합니다. 위에서 정의한 초기 조건들을 채운 후, 나머지 칸부터 순차적으로 (i=1부터 N-1, j=1부터 M-1) 점화식을 적용하여 $DP[i][j]$를 계산합니다. 최종 답은 $DP[N-1][M-1]$입니다.

시간 복잡도: 모든 칸에 대해 상수 시간 $O(1)$ 연산이 수행되므로, 전체 시간 복잡도는 $O(N 	imes M)$입니다. 이는 주어진 제약 조건 (N, M <= 1000) 내에서 충분히 빠릅니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.StringTokenizer;

public class Solution {

    public static void main(String[] args) throws IOException {
        // 효율적인 입출력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 1. N과 M 읽기
        StringTokenizer st = new StringTokenizer(br.readLine());
        int N = Integer.parseInt(st.nextToken()); // 행 (Row)
        int M = Integer.parseInt(st.nextToken()); // 열 (Column)

        // 2. 그리드 A와 DP 배열 준비
        // A[i][j]는 입력 값, DP[i][j]는 최대 경로 합
        long[][] A = new long[N][M];
        long[][] DP = new long[N][M];

        // 3. 그리드 값 입력 및 DP 초기화
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                // 입력값 A[i][j] 저장
                A[i][j] = Long.parseLong(st.nextToken());
                
                // 4. DP 점화식 적용
                if (i == 0 && j == 0) {
                    // 시작점
                    DP[i][j] = A[i][j];
                } else if (i == 0) {
                    // 첫 번째 행 (오른쪽으로만 이동 가능)
                    DP[i][j] = A[i][j] + DP[i][j - 1];
                } else if (j == 0) {
                    // 첫 번째 열 (아래로만 이동 가능)
                    DP[i][j] = A[i][j] + DP[i - 1][j];
                } else {
                    // 일반 칸: 위에서 오거나 왼쪽에서 온 값 중 최대값에 현재 값을 더함
                    DP[i][j] = A[i][j] + Math.max(DP[i - 1][j], DP[i][j - 1]);
                }
            }
        }

        // 5. 결과 출력 (목표점의 최대 경로 합)
        System.out.println(DP[N - 1][M - 1]);
    }
}
```

# 최대 사각형 넓이 구하기
*java · DP · 보통 · DP, 자료구조*

## 입출력 환경

Java의 표준 입출력(Scanner 또는 BufferedReader)을 사용하세요. 좌표값의 범위가 크므로 long 타입을 사용해야 합니다.

## 문제

N개의 점 $(x_i, y_i)$가 주어집니다. 이 점들을 꼭짓점으로 하는 직사각형 중 넓이가 최대인 것을 찾아라. 단, 모든 꼭짓점은 주어진 N개의 점들 중 하나여야 한다.

주어진 점들은 좌표 평면 위의 정수 좌표를 가지며, $x$좌표와 $y$좌표는 각각 독립적으로 정렬되어 있지 않을 수 있습니다.

## 입력

첫째 줄에 정수 $N$이 주어집니다. 다음 $N$줄에는 각 점의 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다.

## 출력

최대 넓이를 나타내는 정수 값 하나를 출력합니다.

## 제약 조건

1 <= N <= 200
-10^9 <= x_i, y_i <= 10^9

## 예제 1

**입력**
```
4
0 0
2 0
0 3
2 3
```

**출력**
```
6
```

*주어진 점들로 만들 수 있는 직사각형 중 가장 넓은 것은 (0, 0), (2, 0), (0, 3), (2, 3)을 꼭짓점으로 하는 사각형입니다.*

## 예제 2

**입력**
```
5
1 1
1 5
4 1
4 5
2 3
```

**출력**
```
16
```

*가장 넓은 직사각형은 (1, 1), (4, 1), (1, 5), (4, 5)를 꼭짓점으로 하는 사각형입니다.*

## 예제 3

**입력**
```
3
0 0
1 1
2 2
```

**출력**
```
0
```

*직사각형을 만들기 위해서는 최소한 두 개의 서로 다른 x좌표와 두 개의 서로 다른 y좌표가 필요합니다. 주어진 점들만으로는 직사각형을 만들 수 없습니다 (점들이 한 직선상에 위치할 경우).*

## 힌트

- 직사각형의 꼭짓점을 결정하는 것은 $x$ 좌표들의 집합과 $y$ 좌표들의 집합입니다.
- 주어진 N개의 점들을 이용하여 가능한 모든 x좌표와 y좌표 조합을 고려해야 합니다.


## 알고리즘 요약

이 문제는 주어진 N개의 점들 중 적절한 최소/최대 x좌표($x_{	ext{min}}, x_{	ext{max}}$)와 최소/최대 y좌표($y_{	ext{min}}, y_{	ext{max}}$)를 찾아, 이 네 꼭짓점을 모두 포함하는 직사각형을 만들 때 넓이가 최대가 되도록 하는 문제입니다. 모든 가능한 $x$ 좌표 쌍과 $y$ 좌표 쌍에 대해 해당 직사각형의 네 꼭짓점이 주어진 점들 중 하나인지 확인하는 것은 비효율적입니다. 대신, 어떤 두 개의 수직선($x=x_1, x=x_2$)과 두 개의 수평선($y=y_1, y=y_2$)이 가능한지 먼저 파악하고, 이 네 꼭짓점이 모두 주어진 점들로 구성되어 있는지 확인하는 방식으로 접근해야 합니다. 하지만 문제의 조건을 다시 보면, '모든 꼭짓점은 주어진 N개의 점들 중 하나여야 한다'는 조건만 있습니다. 따라서, 직사각형을 정의하는 두 개의 x좌표 $x_1, x_2$와 두 개의 y좌표 $y_1, y_2$를 선택하고, 이 네 점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$가 모두 주어진 N개의 점들 안에 존재하는지 확인하면 됩니다. 가능한 모든 $x$ 좌표와 $y$ 좌표를 추출한 후, 이들을 정렬하여 투포인터 또는 DP 방식으로 최대 넓이를 탐색할 수 있습니다.

## 풀이 해설

아이디어: 직사각형의 네 꼭짓점 $(x_{	ext{min}}, y_{	ext{min}}), (x_{	ext{max}}, y_{	ext{min}}), (x_{	ext{min}}, y_{	ext{max}}), (x_{	ext{max}}, y_{	ext{max}})$가 모두 주어진 N개의 점들 중 하나여야 합니다. 따라서, 우리는 가능한 모든 $x$ 좌표 쌍 $(x_1, x_2)$와 $y$ 좌표 쌍 $(y_1, y_2)$를 찾고, 이 네 꼭짓점이 모두 입력된 점 집합에 존재하는지 확인해야 합니다.

단계 1: 고유한 좌표 추출 및 저장
주어진 N개의 점들에서 모든 고유한 $x$ 좌표와 모든 고유한 $y$ 좌표를 각각 리스트로 추출합니다. 이들을 정렬하면 탐색 공간을 줄일 수 있습니다.

단계 2: 점의 존재 여부 빠른 확인 구조 구축
입력된 N개의 점들 $(x_i, y_i)$을 Set 자료구조 (예: `HashSet<Point>`)에 저장합니다. 이렇게 하면 특정 좌표 쌍이 주어진 점 목록에 존재하는지 $O(1)$ 시간 복잡도로 확인할 수 있습니다.

단계 3: 최대 넓이 탐색
추출된 고유한 $x$ 좌표 리스트를 $X$, 고유한 $y$ 좌표 리스트를 $Y$라고 합시다. 직사각형은 $X$에서 두 개의 인덱스 $i_1, i_2$와 $Y$에서 두 개의 인덱스 $j_1, j_2$를 선택하여 정의됩니다.

최대 넓이를 찾기 위해, 가능한 모든 $x_1 = X[i_1], x_2 = X[i_2]$ 쌍 (where $i_1 < i_2$)과 모든 $y_1 = Y[j_1], y_2 = Y[j_2]$ 쌍 (where $j_1 < j_2$)을 반복합니다.

반복문 구조:
for $i_1$ from 0 to $|X|-2$
  for $i_2$ from $i_1+1$ to $|X|-1$
    for $j_1$ from 0 to $|Y|-2$
      for $j_2$ from $j_1+1$ to $|Y|-1$
        // 네 꼭짓점 확인
        Point p1 = (X[i_1], Y[j_1]);
        Point p2 = (X[i_2], Y[j_1]);
        Point p3 = (X[i_1], Y[j_2]);
        Point p4 = (X[i_2], Y[j_2]);
        
        if (Set.contains(p1) && Set.contains(p2) && Set.contains(p3) && Set.contains(p4)) { 
          long area = Math.abs((long)(X[i_2] - X[i_1]) * (Y[j_2] - Y[j_1]));
          maxArea = Math.max(maxArea, area);
        }

시간 복잡도 분석:
$|X|$와 $|Y|$는 최대 $N$입니다. 따라서 네 개의 중첩된 반복문이 존재하며, 시간 복잡도는 $O(|X|^2 	imes |Y|^2) = O(N^4)$입니다. N의 제약 조건이 200이므로, $200^4 = 16 	imes 10^8$은 시간 초과가 발생할 가능성이 높습니다.

개선된 접근 (O(N^3) 또는 O(N^2 log N)): 주어진 점의 개수 N <= 200 이므로, $O(N^4)$는 너무 느립니다. 하지만 좌표값 자체가 크기 때문에 DP나 그리드 기반의 최적화가 어렵습니다.

재검토: 네 개의 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$를 모두 포함하는 직사각형을 찾는 것이 목표입니다. 모든 $x$ 좌표 쌍과 $y$ 좌표 쌍을 시도하는 것은 최선일 수 있습니다.

만약 N <= 50 정도였다면 O(N^4)가 통과 가능하지만, N=200에서는 문제가 됩니다. 그러나 주어진 문제의 제약 조건과 구조상 $O(N^4)$를 피하기는 어렵습니다. 따라서, 이 풀이에서는 $N 	imes N$ 크기의 좌표 집합을 가정하고 네 개의 중첩 반복문을 사용하는 것이 기본 아이디어입니다.

*(참고: 실제 코딩 테스트에서 N=200이라면, 아마도 문제 조건에 숨겨진 제약(예: 점들이 그리드 형태로 주어짐)이 있거나, $O(N^3)$ 이하로 풀리는 다른 접근법이 필요할 것입니다. 하지만 주어진 정보만으로는 O(N^4)가 가장 직관적인 해결책입니다.)*

단계 4: 구현 (Java)
좌표를 long 타입으로 처리하고, Set을 사용하여 점의 존재 여부를 확인하며 최대 넓이를 계산합니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    // 좌표 쌍을 저장하기 위한 클래스 (hashCode와 equals 오버라이딩 필수)
    static class Point implements Comparable<Point> {
        long x, y;

        public Point(long x, long y) {
            this.x = x;
            this.y = y;
        }

        @Override
        public boolean equals(Object o) {
            if (o == null || getClass() != o.getClass()) {
                return false;
            }
            Point point = (Point) o;
            return x == point.x && y == point.y;
        }

        @Override
        public int hashCode() {
            // long형 좌표를 조합하여 해시 코드를 생성합니다.
            return Objects.hash(x, y);
        }

        @Override
        public int compareTo(Point other) {
            if (this.x != other.x) {
                return Long.compare(this.x, other.x); 
            } else {
                return Long.compare(this.y, other.y);
            }
        }
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 첫 줄 N 읽기
        int N = Integer.parseInt(br.readLine());

        List<Point> points = new ArrayList<>();
        Set<Point> pointSet = new HashSet<>();
        Set<Long> uniqueX = new TreeSet<>(); // 정렬된 고유 X 좌표 저장
        Set<Long> uniqueY = new TreeSet<>(); // 정렬된 고유 Y 좌표 저장

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            long x = Long.parseLong(st.nextToken());
            long y = Long.parseLong(st.nextToken());
            Point p = new Point(x, y);
            points.add(p);
            pointSet.add(p);
            uniqueX.add(x);
            uniqueY.add(y);
        }

        // TreeSet을 List로 변환하여 순서 유지 및 반복 용이하게 만듦
        List<Long> X = new ArrayList<>(uniqueX);
        List<Long> Y = new ArrayList<>(uniqueY);

        long maxArea = 0;
        int sizeX = X.size();
        int sizeY = Y.size();

        // 가능한 모든 x1, x2 쌍 (i1 < i2) 탐색 (O(N^2))
        for (int i1 = 0; i1 < sizeX; i1++) {
            long x1 = X.get(i1);
            for (int i2 = i1 + 1; i2 < sizeX; i2++) {
                long x2 = X.get(i2);

                // 가능한 모든 y1, y2 쌍 (j1 < j2) 탐색 (O(N^2))
                for (int j1 = 0; j1 < sizeY; j1++) {
                    long y1 = Y.get(j1);
                    for (int j2 = j1 + 1; j2 < sizeY; j2++) {
                        long y2 = Y.get(j2);

                        // 네 꼭짓점 정의 및 존재 여부 확인
                        Point p1 = new Point(x1, y1); 
                        Point p2 = new Point(x2, y1); 
                        Point p3 = new Point(x1, y2); 
                        Point p4 = new Point(x2, y2);

                        if (pointSet.contains(p1) && pointSet.contains(p2) && pointSet.contains(p3) && pointSet.contains(p4)) {
                            // 넓이 계산: |x2 - x1| * |y2 - y1|
                            long area = Math.abs((x2 - x1) * (y2 - y1));
                            maxArea = Math.max(maxArea, area);
                        }
                    }
                }
            }
        }

        System.out.println(maxArea);
    }
}
```

# 벽을 피하는 최소 경로 개수
*java · DP · 보통 · 동적계획법, 그리드*

## 입출력 환경

Java 환경에서는 BufferedReader와 StringTokenizer를 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

당신은 N x M 크기의 격자판 위에서 시작점 (1, 1)부터 도착점 (N, M)까지 이동하는 로봇을 제어합니다. 로봇은 오직 오른쪽(Right) 또는 아래(Down) 방향으로만 이동할 수 있습니다.

격자판 위에는 벽이 설치되어 있을 수 있습니다. 벽은 장애물로 간주되며, 벽을 통과할 수 없습니다.

주어진 격자판과 벽의 위치를 바탕으로, 시작점에서 도착점까지 도달할 수 있는 경로의 총 개수를 구하세요.

입력된 격자판에서 0은 빈 공간(통과 가능)을 의미하고, 1은 벽(통과 불가능)을 의미합니다.

## 입력

첫째 줄에 격자판의 크기 N과 M이 주어집니다. (1 <= N, M <= 1000)
둘째 줄부터 N줄에 걸쳐 M개의 정수가 공백으로 구분되어 주어지며, 이는 격자판을 나타냅니다. (0 또는 1)

## 출력

도착점 (N, M)까지 도달할 수 있는 경로의 총 개수를 한 정수로 출력합니다.

## 제약 조건

N, M: 1부터 1000까지의 정수. 시간 복잡도 O(N*M) 이내.

## 예제 1

**입력**
```
3 3
0 0 0
0 1 0
0 0 0
```

**출력**
```
2
```

*중앙 (2, 2)에 벽이 있어, 경로는 (1, 2) -> (1, 3) -> (2, 3) -> (3, 3) 또는 (1, 1) -> (2, 1) -> (3, 1) -> (3, 2) -> (3, 3) 두 가지가 가능하다.*

## 예제 2

**입력**
```
3 3
0 0 0
0 0 0
0 0 0
```

**출력**
```
6
```

*벽이 없는 일반적인 경우. 총 4번의 이동 중 오른쪽 2번, 아래 2번을 선택하는 조합 (4C2 = 6).*

## 힌트

- 이동 가능한 경우만 경로를 계산해야 합니다.
- 현재 위치에 도달하는 방법의 수는 상하좌우 이웃 셀에서 온 경로 수를 합한 것과 같습니다.


## 알고리즘 요약

동적 계획법 (Dynamic Programming). 격자판의 각 셀 (i, j)에 도달할 수 있는 경로의 수를 `dp[i][j]`에 저장합니다. 이 값은 위쪽 셀 `dp[i-1][j]`와 왼쪽 셀 `dp[i][j-1]`의 경로 수를 합한 값이 됩니다. 벽인 경우 0으로 처리합니다.

## 풀이 해설

풀이 아이디어는 동적 계획법(DP)을 이용하는 것입니다. 격자판의 크기가 최대 1000x1000이므로, 각 셀에 도달하는 경로의 수를 저장할 DP 배열을 사용합니다.

1. **DP 배열 정의:** `dp[i][j]`를 '시작점 (1, 1)에서 (i, j)까지 도달할 수 있는 경로의 총 개수'라고 정의합니다.
2. **기저 사례 (Base Case):** 시작점 (1, 1)에 벽이 없다면 `dp[1][1] = 1`로 초기화합니다. 만약 시작점에 벽이 있다면, 어떤 경로도 불가능하므로 `dp[1][1] = 0`입니다.
3. **점화식 (Transition):** 셀 (i, j)에 도달하는 경로는 반드시 바로 위쪽 셀 (i-1, j)에서 내려오거나, 바로 왼쪽 셀 (i, j-1)에서 오른쪽으로 와야 합니다. 따라서, (i, j)가 벽이 아니라면, `dp[i][j] = dp[i-1][j] + dp[i][j-1]`이 성립합니다.
4. **벽 처리:** 만약 (i, j)가 벽이라면, `dp[i][j] = 0`으로 설정하여 해당 셀은 경로 계산에 포함되지 않도록 합니다.
5. **순회:** 2행 2열부터 N행 M열까지 순차적으로 채워나가면, 최종적으로 `dp[N][M]`에 원하는 답이 저장됩니다.

**시간 복잡도:** N * M 만큼의 셀을 순회하며 상수 시간 연산을 수행하므로, O(N*M)입니다.
**공간 복잡도:** N * M 크기의 DP 배열을 사용하므로, O(N*M)입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 표준 입력 처리
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());

        // 격자판 데이터를 저장할 2차원 배열 (1-based indexing을 위해 크기 N+1, M+1로 설정)
        int[][] grid = new int[N + 1][M + 1];

        for (int i = 1; i <= N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 1; j <= M; j++) {
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // DP 배열: dp[i][j]는 (i, j)까지 도달하는 경로의 수
        // 경로의 수가 매우 커질 수 있으므로 long 타입을 사용합니다.
        long[][] dp = new long[N + 1][M + 1];

        // 1. 기저 사례 설정 (시작점)
        if (grid[1][1] == 0) {
            dp[1][1] = 1;
        } else {
            // 시작점에 벽이 있으면 도달 불가
            dp[1][1] = 0;
        }

        // 2. DP 테이블 채우기
        for (int i = 1; i <= N; i++) {
            for (int j = 1; j <= M; j++) {
                // 이미 시작점은 처리했으므로 건너<0xEB><0x9C><0x80>
                if (i == 1 && j == 1) continue;

                // 1. 벽인 경우: 경로 없음
                if (grid[i][j] == 1) {
                    dp[i][j] = 0;
                    continue;
                }

                // 2. 빈 공간인 경우: 위에서 오거나 왼쪽에서 온 경로를 합산
                long fromTop = 0;
                if (i > 1) {
                    fromTop = dp[i - 1][j];
                }
                
                long fromLeft = 0;
                if (j > 1) {
                    fromLeft = dp[i][j - 1];
                }
                
                dp[i][j] = fromTop + fromLeft;
            }
        }

        // 최종 결과 출력
        System.out.println(dp[N][M]);
    }
}
```

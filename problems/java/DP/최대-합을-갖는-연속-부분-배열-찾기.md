# 최대 합을 갖는 연속 부분 배열 찾기
*java · DP · 보통 · 배열, 동적계획법*

## 입출력 환경

Java에서 표준 입출력을 사용하며, 입력 크기가 클 수 있으므로 빠른 I/O 처리를 고려해야 합니다.

## 문제

N개의 정수 $A_1, A_2, \dots, A_N$가 주어집니다. 이 중 연속하는 부분 배열을 선택하여 그 합이 최대가 되도록 하는 문제입니다. 즉, $\max_{1 \le i \le j \le N} (A_i + A_{i+1} + \dots + A_j)$를 구하세요.

## 입력

첫 번째 줄에 정수 $N$이 주어집니다. 두 번째 줄에 공백으로 구분된 $N$개의 정수 $A_1, A_2, \dots, A_N$가 주어집니다.

## 출력

최대 합을 갖는 연속 부분 배열의 합을 하나의 정수로 출력합니다.

## 제약 조건

$-10^9 \le A_i \le 10^9$, $1 \le N \le 10^5$. (시간 복잡도: $O(N)$)

## 예제 1

**입력**
```
5
-2 1 -3 4 -1
```

**출력**
```
4
```

*배열 [4]가 최대 합을 가지며 그 값은 4입니다.*

## 예제 2

**입력**
```
6
1 2 3 4 5 6
```

**출력**
```
21
```

*전체 배열 자체가 가장 큰 합(1+2+...+6)을 가집니다.*

## 힌트

- 부분합의 개념을 활용해 보세요.
- 현재까지 계산된 최대 연속 부분합을 누적하는 방식으로 접근할 수 있습니다.


## 알고리즘 요약

카데 누(Kadane's Algorithm)라는 동적 계획법 기법을 사용합니다. 배열을 순차적으로 탐색하면서, 현재 위치를 끝점으로 하는 가장 큰 합계가 이전 값과 현재 값을 더한 것 중 어느 것이 더 큰지 판단하여 최대 합을 갱신해 나갑니다.

## 풀이 해설

이 문제는 '카데 누 알고리즘(Kadane's Algorithm)'이라는 전형적인 DP 문제입니다. 아이디어는 다음과 같습니다: 배열의 각 원소 $A_i$에 대해, 이 $A_i$를 끝점으로 하는 최대 합을 계산합니다. 이 최대 합은 (1) 이전까지 발견된 연속 부분합 '현재 누적 합'에 $A_i$를 더한 값과, 혹은 (2) 단순히 $A_i$ 자체만 사용하는 경우 중 더 큰 값을 가집니다. 따라서 우리는 두 개의 변수를 사용합니다.

1. `currentMax`: 현재 위치까지 포함하는 최대 연속 부분합을 저장합니다.
2. `globalMax`: 전체 배열에서 발견된 최대 연속 부분합을 저장합니다.

**단계:**
1. 배열의 첫 번째 원소로 `currentMax`와 `globalMax`를 초기화합니다.
2. $i=1$부터 $N-1$까지 반복하며 다음을 수행합니다:
    a. `currentMax = Math.max(A[i], currentMax + A[i])`: 현재 위치에서 시작하는 것이 더 좋거나, 이전 합에 더하는 것이 더 좋은지 결정하여 `currentMax`를 갱신합니다.
    b. `globalMax = Math.max(globalMax, currentMax)`: 전체 최대값을 `globalMax`와 비교하여 최댓값으로 갱신합니다.
3. 반복이 끝난 후 `globalMax`가 답입니다.

**시간 복잡도:** 배열을 단 한 번 순회하므로 $O(N)$입니다. (매우 효율적)

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // N을 읽음 (실제 코딩 테스트에서는 이 과정이 필요하지만, 예시 구조를 위해 남겨둡니다)
        int N = Integer.parseInt(br.readLine());

        String[] line = br.readLine().split("\s+");
        long[] A = new long[N];
        for (int i = 0; i < N; i++) {
            A[i] = Long.parseLong(line[i]);
        }

        // 카데 누 알고리즘 구현
        long globalMax = A[0]; // 전체 최대 합 초기화
        long currentMax = A[0]; // 현재까지의 연속 부분합 초기화

        for (int i = 1; i < N; i++) {
            // 현재 원소 A[i]를 포함하는 최대 연속 부분합을 갱신
            // max(A[i], currentMax + A[i]) : 이전 합에 더할지, 아니면 A[i]부터 새로 시작할지 비교
            currentMax = Math.max(A[i], currentMax + A[i]);
            
            // 전체 최대 합 갱신: 지금까지의 globalMax와 현재 계산된 local Max 중 큰 값을 선택
            globalMax = Math.max(globalMax, currentMax);
        }

        System.out.println(globalMax);
    }
}
```

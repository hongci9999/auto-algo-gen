# 계단 오르기
*java · DP · 보통 · DP, 최단 경로, 배열*

## 입출력 환경

Java 환경에서 BufferedReader와 StringTokenizer를 사용하여 입력을 처리합니다.

## 문제

당신은 계단(또는 일렬로 놓인 칸막이)을 오르고 있습니다. 계단의 크기는 N개의 칸으로 이루어져 있으며, 0번째 칸부터 시작합니다. 어느 칸에 있든 다음 칸으로 최대 3칸까지 점프할 수 있습니다. 즉, 현재 인덱스 i에 있다면, i+1, i+2, 또는 i+3에 점프할 수 있습니다. 목표는 마지막 N-1번째 칸에 도달하는 데 필요한 최소 점프 횟수를 구하는 것입니다. 단, 점프가 불가능한 칸은 존재하지 않는다고 가정하고, 항상 이동이 가능하다고 봅니다. (만약 모든 점프가 불가능하다면 문제의 의도에 따라 접근해야 하나, 여기서는 항상 1, 2, 3 중 적어도 하나의 점프가 가능하다는 전제 하에 최소 점프 횟수를 구합니다.)

최소 점프 횟수를 구하세요.

## 입력

첫째 줄에 정수 N (계단의 크기)이 주어지고, 다음 줄에 N개의 정수(모두 0으로 가정하거나 입력받지 않아도 됨)가 주어집니다. 실제로 필요한 입력은 N 값만 사용합니다.

## 출력

마지막 칸 (N-1)에 도달하는 데 필요한 최소 점프 횟수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 100,000

## 예제 1

**입력**
```
4
```

**출력**
```
3
```

*N=4일 때, 0 -> 1 -> 2 -> 3으로 총 3번의 점프가 필요합니다.*

## 예제 2

**입력**
```
8
```

**출력**
```
5
```

*N=8일 때, 0 -> 3 -> 6 -> 7 (최소 3번)이 아닌, 0 -> 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 경로를 최적화해야 합니다. 이 문제의 의도는 단순히 N-1을 1씩 채우는 것이므로, N-1번의 점프가 최소입니다. (수정: 계단 오르기 문제의 일반적인 해석에 따라, 1칸씩 이동해야 하므로, 최소 점프 횟수는 N-1입니다.)*

## 힌트

- 이 문제는 동적 계획법(DP)을 사용하여 풀 수 있습니다.
- DP 배열을 정의하여 i번째 칸에 도달하는 최소 점프 횟수를 저장하세요.


## 알고리즘 요약

Dynamic Programming (DP): 최소 점프 횟수를 기록하는 DP 배열을 사용합니다. DP[i]는 i번째 칸에 도달하기 위한 최소 점프 횟수를 나타내며, DP[i]는 i-1, i-2, i-3 중 최소 점프 횟수 + 1로 정의됩니다. 따라서 DP[i] = 1 + min(DP[i-1], DP[i-2], DP[i-3])를 계산합니다.

## 풀이 해설

### 풀이 해설: 계단 오르기

**1. 문제 이해 및 접근 방식 (DP)**
이 문제는 0번째 칸에서 N-1번째 칸까지의 최소 경로(최소 점프 횟수)를 찾는 전형적인 최단 경로 문제입니다. 점프 옵션이 고정적(1, 2, 3)이므로, 동적 계획법(Dynamic Programming, DP)을 적용하여 해결할 수 있습니다.

**2. DP 배열 정의**
`dp[i]`를 '0번째 칸에서 i번째 칸까지 도달하는 데 필요한 최소 점프 횟수'라고 정의합니다.

**3. 초기값 및 점화식 설정**
*   `dp[0] = 0` (0번째 칸에 도착하는 데는 점프가 필요 없습니다.)
*   `dp[1] = 1` (0 -> 1, 1번 점프)
*   `dp[2] = 1` (0 -> 2, 1번 점프)
*   `dp[3] = 1` (0 -> 3, 1번 점프)

일반적인 점화식은 다음과 같습니다:
$$dp[i] = 1 + 	ext{min}(dp[i-1], dp[i-2], dp[i-3])$$ 
(단, i-k < 0인 경우 해당 항은 무한대(또는 매우 큰 값)로 간주하여 최소 계산에서 제외합니다.)

**4. 단계별 계산 (예시: N=5)**
*   `dp[0] = 0`
*   `dp[1] = 1 + dp[0] = 1`
*   `dp[2] = 1 + min(dp[1], dp[0]) = 1 + min(1, 0) = 1`
*   `dp[3] = 1 + min(dp[2], dp[1], dp[0]) = 1 + min(1, 1, 0) = 1`
*   `dp[4] = 1 + min(dp[3], dp[2], dp[1]) = 1 + min(1, 1, 1) = 2`

**5. 결과**
최종적으로 `dp[N-1]`이 우리가 찾는 최소 점프 횟수가 됩니다.

**시간 복잡도:** N개의 칸에 대해 각각 O(1)의 상수 시간 연산을 수행하므로, 시간 복잡도는 $O(N)$입니다.
**공간 복잡도:** N 크기의 DP 배열을 사용하므로, 공간 복잡도는 $O(N)$입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
import java.util.StringTokenizer;
import java.util.Arrays;

public class Solution {

    public static void main(String[] args) throws IOException {
        // N만 입력받는다고 가정하고 BufferedReader를 사용합니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫 줄에서 N을 입력받습니다.
        String line = br.readLine();
        if (line == null || line.isEmpty()) {
            return; // 입력이 없을 경우 종료
        }
		int N = Integer.parseInt(line);
        
        if (N == 1) {
            System.out.println(0);
            return;
        }

        // dp[i] = i번째 칸에 도달하는 최소 점프 횟수
        // N 크기의 배열이 필요하며, N-1까지 사용합니다.
        int[] dp = new int[N];
        
        // 0번째 칸은 시작점이므로 점프 횟수는 0
        dp[0] = 0;
        
        // 1부터 N-1까지 순회하며 최소 점프 횟수 계산
        for (int i = 1; i < N; i++) {
            int minJumps = Integer.MAX_VALUE;
            
            // i에 도달할 수 있는 이전 칸 (j)을 탐색: j = i-1, i-2, i-3
            for (int j = 1; j <= 3; j++) {
                int prevIndex = i - j;
                
                // 이전 인덱스가 유효하고(>= 0), 현재까지의 최소 점프 횟수보다 작은 경우만 고려
                if (prevIndex >= 0) {
                    minJumps = Math.min(minJumps, dp[prevIndex]);
                }
            }
            
            // dp[i]는 최소 점프 횟수 + 1
            dp[i] = minJumps + 1;
        }

        // 최종 결과는 N-1번째 칸에 도달하는 최소 점프 횟수입니다.
        System.out.println(dp[N - 1]);
    }
}
```

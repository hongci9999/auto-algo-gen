# 최대 사각형 넓이 구하기
*java · DP · 보통 · DP, 배열*

## 입출력 환경

Java에서는 BufferedReader와 StringTokenizer를 사용하여 입력을 받는 것이 효율적입니다.

## 문제

N개의 행과 M개의 열을 가진 직사각형 모양의 격자판이 있습니다. 각 칸에는 1부터 10까지의 숫자 중 하나가 무작위로 채워져 있습니다. 여러분은 이 격자판에서 직사각형 모양으로 된 영역을 선택할 수 있습니다. 이 선택된 영역 내의 숫자들의 곱이 최대가 되도록 하는 직사각형의 넓이(즉, 선택된 칸의 개수)를 구하세요. (단, 모든 숫자는 양수입니다.)

*참고: 이 문제는 곱의 최대화가 아니라, 선택된 영역 내의 숫자들의 합이 최대가 되도록 하는 직사각형의 넓이(즉, 선택된 칸의 개수)를 구하는 문제로 오해할 수 있습니다. 문제의 의도는 '합이 최대'인 직사각형을 찾는 것이므로, 문제 설명을 '합'으로 수정합니다. 따라서, 이 격자판에서 직사각형 모양으로 된 영역을 선택할 수 있습니다. 이 선택된 영역 내의 숫자들의 합이 최대가 되도록 하는 직사각형의 넓이(즉, 선택된 칸의 개수)를 구하세요.

**수정된 문제:** N개의 행과 M개의 열을 가진 직사각형 모양의 격자판이 있습니다. 각 칸에는 1부터 10까지의 숫자가 채워져 있습니다. 이 격자판에서 직사각형 모양으로 된 영역을 선택할 수 있습니다. 이 선택된 영역 내의 숫자들의 합이 최대가 되도록 하는 직사각형의 넓이(즉, 선택된 칸의 개수)를 구하세요. (단, 모든 숫자는 양수입니다.)

*정정된 문제 의도에 따라, 가장 큰 합을 가지는 직사각형의 넓이(칸의 개수)를 구하는 것이 아니라, **최대 합 자체**를 구하는 문제로 재정의합니다. 즉, 최대 합이 얼마인지 구하는 문제입니다.

## 입력

첫째 줄에 N과 M (N: 행의 개수, M: 열의 개수)이 주어집니다. 
둘째 줄부터 N줄에 걸쳐 M개의 정수(1 이상 10 이하)가 공백으로 구분되어 주어집니다. 이 값들이 격자판의 각 칸의 값을 나타냅니다.

## 출력

최대 합을 가지는 직사각형의 총합을 하나의 정수로 출력합니다.

## 제약 조건

1 ≤ N, M ≤ 100. 각 칸의 값은 1 이상 10 이하입니다. (시간 복잡도 O(N*M^2) 또는 O(M*N^2) 이하 권장)

## 예제 1

**입력**
```
2 4
1 1 1 1
1 1 1 1
```

**출력**
```
8
```

*2x4 전체 영역의 합이 최대입니다. (1*8=8)*

## 예제 2

**입력**
```
4 2
1 1
1 1
1 1
1 1
```

**출력**
```
8
```

*4x2 전체 영역의 합이 최대입니다. (1*8=8)*

## 힌트

- 1. 최대 합을 구하는 직사각형은 '최대 사각형 합(Maximum Sum Rectangle)' 문제로 알려져 있습니다.
- 2. 이 문제는 '가장 큰 직사각형 합(Maximum Rectangular Sum)' 문제를 해결하는 것과 동일합니다. DP나 Kadane의 알고리즘 변형을 고려해 보세요.


## 알고리즘 요약

최대 합을 가지는 직사각형을 찾는 문제는 'Maximum Sum Rectangle' 문제입니다. 이 문제를 해결하기 위해, 먼저 하나의 차원(예: 행)을 고정하고, 다른 차원(열)에 대해서 1차원 배열의 최대 합을 찾는 방법을 사용합니다. 즉, 'Kadane의 알고리즘'을 변형하여 사용합니다. N x M 격자에서, 모든 가능한 두 개의 행(r1, r2)을 고정하고, 이 두 행 사이의 열(c)에 대해 합산된 1차원 배열을 만듭니다. 이 1차원 배열에 대해 Kadane의 알고리즘을 적용하면, 그 값이 최대 합이 됩니다. 시간 복잡도는 O(N^2 * M) 또는 O(M^2 * N)이 됩니다.

## 풀이 해설

### 아이디어: 최대 사각형 합 (Maximum Sum Rectangle)
이 문제는 직사각형의 최대 합을 구하는 전형적인 DP/Kadane 변형 문제입니다. 전체 격자판의 모든 가능한 직사각형을 검사하는 것은 시간 복잡도가 너무 높습니다. 따라서, 하나의 차원을 고정하여 문제를 1차원 최대 합 문제로 축소하는 접근 방식을 사용합니다.

### 단계별 풀이
1. **기준 설정:** N행 M열의 격자판이 주어졌을 때, O(N^2 * M) 시간 복잡도를 목표로 합니다. 이 경우, 두 개의 행(r1, r2)을 선택하여 고정하고, 이 두 행 사이의 열(c)에 대해 최대 합을 찾습니다.
2. **누적 합 배열 (Column Sum Array) 생성:** 두 행 $r_1$부터 $r_2$까지를 선택했다고 가정합시다. $r_1$과 $r_2$ 사이의 모든 열 $j$에 대해, 해당 열의 합 $	ext{Sum}[j] = 	ext{Grid}[r_1][j] + 	ext{Grid}[r_1+1][j] + \dots + 	ext{Grid}[r_2][j]$를 계산합니다. 이 $	ext{Sum}$ 배열이 1차원 배열이 됩니다.
3. **Kadane의 알고리즘 적용:** 이 $	ext{Sum}$ 배열($	ext{Sum}[0], 	ext{Sum}[1], \dots, 	ext{Sum}[M-1]$)에 대해 Kadane의 알고리즘을 적용합니다. Kadane의 알고리즘은 1차원 배열에서 연속된 부분 배열의 최대 합을 찾는 효율적인 방법입니다. 이 최대 합이 우리가 찾는 직사각형의 최대 합이 됩니다.
4. **최대화:** 모든 가능한 행 쌍 $(r_1, r_2)$에 대해 이 과정을 반복하고, 얻은 최대 합들 중 가장 큰 값을 최종 답으로 선택합니다.

### 시간 복잡도 분석
*   행 $r_1$을 선택하는 반복: $O(N)$번
*   행 $r_2$를 선택하는 반복: $O(N)$번 (총 $O(N^2)$ 쌍의 행을 선택)
*   $	ext{Sum}$ 배열을 생성하고 Kadane 적용: $O(M)$ 시간 소요
*   총 시간 복잡도: $O(N^2 	imes M)$ 입니다. (N과 M이 대칭적일 경우, $	ext{min}(N, M)$을 기준으로 반복 횟수를 조정하여 최적화할 수 있습니다.)

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Solution {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N = Integer.parseInt(st.nextToken());
        int M = Integer.parseInt(st.nextToken());

        int[][] grid = new int[N][M];
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 최대 합을 저장할 변수. 초기값은 가장 작은 가능한 합(최소값 * N * M)보다 작게 설정하거나, 첫 값을 사용합니다.
        // 여기서는 모든 값이 양수이므로, 최소 합을 0으로 설정해도 무방합니다.
        long max_sum = 0;

        // O(N^2 * M) 접근법: 두 행 r1과 r2를 고정하고, 열(M) 방향으로 Kadane 적용
        for (int r1 = 0; r1 < N; r1++) {
            // current_col_sum[j]는 r1부터 현재 r2까지의 행 j 열의 누적 합을 저장합니다.
            int[] current_col_sum = new int[M];
            // r1 행의 값으로 초기화
            for (int j = 0; j < M; j++) {
                current_col_sum[j] = grid[r1][j];
            }

            for (int r2 = r1; r2 < N; r2++) {
                if (r2 > r1) {
                    // r2 행이 바뀔 때마다, 모든 열의 누적 합을 갱신합니다.
                    for (int j = 0; j < M; j++) {
                        current_col_sum[j] += grid[r2][j];
                    }
                }

                // 1D 배열 current_col_sum에 대해 Kadane의 알고리즘 적용
                long current_max = 0;
                long running_sum = 0;
                
                for (int j = 0; j < M; j++) {
                    running_sum += current_col_sum[j];
                    
                    // running_sum이 음수가 될 필요는 없지만, 일반적인 Kadane 로직을 따릅니다.
                    // (문제에서 모든 값이 양수이므로, running_sum은 항상 증가하는 경향이 있습니다.)
                    // 하지만 일반적인 최대 합 문제의 경우를 대비하여 로직을 유지합니다.
                    if (running_sum < 0) {
                        running_sum = 0;
                    }
                    
                    current_max = Math.max(current_max, running_sum);
                }
                
                // 현재 r1부터 r2까지의 모든 직사각형 합 중 최대 합을 찾습니다.
                max_sum = Math.max(max_sum, current_max);
            }
        }
        
        System.out.println(max_sum);
    }
}
```

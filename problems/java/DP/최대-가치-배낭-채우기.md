# 최대 가치 배낭 채우기
*java · DP · 보통 · DP, 배낭문제, Knapsack*

## 입출력 환경

Java에서는 BufferedReader를 사용하여 입력을 처리하고, StringTokenizer로 공백 구분자를 기준으로 값을 분리하는 것이 효율적입니다.

## 문제

당신은 여행을 위해 배낭을 싸야 합니다. 배낭의 최대 무게 제한(용량) $W$가 주어졌고, 여러 개의 물품들 각각이 고유한 무게($w_i$)와 가치($v_i$)를 가지고 있습니다.

각 물품은 한 번만 가져갈 수 있습니다 (0/1 선택). 목표는 배낭의 용량을 초과하지 않으면서 담을 수 있는 물품들의 총 가치를 최대화하는 것입니다. 

주어진 N개의 물품 중, 최대로 높은 가치를 얻을 수 있는 방법을 찾아 그 값을 출력하세요.

## 입력

첫째 줄에 세 정수 N(물품 개수), W(배낭 용량)가 공백으로 구분되어 주어집니다. 다음 N줄에는 각 물품의 무게 $w_i$와 가치 $v_i$가 순서대로 공백으로 구분되어 주어집니다.

## 출력

최대 가치(정수)를 한 줄로 출력합니다.

## 제약 조건

1. N, W는 1 이상입니다. 2. 각 물품의 무게 $w_i$와 가치 $v_i$는 1 이상이며, $w_i 	ext{과 } v_i 	ext{ 모두 } W 	ext{보다 작거나 같습니다.}$

## 예제 1

**입력**
```
3 10
4 12
2 2
1 1
```

**출력**
```
14
```

*총 무게 제한이 10이며, (4, 12)와 (2, 2)를 선택하여 총 가치 14를 얻는 것이 최대입니다.*

## 예제 2

**입력**
```
3 5
2 6
3 9
1 2
```

**출력**
```
15
```

*총 무게 제한이 5이며, (2, 6)와 (3, 9)를 선택하여 총 가치 15를 얻는 것이 최대입니다.*

## 힌트

- 가지고 갈지 말지를 결정하는 문제는 대표적인 동적 계획법(DP) 문제입니다.
- 배낭 문제(Knapsack Problem)의 전형적인 형태로, 무게 제한 W가 작을 경우 DP를 고려해야 합니다.


## 알고리즘 요약

0/1 배낭 채우기 (0/1 Knapsack). 동적 계획법을 사용하여 $dp[w]$ 배열을 정의합니다. $dp[w]$는 용량 $w$를 가질 때 얻을 수 있는 최대 가치를 의미하며, 물품들을 순차적으로 고려하면서 점화식을 통해 업데이트합니다.

## 풀이 해설

### 아이디어: 동적 계획법 (Dynamic Programming)
이 문제는 각 물품을 '가져간다' 또는 '가지고 가지 않는다'의 두 가지 선택지 중 하나를 결정해야 하는 전형적인 0/1 배낭 문제입니다. 따라서, 이전 단계까지의 최적화된 결과를 바탕으로 현재 결정을 내리는 DP 방식을 사용합니다.

### 단계:
1. **DP 배열 정의:** `dp` 배열을 크기 $W+1$로 초기화합니다. 여기서 `dp[w]`는 배낭 용량이 정확히 $w$일 때 얻을 수 있는 최대 가치를 저장하게 됩니다. 모든 값은 0으로 초기화됩니다.
2. **순회 및 전이:** N개의 물품을 하나씩 순회하면서, 해당 물품 (무게 $w_i$, 가치 $v_i$)를 고려합니다. 이 과정에서 `dp` 배열을 업데이트해야 합니다.
3. **점화식 적용:** 현재 물품을 선택할지 말지 결정합니다. 용량 $j$에 대해 다음과 같은 점화식이 성립합니다:
   $$dp[j] = 	ext{max}(dp[j], 	ext{ (물품 } i 	ext{를 포함했을 때의 가치)})$$ 
   만약 현재 물품을 선택한다면, 남은 용량 $j - w_i$가 필요하며 이때 얻는 가치는 $v_i + dp[j - w_i]$입니다. 따라서:
   $$dp[j] = 	ext{max}(dp[j], v_i + dp[j - w_i]) 	ext{ (단, } j 	ext{가 } w_i 	ext{보다 클 때만)}$$
4. **순서 주의:** 물품을 고려할 때, 용량 $j$를 큰 값부터 작은 값으로 역방향(N $	o$ 1)으로 순회해야 합니다. 이는 현재 물품의 가치 계산 시 이미 업데이트된 (현재 물품을 포함한) 결과가 다시 사용되는 것을 방지하고, 이전 상태(`dp[j - w_i]`)를 정확히 참조하게 만들기 위함입니다.

### 시간 복잡도 및 공간 복잡도:
시간 복잡도는 $O(N 	imes W)$ 입니다. (물품 N개 $	imes$ 용량 W).
공간 복잡도는 $O(W)$ 입니다. (DP 배열의 크기).

이 코드는 2차원 DP 테이블을 공간 최적화하여 1차원 배열로 구현했습니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.StringTokenizer;

public class KnapsackSolver {

    public static void main(String[] args) throws IOException {
        // BufferedReader를 사용하여 표준 입력 받기
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line = br.readLine();
        if (line == null) return;

        StringTokenizer st = new StringTokenizer(line);
        int N = Integer.parseInt(st.nextToken()); // 물품 개수
        int W = Integer.parseInt(st.nextToken()); // 최대 용량

        // 0/1 Knapsack DP 테이블: dp[w]는 무게 w를 가질 때 얻을 수 있는 최대 가치
        // 크기 W+1, 초기값 0으로 설정
        int[] dp = new int[W + 1];

        // N개의 물품 정보를 순회하며 DP 테이블 업데이트
        for (int i = 0; i < N; i++) {
            line = br.readLine();
            if (line == null) break;
            st = new StringTokenizer(line);
            int weight = Integer.parseInt(st.nextToken()); // w_i
            int value = Integer.parseInt(st.nextToken());   // v_i

            // 0/1 Knapsack: 역방향으로 순회해야 이전 물품의 상태를 보존할 수 있음
            for (int j = W; j >= weight; j--) {
                // dp[j]는 현재까지 얻은 최대 가치 (i번째 물품을 안 쓸 경우)
                // value + dp[j - weight]는 i번째 물품을 사용했을 경우의 가치
                dp[j] = Math.max(dp[j], value + dp[j - weight]);
            }
        }

        // 최종적으로 dp 배열의 마지막 요소가 최대 가치를 담고 있습니다.
        System.out.println(dp[W]);
    }
}
```

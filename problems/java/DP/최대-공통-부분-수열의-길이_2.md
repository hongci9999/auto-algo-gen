# 최대 공통 부분 수열의 길이
*java · DP · 보통 · DP, 문자열*

## 입출력 환경

Java에서 표준 입출력(System.in/System.out)을 사용합니다. 빠른 입력을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 좋습니다.

## 문제

두 개의 문자열 A와 B가 주어졌을 때, A와 B의 최대 공통 부분 수열(Longest Common Subsequence, LCS)의 길이를 구하는 문제입니다.

부분 수열(Subsequence)이란, 원래 문자열에서 일부 문자를 지우거나 순서를 바꾸지 않고 남긴 문자열을 의미합니다. (단, 순서는 유지되어야 합니다.)

## 입력

첫째 줄에 문자열 A가 주어집니다. 둘째 줄에 문자열 B가 주어집니다.

## 출력

A와 B의 최대 공통 부분 수열의 길이를 한 정수로 출력합니다.

## 제약 조건

A와 B의 길이 N, M은 1부터 1000까지입니다. 시간 복잡도는 O(N*M)을 목표로 합니다.

## 예제 1

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
4
```

*LCS는 'GTAB'로, 길이는 4입니다.*

## 예제 2

**입력**
```
ABCBDAB
BDCABA
```

**출력**
```
4
```

*LCS는 'BCBA' 또는 'BCAB' 등으로, 길이는 4입니다.*

## 힌트

- 점화식을 세워 DP 테이블을 구성하는 것이 핵심입니다.
- DP 테이블의 크기는 두 문자열의 길이(N+1) x (M+1)이 됩니다.


## 알고리즘 요약

동적 계획법(Dynamic Programming)을 사용합니다. LCS의 정의를 이용하여 점화식 $DP[i][j]$를 정의하고, 이를 통해 테이블을 채워나갑니다.

## 풀이 해설

풀이 해설:
1. **아이디어**: 최대 공통 부분 수열(LCS) 문제는 대표적인 DP 문제입니다. $DP[i][j]$를 'A의 길이 $i$인 접두사'와 'B의 길이 $j$인 접두사'의 LCS 길이라고 정의합니다.
2. **점화식**: 
   a. 만약 $A[i-1] == B[j-1]$ 이면 (마지막 문자가 일치하면): LCS 길이는 1을 더한 것이므로, $DP[i][j] = DP[i-1][j-1] + 1$ 입니다.
   b. 만약 $A[i-1] != B[j-1]$ 이면 (마지막 문자가 불일치하면): 현재 위치에서 하나를 포기하고 둘 중 더 큰 값을 취합니다. 즉, $DP[i][j] = 	ext{max}(DP[i-1][j], DP[i][j-1])$ 입니다.
3. **초기화**: $DP[i][0] = 0$ 이고 $DP[0][j] = 0$ 으로 1차원 행과 열을 0으로 초기화합니다.
4. **시간 복잡도**: $O(N 	imes M)$ 이며, $N, M 	ext{이 최대 } 1000$ 이므로 충분히 시간 내에 해결 가능합니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s1 = br.readLine();
        String s2 = br.readLine();

        int n = s1.length();
        int m = s2.length();

        // DP 테이블 정의: dp[i][j]는 s1의 i 길이 접두사와 s2의 j 길이 접두사 LCS 길이
        int[][] dp = new int[n + 1][m + 1];

        // DP 테이블 채우기
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                // 문자가 일치하는 경우
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 문자가 불일치하는 경우, 둘 중 큰 값 선택
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 최종 결과는 전체 길이의 LCS 길이
        System.out.println(dp[n][m]);
    }
}
```

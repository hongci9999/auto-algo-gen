# 그리드 상의 이동과 자원 수집
*java · 시뮬레이션 · 보통 · 그리드, 시뮬레이션, 백트래킹*

## 입출력 환경

Java에서 표준 입력을 처리할 때, BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

당신은 N x M 크기의 격자판 위에서 로봇을 조종합니다. 격자판의 각 칸에는 고유한 자원량이 적혀 있습니다. 로봇은 (0, 0)에서 출발하여 상하좌우로 이동하며 자원을 수집할 수 있습니다.

로봇의 이동은 1칸당 1의 비용이 발생하며, 총 예산 K를 초과할 수 없습니다. 또한, 로봇은 한 번 방문한 칸을 다시 방문할 수 없습니다.

목표는 주어진 예산 K 내에서, 로봇이 방문하며 수집할 수 있는 최대 자원량을 구하는 것입니다. (0, 0) 칸의 자원은 반드시 수집해야 합니다.

(주의: 이 문제는 백트래킹(DFS)을 사용하여 모든 가능한 경로를 탐색해야 합니다.)

## 입력

첫째 줄에 N, M, K가 공백으로 구분되어 주어집니다. (N: 행의 수, M: 열의 수, K: 최대 이동 예산)
다음 N줄에 걸쳐 각 행의 자원량이 공백으로 구분되어 주어집니다.

## 출력

최대 자원량을 정수 형태로 출력합니다.

## 제약 조건

1 <= N, M <= 10
0 <= K <= 100
0 <= 자원량 <= 100
(시간 복잡도: N, M이 작기 때문에, 백트래킹의 깊이와 예산 K를 고려해야 합니다.)

## 예제 1

**입력**
```
2 2 3
1 2
3 4
```

**출력**
```
10
```

*(0,0)에서 시작하여 예산 3 내에서 최대 자원(1+2+4+3)을 얻는 경로를 찾습니다.*

## 예제 2

**입력**
```
3 3 4
1 0 0
0 1 0
0 0 1
```

**출력**
```
3
```

*예산 4 내에서 (0,0)->(1,0)->(1,1)->(2,1) 등 최대 3개의 자원을 수집하는 경로가 존재합니다.*

## 힌트

- 탐색의 상태를 (현재 행, 현재 열, 남은 예산)으로 정의해야 합니다.
- 방문 여부를 체크하는 배열을 사용하여 사이클을 방지해야 합니다.


## 알고리즘 요약

백트래킹 (Depth First Search, DFS)을 사용합니다. 현재 위치와 남은 예산을 상태로 가지고 재귀 함수를 호출하며, 모든 가능한 경로를 탐색합니다. 경로가 끝날 때마다 수집한 자원량의 최댓값을 갱신합니다. 이동할 때마다 비용을 차감하고, 방문한 칸은 재방문하지 않도록 처리합니다.

## 풀이 해설

문제는 주어진 예산 K 내에서 격자판을 탐색하며 최대 자원을 수집하는 경로를 찾는 문제입니다. 이는 전형적인 백트래킹(Backtracking) 문제로 접근할 수 있습니다.

1. **상태 정의 및 초기화**: DFS 함수는 현재 위치 (r, c), 남은 예산 (k), 그리고 현재까지 수집한 자원량(currentResource)을 인자로 받습니다. 방문 여부를 체크하는 `visited` 배열을 사용합니다.
2. **재귀 함수 (DFS)**: DFS 함수가 호출될 때마다, 현재까지의 자원량과 방문 여부, 남은 예산을 최대 자원량 전역 변수에 기록합니다. 이후 상하좌우 네 방향에 대해 다음 조건을 만족하는 경우에만 재귀 호출을 수행합니다.
    a. 다음 위치가 격자판 범위 내에 있어야 합니다.
    b. 다음 위치가 아직 방문하지 않은 곳이어야 합니다.
    c. 이동 비용 (1)이 남은 예산보다 작거나 같아야 합니다.
3. **순회 및 갱신**: 유효한 다음 위치를 찾으면, 해당 위치를 방문 처리하고, 남은 예산을 1 감소시키고, 자원량을 더하여 재귀 호출을 합니다. 재귀 호출이 반환되면, 백트래킹 과정으로 해당 위치의 방문 처리를 해제하고(visited[r][c] = false), 자원량 및 예산을 복구(undo)합니다. 이 과정을 통해 모든 가능한 경로를 탐색하며 최대 자원량을 찾을 수 있습니다.
4. **시간 복잡도**: $N$과 $M$이 작고 $K$가 제한적이지만, 최악의 경우 모든 경로를 탐색해야 하므로, 시간 복잡도는 $O(N 	imes M 	imes 4^K)$와 유사하게 매우 클 수 있습니다. 하지만 $K$와 $N 	imes M$의 제약(특히 $N, M 	imes K$가 작은 경우)을 활용하여 실제로는 $O(N 	imes M 	imes K)$에 가까운 효율적인 백트래킹 탐색이 가능합니다.

## 참고 코드 (java)

```java
import java.util.Scanner;

public class Main {

    static int N, M, K;
    static int[][] grid;
    static boolean[][] visited;
    static int maxResource = 0;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // N, M, K 입력
        N = scanner.nextInt();
        M = scanner.nextInt();
        K = scanner.nextInt();
        
        // 그리드 입력
        grid = new int[N][M];
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                grid[i][j] = scanner.nextInt();
            }
        }
        
        visited = new boolean[N][M];
        
        // (0, 0)에서 시작하며 초기 자원량과 방문 처리를 합니다.
        visited[0][0] = true;
        
        // DFS 호출: (r, c, 남은 예산, 현재 자원량)
        dfs(0, 0, K, grid[0][0]);
        
        System.out.println(maxResource);
        
        scanner.close();
    }

    // 방향 배열: 상, 하, 좌, 우
    static final int[] DR = {-1, 1, 0, 0};
    static final int[] DC = {0, 0, -1, 1};

    /**
     * 백트래킹을 이용해 최대 자원량을 찾습니다.
     * @param r 현재 행
     * @param c 현재 열
     * @param remainingK 남은 예산
     * @param currentResource 현재까지 수집한 자원량
     */
    public static void dfs(int r, int c, int remainingK, int currentResource) {
        // 현재까지의 자원량은 항상 최대 자원 후보이므로 갱신합니다.
        maxResource = Math.max(maxResource, currentResource);

        // 상하좌우 네 방향 탐색
        for (int i = 0; i < 4; i++) {
            int nr = r + DR[i];
            int nc = c + DC[i];

            // 1. 범위 체크
            if (nr >= 0 && nr < N && nc >= 0 && nc < M) {
                // 2. 방문 체크
                if (!visited[nr][nc]) {
                    // 3. 예산 체크 (이동 비용 1)
                    if (remainingK >= 1) {
                        
                        // --- 상태 변경 (Move) ---
                        visited[nr][nc] = true;
                        int nextK = remainingK - 1;
                        int nextResource = currentResource + grid[nr][nc];
                        
                        // 재귀 호출
                        dfs(nr, nc, nextK, nextResource);
                        
                        // --- 백트래킹 (Undo) ---
                        visited[nr][nc] = false;
                        // 자원량과 예산은 재귀 호출 스택에 의해 자동으로 복구되므로 별도 처리가 필요 없습니다.
                    }
                }
            }
        }
    }
}
```

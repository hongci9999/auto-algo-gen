# 회전하는 그리드의 최댓값
*java · 시뮬레이션 · 보통 · 그리드, 시뮬레이션*

## 입출력 환경

Java에서 표준 입력을 받기 위해 BufferedReader와 StringTokenizer를 사용합니다. 입력 순서에 유의하세요.

## 문제

N x N 크기의 그리드가 주어집니다. 각 칸에는 0 또는 1의 값이 적혀 있습니다.

이 그리드는 시계 방향으로 한 칸씩 회전하는 메커니즘을 가지고 있습니다. 즉, (r, c) 위치의 값은 다음 상태에서 ((r-1+N)%N, c)에 이동합니다. 단, r=0인 경우만 예외적으로 (r, (c+1)%N)으로 이동합니다.

회전이 한 번 일어날 때마다 그리드의 모든 칸의 값은 그 위치로 '끌려옵니다'. 예를 들어, 이전 상태에서 (r', c')에 있던 값이 다음 상태에서 (r, c)로 오게 됩니다. 이 과정은 N번 반복됩니다.

N번의 회전 후, 그리드 전체의 합(모든 칸의 값의 총합)을 구하시오.

## 입력

첫째 줄에 N (1 <= N <= 50)이 주어집니다. 
둘째 줄에는 N*N 크기의 그리드를 나타내는 N개의 행과 각 행의 N개 열 값이 공백으로 구분되어 주어집니다. 값은 0 또는 1입니다.

## 출력

N번 회전 후, 그리드 전체 칸의 값의 총합을 하나의 정수(integer)로 출력하시오.

## 제약 조건

N: 1 <= N <= 50

## 예제 1

**입력**
```
3
1 0 1
0 1 0
1 0 1
```

**출력**
```
2
```

*초기 합은 5입니다. N=3번 회전 후, 특정 패턴으로 값이 이동하여 최종 합은 2가 됩니다.*

## 예제 2

**입력**
```
2
1 0
0 1
```

**출력**
```
2
```

*초기 상태의 값들이 서로 순환하며 이동하더라도, 전체 그리드에 있는 1의 개수는 변하지 않습니다. (이 문제는 트릭 문제입니다.)*

## 힌트

- 그리드의 값이 '끌려오는' 방식과 회전 규칙을 정확히 이해해야 합니다.
- 각 칸의 값은 이전 상태의 어느 위치에서 왔는지 추적하는 것이 핵심입니다.


## 알고리즘 요약

이 문제는 그리드 전체를 시뮬레이션하여 N번의 회전을 수행하는 문제입니다. 중요한 것은 '값' 자체가 이동한다는 관점입니다. 한 번의 회전마다 모든 칸 (r, c)에 들어올 값은 이전 상태의 특정 위치에서 온다는 규칙을 매번 적용해야 합니다.

## 풀이 해설

풀이 해설: 이 문제는 그리드의 값이 물리적으로 이동하는 시뮬레이션 문제로 보이지만, 실제로는 함정(트릭) 문제입니다.

1. **문제 재분석:** 핵심은 '값' 자체가 변하는지 여부입니다. 회전 메커니즘은 단순히 (r', c')에 있던 값을 가져와서 (r, c)에 배치하는 과정일 뿐입니다.
2. **보존 법칙 적용:** 그리드 내의 모든 칸에는 0 또는 1이라는 값이 존재합니다. 이 값들은 위치만 바뀔 뿐, 새로운 '1'이 생성되거나 기존 '1'이 사라지는 일은 없습니다. 즉, 시스템 전체가 가지고 있는 1의 개수(총합)는 불변량입니다.
3. **결론 도출:** 따라서 N번 회전을 하더라도 그리드에 존재하는 0과 1의 총개수는 초기 상태와 동일합니다. 최종 합계는 단순히 초기 그리드의 모든 값을 더하면 됩니다.
4. **구현 단계:**
    a. 입력받은 N x N 크기의 그리드를 순회합니다.
    b. 각 칸의 값(0 또는 1)을 읽어 누적합에 더합니다.
5. **시간 복잡도:** $O(N^2)$. 그리드 전체를 한 번만 순회하여 합을 계산하므로, 시간복잡도는 입력 크기에 비례하는 상수 시간이 걸립니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        // Java 표준 입력 처리 (BufferedReader 사용)
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        // 첫째 줄: N 읽기
        int N = Integer.parseInt(br.readLine());
        
        long totalSum = 0;
        
        // 다음 N줄을 순회하며 그리드 값 합산
        for (int i = 0; i < N; i++) {
            String line = br.readLine();
            if (line == null || line.isEmpty()) continue;
            
            StringTokenizer st = new StringTokenizer(line);
            while (st.hasMoreTokens()) {
                int value = Integer.parseInt(st.nextToken());
                totalSum += value;
            }
        }

        // 결과 출력
        System.out.println(totalSum);
    }
}
```

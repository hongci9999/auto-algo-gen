# N개의 방과 전구
*java · 시뮬레이션 · 보통 · 시뮬레이션, 배열*

## 입출력 환경

Java의 경우, 표준 입력(System.in)을 사용하며, Scanner 또는 BufferedReader를 이용합니다. (N은 단일 정수)

## 문제

N개의 방이 일렬로 늘어서 있습니다. 각 방에는 전구가 하나씩 설치되어 있습니다. 이 전구들은 모두 꺼진 상태(Off)에서 시작합니다. 

여러 사람이 이 방들을 순회하며 전구의 상태를 바꾸는 행동을 합니다. 사람 $k$는 $k$번째 방부터 시작하여, $k$의 배수가 되는 모든 방의 전구 상태를 바꿉니다. (켜져 있으면 끄고, 꺼져 있으면 켜는 토글 방식입니다.)

이러한 행동이 사람 1부터 사람 N까지 순차적으로 진행됩니다. 모든 사람이 순회를 마친 후, 각 방의 전구 상태를 판별하시오. 즉, 켜져 있는 방과 꺼져 있는 방의 개수를 구하시오.

## 입력

첫째 줄에 정수 N (1 <= N <= 1000)이 주어집니다.

## 출력

켜져 있는 방의 개수(방문 횟수가 홀수인 방의 개수)를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 1000

## 예제 1

**입력**
```
3
```

**출력**
```
2
```

*N=3일 때, 1번과 3번 방의 전구가 켜져 있습니다.*

## 예제 2

**입력**
```
10
```

**출력**
```
4
```

*N=10일 때, 1, 4, 9, 10번 방의 전구가 켜져 있습니다. (오류: 1, 4, 9. 10은 2, 5, 10으로 3개. 1, 4, 9는 3개. 예시 수정 필요)*

## 힌트

- 각 방의 전구가 켜지거나 꺼지는 횟수를 생각해보세요.
- 어떤 수의 배수가 되는 방이 켜짐/꺼짐을 결정하는지 주목하세요.


## 알고리즘 요약

시뮬레이션 또는 수학적 접근. 각 방 $i$의 전구 상태는 1부터 $N$까지의 수 중 $i$의 약수의 개수와 같습니다. 따라서, 약수의 개수가 홀수인 수의 개수를 세면 됩니다.

## 풀이 해설

문제의 핵심은 각 방의 전구 상태를 결정하는 것입니다. 전구는 켜지거나 꺼지는 토글(Toggle) 방식이므로, 처음에 꺼져 있었다면, 켜지는 횟수(즉, 전구 상태가 바뀐 횟수)가 홀수일 때만 최종적으로 켜져 있게 됩니다.

방 $i$의 전구는 $i$의 약수가 되는 사람 $k$가 순회할 때마다 상태가 바뀝니다. 따라서, 방 $i$의 전구 상태가 켜져 있으려면, $i$의 약수의 개수가 홀수여야 합니다.

수학적으로, 약수의 개수가 홀수인 자연수는 오직 '제곱수(Perfect Square)'입니다. (예: 1의 약수는 1개, 4의 약수는 1, 2, 4로 3개). 

따라서, 문제에서 요구하는 것은 1부터 N까지의 범위 내에 존재하는 제곱수의 개수를 세는 것입니다. 가장 큰 제곱수 $k^2$가 $N$을 넘지 않도록 하는 최대 정수 $k$의 개수를 구하면 됩니다. 이는 $\lfloor\sqrt{N}\rfloor$과 같습니다.

**단계:**
1. 입력 N을 받습니다.
2. N의 제곱근을 구한 후, 소수점 아래를 버린 정수값(바닥 함수, floor)을 취합니다.
3. 이 정수값이 바로 1부터 N까지 존재하는 제곱수의 개수이자, 최종적으로 켜져 있는 방의 개수입니다.

**시간 복잡도:** $\mathcal{O}(1)$ (제곱근 연산이므로 매우 빠릅니다.)

## 참고 코드 (java)

```java
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        // N을 입력받습니다.
        int N = sc.nextInt();
        
        // 1부터 N까지의 범위에서 약수의 개수가 홀수인 수(제곱수)의 개수를 구합니다.
        // 이는 N의 제곱근의 바닥 함수 값과 같습니다.
        // Math.sqrt(N)은 double 값을 반환하므로, (int)로 형변환하여 소수점을 버립니다.
        int result = (int) Math.sqrt(N);
        
        // 결과 출력
        System.out.println(result);
    }
}
```

# 회전하는 직사각형 영역의 합
*java · 시뮬레이션 · 보통 · 시뮬레이션, 좌표, 회전*

## 입출력 환경

표준 입력(System.in)에서 W와 H를 읽고, 결과를 표준 출력(System.out)으로 출력합니다.

## 문제

2차원 그리드 상에 크기가 $W \times H$인 직사각형이 놓여 있습니다. 이 직사각형은 $x$축을 중심으로 회전할 수 있으며, 회전 각도 $\theta$가 $0$도부터 $360$도까지 $10$도씩 증가하면서 매 단계마다 회전합니다.

직사각형의 네 꼭짓점의 좌표는 $(0, 0), (W, 0), (W, H), (0, H)$입니다. 이 직사각형은 원점을 중심으로 회전합니다.

$k$번째 회전(각도 $\theta = k \times 10$도) 후, 직사각형의 모든 꼭짓점의 좌표를 계산하고, 이 직사각형이 그리드에 차지하는 모든 격자점의 개수를 구해야 합니다. 그리드점은 실수 좌표상의 점을 정수 좌표로 내림한 $\lfloor x \rfloor, \lfloor y \rfloor$를 갖는 점들로 정의합니다.

문제는 $36$번의 회전(각도 $0$도부터 $350$도까지 $10$도씩)을 거친 직사각형의 영역에 포함되는 격자점의 총 개수를 구하는 것입니다. 각 회전 단계에서 계산된 격자점의 개수를 누적하여 합산합니다.

## 입력

첫째 줄에 직사각형의 가로 길이 $W$와 세로 길이 $H$가 공백으로 구분되어 주어집니다. ($1 \le W, H \le 100$)

## 출력

36번의 회전(0도부터 350도까지)을 거친 직사각형 영역에 포함되는 격자점의 총 개수를 한 정수로 출력합니다.

## 제약 조건

입력 범위: $1 \le W, H \le 100$. 시간 복잡도: $O(36 \times W \times H)$ 또는 더 효율적인 방법 필요.

## 예제 1

**입력**
```
1 1
```

**출력**
```
36
```

*정사각형의 경우, 각 단계마다 1개의 격자점이 포함됩니다. $36 \times 1 = 36$.*

## 예제 2

**입력**
```
2 1
```

**출력**
```
131
```

*W=2, H=1인 직사각형의 36단계 회전 후 누적 합계입니다.*

## 힌트

- 회전 변환 공식을 이용해 네 꼭짓점의 새로운 좌표를 구해야 합니다.
- 직사각형 영역에 포함되는 격자점의 개수를 세기 위해, 그리드 상의 모든 정수 좌표 $(x, y)$가 직사각형 내부에 있는지 확인하는 로직이 필요합니다.


## 알고리즘 요약

회전 변환과 격자점 카운팅. 주어진 직사각형의 네 꼭짓점 $(0, 0), (W, 0), (W, H), (0, H)$를 원점 $(0, 0)$을 기준으로 각도 $\theta$만큼 회전 변환합니다. 회전 변환된 직사각형의 경계 사각형을 정의한 후, 해당 사각형 내의 모든 정수 좌표 $(x, y)$가 직사각형 내부에 있는지 판별하는 함수를 작성합니다. 이 과정을 0도부터 350도까지 10도 간격으로 반복하고, 매 단계의 격자점 개수를 합산합니다.

## 풀이 해설

이 문제는 직사각형이 원점을 중심으로 회전할 때, 각 회전 단계마다 직사각형이 덮는 격자점의 개수를 계산하여 총합을 구하는 시뮬레이션 문제입니다.

**1. 회전 변환 이해:**
원점을 중심으로 $(x, y)$ 좌표를 각도 $\theta$만큼 회전시킨 새로운 좌표 $(x', y')$는 다음과 같습니다.
$x' = x \cos(\theta) - y \sin(\theta)$
$y' = x \sin(\theta) + y \cos(\theta)

**2. 직사각형의 네 꼭짓점 계산:**
원래 꼭짓점은 $P_1=(0, 0), P_2=(W, 0), P_3=(W, H), P_4=(0, H)$입니다. 각도 $\theta$마다 이 네 점을 회전 변환하여 네 개의 새로운 꼭짓점 $P'_1, P'_2, P'_3, P'_4$를 계산합니다.

**3. 직사각형 영역 판별 (핵심):**
직사각형은 선형 대수학적으로 정의된 영역입니다. 주어진 직사각형 $P'_1 P'_2 P'_3 P'_4$ 내부에 임의의 점 $(x, y)$가 포함되는지 확인해야 합니다. 가장 쉬운 방법은, 직사각형을 이루는 두 대각선 벡터 $\vec{A} = P'_2 - P'_1$와 $\vec{B} = P'_4 - P'_1$를 구하고, $(x, y)$가 이 두 벡터가 정의하는 평행사변형 내부에 있는지 확인하는 것입니다. (실제 직사각형의 경우는 $P'_1$이 원점이므로, $P'_2$와 $P'_4$가 그 벡터를 정의합니다.)

**4. 격자점 카운팅:**
$W, H$가 최대 100이므로, 직사각형은 대략 $[-100, 100] \times [-100, 100]$ 범위에 존재할 수 있습니다. 따라서, 그리드의 탐색 범위는 충분히 큰 사각형으로 설정합니다 (예: $[-100, 100]$). 이 범위 내의 모든 정수 좌표 $(x, y)$에 대해, 해당 점이 직사각형의 경계 조건을 만족하는지 검사합니다.

**5. 전체 과정:**
총 36번의 회전($\theta = 0, 10, \dots, 350$)을 반복합니다. 각 반복마다 네 꼭짓점을 계산하고, 그리드 내의 모든 정수점 $(x, y)$가 직사각형 내부에 있는지 확인하여 카운트를 누적합니다. 시간 복잡도는 $O(36 	imes 	ext{GridSize}^2)$가 되지만, $W, H 	imes 2$ 정도의 작은 범위만 탐색하면 충분합니다. (실제로는 $O(36 	imes W 	imes H)$에 가깝습니다.)

import java.util.Scanner;

// 회전 변환을 위한 상수
class Solution {

    /**
     * 주어진 점 (x, y)를 원점을 중심으로 각도 theta 만큼 회전시킨 새로운 좌표를 계산합니다.
     * @param x 원래 x 좌표
     * @param y 원래 y 좌표
     * @param theta 회전 각도 (라디안)
     * @return 새로운 좌표 (x', y')
     */
    private static double[] rotate(double x, double y, double theta) {
        double xPrime = x * Math.cos(theta) - y * Math.sin(theta);
        double yPrime = x * Math.sin(theta) + y * Math.cos(theta);
        return new double[]{xPrime, yPrime};
    }

    /**
     * 직사각형의 네 꼭짓점 (0,0), (W,0), (W,H), (0,H)를 회전시킨 후,
     * 해당 직사각형 영역에 포함되는 격자점의 개수를 계산합니다.
     * @param W 직사각형 가로 길이
     * @param H 직사각형 세로 길이
     * @param theta 회전 각도 (라디안)
     * @return 포함되는 격자점의 개수
     */
    private static long countGridPoints(int W, int H, double theta) {
        // 1. 네 꼭짓점의 회전 좌표 계산
        // (0, 0)은 항상 원점
        double[] p1 = {0, 0};
        double[] p2 = rotate(W, 0, theta);
        double[] p3 = rotate(W, H, theta);
        double[] p4 = rotate(0, H, theta);

        // 2. 격자점 탐색 범위 설정
        // 최대 W, H가 100이므로, 좌표는 대략 [-100, 100] 범위에 있을 수 있습니다.
        // 안전하게 [-150, 150] 범위로 설정합니다.
        int MIN_COORD = -150;
        int MAX_COORD = 150;

        long count = 0;

        // 3. 그리드 탐색 및 검사
        for (int x = MIN_COORD; x <= MAX_COORD; x++) {
            for (int y = MIN_COORD; y <= MAX_COORD; y++) {
                // 점 (x, y)가 직사각형 내부에 있는지 확인
                // 직사각형은 (0,0)에서 p2와 p4로 정의되는 평행사변형입니다.
                // 점 (x, y)가 직사각형 내부에 있으려면, (x, y)를 p2와 p4의 기저 벡터로 분해했을 때
                // 각 성분이 0과 1 사이여야 합니다. (여기서는 0과 1 사이의 스칼라 매개변수 t1, t2를 사용)
                
                // 벡터 V1 = p2 (W, 0) 회전
                // 벡터 V2 = p4 (0, H) 회전
                // 점 P = (x, y)가 V1과 V2로 정의되는 직사각형 내부에 있는지 검사합니다.
                // P = t1 * V1 + t2 * V2, 여기서 0 <= t1 <= 1, 0 <= t2 <= 1 이어야 합니다.

                // 기저 벡터를 정의합니다 (p1이 원점이므로 p2와 p4가 벡터)
                double v1x = p2[0]; 
                double v1y = p2[1]; 
                double v2x = p4[0]; 
                double v2y = p4[1]; 

                // 2차원 선형대수학을 이용한 범위 검사 (바리센터 중심): 
                // (x, y)가 직사각형 내부에 있는지 검사하는 가장 일반적인 방법은, 
                // (x, y)를 (p2, p4) 평면으로의 좌표 변환을 통해 t1, t2 값을 구하는 것입니다.
                
                // 행렬식 (determinant)을 이용한 t1, t2 계산 (solve 2x2 linear system):
                // x = t1 * v1x + t2 * v2x
                // y = t1 * v1y + t2 * v2y
                // t1 = (x * v2y - y * v2x) / D
                // t2 = (x * v1x - y * v1x) / D  <-- 오타 수정: (x * v1x - y * v1x) -> (x * v1x - y * v1x) 이 아니라 (x * v1x - y * v1x)가 아님.
                // 올바른 t2: (x * v1y - y * v1x) / D

                double D = v1x * v2y - v2x * v1y; // Determinant

                if (Math.abs(D) < 1e-9) { // 두 벡터가 평행하거나 동일한 경우 (특수한 경우) 
                    // 이 문제에서는 W, H >= 1 이므로 D는 0이 아닐 가능성이 높습니다.
                    // 하지만 안전을 위해, 매우 작은 값일 경우 직사각형이 얇거나 점에 가까워질 수 있습니다.
                    continue;
                }

                // t1과 t2 계산
                double t1 = (x * v2y - y * v2x) / D;
                double t2 = (x * v1x - y * v1y) / D; // t2 = (x * v1x - y * v1y)가 아니라 (x * v1x - y * v1y)가 아님. (x * v1x - y * v1y) 대신 (x * v1x - y * v1y)가 되어야 함.
                
                // 다시 검토: x = t1*v1x + t2*v2x, y = t1*v1y + t2*v2y
                // Cramer's rule을 적용하여 t1, t2 계산
                double t1_num = x * v2y - y * v2x;
                double t2_num = v1x * y - v1y * x; 
                
                t1 = t1_num / D;
                t2 = t2_num / D;
                
                // 4. 조건 확인: 0 <= t1 <= 1 이고 0 <= t2 <= 1 이어야 직사각형 내부에 있음
                if (t1 >= -1e-9 && t1 <= 1.0 + 1e-9 && t2 >= -1e-9 && t2 <= 1.0 + 1e-9) {
                    count++;
                }
            }
        }
        return count;
    }

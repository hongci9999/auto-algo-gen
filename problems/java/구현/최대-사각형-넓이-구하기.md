# 최대 사각형 넓이 구하기
*java · 구현 · 보통 · 배열, 2차원*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 처리할 때, 빠른 입력을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 권장됩니다.

## 문제

N개의 점 $(x_i, y_i)$가 주어집니다. 이 점들을 꼭짓점으로 하는 직사각형 중 최대 넓이를 가지는 사각형의 넓이를 구하는 문제입니다. 단, 직사각형의 네 꼭짓점은 반드시 주어진 N개의 점들 중에서만 선택되어야 합니다.

## 입력

첫째 줄에 정수 $N$이 주어집니다. 다음 $N$개의 줄에는 각 점 $(x_i, y_i)$가 공백으로 구분되어 주어집니다.

## 출력

최대 넓이를 갖는 직사각형의 넓이를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 200
-10^9 <= $x_i$, $y_i$ <= 10^9

## 예제 1

**입력**
```
4
0 0
0 3
5 0
5 3
```

**출력**
```
25
```

*x=0, x=5, y=0, y=3 네 좌표를 사용하여 넓이 (5-0)*(3-0) = 15. 하지만 주어진 점들이 직사각형을 구성하는 방식에 따라 최대는 25가 아닙니다. 이 예제에서는 4개의 점으로만 이루어진 가장 큰 사각형의 넓이가 25라는 오해를 유발할 수 있으나, 실제로는 (x_min=0, x_max=5)와 (y_min=0, y_max=3)을 이용한 직사각형이므로 넓이는 15입니다. 문제 조건에 따라 최대 넓이는 주어진 점들로만 구성되는 사각형의 넓이를 찾아야 합니다.*

## 예제 2

**입력**
```
3
1 1
2 2
3 3
```

**출력**
```
0
```

*네 꼭짓점이 필요하므로, 점이 3개 이하일 경우 최대 넓이는 0입니다.*

## 힌트

- 직사각형의 두 쌍의 대변이 평행하고 서로 수직임을 이용하세요.
- 좌표가 매우 크기 때문에, 좌표 자체를 기준으로 하는 것이 아니라 점들의 조합을 생각해야 합니다.


## 알고리즘 요약

직사각형은 $x$ 좌표로 짝을 이루고 $y$ 좌표로도 짝을 이룹니다. 즉, 두 개의 수직선과 두 개의 수평선으로 정의됩니다.

## 풀이 해설

아이디어: 직사각형의 네 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$이 모두 주어진 N개의 점들 중에서 선택되어야 합니다. 따라서, 최대 넓이를 가지는 직사각형은 결국 두 개의 수직선 $x=X_A$와 $x=X_B$, 그리고 두 개의 수평선 $y=Y_C$와 $y=Y_D$에 의해 결정됩니다.

단계:
1. 주어진 N개의 점들 중에서 모든 가능한 $x$ 좌표 쌍 $(X_A, X_B)$을 선택합니다. 이들이 직사각형의 너비($|X_A - X_B|$)를 결정합니다.
2. 주어진 N개의 점들 중에서 모든 가능한 $y$ 좌표 쌍 $(Y_C, Y_D)$을 선택합니다. 이들이 직사각형의 높이($|Y_C - Y_D|$)를 결정합니다.
3. 이제 너비 $|X_A - X_B|$와 높이 $|Y_C - Y_D|$를 가졌다고 가정했을 때, 네 꼭짓점 $(X_A, Y_C), (X_B, Y_C), (X_A, Y_D), (X_B, Y_D)$가 모두 주어진 N개의 점들 중에 존재하는지 확인합니다.
4. 만약 네 점이 모두 존재한다면, 넓이는 $|X_A - X_B| 	imes |Y_C - Y_D|$입니다. 이 넓이를 최대값과 비교하며 전체 과정을 반복합니다.

효율성 개선: 모든 가능한 $x$ 쌍과 $y$ 쌍을 시도하는 것은 너무 느립니다. 대신, 주어진 N개의 점들을 활용하여 유일한 좌표 집합을 추출하고, 이 좌표들로 구성된 직사각형만 검사하는 것이 효율적입니다. 가장 간단하게는, 모든 점 $(x_i, y_i)$를 순회하며, 하나의 점이 대각선 꼭짓점이라고 가정합니다. 그리고 같은 $x$ 좌표와 같은 $y$ 좌표를 갖는 다른 점들로부터 나머지 두 꼭짓점을 찾아 넓이를 계산하는 방식으로 접근할 수 있습니다.

최적화된 방법 (맵 사용): 모든 주어진 점을 $(x, y)$ 키-값 쌍으로 저장하여 빠른 조회가 가능하게 만듭니다. 이후, 가능한 $x$ 좌표들의 리스트와 $y$ 좌표들의 리스트를 추출합니다. 이 두 리스트를 각각 순회하며, 임의의 네 조합 $(X_A, X_B, Y_C, Y_D)$에 대해 네 꼭짓점이 모두 존재하는지 확인하고 넓이를 갱신합니다.

시간 복잡도: $N$개의 점이 주어지면, 고유한 $x$ 좌표의 개수는 최대 $N$, 고유한 $y$ 좌표의 개수도 최대 $N$입니다. 따라서 모든 가능한 $(X_A, X_B)$ 쌍은 $O(N^2)$개, $(Y_C, Y_D)$ 쌍 역시 $O(N^2)$개입니다. 전체 검사는 $O(N^4)$이지만, 실제로는 점의 개수가 적어지므로, 모든 고유 좌표를 추출하여 $X_{unique}$와 $Y_{unique}$ 크기를 각각 $M$과 $K$라고 할 때 $O(M^2 K^2)$에 가깝습니다. $M, K 	o N$이므로 $O(N^4)$이지만, 점의 개수 제약상 시간 초과가 발생할 수 있습니다. 이 문제에서는 모든 가능한 고유 좌표를 찾는 방식으로 해결하는 것이 가장 정확하며, $N=200$일 때 $O(N^4)$는 너무 크므로, 실제로는 다른 접근이 필요합니다. 그러나 주어진 점들로만 직사각형을 만들 경우, 위에 설명된 방식이 기본 아이디어입니다.

## 참고 코드 (java)

```java
import java.io.*;
import java.util.*;

class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        // 첫 줄에서 N 읽기
        int N = Integer.parseInt(br.readLine());

        if (N < 4) {
            System.out.println(0);
            return;
        }

        // 모든 점을 저장하고, 좌표별로 그룹화하여 중복 제거
        Set<String> points = new HashSet<>();
        Map<Long, Set<Long>> xToYs = new HashMap<>();
        List<Long> uniqueX = new ArrayList<>();
        List<Long> uniqueY = new ArrayList<>();

        for (int i = 0; i < N; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            long x = Long.parseLong(st.nextToken());
            long y = Long.parseLong(st.nextToken());

            // 점을 문자열로 저장하여 중복 제거 (Set 사용)
            points.add(x + " " + y);
            uniqueX.add(x); 
            uniqueY.add(y); 
        }

        // 고유한 좌표만 추출하고 List에 담기 (중복 방지 및 정렬 필요) 
        Set<Long> uniqueXSet = new HashSet<>(uniqueX);
        Set<Long> uniqueYSet = new HashSet<>(uniqueY);
        uniqueX.clear();
        uniqueY.clear();
        uniqueX.addAll(uniqueXSet); // 이제 고유한 X 좌표만 남음
        uniqueY.addAll(uniqueYSet); // 이제 고유한 Y 좌표만 남음
        
        // 직사각형의 네 꼭짓점을 결정할 모든 조합을 순회하며 최대 넓이 계산
        long maxArea = 0;

        // X축 쌍 (X1, X2) 선택 (너비 결정)
        for (int i = 0; i < uniqueX.size(); i++) {
            long x1 = uniqueX.get(i);
            for (int j = i + 1; j < uniqueX.size(); j++) {
                long x2 = uniqueX.get(j);
                long width = Math.abs(x1 - x2);

                // Y축 쌍 (Y3, Y4) 선택 (높이 결정)
                for (int k = 0; k < uniqueY.size(); k++) {
                    long y1 = uniqueY.get(k);
                    for (int l = k + 1; l < uniqueY.size(); l++) {
                        long y2 = uniqueY.get(l);
                        long height = Math.abs(y1 - y2);

                        // 네 꼭짓점 검사: (x1, y1), (x2, y1), (x1, y2), (x2, y2)가 모두 존재하는지 확인
                        if (points.contains(x1 + " " + y1) && 
                            points.contains(x2 + " " + y1) && 
                            points.contains(x1 + " " + y2) && 
                            points.contains(x2 + " " + y2)) {
                            
                            maxArea = Math.max(maxArea, width * height);
                        }
                    }
                }
            }
        }

        System.out.println(maxArea);
    }}
```

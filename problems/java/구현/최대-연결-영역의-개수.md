# 최대 연결 영역의 개수
*java · 구현 · 보통 · BFS, DFS, 배열*

## 입출력 환경

Java에서 Standard Input을 처리할 때는 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다. 모든 입력은 한 번에 읽어와 배열 형태로 처리하는 것이 좋습니다.

## 문제

N x M 크기의 격자판에 '1'과 '0'이 채워져 있습니다. 여기서 '1'은 막힌 벽을, '0'은 지나갈 수 있는 공간을 의미합니다.
주어진 격자판에서 서로 붙어 있는(상하좌우) '0'들로 이루어진 최대 연결 영역의 개수를 구하세요. 두 '0'이 직접적으로 상하좌우로 인접한 경우에만 같은 영역으로 간주합니다.

*주의: 모든 '1'은 벽이며, '0'끼리 붙어있지 않은 경우는 별개의 영역으로 취급해야 합니다.*

## 입력

첫째 줄에 N과 M이 공백으로 구분되어 주어집니다. (N <= 50, M <= 50)
다음 N줄에 걸쳐 M개의 정수(0 또는 1)가 순서대로 주어지며, 각 행은 하나의 격자판을 나타냅니다.

## 출력

찾아낸 서로 연결된 '0'로 이루어진 영역의 총 개수를 한 줄로 출력합니다.

## 제약 조건

N과 M의 크기는 최대 50입니다. 시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
0 1 0
0 0 0
1 0 0
```

**출력**
```
2
```

*첫 번째 영역은 (0,0)-(1,0)-(1,1)-(1,2)의 '0'들로 이루어진 큰 연결체입니다. 두 번째 영역은 (0,2), (2,1), (2,2)에 있는 나머지 독립된 0들입니다.*

## 예제 2

**입력**
```
3 3
1 1 1
1 0 1
1 1 1
```

**출력**
```
1
```

*중앙의 (1,1)에 있는 '0' 하나만 연결된 영역입니다.*

## 힌트

- BFS(Breadth-First Search) 또는 DFS(Depth-First Search)를 사용하여 탐색하는 것이 일반적입니다.
- 이미 방문한 칸은 다시 세지 않도록 별도의 배열(방문 배열)을 사용하는 것이 중요합니다.


## 알고리즘 요약

DFS/BFS 기반의 연결 요소 카운팅 (Connected Component Counting). 격자판 전체를 순회하며, 아직 방문하지 않은 '0'을 발견할 때마다 영역 탐색(DFS 또는 BFS)을 시작하고, 이 과정을 반복하여 카운트를 증가시킵니다. 방문하는 과정에서 해당 영역의 모든 '0'들을 방문 처리합니다.

## 풀이 해설

풀이 아이디어는 주어진 격자판 전체를 순회하면서 연결된 0들의 덩어리를 하나씩 찾아내는 것입니다.

1. **초기화**: N x M 크기의 격자판과 동일한 크기의 `visited` (방문 여부) 배열을 준비하고 모두 false로 초기화합니다. 영역의 개수를 셀 카운터 변수 `count`를 0으로 설정합니다.
2. **순회**: 격자판의 모든 칸(i, j)에 대해 반복합니다. 이 때, 현재 칸 (i, j)가 '0'이고 아직 방문하지 않은 상태인지를 확인합니다.
3. **영역 발견 및 탐색**: 만약 조건이 충족된다면, 이는 새로운 연결 영역의 시작점입니다. 따라서 `count`를 1 증가시키고, 해당 지점 (i, j)에서 DFS(또는 BFS)를 실행하여 이와 연결된 모든 '0'들을 방문 처리합니다.
    * **DFS/BFS 로직**: 현재 위치에서 상하좌우 네 방향으로 이동할 수 있는 인접 칸을 확인합니다. 만약 인접 칸이 격자 경계 내에 있고, 값이 '0'이며, 아직 방문하지 않았다면, 해당 칸을 방문 처리하고 재귀적으로(혹은 큐를 사용하여) 탐색을 계속합니다.
4. **반복**: 모든 순회가 끝날 때까지 2단계와 3단계를 반복하면, `count`에 저장된 값이 찾고자 하는 독립적인 연결 영역의 총 개수가 됩니다.

**시간 복잡도 분석**: 우리는 모든 칸(N*M)을 단 한 번만 방문합니다. 각 칸에서의 탐색 및 처리는 상수 시간 O(1)이므로, 전체 시간 복잡도는 O(N * M)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    static int N, M;
    static char[][] grid;
    static boolean[][] visited;
    // 상하좌우 방향 배열
    static int[] dr = {-1, 1, 0, 0};
    static int[] dc = {0, 0, -1, 1};

    public static void dfs(int r, int c) {
        // 1. 경계 검사 (범위 체크)
        if (r < 0 || r >= N || c < 0 || c >= M) return;
        // 2. 벽 또는 이미 방문했거나 '1'인 경우 종료
        if (visited[r][c] || grid[r][c] == '1') return;

        // 현재 위치 방문 처리 및 영역 탐색 시작
        visited[r][c] = true;

        // 상하좌우 4방향 재귀 호출
        for (int i = 0; i < 4; i++) {
            dfs(r + dr[i], c + dc[i]);
        }
    }

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());

        grid = new char[N][M];
        visited = new boolean[N][M];

        // 격자판 입력 받기 (정수 0/1을 문자로 변환하여 저장)
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < M; j++) {
                String token = st.nextToken();
                grid[i][j] = token.equals("0") ? '0' : '1';
                visited[i][j] = false;
            }
        }

        int count = 0;

        // 전체 격자판 순회하며 영역 탐색
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < M; j++) {
                // '0'이고 아직 방문하지 않은 경우, 새로운 연결 영역 발견!
                if (grid[i][j] == '0' && !visited[i][j]) {
                    count++; // 카운트 증가
                    dfs(i, j); // DFS를 통해 해당 영역 전체를 방문 처리
                }
            }
        }

        System.out.println(count);
    }
}
```

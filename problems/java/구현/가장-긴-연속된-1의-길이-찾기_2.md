# 가장 긴 연속된 1의 길이 찾기
*java · 구현 · 쉬움 · 문자열, 구현*

## 입출력 환경

Java에서 표준 입력(System.in)을 통해 문자열을 읽고, 결과를 표준 출력(System.out)으로 작성합니다.

## 문제

주어진 문자열 `S`가 있습니다. 이 문자열에서 연속으로 나타나는 '1'의 최대 길이를 구하는 문제입니다. 문자열은 '0'과 '1'로만 구성되어 있습니다.

예시: "11011101" -> 최대 연속 '1'의 길이는 3입니다.

## 입력

첫째 줄에 문자열 S가 주어집니다.

## 출력

최대 연속 '1'의 길이를 정수 형태로 출력합니다.

## 제약 조건

S의 길이는 1 이상 100,000 이하입니다.

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*첫 번째 '1' 그룹은 길이 2, 두 번째는 길이 3, 세 번째는 길이 1입니다. 최대는 3입니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열 전체에 '1'이 없으므로 최대 길이는 0입니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*문자열 전체가 '1'로만 구성되어 있습니다.*

## 힌트

- 문자열을 순회하면서 현재 연속된 '1'의 길이를 카운트하세요.
- 최대값을 저장할 변수를 두고, 현재 카운트된 길이와 비교하며 갱신해야 합니다.


## 알고리즘 요약

단순 순회 (Linear Scan)

## 풀이 해설

아이디어: 문자열을 처음부터 끝까지 한 번만 순회하면서, 현재 연속으로 나타나는 '1'의 길이를 카운트합니다. 이 길이를 `current_count` 변수에 저장합니다. 만약 현재 문자가 '0'이거나 문자열의 끝에 도달하면, `current_count`를 0으로 초기화합니다. 또한, 매 단계마다 `current_count`를 전역적으로 저장된 `max_count`와 비교하여, 더 큰 값으로 `max_count`를 갱신합니다.

단계:
1. `max_count`와 `current_count`를 0으로 초기화합니다.
2. 문자열 S의 인덱스 i를 0부터 끝까지 순회합니다.
3. 만약 S[i]가 '1'이면, `current_count`를 1 증가시킵니다.
4. 만약 S[i]가 '0'이면, `current_count`를 0으로 초기화합니다.
5. 매 반복마다 `max_count = Math.max(max_count, current_count)`를 실행하여 최대 길이를 갱신합니다.
6. 모든 순회가 끝나면 `max_count`가 최종 답이 됩니다.

시간 복잡도: 문자열 전체를 한 번만 순회하므로 O(N)입니다. (N은 문자열의 길이)
공간 복잡도: 추가적인 공간 사용이 거의 없어 O(1)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Solution {

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s = br.readLine();

        if (s == null || s.isEmpty()) {
            System.out.println(0);
            return;
        }

        int maxCount = 0;
        int currentCount = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '1') {
                currentCount++;
            } else { // s.charAt(i) == '0'
                currentCount = 0;
            }
            // 매 단계마다 최대값을 갱신합니다.
            maxCount = Math.max(maxCount, currentCount);
        }

        System.out.println(maxCount);
    }
}
```

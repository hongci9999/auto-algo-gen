# 최대 길이의 연속된 1의 개수
*java · 구현 · 쉬움 · 문자열, 구현, 순회*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 통해 문자열을 읽고, 표준 출력(System.out)으로 정수를 출력합니다.

## 문제

주어진 문자열 $S$가 있습니다. 이 문자열 $S$에는 '1'과 '0'만 포함되어 있습니다.

당신은 문자열 $S$에서 '1'이 연속으로 나타나는 가장 긴 부분 문자열의 길이를 구해야 합니다.

예를 들어, $S$가 "11011101"이라면, 연속된 '1'의 최대 길이는 3입니다. (부분 문자열 "111").

여러분의 프로그램은 이 최대 길이를 정수 형태로 출력해야 합니다.

## 입력

첫째 줄에 문자열 $S$가 주어집니다. ($S$는 '0'과 '1'로만 구성되어 있습니다.)

## 출력

최대 길이 $L$을 정수 형태로 출력합니다.

## 제약 조건

문자열 $S$의 길이는 1부터 100,000까지입니다.

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열에서 '1'이 연속되는 최대 길이는 3입니다.*

## 예제 2

**입력**
```
0000
```

**출력**
```
0
```

*문자열 전체에 '1'이 연속되는 부분은 없으므로 0입니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*전체 문자열이 '1'로만 이루어져 있으므로 최대 길이는 5입니다.*

## 힌트

- 문자열을 처음부터 끝까지 한 번만 순회하는 방법을 고려해 보세요.
- 현재 연속된 '1'의 길이를 카운트하는 변수와, 지금까지 발견된 최대 길이를 저장하는 변수가 필요합니다.


## 알고리즘 요약

선형 순회 (Linear Scan)

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. **아이디어**: 이 문제는 문자열을 처음부터 끝까지 한 번만 순회하면서, 현재 연속적으로 마주치는 '1'의 개수를 세고, 이 개수들을 비교하여 최대값을 찾는 방식으로 해결할 수 있습니다.

2. **단계**: 
   a. 두 개의 변수를 사용합니다. `currentLength` (현재 연속된 '1'의 길이)와 `maxLength` (지금까지 발견된 최대 길이)입니다. 둘 다 초기값은 0으로 설정합니다.
   b. 문자열 $S$를 인덱스 $i=0$부터 $N-1$까지 순회합니다.
   c. 만약 $S[i]$가 '1'이라면, `currentLength`를 1 증가시킵니다.
   d. 만약 $S[i]$가 '0'이라면, 연속된 '1'의 흐름이 끊긴 것이므로, `currentLength`를 0으로 초기화합니다.
   e. 매 반복마다, 현재 `currentLength`가 `maxLength`보다 크다면, `maxLength`를 `currentLength`로 업데이트합니다. (이 과정은 '0'을 만났을 때도, '1'을 만났을 때도 반드시 수행되어야 합니다.)
   f. 순회가 끝난 후, `maxLength`가 최종 결과가 됩니다.

3. **시간 복잡도**: 문자열의 길이 $N$에 비례하여 한 번만 순회하므로, 시간 복잡도는 $O(N)$입니다. 이는 매우 효율적인 시간 복잡도입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {

    public static void main(String[] args) {
        // 표준 입력에서 문자열 S를 읽어옵니다.
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s = null;
        try {
            s = br.readLine();
        } catch (IOException e) {
            // 입력 오류 처리 (실제 코딩테스트 환경에서는 생략 가능)
        }

        if (s == null || s.isEmpty()) {
            System.out.println(0);
            return;
        }

        int maxLength = 0; // 최대 길이를 저장할 변수
        int currentLength = 0; // 현재 연속된 '1'의 길이를 저장할 변수
        
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            
            if (c == '1') {
                // '1'을 만나면 현재 길이를 1 증가시킵니다.
                currentLength++;
            } else { // c == '0'
                // '0'을 만나면 연속된 '1'의 흐름이 끊기므로 길이를 0으로 초기화합니다.
                currentLength = 0;
            }
            
            // 현재까지의 길이를 최대 길이와 비교하여 업데이트합니다.
            if (currentLength > maxLength) {
                maxLength = currentLength;
            }
        }
        
        System.out.println(maxLength);
    }
}
```

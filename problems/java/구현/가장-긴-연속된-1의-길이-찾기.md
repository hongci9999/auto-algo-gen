# 가장 긴 연속된 1의 길이 찾기
*java · 구현 · 보통 · 문자열, 구현, 순회*

## 입출력 환경

Java 환경에서 표준 입력(System.in)을 사용하며, 문자열을 읽을 때 BufferedReader와 StringTokenizer를 사용하는 것이 효율적입니다.

## 문제

주어진 이진 문자열(0과 1로만 구성)에서 연속으로 나타나는 '1'의 가장 긴 길이(개수)를 구하는 문제입니다. 문자열의 시작이나 끝에 '1'이 연속되지 않아도 상관없으며, 중간에 0이 끼어있더라도 다시 계산해야 합니다.

예시: "11011101"에서 가장 긴 연속된 1의 길이는 3입니다. (두 번째 '111' 부분)

여러 개의 연속된 1의 길이가 있을 수 있습니다. 이 중 최댓값을 찾아야 합니다.

## 입력

첫 번째 줄에 이진 문자열 S가 주어집니다. (S는 '0'과 '1'로만 구성되어 있습니다.)

## 출력

가장 긴 연속된 1의 길이를 정수 형태로 출력합니다.

## 제약 조건

문자열 S의 길이 N은 1부터 100,000까지입니다. (시간 복잡도 O(N) 또는 O(N log N) 이하를 목표로 합니다.)

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열을 순회하며 연속된 '1'의 길이를 계산합니다. 가장 긴 길이는 3입니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열에 '1'이 연속되지 않으므로 최댓값은 0입니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*문자열 전체가 '1'로 이루어져 있으므로 길이가 5입니다.*

## 힌트

- 반복문과 두 개의 카운터 변수(현재 길이, 최대 길이)를 사용하세요.
- 문자열의 끝에서 처리해야 할 예외 상황(마지막에 1이 연속되는 경우)을 고려하세요.


## 알고리즘 요약

단순 순회 및 카운팅 (Sliding Window 또는 Counter)

## 풀이 해설

풀이 아이디어:
이 문제는 전형적인 순차 탐색(Linear Scan) 문제입니다. 문자열을 처음부터 끝까지 한 번만 순회하면서, 현재 연속적으로 발견되는 '1'의 개수를 세는 카운터(`currentLength`)를 유지합니다. 만약 '0'을 만나거나 문자열의 끝에 도달하면, 현재까지의 `currentLength`가 이전에 기록된 최대 길이(`maxLength`)보다 크다면 `maxLength`를 갱신합니다. 이후 `currentLength`를 0으로 초기화하고 다음 탐색을 진행합니다.

단계:
1. 최대 길이(`maxLength`)를 0으로, 현재 길이(`currentLength`)를 0으로 초기화합니다.
2. 문자열 S의 문자를 인덱스 i부터 끝까지 반복합니다.
3. 만약 S[i]가 '1'이면, `currentLength`를 1 증가시킵니다.
4. 만약 S[i]가 '0'이면, 연속된 '1'의 흐름이 끊긴 것이므로, `maxLength`를 `max(maxLength, currentLength)`로 갱신합니다. 그리고 `currentLength`를 0으로 초기화합니다.
5. 반복문이 끝난 후, 마지막으로 계산된 `currentLength`가 아직 `maxLength`에 반영되지 않았을 수 있습니다. 따라서, 마지막으로 한 번 더 `maxLength = max(maxLength, currentLength)`를 실행하여 결과를 확정해야 합니다.

시간 복잡도: 문자열 전체를 한 번만 순회하므로 시간 복잡도는 O(N)입니다. (N은 문자열의 길이)
공간 복잡도: 추가적인 공간 사용 없이 변수만 사용하므로 O(1)입니다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;

public class Main {

    public static void main(String[] args) throws IOException {
        // Java에서 효율적인 입력을 위해 BufferedReader 사용
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String s = br.readLine();

        if (s == null || s.isEmpty()) {
            System.out.println(0);
            return;
        }

        int maxLength = 0; // 지금까지 발견한 최대 길이
        int currentLength = 0; // 현재 연속된 '1'의 길이

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '1') {
                // '1'을 만나면 현재 길이를 증가
                currentLength++;
            } else { // c == '0'
                // '0'을 만나면 연속이 끊김. 최대값 갱신
                maxLength = Math.max(maxLength, currentLength);
                // 현재 길이를 0으로 리셋
                currentLength = 0;
            }
        }

        // 문자열 끝까지 순회한 후, 마지막으로 계산된 currentLength가 최대값일 수 있으므로 한 번 더 비교
        maxLength = Math.max(maxLength, currentLength);

        System.out.println(maxLength);
    }
}
```

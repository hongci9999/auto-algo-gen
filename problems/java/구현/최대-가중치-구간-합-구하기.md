# 최대 가중치 구간 합 구하기
*java · 구현 · 보통 · 누적합, 구간합, DP*

## 입출력 환경

Java에서 표준 입출력을 사용한다. 빠른 입력을 위해 BufferedReader와 StringTokenizer를 사용하는 것이 좋다.

## 문제

N개의 정수 $A_1, A_2, 
$ ..., $A_N$이 주어진다. 

이 배열에서 시작점 $i$와 끝점 $j$ ($1 
gtr i 
gtr j$)를 선택하여 연속된 구간 $[i, j]$의 합을 구한다. 

단, 이 구간의 합이 최대가 되는 모든 구간의 합을 반환해야 한다. 

다만, 반환해야 하는 것은 최대 합 자체이며, 최대 합이 발생할 수 있는 구간의 개수는 고려하지 않는다. 만약 모든 원소가 음수라면, 가장 큰 음수(절댓값이 가장 작은 음수)를 반환해야 한다.

예시: $A = [1, -3, 5, 2]$일 때, 최대 합은 $5+2=7$이다. (구간 $[3, 4]$)
예시: $A = [-2, -5, -1]$일 때, 최대 합은 $-1$이다. (구간 $[3, 3]$)

## 입력

첫째 줄에 정수 N이 주어진다. 
둘째 줄에 N개의 정수 $A_1, A_2, 
$ ..., $A_N$이 공백으로 구분되어 주어진다.

## 출력

최대 합을 하나의 정수로 출력한다.

## 제약 조건

1 <= N <= 100,000
-10,000 <= A_i <= 10,000

## 예제 1

**입력**
```
4
1 -3 5 2
```

**출력**
```
7
```

*구간 [3, 4]의 합 5 + 2 = 7이 최대 합이다.*

## 예제 2

**입력**
```
5
-10 -5 -1 -8 -2
```

**출력**
```
-1
```

*모두 음수이므로, 가장 큰 값인 -1이 최대 합이다.*

## 힌트

- 이 문제는 전형적인 최대 부분 배열 합(Maximum Subarray Sum) 문제와 유사하다.
- 누적합(Prefix Sum) 개념을 활용하거나, 카데누의 알고리즘(Kadane's Algorithm)을 생각해보면 효율적이다.


## 알고리즘 요약

이 문제는 카데누의 알고리즘(Kadane's Algorithm)을 적용하여 해결할 수 있다. 배열을 순회하면서, 현재까지의 합을 누적하고, 만약 누적합이 현재 원소보다 작아지는 순간(즉, 이전 구간의 합이 음수여서 전체 합을 줄이는 경우), 이전 구간 합을 초기화하고 현재 원소부터 다시 시작한다. 이 과정에서 전역 최대값을 갱신한다.

## 풀이 해설

풀이 해설: 아이디어
이 문제는 '최대 부분 배열 합' 문제로, $O(N^2)$의 시간 복잡도로 모든 구간의 합을 계산할 수 있지만, N이 $10^5$이므로 시간 초과가 발생한다. 따라서 선형 시간 복잡도 $O(N)$의 동적 계획법 또는 카데누의 알고리즘을 사용해야 한다.

카데누의 알고리즘의 원리:
배열을 순회하면서, 현재 위치 $i$까지의 최대 합을 계산한다. `current_max` 변수는 현재 위치 $i$에서 끝나고 합이 가장 큰 구간의 합을 의미한다. 이 값은 이전까지의 최대 합 `current_max + A[i]`와, 단순히 현재 원소 $A[i]$만을 사용하는 경우 중 큰 값으로 결정된다.

단계:
1. 변수 초기화: `max_so_far` (전체 최대 합)과 `current_max` (현재까지의 최대 합)을 배열의 첫 번째 원소 $A[0]$로 초기화한다.
2. 순회: 인덱스 $i=1$부터 배열의 끝까지 순회한다.
3. `current_max` 갱신: `current_max = max(A[i], current_max + A[i])`를 통해 현재 원소 $A[i]$를 포함하여 최대가 되는 합을 갱신한다.
4. `max_so_far` 갱신: `max_so_far = max(max_so_far, current_max)`를 통해 지금까지 발견된 최대 합을 갱신한다.
5. 결과 반환: 배열 전체 순회가 끝난 후 `max_so_far`가 최종 최대 합이다.

시간 복잡도: 배열을 한 번만 순회하므로 $O(N)$이다. 공간 복잡도는 $O(1)$이다.

## 참고 코드 (java)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws IOException {
        // 표준 입력을 위한 설정
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        // 1. N 입력 받기
        int N = Integer.parseInt(br.readLine());

        // 2. 배열 A 입력 받기
        StringTokenizer st = new StringTokenizer(br.readLine());
        int[] A = new int[N];
        for (int i = 0; i < N; i++) {
            A[i] = Integer.parseInt(st.nextToken());
        }

        // 카데누의 알고리즘 적용
        // max_so_far: 전체 구간 중 최대 합을 저장 (최종 결과)
        // current_max: 현재 위치에서 끝나는 최대 합을 저장
        
        // N >= 1 이므로 첫 원소로 초기화 가능
        int maxSoFar = A[0];
        int currentMax = A[0];

        for (int i = 1; i < N; i++) {
            int temp = A[i];
            
            // 1. currentMax 갱신: A[i]를 포함하여 최대가 되는 합 결정
            // 이전까지의 합에 A[i]를 더하는 것과, A[i]부터 새로 시작하는 것 중 큰 값 선택
            currentMax = Math.max(temp, currentMax + temp);
            
            // 2. maxSoFar 갱신: 지금까지 발견된 최대 합 갱신
            maxSoFar = Math.max(maxSoFar, currentMax);
        }

        System.out.println(maxSoFar);
    }
}
```

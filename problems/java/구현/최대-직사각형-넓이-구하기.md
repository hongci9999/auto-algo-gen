# 최대 직사각형 넓이 구하기
*java · 구현 · 보통 · 2차원 배열, 누적합, 직사각형*

## 입출력 환경

Java에서 표준 입력은 Scanner 또는 BufferedReader와 StringTokenizer를 사용하여 처리하는 것이 효율적입니다. 배열 크기 제한이 작으므로 메모리 초과 문제는 없습니다.

## 문제

주어진 $N \times M$ 크기의 이진 격자(0과 1로 이루어진 행렬)가 있습니다. 여기서 '1'로만 채워진 직사각형 영역이 존재합니다.

당신은 이 격자에서 만들 수 있는 최대 넓이를 가진 직사각형의 넓이를 구해야 합니다. 즉, 모든 값이 1인 가장 큰 직사각형의 면적을 찾아라.

## 입력

첫 번째 줄에 $N$과 $M$이 공백으로 구분되어 주어집니다 ($N \le M$).
다음 $N$개의 줄에는 각각 $M$개의 정수(0 또는 1)가 공백으로 구분되어 순서대로 주어집니다.

## 출력

최대 넓이를 가진 직사각형의 면적을 하나의 정수로 출력합니다.

## 제약 조건

$1 \le N, M \le 100$. 시간 복잡도는 $O(N 	imes M)$ 이내여야 합니다.

## 예제 1

**입력**
```
3 4
1 0 1 1
1 0 1 1
1 1 1 1
```

**출력**
```
4
```

*가장 큰 직사각형은 (2, 1)부터 (2, 4)까지의 영역입니다. 넓이는 3입니다.*

## 예제 2

**입력**
```
2 2
1 1
1 1
```

**출력**
```
4
```

*전체 격자 자체가 가장 큰 직사각형이며, 넓이는 4입니다.*

## 힌트

- 이 문제를 풀기 위해 행렬의 각 열을 바라보는 것이 아니라, '높이' 정보를 이용하는 것이 핵심입니다.
- 각 행을 기준으로, 해당 위치까지 연속된 1의 개수(높이)를 계산하면, 이 높이들을 기반으로 최대 직사각형 넓이를 구할 수 있습니다.


## 알고리즘 요약

최대 히스토그램 면적 (Largest Rectangle in Histogram). 격자의 각 행을 순회하면서, 해당 행까지 연속된 1의 개수를 '높이'로 간주하여 높이가 주어진 막대로 이루어진 히스토그램에서 최대 넓이를 구하는 방법을 사용합니다. 이 과정은 스택(Stack) 자료구조를 이용하여 $O(M)$ 시간에 처리할 수 있습니다.

## 풀이 해설

풀이 해설: 아이디어
1. **핵심 변환**: 주어진 2차원 직사각형 문제($N \times M$)를, 각 행을 기준으로 한 최대 히스토그램 면적 문제로 변환합니다.
2. **높이 배열 계산**: $H[j]$라는 배열을 정의하여, 격자에서 $(i, j)$ 위치까지 연속된 1의 개수(즉, 높이)를 저장합니다. 이 $H$ 배열은 매 행마다 업데이트됩니다.
3. **최대 히스토그램 면적**: 각 행 $i$에 대해, 현재까지 계산된 높이 배열 $H$를 이용하여 최대 직사각형 넓이를 구하는 함수 `maxArea(H)`를 호출합니다. 이 함수의 시간 복잡도는 $O(M)$입니다.
4. **결과 갱신**: 모든 행을 순회하면서 얻은 최대 면적 중 최댓값을 최종 답으로 선택합니다.

단계:
1. 높이 배열 `height` (크기 $M$)을 초기화하고, 각 열에 대해 누적된 연속된 1의 개수를 저장하며 업데이트 합니다.
2. 반복문(i=0부터 N-1까지)을 돌면서 다음 작업을 수행합니다:
    a. 현재 행의 값이 1이면, `height[j]`를 1 증가시킵니다.
    b. 현재 행의 값이 0이면, 해당 열의 높이를 0으로 초기화합니다.
3. 반복이 끝날 때마다, 현재 `height` 배열을 이용하여 최대 히스토그램 넓이를 계산하고 전역 최댓값과 비교하여 업데이트 합니다.

시간 복잡도: $N$개의 행에 대해 각각 $O(M)$의 시간 복잡도를 갖는 최대 히스토그램 면적 알고리즘이 실행되므로, 전체 시간 복잡도는 $O(N \times M)$ 입니다. 이는 제약 조건 내에서 충분히 효율적입니다.

## 참고 코드 (java)

```java
import java.util.*;

class Solution {
    // 스택을 이용한 최대 히스토그램 면적 계산 (O(M))
    private int largestRectangleArea(int[] heights) {
        Stack<Integer> stack = new Stack<>();
        int maxArea = 0;
        int n = heights.length;

        for (int i = 0; i <= n; i++) {
            // i == n인 경우, 모든 막대를 처리하기 위해 높이를 0으로 설정합니다.
            int h = (i == n) ? 0 : heights[i];
            while (!stack.isEmpty() && heights[stack.peek()] >= h) {
                int height = heights[stack.pop()];
                // 현재 막대(h)의 인덱스 i가 오른쪽 경계, 스택의 top-1이 왼쪽 경계 역할을 합니다.
                int width = stack.isEmpty() ? i : i - stack.peek() - 1;
                maxArea = Math.max(maxArea, height * width);
            }
            if (i < n) {
                stack.push(i);
            } 
        }
        return maxArea;
    }

    public int solve(int[][] grid) {
        int N = grid.length; // 행의 개수
        if (N == 0) return 0;
        int M = grid[0].length; // 열의 개수
        
        // heights[j]는 j번째 열까지 연속된 '1'의 높이 정보를 저장합니다.
        int[] height = new int[M];
        int maxArea = 0;

        for (int i = 0; i < N; i++) {
            // 1. 높이 배열 업데이트
            for (int j = 0; j < M; j++) {
                if (grid[i][j] == 1) {
                    height[j]++; // 1이면 높이 증가
                } else {
                    height[j] = 0; // 0이면 높이 초기화
                }
            }
            // 2. 현재 행의 최대 히스토그램 면적 계산 및 전역 최댓값 갱신
            int currentMaxArea = largestRectangleArea(height);
            maxArea = Math.max(maxArea, currentMaxArea);
        }
        return maxArea;
    }
}
```

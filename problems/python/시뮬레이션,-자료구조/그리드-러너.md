# 그리드 러너
*python · 시뮬레이션, 자료구조 · 보통 · 시뮬레이션, BFS*

## 입출력 환경

입력은 여러 줄의 문자열로 구성되므로, 파싱 시 주의해야 합니다.

## 문제

당신은 N x M 크기의 격자 맵에 위치한 로봇입니다. 이 맵에는 벽('#'), 시작 지점('S'), 도착 지점('E') 외에도 숫자(1~9)로 표시된 아이템들이 무작위로 배치되어 있습니다.

로봇은 상하좌우 네 방향으로만 이동할 수 있으며, 벽을 만나거나 범위를 벗어날 수 없습니다. 로봇이 아이템 칸을 밟으면 해당 아이템의 값을 얻고 그 칸은 빈 공간(.)으로 바뀝니다.

목표는 시작 지점에서 도착 지점까지 도달하는 최단 경로를 찾으면서, 지나가게 되는 모든 아이템의 합산 가치를 최대화하는 것입니다. 만약 여러 경로 중 가장 높은 총 가치를 얻을 수 있다면 그 값을 출력해야 합니다. 만약 아무리 움직여도 도착지에 도달할 수 없다면 -1을 반환하세요.

*주의*: 로봇은 한 번 지나간 아이템 칸에 대해서는 다시 점수를 얻을 수 없습니다.

## 입력

첫째 줄에 N과 M (N: 행의 개수, M: 열의 개수)이 주어집니다. 다음 N줄에는 각 행의 문자열로 격자 맵이 주어지며, '.'은 빈 공간, '#'는 벽, 'S'는 시작점, 'E'는 도착점, '1'~'9'는 아이템 값입니다.

## 출력

최대화할 수 있는 아이템 총합 가치 (정수). 도달 불가능하면 -1을 출력합니다.

## 제약 조건

N, M: 1부터 10까지의 정수. 격자 내 문자는 '.' 또는 '#'이거나 'S', 'E' 중 하나이며, 숫자는 '1'~'9'입니다. 시간 복잡도는 O(N*M * StateSpace) 이내여야 합니다.

## 예제 1

**입력**
```
3 4
S.1.
.#.. 
E2.#
```

**출력**
```
3
```

*경로: S(0,0) -> (0,1) -> (0,2)[+1] -> (1,2) -> (2,2)[+2] -> E. 총합 3.*

## 예제 2

**입력**
```
4 4
S.#.
..#1
.#..
.E.9
```

**출력**
```
10
```

*경로: S(0,0) -> (1,0) -> (2,0) -> (3,0) -> (3,1)[+.] -> (3,2) -> (3,3)[+9] -> (2,3) -> (1,3)[+1] -> E. 총합 10.*

## 힌트

- 이 문제는 단순히 최단 경로가 아니라 '최대 가치'를 찾는 문제이므로 BFS/DFS에 상태(State) 관리가 필수적입니다.
- 상태에는 현재 위치 (r, c), 지금까지 수집한 아이템의 집합 또는 값, 그리고 이동 횟수 등이 포함되어야 합니다.


## 알고리즘 요약

BFS 기반 상태 탐색: 로봇의 상태를 (현재 행 r, 현재 열 c, 방문한 아이템들의 비트마스크/집합)으로 정의합니다. BFS를 사용하여 가능한 모든 유효한 상태를 탐색하며, 목표 지점('E')에 도달하는 순간의 총 아이템 가치를 기록하고 최댓값을 갱신합니다.

## 풀이 해설

풀이 해설:
1. 개념 파악 및 상태 정의: 이 문제는 단순히 BFS로 최단 거리를 찾는 것이 아니라, '최대 가치'를 얻으면서 도착해야 하므로, 상태 공간을 확장하여 탐색해야 합니다.
2. 자료구조 준비: 맵 크기 (N, M), 시작점(S)과 도착점(E)의 좌표를 찾고, 모든 아이템의 위치와 값을 매핑합니다.
3. BFS 구현 및 상태 전이: 일반적인 BFS Queue에 `(r, c, current_value, visited_mask)` 형태의 튜플을 넣습니다. 'visited_mask'는 어떤 아이템들을 이미 수집했는지 추적하는 비트마스크가 가장 효율적입니다.
4. 탐색 로직:
    a. 큐에서 상태를 꺼내 현재 위치에서 상하좌우로 이동 가능한 모든 인접 칸을 확인합니다.
    b. 다음 칸이 벽이거나 이미 지나온 경로라면 무시합니다.
    c. 만약 아이템 칸이라면, 해당 아이템의 값을 추가하고 `visited_mask`를 업데이트하여 새로운 상태를 큐에 넣습니다.
    d. 도착 지점('E')에 도달하면, 현재까지 쌓인 `current_value`를 전역 최댓값과 비교하여 갱신합니다.
5. 종료 조건: 큐가 빌 때까지 반복하며 모든 가능한 경로와 최대 가치를 탐색합니다. 시작 시 초기화된 최댓값을 반환합니다.

## 참고 코드 (python)

```python
from collections import deque
import sys

def solve():
    # 입력 받기 (N, M 및 맵 전체)
    try:
        input_lines = sys.stdin.read().split()
        if not input_lines: return -1 # 빈 입력 처리
        
        N, M = map(int, input_lines[0].split())
        grid = [list(line) for line in input_lines[1:]]
    except Exception:
        # 테스트 환경에서 직접 실행할 경우를 대비하여 예외 처리
        return -1 

    start_pos = None
    end_pos = None
    item_locations = {}
    all_items = []
    
    for r in range(N):
        for c in range(M):
            char = grid[r][c]
            if char == 'S':
                start_pos = (r, c)
            elif char == 'E':
                end_pos = (r, c)
            elif '1' <= char <= '9':
                value = int(char)
                item_locations[(r, c)] = value
                all_items.append((r, c))
    
    # 아이템 개수만큼 비트마스크를 사용하기 위해 인덱스 매핑 (총 K개 아이템이 있다고 가정)
    item_to_index = {pos: i for i, pos in enumerate(all_items)}
    num_items = len(all_items)

    # BFS 상태 정의: (r, c, mask, current_value)
    # mask: 수집한 아이템을 나타내는 비트마스크. (2^K 크기)
    # deque 초기화: 시작 위치에서 출발하며, 마스크는 0, 가치는 0
    queue = deque([(start_pos[0], start_pos[1], 0, 0)])
    
    # visited[r][c][mask] : 해당 상태 (위치 + 수집 아이템)를 이미 방문했는지 기록. 무한 루프 방지.
    visited = set([(start_pos[0], start_pos[1], 0)]) 
    
    max_value = -1
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

    while queue:
        r, c, mask, value = queue.popleft()
        
        # 도착 지점 체크: E에 도달했을 때의 가치를 갱신합니다.
        if r == end_pos[0] and c == end_pos[1]:
            max_value = max(max_value, value)

        for dr, dc in directions:
            nr, nc = r + dr, c + dc

            # 1. 범위 및 벽 체크
            if not (0 <= nr < N and 0 <= nc < M) or grid[nr][nc] == '#':
                continue
            
            next_mask = mask
            next_value = value
            
            is_item = False
            # 2. 아이템 처리 및 상태 업데이트
            if (nr, nc) in item_locations:
                item_index = item_to_index[(nr, nc)]
                # 해당 아이템이 아직 수집되지 않았다면 (mask의 해당 비트가 0이라면)
                if not (mask & (1 << item_index)):
                    next_mask |= (1 << item_index) # 마스크 업데이트
                    next_value += item_locations[(nr, nc)] # 가치 추가
                    is_item = True
            
            # 3. 방문 여부 체크: (위치 + 새 마스크)가 이미 방문했는지 확인
            if (nr, nc, next_mask) not in visited:
                visited.add((nr, nc, next_mask))
                queue.append((nr, nc, next_mask, next_value))
    
    return max_value

# 실제 제출 시 환경에 맞게 sys.stdin 사용하도록 처리합니다.

```

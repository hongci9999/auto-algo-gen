# 최소 비용으로 모든 지역 연결하기
*python · 그래프 · 보통 · MST, Union-Find, 그래프*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

N개의 지역이 있고, 이 지역들을 연결하는 간선들이 주어집니다. 각 간선은 두 지역을 연결하며, 연결하는 데 드는 비용이 있습니다. 목표는 모든 지역을 연결하는 최소 비용의 간선들을 선택하는 것입니다. 즉, 최소 신장 트리(Minimum Spanning Tree, MST)의 비용을 구해야 합니다.

지역의 번호는 1부터 N까지입니다.

## 입력

첫째 줄에 간선의 개수 M이 주어집니다. (1 <= M <= N*(N-1)/2)
다음 M줄에 걸쳐 간선의 정보가 주어집니다. 각 줄은 'u v w' 형식이며, u는 시작 지역, v는 끝 지역, w는 연결 비용을 나타냅니다. (1 <= u, v <= N, 1 <= w <= 100000)

## 출력

모든 지역을 연결하는 최소 비용의 총합을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10000, 1 <= M <= 50000, 1 <= w <= 100000. 시간 복잡도는 O(M log M) 또는 O(M * α(N)) 이내여야 합니다.

## 예제 1

**입력**
```
4
1 2 3
1 3 5
2 3 7
2 4 2
```

**출력**
```
5
```

*간선 (1, 2, 3)과 (2, 4, 2)를 선택하면 1-2-4가 연결되고, (1, 3, 5)를 추가하여 모든 지역이 연결됩니다. 최소 비용은 3 + 2 + 5 = 10이 아닙니다. (1, 2, 3), (2, 4, 2), (1, 3, 5) 중 최소 비용으로 연결하는 것은 (1, 2, 3), (2, 4, 2), (1, 3, 5)가 아닙니다. 지역 1, 2, 3, 4가 있으므로 3개의 간선이 필요합니다. 최소 비용은 (1, 2, 3), (2, 4, 2), (1, 3, 5) 중 최소 비용으로 연결하는 것입니다. 정답은 3+2+5=10이 아닙니다. (1, 2, 3), (2, 4, 2), (1, 3, 5) 중 최소 비용은 3+2+5=10입니다. (1, 2, 3), (2, 4, 2), (1, 3, 5)를 선택하면 총 비용은 10입니다. (정정: 간선 (1, 2, 3), (2, 4, 2), (1, 3, 5)가 아닌, (1, 2, 3), (2, 4, 2), (1, 3, 5)가 최소 비용입니다. 1-2-4, 1-3 연결. 3개의 간선 필요. (1, 2, 3), (2, 4, 2), (1, 3, 5)가 아닙니다. 최소 비용은 3+2+5=10입니다.*

## 예제 2

**입력**
```
3
1 2 10
1 3 5
2 3 1
```

**출력**
```
6
```

*세 지역이 있고, 간선 (1, 2, 10), (1, 3, 5), (2, 3, 1)이 있습니다. 모든 지역을 연결하는 최소 비용은 10, 5, 1 중 가장 작은 두 개를 선택하는 것이 아닙니다. 가장 작은 2개는 (2, 3, 1)과 (1, 3, 5)이며, 이들을 선택하면 모든 지역이 연결됩니다. 총 비용은 1 + 5 = 6입니다.*

## 예제 3

**입력**
```
5
1 2 1
1 3 1
2 3 1
2 4 1
3 4 1
```

**출력**
```
4
```

*5개의 지역이 아닌 4개의 지역(1, 2, 3, 4)이 있고, 4개의 지역을 연결하는 데 필요한 최소 간선은 3개입니다. 최소 비용은 1+1+1=3입니다. (오류 수정: 지역 1, 2, 3, 4가 존재하며, 간선이 5개입니다. 최소 비용은 3입니다.)*

## 힌트

- 크루스칼 알고리즘(Kruskal's Algorithm)을 사용해 보세요.
- 간선들을 비용(w)을 기준으로 오름차순 정렬하는 것이 핵심입니다.
- Union-Find(Disjoint Set Union, DSU) 자료구조를 사용하여 사이클 발생 여부와 연결 상태를 효율적으로 확인해야 합니다.


## 알고리즘 요약

최소 신장 트리(MST) 문제는 크루스칼 알고리즘을 이용하는 것이 가장 효율적입니다. 먼저 모든 간선들을 비용(w) 기준으로 오름차순 정렬합니다. 정렬된 간선들을 순서대로 탐색하면서, 현재 간선이 이미 연결된 두 지역(u, v) 사이에 사이클을 만들지 않는지 확인합니다. 사이클을 만들지 않는 간선이라면, 해당 간선을 MST에 포함시키고, 두 지역 u와 v를 같은 집합으로 합칩니다(Union-Find 사용). 모든 지역이 연결될 때까지 반복하며, 포함된 간선들의 비용을 모두 합산한 값이 정답입니다.

## 풀이 해설

### 💡 아이디어 (크루스칼 알고리즘)
이 문제는 최소 신장 트리(MST)를 찾는 전형적인 문제입니다. MST를 찾는 가장 대표적인 알고리즘 중 하나가 크루스칼 알고리즘입니다. 크루스칼 알고리즘의 핵심은 '가장 저렴한 간선부터 순서대로 선택하되, 이 간선이 이미 연결된 지역들을 다시 연결(사이클 형성)하지 않도록' 하는 것입니다.

### ⚙️ 단계별 풀이
1. **정렬**: 주어진 모든 간선들을 연결 비용(w)을 기준으로 오름차순으로 정렬합니다. 비용이 낮은 간선부터 처리해야 최소 비용을 보장할 수 있습니다.
2. **초기화 (Union-Find)**: 모든 지역(노드)을 독립된 집합으로 초기화합니다. Union-Find 자료구조를 사용하여 각 지역의 대표(parent)를 관리합니다. (N개의 지역이 있다면, N개의 집합이 존재합니다.)
3. **탐색 및 선택**: 정렬된 간선들을 순서대로 탐색합니다. 현재 간선 (u, v, w)에 대해 다음을 확인합니다:
    a. **사이클 검사 (Find)**: u와 v가 이미 같은 집합에 속해 있는지 확인합니다. 만약 `find(u) == find(v)`라면, 이 간선을 선택해도 새로운 연결이 생기지 않으므로 사이클이 발생합니다. 이 간선은 무시합니다.
    b. **MST 포함 (Union)**: 만약 `find(u) != find(v)`라면, 이 간선은 두 지역을 연결하는 필수 간선입니다. 따라서 이 간선을 MST에 포함시키고, 총 비용에 w를 더합니다. 그리고 두 지역 u와 v의 집합을 합칩니다 (`union(u, v)`). 
4. **종료**: 모든 간선을 탐색하거나, 또는 N-1개의 간선을 선택하여 모든 지역이 연결되었을 때(MST가 완성되었을 때) 종료합니다. 최종적으로 누적된 총 비용이 답입니다.

### ⏱️ 시간 복잡도
*   **정렬**: M개의 간선을 정렬하는 데 $O(M 	imes 	ext{log} M)$ 시간이 걸립니다.
*   **Union-Find 연산**: M번의 간선을 탐색하며, 각 간선에 대해 Find와 Union 연산을 수행합니다. 최적화된 Union-Find(경로 압축 및 랭크 기반 합치기)를 사용하면, 이 연산은 사실상 상수 시간 $O(	ext{α}(N))$에 가깝습니다.
*   **전체**: 따라서 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$에 지배됩니다. (M은 간선의 개수, N은 지역의 개수)

### 🚀 코드 구현 시 유의사항
*   지역 번호가 1부터 시작하는지, 0부터 시작하는지 확인하고 Union-Find 배열의 크기를 정확히 설정해야 합니다. (이 문제에서는 1부터 N입니다.)
*   Union-Find 함수(find, union)를 클래스 또는 함수로 구현하여 재사용성을 높이는 것이 좋습니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 Union-Find의 안정성을 확보합니다.
sys.setrecursionlimit(200000)

# Union-Find 자료구조 구현
class UnionFind:
    def __init__(self, n):
        # n은 지역의 최대 번호 (1부터 N까지)
        self.parent = list(range(n + 1))
        self.rank = [0] * (n + 1)
        self.count = n # 초기 연결된 지역의 개수

    def find(self, i):
        if self.parent[i] == i:
            return i
        # 경로 압축 (Path Compression)
        self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i, j):
        root_i = self.find(i)
        root_j = self.find(j)

        if root_i != root_j:
            # 랭크 기반 합치기 (Union by Rank)
            if self.rank[root_i] < self.rank[root_j]:
                self.parent[root_i] = root_j
            elif self.rank[root_i] > self.rank[root_j]:
                self.parent[root_j] = root_i
            else:
                self.parent[root_j] = root_i
                self.rank[root_i] += 1
            
            self.count -= 1 # 두 집합이 합쳐지므로 연결된 지역의 개수 감소
            return True # 성공적으로 합쳐짐
        return False # 이미 같은 집합에 속해 있음

def solve():
    # sys.stdin.readline을 사용하여 입력 처리
    input = sys.stdin.read().split()
    if not input: # 입력이 없을 경우 처리
        return

    M = int(input[0]) # 간선의 개수
    
    edges = []
    # input[1:]에는 M*3개의 값이 순서대로 들어있음 (u1, v1, w1, u2, v2, w2, ...)
    for i in range(M): 
        u = int(input[1] + str(i * 3))

        # 입력 배열의 인덱스를 조정하여 u, v, w를 가져옵니다. (i*3 + 1, i*3 + 2, i*3 + 3)
        u = int(input[1 + i * 3])
        v = int(input[1 + i * 3 + 1])
        w = int(input[1 + i * 3 + 2])
        edges.append((w, u, v))

    # 1. 비용(w) 기준으로 오름차순 정렬 (크루스칼의 핵심)
    edges.sort()

    # N은 지역의 최대 번호. 모든 지역 번호를 스캔하여 N을 찾습니다.
    # 문제 제약 조건에서 N이 명시되지 않았으므로, 모든 간선에 등장하는 최대 지역 번호를 N으로 가정합니다.
    max_node = 0
    for w, u, v in edges:
        max_node = max(max_node, u, v)
    N = max_node
    
    uf = UnionFind(N)
    mst_cost = 0
    edges_count = 0

    # 2. 정렬된 간선을 순회하며 MST 구성
    for w, u, v in edges:
        # 이미 같은 집합에 속해 있다면 (사이클 발생) 무시
        if uf.find(u) != uf.find(v):
            # MST에 포함
            uf.union(u, v)
            mst_cost += w
            edges_count += 1
            
            # 모든 지역(N)을 연결하는 간선은 N-1개이므로, N-1개를 찾으면 종료
            if edges_count == N - 1:
                break

    print(mst_cost)

# solve() # 주석 처리하여 JSON 출력에 방해되지 않도록 함
```

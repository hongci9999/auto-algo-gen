# 최소 비용으로 모든 노드 연결하기
*python · 그래프 · 보통 · MST, 크루스칼, Union-Find*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

여러 개의 도시가 지도 위에 위치해 있습니다. 각 도시 쌍 사이에는 도로를 건설할 수 있으며, 도로 건설 비용은 두 도시 간의 거리에 비례합니다. 지도를 완전히 연결하는 데 필요한 최소 비용을 구하는 문제입니다. 단, 모든 도로는 직선으로 건설 가능하며, 도시의 좌표는 정수점입니다.

만약 도시가 $N$개 있고, 도시 $i$와 도시 $j$의 좌표가 각각 $(x_i, y_i)$와 $(x_j, y_j)$라면, 두 도시를 잇는 도로의 비용(거리)은 유클리드 거리를 사용합니다: $\sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$입니다.

모든 도시를 연결하는 데 필요한 최소 비용을 구하세요.

## 입력

첫째 줄에 도시의 개수 $N$이 주어집니다. (1 ≤ N ≤ 100)
다음 $N$개의 줄에 걸쳐 각 도시의 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다. (좌표 범위: 0부터 1000까지의 정수)

## 출력

모든 도시를 연결하는 데 필요한 최소 비용(실수점, 소수점 3째 자리까지 반올림)을 한 줄에 출력합니다.

## 제약 조건

시간 복잡도: $O(E \log E)$ 또는 $O(E \ \alpha(N))$ (E는 간선 수)
메모리: $O(N^2)$

## 예제 1

**입력**
```
3
0 0
1 0
0 1
```

**출력**
```
1.414
```

*삼각형 모양의 세 점을 연결하는 최소 비용은 두 변의 합과 같습니다 (1 + $\sqrt{2}$).*

## 예제 2

**입력**
```
4
0 0
10 0
0 10
10 10
```

**출력**
```
20.000
```

*네 꼭짓점을 연결하는 최소 비용은 네 변의 합과 같습니다 (10 + 10).*

## 힌트

- 모든 노드를 연결하는 최소 비용은 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다.
- 간선의 가중치는 유클리드 거리를 사용합니다.
- 크루스칼 알고리즘이나 프림 알고리즘을 사용해 MST를 찾을 수 있습니다.


## 알고리즘 요약

최소 신장 트리 (MST) 알고리즘 (크루스칼 또는 프림)

## 풀이 해설

이 문제는 주어진 $N$개의 도시(노드)를 모두 연결하는 데 필요한 최소 비용을 구하는 문제입니다. 이는 전형적인 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다. 모든 도시 쌍 사이에 간선이 존재하며, 간선의 가중치는 두 도시 간의 유클리드 거리입니다.

**아이디어:** 크루스칼 알고리즘(Kruskal's Algorithm)을 사용하여 MST를 구하는 것이 가장 직관적입니다.

**단계:**
1. **모든 간선 생성 및 비용 계산:** $N$개의 도시가 있으므로, 가능한 모든 간선 쌍 $(i, j)$에 대해 비용을 계산합니다. 비용 $w_{ij} = \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$입니다. 총 간선의 수는 $E = N(N-1)/2$개입니다.
2. **간선 정렬:** 계산된 모든 간선들을 비용(가중치)을 기준으로 오름차순 정렬합니다.
3. **MST 구성 (크루스칼):** 정렬된 간선들을 순회하면서, 현재 간선 $(u, v)$를 추가했을 때 사이클이 형성되는지 확인합니다. 사이클이 형성되지 않는 경우에만 해당 간선을 MST에 포함시키고, 비용을 누적합니다. 사이클 여부는 Union-Find 자료구조를 이용해 효율적으로 확인할 수 있습니다.
4. **결과 반환:** $N-1$개의 간선을 선택하여 MST를 완성했을 때의 총 비용이 최소 비용입니다. 최종 결과는 소수점 3째 자리까지 반올림하여 출력합니다.

**시간 복잡도:** 간선 개수 $E = O(N^2)$입니다. 간선을 정렬하는 데 $O(E 	ext{ log } E)$가 걸리며, 크루스칼 알고리즘의 Union-Find 연산은 거의 상수 시간 $O(\alpha(N))$에 수렴하므로, 전체 시간 복잡도는 $O(N^2 	ext{ log } N^2) = O(N^2 	ext{ log } N)$이 됩니다. $N 	ext{이 최대 } 100$이므로 충분히 빠릅니다.

## 참고 코드 (python)

```python
import sys
import math

# 재귀 깊이 제한 증가 (Union-Find 사용 시 안전 장치)
# sys.setrecursionlimit(2000)

def solve():
    # 표준 입력을 빠르게 읽기 위해 설정
    input = sys.stdin.read
    data = input().split()
    
    if not data: return
    
    N = int(data[0])
    coordinates = []
    for i in range(N): 
        x = int(data[2*i + 1])
        y = int(data[2*i + 2])
        coordinates.append((x, y))

    # 1. 모든 간선 생성 및 비용 계산
    edges = []
    for i in range(N):
        for j in range(i + 1, N):
            x1, y1 = coordinates[i]
            x2, y2 = coordinates[j]
            # 유클리드 거리 계산
            distance = math.sqrt((x1 - x2)**2 + (y1 - y2)**2)
            # (비용, 노드1 인덱스, 노드2 인덱스) 형태로 저장
            edges.append((distance, i, j))

    # 2. 간선 정렬 (비용 오름차순)
    edges.sort()

    # Union-Find 자료구조 초기화
    parent = list(range(N))
    rank = [0] * N

    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i]) # 경로 압축
        return parent[i]

    def union(i, j):
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            # 랭크(rank)를 이용한 합치기 (Union by Rank)
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 합병 성공
        return False # 이미 연결되어 있음

    # 3. MST 구성 (크루스칼 알고리즘)
    min_cost = 0.0
    edges_count = 0
    
    for cost, u, v in edges:
        if union(u, v):
            min_cost += cost
            edges_count += 1
            
            # N-1개의 간선이 연결되면 종료
            if edges_count == N - 1:
                break
                
    # 4. 결과 출력 (소수점 3째 자리 반올림)
    print(f"{min_cost:.3f}")

solve()
```

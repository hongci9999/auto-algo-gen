# 최소 비용으로 경로 만들기
*python · 그래프 · 보통 · Dijkstra*

## 입출력 환경

Python의 sys.stdin.readline 또는 input() 함수를 사용하여 입력을 받는다.

## 문제

N개의 지점과 M개의 연결 도로가 주어진다. 각 도로는 두 지점을 연결하며, 그 길이(비용)는 일정하다.
너는 이 N개의 모든 지점을 반드시 거쳐야 하는 경로를 만들고자 한다. 단, 시작 지점과 끝 지점은 따로 지정되지 않으며, 총 비용을 최소화하는 순회 경로는 무엇인지 구해야 한다. (즉, 모든 지점을 포함하는 최소 비용의 트리 구조와 같다.)
다만, 이 문제에서는 트리를 구성할 때, 간선(도로)들을 연결하여 '경로'를 만드는 형태라고 가정하고 풀이한다.

## 입력

첫째 줄에 두 정수 N과 M (1 <= N <= 10^5, 0 <= M <= N-1)이 주어진다. N은 지점의 개수, M은 연결된 도로의 개수이다.
다음 M줄에는 각 간선(도로)의 정보가 'u v w' 형태로 주어지는데, u와 v는 연결되는 두 지점의 번호(1부터 N), w는 해당 도로의 비용을 나타낸다.

## 출력

최소 총 비용을 구하여 출력하시오.

## 제약 조건

N <= 10^5, M < N. 주어진 간선들은 항상 하나의 연결된 그래프를 형성한다.
시간 제한: 1초

## 예제 1

**입력**
```
4 3
1 2 10
2 3 5
3 4 10
```

**출력**
```
20
```

*주어진 세 간선(1-2, 2-3, 3-4)을 모두 포함하는 최소 비용 경로는 이 세 간선을 합친 비용의 총합이다.*

## 예제 2

**입력**
```
5 4
1 2 1
2 3 1
3 4 1
4 5 1
```

**출력**
```
4
```

*주어진 네 개의 간선(총 길이)을 모두 포함하는 최소 비용 경로는 1+1+1+1=4이다.*

## 힌트

- 문제의 핵심은 모든 지점을 연결하면서 비용이 가장 적게 드는 구조를 찾는 것이다.
- N개의 지점과 M개의 간선 정보가 주어졌으며, 특히 $M < N$이라는 제약 조건에 주목해야 한다.


## 알고리즘 요약

주어진 문제가 '모든 노드를 포함하는 최소 비용의 연결 구조'를 찾으라는 요구사항(MST 문제와 유사)을 가집니다. 그러나 이 문제는 주어진 간선들($M$)이 이미 모든 지점($N$)을 연결하는 데 필요한 충분한 정보를 담고 있다고 가정합니다 (실제로는 $M=N-1$이고 그래프가 트리인 경우를 전제로 합니다). 따라서, 주어지는 모든 간선의 비용을 단순히 합산하면 됩니다. 만약 주어진 간선들만으로는 모든 지점을 연결할 수 없다면 문제가 성립하지 않지만, 문제 조건과 예시를 종합해 볼 때, 이 문제는 주어진 모든 $M$개의 간선을 사용해야 하는 최소 경로의 총합을 구하는 것으로 해석됩니다 (즉, 신장 트리(Spanning Tree)가 아닌, 주어진 모든 간선의 비용 합계를 묻는 구조).

## 풀이 해설

풀이 아이디어: 본 문제는 '모든 지점을 반드시 거쳐야 하는' 최소 비용 경로를 요구합니다. 하지만 문제의 제약 조건과 예시를 분석하면, 주어진 $M$개의 도로(간선)들이 이미 필요한 모든 연결 정보를 가지고 있으며, 이 간선들을 모두 사용해야 총 비용이 결정된다는 것을 알 수 있습니다. 따라서 가장 간단하고 직관적인 해석은 '주어진 모든 M개 간선의 가중치를 단순히 합산'하는 것입니다.

단계:
1. 입력받은 $M$개의 각 간선 정보(u, v, w)를 순회합니다.
2. 각 간선의 가중치 $w$를 총합 변수에 누적하여 더해 나갑니다.
3. 최종적으로 계산된 총합이 최소 비용의 경로가 됩니다. (실제로는 이 조건 하에서는 모든 간선을 사용해야만 가능한 구조입니다.)

시간 복잡도: 시간 복잡도는 $O(M)$ 입니다. 주어진 간선의 개수 $M$만큼만 반복하면 되기 때문에 매우 효율적입니다.

## 참고 코드 (python)

```python
import sys
# 표준 입력에서 전체 라인을 읽어와 리스트로 처리합니다.
screen = sys.stdin.readlines()

if not screen:
    print(0)
else:
    # 첫 줄에서 N과 M을 가져옵니다.
    try:
        N, M = map(int, screen[0].split())
    except ValueError:
        # 입력 형식이 잘못된 경우를 대비
        print(0)
        sys.exit()

    total_cost = 0
    
    # 다음 M줄부터 간선 정보를 읽고 비용만 누적합니다.
    # screen 인덱스는 1부터 시작하며, 총 M개의 간선이 있습니다.
    for i in range(M): 
        if i + 1 < len(screen):
            try:
                # 각 줄에서 u, v, w를 분리하고, 세 번째 값인 비용 w만 가져옵니다.
                _, _, w = map(int, screen[i+1].split())
                total_cost += w
            except ValueError:
                # 해당 라인의 형식이 잘못된 경우 건너<0xEB><0x9C><0x81>니다.
                continue
    
    print(total_cost)
```

# 최소 비용 경로 찾기
*python · 그래프 · 보통 · BFS, Dijkstra, 최단경로*

## 입출력 환경

입력은 표준 입력(stdin)에서 받으며, Python의 sys.stdin.readline 등을 사용하여 처리하는 것을 권장합니다.

## 문제

당신은 격자 모양의 지도 위를 이동하는 로봇을 제어합니다. 지도는 N행 M열 크기의 그리드이며, 각 칸에는 이동 비용이 기록되어 있습니다.

로봇은 (1, 1) 위치에서 출발하여 목표 지점 (N, M)까지 도달해야 합니다. 상하좌우 네 방향으로만 이동할 수 있으며, 빈 공간을 통과하는 데는 추가 비용이 발생하지 않습니다. 다만, 칸에 표시된 값만큼의 비용을 그 칸에 진입할 때마다 지불해야 합니다.

최소 비용으로 (N, M)까지 도달하는 경로를 찾는 것이 목표입니다. 경로 상의 모든 칸에 기록된 비용을 합한 최소값을 반환하세요.

## 입력

첫째 줄에 N과 M이 공백으로 구분되어 주어집니다. 다음 N줄에는 각 행의 M개 열 값이 공백으로 구분되어 주어지며, 이 값들이 지도의 이동 비용입니다.

## 출력

최소 비용을 하나의 정수 값으로 출력합니다.

## 제약 조건

1 <= N, M <= 100
1 <= Cost[i][j] <= 1000

## 예제 1

**입력**
```
3 3
1 4 2
5 1 3
3 2 1
```

**출력**
```
10
```

*출발지(1,1)에서 도착지(3,3)까지의 최소 비용은 10입니다. 예시 경로: (1,1)->(1,2)->(2,2)->(3,2)->(3,3)*

## 예제 2

**입력**
```
2 4
1 1 1 5
1 1 1 1
```

**출력**
```
6
```

*직선 경로를 택할 경우 최소 비용은 6입니다. (1,1)->(2,1)->(2,2)->(2,3)->(2,4)*

## 힌트

- 최소 비용을 찾는 문제는 최단 경로 문제로 해석할 수 있습니다.
- 각 칸에 진입하는 순간의 비용이 존재하므로, 일반적인 BFS보다는 가중치를 고려해야 합니다.


## 알고리즘 요약

다익스트라(Dijkstra) 알고리즘 또는 플로이드-워셜 변형을 이용한 최소 비용 경로 탐색. 그리드 형태에서 시작하여 우선순위 큐를 사용하여 가장 적은 누적 비용을 가진 노드를 먼저 탐색합니다.

## 풀이 해설

풀이 아이디어:
이 문제는 가중치가 존재하는 그래프에서의 최단 경로 문제입니다. 격자 지도를 그래프로 간주하고, 각 칸 (i, j)는 하나의 노드가 됩니다.

다익스트라 알고리즘을 사용하면 시작 노드에서 다른 모든 노드까지의 최소 비용을 효율적으로 찾을 수 있습니다. 여기서 '비용'은 단순히 거리가 아니라, 경로 상에 진입하는 모든 칸의 값(가중치)을 합한 누적 값이 됩니다.

단계:
1. 초기화: 시작 지점 (0, 0)까지의 최소 비용 배열 `dist[N][M]`를 무한대로 설정하고, `dist[0][0]`을 해당 위치의 비용 값으로 설정합니다.
2. 우선순위 큐(Min-Heap) 사용: 우선순위 큐에 (비용, r, c) 형태의 튜플로 시작 지점의 정보를 삽입합니다. 여기서 '비용'은 현재까지 도달한 누적 최소 비용입니다.
3. 탐색 과정:
   - 큐에서 가장 작은 비용을 가진 노드 (d, r, c)를 추출합니다.
   - 만약 d가 이미 기록된 `dist[r][c]`보다 크다면 (이미 더 좋은 경로가 발견되었다면) 건너<0xEB><0x9C><0x81>니다.
   - 상하좌우 네 방향의 인접 칸 (nr, nc)을 확인합니다.
   - (nr, nc)이 유효한 범위 내에 있고, 현재 노드에서 이웃 노드로 이동하는 비용 계산:
     새로운 총 비용 = d + Cost[nr][nc]
   - 만약 새로운 총 비용이 `dist[nr][nc]`보다 작다면: 
     `dist[nr][nc]`를 업데이트하고, (새로운 총 비용, nr, nc)를 우선순위 큐에 삽입합니다.
3. 결과 반환:
탐색이 완료되면, 목표 지점의 최소 비용인 `dist[N-1][M-1]`을 반환합니다. 다익스트라 알고리즘은 시작 노드에서 목적지까지의 최단 경로를 보장합니다.

시간 복잡도: O(E log V) 또는 O(V log V). 여기서 V는 정점의 수 (N*M), E는 간선의 수 (최대 4*N*M)입니다. 따라서 N과 M이 최대 100일 때, 시간 복잡도는 대략 $O(N 	imes M 	imes 	ext{log}(N 	imes M))$가 됩니다.

## 참고 코드 (python)

```python
import heapq
import sys
# 입력 속도 최적화
screen = sys.stdin.read().split()
if not screen: # 빈 입력 처리
    print(0)
else:
    N = int(screen[0])
    M = int(screen[1])
    
    # 지도를 2차원 배열로 구성
    grid = []
    for i in range(N): 
        row = [int(x) for x in screen[2 + i]]
        grid.append(row)

    # 다익스트라 알고리즘을 위한 초기화
    # dist[r][c]는 (0, 0)에서 (r, c)까지의 최소 누적 비용을 저장
    INF = float('inf')
    dist = [[INF] * M for _ in range(N)]

    # 시작점 (0, 0):
    # 초기 비용은 해당 칸에 진입하는 비용 자체입니다.
    start_cost = grid[0][0]
    dist[0][0] = start_cost
    
    # 우선순위 큐: (비용, r, c)
    pq = [(start_cost, 0, 0)]

    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)] # 상하좌우

    while pq:
        d, r, c = heapq.heappop(pq)
        
        # 이미 더 작은 비용으로 도달한 경로가 있다면 무시
        if d > dist[r][c]:
            continue

        # 인접 노드 탐색
        for dr, dc in directions:
            nr = r + dr
            nc = c + dc
            
            # 범위 체크
            if 0 <= nr < N and 0 <= nc < M:
                # 새 경로의 총 비용: 현재 누적 비용 (d) + 다음 칸 진입 비용 (grid[nr][nc])
                new_cost = d + grid[nr][nc]
                
                # 최소 비용 업데이트 확인
                if new_cost < dist[nr][nc]:
                    dist[nr][nc] = new_cost
                    heapq.heappush(pq, (new_cost, nr, nc))

    # 최종 목표 지점의 최소 비용 반환
    print(dist[N - 1][M - 1])
```

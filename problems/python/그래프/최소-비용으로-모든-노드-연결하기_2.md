# 최소 비용으로 모든 노드 연결하기
*python · 그래프 · 보통 · MST, 프림, 크루스칼*

## 입출력 환경

입력은 표준 입력에서 받으며, 모든 좌표는 정수입니다. 출력은 실수형입니다.

## 문제

N개의 도시가 있습니다. 각 도시는 좌표 평면 위에 위치하며, 두 도시 사이를 연결하는 데 필요한 비용은 두 도시 간의 유클리드 거리입니다.

당신은 모든 도시를 연결하는 최소 비용의 네트워크를 구축해야 합니다. 즉, 모든 도시가 최소한 하나의 경로를 통해 연결되도록 하는 연결망의 총 비용을 구하세요. 이 연결망은 최소 신장 트리(Minimum Spanning Tree, MST)를 구성합니다.

## 입력

첫째 줄에 도시의 개수 N이 주어집니다. (1 <= N <= 100)
다음 N줄에 걸쳐 각 도시의 (x, y) 좌표가 순서대로 주어집니다. (좌표는 정수입니다.)

## 출력

모든 도시를 연결하는 최소 비용의 총합(실수점)을 소수점 이하 2자리까지 출력하세요.

## 제약 조건

N: 1 <= N <= 100. 시간 복잡도: O(E log E) 또는 O(E log V) 수준을 목표로 합니다. (E는 간선의 수)

## 예제 1

**입력**
```
3
0 0
1 0
2 0
```

**출력**
```
2.00
```

*A(0,0), B(1,0), C(2,0) 세 점. 간선 비용: AB=1, BC=1, AC=2. MST는 AB와 BC를 연결하여 총 비용 2.0입니다.*

## 예제 2

**입력**
```
4
0 0
10 0
0 10
10 10
```

**출력**
```
20.00
```

*네 꼭짓점을 이룰 때, 최소 비용으로 연결하는 경로는 10+10=20입니다. (예: (0,0)-(10,0)과 (0,10)-(10,10)을 연결한 후, (0,0)-(0,10) 연결)*

## 힌트

- 모든 노드를 연결하는 최소 비용의 구조는 최소 신장 트리(MST)입니다.
- 간선 가중치는 유클리드 거리 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$로 계산합니다.


## 알고리즘 요약

이 문제는 최소 신장 트리(MST)를 구하는 전형적인 문제입니다. 도시의 개수 N이 최대 100으로 작기 때문에, 모든 도시 쌍 간의 거리를 간선으로 간주하여 그래프를 구성할 수 있습니다. 간선 가중치는 유클리드 거리가 됩니다. 크루스칼 알고리즘이나 프림 알고리즘을 사용하여 MST를 구하면 됩니다. 크루스칼 알고리즘을 사용하면 모든 간선(N*(N-1)/2개)을 정렬한 후, Union-Find 구조를 이용해 사이클이 생기지 않도록 간선을 선택합니다.

## 풀이 해설

1. **문제 이해 및 모델링**: 이 문제는 N개의 노드와 모든 쌍을 연결하는 간선들로 이루어진 완전 그래프에서, 모든 노드를 연결하는 최소 비용의 부분 그래프(MST)를 찾는 문제입니다. 간선 가중치는 유클리드 거리입니다.
2. **간선 생성**: 모든 도시 쌍 $(i, j)$에 대해 간선 $(i, j)$를 만들고, 그 가중치 $w_{i,j}$를 $\sqrt{(x_i-x_j)^2 + (y_i-y_j)^2}$로 계산합니다. 간선의 개수는 $E = N(N-1)/2$입니다.
3. **알고리즘 선택 (크루스칼)**: 간선이 $E$개이고 노드가 $N$개일 때, 간선을 정렬하고 Union-Find를 사용하는 크루스칼 알고리즘이 효율적입니다.
    a. 모든 간선 리스트를 생성하고, 가중치(거리)를 기준으로 오름차순 정렬합니다.
    b. Union-Find 구조를 초기화합니다 (각 노드가 자신의 집합의 대표). 
    c. 정렬된 간선을 순회하며, 간선 $(u, v)$를 고려합니다.
    d. 만약 $u$와 $v$가 아직 같은 집합에 속해 있지 않다면 (즉, `find(u) != find(v)`), 이 간선을 MST에 포함시키고, 두 노드를 같은 집합으로 합칩니다 (`union(u, v)`). 동시에 총 비용에 이 간선 가중치를 더합니다.
4. **종료**: MST에 간선 $N-1$개를 추가하거나, 모든 간선을 확인하여 더 이상 연결할 수 없을 때까지 반복합니다. 최종적으로 누적된 총 비용이 답입니다.
5. **시간 복잡도**: 간선 생성에 $O(N^2)$이 걸리며, 간선 정렬에 $O(E 	ext{ log } E)$이 걸립니다. $E = O(N^2)$이므로, 전체 시간 복잡도는 $O(N^2 	ext{ log } N^2) = O(N^2 	ext{ log } N)$입니다. N이 100이므로 충분히 빠릅니다.

## 참고 코드 (python)

```python
import math

def solve():
    # 표준 입력을 받기 위해 전체 입력을 한 번에 읽습니다.
    import sys
    input_data = sys.stdin.read().split() 
    
    if not input_data: 
        return

    N = int(input_data[0])
    coords = []
    
    # 좌표를 저장합니다. N개의 (x, y) 튜플 리스트
    for i in range(N): 
        x = int(input_data[1 + i * 2])
        y = int(input_data[2 + i * 2])
        coords.append((x, y))

    # 1. 모든 간선 생성 (가중치, u, v) 형태의 리스트
    edges = []
    for i in range(N):
        for j in range(i + 1, N):
            # 유클리드 거리 계산
            dx = coords[i][0] - coords[j][0]
            dy = coords[i][1] - coords[j][1]
            weight = math.sqrt(dx*dx + dy*dy)
            edges.append((weight, i, j))

    # 2. 크루스칼 알고리즘 준비: 간선을 가중치 기준으로 정렬
    edges.sort()

    # Union-Find 구조 구현
    parent = list(range(N)) # parent[i]는 i의 부모
    rank = [0] * N

    def find(i): # 경로 압축을 사용한 find 연산
        if parent[i] == i:
            return i
        parent[i] = find(parent[i]) # 경로 압축
        return parent[i]

    def union(i, j): # 두 집합을 합치는 union 연산
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            # 랭크를 이용한 합치기 (Union by Rank)
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 성공적으로 합쳐짐
        return False # 이미 같은 집합에 속함

    # 3. MST 구성 및 비용 계산
    mst_cost = 0.0
    edges_count = 0
    
    for weight, u, v in edges:
        if union(u, v):
            mst_cost += weight
            edges_count += 1
            
            # N-1개의 간선을 찾으면 종료
            if edges_count == N - 1:
                break

    # 결과 출력 (소수점 2자리까지)
    print(f"{mst_cost:.2f}")

solve()
```

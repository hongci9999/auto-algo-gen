# 최소 비용으로 모든 전구 켜기
*python · 그래프 · 보통 · 최단경로, BFS, 가중치*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

N개의 방이 일렬로 배치되어 있으며, 각 방에는 전구가 달려 있습니다. 이 전구들은 서로 연결되어 있어, 방과 방 사이를 이동할 수 있습니다. 각 방의 전구는 특정 비용으로 켜거나 끌 수 있습니다. 또한, 인접한 방의 전구들을 함께 켜거나 끌 때도 비용이 발생합니다.

당신은 시작 방(1번 방)에서 출발하여, 모든 방의 전구를 켜는 것을 목표로 합니다. 전구를 켜는 과정은 방과 방 사이를 이동하며, 현재 방의 전구 상태를 변경하는 방식으로 진행됩니다.

방 $i$의 전구 상태를 변경하는 비용은 $C_i$입니다. 인접한 방 $i$와 $j$의 전구 상태를 동시에 변경하는 비용은 $D_{i,j}$입니다. 이동은 인접한 방으로만 가능합니다.

이동을 통해 모든 방의 전구를 켜는 최소 비용을 구하시오.

## 입력

첫째 줄에 N (방의 개수)이 주어집니다. 
둘째 줄에 N개의 정수 $C_1, C_2, 
... C_N$이 주어집니다. (각 방의 전구 개별 변경 비용)
셋째 줄에 N-1개의 정수 $D_{1,2}, D_{2,3}, 
... D_{N-1,N}$이 주어집니다. (인접한 방 쌍의 동시 변경 비용)

## 출력

모든 전구를 켜는 최소 비용을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10; 1 <= C_i, D_{i,j} <= 1000; 시간 복잡도는 충분함.

## 예제 1

**입력**
```
3
10 10 10
1 1
```

**출력**
```
2
```

*1번 방에서 3번 방까지 이동하며, 1-2와 2-3의 동시 변경 비용(1+1)을 사용하면 최소 비용 2로 모든 전구를 켤 수 있습니다.*

## 예제 2

**입력**
```
4
5 1 5 1
2 3 2
```

**출력**
```
4
```

*1번 방에서 4번 방까지 이동하며, 1-2의 동시 변경 비용(2)과 3-4의 동시 변경 비용(2)을 사용하면 최소 비용 4가 됩니다.*

## 힌트

- 모든 방의 전구 상태를 '켜짐'으로 만드는 것은 최소 비용 경로 찾기 문제로 모델링할 수 있습니다.
- 방의 전구 상태를 '켜짐'으로 만드는 것은 일종의 '상태'를 나타내며, 이 상태 공간을 탐색해야 합니다.


## 알고리즘 요약

최소 비용 경로 탐색 (Dijkstra 또는 BFS 변형)

## 풀이 해설

### 아이디어
이 문제는 모든 방의 전구를 켜는 최소 비용을 찾는 문제입니다. 방의 전구 상태는 켜짐/꺼짐으로 표현할 수 있으며, N개의 방이 있으므로 총 $2^N$가지의 상태 공간이 존재합니다. 우리는 시작 상태(모두 꺼짐)에서 목표 상태(모두 켜짐)에 도달하는 최소 비용 경로를 찾아야 합니다. 이는 전형적인 최단 경로 문제(Shortest Path Problem)이며, 상태 공간 그래프를 이용한 Dijkstra 알고리즘이나 BFS(가중치 고려)로 해결할 수 있습니다.

### 상태 정의
상태(State)는 $N$개의 방의 전구 상태를 나타내는 비트마스크(Bitmask)로 정의합니다. $0$부터 $2^N - 1$까지의 정수 $S$가 하나의 상태가 됩니다. 예를 들어, $N=3$일 때, $S=7$ (111)은 모든 전구가 켜진 상태를 의미합니다.

### 전이(Transition) 및 비용
현재 상태 $S$에서 다음 상태 $S'$로 전이하는 방법은 다음과 같습니다:
1. **개별 변경 (비용 $C_i$)**: $i$번째 전구만 변경하는 경우. $S$의 $i$번째 비트를 반전시킵니다. 비용은 $C_i$입니다.
2. **인접 쌍 변경 (비용 $D_{i,j}$)**: 인접한 $i, j$의 전구 상태를 동시에 변경하는 경우. $S$의 $i$번째 비트와 $j$번째 비트를 동시에 반전시킵니다. 비용은 $D_{i,j}$입니다.

이동 제약 조건이 있지만, 문제의 핵심은 '최소 비용으로 모든 전구를 켜는 것'이며, 이동은 단지 전구 상태를 변경할 수 있는 '행위'의 제약 조건으로 해석됩니다. 모든 방의 전구 상태 변경은 결국 전역적인 상태 변화를 의미하므로, 상태 $S$에서 $S'$로 가는 최소 비용을 계산하는 것이 목표입니다. (주어진 문제 설정상, 이동 제약은 상태 변화의 종류를 제한하는 것이 아니라, 모든 상태 변화가 가능한 '행위'로 해석하여 Dijkstra를 적용합니다.)

### 단계
1. **초기화**: 거리를 저장할 배열 `dist`를 $2^N$ 크기로 초기화하고, `dist[0] = 0` (모두 꺼짐 상태의 비용은 0)으로 설정합니다. 나머지 값은 무한대로 설정합니다.
2. **Dijkstra 실행**: 우선순위 큐(Priority Queue)에 `(비용, 상태)` 쌍을 넣고, 거리가 가장 짧은 상태부터 탐색합니다.
3. **탐색**: 현재 상태 $S$와 비용 $d$를 꺼냅니다. $S$에서 도달할 수 있는 모든 다음 상태 $S'$를 찾고, 새로운 비용 $d' = d + 	ext{transition_cost}(S, S')$를 계산합니다. 만약 $d' < 	ext{dist}[S']$ 이면, $	ext{dist}[S'] = d'$로 업데이트하고 $(d', S')$를 우선순위 큐에 삽입합니다.
4. **결과**: 목표 상태는 $2^N - 1$ (모두 켜짐)입니다. $	ext{dist}[2^N - 1]$이 최소 비용입니다.

### 시간 복잡도
상태 공간의 크기는 $V = 2^N$입니다. 간선의 개수는 $E$이며, 각 상태에서 $N$개의 개별 변경과 $N-1$개의 인접 쌍 변경이 가능하므로 $E = O(N 	imes 2^N)$입니다. Dijkstra 알고리즘의 시간 복잡도는 $O(E 	imes 	ext{log} V)$ 또는 $O(E + V 	ext{log} V)$입니다. $N 	imes 2^N$이 주된 항이 되므로, $N$이 최대 10일 때 $2^{10} 	imes 10$ 정도의 연산으로 매우 빠르게 해결됩니다. (N이 작기 때문에 DP나 BFS/Dijkstra가 적합합니다.)

## 참고 코드 (python)

```python
import heapq
import sys

# 재귀 깊이 제한 해제 (필요할 경우)
# sys.setrecursionlimit(2000)

def solve():
    # 표준 입력에서 N 읽기
    try:
        N = int(sys.stdin.readline())
    except:
        # 입력이 없을 경우 종료
        return

    # C_i (개별 변경 비용) 읽기
    C = list(map(int, sys.stdin.readline().split()))
    
    # D_i,j (인접 쌍 변경 비용) 읽기
    # N-1개의 비용이 주어지며, D[i]는 i와 i+1 사이의 비용
    D_list = list(map(int, sys.stdin.readline().split()))

    # 상태 공간의 크기: 2^N
    MAX_STATE = 1 << N
    
    # 거리를 저장할 배열 (최소 비용)
    # 초기값은 무한대
    INF = float('inf')
    dist = [INF] * MAX_STATE
    
    # 시작 상태: 0 (모두 꺼짐)
    start_state = 0
    dist[start_state] = 0
    
    # 우선순위 큐: (비용, 상태)
    pq = [(0, start_state)]

    # 목표 상태: 2^N - 1 (모두 켜짐)
    target_state = MAX_STATE - 1

    while pq: 
        d, u = heapq.heappop(pq)
        
        # 이미 더 짧은 경로가 발견되었다면 건너뜀
        if d > dist[u]:
            continue
            
        # 1. 개별 변경 (i번째 전구만 변경)
        for i in range(N):
            # i번째 전구의 상태를 반전시킨 새로운 상태 v
            v = u ^ (1 << i)
            cost = C[i]
            new_dist = d + cost
            
            if new_dist < dist[v]:
                dist[v] = new_dist
                heapq.heappush(pq, (new_dist, v))
                
        # 2. 인접 쌍 변경 (i와 i+1 전구 동시 변경)
        for i in range(N - 1):
            # i번째와 i+1번째 전구의 상태를 동시에 반전시킨 새로운 상태 v
            # 비트마스크: (1 << i) | (1 << (i+1))
            mask = (1 << i) | (1 << (i+1))
            v = u ^ mask
            cost = D_list[i]
            new_dist = d + cost
            
            if new_dist < dist[v]:
                dist[v] = new_dist
                heapq.heappush(pq, (new_dist, v))

    # 최종 결과 출력: 목표 상태의 최소 비용
    print(dist[target_state])

if __name__ == '__main__':
    solve()
```

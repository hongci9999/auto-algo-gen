# 점프 이동의 최소 연료 비용
*python · 그래프 · 보통 · 다익스트라, 최단 경로, 그리디*

## 입출력 환경

입력은 표준 입력 (sys.stdin)으로부터 받아야 하며, 여러 줄에 걸쳐 데이터를 받으므로 적절한 파싱이 필요합니다.

## 문제

당신은 길이 $N$개의 체크포인트로 이루어진 배열 $A$ 위를 이동하는 로봇을 제어합니다. 각 체크포인트 $i$는 고유한 '에너지 레벨'인 값 $A[i]$를 가지고 있습니다.

로봇이 시작 지점 $start$에서 목표 지점 $end$까지 도달하기 위해 필요한 최소 연료 비용을 계산해야 합니다. 로봇은 배열의 어떤 인덱스 $i$에서 다른 인덱스 $j$로 점프할 수 있으며, 이 점프에 드는 연료 비용(Edge Weight)은 두 지점의 에너지 레벨 차이의 절대값 $|A[j] - A[i]|$입니다.

최소 비용을 구하는 과정에서 반드시 최단 경로 알고리즘을 사용해야 하며, 만약 $start$에서 $end$로 도달할 수 없다면 -1을 반환해야 합니다.

## 입력

첫 번째 줄에는 정수 N (배열의 길이)이 주어집니다.
두 번째 줄에는 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.
세 번째 줄에는 시작 인덱스 start와 끝 인덱스 end가 공백으로 구분되어 주어집니다.

## 출력

최소 연료 비용을 한 개의 정수 형태로 출력합니다. 도달 불가능할 경우 -1을 출력합니다.

## 제약 조건

N의 범위는 2부터 500까지입니다. 배열 A의 각 요소 값은 -10^9에서 10^9 사이의 정수일 수 있습니다. 시간 복잡도는 O(E log V) 또는 이와 유사한 수준을 목표로 합니다.

## 예제 1

**입력**
```
3
10 20 30
0 2
```

**출력**
```
20
```

*0 -> 1 (비용: |20-10|=10), 1 -> 2 (비용: |30-20|=10). 총 비용: 20.*

## 예제 2

**입력**
```
4
5 1 8 3
0 3
```

**출력**
```
7
```

*최적 경로는 0 -> 1 (비용: |1-5|=4), 1 -> 3 (비용: |3-1|=2). 총 비용: 6. (오류 수정: 0->1(4) + 1->3(2) = 6)*

## 예제 3

**입력**
```
3
5 1 8
0 2
```

**출력**
```
7
```

*최적 경로는 0 -> 1 (비용: |1-5|=4), 1 -> 2 (비용: |8-1|=7). 총 비용은 11. 혹은 0에서 2로 바로 이동하는 것이 더 최단 경로일 수 있습니다.*

## 힌트

- 문제는 '최소 비용'을 구하므로, 그래프 탐색 중 최소 비용을 찾는 알고리즘(다익스트라)이 적합합니다.
- 배열의 모든 인덱스는 노드(Node)가 되고, 모든 쌍의 점프는 간선(Edge)이 됩니다. 가중치는 $|A[j] - A[i]|$입니다.


## 알고리즘 요약

다익스트라 알고리즘 (Dijkstra's Algorithm). 이 문제는 배열의 인덱스들을 노드로, 두 인덱스 사이의 점프를 간선으로 가중치를 부여한 완전 그래프에서 시작점부터 끝점까지의 최단 경로(Minimum Cost Path)를 찾는 문제와 같습니다. 최소 힙(Priority Queue)을 사용하여 아직 방문하지 않은 노드 중 가장 비용이 적게 드는 노드를 반복적으로 탐색하며 거리를 업데이트합니다.

## 풀이 해설

1. 아이디어: 이 문제는 시작점부터 끝점까지의 최단 경로를 찾는 전형적인 최소 비용 그래프 문제입니다. 간선 가중치가 모두 0 이상이므로, 다익스트라 알고리즘을 적용합니다.
2. 단계:
   a. 초기화: 모든 노드의 거리를 무한대(Infinity)로 설정하고, 시작 노드 $start$의 거리는 0으로 설정합니다.
   b. 우선순위 큐 (Min-Heap): `(비용, 인덱스)` 형태로 힙에 `(0, start)`를 삽입합니다. 힙은 현재까지 발견된 최소 비용을 가진 경로를 항상 맨 앞에 꺼낼 수 있게 합니다.
   c. 탐색 과정: 힙이 비거나 목표 지점 $end$의 거리가 확정될 때까지 반복합니다.
      i. 최저 비용 노드 추출: 힙에서 가장 비용이 작은 `(cost, u)`를 꺼냅니다. 만약 이 `cost`가 이미 기록된 $u$까지의 최소 거리보다 크다면 (이미 더 좋은 경로를 찾았다면) 무시하고 넘어갑니다.
      ii. 목표 도달 확인: 만약 추출된 노드 $u$가 $end$라면, 이것이 최단 거리가 됩니다.
      iii. 이웃 탐색: 현재 노드 $u$에서 배열의 모든 다른 인덱스 $v$ (즉, $0$부터 $N-1$까지)로 점프할 수 있습니다. 점프 비용은 $|A[v] - A[u]|$입니다.
      iv. 거리 갱신: 새로운 총 비용 $	ext{new_cost} = 	ext{cost} + |A[v] - A[u]|$를 계산합니다. 만약 이 $	ext{new_cost}$가 현재 기록된 $v$까지의 최소 거리보다 작다면, 거리를 업데이트하고 `(new_cost, v)`를 힙에 삽입합니다.
3. 시간 복잡도: 노드의 개수 $V = N$, 간선의 개수 $E = N(N-1)$ (거의 $O(N^2)$). 다익스트라 알고리즘의 시간 복잡도는 일반적으로 $O(E + V 	ext{ log } V)$입니다. 최악의 경우 $E$가 크기 때문에, 이 문제에서는 전체적으로 $O(N^2 	ext{ log } N)$ 또는 구현 방식에 따라 $O(N^2)$에 가까운 시간 복잡도를 가집니다. (Python `heapq` 사용 시 $O(E 	ext{ log } V) = O(N^2 	ext{ log } N)$입니다.)

## 참고 코드 (python)

```python
import heapq
import sys
from collections import defaultdict

def solve():
    # 빠른 입력을 위해 sys.stdin.read() 사용
    input_data = sys.stdin.read().split()
    if not input_data: return -1

    N = int(input_data[0])
    A = [int(x) for x in input_data[1:N+1]]
    start = int(input_data[N+1])
    end = int(input_data[N+2])

    # 1. 거리 초기화 (dist[i]는 i까지의 최소 비용)
    infinity = float('inf')
    min_cost = [infinity] * N
    min_cost[start] = 0

    # 우선순위 큐: (비용, 인덱스)
    pq = [(0, start)]

    while pq:
        current_cost, u = heapq.heappop(pq)

        # 이미 더 낮은 비용으로 도착한 경우 스킵 (핵심 최적화)
        if current_cost > min_cost[u]:
            continue

        # 목표 지점에 도달하면 바로 반환 가능 (최소 비용이므로)
        if u == end:
            return current_cost

        # 2. 모든 인덱스 v에 대해 점프 시도 (모든 간선 탐색)
        for v in range(N):
            if u == v: 
                continue
            
            # 점프 비용 계산: |A[v] - A[u]|
            edge_weight = abs(A[v] - A[u])
            new_cost = current_cost + edge_weight

            # 3. 거리 갱신 및 힙에 삽입
            if new_cost < min_cost[v]:
                min_cost[v] = new_cost
                heapq.heappush(pq, (new_cost, v))

    # 목표 지점에 도달하지 못한 경우
    return min_cost[end]

if __name__ == "__main__"]
    result = solve()
    print(result)
```

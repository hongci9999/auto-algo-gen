# 최소 비용으로 연결되는 간선
*python · 그래프 · 보통 · MST, Union-Find, 크루스칼*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받습니다. 첫 줄에 N과 M이 있고, 다음 M줄에 각각 간선 정보 (u, v, cost)가 공백으로 구분되어 주어집니다.

## 문제

여러 개의 도시와 그 사이를 연결하는 도로가 주어집니다. 각 도로는 연결되는 두 도시와 그 도로를 건설하는 데 필요한 비용을 가집니다. 여러분은 모든 도시를 최소 비용으로 연결하는 도로망을 구축해야 합니다. 즉, 모든 도시가 서로 통신할 수 있도록 하면서도, 총 건설 비용이 가장 적게 드는 도로망을 찾아야 합니다. 이 때, 도로망을 구성하는 간선들의 총 비용을 출력하세요. 간선들은 중복되거나 순환 구조를 만들 필요는 없습니다.

## 입력

첫째 줄에 도시의 개수 N과 간선의 개수 M이 주어집니다. (1 <= N <= 1000, 1 <= M <= 1000)

## 출력

모든 도시를 연결하는 최소 비용의 총합을 하나의 정수로 출력합니다.

## 제약 조건

N, M의 범위: 1 <= N <= 1000, 1 <= M <= 1000. 간선의 비용은 1 이상 10000 이하의 정수입니다. 시간 복잡도는 O(M log M) 또는 O(M α(N)) 정도가 적절합니다.

## 예제 1

**입력**
```
4 5
1 2 10
1 3 1
2 3 2
2 4 5
3 4 3
```

**출력**
```
11
```

*간선 (1, 3, 1), (2, 3, 2), (3, 4, 3), (1, 2, 10) 중 비용이 낮은 4개의 간선을 선택합니다. 최소 비용은 1 + 2 + 3 + 10 = 16이 아니라, MST를 구성하는 간선들을 선택해야 합니다. (1, 3, 1), (2, 3, 2), (3, 4, 3), (1, 2, 10) 대신, (1, 3, 1), (2, 3, 2), (3, 4, 3)을 선택하면 3개의 도시만 연결됩니다. 모든 도시를 연결하려면 최소 3개의 간선이 필요합니다. 정답은 1 + 2 + 3 + 5 = 11 입니다.*

## 예제 2

**입력**
```
3 2
1 2 5
1 3 1
```

**출력**
```
6
```

*도시 3개와 간선 2개만 주어졌습니다. 모든 도시를 연결할 수 없습니다. 이 경우, 연결된 모든 컴포넌트의 비용 합을 구하는 것이 아니라, 모든 도시가 연결될 수 있도록 하는 최소 비용을 구하는 문제입니다. 간선 (1, 3, 1)과 (1, 2, 5)를 선택하여 총 비용 6을 얻습니다.*

## 예제 3

**입력**
```
5 4
1 2 1
2 3 1
3 4 1
4 5 1
```

**출력**
```
4
```

*모든 도시가 일렬로 연결되어 있으며, 모든 간선을 사용해야 하므로 비용은 1+1+1+1 = 4입니다.*

## 힌트

- 1. 모든 도시를 연결하는 최소 비용의 도로망을 찾는 문제는 최소 신장 트리(MST) 문제입니다.
- 2. 크루스칼 알고리즘을 사용하면 간선들을 비용 순으로 정렬한 후, 사이클을 만들지 않는 간선들을 하나씩 선택하여 MST를 구성할 수 있습니다.


## 알고리즘 요약

크루스칼 알고리즘 (Kruskal's Algorithm)을 사용합니다. 모든 간선들을 비용(가중치)을 기준으로 오름차순 정렬합니다. 이후, Union-Find 자료구조를 사용하여 간선 (u, v)를 선택할 때, u와 v가 이미 같은 집합(같은 컴포넌트)에 속해 있는지 확인합니다. 만약 다르다면, 이 간선을 선택하고 두 집합을 Union 연산으로 합칩니다. 이 과정을 모든 간선을 탐색할 때까지 반복하며, 선택된 간선들의 비용을 누적합니다. 최종 누적 비용이 최소 비용입니다.

## 풀이 해설

풀이 해설: 이 문제는 전형적인 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다. MST는 주어진 그래프의 모든 정점(도시)을 연결하면서 간선(도로)의 총 가중치(비용)의 합이 최소가 되는 트리를 의미합니다.

**아이디어:** 크루스칼 알고리즘(Kruskal's Algorithm)을 사용합니다. 크루스칼 알고리즘은 모든 간선을 비용이 낮은 순서대로 정렬한 후, 사이클을 만들지 않는 간선들을 차례로 선택해 나가는 방식으로 MST를 구축합니다.

**단계:**
1. **정렬:** 주어진 M개의 모든 간선들을 비용(cost)을 기준으로 오름차순 정렬합니다.
2. **Union-Find 초기화:** N개의 도시 각각에 대해 Union-Find 자료구조를 초기화합니다. 각 도시는 처음에는 독립적인 집합(컴포넌트)을 이룹니다.
3. **간선 탐색 및 선택:** 정렬된 간선들을 처음부터 끝까지 순회합니다.
    a. 현재 간선 (u, v, cost)를 가져옵니다.
    b. Union-Find의 `find(u)`와 `find(v)`를 통해 u와 v가 현재 같은 집합에 속하는지 확인합니다. (즉, 이미 연결되어 있는지 확인)
    c. 만약 `find(u)`와 `find(v)`의 결과가 다르면 (서로 다른 컴포넌트에 속한다면), 이 간선은 사이클을 만들지 않습니다. 따라서 이 간선을 선택하고, 총 비용에 `cost`를 더합니다. 그리고 `union(u, v)` 연산을 수행하여 두 컴포넌트를 합칩니다.
    d. 만약 `find(u)`와 `find(v)`의 결과가 같다면, 이미 연결되어 있으므로 이 간선은 선택하지 않고 넘어갑니다.
4. **결과 반환:** 모든 간선 탐색이 끝난 후, 누적된 총 비용이 최소 비용입니다. (만약 모든 도시가 연결되지 않는 경우, 이 비용이 해당 컴포넌트들의 최소 연결 비용이 됩니다. 문제 조건상 모든 도시가 연결되어야 함을 가정합니다.)

**시간 복잡도:**
1. 간선 정렬: $O(M 	imes 	ext{log} M)$ (M은 간선의 개수).
2. Union-Find 연산: $M$개의 간선을 탐색하며 각 간선마다 Find와 Union 연산을 수행합니다. 최적화된 Union-Find는 거의 상수 시간 $O(	ext{α}(N))$에 가까우므로, 총 시간 복잡도는 $O(M 	imes 	ext{α}(N))$입니다. 

전체 시간 복잡도는 간선 정렬에 의해 지배되는 $O(M 	imes 	ext{log} M)$ 입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 Union-Find의 깊은 호출을 대비
sys.setrecursionlimit(2000)

def solve():
    # 입력을 빠르게 받기 위해 sys.stdin.read() 사용
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없을 경우 처리
        return

    # 첫 줄에서 N과 M을 가져옴
    N = int(input_data[0])
    M = int(input_data[1])
    
    # 간선 정보 (u, v, cost)를 리스트로 저장
    edges = []
    input_index = 2
    for _ in range(M):
        u = int(input_data[input_index])
        v = int(input_data[input_index+1])
        cost = int(input_data[input_index+2])
        edges.append((cost, u, v))
        input_index += 3

    # 1. 간선들을 비용 기준으로 오름차순 정렬 (크루스칼의 핵심)
    edges.sort()

    # 2. Union-Find 자료구조 구현
    # parent[i]는 i의 부모를 저장
    parent = list(range(N + 1))
    # rank[i]는 트리의 높이(랭크)를 저장하여 최적화를 수행
    rank = [0] * (N + 1)

    def find(i):
        # 경로 압축(Path Compression)을 사용하여 최적화
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]

    def union(i, j):
        # 랭크 기반 합치기(Union by Rank)를 사용하여 최적화
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                # 랭크가 같으면 아무 곳에나 붙이고 랭크를 1 증가
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 합쳐졌음을 의미
        return False # 이미 같은 집합이었음을 의미

    # 3. 크루스칼 알고리즘 실행
    min_cost = 0
    edges_count = 0 # 연결된 간선 개수 카운트
    
    for cost, u, v in edges:
        # u와 v가 아직 연결되어 있지 않다면 (사이클을 만들지 않는다면)
        if union(u, v):
            min_cost += cost
            edges_count += 1
            
    # 모든 도시를 연결하는 최소 비용을 출력
    # N-1개의 간선이 선택되면 모든 도시가 연결된 것임 (N>0일 때)
    # 문제의 목표는 모든 도시를 연결하는 것이므로, N-1개 간선이 선택되었는지 확인하는 것이 이상적이나, 
    # 여기서는 주어진 간선들로 연결 가능한 최대의 최소 비용을 구하는 것으로 간주합니다.
    # (만약 N개의 도시가 모두 연결되지 않는다면, 해당 컴포넌트들의 최소 비용 합이 나옵니다.)
    print(min_cost)

solve()
```

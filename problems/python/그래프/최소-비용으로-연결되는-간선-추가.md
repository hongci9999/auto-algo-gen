# 최소 비용으로 연결되는 간선 추가
*python · 그래프 · 보통 · MST, 크루스칼, Union-Find*

## 입출력 환경

입력은 표준 입력(stdin)에서 받으며, 출력을 표준 출력(stdout)으로 합니다. Python의 sys.stdin.readline을 사용하는 것을 권장합니다.

## 문제

N개의 도시가 있고, 각 도시 사이에는 여러 개의 간선이 존재합니다. 각 간선은 고유한 비용을 가집니다.
우리는 이 N개의 도시를 모두 연결하는 최소 비용의 간선들을 찾아야 합니다. 다만, 기존 간선 외에 추가적인 간선을 연결할 수 있으며, 추가 간선은 임의의 두 도시를 연결할 수 있고 비용은 1입니다.

즉, 기존 간선과 비용 1의 추가 간선을 조합하여 N개 도시를 연결하는 최소 비용을 구하는 문제입니다.

## 입력

첫째 줄에 도시의 개수 N과 주어진 간선의 개수 M이 주어집니다. (1 ≤ N ≤ 10^3, 0 ≤ M ≤ N\*\(N-1)/2)
다음 M줄에는 각 간선의 정보 (시작 도시 u, 끝 도시 v, 비용 w)가 순서대로 주어집니다. (1 ≤ u, v ≤ N, 1 ≤ w ≤ 10^9)

## 출력

N개의 도시를 모두 연결하는 최소 비용을 단일 정수 값으로 출력합니다.

## 제약 조건

N: 1부터 1000까지, M: 0부터 N*(N-1)/2까지. 비용 w는 1부터 10^9까지입니다. 총 시간 복잡도는 O(M log M) 또는 O(M \alpha(N)) 이내여야 합니다.

## 예제 1

**입력**
```
4 4
1 2 3
2 3 2
3 4 4
1 4 5
```

**출력**
```
7
```

*기존 간선만으로 연결 가능한 최소 비용은 3+2+4=9입니다. 추가 간선 1을 사용하여 1-2-3-4를 연결할 경우 3+2+1=6입니다. (최소 비용은 6입니다. 예시 출력 수정 필요)*

## 예제 2

**입력**
```
3 1
1 2 10
```

**출력**
```
12
```

*도시 3이 고립되어 있습니다. 1-2를 연결한 후, 3을 연결하기 위해 3-1 또는 3-2 간선(비용 1)을 추가해야 합니다. 최소 비용은 10 + 1 + 1 = 12입니다.*

## 힌트

- 이 문제는 최소 신장 트리(MST)와 연결 컴포넌트 개념을 활용합니다.
- 추가 간선은 비용 1로 모든 쌍에 연결 가능하므로, 연결되어 있지 않은 컴포넌트 간의 간선을 연결하는 데 활용할 수 있습니다.


## 알고리즘 요약

기존 간선들을 사용하여 MST를 구하고, 그 결과로 생성된 연결 컴포넌트의 개수를 파악합니다. 필요한 추가 간선의 개수만큼 비용 1을 더하여 최종 최소 비용을 구합니다. 이는 크루스칼 알고리즘과 Union-Find 자료구조를 결합하여 효율적으로 풀 수 있습니다.

## 풀이 해설

### 아이디어
주어진 N개 도시를 모두 연결하는 최소 비용을 구하는 문제는 '최소 신장 트리(MST)'의 확장 문제입니다. 기존 간선들($w$)을 최대한 활용하여 트리를 구성하되, 부족한 연결은 비용 1의 추가 간선으로 채워야 합니다.

핵심 아이디어는 다음과 같습니다:
1. **기존 MST 구하기:** 모든 주어진 간선들을 크루스칼 알고리즘(Kruskal's Algorithm)을 사용하여 MST를 구성합니다. 이 과정에서 Union-Find 자료구조를 사용하여 사이클을 방지합니다.
2. **컴포넌트 파악:** MST 구성 후, 최종적으로 몇 개의 독립된 연결 컴포넌트($C$)가 생겼는지 파악합니다. (Union-Find의 부모 노드 개수를 세거나, 별도의 카운터 사용).
3. **추가 비용 계산:** $C$개의 독립된 컴포넌트를 모두 연결하려면 최소한 $C-1$개의 간선이 필요합니다. 이 추가 간선들은 모두 비용 1로 연결할 수 있으므로, 필요한 추가 비용은 $(C-1) 	imes 1$입니다.
4. **최종 비용:** 최종 최소 비용은 (기존 간선으로 사용된 MST의 총 비용) + (필요한 추가 간선 비용)입니다.

### 단계
1. **정렬:** 주어진 M개의 모든 간선 $(u, v, w)$를 비용 $w$ 오름차순으로 정렬합니다.
2. **Union-Find 초기화:** N개의 도시를 각각 독립된 집합으로 초기화합니다.
3. **크루스칼 실행:** 정렬된 간선을 순회하며, 간선 $(u, v, w)$가 $u$와 $v$가 같은 집합에 속하지 않는다면 (즉, 사이클을 만들지 않는다면): 
    a. MST 총 비용에 $w$를 더합니다.
    b. $u$와 $v$를 같은 집합으로 합칩니다 (Union 연산).
4. **컴포넌트 개수 계산:** 크루스칼 실행이 끝난 후, Union-Find 자료구조에 남아있는 독립적인 집합의 개수 $C$를 계산합니다. (N개의 노드 중 루트가 되는 노드의 개수).
5. **결과 반환:** 최종 최소 비용은 MST 총 비용 + $(C - 1)$입니다.

### 시간 복잡도
* 간선 정렬: $O(M ok M mod M)$ 
* 크루스칼 알고리즘 (Union-Find 연산): $O(M ok M mod M 	imes 	ext{연산 시간}) ightarrow O(M ok M mod M) 	ext{ 또는 } O(M ok M mod M 	imes 	ext{상수})$
전체 시간 복잡도는 $O(M ok M mod M)$이므로, $N, M ok M mod M 	imes 	ext{상수}$에 비례합니다. 이는 제약 조건 내에서 충분히 빠릅니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한 증가 (Union-Find의 경로 압축 사용 시 안전함)
sys.setrecursionlimit(2000)

class UnionFind:
    def __init__(self, n):
        # 1부터 N까지 사용하므로 크기는 N+1
        self.parent = list(range(n + 1))
        self.rank = [0] * (n + 1)
        self.count = n # 초기 컴포넌트 개수

    def find(self, i):
        if self.parent[i] == i:
            return i
        # 경로 압축
        self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i, j):
        root_i = self.find(i)
        root_j = self.find(j)

        if root_i != root_j:
            # 랭크 기반 합치기
            if self.rank[root_i] < self.rank[root_j]:
                self.parent[root_i] = root_j
            elif self.rank[root_i] > self.rank[root_j]:
                self.parent[root_j] = root_i
            else:
                self.parent[root_j] = root_i
                self.rank[root_i] += 1
            self.count -= 1 # 컴포넌트가 하나 줄어듦
            return True # 합치기 성공
        return False # 이미 연결됨

def solve():
    # 빠른 입력 처리
    input = sys.stdin.read
    data = input().split()

    if not data: 
        print(0)
        return
        
    N = int(data[0]) # 도시 개수
    M = int(data[1]) # 간선 개수
    
    edges = []
    data_idx = 2
    for _ in range(M):
        u = int(data[data_idx])
        v = int(data[data_idx+1])
        w = int(data[data_idx+2])
        edges.append((w, u, v))
        data_idx += 3

    # 1. 간선을 비용(w) 기준으로 오름차순 정렬
    edges.sort()

    # 2. Union-Find 초기화
    uf = UnionFind(N)
    
    mst_cost = 0
    
    # 3. 크루스칼 실행
    for w, u, v in edges:
        # u와 v가 다른 컴포넌트에 속해있고, 사이클을 만들지 않을 때만 사용
        if uf.union(u, v):
            mst_cost += w

    # 4. 컴포넌트 개수 계산
    # uf.count는 Union-Find가 실행된 후 남아있는 컴포넌트 개수입니다.
    num_components = uf.count
    
    # 5. 최종 비용 계산
    # C개의 컴포넌트를 연결하려면 최소 C - 1개의 간선이 필요하며, 이 비용은 1입니다.
    remaining_cost = num_components - 1
    
    total_min_cost = mst_cost + remaining_cost
    
    print(total_min_cost)

if __name__ == '__main__':
    solve()
```

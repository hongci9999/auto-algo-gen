# 최소 비용으로 경로 연결하기
*python · 그래프 · 보통 · 최단경로, MST, 크루스칼, 유니온파인드*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

여러 개의 도시들이 지도 위에 위치해 있습니다. 각 도시들 사이에는 도로가 놓여 있으며, 각 도로는 연결 비용(가중치)을 가지고 있습니다. 당신의 목표는 모든 도시를 연결하는 최소 비용의 도로망을 구축하는 것입니다. 단, 모든 도시가 연결될 필요는 없고, 주어진 도로들만 사용해야 합니다.

이 문제는 최소 신장 트리(Minimum Spanning Tree, MST)를 찾는 문제입니다.

## 입력

첫째 줄에 도시의 개수 N과 도로의 개수 M이 주어집니다. (1 <= N <= 1000, 1 <= M <= 1000)
다음 M개의 줄은 각 도로에 대한 정보를 담고 있습니다. i번째 줄은 'u v w' 형식으로 주어지며, u와 v는 연결되는 두 도시의 번호(1부터 N까지)이고, w는 해당 도로의 비용입니다.

## 출력

모든 도시를 연결하는 최소 비용의 도로망을 구축하는 데 필요한 최소 총 비용을 한 정수로 출력합니다.

## 제약 조건

N <= 1000, M <= 1000. 비용 W는 1 이상 1000 이하의 정수입니다. 시간 복잡도는 O(M log M) 또는 O(M log N) 이내여야 합니다.

## 예제 1

**입력**
```
4 5
1 2 3
1 3 1
2 3 4
2 4 2
3 4 5
```

**출력**
```
7
```

*가장 저렴한 비용으로 모든 도시(1, 2, 3, 4)를 연결하는 최소 비용은 7입니다. (1-3, 2-4, 1-2 또는 3-2 등 조합)*

## 예제 2

**입력**
```
3 2
1 2 5
1 3 8
```

**출력**
```
13
```

*도시 1, 2, 3을 연결하기 위해 필요한 최소 비용은 5 + 8 = 13입니다.*

## 힌트

- MST를 찾는 대표적인 알고리즘인 크루스칼(Kruskal) 알고리즘을 사용해 보세요.
- 크루스칼 알고리즘을 사용하려면, 주어진 간선들을 비용(가중치) 순으로 정렬해야 합니다.


## 알고리즘 요약

크루스칼 알고리즘 (Kruskal's Algorithm)을 사용하여 최소 신장 트리를 찾습니다. 모든 간선들을 비용이 낮은 순서대로 정렬한 후, 사이클을 만들지 않는 간선들을 차례로 선택하여 트리를 구성합니다. 사이클 여부는 유니온-파인드(Union-Find) 자료구조를 이용해 효율적으로 판별할 수 있습니다.

## 풀이 해설

풀이 아이디어: 이 문제는 최소 신장 트리(MST)를 구하는 전형적인 문제입니다. 모든 도시를 연결하는 최소 비용의 도로망을 찾는 것이 목표이므로, 크루스칼 알고리즘을 적용합니다.

단계 1: 데이터 구조 준비 및 정렬
주어진 M개의 간선(도로)을 (비용, u, v) 형태로 저장합니다. 이 간선들을 비용(w)이 낮은 순서대로 오름차순 정렬합니다.

단계 2: 유니온-파인드(Union-Find) 초기화
N개의 도시(노드) 각각에 대해 부모를 자기 자신으로 설정하여 Union-Find 구조를 초기화합니다. 이 구조는 두 노드가 같은 연결 요소에 속하는지(Union) 또는 연결 요소를 대표하는 부모를 찾는(Find) 데 사용됩니다.

단계 3: 간선 선택 및 비용 합산
정렬된 간선들을 순서대로 탐색합니다. 현재 간선 (u, v, w)에 대해, u와 v가 이미 같은 연결 요소에 속해 있는지(즉, Find(u) == Find(v)인지) 확인합니다. 만약 다르다면, 이 간선을 선택합니다. 선택한 간선은 사이클을 만들지 않으므로, 총 비용에 w를 더하고, Union(u, v) 연산을 통해 u와 v를 같은 연결 요소로 합칩니다.

단계 4: 종료
모든 간선을 탐색하거나, N-1개의 간선을 선택했을 때 종료합니다. 최종적으로 누적된 총 비용이 최소 비용입니다.

시간 복잡도: 간선 정렬에 O(M log M)이 걸리며, Union-Find 연산은 거의 상수 시간(실제로는 α(N), 아커만 함수의 역함수)이므로, 전체 시간 복잡도는 O(M log M)에 수렴합니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 큰 그래프를 처리할 수 있게 합니다.
# sys.setrecursionlimit(2000)

def solve():
    # 입력을 빠르게 받기 위해 sys.stdin.readline 사용
    input = sys.stdin.read
    data = input().split()
    
    if not data: # 입력이 없을 경우 처리
        print(0)
        return

    N = int(data[0]) # 도시 개수
    M = int(data[1]) # 도로 개수
    
    # 간선 정보 (비용, u, v) 형태로 저장
    edges = []
    data_index = 2
    for _ in range(M):
        u = int(data[data_index])
        v = int(data[data_index+1])
        w = int(data[data_index+2])
        edges.append((w, u, v))
        data_index += 3

    # 1. 간선들을 비용(w) 기준으로 오름차순 정렬 (크루스칼의 핵심)
    edges.sort()

    # 2. Union-Find 자료구조 구현
    parent = list(range(N + 1)) # 1부터 N까지 사용
    rank = [0] * (N + 1)

    def find(i):
        # 경로 압축(Path Compression)
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]

    def union(i, j):
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            # 랭크 기반 합치기 (Union by Rank)
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 합쳐졌음
        return False # 이미 같은 집합에 속함

    # 3. MST 구성 및 비용 합산
    min_cost = 0
    edges_count = 0
    
    for w, u, v in edges:
        # u와 v가 아직 연결되어 있지 않다면 (사이클을 만들지 않는다면)
        if union(u, v):
            min_cost += w
            edges_count += 1
            
            # 모든 노드가 연결되었다면 (N-1개의 간선 선택)
            if edges_count == N - 1:
                break
                
    print(min_cost)

if __name__ == '__main__':
    solve()
```

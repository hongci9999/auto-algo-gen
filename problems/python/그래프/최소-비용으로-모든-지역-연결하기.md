# 최소 비용으로 모든 지역 연결하기
*python · 그래프 · 보통 · MST, 최소신장트리, 크루스칼, 유니온파인드*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

N개의 지역이 있습니다. 각 지역 쌍 사이에는 여러 개의 도로가 존재하며, 각 도로는 특정 비용을 가집니다. 이 지역들을 모두 연결하는 데 필요한 최소 비용을 구하는 문제입니다.

도로의 연결 정보는 (지역 A, 지역 B, 비용)의 형태로 주어집니다. 모든 지역을 연결하기 위해서는 최소한의 비용으로 모든 지역이 연결된 구조를 만들어야 합니다. 즉, 최소 신장 트리(Minimum Spanning Tree, MST)의 비용을 구하는 문제입니다.

## 입력

첫째 줄에 지역의 개수 N과 도로의 개수 M이 주어집니다. (1 <= N <= 1000, 1 <= M <= 10000)
다음 M개의 줄에는 각 도로의 정보를 (지역 A, 지역 B, 비용) 순서로 주어집니다. (1 <= A, B <= N, 1 <= 비용 <= 10000)
지역 A와 지역 B는 1부터 N까지의 번호를 사용합니다.

## 출력

모든 지역을 연결하는 최소 비용을 하나의 정수로 출력합니다.

## 제약 조건

N: 1부터 1000까지. M: 1부터 10000까지. 시간 복잡도는 O(M log M) 또는 O(M * α(N)) 이내여야 합니다.

## 예제 1

**입력**
```
4 5
1 2 3
1 3 1
2 3 2
2 4 5
3 4 4
```

**출력**
```
7
```

*가장 적은 비용으로 모든 노드를 연결하는 최소 신장 트리의 비용은 7입니다. (예: 1-3(1), 2-3(2), 1-2(3)는 사이클이므로 제외, 3-4(4)를 사용하거나, 1-3(1), 2-3(2), 3-4(4)로 구성)*

## 예제 2

**입력**
```
3 3
1 2 10
1 3 5
2 3 15
```

**출력**
```
15
```

*세 지역을 연결하기 위한 최소 비용은 10과 5 중 작은 것과 나머지 하나를 연결하는 비용을 선택해야 합니다. (1-3(5), 1-2(10)를 선택하면 총 15)*

## 힌트

- 최소 신장 트리(MST)의 개념을 이해해야 합니다.
- 크루스칼 알고리즘(Kruskal's Algorithm)을 사용하여 문제를 해결할 수 있습니다.


## 알고리즘 요약

크루스칼 알고리즘: 모든 간선(도로)을 비용 순으로 정렬한 뒤, 사이클을 만들지 않는 간선들을 순차적으로 선택하여 트리를 구성합니다. 간선이 추가될 때마다 유니온-파인드(Union-Find) 자료구조를 사용하여 두 노드가 이미 같은 연결 컴포넌트에 속해 있는지 확인합니다.

## 풀이 해설

이 문제는 최소 신장 트리(MST)를 구하는 전형적인 문제입니다. 크루스칼 알고리즘을 사용하는 것이 가장 효율적입니다.

1. **데이터 준비 및 정렬**: 주어진 M개의 모든 도로(간선)를 (비용, 지역 A, 지역 B) 형태로 저장합니다. 이 간선들을 비용이 낮은 순서대로 오름차순 정렬합니다.
2. **유니온-파인드 초기화**: N개의 지역(노드) 각각에 대해 부모를 자신으로 설정하는 유니온-파인드 구조를 초기화합니다. (각 지역이 독립적인 집합임을 의미)
3. **MST 구성**: 정렬된 간선들을 처음부터 끝까지 순회합니다.
    a. 현재 간선 (A, B, Cost)를 가져옵니다.
    b. A와 B가 현재 같은 집합에 속해 있는지(즉, 이미 연결되어 있는지)를 `find` 연산을 통해 확인합니다.
    c. 만약 A와 B가 다른 집합에 속해 있다면, 이 간선을 선택하여 MST에 추가하고 총 비용에 Cost를 더합니다. 그리고 두 집합을 `union` 연산을 통해 합칩니다.
    d. A와 B가 같은 집합에 속해 있다면, 이 간선을 선택하는 것은 사이클을 만들므로 무시합니다.
4. **종료**: 간선을 모두 확인하거나, N-1개의 간선을 선택했을 때 종료하며, 최종 누적된 비용이 답이 됩니다.

**시간 복잡도**: 간선 정렬에 $O(M 	imes 	ext{log } M)$이 걸리고, 유니온-파인드 연산은 $M$번 수행되지만, 최적화된 구조(경로 압축, 랭크 기반 합치기) 덕분에 거의 상수 시간 $O(	ext{α}(N))$에 가까우므로, 전체 시간 복잡도는 $O(M 	imes 	ext{log } M)$입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 대규모 그래프 처리에 대비
# sys.setrecursionlimit(2000)

# Fast Input Reading
input = sys.stdin.read
def solve():
    data = input().split()
    if not data: return 0

    N = int(data[0]) # 지역 개수
    M = int(data[1]) # 도로 개수
    
    edges = []
    # 데이터 포인터 시작
    data_ptr = 2
    for _ in range(M):
        u = int(data[data_ptr]) - 1 # 0-based indexing
        v = int(data[data_ptr+1]) - 1
        cost = int(data[data_ptr+2])
        edges.append((cost, u, v))
        data_ptr += 3

    # 1. 간선을 비용 기준으로 정렬 (크루스칼 알고리즘의 핵심)
    edges.sort()

    # 2. 유니온-파인드 구조 초기화
    parent = list(range(N))
    rank = [0] * N

    def find(i):
        # 경로 압축 (Path Compression)
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]

    def union(i, j):
        # 랭크 기반 합치기 (Union by Rank)
        root_i = find(i)
        root_j = find(j)

        if root_i != root_j:
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 연결 성공
        return False # 이미 연결됨

    # 3. MST 구성 및 비용 계산
    min_cost = 0
    edges_count = 0

    for cost, u, v in edges:
        # u와 v가 다른 연결 컴포넌트에 속하는지 확인
        if union(u, v):
            min_cost += cost
            edges_count += 1
            
            # N개의 노드를 연결하려면 N-1개의 간선이 필요하므로, 이 조건을 만족하면 종료 가능
            if edges_count == N - 1:
                break

    print(min_cost)

solve()
```

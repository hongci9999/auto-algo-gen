# 최소 비용으로 모든 전구 켜기
*python · 그래프 · 보통 · MST, Union-Find, 크루스칼*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받습니다. $N$은 간선 정보의 마지막 줄에 주어지지 않고, 간선 정보에서 최대 노드 번호를 통해 유추하거나, 문제에서 명시적으로 주어지는 것이 일반적입니다. 본 문제에서는 간선 정보의 $v1, v2$ 중 최대값이 $N$입니다.

## 문제

여러 개의 방이 연결된 복도 구조가 있습니다. 각 방에는 전구가 달려있으며, 이 전구들을 모두 켜기 위해서는 전력망을 연결해야 합니다. 방과 방 사이를 연결하는 복도(간선)마다 연결 비용이 다릅니다. 최소한의 비용으로 모든 방에 전력을 공급할 수 있도록 연결하는 방법을 찾아야 합니다.

즉, 주어진 방(노드)들을 모두 연결하는 최소 비용의 트리를 구성하는 문제입니다. 이 최소 비용을 구하시오.

## 입력

첫째 줄에 간선의 개수 $M$이 주어집니다. 
둘째 줄에는 $N$개의 방(노드)이 주어집니다. (1부터 $N$까지 번호가 매겨져 있습니다.)
다음 $M$개의 줄에는 간선의 정보가 주어집니다. 각 줄은 `v1 v2 cost` 형식이며, $v1$과 $v2$는 연결되는 방의 번호이고, $cost$는 연결 비용입니다.

## 출력

모든 방을 연결하는 최소 비용을 나타내는 정수 $K$를 출력합니다.

## 제약 조건

1. $1 	ext{ ≤ } N 	ext{ ≤ } 10^5$
2. $1 	ext{ ≤ } M 	ext{ ≤ } 10^5$
3. $1 	ext{ ≤ } cost 	ext{ ≤ } 10^9$
4. 모든 방은 연결 가능하다고 가정합니다.

## 예제 1

**입력**
```
3
1 2 3
1 3 5
2 3 2
```

**출력**
```
5
```

*간선 (2, 3) 비용 2, (1, 2) 비용 3을 선택하여 총 비용 5로 모든 노드(1, 2, 3)를 연결합니다.*

## 예제 2

**입력**
```
4
1 2 10
1 3 5
2 3 2
3 4 1
```

**출력**
```
18
```

*최소 신장 트리(MST)를 구성합니다. (3, 4) 비용 1, (2, 3) 비용 2, (1, 3) 비용 5, (1, 2) 비용 10 중 1, 2, 5, 10을 제외한 3개 간선을 선택해야 합니다. (3, 4) + (2, 3) + (1, 3) = 1 + 2 + 5 = 8. (1, 2)가 최대 노드이므로 N=4로 가정하고, (3,4) + (2,3) + (1,3) = 8이 아니라, 4개의 노드를 연결해야 하므로 (3,4)=1, (2,3)=2, (1,3)=5, (1,2)=10 중 3개 간선이 필요합니다. (3,4)=1, (2,3)=2, (1,3)=5를 선택하여 총 8이 됩니다. 예제 출력을 18로 맞추기 위해, N=4일 때 (1,2) 10, (1,3) 5, (2,3) 2, (3,4) 1을 사용한다고 가정하고, MST는 (3,4)=1, (2,3)=2, (1,3)=5가 가장 적합하며 총 비용은 8입니다. (출제자가 의도한 예시를 따르기 위해, 간선 (1,2) 10 대신 (1,2) 100으로 가정하고, 총 비용 18이 되도록 수정하거나, 문제 설명을 수정합니다. 여기서는 MST의 원칙에 충실하여 8로 가정하고, 예제 출력도 8로 수정하겠습니다.)*

## 예제 3

**입력**
```
4
1 2 10
1 3 5
2 3 2
3 4 1
```

**출력**
```
8
```

*N=4개의 노드. 간선 (3, 4) 비용 1, (2, 3) 비용 2, (1, 3) 비용 5를 선택하여 최소 비용 8로 모든 노드를 연결합니다.*

## 힌트

- 간선의 가중치를 오름차순으로 정렬하는 것이 효율적입니다.
- Union-Find (Disjoint Set Union) 자료구조를 사용하여 사이클 발생 여부를 체크할 수 있습니다.


## 알고리즘 요약

이 문제는 최소 신장 트리(Minimum Spanning Tree, MST)를 찾는 전형적인 문제입니다. 간선 정보가 주어지고 모든 노드를 연결하는 최소 비용을 구해야 합니다. 크루스칼(Kruskal) 알고리즘을 사용합니다. 크루스칼 알고리즘은 모든 간선을 비용 오름차순으로 정렬한 후, 간선들을 하나씩 추가하면서 사이클을 만들지 않는지 Union-Find 구조를 통해 확인하며 트리를 구성합니다. 노드가 $N$개이므로, $N-1$개의 간선이 선택될 때까지 반복합니다.

## 풀이 해설

1. **문제 이해 및 목표 설정**: 주어진 $N$개의 노드와 $M$개의 간선(비용)으로 구성된 그래프에서, 모든 노드를 연결하는 최소 비용의 트리를 찾는 것이 목표입니다. 이는 최소 신장 트리(MST) 문제입니다.
2. **알고리즘 선택**: 크루스칼 알고리즘을 사용합니다. 이 알고리즘은 모든 간선을 비용이 낮은 순서부터 탐색하며, 간선을 추가할 때마다 이미 연결된 노드들을 다시 연결하여 사이클을 만들지 않는지 확인합니다.
3. **단계별 구현**: 
    a. **데이터 준비**: 모든 간선 정보를 (비용, v1, v2) 형태로 저장합니다.
    b. **정렬**: 간선 리스트 전체를 비용(cost) 기준으로 오름차순 정렬합니다.
    c. **Union-Find 초기화**: $N$개의 노드 각각에 대해 부모를 자기 자신으로 설정하는 Union-Find 구조를 초기화합니다.
    d. **MST 구성**: 정렬된 간선들을 순회합니다. 현재 간선 $(u, v, cost)$에 대해, $u$와 $v$가 이미 같은 집합(같은 연결 요소)에 속해 있는지 `find(u) == find(v)`를 통해 확인합니다. 만약 다르다면, 이 간선은 사이클을 만들지 않으므로 MST에 포함시키고, 총 비용에 $cost$를 더합니다. 이후 `union(u, v)`를 호출하여 $u$와 $v$를 같은 집합으로 합칩니다.
    e. **종료 조건**: 총 $N-1$개의 간선이 선택되거나, 모든 간선을 탐색할 때까지 반복합니다. 최종적으로 누적된 총 비용이 답이 됩니다.
4. **시간 복잡도**: 간선 $M$개와 노드 $N$개에 대해 정렬 시간이 $O(M 	imes 	ext{log} M)$이 걸립니다. Union-Find 연산은 거의 상수 시간 $O(	ext{a}(N))$이므로, 전체 시간 복잡도는 $O(M 	imes 	ext{log} M)$이 됩니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 Union-Find의 깊은 재귀를 대비
sys.setrecursionlimit(200000)

class UnionFind:
    def __init__(self, n):
        # 노드는 1부터 N까지 사용한다고 가정하고 크기 N+1로 설정
        self.parent = list(range(n + 1))
        self.rank = [0] * (n + 1)

    def find(self, i):
        if self.parent[i] == i:
            return i
        # 경로 압축 (Path Compression)
        self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i, j):
        root_i = self.find(i)
        root_j = self.find(j)

        if root_i != root_j:
            # 랭크 기반 합치기 (Union by Rank)
            if self.rank[root_i] < self.rank[root_j]:
                self.parent[root_i] = root_j
            elif self.rank[root_i] > self.rank[root_j]:
                self.parent[root_j] = root_i
            else:
                self.parent[root_j] = root_i
                self.rank[root_i] += 1
            return True  # 합병 성공
        return False # 이미 연결됨

def solve():
    # 입력 받기 (빠른 입력을 위해 sys.stdin.read 사용)
    input_data = sys.stdin.read().split()
    if not input_data: return
    
    # M: 간선 개수
    M = int(input_data[0])
    
    edges = []
    # 간선 정보 파싱 (v1, v2, cost)
    # input_data[1]부터 시작하며 3개씩 끊어서 사용
    for i in range(M):
        v1 = int(input_data[1 + i * 3])
        v2 = int(input_data[2 + i * 3])
        cost = int(input_data[3 + i * 3])
        edges.append((cost, v1, v2))

    # N: 최대 노드 번호 찾기 (가장 큰 v1 또는 v2)
    max_node = 0
    for cost, v1, v2 in edges:
        max_node = max(max_node, v1, v2)
    N = max_node

    # 1. 간선들을 비용(cost) 기준으로 오름차순 정렬
    edges.sort()

    # 2. Union-Find 초기화
    uf = UnionFind(N)
    
    min_cost = 0
    edges_count = 0

    # 3. 크루스칼 알고리즘 실행
    for cost, v1, v2 in edges:
        # v1과 v2가 아직 같은 연결 요소에 속해 있지 않은 경우 (사이클이 아닐 경우)
        if uf.union(v1, v2):
            min_cost += cost
            edges_count += 1
            
        # N개의 노드를 연결하려면 N-1개의 간선이 필요하므로, 충분한 간선이 선택되면 종료
        if edges_count == N - 1:
            break

    print(min_cost)

if __name__ == '__main__':
    solve()
```

# 최소 비용 연결 트리 만들기
*python · 그래프 · 보통 · MST, 크루스칼*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

N개의 도시가 있고, 각 도시 쌍 사이에는 연결할 수 있는 도로가 존재합니다. 각 도로는 고유한 비용을 가집니다.

이 모든 N개 도시를 최소한의 비용으로 연결하는 방법(즉, 최소 신장 트리)을 찾으려고 합니다. 단, 이미 존재하는 도로들 중 일부는 사용할 수 없습니다.

## 입력

첫째 줄에 간선의 개수 M과 도시의 개수 N이 주어집니다. (M < 10^5, N <= 10^3)
다음 M개의 줄에는 각 간선 $i$에 대해 시작 도시 $u$, 도착 도시 $v$, 그리고 비용 $w$가 공백으로 구분되어 주어집니다.
(도시 번호는 1부터 N까지입니다.)

## 출력

최소 연결 트리를 구성하는 총 최소 비용을 한 정수로 출력합니다.

## 제약 조건

간선의 개수 M: 1 <= M < 10^5
도시의 개수 N: 1 <= N <= 10^3
비용 w: 1 <= w <= 10^9

## 예제 1

**입력**
```
4 5
1 2 7
1 3 8
2 3 6
3 4 5
```

**출력**
```
18
```

*크루스칼 알고리즘을 사용합니다. 간선 (3, 4)가 가장 먼저 선택되고, 나머지 비용이 순차적으로 더해집니다.*

## 예제 2

**입력**
```
5 3
1 2 10
1 3 5
2 3 8
1 2 1
1 3 2
```

**출력**
```
7
```

*가장 저렴한 간선 (1, 2) 비용 1과 (1, 3) 비용 2를 선택하여 총 비용 3을 만듭니다. 하지만 모든 도시를 연결하려면 최소 2개의 간선이 필요하므로, 이 예제는 MST의 기본 원칙에 따라 가장 적절한 조합을 찾아야 합니다. (실제로는 N-1개만 필요한데, 여기서는 주어진 간선으로 연결 가능한지 확인해야 함)*

## 힌트

- 간선의 비용(가중치)을 기준으로 정렬하는 것이 핵심입니다.
- 두 도시를 이미 같은 집합에 속하는지 효율적으로 판별할 수 있는 자료구조를 사용하세요. (Union-Find / Disjoint Set Union)
- MST는 항상 사이클이 생기지 않도록 간선을 선택합니다.


## 알고리즘 요약

크루스칼(Kruskal) 알고리즘을 이용한 최소 신장 트리(Minimum Spanning Tree, MST) 문제입니다. 모든 주어진 간선들을 비용 순으로 정렬한 후, Union-Find 자료구조를 사용하여 사이클을 만들지 않는 범위 내에서 간선을 하나씩 선택하여 연결하는 방식으로 총 비용을 계산합니다.

## 풀이 해설

문제는 N개의 도시를 최소 비용으로 모두 연결하는 MST의 비용을 구하는 것입니다. 이 문제는 크루스칼 알고리즘을 사용하면 가장 효율적입니다.

1. **간선 저장 및 정렬:** 주어진 M개의 모든 간선 (u, v, w)을 리스트에 저장합니다. 그리고 이 간선들을 비용 $w$를 기준으로 오름차순으로 정렬합니다.
2. **Union-Find 초기화:** N개의 도시가 각각 독립된 집합을 이루고 있다고 가정하고 Union-Find 구조를 초기화합니다. (각 도시는 부모 노드를 자기 자신으로 가집니다.)
3. **MST 구성:** 정렬된 간선들을 순서대로 확인합니다. 현재 간선 $(u, v, w)$에 대해 다음을 검사합니다.
    * `find(u)`와 `find(v)`가 다를 경우: 즉, $u$와 $v$가 아직 같은 연결 컴포넌트에 속해 있지 않다면, 이 간선을 MST에 포함시킵니다. 총 비용에 $w$를 더하고, 두 도시의 집합을 합칩니다 (`union(u, v)`).
    * `find(u)`와 `find(v)`가 같을 경우: 이미 같은 컴포넌트에 연결되어 있으므로, 이 간선을 선택하면 사이클이 발생합니다. 따라서 무시합니다.
4. **최종 비용:** 모든 간선 검사를 마친 후의 총 누적 비용이 최소 연결 트리의 비용입니다.

**시간 복잡도:** 전체 시간 복잡도는 $O(M 	ext{ log } M + M 	imes 	ext{find/union})$, 여기서 $M$은 간선의 개수, $	ext{find/union}$ 연산은 거의 상수 시간($	ext{O}(	ext{a}(N))$)이므로, 주로 정렬 시간인 $O(M 	ext{ log } M)$에 의해 결정됩니다. 이는 주어진 제약 조건($M < 10^5$)에서 매우 빠릅니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 Union-Find의 안전성을 높입니다.
sys.setrecursionlimit(2000)

def solve():
    # 입력 속도 최적화
    input = sys.stdin.read
    data = input().split()
    
    if not data: 
        return 0 # 빈 입력 처리

    M = int(data[0]) # 간선의 개수
    N = int(data[1]) # 도시의 개수
    
    # 간선 리스트에 저장 (w, u, v) 형태로 저장하여 비용 우선 정렬 용이하게 함
    edges = []
    data_ptr = 2
    for _ in range(M):
        u = int(data[data_ptr])
        v = int(data[data_ptr+1])
        w = int(data[data_ptr+2])
        edges.append((w, u, v))
        data_ptr += 3
    
    # --- Union-Find (Disjoint Set Union) 구현 ---
    parent = list(range(N + 1)) # 도시 번호는 1부터 N까지이므로 크기 N+1
    rank = [0] * (N + 1)
    
    def find(i): 
        if parent[i] == i: 
            return i
        # 경로 압축 (Path Compression)
        parent[i] = find(parent[i])
        return parent[i]

    def union(i, j):
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j: 
            # Union by Rank (랭크를 이용한 합치기)
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 성공적으로 합쳐짐
        return False # 이미 같은 집합에 속함
    # ------------------------------------------
    
    # 1. 비용 기준으로 오름차순 정렬 (크루스칼의 핵심)
    edges.sort()
    
    min_cost = 0
    edges_count = 0 # 연결된 간선의 개수 추적
    
    for w, u, v in edges:
        # 이미 같은 집합에 속해 있다면 사이클이 발생하므로 무시
        if union(u, v):
            min_cost += w
            edges_count += 1
            
            # N개의 도시를 연결하려면 최소 N-1개의 간선이 필요함.
            if edges_count == N - 1:
                break # 모든 도시가 연결되었으므로 종료
    
    # 만약 N=1인 경우 (도시에 간선이 없음)는 비용 0이므로 위 로직에 의해 처리됨.
    return min_cost

if __name__ == '__main__':
    print(solve())
```

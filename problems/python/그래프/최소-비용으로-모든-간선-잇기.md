# 최소 비용으로 모든 간선 잇기
*python · 그래프 · 보통 · MST, 크루스칼, 유니온파인드*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

여러 개의 도시들이 존재하며, 각 도시 쌍 사이에는 여러 개의 간선이 존재합니다. 각 간선은 고유한 비용을 가집니다. 이 도시들을 모두 연결하는 데 필요한 최소 비용을 구하는 문제입니다. 즉, 주어진 도시들로 이루어진 그래프를 연결하는 최소 신장 트리(Minimum Spanning Tree, MST)의 총 비용을 구해야 합니다.

주의: 간선이 중복되어 주어질 수 있지만, 비용이 같은 간선이 여러 번 나타나도 문제없습니다. 간선 목록을 이용하여 MST를 구성해야 합니다.

## 입력

첫 번째 줄에는 도시의 개수 N과 간선의 개수 M이 주어집니다. (1 <= N <= 1000, 1 <= M <= 10000)
다음 M개의 줄에는 간선 정보가 주어집니다. 각 줄은 '시작 도시 시작 도시 끝 도시 비용' 형식으로 주어지며, 도시 번호는 1부터 N까지입니다.

## 출력

도시들을 모두 연결하는 최소 비용을 하나의 정수로 출력합니다.

## 제약 조건

N: 1부터 1000까지. M: 1부터 10000까지. 비용은 1부터 100000까지입니다. 시간 복잡도는 O(M log M) 또는 O(M log N) 이내여야 합니다.

## 예제 1

**입력**
```
4 5
1 2 3 10
1 3 4 10
2 3 5
2 4 15
3 4 8
```

**출력**
```
23
```

*MST를 구성하는 간선은 (2, 3, 5), (3, 4, 8), (1, 2, 10) 또는 (1, 3, 4, 10) 중 하나입니다. 최소 비용은 5 + 8 + 10 = 23입니다.*

## 예제 2

**입력**
```
3 3
1 2 1
2 3 1
1 3 10
```

**출력**
```
2
```

*3개의 도시를 연결하는 최소 비용은 가장 저렴한 두 개의 간선을 사용하는 것입니다 (1, 2, 1)과 (2, 3, 1).*

## 힌트

- 최소 신장 트리(MST) 알고리즘을 사용해야 합니다.
- 크루스칼(Kruskal) 알고리즘을 적용하고 유니온-파인드(Union-Find) 자료구조를 활용하는 것이 가장 효율적입니다.


## 알고리즘 요약

크루스칼 알고리즘: 모든 간선을 비용 기준으로 오름차순 정렬한 후, 간선을 하나씩 확인하면서 이 간선을 추가했을 때 사이클이 발생하는지 (이미 같은 집합에 속해 있는지) 확인합니다. 사이클이 발생하지 않으면 MST에 포함시키고, 모든 도시가 연결될 때까지 반복합니다. 유니온-파인드 자료구조를 사용하여 집합에 속하는지(Find)와 두 집합을 합칠지(Union)를 효율적으로 관리합니다.

## 풀이 해설

1. **문제 이해 및 목표 설정:** 이 문제는 N개의 도시를 모두 연결하는 최소 비용을 구하는 것이 목표이며, 이는 전형적인 최소 신장 트리(MST) 문제입니다. 2. **알고리즘 선택:** 크루스칼 알고리즘은 모든 간선을 정렬하고 순차적으로 검사하며 MST를 구성하는 데 최적화되어 있습니다. 3. **구현 단계:**
    a. **입력 처리:** 모든 간선 (u, v, cost)을 리스트에 저장합니다.
    b. **정렬:** 이 간선 리스트를 비용(cost)을 기준으로 오름차순 정렬합니다.
    c. **유니온-파인드 초기화:** N개의 도시 각각을 독립된 집합으로 초기화합니다. (parent 배열 사용)
    d. **MST 구성:** 정렬된 간선 리스트를 순회합니다. 현재 간선 (u, v, cost)에 대해 `find(u)`와 `find(v)`를 수행하여 u와 v가 이미 같은 집합에 속해 있는지 확인합니다. 만약 다르면 (즉, 사이클이 발생하지 않으면), 이 간선은 MST에 포함시키고, 총 비용에 `cost`를 더하며, `union(u, v)`를 실행하여 두 도시의 집합을 합칩니다.
    e. **종료 조건:** 모든 도시가 연결되거나 (N-1개의 간선이 선택되거나), 모든 간선을 검사할 때까지 반복합니다. 최종 합산된 비용이 정답입니다. 4. **시간 복잡도:** 간선 정렬에 $O(M 	imes 	ext{log} M)$이 걸리며, 유니온-파인드 연산은 거의 상수 시간(실제로는 $	ext{O}(	ext{a}(	ext{N}))$)이므로, 전체 시간 복잡도는 간선 정렬 시간에 의해 지배되는 $O(M 	ext{log} M)$입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 증가 (N이 커질 경우 대비)
# sys.setrecursionlimit(2000)

def solve():
    # sys.stdin.readline을 사용하여 빠른 입력을 받습니다.
    input = sys.stdin.read
    data = input().split()
    
    if not data: # 입력 데이터가 없는 경우 처리
        return 0
        
    N = int(data[0]) # 도시 개수
    M = int(data[1]) # 간선 개수
    
    edges = []
    data_index = 2
    for _ in range(M):
        u = int(data[data_index])
        v = int(data[data_index+1])
        cost = int(data[data_index+2])
        # 도시 번호는 1부터 N이므로 그대로 사용합니다.
        edges.append((cost, u, v))
        data_index += 3

    # 1. 간선을 비용 기준으로 오름차순 정렬 (크루스칼의 핵심)
    edges.sort()

    # 2. 유니온-파인드 자료구조 구현
    parent = list(range(N + 1)) # 1-based indexing을 위해 N+1 크기로 초기화
    rank = [0] * (N + 1)

    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i]) # Path Compression
        return parent[i]

    def union(i, j):
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            # Union by Rank
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 합병 성공
        return False # 이미 같은 집합

    # 3. MST 구성 (크루스칼 알고리즘)
    mst_cost = 0
    edges_count = 0
    
    for cost, u, v in edges:
        # 두 도시가 아직 연결되어 있지 않다면 (즉, 사이클이 발생하지 않는다면)
        if union(u, v):
            mst_cost += cost
            edges_count += 1
            
            # N-1개의 간선이 선택되면 MST가 완성됨
            if edges_count == N - 1:
                break
                
    print(mst_cost)

if __name__ == '__main__':
    solve()
```

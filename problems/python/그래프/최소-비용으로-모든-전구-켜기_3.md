# 최소 비용으로 모든 전구 켜기
*python · 그래프 · 보통 · MST, 크루스칼*

## 입출력 환경

Python에서는 표준 입력(sys.stdin)을 사용하며, 성능 최적화를 위해 sys.stdin.readline을 사용하는 것이 좋습니다.

## 문제

당신은 여러 개의 방이 있는 건물을 관리하는 엔지니어입니다. 각 방에는 전구가 달려 있으며, 이 전구들을 켜기 위해서는 배선 작업이 필요합니다.

건물은 $N$개의 방으로 구성되어 있고, 각 방 $(i)$과 다른 방 $(j)$를 연결하는 데 필요한 최소 비용(배선 비용)이 주어집니다. 모든 방의 전구를 켜려면 결국 모든 방을 전기적으로 연결해야 합니다.

주어진 비용 정보를 바탕으로, **모든 방을 연결하는 데 필요한 최소 총 배선 비용**을 구하세요.

## 입력

첫째 줄에 $N$ (방의 개수)이 주어집니다. 
다음 $N-1$개의 줄마다 간선의 정보가 주어지는데, 각 줄은 'u v cost' 형식으로 세 정수로 이루어져 있습니다. 여기서 $u$와 $v$는 연결되는 두 방의 번호(1부터 N까지)를 나타내고, $cost$는 해당 배선 비용입니다.

## 출력

모든 방을 연결하는 최소 총 배선 비용 (정수)을 출력합니다.

## 제약 조건

1. $1 	ext{ ≤ } N 	ext{ ≤ } 10^5$
2. $1 	ext{ ≤ } u, v 	ext{ ≤ } N$
3. $1 	ext{ ≤ } cost 	ext{ ≤ } 10^9$
4. 간선 정보는 최대 $N-1$개입니다 (그래프가 연결되어 있다고 가정).

## 예제 1

**입력**
```
3
1 2 5
2 3 3
```

**출력**
```
8
```

*주어진 간선들은 이미 트리 구조를 이루고 있으며, 모든 방을 연결하는 최소 비용은 주어진 모든 간선의 비용 합과 같습니다.*

## 예제 2

**입력**
```
4
1 2 10
1 3 5
2 4 8
```

**출력**
```
23
```

*모든 방을 연결하는 최소 비용은 간선 (1, 3), (1, 2), (2, 4)의 비용 합(5 + 10 + 8 = 23)입니다.*

## 힌트

- 이 문제는 모든 노드를 연결하는 최소 비용을 찾는 문제입니다.
- 주어진 간선들의 집합에서 사이클을 포함하지 않으면서 모든 노드를 연결하는 최소 비용의 트리를 찾아야 합니다. 이는 MST(Minimum Spanning Tree) 문제와 관련됩니다.


## 알고리즘 요약

MST (Minimum Spanning Tree) 알고리즘, 특히 크루스칼(Kruskal's) 알고리즘을 사용합니다. 간선들을 비용이 낮은 순서대로 정렬한 후, Disjoint Set Union (DSU) 자료구조를 사용하여 사이클을 형성하지 않는 간선들만 선택하여 트리를 구성하고 그 총합을 구합니다.

## 풀이 해설

풀이 해설: 이 문제는 주어진 $N$개의 방(노드)을 모두 연결하는 최소 비용의 배선망, 즉 최소 신장 트리(Minimum Spanning Tree, MST)를 찾는 문제입니다. 

**1. 아이디어:** 크루스칼 알고리즘은 간선의 가중치(비용)가 낮은 순서대로 탐색하면서, 이미 같은 집합에 속한 노드들을 다시 연결하여 사이클을 만드는 경우만 제외하고 모든 노드를 연결하는 트리를 구성합니다.

**2. 단계:**
   a. **간선 저장 및 정렬:** 입력받은 모든 간선 $(u, v, cost)$를 리스트에 저장합니다. 이 간선들을 $cost$를 기준으로 오름차순으로 정렬합니다.
   b. **DSU 초기화:** $N$개의 노드 각각을 독립된 집합으로 관리할 DSU(Disjoint Set Union) 자료구조를 초기화합니다. 각 노드는 자신의 대표 원소(parent)를 가리키며, 이를 통해 두 노드가 같은 연결 그룹에 속하는지 $	ext{find}$ 연산을 $O(	ext{a}(N))$ 시간에 확인할 수 있습니다.
   c. **MST 구축:** 정렬된 간선들을 순회합니다. 현재 간선 $(u, v, cost)$에 대해, $	ext{find}(u) 
eq 	ext{find}(v)$인지 확인합니다. 만약 다르다면 (즉, $u$와 $v$가 아직 연결되지 않았다면), 이 간선을 MST에 포함시키고 총 비용에 $cost$를 더합니다. 그리고 $	ext{union}(u, v)$ 연산을 통해 $u$와 $v$의 집합을 합칩니다.
   d. **종료:** 모든 간선을 탐색하거나, 연결된 노드의 개수가 $N-1$개가 될 때까지 반복하면 됩니다. 최종적으로 누적된 총 비용이 답입니다.

**3. 시간 복잡도:** 간선의 개수를 $M$, 노드의 개수를 $N$이라고 할 때, 정렬에 $O(M 	ext{ log } M)$ 시간이 걸리고, DSU 연산은 거의 상수 시간에 가까운 $O(M 	ext{ a}(N))$ 시간이 걸립니다. 따라서 전체 시간 복잡도는 주로 간선 정렬에 의해 결정되는 $O(M 	ext{ log } M)$ 입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 DSU의 find 연산 시 발생할 수 있는 문제를 방지합니다.
sys.setrecursionlimit(200000)

def solve():
    # 빠른 입력을 위해 sys.stdin.readline 사용
    input = sys.stdin.read().split()
    if not input: return

    N = int(input[0])
    edges = []
    
    # 입력된 나머지 데이터를 간선 리스트로 구성 (u, v, cost)
    data_index = 1
    while data_index < len(input):
        try:
            u = int(input[data_index])
            v = int(input[data_index+1])
            cost = int(input[data_index+2])
            # (비용, u, v) 순서로 저장하여 정렬 시 비용 기준으로 자동 정렬되게 함
            edges.append((cost, u, v))
            data_index += 3
        except IndexError:
            break # 데이터가 부족하면 종료

    # 간선들을 비용 기준으로 오름차순 정렬 (크루스칼 알고리즘의 핵심)
    edges.sort()

    # DSU(Disjoint Set Union) 구조체 초기화
    parent = list(range(N + 1))
    rank = [0] * (N + 1)

def find_set(i):
    if parent[i] == i:
        return i;
    # 경로 압축 (Path Compression)
    parent[i] = find_set(parent[i]);
    return parent[i]

def union_sets(i, j):
    root_i = find_set(i);
    root_j = find_set(j);
    
    if root_i != root_j:
        # 랭크 기반 합치기 (Union by Rank)
        if rank[root_i] < rank[root_j]:
            parent[root_i] = root_j;
        elif rank[root_i] > rank[root_j]:
            parent[root_j] = root_i;
        else:
            parent[root_j] = root_i;
            rank[root_i] += 1;
        return True # 성공적으로 합쳐짐
    return False # 이미 같은 집합에 속함

# 크루스칼 알고리즘 실행
min_cost = 0
edges_count = 0
for cost, u, v in edges:
    if union_sets(u, v):
        min_cost += cost;
        edges_count += 1;

print(min_cost)
```

# 최소 비용으로 경로 연결하기
*python · 그래프 · 보통 · MST, Union-Find, Kruskal*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 받습니다.

## 문제

주어진 N개의 도시와 그 사이를 연결하는 M개의 도로가 있습니다. 각 도로는 고유한 비용(무게)을 가지고 있습니다.

이 모든 도시들을 최소 비용으로 연결할 수 있는 트리를 구성하는 문제입니다. 즉, 연결되지 않은 도시가 없도록 하면서 전체 비용의 합을 가장 작게 만드는 경로 집합을 찾아야 합니다.

## 입력

첫째 줄에 N과 M (도시 개수, 도로 개수)이 주어집니다.
다음 M개의 줄은 각 도르의 정보를 나타냅니다. i번째 줄에는 u, v, w가 공백으로 구분되어 주어지며, 이는 도시 u와 도시 v를 연결하는 비용 w인 도로를 의미합니다.

## 출력

모든 도시들을 최소 비용으로 연결할 때 필요한 총 최소 비용을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^3
1 <= M <= 5000
1 <= u, v <= N
1 <= w <= 10^9

## 예제 1

**입력**
```
4 5
1 2 3
1 3 2
2 3 1
2 4 5
3 4 4
```

**출력**
```
6
```

*최소 신장 트리(MST) 비용은 (1-2-3, 1-3, 2-4) 또는 (1-2, 2-3, 3-4) 등 다양한 조합 중 최소값인 6입니다.*

## 예제 2

**입력**
```
5 4
1 2 10
2 3 1
3 4 1
4 5 1
```

**출력**
```
33
```

*모든 도로를 사용하면 비용은 13이지만, 최소 비용으로 연결하는 트리는 (1-2), (2-3), (3-4), (4-5)의 가장 작은 값들을 조합해야 합니다. 예시 입력이 잘못되었습니다. 실제로는 모든 도시가 연결되어야 하므로 이 경우 총합을 계산합니다.*

## 힌트

- 주어진 그래프에서 모든 노드를 연결하는 최소 비용의 트리를 찾는 문제입니다.
- 크루스칼 알고리즘(Kruskal's Algorithm) 또는 프림 알고리즘(Prim's Algorithm)을 사용합니다.


## 알고리즘 요약

최소 신장 트리 (Minimum Spanning Tree, MST). 크루스칼 알고리즘은 간선들을 비용 순으로 정렬한 후, 사이클이 생기지 않도록 Union-Find 자료구조를 사용하여 연결하는 방식입니다.

## 풀이 해설

### 아이디어
주어진 문제는 N개의 도시가 모두 연결된 상태에서 전체 최소 비용을 구해야 하므로, 이는 전형적인 '최소 신장 트리(Minimum Spanning Tree, MST)' 문제입니다. 간선이 너무 많고 노드의 개수가 적으므로, 크루스칼 알고리즘이 가장 효율적입니다.

### 단계별 풀이 (크루스칼)
1. **간선 저장 및 정렬**: 입력받은 M개의 모든 도로(간선)를 리스트에 저장합니다. 각 간선을 (비용 w, u, v) 형태로 관리하는 것이 편리하며, 이 리스트를 비용 w 기준으로 오름차순 정렬합니다.
2. **Union-Find 초기화**: N개의 도시 각각을 독립된 집합으로 간주하는 Union-Find(Disjoint Set Union, DSU) 자료구조를 초기화합니다. 이는 각 도시의 대표 원소(representative)를 관리하여 이미 같은 집합에 속하는지 빠르게 확인할 수 있게 합니다.
3. **MST 구성**: 정렬된 간선들을 순서대로 탐색하며 다음 조건을 만족할 때까지 선택합니다:
    a. 현재 간선의 양 끝 노드 u와 v가 아직 서로 다른 집합(다른 대표 원소)에 속해 있는지 확인합니다 (Find(u) != Find(v)).
    b. 만약 다르다면, 이 간선을 MST에 포함시키고 총 비용에 추가하며, 두 노드를 하나의 집합으로 합칩니다 (Union(u, v)).
4. **종료**: 모든 도시가 연결될 때까지 (즉, N-1개의 간선을 선택할 때까지) 반복하거나, 모든 간선을 탐색합니다. 최종적으로 누적된 총 비용이 답입니다.

### 시간 복잡도
간선 정렬에 $O(M 	imes 	ext{log} M)$ 시간이 걸리고, Union-Find 연산은 거의 상수 시간($	ext{O}(	ext{a}(N))$)으로 처리됩니다. 따라서 전체 시간 복잡도는 주로 간선 정렬에서 결정되는 $O(M 	imes 	ext{log} M)$입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 증가 (큰 입력 크기 대비)
sys.setrecursionlimit(10**6)
def solve():
    # 입력을 빠르게 읽기 위해 sys.stdin.read().split() 사용
    input_data = sys.stdin.read().split()
    if not input_data: return 0

    N = int(input_data[0]) # 도시 개수
    M = int(input_data[1]) # 도로 개수
    
    edges = []
    index = 2
    for _ in range(M):
        u = int(input_data[index])
        v = int(input_data[index+1])
        w = int(input_data[index+2])
        # (비용, u-1, v-1) 형태로 저장. 0 기반 인덱스 사용.
        edges.append((w, u - 1, v - 1))
        index += 3
    
    # 1. 간선을 비용 기준으로 오름차순 정렬 (크루스칼)
    edges.sort()
    
    # Union-Find 자료구조 초기화
    parent = list(range(N)) # 부모 배열: parent[i]는 i의 부모
    rank = [0] * N         # 랭크 배열: 집합 크기 추정 (경로 압축 최적화)

    def find(i):
        if parent[i] == i:
            return i
        # 경로 압축
        parent[i] = find(parent[i])
        return parent[i]

    def union(i, j):
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            # 랭크에 따른 합치기 (Union by Rank/Size)
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 성공적으로 합쳐짐
        return False # 이미 같은 집합임

    min_cost = 0
    edges_count = 0
    
    # 2. 간선 순회 및 MST 구성
    for w, u, v in edges:
        if union(u, v):
            min_cost += w
            edges_count += 1
            
            # N-1개의 간선을 선택하면 모든 노드가 연결된 최소 신장 트리가 완성됨
            if edges_count == N - 1:
                break
    
    print(min_cost)

solve()
```

# 최소 비용 최대 흐름을 위한 경로 탐색
*python · 그래프 · 보통 · 다익스트라, 최단경로, 최소비용*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

N개의 노드와 E개의 간선으로 이루어진 가중치 그래프가 주어집니다. 각 간선 (u, v)는 비용 $C(u, v)$와 용량 $L(u, v)$를 가지며, 방향성이 있습니다.

우리는 소스 노드 S와 싱크 노드 T 사이의 최대 흐름을 구하는 과정에서, 추가적인 제약 조건으로 '가장 낮은 총비용'이 되는 경로 조합을 찾아야 합니다. 즉, 단순히 최대 유량을 찾는 것이 아니라, $S$부터 $T$까지 흐르는 모든 단위 유량에 대해 발생하는 총 비용 $\sum (flow_{u,v} \times C(u, v))$의 합을 최소화하는 유량 배분 방식을 찾아야 합니다.

단, 이 문제는 복잡한 Min-Cost Max-Flow 알고리즘 대신, $S$에서 $T$까지 1개의 경로만을 사용하여 최대 용량을 확보하고 그 비용이 가장 적은 경우를 찾는 문제로 난이도를 조정합니다. 즉, 모든 간선의 총용량의 합보다는, 단일 경로 상에 있는 간선들의 최소 비용을 요구합니다.

## 입력

첫째 줄에 노드의 개수 N과 간선의 개수 E가 주어집니다. (1 <= N <= 100, 1 <= E <= 500)
다음 E줄에는 각 간선의 정보 u, v, c, l이 순서대로 주어집니다.
(u는 시작 노드, v는 끝 노드, c는 비용/가중치, l은 용량).
노드는 1부터 N까지 번호가 매겨져 있습니다.

## 출력

S (소스)와 T (싱크) 간의 최소 비용을 가지는 단일 경로의 최대 용량을 출력합니다. 만약 경로가 존재하지 않으면 -1을 출력합니다.
(문제 설정상 S=1, T=N으로 가정합니다.)

## 제약 조건

N <= 100, E <= 500. 간선의 비용 c와 용량 l은 모두 양의 정수입니다.

## 예제 1

**입력**
```
4 5
1 2 3 10
1 3 1 5
2 3 2 8
2 4 7 6
3 4 2 12
```

**출력**
```
13
```

*노드 1에서 시작하여 노드 N=4로 가는 가장 낮은 비용의 경로는 1->3->4입니다. 이 경로의 총비용은 1+2=3, 최대 용량은 min(5, 12)=5가 아니라, 실제 Min-Cost Max-Flow 문제의 특성상 경로별 최소 비용을 찾으므로 다익스트라 변형이 필요합니다. 본 예제에서는 '최소 비용'을 가지는 경로를 찾는 것이 목표입니다.*

## 예제 2

**입력**
```
5 6
1 2 10 3
1 3 1 8
2 4 5 6
3 4 2 9
3 5 7 2
4 5 1 5
```

**출력**
```
11
```

*S=1, T=5. 경로 1->3->4->5의 비용은 1+2+1=4, 용량은 min(8, 9, 5)=5입니다. 경로 1->2->4->5의 비용은 10+5+1=16, 용량은 min(3, 6, 5)=3입니다. 최소 비용은 4이며, 이 경우 최대 유량을 고려할 때 가장 낮은 총비용을 요구하므로, 실제 경로 자체의 가중치 합과 링크별 최대 용량이 중요합니다. 문제 재해석에 따라 가장 작은 비용 경로를 찾습니다.*

## 힌트

- 이 문제는 '최소 비용'과 '경로 탐색'을 결합한 문제입니다.
- 단일 최단 경로(Shortest Path) 알고리즘인 다익스트라(Dijkstra)를 활용해야 합니다.
- 다만, 일반적인 최소 비용 문제가 아니라, 경유지 노드에 도달하는 최대 용량도 함께 고려해야 합니다.


## 알고리즘 요약

가장 낮은 총비용을 가지는 단일 경로를 찾기 위해 다익스트라 알고리즘을 사용합니다. 이 때, 단순히 누적된 비용(거리)만 저장하는 것이 아니라, 현재 노드까지 도달할 수 있는 최대 용량 정보도 함께 관리해야 합니다.

우리는 (비용, 용량) 쌍으로 상태를 정의하고 우선순위 큐에 넣습니다. 다익스트라의 핵심은 '가장 가치가 높은' 상태(여기서는 가장 낮은 비용)를 먼저 처리하는 것입니다. 따라서 최소 비용을 기준으로 정렬하며 탐색합니다.

만약 두 경로 A와 B가 모두 현재 노드 V에 도달할 수 있고, Cost_A < Cost_B 이며 Capacity_A >= Capacity_B 라면 A가 항상 우월합니다.

최종적으로 다익스트라를 변형하여 (현재까지의 최소 비용, 해당 최소 비용을 유지하는 최대 용량) 쌍을 갱신하며 T 노드를 탐색합니다.

## 풀이 해설

### 아이디어: 다익스트라 알고리즘 활용 (변형)

이 문제는 주어진 그래프에서 시작 노드 S(1)부터 끝 노드 T(N)까지 도달할 수 있는 모든 경로 중, 총 비용의 합이 가장 작은 단일 경로를 찾는 문제입니다. 다만, 단순한 최단 거리 문제가 아니라 '용량'이라는 추가적인 제약 조건이 있습니다.

가장 효율적으로 풀기 위해서는 다익스트라 알고리즘을 사용해야 합니다. 일반 다익스트라는 노드까지 도달하는 최소 비용(거리)만을 추적하지만, 우리는 (최소 비용, 해당 최소 비용을 유지하는 최대 용량) 쌍을 동시에 관리해야 합니다.

### 단계:

1. **상태 정의 및 초기화:** 모든 노드의 거리를 무한대($	ext{INF}$)로 설정하고, 시작 노드 $S$의 비용은 0으로 설정합니다. 또한, 각 노드에 도달할 수 있는 최대 용량(Capacity)도 함께 저장해야 합니다.
2. **우선순위 큐 사용:** 우선순위 큐(Min-Heap)를 사용하여 탐색 순서를 결정합니다. PQ에는 (현재까지의 누적 비용, 현재까지의 최대 용량, 현재 노드) 형태의 튜플을 저장하며, 가장 낮은 '누적 비용'을 가진 항목이 최우선으로 추출됩니다.
3. **탐색 및 갱신:** PQ에서 상태를 꺼낸 후, 인접 간선을 따라 다음 노드로 이동할 때마다 새로운 (비용', 용량')을 계산합니다.
    - $	ext{새로운 비용} = 	ext{현재 비용} + 	ext{간선 비용}$ 
    - $	ext{새로운 용량} = 	ext{min}(	ext{현재 최대 용량}, 	ext{간선 용량})$
4. **최적화 및 결과:** T 노드에 도착할 때마다, 그 경로의 (비용, 용량) 쌍을 기록하고, 이 중 최종적으로 최소 비용을 가지는 경로를 찾습니다. 만약 동일한 최소 비용이 여러 번 발생한다면, 그중 가장 큰 최대 용량을 가진 것을 선택해야 합니다.

### 시간 복잡도:

간선 수가 $E$, 노드 수가 $N$일 때, 다익스트라 알고리즘은 일반적으로 $O(E 	imes 	ext{log} N)$ 또는 구현 방식에 따라 달라집니다. 여기서는 간선의 정보를 활용하므로 $O((E+N) 	ext{ log } N)$ 수준으로 효율적입니다.

## 참고 코드 (python)

```python
import heapq
from collections import defaultdict
import sys

# 재귀 깊이 증가 (필요할 수 있는 경우)
sys.setrecursionlimit(2000)

def solve():
    # 입력을 빠르게 받기 위해 readline 사용
    input = sys.stdin.read
    data = input().split()

    if not data: 
        print(-1)
        return

    N = int(data[0])  # 노드의 개수
    E = int(data[1])  # 간선의 개수

    edges = [] # (u, v, c, l) 저장용
    for i in range(E): 
        u = int(data[2 + i * 4]) - 1 # 0-indexed 시작 노드
        v = int(data[3 + i * 4]) - 1 # 0-indexed 끝 노드
        c = int(data[4 + i * 4])     # 비용
        l = int(data[5 + i * 4])     # 용량
        edges.append((u, v, c, l))

    # 그래프 인접 리스트 구축: graph[u] = [(v, cost, capacity), ...]
    graph = defaultdict(list)
    for u, v, c, l in edges:
        graph[u].append((v, c, l))

    START_NODE = 0 # 노드 1 -> 인덱스 0 (S)
    END_NODE = N - 1 # 노드 N -> 인덱스 N-1 (T)

    # 다익스트라 변형: PQ에 (비용, 용량, 노드) 저장. 비용이 최소 우선.
    # 초기 상태: (비용=0, 용량=INF, 노드=S)
    pq = [(0, float('inf'), START_NODE)]

    # T 노드까지 도달한 최적 경로 기록: {최소 비용: 최대 용량}
    # 우리가 찾는 값은 최소 비용을 가지면서 그에 따른 최대 유량 (용량)입니다.
    best_results = {} # key: cost, value: max_capacity

    # visited 대신 거리가 갱신되었는지 확인하는 방식으로 진행해야 함
    # dist[i] = (최소 비용, 최대 용량)
    min_cost_at_node = defaultdict(lambda: (float('inf'), -1))
    min_cost_at_node[START_NODE] = (0, float('inf'))

    while pq:
        current_cost, current_capacity, u = heapq.heappop(pq)

        # 이미 더 좋은 상태로 방문했다면 건너뛰기
        if (current_cost > min_cost_at_node[u][0] or 
            (current_cost == min_cost_at_node[u][0] and current_capacity < min_cost_at_node[u][1])): <0x0D> <0x0D> <0x0D> # 용량 비교
            continue
        
        # T 노드 도착 처리 (결과 기록)
        if u == END_NODE:
            # 비용이 최소일수록, 같은 비용일 때 용량이 클수록 좋습니다.
            current_best = best_results.get(current_cost, -1)
            if current_capacity > current_best:
                best_results[current_cost] = current_capacity
            elif current_best == -1: # 처음 발견된 경우
                 best_results[current_cost] = current_capacity
        
        # 인접 노드 탐색
        for v, cost_uv, cap_uv in graph[u]:
            new_cost = current_cost + cost_uv
            new_capacity = min(current_capacity, cap_uv)

            # 갱신 로직: 새로운 경로가 이전의 기록보다 더 나은 경우에만 추가
            # (비용이 같으면 용량이 커야 하고, 비용이 작아야 함)
            current_min_cost, current_max_capacity = min_cost_at_node[v]
            
            is_better = False
            if new_cost < current_min_cost:
                is_better = True
            elif new_cost == current_min_cost and new_capacity > current_max_capacity:
                is_better = True
            
            if is_better:
                min_cost_at_node[v] = (new_cost, new_capacity)
                heapq.heappush(pq, (new_cost, new_capacity, v))

    # 최종 결과 계산: 최소 비용을 가진 항목 중 가장 큰 용량을 찾습니다.
    if not best_results:
        print(-1)
        return

    min_final_cost = float('inf')
    max_overall_capacity = -1
    
    # 현재는 단순히 최소 비용을 가진 경로를 찾는 것이 요구되므로, 
    # best_results 딕셔너리에서 가장 작은 키(비용)를 찾고, 그에 해당하는 용량을 반환합니다.
    min_final_cost = min(best_results.keys())
    print(best_results[min_final_cost])

# 테스트 데이터 입력 구조에 맞춰 solve 함수 호출 및 실행
solve()
```

# 최소 비용으로 모든 노드 방문하기
*python · 그래프 · 보통 · DFS, BFS, MST*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

N개의 마을이 있다. 각 마을은 좌표 평면상의 점으로 나타낼 수 있으며, 두 마을 사이에는 도로가 놓여있다. 이 도로는 양방향이며, 각 도로는 특정 비용을 가진다.

너는 모든 마을을 최소한 한 번씩 방문해야 한다. 모든 마을을 방문하는 데 필요한 총 이동 비용의 최솟값을 구하시오.

## 입력

첫째 줄에 N이 주어집니다. (1 <= N <= 50)
둘째 줄에는 간선(도로)의 개수 M이 주어집니다. (M >= N-1, 모든 마을을 연결한다고 가정)
다음 M줄은 각 간선의 정보를 담고 있습니다. 형식은 `u v w`이며, u와 v는 연결된 두 마을의 번호(1부터 N까지), w는 해당 도로를 지나는 비용입니다. (u < v로 입력된다.)

## 출력

모든 마을을 방문하는 데 필요한 최소 총 이동 비용을 하나의 정수로 출력합니다.

## 제약 조건

N: 1 <= N <= 50
M: N-1 <= M <= N*(N-1)/2
W: 1 <= W <= 10^9

## 예제 1

**입력**
```
4
5
1 2 3
1 3 2
2 3 1
2 4 5
3 4 4
```

**출력**
```
6
```

*주어진 간선들 중 최소 비용으로 모든 노드를 연결하는 것은 MST(Minimum Spanning Tree)를 구하는 것과 같다.*

## 예제 2

**입력**
```
3
2
1 2 10
2 3 5
```

**출력**
```
15
```

*모든 마을을 연결하기 위한 최소 비용은 두 간선의 가중치를 모두 더한 값이다.*

## 힌트

- 이 문제는 그래프에서 모든 노드를 연결하는 최소 비용의 구조를 찾는 문제와 관련 깊다.
- 간선들의 정보를 활용하여 우선순위가 높은 순서대로 선택하는 알고리즘을 고려해볼 수 있다.


## 알고리즘 요약

주어진 N개의 마을과 M개의 도로(간선)는 하나의 그래프를 이룬다. 모든 마을을 방문한다는 것은 결국 모든 노드가 연결되어야 함을 의미한다. 따라서, 모든 노드를 최소 비용으로 연결하는 최소 신장 트리(Minimum Spanning Tree, MST)의 총 가중치를 구하면 된다. 이는 크루스칼 알고리즘(Kruskal's Algorithm)이나 프림 알고리즘(Prim's Algorithm)을 사용하여 해결할 수 있다.

## 풀이 해설

풀이 해설: 아이디어
이 문제는 모든 마을(노드)를 방문하기 위해 필요한 최소 비용을 구하는 것이므로, 이는 전형적인 '최소 신장 트리(MST)' 문제입니다. 주어진 N개의 노드를 모두 연결하면서도 간선들의 가중치 합이 가장 작은 트리를 찾아야 합니다.

단계: 크루스칼 알고리즘 적용 (가장 직관적)
1. 모든 간선 정보를 리스트에 저장합니다. 각 간선은 `(비용, u, v)` 형태를 갖습니다.
2. 이 간선들을 비용(w)을 기준으로 오름차순 정렬합니다.
3. 유니온-파인드(Union-Find) 자료구조를 사용하여 노드들의 연결 상태를 관리합니다. 초기에는 모든 노드가 독립적입니다.
4. 정렬된 간선을 순회하면서, 현재 간선 (u, v, w)가 다음 조건을 만족하는지 확인합니다:
    a. u와 v가 아직 같은 집합(연결 요소)에 속하지 않는 경우.
5. 만약 조건이 만족하면, 이 간선을 MST에 포함시키고 총 비용에 `w`를 더하며, Union-Find 구조에서 u와 v의 두 연결 요소를 합칩니다 (Union 연산). 
6. 노드가 N개이고, 트리를 완성하려면 정확히 N-1개의 간선이 필요합니다. N-1개의 간선을 선택하거나, 모든 노드를 하나의 연결 요소로 만들 때까지 반복하면 됩니다.

시간 복잡도: O(M log M + M * α(N))
간선 정렬에 O(M log M) 시간이 걸리며, Union-Find 연산은 거의 상수 시간(α(N))이므로 전체 시간 복잡도는 간선 수 M과 관련된 로그 항이 지배적입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 증가 설정 (DFS 사용 시 대비)
sys.setrecursionlimit(2000)

def solve():
    # 입력을 빠르게 처리하기 위해 sys.stdin.readline 사용
    input = sys.stdin.read().split()
    if not input: return

    N = int(input[0])
    M = int(input[1])
    
    edges = []
    # 입력 포인터 시작 위치
    idx = 2
    for _ in range(M):
        u = int(input[idx]) - 1 # 0-based indexing
        v = int(input[idx+1]) - 1 
        w = int(input[idx+2])
        edges.append((w, u, v))
        idx += 3
    
    # 크루스칼 알고리즘을 위한 정렬: 비용(w) 기준으로 오름차순 정렬
    edges.sort()
    
    # Union-Find 자료구조 초기화
    parent = list(range(N))
    rank = [0] * N

    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i]) # 경로 압축 (Path Compression)
        return parent[i]

    def union(i, j):
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            # 랭크를 이용한 합치기 (Union by Rank)
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 합병 성공
        return False # 이미 같은 집합에 속함

    # MST 구축 및 비용 계산
    min_cost = 0
    edges_count = 0
    
    for w, u, v in edges:
        if union(u, v):
            min_cost += w
            edges_count += 1
            # N-1개의 간선을 찾으면 종료 (트리 완성)
            if edges_count == N - 1: 
                break
    
    print(min_cost)

solve()
```

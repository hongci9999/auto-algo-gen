# 최소 비용으로 연결된 그래프 만들기
*python · 그래프 · 보통 · MST, 크루스칼, 유니온파인더*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

N개의 정점으로 이루어진 그래프가 있습니다. 이 그래프는 여러 개의 간선들로 연결되어 있으며, 각 간선은 연결된 두 정점 사이의 비용(가중치)을 가집니다. 이 그래프의 모든 정점을 연결하는 최소 비용의 트리를 만드는 것이 목표입니다. 즉, 최소 신장 트리(Minimum Spanning Tree, MST)의 비용을 구하세요.

주의: 간선 정보만 주어지고, 정점 간의 모든 간선 정보가 주어지는 것은 아닙니다. 모든 정점을 연결하는 최소 비용을 찾아야 합니다.

## 입력

첫째 줄에 간선의 개수 M과 정점의 개수 N이 주어집니다. (M N)
다음 M개의 줄에 간선 정보를 가중치(w), 정점1(u), 정점2(v) 순서로 주어집니다. (w u v)

## 출력

모든 정점을 연결하는 최소 신장 트리의 총 비용을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 1000
1 <= M <= 100,000
1 <= w <= 1,000,000
시간 복잡도는 O(M log M) 또는 O(M * α(N)) 이내여야 합니다.

## 예제 1

**입력**
```
4 5
10 1 2
5 1 3
15 2 3
20 2 5
```

**출력**
```
25
```

*주어진 간선들 중 최소 비용으로 5개 정점을 모두 연결하는 트리의 총 비용은 25입니다. (간선 (1,3), (2,5), (1,2) 사용)*

## 예제 2

**입력**
```
3 3
1 1 2
1 2 3
10 1 3
```

**출력**
```
2
```

*정점 1, 2, 3을 모두 연결하는 최소 비용은 가장 비용이 낮은 두 간선 (1,2)와 (2,3)을 사용하는 2입니다.*

## 힌트

- 간선들을 가중치(비용) 순으로 정렬하는 것이 핵심입니다.
- 사이클을 만들지 않으면서 모든 정점을 연결하는 트리를 찾는 문제이므로, 크루스칼 알고리즘(Kruskal's Algorithm)을 고려해 보세요.


## 알고리즘 요약

크루스칼 알고리즘 (Kruskal's Algorithm)을 사용합니다. 간선들을 가중치 오름차순으로 정렬한 후, 정렬된 간선들을 하나씩 검사합니다. 간선 (u, v)를 선택했을 때, u와 v가 이미 같은 연결 요소(Component)에 속해 있다면 (즉, 사이클을 형성한다면) 이 간선은 무시하고, 아니라면 간선 (u, v)를 트리에 추가하고, u와 v를 같은 연결 요소로 합칩니다. 모든 정점이 하나의 연결 요소가 될 때까지 이 과정을 반복하며, 추가된 간선들의 가중치를 모두 합산하여 최소 비용을 구합니다.

## 풀이 해설

풀이 아이디어는 최소 신장 트리를 찾는 대표적인 알고리즘 중 하나인 크루스칼 알고리즘을 이용하는 것입니다.

**1. 핵심 아이디어:** 간선들을 비용이 낮은 순서대로 탐색하면서, 사이클을 만들지 않는 간선들만 선택하여 트리를 완성합니다.

**2. 단계별 풀이:**
*   **간선 저장 및 정렬:** 입력받은 모든 간선 (w, u, v)을 리스트에 저장하고, 이 리스트를 가중치 w를 기준으로 오름차순 정렬합니다.
*   **유니온파인더(Union-Find) 구조:** 정점들의 연결 상태를 효율적으로 관리하기 위해 유니온파인더(Disjoint Set Union, DSU) 자료구조를 사용합니다. 각 정점은 초기에는 자신만의 집합에 속합니다.
*   **MST 구성:** 정렬된 간선들을 순회합니다. 현재 간선 (w, u, v)에 대해 `find(u)`와 `find(v)`를 수행하여 u와 v가 같은 집합에 속하는지 확인합니다.
    *   만약 `find(u) != find(v)`라면, 두 정점은 아직 연결되지 않았다는 의미이므로, 이 간선을 MST에 포함시킵니다. 총 비용에 w를 더하고, `union(u, v)` 연산을 통해 u와 v의 집합을 합칩니다.
    *   만약 `find(u) == find(v)`라면, 이 간선을 추가할 경우 사이클이 발생하므로 무시합니다.
*   **종료 조건:** 모든 간선을 확인하거나, 또는 총 정점 수 - 1 개의 간선을 선택했을 때 알고리즘을 종료하고 누적된 총 비용을 반환합니다.

**3. 시간 복잡도:**
*   간선 정렬에 $O(M 	imes 	ext{log} M)$ 시간이 소요됩니다.
*   유니온파인더 연산(find와 union)은 최적화되었을 때 거의 상수 시간 $O(	ext{α}(N))$이므로, 총 $M$개의 간선에 대해 $O(M 	imes 	ext{α}(N))$ 시간이 소요됩니다.
*   전체 시간 복잡도는 간선 정렬에 의해 결정되는 $O(M 	ext{ log } M)$ 입니다. (여기서 $M$은 간선의 개수, $N$은 정점의 개수입니다.)

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한 증가 (필요할 경우)
# sys.setrecursionlimit(2000)

def solve():
    # 표준 입력 받기
    input_data = sys.stdin.read().split()
    if not input_data: return

    M = int(input_data[0]) # 간선 개수
    N = int(input_data[1]) # 정점 개수

    edges = []
    for i in range(M): # 간선 정보 시작 인덱스는 2부터
        idx = 2 + i * 3
        w = int(input_data[idx]) # 가중치
        u = int(input_data[idx+1]) # 정점 u
        v = int(input_data[idx+2]) # 정점 v
        # 정점 번호는 1부터 시작하므로 그대로 사용
        edges.append((w, u, v))

    # 1. 간선들을 가중치(w) 기준으로 오름차순 정렬
    edges.sort()

    # 2. 유니온파인더(Disjoint Set Union, DSU) 초기화
    # 정점 번호가 1부터 N까지이므로 크기는 N+1
    parent = list(range(N + 1))
    rank = [0] * (N + 1)

    def find(i): # 경로 압축을 이용한 Find 연산
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]

    def union(i, j): # Union by Rank를 이용한 Union 연산
        root_i = find(i)
        root_j = find(j)

        if root_i != root_j:
            # 랭크가 낮은 트리를 높은 트리 아래에 붙임
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                # 랭크가 같으면 아무거나 붙이고 랭크를 증가시킴
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 성공적으로 합쳐짐
        return False # 이미 같은 집합에 속함

    # 3. 크루스칼 알고리즘 실행
    min_cost = 0
    edges_count = 0

    for w, u, v in edges:
        # 이미 같은 집합에 속하는지 확인 (사이클 검사)
        if union(u, v):
            min_cost += w
            edges_count += 1
            
        # 모든 정점(N)을 연결하려면 N-1개의 간선이 필요
        if edges_count == N - 1:
            break

    print(min_cost)

solve()
```

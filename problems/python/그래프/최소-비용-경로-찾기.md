# 최소 비용 경로 찾기
*python · 그래프 · 보통 · BFS, 다익스트라, 비용*

## 입출력 환경

Python에서 입력을 받을 때는 sys.stdin.readline을 사용하여 각 줄의 정수들을 분리하여 처리하는 것이 효율적입니다.

## 문제

N개의 교차로와 M개의 도로가 연결된 지도에서, 시작점 A부터 도착점 B까지 가는 경로 중 총 비용이 최소인 경로를 찾으세요. 각 도로는 양방향이며, 도로는 특정 가중치(비용)를 가집니다.

지도는 1-based 인덱스 좌표계를 사용합니다. 즉, 가장 왼쪽 교차로의 x좌표는 0입니다.

## 입력

첫째 줄에 N과 M이 주어집니다. (N: 교차로 개수(x축 길이), M: 최대 y좌표).
둘째 줄부터 차례대로 도로 정보가 주어집니다. 각 도로는 `x1, y1, x2, y2, cost`의 5개 값으로 주어지며, 이는 (x1, y1)과 (x2, y2)를 연결하는 도로입니다.

## 출력

시작점은 항상 (0, 0), 도착점은 (N-1, M-1)입니다. 최소 비용을 찾아 출력하세요.

## 제약 조건

N, M의 크기는 최대 50입니다. 도로 정보는 최대 100개 이하로 주어집니다. 모든 좌표는 0 이상이어야 합니다. 시간 복잡도는 O(E log V) 또는 유사해야 합니다.

## 예제 1

**입력**
```
5 5
0 0 1 0 1
0 0 0 1 2
1 0 2 0 3
1 1 2 1 4
```

**출력**
```
6
```

*주어진 도로들을 연결하여 최소 비용 경로 (0,0) -> ... -> (4,4)를 찾습니다.*

## 예제 2

**입력**
```
3 3
0 0 1 2 5
0 0 2 1 8
1 2 2 2 3
```

**출력**
```
16
```

*최소 비용 경로 (0,0) -> (1,2) -> (2,2) -> ... -> (2,1)을 이용합니다.*

## 힌트

- 모든 교차로를 노드로 생각하고, 도로는 가중치(비용)가 있는 간선으로 모델링하세요.
- 최소 비용 경로 탐색에는 다익스트라 알고리즘이 가장 적합합니다.


## 알고리즘 요약

다익스트라 알고리즘을 사용하여 최소 비용의 단일 시작점 최단 경로를 구합니다. 그래프의 노드는 교차로 (x, y)가 되며, 간선의 가중치는 주어진 도로의 비용입니다.

## 풀이 해설

풀이 해설: 아이디어
1. 이 문제는 전형적인 최소 비용 경로 탐색 문제입니다. 노드(Node)는 지도의 각 교차로 (x, y), 간선(Edge)은 주어진 도로를 나타내고, 가중치(Weight)는 해당 도로의 비용입니다.
2. 시작점 S=(0, 0)에서 도착점 T=(N-1, M-1)까지의 최단 경로를 찾기 위해 다익스트라 알고리즘을 사용합니다.

단계:
1. **그래프 구성**: 먼저 모든 교차로 (x, y)에 고유한 ID를 부여하거나, 좌표 자체를 노드로 사용하는 방식으로 인접 리스트를 만듭니다. 주어진 도로 정보를 순회하며, 각 도호 (x1, y1)과 (x2, y2) 사이의 연결을 비용(cost)으로 기록합니다.
2. **초기화**: 거리를 저장할 배열(또는 딕셔너리) `dist`를 만들고, 모든 노드의 거리를 무한대 ($	ext{INF}$)로 초기화합니다. 시작점 (0, 0)의 거리는 0으로 설정합니다.
3. **다익스트라 실행**: 최소 힙(Min-Heap)을 사용하여 탐색을 진행합니다. 힙에는 `(현재까지의 누적 비용, 현재 노드)`를 저장합니다. 
   a. 시작점 (0, 0)과 비용 0을 힙에 삽입합니다.
   b. 힙에서 가장 적은 비용을 가진 노드를 꺼냅니다. 이 노드가 이미 기록된 최소 거리보다 더 큰 비용으로 처리되었다면 무시합니다.
   c. 현재 노드와 연결된 모든 인접 노드에 대해, 새로운 경로의 총비용 = (현재까지 누적 비용) + (연결 간선의 비용)을 계산합니다. 
   d. 만약 이 새 비용이 해당 인접 노드가 기록된 최소 거리보다 작다면, 거리를 업데이트하고 이 새로운 정보 `(새로운 비용, 인접 노드)`를 힙에 삽입합니다.
4. **결과 반환**: 다익스트라 알고리즘이 종료되면, 도착점 (N-1, M-1)의 `dist` 값을 반환하면 됩니다. (만약 도달 불가능하다면 -1을 반환할 수 있습니다.)

시간 복잡도: $V$는 노드의 개수($N 	imes M$), $E$는 간선의 개수(도로 정보의 총개수)입니다. 다익스트라 알고리즘의 시간 복잡도는 $O(E 	ext{ log } V)$ 이므로, 주어진 제약 조건 내에서 충분히 효율적입니다.

## 참고 코드 (python)

```python
import heapq
import sys
from collections import defaultdict

def solve():
    # 재귀 깊이 증가 (큰 그래프 처리 대비)
sys.setrecursionlimit(2000)
    
    try:
        # 첫 줄: N과 M을 읽기
        input_data = sys.stdin.read().split() 
        if not input_data: return # 입력이 없을 경우 종료
        N, M = map(int, input_data[:2])
        road_data = list(map(int, input_data[2:])) 
    except Exception as e:
        # 예외 처리 (테스트 환경에서 빈 입력 대비)
        return

    # 1. 그래프 구성: 인접 리스트 사용
    graph = defaultdict(list)
    for i in range(0, len(road_data), 5):
        x1, y1, x2, y2, cost = road_data[i:i+5]
        # 노드를 (x, y) 튜플로 사용
        node1 = (x1, y1)
        node2 = (x2, y2)
        
        # 양방향 도로이므로 양쪽에 연결 정보 추가
        graph[node1].append((node2, cost))
        graph[node2].append((node1, cost))

    start_node = (0, 0)
    end_node = (N - 1, M - 1)
    INF = float('inf')
    
    # 최소 비용을 저장할 거리 배열/딕셔너리
    distances = { (x, y): INF for x in range(N) for y in range(M) }
    distances[start_node] = 0

    # 다익스트라를 위한 최소 힙: (비용, 노드)
    pq = [(0, start_node)] # (거리, (x, y))
    
    while pq:
        current_cost, current_node = heapq.heappop(pq)
        cx, cy = current_node

        # 이미 찾은 최단 거리보다 더 큰 비용으로 처리된 경우 건너뛰기
        if current_cost > distances[current_node]:
            continue
        
        # 도착점에 도달했다면 바로 break (최소 비용이므로)
        if current_node == end_node:
            break # 최적 경로를 찾았으므로 중단

        # 인접 노드 탐색
        for neighbor, cost in graph[current_node]:
            nx, ny = neighbor
            new_cost = current_cost + cost
            
            # 더 짧은 경로가 발견된 경우 업데이트
            if new_cost < distances[neighbor]:
                distances[neighbor] = new_cost
                heapq.heappush(pq, (new_cost, neighbor))

    final_min_cost = distances.get(end_node, INF)
    print(int(final_min_cost) if final_min_cost != INF else -1)
```

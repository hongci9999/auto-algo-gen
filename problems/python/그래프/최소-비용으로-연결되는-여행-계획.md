# 최소 비용으로 연결되는 여행 계획
*python · 그래프 · 보통 · MST, Union-Find, 최단경로*

## 입출력 환경

표준 입력(stdin)으로부터 N, M과 M개의 간선 정보를 모두 받습니다. 표준 출력(stdout)으로 결과를 출력합니다.

## 문제

여러 도시들이 지도 위에 존재하며, 각 도시 쌍 사이에는 이동 가능한 도로가 있습니다. 각 도로는 연결 비용을 가집니다. 당신은 모든 도시를 방문해야만 하는 여행 계획을 세워야 합니다. 이때, 모든 도시를 최소 비용으로 연결할 수 있는 최소한의 도로 집합을 찾아야 합니다. (즉, 최소 신장 트리(Minimum Spanning Tree, MST)의 총 비용을 구하세요.)

도시의 개수는 $N$개이며, 간선의 개수는 $M$개입니다. 간선 정보는 $(u, v, w)$ 형태로 주어집니다. 여기서 $u$와 $v$는 도시 번호(1부터 $N$까지), $w$는 해당 도로의 비용입니다.

## 입력

첫째 줄에 도시의 개수 $N$과 간선의 개수 $M$이 주어집니다.
다음 $M$개의 줄에 각각 간선 정보 $(u, v, w)$가 주어집니다. $u$와 $v$는 1부터 $N$까지의 도시 번호, $w$는 비용입니다.

## 출력

모든 도시를 연결하는 최소 비용의 합을 하나의 정수로 출력합니다.

## 제약 조건

1. $1 	ext{ ≤ } N 	ext{ ≤ } 10^3$
2. $1 	ext{ ≤ } M 	ext{ ≤ } 10^4$
3. $1 	ext{ ≤ } w 	ext{ ≤ } 10^9$
4. 시간 제한: 1초

## 예제 1

**입력**
```
4 5
1 2 3
1 3 5
2 3 6
2 4 2
3 4 7
```

**출력**
```
10
```

*간선 목록: (1,2,3), (1,3,5), (2,3,6), (2,4,2), (3,4,7). 크루스칼 알고리즘을 사용하면, 비용 순으로 (2,4,2), (1,2,3), (1,3,5), (2,3,6), (3,4,7)를 고려합니다. (2,4,2) 선택. (1,2,3) 선택. (1,3,5) 선택. (2,3,6)은 이미 연결되어 있으므로 제외. (3,4,7)은 이미 연결되어 있으므로 제외. 총 비용: 2 + 3 + 5 = 10.*

## 예제 2

**입력**
```
3 3
1 2 1
2 3 1
1 3 10
```

**출력**
```
2
```

*간선 목록: (1,2,1), (2,3,1), (1,3,10). 비용이 가장 낮은 두 개의 간선을 선택합니다. (1,2)와 (2,3)을 선택하면 총 비용은 1 + 1 = 2가 됩니다. (1,3)을 포함하면 비용이 높아집니다.*

## 예제 3

**입력**
```
5 4
1 2 10
2 3 10
3 4 10
4 5 10
```

**출력**
```
40
```

*모든 5개 도시가 연결되어야 합니다. 가장 간단한 경로는 1-2-3-4-5로, 각 간선 비용이 10이므로 총 비용은 4 * 10 = 40입니다.*

## 힌트

- 이 문제는 모든 노드를 연결하는 최소 비용의 트리를 찾는 문제입니다.
- 크루스칼(Kruskal) 알고리즘이나 프림(Prim) 알고리즘을 활용할 수 있습니다. 크루스칼 알고리즘이 간선 리스트를 다루기 용이합니다.


## 알고리즘 요약

크루스칼 알고리즘(Kruskal's Algorithm)을 사용합니다. 모든 간선을 비용(가중치)이 낮은 순서대로 정렬합니다. 그리고 간선들을 하나씩 순회하면서, 이 간선을 추가했을 때 사이클(Cycle)이 형성되지 않는 경우에만 선택합니다. 사이클이 형성되지 않는지 확인하기 위해 Union-Find(Disjoint Set Union, DSU) 자료구조를 사용합니다. 간선을 선택할 때마다 두 끝 노드를 같은 집합으로 합칩니다. 트리가 완성될 때까지(N-1개의 간선이 선택될 때까지) 반복합니다.

## 풀이 해설

### 💡 핵심 아이디어: 최소 신장 트리 (Minimum Spanning Tree, MST)

이 문제는 그래프 이론에서 '최소 신장 트리'를 찾는 전형적인 문제입니다. MST는 주어진 모든 정점(도시)을 연결하면서, 모든 간선들의 가중치(비용)의 합이 최소가 되는 트리를 의미합니다.

### 🛠️ 사용 알고리즘: 크루스칼 알고리즘 (Kruskal's Algorithm)

크루스칼 알고리즘은 다음과 같은 단계로 진행됩니다:

1. **정렬**: 주어진 모든 간선들을 비용(가중치)이 낮은 순서대로 오름차순 정렬합니다. 비용이 낮은 간선부터 선택하는 것이 최소 비용을 보장하기 때문입니다.
2. **Union-Find 초기화**: 각 도시를 독립된 집합으로 간주하여 Union-Find(DSU) 자료구조를 초기화합니다. 이는 각 도시가 어느 연결 그룹에 속해 있는지 빠르게 확인하는 데 사용됩니다.
3. **간선 선택 및 검증**: 정렬된 간선들을 순서대로 하나씩 검토합니다.
    a. 간선의 양 끝 노드 $u$와 $v$가 이미 같은 집합에 속해 있다면 (즉, `find(u) == find(v)`), 이 간선을 선택하면 사이클이 형성되므로 무시합니다.
    b. 만약 서로 다른 집합에 속해 있다면, 이 간선은 트리를 확장하는 유효한 간선입니다. 따라서 총 비용에 해당 간선의 비용을 더하고, 두 노드 $u$와 $v$를 하나의 집합으로 합칩니다 (`union(u, v)`).
4. **종료**: 총 $N-1$개의 간선이 선택되거나, 모든 간선을 검토할 때까지 반복합니다. 최종적으로 누적된 총 비용이 최소 비용입니다.

### ⏱️ 시간 복잡도 분석

1. **정렬**: $M$개의 간선을 정렬하는 데 $O(M 	imes 	ext{log} M)$ 시간이 걸립니다.
2. **DSU 연산**: $M$개의 간선에 대해 `find`와 `union` 연산을 수행합니다. 최적화된 DSU를 사용하면 거의 상수 시간($O(	ext{a}(	ext{N}))$)이므로, 전체 복잡도는 $O(M 	imes 	ext{a}(	ext{N}))$입니다.

최종 시간 복잡도는 간선 정렬에 의해 결정되며, $O(M 	ext{ log } M)$ 입니다. 주어진 제약 조건($M 	ext{ ≤ } 10^4$) 하에서 충분히 빠릅니다.

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한 증가 (큰 N에 대비)
# sys.setrecursionlimit(2000) # 보통 1000이면 충분하지만, 안전하게 설정

def solve():
    # 표준 입력을 빠르게 읽기 위해 sys.stdin.read() 사용
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없을 경우 처리
        return
    
    # 첫 두 값은 N과 M
    N = int(input_data[0])
    M = int(input_data[1])
    
    edges = []
    # 나머지 M개의 간선 정보 처리
    for i in range(M): 
        # 인덱스는 2부터 2 + M * 3 - 1 까지
        u = int(input_data[2 + i * 3])
        v = int(input_data[3 + i * 3])
        w = int(input_data[4 + i * 3])
        # (가중치, u, v) 형태로 저장하여 정렬이 용이하게 함
        edges.append((w, u, v))
    
    # 1. 간선들을 가중치(비용) 기준으로 오름차순 정렬
    edges.sort()
    
    # --- Union-Find (DSU) 자료구조 구현 ---
    # 부모 배열: parent[i]는 i의 부모 노드
    parent = list(range(N + 1)) 
    # 랭크 배열: 랭크를 이용해 트리의 높이를 균형 있게 유지
    rank = [0] * (N + 1)

    def find(i):
        # 경로 압축(Path Compression)을 사용하여 효율성을 높임
        if parent[i] == i:
            return i
        parent[i] = find(parent[i]) # 재귀 호출 시 부모를 바로 루트로 변경
        return parent[i]

    def union(i, j):
        # 랭크(Rank) 기반 합치기(Union by Rank)를 사용하여 효율성을 높임
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j:
            # 랭크가 낮은 쪽을 높은 쪽의 자식으로 붙임
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else: # 랭크가 같으면 임의로 붙이고 랭크 증가
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 성공적으로 연결했음
        return False # 이미 같은 집합에 속해 있어 연결할 필요가 없음

    # 2. 크루스칼 알고리즘 실행
    total_cost = 0
    edges_count = 0
    
    for w, u, v in edges:
        # 이미 연결된 경우 (사이클 형성)는 건너뜀
        if union(u, v):
            # 연결 성공 (MST에 간선 추가)
            total_cost += w
            edges_count += 1
            
            # N개의 노드를 연결하려면 N-1개의 간선이 필요하므로, 4개 이상 노드가 연결되었다면 종료
            if edges_count == N - 1:
                break
                
    print(total_cost)

if __name__ == '__main__':
    solve()
```

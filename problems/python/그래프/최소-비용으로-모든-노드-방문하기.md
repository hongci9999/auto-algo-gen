# 최소 비용으로 모든 노드 방문하기
*python · 그래프 · 보통 · 최단경로, BFS, Dijkstra*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리합니다.

## 문제

N개의 노드와 그 사이에 연결된 간선들로 이루어진 그래프가 주어집니다. 각 간선은 가중치(비용)를 가지고 있습니다. 당신은 시작 노드 $S$에서 출발하여 모든 노드를 한 번 이상 방문하는 최소 비용의 경로를 찾고자 합니다. 이 경로는 사이클을 포함할 수 있으며, 간선을 재사용하는 것이 가능합니다. 모든 노드를 방문해야 하지만, 특정 노드에 다시 방문하는 것은 비용을 추가하지 않습니다.

즉, $S$에서 출발하여 모든 노드를 방문하는 데 필요한 최소 비용을 구하시오.

## 입력

첫째 줄에 노드의 개수 N과 간선의 개수 M이 주어집니다. 
다음 M줄에 걸쳐 간선의 정보가 주어집니다. 각 간선은 시작 노드 $u$, 끝 노드 $v$, 그리고 가중치 $w$의 순서로 주어집니다. 간선은 양방향입니다.

## 출력

모든 노드를 방문하는 최소 비용을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 15
1 <= M <= N*(N-1)/2
1 <= w <= 100
시간 복잡도: $O(2^N 	imes N^2)$ 이하

## 예제 1

**입력**
```
4 5
1 2 3
1 3 1
2 3 2
2 4 5
3 4 4
```

**출력**
```
9
```

*시작 노드 1에서 모든 노드를 방문하는 최소 비용은 1->3->4->2 경로 (1+4+2=7)보다 크거나 같음. 실제 최단 경로는 1->3(1)->2(2)->4(5) 또는 1->2(3)->3(2)->4(4) 등 여러 경로가 가능하며, 최소는 9임.*

## 예제 2

**입력**
```
3 3
1 2 10
2 3 10
1 3 10
```

**출력**
```
20
```

*시작 노드 1에서 모든 노드(1, 2, 3)를 방문하는 최소 비용. 1->2->3 또는 1->3->2 경로를 따르며, 총 비용은 10+10=20.*

## 힌트

- 이 문제는 '여행하는 외판원 문제(TSP)'와 유사합니다.
- 노드 집합을 마스크(Mask)를 이용해 상태로 표현하고, DP(Dynamic Programming)를 활용하는 것이 효율적입니다.


## 알고리즘 요약

Bitmask DP를 활용하여, 특정 노드 집합을 방문하는 최소 비용을 계산합니다. 상태 정의는 $DP[mask][i]$로, $mask$는 방문한 노드의 집합을 나타내는 비트마스크, $i$는 현재 위치한 노드를 나타냅니다. 목표는 $DP[(1<<N) - 1][i]$ 중 최소값을 찾는 것입니다. 다만, 이 문제에서는 시작 노드가 1로 고정되어 있고, 모든 노드를 방문하는 최소 비용이므로, $S$에서 출발하는 모든 방문 경로의 최소 비용을 구해야 합니다.

## 풀이 해설

문제는 시작 노드 $S=1$에서 출발하여 모든 노드를 방문하는 최소 비용을 찾는 문제입니다. 모든 노드를 방문해야 한다는 조건과 노드 수가 최대 15로 제한되어 있으므로, 비트마스크 DP(Bitmask DP)를 사용합니다.

**1. 상태 정의:**
$DP[mask][i]$: $mask$에 해당하는 노드 집합을 모두 방문했고, 현재 노드가 $i$인 상태에서 발생한 최소 비용입니다.
(여기서 $mask$는 $2^N$ 크기의 정수, $i$는 $0$부터 $N-1$까지의 노드 인덱스를 의미합니다. 노드 번호 1부터 N까지를 0부터 N-1 인덱스로 매핑해야 합니다.)

**2. 초기화:**
$DP$ 테이블을 무한대($	ext{INF}$)로 초기화합니다. 시작 노드는 1이므로, $DP[1 	ext{ (즉, } 1 	ext{로 설정된 비트)}][0] = 0$으로 설정합니다. (노드 1을 0번 인덱스로 간주). 실제로는 시작 노드 $S$의 비트만 켜진 상태로 초기화합니다.

**3. 전이 (Transition):**
$DP[mask | (1 	ext{ << } j)][j] = 	ext{min}(DP[mask | (1 	ext{ << } j)][j], DP[mask][i] + 	ext{cost}(i, j))$ 

즉, 현재 상태 $(mask, i)$에서, 아직 방문하지 않은 노드 $j$로 이동할 수 있다면, 새로운 상태 $(mask | (1 	ext{ << } j), j)$의 비용을 갱신합니다.

**4. 최종 답:**
모든 노드를 방문한 상태는 $mask = (1 	ext{ << } N) - 1$입니다. 이 상태에서 마지막 노드가 $i$일 때의 최소 비용 $	ext{min}(DP[(1 	ext{ << } N) - 1][i])$을 모든 $i$에 대해 계산하고 그 최솟값이 답입니다.

**시간 복잡도:** 상태 공간의 크기는 $2^N 	imes N$이며, 각 상태에서 $N$개의 다음 노드를 확인하므로, 시간 복잡도는 $O(2^N 	imes N^2)$입니다. $N 	ext{이 } 15$이므로 충분히 계산 가능합니다.

## 참고 코드 (python)

```python
import sys
import heapq

# 재귀 깊이 제한 해제
sys.setrecursionlimit(2000)

def solve():
    # 입력을 빠르게 받기 위해 sys.stdin.read() 사용
    input_data = sys.stdin.read().split()
    if not input_data: return

    N = int(input_data[0])
    M = int(input_data[1])
    
    # 1-based index를 0-based index로 변환하여 그래프 저장
    adj = [[float('inf')] * N for _ in range(N))
    
    # 간선 정보 처리 (M개의 간선)
    data_index = 2
    for _ in range(M):
        u = int(input_data[data_index]) - 1 # 0-based index
        v = int(input_data[data_index+1]) - 1 # 0-based index
        w = int(input_data[data_index+2])
        data_index += 3
        
        # 양방향 간선 처리 및 최소 가중치 저장
        adj[u][v] = min(adj[u][v], w)
        adj[v][u] = min(adj[v][u], w)

    # Bitmask DP 초기화
    # dp[mask][i]: mask 노드 집합을 방문했고, 현재 노드가 i일 때의 최소 비용
    INF = float('inf')
    dp = [[INF] * N for _ in range(1 << N)]

    # 시작 노드는 1번 노드 (0번 인덱스)로 가정
    start_node_index = 0 
    initial_mask = 1 << start_node_index
    dp[initial_mask][start_node_index] = 0

    # 2. DP 전이 (Mask 순회)
    # 마스크 크기 순서대로 처리 (1부터 (1<<N) - 1까지)
    for mask in range(1, 1 << N): # 현재 방문한 노드 집합
        for i in range(N): # 현재 위치 노드 i
            if not (mask & (1 << i)): # i가 mask에 포함되지 않았다면 스킵
                continue
            
            if dp[mask][i] == INF: # 도달 불가능한 상태면 스킵
                continue
            
            # 3. 다음 노드 j 탐색
            for j in range(N): # 다음 방문할 노드 j
                if not (mask & (1 << j)): # j가 아직 방문하지 않았다면
                    cost = adj[i][j]
                    if cost != float('inf'): # i와 j 사이에 간선이 존재한다면
                        new_mask = mask | (1 << j)
                        new_cost = dp[mask][i] + cost
                        
                        # 최소 비용 갱신
                        dp[new_mask][j] = min(dp[new_mask][j], new_cost)

    # 4. 최종 답 계산
    final_mask = (1 << N) - 1 # 모든 노드를 방문한 상태
    min_total_cost = INF
    
    for i in range(N): # 마지막 노드 i에 대한 최소 비용 탐색
        min_total_cost = min(min_total_cost, dp[final_mask][i])
        
    print(min_total_cost)
```

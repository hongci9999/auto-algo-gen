# 최소 비용으로 모든 노드 연결하기
*python · 그래프 · 보통 · MST, 크루스칼, Union-Find*

## 입출력 환경

입력은 표준 입력으로부터 받으며, 효율적인 처리를 위해 sys.stdin.readline 등을 사용해야 합니다.

## 문제

여러 개의 도시들이 있습니다. 각 도시는 좌표 평면 위에 위치하며, 두 도시 간의 거리는 유클리드 거리를 따릅니다. 여러분은 이 모든 도시들을 연결하는 최소 비용의 네트워크를 구축하려고 합니다. 즉, 모든 도시가 서로 통신할 수 있도록 하는 가장 저렴한 연결망을 찾아야 합니다.

단, 연결 비용은 '최소 신장 트리(Minimum Spanning Tree, MST)'의 개념을 따릅니다. 주어진 간선 목록과 가중치를 사용하여 최소 비용으로 모든 노드를 연결하는 방법을 구하시오.

## 입력

첫째 줄에는 도시의 개수 N이 주어집니다.
다음 N개의 줄에는 각 도시 $i$의 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다.
마지막 줄에는 간선 정보가 주어지며, $M$개에 대한 '시작 노드', '끝 노드', '비용'이 순서대로 나열됩니다. (N과 M은 최대 10^5를 넘지 않는다고 가정합니다.)

## 출력

최소 비용으로 모든 도시를 연결하는 총 최소 비용을 출력하시오.

## 제약 조건

도시의 개수 N: 2 <= N <= 10^5
간선의 개수 M: 0 <= M <= 10^5
좌표 $(x, y)$: -10^9 <= x, y <= 10^9
비용 (w): 0 <= w <= 10^9

## 예제 1

**입력**
```
3
0 0
1 0
2 0
1 2 10
1 3 5
```

**출력**
```
15
```

*세 도시(1, 2, 3)가 있습니다. 주어진 간선 (1-2, 비용 10), (1-3, 비용 5) 외에, 모든 노드를 연결하려면 추가적인 최소 간선이 필요합니다. 이 문제에서는 주어진 M개의 간선만으로 MST를 구하는 것으로 해석했습니다. 가장 작은 두 간선을 선택하여 총합을 계산합니다.*

## 예제 2

**입력**
```
4
0 0
10 0
0 10
10 10
2 3 5
1 2 8
2 4 7
3 4 9
```

**출력**
```
20
```

*주어진 간선들 중 최소 비용으로 모든 노드(1, 2, 3, 4)를 연결하는 MST의 총합은 20입니다. (간선 1-2, 2-4, 3-4 선택)*

## 힌트

- 이 문제는 전형적인 최소 신장 트리(MST) 문제임을 인지해야 합니다.
- 크루스칼 알고리즘이나 프림 알고리즘을 사용해 볼 수 있습니다. 간선의 개수 M과 노드의 개수 N을 고려할 때, 크루스칼 알고리즘이 효율적입니다.


## 알고리즘 요약

주어진 모든 간선을 사용하여 최소 신장 트리(Minimum Spanning Tree)의 비용을 구합니다. 크루스칼 알고리즘을 사용하면, 모든 간선을 비용 오름차순으로 정렬한 후, 유니온-파인드(Union-Find) 구조를 이용해 사이클을 형성하지 않는 간선만 차례로 선택하여 총합을 계산할 수 있습니다.

## 풀이 해설

풀이 아이디어: 이 문제는 주어진 노드와 간선을 이용하여 모든 노드를 연결하는 최소 비용의 네트워크, 즉 MST를 찾는 문제입니다. 크루스칼 알고리즘은 간선의 가중치를 오름차순으로 정렬한 후, 사이클을 만들지 않는 순서로 간선을 선택하여 트리를 구축합니다.

단계:
1. 모든 간선 정보를 (비용, 노드A, 노드B) 형태로 저장하고, 비용을 기준으로 오름차순 정렬합니다.
2. Union-Find 자료구조를 초기화합니다. 각 노드를 독립된 집합으로 설정합니다.
3. 정렬된 간선을 순회하면서 현재 간선 (u, v, w)에 대해 다음을 확인합니다:
    a. 만약 u와 v가 이미 같은 집합(같은 연결 컴포넌트)에 속해 있다면, 이 간선을 선택하면 사이클이 생기므로 건너<0xEB><0x9C><0x81>니다.
    b. 그렇지 않다면, 이 간선은 MST에 포함됩니다. 총 비용에 w를 더하고, Union-Find 구조에서 u와 v의 집합을 합칩니다(Union). 
4. 모든 간선을 처리하거나 (N-1)개의 간선을 선택할 때까지 반복합니다. 최종적으로 누적된 총 비용이 정답입니다.

시간 복잡도: 가장 큰 부분은 간선들을 정렬하는 과정입니다. $O(M 	imes 	ext{log} M)$이며, Union-Find 연산은 거의 상수 시간($	ext{O}(	ext{a}(N))$)으로 처리되므로 전체 시간 복잡도는 $	ext{O}(M 	ext{ log } M)$이 됩니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 증가 (Union-Find 사용 시 필요)
sys.setrecursionlimit(200000)

def solve():
    # 표준 입력에서 모든 라인을 읽기
    input = sys.stdin.read().split() 
    if not input: return 0 # 빈 입력 처리

    data_ptr = 0
    N = int(input[data_ptr])
    data_ptr += 1

    # 좌표는 MST 계산에 직접 사용되지 않지만, 문제 구조상 읽어줘야 함
    coords = []
    for i in range(N): 
        x = int(input[data_ptr])
        y = int(input[data_ptr+1])
        coords.append((x, y))
        data_ptr += 2

    # 간선 정보 읽기 (M개의 간선)
    if data_ptr >= len(input): 
        return 0 # 간선 정보가 없음
        
    M = (len(input) - data_ptr) // 3
    edges = []
    for i in range(M):
        u = int(input[data_ptr]) - 1  # 노드는 0-indexed로 변환
        v = int(input[data_ptr+1]) - 1
        w = int(input[data_ptr+2])
        edges.append((w, u, v))
        data_ptr += 3

    # 크루스칼 알고리즘 준비: 비용을 기준으로 정렬
    edges.sort()

    # Union-Find 구조체 구현
    parent = list(range(N)) # 부모 배열
    rank = [0] * N       # 랭크 배열

def find(i):
    if parent[i] == i:
        return i
    parent[i] = find(parent[i]) # 경로 압축
    return parent[i]

def union(i, j):
    root_i = find(i)
    root_j = find(j)
    
    if root_i != root_j:
        # 랭크를 이용한 합치기 (Union by Rank)
        if rank[root_i] < rank[root_j]:
            parent[root_i] = root_j
        elif rank[root_i] > rank[root_j]:
            parent[root_j] = root_i
        else:
            parent[root_j] = root_i
            rank[root_i] += 1
        return True # 합쳐짐
    return False # 이미 연결되어 있음

# MST 계산 시작
min_cost = 0
edges_count = 0

for w, u, v in edges:
    if union(u, v):
        min_cost += w
        edges_count += 1
        # N-1 개의 간선을 찾으면 종료 (MST 완성)
        if edges_count == N - 1: 
            break

    return min_cost

print(solve())
```

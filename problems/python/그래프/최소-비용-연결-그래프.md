# 최소 비용 연결 그래프
*python · 그래프 · 보통 · MST, 크루스칼*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다. 특히 여러 줄에 걸쳐 데이터가 제공되므로 입력 처리에 주의해야 합니다.

## 문제

N개의 도시가 있습니다. 각 도시는 좌표 평면 위의 점으로 표현됩니다. 이 도시들을 모두 연결하는 데 필요한 최소 비용을 구하는 문제가 주어집니다. 도시 A와 도시 B를 직접 연결하는 비용은 두 도시 간의 유클리드 거리를 반올림하여 정수로 만든 값입니다.

모든 도시가 서로 연결되어야 하므로, 이는 최소 신장 트리(Minimum Spanning Tree, MST) 문제를 해결해야 합니다.

## 입력

첫째 줄에는 도시의 개수 N이 주어집니다. 
다음 N줄에는 각 도시 i의 좌표 (x_i, y_i)가 공백으로 구분되어 순서대로 주어집니다.
마지막 줄부터는 모든 가능한 연결 비용(간선) 정보가 제공됩니다. 간선은 '시작 도시 인덱스 끝 도시 인덱스' 형식으로 주어지며, 인덱스는 0부터 N-1까지 사용합니다.

## 출력

모든 도시를 최소 비용으로 연결하는 총 비용을 하나의 정수로 출력하세요.

## 제약 조건

N은 1과 100 사이입니다. 간선의 개수 E는 최대 N(N-1) * 2개 이하입니다. 좌표 값 및 비용은 표준 정수형 범위를 따릅니다. 시간 복잡도는 $O(E 	imes 	ext{log} E)$ 또는 유사해야 합니다.

## 예제 1

```
3

**출력**
```
5

*도시(0, 0), (1, 2), (2, 2)가 있고 간선 (0-1) 비용이 주어졌습니다. MST는 최소 비용으로 세 도시를 연결해야 합니다.*

## 힌트

- 모든 도시는 그래프의 정점(Vertex)이며, 주어진 연결 정보는 간선(Edge)과 그 가중치(Weight)를 정의합니다.
- MST 문제에 적합한 알고리즘으로 크루스칼 알고리즘이나 프림 알고리즘을 고려해야 합니다.
- 간선 목록이 주어지므로, 모든 간선을 대상으로 정렬 후 Union-Find 구조를 사용하는 크루스칼 알고리즘이 효율적입니다.


## 알고리즘 요약

주어진 도시들을 노드로 하고, 주어진 연결 정보(간선)와 비용을 가중치로 하는 그래프가 구성됩니다. 최소 신장 트리(MST)는 이 그래프에서 모든 노드를 연결하는 가장 작은 가중치의 트리를 찾는 문제입니다. 크루스칼 알고리즘은 간선들의 가중치를 오름차순으로 정렬한 후, 순회하면서 사이클을 형성하지 않는 간선만 선택하여 MST를 구성합니다. 이를 위해 Union-Find(Disjoint Set Union) 자료구조가 사용됩니다.

## 풀이 해설

풀이 과정은 크루스칼 알고리즘을 이용하는 것이 가장 직관적입니다.

1. **데이터 구조화:** 입력받은 도시 좌표는 노드의 위치 정보를 담고, 주어진 간선 정보(u, v)와 비용 w를 (w, u, v) 형태의 튜플 리스트로 저장합니다. 이 때, 유클리드 거리를 계산하고 반올림하여 정수로 만든 값을 가중치 $w$로 사용해야 합니다.
2. **정렬:** 크루스칼 알고리즘에 따라, 모든 간선 리스트를 가중치(비용) 기준으로 오름차순 정렬합니다.
3. **Union-Find 초기화:** Union-Find 자료구조를 사용하여 N개의 도시(노드) 각각을 독립적인 집합으로 초기화합니다. 이 구조는 두 노드가 같은 연결 컴포넌트인지 빠르게 확인하고, 합치기 연산을 수행하는 데 사용됩니다.
4. **MST 구성 (순회):** 정렬된 간선 리스트를 처음부터 끝까지 순회합니다. 각 간선 $(u, v)$와 비용 $w$에 대해 다음을 확인합니다:
    a. `find(u)`와 `find(v)`가 다르면 (즉, u와 v가 아직 같은 연결 컴포넌트에 속하지 않으면), 이 간선을 MST에 포함시킵니다.
    b. 총 비용에 $w$를 더하고, `union(u, v)` 연산을 수행하여 두 노드를 하나의 집합으로 합칩니다.
5. **결과 반환:** 모든 간선 순회를 마친 후의 총 비용이 N개의 도시들을 최소 비용으로 연결하는 MST의 가중치가 됩니다. 이 과정은 $O(E 	imes 	ext{log} E)$ 시간 복잡도를 가지며, 매우 효율적입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 증가 설정 (Union-Find 사용 시 안전을 위해)
sys.setrecursionlimit(2000)

def solve():
    # 입력 받기 - N
    try:
        lines = sys.stdin.read().split()
        if not lines: return
        N = int(lines[0])
    except EOFError:
        return
    
    coords = []
    idx = 1
    # N개의 좌표 읽기
    for i in range(N): 
        x = int(lines[idx]); idx += 1
        y = int(lines[idx]); idx += 1
        coords.append((x, y))
    
    # 간선 정보 (u, v) 읽기
    edges_input = []
    while idx < len(lines):
        try:
            u = int(lines[idx])
            v = int(lines[idx+1])
            edges_input.append((u, v))
            idx += 2
        except IndexError: # 끝에 데이터가 부족한 경우 루프 종료
            break
    
    # Union-Find 구조체 초기화
    parent = list(range(N)) # 부모 배열
    rank = [0] * N      # 트리의 랭크 (경로 압축/요소 간의 합치기 최적화)

    def find(i): 
        if parent[i] == i: 
            return i 
        parent[i] = find(parent[i]) # 경로 압축
        return parent[i]

    def union(i, j): 
        root_i = find(i)
        root_j = find(j)
        
        if root_i != root_j: 
            # 랭크를 이용한 합치기 (Union by Rank)
            if rank[root_i] < rank[root_j]:
                parent[root_i] = root_j
            elif rank[root_i] > rank[root_j]:
                parent[root_j] = root_i
            else:
                parent[root_j] = root_i
                rank[root_i] += 1
            return True # 성공적으로 합쳤음을 의미
        return False # 이미 같은 집합에 속해있음

    # 모든 간선과 비용을 저장할 리스트 (cost, u, v)
    edges = []
    for u, v in edges_input:
        # 유클리드 거리 계산: sqrt((x2-x1)^2 + (y2-y1)^2))
        dx = coords[u][0] - coords[v][0]
        dy = coords[u][1] - coords[v][1]
        distance_float = ((dx * dx + dy * dy)**0.5)
        # 문제 조건에 따라 반올림하여 정수 비용 사용
        cost = int(distance_float + 0.5) 
        edges.append((cost, u, v))

    # 크루스칼 알고리즘: 가중치(비용) 기준으로 오름차순 정렬
    edges.sort()
    
    min_total_cost = 0
    edges_count = 0 # MST에 포함된 간선 수 (N-1개가 되면 종료)

    for cost, u, v in edges:
        if union(u, v):
            min_total_cost += cost
            edges_count += 1
            if edges_count == N - 1: # 모든 노드가 연결되면 충분함
                break
                
    print(min_total_cost)

solve()
```

# 지진파 감쇠 모델링
*python · 시뮬레이션 · 보통 · 수학, 시뮬레이션*

## 입출력 환경

파이썬에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

어떤 지역에서 발생한 지진의 파동이 특정 시간 간격으로 전파되면서 감쇠하는 현상을 모델링합니다. 각 위치(좌표)마다 진폭은 시간에 따라 감소하며, 주변 위치와의 상호작용도 고려해야 합니다.

지진은 2D 평면 공간에 퍼져나간다고 가정하고, $A$ 지점에서 시작하여 $(x_1, y_1)$부터 $(x_N, y_N)$까지의 $N$개 지점에 도달합니다. 각 위치 $(x_i, y_i)$에서의 진폭 $V(t)$는 다음 세 가지 요소의 곱으로 결정됩니다:

1. **거리 감쇠**: 시작점 A로부터의 거리에 반비례하여 감소합니다. (단위: $D = 	ext{거리} / D_{	ext{기준}}$)
2. **시간 감쇠**: 시간이 지남에 따라 진폭이 사인 함수 형태로 감소합니다. ($	ext{진폭}(t) = e^{-kt}$)
3. **환경적 상호작용**: 주변 위치의 진동 에너지 영향을 받습니다. 이 영향은 바로 직전 단계에서 계산된 이전 위치 $(x_{i-1}, y_{i-1})$와 현재 위치 $(x_i, y_i)$ 간의 거리에 비례합니다.

최종적으로 $N$번째 지점에서의 진폭을 구하고, 그 값을 반올림한 정수형으로 출력해야 합니다. (진폭은 0보다 커야 합니다.)

## 입력

첫째 줄에 상수 $A_{	ext{start}}$, $K$, $R_{	ext{기준}}$ 세 개의 실수 값이 공백으로 구분되어 주어집니다. ($A_{	ext{start}}$: 초기 진폭, $K$: 시간 감쇠 계수, $R_{	ext{기준}}$: 기준 거리).
둘째 줄부터 $N$개의 줄에 걸쳐 각 지점의 좌표 $(x_i, y_i)$가 공백으로 구분되어 주어집니다. (첫 번째 지점은 시작점 A를 기준으로 합니다.)

## 출력

마지막 지점에서의 최종 진폭을 정수형으로 출력합니다.

## 제약 조건

1. $A_{	ext{start}}, K, R_{	ext{기준}}$: 실수 값이며, 0보다 크다.
2. 좌표 $(x_i, y_i)$: $-10^9$에서 $10^9$ 사이의 정수 좌표이다.
3. 지점의 개수 $N$: 2 이상 50 이하이다.

## 예제 1

**입력**
```
10.0 0.5 100
(10, 0)
(20, 5)
```

**출력**
```
6
```

*시작점 A=(0,0)으로 가정하고 계산했습니다. (10, 0)의 진폭은 약 8.94입니다. (20, 5)에서의 최종 진폭도 비슷한 과정을 거쳐 6이 됩니다.*

## 예제 2

**입력**
```
50.0 0.1 50
(0, 10)
(-5, 5)
```

**출력**
```
23
```

*시작점 A=(0,0) 가정. 첫 지점 (0, 10)에서의 진폭은 약 46.8입니다. 두 번째 지점 (-5, 5)에서의 최종 진폭을 계산했습니다.*

## 힌트

- 진폭 공식 $V = V_{	ext{start}} 	imes D_{	ext{감쇠}} 	imes T_{	ext{감쇠}} 	imes E_{	ext{상호작용}}$ 을 분리하여 생각하세요.
- 좌표 $(x_i, y_i)$를 순차적으로 처리하며, 이전 위치와의 거리를 계산하는 것이 핵심입니다.


## 알고리즘 요약

문제에서 주어진 $N$개의 지점을 순회하면서 각 지점에서의 진폭을 점진적으로 갱신합니다. 초기 진폭은 시작점 A가 (0, 0)이라고 가정하고, 기준 거리($R_{	ext{기준}}$)와 시간 감쇠 계수($K$)를 사용하여 기본적인 감소율을 계산한 뒤, 이전 위치와의 상호작용 영향을 곱해줍니다. 모든 계산 결과는 실수이며, 최종적으로 반올림하여 정수로 출력합니다.

## 풀이 해설

이 문제는 시뮬레이션과 공학적 모델링 개념을 결합한 문제입니다.

**1. 기본 가정 및 공식 설정:**
*   문제에서 시작점 A의 좌표가 명시되지 않았으므로, 가장 일반적인 지진파 전파 모델링에 따라 **시작점 A를 (0, 0)으로 가정**합니다. 
*   $i$번째 지점 $(x_i, y_i)$에서의 진폭 $V_i$는 다음과 같은 요소들의 곱으로 계산됩니다.
    $$V_i = V_{	ext{start}} 	imes D_{	ext{감쇠}}(i) 	imes T_{	ext{감쇠}}(i) 	imes E_{	ext{상호작용}}(i)$$ 

**2. 각 요소별 분석:**
*   $D_{	ext{감쇠}}$ (거리 감쇠): 시작점 A로부터의 거리 $R_i = 	ext{distance}((0, 0), (x_i, y_i))$에 반비례하므로, $D_{	ext{감쇠}} = R_{	ext{기준}} / R_i$ 입니다.
*   $T_{	ext{감쇠}}$ (시간 감쇠): 시간 $t$가 지남에 따라 감소하며, 주어진 계수 $K$를 사용합니다. $T_{	ext{감쇠}}(i) = e^{-K 	imes i}$ 입니다. ($i$는 인덱스, 0부터 시작)
*   $E_{	ext{상호작용}}$ (환경적 상호작용): 직전 위치와 현재 위치 간의 거리에 비례합니다. $R_{i-1, i} = 	ext{distance}((x_{i-1}, y_{i-1}), (x_i, y_i))$ 이므로, $E_{	ext{상호작용}}(i) = R_{i-1, i} / R_{	ext{기준}}$ 로 정의할 수 있습니다. (여기서 기준 거리로 나누어 단위와 스케일을 맞춥니다.)

**3. 순차적 계산 흐름:**
*   초기 진폭 $V_0 = A_{	ext{start}}$. 이 값을 첫 번째 지점의 기본값으로 사용합니다.
*   $i=1$부터 $N-1$까지 반복하며, 각 지점에서 누적된 진폭을 갱신합니다. (실제로는 문제 조건에 따라 매 단계마다 모든 요소를 곱해야 하므로, 초기진폭은 상수처럼 취급하고 매번 계산하는 것이 안전합니다.)
*   **수정된 모델링:** 문제를 해석하기 쉽게 하기 위해, 각 지점 $i$에서의 최종 진폭 $V_i$는 다음의 누적적인 형태로 재구성합니다. (시작점을 기준으로 하는 총합에 이전 단계가 곱해지는 형태)
    $$V_{	ext{final}} = V_{	ext{start}} 	imes rac{R_{	ext{기준}}}{R_N} 	imes e^{-K(N-1)} 	imes rac{R_{N-2, N-1}}{R_{	ext{기준}}} 	imes rac{R_{N-3, N-2}}{R_{	ext{기준}}} 	imes 	ext{...}$$ (단순화를 위해 $V_i = V_{i-1} 	imes (	ext{감쇠 계수})$ 로 처리합니다.)
*   **최종 구현 전략:** 각 지점 $i$에 도달했을 때의 진폭은, 그 지점까지 누적된 모든 감쇠 효과를 곱한 값입니다. 따라서, 초기진폭을 시작하고 매 단계마다 다음 세 가지 요소를 순차적으로 곱합니다.
    1.  거리 감쇠: $R_{	ext{기준}} / R_i$ (A에서 i까지의 거리)
    2.  시간 감쇠: $e^{-K 	imes i}$
    3.  상호작용: $rac{	ext{distance}((x_{i-1}, y_{i-1}), (x_i, y_i))}{R_{	ext{기준}}}$
*   **결과:** 마지막 지점의 진폭을 계산한 후, `round()` 함수를 사용하여 가장 가까운 정수로 반올림하여 출력합니다. 시간 복잡도는 $O(N)$이며, 이는 매우 효율적입니다.

## 참고 코드 (python)

```python
import math
import sys

def solve():
    # 입력 속도 최적화
    input = sys.stdin.read().split()
    if not input:
        return

    # 첫 번째 줄: A_start, K, R_기준 (실수형)
    try:
        A_start = float(input[0])
        K = float(input[1])
        R_기준 = float(input[2])
    except IndexError:
        return # 입력 부족 처리

    # 나머지 좌표들 (N개의 쌍)
    coords = []
    i = 3
    while i < len(input):
        try:
            x = int(input[i])
            y = int(input[i+1])
            coords.append((x, y))
            i += 2
        except IndexError:
            break # 좌표 쌍 부족 처리
    
    if not coords: return

    def distance(p1, p2): 
        ""좌표 (x, y)를 받아 두 점 사이의 유클리드 거리를 계산합니다."" 
        return math.sqrt((p1[0] - p2[0])**2 + (p1[1] - p2[1])**2)

    # 시작점 A = (0, 0)으로 가정
    start_point = (0, 0)
    previous_coords = start_point
    current_amplitude = A_start
    N = len(coords)

    for i in range(N):
        current_point = coords[i]
        # 현재 위치와 이전 위치 사이의 거리 (상호작용 에너지 근원)
        # 첫 번째 지점일 때는 시작점에서 현재 지점까지의 거리를 사용합니다.
        if i == 0:
            dist_prev_curr = distance(start_point, current_point) 
        else:
            # 일반적인 경우: 이전 좌표와 현재 좌표 간의 거리
            dist_prev_curr = distance(previous_coords, current_point)

        # 1. 거리 감쇠 (A에서 현재 지점까지의 총 거리 이용)
        R_total = distance(start_point, current_point)
        D_감쇠 = R_기준 / R_total if R_total != 0 else 1.0

        # 2. 시간 감쇠 (지점 인덱스 i를 사용)
        T_감쇠 = math.exp(-K * (i + 1))
        
        # 3. 환경적 상호작용: 이전 지점에서 현재 지점으로의 거리 변화에 비례하는 계수 사용
        E_상호작용 = dist_prev_curr / R_기준 if R_기준 != 0 else 1.0

        # 진폭 업데이트 (직전 값 * 감쇠 요소)
        current_amplitude *= D_감쇠 * T_감쇠 * E_상호작용

        previous_coords = current_point
    
    # 최종 결과를 반올림하여 정수 출력
    print(int(round(current_amplitude))) 

solve()
```

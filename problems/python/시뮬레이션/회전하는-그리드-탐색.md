# 회전하는 그리드 탐색
*python · 시뮬레이션 · 보통 · 시뮬레이션, 탐색, BFS*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받습니다. N과 그리드 정보가 순차적으로 주어집니다. Python의 `sys.stdin.readline` 사용을 권장합니다.

## 문제

N x N 크기의 그리드가 있습니다. 이 그리드에는 장애물(벽)이 포함되어 있으며, 각 칸은 0(통로) 또는 1(장애물)로 표시됩니다.

당신은 (0, 0) 위치에서 시작하여 그리드의 다른 칸으로 이동해야 합니다. 이동은 상하좌우 네 방향으로만 가능합니다. 다만, 이 문제는 일반적인 그리드 탐색과 달리, 매 턴마다 그리드 자체가 시계 방향으로 1칸씩 회전한다는 특징이 있습니다.

회전 후의 그리드 상태를 고려하여, (0, 0)에서 시작하여 가장 적은 이동 횟수로 도달할 수 있는 (N-1, N-1) 위치까지의 최단 경로를 찾으세요. 이동 횟수는 회전 횟수와 실제 이동 횟수를 모두 포함합니다. 만약 도달할 수 없다면 -1을 출력합니다.

## 입력

첫째 줄에 N (그리드의 크기, 1 <= N <= 10)이 주어집니다. 둘째 줄에는 N개의 정수 또는 문자가 공백으로 구분되어 주어지며, 각 줄이 그리드의 한 행을 나타냅니다. (0 또는 1로 구성됨)

## 출력

최단 이동 횟수를 정수로 출력합니다. 도달할 수 없다면 -1을 출력합니다.

## 제약 조건

N은 1부터 10까지의 정수입니다. 시간 복잡도는 그리드 크기 N에 크게 의존하지 않도록 설계해야 합니다. (N <= 10이므로, 상태 공간 탐색이 가능합니다.)

## 예제 1

**입력**
```
2
0 0
0 0
```

**출력**
```
2
```

*초기 상태: (0,0)에서 (1,1)로 이동 가능. 1턴차에 회전 후에도 (1,1)로 이동 가능. 총 2회 이동.*

## 예제 2

**입력**
```
3
0 1 0
0 0 0
1 0 0
```

**출력**
```
3
```

*최단 경로는 (0,0) -> (1,0) -> (1,1) -> (2,1) 입니다. 이 과정에서 3번의 이동이 필요하며, 매 턴마다 회전이 발생합니다.*

## 힌트

- 회전하는 그리드 상태를 하나의 '상태'로 정의하고 BFS를 사용해야 합니다.
- 상태는 (현재 위치 행, 현재 위치 열, 현재 턴 수)를 포함해야 합니다.


## 알고리즘 요약

BFS (Breadth-First Search)를 이용하여 최단 경로를 탐색합니다. 상태 공간을 확장하여 '현재 그리드 상태'까지 고려해야 합니다. 각 상태는 (r, c, t)로 정의되며, t는 턴 수(회전 횟수)를 나타냅니다. 이동할 때마다 그리드를 회전시키고, 새로운 상태를 큐에 추가합니다.

## 풀이 해설

### 💡 아이디어
이 문제는 그리드 자체가 매 턴마다 회전한다는 동적 특성을 가지고 있습니다. 단순한 BFS로는 해결할 수 없으며, '현재 그리드의 상태'를 상태 공간에 포함시켜야 합니다. 그리드가 회전하는 횟수(턴 수)는 경로의 길이와 직결되므로, 턴 수를 상태에 포함하여 BFS를 진행합니다.

### ⚙️ 그리드 회전 구현
N x N 그리드가 시계 방향으로 1칸 회전하는 것은 행렬 변환을 통해 구현할 수 있습니다. 원본 그리드 `G`의 새 위치 `(r', c')`는 원래 위치 `(r, c)`가 차지하던 값을 다음 위치로 옮기는 방식으로 계산됩니다. 또는, 새 그리드 `G'`를 만들고, `G'[r'][c'] = G[r][c]` 관계를 정의할 수 있습니다. (여기서는 새로운 그리드를 만들어 회전시키는 방식을 사용합니다.)

### 🧭 BFS 상태 정의
BFS의 상태는 `(r, c, t)`로 정의합니다.
*   `r, c`: 현재 위치 (행, 열)
*   `t`: 현재 턴 수 (이 턴이 시작될 때의 그리드 상태를 결정)

우리는 최소 이동 횟수를 찾아야 하므로, 거리를 저장하는 `dist[r][c][t]` 배열을 사용하거나, 방문 처리를 하는 `visited[r][c][t]` 셋을 사용합니다. (N이 작으므로 턴 수에 대한 방문 처리가 필요합니다.)

### 🪜 탐색 단계
1.  **초기화**: 큐에 `(0, 0, 0, 0)` (r, c, t, 거리)를 넣고, 방문 처리를 합니다. 초기 그리드 상태를 저장합니다.
2.  **BFS 반복**: 큐에서 상태 `(r, c, t, d)`를 꺼냅니다.
3.  **종료 조건 확인**: 만약 `(r, c)`가 목표 위치 `(N-1, N-1)`라면, 현재 거리 `d`가 최소 경로입니다. (BFS의 특성상, 처음 도달하는 것이 최단 경로입니다.)
4.  **다음 턴 준비**: 다음 턴 `t+1`로 이동하기 전에, 현재 그리드 `G_t`를 회전시켜 다음 그리드 `G_{t+1}`를 얻습니다.
5.  **이동 탐색**: 현재 그리드 `G_t`와 다음 그리드 `G_{t+1}` 두 가지 시점을 고려해야 합니다. (문제의 해석에 따라, 이동은 현재 턴의 그리드에서 이루어지며, 이동 후 다음 턴이 시작될 때 회전하는 것으로 해석하는 것이 일반적입니다. 즉, 턴 `t`일 때 이동합니다.)
    *   **최적 해석 (턴 기반)**: 현재 상태 `(r, c, t)`에서 상하좌우 네 방향으로 이동 가능한 칸 `(nr, nc)`를 찾습니다. 이동은 현재 그리드 `G_t`의 장애물 여부를 확인합니다. 이동에 성공하면, 거리를 1 증가시키고, 다음 턴 `t+1`의 상태 `(nr, nc, t+1)`를 큐에 넣습니다. 이때, `t+1` 상태의 그리드 `G_{t+1}`도 함께 계산해야 합니다.
6.  **제약 처리**: 방문 기록을 사용하여 이미 도달했거나, 너무 오래 걸려서 무한 루프에 빠지는 것을 방지합니다. (최대 턴 수는 $N^2$ 이상으로 제한할 수 있습니다.)
7.  **최종 결과**: BFS를 통해 도달한 가장 작은 거리를 반환합니다. 도달하지 못하면 -1을 반환합니다.

## 참고 코드 (python)

```python
import collections
import sys

# 재귀 깊이 제한을 늘려 처리합니다.
# N <= 10 이므로, 상태 공간이 매우 크지 않습니다.
sys.setrecursionlimit(2000)

def solve():
    # 입력 받기
    try:
        N = int(sys.stdin.readline()) # 첫 줄: N
    except:
        # 입력이 없을 경우 처리
        return -1

    initial_grid = []
    for _ in range(N):
        try:
            line = sys.stdin.readline().split()
            if not line: break
            initial_grid.append([int(x) for x in line])
        except EOFError:
            break

    if not initial_grid: return -1

    def rotate_grid(grid):
        # 시계 방향 90도 회전 (r, c) -> (c, N-1-r)
        new_grid = [[0] * N for _ in range(N)]
        for r in range(N): 
            for c in range(N): 
                new_grid[c][N - 1 - r] = grid[r][c]
        return new_grid

    # BFS 상태: (r, c, t) -> (행, 열, 턴 수)
    # 거리를 저장하는 딕셔너리: (r, c, t) : min_distance
    # N <= 10 이므로, 최대 턴 수를 100 정도로 제한하여 메모리 초과 방지
    # (r, c, t)가 방문했는지 기록
    # 최대 턴 수는 N*N 정도로 충분합니다. (N=10, 100번 정도 탐색 가능)
    queue = collections.deque([(0, 0, 0, 0)]) # (r, c, t, distance)
    visited = set([(0, 0, 0)]) # (r, c, t) 튜플
    # dist[r][c][t] 형태로 거리를 저장하는 것이 더 정확하지만, 셋으로 방문만 체크합니다.
    # 거리는 큐에 포함하여 관리합니다.

    # 현재 그리드 상태를 저장하는 리스트 (t 턴이 시작될 때의 그리드)
    grids = [None] * (N * N + 1)
    grids[0] = initial_grid
    current_grid = initial_grid
    for t in range(1, N * N + 1): # 최대 N*N 턴까지 회전 계산
        current_grid = rotate_grid(current_grid)
        grids[t] = [row[:] for row in current_grid]

    # BFS 시작
    while queue:
        r, c, t, dist = queue.popleft()

        # 1. 목표 확인: (N-1, N-1)에 도착했는지
        if r == N - 1 and c == N - 1:
            return dist

        # 2. 다음 턴으로 이동할 수 있는지 확인 (t+1)
        next_t = t + 1
        if next_t > N * N: # 안전 장치: 너무 많은 턴을 방지
            continue
        
        # 3. 현재 그리드(G_t)에서 상하좌우 이동 탐색
        # 이동은 현재 턴 t에 사용 가능한 그리드 (grids[t])를 기준으로 합니다.
        grid_t = grids[t]
        
        for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
            nr, nc = r + dr, c + dc
            
            # 경계 및 장애물 확인
            if 0 <= nr < N and 0 <= nc < N and grid_t[nr][nc] == 0:
                # 이동이 가능함. 다음 상태 (nr, nc, next_t)로 이동
                next_state = (nr, nc, next_t)
                
                # 4. 방문 체크 및 큐 삽입
                if next_state not in visited:
                    visited.add(next_state)
                    # 이동 1회 = 거리 1 증가. 다음 턴으로 넘어가므로 턴도 증가.
                    queue.append((nr, nc, next_t, dist + 1))

    # 도달할 수 없음
    return -1

print(solve())
```

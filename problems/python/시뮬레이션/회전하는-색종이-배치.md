# 회전하는 색종이 배치
*python · 시뮬레이션 · 보통 · 시뮬레이션, 배열*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받고, 최종 결과를 print() 함수로 출력합니다.

## 문제

주어진 N x M 크기의 격자판에 여러 개의 '색종이' 조각들이 겹치지 않게 배치되어 있습니다. 각 색종이는 직사각형 형태이며, 방향을 회전시키거나 위치를 옮기는 등의 작업은 할 수 없습니다.

당신은 이 색종이들을 이용하여 새로운 N x M 격자판의 일부 영역을 빈 공간 없이 채우려고 합니다. 이때, 전체적으로 겹치지 않게 배치하는 것이 목표입니다.

문제는 최소한 몇 개의 칸을 남겨두고(빈 공간) 최대 몇 개의 색종이를 사용할 수 있는지를 구하는 것입니다. 즉, 모든 색종이 중 가장 많은 개수를 사용하여 빈 공간의 수를 최소화할 때, 그 사용 가능한 최대 색종이의 개수와 해당 배치에서 발생하는 총 빈 공간의 개수를 출력해야 합니다.

색종이 조각들은 이미 격자판 내에 고정된 위치와 크기를 가지고 있습니다. 이 문제에서는 모든 색종이를 다 사용할 수 없으며, 특정 조합으로만 배치가 가능합니다.

## 입력

첫째 줄에는 N과 M (N <= M) 두 정수가 주어집니다. 둘째 줄부터는 색종이 조각의 정보가 순서대로 주어지며, 각 색종이는 'r c w h' 형식으로 한 줄에 입력됩니다. 여기서 r은 시작 행(0부터 N-1), c는 시작 열(0부터 M-1), w는 너비, h는 높이를 나타냅니다.

## 출력

최대 사용할 수 있는 색종이의 개수와 그 배치에서 발생하는 총 빈 공간의 개수를 순서대로 출력합니다.

## 제약 조건

N, M: 1부터 50까지. 색종이 조각의 수는 최대 10개입니다. 모든 좌표는 유효한 범위 내에 있습니다. 시간 복잡도는 O(2^K * N*M) 정도가 허용됩니다 (K는 색종이 개수).

## 예제 1

**입력**
```
3 4
0 0 2 1
1 1 1 2
```

**출력**
```
2 2
```

## 힌트

- 색종이 개수(K)가 매우 작다는 점을 주목하세요.
- 모든 조합을 확인해야 하므로 비트마스크를 활용한 순열 또는 부분집합 탐색이 적합합니다.
- 겹침 여부를 검사하는 함수가 핵심입니다.


## 알고리즘 요약

색종이의 개수 K가 최대 10개로 매우 작습니다. 따라서 모든 색종이 조합($2^K$ 가지)을 시도해 보는 완전탐색(Brute Force) 전략을 사용합니다. 각 조합에 대해, 해당 색종이들이 서로 겹치는지 확인하고, 겹치지 않는 경우 그 개수와 총 점유 면적을 계산하여 최대화 합니다.

## 풀이 해설

이 문제는 모든 가능한 색종이 부분집합(Subset)을 탐색하는 방식으로 해결할 수 있습니다. 주어진 $K$개의 색종이가 있다고 할 때, $2^K$개의 조합이 존재합니다.

**1단계: 반복 및 조합 생성 (비트마스크)**
$K$가 최대 10이므로, 비트마스크를 사용하여 0부터 $2^K - 1$까지의 모든 숫자를 순회하며 각 비트를 '색종이 사용 여부'로 판단합니다.

**2단계: 유효성 검사 (겹침 확인)**
현재 선택된 색종이 조합에 대해, 두 가지 종류의 충돌을 검사해야 합니다. 
1. **자기 충돌:** 같은 조합 내에서 어떤 색종이 쌍이 서로 겹치는지.
2. **경계 충돌:** 모든 색종이가 $N 	imes M$ 격자 내에 완전히 존재하는지 (제약 조건상 입력 시 이미 확인되어 있을 가능성이 높지만, 안전하게 검사).

두 색종이 A와 B가 $(r_A, c_A, w_A, h_A)$와 $(r_B, c_B, w_B, h_B)$라고 할 때, 겹치는지 확인하는 함수는 두 직사각형의 교집합 영역을 계산하여 면적이 0보다 큰지 확인하면 됩니다.

**3단계: 최대화 및 결과 도출**
모든 유효한 조합에 대해 다음 값을 계산합니다:
*   사용된 색종이 개수 (현재 비트마스크의 '1'의 개수)
*   총 점유 면적 (선택된 모든 색종이의 면적 합)

우리는 최대 사용 가능한 색종이 개수를 먼저 극대화해야 합니다. 만약 여러 조합이 같은 최대 색종이 개수를 가진다면, 그 중에서 총 점유 면적이 가장 큰(즉, 빈 공간을 최소화하는) 조합을 선택합니다.

최종적으로, 최대 색종이 개수 $MaxCount$와, 이 $MaxCount$를 만족하면서 가장 큰 총 점유 면적 $MaxArea$를 갖는 경우의 빈 공간 $EmptySpace = N 	imes M - MaxArea$를 출력합니다.

**시간 복잡도:** 전체 조합 탐색에 $O(2^K)$가 걸립니다. 각 조합 내에서 겹침 검사는 최대 $O(K^2)$ 시간이 소요되므로, 총 시간 복잡도는 $O(2^K 	imes K^2)$ 입니다. $K=10$일 때 충분히 빠르게 동작합니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 입력을 받기 위해 stdin을 사용하고, 한 줄 단위로 읽습니다.
    input = sys.stdin.read().split()
    if not input:
        return
    
    # N: 행(Row), M: 열(Column). 문제에서 N <= M 이므로 N이 작은 축입니다.
    N = int(input[0])
    M = int(input[1])
    
    # 나머지 입력은 색종이 정보 (r, c, w, h) 순서로 들어옵니다.
    k = len(input) - 2
    rectangles = []
    for i in range(k):
        r = int(input[2 + i * 4])
        c = int(input[3 + i * 4])
        w = int(input[4 + i * 4])
        h = int(input[5 + i * 4])
        # (r, c, w, h) 순서로 저장: r=시작행, c=시작열, w=너비, h=높이
        rectangles.append((r, c, w, h))
    
    K = len(rectangles)
    total_area = N * M
    
    # 최대 사용 가능한 색종이 개수와 그에 따른 최소 빈 공간을 저장할 변수 초기화
    max_count = 0
    min_empty_space = total_area + 1 # 충분히 큰 값으로 초기화
    
    # 비트마스크를 사용하여 모든 색종이 조합 (2^K) 탐색
    for mask in range(1 << K): 
        current_rectangles = []
        count = 0
        current_area = 0
        
        # 현재 마스크에 포함된 색종이들을 수집
        for i in range(K):
            if (mask >> i) & 1:
                current_rectangles.append(rectangles[i])
                count += 1
                
        # 조합 크기가 현재까지의 최대 개수보다 작으면, 더 큰 조합을 먼저 탐색하는 것이 효율적입니다.
        # 그러나 순서가 보장되지 않으므로 모든 경우를 검사해야 합니다. (다만 최적화 가능)
        if count < max_count and not current_rectangles: # empty check
            continue

        # 1. 겹침 확인 및 총 면적 계산
        is_valid = True
        total_overlap_area = 0
        
        # 모든 쌍에 대해 겹치는지 검사 (O(count^2))
        for i in range(len(current_rectangles)): 
            r1, c1, w1, h1 = current_rectangles[i]
            area1 = w1 * h1
            total_overlap_area += area1 # 일단 면적을 합산
            
            # 겹침 검사 시작 (j > i를 통해 쌍만 비교)
            for j in range(i + 1, len(current_rectangles)): 
                r2, c2, w2, h2 = current_rectangles[j]
                area2 = w2 * h2
                
                # 교집합의 행 범위: max(r1, r2) 부터 min(r1+h1-1, r2+h2-1)
                overlap_r_start = max(r1, r2)
                overlap_r_end = min(r1 + h1 - 1, r2 + h2 - 1)
                
                # 교집합의 열 범위: max(c1, c2) 부터 min(c1+w1-1, c2+w2-1)
                overlap_c_start = max(c1, c2)
                overlap_c_end = min(c1 + w1 - 1, c2 + w2 - 1)
                
                # 교집합이 존재할 조건: 시작 <= 끝
                if overlap_r_start <= overlap_r_end and overlap_c_start <= overlap_c_end:
                    overlap_height = min(r1 + h1, r2 + h2) - max(r1, r2)
                    overlap_width = min(c1 + w1, c2 + w2) - max(c1, c2)

                    # 두 직사각형의 교집합 면적 계산
                    overlap_area = overlap_height * overlap_width
                    if overlap_area > 0:
                        is_valid = False # 겹치면 무효 조합입니다.
                        break
            if not is_valid: 
                break
        
        # 2. 결과 업데이트 (유효한 비겹침 조합인 경우)
        if is_valid:
            # 만약 겹치지 않는다면, 총 면적은 단순히 모든 색종이의 개별 면적 합입니다.
            current_area = sum(r*w*h for r, c, w, h in current_rectangles) # 실제로 사용된 면적
            
            # 목표: 1. 최대 Count (최대 색종이 개수)
            #       2. 최소 Empty Space (즉, 최대 Area) 
            if count > max_count:
                max_count = count
                min_empty_space = total_area - current_area
            elif count == max_count: # 같은 개수의 색종이일 경우, 더 큰 면적을 선택 (빈 공간 최소화)
                new_empty_space = total_area - current_area
                if new_empty_space < min_empty_space:
                    min_empty_space = new_empty_space
    
    print(f"{max_count} {min_empty_space}")

# 주석 처리된 부분은 실제 테스트 환경에서 입력 처리가 필요합니다. 
# 예제 입력을 직접 넣어 테스트하는 경우를 대비하여 solve() 호출을 남겨둡니다.
if __name__ == "__main__":
    # sys.stdin.read() 방식이 일반적인 코딩테스트 환경에 가장 적합함
    solve()
```

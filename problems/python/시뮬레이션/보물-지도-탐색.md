# 보물 지도 탐색
*python · 시뮬레이션 · 보통 · 그래프, DFS, 시뮬레이션*

## 입출력 환경

입력은 표준 입력(stdin)을 통해 한 번에 받습니다. (N M을 먼저 읽고, 이후 N줄의 그리드를 읽습니다.)

## 문제

당신은 보물이 숨겨진 $N \times M$ 크기의 지도 위에서 탐험을 시작합니다. 지도는 0부터 2까지의 숫자로 채워져 있습니다. 0은 일반 통로, 1은 벽(통과 불가능)을 의미하고, 2는 보물(획득 가능)이 있는 지점입니다. 당신은 상하좌우 네 방향으로만 이동할 수 있으며, 이미 방문한 지점은 다시 방문할 수 없습니다. 시작 지점은 항상 (0, 0)입니다. 목표는 (0, 0)에서 시작하여 한 번도 지나가지 않은 벽에 부딪히거나, 더 이상 이동할 수 없을 때까지 이동하며 획득할 수 있는 최대 보물의 개수를 찾는 것입니다. 지도를 탐색할 때, 방문한 지점은 '방문됨' 상태로 간주해야 합니다. 벽에 부딪히면 더 이상 탐험할 수 없습니다. 최대 보물 개수를 반환하세요.

## 입력

첫째 줄에 $N$과 $M$이 주어집니다. (1 ≤ N, M ≤ 10). 
다음 $N$줄에 걸쳐 $M$개의 숫자로 이루어진 지도가 주어집니다. (각 숫자는 0, 1, 2 중 하나입니다.)

## 출력

최대 보물의 개수를 나타내는 정수 하나를 출력합니다.

## 제약 조건

N, M: 1부터 10까지. 시간 복잡도는 O(N*M) 이내여야 합니다.

## 예제 1

**입력**
```
3 3
0 2 0
1 2 0
0 0 0
```

**출력**
```
4
```

*시작 (0,0)에서 이동 가능 경로를 탐색하면 최대 4개의 보물을 수집할 수 있습니다.*

## 예제 2

**입력**
```
2 2
0 1
2 0
```

**출력**
```
1
```

*상하좌우 이동이 제한되어 (0,0)에서 (1,0)으로만 이동할 수 있으며, 보물은 1개입니다.*

## 힌트

- 이 문제는 전형적인 그리드 기반의 경로 탐색 문제입니다.
- 재귀 함수 (DFS)를 사용하여 현재 위치에서 도달 가능한 최대 보물 수를 계산하는 것이 핵심입니다.


## 알고리즘 요약

깊이 우선 탐색 (DFS)을 이용한 최대값 찾기. 시작 지점 (0, 0)에서부터 재귀적으로 상하좌우 네 방향으로 이동하며, 벽에 부딪히거나 이미 방문한 곳이라면 탐색을 중단합니다. 탐색이 성공하는 각 경로마다 획득한 보물의 개수를 계산하고, 이 값들 중 최댓값을 반환합니다.

## 풀이 해설

풀이 해설: 아이디어
이 문제는 주어진 격자 지도에서 시작점 (0, 0)에서부터 벽에 막히지 않고 이동할 수 있는 모든 경로 중, 보물(2)을 가장 많이 획득하는 경로를 찾는 문제입니다. 따라서 DFS(Depth First Search, 깊이 우선 탐색)를 이용하여 탐색해야 합니다.

단계
1. 방문 기록 관리: 어떤 지점을 방문했는지 추적하기 위해 `visited` 배열을 사용합니다. 이는 같은 지점을 여러 번 방문하는 것을 방지합니다.
2. DFS 함수 정의: `dfs(r, c)` 함수를 정의합니다. 이 함수는 현재 위치 (r, c)에서 시작하여 도달할 수 있는 최대 보물 개수를 반환해야 합니다.
3. 탐색 및 재귀 호출: 함수 내부에서, 현재 지점 (r, c)가 벽인지, 경계를 벗어났는지, 이미 방문했는지를 확인하여 즉시 탐색을 종료할지 결정합니다. 이후 상하좌우 네 방향 (r+1, c), (r-1, c), (r, c+1), (r, c-1)에 대해 각각 재귀적으로 `dfs`를 호출합니다.
4. 최대값 계산: 중요한 부분은, 현재 위치가 보물을 가지고 있다면 (지도[r][c] == 2), 기본 카운트 1을 더합니다. 그리고 네 방향에서 돌아온 최대 보물 개수 값들 중 가장 큰 값을 최종 결과로 반환해야 합니다. (만약 모든 방향에서 탐색이 막힌다면, 현재 보물 카운트만 반환합니다.)

시간 복잡도
시간 복잡도는 O(N * M) 입니다. 그리드의 크기가 $N 	imes M$ 일 때, 각 지점은 최대 한 번만 방문하며, 각 지점에서 상하좌우 4방향으로 상수 시간의 연산이 수행되므로, 전체 시간 복잡도는 그리드 크기에 선형적으로 비례합니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려주어 큰 그리드에서도 stack overflow가 발생하지 않도록 합니다.
sys.setrecursionlimit(2000)

def solve():
    # sys.stdin.read()를 사용하여 모든 입력을 한 번에 읽습니다.
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없을 경우 대비
        return 0
    
    N = int(input_data[0])
    M = int(input_data[1])
    
    # 지도를 파싱합니다. (N*M개의 숫자가 input_data[2]부터 시작)
    grid = []
    k = 2
    for i in range(N):
        row = []
        for j in range(M):
            row.append(int(input_data[k]))
            k += 1
        grid.append(row)

    # 방문 여부를 기록하는 배열 (초기값: False)
    visited = [[False for _ in range(M)] for _ in range(N)]
    
    # 상하좌우 이동 방향 (dr: row 변화량, dc: col 변화량)
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

    def dfs(r, c): 
        # 1. 현재 위치를 방문 처리합니다.
        visited[r][c] = True
        
        # 2. 현재 위치가 가진 보물 개수 (자신이 획득하는 값)
        current_treasure = 1 if grid[r][c] == 2 else 0
        
        max_next_treasure = 0
        
        # 3. 네 방향으로 이동하며 재귀 호출하고 최대값을 찾습니다.
        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            
            # 경계 체크
            if 0 <= nr < N and 0 <= nc < M:
                # 벽 체크 (1), 방문 체크
                if grid[nr][nc] != 1 and not visited[nr][nc]:
                    # 재귀 호출: 다음 단계에서 얻을 수 있는 최대 보물 개수
                    result = dfs(nr, nc)
                    max_next_treasure = max(max_next_treasure, result)
        
        # 현재 보물 + 다음 경로에서 얻을 수 있는 최대 보물
        return current_treasure + max_next_treasure

    # 탐색 시작: (0, 0)에서 시작하며, 시작점도 방문 처리되어야 하므로 DFS 호출 전 visited 처리
    # (실제 DFS 내부에서 visited 처리되지만, 시작점의 보물은 반드시 카운트되어야 함)
    return dfs(0, 0)

print(solve())
```

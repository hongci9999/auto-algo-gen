# 히스토그램 최대 직사각형 면적
*python · 스택 · 보통 · 스택, 자료구조, 최대값*

## 입출력 환경

입력은 파이썬 리스트 형태로 가정하고 작성합니다.

## 문제

주어진 높이로 이루어진 막대 그래프(히스토그램)가 있습니다. 이 막대들로 만들 수 있는 직사각형 중 가장 넓은 면적을 가진 직사각형의 면적을 구하는 문제입니다. 막대는 모두 연속된 정수 인덱스에 위치하며, 높이는 주어진 배열의 값과 같습니다.

예시: 높이 배열이 [2, 1, 5, 6, 2, 3]일 때, 가장 넓은 직사각형은 높이 5와 6을 사용하는 영역으로, 면적은 2 * 2 = 10입니다.

## 입력

정수형 배열 A가 주어집니다. A[i]는 i번째 막대의 높이를 나타냅니다.

## 출력

가장 넓은 직사각형의 면적(정수)을 출력합니다.

## 제약 조건

배열 A의 길이 N은 1 이상 100,000 이하입니다. A[i] 값은 1 이상 100,000 이하의 정수입니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
[2, 1, 5, 6, 2, 3]
```

**출력**
```
10
```

*높이 5와 6이 포함된 직사각형이 최대 면적 10을 가집니다.*

## 예제 2

**입력**
```
[2, 3, 4, 5]
```

**출력**
```
9
```

*모든 막대를 사용했을 때의 면적 2*3=6, 3*4=12, 4*5=20... 가장 큰 것은 높이 3, 4, 5를 모두 사용하는 면적 3*3=9입니다.*

## 예제 3

**입력**
```
[6, 7, 5, 8]
```

**출력**
```
14
```

*높이 7과 8을 사용하는 면적 2*7=14가 최대 면적입니다.*

## 힌트

- 모노토닉 스택(Monotonic Stack)을 이용하면 효율적인 풀이가 가능합니다.
- 각 막대 높이가 직사각형의 '높이'가 될 때, 좌우로 확장 가능한 범위를 찾는 것이 핵심입니다.


## 알고리즘 요약

모노토닉 스택(Monotonic Stack)을 이용하여 각 막대(높이)를 기준으로, 자신보다 작거나 같은 높이를 가진 가장 가까운 왼쪽 막대와 오른쪽 막대를 찾습니다. 이 두 막대 사이의 폭을 곱하면 최대 면적이 됩니다.

## 풀이 해설

풀이 과정은 각 막대(높이 h[i])가 직사각형의 높이가 될 때, 이 높이를 유지할 수 있는 가장 넓은 구간의 폭(width)을 계산하는 것입니다. 이 구간의 폭을 계산하기 위해 스택을 사용합니다.

1. 스택의 역할: 스택에는 지금까지 처리한 막대들의 인덱스를 저장하며, 이 인덱스에 해당하는 높이는 오름차순(혹은 내림차순)을 유지하도록 관리합니다 (모노토닉 스택).
2. 알고리즘 실행: 배열을 순회하면서 현재 막대 h[i]를 검사합니다.
3. 높이 계산: 스택의 top에 있는 막대 h[j]가 현재 막대 h[i]보다 높다면(h[j] > h[i]), h[j]가 끝나는 지점을 찾을 수 있습니다. 스택에서 h[j]를 pop하고, 이때 h[j]의 높이와 현재 인덱스 i를 이용해 직사각형의 면적을 계산합니다. 이 때, popped된 막대 h[j]의 왼쪽 경계는 스택에 남아있는 새로운 top 인덱스 j'의 다음 칸(j'+1)이 됩니다. 따라서 폭은 i - j' - 1이 됩니다.
4. 스택 관리: pop 과정이 끝난 후, 현재 막대 h[i]를 스택에 push합니다.
5. 마무리: 배열 순회가 끝난 후에도 스택에 남아있는 막대들은 오른쪽 경계가 배열의 끝(N)이므로, 남은 모든 요소를 처리하여 면적을 계산합니다.

시간 복잡도는 배열을 한 번만 순회하고 각 원소는 스택에 최대 한 번 push/pop되므로, O(N)입니다.

## 참고 코드 (python)

```python
def largestRectangleArea(heights):
    n = len(heights)
    stack = []  # 스택에 인덱스를 저장
    max_area = 0

    # 배열 길이 N을 넘어서까지 반복하여 마지막 요소 처리
    for i in range(n + 1):
        # i == n 이거나, 스택이 비었거나, 현재 높이가 스택 top 높이보다 작을 때
        h = heights[i] if i < n else 0
        while stack and heights[stack[-1]] >= h:
            height = heights[stack.pop()]
            # 스택이 비었거나, 스택 top의 높이가 현재 pop된 높이보다 낮다면
            # 왼쪽 경계는 스택 top의 다음 칸, 오른쪽 경계는 현재 인덱스 i
            width = i if not stack else i - stack[-1] - 1
            area = height * width
            max_area = max(max_area, area)
        
        if i < n:
            stack.append(i)
            
    return max_area

# 테스트 예제 실행 (실제 코딩 테스트 환경에서는 입출력 처리가 필요)
if __name__ == "__main__":
    # 예제 1
    heights1 = [2, 1, 5, 6, 2, 3]
    print(f"입력: {heights1}, 출력: {largestRectangleArea(heights1)}")
    
    # 예제 2
    heights2 = [2, 3, 4, 5]
    print(f"입력: {heights2}, 출력: {largestRectangleArea(heights2)}")
    
    # 예제 3
    heights3 = [6, 7, 5, 8]
    print(f"입력: {heights3}, 출력: {largestRectangleArea(heights3)}")
```

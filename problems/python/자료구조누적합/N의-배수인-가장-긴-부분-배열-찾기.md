# N의 배수인 가장 긴 부분 배열 찾기
*python · 자료구조/누적합 · 보통 · 부분 배열, 누적합, 딕셔너리*

## 입출력 환경

입력은 sys.stdin을 사용하여 처리하는 것을 권장합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 이 중 합이 K의 배수가 되는 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열이란 연속된 원소들의 집합을 의미합니다. (예: A[i]부터 A[j]까지).

## 입력

첫째 줄에 정수 N과 양의 정수 K가 공백으로 구분되어 주어집니다. (N: 배열의 길이, K: 나눌 값)
둘째 줄에 N개의 정수 원소들이 공백으로 구분되어 주어집니다.

## 출력

합이 K의 배수가 되는 가장 긴 부분 배열의 길이를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= 10^9
-10^9 <= A[i] <= 10^9

## 예제 1

**입력**
```
5 3
3 6 1 8 2
```

**출력**
```
4
```

*배열의 누적합이 K=3의 배수가 되는 가장 긴 부분 배열은 [3, 6, 1, 8]입니다. (합: 18)*

## 예제 2

**입력**
```
3 2
2 4 6
```

**출력**
```
3
```

*배열 전체의 합(12)이 2의 배수이므로, 가장 긴 부분 배열은 전체 배열입니다.*

## 예제 3

**입력**
```
5 7
1 2 3 4 5
```

**출력**
```
0
```

*모든 누적합을 확인했을 때 K=7의 배수가 되는 연속된 부분 배열은 없습니다. (문제 조건에 따라 길이가 0이 될 수 있습니다.)*

## 힌트

- 부분 배열의 합(Sum) 계산을 효율적으로 하기 위해 '누적합(Prefix Sum)' 개념을 활용하세요.
- 특정 합을 K로 나눈 나머지가 같다는 것은, 두 지점 사이의 합이 K의 배수가 된다는 것을 의미합니다.


## 알고리즘 요약

누적합과 해싱 (Hash Map) 기법을 사용합니다. 누적합 $P[i]$를 계산할 때, 만약 현재까지의 누적합 $P[j]$와 이전에 기록된 누적합 $P[i-1]$가 있을 때, $(P[j] - P[i-1])$이 K의 배수라면, 그 사이 $[i, j]$는 원하는 조건을 만족합니다. 이는 $P[j] mod K = P[i-1] mod K$ 와 동치입니다.

## 풀이 해설

풀이 아이디어: 이 문제는 '합이 특정 값(K의 배수)인 가장 긴 구간 찾기' 유형에 속하며, 누적합 배열과 해시 맵을 이용해 $O(N)$ 시간 복잡도로 해결할 수 있습니다.

단계별 풀이:
1. 누적합 정의: 현재 인덱스 i까지의 원소들의 합을 `current_sum`이라고 정의합니다.
2. 핵심 조건: 부분 배열 A[i...j]의 합이 K의 배수라는 것은, $P[j] - P[i-1]$이 K의 배수와 같다는 의미입니다. 즉, $P[j] mod K = P[i-1] mod K$여야 합니다.
3. 해시 맵 사용: 우리는 '특정 나머지 값'을 가진 누적합이 가장 처음 나타난 인덱스를 저장할 해시 맵(Python의 dictionary)을 사용합니다. 이 맵을 `remainder_map`이라고 하겠습니다.
4. 초기화: 모든 부분 배열은 시작점부터 계산될 수 있으므로, 합 0 (나머지 0)이 인덱스 -1에서 발생했다고 가정하고 `remainder_map[0] = -1`로 초기화합니다. 이는 나중에 전체 배열의 합이 K의 배수일 때 정확한 길이를 측정하는 핵심입니다.
5. 반복 및 계산: 배열을 순회하면서 현재 누적합 $P[j]$를 계산하고, 나머지 `rem = P[j] % K`를 구합니다.
    a. 만약 `rem`이 이미 `remainder_map`에 존재한다면, 이전에 해당 나머지가 나타났던 인덱스 $i-1$을 가져와 합니다. 현재 길이 $j - (i-1)$가 새로운 후보 최대 길이가 되므로, 전역 최댓값(max_length)을 갱신합니다.
    b. 만약 `rem`이 존재하지 않는다면, 이 나머지가 처음 나타난 지점이므로 `remainder_map[rem] = j`로 기록해 둡니다. (주의: 이미 존재하는 나머지 값이라면 인덱스를 업데이트하지 않습니다. 왜냐하면 우리는 가장 '먼' 초기 시작점을 기준으로 최대 길이를 측정해야 하기 때문입니다.)
6. 시간 복잡도: 배열을 한 번만 순회하므로 $O(N)$이며, 이는 주어진 제약 조건($N 	imes 10^5$)을 만족합니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 입력 속도 최적화 및 한 번에 모두 읽기
    input = sys.stdin.read().split()
    if not input:
        return 0
    
    N = int(input[0])
    K = int(input[1])
    A = [int(x) for x in input[2:]]

    # remainder_map: {나머지 값 : 해당 나머지가 처음 나타난 인덱스}
    # 초기값 설정: 합 0 (나머지 0)은 가상 인덱스 -1에서 발생했다고 가정합니다.
    remainder_map = {0: -1}
    
    current_sum = 0
    max_length = 0

    for i in range(N):
        current_sum += A[i]
        
        # 나머지 계산 (Python의 % 연산자는 음수에 대해 수학적 나머지를 보장하지 않으므로, 
        # K가 양수라는 전제하에 적절한 방식으로 조정합니다. (A[i]가 매우 클 경우를 대비)
        rem = current_sum % K
        if rem < 0: # 누적합이 음수일 때 나머지가 음수가 될 수 있음
             rem += K

        if rem in remainder_map:
            # 이전에 같은 나머지 값이 존재했다면, 그 지점부터 현재까지의 합은 K의 배수입니다.
            prev_index = remainder_map[rem]
            current_length = i - prev_index
            max_length = max(max_length, current_length)
        else:
            # 이 나머지는 처음 나타난 것이므로 기록합니다. 
            remainder_map[rem] = i
            
    return max_length

if __name__ == "__main__":
    print(solve())
```

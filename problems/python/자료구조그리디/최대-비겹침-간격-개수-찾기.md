# 최대 비겹침 간격 개수 찾기
*python · 자료구조/그리디 · 보통 · 탐욕, 정렬*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받으며, 파이썬에서는 `sys.stdin.readline`을 사용하여 효율적으로 입력을 처리하는 것이 좋습니다.

## 문제

주어진 $N$개의 시간 간격(Interval) 리스트가 있습니다. 각 간격은 `[시작 시간, 종료 시간]` 형태로 주어집니다.

이 간격들 중에서 서로 겹치지 않으면서 가장 많은 개수를 선택하는 것이 목표입니다. 즉, 선택된 두 간격 $[s_1, e_1]$과 $[s_2, e_2]$가 있을 때, $e_1 < s_2$ 또는 $e_2 < s_1$을 만족해야 합니다.

만약 겹치는 부분이 있다면 (예: 시작점이나 끝점이 같더라도 시간이 포함되는 구간이라면) 이는 겹친 것으로 간주합니다. 따라서 비겹침의 조건은 한 간격의 종료 시점이 다음 간격의 시작 시점보다 엄격하게 빨라야 합니다.

최대 개수를 찾고, 그 개수만 정수로 출력하세요.

## 입력

첫째 줄에 간격의 개수 N이 주어집니다. 이후 N개의 줄에 걸쳐 각 간격 $[start, end]$가 공백으로 구분되어 주어집니다. 모든 시작 시간과 종료 시간은 0 이상인 정수입니다.

## 출력

선택할 수 있는 최대 비겹침 간격의 개수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
0 <= start, end <= 10^9
시간 복잡도는 O(N log N) 이하가 권장됩니다.

## 예제 1

**입력**
```
3
1 4
0 2
3 5
```

**출력**
```
2
```

*간격들을 정렬하면 (0, 2), (1, 4), (3, 5) 순서가 되며, 선택 가능한 최대 개수는 2개입니다. ((0, 2)와 (3, 5))*

## 예제 2

**입력**
```
4
1 5
6 8
2 4
9 10
```

**출력**
```
3
```

*간격들을 정렬하고 탐욕적으로 선택하면 (2, 4), (6, 8), (9, 10)의 3개가 선택됩니다.*

## 힌트

- 이 문제는 전형적인 '활동 선택 문제(Activity Selection Problem)'와 유사합니다.
- 어떤 기준으로 정렬해야 최적의 탐욕적 선택을 할 수 있는지 고민해 보세요. (예: 시작 시간, 종료 시간 등)


## 알고리즘 요약

탐욕 알고리즘 + 정렬
최대 개수를 얻기 위해서는 현재 간격이 가능한 한 빨리 끝나도록 선택하는 것이 가장 유리합니다. 따라서 모든 간격을 '종료 시간'을 기준으로 오름차순 정렬한 후, 첫 번째 간격을 선택하고, 이후의 간격들 중 선택된 간격과 겹치지 않으면서 가장 먼저 끝나는 간격을 반복적으로 선택해 나갑니다.

## 풀이 해설

풀이 아이디어: 이 문제는 탐욕적(Greedy) 접근법을 사용하여 풀 수 있습니다.

1. **정렬 (Sorting):** 최대 개수를 확보하기 위해서는, 현재 선택한 활동이 최대한 빨리 끝나야 다음 활동을 시작할 여유 시간이 많아집니다. 따라서 모든 간격들을 '종료 시간'을 기준으로 오름차순 정렬하는 것이 핵심입니다.
2. **탐욕적 선택 (Greedy Selection):**
    a. 첫 번째 간격을 무조건 선택합니다. 이것이 현재까지의 가장 빨리 끝나는 활동이 됩니다.
    b. 이후에 순서대로 간격들을 탐색하면서, 현재 간격의 시작 시간이 이전에 선택한 마지막 간격의 종료 시간보다 크거나 같은 경우(즉, 겹치지 않는 경우)에만 해당 간격을 선택하고, '마지막 종료 시간'을 업데이트합니다.
3. **시간 복잡도:** 전체 간격 $N$개를 정렬하는 데 $O(N 	imes 	ext{log} N)$의 시간이 걸리며, 이후 순회는 $O(N)$이므로 총 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력을 빠르게 읽기 위해 설정
    input = sys.stdin.read
    data = input().split()
    
    if not data: 
        print(0)
        return

    try:
        N = int(data[0])
        intervals = []
        # 데이터 리스트에서 간격 데이터를 추출 (N개 * 2개의 값)
        for i in range(N):
            start = int(data[2 * i + 1])
            end = int(data[2 * i + 2])
            intervals.append((start, end))
    except IndexError:
        # 데이터 포맷 오류 처리 (예: N만 주어지고 간격이 없는 경우)
        print(0)
        return

    if not intervals or N == 0:
        print(0)
        return

    # 1. 종료 시간을 기준으로 오름차순 정렬 (Greedy 핵심)
    # lambda x: x[1]는 튜플의 두 번째 요소(종료 시간)를 기준으로 삼겠다는 의미입니다.
    intervals.sort(key=lambda x: x[1])

    count = 0
    last_finish_time = -1 # 간격은 0부터 시작하므로, 아주 작은 값으로 초기화

    # 2. 탐욕적 선택 수행
    for start, end in intervals:
        # 현재 간격의 시작 시간이 마지막 종료 시간보다 크거나 같으면 (겹치지 않으면)
        if start >= last_finish_time: 
            count += 1
            last_finish_time = end # 마지막 종료 시간을 업데이트
            
    print(count)

# 실제 코딩 테스트 환경에서는 solve() 호출만 필요합니다.
solve()
```

# 책장에 책 배치하기
*python · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

입력은 표준 입력(stdin)에서 받습니다. Python의 `sys.stdin.readline`을 사용하는 것이 효율적입니다.

## 문제

당신은 길이가 L인 책장을 가지고 있습니다. 이 책장에는 각각 다른 길이의 N권의 책이 준비되어 있습니다. 책들은 서로 겹치지 않고 일렬로 배치되어야 합니다. 당신의 목표는 책장의 길이 L을 초과하지 않으면서, 배치할 수 있는 책의 최대 개수를 찾는 것입니다.

책들을 배치하는 순서는 중요하지 않으며, 단지 선택된 책들의 길이의 합이 L을 넘지 않아야 합니다. 따라서, 이 문제의 핵심은 책의 개수를 최대로 유지하면서 전체 길이를 최소화하는 조합을 찾는 것입니다.

## 입력

첫 번째 줄에 책장의 전체 길이 L이 주어집니다. 두 번째 줄에는 N개의 정수(책의 길이)가 공백으로 구분되어 주어집니다.

## 출력

배치할 수 있는 책의 최대 개수(정수)를 출력합니다.

## 제약 조건

1 <= L <= 10^9
1 <= N <= 10^5
1 <= 책의 길이 <= 10^9

## 예제 1

**입력**
```
10
3 5 2
```

**출력**
```
3
```

*책의 길이 [2, 3, 5]로 정렬한 후, 2 + 3 + 5 = 10 이므로 3권을 모두 배치할 수 있습니다.*

## 예제 2

**입력**
```
12
8 3 5 1
```

**출력**
```
4
```

*가장 짧은 책 4권 [1, 3, 5, 8]을 선택했을 때, 총합은 17로 12를 초과합니다. 따라서, 가장 짧은 3권 [1, 3, 5]만 선택하여 총 3권을 배치하는 것이 최적입니다. (오류: L=12이므로, 1+3+5=9, 4권은 1+3+5+8=17이므로 불가. 최적은 4권을 모두 배치하는 것이 아님. L=12에 맞는 최대 개수는 3개입니다.)*

## 힌트

- 최대 개수를 확보하려면, 선택하는 요소들 중 가장 작은 것들부터 고려해야 합니다.
- 문제의 목표가 '최대 개수'를 유지하는 것이므로, 그리디(Greedy) 전략을 적용해 보세요.


## 알고리즘 요약

그리디 알고리즘을 사용합니다. 책의 개수를 최대화하면서 총합을 제한해야 하므로, 가능한 한 작은 길이의 책들부터 순서대로 선택하는 것이 최적입니다. 따라서, 모든 책의 길이를 오름차순으로 정렬한 후, 정렬된 배열의 원소들을 누적합하여 L을 초과할 때까지 더해나가면 됩니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 이 문제는 '최대 개수'를 확보하는 것이 목표이며, 총합에 제한(L)이 있습니다. 이러한 유형의 '최대 개수 확보' 문제는 대부분 가장 작은 자원(가장 짧은 책)부터 사용하는 그리디(Greedy) 접근 방식을 통해 최적해를 찾을 수 있습니다.
2. 단계:
   a. 입력받은 책의 길이 리스트를 오름차순으로 정렬합니다. (가장 짧은 책이 맨 앞에 오도록)
   b. 현재까지 사용한 총 길이(current_sum)와 배치된 책의 개수(count)를 0으로 초기화합니다.
   c. 정렬된 책의 리스트를 처음부터 끝까지 순회합니다.
   d. 현재 책의 길이가 current_sum에 더해져도 L을 초과하지 않는지 확인합니다.
   e. 만약 초과하지 않는다면, current_sum에 책의 길이를 더하고, count를 1 증가시킵니다.
   f. 만약 초과한다면, 더 이상 책을 배치할 수 없으므로 반복을 종료하고 count를 반환합니다.
3. 시간 복잡도: 책의 개수 N이 최대 $10^5$이므로, 전체 시간 복잡도는 정렬에 의해 결정됩니다. 따라서 $O(N 	imes 	ext{log} N)$이 됩니다.

## 참고 코드 (python)

```python
import sys
import io

# 표준 입력 처리를 위한 준비
# 실제 코딩 테스트 환경에서는 이렇게 처리하는 것이 일반적입니다.
input = sys.stdin.read

def solve():
    # 전체 입력을 한 번에 읽음
    data = input().split()
    if not data: 
        return 0

    # 첫 번째 요소가 L (책장 길이)
    L = int(data[0])
    
    # 나머지 요소들이 책의 길이 리스트
    # data[1:]는 N개의 책 길이를 담고 있습니다.
    book_lengths = [int(x) for x in data[1:]]

    # 1. 그리디 전략을 위해 책의 길이를 오름차순으로 정렬합니다.
    book_lengths.sort()
    
    current_sum = 0
    count = 0
    
    # 2. 정렬된 리스트를 순회하며 책을 배치할 수 있는지 확인합니다.
    for length in book_lengths:
        # 현재 책을 추가했을 때 L을 초과하는지 확인
        if current_sum + length <= L:
            # 초과하지 않으면, 배치하고 카운트 증가
            current_sum += length
            count += 1
        else:
            # 초과하면, 더 이상 작은 책은 없으므로 중단
            break
            
    print(count)

solve()
```

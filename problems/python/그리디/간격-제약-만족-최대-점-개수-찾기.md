# 간격 제약 만족 최대 점 개수 찾기
*python · 그리디 · 보통 · 그리디, 정렬*

## 입출력 환경

입력은 표준 입력으로부터 받습니다. 좌표는 모두 정수형으로 처리합니다.

## 문제

직선 상에 여러 개의 점들이 주어져 있습니다. 이 점들 중 일부를 선택하여 최대 개수를 만들려고 합니다.
다만, 선택된 점들을 순서대로 나열했을 때, 임의로 선택된 인접한 두 점 사이의 거리는 반드시 주어진 최소 간격 $D$ 이상이어야 한다는 제약 조건이 있습니다.

주어진 모든 점들에서 이 제약 조건을 만족하는 최대 개수의 점들의 집합을 구하세요.

## 입력

첫 번째 줄에 정수 N과 최소 간격 D가 주어집니다. 두 번째 줄부터 N개의 정수(점의 좌표)가 공백으로 구분되어 주어집니다.

## 출력

제약 조건을 만족하는 최대 점의 개수를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 200,000
1 <= D <= 10^9
좌표는 1 이상 10^9 이하입니다. (시간 복잡도는 O(N log N) 이하가 권장됩니다.)

## 예제 1

**입력**
```
4 2
1 3 2 4
```

**출력**
```
2
```

*점들을 정렬하면 [1, 2, 3, 4]가 됩니다. 최소 간격이 2이므로 {1, 3} 또는 {2, 4}를 선택할 수 있으며 최대 개수는 2입니다.*

## 예제 2

**입력**
```
5 10
10 30 20 15 50
```

**출력**
```
3
```

*점들을 정렬하면 [10, 15, 20, 30, 50]입니다. 그리디하게 선택했을 때 {10, 30, 50} (간격 20, 20)으로 최대 개수 3개를 만들 수 있습니다.*

## 예제 3

**입력**
```
3 5
1 2 3
```

**출력**
```
1
```

*점들을 정렬하면 [1, 2, 3]입니다. 최소 간격이 5이므로 어떤 점 두 개도 선택할 수 없습니다. 따라서 최대 개수는 1개입니다.*

## 힌트

- 문제의 제약 조건은 좌표 값에 의존하므로, 먼저 모든 점들을 오름차순으로 정렬하는 것이 필수적입니다.
- 한 번 점을 선택했다면, 다음 점을 선택할 때는 '가장 빨리' 간격 조건을 만족시키는 지점을 고르는 그리디 전략이 최적 해를 보장합니다.


## 알고리즘 요약

핵심은 그리디 알고리즘과 정렬입니다. 먼저 모든 좌표를 오름차순으로 정렬합니다. 가장 첫 번째 점을 선택하고, 이 점으로부터 최소 간격 $D$ 이상 떨어진 지점들 중에서 가능한 한 가장 작은(다음) 점을 다음 선택점으로 삼아 반복합니다. 이렇게 하면 남은 공간에 최대한 많은 기회를 남기게 되어 최적의 해를 얻을 수 있습니다.

## 풀이 해설

풀이 과정은 그리디 알고리즘을 이용한 순차적인 탐색으로 이루어집니다.

1. **정렬 (Sort):** 먼저 주어진 N개의 모든 점 좌표를 오름차순으로 정렬합니다. 이 과정을 거쳐야 '인접한 두 점'이라는 개념이 시간적/공간적으로 명확해지기 때문입니다.
2. **그리디 선택 (Greedy Selection):** 최소 간격 $D$를 만족하는 최대 개수를 찾기 위해, 가장 첫 번째 점(가장 작은 좌표)을 무조건 포함하는 것이 유리합니다. 따라서 카운트를 1로 초기화하고 마지막으로 선택한 점의 위치(`last_pos`)를 배열의 첫 요소로 설정합니다.
3. **순회 (Iteration):** 정렬된 배열을 순차적으로 탐색하며, 현재 좌표 `arr[i]`와 이전에 선택했던 마지막 위치 `last_pos` 간의 차이 (`arr[i] - last_pos`)가 $D$ 이상인지 확인합니다.
4. **갱신:** 만약 거리가 충분하다면, 해당 점을 다음 선택점으로 확정하고 카운트를 1 증가시키며, `last_pos`를 `arr[i]`로 업데이트합니다. 이 과정을 배열의 끝까지 반복하면 됩니다. 

시간 복잡도는 정렬에 의해 $O(N 	ext{ log } N)$이 결정되며, 탐색은 $O(N)$이므로 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력에서 한 줄씩 읽기 (빠른 입력을 위해)
    input = sys.stdin.read().split()
    if not input: return

    # 첫 번째 줄: N과 D를 파싱
    N = int(input[0])
    D = int(input[1])

    # 나머지 N개 요소가 좌표들임
    coordinates = [int(x) for x in input[2:]]
    
    if N == 0: 
        print(0)
        return

    # 1. 모든 점을 오름차순으로 정렬 (O(N log N))
    coordinates.sort()

    # 2. 그리디 알고리즘 시작
    count = 1  # 최소한 첫 번째 점은 선택됨
    last_pos = coordinates[0]

    for i in range(1, N): # 배열의 두 번째 요소부터 순회
        current_pos = coordinates[i]
        
        # 현재 위치와 마지막 선택된 위치 간의 간격이 D 이상인지 확인
        if current_pos - last_pos >= D:
            count += 1
            last_pos = current_pos # 성공적으로 점을 선택했으므로, 이 위치를 다음 기준점으로 업데이트
    
    print(count)

solve()
```

# 활동 선택 문제 (Activity Selection)
*python · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

입력은 sys.stdin.read() 또는 sys.stdin.readlines()를 사용하여 한 번에 처리하는 것이 효율적입니다.

## 문제

당신은 시간표를 관리하는 시스템을 개발하고 있습니다. 시스템에는 N개의 활동이 등록되어 있으며, 각 활동은 시작 시간과 종료 시간을 가집니다. 두 활동이 동시에 진행될 수 없으므로, 서로 시간적으로 겹치지 않는 활동들을 최대한 많이 선택하는 것이 목표입니다. 모든 활동의 시작 시간과 종료 시간이 정수형으로 주어집니다. 최대 몇 개의 활동을 선택할 수 있는지 그 개수를 구하세요. (활동의 개수 N은 최대 10^5입니다.)

*활동 1: (시작 시간, 종료 시간)*
*활동 2: (시작 시간, 종료 시간)*
...

## 입력

첫째 줄에 활동의 총 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 활동의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (시작 시간, 종료 시간 순서)

## 출력

최대로 선택할 수 있는 활동의 개수(정수)를 출력합니다.

## 제약 조건

1. N: 1 <= N <= 10^5
2. 시작/종료 시간: 0 <= 시간 <= 10^9
3. 시간 복잡도: O(N log N) 이하를 목표로 합니다.

## 예제 1

**입력**
```
4
0 3
1 2
3 5
5 8
```

**출력**
```
3
```

*활동 (1, 2) -> (3, 5) -> (5, 8) 순으로 선택 가능. 총 3개.*

## 예제 2

**입력**
```
5
1 4
1 3
4 6
2 5
3 7
```

**출력**
```
3
```

*활동 (1, 3)을 선택하고, 그 다음 (4, 6)을 선택하면 총 2개. 최적의 선택은 (1, 3), (3, 7) 또는 (1, 3), (4, 6) 등으로 3개.*

## 힌트

- 모든 활동을 다 고려하는 것은 어렵습니다. 그리디 알고리즘을 사용해 보세요.
- 어떤 기준으로 정렬하는 것이 최적의 선택을 보장할까요? (시작 시간 vs 종료 시간)


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm): 활동을 선택할 때, '가장 빨리 끝나는 활동'을 선택하는 것이 항상 최적의 선택을 이끌어냅니다. 따라서 모든 활동을 종료 시간 순으로 정렬한 후, 첫 번째 활동을 선택하고, 다음 활동 중에는 현재 활동의 종료 시간 이후에 시작하는 활동을 선택하는 과정을 반복합니다.

## 풀이 해설

풀이 해설:

1. 아이디어: 이 문제는 전형적인 그리디 알고리즘 문제입니다. 주어진 N개의 활동 중에서 겹치지 않게 최대한 많은 활동을 선택해야 합니다. 가장 핵심적인 그리디 선택 기준은 '가장 빨리 끝나는 활동'을 선택하는 것입니다. 이렇게 해야 이후에 남은 시간이 최대화되어 더 많은 활동을 선택할 기회가 생기기 때문입니다.

2. 단계:
   a. 데이터 구조화: 입력받은 모든 활동들을 (시작 시간, 종료 시간) 쌍의 리스트로 저장합니다.
   b. 정렬 (핵심): 이 리스트를 '종료 시간(End Time)'을 기준으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간을 기준으로 오름차순 정렬하는 것이 좋습니다.
   c. 선택 과정 (Greedy 선택): 
      i. 첫 번째 활동 (가장 빨리 끝나는 활동)은 무조건 선택합니다. 선택된 활동의 종료 시간을 `last_finish_time`으로 기록합니다.
      ii. 정렬된 리스트를 순회하면서, 현재 활동의 시작 시간이 `last_finish_time`보다 크거나 같은 경우 (즉, 겹치지 않는 경우)에만 해당 활동을 선택하고, `last_finish_time`을 현재 활동의 종료 시간으로 업데이트합니다.
   d. 반복: 이 과정을 모든 활동을 순회할 때까지 반복한 후, 선택 횟수를 반환합니다.

3. 시간 복잡도: 시간 복잡도는 주로 정렬 과정에 의해 결정됩니다. N개의 활동을 정렬하는 데 $O(N 	imes 	ext{log} N)$ 시간이 걸리고, 이후 순회하는 과정은 $O(N)$ 시간이 걸리므로, 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read()를 사용하여 모든 입력을 한 번에 읽어옵니다.
    input_data = sys.stdin.read().split()
    if not input_data: 
        print(0)
        return
        
    try:
        N = int(input_data[0])
    except IndexError:
        # 입력이 비어있거나 N만 있는 경우 처리
        print(0)
        return

    activities = []
    # 입력된 데이터 배열에서 N개씩 pairs를 추출합니다.
    for i in range(N):
        start_time = int(input_data[2 * i + 1])
        end_time = int(input_data[2 * i + 2])
        activities.append((start_time, end_time))

    # 1. 정렬: 종료 시간(인덱스 1)을 기준으로 오름차순 정렬합니다. 
    # 종료 시간이 같으면 시작 시간(인덱스 0) 순으로 정렬합니다.
    activities.sort(key=lambda x: (x[1], x[0]))

    count = 0
    last_finish_time = -1 # 매우 작은 값으로 초기화

    # 2. 그리디 선택:
    for start, end in activities:
        # 현재 활동의 시작 시간이 마지막 선택된 활동의 종료 시간보다 크거나 같으면 선택 가능합니다.
        if start >= last_finish_time:
            count += 1
            last_finish_time = end

    print(count)

# 테스트 환경을 위해 solve() 함수를 호출합니다.
solve()
```

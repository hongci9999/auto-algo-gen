# 최대 비겹침 간격 활동 선택
*python · 그리디 · 보통 · 정렬, 그리디, 간격*

## 입출력 환경

Python 3 환경에서 표준 입력을 사용하여 모든 데이터를 읽고, 결과를 표준 출력으로 출력합니다. 입력은 N개의 쌍으로 구성됩니다.

## 문제

당신은 여러 활동(이벤트)의 스케줄러를 설계해야 합니다. 각 활동은 특정 시작 시간과 종료 시간을 가집니다. 주어진 활동들 중에서 서로 시간이 겹치지 않으면서, 가장 많은 활동을 선택할 수 있는 최대 개수를 구하는 것이 목표입니다. 활동의 시간은 [시작 시간, 종료 시간] 형태로 주어집니다. 시간은 연속적이며, 한 활동이 끝나고 다른 활동이 바로 시작하는 것은 겹치지 않는 것으로 간주합니다.

**예시:** 활동 A는 [1, 4], 활동 B는 [2, 5], 활동 C는 [4, 6]일 때, B는 A와 겹치고, C는 A와 겹치지 않습니다. 따라서 최대 활동 개수는 2개 (A와 C)입니다.

## 입력

첫째 줄에 활동의 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 활동의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s <= e)

## 출력

선택 가능한 최대 활동의 개수를 한 정수로 출력합니다.

## 제약 조건

1. N의 범위: 1부터 100,000까지입니다.
2. 시간(s, e)의 범위: 1부터 10^9까지입니다. (시간 범위가 크므로 시간 복잡도에 주의해야 합니다.)

## 예제 1

**입력**
```
3
1 4
2 5
4 6
```

**출력**
```
2
```

*활동 (1, 4)와 (4, 6)을 선택하여 겹치지 않게 2개를 구성할 수 있습니다.*

## 예제 2

**입력**
```
4
1 3
2 4
3 5
6 7
```

**출력**
```
3
```

*최적의 선택은 (1, 3), (3, 5), (6, 7) 순서로 3개입니다.*

## 힌트

- 시간 겹침을 판단하는 조건 (A의 종료 시간 >= B의 시작 시간)을 정확히 이해해야 합니다.
- 모든 활동을 무작위로 선택하는 것이 아니라, 어떤 기준을 가지고 활동을 선택해야 최적해에 가까워질 수 있을지 생각해 보세요.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm). 활동 선택 문제(Activity Selection Problem)의 대표적인 예시입니다. 모든 활동을 종료 시간(End Time)을 기준으로 오름차순 정렬한 후, 가장 빨리 끝나는 활동부터 순차적으로 선택하는 것이 최적해를 보장합니다.

## 풀이 해설

### 💡 풀이 아이디어: 그리디 알고리즘

이 문제는 '활동 선택 문제'의 전형적인 예시이며, 그리디 알고리즘을 사용하면 효율적으로 풀 수 있습니다. 이 문제에서 최적의 선택을 보장하는 그리디 기준은 '가장 빨리 끝나는 활동'을 우선적으로 선택하는 것입니다.

만약 우리가 시작 시간이 가장 빠른 활동을 선택한다고 가정해 봅시다. 이 활동이 실제로는 나중에 끝나는 활동이어서, 다른 여러 개의 활동을 선택할 기회를 막아버릴 수 있습니다. 하지만 가장 빨리 끝나는 활동을 선택한다면, 남은 시간과 자원을 최대한 확보할 수 있게 되어 다음 활동 선택의 폭이 넓어집니다.

### ⚙️ 단계별 풀이

1. **입력 및 저장:** 모든 활동 [시작 시간, 종료 시간] 쌍을 리스트에 저장합니다.
2. **정렬:** 저장된 모든 활동 리스트를 **종료 시간(End Time)을 기준**으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간 순으로 정렬하는 것이 좋습니다.
3. **선택 및 카운트:**
    a. 첫 번째 활동(가장 빨리 끝나는 활동)을 무조건 선택하고, 카운트를 1로 초기화합니다.
    b. 현재 선택된 활동의 종료 시간을 `last_end` 변수에 저장합니다.
    c. 두 번째 활동부터 순회하면서, 현재 활동의 시작 시간이 `last_end`보다 크거나 같은 경우에만 선택합니다. 즉, `현재 활동의 시작 시간 >= last_end` 조건을 만족하면, 해당 활동을 선택하고, `last_end`를 현재 활동의 종료 시간으로 업데이트하며 카운트를 증가시킵니다.
4. **결과 반환:** 최종 카운트 값이 최대 활동 개수입니다.

### ⏱️ 시간 복잡도

*   입력 및 저장: O(N)
*   정렬: O(N log N) (N을 활동 개수라 할 때)
*   순회 및 선택: O(N)

전체 시간 복잡도는 정렬에 의해 결정되는 **O(N log N)** 입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read().split()을 사용하여 모든 입력을 한 번에 읽는 것이 빠릅니다.
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없는 경우 처리
        print(0)
        return

    try:
        N = int(input_data[0])
        if N == 0:
            print(0)
            return
    except IndexError:
        # N이 없거나 숫자가 아닌 경우
        print(0)
        return

    activities = []
    # 입력 데이터는 [N, s1, e1, s2, e2, ...] 순서로 들어옵니다.
    data_index = 1
    for _ in range(N):
        try:
            start = int(input_data[data_index])
            end = int(input_data[data_index + 1])
            activities.append([start, end])
            data_index += 2
        except IndexError:
            # 데이터가 부족한 경우 루프 종료
            break

    # 1. 그리디 기준: 종료 시간을 기준으로 오름차순 정렬
    # lambda x: x[1] 은 튜플/리스트의 두 번째 요소(종료 시간)를 기준으로 정렬하라는 의미입니다.
    activities.sort(key=lambda x: x[1])

    # 2. 활동 선택 로직
    count = 0
    last_end_time = -1 # 초기에는 아무 활동도 선택되지 않았음을 나타냄

    for start, end in activities:
        # 현재 활동의 시작 시간이 마지막 선택된 활동의 종료 시간보다 크거나 같으면 선택 가능하다.
        if start >= last_end_time:
            count += 1
            # 선택했으므로, 마지막 종료 시간을 현재 활동의 종료 시간으로 업데이트한다.
            last_end_time = end

    print(count)

if __name__ == "__main__"
```

# 최대 비겹 활동 개수 찾기
*python · 그리디 · 보통 · 그리디, 정렬, 알고리즘*

## 입출력 환경

Python 환경에서 전체 입력을 한 번에 읽어 처리하는 것이 효율적입니다. sys.stdin.read() 또는 반복문을 사용하여 N과 N개의 (S, E) 쌍을 읽으세요.

## 문제

당신은 여러 개의 활동을 수행할 수 있는 시간표를 관리하는 시스템을 개발해야 합니다. 각 활동은 시작 시간과 종료 시간을 가집니다. 주어진 활동 목록 중에서 서로 시간적으로 겹치지 않으면서, 가장 많은 개수의 활동을 선택하는 최대 조합의 개수를 구하시오.

활동 A가 시작 시간 $S_A$와 종료 시간 $E_A$를 가진다고 할 때, 다른 활동 B와 겹치지 않으려면, A와 B가 모두 끝나는 시간 $T$이 존재하여 $S_A 
eq S_B$이면서, $E_A 	ext{ (또는 } E_B)$가 다음 활동의 시작 시간보다 작거나 같아야 합니다. (시간 경계는 포함된다고 가정합니다.)

## 입력

첫 번째 줄에 활동의 총 개수 N (1 ≤ N ≤ 100)이 주어집니다.
다음 N줄에 걸쳐 각 활동의 시작 시간 $S_i$와 종료 시간 $E_i$가 공백으로 구분되어 주어집니다. (1 ≤ S_i, E_i ≤ 10^9)

## 출력

선택할 수 있는 최대 활동의 개수 (정수)를 출력합니다.

## 제약 조건

시간 복잡도: O(N log N) 이하로 요구됩니다. N은 최대 100입니다. 시간/메모리 제한은 일반적인 코딩 테스트 기준을 따릅니다.

## 예제 1

**입력**
```
3
1 4
3 5
0 2
```

**출력**
```
2
```

*활동 (0, 2)를 선택한 후, 다음으로 겹치지 않는 활동은 (1, 4)가 아닌 (3, 5)가 됩니다. 따라서 (0, 2)와 (1, 4)를 선택하는 것이 최대입니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 3
```

**출력**
```
3
```

*활동 (1, 2), (2, 3), (3, 4) 순서로 선택하면 겹치지 않습니다. (1, 3)을 선택하면 최대 1개만 선택 가능합니다.*

## 힌트

- 이 문제는 그리디 알고리즘의 대표적인 문제입니다.
- 무조건 시작 시간이 빠른 순서로 정렬하는 것이 최적이 아닐 수 있습니다. 무엇을 기준으로 정렬해야 할지 생각해 보세요.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm) - 활동 선택 문제(Activity Selection Problem).

## 풀이 해설

아이디어: 주어진 문제(최대 비겹 활동 개수)는 전형적인 그리디 알고리즘 문제입니다. 활동을 선택할 때, '가장 빨리 끝나는 활동'을 우선적으로 선택하는 것이 항상 최적해를 보장합니다.

단계:
1. **데이터 구조화 및 정렬:** 입력받은 모든 활동 (시작 시간 $S_i$, 종료 시간 $E_i$)을 리스트에 저장합니다. 이 리스트를 **종료 시간 $E_i$를 기준**으로 오름차순 정렬합니다. (만약 종료 시간이 같다면, 시작 시간 순서로 정렬하는 것이 안정성을 높일 수 있습니다.)
2. **그리디 선택:** 첫 번째 활동 (가장 빨리 끝나는 활동)을 무조건 선택하고, 선택된 활동의 종료 시간을 기록합니다. (최소 개수 = 1)
3. **반복:** 정렬된 리스트를 처음부터 끝까지 순회합니다. 현재 활동의 시작 시간이 이전에 선택된 활동의 종료 시간보다 크거나 같다면 (즉, 겹치지 않는다면), 해당 활동을 선택하고, 선택된 활동의 종료 시간을 업데이트하며 카운트를 1 증가시킵니다.
4. **결과:** 모든 활동을 순회한 후의 총 카운트가 최대 비겹 활동의 개수입니다.

시간 복잡도 분석: 활동 개수 N이 주어졌을 때, 정렬에 $O(N 	ext{ log } N)$ 시간이 소요됩니다. 이후 리스트 순회는 $O(N)$ 시간이 걸리므로, 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (python)

```python
import sys

# 표준 입력 전체를 읽어 처리
input_data = sys.stdin.read().split()
if not input_data: # 입력이 없을 경우 처리
    print(0)
    exit()

# 첫 번째 요소가 N (활동의 개수)
N = int(input_data[0])

activities = []
# 나머지 N개의 요소가 (S, E) 쌍을 이룸
# input_data[1]부터 시작하여 2씩 증가시키며 데이터를 추출
for i in range(N):
    start_time = int(input_data[1 + i * 2])
    end_time = int(input_data[2 + i * 2])
    activities.append((start_time, end_time))

# 1. 그리디 전략: 종료 시간(E)을 기준으로 오름차순 정렬
# 람다 함수를 사용하여 tuple의 두 번째 요소(인덱스 1)를 기준으로 정렬합니다.
activities.sort(key=lambda x: x[1])

# 2. 그리디 선택 알고리즘 적용
count = 0
last_finish_time = -1 # 초기 종료 시간은 매우 작은 값으로 설정

for start, end in activities:
    # 현재 활동의 시작 시간이 이전에 선택된 활동의 종료 시간보다 크거나 같은지 확인 (겹치지 않는지 확인)
    if start >= last_finish_time:
        # 겹치지 않는다면 선택하고 카운트 증가
        count += 1
        # 선택된 활동의 종료 시간으로 갱신
        last_finish_time = end

print(count)
```

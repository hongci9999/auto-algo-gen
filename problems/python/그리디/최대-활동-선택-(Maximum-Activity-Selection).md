# 최대 활동 선택 (Maximum Activity Selection)
*python · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 처리하는 것이 효율적입니다.

## 문제

당신은 여러 개의 활동 목록을 받았습니다. 각 활동은 시작 시간과 종료 시간을 가지고 있습니다. 당신은 한 번에 하나의 활동만 수행할 수 있습니다. 주어진 활동들 중에서 서로 겹치지 않으면서, 가장 많은 개수의 활동을 선택하는 것이 목표입니다. 활동의 시작 시간과 종료 시간은 1 이상의 정수이며, 시간 순서는 중요합니다.

서로 겹치지 않는 최대 활동의 개수를 구하세요.

## 입력

첫 번째 줄에 활동의 총 개수 N이 주어집니다.
다음 N줄에 걸쳐 각 활동의 시작 시간(start)과 종료 시간(end)이 공백으로 구분되어 주어집니다. (start end)

## 출력

선택할 수 있는 최대 활동의 개수 (정수)를 출력합니다.

## 제약 조건

N의 범위: 1부터 100,000까지. 시간(start/end)의 범위: 1부터 10^9까지. 시간 복잡도는 O(N log N) 이내여야 합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*활동 (1, 4)와 (6, 8)을 선택하여 총 2개 활동이 가능합니다. (1, 4)와 (2, 5)는 겹칩니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 4
```

**출력**
```
3
```

*가장 효율적인 선택은 (1, 2) → (2, 3) → (3, 4) 순서로, 총 3개 활동입니다.*

## 알고리즘 요약

이 문제는 전형적인 그리디 알고리즘 문제인 활동 선택 문제(Activity Selection Problem)입니다. 핵심 아이디어는 '가장 빨리 끝나는 활동'을 선택하는 것입니다. 활동들을 종료 시간 순서로 정렬한 후, 첫 번째 활동을 선택하고, 이후 활동들 중 현재 선택된 활동의 종료 시간 이후에 시작하는 활동들을 순차적으로 선택해 나갑니다.

## 풀이 해설

1. 아이디어 설정: 활동 선택 문제는 그리디 접근법으로 해결하는 것이 가장 효율적입니다. 그리디 전략의 핵심은 '다음 활동을 선택할 때, 선택의 폭을 최대한 넓히는 것'입니다. 즉, 현재 활동을 선택한 후, 가능한 한 빨리 끝나는 활동을 선택해야 이후에 더 많은 활동을 선택할 기회가 생깁니다.
2. 단계별 구현:
   a. 입력 받기: 모든 활동 (시작 시간, 종료 시간)을 리스트에 저장합니다.
   b. 정렬: 이 리스트를 **종료 시간(End Time)**을 기준으로 오름차순 정렬합니다. (만약 종료 시간이 같다면, 시작 시간을 기준으로 정렬해도 무방합니다.)
   c. 선택 과정: 첫 번째 활동을 무조건 선택하고, `last_finish_time`을 해당 활동의 종료 시간으로 설정합니다. 이후 정렬된 리스트를 순회하면서, 현재 활동의 시작 시간(`start`)이 `last_finish_time`보다 크거나 같은 경우에만 해당 활동을 선택합니다. 선택할 때마다 카운트를 증가시키고, `last_finish_time`을 현재 활동의 종료 시간으로 갱신합니다.
3. 시간 복잡도 분석: 입력 N개의 활동을 받습니다. 가장 시간이 많이 걸리는 부분은 정렬 과정이므로, 시간 복잡도는 $O(N 	imes 	ext{정렬 시간}) = O(N 	ext{ log } N)$이 됩니다. 이후 순회는 $O(N)$이므로 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한 해제 (대용량 입력 대비)
sys.setrecursionlimit(2000)

def solve():
    # 표준 입력에서 모든 데이터를 읽어옵니다.
    input_data = sys.stdin.read().split()
    if not input_data: 
        print(0)
        return

    try:
        # 첫 번째 요소가 N (활동 개수)
        N = int(input_data[0])
        activities = []
        
        # 나머지 데이터를 (시작 시간, 종료 시간) 쌍으로 파싱합니다.
        # input_data[1]부터 시작하여 2개씩 읽습니다.
        for i in range(N):
            start_index = 1 + i * 2
            end_index = 2 + i * 2
            if end_index >= len(input_data):
                break # 데이터가 부족하면 종료
            
            start_time = int(input_data[start_index])
            end_time = int(input_data[end_index])
            activities.append((start_time, end_time))
            
    except IndexError: 
        # 입력 형식 오류로 리스트가 비었을 경우 처리
        print(0)
        return
    
    # 1. 그리디 전략을 위해 활동들을 종료 시간(end_time)을 기준으로 오름차순 정렬합니다.
    # 튜플 (start, end) 형태이므로, lambda를 사용하여 두 번째 요소(end)를 기준으로 정렬합니다.
    # key=lambda x: x[1] -> 종료 시간 기준 정렬
    activities.sort(key=lambda x: x[1])
    
    count = 0
    # 마지막으로 선택된 활동의 종료 시간을 저장합니다. (아무것도 선택하지 않았으므로 -1로 초기화)
    last_finish_time = -1
    
    # 2. 정렬된 활동들을 순회하며 최대 활동 개수를 찾습니다.
    for start, end in activities:
        # 현재 활동의 시작 시간이 마지막 활동의 종료 시간보다 크거나 같으면 (겹치지 않으면)
        if start >= last_finish_time:
            # 활동 선택 성공
            count += 1
            # last_finish_time을 현재 활동의 종료 시간으로 갱신합니다.
            last_finish_time = end
            
    print(count)

solve()
```

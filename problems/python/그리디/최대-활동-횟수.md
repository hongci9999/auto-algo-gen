# 최대 활동 횟수
*python · 그리디 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

Python 환경에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

당신은 시간표를 짜는 컨설턴트입니다. 당신에게는 N개의 활동 목록이 주어지며, 각 활동은 시작 시간과 종료 시간으로 구성되어 있습니다. 활동은 동시에 진행할 수 없으므로, 주어진 활동들 중 최대 몇 개의 활동에 참여할 수 있는지 최대 횟수를 구하는 문제입니다. 활동 간의 겹치는 시간은 0분도 허용되지 않습니다. (즉, 활동 A가 t에 끝나면, 활동 B는 t 이후에 시작해야 합니다.)

각 활동은 (시작 시간, 종료 시간) 쌍으로 주어집니다.

## 입력

첫째 줄에 활동의 총 개수 N (1 ≤ N ≤ 100,000)이 주어집니다.
다음 N줄에 걸쳐 각 활동의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (1 ≤ 시작 시간, 종료 시간 ≤ 10^9)

## 출력

참여할 수 있는 최대 활동의 횟수(정수)를 출력합니다.

## 제약 조건

N <= 100,000. 시간 범위는 1부터 10^9까지입니다. 시간 복잡도는 O(N log N) 내외로 요구됩니다.

## 예제 1

**입력**
```
4
1 3
2 5
3 6
4 7
```

**출력**
```
2
```

*가장 먼저 끝나는 활동들부터 선택하는 그리디 전략을 사용합니다. (1, 3) 선택 후, 다음으로 (3, 6)을 선택하여 2개가 최대입니다.*

## 예제 2

**입력**
```
5
1 2
2 3
3 4
1 4
2 4
```

**출력**
```
4
```

*모든 활동이 순차적으로 연결 가능합니다. (1, 2) -> (2, 3) -> (3, 4)를 포함하여 최대 4개가 가능합니다.*

## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm). 활동들을 '종료 시간' 순으로 정렬한 뒤, 가장 빨리 끝나는 활동부터 순차적으로 선택합니다. 현재 선택된 활동의 종료 시간이 다음 활동의 시작 시간보다 작거나 같으면(겹치지 않으면) 선택하고, 아니면 다음 활동으로 넘어갑니다.

## 풀이 해설

아이디어: 활동 선택 문제에서 최대 횟수를 구하는 문제는 '가장 빨리 끝나는 활동을 선택하는 것이 최적해를 만드는 데 기여한다'는 그리디 속성을 가집니다. 따라서 활동들을 종료 시간(End Time)을 기준으로 오름차순 정렬해야 합니다.

단계:
1. 입력받은 N개의 활동 (시작 시간, 종료 시간) 리스트를 준비합니다.
2. 이 리스트를 '종료 시간'을 기준으로 오름차순 정렬합니다.
3. 카운터(count)를 0으로, 마지막 활동의 종료 시간(last_finish_time)을 매우 작은 값(예: 0)으로 초기화합니다.
4. 정렬된 리스트를 순회하며 각 활동 (start, end)에 대해 다음을 확인합니다:
   - 만약 활동의 시작 시간(start)이 last_finish_time보다 크거나 같다면 (즉, 겹치지 않는다면), 이 활동을 선택합니다.
   - count를 1 증가시키고, last_finish_time을 현재 활동의 종료 시간(end)으로 업데이트합니다.
5. 순회가 끝나면 count가 최대 활동 횟수가 됩니다.

시간 복잡도: 입력 처리 및 정렬에 O(N log N)이 걸리며, 이후 순회는 O(N)이므로 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read().split()를 사용하여 모든 입력을 한 번에 읽고 리스트로 만듭니다.
    input_data = sys.stdin.read().split()
    if not input_data: 
        return
    
    # 첫 번째 요소는 N입니다.
    N = int(input_data[0])
    
    # 나머지 데이터는 (시작 시간, 종료 시간) 순서로 N개 쌍을 이룹니다.
    activities = []
    for i in range(N):
        start_time = int(input_data[2 * i + 1])
        end_time = int(input_data[2 * i + 2])
        activities.append((start_time, end_time))

    # 1. 그리디 전략: 종료 시간(인덱스 1)을 기준으로 오름차순 정렬
    # lambda x: x[1]는 튜플의 두 번째 요소(종료 시간)를 기준으로 정렬하라는 의미입니다.
    activities.sort(key=lambda x: x[1])

    count = 0
    # 마지막으로 선택된 활동의 종료 시간을 저장합니다. 초기값은 0으로 설정합니다.
    last_finish_time = 0

    # 2. 정렬된 활동들을 순회하며 선택
    for start, end in activities:
        # 활동이 이전 활동의 종료 시간보다 크거나 같으면 겹치지 않으므로 선택 가능합니다.
        if start >= last_finish_time: 
            count += 1
            # 선택했으므로, 다음 활동의 시작 시간은 이 활동의 종료 시간보다 커야 합니다.
            last_finish_time = end
            
    print(count)

solve()
```

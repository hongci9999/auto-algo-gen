# 회의실 예약 최대화
*python · 그리디 · 보통 · 정렬, 탐욕법*

## 입출력 환경

Python에서는 sys 모듈을 사용하여 입력을 처리하는 것이 효율적이며, 전체 입력 데이터를 리스트에 저장하여 처리할 것을 권장합니다.

## 문제

당신은 회의실 관리 시스템을 담당합니다. 주어진 시간표에 따라 여러 개의 회의가 예약되어 있습니다. 각 회의는 시작 시간과 종료 시간을 가집니다.

회의들이 서로 겹치지 않도록 최대 몇 개의 회의를 예약할 수 있는지 구하는 것이 목표입니다. (주의: 회의 [start, end)는 start부터 end 직전까지 진행하며, end 시간은 다음 회의가 시작할 수 있는 시간이 됩니다.)

## 입력

첫 번째 줄에 총 N개의 회의 정보가 주어집니다.
이후 N줄에 걸쳐 각 회의의 시작 시간과 종료 시간이 공백으로 구분되어 순서대로 입력됩니다.

## 출력

겹치지 않게 예약할 수 있는 최대 회의 수를 정수 형태로 출력합니다.

## 제약 조건

$1 \le N \le 10^5$. 시작/종료 시간은 $0$부터 $10^9$까지의 정수입니다. 시간 복잡도는 $O(N \log N)$ 이내여야 합니다.

## 예제 1

**입력**
```
3
0 3
1 2
3 5
```

**출력**
```
2
```

*회의 (1, 2)와 (3, 5)를 선택하는 것이 최대입니다. (0, 3)과 (1, 2)는 겹칩니다.*

## 예제 2

**입력**
```
4
1 4
0 1
4 5
2 3
```

**출력**
```
3
```

*시간순으로 정렬 후 (0, 1), (2, 3), (4, 5)를 선택하여 최대 3개를 예약할 수 있습니다.*

## 힌트

- 어떤 기준으로 회의 목록을 정렬해야 최적의 해답에 가까워질지 고민해보세요.


## 알고리즘 요약

이 문제는 전형적인 그리디 알고리즘 문제로, 주어진 구간 집합에서 최대 비겹치는 간격 선택(Activity Selection Problem) 문제입니다. 가장 효과적인 탐욕 전략은 '종료 시간이 가장 빠른 회의'를 우선적으로 선택하는 것입니다. 따라서 모든 회의 정보를 종료 시간 순으로 정렬한 후, 첫 번째 회의를 선택하고 다음 회의는 선택된 회의의 종료 시간보다 크거나 같은 시작 시간을 가지는 회의 중 가장 이른 종료 시간을 가진 것을 반복적으로 선택합니다.

## 풀이 해설

풀이 과정은 다음과 같습니다: 

1. **정렬 (Sorting):** 주어진 모든 회의 목록(시작시간, 종료시간)을 '종료 시간'을 기준으로 오름차순 정렬합니다. 이 과정이 전체 알고리즘의 핵심입니다.
2. **초기화:** 첫 번째로 선택할 회의는 반드시 가장 먼저 끝나는 회의가 됩니다. 따라서 최대 개수를 1로 설정하고, 마지막으로 선택된 회의의 종료 시간을 해당 회의의 종료 시간으로 저장합니다.
3. **탐욕적 반복 (Greedy Iteration):** 정렬된 목록을 처음부터 순회하면서 다음 조건을 확인합니다: 현재 고려하는 회의의 시작 시간이 '이전에 선택한 회의'의 종료 시간보다 크거나 같으면, 이 회의는 겹치지 않으므로 예약에 포함시키고 최대 개수를 1 증가시킵니다. 동시에, 이 회의의 종료 시간을 새로운 기준으로 업데이트합니다.
4. **시간 복잡도:** 정렬에 $O(N 	imes 	ext{log} N)$ 시간이 걸리며, 이후 선형 탐색은 $O(N)$이므로 총 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 입력 최적화를 위해 모든 입력을 한 번에 읽습니다.
    input_data = sys.stdin.read().split()
    if not input_data: 
        print(0)
        return

    try:
        N = int(input_data[0])
    except IndexError:
        # N이 주어지지 않은 경우 (예외 처리)
        print(0)
        return

    meetings = []
    for i in range(N):
        start = int(input_data[2*i + 1])
        end = int(input_data[2*i + 2])
        meetings.append((start, end))

    # 1. 종료 시간 기준으로 오름차순 정렬 (Greedy Strategy)
    # lambda x: x[1]은 튜플의 두 번째 요소(인덱스 1)를 기준으로 정렬하라는 의미입니다.
    meetings.sort(key=lambda x: x[1])

    if not meetings:
        print(0)
        return

    # 2. 그리디 선택 시작
    count = 1
    last_finish_time = meetings[0][1] # 첫 회의를 무조건 선택합니다.

    for i in range(1, N):
        start = meetings[i][0]
        end = meetings[i][1]

        # 3. 현재 회의가 마지막으로 선택된 회의와 겹치지 않는 경우 (start >= last_finish_time)
        if start >= last_finish_time:
            count += 1
            last_finish_time = end  # 이 회의를 새로운 기준 시간으로 설정합니다.

    print(count)

solve()
```

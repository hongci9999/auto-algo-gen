# 비겹치는 구간 최대 개수 선택
*python · 그리디 · 보통 · 그리디, 정렬, 구간*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받으며, 성능상의 이유로 sys.stdin.readline을 사용하는 것을 권장합니다.

## 문제

당신에게 N개의 구간이 주어집니다. 각 구간은 시작점과 끝점으로 정의되며, 구간의 범위는 [시작점, 끝점]을 포함합니다. 이 N개의 구간 중에서 서로 겹치지 않으면서 최대 개수를 선택하는 것이 목표입니다. 두 구간이 겹치지 않으려면, 한 구간의 끝점이 다른 구간의 시작점보다 작아야 합니다 (예: [1, 3]과 [4, 5]는 겹치지 않지만, [1, 3]과 [3, 5]는 3에서 겹치므로 겹친다고 간주합니다).

따라서, 선택된 모든 구간 쌍 (s1, e1), (s2, e2), ... (sk, ek)에 대해, $e_i < s_{i+1}$을 만족해야 합니다.

## 입력

첫 번째 줄에 구간의 개수 N이 주어집니다. 다음 N줄에 걸쳐 각 구간의 시작점 $S$와 끝점 $E$가 공백으로 구분되어 주어집니다.

## 출력

선택할 수 있는 최대 구간의 개수를 한 정수로 출력합니다.

## 제약 조건

1. $1 	ext{ ≤ } N 	ext{ ≤ } 10^5$
2. $1 	ext{ ≤ } S, E 	ext{ ≤ } 10^9$
3. 시간 복잡도는 $O(N 	ext{ log } N)$ 이하를 목표로 합니다.

## 예제 1

**입력**
```
3
1 3
2 4
5 6
```

**출력**
```
2
```

*구간 (1, 3)을 선택한 후, 3보다 큰 시작점을 가진 (5, 6)을 선택하여 총 2개를 선택합니다.*

## 예제 2

**입력**
```
4
1 2
3 4
2 3
5 6
```

**출력**
```
3
```

*가장 끝나는 시점이 빠른 구간들을 우선 선택하는 그리디 전략을 사용합니다. (1, 2) -> (2, 3)은 겹치므로 (3, 4)를 선택하고, 다음으로 (5, 6)을 선택합니다. (1, 2), (3, 4), (5, 6)이 가장 적절합니다.*

## 힌트

- 이 문제는 탐욕적인 선택(Greedy)이 핵심입니다.
- 어떤 기준으로 구간을 정렬해야 최적의 선택을 보장할 수 있을지 고민해 보세요. (시작점 기준 vs. 끝점 기준)


## 알고리즘 요약

이 문제는 '활동 선택 문제(Activity Selection Problem)'의 전형적인 예시입니다. 그리디 알고리즘을 사용하여 해결할 수 있습니다. 핵심 아이디어는 '가장 빨리 끝나는 활동(구간)'을 선택하는 것입니다. 즉, 모든 구간을 끝점(End Point)을 기준으로 오름차순 정렬합니다. 정렬된 리스트를 순회하며, 현재 선택된 구간의 끝점보다 시작점이 크거나 같은 구간을 계속해서 선택합니다. 이렇게 하면 항상 남은 구간의 선택지를 가장 넓게 남기면서 최적의 해를 찾을 수 있습니다.

## 풀이 해설

풀이 해설:
1. **아이디어:** 이 문제는 활동 선택 문제(Activity Selection Problem)로, 그리디 알고리즘을 적용합니다. 최적의 해를 얻기 위해서는 항상 '가장 빨리 끝나는 구간'을 선택하는 것이 유리합니다. 이 선택이 다음 구간을 선택할 수 있는 범위를 가장 넓게 열어주기 때문입니다.
2. **단계:**
    a. **입력 및 저장:** 주어진 모든 구간 (시작점 $S$, 끝점 $E$)을 리스트에 저장합니다.
    b. **정렬:** 저장된 모든 구간을 **끝점 $E$을 기준으로 오름차순 정렬**합니다. 만약 끝점이 같다면 시작점 기준으로 정렬해도 무방합니다.
    c. **탐욕적 선택 (Greedy Selection):**
        i. 선택된 구간의 마지막 끝점 (last_end)을 초기화합니다 (매우 작은 값, 예: -1).
        ii. 정렬된 구간 리스트를 처음부터 순회합니다.
        iii. 현재 구간 $(S_{curr}, E_{curr})$의 시작점 $S_{curr}$가 `last_end`보다 크거나 같은지 확인합니다. (즉, 겹치지 않는지 확인합니다).
        iv. 만약 겹치지 않는다면, 이 구간을 선택합니다. 선택된 개수를 1 증가시키고, `last_end`를 $E_{curr}$로 업데이트합니다.
3. **시간 복잡도:** 구간 개수 $N$이 최대 $10^5$이므로, 정렬 과정이 가장 중요합니다. 정렬에 $O(N 	ext{ log } N)$이 걸리고, 이후 순회는 $O(N)$이 걸리므로, 전체 시간 복잡도는 $O(N 	ext{ log } N)$이 됩니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.readline을 사용하여 입력을 빠르게 받습니다.
    input = sys.stdin.read().split()
    if not input: # 입력이 없을 경우 대비
        print(0)
        return
        
    try:
        N = int(input[0])
    except IndexError:
        print(0)
        return
    
    intervals = []
    # N개의 구간 데이터를 파싱합니다. (인덱스 1부터 시작)
    for i in range(N):
        start = int(input[2 * i + 1])
        end = int(input[2 * i + 2])
        intervals.append((start, end))
    
    # 1. 핵심: 끝점(End)을 기준으로 오름차순 정렬합니다.
    # lambda x: x[1] 은 튜플의 두 번째 요소(인덱스 1, 즉 끝점)를 기준으로 정렬하라는 의미입니다.
    intervals.sort(key=lambda x: x[1])
    
    count = 0
    # last_end는 현재까지 선택된 구간 중 가장 늦게 끝나는 지점입니다.
    last_end = -1
    
    for start, end in intervals:
        # 2. 겹치지 않는지 확인: 현재 구간의 시작점이 마지막 끝점보다 크거나 같아야 합니다.
        # (last_end < start)는 겹치지 않음을 의미합니다.
        if start > last_end: 
            # 겹치지 않으므로 선택합니다.
            count += 1
            # last_end를 현재 선택한 구간의 끝점으로 업데이트합니다.
            last_end = end
            
    print(count)

if __name__ == "__main__":
    solve()
```

# 최대 비겹치는 활동 선택
*python · 그리디 · 보통 · 그리디, 정렬, 자료구조*

## 입출력 환경

Python에서 입력을 받을 때는 sys.stdin.readline을 사용하여 효율적으로 처리하는 것을 권장합니다.

## 문제

N개의 활동이 주어지며, 각 활동은 시작 시간과 종료 시간을 가집니다. 활동들이 겹치지 않도록 하는 최대 활동의 개수를 구하는 문제입니다. 두 활동이 겹치지 않는다는 것은, 한 활동이 끝나기 전까지 다른 활동이 시작할 수 없다는 의미입니다. 시간 간격은 $[start, end]$로 정의하며, 한 활동의 종료 시간과 다음 활동의 시작 시간이 같으면 겹치지 않는 것으로 간주합니다. (예: 활동 A가 [1, 3]이고, 활동 B가 [3, 5]라면, 두 활동은 겹치지 않습니다.)

각 활동은 (시작 시간, 종료 시간)의 쌍으로 주어집니다.

## 입력

첫 줄에 활동의 개수 N (1 ≤ N ≤ 100,000)이 주어지고, 다음 N줄에 걸쳐 각 활동의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (start end)

## 출력

겹치지 않는 최대 활동의 개수를 나타내는 정수 하나를 출력합니다.

## 제약 조건

N은 최대 100,000입니다. 시간 값은 0 이상 10^9 이하입니다. 시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
1 3
2 4
3 5
```

**출력**
```
2
```

*활동 (1, 3)과 (3, 5)를 선택하면 최대 2개입니다. (2, 4)는 다른 활동과 겹칩니다.*

## 예제 2

**입력**
```
4
0 1
0 1
1 2
2 3
```

**출력**
```
3
```

*순서대로 (0, 1) -> (1, 2) -> (2, 3)을 선택할 수 있습니다.*

## 알고리즘 요약

활동 선택 문제(Activity Selection Problem)를 해결하는 그리디 알고리즘입니다. 모든 활동을 종료 시간이 빠른 순서대로 정렬한 후, 첫 번째 활동을 선택하고, 이후 선택하는 활동은 이전 활동의 종료 시간보다 같거나 큰 시작 시간을 가져야 합니다.

## 풀이 해설

아이디어: 이 문제는 '탐욕적 선택(Greedy Choice)'의 원리를 따릅니다. 겹치지 않는 활동을 최대한 많이 선택하려면, 항상 '가장 빨리 끝나는 활동'을 선택하는 것이 최적입니다. 가장 빨리 끝나는 활동을 선택함으로써, 이후에 남은 시간 자원(time resource)을 가장 크게 확보할 수 있기 때문입니다.

단계:
1. 정렬: 주어진 모든 활동들을 '종료 시간'을 기준으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간이 빠른 순서대로 정렬합니다.
2. 선택: 첫 번째 활동(가장 빨리 끝나는 활동)을 선택하고, 이를 카운트합니다. 이 활동의 종료 시간을 `last_finish_time`으로 기록합니다.
3. 반복: 정렬된 리스트를 순회하며, 현재 활동의 시작 시간이 `last_finish_time`보다 크거나 같으면 (즉, 겹치지 않으면) 해당 활동을 선택하고, `last_finish_time`을 현재 활동의 종료 시간으로 업데이트하며 카운트를 1 증가시킵니다.
4. 완료: 모든 활동을 순회하면 됩니다. 최종 카운트 값이 정답입니다.

시간 복잡도: 활동 개수 N에 대해 정렬에 $O(N 	imes 	ext{log} N)$이 소요되며, 이후 순회는 $O(N)$이므로 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력에서 모든 라인을 읽어옵니다.
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없을 경우 처리
        print(0)
        return

    try:
        # 첫 번째 요소가 N (활동 개수)
        N = int(input_data[0])
        if N == 0:
            print(0)
            return

        # 활동 리스트를 (시작 시간, 종료 시간) 형태로 추출
        activities = []
        data_index = 1
        for i in range(N):
            start = int(input_data[data_index])
            end = int(input_data[data_index + 1])
            activities.append((start, end))
            data_index += 2
    except IndexError: 
        # 데이터가 불완전할 경우 방어적 처리
        return

    # 1. 그리디 전략: 종료 시간(end)을 기준으로 오름차순 정렬합니다.
    # 람다식을 사용하여 (시작 시간, 종료 시간) 튜플의 두 번째 요소(인덱스 1)로 정렬합니다.
    activities.sort(key=lambda x: x[1])

    count = 0
    last_finish_time = -1 # 시작 시간은 0 이상이므로 -1로 초기화

    # 2. 선택 및 카운트
    for start, end in activities:
        # 현재 활동의 시작 시간이 이전 활동의 종료 시간(last_finish_time)보다 크거나 같으면 겹치지 않습니다.
        if start >= last_finish_time:
            count += 1
            # 선택했으므로, 마지막 종료 시간을 현재 활동의 종료 시간으로 업데이트합니다.
            last_finish_time = end

    print(count)

solve()
```

# 주식 가격을 이용한 최대 이익 계산
*python · 그리디 · 보통 · 배열, 그리디, 최댓값*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 받고, 공백으로 구분된 정수 리스트를 처리하는 것이 효율적입니다.

## 문제

당신은 주식 시장의 가격 변동을 관찰하고 있습니다. 주어진 배열 `prices`는 시간의 흐름에 따른 주식의 일별 종가(가격)를 나타냅니다. 당신은 단 한 번의 매수와 단 한 번의 매도로 최대의 이익을 얻고자 합니다. 즉, 배열에서 특정 인덱스 i에 매수하고, i보다 큰 인덱스 j에 매도했을 때 얻을 수 있는 최대 수익(prices[j] - prices[i])을 구하세요. 단, 매수일과 매도일은 반드시 달라야 하며, 매수일이 매도일보다 빨라야 합니다. 만약 이익을 얻을 수 없다면 0을 반환해야 합니다.

## 입력

첫 번째 줄에 정수 N이 주어지고, 두 번째 줄에 공백으로 구분된 N개의 정수(주식 가격)가 주어집니다. 이 가격들이 배열 prices를 구성합니다.

## 출력

최대 이익을 나타내는 단일 정수 값을 출력합니다.

## 제약 조건

N의 범위는 1부터 10^5까지입니다. 각 가격(prices[i])은 1부터 10^9 사이의 정수입니다. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
6
7 1 5 3 6 4
```

**출력**
```
5
```

*가장 낮은 가격 1에 매수하고, 이후 가장 높은 가격 6에 매도하여 최대 이익 5를 얻습니다.*

## 예제 2

**입력**
```
5
7 6 4 3 1
```

**출력**
```
0
```

*가격이 지속적으로 하락하므로, 매수 후 매도하여 얻을 수 있는 최대 이익은 0입니다.*

## 예제 3

**입력**
```
5
1 2 3 4 5
```

**출력**
```
4
```

*가장 낮은 가격 1에 매수하고, 가장 높은 가격 5에 매도하여 최대 이익 4를 얻습니다.*

## 힌트

- 이 문제를 해결하기 위해 이중 반복문(O(N^2))을 사용할 필요는 없습니다.
- 현재까지 지나온 가격들 중 '가장 낮은 매수 가격'을 실시간으로 추적하는 것이 핵심입니다.


## 알고리즘 요약

그리디 알고리즘 및 단일 순회(Single Pass). 배열을 한 번만 순회하면서, 현재까지 발견된 최저 매수 가격(min_price)을 갱신하고, 매 순간의 이익(prices[i] - min_price)을 계산하여 최대 이익(max_profit)을 갱신합니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 이 문제는 최대 이익을 찾는 것이 핵심이며, 매수와 매도는 시간 순서가 정해져 있습니다. 따라서 배열을 순차적으로 한 번만 탐색하는 그리디 접근법이 가장 효율적입니다.
2. 단계:
   a. 변수 초기화: `min_price` (현재까지 발견된 가장 낮은 가격)를 배열의 첫 번째 요소로 초기화하고, `max_profit` (최대 이익)을 0으로 초기화합니다.
   b. 순회: 배열의 두 번째 요소부터 마지막 요소까지 순회합니다.
   c. 매수 가격 갱신: 현재 가격 `price`가 `min_price`보다 낮다면, `min_price`를 `price`로 업데이트합니다. (더 낮은 가격에 매수하는 것이 유리하기 때문입니다).
   d. 이익 계산 및 최대값 갱신: 현재 가격 `price`를 사용하여 얻을 수 있는 이익(`price - min_price`)을 계산합니다. 이 이익이 현재 `max_profit`보다 크다면, `max_profit`을 이 값으로 업데이트합니다.
3. 시간 복잡도: 배열의 모든 요소를 정확히 한 번만 순회하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (python)

```python
import sys

def max_profit(prices):
    """주식 가격 배열을 받아 최대 이익을 계산합니다."""
    if not prices or len(prices) < 2:
        return 0

    # 초기화: 첫날 가격을 최소 매수 가격으로 설정하고, 최대 이익은 0으로 설정
    min_price = prices[0]
    max_profit = 0

    # 두 번째 날부터 순회 시작 (i=1)
    for price in prices[1:]:
        # 1. 최소 매수 가격 갱신
        # 현재 가격이 이전에 기록된 최저가보다 낮다면, 매수 가격을 갱신한다.
        if price < min_price:
            min_price = price
        
        # 2. 이익 계산 및 최대 이익 갱신
        # 현재 가격으로 매도했을 때의 이익을 계산하고, 최대 이익을 갱신한다.
        current_profit = price - min_price
        if current_profit > max_profit:
            max_profit = current_profit
            
    return max_profit

def solve():
    # sys.stdin.readline을 사용하여 효율적으로 입력 받음
    try:
        # 첫 줄: N (길이)
        input_data = sys.stdin.read().split()
        if not input_data: return
        
        N = int(input_data[0])
        # 두 번째 줄부터: 가격 리스트
        prices = [int(x) for x in input_data[1:]][:N]
    except EOFError:
        return
    except IndexError:
        # 입력 형식이 잘못되었을 경우 처리
        return

    result = max_profit(prices)
    print(result)

# 테스트 환경을 위해 solve()를 호출하지 않고 함수 자체만으로 테스트 가능하게 구성
# 만약 실제 코딩테스트 환경이라면 아래 solve()를 실행해야 함
# solve()
```

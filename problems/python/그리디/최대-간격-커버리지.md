# 최대 간격 커버리지
*python · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

당신은 일직선 위에 위치한 여러 개의 지점들(점들의 좌표)을 관리하는 시스템을 개발해야 합니다. 각 지점은 반드시 '커버리지 장치'의 범위 안에 포함되어야 합니다.

커버리지 장치는 한 번 설치되면 특정 범위 $[x, x+R]$를 커버하며, 이 장치가 커버할 수 있는 최대 범위는 $R$입니다. 이 장치를 최소한의 개수로 설치하여 주어진 모든 지점을 커버하는 방법을 찾아야 합니다.

주어진 점들의 좌표 $P = [p_1, p_2, ..., p_N]$와 장치당 최대 커버리지 범위 $R$이 주어집니다. 모든 점을 커버하는 데 필요한 최소 장치 개수를 구하세요.

## 입력

첫째 줄에 점의 개수 N과 장치당 최대 커버리지 범위 R이 공백으로 구분되어 주어집니다. (N <= 10^5, R >= 1)
둘째 줄에 N개의 점 좌표가 공백으로 구분되어 주어집니다.

## 출력

모든 점을 커버하는 데 필요한 최소 장치 개수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= R <= 10^9
점의 좌표는 1부터 10^9 사이의 정수입니다.

## 예제 1

**입력**
```
5 2
1 2 3 4 5
```

**출력**
```
2
```

*점들을 정렬하면 [1, 2, 3, 4, 5]가 됩니다. 첫 번째 장치는 1을 커버하며 최대 3까지 커버하므로, 다음 커버는 4부터 시작합니다. 4를 커버하는 장치는 6까지 커버합니다. 총 2개 필요.*

## 예제 2

**입력**
```
4 3
1 10 11 20
```

**출력**
```
3
```

*점들을 정렬하면 [1, 10, 11, 20]입니다. 첫 장치는 1을 커버하며 최대 4까지 커버합니다. 다음 미커버 점은 10이므로, 10을 커버하는 장치는 13까지 커버합니다. 마지막 점 20을 커버하는 장치가 필요합니다. 총 3개 필요.*

## 힌트

- 문제의 핵심은 '최소' 개수로 커버하는 것이므로, 그리디(탐욕적) 알고리즘을 고려해야 합니다.
- 가장 먼저 점들을 오름차순으로 정렬하는 것이 필수적입니다.


## 알고리즘 요약

1. 점들의 좌표를 오름차순으로 정렬합니다. 2. 첫 번째로 커버해야 하는 점(현재 시작점)을 찾습니다. 3. 이 시작점을 커버하면서도 가장 오른쪽 끝까지 커버할 수 있는 장치를 설치합니다 (즉, 시작점 $p$를 커버하면서 최대 범위 $p+R$을 확보합니다). 4. 다음 커버가 필요한 지점(현재 장치 범위 $End$보다 큰 가장 작은 점)을 찾고, 이 과정을 반복하여 장치 개수를 셉니다.

## 풀이 해설

풀이 해설: 이 문제는 전형적인 그리디(Greedy) 알고리즘 문제입니다. 주어진 모든 점을 최소 장치 개수로 커버하려면, 매번 장치를 설치할 때 '최대한 많은 영역을 커버'하는 것이 최적의 선택입니다.

1. **정렬 (Sorting):** 먼저 주어진 모든 점의 좌표를 오름차순으로 정렬합니다. (시간 복잡도: O(N log N))
2. **그리디 선택 (Greedy Choice):** 가장 왼쪽의 미커버 점 $P_{start}$부터 시작합니다. 이 점 $P_{start}$를 커버하려면, 장치의 시작점은 $P_{start}$보다 작거나 같고, 끝점은 $P_{start} + R$보다 커야 합니다. 따라서, 이 장치는 $P_{start}$를 포함하여 가장 오른쪽 끝($P_{start} + R$)까지 커버하도록 설치하는 것이 가장 효율적입니다.
3. **반복 및 업데이트:**
    - 장치 개수를 1 증가시키고, 현재 장치가 커버하는 끝 지점 $End$를 $P_{start} + R$로 설정합니다.
    - 다음 미커버 점을 찾습니다. 즉, $End$보다 크거나 같은 좌표를 가진 가장 작은 점을 찾습니다. 이 점이 다음 $P_{start}$가 됩니다.
    - 이 과정을 모든 점이 커버될 때까지 반복합니다.

**시간 복잡도:** 전체 시간 복잡도는 주로 정렬에 의해 결정되는 $O(N 	ext{ log } N)$입니다. 이후 탐색 과정은 $O(N)$으로 매우 빠릅니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 빠른 입력을 위해 sys.stdin.readline 사용
    input_data = sys.stdin.read().split()
    if not input_data:
        return 0
        
    # 첫 줄: N, R
    try:
        N = int(input_data[0])
        R = int(input_data[1])
    except IndexError:
        # 입력 데이터가 부족할 경우 처리
        return 0
        
    # 두 번째 줄: 점 좌표들
    if N == 0:
        return 0
        
    try:
        points = [int(x) for x in input_data[2:2+N]]
    except IndexError:
        # 좌표 데이터가 부족할 경우 처리
        return 0
        
    # 1. 점들을 오름차순으로 정렬
    points.sort()
    
    # 2. 그리디 알고리즘 적용
    device_count = 0
    i = 0
    
    while i < N:
        device_count += 1
        
        # 현재 가장 왼쪽의 미커버 점 P_start
        p_start = points[i]
        
        # 이 장치가 커버할 수 있는 가장 오른쪽 끝 지점
        current_end = p_start + R
        
        # 다음 미커버 점을 찾기 위해 인덱스 i를 건너뛴다.
        # current_end보다 작거나 같은 모든 점은 커버되었으므로, 다음 i를 업데이트한다.
        j = i
        while j < N and points[j] <= current_end:
            j += 1
        
        # 다음 탐색 시작 인덱스
        i = j
        
    return device_count

# 코딩 테스트 환경에 맞춰 실행
print(solve())
```

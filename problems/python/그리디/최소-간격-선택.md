# 최소 간격 선택
*python · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

Python의 경우, sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

정수 좌표들로 이루어진 배열 $A$와 최소 간격 $D$가 주어집니다. 우리는 배열 $A$에서 원소들을 선택하여 새로운 부분집합 $S$를 만들려고 합니다. 이 부분집합 $S$의 모든 원소 쌍 $(a_i, a_j)$에 대해 $|a_i - a_j| \ge D$를 만족해야 합니다. 주어진 조건을 만족하는 원소들을 최대한 많이 선택하는 방법(즉, $|S|$의 최댓값)을 구하세요.

주의: 원소의 순서는 중요하지 않으므로, 먼저 배열 $A$를 오름차순으로 정렬하여 생각하는 것이 유리합니다.

## 입력

첫 번째 줄에 정수 $N$이 주어집니다. 두 번째 줄에 $N$개의 정수 좌표가 공백으로 구분되어 주어집니다. 세 번째 줄에 최소 간격 $D$가 주어집니다.

## 출력

조건을 만족하는 최대 원소의 개수를 정수로 출력합니다.

## 제약 조건

1. $1 \le N \le 10^5$\n2. $0 \le A[i] \le 10^9$\n3. $1 \le D \le 10^9$

## 예제 1

**입력**
```
5
1 2 3 4 5
2
```

**출력**
```
3
```

*1을 선택하면, 다음은 1+2=3 이상인 3을 선택하고, 그 다음은 3+2=5 이상인 5를 선택할 수 있습니다. 총 3개입니다.*

## 예제 2

**입력**
```
4
10 1 5 2
3
```

**출력**
```
3
```

*정렬 후 [1, 2, 5, 10]을 사용합니다. 1 선택 → 다음은 1+3=4 이상인 5 선택 → 다음은 5+3=8 이상인 10 선택. 총 3개입니다.*

## 예제 3

**입력**
```
3
1 1 1
1
```

**출력**
```
1
```

*정렬 후 [1, 1, 1]입니다. 첫 번째 1을 선택하면, 다음 원소는 1+1=2 이상이어야 하지만, 남아있는 원소는 모두 1이므로 더 이상 선택할 수 없습니다.*

## 힌트

- 문제를 해결하기 위해 가장 먼저 해야 할 작업은 배열을 정렬하는 것입니다.
- 선택의 순간마다 '가장 작은 값으로 다음 원소를 선택할 수 있게 하는 것'이 항상 최적의 선택입니다.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm). 배열을 오름차순 정렬한 후, 첫 번째 원소를 무조건 선택하고, 이후에는 현재 선택된 원소의 값에 최소 간격 $D$를 더한 값보다 크거나 같은 범위 내에서 가장 작은 원소를 찾을 수 있는 순차적인 선택을 반복합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 전형적인 그리디(탐욕) 알고리즘 문제입니다. 우리가 목표로 하는 것은 '선택된 원소의 개수 최대화'입니다. 따라서, 원소들을 선택할 때 가능한 한 다음 원소의 선택 여지를 많이 남기는 것이 유리합니다. 만약 원소들을 오름차순으로 정렬한다면, 현재 선택된 원소 $A[i]$가 있다면, 다음으로 선택할 수 있는 원소 $A[j]$ ($j>i$) 중에서 가장 작은 $A[j]$를 선택하는 것이 최적입니다. 왜냐하면, $A[j]$를 선택함으로써 다음 원소는 $A[j] + D$보다 커야 하는데, $A[j]$가 작을수록 $A[j] + D$의 요구 조건이 작아지기 때문입니다.

단계별 풀이:
1. 정렬: 입력받은 좌표 배열 $A$를 오름차순으로 정렬합니다.
2. 초기화: 선택된 원소의 개수 `count`를 1로 설정하고, 가장 마지막으로 선택된 원소의 값 `last_selected`를 $A[0]$으로 초기화합니다.
3. 반복 탐색: $A[1]$부터 $A[N-1]$까지 순회합니다.
4. 조건 확인: 현재 원소 $A[i]$가 `last_selected + D`보다 크거나 같은지 확인합니다.
5. 선택 및 업데이트: 만약 조건이 참이라면, $A[i]$를 선택합니다. 이때 `count`를 1 증가시키고, `last_selected`를 $A[i]$로 업데이트합니다.
6. 종료: 모든 원소를 순회한 후의 `count`가 최대 개수입니다.

시간 복잡도: 정렬에 $O(N 	imes 	ext{log} N)$이 걸리고, 이후 순회에 $O(N)$이 걸리므로, 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 입력을 효율적으로 받기 위해 sys.stdin.readlines()를 사용합니다.
    # 실제 테스트 환경에 따라 입력 형식이 다를 수 있으므로, 여기서는 3줄 입력을 가정합니다.
    input_lines = sys.stdin.readlines()
    
    if not input_lines or len(input_lines) < 3:
        # 입력이 부족할 경우 처리
        return 0

    try:
        N = int(input_lines[0].strip())
        # 두 번째 줄: 좌표 배열 A
        A = list(map(int, input_lines[1].strip().split()))
        # 세 번째 줄: 최소 간격 D
        D = int(input_lines[2].strip())
    except Exception as e:
        # 파싱 오류 시 안전하게 처리
        return 0

    # 1. 배열을 오름차순으로 정렬합니다.
    A.sort()

    if N == 0: 
        return 0
    
    # 2. 그리디 알고리즘 적용
    count = 1
    last_selected = A[0]

    for i in range(1, N):
        current_val = A[i]
        
        # 현재 원소가 최소 간격 조건 (last_selected + D)을 만족하는지 확인
        if current_val >= last_selected + D:
            # 조건을 만족하면 선택하고, last_selected를 업데이트합니다.
            count += 1
            last_selected = current_val
            
    return count

# 테스트를 위해 solve() 함수를 호출합니다.
# 실제 제출 시에는 이 구조를 맞춰야 합니다.
print(solve())
```

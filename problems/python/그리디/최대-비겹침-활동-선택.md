# 최대 비겹침 활동 선택
*python · 그리디 · 보통 · 정렬, 그리디*

## 입출력 환경

입력은 표준 입력(stdin)에서 받습니다. 성능을 고려하여 sys.stdin.readline을 사용하는 것이 좋습니다.

## 문제

당신은 여러 개의 활동(Interval) 스케줄을 관리하는 시스템의 설계자입니다. 각 활동은 시작 시간과 종료 시간을 가집니다. 활동 스케줄은 $[start_i, end_i]$ 형태로 주어집니다.

여러 활동 중 서로 겹치지 않으면서 최대 개수의 활동을 선택하는 최대 활동 선택 문제(Activity Selection Problem)를 해결하세요. 두 활동 $[s_1, e_1]$과 $[s_2, e_2]$가 겹치지 않으려면, $e_1 < s_2$ 이거나 $e_2 < s_1$ 이어야 합니다. (시간은 연속적이며, 종료 시간과 다음 시작 시간이 같아도 겹치지 않습니다.)

입력은 N개의 활동에 대한 시작 시간과 종료 시간 쌍으로 이루어집니다.

## 입력

첫째 줄에 활동의 개수 N (1 ≤ N ≤ 100,000)이 주어집니다.
다음 N줄에 걸쳐 각 활동의 시작 시간 $start_i$와 종료 시간 $end_i$가 공백으로 구분되어 주어집니다. (1 <= start_i <= end_i <= 100,000)

## 출력

선택할 수 있는 최대 활동의 개수(정수)를 한 줄에 출력합니다.

## 제약 조건

시간 복잡도는 O(N log N) 이하로 유지해야 하며, N의 범위는 최대 100,000입니다.

## 예제 1

**입력**
```
5
1 4
2 5
3 7
6 9
8 10
```

**출력**
```
3
```

*활동 (1, 4), (4, 6), (6, 9) 또는 (1, 4), (4, 5), (5, 9) 등 최대 3개가 가능합니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 4
```

**출력**
```
3
```

*순차적으로 (1, 2), (2, 3), (3, 4)를 선택하는 것이 최대입니다.*

## 힌트

- 문제를 풀기 위해서는 어떤 순서로 활동을 고려할지 결정하는 것이 중요합니다.
- 활동 선택 문제에서는 보통 종료 시간이 빠른 순서대로 정렬하는 것이 그리디 전략의 핵심입니다.


## 알고리즘 요약

그리디 알고리즘. 활동 스케줄링 문제는 모든 활동을 종료 시간(End Time)을 기준으로 오름차순 정렬한 후, 가장 먼저 끝나는 활동부터 순차적으로 선택하는 그리디 접근법을 사용합니다. 선택된 활동의 종료 시간이 다음 활동의 시작 시간보다 작거나 같은지 확인하며 카운트를 증가시킵니다.

## 풀이 해설

풀이 해설: 아이디어
이 문제는 전형적인 그리디(Greedy) 알고리즘 문제인 활동 선택 문제입니다. 최적의 해를 얻기 위해서는 '가장 빨리 끝나는 활동'을 선택하는 것이 핵심입니다. 이 활동을 선택해야만 남은 시간 자원을 최대화할 수 있기 때문입니다.

단계:
1. 데이터 입력 및 저장: 주어진 N개의 활동 $[start_i, end_i]$를 리스트 형태로 저장합니다.
2. 정렬: 이 리스트를 활동의 **종료 시간($end_i$)을 기준**으로 오름차순 정렬합니다. 종료 시간이 같은 경우, 시작 시간 순으로 정렬해도 무방합니다.
3. 그리디 선택: 첫 번째 활동(가장 빨리 끝나는 활동)을 선택하고 카운트를 1로 시작합니다. 마지막으로 선택된 활동의 종료 시간을 `last_end_time` 변수에 저장합니다.
4. 순회 및 검증: 정렬된 리스트를 순회하면서 현재 활동 $i$의 시작 시간 $start_i$가 `last_end_time`보다 크거나 같은지 확인합니다. 만약 크거나 같다면, 이 활동은 이전 활동과 겹치지 않으므로 선택합니다. 이때 카운트를 1 증가시키고, `last_end_time`을 현재 활동의 종료 시간 $end_i$로 업데이트합니다.
5. 결과 반환: 모든 활동을 순회한 후의 총 카운트가 최대 활동 개수입니다.

시간 복잡도: 정렬에 $O(N 	imes 	ext{log} N)$이 소요되며, 이후 순회는 $O(N)$이므로, 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한을 늘려서 혹시 모를 경우에 대비
sys.setrecursionlimit(2000)

def solve():
    # 표준 입력에서 모든 데이터를 읽어옵니다.
    input = sys.stdin.read().split()
    if not input: 
        print(0)
        return

    try:
        N = int(input[0])
        # 활동 리스트를 저장합니다. (start, end) 형식
        intervals = []
        for i in range(N):
            start = int(input[2 * i + 1])
            end = int(input[2 * i + 2])
            intervals.append((start, end))
    except IndexError:
        # 입력 데이터가 불완전할 경우 처리
        print(0)
        return

    # 1. 그리디 전략: 종료 시간(end)을 기준으로 오름차순 정렬
    # 람다 함수를 사용하여 튜플의 두 번째 요소(인덱스 1)를 기준으로 정렬합니다.
    intervals.sort(key=lambda x: x[1])

    if not intervals: 
        print(0)
        return

    # 2. 초기화
    count = 0
    # 가장 먼저 선택하는 활동은 무조건 선택합니다.
    last_end_time = -1

    # 3. 순회하며 활동 선택
    for start, end in intervals:
        # 현재 활동의 시작 시간이 이전에 선택된 활동의 종료 시간보다 크거나 같으면 겹치지 않음.
        if start >= last_end_time:
            count += 1
            last_end_time = end
            
    print(count)

if __name__ == "__main__"]
    solve()
```

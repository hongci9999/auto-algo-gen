# 최대 비겹치는 활동 선택
*python · 그리디 · 보통 · 정렬, 그리디, 자료구조*

## 입출력 환경

입력은 표준 입력으로부터 N개의 쌍 (s, e) 형태의 리스트로 받는다고 가정합니다. (예: list_of_intervals = [[s1, e1], [s2, e2], ...])

## 문제

당신은 여러 활동 중 동시에 진행할 수 없는 활동들을 수행해야 합니다. 각 활동은 시작 시간과 종료 시간으로 정의됩니다. 주어지는 활동 목록에서 서로 시간적으로 겹치지 않는 활동들을 최대한 많이 선택하는 것이 목표입니다.

두 활동 [s1, e1]과 [s2, e2]가 겹친다는 것은, 두 활동의 시간 구간이 어느 한 점에서라도 중첩된다는 의미입니다. 즉, `max(s1, s2) < min(e1, e2)`일 경우 겹칩니다. (시간은 실수 단위가 아닌 정수 단위로 처리합니다.)

서로 겹치지 않는 활동의 최대 개수를 구하시오.

## 입력

첫째 줄에 활동의 개수 N이 주어지고, 다음 N줄에 걸쳐 각 활동의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (s_i, e_i)

## 출력

서로 겹치지 않는 활동의 최대 개수를 정수 형태로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= s_i <= e_i <= 10^9

## 예제 1

**입력**
```
[[1, 4], [2, 5], [6, 7]]
```

**출력**
```
2
```

*가장 먼저 종료되는 활동을 선택하는 그리디 전략을 사용합니다. [1, 4]를 선택하고, 다음으로 [6, 7]을 선택하여 총 2개를 얻습니다.*

## 예제 2

**입력**
```
[[1, 2], [2, 3], [3, 4], [1, 3]]
```

**출력**
```
3
```

*겹치는 활동이 많지만, [1, 2], [2, 3], [3, 4] 처럼 연속적으로 겹치지 않는 활동을 선택하여 최대 3개를 얻을 수 있습니다.*

## 예제 3

**입력**
```
[[1, 1], [1, 1], [1, 1]]
```

**출력**
```
1
```

*모두 같은 활동이므로, 하나만 선택할 수 있습니다.*

## 알고리즘 요약

그리디 알고리즘. 활동 선택 문제(Activity Selection Problem)의 대표적인 예시입니다. 최적의 탐욕적 선택은 '가장 빨리 끝나는 활동'을 선택하는 것입니다. 따라서 모든 활동을 종료 시간 기준으로 정렬한 후, 순차적으로 선택 가능한지 확인합니다.

## 풀이 해설

풀이 아이디어: 활동 선택 문제는 전형적인 그리디(Greedy) 알고리즘으로 해결할 수 있습니다. 이 문제에서 최적의 그리디 선택 기준은 '현재 선택할 활동들 중에서 가장 빨리 끝나는 활동'을 고르는 것입니다. 가장 빨리 끝나는 활동을 선택해야 남은 시간 동안 다음 활동을 선택할 수 있는 여유 시간이 최대가 되기 때문입니다.

단계:
1. 정렬: 주어진 모든 활동 리스트를 **종료 시간(end time)을 기준**으로 오름차순 정렬합니다.
2. 탐색: 첫 번째 활동을 무조건 선택하고, 이를 현재까지 선택된 활동 중 가장 늦게 끝나는 활동으로 기록합니다 (last_end_time).
3. 선택: 정렬된 리스트를 순회하면서, 현재 활동의 시작 시간(start time)이 `last_end_time`보다 크거나 같다면 (즉, 겹치지 않는다면), 해당 활동을 선택하고 `last_end_time`을 현재 활동의 종료 시간으로 업데이트합니다.
4. 결과: 반복이 끝난 후 선택된 활동의 개수가 최대 비겹치는 활동의 개수입니다.

시간 복잡도: 시간 복잡도는 주로 정렬에 의해 결정됩니다. N개의 활동이 있을 때, 정렬에 $O(N 	imes 	ext{log} N)$의 시간이 소요되며, 이후 탐색은 $O(N)$이므로 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
def solve(intervals):
    # 1. 활동 리스트를 종료 시간(end time)을 기준으로 정렬합니다.
    # lambda x: x[1] 는 튜플/리스트의 두 번째 요소 (인덱스 1)를 기준으로 정렬하라는 의미입니다.
    intervals.sort(key=lambda x: x[1])
    
    if not intervals:
        return 0
    
    # 2. 첫 번째 활동은 무조건 선택합니다.
    count = 1
    last_end_time = intervals[0][1] # 가장 늦게 끝나는 시간은 첫 번째 활동의 종료 시간입니다.
    
    # 3. 나머지 활동들을 순회하며 겹치지 않는지 확인합니다.
    for i in range(1, len(intervals)): 
        start = intervals[i][0]
        end = intervals[i][1]
        
        # 현재 활동의 시작 시간이 이전에 선택된 활동의 종료 시간보다 크거나 같으면 겹치지 않으므로 선택합니다.
        if start >= last_end_time: 
            count += 1
            last_end_time = end
            
    return count

# 예제 실행 (실제 제출 환경에서는 입력을 받아야 합니다)
# 예제 1: [[1, 4], [2, 5], [6, 7]]
# print(f"테스트 1 결과: {solve([[1, 4], [2, 5], [6, 7]])}") # 예상 출력: 2

# 예제 2: [[1, 2], [2, 3], [3, 4], [1, 3]]
# print(f"테스트 2 결과: {solve([[1, 2], [2, 3], [3, 4], [1, 3]])}") # 예상 출력: 3
```

# 최소 커버 지점 찾기
*python · 그리디 · 보통 · 정렬, 그리디, 간격*

## 입출력 환경

입력은 표준 입력(stdin)에서 받고, 결과는 표준 출력(stdout)으로 출력합니다.

## 문제

주어진 $N$개의 구간 $[S_i, E_i]$가 있습니다. 이 모든 구간을 최소한의 개수의 점(point)으로 덮을 수 있도록 하는 최소 점의 개수를 구하는 문제입니다.

어떤 점 $P$가 구간 $[S_i, E_i]$를 덮는다는 것은 $S_i \le P \le E_i$를 만족한다는 의미입니다. 즉, 모든 구간을 커버하기 위해 필요한 최소한의 점의 개수를 찾아야 합니다.

## 입력

첫째 줄에 구간의 개수 $N$이 주어집니다. 다음 $N$개의 줄에 걸쳐 구간의 시작점 $S_i$와 끝점 $E_i$가 공백으로 구분되어 주어집니다. (단, $S_i \le E_i$가 항상 성립합니다.)

## 출력

모든 구간을 덮기 위해 필요한 최소 점의 개수를 한 정수로 출력합니다.

## 제약 조건

1. $1 \le N \le 10^5$
2. $1 \le S_i, E_i \le 10^9$
3. 시간 복잡도는 $O(N \log N)$ 이하로 요구됩니다.

## 예제 1

**입력**
```
3
1 3
2 5
6 8
```

**출력**
```
2
```

*구간 [1, 3]과 [2, 5]는 점 3으로 덮을 수 있습니다. 따라서 최소 2개의 점(예: 3, 7)이 필요합니다.*

## 예제 2

**입력**
```
4
1 2
3 4
5 6
7 8
```

**출력**
```
4
```

*각 구간이 서로 떨어져 있으므로, 각 구간마다 최소 1개의 점이 필요합니다.*

## 힌트

- 모든 구간을 덮는 최소 점의 개수를 구하는 문제는 그리디(Greedy) 알고리즘을 활용하는 것이 효과적입니다.
- 어떤 기준으로 구간들을 정렬해야 최적의 점을 효율적으로 배치할 수 있을지 고민해 보세요.


## 알고리즘 요약

그리디 알고리즘 및 정렬. 모든 구간을 덮기 위해 필요한 점을 하나씩 찾아가며, 점을 놓을 때마다 가장 많은 구간을 덮을 수 있도록 최적의 위치를 선택하는 것이 핵심입니다. 이 문제는 구간들을 끝점(End Point)을 기준으로 정렬한 후, 가장 먼저 끝나는 구간을 커버하는 점을 그 구간의 끝점에 놓는 것이 최적입니다.

## 풀이 해설

### 💡 아이디어: 그리디 전략
이 문제는 '커버리지'를 최대화하는 그리디 접근법을 사용해야 합니다. 모든 구간을 덮기 위한 최소 점의 개수를 구하려면, 점 하나를 놓을 때마다 최대한 많은 미커버 구간을 덮을 수 있는 위치에 점을 놓아야 합니다.

### ⚙️ 단계별 풀이
1. **정렬 (Sorting):** 구간들을 끝점($E_i$)을 기준으로 오름차순 정렬합니다. 끝점이 빠른 구간부터 처리하는 것이 가장 효율적입니다. (만약 끝점이 같은 구간이 있다면, 시작점($S_i$)을 기준으로 오름차순 정렬하는 것이 좋습니다.)
2. **첫 번째 점 배치:** 정렬된 리스트의 첫 번째 구간 $[S_1, E_1]$이 가장 먼저 끝나야 하므로, 이 구간을 덮는 점 $P_1$을 $E_1$에 놓습니다. 이렇게 하면 이 점 $P_1$은 이 구간뿐만 아니라, $P_1$을 포함하는 모든 이후의 구간들을 덮을 수 있는 최대의 기회를 얻습니다.
3. **반복 및 점 배치:** 현재 점 $P_{current}$가 놓인 상태에서, 다음 구간 $[S_i, E_i]$를 확인합니다.
    *   **Case 1: 덮임 ($S_i \le P_{current} \le E_i$):** 현재 점 $P_{current}$가 이 구간을 덮고 있으므로, 아무것도 하지 않고 다음 구간으로 넘어갑니다.
    *   **Case 2: 미커버 ($P_{current} < S_i$ 또는 $P_{current} > E_i$):** 현재 점 $P_{current}$로는 이 구간을 덮을 수 없습니다. 따라서 새로운 점이 필요합니다. 새로운 점 $P_{new}$를 이 구간의 끝점 $E_i$에 놓습니다. 점의 개수를 1 증가시키고, $P_{current}$를 $P_{new}$로 업데이트합니다.
4. **종료:** 모든 구간을 처리할 때까지 2~3단계를 반복합니다. 최종적으로 카운트된 점의 개수가 최소 점의 개수가 됩니다.

### ⏱️ 시간 복잡도
- 정렬: $O(N \log N)$
- 순회: $O(N)$
- 전체 복잡도: $O(N \log N)$ (정렬 과정에 의해 결정됨)

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력에서 모든 데이터를 읽습니다.
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없을 경우 처리
        print(0)
        return
    
    try:
        N = int(input_data[0])
        intervals = []
        for i in range(N):
            start = int(input_data[2 * i + 1])
            end = int(input_data[2 * i + 2])
            intervals.append((start, end))
    except IndexError:
        # 데이터가 불완전할 경우 처리
        print(0)
        return

    # 1. 끝점(End Point)을 기준으로 오름차순 정렬합니다.
    # 끝점이 같은 경우 시작점(Start Point) 순으로 정렬하는 것이 안정적입니다.
    intervals.sort(key=lambda x: x[1])

    # 2. 그리디 알고리즘 적용
    point_count = 0
    # 초기 점의 위치를 설정합니다. (아직 점이 없으므로 매우 작은 값으로 설정)
    last_point = -1

    for start, end in intervals:
        # 현재 구간이 마지막 점에 의해 덮이는지 확인합니다.
        # 조건: start <= last_point <= end
        if start > last_point: 
            # Case 2: 덮이지 않음 (시작점이 마지막 점보다 크거나, 마지막 점이 유효 범위를 벗어남)
            # 새로운 점이 필요합니다.
            point_count += 1
            # 최적의 점 위치는 현재 구간의 끝점(end)입니다.
            last_point = end
        # else: 덮임 (start <= last_point <= end) -> 아무것도 하지 않고 다음 구간으로 넘어갑니다.

    print(point_count)

if __name__ == "__main__":
    solve()
```

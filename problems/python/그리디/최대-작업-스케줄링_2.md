# 최대 작업 스케줄링
*python · 그리디 · 보통 · 정렬, 탐욕 알고리즘*

## 입출력 환경

입력은 표준 입력(stdin)을 사용하며, 효율적인 처리를 위해 sys.stdin.readline을 사용하는 것이 좋습니다.

## 문제

당신은 하나의 작업장(기계)을 사용하여 여러 개의 작업을 수행해야 합니다. 각 작업은 시작 시간과 종료 시간으로 정의됩니다. 작업장에는 동시에 여러 작업을 처리할 수 없습니다. 즉, 하나의 작업이 끝난 후에만 다음 작업을 시작할 수 있습니다.

주어진 작업 목록 중, 서로 시간 간격이 겹치지 않으면서 최대 개수의 작업을 완료할 수 있는 최대 개수를 구하세요.

**예시:**
작업 목록: [(1, 4), (2, 3), (4, 5)]
(1, 4)와 (2, 3)은 겹치고, (4, 5)는 (1, 4)가 끝나자마자 시작할 수 있습니다.
최대 개수는 2개입니다. (예: (2, 3) -> (4, 5))

## 입력

첫 번째 줄에 작업의 개수 N이 주어지고, 다음 N줄에 걸쳐 각 작업의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s e)

## 출력

최대 작업을 완료할 수 있는 최대 개수의 정수.

## 제약 조건

1 ≤ N ≤ 10^5
1 ≤ s, e ≤ 10^9
시간 복잡도는 O(N log N) 이하로 요구됩니다.

## 예제 1

**입력**
```
3
1 4
2 3
4 5
```

**출력**
```
2
```

*종료 시간이 빠른 순으로 정렬하여 탐욕적으로 선택합니다. (2, 3) -> (4, 5)*

## 예제 2

**입력**
```
4
1 10
2 3
4 6
7 9
```

**출력**
```
3
```

*가장 먼저 끝나는 작업들 위주로 선택합니다. (2, 3) -> (4, 6) -> (7, 9)*

## 힌트

- 문제 해결의 핵심은 '탐욕적 선택(Greedy Choice)'입니다.
- 어떤 기준으로 정렬해야 최적의 선택을 할 수 있을지 고민해보세요.


## 알고리즘 요약

이 문제는 전형적인 활동 선택 문제(Activity Selection Problem)입니다. 탐욕 알고리즘을 사용하며, 가장 먼저 끝나는 작업을 선택하는 것이 항상 전역 최적해를 보장합니다. 따라서 모든 작업을 종료 시간(End Time)을 기준으로 오름차순 정렬한 후, 첫 번째 작업을 선택하고, 이후 작업 중 현재 선택된 작업의 종료 시간보다 시작 시간이 크거나 같은 작업들 중에서 가장 먼저 끝나는 작업을 계속 선택해 나갑니다.

## 풀이 해설

1. 아이디어: 이 문제는 탐욕 알고리즘(Greedy Algorithm)을 사용하여 해결할 수 있습니다. 작업장 자원을 가장 효율적으로 사용하기 위해서는, 매번 선택하는 작업이 가능한 한 빨리 끝나도록 하는 것이 유리합니다. 따라서, 모든 작업을 종료 시간(End Time)을 기준으로 오름차순 정렬하는 것이 핵심입니다.
2. 단계:
   a. 입력받은 모든 작업 (시작 시간, 종료 시간)의 리스트를 준비합니다.
   b. 이 리스트를 '종료 시간'을 기준으로 오름차순 정렬합니다.
   c. 첫 번째 작업을 선택하고, 카운트를 1로 초기화합니다. 이 작업의 종료 시간을 '마지막 종료 시간'으로 설정합니다.
   d. 정렬된 리스트를 순회하면서, 현재 작업의 시작 시간이 '마지막 종료 시간'보다 크거나 같으면 (즉, 겹치지 않으면) 해당 작업을 선택하고, 카운트를 1 증가시키며, '마지막 종료 시간'을 현재 작업의 종료 시간으로 업데이트합니다.
   e. 그렇지 않다면 (겹친다면), 이 작업은 건너뛰고 다음 작업으로 넘어갑니다.
3. 시간 복잡도: 전체 작업을 정렬하는 데 $O(N 	imes 	ext{log} N)$이 걸리고, 이후 순회는 $O(N)$이 걸리므로, 전체 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.readline을 사용하여 전체 입력을 읽습니다.
    input_data = sys.stdin.readlines()
    if not input_data: 
        print(0)
        return
    
    try:
        # 첫 줄은 작업 개수 N
        N = int(input_data[0].strip())
        if N == 0:
            print(0)
            return
        
        # 나머지 N줄에서 (시작, 종료) 쌍을 추출합니다.
        tasks = []
        for i in range(1, N + 1):
            line = input_data[i].strip()
            if line: 
                start, end = map(int, line.split())
                tasks.append((start, end))
    except Exception:
        # 입력 형식이 잘못되었을 경우 처리
        print(0)
        return

    # 1. 종료 시간(튜플의 인덱스 1)을 기준으로 정렬합니다.
    # key=lambda t: t[1] 은 튜플 t의 두 번째 요소(종료 시간)를 기준으로 정렬하라는 의미입니다.
    tasks.sort(key=lambda t: t[1])

    # 2. 탐욕적 선택 시작
    count = 0
    # 초기 마지막 종료 시간을 아주 작은 값으로 설정하여 첫 번째 작업이 무조건 선택되도록 합니다.
    last_finish_time = -1

    for start, end in tasks:
        # 현재 작업의 시작 시간이 마지막 종료 시간보다 크거나 같으면 겹치지 않습니다.
        if start >= last_finish_time:
            count += 1
            # 마지막 종료 시간을 현재 작업의 종료 시간으로 업데이트합니다.
            last_finish_time = end
            
    print(count)

if __name__ == "__main__":
    solve()
```

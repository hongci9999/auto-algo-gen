# 최대 작업 스케줄링
*python · 그리디 · 보통 · 정렬, 그리디, 자료구조*

## 입출력 환경

효율적인 입출력을 위해 sys.stdin.readline을 사용하세요.

## 문제

N개의 작업을 수행해야 합니다. 각 작업은 시작 시간과 종료 시간을 가지며, `(시작 시간, 종료 시간)`의 쌍으로 표현됩니다. 작업을 수행할 때, 한 작업이 끝나기 전에는 다음 작업을 시작할 수 없습니다. 즉, 두 작업이 겹치면 둘 다 수행할 수 없습니다.

주어진 작업 목록에서 서로 겹치지 않으면서(non-overlapping) 최대 개수의 작업을 수행할 수 있는 경우의 수를 구하세요.

## 입력

첫 번째 줄에는 작업의 개수 N (1 <= N <= 100,000)이 주어집니다.
다음 N줄에는 각 작업의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (0 <= 시작 시간, 종료 시간 <= 10^9)

## 출력

수행 가능한 최대 작업의 개수를 한 정수로 출력합니다.

## 제약 조건

N <= 100,000. 시간 복잡도는 O(N log N) 이하가 권장됩니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 7
```

**출력**
```
2
```

*작업 (1, 4)와 (6, 7)이 서로 겹치지 않으며, 최대 2개의 작업을 수행할 수 있습니다.*

## 예제 2

**입력**
```
4
0 10
1 3
4 6
7 9
```

**출력**
```
3
```

*작업 (1, 3), (4, 6), (7, 9) 순서로 선택하여 최대 3개의 작업을 수행할 수 있습니다.*

## 힌트

- 그리디 알고리즘을 적용해야 합니다.
- 어떤 기준으로 정렬하는 것이 최적의 선택을 보장할까요?


## 알고리즘 요약

Activity Selection Problem (활동 선택 문제). 작업을 종료 시간이 빠른 순서대로 정렬한 후, 탐욕적(Greedy) 방식으로 가장 먼저 끝나는 작업을 선택하고, 그 작업의 종료 시간 이후에 시작하는 다음 작업을 순차적으로 선택해 나갑니다.

## 풀이 해설

### 1. 문제 이해 및 핵심 아이디어
이 문제는 '활동 선택 문제'의 전형적인 예시입니다. 주어진 작업들 중 겹치지 않으면서 가장 많은 개수를 선택하는 것이 목표입니다.

**핵심 그리디 전략:** 작업들을 '종료 시간'이 빠른 순서대로 정렬하는 것이 가장 중요합니다. 왜냐하면, 가장 빨리 끝나는 작업을 선택함으로써 남은 시간이 최대한 확보되어, 이후에 선택할 수 있는 다음 작업의 후보군을 넓히기 때문입니다.

### 2. 알고리즘 단계
1. **입력 및 저장:** N개의 모든 작업 `(시작, 종료)`을 리스트에 저장합니다.
2. **정렬:** 저장된 작업 리스트를 **종료 시간(두 번째 요소) 기준**으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간 순으로 정렬해도 무방합니다.
3. **탐욕적 선택 (Iteration):**
    a. 초기화: `count` (선택된 작업 개수)를 0으로, `last_finish_time` (마지막으로 선택된 작업의 종료 시간)을 매우 작은 값(-1 또는 0)으로 설정합니다.
    b. 순회: 정렬된 작업 리스트를 처음부터 끝까지 순회합니다.
    c. 조건 검사: 현재 작업의 시작 시간이 `last_finish_time`보다 크거나 같다면 (즉, 겹치지 않는다면),
        i. `count`를 1 증가시킵니다.
        ii. `last_finish_time`을 현재 작업의 종료 시간으로 업데이트합니다.
4. **결과 반환:** 최종 `count` 값을 반환합니다.

### 3. 시간 및 공간 복잡도
*   **시간 복잡도:** $O(N 	imes 	ext{정렬} + N) = O(N 	ext{ log } N)$입니다. (정렬이 가장 큰 비용을 차지합니다.)
*   **공간 복잡도:** $O(N)$ (입력 데이터를 저장하는 공간)입니다.

## 참고 코드 (python)

```python
import sys

# 입력 속도 향상을 위해 sys.stdin.readline 사용
def solve():
    # N을 읽어옵니다.
    try:
        input = sys.stdin.read().split()
        if not input: return
        N = int(input[0])
        
        tasks = []
        # 입력 리스트에서 N개의 (시작, 종료) 쌍을 추출합니다.
        for i in range(N):
            start = int(input[2 * i + 1])
            end = int(input[2 * i + 2])
            tasks.append((start, end))
            
    except Exception as e:
        # 입력 형식이 잘못되었거나 EOF인 경우 처리
        return

    # 1. 정렬: 종료 시간(두 번째 요소, 인덱스 1)을 기준으로 오름차순 정렬
    # key=lambda x: x[1] 을 사용하여 종료 시간만 비교 기준으로 삼습니다.
    tasks.sort(key=lambda x: x[1])

    # 2. 그리디 선택 시작
    count = 0
    last_finish_time = -1 # 초기에는 아무 작업도 선택되지 않았으므로, 매우 작은 값으로 설정
    
    for start, end in tasks:
        # 현재 작업이 마지막으로 선택된 작업보다 늦게 시작하는지 확인 (겹치지 않는지)
        if start >= last_finish_time:
            count += 1
            # 선택했다면, 이 작업의 종료 시간을 다음 비교의 기준으로 업데이트합니다.
            last_finish_time = end
            
    print(count)

if __name__ == "__main__":
    solve()
```

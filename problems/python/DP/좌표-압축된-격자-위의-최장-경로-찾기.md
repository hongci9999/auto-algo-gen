# 좌표 압축된 격자 위의 최장 경로 찾기
*python · DP · 보통 · 동적계획법, 그래프, 트리*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

N개의 지점들이 주어졌으며, 각 지점은 고유한 (x, y) 좌표를 갖습니다. 이 지점들로만 이루어진 격자 위에서, 인접한 두 지점 사이의 거리는 맨해튼 거리(Manhattan Distance: $|x_1 - x_2| + |y_1 - y_2|$)	ext{를 따릅니다.} 

이 N개의 지점을 모두 방문하면서 만들 수 있는 가장 긴 경로의 길이를 구하는 문제입니다. 단, 경로는 사이클을 형성할 수 없으며, 이미 지나간 지점은 다시 방문할 수 없습니다.

지점들은 좌표가 매우 크지만(최대 $10^9$), 지점의 개수 N은 최대 10만 개입니다.

## 입력

첫째 줄에 정수 N이 주어집니다. 다음 N개의 줄에는 각각 지점 $(x, y)$의 좌표가 공백으로 구분되어 주어집니다.
(x, y)는 $1 	ext{부터 } 10^9$ 사이의 값을 가질 수 있습니다.

## 출력

N개의 지점을 모두 방문할 수 있는 가장 긴 경로의 총 길이(맨해튼 거리의 합)를 출력합니다.

## 제약 조건

1 <= N <= 100,000
1 <= x, y <= 10^9

## 예제 1

**입력**
```
3
1 1
2 2
3 3
```

**출력**
```
6
```

*지점 (1, 1) -> (2, 2) -> (3, 3) 경로의 길이는 |1-2|+|1-2| + |2-3|+|2-3| = 2 + 2 = 4가 아닙니다. 이 문제에서는 최장 경로를 찾으므로, 모든 지점을 방문하는 트리의 최대 엣지 가중치 합을 구해야 합니다. (1, 1)-(2, 2)의 거리는 2, (2, 2)-(3, 3)의 거리는 2입니다. 따라서 총 경로는 4가 됩니다. (수정: 문제 의도에 맞게 가장 긴 경로를 찾는 것이므로, 이는 트리 구조에서 최대 경로 합을 구하는 문제입니다.)*

## 예제 2

**입력**
```
4
1 1
1 3
5 2
7 2
```

**출력**
```
10
```

*지점들을 모두 방문하는 최장 경로는 (1, 1) -> (1, 3) -> (5, 2) -> (7, 2)와 같은 순서가 가능합니다. 총 거리: |1-1|+|1-3| + |1-5|+|3-2| + |5-7|+|2-2| = 2 + 4 + 2 = 8입니다. 최대 경로는 (1, 1) -> (1, 3) -> (7, 2) -> (5, 2) 순서가 아니라, 모든 지점을 연결하는 최소 스패닝 트리를 만들고 그 간선들을 모두 더하는 문제로 해석해야 합니다. (실제 최장 경로는 N-1개의 간선을 사용하며, 이는 MST의 합이 아닙니다.)*

## 힌트

- 만약 모든 지점을 방문한다면, 이 지점들은 그래프의 정점이 되고, 맨해튼 거리는 엣지 가중치가 됩니다.
- 문제에서 '가장 긴 경로'를 찾는다는 것은, 모든 정점을 포함하는 트리의 최대 간선 길이 합을 구하라는 의미로 해석됩니다. 이는 전체 지점들을 잇는 가장 효율적인 연결 방식을 찾아야 합니다.


## 알고리즘 요약

이 문제는 모든 N개의 정점을 반드시 지나가야 하므로, 이들 사이에 존재하는 간선들 중 어떤 경로를 선택하든 총 $N-1$개의 간선이 사용됩니다. 따라서 이 문제를 '최소 스패닝 트리의 가중치 합' 문제와 연결하여 해석해야 합니다. 그러나 일반적으로 최장 경로는 트리 구조에서 가장 긴 지름(Diameter)을 의미합니다.

하지만, 모든 정점을 방문하는 경로가 최대가 되려면, 사실상 모든 간선의 가중치를 더한 값에 가까워야 합니다. 좌표의 특성을 이용하면, 이 문제는 각 축(X축과 Y축)으로 투영했을 때의 범위와 관련된 성질을 갖습니다. 

실제 풀이 아이디어는 다음과 같습니다: N개의 점들을 주어진대로 간선으로 연결하여 그래프 $G$를 만듭니다. 이 그래프에서 모든 정점을 포함하는 경로가 최대가 되려면, 이는 모든 정점들이 특정한 '기준'에 대해 얼마나 퍼져 있는지를 계산해야 합니다.

핵심 아이디어는 좌표 압축을 통해 문제를 1차원 또는 2차원으로 축소하고, 각 축의 최소-최대 범위와 이웃 간의 거리를 이용하는 것입니다. (이 경우, 모든 정점을 방문할 때 최대 경로는 일반적으로 $X_{max} - X_{min} + Y_{max} - Y_{min}$과 같은 형태로 나타납니다.)

## 풀이 해설

풀이 해설: 이 문제는 N개의 점들로 이루어진 그래프에서 모든 점을 포함하는 가장 긴 경로의 길이를 구하는 문제입니다. 이 문제는 단순한 최장 경로(지름) 문제가 아니라, '모든 정점을 방문해야 한다'는 제약 조건 때문에 특수한 형태를 가집니다.

**아이디어:** N개의 지점이 주어졌고 모든 점을 지나가야 하므로, 사용되는 간선의 총 개수는 $N-1$개입니다. 만약 이들이 일렬로 놓여 있다면 그 합이 최대 경로 길이가 됩니다. 좌표의 특성상, 맨해튼 거리를 사용하는 경우 최장 경로는 각 좌표축의 최소값과 최대값을 이용한 차이의 합으로 나타나는 경우가 많습니다.

**단계 1: 모든 정점의 좌표 범위 확인.**
주어진 N개의 점 $(x_i, y_i)$에 대해 X좌표의 최솟값($X_{min}$), 최댓값($X_{max}$), Y좌표의 최솟값($Y_{min}$), 그리고 최댓값($Y_{max}$)을 찾습니다.

**단계 2: 경로 길이 계산.**
맨해튼 거리로 모든 점을 연결하여 만들 수 있는 최대 경로는, 마치 이 점들이 한 평면 위에 가장 넓게 퍼져 있을 때의 총 거리를 나타냅니다. 이 경우, 최장 경로는 $X_{max} - X_{min}$ (가장 왼쪽에서 가장 오른쪽까지의 거리)와 $Y_{max} - Y_{min}$ (가장 아래에서 가장 위까지의 거리)를 더한 값과 같습니다.

*주의: 예제 2의 해석이 복잡하여, 이 문제는 좌표 압축을 통해 얻는 직관적인 최댓값 차이를 이용하는 것이 출제 의도에 가깝습니다.* 
최종적으로 최대 경로는 $X_{max} - X_{min} + Y_{max} - Y_{min}$입니다.

**시간 복잡도:** 모든 점의 좌표를 한 번만 순회하며 최소/최대값을 찾는 과정이므로, 시간 복잡도는 $O(N)$ 입니다.

## 참고 코드 (python)

```python
import sys
input = sys.stdin.read

def solve():
    # 입력을 모두 읽고 분리합니다.
    data = input().split()
    if not data: # 입력이 없을 경우 처리
        return 0
    
    N = int(data[0])
    points = []
    for i in range(N): 
        x = int(data[2*i + 1])
        y = int(data[2*i + 2])
        points.append((x, y))

    if N == 0:
        return 0
    if N == 1:
        # 점이 하나만 있으면 경로는 0입니다.
        return 0

    # 모든 좌표의 최소/최대값을 초기화합니다.
    x_min = float('inf')
    x_max = float('-inf')
    y_min = float('inf')
    y_max = float('-inf')

    for x, y in points:
        x_min = min(x_min, x)
        x_max = max(x_max, x)
        y_min = min(y_min, y)
        y_max = max(y_max, y)

    # 최대 경로는 X축 범위와 Y축 범위를 합한 값입니다.
    max_path_length = (x_max - x_min) + (y_max - y_min)
    print(max_path_length)

if __name__ == "__main__":
    solve()
```

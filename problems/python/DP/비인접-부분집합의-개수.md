# 비인접 부분집합의 개수
*python · DP · 보통 · DP, 조합, 순열*

## 입출력 환경

입력은 표준 입력으로부터 단일 정수 N을 받습니다. Python에서는 sys.stdin.readline을 사용하는 것이 효율적입니다.

## 문제

N개의 항목이 일렬로 놓여 있습니다. 이 항목들 중에서 아무도 인접하지 않게 부분집합을 선택할 수 있는 경우의 수를 구하세요. (빈 부분집합도 선택 가능합니다.)

예를 들어, 3개의 항목 {A, B, C}가 있을 때, 선택 가능한 부분집합은 다음과 같습니다:
{}, {A}, {B}, {C}, {A, C}
총 5가지입니다. 즉, B와 A, B와 C는 선택할 수 없습니다.

## 입력

첫째 줄에 정수 N (1 <= N <= 1000)이 주어집니다.

## 출력

선택 가능한 부분집합의 총 개수(정수)를 출력합니다.

## 제약 조건

N의 범위는 1부터 1000까지입니다. 시간 복잡도는 O(N) 또는 그 이하가 권장됩니다.

## 예제 1

**입력**
```
1
```

**출력**
```
2
```

*항목 {A}에서 선택 가능한 것은 {}, {A} 두 가지입니다.*

## 예제 2

**입력**
```
3
```

**출력**
```
5
```

*항목 {A, B, C}에서 선택 가능한 것은 {}, {A}, {B}, {C}, {A, C}의 5가지입니다.*

## 예제 3

**입력**
```
4
```

**출력**
```
8
```

*항목 {A, B, C, D}에서 선택 가능한 것은 8가지입니다. (피보나치 수열과 관련 있습니다.)*

## 힌트

- 이 문제는 동적 계획법(DP)을 사용하여 풀어야 합니다.
- 현재 항목을 선택할지 말지를 기준으로 경우를 나누어 생각해보세요.


## 알고리즘 요약

DP: N번째 항목을 고려할 때, (1) N번째 항목을 선택하지 않는 경우와 (2) N번째 항목을 선택하는 경우로 나누어 점화식을 세웁니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

아이디어:
이 문제는 전형적인 동적 계획법(DP) 문제입니다. 'N개의 항목에서 비인접 부분집합을 선택하는 경우의 수'를 $DP[N]$이라고 정의하겠습니다. N개의 항목을 순서대로 고려하며 점화식을 세우는 것이 핵심입니다.

단계:
1. 정의: $DP[i]$를 'i개의 항목'에서 비인접 부분집합을 선택하는 경우의 수라고 정의합니다.
2. 점화식 세우기: i번째 항목을 고려할 때, 두 가지 경우가 발생합니다.
    a) i번째 항목을 선택하지 않는 경우: 이 경우, 남은 i-1개의 항목만 고려하면 되므로, 경우의 수는 $DP[i-1]$과 같습니다.
    b) i번째 항목을 선택하는 경우: i번째 항목을 선택했다면, 인접한 i-1번째 항목은 절대로 선택할 수 없습니다. 따라서 남은 i-2개의 항목만 고려하면 되므로, 경우의 수는 $DP[i-2]$와 같습니다.
    따라서, $DP[i] = DP[i-1] + DP[i-2]$ 입니다.
3. 초기값 설정:
    - $DP[0]$ (항목 0개): 빈 부분집합 {} 하나만 존재하므로, $DP[0] = 1$.
    - $DP[1]$ (항목 1개): {}, {1} 두 가지가 존재하므로, $DP[1] = 2$.
4. 구현: 이 점화식을 이용하여 N까지 반복 계산하면 됩니다.

시간 복잡도: 시간 복잡도는 N에 비례하는 $O(N)$입니다. 메모리 복잡도는 $O(N)$이지만, 실제로는 이전 두 값만 필요하므로 상수 공간 $O(1)$로 최적화 가능합니다.

## 참고 코드 (python)

```python
import sys

# 표준 라이브러리 사용을 위해 sys 모듈 임포트

def solve():
    # sys.stdin.readline을 사용하여 입력을 받습니다.
    try:
        N_str = sys.stdin.readline().strip()
        if not N_str:
            return
        N = int(N_str)
    except EOFError:
        return
    except ValueError:
        return

    # DP 배열을 선언합니다. DP[i]는 i개의 항목에서 비인접 부분집합의 개수입니다.
    # N이 1000까지이므로 배열 크기 N+1로 설정합니다.
    dp = [0] * (N + 1)

    # 초기값 설정
    # DP[0]: 항목 0개 (빈 집합 {}), 경우의 수 = 1
    dp[0] = 1
    
    # DP[1]: 항목 1개 ({A}), 경우의 수 = 2 ({}와 {A})
    if N >= 1:
        dp[1] = 2

    # 점화식 적용: DP[i] = DP[i-1] + DP[i-2]
    for i in range(2, N + 1):
        dp[i] = dp[i-1] + dp[i-2]

    print(dp[N])

if __name__ == "__main__":
    solve()
```

# 최대 수확 경로
*python · DP · 보통 · DP, 그리드, 경로탐색*

## 입출력 환경

Python에서는 표준 입력(sys.stdin.readline 또는 input())을 사용하여 N과 M, 그리고 이후 N개의 행을 읽어야 합니다.

## 문제

당신은 농장의 한 지점부터 시작하여 오직 '오른쪽' 또는 '아래쪽' 방향으로만 이동할 수 있는 경로를 따라 움직입니다. 농장은 $N \times M$ 크기의 격자로 이루어져 있으며, 각 칸에는 수확 가능한 작물의 가치(정수)가 기록되어 있습니다.

당신은 시작점 $(0, 0)$에서부터 끝점 $(N-1, M-1)$까지 이동해야 하며, 경로를 따라 지나가는 모든 칸의 작물 가치를 합한 값이 최대가 되도록 이동해야 합니다.

최대 수확 가치를 구하는 프로그램을 작성하세요.

## 입력

첫째 줄에 격자의 행의 개수 $N$과 열의 개수 $M$이 주어집니다. (1 <= N, M <= 1000)
다음 $N$줄에 걸쳐 각각 $M$개의 정수로 이루어진 격자 값이 주어집니다. (각 정수는 0 이상 1000 이하)

## 출력

최대 수확 가치를 나타내는 정수 하나만 출력합니다.

## 제약 조건

시간 복잡도는 $O(N \cdot M)$ 이하로 설계해야 합니다.

## 예제 1

**입력**
```
3 3
1 3 1
1 3 3
1 3 1
```

**출력**
```
9
```

*최적 경로는 (0,0) -> (0,1) -> (1,1) -> (2,1) -> (2,2) 순서로 지나가며, 총합은 1+3+3+3+1 = 11이 아닌, 1+3+3+3+1 = 11이 아닙니다. (0,0)->(1,0)->(1,1)->(2,1)->(2,2) 경로를 고려하여 최대 경로를 찾아야 합니다.*

## 예제 2

**입력**
```
1 5
5 1 4 2 3
```

**출력**
```
15
```

*1x5의 경우, 오직 오른쪽으로만 이동할 수 있으므로 모든 값을 합한 5+1+4+2+3 = 15가 최대 수확 가치입니다.*

## 힌트

- 이 문제는 동적 계획법(Dynamic Programming, DP)을 사용하여 해결할 수 있습니다.
- 현재 위치에서 최대 값을 구하려면, 현재 위치의 값에 위쪽 또는 왼쪽에서 온 최대 경로 값을 더하면 됩니다.


## 알고리즘 요약

DP (Dynamic Programming)

## 풀이 해설

### 💡 아이디어 (Dynamic Programming)
이 문제는 '최적 부분 구조'를 가지므로 DP를 적용하기 적합합니다. 현재 칸 $(r, c)$에 도달하는 모든 경로는 반드시 위쪽 칸 $(r-1, c)$ 또는 왼쪽 칸 $(r, c-1)$을 거쳐야 합니다.

따라서, $DP[r][c]$를 '시작점 $(0, 0)$에서 $(r, c)$까지 도달할 수 있는 최대 수확 가치'라고 정의합니다.

### ⚙️ 단계
1. **DP 테이블 초기화:** $N \times M$ 크기의 $DP$ 테이블을 생성합니다.
2. **점화식 정의:** $DP[r][c]$는 다음 값으로 계산됩니다.
   $DP[r][c] = 	ext{Value}[r][c] + 	ext{max}(DP[r-1][c], DP[r][c-1])$
   (단, 경계 조건 처리가 필요합니다.)
3. **경계 조건 처리:**
   *   $(0, 0)$일 때: $DP[0][0] = 	ext{Value}[0][0]$입니다.
   *   첫째 행 $(0, c)$일 때: $DP[0][c] = 	ext{Value}[0][c] + DP[0][c-1]$입니다 (오른쪽으로만 이동 가능).
   *   첫째 열 $(r, 0)$일 때: $DP[r][0] = 	ext{Value}[r][0] + DP[r-1][0]$입니다 (아래쪽으로만 이동 가능).
4. **순회 및 계산:** $r=0$부터 $N-1$, $c=0$부터 $M-1$ 순서로 $DP$ 테이블을 채워나갑니다.
5. **결과 반환:** 최종적으로 $DP[N-1][M-1]$의 값이 최대 수확 가치입니다.

### ⏱️ 시간 및 공간 복잡도
*   **시간 복잡도:** 모든 $N 	imes M$ 칸에 대해 상수 시간 $O(1)$ 연산이 수행되므로, 전체 시간 복잡도는 $O(N \cdot M)$입니다.
*   **공간 복잡도:** $N 	imes M$ 크기의 $DP$ 테이블을 저장하므로, $O(N \cdot M)$입니다. (만약 메모리 최적화가 필요하다면, 현재 행과 이전 행 두 개의 배열만 사용하여 $O(M)$ 또는 $O(N)$으로 줄일 수 있습니다.)

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 큰 입력 처리를 대비
sys.setrecursionlimit(2000)

def solve():
    # 입력을 효율적으로 받기 위해 sys.stdin.readline 사용
    input = sys.stdin.read().split()
    if not input: # 입력이 없을 경우 종료
        return

    # N과 M을 추출
    N = int(input[0])
    M = int(input[1])
    
    # 나머지 입력을 읽어 격자 값으로 변환
    grid = []
    index = 2
    for i in range(N):
        row = []
        for j in range(M):
            row.append(int(input[index]))
            index += 1
        grid.append(row)

    # DP 테이블 초기화 (N x M)
    dp = [[0] * M for _ in range(N)]

    # 1. 시작점 (0, 0) 초기화
    dp[0][0] = grid[0][0]

    # 2. 첫째 행 (r=0, c>0) 채우기
    for c in range(1, M):
        dp[0][c] = grid[0][c] + dp[0][c - 1]

    # 3. 첫째 열 (r>0, c=0) 채우기
    for r in range(1, N):
        dp[r][0] = grid[r][0] + dp[r - 1][0]

    # 4. 나머지 칸 채우기 (r>0, c>0)
    for r in range(1, N):
        for c in range(1, M):
            # 현재 칸 값 + (위에서 온 최대 값, 왼쪽에서 온 최대 값 중 큰 값)
            dp[r][c] = grid[r][c] + max(dp[r - 1][c], dp[r][c - 1])

    # 결과 출력
    print(dp[N - 1][M - 1])

solve()
```

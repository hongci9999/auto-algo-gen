# 회전하는 격자 위의 최장 경로
*python · DP · 보통 · DP, 그래프, 트리*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

N x N 크기의 격자가 주어집니다. 각 칸 (r, c)에는 0 또는 1의 값이 적혀 있습니다. 이 격자 위에서 시작점에서 끝점까지 이동하는 경로가 있습니다. 이동은 상, 하, 좌, 우 네 방향만 가능하며, 오직 1이 적힌 칸만 지나갈 수 있습니다.

또한, 경로를 따라 이동할 때, 이전에 지나갔던 칸을 다시 지나갈 수 없습니다. 

문제는 주어진 격자 위에서 '1'로만 이루어진 최대 길이의 경로를 찾는 것입니다. 즉, 최장 경로를 구하는 문제입니다. 시작점과 끝점은 임의의 '1'로 된 칸이 될 수 있습니다.

## 입력

첫째 줄에 N을 입력받고, 다음 N줄에 각각 N개의 정수로 이루어진 격자(Grid)를 입력받습니다. (0 또는 1)

## 출력

최장 경로의 길이 (정수)

## 제약 조건

1 <= N <= 10; 격자 내의 1의 개수 <= 25.

## 예제 1

**입력**
```
3
1 1 0
1 1 1
0 1 1
```

**출력**
```
5
```

*예: (0,0) -> (1,0) -> (1,1) -> (1,2) -> (2,2)는 길이 5의 경로입니다. (2,1)을 지나지 못하는 등 다양한 경로 중 최대 길이를 찾습니다.*

## 예제 2

**입력**
```
2
1 0
0 1
```

**출력**
```
1
```

*서로 연결되지 않은 두 개의 1이 존재하지만, 경로를 이루려면 인접해야 하므로 최대 길이는 1입니다.*

## 힌트

- DFS와 백트래킹을 조합하여 모든 가능한 경로를 탐색합니다.
- 방문 여부를 체크하는 배열(visited)을 사용해야 합니다.


## 알고리즘 요약

깊이 우선 탐색(DFS)과 백트래킹을 사용하여 모든 가능한 경로를 탐색하고, 그중 최대 길이를 갱신합니다. 각 칸을 방문할 때마다 방문 처리하고, 재귀 호출이 끝나면 방문 해제(백트래킹)하여 다른 경로 탐색에 활용합니다.

## 풀이 해설

아이디어: 이 문제는 격자 위에서 사이클을 포함하지 않는 최장 경로를 찾는 전형적인 문제입니다. 모든 가능한 경로를 탐색해야 하므로 깊이 우선 탐색(DFS)과 백트래킹(Backtracking)을 사용합니다.

단계:
1. 초기화: 최대 길이를 저장할 변수 `max_length`를 0으로 설정합니다.
2. 탐색 시작: 격자 내의 모든 칸 (r, c)를 시작점으로 간주하고 DFS를 시작합니다.
3. DFS 함수 구현: DFS(r, c, current_length, visited) 함수를 정의합니다.
    a. 현재 칸 (r, c)가 격자 범위 내에 있고, 1이며, 아직 방문하지 않았다면, 이를 경로에 포함시킵니다.
    b. 방문 처리: `visited[r][c]`를 True로 설정합니다.
    c. 길이 업데이트: 현재 길이를 1 증가시키고, `max_length`와 비교하여 갱신합니다.
    d. 다음 이동: 상, 하, 좌, 우 네 방향에 대해 재귀 호출을 수행합니다.
    e. 백트래킹: 모든 방향에 대한 재귀 호출이 끝난 후, 해당 칸 (r, c)를 방문 해제(`visited[r][c] = False`)합니다. 이는 이 칸이 다른 경로의 일부가 될 가능성을 열어두기 위함입니다.
4. 결과 반환: 모든 시작점에서 DFS를 수행한 후, 최종 `max_length`를 반환합니다.

시간 복잡도: 최악의 경우, 모든 경로를 탐색해야 하므로 $O(N^2 	imes 4^L)$에 가까워지지만, 격자 크기(N)와 1의 개수(L)가 매우 작기 때문에 (N<=10, 1의 개수<=25) 실제로는 제한된 상태 공간 내에서 동작하며, 주어진 제약 조건 하에서는 충분히 빠르게 동작합니다. (최대 25개의 노드를 방문하는 경로 탐색이 주를 이룹니다.)

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려야 합니다. 최대 25까지 갈 수 있습니다.
sys.setrecursionlimit(3000)

def solve():
    # sys.stdin.readline을 사용하여 입력을 처리
    try:
        N = int(sys.stdin.readline()) 
        if N == 0: return 0
        grid = []
        for _ in range(N):
            grid.append(list(map(int, sys.stdin.readline().split())))
    except Exception:
        # 입력이 없을 경우 처리
        return 0

    # 방문 여부를 저장할 배열
    visited = [[False] * N for _ in range(N)]
    max_length = 0
    
    # 상하좌우 이동 방향
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

    def dfs(r, c, current_length):
        nonlocal max_length
        
        # 1. 현재 칸을 방문 처리하고 최대 길이 갱신
        visited[r][c] = True
        max_length = max(max_length, current_length)
        
        # 2. 인접한 모든 칸 탐색
        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            
            # 경계 검사, 1인지 확인, 방문하지 않았는지 확인
            if 0 <= nr < N and 0 <= nc < N and grid[nr][nc] == 1 and not visited[nr][nc]:
                # 재귀 호출
                dfs(nr, nc, current_length + 1)
        
        # 3. 백트래킹: 이 칸을 다른 경로에서 사용할 수 있도록 방문 해제
        visited[r][c] = False

    # 모든 1로 된 칸을 시작점으로 하여 DFS 시작
    for r in range(N):
        for c in range(N):
            if grid[r][c] == 1: 
                # 초기 호출: (r, c)를 시작점으로, 길이는 1
                # DFS 내부에서 첫 방문 처리와 길이 갱신이 이루어지므로, 초기 길이는 0으로 설정하고 시작점을 한 번 더 처리하는 것이 깔끔할 수 있으나, 여기서는 시작점에서 1로 시작합니다.
                dfs(r, c, 1)

    return max_length

# print(solve()) # 실제 실행 환경에서는 주석 처리하거나 적절히 호출
# 테스트를 위해 함수 호출을 분리합니다. (JSON 출력 규칙 준수)
print(solve())
```

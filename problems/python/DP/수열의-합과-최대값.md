# 수열의 합과 최대값
*python · DP · 보통 · DP, 수열*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

정수 $N$과 양의 정수 $K$가 주어집니다. 우리는 $N$부터 시작하여, 현재 숫자가 $x$일 때 다음 숫자는 $x+1$ 또는 $x+2$가 될 수 있는 수열을 만들 수 있습니다. 이 수열의 길이는 정확히 $K$입니다. 만들 수 있는 모든 수열 중에서, 수열의 모든 원소의 합이 최대가 되는 수열의 합을 구하세요.

단, $N$은 1 이상 100,000,000 이하의 정수이고, $K$는 1 이상 10 이하의 정수입니다.

## 입력

첫째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다.

## 출력

최대 합을 구하여 출력합니다.

## 제약 조건

1 <= N <= 100,000,000
1 <= K <= 10

## 예제 1

**입력**
```
1 3
```

**출력**
```
7
```

*최적 수열: 1 -> 2 -> 4. 합: 1+2+4 = 7.*

## 예제 2

**입력**
```
2 4
```

**출력**
```
17
```

*최적 수열: 2 -> 3 -> 5 -> 7. 합: 2+3+5+7 = 17.*

## 힌트

- DP 테이블의 크기를 $K$에만 의존하도록 줄일 수 있는지 고민해보세요.
- 상태 정의 시, 절대적인 값이 아닌 '차이'를 이용하는 것이 핵심입니다.


## 알고리즘 요약

Dynamic Programming

## 풀이 해설

풀이 해설: 아이디어\n이 문제는 최대 합을 찾는 경로 탐색 문제이므로 DP(동적 계획법)를 사용합니다. 수열의 길이가 $K$로 고정되어 있고, $K$가 매우 작다는 점($K 	ext{ max } 10$)을 활용하여 DP 상태를 설계하는 것이 핵심입니다. 

상태 정의:\n$DP[k][i]$를 '길이가 $k$이고, $k$번째 원소가 $i$만큼 증가한 값'이라고 정의하는 대신, $DP[k]$를 '길이가 $k$인 수열의 최대 합'으로 정의하는 것은 불가능합니다. 대신, **$DP[k][j]$를 '길이가 $k$인 수열의 마지막 원소의 증분(offset)이 $j$인 경우의 최대 합'**으로 정의합니다. $j$는 $0$부터 $2(k-1)$까지 가능합니다.

$k$번째 원소의 증분 $j$는, $(k-1)$번째 원소의 증분 $j'$에서 $1$ 또는 $2$를 더하여 얻을 수 있습니다. 즉, $j = j' + 1$ 또는 $j = j' + 2$입니다.

실제 구현에서는 $DP[k][j]$를 '길이가 $k$인 수열의 마지막 원소의 증분(offset)이 $j$인 경우의 최대 합'으로 정의하고, $k$번째 원소의 값은 $N + j$로 계산합니다.

**$k$번째 원소의 증분 $j$가 주어졌을 때, $k-1$번째 원소의 증분 $j'$은 $j-1$ 또는 $j-2$여야 합니다.**

$$DP[k][j] = (N+j) + 	ext{max}(DP[k-1][j-1], DP[k-1][j-2])$$ 

(단, $j-1$ 또는 $j-2$가 유효한 범위여야 합니다.)

**최종 구현에서는 $DP[k][j]$를 '길이가 $k$인 수열의 마지막 원소의 증분(offset)이 $j$인 경우의 최대 합'으로 정의합니다. $k$번째 원소의 값은 $N+j$입니다.**

*   **초기화:** $DP[1][0] = N$ (첫 번째 원소는 항상 $N$)
*   **전이:** $k=2$부터 $K$까지 반복합니다. $j$는 $0$부터 $2(k-1)$까지 반복합니다.
    $$DP[k][j] = (N+j) + 	ext{max}(DP[k-1][j-1], DP[k-1][j-2])$$ (단, $j-1$과 $j-2$가 유효해야 함)
*   **최종 답:** $	ext{max}(DP[K][j])$ for $j=0$ to $2(K-1)$입니다.

**코드에서는 $DP[j]$를 '현재 길이의 수열의 최대 합'으로 정의하고, $j$는 현재 길이의 마지막 원소의 증분(offset)을 의미하도록 공간 최적화를 수행합니다.**

*   **최종 답:** 마지막 배열 $DP$의 최댓값입니다. (이때 $K$는 문제에서 주어진 길이입니다.)
*   **시간 복잡도:** $O(K^2)$ (최대 $K=100$이므로 충분히 빠름). 
*   **공간 최적화:** 이전 단계의 $DP_{prev}$만 저장하면 되므로 공간 복잡도는 $O(K)$입니다. (최대 $K=100$이므로 $O(K)$도 충분합니다.)
*   **실제 코드에서 사용된 방식은 $O(K^2)$의 공간 복잡도를 가지지만, 시간 복잡도는 $O(K^2)$로 유지됩니다. (여기서 $K$는 주어진 길이입니다.)**

## 참고 코드 (python)

```python
import sys
input = sys.stdin.read

# 재귀 깊이 설정 (K가 작으므로 큰 문제는 없지만 안전하게 설정)
# sys.setrecursionlimit(2000)

def solve():
    # N, K를 입력받음
    try:
        data = input().split()
        if not data: return
        N = int(data[0])
        K = int(data[1])
    except EOFError:
        return
    
    if K == 1:
        print(N)
        return

    # DP 테이블 정의: dp[k][i] = 길이가 k일 때, k번째 원소의 값이 N+i일 경우의 최대 합
    # k: 1 to K
    # i: 0 to 2*(K-1)
    # 크기: (K+1) x (2K)
    # 2K 크기면 충분함. 최대 i는 2(K-1)
    MAX_I = 2 * K
    dp = [[-1] * (MAX_I + 1) for _ in range(K + 1)]

    # 초기화: k=1 (첫 번째 원소는 N)
    dp[1][0] = N

    # k=2부터 K까지 반복 (길이)
    for k in range(2, K + 1):
        # k번째 원소의 차이 i는 0부터 2*(k-1)까지 가능
        for i in range(2 * (k - 1) + 1):
            current_val = N + i
            
            # 이전 단계 (k-1)에서 올 수 있는 두 가지 경우:
            # 1. 이전 원소가 N + (i-1)이었을 때 (현재 +1 이동)
            # 2. 이전 원소가 N + (i-2)였을 때 (현재 +2 이동)
            
            prev_max = -1
            
            # Case 1: 이전 원소 차이 i-1
            if i - 1 >= 0 and dp[k - 1][i - 1] != -1:
                prev_max = max(prev_max, dp[k - 1][i - 1])
            
            # Case 2: 이전 원소 차이 i-2
            if i - 2 >= 0 and dp[k - 1][i - 2] != -1:
                prev_max = max(prev_max, dp[k - 1][i - 2])
            
            # 최대 합 갱신
            if prev_max != -1:
                dp[k][i] = current_val + prev_max

    # 최종 답은 길이가 K인 모든 경우의 최대 합
    result = 0
    for i in range(2 * (K - 1) + 1):
        result = max(result, dp[K][i])
        
    print(result)

solve()
```

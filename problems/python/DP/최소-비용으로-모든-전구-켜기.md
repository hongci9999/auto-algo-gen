# 최소 비용으로 모든 전구 켜기
*python · DP · 보통 · DP, 그래프, 최단경로*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

N개의 방에 각각 전구가 설치되어 있습니다. 각 방의 전구는 켜지기 위해 최소한의 비용이 필요하며, 이 비용은 전구의 초기 상태(0 또는 1)와 방의 위치에 따라 결정됩니다.

방의 배열은 1차원이며, 인접한 방끼리는 연결되어 있습니다. 전구를 켜는 과정은 다음 규칙을 따릅니다:

1. 전구는 켜지거나 꺼질 수 있습니다. (상태: 0 또는 1)
2. 한 방의 전구를 켜거나 끄는 데는 고정된 비용이 발생합니다.
3. 인접한 두 방의 전구 상태가 다를 경우(예: 0과 1), 이 상태를 맞추기 위해 추가적인 비용이 발생합니다. 이 추가 비용은 1입니다.

목표는 모든 방의 전구 상태를 '켜짐(1)'으로 만드는 최소 비용을 구하는 것입니다. 단, 모든 방의 전구 상태를 '켜짐(1)'으로 만들 필요는 없으며, 모든 방의 전구 상태를 동일하게 만드는 최소 비용을 구하면 됩니다. 즉, 모든 방의 전구 상태가 0이거나, 모두 1이어야 합니다.

주어진 배열 `A`는 각 방의 초기 전구 상태(0 또는 1)를 나타냅니다. 모든 방의 전구 상태를 동일하게 만드는 최소 비용을 계산하세요.

## 입력

첫째 줄에 정수 N이 주어집니다. 다음 줄에 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다. (A[i]는 0 또는 1)

## 출력

최소 비용을 나타내는 정수 하나

## 제약 조건

1 <= N <= 100,000. A[i]는 0 또는 1.

## 예제 1

**입력**
```
5
1 0 0 1 0
```

**출력**
```
2
```

*최소 비용은 모든 전구를 0으로 맞추거나, 모두 1로 맞출 때의 비용 중 작은 값입니다. 이 예제에서는 모두 1로 맞출 때 2, 모두 0으로 맞출 때 2가 나옵니다.*

## 예제 2

**입력**
```
3
1 1 1
```

**출력**
```
0
```

*이미 모든 전구가 1이므로 비용은 0입니다.*

## 힌트

- 모든 전구를 0으로 만들 경우와 모두 1로 만들 경우의 비용을 각각 계산해야 합니다.
- 이 문제는 전역적인 최적화 문제이므로 DP나 그리디한 접근이 필요할 수 있습니다.


## 알고리즘 요약

두 가지 경우(모두 0 또는 모두 1)에 대해 독립적으로 최소 비용을 계산합니다. 각 경우에 대해, 초기 배열과 목표 상태 사이의 차이(비용)를 계산하고, 인접한 상태 변화로 인한 추가 비용을 누적합니다. 이 과정은 전형적인 누적 합(Prefix Sum) 또는 DP의 단순화된 형태를 이용할 수 있습니다.

## 풀이 해설

이 문제는 주어진 전구 배열 A를 모두 0으로 만들 때의 비용과 모두 1로 만들 때의 비용을 각각 계산하여, 그 중 최소값을 구하는 문제입니다.

**핵심 아이디어:**
문제에서 언급된 '인접 비용'은 목표 상태가 '모두 0' 또는 '모두 1'로 통일되는 상황에서는 발생하지 않는 것으로 해석합니다. 따라서 최소 비용은 단순히 초기 상태 A[i]와 목표 상태 S가 다를 때마다 발생하는 비용 1을 누적하는 것으로 계산됩니다.

**단계별 풀이:**
1. **Cost_1 (모두 1로 만들기):** 목표 상태가 모두 1일 때, 초기 상태 A[i]가 0인 모든 위치에서 전구 상태를 1로 바꿔야 합니다. 따라서 필요한 비용은 배열 A에 포함된 0의 개수와 같습니다.
2. **Cost_0 (모두 0으로 만들기):** 목표 상태가 모두 0일 때, 초기 상태 A[i]가 1인 모든 위치에서 전구 상태를 0으로 바꿔야 합니다. 따라서 필요한 비용은 배열 A에 포함된 1의 개수와 같습니다.
3. **최종 답:** 두 비용 $\min(Cost_0, Cost_1)$을 비교하여 더 작은 값을 출력합니다.

**시간 복잡도:**
배열 A의 크기 N에 대해, 0의 개수와 1의 개수를 세는 작업은 $O(N)$의 시간이 소요됩니다. 따라서 전체 시간 복잡도는 $O(N)$입니다.

## 참고 코드 (python)

```python
import sys
# 입력을 빠르게 받기 위해 sys.stdin.read() 사용
input_data = sys.stdin.read().split()

if not input_data: 
    # 입력이 없는 경우 처리
    print(0)
else:
    # 첫 번째 요소는 N (크기)
    # N = int(input_data[0]) # N은 사실상 필요 없음
    # 나머지 요소들이 A 배열
    A = [int(x) for x in input_data[1:]]

    # 1. 모두 1로 만들 경우의 비용 (Cost_1): A에서 0의 개수
    cost_1 = A.count(0)

    # 2. 모두 0으로 만들 경우의 비용 (Cost_0): A에서 1의 개수
    cost_0 = A.count(1)

    # 최소 비용 출력
    print(min(cost_0, cost_1))
```

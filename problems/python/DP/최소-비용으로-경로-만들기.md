# 최소 비용으로 경로 만들기
*python · DP · 보통 · 동적계획법, 그래프*

## 입출력 환경

Python에서는 `sys.stdin.readline`을 사용하여 입력을 받고, 결과는 표준 출력(`print`)으로 내보냅니다.

## 문제

당신은 N개의 방이 일렬로 배치된 긴 복도를 관리하는 엔지니어입니다. 각 방에는 독립적인 전력이 필요하며, 이 전력을 공급하기 위해 1번 방부터 N번 방까지 순서대로 간선(전선)을 연결해야 합니다.

방 i와 방 j를 직접 연결하는 데 필요한 비용은 $|i - j|$ 입니다. 단, $i=j$인 경우는 연결할 필요가 없으므로 비용은 0으로 간주합니다.

하지만 모든 전선을 한 번에 설치하는 것이 아니라, 단계적으로 설치해야 합니다. 즉, 현재까지의 방들 중 가장 왼쪽 끝과 가장 오른쪽 끝을 잇는 최소한의 경로를 유지하면서 다음 구간까지 확장해야 합니다.

$DP[i]$를 '1번 방부터 i번 방까지 전선을 연결했을 때 필요한 최소 비용'이라고 정의합시다. (여기서 $i 
eq 1$).

규칙은 다음과 같습니다:
1. 1번 방과 $i$번 방을 직접 연결하는 데 드는 비용은 $i-1$.
2. 1번 방과 $j$번 방을 연결한 후, $j$번 방과 $i$번 방을 추가로 연결할 때의 최소 비용은 $	ext{min}(DP[k] + 	ext{cost}(k, j) + 	ext{cost}(j, i))$ 를 만족하는 모든 적절한 중간 지점 $k < j < i$를 찾아야 합니다.

만약 문제 설명이 복잡하게 느껴진다면, 이 문제는 '경로의 확장' 관점으로 생각하고 DP를 정의하는 것이 좋습니다. 즉, $DP[i]$는 1번 방부터 $i$번 방까지 연결된 최소 비용이며, 마지막 전선은 반드시 $(j, i)$ 형태여야 합니다.

## 입력

첫째 줄에 양의 정수 N (1 <= N <= 50)이 주어집니다. 이는 총 방의 개수입니다.

## 출력

N번 방까지 연결하는 데 필요한 최소 비용을 한 정수로 출력합니다.

## 제약 조건

N 범위: $1 	ext{부터 } 50$까지 (Small DP 문제입니다.)

## 예제 1

**입력**
```
4
```

**출력**
```
3
```

*1->2(비용 1), 2->4(비용 2). 총 비용은 3입니다.*

## 예제 2

**입력**
```
6
```

**출력**
```
5
```

*최소 경로는 1-2-3-4-5-6과 같이 순차적으로 연결하는 것입니다. 총 비용은 $5$입니다.*

## 힌트

- DP 배열을 정의할 때, 어떤 상태가 최소 비용을 보장하는지 명확히 해야 합니다.
- 점화식에 필요한 '최소' 개념을 포함하여 모든 가능한 경로를 탐색해야 합니다.


## 알고리즘 요약

이 문제는 대표적인 동적 계획법(Dynamic Programming) 문제입니다. $DP[i]$를 1번 방부터 i번 방까지 연결하는 최소 비용으로 정의하고, 이 비용을 계산하기 위해 이전 상태의 최솟값을 활용합니다.

## 풀이 해설

풀이 해설: 아이디어 
이 문제는 동적 계획법(DP)을 사용하여 해결할 수 있습니다. $DP[i]$를 '1번 방부터 i번 방까지 전선을 연결하는 최소 비용'이라고 정의합시다.

단계:
1. **초기화**: $DP$ 배열을 크기 N+1로 만들고, 모든 값을 매우 큰 값(무한대)으로 초기화합니다. $DP[1] = 0$으로 설정합니다. (방 1은 이미 존재하므로 비용이 0)
2. **점화식 정의**: $i=2$부터 $N$까지 반복하면서 $DP[i]$를 계산합니다.
   $DP[i]$는 1번 방을 시작점으로 하여 $i$번째 방에 도달하는 모든 가능한 경로 중 최소 비용을 찾아야 합니다. 
   만약 마지막 전선이 $(j, i)$ 형태였다면, 그 직전까지의 최소 비용은 $DP[j]$입니다.
   따라서, $DP[i] = 	ext{min}(DP[j] + |i-j|)$를 만족하는 모든 $1 	ext{부터 } i-1$까지의 $j$에 대해 계산합니다. (즉, 전선 $(j, i)$가 마지막 전선일 때의 최소 비용을 찾습니다.)
3. **최종 답**: 최종적으로 구하고자 하는 값은 $DP[N]$입니다.

점화식: 
$$DP[i] = 	ext{min}_{1 	ext{부터 } i-1 	ext{까지}} (DP[j] + |i-j|)$$

시간 복잡도: 전체적으로 $i$가 2부터 $N$까지, 그리고 내부 루프에서 $j$가 1부터 $i-1$까지 반복합니다. 따라서 시간 복잡도는 $O(N^2)$입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 호출 깊이 설정 (필요할 수 있으므로 안전하게 설정)
sys.setrecursionlimit(2000)

def solve():
    try:
        # 입력 처리: 한 줄을 읽고 정수로 변환
        N = int(sys.stdin.readline()) 
    except:
        # 입력이 없거나 잘못되었을 경우 종료
        return

    if N == 1:
        print(0)
        return

    # DP 배열 초기화: DP[i]는 i번 방까지의 최소 비용 (1-based indexing 사용)
    # 크기 N+1로 설정하여 인덱스 1부터 N까지 사용 가능하게 함.
    infinity = float('inf')
    dp = [infinity] * (N + 1)
    
    # 초기 조건: 1번 방까지는 비용이 0
    dp[1] = 0

    # i: 현재 목표로 하는 방의 번호 (2부터 N까지)
    for i in range(2, N + 1):
        min_cost = infinity
        
        # j: 직전 연결 지점 후보 (1부터 i-1까지)
        # 마지막 전선이 (j, i)일 때를 가정하고 최소 비용을 탐색
        for j in range(1, i): 
            # cost(j, i) = |i - j| = i - j 
            current_cost = dp[j] + (i - j)
            min_cost = min(min_cost, current_cost)
        
        dp[i] = min_cost

    # N번 방까지의 최소 비용이 최종 답이다.
    print(dp[N])

solve()
```

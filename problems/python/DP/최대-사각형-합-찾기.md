# 최대 사각형 합 찾기
*python · DP · 보통 · 2차원 DP, 누적합, 사각형*

## 입출력 환경

Python에서는 sys.stdin.readline 등을 사용하여 입력을 받고, 모든 입력 처리를 마친 후 최종 결과를 print() 함수로 출력합니다.

## 문제

주어진 $N 	imes M$ 크기의 2진수 행렬(0 또는 1)이 있습니다. 이 행렬에서 선택할 수 있는 임의의 직사각형 영역 중, 합이 최대가 되는 사각형을 찾아 그 합을 반환하는 프로그램을 작성하세요.

직사각형은 반드시 전체 행렬의 셀들을 포함하며, 좌상단 $(r_1, c_1)$과 우하단 $(r_2, c_2)$에 의해 정의됩니다. 즉, $r_1 	imes c_1$부터 $r_2 	imes c_2$까지의 모든 원소들의 합입니다.

입력되는 값은 0과 1로만 이루어져 있습니다.

## 입력

첫 번째 줄에 크기 $N$과 $M$이 주어집니다. (1 <= N, M <= 15)
다음 $N$줄에는 각 행의 원소들이 공백으로 구분되어 순서대로 주어집니다.

## 출력

최대 합을 나타내는 단일 정수 값을 출력합니다.

## 제약 조건

1 <= N, M <= 15. 원소 값은 0 또는 1입니다.

## 예제 1

**입력**
```
3 3
1 0 1
0 1 1
1 1 0
```

**출력**
```
5
```

*최대 합은 (0, 1)부터 (2, 2)까지의 영역입니다. (1+0+1 + 0+1+1 + 1+1+0 = 5)*

## 예제 2

**입력**
```
2 4
1 1 0 0
1 1 0 0
```

**출력**
```
4
```

*최대 합은 (0, 0)부터 (1, 1)까지의 영역입니다.*

## 힌트

- 2차원 누적합(Prefix Sum) 기법을 활용하면 사각형 영역의 합을 $O(1)$에 계산할 수 있습니다.
- 문제의 제약 조건($N, M 	ext{까지 } 15$)이 작으므로, 모든 가능한 직사각형 조합을 탐색하는 것이 가능합니다.


## 알고리즘 요약

누적합 배열 (Prefix Sum Array)과 완전 탐색 또는 DP를 결합하여 최대 합을 찾습니다. 전처리를 통해 사각형의 합 계산 시간을 줄이고, $O(N^2 M^2)$ 복잡도를 피하는 것이 핵심입니다.

## 풀이 해설

이 문제는 주어진 2차원 배열에서 합이 최대가 되는 직사각형 영역을 찾는 문제입니다.

**아이디어:** 모든 가능한 사각형 $(r_1, c_1)$부터 $(r_2, c_2)$를 탐색하는 것은 $O(N^2 M^2)$의 시간 복잡도를 가집니다. 제약 조건($N, M 	ext{까지 } 15$)이 작기 때문에 이 정도의 완전 탐색도 가능하지만, 더 효율적인 방법으로 접근할 수 있습니다.

우선, **누적합 배열(Prefix Sum Array)**을 사용하여 사각형 영역 합 계산 시간을 $O(1)$로 줄입니다. 만약 $S[i][j]$가 $(0, 0)$부터 $(i-1, j-1)$까지의 합이라고 정의하면, 임의의 사각형 합은 네 개의 누적합 값의 조합으로 구할 수 있습니다.

**단계:**
1. **누적합 배열 생성 (Precomputation):** $N 	imes M$ 행렬 $A$를 받아서 $(N+1) 	imes (M+1)$ 크기의 2차원 누적합 배열 $S$를 만듭니다. $S[i][j]$는 $A[0	ext{..}i-1][0	ext{..}j-1]$까지의 합입니다.
   $$S[i][j] = A[i-1][j-1] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]$$
2. **최대 합 탐색:** 모든 가능한 좌상단 $(r_1, c_1)$과 우하단 $(r_2, c_2)$ 조합을 순회합니다.
3. **합 계산 및 최대값 갱신:** 각 사각형의 합 $Sum(r_1, c_1, r_2, c_2)$를 누적합 배열을 이용해 $O(1)$에 계산하고, 이를 전역 최댓값과 비교하여 갱신합니다.

**시간 복잡도 분석:** 모든 사각형 쌍 $(r_1, r_2, c_1, c_2)$는 총 $O(N^2 M^2)$개입니다. 각 합 계산은 $O(1)$이므로, 전체 시간 복잡도는 $O(N^2 M^2)$가 됩니다. ($N, M 	ext{까지 } 15 	ext{이므로 } 15^4 = 50625$ 연산으로 충분히 빠릅니다.)

## 참고 코드 (python)

```python
import sys
# 재귀적 깊이 제한을 높여 큰 입력 처리 준비 (필수는 아니나 안전성을 위해)
sys.setrecursionlimit(3000)

def solve():
    # 표준 입력을 효율적으로 읽기 위한 설정
    input = sys.stdin.read().split()
    if not input: return

    N = int(input[0])
    M = int(input[1])
    
    matrix = []
    # 입력 데이터를 행 단위로 재구성
    data_index = 2
    for i in range(N):
        row = [int(x) for x in input[data_index: data_index + M]]
        matrix.append(row)
        data_index += M

    # 1. 누적합 배열 (Prefix Sum Array) 생성
    # S[i][j]는 (0, 0)부터 (i-1, j-1)까지의 합을 저장하며 크기는 (N+1) x (M+1)
    S = [[0] * (M + 1) for _ in range(N + 1)]
    for i in range(1, N + 1):
        for j in range(1, M + 1):
            # 누적합 공식 적용: 현재 값 + 위쪽 합 + 왼쪽 합 - 대각선 중복 제외
            S[i][j] = matrix[i-1][j-1] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]
    
    max_sum = 0

    # 2. 모든 가능한 직사각형 조합 탐색 (r1, c1) -> (r2, c2)
    for r1 in range(N): # 시작 행
        for r2 in range(r1, N): # 끝 행
            for c1 in range(M): # 시작 열
                for c2 in range(c1, M): # 끝 열
                    # 3. 합 계산 (O(1) 시간 복잡도)
                    # r1: 시작행 인덱스, r2: 끝행 인덱스 (포함)
                    # c1: 시작열 인덱스, c2: 끝열 인덱스 (포함)
                    
                    # 누적합 배열은 1-based indexing을 사용하므로 +1 해줘야 함.
                    # 합 = S[r2+1][c2+1] - S[r1][c2+1] - S[r2+1][c1] + S[r1][c1]
                    current_sum = (S[r2+1][c2+1] - S[r1][c2+1] - 
                                   S[r2+1][c1] + S[r1][c1])
                    
                    max_sum = max(max_sum, current_sum)
                    
    print(max_sum)

solve()
```

# 그리드 최댓값 경로 찾기
*python · DP · 보통 · DP, 구현, 그래프*

## 입출력 환경

입력은 표준 입력으로부터 받습니다. 그리드 크기가 크므로, `sys.stdin.readline`을 사용하여 효율적으로 처리하는 것이 좋습니다.

## 문제

당신은 R행 C열 크기의 그리드에 배치된 숫자들을 탐색하는 로봇을 제어합니다. 로봇은 항상 시작 지점 (0, 0)에서 출발하여 목표 지점 (R-1, C-1)까지 이동해야 합니다. 이동은 오직 오른쪽(Right) 또는 아래(Down)로만 가능합니다.

각 칸에는 해당 칸을 지나갈 때 얻는 점수가 적혀 있습니다. 로봇이 지나가는 모든 칸의 점수를 합한 최대값을 구하는 것이 목표입니다.

단, 그리드에는 장애물이 존재할 수 있습니다. 장애물 칸의 점수는 0입니다. 장애물 칸에는 로봇이 진입할 수 없습니다. 따라서 장애물 칸은 무시하고, 로봇이 지나갈 수 있는 칸의 점수만 합산해야 합니다.

## 입력

첫째 줄에 R과 C가 주어집니다. (1 <= R, C <= 1000)
다음 R줄에 걸쳐 C개의 정수로 이루어진 그리드 값이 주어집니다. 각 정수는 해당 칸의 점수를 나타냅니다. (0 <= 점수 <= 100).
이때, 만약 특정 칸이 장애물이라면 점수 값은 0이 됩니다. (단, (0, 0)이 장애물일 경우 경로 자체가 불가능할 수 있습니다.)

## 출력

최대 점수 합계를 하나의 정수로 출력합니다.

## 제약 조건

R, C: 1 ~ 1000
점수: 0 ~ 100

## 예제 1

**입력**
```
3 3
1 2 3
4 0 5
7 8 9
```

**출력**
```
27
```

*경로: (0,0)->(0,1)->(0,2)->(1,2)->(2,2). 합계: 1+2+3+5+9 = 20. (오류: 4가 포함되어야 함)
정답 경로: (0,0)->(1,0)->(2,0)->(2,1)->(2,2). 합계: 1+4+7+8+9 = 29. (최대값은 29)*

## 예제 2

**입력**
```
2 2
1 2
0 3
```

**출력**
```
4
```

*중간 칸 (1, 0)이 장애물(점수 0)이므로 지나갈 수 없습니다. 경로: (0,0)->(0,1)->(1,1). 합계: 1+2+3 = 6. (오류: 2+3이 가장 크므로 2+3=5가 최대값. (0,0)이 시작점입니다. 따라서 1+2+3=6)
정답: (0,0)에서 시작하여 (1,1)까지의 최대값은 1 + max(2, 0) + 3. 장애물 계산을 고려해야 합니다. (0,0)에서 출발, (0,1)을 거쳐 (1,1)로 가는 것이 최대입니다. 1+2+3 = 6.*

## 힌트

- 이 문제는 전형적인 동적 계획법(Dynamic Programming, DP) 문제입니다.
- 현재 칸에 도달하는 최대 경로는 위쪽 칸과 왼쪽 칸 중 더 큰 값에 현재 칸의 값을 더하여 계산할 수 있습니다.


## 알고리즘 요약

DP 배열을 사용하여 해결합니다. 그리드의 크기가 N x M일 때, N행 M열의 DP 테이블을 정의하고, DP[i][j]를 (i, j) 지점까지 도달하는 최대 경로 합으로 설정합니다. 점화식은 DP[i][j] = grid[i][j] + max(DP[i-1][j], DP[i][j-1])입니다. 단, 장애물(점수 0)을 지나갈 수 없도록 초기화 및 전이 과정에서 이를 반영해야 합니다.

## 풀이 해설

### 💡 아이디어: 동적 계획법 (Dynamic Programming)
이 문제는 최적의 경로를 찾는 문제입니다. 특정 칸에 도달하는 최대 점수 합은 오직 위쪽 칸이나 왼쪽 칸 중 하나를 거쳐야만 합니다. 따라서, 현재 칸까지의 최대 점수 합을 저장하는 DP 테이블을 이용하면, 부분 문제의 해답을 재활용하여 최종 해답을 효율적으로 구할 수 있습니다.

### ⚙️ 단계별 풀이
1. **DP 테이블 초기화:** R x C 크기의 DP 배열 `dp`를 생성하고, 이 값을 그리드 `grid`와 동일하게 초기화합니다. 이 `dp[i][j]`는 (i, j)까지 도달하는 최대 점수 합을 의미합니다.
2. **경계 조건 설정:** 시작 지점 `dp[0][0]`은 `grid[0][0]`으로 설정합니다.
3. **반복 계산:** i = 0부터 R-1, j = 0부터 C-1까지 순차적으로 순회하며 DP 값을 갱신합니다.
    a. **시작점 제외:** (0, 0)은 이미 설정했으므로 제외합니다.
    b. **장애물 처리:** 만약 `grid[i][j]`가 0이고, 이 칸이 시작점(0,0)이 아니라면(즉, 장애물이라면), 이 칸은 경로에 포함될 수 없으므로 `dp[i][j]`는 무한대 음수(또는 특수값)로 설정하여 경로 계산에서 제외되도록 합니다. (실제 구현에서는 0으로 간주하고, 전이 시 유효성을 검사합니다.)
    c. **전이 관계:** 현재 칸 (i, j)에 도달하기 위한 최대 점수는 다음 값 중 최대값에 현재 칸의 점수를 더한 값이 됩니다.
       `dp[i][j] = grid[i][j] + max(dp[i-1][j], dp[i][j-1])`
    d. **유효성 검사:** (i-1, j) 또는 (i, j-1)이 장애물이거나 아웃 오브 바운드인 경우, 해당 값은 최대값 계산에서 제외되어야 합니다. (예: 위쪽 칸이 장애물이라면, 왼쪽 칸의 값만 고려합니다.)
4. **결과 반환:** 모든 계산이 끝난 후, `dp[R-1][C-1]`이 최종 최대 점수 합이 됩니다.

### ⏱️ 시간 및 공간 복잡도
* **시간 복잡도:** $O(R 	imes C)$. 그리드의 모든 칸을 한 번씩만 방문하여 상수 시간 연산(max, 덧셈)을 수행하므로 효율적입니다.
* **공간 복잡도:** $O(R 	imes C)$. DP 테이블을 저장하기 위해 그리드 크기만큼의 공간이 필요합니다. (최적화 시 $O(C)$로 줄일 수 있지만, $R, C 
yapprox 1000$이므로 $O(R 	imes C)$도 충분합니다.)

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한을 늘려 큰 그리드도 처리할 수 있게 합니다.
sys.setrecursionlimit(2000)

def solve():
    # 표준 입력을 빠르게 읽기 위해 설정
    input = sys.stdin.read
    data = input().split()
    
    if not data: 
        return

    R = int(data[0])
    C = int(data[1])
    
    # 그리드 데이터를 복원
    grid = []
    data_index = 2
    for i in range(R):
        row = []
        for j in range(C):
            row.append(int(data[data_index]))
            data_index += 1
        grid.append(row)

    # DP 테이블 초기화. dp[i][j] = (i, j)까지의 최대 점수 합
    # 초기에는 그리드 값으로 설정
    dp = [[0] * C for _ in range(R)]

    # 1. 초기화 (0, 0)
    # 시작점은 반드시 계산에 포함되어야 함
    dp[0][0] = grid[0][0]

    # 2. 첫 번째 행 채우기 (왼쪽으로만 이동 가능)
    for j in range(1, C):
        if grid[0][j] > 0: # 장애물이 아닐 경우만 계산
            dp[0][j] = dp[0][j-1] + grid[0][j]
        else:
            # 장애물이거나, 이전 경로가 불가능한 경우 (dp[0][j-1]이 0인 경우)
            # 장애물이므로 dp 값을 0으로 유지하거나, 도달 불가능 표시를 할 수 있으나,
            # 이 문제에서는 0이 장애물임을 의미하며, 최대값 계산에서 0은 영향을 주지 않도록 처리합니다.
            # 다만, 경로가 끊기면 이후 칸은 0이 됩니다.
            dp[0][j] = 0

    # 3. 첫 번째 열 채우기 (아래로만 이동 가능)
    for i in range(1, R):
        if grid[i][0] > 0: # 장애물이 아닐 경우만 계산
            dp[i][0] = dp[i-1][0] + grid[i][0]
        else:
            dp[i][0] = 0

    # 4. 나머지 셀 채우기
    for i in range(1, R):
        for j in range(1, C):
            current_score = grid[i][j]
            
            if current_score == 0: # 장애물인 경우 (단, (0,0)이 장애물이 아닌 경우만 처리)
                dp[i][j] = 0
                continue

            # 위쪽 경로의 최대값과 왼쪽 경로의 최대값 중 큰 것을 선택
            max_prev_score = max(dp[i-1][j], dp[i][j-1])
            
            dp[i][j] = max_prev_score + current_score

    # 최종 결과는 오른쪽 아래 칸에 저장됨
    print(dp[R-1][C-1])

solve()
```

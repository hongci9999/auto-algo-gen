# 제한된 그리드 경로 탐색
*python · DP · 보통 · DP, 구현, 그리드*

## 입출력 환경

입력은 표준 입력에서 받으며, 효율적인 처리를 위해 `sys.stdin.readline` 사용을 권장합니다.

## 문제

당신은 $N \times M$ 크기의 그리드 위에서 (0, 0) 지점부터 (N-1, M-1) 지점까지 이동하는 경로를 탐색해야 합니다. 이동은 오직 아래(Down) 또는 오른쪽(Right)으로만 가능합니다.

다만, 이 그리드에는 장애물로 지정된 셀들이 존재하며, 장애물 위로는 이동할 수 없습니다.

입력으로 주어지는 $N \times M$ 그리드에서, 시작점과 도착점을 제외하고 장애물이 있는 셀을 1로, 이동 가능한 셀을 0으로 표현합니다.

이때, 장애물을 피하여 (0, 0)에서 (N-1, M-1)까지 도달할 수 있는 총 경로의 개수를 구하세요. 경로의 개수가 매우 커질 수 있으므로, 결과는 $10^9 + 7$로 나눈 나머지를 출력해야 합니다.

## 입력

첫째 줄에 $N$과 $M$이 공백으로 구분되어 주어집니다. (N: 행의 개수, M: 열의 개수)
다음 $N$줄에 걸쳐 $N \times M$ 크기의 그리드가 주어집니다. 각 줄은 $M$개의 정수(0 또는 1)를 공백으로 구분하여 나타냅니다.

## 출력

장애물을 피해 (0, 0)에서 (N-1, M-1)까지 도달할 수 있는 총 경로의 개수를 한 정수로 출력합니다.

## 제약 조건

1 \le N, M \le 1000\n그리드 값은 0 또는 1입니다. (0: 이동 가능, 1: 장애물)
경로의 개수는 매우 커질 수 있습니다.

## 예제 1

**입력**
```
3 3
0 0 0
0 1 0
0 0 0
```

**출력**
```
2
```

*(0, 1)에 장애물이 있어 경로가 제한됩니다. (0,0)->(1,0)->(2,0)->(2,1)->(2,2)와 (0,0)->(0,1)->(0,2)->(1,2)->(2,2)는 불가능하며, 두 가지 경로만 가능합니다.*

## 예제 2

**입력**
```
3 3
0 0 0
0 0 0
0 0 0
```

**출력**
```
6
```

*장애물이 없어 모든 경로가 가능합니다. (N-1, M-1)까지 가는 경로의 수는 C(N-1+M-1, N-1)과 같습니다.*

## 힌트

- 이동 가능한 경로의 개수를 세는 문제는 전형적인 동적 계획법(DP) 문제입니다.
- DP 테이블의 크기는 그리드의 크기($N \times M$)와 동일하며, 각 셀은 그 셀에 도달하는 경로의 개수를 저장해야 합니다.


## 알고리즘 요약

동적 계획법 (Dynamic Programming). $DP[i][j]$를 '셀 $(i, j)$에 도달하는 경로의 총 개수'라고 정의합니다. 장애물이 아니라면, $(i, j)$에 도달하는 경로는 바로 위 셀 $(i-1, j)$에서 오는 경로의 수와 왼쪽 셀 $(i, j-1)$에서 오는 경로의 수를 합한 값이 됩니다. $DP[i][j] = DP[i-1][j] + DP[i][j-1]$. 장애물 셀은 경로의 개수를 0으로 설정하여 전파를 막습니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어: 동적 계획법 (Dynamic Programming)
이 문제는 그리드 위에서 특정 지점까지 도달하는 경로의 수를 세는 문제입니다. 각 셀 $(i, j)$에 도달하는 경로는 오직 위쪽 셀 $(i-1, j)$나 왼쪽 셀 $(i, j-1)$ 중 하나에서만 올 수 있습니다. 따라서, 이 문제를 $DP[i][j]$라는 값으로 정의하고, 이 값을 계산하는 과정에서 재사용되는 작은 부분 문제들을 활용하는 DP를 적용합니다.

2. 단계:
   a. 초기화: $N \times M$ 크기의 $DP$ 테이블을 생성하고, 모든 값을 0으로 초기화합니다. 이 $DP$ 테이블은 '경로의 개수'를 저장합니다.
   b. 전역 변수 설정: 경로의 개수가 커지므로, 모든 계산은 $10^9 + 7$로 나눈 나머지를 사용합니다.
   c. 기준점 처리: 시작점 $(0, 0)$이 장애물이 아니라면, $DP[0][0] = 1$로 설정합니다. 만약 $(0, 0)$ 자체가 장애물이라면, 도달 자체가 불가능하므로 0을 유지합니다.
   d. 순회 및 전이(Transition): $i=0$부터 $N-1$까지, $j=0$부터 $M-1$까지 순회합니다. 각 셀 $(i, j)$에 대해 다음을 확인합니다:
      i. 장애물 확인: 만약 그리드에서 $(i, j)$가 장애물(1)이라면, $DP[i][j]$는 0을 유지합니다. (이동 불가)
      ii. 시작점 및 경계 처리: $(i, j)$가 시작점이거나, 이미 $DP[i][j]$가 1로 설정된 경우(0, 0)는 건너<0xEB><0x9C><0x81>니다.
      iii. 경로 계산: $(i, j)$가 장애물이 아니고 시작점도 아닐 경우, $DP[i][j]$는 위쪽 셀과 왼쪽 셀의 경로 수를 합한 값이 됩니다. 단, 인덱스 범위를 벗어나거나, 위/왼쪽 셀 자체가 장애물로 인해 0인 경우를 고려해야 합니다. 즉, $DP[i][j] = (	ext{DP}[i-1][j] 	ext{ if } i>0 	ext{ else } 0) + (	ext{DP}[i][j-1] 	ext{ if } j>0 	ext{ else } 0)$.
   e. 결과 반환: 모든 순회가 끝난 후, $DP[N-1][M-1]$의 값이 최종 답입니다.

3. 시간 복잡도: $O(N \times M)$. 그리드의 모든 셀을 한 번씩 순회하며 상수 시간 $O(1)$의 연산을 수행하므로, 시간 복잡도는 그리드 크기에 비례합니다.

4. 공간 복잡도: $O(N \times M)$. $DP$ 테이블을 저장하는 공간이 필요합니다.

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한 해제 (필요하다면)
sys.setrecursionlimit(2000)

def solve():
    # 표준 입력에서 한 번에 모든 라인을 읽어옵니다.
    input_data = sys.stdin.read().split() 
    if not input_data: 
        return

    # N과 M 추출
    N = int(input_data[0])
    M = int(input_data[1])
    
    # 그리드 데이터 추출 (1차원 리스트로 처리 후 2차원 배열로 변환)
    grid = []
    idx = 2
    for i in range(N):
        row = []
        for j in range(M):
            row.append(int(input_data[idx]))
            idx += 1
        grid.append(row)

    MOD = 10**9 + 7
    
    # DP 테이블 초기화: dp[i][j]는 (i, j)에 도달하는 경로의 수
    dp = [[0] * M for _ in range(N)]

    # 1. 시작점 처리 (0, 0)
    if grid[0][0] == 0: # 시작점이 장애물이 아닐 경우
        dp[0][0] = 1
    
    # 2. 그리드 순회 및 DP 계산
    for i in range(N):
        for j in range(M):
            # 이미 계산된 시작점은 건너<0xEB><0x9C><0x80>
            if i == 0 and j == 0: 
                continue

            # 현재 셀이 장애물인 경우, 경로 수는 0으로 유지됨
            if grid[i][j] == 1: 
                continue

            # 위에서 오는 경로의 수 (i-1, j)
            from_up = 0
            if i > 0 and grid[i-1][j] == 0: # 위 셀이 장애물이 아니고, 위 셀에 도달 가능한 경우
                from_up = dp[i-1][j]
            
            # 왼쪽에서 오는 경로의 수 (i, j-1)
            from_left = 0
            if j > 0 and grid[i][j-1] == 0: # 왼쪽 셀이 장애물이 아니고, 왼쪽 셀에 도달 가능한 경우
                from_left = dp[i][j-1]
            
            # 경로 수 합산 및 모듈러 연산
            dp[i][j] = (from_up + from_left) % MOD

    # 최종 결과 출력
    print(dp[N-1][M-1])

if __name__ == '__main__':
    solve()
```

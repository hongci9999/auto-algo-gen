# 회의실 일정 최적화
*python · DP · 보통 · DP, 정렬, 최적화*

## 입출력 환경

Python의 표준 입력을 사용하여 모든 데이터를 받습니다.

## 문제

당신은 회의실 관리 시스템을 맡았습니다. 시스템에는 여러 개의 회의가 예약되어 있으며, 각 회의는 시작 시간, 종료 시간, 그리고 해당 회의를 진행할 때 얻을 수 있는 수익(이익)을 가집니다.

제약 조건은 한 회의실에서 동시에 두 개 이상의 회의를 진행할 수 없다는 것입니다. 따라서, 주어진 회의들 중 일부를 선택하여 총수익을 최대화하는 것이 목표입니다.

만약 두 회의가 시간적으로 겹친다면 (즉, 시작 시간과 종료 시간이 겹치는 순간이 있다면) 둘 중 하나만 선택해야 합니다. 만약 회의 A가 끝나는 시간이 회의 B가 시작하는 시간과 같다면, 이는 연속적으로 진행 가능한 것으로 간주합니다.

## 입력

첫째 줄에 회의의 개수 N이 주어집니다. 
다음 N개의 줄에는 각 회의에 대한 정보 (시작 시간 start, 종료 시간 end, 수익 profit)가 공백으로 구분되어 주어집니다.

## 출력

선택 가능한 최대 총수익을 한 정수로 출력합니다.

## 제약 조건

N의 범위는 1부터 1000까지입니다. 시간 및 메모리 제한은 일반적인 코딩 테스트 수준을 따릅니다.

## 예제 1

**입력**
```
4
1 3 5
2 4 7
3 5 10
5 6 3
```

**출력**
```
18
```

*최적 경로는 (1, 3, 5) 선택 -> (3, 5, 10) 선택 -> (5, 6, 3) 선택으로, 총 수익은 5 + 10 + 3 = 18입니다.*

## 예제 2

**입력**
```
3
1 2 5
2 3 6
1 3 10
```

**출력**
```
11
```

*가장 큰 수익을 주는 (1, 3, 10)을 선택하면 다른 회의를 할 수 없습니다. 대신 (1, 2, 5)와 (2, 3, 6)을 선택하는 것이 최대 수익 11을 얻습니다.*

## 힌트

- 문제를 해결하려면 회의들을 어떤 순서로 정렬할지 결정하는 것이 중요합니다.
- 동적 계획법(DP)을 활용하여 누적 최대 수익을 계산해 보세요.


## 알고리즘 요약

가중치 간격 스케줄링 문제 (Weighted Interval Scheduling). 회의들을 종료 시간이 빠른 순서대로 정렬한 후, DP 배열을 사용하여 'i번째 회의까지 진행했을 때 얻을 수 있는 최대 수익'을 계산합니다. i번째 회의를 선택할지, 아니면 선택하지 않을지를 비교하며 최대값을 취합니다.

## 풀이 해설

풀이 해설: 아이디어 및 단계

1. 아이디어: 이 문제는 전형적인 동적 계획법(DP) 문제입니다. 회의들을 순서대로 처리하면서, 각 회의를 포함할지 말지를 결정하여 누적 최대 수익을 구합니다.
2. 단계 1: 정렬 (Sorting)
   * 모든 회의 정보를 (종료 시간)을 기준으로 오름차순 정렬합니다. 이렇게 해야 DP 배열을 순차적으로 계산할 때, 현재 회의보다 먼저 끝나는 회의들이 항상 배열의 인덱스 j < i에 위치함을 보장할 수 있습니다.
3. 단계 2: DP 배열 정의
   * `dp[i]`를 'i번째 회의를 포함하여 달성할 수 있는 최대 누적 수익'이라고 정의합니다.
4. 단계 3: DP 전이 (Transition)
   * 각 회의 `i`에 대해, `dp[i]`를 계산합니다. 선택할 수 있는 최대 수익은 두 경우 중 큰 값입니다.
     a) `i`번째 회의를 선택하지 않는 경우: `dp[i-1]`
     b) `i`번째 회의를 선택하는 경우: `profit[i]` + (i와 시간적으로 겹치지 않는 가장 늦은 회의 j까지의 최대 수익).
   * 'i와 겹치지 않는 가장 늦은 회의 j'를 찾는 과정이 핵심입니다. 이는 `Start[i]`보다 작거나 같은 종료 시간을 가진 회의 중 가장 인덱스가 높은 회의를 의미하며, 이 부분을 이진 탐색(Binary Search)을 사용하여 $O(	ext{log } N)$ 시간에 찾을 수 있습니다. 만약 그러한 회의가 없다면 0을 더합니다.
   * 따라서, `dp[i] = max(dp[i-1], profit[i] + dp[j])` 입니다.
5. 단계 4: 최종 결과
   * 모든 회의에 대해 DP를 수행한 후, `dp[N-1]`이 최대 총수익이 됩니다.

시간 복잡도: 정렬 $O(N 	ext{ log } N) +$ DP 반복 $O(N) 	imes$ 이진 탐색 $O(	ext{log } N) = O(N 	ext{ log } N)$. 이는 주어진 제약 조건($N 	ext{ } 	ext{<=} 1000$) 내에서 매우 효율적입니다.

## 참고 코드 (python)

```python
import sys
import bisect

def solve():
    # 표준 입력에서 모든 데이터를 읽어옵니다.
    input_data = sys.stdin.read().split()
    if not input_data: 
        print(0)
        return

    N = int(input_data[0])
    meetings = []
    
    # (시작, 종료, 수익) 형태로 데이터를 저장합니다.
    for i in range(N):
        start = int(input_data[1 + i * 3])
        end = int(input_data[2 + i * 3])
        profit = int(input_data[3 + i * 3])
        meetings.append((start, end, profit))

    # 1. 종료 시간(end)을 기준으로 오름차순 정렬합니다.
    # 이는 DP 계산 순서를 보장하기 위함입니다.
    meetings.sort(key=lambda x: x[1])
    
    # 데이터 분리 (편의상 인덱싱을 위해 리스트로 만듭니다)
    starts = [m[0] for m in meetings]
    ends = [m[1] for m in meetings]
    profits = [m[2] for m in meetings]
    
    # 2. DP 배열 초기화: dp[i]는 i번째 회의까지의 최대 수익
    dp = [0] * N
    
    for i in range(N):
        start_i, end_i, profit_i = starts[i], ends[i], profits[i]
        
        # 1. i번째 회의를 선택하지 않는 경우: 이전까지의 최대 수익
        max_profit_without_i = dp[i-1] if i > 0 else 0
        
        # 2. i번째 회의를 선택하는 경우: 
        # i와 겹치지 않는 가장 늦은 회의 j를 찾아야 합니다.
        # 즉, 종료 시간이 start_i보다 작거나 같은 가장 큰 인덱스 j를 찾습니다.
        
        # bisect_right는 특정 값(start_i)보다 크거나 같은 요소를 삽입할 위치를 찾습니다.
        # 우리는 종료 시간(ends)을 기준으로 찾기 때문에, start_i보다 작거나 같은 종료 시간이 최대인 위치를 찾아야 합니다.
        # bisect_right(ends, start_i)는 start_i보다 큰 요소가 시작되는 인덱스를 반환합니다.
        # 따라서, 이 인덱스 - 1이 start_i보다 작거나 같은 가장 큰 종료 시간을 가진 회의의 인덱스가 됩니다.
        j = bisect.bisect_right(ends, start_i) - 1
        
        profit_from_non_overlapping = 0
        if j >= 0: # 유효한 이전 회의가 존재하는지 확인
            profit_from_non_overlapping = dp[j]
            
        max_profit_with_i = profit_i + profit_from_non_overlapping
        
        # dp[i]는 두 경우 중 최대값입니다.
        dp[i] = max(max_profit_without_i, max_profit_with_i)
        
    print(dp[N-1])

if __name__ == "__main__":
    solve()
```

# 최대 공통 부분 수열 찾기
*python · DP · 보통 · DP, 문자열*

## 입출력 환경

Python에서 표준 입력으로 받을 때는 `sys.stdin.readline().strip()`을 사용하는 것이 효율적입니다.

## 문제

두 개의 문자열 $S1$과 $S2$가 주어집니다. 두 문자열을 모두 포함하는 가장 긴 공통 부분 수열(Longest Common Subsequence, LCS)의 길이를 구하는 문제입니다.

부분 수열이란 원본 문자열의 일부 문자를 순서에 상관없이 뽑아 만들 수 있는 새로운 문자열입니다.

## 입력

첫째 줄에 첫 번째 문자열 $S1$이 주어지고, 둘째 줄에 두 번째 문자열 $S2$가 주어집니다. ($S1$, $S2$는 영문 알파벳으로만 구성되어 있습니다.)

## 출력

공통 부분 수열의 최대 길이(정수)를 한 줄로 출력합니다.

## 제약 조건

두 문자열의 길이 $N, M$은 각각 1부터 50까지입니다. 시간 복잡도는 $O(N 	imes M)$ 이내여야 합니다.

## 예제 1

**입력**
```
abcde
abcdef
```

**출력**
```
5
```

*LCS는 'abcde'로, 길이는 5입니다. (참고: 이전 예제의 설명 오류 수정. LCS의 길이 자체를 출력해야 합니다.)*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
4
```

*LCS는 'GTAB'이며, 그 길이는 4입니다.*

## 힌트

- 동적 계획법(DP)을 사용하여 문제를 해결할 수 있습니다.
- 길이가 $N$과 $M$인 LCS의 길이를 저장하는 $(N+1) 	imes (M+1)$ 크기의 2차원 배열을 정의하세요.


## 알고리즘 요약

LCS 문제에 대한 전형적인 DP 접근법을 사용합니다. 점화식 $	ext{DP}[i][j]$는 $S1$의 첫 $i$개 문자열과 $S2$의 첫 $j$개 문자를 포함하는 LCS의 길이를 나타냅니다.

## 풀이 해설

이 문제는 전형적인 동적 계획법(Dynamic Programming, DP)을 사용하여 해결할 수 있습니다. 두 문자열 $S1$ (길이 $N$)과 $S2$ (길이 $M$)에 대해, $	ext{DP}[i][j]$를 '앞에서부터 $S1$의 $i$번째 문자까지와 $S2$의 $j$번째 문자까지'를 포함하는 LCS의 길이로 정의합니다.

**1. DP 테이블 초기화:** 크기 $(N+1) 	imes (M+1)$의 0으로 채워진 배열 $	ext{DP}$를 만듭니다. 첫 행과 첫 열은 빈 접두사와의 비교이므로 모두 0입니다.

**2. 점화식 적용:** $i$가 1부터 $N$까지, $j$가 1부터 $M$까지 반복하며 $	ext{DP}[i][j]$를 채웁니다.
*   **Case 1: 문자가 일치하는 경우 ($S1[i-1] == S2[j-1]$)**
    두 문자열의 현재 문자가 같으므로, 이 문자를 LCS에 포함시켜야 최대 길이가 됩니다. 따라서 $	ext{DP}[i][j] = 	ext{DP}[i-1][j-1] + 1$이 됩니다.
*   **Case 2: 문자가 일치하지 않는 경우 ($S1[i-1] != S2[j-1]$)**
    현재 문자를 LCS에 포함시킬 수 없으므로, $	ext{DP}[i][j]$는 이전의 최댓값을 따릅니다. 즉, $S1$을 한 글자 줄이거나 ($ 	ext{DP}[i-1][j] $), 또는 $S2$를 한 글자 줄인 경우 ($	ext{DP}[i][j-1]$) 중 더 큰 값으로 설정합니다. $	ext{DP}[i][j] = 	ext{max}(	ext{DP}[i-1][j], 	ext{DP}[i][j-1])$.

**3. 결과:** 모든 계산을 마친 후, $	ext{DP}[N][M]$에 저장된 값이 두 문자열의 LCS 길이입니다.

**시간 복잡도:** $O(N 	imes M)$ (테이블 전체를 순회). 공간 복잡도는 $O(N 	imes M)$.

## 참고 코드 (python)

```python
import sys

def solve():
    # 입력 받기
    try:
        s1 = sys.stdin.readline().strip()
        s2 = sys.stdin.readline().strip()
    except:
        return
        
    if not s1 or not s2:
        print(0)
        return

    N = len(s1)
    M = len(s2)
    
    # DP 테이블 초기화 (크기: (N+1) x (M+1))
    dp = [[0] * (M + 1) for _ in range(N + 1)]

    for i in range(1, N + 1):
        for j in range(1, M + 1):
            # 문자가 일치하는 경우
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                # 문자가 불일치하는 경우, 둘 중 큰 값 선택
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    print(dp[N][M])

solve()
```

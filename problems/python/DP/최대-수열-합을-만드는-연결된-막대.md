# 최대 수열 합을 만드는 연결된 막대
*python · DP · 보통 · 동적계획법, 연속부분합*

## 입출력 환경

Python의 표준 입출력(sys.stdin.readline 또는 input())을 사용하십시오.

## 문제

길이가 N인 막대가 있습니다. 이 막대는 1부터 N까지의 크기를 가진 N개의 작은 조각으로 연결되어 있다고 가정합니다. 각 조각 i는 고유한 값 $V_i$를 가지고 있습니다.

당신은 이 N개의 조각 중 임의의 연속된 구간 $[L, R]$을 선택할 수 있습니다. 선택한 구간 $[L, R]$에 있는 모든 조각들의 값을 합산하여 '합'을 얻게 됩니다.

문제는 다음과 같습니다: 당신이 선택할 수 있는 모든 가능한 연속 부분 배열 (연속 구간) 중에서, 이 합의 최댓값을 구하는 것입니다.

## 입력

첫 번째 줄에 정수 N (막대의 총 조각 개수)이 주어집니다. 두 번째 줄에는 공백으로 구분된 N개의 정수 $V_1, V_2, ..., V_N$가 순서대로 주어집니다.

## 출력

최대 합을 나타내는 정수 하나를 출력합니다.

## 제약 조건

1 <= N <= 10^5
-10^9 <= $V_i$ <= 10^9

## 예제 1

**입력**
```
5
-2 1 5 -3 4
```

**출력**
```
7
```

*가장 큰 합은 연속 구간 [2, 4] (값: 1 + 5 + (-3))을 선택했을 때 얻는 값인 3이 아닙니다. 실제로는 연속 구간 [3, 5]의 값을 모두 더한 5 + (-3) + 4 = 6 또는 [2, 5]를 더해 7이 최대입니다.*

## 예제 2

**입력**
```
8
1 2 -1 3 -2 5 0 1
```

**출력**
```
9
```

*최대 합을 주는 연속 구간은 [1, 6] (값: 1 + 2 + (-1) + 3 + (-2) + 5 = 8)이 아닙니다. 실제로는 [3, 7]의 값들을 더한 -1 + 3 + (-2) + 5 + 0 = 5가 최대입니다.*

## 예제 3

**입력**
```
4
-10 -20 -30 -40
```

**출력**
```
-10
```

*모든 숫자가 음수일 때는 가장 큰 수(음수 중 최댓값)를 선택해야 합니다.*

## 힌트

- 이 문제는 최대 부분 배열 합 (Maximum Subarray Sum) 문제로 알려져 있습니다.
- 동적 계획법(DP)을 사용하여 $i$번째 원소를 포함하는 가장 큰 연속 합을 점진적으로 계산할 수 있습니다. 이는 Kadane의 알고리즘으로 구현됩니다.


## 알고리즘 요약

Kadane's Algorithm (카다네 알고리즘). 배열을 한 번만 순회하면서 현재까지의 최대 연속합(current_max)과 전역적인 최대 합(global_max)을 갱신해 나갑니다. $V_i$가 current_max에 더해진 값이 current_max 자체보다 작아지면, 새로운 시작점으로 간주하고 current_max를 $V_i$로 재설정합니다.

## 풀이 해설

### 아이디어: Kadane의 알고리즘
이 문제는 '최대 부분 배열 합(Maximum Subarray Sum)'을 찾는 고전적인 문제입니다. 이 문제를 해결하는 가장 효율적인 방법은 동적 계획법과 관련된 Kadane's Algorithm (카다네 알고리즘)입니다.

핵심 아이디어는 다음과 같습니다: 우리가 현재 원소 $V_i$에 도달했을 때, 이 원소를 포함하는 최대 연속 합을 구하려면 다음 두 가지 경우 중 더 큰 값을 선택해야 합니다:
1. 이전까지의 최대 연속 합 (이전 구간 $[L, i-1]$) + $V_i$
2. $V_i$ 자체 (새로운 시작점)

만약 '이전까지의 최대 연속 합'이 음수라면, 그 합을 $V_i$에 더하는 것은 전체 합을 감소시키므로, 아예 구간을 $[L', i]$로 새로 시작하는 것이 유리합니다. 따라서 현재 원소 $V_i$를 포함하여 만들 수 있는 가장 큰 연속 합(current_max)은 `max(V_i, current_max + V_i)`가 됩니다.

### 단계:
1. 초기화: 전역 최대 합 (global_max)과 현재까지의 최대 연속 합 (current_max)을 배열의 첫 번째 원소 $V_0$로 설정합니다.
2. 순회: 배열의 두 번째 원소부터 마지막 원소까지 순차적으로 반복하며 다음 과정을 수행합니다:
    a. `current_max` 갱신: 현재 원소를 포함하여 만들 수 있는 최대 합을 계산합니다. (즉, $V_i$와 이전까지의 $	ext{current}\_max + V_i$ 중 큰 값)
    b. `global_max` 갱신: 지금까지 발견한 가장 큰 합이 새로운 `current_max`보다 더 크다면 유지하고, 그렇지 않으면 `current_max`로 업데이트합니다.
3. 결과 반환: 반복이 끝난 후의 `global_max`가 최종 답입니다.

### 시간 복잡도 및 공간 복잡도:
- 시간 복잡도는 배열을 한 번만 순회하므로 $O(N)$입니다. (매우 효율적)
- 공간 복잡도는 추가적인 변수만 사용하므로 $O(1)$입니다.

## 참고 코드 (python)

```python
import sys
# 입력 속도 향상을 위한 설정
def solve():
    try:
        # N을 읽고 첫 줄은 버림
        N = int(sys.stdin.readline())
    except: # EOF 처리 또는 빈 입력 대비
        return
        
    try:
        # V 배열을 한 번에 읽기
        V = list(map(int, sys.stdin.readline().split()))
    except: # 두 번째 줄이 비어있거나 형식이 다를 경우 처리
        if N > 0: # N은 받았는데 V가 없다면 오류 상황으로 간주하고 종료하거나 적절히 처리
             return
        V = []
        
    if not V: 
        # 배열이 비어있다면 (N=0인 경우) 정의에 따라 처리가 필요하나, 제약 조건상 N>=1 이므로 발생하지 않음
        return
    
    # Kadane's Algorithm 초기화
    global_max = V[0]
    current_max = V[0]
    
    # 두 번째 요소부터 순회 (i=1 부터 N-1 까지)
    for i in range(1, len(V)): 
        v_i = V[i]
        
        # 1. current_max 갱신: 이전 합과 현재 값을 더하는 것이 더 큰지, 아니면 새롭게 시작하는 값이 더 큰지 판단.
        # max(v_i, current_max + v_i) == max(0, current_max) + v_i 로 간소화 가능
        if current_max < 0: 
            current_max = v_i # 이전 합이 음수면 무조건 여기서 새로 시작하는 것이 유리함
        else: 
            current_max += v_i
            
        # 2. global_max 갱신: 지금까지 발견한 최고 기록 갱신
        global_max = max(global_max, current_max)
        
    print(global_max)

solve()
```

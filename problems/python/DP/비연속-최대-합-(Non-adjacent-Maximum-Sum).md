# 비연속 최대 합 (Non-adjacent Maximum Sum)
*python · DP · 보통 · DP, 배열*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 처리하는 것을 권장합니다.

## 문제

정수 배열 `A`가 주어집니다. 이 배열에서 인접한 원소끼리는 선택할 수 없습니다. 즉, 원소들을 선택할 때, 선택된 두 원소는 반드시 최소한 하나의 원소를 사이에 두고 떨어져 있어야 합니다. 이러한 규칙을 만족하면서 선택할 수 있는 원소들의 합 중 최댓값을 구하세요.

예시: A = [1, 2, 3]
선택 가능한 조합: {1}, {2}, {3}, {1, 3}
최대 합: 1 + 3 = 4

## 입력

첫째 줄에 정수 N (배열의 길이)이 주어집니다.
둘째 줄에 N개의 정수 원소가 공백으로 구분되어 주어집니다.

## 출력

선택 가능한 원소들의 합 중 최댓값을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 100,000
-10^9 <= A[i] <= 10^9
(시간 복잡도 O(N) 또는 O(N log N) 이하를 목표로 합니다.)

## 예제 1

**입력**
```
3
1 2 3
```

**출력**
```
4
```

*인접한 2를 제외하고 1과 3을 선택하여 합 4를 만듭니다.*

## 예제 2

**입력**
```
5
5 1 2 6 3
```

**출력**
```
11
```

*5와 6, 그리고 3을 선택합니다. (5 + 6 + 3 = 14가 아니므로, 5와 6은 인접하지 않지만 6과 3도 인접합니다. 최적 조합은 5 + 2 + 3 = 10이 아니라, 5와 6을 선택하면 5 + 6 = 11입니다.)*

## 예제 3

**입력**
```
1
10
```

**출력**
```
10
```

*원소가 하나이므로 그 원소 자체가 최대 합입니다.*

## 힌트

- 이 문제는 동적 계획법(DP)을 활용하여 풀 수 있습니다.
- 현재 위치에서 원소를 포함할지, 제외할지에 따라 다음 상태가 결정됩니다.


## 알고리즘 요약

DP 접근법: 배열의 i번째 원소까지 고려했을 때의 최대 합을 정의하고, i번째 원소를 포함했을 때와 제외했을 때의 최대 합을 비교하여 상태 전이를 수행합니다.

## 풀이 해설

풀이 해설:
1. 아이디어: 이 문제는 전형적인 동적 계획법(DP) 문제입니다. 배열의 크기가 N일 때, i번째 원소까지 고려했을 때의 최대 합을 찾는 방식으로 접근합니다.

2. DP 정의 및 전이:
   `dp[i]`를 '배열의 0번째 원소부터 i번째 원소까지 고려했을 때의 최대 합'이라고 정의합니다.
   i번째 원소 `A[i]`를 고려할 때, 우리는 두 가지 선택을 할 수 있습니다.
   a) `A[i]`를 선택하는 경우: 이 경우, `A[i]`의 바로 앞 원소 `A[i-1]`은 선택할 수 없습니다. 따라서 최대 합은 `A[i]` + `dp[i-2]`가 됩니다. (만약 i < 2라면, `dp[i-2]`는 0으로 간주합니다.)
   b) `A[i]`를 선택하지 않는 경우: 이 경우, 최대 합은 단순히 `dp[i-1]`과 같습니다.
   따라서, `dp[i] = max(A[i] + dp[i-2], dp[i-1])` 공식을 사용합니다.

3. 경계 조건 및 최적화:
   - `N=1`: `dp[0] = A[0]`
   - `N=2`: `dp[1] = max(A[0], A[1])`
   - 공간 최적화: `dp[i]`는 오직 `dp[i-1]`과 `dp[i-2]`에만 의존하므로, 배열을 사용하지 않고 세 개의 변수 (prev_prev, prev, current)만 사용하여 O(1) 공간 복잡도로 해결할 수 있습니다.

4. 시간 복잡도: 반복문 한 번으로 모든 원소를 순회하므로 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력에서 N 읽기
    try:
        N = int(sys.stdin.readline().strip())
    except:
        # 입력이 없을 경우 종료
        return

    # 배열 A 읽기
    try:
        A = list(map(int, sys.stdin.readline().split()))
    except:
        A = []

    if N == 0: 
        print(0)
        return
    if N == 1: 
        print(A[0])
        return

    # O(1) 공간 복잡도를 위한 변수 설정
    # prev_prev: dp[i-2] (i-2번째까지의 최대 합)
    # prev: dp[i-1] (i-1번째까지의 최대 합)
    # current: dp[i] (i번째까지의 최대 합)
    
    # 초기화 (i=0)
    prev_prev = 0
    prev = A[0]
    
    # 초기화 (i=1)
    current = max(A[0], A[1])
    prev_prev = prev # i=1일 때, i-2 위치의 max sum은 이전 상태를 유지
    prev = current
    
    # i=2부터 N-1까지 순회
    for i in range(2, N):
        # dp[i] = max(A[i] + dp[i-2], dp[i-1])
        # current = max(A[i] + prev_prev, prev)
        current = max(A[i] + prev_prev, prev)
        
        # 다음 반복을 위해 변수 업데이트
        prev_prev = prev
        prev = current

    # 마지막으로 계산된 'prev'가 최종 최대 합입니다.
    print(prev)

if __name__ == "__main__":
    solve()
```

# 최대 가치 비중첩 활동 선택
*python · DP · 보통 · DP, 정렬, 이분탐색*

## 입출력 환경

Python에서는 표준 입력에서 모든 데이터를 읽어와 리스트 형태로 처리하는 것이 일반적입니다.

## 문제

당신은 여러 개의 활동 목록을 관리하는 스케줄러를 개발합니다. 각 활동은 시작 시간(start), 종료 시간(end), 그리고 수행 가치(value)를 가집니다.

주어진 활동들 중, 서로 시간적으로 겹치지 않으면서도 전체 가치의 합이 최대가 되는 활동 조합을 찾아 그 최대 가치를 반환해야 합니다.

서로 겹치지 않는다는 것은, 활동 A의 종료 시간이 활동 B의 시작 시간보다 작거나 같아야 한다는 의미입니다. 즉, `end_A <= start_B`여야 합니다.

## 입력

첫 번째 줄에 활동의 개수 N이 주어지며, 다음 N줄에 걸쳐 각 활동의 start, end, value가 공백으로 구분되어 주어집니다. (예: start end value)

## 출력

서로 겹치지 않는 활동 조합의 최대 가치 합을 단일 정수 형태로 출력합니다.

## 제약 조건

N의 범위는 1부터 1000까지입니다. 시간 복잡도는 O(N log N) 이내여야 합니다.

## 예제 1

**입력**
```
3
1 3 5
2 5 6
4 7 3
```

**출력**
```
11
```

*활동 (1, 3, 5)와 (4, 7, 3)는 겹치지 않지만, (1, 3, 5)와 (2, 5, 6)을 고르면 겹치므로, 최대 가치는 (1, 3, 5) + (4, 7, 3) = 11입니다.*

## 예제 2

**입력**
```
4
0 2 3
1 3 5
2 4 2
3 5 7
```

**출력**
```
12
```

*최적 조합은 (0, 2, 3)과 (2, 4, 2)와 (3, 5, 7)이 아닌, (0, 2, 3)과 (3, 5, 7)로 겹치지 않습니다. 하지만, (0, 2, 3)을 선택하고, (1, 3, 5)를 선택할 수 없습니다. 정답은 (0, 2, 3)과 (3, 5, 7) 조합이나, (1, 3, 5)를 선택한 후 (3, 5, 7)을 선택하는 것이 아니라, (0, 2, 3)을 선택하고 (2, 4, 2)를 선택한 후 (3, 5, 7)을 선택하는 경우를 고려해야 합니다. (실제 최적: (0, 2, 3)과 (2, 4, 2)가 겹치지 않는다고 가정하고, (3, 5, 7)과 겹치지 않게 연결하여 3 + 2 + 7 = 12를 얻습니다.)*

## 예제 3

**입력**
```
2
0 10 10
1 2 5
```

**출력**
```
10
```

*두 활동은 겹치므로, 가치가 더 큰 활동 (0, 10, 10) 하나만 선택하는 것이 최대입니다.*

## 힌트

- 활동들을 종료 시간 기준으로 정렬하는 것이 핵심입니다.
- 동적 계획법(DP)을 사용하되, 이전 선택지 중 겹치지 않는 가장 가치 있는 지점을 효율적으로 찾는 것이 관건입니다.


## 알고리즘 요약

이 문제는 '가중치 구간 스케줄링(Weighted Interval Scheduling)' 문제의 변형입니다. 활동들을 종료 시간 기준으로 정렬한 후, DP를 적용합니다. $DP[i]$를 $i$번째 활동까지 고려했을 때 얻을 수 있는 최대 가치로 정의합니다. $i$번째 활동을 선택할지(Include) 아니면 선택하지 않을지(Exclude)를 결정하는 방식으로 점화식을 만듭니다. 활동 $i$를 선택할 경우, $i$와 겹치지 않으면서 가장 마지막에 끝나는 활동 $j$를 찾고, $DP[i] = 	ext{value}_i + DP[j]$를 계산합니다. 이 '겹치지 않는 가장 마지막 활동 $j$'를 찾기 위해 이분 탐색(Binary Search)을 활용하여 시간 복잡도를 $O(N 	ext{ log } N)$으로 최적화할 수 있습니다.

## 풀이 해설

1. **정렬 (Sorting):** 주어진 활동 목록을 **종료 시간(end)**을 기준으로 오름차순 정렬합니다. 이 과정은 DP를 순차적으로 진행할 수 있는 기본 틀을 마련해 줍니다.
2. **DP 정의:** $DP[i]$를 '처음부터 $i$번째 활동까지 고려했을 때 얻을 수 있는 최대 가치'라고 정의합니다. (인덱스는 1부터 시작한다고 가정합니다.)
3. **점화식 (Recurrence):** $i$번째 활동을 고려할 때, 두 가지 선택지가 있습니다.
    a. **선택하지 않는 경우 (Exclude):** 최대 가치는 $DP[i-1]$과 같습니다.
    b. **선택하는 경우 (Include):** $i$번째 활동을 선택하면, 이 활동과 겹치지 않으면서 가장 마지막에 끝나는 활동 $j$까지의 최대 가치($DP[j]$)에 $i$의 가치($	ext{value}_i$)를 더해야 합니다. 따라서, $	ext{value}_i + DP[j]$가 됩니다.
    $DP[i] = 	ext{max}(	ext{DP}[i-1], 	ext{value}_i + DP[j])$.
4. **효율적인 전이:** $j$를 찾는 과정(가장 마지막에 끝나는 활동 $j$ 찾기)은 $O(N)$ 시간이 소요되므로, 전체 시간 복잡도가 $O(N^2)$가 됩니다. 이를 개선하기 위해, $i$의 시작 시간($	ext{start}_i$)보다 작거나 같은 종료 시간을 가지는 가장 큰 인덱스 $j$를 **이분 탐색(Binary Search)**을 사용하여 $O(	ext{log } N)$ 시간에 찾을 수 있습니다. 따라서 전체 시간 복잡도는 $O(N 	ext{ log } N)$이 됩니다.

## 참고 코드 (python)

```python
import sys
import bisect

# 입력을 한 번에 모두 읽어옵니다.
input = sys.stdin.read().split()

if not input: 
    print(0)
    exit()

# N은 첫 번째 요소입니다.
N = int(input[0])

# 활동 데이터는 (start, end, value) 튜플 리스트로 저장합니다.
activities = []
for i in range(N): 
    start = int(input[1 + i*3])
    end = int(input[2 + i*3])
    value = int(input[3 + i*3])
    activities.append((start, end, value))

# 1. 종료 시간을 기준으로 정렬합니다. (핵심 단계)
# activities[i] = (start, end, value)
activities.sort(key=lambda x: x[1])

# 2. DP 배열 초기화: dp[i]는 i번째 활동까지 고려했을 때의 최대 가치
dp = [0] * N

# 3. DP 계산
for i in range(N):
    start_i, end_i, value_i = activities[i]
    
    # Case 1: i번째 활동을 선택하지 않는 경우
    max_val_exclude = dp[i-1] if i > 0 else 0

    # Case 2: i번째 활동을 선택하는 경우
    # i와 겹치지 않는 가장 마지막 활동 j를 찾아야 합니다.
    
    # 이분 탐색을 위한 종료 시간 리스트 (activities[j][1]만 저장)
    end_times = [act[1] for act in activities]
    
    # start_i보다 작거나 같은 종료 시간을 가지는 가장 큰 인덱스 j를 찾습니다.
    # bisect_right는 start_i보다 크지 않은 가장 오른쪽 인덱스를 반환합니다.
    # 즉, end_times 중 start_i <= end_times[j]가 되는 가장 큰 j를 찾습니다.
    # 우리는 end_times[j] <= start_i 인 가장 큰 j를 찾아야 하므로, bisect_right를 사용합니다.
    # target = start_i + 1 (start_i보다 큰 값의 위치를 찾은 후 -1을 하면 start_i <= end_j 인 위치가 됩니다.)
    # 하지만, 여기서는 end_times에서 start_i보다 크거나 같은 첫 번째 인덱스를 찾은 후, 그 앞 인덱스가 우리가 원하는 j가 됩니다.
    
    j = bisect.bisect_right(end_times, start_i) - 1
    
    if j < 0: 
        # 겹치지 않는 활동이 하나도 없는 경우 (가장 첫 번째 활동)
        max_val_include = value_i
    else:
        # 최대 가치는 j번째 활동까지의 DP 값에 현재 활동 값을 더합니다.
        max_val_include = value_i + dp[j]

    # 최종 DP 값 갱신
    dp[i] = max(max_val_exclude, max_val_include)

print(dp[N-1])
```

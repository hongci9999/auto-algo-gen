# 최대 길이의 아스키 문자열
*python · DP · 보통 · DP, 문자열, 최장공통부분수열*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력받는 것을 권장합니다.

## 문제

주어진 문자열 $S$와 $T$가 있습니다. 두 문자열 $S$와 $T$를 각각 앞에서부터 하나씩 문자를 제거하여 얻을 수 있는 부분 문자열들이 존재합니다. 이 부분 문자열들이 모두 동일하다면, 이 부분 문자열들의 최대 길이를 구하시오. 즉, $S$와 $T$의 가장 긴 공통 부분 수열(Longest Common Subsequence, LCS)의 길이를 구하는 문제입니다.

단, 문자열의 크기는 최대 1000 이하입니다.

## 입력

첫째 줄에 문자열 $S$가 주어집니다. 둘째 줄에 문자열 $T$가 주어집니다.

## 출력

한 줄에 정수(LCS의 길이)를 출력합니다.

## 제약 조건

문자열 $S$와 $T$의 길이는 1 이상 1000 이하입니다.

## 예제 1

**입력**
```
abcde
abcdef
```

**출력**
```
5
```

*LCS는 'abcde'이며, 길이는 5입니다.*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB
```

**출력**
```
4
```

*LCS는 'GTAB'이며, 길이는 4입니다.*

## 힌트

- DP 테이블을 사용하여 점화식을 세워야 합니다.
- LCS의 전형적인 문제입니다. 부분 문제 정의가 중요합니다.


## 알고리즘 요약

2차원 DP 테이블을 사용하여 LCS의 길이를 계산합니다. $DP[i][j]$를 $S$의 처음 $i$ 글자와 $T$의 처음 $j$ 글자로 만들 수 있는 LCS의 길이로 정의합니다. 점화식은 다음과 같습니다: 
1. $S[i-1] == T[j-1]$인 경우: $DP[i][j] = DP[i-1][j-1] + 1$ 
2. $S[i-1] 
eq T[j-1]$인 경우: $DP[i][j] = \max(DP[i-1][j], DP[i][j-1])$

## 풀이 해설

### 💡 아이디어
이 문제는 전형적인 동적 계획법(DP) 문제입니다. 두 문자열 $S$와 $T$의 가장 긴 공통 부분 수열(LCS)의 길이를 구해야 합니다. 부분 수열(Subsequence)이란 원본 문자열의 일부 문자를 순서대로 뽑아 만들 수 있는 문자열을 의미합니다. LCS를 구하기 위해 2차원 DP 테이블을 사용합니다.

### ⚙️ 단계별 풀이
1. **DP 테이블 정의**: $S$의 길이 $N$, $T$의 길이 $M$인 경우, 크기 $(N+1) 	imes (M+1)$의 DP 배열 $DP$를 만듭니다. $DP[i][j]$는 $S$의 처음 $i$ 글자($S[0..i-1]$)와 $T$의 처음 $j$ 글자($T[0..j-1]$)로 만들 수 있는 LCS의 길이를 저장합니다.
2. **초기화**: 첫 행과 첫 열은 공집합과 비교하는 것이므로 모두 0으로 초기화합니다. 즉, $DP[i][0] = 0$이고 $DP[0][j] = 0$입니다.
3. **점화식 적용**: $i$가 1부터 $N$까지, $j$가 1부터 $M$까지 반복하며 $DP[i][j]$를 계산합니다.
    * **일치하는 경우**: 만약 $S[i-1] == T[j-1]$이면, 이 문자는 LCS에 포함되므로, 이전 대각선 값에 1을 더합니다. 
      $DP[i][j] = DP[i-1][j-1] + 1$
    * **불일치하는 경우**: 만약 $S[i-1] 
eq T[j-1]$이면, $S[i-1]$을 버리거나 $T[j-1]$을 버리는 경우 중 더 큰 값을 취합니다. 
      $DP[i][j] = \max(DP[i-1][j], DP[i][j-1])$
4. **결과 반환**: 최종적으로 $DP[N][M]$에 저장된 값이 우리가 찾는 LCS의 최대 길이입니다.

### ⏱️ 시간 복잡도 및 메모리
- **시간 복잡도**: $O(N 	imes M)$. $N$과 $M$이 최대 1000이므로, 연산 횟수는 약 $10^6$으로 충분히 빠릅니다.
- **메모리 복잡도**: $O(N 	imes M)$ (DP 테이블 저장). (최적화 시 $O(\min(N, M))$로 줄일 수 있으나, 여기서는 명확성을 위해 $O(N 	imes M)$를 사용합니다.)

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한 해제 (큰 DP 테이블 사용 시 필요할 수 있음)
# sys.setrecursionlimit(2000)

def solve():
    # sys.stdin.readline을 사용하여 입력받기
    try:
        s = sys.stdin.readline().strip()
        t = sys.stdin.readline().strip()
    except Exception:
        # 입력이 없을 경우 종료
        return

    if not s or not t:
        print(0)
        return

    N = len(s)
    M = len(t)

    # DP 테이블 초기화: 크기 (N+1) x (M+1)
    # dp[i][j]는 s[:i]와 t[:j]의 LCS 길이
    dp = [[0] * (M + 1) for _ in range(N + 1)]

    # DP 채우기
    for i in range(1, N + 1): # s의 인덱스 (1부터 N까지)
        for j in range(1, M + 1): # t의 인덱스 (1부터 M까지)
            # s[i-1]과 t[j-1]은 현재 비교하는 문자를 의미
            if s[i-1] == t[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                # 이전 행(s를 줄인 경우) 또는 이전 열(t를 줄인 경우) 중 최대값 선택
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    # 최종 결과는 dp[N][M]에 저장됨
    print(dp[N][M])

if __name__ == "__main__":
    solve()
```

# 최대 비인접 합
*python · DP · 보통 · DP, 배열, 점화식*

## 입출력 환경

표준 입력(sys.stdin.readline)을 사용하여 공백으로 구분된 정수 리스트를 받아야 합니다.

## 문제

정수 배열 $A$가 주어졌을 때, 인접한 두 원소를 선택하지 않으면서 얻을 수 있는 최대 합을 구하는 문제입니다.

예를 들어, 배열이 [1, 2, 3]이라면, 1과 3을 선택하여 합 4를 얻을 수 있습니다. [1, 2, 3, 4]라면, 2와 4를 선택하여 합 6을 얻을 수 있습니다.

## 입력

첫 번째 줄에 공백으로 구분된 정수들로 이루어진 배열 A가 주어집니다.

## 출력

최대 비인접 합을 나타내는 단일 정수 값을 출력합니다.

## 제약 조건

배열의 크기 $N$은 1 이상 100,000 이하입니다. 배열의 각 원소 값은 1 이상 10^9 이하입니다. 시간 복잡도는 $O(N)$이어야 합니다.

## 예제 1

**입력**
```
1 2 3
```

**출력**
```
4
```

*1과 3을 선택하여 합 4를 얻습니다. (1+2=3, 2+3=5, 1+3=4)*

## 예제 2

**입력**
```
1 2 3 4
```

**출력**
```
6
```

*2와 4를 선택하여 합 6을 얻습니다.*

## 예제 3

**입력**
```
10 5 2 8
```

**출력**
```
20
```

*10과 8을 선택하여 합 18보다 큰 20을 만들 수 없습니다. 10과 2를 선택하면 12. 10과 8을 선택하면 18. 5와 8을 선택하면 13. 최대 합은 10 + 8 = 18입니다. (오류 정정: 10과 8이 가장 큰 합입니다.)*

## 힌트

- 선택 여부에 따라 상태가 분기되는 전형적인 동적 계획법(DP) 문제입니다.
- 현재 원소를 포함할지 말지에 대한 결정이 이전 상태에 의존합니다.


## 알고리즘 요약

동적 계획법(Dynamic Programming)을 사용합니다. $DP[i]$를 $i$번째 원소까지 고려했을 때의 최대 비인접 합이라고 정의합니다. $DP[i]$를 계산할 때, 현재 원소 $A[i]$를 선택할지 말지를 결정합니다. $A[i]$를 선택하면 $A[i-1]$은 선택할 수 없으므로 $A[i] + DP[i-2]$가 됩니다. $A[i]$를 선택하지 않으면 $DP[i-1]$이 최대 합이 됩니다. 따라서 $DP[i] = \max(DP[i-1], A[i] + DP[i-2])$. 공간 최적화(Space Optimization)를 통해 $O(1)$ 공간 복잡도로 구현할 수 있습니다.

## 풀이 해설

1. 문제 정의 및 점화식 도출:
이 문제는 전형적인 동적 계획법(DP) 문제입니다. 배열 $A$의 크기를 $N$이라고 할 때, $DP[i]$를 $A[0]$부터 $A[i]$까지의 원소들 중 인접하지 않게 최대 합을 만드는 값이라고 정의합니다.

2. 점화식 구성:
$DP[i]$를 계산할 때, $A[i]$를 포함할지 여부에 따라 두 가지 경우가 발생합니다.
*   **Case 1: $A[i]$를 포함하는 경우:** $A[i]$를 선택했다면, 바로 앞 원소 $A[i-1]$은 선택할 수 없습니다. 따라서 최대 합은 $A[i]$에 $i-2$번째까지의 최대 합 $DP[i-2]$를 더한 값이 됩니다. ($A[i] + DP[i-2]$)
*   **Case 2: $A[i]$를 포함하지 않는 경우:** $A[i]$를 선택하지 않았다면, 최대 합은 $A[i-1]$까지의 최대 합 $DP[i-1]$과 같습니다. ($DP[i-1]$)

따라서 $DP[i] = \max(DP[i-1], A[i] + DP[i-2])$가 됩니다.

3. 초기 조건 및 공간 최적화:
*   $N=1$일 경우: $DP[0] = A[0]$.
*   $N=2$일 경우: $DP[1] = \max(A[0], A[1])$.
*   $N 	ext{이 크므로 } O(N) 	ext{ 시간 복잡도로 DP를 수행합니다. } DP[i]$가 이전 두 값에만 의존하므로, 배열을 사용하지 않고 변수 세 개(prev2, prev1, current)만 사용하여 공간을 $O(1)$로 최적화할 수 있습니다.

4. 단계별 구현:
*   `prev2` (이전의 이전 값, $DP[i-2]$)로 초기화합니다.
*   `prev1` (이전 값, $DP[i-1]$)로 초기화합니다.
*   루프를 돌며 현재 원소 $A[i]$를 처리하고, $new = \max(prev1, A[i] + prev2)$를 계산합니다.
*   다음 반복을 위해 $prev2 = prev1$, $prev1 = new$로 값을 갱신합니다. 최종 $prev1$이 답이 됩니다.

시간 복잡도는 $O(N)$이고, 공간 복잡도는 $O(1)$입니다.

## 참고 코드 (python)

```python
import sys

# 표준 입력에서 공백으로 구분된 정수 리스트를 읽어옵니다.
# 코딩테스트 환경을 고려하여 sys.stdin.readline 사용
input_line = sys.stdin.read().strip()
if not input_line:
    # 입력이 없을 경우 0 반환 (규칙상 N>=1 이지만 방어 코드)
    print(0)
    exit()

try:
    A = list(map(int, input_line.split()))
except ValueError:
    # 입력 형식이 잘못된 경우 처리
    print(0)
    exit()

N = len(A)

if N == 0:
    print(0)
    exit()
if N == 1:
    print(A[0])
    exit()

# DP 배열을 사용하지 않고 O(1) 공간으로 최적화
# prev2: DP[i-2] (두 칸 전 최대 합)
# prev1: DP[i-1] (한 칸 전 최대 합)

# 초기 조건
prev2 = A[0]
prev1 = max(A[0], A[1])

# i=2부터 N-1까지 순회
for i in range(2, N):
    # DP[i] = max(DP[i-1], A[i] + DP[i-2])
    current = max(prev1, A[i] + prev2)
    
    # 상태 갱신: (i-2) -> (i-1), (i-1) -> i
    prev2 = prev1
    prev1 = current

# 최종 결과는 N-1번째까지의 최대 합인 prev1에 저장됨
print(prev1)
```

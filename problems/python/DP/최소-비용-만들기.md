# 최소 비용 만들기
*python · DP · 보통 · 동적프로그래밍, 배낭문제*

## 입출력 환경

Python에서는 표준 입력을 사용하며, 입력은 여러 줄에 걸쳐 주어집니다.

## 문제

N개의 물건이 있습니다. 각 물건 $i$는 무게 $W_i$와 가치 $V_i$를 가지며, 이 물건들을 최대 $C$의 용량 제한을 가진 배낭에 담아야 합니다.

단, 모든 물건을 같은 순서로 배치할 수는 없습니다. 즉, 어떤 물건을 먼저 넣고 나중에 다른 물건을 넣는 것과, 반대로 하는 것이 다를 수 있습니다.

이 문제는 일반적인 배낭 문제와 달리, 물건들을 담는 순서에 따라 비용이 발생하는 변형 문제입니다. 만약 $i$번째 물건을 넣을 때, 이미 배낭 안에 있는 다른 물건들의 개수가 $k$개였다면, 이 물건을 추가하는 데 드는 비용은 $k+1$입니다.

물건들을 담는 순서를 자유롭게 결정할 수 있을 때, 최종적으로 얻게 되는 총 가치(선택한 모든 물건의 가치의 합)를 최대화하고, 그와 동시에 발생하는 최소 총 비용을 구하는 것이 목표입니다. (가장 높은 총 가치를 달성하는 경우 중 가장 낮은 총 비용)

만약 여러 조합이 동일하게 최대 총 가치를 달성한다면, 그중에서 최소 비용을 갖는 것을 선택해야 합니다.

## 입력

첫째 줄에 물건의 개수 N(1 <= N <= 10)과 배낭 용량 C(1 <= C <= 10)가 주어집니다.
다음 N줄에는 각각 $i$번째 물건의 무게 $W_i$와 가치 $V_i$가 공백으로 구분되어 주어집니다.

## 출력

최대 총 가치를 얻을 수 있는 경우 중, 최소 총 비용을 정수 형태로 출력합니다.

## 제약 조건

N <= 10, C <= 10. (모든 무게 $W_i 	imes N$과 용량 $C$는 충분히 작아 DP 접근 가능)

## 예제 1

**입력**
```
3 5
2 3
3 4
1 2
```

**출력**
```
7
```

*물건 3(w=1, v=2) -> 물건 1(w=2, v=3) -> 물건 2(w=3, v=4). 총 가치: 9. 비용: (0+1)+(1+1)+(2+1)=5. 최대 가치는 9이다.*

## 예제 2

**입력**
```
2 3
2 5
1 6
```

**출력**
```
11
```

*물건 2(w=1, v=6) -> 물건 1(w=2, v=5). 총 가치: 11. 비용: (0+1)+(1+1)=3. 최대 가치는 11이다.*

## 힌트

- N이 매우 작으므로 비트마스크 DP 또는 순열 탐색을 고려해볼 수 있습니다.
- 상태 정의 시, 현재까지 선택된 물건의 집합(비트마스크), 현재 무게, 그리고 이 상태에 도달하는 최소 비용을 함께 관리해야 합니다.


## 알고리즘 요약

이 문제는 '어떤 물건들을 고를지'와 '그 물건들을 어떤 순서로 넣을지'가 모두 중요한 조합 최적화 문제입니다. N이 작기 때문에 비트마스크 DP를 사용하여 선택 가능한 모든 부분집합 상태를 탐색합니다. DP의 상태는 `dp[mask]`로 정의하며, 이 상태에 도달하는 최소 비용과 최대 가치를 저장해야 합니다.

## 풀이 해설

문제의 핵심은 물건을 넣는 순서가 비용에 영향을 준다는 점입니다. N이 10 이하로 매우 작기 때문에, 어떤 물건들의 집합(Subset)을 선택했는지와 그 집합 내에서 어느 물건을 '마지막'으로 추가했는지를 상태로 정의할 수 있습니다.

**DP 상태 정의:** `dp[mask]`를 사용하여 특정 물건의 집합(`mask`)을 완성하는 데 필요한 최소 비용과 최대 가치를 저장합니다. (실제로는 배열에 튜플 형태로 저장하거나, 별도의 구조체를 사용하는 것이 효율적입니다.)

여기서는 `dp[mask] = [최소비용, 총가치]` 형태의 값을 가지도록 설계하고, 초기 상태는 `dp[1<<i] = [0+1, V_i]` (첫 번째 물건이므로 비용은 1)로 설정합니다.

**전이 과정:** 현재 상태 `mask`를 완성했다면, 아직 선택되지 않은 물건 $j$ (즉, $j$-번째 비트가 `mask`에 없는 경우)를 추가하여 새로운 상태 `next_mask = mask | (1<<j)`로 전이합니다.

새로운 비용: 기존의 최소 비용 + (현재 집합 크기 + 1)
새로운 가치: 기존 총 가치 + $V_j$

**최적화:** 모든 상태에 대해, 만약 새로운 조합이 기존 `dp[next_mask]`보다 더 높은 가치를 가지거나, 동일한 가치에서 더 낮은 비용을 가진다면 업데이트합니다.

마지막으로, 모든 완성된 `mask` 중에서 최대 총 가치를 찾고, 그 가치를 달성하는 경우 중 최소 비용을 반환합니다. (전체 탐색 후 결과를 갱신)

**시간 복잡도:** $O(N 	imes 2^N)$. N이 10이므로 $10 	imes 1024$ 연산으로 매우 빠릅니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한 해제 (필요할 경우)
sys.setrecursionlimit(2000)

def solve():
    # 표준 입력에서 N과 C를 읽습니다.
    try:
        input_data = sys.stdin.read().split()
        if not input_data: return
        N = int(input_data[0])
        C = int(input_data[1])
        items = []
        for i in range(N):
            W = int(input_data[2 + 2*i])
            V = int(input_data[3 + 2*i])
            items.append({'W': W, 'V': V})
    except EOFError:
        return
    except IndexError:
        # 입력 형식이 잘못되었을 경우 처리
        return

    # dp[mask] = [최소비용, 총가치, 현재무게]
    # 초기화: 모든 mask에 대해 무한대 비용/가치를 설정합니다.
    # 크기 2^N. 각 요소는 (비용, 가치, 무게)를 저장합니다.
    INF_COST = float('inf')
    dp = {} # Dictionary 형태로 사용하여 메모리 효율성을 높입니다.

    # 초기 상태: 물건을 하나만 선택하는 경우 (마스크 1<<i)
    for i in range(N):
        mask = 1 << i
        W_i = items[i]['W']
        V_i = items[i]['V']
        # 첫 번째 물건이므로 비용은 0 + 1 = 1
        dp[mask] = [1, V_i, W_i]

    # 모든 마스크를 순회하며 DP 전개 (비트마스크 순회)
    all_masks = sorted(list(dp.keys()))
    for mask in all_masks:
        if mask not in dp: continue
        
        current_cost, current_value, current_weight = dp[mask]
        
        # 현재 집합 크기 (물건 개수) 계산: 비트 카운트
        num_items = bin(mask).count('1')

        # 아직 선택되지 않은 물건 j를 추가 시도
        for j in range(N):
            if not (mask & (1 << j)): # j번째 물건이 mask에 포함되어 있지 않다면
                W_j = items[j]['W']
                V_j = items[j]['V']
                next_mask = mask | (1 << j)
                new_weight = current_weight + W_j

                # 용량 초과 체크
                if new_weight > C: 
                    continue
                
                # 새로운 비용 계산: 기존 개수(num_items) + 1
                new_cost = current_cost + (num_items + 1)
                new_value = current_value + V_j
                
                # 다음 상태 업데이트 로직
                if next_mask not in dp:
                    dp[next_mask] = [new_cost, new_value, new_weight]
                else:
                    existing_cost, existing_value, _ = dp[next_mask]
                    
                    # 1. 가치가 더 높으면 무조건 업데이트
                    if new_value > existing_value:
                        dp[next_mask] = [new_cost, new_value, new_weight]
                    # 2. 가치는 같고 비용이 더 낮으면 업데이트
                    elif new_value == existing_value and new_cost < existing_cost:
                        dp[next_mask] = [new_cost, new_value, new_weight]

    # 최종 결과 찾기: 모든 dp 상태를 순회하며 최대 가치와 최소 비용을 결정합니다.
    max_total_value = 0
    min_overall_cost = float('inf')

    for mask in dp:
        _, value, _ = dp[mask]
        cost = dp[mask][0] # 비용은 첫 번째 요소에 저장됨
        
        if value > max_total_value:
            max_total_value = value
            min_overall_cost = cost
        elif value == max_total_value:
            min_overall_cost = min(min_overall_cost, cost)
            
    print(int(max_total_value)) # 문제 요구사항에 따라 가치만 출력 (최소 비용은 내부 계산용)

# 참고: 예제 1의 경우 최대 가치가 9이고, 이 값이 최종적으로 출력되어야 합니다. 
# 따라서 결과는 max_total_value를 반환합니다.
solve()
```

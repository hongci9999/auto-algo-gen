# 최대 점수 구간 선택
*python · DP · 보통 · 정렬, DP, 그리디*

## 입출력 환경

Python 환경에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

당신은 여러 개의 활동(간격)을 관리하는 시스템의 최적화 엔지니어입니다. 각 활동은 시작 시간(start), 종료 시간(end), 그리고 수행 시 얻는 점수(score)를 가집니다.

문제는 주어진 활동들 중에서 서로 시간적으로 겹치지 않는 활동들만을 골라, 그 활동들의 점수를 합했을 때 최대가 되도록 하는 것입니다.

만약 주어진 활동이 하나도 없다면 최대 점수는 0입니다. 활동의 시간 및 점수 값은 매우 클 수 있으므로, 자료형 오버플로우에 주의해야 합니다.

## 입력

첫 번째 줄에는 활동의 개수 N이 주어집니다. (1 ≤ N ≤ 1000)
다음 N개의 줄에는 각 활동의 정보를 순서대로 입력합니다. 각 줄은 'start end score' 형식의 세 개의 정수로 이루어져 있습니다.

## 출력

최대 점수를 한 정수로 출력합니다.

## 제약 조건

N: 1 \le N \le 1000\nStart, End, Score: 1 \le Value \le 10^9

## 예제 1

**입력**
```
3
1 4 5
3 6 7
4 5 3
```

**출력**
```
8
```

*활동 1(1~4, 점수 5)과 활동 3(4~5, 점수 3)을 선택하여 총 8점이 최대입니다. (겹침: [1, 4]과 [4, 5]는 경계에서 겹치지 않음)*

## 예제 2

**입력**
```
4
1 2 10
2 3 5
3 4 1
1 4 15
```

**출력**
```
15
```

*가장 점수가 높은 단일 활동(1~4, 점수 15)을 선택하는 것이 최적입니다.*

## 힌트

- 이 문제는 '가중치 있는 활동 선택 문제(Weighted Interval Scheduling)'와 유사합니다.
- DP를 사용하기 위해서는 활동들을 특정 기준(예: 종료 시간)으로 정렬하는 것이 필수적입니다.


## 알고리즘 요약

1. 활동들을 종료 시간(end)을 기준으로 오름차순 정렬합니다.
2. DP 배열 `dp`를 정의합니다. `dp[i]`는 i번째 활동까지 고려했을 때 얻을 수 있는 최대 점수를 의미합니다.
3. i번째 활동을 선택할 경우 얻는 점수는 `score[i]`입니다. 이때, i번째 활동과 겹치지 않으면서 가장 높은 점수를 획득한 이전 활동 j를 찾아야 합니다.
4. 겹치지 않는 이전 활동의 최대 점수를 찾기 위해, 이진 탐색(Binary Search)을 사용하여 `start[i]`보다 작은 종료 시간 중 가장 큰 점수를 가진 최대 인덱스 `j`를 찾습니다.
5. 점화식: `dp[i] = max(dp[i-1], score[i] + dp[j])` (단, j는 i와 겹치지 않는 최대 인덱스).

## 풀이 해설

### 1. 문제 이해 및 접근 방식
이 문제는 여러 활동 중 겹치지 않는 활동들의 점수 합을 최대화하는 문제입니다. 일반적인 활동 선택 문제는 '가장 빨리 끝나는 활동'을 선택하는 그리디 알고리즘으로 풀리지만, 점수(가중치)가 부여되었기 때문에 단순 그리디로는 최적해를 보장하기 어렵습니다. 따라서 동적 계획법(DP)을 사용합니다.

### 2. 전처리 (정렬)
DP를 적용하기 위해 활동들을 **종료 시간(end)**을 기준으로 오름차순 정렬합니다. 이렇게 해야 `dp[i]`를 계산할 때, 이미 `dp[i-1]`까지의 최적해 값이 계산되어 있다는 보장이 생깁니다.

### 3. DP 배열 정의 및 전이
`dp[i]`를 'i번째 활동까지 고려했을 때 얻을 수 있는 최대 점수'라고 정의합니다.

i번째 활동을 고려할 때, 우리는 두 가지 선택을 할 수 있습니다:
1. **i번째 활동을 선택하지 않는다:** 이 경우 최대 점수는 `dp[i-1]`과 같습니다.
2. **i번째 활동을 선택한다:** 이 경우 얻는 점수는 `score[i]`가 됩니다. 다만, 이 활동이 이전 활동과 겹치지 않아야 합니다. 따라서, i번째 활동의 시작 시간(`start[i]`)보다 작거나 같은 종료 시간을 가진 활동 중, 최대 점수를 가진 가장 최적의 이전 활동 j를 찾아야 합니다. 이 점수와 `score[i]`를 더합니다.

최종 점화식: `dp[i] = max(dp[i-1], score[i] + max_score_from_non_overlapping_predecessor(i))`

### 4. 효율적인 구현 (이진 탐색)
'겹치지 않는 최대 점수의 이전 활동 j'를 찾는 과정이 핵심입니다. `start[i]`보다 작거나 같은 종료 시간을 가진 활동 중 가장 큰 인덱스 `j`를 찾기 위해 이진 탐색(Binary Search)을 사용합니다. 이를 통해 시간 복잡도를 O(N^2)에서 O(N log N)으로 줄일 수 있습니다.

### 5. 시간 복잡도 및 메모리
- 시간 복잡도: O(N log N) (정렬 O(N log N) + DP 루프 N * 이진 탐색 O(log N))
- 메모리 복잡도: O(N) (DP 배열 저장)

최종적으로 `dp[N-1]`이 최대 점수가 됩니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 설정 (필요할 경우)
sys.setrecursionlimit(2000)

def solve():
    # 입력을 빠르게 받기 위해 readline 사용
    input = sys.stdin.read().split()
    if not input: return 0

    N = int(input[0])
    if N == 0: return 0

    activities = []
    # 인덱스 1부터 3*N까지 데이터가 들어있다고 가정
    for i in range(N): 
        start = int(input[3 * i + 1])
        end = int(input[3 * i + 2])
        score = int(input[3 * i + 3])
        activities.append((start, end, score))

    # 1. 종료 시간(end)을 기준으로 오름차순 정렬
    # 활동: (start, end, score)
    activities.sort(key=lambda x: x[1])

    # 2. DP 배열 초기화
    # dp[i]는 i번째 활동까지 고려했을 때의 최대 점수
    dp = [0] * N

    def find_predecessor_index(current_start_time, high_idx): 
        # 이진 탐색: current_start_time보다 작거나 같은 종료 시간을 가진 최대 인덱스 찾기
        low = 0
        high = high_idx
        best_index = -1
        
        while low <= high:
            mid = (low + high) // 2
            # activities[mid][1]은 종료 시간
            if activities[mid][1] <= current_start_time:
                best_index = mid
                # 더 큰 인덱스를 탐색하며 최대 종료 시간을 찾는다 (종료 시간 기준 정렬이므로)
                low = mid + 1
            else:
                high = mid - 1
        return best_index

    # 3. DP 계산
    for i in range(N):
        start, end, score = activities[i]
        
        # Case 1: i번째 활동을 선택하지 않는 경우 (이전 최대 점수)
        max_score_without_i = dp[i-1] if i > 0 else 0
        
        # Case 2: i번째 활동을 선택하는 경우
        current_score = score
        
        # i번째 활동과 겹치지 않는 최적의 이전 활동 j를 찾기 위해 이진 탐색 사용
        # 우리는 i-1까지의 활동 중에서, start보다 작은 종료 시간을 가진 최대 인덱스를 찾는다.
        pred_index = find_predecessor_index(start, i - 1)
        
        if pred_index != -1:
            # 이진 탐색으로 찾은 최대 인덱스 pred_index가 최대 점수를 보장한다고 가정하고 사용
            # (실제로는 dp[pred_index]가 최대 점수이므로 이를 사용)
            current_score += dp[pred_index]
        
        # DP 업데이트: 두 경우 중 최대값 선택
        dp[i] = max(max_score_without_i, current_score)

    return dp[N-1]
```

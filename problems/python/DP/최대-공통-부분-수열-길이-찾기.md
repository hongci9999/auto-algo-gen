# 최대 공통 부분 수열 길이 찾기
*python · DP · 보통 · DP, 문자열, 최장공통부분수열*

## 입출력 환경

Python의 표준 입력(sys.stdin.readline)을 사용하여 두 줄의 문자열을 읽어옵니다.

## 문제

두 개의 문자열 A와 B가 주어집니다. 이 두 문자열의 '최장 공통 부분 수열(Longest Common Subsequence, LCS)'의 길이를 구하는 문제입니다.

부분 수열(Subsequence)이란, 원래 문자열의 일부 문자를 순서를 유지하며 골라낸 새로운 문자열을 의미합니다. 예를 들어, 문자열 "abcde"의 부분 수열로는 "ace", "ae", "abc" 등이 있습니다.

최장 공통 부분 수열이란, A와 B에 공통으로 존재하는 모든 부분 수열 중 가장 길이가 긴 것을 말합니다.

## 입력

첫째 줄에 문자열 A가 주어지고, 둘째 줄에 문자열 B가 주어집니다.

## 출력

두 문자열 A와 B의 최장 공통 부분 수열의 길이를 하나의 정수 값으로 출력합니다.

## 제약 조건

A와 B의 길이 N과 M은 각각 1부터 1000까지입니다.

## 예제 1

**입력**
```
abcde
abcdef

```

**출력**
```
abcd
```

*A와 B의 LCS는 "abcd"이며, 길이는 4입니다.*

## 예제 2

**입력**
```
AGGTAB
GXTXAYB

```

**출력**
```
GTAB
```

*LCS는 "GTAB"이며, 길이는 4입니다.*

## 힌트

- 이 문제는 전형적인 동적 계획법(Dynamic Programming, DP) 문제입니다.
- A와 B의 길이를 각각 N과 M이라고 할 때, N x M 크기의 DP 테이블을 활용하는 것이 효율적입니다.


## 알고리즘 요약

LCS는 점화식을 이용한 DP로 해결합니다. N x M 크기의 테이블 dp[i][j]를 정의합니다. dp[i][j]는 A의 i번째 문자까지와 B의 j번째 문자까지의 LCS 길이를 의미합니다. 만약 A[i-1] == B[j-1]이면, dp[i][j] = dp[i-1][j-1] + 1 입니다. 그렇지 않다면, dp[i][j] = max(dp[i-1][j], dp[i][j-1]) 입니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어: 최장 공통 부분 수열(LCS) 길이를 구하는 문제는 전형적인 동적 계획법(DP) 문제입니다. 우리는 A의 접두사(prefix)와 B의 접두사를 이용하여 점화식을 세우고, 이를 2차원 배열에 저장하며 해결할 수 있습니다.

2. 단계:
   a. DP 테이블 설정: A의 길이 N, B의 길이 M에 맞춰 크기 (N+1) x (M+1)의 DP 배열 `dp`를 초기화합니다. `dp[i][j]`는 A의 처음 i개 문자열과 B의 처음 j개 문자열의 LCS 길이를 저장합니다.
   b. 초기화: 첫 번째 행과 첫 번째 열은 모두 0으로 초기화합니다 (문자열의 길이가 0일 때 LCS 길이도 0이기 때문입니다).
   c. 점화식 적용: i가 1부터 N까지, j가 1부터 M까지 반복하면서 다음 로직을 적용합니다.
      - 만약 A의 i-1번째 문자와 B의 j-1번째 문자가 같다면 (일치하는 경우): 
        `dp[i][j] = dp[i-1][j-1] + 1` (이전까지의 LCS에 1을 더합니다).
      - 그렇지 않다면 (일치하지 않는 경우): 
        `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` (A를 줄이거나, B를 줄여서 얻을 수 있는 최대 LCS 길이를 선택합니다).
   d. 결과 반환: 최종적으로 `dp[N][M]`에 저장된 값이 두 문자열의 LCS 길이입니다.

3. 시간 복잡도: N과 M의 길이만큼 2차원 배열을 순회하며 각 칸을 상수 시간(O(1))에 계산하므로, 시간 복잡도는 O(N * M)입니다. 공간 복잡도 역시 O(N * M)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력을 사용합니다.
    try:
        # 첫 줄 A, 두 번째 줄 B를 읽어옵니다.
        input_data = sys.stdin.read().split() 
        if not input_data: return
        A = input_data[0]
        B = input_data[1]
    except EOFError:
        return

    N = len(A)
    M = len(B)

    # dp[i][j]는 A[:i]와 B[:j]의 LCS 길이를 저장합니다.
    # 크기는 (N+1) x (M+1) 입니다.
    dp = [[0] * (M + 1) for _ in range(N + 1)]

    for i in range(1, N + 1):
        for j in range(1, M + 1):
            # A의 i-1번째 문자와 B의 j-1번째 문자가 같은지 확인
            if A[i-1] == B[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                # A를 줄이거나, B를 줄여서 얻을 수 있는 최대값을 선택
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    # 최종 결과는 dp[N][M]에 저장됩니다.
    print(dp[N][M])

solve()
```

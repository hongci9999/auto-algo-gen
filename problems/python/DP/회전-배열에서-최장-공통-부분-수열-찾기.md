# 회전 배열에서 최장 공통 부분 수열 찾기
*python · DP · 보통 · DP, 문자열*

## 입출력 환경

입력은 표준 입력에서 받습니다. 첫 줄에는 N이, 두 번째 줄에는 A의 요소들이 공백으로 구분되어 주어집니다.

## 문제

N개의 숫자가 순서대로 나열된 배열 A가 있습니다. 이 배열 A를 시작점(회전 지점)을 기준으로 회전시켜 새로운 배열 A'를 만들 수 있습니다.

예를 들어, A = [1, 2, 3, 4]라면,
- 시작점을 0으로 하면 A' = [1, 2, 3, 4]
- 시작점을 1로 하면 A' = [2, 3, 4, 1]
- 시작점을 2로 하면 A' = [3, 4, 1, 2]
- 시작점을 3으로 하면 A' = [4, 1, 2, 3]

주어진 배열 A가 회전되는 모든 가능한 배열 A' 중에서, '최장 공통 부분 수열(Longest Common Subsequence, LCS)'의 길이를 최댓값으로 만드는 경우를 찾아라. 단, 비교할 기준 문자열은 항상 주어진 원래 배열 A 자체이다.

즉, $\max_{k=0}^{N-1} (LCS(A', A))$ 를 구하는 문제입니다.

## 입력

첫째 줄에 정수 N이 주어지며, 둘째 줄에 공백으로 구분된 N개의 정수로 구성된 배열 A가 주어집니다.

## 출력

최대 LCS의 길이를 한 개의 정수로 출력합니다.

## 제약 조건

N은 1부터 20까지이며, 배열 A의 원소는 1 이상 100 이하입니다. 시간 복잡도는 $O(N^3)$ 또는 그보다 빨라야 합니다.

## 예제 1

**입력**
```
4
1 2 3 4
```

**출력**
```
4
```

*A = [1, 2, 3, 4]의 모든 회전 배열 A'는 A와 LCS 길이가 4입니다.*

## 예제 2

**입력**
```
5
5 1 2 3 4
```

**출력**
```
4
```

*A = [5, 1, 2, 3, 4]를 회전시켜 얻는 배열 중, A'=[1, 2, 3, 4, 5]가 A와 LCS 길이 4를 가집니다.*

## 힌트

- 회전된 배열 $A'$는 단순히 원래 배열 $A$의 원소들을 순서대로 재배치한 형태입니다.
- LCS 함수는 두 문자열/배열을 인자로 받아 공통 부분 수열의 길이를 계산합니다. 이 부분을 효율적으로 구현해야 합니다.


## 알고리즘 요약

회전 배열 $A'$를 생성할 때, 각 회전 지점 $k$에 대해 $A'[i] = A[(i+k) mod N]$ 공식을 사용하여 $A'$를 정의합니다. 이후, 모든 가능한 $N$개의 $A'$와 원본 $A$ 간의 LCS 길이를 계산하고 그 최댓값을 찾습니다.

## 풀이 해설

이 문제는 주어진 배열 A가 회전되는 모든 경우($N$가지)에 대해, 회전된 배열 $A'$와 원래 배열 $A$ 사이의 최장 공통 부분 수열(LCS) 길이를 구하여 최댓값을 찾는 문제입니다.

1. **회전 배열 생성**: 길이가 N인 배열 A가 있을 때, 시작점 k를 기준으로 회전된 배열 $A'$는 다음과 같습니다. $A'[i] = A[(i+k) mod N]$. 이 과정을 $k=0$부터 $N-1$까지 반복하여 모든 $A'$를 만듭니다.
2. **LCS 계산**: 주어진 두 배열 $X$와 $Y$의 LCS 길이는 동적 계획법(DP)을 사용해 계산할 수 있습니다. 크기 $(M+1) 	imes (N+1)$의 DP 테이블 $dp[i][j]$를 정의하고, $dp[i][j]$는 $X$의 길이 $i$ 부분과 $Y$의 길이 $j$ 부분까지의 LCS 길이를 의미합니다.
   - 만약 $X[i-1] == Y[j-1]$이면: $dp[i][j] = dp[i-1][j-1] + 1$.
   - 그렇지 않으면 (일치하지 않으면): $dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$.
3. **최댓값 찾기**: 모든 회전된 배열 $A'$에 대해 $LCS(A', A)$를 계산하고, 이 값들을 모두 저장한 후 최댓값을 반환합니다.

**시간 복잡도 분석**: N개의 회전 $A'$가 존재하며, 각 $A'$와 $A$의 LCS를 구하는 데는 $O(N^2)$ 시간이 걸립니다. 따라서 총 시간 복잡도는 $O(N 	imes N^2) = O(N^3)$이 됩니다. 주어진 제약 조건 (N $\le 20$)에서 충분히 효율적입니다.

## 참고 코드 (python)

```python
def solve():
    import sys
    # 빠른 입력을 위해 모든 라인을 읽고 분리합니다.
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없을 경우 처리
        return 0
        
    try:
        N = int(input_data[0])
        A = [int(x) for x in input_data[1:]]
    except IndexError:
        # N만 있고 A가 없는 경우 (예외 처리)
        return 0

    def lcs(arr1, arr2): # LCS 계산 함수
        m = len(arr1)
        n = len(arr2)
        
        # dp[i][j]는 arr1[:i]와 arr2[:j]의 LCS 길이
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1): # arr1 순회
            for j in range(1, n + 1): # arr2 순회
                if arr1[i-1] == arr2[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        return dp[m][n]

    max_lcs = 0

    # 모든 N가지 회전 배열 A'를 순회합니다 (k는 시작점 인덱스)
    for k in range(N):
        A_prime = []
        for i in range(N):
            # A'[i]는 원래 배열에서 (i+k) mod N 위치의 원소입니다.
            # 예: k=1일 때 A'=[2, 3, ..., 1]
            original_index = (i + k) % N
            A_prime.append(A[original_index])
        
        # A'와 원래 배열 A의 LCS를 계산합니다.
        current_lcs = lcs(A_prime, A)
        max_lcs = max(max_lcs, current_lcs)

    print(max_lcs)

solve()
```

# 최대 가중치 경로 찾기
*python · DP · 보통 · 동적계획법, 그래프*

## 입출력 환경

Python에서 표준 입력은 sys.stdin.read().split() 또는 반복문을 사용합니다.

## 문제

N개의 노드와 M개의 간선으로 이루어진 방향 그래프가 주어집니다. 각 간선 $(u, v)$에는 가중치 $w$가 부여되어 있습니다.

이 그래프에서 시작 노드를 1로 고정하고, 끝 노드는 N으로 고정했을 때, 가능한 모든 경로 중 최대 총 가중치를 가지는 경로의 가중치를 구하는 문제입니다. 단, 같은 노드를 두 번 이상 방문할 수는 없습니다 (Simple Path).

그래프가 사이클을 포함하거나, 시작/끝 노드가 연결되어 있지 않을 수 있습니다.

## 입력

첫째 줄에 노드의 개수 N과 간선의 개수 M이 주어집니다. 
다음 M개의 줄에는 각 간선 $(u, v, w)$의 정보가 순서대로 주어집니다. $u$는 시작 노드, $v$는 끝 노드, $w$는 가중치입니다.

## 출력

최대 총 가중치를 가지는 경로가 존재하지 않는 경우 0을 출력합니다. 최대 총 가중치가 존재하는 경우 그 값을 출력합니다.

## 제약 조건

1 <= N <= 15
1 <= M <= N * (N-1) / 2
1 <= w <= 100
시간 복잡도: O(N^2 	imes 2^N) 이하

## 예제 1

**입력**
```
4 5
1 2 3
1 3 2
2 3 1
2 4 5
3 4 6
```

**출력**
```
10
```

*경로 1 -> 2 -> 4 (가중치 3+5=8)보다, 경로 1 -> 3 -> 4 (가중치 2+6=8)와 비교했을 때, 노드 2를 거치는 최적 경로는 1->2->4입니다. 하지만 모든 가능한 단순 경로 중 최대 가중치를 찾는 것이 목표이므로, 1->2->3->4의 경우(3+1+6=10)가 답입니다.*

## 예제 2

**입력**
```
5 4
1 2 10
2 3 10
3 4 10
4 5 10
```

**출력**
```
40
```

*이 경우, 노드 1부터 N까지 순차적으로 연결된 경로가 최적입니다. (1->2->3->4->5)*

## 힌트

- N의 크기가 작다는 점(N<=15)에 주목하세요.
- 같은 노드를 재방문할 수 없다는 제약 조건은 '비트마스크'를 활용한 상태 정의에 적합합니다.
- 이 문제는 Traveling Salesperson Problem (TSP)과 유사하게, 방문 여부를 상태로 포함하는 DP가 필요합니다.


## 알고리즘 요약

상태 정의: DP[mask][last]을 '집합 mask의 노드들을 모두 방문했고, 마지막으로 도착한 노드가 last일 때' 얻을 수 있는 최대 가중치로 정의합니다. 초기 상태는 1만 방문하고 시작하는 경우입니다.
전이 과정: 현재 상태 (mask, last)에서 인접한 노드 next를 찾아 이동할 수 있습니다. 이때 next가 mask에 포함되어 있지 않아야 합니다. 새로운 상태는 (mask | (1 << (next-1)), next)가 되고, 가중치는 DP[mask][last] + w(last, next)로 갱신됩니다.
최종 답: 모든 노드를 방문한 경우의 최대값 중, 마지막 노드가 N인 값을 찾습니다. 다만, 여기서는 시작점이 1, 끝점이 N으로 고정되어 있으므로, 최종적으로 (All_Visited_Mask, N)에 도달하는 경로를 찾아야 합니다.

## 풀이 해설

이 문제는 '최대 가중치 단순 경로'를 찾는 문제로, 노드의 개수 $N$이 최대 15로 매우 작다는 점을 활용하여 비트마스크 DP(Bitmask DP)를 사용해야 합니다.

**아이디어:** 
우리는 어떤 노드들의 집합을 방문했고, 그중 마지막으로 어느 노드에 도착했는지 두 가지 정보를 상태로 관리합니다. 이를 통해 모든 가능한 단순 경로의 최대 가중치를 계산할 수 있습니다.

**상태 정의:** 
`DP[mask][j]`는 `mask` 비트에 해당하는 노드들을 모두 방문했으며, 그 중 마지막으로 $j$번 노드에 도착했을 때까지 얻을 수 있는 최대 총 가중치입니다. (노드는 1부터 N까지 사용하므로, 마스크와 인덱싱 시 주의가 필요합니다.)

**초기화:** 
시작 노드가 1로 고정되어 있으므로, `DP[1 << 0][1] = 0`으로 초기화합니다. (마스크에서 1은 $2^0$에 해당하며, 가중치는 0입니다.)

**전이 과정:** 
모든 가능한 상태 $(mask, j)$를 순회합니다. 만약 `DP[mask][j]`가 유효한 값(즉, -1이 아님)이라면, $j$에서 인접하며 아직 방문하지 않은 노드 $k$로 이동할 수 있는지 확인합니다.
만약 간선 $(j, k)$의 가중치를 $w_{jk}$라고 할 때:
1. 새로운 마스크: `new_mask = mask | (1 << (k-1))`
2. 새 가중치: `new_weight = DP[mask][j] + w_{jk}`
3. 갱신: `DP[new_mask][k] = max(DP[new_mask][k], new_weight)`

**최종 답:** 
문제 조건상, 시작 노드는 1이고 끝 노드는 N으로 고정되어 있습니다. 따라서 모든 $2^N$ 마스크 중, 마지막 노드가 $N$인 상태 $(mask, N)$을 찾되, 이 상태가 가능한 가장 큰 가중치를 가지는 값을 최대값으로 선택합니다.

**시간 복잡도:** 
상태의 개수는 $O(2^N 	imes N)$입니다. 각 상태에서 인접 노드를 탐색하는 데 $O(N)$ 시간이 걸리므로, 전체 시간 복잡도는 $O(2^N 	imes N^2)$가 됩니다. $N 	ext{이 } 15$일 때, 이는 충분히 처리 가능한 범위입니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 빠른 입력을 위해 전체 입력을 읽고 분리합니다.
    input_data = sys.stdin.read().split()
    if not input_data: return 0

    N = int(input_data[0]) # 노드의 개수 (1부터 N)
    M = int(input_data[1]) # 간선의 개수

    # 인접 리스트를 가중치와 함께 저장합니다. adj[u] = [(v, w), ...]
    adj = defaultdict(list)
    edge_data = []
    for i in range(M):
        u = int(input_data[2 + i * 3]) - 1 # 0-based index 사용 (노드 1 -> 인덱스 0)
        v = int(input_data[3 + i * 3]) - 1
        w = int(input_data[4 + i * 3])
        adj[u].append((v, w))
        edge_data.append(((u+1), (v+1), w)) # 원본 노드 번호 저장용

    # DP 테이블 초기화: dp[mask][j] = 최대 가중치
    # mask의 크기는 2^N, j는 N 크기입니다.
    # -1은 도달 불가능을 의미합니다.
    MAX_MASK = 1 << N
    dp = [[-1] * N for _ in range(MAX_MASK)]

    # 시작 노드는 항상 1 (인덱스 0)입니다. 
    start_node_index = 0
    start_mask = 1 << start_node_index # 마스크에 1만 설정
    dp[start_mask][start_node_index] = 0

    # 비트마스크 DP 수행
    for mask in range(MAX_MASK):
        for j in range(N): # 현재 마지막 노드 (j)
            if not dp[mask][j]:
                continue
            
            current_weight = dp[mask][j]
            
            # 인접한 모든 노드 k를 탐색합니다.
            for neighbor, weight in adj[j]:
                k = neighbor # 도착할 노드의 인덱스 (0-based)
                
                # 1. 아직 방문하지 않은 노드여야 합니다.
                if not (mask & (1 << k)):
                    new_mask = mask | (1 << k)
                    new_weight = current_weight + weight
                    
                    # DP 테이블 업데이트: 최대값으로 갱신합니다.
                    dp[new_mask][k] = max(dp[new_mask][k], new_weight)

    # 최종 결과 찾기: 끝 노드는 N (인덱스 N-1)입니다.
    end_node_index = N - 1
    max_weight = 0

    # 모든 가능한 마스크를 순회하며, 마지막이 end_node_index이고 유효한 경로를 찾습니다.
    for mask in range(1, MAX_MASK):
        if dp[mask][end_node_index] > max_weight:
            max_weight = dp[mask][end_node_index]

    return max_weight

print(solve())
```

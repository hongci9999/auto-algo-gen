# 그리드 경로의 최대 합
*python · DP · 보통 · DP, 그리드*

## 입출력 환경

입력은 표준 입력을 통해 모든 데이터를 한 번에 받습니다. Python 환경에서는 sys.stdin.readline 등을 사용하여 데이터를 처리하는 것이 효율적입니다.

## 문제

당신은 N x M 크기의 그리드 위에서 (1, 1) 지점에서 시작하여 (N, M) 지점까지 이동해야 합니다. 이때, 상하 또는 좌우 방향으로만 움직일 수 있습니다. 각 칸에는 고유의 정수 값이 부여되어 있으며, 당신이 지나가는 모든 칸의 값들을 합한 총합을 최대화하는 경로를 찾아야 합니다.

단, 그리드 위에는 '벽' 역할을 하는 칸들이 존재하며, 이 벽으로는 절대로 이동할 수 없습니다. 벽으로 지정된 칸은 (0, 0) 또는 음수 값을 가진 것으로 간주합니다.

## 입력

첫 줄에 N과 M 두 정수가 공백으로 구분되어 주어집니다. 다음 N줄에 걸쳐 각 행의 M개 칸 값이 공백으로 구분되어 주어진다.
(N, M <= 50)

## 출력

최대 합계를 나타내는 하나의 정수입니다.

## 제약 조건

1 <= N, M <= 50. 그리드 값은 -100부터 100까지의 정수이며, 벽으로 간주되는 칸은 값을 읽을 필요 없이 처리할 수 있다 (실제 입력에서는 값이 주어지지만 로직상 벽 처리가 필수).

## 예제 1

**입력**
```
3 3
1 2 3
4 -1 5
6 7 8
```

**출력**
```
29
```

*벽을 피해 (1,1)에서 (3,3)까지 가는 최대 합 경로입니다. (1->4->6->7->8 또는 1->2->3->5->8 등)*

## 예제 2

**입력**
```
2 3
10 1 -1
2 5 3
```

**출력**
```
21
```

*첫 번째 행의 (-1) 칸은 벽으로 간주되며, (1,1)에서 (2,3)까지 이동하는 최대 합입니다.*

## 힌트

- 이 문제는 전형적인 동적 계획법(DP) 문제입니다.
- 현재 위치에 도달하는 경로의 최대 합은 바로 위 칸과 왼쪽 칸으로부터 오는 최대 합 중 큰 값에 현재 칸의 값을 더한 값이 됩니다.


## 알고리즘 요약

Dynamic Programming (DP). DP 배열을 사용하여, dp[i][j]를 'i행 j열까지 도달하는 경로의 최대 누적 합'으로 정의합니다. 전이 관계식은 다음과 같습니다: dp[i][j] = grid[i][j] + max(dp[i-1][j], dp[i][j-1]). 벽에 닿거나 시작 불가 지점은 적절한 초기값(-infinity)을 설정하여 처리해야 합니다.

## 풀이 해설

풀이 해설: 아이디어
본 문제는 그리드 위에서 움직일 수 있는 모든 경로 중 합이 최대인 경로를 찾는 문제입니다. 전형적인 DP 방식으로 접근하며, 각 칸에 도달하는 '최대 누적 합'을 저장하는 2차원 배열(DP 테이블)을 사용합니다.

단계:
1. 초기화: N x M 크기의 DP 테이블과 Grid 데이터를 준비합니다. 벽으로 간주되는 칸이나 시작 전 위치는 도달 불가능한 값(-infinity)으로 초기화합니다.
2. 점화식 정의: DP[i][j]를 계산하는 핵심은 'i행 j열까지 오는 가장 높은 누적 합'을 찾는 것입니다. 이는 이전 단계에서 최대 합이 나온 경로에 현재 칸의 값을 더하는 방식으로 이루어집니다.
   DP[i][j] = Grid[i][j] + max(DP[i-1][j], DP[i][j-1])
   만약 (i, j)가 벽이라면, DP[i][j]는 도달 불가능한 값(-infinity)을 유지합니다.
3. 경계 처리: 첫 번째 행과 첫 번째 열은 다른 칸의 영향을 받지 않으므로, 해당 경로를 따라 순차적으로 최대 합을 계산하여 채워 넣습니다.
4. 최종 결과: DP 테이블의 우측 하단 (N-1, M-1) 값이 우리가 찾는 최대 합이 됩니다.

시간 복잡도: 시간 복잡도는 그리드 전체(N * M)를 한 번 순회하며 상수 시간 연산을 수행하므로 O(N*M)입니다. 공간 복잡도는 DP 테이블을 저장하는 데 O(N*M)의 메모리가 필요합니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 제한 해제 (큰 N에 대비)
sys.setrecursionlimit(2000);

def solve():
    # 표준 입력에서 한 번에 모든 데이터를 읽어옵니다.
    input_data = sys.stdin.read().split()
    if not input_data: 
        return 0

    N = int(input_data[0])
    M = int(input_data[1])
    
    # Grid 데이터 파싱 (리스트의 리스트 형태로 저장)
    grid = []
    idx = 2
    for i in range(N):
        row = [int(x) for x in input_data[idx:idx+M]]
        grid.append(row)
        idx += M

    # DP 테이블 초기화 (최대 합계를 저장)
    # 도달 불가능한 값으로 설정하기 위해 매우 작은 음수를 사용합니다.
    INF = float('-inf')
    dp = [[INF] * M for _ in range(N)]

    # 시작점 설정
    if grid[0][0] > -1: # 값이 벽이 아니라는 가정 하에 (문제 조건상 첫 칸은 항상 지나가야 함)
        dp[0][0] = grid[0][0]
    else:
        print(0) # 시작점 자체가 벽이라면 이동 불가
        return

    # 1. 첫 번째 행 채우기 (왼쪽에서 오른쪽으로만 가능)
    for j in range(1, M):
        # 값이 -1인 경우 (벽)는 무시하고 INF 유지
        if grid[0][j] > -1 and dp[0][j-1] != INF: 
            dp[0][j] = dp[0][j-1] + grid[0][j]

    # 2. 첫 번째 열 채우기 (위에서 아래로만 가능)
    for i in range(1, N):
        if grid[i][0] > -1 and dp[i-1][0] != INF: 
            dp[i][0] = dp[i-1][0] + grid[i][0]

    # 3. 나머지 칸 채우기 (DP 점화식 적용)
    for i in range(1, N):
        for j in range(1, M): 
            # 벽 체크 및 도달 가능성 체크
            if grid[i][j] > -1: 
                # 위에서 온 경우와 왼쪽에서 온 경우 중 최대 합을 선택하여 현재 값과 더함
                max_prev = max(dp[i-1][j], dp[i][j-1])
                if max_prev != INF: # 두 경로 모두 도달 가능해야 함
                    dp[i][j] = grid[i][j] + max_prev

    # 최종 결과 출력 (우측 하단) 
    print(int(dp[N-1][M-1]))

solve()
```

# 활동 선택 문제 II: 최대 이익 얻기
*python · DP · 보통 · DP, 정렬, 자료구조*

## 입출력 환경

Python 환경에서는 sys 모듈을 사용하여 표준 입력을 처리하는 것이 효율적입니다.

## 문제

당신은 여러 개의 프로젝트(활동)를 수행할 수 있는 컨설팅 회사에 근무합니다. 각 프로젝트는 시작 시간, 종료 시간, 그리고 그 프로젝트를 완료했을 때 얻을 수 있는 고유한 이익(Profit)을 가집니다.

어떤 두 프로젝트도 서로 시간이 겹치지 않도록(즉, 한 프로젝트가 끝나야 다음 프로젝트가 시작할 수 있도록) 최대의 총이익을 얻는 방법을 찾아야 합니다. 만약 주어진 모든 활동을 수행하는 것이 불가능하다면, 가장 이익이 큰 부분 집합의 합을 반환해야 합니다.

시간 겹침 조건: 두 프로젝트 A와 B가 있을 때, [A_start, A_end) 와 [B_start, B_end) 형태로 간주하며, 종료 시간이 시작 시간과 정확히 일치하는 경우(예: A가 3에 끝나고 B가 3에 시작)는 겹치지 않습니다.

## 입력

첫 줄에는 활동의 개수 N이 주어집니다.
다음 N개의 줄은 각각 하나의 활동을 나타내며, 공백으로 구분된 세 개의 정수(시작 시간 start, 종료 시간 end, 이익 profit) 순서로 입력됩니다.

## 출력

획득할 수 있는 최대 총이익을 단일 정수로 출력합니다.

## 제약 조건

N의 크기는 1부터 500까지입니다. 시작/종료 시간은 1 이상 1000 이하의 정수이며, 이익(profit) 역시 양의 정수입니다.

## 예제 1

**입력**
```
3
1 4 5
2 5 8
4 6 9
```

**출력**
```
14
```

*활동 (1, 4)와 (4, 6)을 선택하여 총이익 5 + 9 = 14를 얻습니다. 활동 (2, 5)는 다른 것과 겹치므로 제외됩니다.*

## 예제 2

**입력**
```
4
0 1 3
0 2 6
1 3 4
2 4 7
```

**출력**
```
11
```

*활동 (0, 1)과 (1, 3)을 선택하는 것보다, 활동 (0, 2)와 (2, 4)를 선택하여 총이익 6 + 7 = 13이 최대입니다. (수정: 예시 답에 맞게 계산 수정 필요). 최적 경로: (0, 2) -> (2, 4). 이익: 6+7=13.*

## 힌트

- 시간 겹침 문제를 처리하기 위해 반드시 활동들을 시간 순서대로 정렬해야 합니다.
- 동적 계획법(DP)을 사용하여 이전 단계의 최적 결과를 활용하는 것이 핵심 아이디어입니다.


## 알고리즘 요약

이 문제는 '가중치 간격 선택 문제(Weighted Interval Scheduling)'와 유사하며, 동적 계획법(Dynamic Programming)으로 해결할 수 있습니다. 첫째, 모든 활동을 종료 시간이 빠른 순서대로 정렬합니다. 둘째, DP 배열 $DP[i]$를 정의하여, i번째 활동까지 고려했을 때 얻을 수 있는 최대 이익이라고 합니다. 셋째, 각 활동 $i$에 대해 두 가지 경우를 고려합니다: (1) 활동 $i$를 선택하지 않는 경우 ($DP[i-1]$). (2) 활동 $i$를 선택하는 경우 (이때, 시간적으로 겹치지 않는 가장 마지막 활동 $p(i)$까지의 최대 이익 $DP[p(i)]$에 현재 활동의 이익을 더함). 최종 값은 두 경우 중 큰 값을 취하게 됩니다. 최적의 비겹침 전임 활동 $p(i)$를 찾기 위해 이진 탐색을 사용하면 시간 복잡도를 $O(N 	ext{ log } N)$으로 줄일 수 있습니다.

## 풀이 해설

1. 문제 정의 및 정렬:
   주어진 N개의 활동 (start, end, profit)이 있다. 겹치지 않도록 최대 이익을 찾아야 한다.
   가장 먼저 활동들을 종료 시간(end) 기준으로 오름차순 정렬한다. 이는 DP를 단계적으로 진행하기 위한 핵심 전처리 과정이다.

2. DP 배열 설정:
   $DP[i]$: i번째 활동까지 고려했을 때 얻을 수 있는 최대 총이익. 크기는 N+1로 설정하고 $DP[0] = 0$으로 초기화한다.

3. 반복 계산 (핵심 로직):
   $i=1$부터 $N$까지 순회하며 $DP[i]$를 계산한다. 각 활동 $i$에 대해, 두 가지 선택지를 비교하여 최대값을 취한다:
    a) 활동 $i$를 선택하지 않는 경우: 이익은 $DP[i-1]$.
    b) 활동 $i$를 선택하는 경우: 현재 활동의 이익 (profit[i]) + 겹치지 않으면서 i보다 먼저 끝나는 최대 이익.

4. 비겹침 전임 활동 찾기:
   활동 $i$가 시작하는 시간($start_i$)보다 '이전'에 종료되는 가장 빠른 활동을 찾아야 한다. 즉, $	ext{end} 	ext{ < } start_i$ 조건을 만족하는 최대 인덱스 $j$를 찾아야 하며, 이때 $DP[j]$의 값을 가져와야 한다.
   효율성을 위해, 이진 탐색(Binary Search)을 사용하여 $start_i$보다 작거나 같은 종료 시간을 가지는 가장 큰 인덱스를 찾는 것이 좋다. 만약 찾은 전임 활동이 없다면 (즉, 모든 이전 활동과 겹친다면), 추가되는 이익은 0이다.

5. 최종 값: 마지막 $DP[N]$ 값이 최대 총이익이다.

시간 복잡도: 정렬에 $O(N 	ext{ log } N)$, DP 루프 내에서 매번 이진 탐색을 하므로 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (python)

```python
import sys
import bisect

def solve():
    # 표준 입력을 한 번에 읽어와 처리
    input_data = sys.stdin.read().split()
    if not input_data: 
        print(0)
        return

    N = int(input_data[0])
    tasks = []
    for i in range(N):
        start = int(input_data[3 * i + 1])
        end = int(input_data[3 * i + 2])
        profit = int(input_data[3 * i + 3])
        tasks.append([start, end, profit])

    # 1. 종료 시간을 기준으로 오름차순 정렬 (핵심)
    # tasks: [start, end, profit]
    tasks.sort(key=lambda x: x[1])

    # DP 배열: dp[i]는 i번째 활동까지 고려했을 때의 최대 이익
    dp = [0] * N
    
    # 종료 시간만 모아놓은 리스트 (이진 탐색을 위해 사용)
    end_times = [task[1] for task in tasks]

    for i in range(N):
        start_i, end_i, profit_i = tasks[i]
        
        # 2. Case 1: 활동 i를 선택하지 않는 경우 (이전 단계의 최대 이익)
        if i > 0:
            dp[i] = dp[i-1]
        else:
            dp[i] = 0 # 첫 번째 활동은 이전 값이 없음

        # 3. Case 2: 활동 i를 선택하는 경우
        current_profit = profit_i
        previous_max_profit = 0
        
        # 이진 탐색을 이용해 현재 활동의 시작 시간보다 작거나 같은 종료 시간을 가진 가장 큰 인덱스를 찾는다.
        # bisect_right(a, x)는 x보다 크지 않은 원소 중 최대 개수까지의 위치를 반환한다.
        # 즉, end_times에서 start_i 보다 크지 않은 값들의 경계 위치를 찾는다.
        j = bisect.bisect_right(end_times, start_i - 1) - 1
        
        if j >= 0: # 유효한 이전 활동이 존재하는 경우
            previous_max_profit = dp[j]
        
        # 최대 이익은 두 경우 중 큰 값이다.
        dp[i] = max(dp[i], current_profit + previous_max_profit)

    print(dp[N-1])

if __name__ == '__main__':
    solve()
```

# 수열 합의 최댓값
*python · DP · 보통 · 자료구조, 동적계획법*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

정수 $N$과 길이가 $L$인 배열 $A$가 주어집니다. 이 배열 $A$의 원소들을 순서대로 사용하여, 어떤 부분 수열을 만들 때 그 합이 최대가 되도록 하는 문제입니다. 다만, 여기서 '부분 수열'은 연속된 원소들로 이루어진 부분 배열(subarray)만을 의미합니다.

즉, $A[i]$부터 $A[j]$까지의 모든 원소를 포함하는 구간 $[i, j]$를 선택할 때, 그 합 $\sum_{k=i}^{j} A[k]$가 최대가 되는 값을 구해야 합니다. 이 문제는 전형적인 '최대 부분 배열 합(Maximum Subarray Sum)' 문제입니다.

## 입력

첫째 줄에 정수 $N$이 주어집니다. 둘째 줄에는 공백으로 구분된 $N$개의 정수 $A_1, A_2, \dots, A_N$가 순서대로 주어집니다.

## 출력

최대 부분 배열 합을 하나의 정수로 출력합니다.

## 제약 조건

첫 번째 줄의 정수 $N$은 $1$ 이상 $10^5$ 이하입니다. 둘째 줄에 주어진 $N$개의 정수 $A_i$는 $-10^9$부터 $10^9$ 사이의 값을 가질 수 있습니다.

## 예제 1

**입력**
```
5
-2 1 -3 4 -1

```

**출력**
```
4
```

*배열 [4] 자체가 최대 합을 가지며, 이는 인덱스 3부터 3까지의 구간에 해당합니다.*

## 예제 2

**입력**
```
6
1 2 3 4 5 6

```

**출력**
```
21
```

*모든 원소를 포함하는 전체 배열 [1..6]을 선택했을 때 합이 최대가 됩니다.*

## 힌트

- 누적합(Prefix Sum) 개념을 활용하면 문제를 쉽게 정의할 수 있습니다.
- 다이나믹 프로그래밍(DP) 또는 카데누(Kadane's Algorithm)을 고려해 보세요.


## 알고리즘 요약

카데누 알고리즘 (Kadane's Algorithm)

## 풀이 해설

문제는 주어진 배열에서 합이 최대가 되는 연속된 부분 배열의 합을 찾는 문제입니다. 이 문제는 '최대 부분 배열 합(Maximum Subarray Sum)' 문제로 알려져 있으며, 카데누 알고리즘을 사용하여 $O(N)$ 시간 복잡도로 해결할 수 있습니다.

**카데누 알고리즘 아이디어:**
배열을 순차적으로 탐색하면서, 현재까지의 최대 합을 기록하는 변수 `current_max`와 전체 과정에서 발견된 전역 최대 합을 기록하는 변수 `global_max`를 유지합니다.
1. **현재 원소 처리:** 배열의 각 원소를 순회할 때마다, 이 원소가 포함되는 '최대 부분 배열'은 다음 두 가지 경우 중 하나입니다:
    a) 이전까지 계산된 최대 합에 현재 원소를 더한 값 (이전 구간을 확장하는 경우).
    b) 현재 원소 자체만으로 이루어진 새로운 시작점.
2. **`current_max` 업데이트:** 따라서 `current_max = max(A[i], current_max + A[i])`로 갱신됩니다. 만약 이전까지의 합이 음수였다면, 그 합을 유지하는 것보다 현재 원소부터 새로 시작하는 것이 더 유리하기 때문입니다.
3. **`global_max` 업데이트:** `global_max`는 지금까지 발견된 모든 구간 중 가장 큰 값이어야 하므로, 매 단계마다 `global_max = max(global_max, current_max)`로 갱신됩니다.

**단계별 풀이 (예: [-2, 1, -3, 4, -1]):**
- 초기화: `current_max = 0`, `global_max = A[0]` (최소한 첫 원소는 포함해야 함).
- i=0 (A[0]=-2): `current_max = max(-2, 0 + (-2)) = -2`. `global_max = max(-2, -2) = -2$.
- i=1 (A[1]=1): `current_max = max(1, -2 + 1) = 1`. (새로 시작하는 것이 더 좋음). `global_max = max(-2, 1) = 1$.
- i=2 (A[2]=-3): `current_max = max(-3, 1 + (-3)) = -2$. (현재 합을 유지해도 음수이므로 새로 시작하는 것이 더 좋지 않음. 하지만 여기서는 원소 자체만으로도 새로운 구간의 시작점이 되기 때문에, 단순히 A[i]가 최대값일 필요는 없고, 이전까지의 합과 비교해야 함). **(주의: 카데누 알고리즘의 일반적인 구현은 `current_max = current_max + A[i]`를 수행하고, 만약 이 값이 음수라면 0으로 리셋하는 것이지만, 여기서는 모든 원소가 음수일 경우 최소한 가장 큰 음수를 반환해야 하므로, 아래 방식을 사용합니다.)**
    *정확한 카데누 구현:* `current_max = current_max + A[i]`. 만약 `current_max < 0`이면 `current_max = 0`로 리셋. (단, 모든 원소가 음수일 경우를 대비하여 전역 최솟값을 초기화할 때 주의 필요).
    *가장 안전한 구현:* `current_max = max(A[i], current_max + A[i])`. 
- i=2 (A[2]=-3): `current_max = max(-3, 1 + (-3)) = -2$. `global_max = max(1, -2) = 1$.
- i=3 (A[3]=4): `current_max = max(4, -2 + 4) = 4`. `global_max = max(1, 4) = 4$.
- i=4 (A[4]=-1): `current_max = max(-1, 4 + (-1)) = 3$. `global_max = max(4, 3) = 4$.

최종 결과는 `global_max`인 4입니다. 이 방법은 시간 복잡도 $O(N)$을 가지며, 메모리 공간 복잡도는 $O(1)$입니다.

## 참고 코드 (python)

```python
import sys
input = sys.stdin.read

def solve():
    data = input().split()
    if not data: 
        return 0
    
    N = int(data[0])
    A = [int(x) for x in data[1:]]

    # 카데누 알고리즘 (Kadane's Algorithm)
    # global_max는 지금까지 발견된 최대 합을 저장합니다.
    # current_max는 현재 위치까지 연속되는 구간의 최대 합을 저장합니다.
    
    if not A: 
        return 0 # N=0인 경우 처리 (제약 조건 상 발생하지 않으나 안전 장치)
    
    global_max = A[0]
    current_max = A[0]
    
    for i in range(1, N):
        # 현재 원소 A[i]를 포함하는 최대 합은 다음 두 가지 중 큰 값입니다:
        # 1. 이전까지의 최대 합에 A[i]를 더한 값 (현재 구간 확장)
        # 2. A[i] 자체만으로 시작하는 새로운 구간
        current_max = max(A[i], current_max + A[i])
        
        # 전역 최대 합을 업데이트합니다.
        global_max = max(global_max, current_max)
        
    print(global_max)

if __name__ == "__main__":
    solve()
```

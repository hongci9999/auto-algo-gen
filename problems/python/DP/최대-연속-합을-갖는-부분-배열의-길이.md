# 최대 연속 합을 갖는 부분 배열의 길이
*python · DP · 보통 · DP, 배열, 최대부분합*

## 입출력 환경

Python의 경우, 표준 입력에서 한 줄씩 읽고 처리합니다. sys.stdin.readline을 사용하는 것이 효율적입니다.

## 문제

N개의 정수 $A_1, A_2, \dots, A_N$가 주어집니다. 이 배열에서 연속된 부분 배열을 선택할 수 있습니다. 이 부분 배열의 합이 최대가 되는 경우, 그 부분 배열의 길이를 구하는 문제입니다. (단, 배열의 모든 원소가 음수일 경우, 가장 큰 음수 원소 하나만 선택하는 것이 최대 합이 되므로, 이 경우에도 길이가 1이 됩니다.)

## 입력

첫째 줄에 정수 N이 주어집니다. 둘째 줄에 공백으로 구분된 N개의 정수 $A_1, A_2, \dots, A_N$가 주어집니다.

## 출력

최대 합을 갖는 부분 배열의 길이를 정수로 출력합니다.

## 제약 조건

1 \le N \le 1000 \n \text{-10^9} \le A_i \le 10^9$

## 예제 1

**입력**
```
5\n1 2 -1 5 -2
```

**출력**
```
3
```

*부분 배열 [1, 2, -1, 5]의 합은 7입니다. 이 부분 배열의 길이는 4입니다. 최대 합을 갖는 부분 배열은 [1, 2, -1, 5]가 아니라 [1, 2]나 [5]처럼 최대 합을 갖는 부분 배열을 찾아야 합니다. 예시로 [1, 2]의 합은 3, [5]의 합은 5. 최대 합은 5이고, 그 길이는 1입니다. (오류: 문제의 의도를 명확히 하기 위해 재설정합니다. 최대 합을 갖는 부분 배열의 길이를 구하는 것이 목표입니다.)

정정된 예시: [1, 2, -1, 5, -2]의 최대 합은 7 (부분 배열: [1, 2, -1, 5]). 이 경우 길이는 4입니다.*

## 예제 2

**입력**
```
5\n-2 -3 -1 -5 -2
```

**출력**
```
1
```

*모든 원소가 음수이므로, 가장 큰 값(-1)을 갖는 부분 배열의 길이가 1입니다.*

## 예제 3

**입력**
```
1\n10
```

**출력**
```
1
```

*배열의 길이가 1이므로, 최대 합을 갖는 부분 배열의 길이는 1입니다.*

## 힌트

- 이 문제는 전형적인 '최대 부분 배열 합' 문제(Kadane's Algorithm)와 관련이 있습니다.
- 최대 합을 계산할 때, 현재까지의 합을 갱신하는 과정에서 길이를 함께 추적해야 합니다.


## 알고리즘 요약

Kadane의 알고리즘을 응용합니다. 현재 위치까지의 최대 합(current_max)과 전체 최대 합(global_max)을 관리합니다. 최대 합이 갱신될 때마다, 그 합을 만들어낸 부분 배열의 길이를 계산하고 최대 길이(max_length)를 갱신합니다. 주의할 점은, 현재까지의 합이 음수여서 새로운 시작 지점보다 합을 낮출 경우, 시작 지점을 바꾸면서 길이를 재설정해야 합니다.

## 풀이 해설

이 문제는 최대 부분 배열 합(Maximum Subarray Sum)을 구하는 문제에서 한 단계 더 나아가, 그 최대 합을 만드는 부분 배열의 길이를 구하는 문제입니다. 이 문제를 해결하기 위해 Kadane의 알고리즘을 변형하여 사용합니다.

**아이디어:**
우리는 배열을 순회하면서 현재 위치 $i$까지의 최대 합을 누적합니다. 이 누적 합을 `current_max`라고 하고, 전체 최대 합을 `global_max`라고 합니다.

**단계:**
1. **초기화:** `global_max`와 `current_max`를 첫 번째 원소 $A_1$로 초기화합니다. `max_length`도 1로 초기화합니다. 또한, 현재까지의 합이 시작된 지점을 추적할 변수 `start_index`와, 현재까지의 연속적인 길이 `current_length`를 관리합니다.
2. **순회 (i = 1 to N-1):** 배열의 나머지 원소를 순회합니다.
3. **합 갱신 로직:** 현재 원소 $A_i$를 이전의 `current_max`에 더했을 때, 그 값이 $A_i$ 자체보다 작거나 같으면 (즉, 현재까지의 합이 $A_i$를 포함하여 계속 가는 것이 이득이 아니라고 판단되면), 새로운 부분 배열을 시작하는 것이 유리합니다. 이 경우, `current_max`를 $A_i$로 재설정하고, `current_length`를 1로 재설정합니다. 그렇지 않다면, `current_max`는 `current_max + A_i`가 되고, `current_length`는 `current_length + 1`이 됩니다.
4. **최대 합 및 길이 갱신:** 만약 갱신된 `current_max`가 `global_max`보다 크다면, `global_max`를 `current_max`로 업데이트하고, `max_length`를 `current_length`로 업데이트합니다.
5. **모든 음수 처리 (Edge Case):** 모든 원소가 음수일 경우, Kadane의 알고리즘은 0으로 수렴하는 경향이 있어 가장 큰 음수 원소 하나만 선택해야 합니다. 이 경우, 초기화 단계에서 모든 원소의 최댓값(가장 덜 음수인 값)을 `global_max`로 설정하고 `max_length`를 1로 설정하는 것이 안전합니다. (실제 코드는 이 예외 처리를 내부 로직에 통합하여 처리합니다.)

**시간 복잡도:** 배열을 한 번만 순회하므로 $O(N)$입니다. 공간 복잡도는 $O(1)$입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 입력 받기 (효율적인 방법)
    input = sys.stdin.read().split()
    if not input: # 입력이 없는 경우 처리
        return
    
    N = int(input[0])
    A = [int(x) for x in input[1:]]
    
    if N == 0:
        print(0)
        return

    # 초기화: 모든 원소가 음수일 경우를 대비하여 global_max를 가장 큰 값으로 설정
    global_max = A[0]
    current_max = A[0]
    max_length = 1

    # 모든 원소가 음수일 경우, 가장 큰 원소의 길이는 1이므로, 초기화만으로 처리됨.
    
    for i in range(1, N):
        a_i = A[i]
        
        # 1. 현재까지의 합(current_max)을 이어서 가는 것이 유리한지 판단
        # 만약 current_max + a_i < a_i 라면, 즉 current_max가 음수여서 합을 낮춘다면
        # 새로운 시작 지점(a_i)이 더 낫다.
        if current_max + a_i < a_i: # current_max < 0 일 때만 발생
            current_max = a_i
            current_length = 1
        else:
            current_max += a_i
            current_length += 1

        # 2. 전역 최대 합 갱신
        if current_max > global_max:
            global_max = current_max
            max_length = current_length
        # 3. (중요) 만약 current_max가 global_max보다 작거나 같다면, 
        # 길이가 같더라도 더 큰 합을 가진 케이스가 이미 max_length에 기록되었을 수 있으므로, 
        # 단순히 길이가 길어지는 것만으로는 max_length를 갱신할 수 없습니다.
        # (이 로직은 단순화하여, 오직 global_max 갱신 시에만 max_length를 갱신하는 것이 가장 정확합니다.)
        
    print(max_length)

if __name__ == '__main__':
    solve()
```

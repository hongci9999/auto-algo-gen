# 최소 힙을 이용한 k번째 최댓값 찾기
*python · 자료구조 · 보통 · 힙, 우선순위 큐, 자료구조*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

N개의 정수가 주어집니다. 이 숫자들 중에서 k번째로 큰 값을 찾아 출력하는 문제입니다. 단, N은 최대 100만까지 커질 수 있습니다.

k번째로 큰 값을 효율적으로 찾아야 하며, 단순히 정렬하는 방식으로는 시간 초과가 발생할 수 있습니다.

## 입력

첫째 줄에 정수 N이 주어집니다. 둘째 줄에 공백으로 구분된 N개의 정수 A[1], A[2], ..., A[N]이 주어집니다.

## 출력

k번째로 큰 정수 값을 출력합니다.

## 제약 조건

1 <= N <= 1000000
1 <= k <= N
1 <= A[i] <= 10^9

## 예제 1

**입력**
```
5
10 20 5 30 15
```

**출력**
```
20
```

*주어진 수열에서 k=2일 때, 정렬하면 [30, 20, 15, 10, 5]가 되므로, 두 번째로 큰 값은 20입니다.*

## 예제 2

**입력**
```
7
1 2 3 4 5 6 7
```

**출력**
```
4
```

*k=4일 때, 7개의 수 중 네 번째로 큰 값은 4입니다. (7, 6, 5, 4, ...)*

## 힌트

- 문제의 핵심은 'k번째'라는 조건과 N의 크기(10^6)입니다.
- 시간 복잡도를 O(N log k) 또는 O(N log N) 이하로 유지해야 합니다.
- 작은 값 k를 활용하는 자료구조를 고려해 보세요.


## 알고리즘 요약

Min-Heap (최소 힙)을 사용하여 상위 k개의 원소를 유지합니다. N개의 원소를 순회하면서, 현재까지 발견한 상위 k개 원소의 크기 k개만을 힙에 저장합니다. 새로운 원소 A[i]가 들어올 때마다, 힙의 최댓값(즉, k번째로 큰 값)과 비교하여 힙의 크기를 유지합니다.

## 풀이 해설

풀이 아이디어:
이 문제는 N개의 원소 중 k번째로 큰 값을 찾는 문제입니다. N이 최대 10^6이므로, 단순히 모든 원소를 정렬하는 O(N log N) 방법도 가능하지만, k를 활용하여 더 최적화할 수 있습니다. 가장 효율적인 방법은 '상위 k개의 원소'만을 유지하는 최소 힙(Min-Heap)을 사용하는 것입니다.

단계별 풀이:
1. **힙 초기화**: 크기가 k인 최소 힙(Min-Heap)을 초기화합니다. 이 힙은 현재까지 발견된 k개의 가장 큰 원소들을 저장합니다. 힙의 루트는 이 k개의 원소 중 가장 작은 값, 즉 k번째로 큰 값이 됩니다.
2. **원소 처리**: 주어진 N개의 원소 A[i]를 순서대로 순회합니다.
3. **힙에 삽입**: 힙의 크기가 k보다 작을 경우, A[i]를 무조건 힙에 삽입합니다.
4. **힙 유지**: 힙의 크기가 이미 k인 경우, A[i]와 힙의 최솟값(힙의 루트, k번째로 큰 값)을 비교합니다.
    - 만약 A[i]가 힙의 최솟값보다 크다면, A[i]는 현재 k번째로 큰 값보다 크다는 의미이므로, 힙의 최솟값을 제거하고 A[i]를 삽입합니다. (힙에 k개의 가장 큰 값만 유지)
    - 만약 A[i]가 힙의 최솟값보다 작거나 같다면, A[i]는 상위 k개에 들지 못하므로 무시합니다.
5. **결과 반환**: 모든 원소 처리가 끝난 후, 힙의 루트에 남아있는 값이 바로 전체 N개 원소 중 k번째로 큰 값입니다.

시간 복잡도: N개의 원소를 한 번 순회하며, 각 원소마다 힙에 삽입(push) 또는 삭제(pop) 연산을 수행합니다. 힙의 크기는 최대 k이므로, 각 연산은 O(log k) 시간이 걸립니다. 따라서 총 시간 복잡도는 O(N log k)가 됩니다.

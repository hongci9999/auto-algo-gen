# 최대 공약수를 이용한 배열 처리
*python · 자료구조 · 보통 · GCD, 배열*

## 입출력 환경

입력은 표준 입력에서 받습니다. Python에서는 sys.stdin.read()를 사용하여 모든 입력을 한 번에 처리하는 것이 효율적입니다.

## 문제

N개의 양의 정수 $A_1, A_2, \dots, A_N$이 주어집니다. 이 배열에서 임의로 두 원소 $A_i$와 $A_j$ ($i \neq j$)를 선택하여 최대 공약수 $\text{gcd}(A_i, A_j)$를 계산합니다.
\n문제는 다음과 같습니다: 모든 가능한 쌍 $(A_i, A_j), i < j$에 대해 계산한 최대 공약수 값들의 집합 중에서 가장 큰 값을 구하시오.

## 입력

첫 번째 줄에는 정수 N (1 <= N <= 100)이 주어집니다. 두 번째 줄에는 공백으로 구분된 N개의 양의 정수 $A_1, A_2, \dots, A_N$이 주어집니다.

## 출력

가장 큰 최대 공약수 값을 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 100. 각 원소 $A_i$는 1 이상 100,000 이하입니다. 시간 복잡도는 O(N^2) 또는 그보다 빠르게 제한됩니다.

## 예제 1

**입력**
```
3
6 10 15
```

**출력**
```
5
```

*가능한 쌍의 GCD는 gcd(6, 10)=2, gcd(6, 15)=3, gcd(10, 15)=5 이므로 최대값은 5입니다.*

## 예제 2

**입력**
```
4
7 14 21 28
```

**출력**
```
14
```

*최대 공약수는 gcd(14, 28) = 14 입니다.*

## 힌트

- 모든 가능한 쌍을 순회하는 브루트 포스 접근법이 가장 직관적입니다.
- 유클리드 호제법을 사용하여 두 수의 최대 공약수를 효율적으로 계산해야 합니다.


## 알고리즘 요약

모든 쌍에 대한 GCD 계산 (Brute Force)

## 풀이 해설

아이디어: 문제에서 요구하는 값은 모든 가능한 $i < j$ 쌍에 대해 $\text{gcd}(A_i, A_j)$를 계산한 후, 그 결과들 중 최댓값을 찾는 것입니다. 주어진 N의 제약 조건($N \le 100$)과 원소값의 제약 조건($A_i \le 100,000$)을 고려했을 때, 모든 쌍을 순회하는 $O(N^2)$ 접근법이 가장 간단하고 효율적입니다. 

단계:
1. 전역 변수 `max_gcd`를 0으로 초기화합니다.
2. 이중 반복문을 사용하여 배열의 모든 서로 다른 인덱스 $i$와 $j$ ($i < j$) 쌍을 순회합니다.
3. 각 쌍 $(A_i, A_j)$에 대해 최대 공약수 $\text{gcd}(A_i, A_j)$를 계산합니다 (유클리드 호제법 사용).
4. 계산된 GCD 값을 `max_gcd`와 비교하여, 더 크다면 `max_gcd`를 업데이트합니다.
5. 반복문이 완료되면 최종 `max_gcd` 값이 답입니다.

시간 복잡도: $O(N^2 \cdot 	ext{log}(	ext{max}(A)))$. 여기서 $	ext{log}(	ext{max}(A))$는 GCD 계산에 필요한 시간이며, 이는 매우 빠르게 수렴합니다. 따라서 전체 시간 복잡도는 실질적으로 $O(N^2)$으로 간주할 수 있습니다.

## 참고 코드 (python)

```python
import sys
# 재귀 호출을 위한 최대 깊이 설정 (필요하다면)
sys.setrecursionlimit(10**6)

def gcd(a, b):
    ""유클리드 호제법으로 두 수의 최대 공약수를 계산합니다."""
    while b:
        a, b = b, a % b
    return a

def solve():
    # 표준 입력에서 모든 데이터를 읽어옵니다.
    data = sys.stdin.read().split()
    if not data: 
        return 0 # 입력이 없으면 0 반환 (실제 테스트 환경 고려)
    
    N = int(data[0])
    A = [int(x) for x in data[1:]]
    
    # N이 1인 경우, 쌍을 만들 수 없으므로 문제 정의상 불가능하나, 가장 작은 값을 반환하거나 예외 처리해야 함. 
    # 여기서는 N >= 2를 가정합니다 (제약 조건에 의해 N>=1이지만, gcd는 i!=j가 필요).
    if N < 2:
        return 0 # 적절한 초기값 혹은 오류 처리

    max_gcd = 0
    
    # 모든 쌍을 순회하며 최대 GCD를 찾습니다.
    for i in range(N):
        for j in range(i + 1, N):
            current_gcd = gcd(A[i], A[j])
            if current_gcd > max_gcd:
                max_gcd = current_gcd
    
    return max_gcd

print(solve())
```

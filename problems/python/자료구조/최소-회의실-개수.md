# 최소 회의실 개수
*python · 자료구조 · 보통 · 스윕라인, 정렬, 자료구조*

## 입출력 환경

표준 입력을 통해 모든 데이터를 읽고, 결과를 표준 출력합니다. 효율적인 입력을 위해 sys.stdin.readline을 사용하는 것을 권장합니다.

## 문제

여러 개의 회의가 예정되어 있습니다. 각 회의는 시작 시간과 종료 시간(반드시 종료 시간 포함)을 가집니다. 이 모든 회의가 동시에 진행될 때, 필요한 최소한의 회의실 개수를 구하는 문제입니다.

주의사항: 회의의 시간 범위는 [시작 시간, 종료 시간]을 포함하며, 종료 시간과 다음 회의의 시작 시간이 같을 경우, 같은 회의실을 사용할 수 있습니다. 즉, (A: 1~3), (B: 3~5)는 같은 회의실 사용 가능합니다.

## 입력

첫 번째 줄에 회의의 총 개수 N이 주어집니다.
다음 N줄에 걸쳐 각 회의의 시작 시간(s)과 종료 시간(e)이 공백으로 구분되어 주어집니다. (s e)

## 출력

필요한 최소 회의실 개수를 정수 형태로 출력합니다.

## 제약 조건

N은 1 이상 10^5 이하입니다. 시작 시간과 종료 시간은 0 이상 10^9 이하의 정수입니다. 시간 복잡도는 O(N log N)을 목표로 합니다.

## 예제 1

**입력**
```
3
0 3
1 5
4 7
```

**출력**
```
2
```

*시간 1~3 구간에서 (0, 3)과 (1, 5)가 동시에 진행되어 최소 2개의 회의실이 필요합니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
5 6
```

**출력**
```
1
```

*모든 회의들이 순차적으로 진행되므로, 하나의 회의실만으로 충분합니다.*

## 예제 3

**입력**
```
5
0 10
0 1
2 3
4 5
6 7
```

**출력**
```
3
```

*시간 0 근처에서 (0, 10), (0, 1)이 충돌합니다. 추가적으로 (2, 3)도 충돌하며, 최대 3개의 회의실이 필요합니다.*

## 힌트

- 이 문제는 '최대 동시 중첩 구간의 개수'를 찾는 문제와 같습니다.
- 시간의 흐름을 따라가며 사건(Event)을 기록하고 처리하는 스윕라인(Sweep Line) 기법을 사용하면 효율적입니다.


## 알고리즘 요약

스윕라인 알고리즘 (Sweep Line Algorithm): 각 회의의 시작점과 종료점을 '사건'으로 간주하고, 이 사건들을 시간 순으로 정렬합니다. 시작점에서는 필요한 회의실 개수를 1 증가시키고, 종료점에서는 1 감소시킵니다. 이때, 최대 값이 필요한 회의실 개수가 됩니다.

## 풀이 해설

아이디어: 이 문제는 주어진 모든 회의가 동시에 진행될 때, 시간상 가장 많은 회의가 겹치는 순간이 언제인지 찾아내는 문제입니다. 이 '최대 동시 충돌 횟수'가 바로 필요한 최소 회의실 개수와 같습니다.

단계:
1. 이벤트 리스트 생성: 각 회의 [s, e]에 대해 두 개의 이벤트를 생성합니다. 시작 시간 s에서 +1 (회의실 필요), 종료 시간 e에서 -1 (회의실 해제)을 기록합니다. (주의: 문제 조건에 따라 끝나는 순간 바로 다음 회의가 시작할 수 있으므로, 종료 이벤트는 시작 이벤트보다 먼저 처리되어야 합니다. 즉, (2, 3)과 (3, 5)의 경우, 3 시점에서는 '종료'가 '시작'보다 우선순위를 갖도록 처리해야 합니다.)
2. 이벤트 정렬: 모든 이벤트를 시간 순으로 정렬합니다. 만약 동일한 시간(t)에 여러 이벤트가 있다면, 종료 이벤트(-1)가 시작 이벤트(+1)보다 우선순위가 높도록 정렬합니다.
3. 스윕라인 처리: 정렬된 이벤트 리스트를 순회하면서 누적된 '현재 사용 중인 회의실 수'를 계산합니다. 이 값을 누적시키고, 최대 사용 횟수를 갱신합니다.
4. 결과 반환: 순회 후 기록된 최대 사용 횟수가 최종 답이 됩니다.

시간 복잡도: 이벤트 총 개수는 2N개입니다. 이를 정렬하는 데 O(N log N)이 걸리며, 이후 순회는 O(N)이므로, 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 증가 (필요시)
sys.setrecursionlimit(2000)

def solve():
    # 빠른 입력을 위해 sys.stdin.readline 사용
    input = sys.stdin.read
    data = input().split()

    if not data: 
        print(0)
        return

    N = int(data[0])
    meetings = []
    for i in range(N): 
        start = int(data[2*i + 1])
        end = int(data[2*i + 2])
        meetings.append((start, end))

    # Sweep Line (스윕라인) 이벤트 리스트 생성
    # 이벤트 형식: (시간, 타입) 
    # 타입: -1 (종료, 우선순위 높음), 1 (시작, 우선순위 낮음)
    # 종료가 시작보다 우선해야 같은 시점의 회의실 해제/할당 오류 방지
    events = []
    for s, e in meetings:
        # 시작 이벤트: (s, 1) -> 회의실 필요 (+1)
        events.append((s, 1))
        # 종료 이벤트: (e, -1) -> 회의실 해제 (-1)
        events.append((e, -1))

    # 1. 정렬: 시간 순으로 정렬하고, 동일 시간 내에서는 종료 이벤트(-1)가 시작 이벤트(1)보다 먼저 오도록 정렬한다.
    # (시간, 타입) 튜플을 사용하면 파이썬 기본 정렬이 (t, -1) < (t, 1) 순서로 처리되어 원하는 우선순위를 만족한다.
    events.sort()

    max_rooms = 0
    current_rooms = 0

    # 2. 스윕라인 처리
    for time, type_change in events:
        if type_change == 1: # 시작 이벤트
            current_rooms += 1
        elif type_change == -1: # 종료 이벤트
            # 주의: 문제 조건상 (A: 1~3), (B: 3~5)는 같은 회의실 사용 가능하므로, 
            # 종료 시점에 카운트를 줄이고, 시작 시점에 다시 카운트를 올립니다. 
            # (이벤트 정렬 덕분에 이 논리가 성립합니다.)
            current_rooms -= 1
        
        # 현재 사용 중인 회의실 수 갱신 및 최대값 기록
        max_rooms = max(max_rooms, current_rooms)

    print(max_rooms)

if __name__ == '__main__':
    solve()
```

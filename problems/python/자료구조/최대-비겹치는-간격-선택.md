# 최대 비겹치는 간격 선택
*python · 자료구조 · 보통 · 정렬, 그리디, 간격*

## 입출력 환경

입력 처리 시 시간 초과를 방지하기 위해 `sys.stdin.readline` 등을 사용하여 효율적으로 입력받는 것이 좋습니다.

## 문제

당신은 여러 개의 시간 간격(Interval) 목록을 받았습니다. 각 간격은 시작 시간과 끝 시간으로 이루어져 있습니다. 목표는 이 간격들 중에서 서로 겹치지 않으면서, 개수가 최대가 되는 간격들의 조합을 찾는 것입니다.

즉, 주어진 $N$개의 간격 $[start_i, end_i]$가 있을 때, 최대 몇 개의 간격을 선택할 수 있는지 그 개수를 구하세요. 간격 $[A, B]$와 $[C, D]$가 겹치지 않으려면, $B < C$ 또는 $D < A$여야 합니다. (시작 시간과 끝 시간이 같은 간격도 겹치지 않는다고 가정합니다.)

## 입력

첫 번째 줄에 간격의 총 개수 $N$이 주어집니다.
다음 $N$개의 줄에는 공백으로 구분된 두 개의 정수 $start_i$와 $end_i$가 주어지며, 이는 $i$번째 간격 $[start_i, end_i]$를 나타냅니다.

## 출력

선택 가능한 최대 비겹치는 간격의 개수를 하나의 정수 형태로 출력합니다.

## 제약 조건

N의 범위: 1부터 200,000까지입니다.
좌표(시작/끝 시간)의 범위: 1부터 10^9까지입니다.
시간 복잡도는 $O(N 	ext{ log } N)$ 이내여야 합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 7
```

**출력**
```
2
```

*간격 [1, 4]를 선택하고, 다음으로 겹치지 않는 [6, 7]을 선택하여 최대 2개를 만들 수 있습니다.*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 5
```

**출력**
```
3
```

*간격 [1, 2], [2, 3], [3, 4]를 순서대로 선택하여 최대 3개를 만들 수 있습니다.*

## 힌트

- 모든 간격을 임의로 선택하는 것이 아니라, 최적의 선택 기준이 필요합니다.
- 어떤 간격을 먼저 처리할지 결정하는 '정렬'이 핵심입니다. 주로 끝나는 시점을 기준으로 정렬해보세요.


## 알고리즘 요약

그리디 알고리즘 (Greedy Algorithm)을 사용합니다. 문제의 핵심은 '가장 빨리 끝나는 간격'을 선택하는 것입니다. 이 간격을 선택함으로써 남은 시간대에 가장 많은 선택지를 남길 수 있기 때문입니다. 따라서 모든 간격을 끝나는 시간 순서대로 정렬한 후, 가장 먼저 끝나는 간격부터 순차적으로 겹치는지 확인하며 선택합니다.

## 풀이 해설

1. 아이디어: 이 문제는 전형적인 활동 선택 문제(Activity Selection Problem)이며, 그리디 알고리즘을 통해 해결할 수 있습니다. 최적의 그리디 선택 기준은 '현재까지 선택한 간격들 중에서 가장 빨리 끝나는 간격'을 고르는 것입니다. 이 간격을 선택해야 남은 시간대에 가능한 간격의 범위가 가장 넓게 유지됩니다.
2. 단계:
    a. 입력된 모든 간격들을 리스트에 저장합니다.
    b. 이 간격 리스트를 **끝나는 시간(End Time)을 기준으로 오름차순 정렬**합니다. (만약 끝나는 시간이 같다면, 시작 시간을 기준으로 정렬하는 것이 좋습니다.)
    c. 선택된 간격의 개수(Count)를 0으로 초기화하고, 마지막으로 선택된 간격의 끝 시간(LastEnd)을 아주 작은 값으로 초기화합니다.
    d. 정렬된 리스트를 처음부터 순회합니다.
    e. 현재 간격의 시작 시간이 `LastEnd`보다 크거나 같은지 확인합니다. (즉, 겹치지 않는지 확인합니다.)
    f. 겹치지 않는다면, 이 간격을 선택합니다. Count를 1 증가시키고, `LastEnd`를 현재 간격의 끝 시간으로 업데이트합니다.
    g. 순회가 끝나면 Count가 최대 개수입니다.
3. 시간 복잡도: $O(N 	ext{ log } N)$는 정렬 과정에 의해 결정되며, 이후 순회는 $O(N)$이므로 전체 시간 복잡도는 $O(N 	ext{ log } N)$입니다.

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한을 늘려 혹시 모를 상황에 대비 (필수는 아님)
sys.setrecursionlimit(200000)

def solve():
    # 표준 입력을 빠르게 읽기 위해 sys.stdin.read() 사용
    input_data = sys.stdin.read().split()
    if not input_data: 
        print(0)
        return

    try:
        N = int(input_data[0])
    except IndexError:
        # N이 없거나 잘못된 경우
        print(0)
        return

    intervals = []
    # input_data[1:]부터 시작하여 2개씩 묶어 간격 정보를 추출
    for i in range(N):
        start = int(input_data[2*i + 1])
        end = int(input_data[2*i + 2])
        intervals.append((start, end))

    # 1. 그리디 알고리즘의 핵심: 끝나는 시간을 기준으로 오름차순 정렬
    # lambda x: x[1] 은 튜플의 두 번째 요소(end)를 기준으로 정렬하라는 의미입니다.
    intervals.sort(key=lambda x: x[1])

    count = 0
    last_end_time = -1 # 시작 시간이 1부터이므로, -1로 초기화하여 첫 간격은 무조건 선택되게 함

    for start, end in intervals:
        # 2. 현재 간격의 시작 시간이 마지막 선택 간격의 끝 시간보다 크거나 같은지 확인
        # (겹치지 않음 = start >= last_end_time)
        if start >= last_end_time:
            count += 1
            # 3. 선택했다면, last_end_time을 현재 간격의 끝 시간으로 업데이트
            last_end_time = end

    print(count)

solve()
```

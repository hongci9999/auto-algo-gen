# 최대 사각형 넓이 구하기
*python · 자료구조 · 보통 · 스택, 사각형*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 처리하는 것이 효율적입니다.

## 문제

N개의 좌표 점들이 주어집니다. 이 점들 중 일부를 꼭짓점으로 하는 직사각형을 만들 때, 그 넓이의 최댓값을 구하는 문제입니다.

주어진 N개 점은 (x, y) 쌍으로 이루어져 있으며, 모든 좌표는 정수입니다. 직사각형의 네 꼭짓점은 반드시 주어진 N개의 점들 중에서만 선택되어야 합니다.

## 입력

첫째 줄에 정수 N이 주어집니다. 다음 N줄에는 각각 x좌표와 y좌표를 가진 점 (x, y)가 공백으로 구분되어 주어집니다.

## 출력

최대 사각형 넓이의 최댓값을 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 2000
1 <= x_i, y_i <= 1000

## 예제 1

**입력**
```
4
1 1
3 1
1 2
3 2
```

**출력**
```
4
```

*주어진 점들로 만들 수 있는 가장 큰 직사각형은 (1,1), (3,1), (1,2), (3,2)를 꼭짓점으로 할 때 넓이가 4입니다.*

## 예제 2

**입력**
```
5
0 0
1 0
0 1
1 1
2 2
```

**출력**
```
1
```

*가장 큰 직사각형은 (0,0), (1,0), (0,1), (1,1)를 꼭짓점으로 할 때 넓이가 1입니다. 다른 조합도 고려해야 합니다.*

## 예제 3

**입력**
```
3
5 5
5 8
2 8
```

**출력**
```
0
```

*직사각형을 이루려면 최소한 두 쌍의 x좌표와 두 쌍의 y좌표가 필요합니다. 이 점들로는 직사각형을 만들 수 없습니다.*

## 힌트

- 직사각형은 항상 평행사변형입니다.
- 주어진 N개의 점들을 이용하여 가능한 모든 직사각형의 꼭짓점 조합을 탐색하는 것이 핵심입니다.


## 알고리즘 요약

O(N^2) 시간 복잡도로, 모든 쌍의 x좌표를 사용하여 가능한 너비를 확정한 후, 각 x 좌표에 대해 공통으로 포함되는 y 좌표들의 최댓값을 찾아 넓이를 계산합니다. 이를 통해 직사각형을 구성하는 네 꼭짓점을 효율적으로 찾습니다.

## 풀이 해설

문제는 주어진 N개의 점들로 이루어진 직사각형의 최대 넓이를 구하는 문제입니다.

**아이디어**: 직사각형은 두 개의 x좌표 ($x_{min}, x_{max}$)와 두 개의 y좌표 ($y_{min}, y_{max}$)를 가지고 정의됩니다. 즉, 네 꼭짓점은 $(x_{min}, y_{min}), (x_{max}, y_{min}), (x_{min}, y_{max}), (x_{max}, y_{max})$가 되어야 합니다. 이 네 점이 모두 주어진 N개의 점들 속에 포함되어야만 직사각형이 성립합니다.

**단계**: 
1. **좌표 집합 구성**: 주어진 N개 점의 모든 x 좌표와 모든 y 좌표를 별도의 집합(Set)에 저장하여, 특정 좌표가 존재하는지 $O(1)$ 시간 복잡도로 빠르게 확인하도록 합니다. (실제로는 맵이나 배열을 사용하는 것이 더 효율적일 수 있습니다.)
2. **쌍 반복**: 가능한 모든 x좌표 쌍 $(x_1, x_2)$와 y좌표 쌍 $(y_1, y_2)$를 순회합니다.
3. **검증 및 계산**: 각 네 좌표 $(x_1, x_2, y_1, y_2)$에 대해, 네 꼭짓점 $(x_1, y_1), (x_2, y_1), (x_1, y_2), (x_2, y_2)$가 모두 주어진 N개 점들 속에 존재하는지 확인합니다.
4. **최댓값 갱신**: 만약 네 꼭짓점이 모두 존재한다면, 이 직사각형의 넓이 $|x_1 - x_2| 	imes |y_1 - y_2|$를 계산하고 현재까지의 최대 넓이를 갱신합니다.

*개선된 접근 (O(N^2) 시간 복잡도)*: 모든 점들을 좌표 기준으로 정렬한 후, 가능한 두 개의 수직선 $x=x_a$와 $x=x_b$를 선택하고, 이 두 선분 위에 공통으로 존재하는 y좌표들 중 가장 넓게 퍼진 구간을 찾아 최대 넓이를 계산하는 것이 더 효율적일 수 있습니다. 하지만 주어진 제약 조건 N<=2000과 좌표 범위 <=1000을 고려할 때, 모든 가능한 x 쌍과 모든 가능한 y 쌍을 조합하여 네 꼭짓점의 존재 여부를 확인하는 방법이 직관적이고 구현하기 용이합니다.

최종적으로, 이 문제에서는 **모든 고유한 x좌표 $X$ 집합과 고유한 y좌표 $Y$ 집합**을 구하고, $|X| 	imes |X|$ 쌍의 $(x_1, x_2)$와 $|Y| 	imes |Y|$ 쌍의 $(y_1, y_2)$를 순회하며 네 꼭짓점을 검사합니다. (최대 $|X|, |Y| 	o N$). 따라서 시간 복잡도는 $O(N^4)$이지만, 실제로는 $O(|X|^2 |Y|^2)$로 제한됩니다. 최악의 경우 $O(N^4)$이 될 수 있으나, 이 문제에서는 좌표값을 이용하는 것이 더 빠릅니다. (실제 구현 시에는 모든 점을 Set에 저장하고, 가능한 x 쌍만 반복하며, 그 사이 공통 y를 찾는 방법이 가장 효율적입니다.)

**시간 복잡도**: $O(N^2)$ 또는 $O(|X|^2 	imes |Y|)$ (실제 구현 방식에 따라 달라지나, N=2000 제약 하에서 충분히 통과 가능한 수준으로 설계되었습니다.)

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 표준 입력을 빠르게 읽기 위해 설정
    input = sys.stdin.read
    data = input().split()
    
    if not data: return 0
    
    N = int(data[0])
    points = []
    for i in range(N): 
        x = int(data[i*2 + 1])
        y = int(data[i*2 + 2])
        points.append((x, y))

    # 모든 점을 Set에 저장하여 O(1) 탐색 가능하게 만듦
    point_set = set(points)
    
    # 고유한 x좌표와 y좌표 추출
    unique_x = sorted(list(set(p[0] for p in points)))
    unique_y = sorted(list(set(p[1] for p in points))) 
    
    max_area = 0

    # 가능한 모든 두 x 좌표 쌍 (x1, x2) 순회
    for i in range(len(unique_x)): 
        for j in range(i + 1, len(unique_x)): # x1 < x2로 가정
            x1 = unique_x[i]
            x2 = unique_x[j]
            width = x2 - x1

            # 가능한 모든 두 y 좌표 쌍 (y1, y2) 순회
            for k in range(len(unique_y)): 
                for l in range(k + 1, len(unique_y)): # y1 < y2로 가정
                    y1 = unique_y[k]
                    y2 = unique_y[l]
                    height = y2 - y1

                    # 네 꼭짓점 (x1, y1), (x2, y1), (x1, y2), (x2, y2)이 모두 존재하는지 확인
                    if ((x1, y1) in point_set and 
                        (x2, y1) in point_set and 
                        (x1, y2) in point_set and 
                        (x2, y2) in point_set): 
                        
                        area = width * height
                        max_area = max(max_area, area)
                        
    return max_area

if __name__ == "__main__":
    print(solve())
```

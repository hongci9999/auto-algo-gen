# 최대 사각형의 넓이
*python · 자료구조 · 보통 · 스택, 사각형, 히스토그램*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

주어진 높이(height)와 너비(width)로 이루어진 직사각형 격자 형태의 배열이 있습니다. 이 격자 내에서 네 꼭짓점이 모두 격자점 위에 놓이고, 내부가 직사각형인 가장 넓은 직사각형의 넓이를 구하는 문제입니다.

단, 이 문제의 핵심은, 주어진 격자 배열의 각 열(column)을 하나의 높이(height)를 가진 막대 그래프(히스토그램)로 간주하고, 이 히스토그램을 이용하여 가장 넓은 직사각형을 찾는 문제입니다. 이 넓이는 직사각형의 너비와 그 너비에 걸쳐 유지되는 최소 높이로 결정됩니다.

즉, 높이 배열 `height`가 주어졌을 때, 이 높이 배열을 히스토그램으로 간주하고 가장 넓은 직사각형의 넓이를 구하세요.

## 입력

첫째 줄에 양의 정수 N (높이 배열의 길이)이 주어집니다. 
둘째 줄에 N개의 정수 h1, h2, ..., hN이 공백으로 구분되어 주어지며, 이것이 높이 배열입니다.

## 출력

가장 넓은 직사각형의 넓이 (정수)를 출력합니다.

## 제약 조건

1 <= N <= 100000
1 <= hi <= 100000

## 예제 1

**입력**
```
4
2 1 5 6
```

**출력**
```
10
```

*높이 2, 1, 5, 6을 가진 히스토그램에서, 높이 5와 6을 포함하는 너비 2의 직사각형 (넓이 10)이 최대입니다.*

## 예제 2

**입력**
```
5
6 7 7 7 6
```

**출력**
```
12
```

*높이 6, 7, 7, 7, 6에서, 중앙 7을 포함하는 너비 3의 직사각형 (넓이 21)이 아닌, 7이 연속되는 부분 중 넓이를 최대화해야 합니다. 실제 최대는 7 * 2 = 14 (중앙 7 두 개)가 아니라, 6~7~7~7~6 전체에서 가장 큰 직사각형을 찾아야 합니다. (가장 큰 넓이는 6*7=42가 아닙니다. 가장 넓은 것은 7*2=14 또는 7*3=21 (만약 높이가 7로 유지된다면)입니다. 이 예제에서는 7*3=21을 목표로 합니다. -> 실제 최대는 7*3=21이 아니라, 7*2=14 또는 7*3=21이 아닙니다. 최대는 7*3=21입니다. (수정: 가장 넓은 것은 7*3=21입니다.)*

## 예제 3

**입력**
```
1
5
```

**출력**
```
5
```

*높이가 5인 막대 하나만 있으므로 넓이는 5입니다.*

## 힌트

- 이 문제는 '가장 넓은 히스토그램 직사각형' 문제로 알려져 있습니다.
- 모든 가능한 직사각형을 탐색하는 것은 O(N^2)이 되어 시간 초과가 발생할 수 있습니다. O(N) 또는 O(N log N) 복잡도를 목표로 해야 합니다.


## 알고리즘 요약

스택(Stack) 자료구조와 단조 스택(Monotonic Stack) 개념을 활용합니다. 각 막대 `i`를 높이로 하는 직사각형이 최대가 되려면, 이 막대 `i`의 높이보다 작거나 같은 높이를 가진 가장 가까운 왼쪽 막대 `L`과 오른쪽 막대 `R`을 찾아야 합니다. 이 경우 직사각형의 너비는 `R - L - 1`이 되고, 넓이는 `height[i] * (R - L - 1)`이 됩니다. 스택을 사용하여 이 `L`과 `R`을 효율적으로 찾을 수 있습니다.

## 풀이 해설

문제는 주어진 높이 배열 `height`를 히스토그램으로 간주하고 최대 넓이의 직사각형을 찾는 문제입니다. 모든 가능한 직사각형을 탐색하는 것은 시간이 너무 오래 걸리므로, 스택을 이용한 단조 스택 기법을 사용합니다.

**아이디어:** 모든 막대 `i`를 기준으로 '이 막대가 높이로 사용될 때 얻을 수 있는 최대 넓이'를 계산하고, 그 중 최댓값을 찾습니다.

**단계:**
1. **다음 작은 요소 찾기 (Next Smaller Element):** 각 인덱스 `i`에 대해, 그보다 크거나 같은 높이를 유지하며 연속되는 가장 가까운 왼쪽 인덱스 `L[i]`와 오른쪽 인덱스 `R[i]`를 찾아야 합니다. 이 `L[i]`와 `R[i]`는 각각 `height[i]`보다 작거나 같은 높이를 가진 첫 번째 막대의 위치입니다. (즉, 이 막대 `i`를 포함하는 직사각형이 좌우로 뻗어나갈 수 있는 최대 범위를 정의합니다.)
2. **스택 활용:** 단조 스택(Monotonic Stack)을 사용하여 이 `L`과 `R` 배열을 O(N) 시간에 계산합니다. 스택에는 현재까지 처리된 인덱스들이 오름차순(또는 내림차순)으로 높이가 유지되도록 관리합니다.
3. **넓이 계산:** 모든 `i`에 대해, 최대 넓이는 `height[i] * (R[i] - L[i] - 1)`입니다. 이 값을 최대 넓이로 갱신합니다.

**시간 복잡도:** L 배열 계산 (O(N)), R 배열 계산 (O(N)), 최대값 탐색 (O(N)). 총 시간 복잡도는 O(N)입니다. 공간 복잡도는 스택과 배열을 저장하므로 O(N)입니다.

## 참고 코드 (python)

```python
import sys

# 재귀 깊이 제한 해제 (큰 입력 처리 대비)
# sys.setrecursionlimit(2000) # 파이썬에서는 일반적으로 불필요하나 습관적으로 포함
def largestRectangleArea(height):
    n = len(height)
    
    # 1. 왼쪽 경계 (L[i]): height[i]보다 작거나 같은 가장 가까운 왼쪽 인덱스
    # L[i]는 height[i]보다 낮은 막대가 나타나는 위치의 인덱스 - 1로 생각할 수 있습니다.
    # 여기서는 직관적으로, height[i]를 포함하는 직사각형이 왼쪽으로 뻗어나갈 수 있는 범위의 시작점 (L[i] + 1)을 찾습니다.
    # L[i]는 height[i]보다 작은 가장 가까운 인덱스입니다. (즉, L[i]는 직사각형의 시작점 바로 왼쪽입니다.)
    L = [-1] * n
    stack = [] # 스택에는 인덱스를 저장합니다.
    
    for i in range(n):
        while stack and height[stack[-1]] >= height[i]:
            stack.pop()
        
        if not stack:
            L[i] = -1 # 왼쪽 경계가 없으면 -1
        else:
            L[i] = stack[-1] # 스택 맨 위의 인덱스가 가장 가까운 낮은 왼쪽 경계
        
        stack.append(i)

    # 2. 오른쪽 경계 (R[i]): height[i]보다 작거나 같은 가장 가까운 오른쪽 인덱스
    # R[i]는 height[i]보다 낮은 막대가 나타나는 위치의 인덱스 + 1로 생각할 수 있습니다.
    R = [n] * n
    stack = [] # 스택을 초기화
    
    for i in range(n - 1, -1, -1):
        while stack and height[stack[-1]] >= height[i]:
            stack.pop()
        
        if not stack:
            R[i] = n # 오른쪽 경계가 없으면 n
        else:
            R[i] = stack[-1] # 스택 맨 위의 인덱스가 가장 가까운 낮은 오른쪽 경계
        
        stack.append(i)

    # 3. 최대 넓이 계산
    max_area = 0
    for i in range(n):
        # 너비 = R[i] - L[i] - 1
        width = R[i] - L[i] - 1
        area = height[i] * width
        max_area = max(max_area, area)
        
    return max_area

# 입출력 처리
def solve():
    # 첫 줄: N (길이는 사용하지 않아도 됨)
    try:
        # N = int(sys.stdin.readline())
        _ = sys.stdin.readline()
    except:
        return

    # 둘째 줄: 높이 배열
    try:
        line = sys.stdin.readline().strip()
        if not line:
            return
        height = list(map(int, line.split()))
    except EOFError:
        return

    result = largestRectangleArea(height)
    print(result)

# solve() # 실제 코딩테스트 환경에서는 주석 처리하거나 직접 실행

# 테스트용 호출 (JSON 출력 시에는 실제 코드를 사용함)

# height2 = [6, 7, 7, 7, 6]
# print(largestRectangleArea(height2)) # 21
```

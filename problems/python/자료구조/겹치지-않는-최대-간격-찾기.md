# 겹치지 않는 최대 간격 찾기
*python · 자료구조 · 보통 · 정렬, 그리디*

## 입출력 환경

Python 환경에서 입력을 받을 때는 sys.stdin.readline을 사용하여 효율적으로 처리하는 것이 좋습니다.

## 문제

N개의 시간 간격 $[s_i, e_i]$가 주어집니다. 이 간격들은 1차원 좌표축 위에 존재합니다.

주어진 N개의 간격들 중에서 최대 개수의 간격들을 선택하되, 선택된 어떤 두 간격도 서로 겹치지 않도록(즉, $s_a 
eq s_b$이고 $[s_a, e_a]$와 $[s_b, e_b]$가 공통의 점을 갖지 않도록) 하는 것이 목표입니다.

이 문제를 '활동 선택 문제(Activity Selection Problem)'라고 하며, 겹치지 않는 간격들의 최대 개수를 구하는 문제입니다.

## 입력

첫째 줄에 정수 N이 주어집니다. 다음 N줄에는 각 간격의 시작 시간 $s_i$와 종료 시간 $e_i$가 공백으로 구분되어 순서대로 주어집니다.

## 출력

겹치지 않는 최대 개수의 간격을 찾아 그 개수를 정수 형태로 출력합니다.

## 제약 조건

1. N의 범위: 1 <= N <= 200,000
2. 시간 범위: 0 <= s_i, e_i < 10^9
3. 시간 복잡도: O(N log N) 이하를 목표로 합니다.

## 예제 1

**입력**
```
5
1 3
2 4
3 5
0 1
6 7
```

**출력**
```
3
```

*간격 [0, 1], [1, 3]는 시작점 1에서 겹치므로 선택 불가. 최적의 조합은 [0, 1], [1, 3] 대신 다른 간격을 골라야 합니다. 예: [0, 1], [3, 5], [6, 7].*

## 예제 2

**입력**
```
4
1 2
2 3
3 4
1 4
```

**출력**
```
3
```

*가장 짧게 끝나는 간격들을 선택하는 것이 유리합니다. [1, 2], [2, 3]은 시작점 2에서 겹치므로, 예: [1, 2], [2, 3] 대신 [1, 4]를 제외하고 순서대로 선택하면 최대 3개 ([1, 2], [2, 3], [3, 4])가 됩니다.*

## 힌트

- 간격들을 어떤 기준으로 정렬할지 고민해 보세요. 시작 시간 순이나 길이 순이 아닌, 종료 시간을 기준으로 정렬하는 것이 핵심입니다.
- 탐욕 알고리즘(Greedy Algorithm)의 원리를 적용하여 문제를 해결할 수 있습니다.


## 알고리즘 요약

활동 선택 문제(Activity Selection Problem)는 대표적인 그리디 알고리즘 문제입니다. 간격들을 종료 시간 $e_i$ 오름차순으로 정렬한 후, 가장 먼저 끝나는 간격을 선택하고, 그 간격이 끝난 시점($e_{chosen}$)보다 시작 시간이 크거나 같은 다음 간격을 순차적으로 선택해 나갑니다. 이렇게 하면 항상 전역 최적 해에 도달합니다.

## 풀이 해설

1. 아이디어 (그리디 접근): 주어진 N개의 활동(간격) 중에서 겹치지 않는 최대 개수를 찾는 문제입니다. 이 문제는 그리디 알고리즘을 사용하여 해결할 수 있습니다. 핵심 원칙은 '가장 빨리 끝나는 활동을 선택하는 것'입니다. 가장 먼저 종료되는 간격을 선택하면, 남은 시간이 최소화되어 이후에 선택할 수 있는 활동의 기회가 최대화되기 때문입니다.
2. 단계:
   a) 정렬: 모든 간격 $(s_i, e_i)$를 **종료 시간 $e_i$을 기준으로 오름차순**으로 정렬합니다. 만약 종료 시간이 같다면 시작 시간을 기준으로 오름차순 정렬해도 무방합니다.
   b) 선택 및 카운트: 첫 번째 간격을 반드시 선택하고(이것이 가장 먼저 끝나는 활동임), 이 간격의 종료 시간 $T_{last}$을 기록합니다. 총 개수를 1로 초기화합니다.
   c) 반복: 정렬된 리스트를 순회하며, 현재 간격 $(s_i, e_i)$가 $T_{last}$보다 시작 시간이 크거나 같으면 ($s_i 	ext{ >= } T_{last}$), 이 간격을 선택하고, $T_{last}$을 $e_i$로 업데이트한 후, 총 개수를 1 증가시킵니다.
3. 시간 복잡도: 전체 과정에서 가장 시간이 많이 걸리는 부분은 N개의 간격들을 정렬하는 단계입니다. 따라서 시간 복잡도는 O(N log N)이며, 이는 주어진 제약 조건 내에서 충분히 빠릅니다.

## 참고 코드 (python)

```python
import sys
from typing import List
def solve():
    # 표준 입력 대신 시뮬레이션 환경을 가정하고 입력을 받습니다.
    input = sys.stdin.read().split()
    if not input: 
        print(0)
        return
    
    try:
        N = int(input[0])
        intervals = []
        # N이 200,000까지 가능하므로 리스트로 처리합니다.
        for i in range(N):
            s_i = int(input[1 + i * 2])
            e_i = int(input[1 + i * 2 + 1])
            intervals.append((s_i, e_i))
    except IndexError:
        # 입력 데이터가 부족한 경우 처리 (테스트 케이스 대비)
        print(0)
        return

    # 1. 종료 시간(e)을 기준으로 오름차순 정렬합니다.
    # key=lambda x: x[1]은 튜플의 두 번째 요소(종료 시간)를 기준으로 삼겠다는 의미입니다.
    intervals.sort(key=lambda x: x[1])

    if not intervals:
        print(0)
        return

    # 2. 그리디 선택 시작
    count = 1
    # 첫 번째 간격은 무조건 선택됩니다.
    last_finish_time = intervals[0][1]

    # 3. 나머지 간격들을 순회하며 조건을 만족하는지 확인합니다.
    for i in range(1, N):
        start_time = intervals[i][0]
        end_time = intervals[i][1]
        
        # 시작 시간이 이전 선택된 활동의 종료 시간보다 크거나 같으면 (겹치지 않으면)
        if start_time >= last_finish_time:
            count += 1
            last_finish_time = end_time

    print(count)

solve()
```

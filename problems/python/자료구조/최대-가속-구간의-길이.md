# 최대 가속 구간의 길이
*python · 자료구조 · 보통 · 스택, 최소/최대*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받고, print() 함수를 사용하여 결과를 출력합니다.

## 문제

N개의 건물이 일렬로 세워져 있습니다. 각 건물에는 높이가 적혀 있습니다. 당신은 이 건물들 사이의 특정 구간을 관찰할 수 있습니다. 관찰하는 구간 $[i, j]$는 시작 건물 $i$부터 끝 건물 $j$까지입니다. 이 구간에서 가장 높은 건물을 기준으로 생각할 때, 이 건물보다 낮은 건물이 연속적으로 이어지는 최대 길이의 연속된 구간을 찾고자 합니다.

즉, 구간 $[i, j]$ 내에서 가장 높은 건물 $H_{max}$를 찾고, $H_{max}$를 포함하지 않으면서, 이 $H_{max}$를 기준으로 좌우로 떨어진 가장 긴 연속된 '내림 경사' 혹은 '상승 경사'의 길이를 구해야 합니다. 단, 이 '경사'는 단순히 높이의 차이가 연속적으로 유지되는 구간을 의미하며, 구간의 길이는 포함된 건물의 개수입니다. 가장 긴 길이를 구하세요.

## 입력

첫째 줄에 정수 N (건물 개수)이 주어집니다. 둘째 줄에 공백으로 구분된 N개의 정수(건물 높이)가 주어집니다.

## 출력

가장 긴 연속된 경사의 길이 1개의 정수

## 제약 조건

1 <= N <= 20000
1 <= 높이[i] <= 10000

## 예제 1

**입력**
```
5
3 1 4 2 5
```

**출력**
```
3
```

*가장 높은 건물은 5 (인덱스 4)입니다. 5를 기준으로 왼쪽으로 4(높이 2)와 2(높이 4)가 이어지는 경사 구간이 있습니다. 2-4-5는 경사가 아닙니다. 5를 포함하지 않는 최대 경사 구간은 [3, 1, 4]의 길이 3입니다.*

## 예제 2

**입력**
```
6
1 2 3 4 5 6
```

**출력**
```
6
```

*가장 높은 건물은 6입니다. 6를 포함하지 않는 최대 경사 구간은 전체 6개 건물입니다. (모든 건물이 연속적인 상승 경사입니다.)*

## 힌트

- 모든 가능한 구간 $[i, j]$를 탐색하는 것은 시간 복잡도가 높으므로, 최적화가 필요합니다.
- 특정 건물 $k$를 기준으로, 그를 포함하는 최대 경사 구간을 계산하고, 이 값들 중 최댓값을 찾습니다.


## 알고리즘 요약

모든 건물 $k$를 '기준 건물'로 가정하고, 이 건물을 포함하는 최대 경사 구간의 길이를 계산합니다. 이 경사 구간은 반드시 연속적인 상승 또는 하강 경사를 이루어야 합니다. 이 과정을 모든 $k$에 대해 수행하고 그 최댓값을 반환합니다.

## 풀이 해설

풀이 해설: 이 문제는 '연속적인 경사'를 이루는 최대 길이의 구간을 찾는 문제입니다. 경사 구간의 정의는 '높이의 변화가 일정하게 유지되는 연속적인 배열'입니다. (예: 1, 2, 3 또는 5, 4, 3)

1. **문제 재정의**: 주어진 배열 $H$에서, 연속된 부분 배열 $H[i..j]$ 중, $H[k+1] - H[k]$ 또는 $H[k] - H[k+1]$의 부호가 일정하게 유지되는 가장 긴 길이 $j-i+1$을 찾으면 됩니다.

2. **접근 방식**: 모든 가능한 구간을 체크하는 것은 $O(N^2)$ 이상의 시간이 걸리므로, 선형 시간 $O(N)$에 접근해야 합니다. 

3. **경사 길이 계산**: 우리는 현재 위치 $i$에서 시작하여, 오른쪽으로 이동하면서 경사가 깨지는 지점까지의 길이를 셉니다.
   - 초기 길이(카운트)는 1로 시작합니다. 
   - $i$부터 $j-1$까지 반복하면서, $H[j]$와 $H[j-1]$의 높이 차이의 부호를 확인합니다.
   - **경사 유지 조건**: 현재 경사 방향(상승 또는 하강)이 유지되거나, 아직 방향이 정해지지 않은 경우에만 카운트를 증가시킵니다.
   - **경사 방향 전환/파괴**: 만약 높이 차이의 부호가 이전과 다르거나, 높이 차이가 0이 아닌데 방향이 일관되지 않다면, 경사가 깨진 것으로 간주하고 카운트를 초기화합니다.

4. **구현 단계**: 
   - 전체 배열을 순회하며 현재 연속된 경사의 길이를 `current_length`로 유지합니다. 
   - `max_length`를 0 또는 1로 초기화하고, `current_direction` (1: 상승, -1: 하강, 0: 미정)을 사용하여 경사 상태를 추적합니다. 
   - $i=1$부터 $N-1$까지 반복하며, $H[i]$와 $H[i-1]$을 비교합니다. 
   - 높이 차이 $D = H[i] - H[i-1]$을 계산합니다. 
     - $D > 0$ (상승): 
       - 만약 `current_direction`이 하강(-1)이었다면, 경사 파괴. `current_length` = 2, `current_direction` = 1. 
       - 만약 `current_direction`이 미정(0)이거나 상승(1)이었다면, 경사 유지/시작. `current_length` += 1, `current_direction` = 1. 
     - $D < 0$ (하강): 
       - 만약 `current_direction`이 상승(1)이었다면, 경사 파괴. `current_length` = 2, `current_direction` = -1. 
       - 만약 `current_direction`이 미정(0)이거나 하강(-1)이었다면, 경사 유지/시작. `current_length` += 1, `current_direction` = -1. 
     - $D = 0$ (수평): 
       - 경사 파괴. `current_length` = 1, `current_direction` = 0. 
   - 매 단계마다 `max_length = max(max_length, current_length)`를 갱신합니다.

5. **시간 복잡도**: 배열을 한 번만 순회하므로 $O(N)$입니다. 메모리 복잡도는 $O(1)$입니다.

## 참고 코드 (python)

```python
import sys

# sys.stdin.readline을 사용하여 입력을 받습니다.
input = sys.stdin.read
data = input().split()

if not data: 
    print(0)
    exit()

N = int(data[0])
if N == 0:
    print(0)
    exit()

heights = [int(x) for x in data[1:]]

if N == 1:
    print(1)
    exit()

# max_length: 찾은 최대 경사 길이
max_length = 1

# current_length: 현재 연속된 경사의 길이
current_length = 1

# current_direction: 1 (상승), -1 (하강), 0 (미정/수평)
# 초기에는 첫 두 원소의 관계를 보고 방향을 결정해야 하지만, 안전하게 0으로 시작하고 2번째 원소부터 로직을 돌립니다.
current_direction = 0

for i in range(1, N): 
    h_prev = heights[i-1]
    h_curr = heights[i]
    
    # 높이 차이 계산
    diff = h_curr - h_prev
    
    new_direction = 0
    if diff > 0: 
        new_direction = 1
    elif diff < 0: 
        new_direction = -1
    else: # diff == 0
        new_direction = 0
        
    if new_direction == 0: # 수평 구간: 경사 파괴, 길이 1로 리셋
        current_length = 1
        current_direction = 0
    
    elif current_direction == 0: # 아직 방향이 정해지지 않았을 때 (i=1일 경우)
        current_length = 2
        current_direction = new_direction
    
    elif new_direction == current_direction: # 방향 유지
        current_length += 1
        current_direction = new_direction
    
    elif new_direction != 0 and current_direction != 0: # 방향 전환 (경사 파괴)
        # 새로운 경사 시작: 이전 2개 원소 (i-1, i)가 새로운 경사를 만듦
        current_length = 2
        current_direction = new_direction
    
    else: # new_direction != 0 이고 current_direction == 0 이거나, 기타 예외 처리 (실제로는 위에서 다 처리됨)
        # 만약 이전이 수평이었다가 다시 경사가 시작되는 경우 (예: 3, 3, 4) -> 3->3 (길이 1), 3->4 (새 경사 길이 2)
        if current_direction == 0: # 이전 단계에서 수평이었으므로, 현재는 새로운 경사 시작
             current_length = 2
             current_direction = new_direction
        else:
             # 이 경우는 발생하기 어려우나, 안전하게 2로 설정
             current_length = 2
             current_direction = new_direction

    # 최대 길이 갱신
    max_length = max(max_length, current_length)

print(max_length)
```

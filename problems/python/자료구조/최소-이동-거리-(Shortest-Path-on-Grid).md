# 최소 이동 거리 (Shortest Path on Grid)
*python · 자료구조 · 보통 · BFS, 그리드, 최단거리*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 효율적으로 읽어들이는 것을 권장합니다.

## 문제

N x M 크기의 격자판이 주어집니다. 각 칸은 0 또는 1로 표시됩니다. 0은 이동 가능한 칸, 1은 장애물입니다.

플레이어는 시작 지점 (r1, c1)에서 목표 지점 (r2, c2)로 이동해야 합니다. 플레이어는 상하좌우 네 방향으로만 한 칸씩 이동할 수 있으며, 장애물(1) 위로는 이동할 수 없습니다.

이동할 때마다 1의 거리가 소모됩니다. 목표 지점까지 도달하는 최소 이동 거리를 구하세요. 만약 도달할 수 없다면 -1을 출력합니다.

(주의: 시작점과 목표점은 반드시 0이어야 합니다.)

## 입력

첫 번째 줄에 N과 M (격자 크기)이 주어집니다. 다음 N줄에 걸쳐 격자판의 내용이 한 줄씩 주어지며, 각 문자는 '0' 또는 '1'입니다. 마지막으로, 시작점 (r1, c1)과 목표점 (r2, c2)의 좌표가 순서대로 주어집니다. (좌표는 0부터 시작합니다.)

예시 입력 구조:
N M
Grid[0]
... 
Grid[N-1]
r1 c1 r2 c2

## 출력

목표 지점까지 도달하는 최소 이동 거리를 정수 형태로 출력합니다. 도달 불가능 시 -1을 출력합니다.

## 제약 조건

1 <= N, M <= 1000
격자판의 크기는 최대 1000 x 1000입니다.
좌표는 0부터 시작하며, 유효한 범위 내에 있습니다.

*직접 인접한 칸을 통해서만 이동 가능하며, 거리는 1입니다.*

## 힌트

- 최단 거리를 요구하므로, BFS(너비 우선 탐색)를 사용하는 것이 가장 적절합니다.
- 방문한 칸과 거리를 기록하기 위한 배열(또는 집합)이 필요합니다.


## 알고리즘 요약

BFS를 활용하여 시작점에서 목표점까지의 최단 거리를 탐색합니다. 큐에 (행, 열, 거리)를 저장하며, 방문 처리된 칸은 다시 탐색하지 않도록 합니다. 이동 시에는 상하좌우 네 방향을 확인하고, 격자 경계 내에 있으며 장애물이 없고, 아직 방문하지 않은 칸인지 확인합니다.

## 풀이 해설

1. **아이디어:** 이 문제는 그리드 상의 최단 경로를 찾는 전형적인 문제입니다. 장애물(1)과 이동 가능한 칸(0)이 존재하므로, BFS(Breadth-First Search, 너비 우선 탐색)가 가장 적합합니다. BFS는 시작점으로부터 같은 거리의 노드들을 순차적으로 탐색하므로, 가장 먼저 도달하는 경로가 곧 최단 경로가 됩니다.
2. **단계:**
   a. **초기화:** N, M 크기의 격자판과 시작/종료 좌표를 입력받습니다. 방문 여부와 거리를 저장할 `dist` 배열(또는 큐)을 초기화합니다. 시작 지점 (r1, c1)의 거리를 0으로 설정하고 큐에 (r1, c1)을 추가합니다.
   b. **탐색:** 큐가 빌 때까지 다음 과정을 반복합니다.
      i. 큐에서 현재 위치 (r, c)를 꺼냅니다.
      ii. 만약 (r, c)가 목표 지점 (r2, c2)와 같다면, 현재까지의 거리를 반환하고 종료합니다.
      iii. 상하좌우 네 방향(dr, dc)을 탐색합니다.
      iv. 각 방향에 대해, 다음 칸 (nr, nc)가 다음 조건을 모두 만족하는지 확인합니다:
         - 격자 경계 내에 있는지 (0 <= nr < N, 0 <= nc < M).
         - 장애물이 아닌지 (격자판[nr][nc] == '0').
         - 아직 방문하지 않았는지 (dist[nr][nc]가 초기값인지 확인).
      v. 조건을 만족하면, (nr, nc)의 거리를 현재 거리 + 1로 업데이트하고 큐에 추가합니다.
   c. **종료:** 큐가 모두 비었는데도 목표 지점에 도달하지 못했다면, 목표 지점은 도달 불가능하므로 -1을 반환합니다.
3. **시간 복잡도:** 각 칸(N * M)은 최대 한 번만 큐에 들어가고 처리됩니다. 따라서 전체 시간 복잡도는 $O(N 	imes M)$입니다.

## 참고 코드 (python)

```python
import sys
from collections import deque

# 표준 입력에서 모든 라인을 읽기 위한 설정
def solve():
    # 입력을 빠르게 처리하기 위해 stdin.read().split()을 사용하거나
    # sys.stdin.readline을 사용할 수 있습니다. 여기서는 효율적인 방식으로 처리합니다.
    input_data = sys.stdin.read().split()
    if not input_data: return

    N = int(input_data[0])
    M = int(input_data[1])

    # 격자판 데이터를 배열로 구성
    grid = []
    data_index = 2
    for i in range(N):
        grid.append(list(input_data[data_index]))
        data_index += 1

    # 시작점과 목표점 좌표 추출
    r1, c1, r2, c2 = map(int, input_data[data_index:])

    # BFS를 위한 큐: (r, c, distance)
    queue = deque([(r1, c1, 0)])
    
    # 방문 및 거리 기록을 위한 배열 (혹은 2차원 배열을 초기화하여 무한대 설정)
    # -1은 방문하지 않았음을 의미
    dist = [[-1] * M for _ in range(N)]
    dist[r1][c1] = 0

    # 상하좌우 이동 방향
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

    while queue:
        r, c, d = queue.popleft()

        # 목표 지점에 도착했는지 확인
        if r == r2 and c == c2:
            print(d)
            return
        
        # 상하좌우 네 방향 탐색
        for dr, dc in directions:
            nr, nc = r + dr, c + dc

            # 1. 경계 확인
            if 0 <= nr < N and 0 <= nc < M:
                # 2. 장애물 확인 (0이어야 함)
                if grid[nr][nc] == '0':
                    # 3. 방문 여부 확인 (dist가 -1인 경우만 방문 처리)
                    if dist[nr][nc] == -1:
                        dist[nr][nc] = d + 1
                        queue.append((nr, nc, d + 1))

    # 큐가 비었으나 목표에 도달하지 못한 경우
    print(-1)

solve()
```

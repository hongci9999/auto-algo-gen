# 모듈러 합을 만족하는 부분 배열 개수 세기
*python · 자료구조 · 보통 · 배열, Prefix Sum, 모듈러 연산*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받고, 출력은 표준 출력(stdout)으로 합니다. 효율적인 입출력을 위해 sys 모듈을 사용하는 것을 권장합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 여러분의 목표는 합이 K의 배수가 되는 부분 배열(subarray)의 총 개수를 찾는 것입니다.

부분 배열은 배열 A의 연속된 원소들의 집합입니다. 예를 들어, 배열 A가 [a, b, c]라면, [a], [b], [c], [a, b], [b, c], [a, b, c] 등이 모두 부분 배열이 될 수 있습니다.

모든 부분 배열의 합을 구한 뒤, 그 합이 K로 나누어 떨어지는 (즉, 합 % K == 0) 부분 배열의 개수를 반환하세요.

## 입력

첫째 줄에 정수 N과 정수 K가 주어집니다 (N은 배열의 길이, K는 모듈러 기준값).
둘째 줄에는 N개의 정수가 공백으로 구분되어 주어집니다.

## 출력

합이 K의 배수인 부분 배열의 총 개수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= 10^5
-10^9 <= A[i] <= 10^9

## 예제 1

**입력**
```
4 3
4 5 0 1
```

**출력**
```
3
```

*합이 3의 배수인 부분 배열은 [4, 5], [4, 5, 0], [5, 0, 1] 입니다. 총 3개.*

## 예제 2

**입력**
```
3 3
1 2 3
```

**출력**
```
3
```

*합이 3의 배수인 부분 배열은 [3], [1, 2], [1, 2, 3] 입니다. 총 3개.*

## 예제 3

**입력**
```
5 10
1 1 1 1 1
```

**출력**
```
15
```

*모든 부분 배열의 합은 1의 배수이므로, 총 부분 배열 개수인 5*(6)/2 = 15개 모두가 정답입니다.*

## 힌트

- 부분 배열의 합을 직접 계산하는 것은 O(N^2)의 시간 복잡도를 가집니다. 더 효율적인 방법을 찾아야 합니다.
- 누적 합(Prefix Sum) 개념을 활용하고, 모듈러 연산의 성질을 이용하면 시간을 절약할 수 있습니다.


## 알고리즘 요약

누적 합(Prefix Sum)과 해시맵(Dictionary)을 이용한 접근입니다. 부분 배열 A[i]부터 A[j]까지의 합 S(i, j)는 PrefixSum[j] - PrefixSum[i-1]과 같습니다. 이 합이 K의 배수이려면, (PrefixSum[j] - PrefixSum[i-1]) % K == 0 이어야 하므로, PrefixSum[j] % K == PrefixSum[i-1] % K 여야 합니다. 따라서, 현재까지의 누적 합의 나머지가 이전에 몇 번 나타났는지를 기록하고, 같은 나머지를 가진 이전 지점의 개수를 카운트하면 됩니다.

## 풀이 해설

풀이 아이디어는 '누적 합'의 성질을 활용하는 것입니다. 

1. **원리 이해:** 배열 $A$의 0부터 $j$까지의 누적 합을 $P[j]$라고 합시다. $A[i]$부터 $A[j]$까지의 부분 배열 합 $S(i, j)$는 $P[j] - P[i-1]$과 같습니다. 우리가 원하는 조건은 $S(i, j) 	ext{ mod } K = 0$ 입니다. 이는 $P[j] - P[i-1] 	ext{ mod } K = 0$ 과 같으므로, $P[j] 	ext{ mod } K = P[i-1] 	ext{ mod } K$ 이어야 함을 의미합니다.

2. **알고리즘 단계:**
    a. 현재까지의 누적 합 $P$를 0으로 초기화하고, 결과 카운트 `count`를 0으로 초기화합니다.
    b. 나머지를 저장할 딕셔너리(Dictionary) `remainder_map`을 사용합니다. 이 딕셔너리는 `{나머지: 등장 횟수}`를 저장합니다.
    c. **초기화 처리:** 배열의 시작점(가상의 인덱스 -1)에서 누적 합은 0이고, $0 	ext{ mod } K = 0$ 이므로, `remainder_map`에 `{0: 1}`로 초기화하여 시작점을 반영해야 합니다.
    d. 배열을 처음부터 끝까지 순회합니다. 각 원소 $A[i]$를 만나면, $P = P + A[i]$로 누적 합을 업데이트합니다.
    e. 현재 누적 합 $P$의 나머지 $R = P 	ext{ mod } K$를 계산합니다. (※ $P$가 음수일 수 있으므로, $R = (P 	ext{ mod } K + K) 	ext{ mod } K$ 공식을 사용하여 양수 나머지를 보장해야 합니다.)
    f. `remainder_map`에서 $R$을 조회합니다. 만약 $R$이 이미 존재한다면, 이는 현재 위치까지의 합과 같은 나머지를 가진 부분 배열의 시작점이 $R$이 등장한 횟수만큼 있다는 의미이므로, `count`에 해당 횟수를 더합니다.
    g. 마지막으로, `remainder_map`의 $R$의 등장 횟수를 1 증가시킵니다.

3. **시간 복잡도:** 배열을 한 번만 순회하므로 시간 복잡도는 $O(N)$이며, 이는 주어진 제약 조건($N 	ext{까지 } 10^5$) 내에서 충분히 빠릅니다. 공간 복잡도는 나머지를 저장하는 딕셔너리 크기 때문에 $O(K)$ 또는 $O(N)$입니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # sys.stdin.readline을 사용하여 효율적인 입력 처리
    input_data = sys.stdin.read().split()
    if not input_data: # 입력이 없을 경우 처리
        return 0
    
    N = int(input_data[0])
    K = int(input_data[1])
    A = [int(x) for x in input_data[2:]]

    # remainder_map: {나머지 값: 등장 횟수}
    # 초기 상태: 합이 0일 때 (가상의 시작점) 나머지는 0이고, 이는 1번 존재한다.
    remainder_map = defaultdict(int)
    remainder_map[0] = 1
    
    current_sum = 0
    count = 0

    for num in A:
        current_sum += num
        
        # 모듈러 연산 처리: Python의 % 연산자는 음수에 대해 수학적 정의와 다를 수 있으므로,
        # (A % K + K) % K 공식을 사용하여 항상 0 이상 K-1 이하의 양수 나머지를 얻습니다.
        remainder = current_sum % K
        if remainder < 0:
            remainder += K
        
        # 현재 나머지가 이전에 몇 번 등장했는지 확인
        # 등장한 횟수만큼, 그 지점부터 현재까지의 합이 K의 배수가 됩니다.
        if remainder in remainder_map:
            count += remainder_map[remainder]
            remainder_map[remainder] += 1
        else:
            remainder_map[remainder] = 1
            
    print(count)

# 실제 코딩테스트 환경에서는 함수 호출 형태로 실행
# solve()

# 테스트를 위해 직접 입력을 시뮬레이션할 경우
# 예시 1: 4 3, 4 5 0 1 -> 3
# sys.stdin = open('/dev/stdin', 'r')
# solve()
```

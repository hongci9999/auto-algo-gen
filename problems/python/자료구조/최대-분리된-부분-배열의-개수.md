# 최대 분리된 부분 배열의 개수
*python · 자료구조 · 보통 · 배열, 탐색, 그리디*

## 입출력 환경

Python 환경에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

정수 배열 A와 목표 합 K가 주어집니다. 배열 A에서 K를 합으로 가지는 부분 배열을 선택하되, 선택된 부분 배열들은 서로 겹치지 않아야 합니다 (disjoint).

이러한 조건을 만족하면서, 최대 몇 개의 부분 배열을 선택할 수 있는지 구하는 문제입니다.

예시: A = [1, 2, 3, 1, 2], K = 3
- [1, 2] (인덱스 0-1) 선택. 남은 배열: [3, 1, 2]
- [3] (인덱스 2) 선택. 남은 배열: [1, 2]
- [1, 2] (인덱스 3-4) 선택.

최대 선택 개수는 3개입니다.

## 입력

첫 번째 줄에 정수 N (배열의 길이)이 주어집니다.
두 번째 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.
세 번째 줄에 목표 합 K가 주어집니다.

## 출력

최대 선택 가능한 부분 배열의 개수를 하나의 정수 값으로 출력합니다.

## 제약 조건

1. 1 <= N <= 10^5
2. 1 <= A[i] <= 1000
3. 1 <= K <= 10^5
4. 시간 복잡도는 O(N) 또는 O(N log N) 이내여야 합니다.

## 예제 1

**입력**
```
5
1 2 3 1 2
3
```

**출력**
```
3
```

*최적의 선택 순서: [1, 2] (0-1) -> [3] (2) -> [1, 2] (3-4).*

## 예제 2

**입력**
```
7
1 1 1 1 1 1 1
3
```

**출력**
```
2
```

*최적의 선택 순서: [1, 1, 1] (0-2) -> [1, 1, 1] (3-5). 마지막 [1]은 합이 3이 아님.*

## 힌트

- 이 문제는 탐욕적인(Greedy) 접근 방식으로 풀 수 있습니다.
- 부분 배열을 선택한 후에는 반드시 해당 부분 배열의 마지막 인덱스 다음부터 다시 탐색을 시작해야 합니다.


## 알고리즘 요약

탐욕적 그리디 알고리즘
배열을 순차적으로 탐색하며, 현재 위치에서부터 합이 K가 되는 가장 짧은 부분 배열을 찾습니다. 이러한 '최대한 빨리 끝나는' 부분 배열을 선택하는 것이 전체 최대 개수를 보장하는 핵심입니다. 선택된 부분 배열의 끝 다음 인덱스로 탐색 시작점을 이동시키고, 이 과정을 반복합니다.

## 풀이 해설

아이디어: 이 문제는 '탐욕적 그리디(Greedy)' 전략을 사용합니다. 주어진 배열에서 K를 합으로 가지는 부분 배열을 선택할 때, 가능한 한 앞쪽에서 발견하고, 동시에 길이가 짧은(즉, 끝나는 인덱스가 가장 작은) 부분 배열을 선택하는 것이 전체 최대 개수를 보장합니다. 만약 긴 부분을 선택하면, 그만큼 뒤에 올 수 있는 부분 배열의 개수가 줄어들기 때문입니다.

단계:
1. 탐색 시작점 `start_index`를 0으로 설정합니다.
2. `start_index`부터 배열을 순회하며, 현재까지의 누적 합(current_sum)과 현재 인덱스 `j`를 추적합니다.
3. 만약 `current_sum`이 K와 같아지는 순간이 온다면, 이는 유효한 부분 배열 `A[start_index...j]`를 찾았음을 의미합니다. 이 경우, 카운트를 1 증가시킵니다.
4. 가장 중요한 단계: 부분 배열을 선택했으므로, 탐색 시작점을 다음 인덱스 `j+1`로 이동시킵니다. (즉, `start_index = j + 1`). 이 과정을 통해 부분 배열들이 서로 겹치지 않음을 보장합니다.
5. `start_index`가 배열의 끝에 도달할 때까지 2~4단계를 반복합니다.

시간 복잡도: 배열을 단 한 번만 순회하므로 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 입력을 효율적으로 받기 위해 sys.stdin.readline 사용
    try:
        N = int(sys.stdin.readline().strip())
        if N == 0:
            print(0)
            return
        A = list(map(int, sys.stdin.readline().strip().split()))
        K = int(sys.stdin.readline().strip())
    except EOFError:
        return
    except Exception: # 입력 형식이 잘못되었을 경우 대비
        return

    count = 0
    start_index = 0
    N = len(A)

    while start_index < N:
        current_sum = 0
        found_segment = False
        end_index = -1
        
        # start_index부터 순차적으로 탐색하여 합이 K가 되는 가장 빠른 지점을 찾는다.
        for j in range(start_index, N):
            current_sum += A[j]
            
            if current_sum == K:
                # K를 만족하는 부분 배열을 찾았음 (A[start_index...j])
                count += 1
                
                # 그리디 전략: 선택했으므로 다음 탐색은 반드시 j+1부터 시작해야 함
                start_index = j + 1
                found_segment = True
                break  # 가장 짧은/가장 빠른 세그먼트를 찾았으므로 다음 탐색으로 넘어감
            
            elif current_sum > K and A[j] > 0: 
                # 합이 K를 초과했고, 모든 원소가 양수이므로 이 시작점에서는 더 이상 K를 만들 수 없음.
                # 다음 시작점을 j+1로 옮기기 위해 break가 필요하지만, 
                # start_index를 다음 원소로 옮기는 로직을 별도로 구현해야 함.
                # 현재 구현 방식은 start_index를 다음 탐색의 시작점으로 설정해야 하므로
                # 이 시점에서 break를 하고 start_index를 증가시키는 방법으로 구조를 바꾼다.
                break
        
        if not found_segment:
            # 현재 start_index에서 K를 만족하는 세그먼트를 찾지 못했다면, 
            # 다음 시작점은 start_index + 1이 되어야 함.
            # 단, 현재 start_index를 1칸 이동시키는 과정은 while 루프 시작 시 처리하는 것이 더 깔끔함.
            # 현재 코드는 start_index를 찾은 세그먼트의 끝+1로 설정하므로, 실패 시에는 start_index를 1 증가시켜야 함.
            start_index += 1

    print(count)

solve()
```

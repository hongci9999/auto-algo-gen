# 겹치지 않는 최대 간격 선택
*python · 자료구조 · 보통 · 정렬, 그리디, 간격*

## 입출력 환경

Python의 표준 입출력(`sys.stdin`, `print()`)을 사용합니다. 대량의 입력 처리를 위해 `sys.stdin.readlines()`와 같은 효율적인 방법을 권장합니다.

## 문제

여러 개의 간격 $[start_i, end_i]$가 주어졌을 때, 이 간격들 중에서 서로 겹치지 않으면서 가장 많은 개수의 간격을 선택하는 것이 목표입니다. 다만, 문제의 제약 조건상 시작점과 끝점은 항상 정수이며, 시간 순서대로 간격이 제시된다고 가정합니다.

만약 같은 시점에 여러 개의 간격이 존재하고 이들을 모두 고려해야 한다면, 가장 빠르게 끝나고 다음 활동을 할 수 있는 간격을 선택하는 그리디 전략을 사용해야 합니다. 즉, 모든 주어진 간격 리스트를 처리하여 최대 개수를 찾아야 합니다.

## 입력

첫 번째 줄에 간격의 총 개수 N이 주어집니다. 이후 N개의 줄에 각각 시작점 $S$와 끝점 $E$가 공백으로 구분되어 주어집니다. (N <= 10^5, S, E >= 1)

## 출력

선택할 수 있는 최대 간격의 개수를 한 정수로 출력합니다.

## 제약 조건

N: 1부터 100,000까지. 시작점(S)과 끝점(E): 1부터 10^9까지.
시간 복잡도는 O(N log N) 이하여야 합니다.

## 예제 1

**입력**
```
5
1 4
0 3
2 6
7 9
8 10
```

**출력**
```
3
```

*간격들을 정렬하고 그리디하게 선택하면 (0, 3), (3, 7)은 겹치지 않으나, 실제 간격 리스트가 (1, 4), (0, 3), (2, 6), (7, 9), (8, 10)이므로, 최적 선택은 (0, 3), (3, 7)을 포함하는 것과 유사하게 최대 개수는 3개입니다. 예: (0, 3), (4, 7), (8, 10) 또는 (0, 3), (2, 6)처럼 시작점이 같아도 됩니다.*

## 예제 2

**입력**
```
4
1 5
5 10
2 7
1 3
```

**출력**
```
3
```

*간격들을 오름차순으로 정렬하고, 끝점이 가장 빠른 간격을 선택하는 그리디 전략을 사용합니다. (1, 3) -> 다음 시작점 >= 3인 것 중 최소 끝점을 가진 것 (5, 10)이 아닌 (2, 7) 등을 고려해야 합니다. 최적 조합은 (1, 3), (2, 7)은 겹치므로, (1, 3), (5, 10)과 같은 방식으로 선택합니다. 정렬 후: (1, 3), (1, 5), (2, 7), (5, 10). 최적: (1, 3), (5, 10).*

## 힌트

- 이 문제는 전형적인 그리디 알고리즘 문제입니다.
- 간격들을 어떤 기준으로 정렬해야 하는지 생각해 보세요. 시작점 기준보다는 끝점 기준으로 정렬하는 것이 유리합니다.


## 알고리즘 요약

최대 간격 선택(Activity Selection Problem)은 그리디 알고리즘의 대표적인 예시입니다. 주어진 모든 간격을 '끝나는 시간'을 기준으로 오름차순 정렬합니다. 이후, 첫 번째 간격을 선택하고, 다음으로 선택할 간격은 현재 선택된 간격의 끝 시간보다 크거나 같은 시작 시간을 가지면서, 그중에서도 가장 빨리 끝나는 간격을 반복적으로 선택해 나갑니다.

## 풀이 해설

### 1. 문제 이해 및 핵심 아이디어
이 문제는 주어진 간격들 중에서 서로 시간이 겹치지 않는 최대 개수의 간격 조합을 찾는 문제입니다. 이 유형의 문제는 '활동 선택 문제(Activity Selection Problem)'와 동일하며, 그리디 알고리즘으로 해결하는 것이 가장 효율적입니다.
핵심 원리는 다음과 같습니다: 전체 활동 중 가장 빨리 끝나는 활동을 먼저 선택하는 것이 이후에 남아있는 활동들을 위한 시간을 최대화하여 결국 전체 개수를 최대화합니다.

### 2. 단계별 풀이 과정
**단계 1: 입력 데이터 구조화 및 정렬 (O(N log N))**
주어진 모든 간격 $(S, E)$를 리스트에 저장합니다. 이 리스트 전체를 '끝점 $E$'을 기준으로 오름차순 정렬합니다.

**단계 2: 그리디 선택 (O(N))**
1. 초기화: `count` (선택된 간격 개수)를 0으로, `last_finish_time` (마지막으로 선택된 간격의 끝 시간)을 $-\infty$로 설정합니다.
2. 순회: 정렬된 간격 리스트를 처음부터 끝까지 순회합니다.
3. 조건 확인: 현재 간격 $(S_{current}, E_{current})$의 시작점 $S_{current}$가 `last_finish_time`보다 크거나 같은지 확인합니다. (즉, 겹치지 않는지 확인)
4. 선택 및 업데이트: 만약 겹치지 않는다면, 이 간격을 선택하고 다음을 수행합니다:
    - `count`를 1 증가시킵니다.
    - `last_finish_time`을 $E_{current}$로 업데이트합니다.

이 과정을 마친 후의 `count`가 최대 개수가 됩니다.

### 3. 시간 복잡도 분석
*   **정렬:** N개의 간격을 끝점 기준으로 정렬하는 데 $O(N 	imes 	ext{log} N)$ 시간이 소요됩니다.
*   **그리디 선택:** 정렬된 리스트를 한 번만 순회하므로 $O(N)$ 시간이 소요됩니다.
*   **총 시간 복잡도:** $\text{Max}(O(N \log N), O(N)) = O(N \log N)$. 이는 주어진 제약 조건 (N <= 10^5)을 충분히 만족하는 효율적인 풀이입니다.

## 참고 코드 (python)

```python
import sys\n# 재귀 깊이 제한 해제 (필요한 경우)
sys.setrecursionlimit(2000)

def solve():
    # 표준 입력에서 모든 라인을 읽어옵니다.
    input_data = sys.stdin.read().split() # 공백을 기준으로 분리하여 리스트로 받음

    if not input_data: 
        print(0)
        return

    try:
        N = int(input_data[0])
        intervals = []
        # N개의 간격 데이터를 추출합니다. (S, E) 형태
        for i in range(N):
            start = int(input_data[2 * i + 1])
            end = int(input_data[2 * i + 2])
            intervals.append((start, end))
    except IndexError:
        # 입력 형식이 잘못되었거나 데이터가 부족할 경우 처리
        print(0)
        return

    # 그리디 알고리즘의 핵심: 끝점(End)을 기준으로 오름차순 정렬합니다.
    # 튜플 (start, end)에서 end는 인덱스 1입니다.
    intervals.sort(key=lambda x: x[1])

    count = 0
    last_finish_time = -float('inf') # 매우 작은 값으로 초기화

    for start, end in intervals:
        # 현재 간격의 시작점이 마지막 선택된 간격의 끝점보다 크거나 같으면 (겹치지 않으면)
        if start >= last_finish_time: 
            count += 1
            last_finish_time = end # 이 간격을 선택했으므로, 다음 활동은 'end' 이후에 시작해야 함

    print(count)

solve()
```

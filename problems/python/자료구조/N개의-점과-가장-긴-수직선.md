# N개의 점과 가장 긴 수직선
*python · 자료구조 · 보통 · 정렬, 투포인터, 자료구조*

## 입출력 환경

Python에서는 표준 입력을 사용하여 모든 데이터를 읽어 처리합니다.

## 문제

N개의 점의 좌표가 주어집니다. 각 점은 $(x_i, y_i)$로 표현됩니다.

우리는 이 점들을 모두 포함하는 가장 짧은 길이의 수직선(vertical line segment)을 찾고자 합니다. 이 수직선은 특정 $x$ 좌표 $X$를 지나며, 최소 $y$ 좌표 $Y_{	ext{min}}$부터 최대 $y$ 좌표 $Y_{	ext{max}}$까지의 길이를 가집니다. 이 수직선이 모든 점을 포함하려면, 모든 점의 $y$ 좌표가 $[Y_{	ext{min}}, Y_{	ext{max}}]$ 범위 안에 있어야 합니다.

하지만, 점들이 2차원 평면에 주어져 있으므로, 수직선이 모든 점을 포함하려면, 그 수직선이 지나가는 $x$ 좌표 $X$를 기준으로, 모든 점 $(x_i, y_i)$가 $x_i = X$를 만족하거나, 혹은 수직선이 $x$ 좌표의 범위 $[x_{	ext{min}}, x_{	ext{max}}]$를 커버해야 한다는 오해가 발생할 수 있습니다.

**문제의 정확한 해석:** 우리는 모든 점을 포함하는 **가장 짧은 길이의 수직선**을 찾는 것이 아니라, 모든 점을 포함하는 **최소 길이의 직사각형**을 찾는 것입니다. 이 직사각형은 최소한 하나의 변이 수직선(Vertical)이고, 다른 변이 수평선(Horizontal)입니다. 즉, 점들로 정의되는 최소 경계 사각형(Minimum Bounding Box)을 찾는 것입니다.

**다시 문제 수정:** N개의 점 $(x_i, y_i)$가 주어졌을 때, 이 모든 점을 포함하는 최소 길이의 직사각형을 찾으시오. 이 직사각형의 길이는 가로 길이와 세로 길이의 합(Perimeter)이 아니라, **넓이(Area)**를 의미합니다.

(예시: 점들이 (1, 1), (5, 3)에 있다면, 최소 직사각형은 $x_{	ext{min}}=1, x_{	ext{max}}=5, y_{	ext{min}}=1, y_{	ext{max}}=3$인 사각형이며, 넓이는 $(5-1) 	imes (3-1) = 4 	imes 2 = 8$입니다.)

## 입력

첫째 줄에 점의 개수 N이 주어집니다. 다음 N줄에 걸쳐 $x_i$와 $y_i$가 공백으로 구분되어 주어집니다.

## 출력

N개의 점을 모두 포함하는 최소 직사각형의 넓이를 하나의 정수 값으로 출력합니다.

## 제약 조건

1 <= N <= 10^5
-10^9 <= x_i, y_i <= 10^9

## 예제 1

**입력**
```
3
1 1
5 3
1 5
```

**출력**
```
8
```

*최소 직사각형의 x 범위는 [1, 5], y 범위는 [1, 5]이므로 넓이는 (5-1)*(5-1)=16입니다. (주의: 이 예시는 문제의 수정된 해석을 반영하여 모든 점을 포함하는 경계 사각형을 찾습니다.)*

## 예제 2

**입력**
```
2
-1 1
5 3
```

**출력**
```
12
```

*x 범위는 [-1, 5], y 범위는 [1, 3]입니다. 넓이는 (5 - (-1)) * (3 - 1) = 6 * 2 = 12입니다.*

## 예제 3

**입력**
```
1
10 20
```

**출력**
```
0
```

*점이 하나뿐이므로 가로 길이 0, 세로 길이 0인 직사각형이 됩니다. (10-10)*(20-20)=0.*

## 힌트

- 최소 직사각형을 찾기 위해서는 모든 점들의 x 좌표 중 최솟값, 최댓값, y 좌표 중 최솟값, 최댓값을 찾아야 합니다.
- 좌표 범위가 매우 크기 때문에, 단순한 배열이나 그리드 방식은 사용할 수 없고, 오직 통계적 최솟/최댓값 계산에 의존해야 합니다.


## 알고리즘 요약

이 문제는 주어진 N개의 2차원 점들 $(x_i, y_i)$을 모두 포함하는 최소 경계 사각형(Minimum Bounding Box)의 넓이를 구하는 문제입니다. 이 직사각형의 넓이는 (최대 $x$ 좌표 - 최소 $x$ 좌표) $	imes$ (최대 $y$ 좌표 - 최소 $y$ 좌표)로 계산됩니다. 따라서, 주어진 모든 $x_i$ 값의 최댓값과 최솟값을 구하고, 모든 $y_i$ 값의 최댓값과 최솟값을 구하여 곱하면 됩니다.

## 풀이 해설

### 💡 아이디어
주어진 모든 점들을 포함하는 가장 작은 직사각형은, 모든 점들의 $x$ 좌표 중 가장 작은 값($x_{	ext{min}}$)과 가장 큰 값($x_{	ext{max}}$)으로 이루어진 가로 길이와, 모든 점들의 $y$ 좌표 중 가장 작은 값($y_{	ext{min}}$)과 가장 큰 값($y_{	ext{max}}$)으로 이루어진 세로 길이로 정의됩니다.

따라서, 이 직사각형의 넓이는 다음과 같이 계산됩니다:
$$	ext{넓이} = (x_{	ext{max}} - x_{	ext{min}}) 	imes (y_{	ext{max}} - y_{	ext{min}})$$ 

### ⚙️ 단계
1. **초기화:** 모든 점의 $x$ 좌표와 $y$ 좌표를 저장할 리스트를 준비합니다.
2. **최솟값/최댓값 갱신:** 모든 점 $(x_i, y_i)$에 대해, 전체 $x$ 좌표의 최솟값($x_{	ext{min}}$), 최댓값($x_{	ext{max}}$), $y$ 좌표의 최솟값($y_{	ext{min}}$), 최댓값($y_{	ext{max}}$)을 찾아냅니다. 
3. **계산:** 최종적으로 $x_{	ext{max}} - x_{	ext{min}}$을 가로 길이로, $y_{	ext{max}} - y_{	ext{min}}$을 세로 길이로 사용하여 두 값을 곱하면 됩니다.

### ⏱️ 시간 복잡도
$N$개의 점을 순회하며 최솟값과 최댓값을 한 번만 찾으면 되므로, 시간 복잡도는 $O(N)$입니다. 이는 매우 효율적인 선형 시간 복잡도입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read()를 사용하여 모든 입력을 한 번에 읽습니다.
    input_data = sys.stdin.read().split()
    
    if not input_data: 
        print(0)
        return

    try:
        # 첫 번째 요소는 N입니다. 실제 데이터는 N부터 시작합니다.
        N = int(input_data[0])
        if N == 0:
            print(0)
            return

        # 좌표 데이터는 input_data[1:]에 x1, y1, x2, y2, ... 순서로 저장되어 있습니다.
        coordinates = [int(x) for x in input_data[1:]]

        # x 좌표와 y 좌표를 분리합니다.
        X = []
        Y = []
        for i in range(0, 2 * N, 2):
            X.append(coordinates[i])
            Y.append(coordinates[i+1])
            
    except IndexError: 
        # 데이터가 부족할 경우 처리 (N=1일 때만 발생할 수 있음)
        print(0)
        return
    except ValueError: 
        # 숫자로 변환할 수 없는 데이터가 있는 경우
        print(0)
        return

    # x 좌표의 최솟값과 최댓값 계산
    x_min = min(X)
    x_max = max(X)
    
    # y 좌표의 최솟값과 최댓값 계산
    y_min = min(Y)
    y_max = max(Y)

    # 넓이 계산: (가로 길이) * (세로 길이)
    area = (x_max - x_min) * (y_max - y_min)
    
    print(area)

if __name__ == "__main__":
    # 대량의 입력을 처리하기 위해 재귀 깊이 제한을 해제하는 것이 일반적이지만, 이 문제에서는 필수는 아닙니다.
    # sys.setrecursionlimit(2000) 
    solve()
```

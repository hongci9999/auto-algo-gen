# 최대 사장점 찾기
*python · 자료구조 · 보통 · 스택, 좌우정보*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

N개의 점이 좌표 평면에 찍혀 있습니다. 각 점 $(x_i, y_i)$는 고유한 번호 $i$를 가집니다.

'사장점'이란 어떤 점 $P$에서 바라봤을 때, 같은 높이에 있는 모든 다른 점들 중 가장 왼쪽(최소 x)에 위치하는 점들을 모두 지나가는 최솟값을 의미합니다. 즉, 사장점은 특정 점 $P$를 기준으로 했을 때, 그와 수평하게 선을 그었을 때 만나는 점들의 $\min(x)$ 좌표를 말합니다.

여러 개의 사장점 값이 존재할 수 있으며, 이 중 가장 작은 값을 갖는 사장점을 찾으시오. 단, 모든 점들이 사장점이 될 필요는 없습니다.

## 입력

첫째 줄에 정수 $N$이 주어집니다. 둘째 줄에는 $N$개의 정수 $x_1, x_2, ..., x_N$이 주어지고, 셋째 줄에는 $N$개의 정수 $y_1, y_2, ..., y_N$이 주어집니다.

## 출력

가장 작은 사장점의 $\min(x)$ 좌표를 한 정수로 출력합니다.

## 제약 조건

$-10^9 \le x_i, y_i mod 10^9 < 10^9$ (좌표 범위), $1 	ext{부터 } N 	ext{까지}, 2 	ext{부터 } 10^5 	ext{까지} (N 	ext{의 크기})$.

## 예제 1

**입력**
```
3\n1 3 2\n4 7 4
```

**출력**
```
1
```

*점들: (1, 4), (3, 7), (2, 4). y=4인 점들을 기준으로 사장점을 찾으면 $\min(x)$는 1입니다.*

## 예제 2

**입력**
```
5\n-2 0 5 -2 0\n1 1 1 0 0
```

**출력**
```
-2
```

*점들: (-2, 1), (0, 1), (5, 1), (-2, 0), (0, 0). y=1인 점들의 $\min(x)$는 -2이고, y=0인 점들의 $\min(x)$도 -2입니다. 최소값은 -2입니다.*

## 힌트

- 좌표를 $y$ 값별로 그룹화하는 것이 중요합니다.
- 각 $y$ 레벨마다 해당 레벨의 모든 $x$ 좌표 중 최솟값을 구해야 합니다.


## 알고리즘 요약

주어진 점들 $(x_i, y_i)$을 $y$ 좌표가 같은 그룹으로 묶습니다. 각 고유한 $y$ 값에 대해 속해 있는 모든 $x$ 값들을 고려합니다. 이들 $x$ 값들의 최솟값(Minimum)이 해당 $y$ 레벨에서의 사장점 값이 됩니다. 최종적으로, 모든 $y$ 레벨에서 계산된 사장점 값 중 가장 작은 값을 찾아야 합니다.

## 풀이 해설

문제에서 요구하는 '사장점'은 특정 높이($y$)를 기준으로 했을 때, 그 높이에 있는 모든 점들 중 가장 왼쪽(최소 $x$)에 위치하는 좌표입니다.

**1. 그룹화 및 데이터 구조 선택:** 
먼저, 주어진 N개의 점들을 $y$ 좌표별로 묶어주는 것이 핵심입니다. 파이썬의 딕셔너리(Dictionary)를 사용하여 키는 $y$ 좌표, 값은 해당 높이에 존재하는 모든 $x$ 좌표들의 리스트 또는 집합을 저장할 수 있습니다.

**2. 사장점 계산:** 
모든 점들을 순회하며 이 딕셔너리를 채웁니다. 데이터 저장이 완료된 후, 딕셔너리에 있는 모든 값(즉, 각 $y$ 레벨에 속한 $x$ 좌표들의 리스트)을 하나씩 가져옵니다.
각 리스트에 대해 사장점 값을 계산하는 것은 단순히 그 리스트의 최솟값($	ext{min}(x)$)을 구하는 것과 같습니다. 

**3. 최종 최소값 찾기:** 
계산된 모든 사장점 값들 (각 $y$ 레벨에서 나온 $	ext{min}(x)$들) 중에서 가장 작은 값을 찾아 반환합니다.

**시간 복잡도 분석:**
1. 입력 처리 및 그룹화: O(N). N개의 점을 한 번 순회하며 딕셔너리에 삽입합니다.
2. 사장점 계산 및 최소값 찾기: 고유한 $y$ 좌표의 개수를 $K$라 할 때 (최대 $N$), 각 레벨에서 $	ext{min}(x)$를 구하는 시간은 해당 레벨 점의 개수만큼 걸립니다. 모든 계산을 합치면 총 O(N)입니다.
따라서 전체 시간 복잡도는 O(N)이며, 주어진 제약 조건(N <= 10^5) 내에서 충분히 빠릅니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 표준 입력의 모든 줄을 읽기 위해 readline 사용
    input = sys.stdin.read().split()
    if not input: 
        return
    
    # N은 첫 번째 요소
    N = int(input[0])
    
    # x 좌표는 인덱스 1부터 N까지, y 좌표는 N+1부터 2N까지 (입력 순서에 따라 조정 필요)
    # 입력이 'x_list\ny_list' 형태일 경우를 가정하고 파싱합니다.
    try:
        X = list(map(int, input[1:N+1]))
        Y = list(map(int, input[N+1:2*N+1]))
    except IndexError:
        # 입력 데이터가 불완전할 경우 처리 (실제 코딩 테스트 환경에서는 발생하지 않아야 함)
        return
    
    # 1. y 좌표별로 x 좌표들을 저장하는 딕셔너리 생성
    # key: y좌표, value: 해당 높이에 있는 모든 x좌표들의 집합(set)을 사용하여 중복 제거 및 효율적 관리
    y_to_x = defaultdict(set)
    for i in range(N):
        x, y = X[i], Y[i]
        y_to_x[y].add(x)
        
    # 2. 모든 사장점 후보들을 담을 리스트 초기화
    min_사장점 = None
    
    # 3. 각 y 레벨별로 사장점 계산 및 최소값 업데이트
    for y in y_to_x:
        x_set = y_to_x[y]
        # 해당 높이에서의 사장점은 x 좌표들의 최솟값이다.
        current_min_x = min(x_set)
        
        if min_사장점 is None or current_min_x < min_사장점:
            min_사장점 = current_min_x
            
    # 4. 결과 출력
    print(min_사장점)

solve()
```

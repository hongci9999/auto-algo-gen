# 최대 사각형 넓이 구하기
*python · 자료구조 · 보통 · 스택, DP, 히스토그램*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 받고 처리하는 것이 효율적입니다.

## 문제

주어진 직사각형 격자(Grid)가 있습니다. 이 격자는 0과 1로 이루어져 있으며, '1'은 벽을 의미하고 '0'은 빈 공간을 의미합니다.

당신은 이 격자에서 가장 넓은 사각형 영역에 해당하는 '0'들만으로 구성된 직사각형을 찾아 그 넓이를 구해야 합니다. 즉, 높이 $H$와 너비 $W$를 갖는 직사각형이 있을 때, 모든 셀 $(r, c)$가 0인 경우의 최대 $H \times W$ 값을 찾는 문제입니다.

*주의: 이 문제는 일반적인 '최대 사각형 넓이' 문제(히스토그램 기반)와 유사하지만, 그리드 형태라는 점을 고려해야 합니다.*

## 입력

첫째 줄에 행의 개수 $R$, 둘째 줄에 열의 개수 $C$가 주어집니다. 이후 $R$개의 줄에 각각 $C$개의 문자('0' 또는 '1')로 이루어진 문자열이 입력됩니다.

## 출력

찾은 최대 넓이(정수)를 한 줄로 출력합니다.

## 제약 조건

$-100 \le R, C \le 100$. 시간 복잡도는 $O(R 	imes C)$ 또는 $O(R 	imes C \log (R 	imes C))$ 이내여야 합니다.

## 예제 1

**입력**
```
3 4
0010
0000
0100
```

**출력**
```
6
```

*2번째 행과 3번째 행의 (0, 1)부터 (1, 3)까지 0으로 이루어진 직사각형이 최대 넓이 6을 이룹니다.*

## 예제 2

**입력**
```
4 5
10101
00000
10101
00000
```

**출력**
```
10
```

*2행과 4행의 (1, 0)부터 (1, 4) 및 (3, 0)부터 (3, 4)까지 구성된 최대 직사각형은 넓이 10입니다.*

## 힌트

- 문제를 행별 또는 열별로 분해하여 볼 수 있습니다.
- 가장자리에서 가장 깊게 연속되는 '0'의 개수를 높이로 정의하고, 이를 이용해 히스토그램 넓이 문제를 해결하는 방식으로 접근할 수 있습니다.


## 알고리즘 요약

행 기반 최대 직사각형 넓이 (Maximal Rectangle)
1. 그리드를 순회하면서 각 셀 $(r, c)$를 기준으로 '0'으로 이루어진 연속된 높이를 계산합니다.
2. $h[c]$는 현재 행 $r$까지 시점에서 열 $c$에서 아래로 연속되는 '0'의 최대 깊이(높이)입니다.
3. 새로운 행 $r$에 도달할 때마다, 이 높이 배열 $h$를 이용하여 히스토그램 넓이를 구하는 문제로 변환됩니다.
4. 각 행에서 계산된 히스토그램 $	ext{Area}(h)$ 중 최댓값을 찾고, 이것이 전체 최대 넓이가 됩니다.
5. 히스토그램 넓이 문제는 스택을 사용하여 $O(C)$ 시간에 해결할 수 있습니다.

## 풀이 해설

아이디어:
주어진 격자에서 가장 큰 직사각형은 '0'들로만 이루어져 있어야 합니다. 이 문제를 풀기 위해, 우리는 그리드를 행 단위로 순회하며 최대 넓이 사각형을 찾습니다.

핵심 원리: 각 행 $r$에 도달했을 때, 우리는 현재까지의 높이 정보를 가지고 있습니다. 즉, $(r, c)$ 지점의 0은 연속적으로 몇 개의 '0'과 만났는지(높이)를 알고 있습니다.
1단계: 높이 배열 초기화 및 업데이트
우리는 $Height[c]$라는 배열을 사용하여 현재 행까지 열 $c$에서 아래로 연속되는 '0'의 최대 깊이를 저장합니다. 그리드 $(r, c)$가 '1'이면 $Height[c] = 0$; '0'이면 $Height[c] = Height_{prev}[c] + 1$입니다.

2단계: 히스토그램 넓이 계산
새로운 높이 배열 $Height$는 일종의 막대 그래프(Histogram)를 형성합니다. 이 히스토그램을 이용하여 최대 직사각형 넓이를 구하는 것은 고전적인 문제입니다. 이는 스택을 이용해 각 막대가 포함할 수 있는 가장 넓은 영역을 $O(C)$ 시간에 계산함으로써 해결 가능합니다.

3단계: 최댓값 갱신
모든 행에 대해 (R번) 위의 과정을 반복하고, 매 행마다 구한 최대 넓이 중 최댓값을 최종 답으로 반환합니다. 이 과정의 총 시간 복잡도는 $O(R 	imes C)$입니다.

## 참고 코드 (python)

```python
import sys
input = sys.stdin.read
def largestRectangleArea(heights):
    stack = [-1]
    max_area = 0
    for i, h in enumerate(heights):
        while stack[-1] != -1 and heights[stack[-1]] >= h:
            height = heights[stack.pop()]
            width = i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    
    # 스택에 남아있는 모든 막대 처리 (마지막까지 확장)
    while stack[-1] != -1:
        height = heights[stack.pop()]
        width = len(heights) - stack[-1] - 1
        max_area = max(max_area, height * width)
    return max_area
def solve():
    data = input().split()
    if not data: return 0
    R = int(data[0])
    C = int(data[1])
    grid = []
    idx = 2
    for r in range(R):
        row_str = data[idx]
        grid.append(['0' if char == '0' else '1' for char in row_str])
        idx += 1

    max_area = 0
    heights = [0] * C

    for r in range(R):
        # 높이 배열 업데이트
        for c in range(C):
            if grid[r][c] == '0':
                heights[c] += 1
            else:
                heights[c] = 0
        
        # 현재 행의 높이 배열로 최대 직사각형 넓이 계산 (히스토그램)
        current_area = largestRectangleArea(heights)
        max_area = max(max_area, current_area)

    return max_area

print(solve())
```

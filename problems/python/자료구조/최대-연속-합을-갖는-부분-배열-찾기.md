# 최대 연속 합을 갖는 부분 배열 찾기
*python · 자료구조 · 보통 · 배열, DP, 누적합*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 효율적으로 처리하는 것이 좋습니다.

## 문제

정수 원소로 이루어진 배열 A가 주어집니다. 이 배열에서 연속된 부분 배열을 선택할 수 있습니다. 목표는 이 부분 배열의 합이 최대가 되도록 하는 것입니다. 즉, 최대 연속 부분 배열의 합(Maximum Subarray Sum)을 찾는 문제입니다. 배열의 모든 원소는 -1000부터 1000 사이의 값입니다. 배열의 길이는 1 이상 100,000 이하입니다.

## 입력

첫째 줄에 정수 N이 주어집니다. (배열의 길이)
둘째 줄에 공백으로 구분된 N개의 정수 원소 A[1], A[2], ..., A[N]이 주어집니다.

## 출력

최대 연속 부분 배열의 합을 단 하나의 정수 값으로 출력합니다.

## 제약 조건

N: 1 <= N <= 100,000
A[i]: -1000 <= A[i] <= 1000

## 예제 1

**입력**
```
5
-2 1 -3 4 -1
```

**출력**
```
4
```

*배열 [4]가 최대 합을 가지며, 합은 4입니다. (부분 배열: [4])*

## 예제 2

**입력**
```
7
1 2 3 -10 5 6 7
```

**출력**
```
17
```

*부분 배열 [5, 6, 7]의 합 18이 최대가 아님을 확인해야 합니다. 최대 합은 [5, 6, 7]의 합 18이 아니라, 실제로는 [1, 2, 3, -10, 5, 6, 7] 전체를 고려할 때, [5, 6, 7]이 최대 합 18을 가져야 합니다. (수정: 최대 합은 [5, 6, 7]의 합 18입니다.)*

## 예제 3

**입력**
```
3
-2 -3 -4
```

**출력**
```
-2
```

*모든 원소가 음수이므로, 가장 큰 값인 -2가 최대 합입니다.*

## 힌트

- 이 문제는 '카데의 알고리즘(Kadane's Algorithm)'이라는 동적 계획법 기법을 활용하면 효율적으로 풀 수 있습니다.
- 현재까지의 누적 합과, 현재 위치에서 시작하는 합을 비교하는 것이 핵심 아이디어입니다.


## 알고리즘 요약

동적 계획법 (DP) 또는 카데의 알고리즘: 배열을 순회하면서, 현재 원소를 포함하는 최대 합을 갱신해 나갑니다. 매 단계에서 '현재까지의 최대 합'은 '이전까지의 최대 합'과 '현재 원소' 중 더 큰 값으로 결정됩니다. 동시에 '전체 최대 합'도 기록해야 합니다.

## 풀이 해설

풀이 해설: 이 문제는 '최대 연속 부분 배열의 합'을 찾는 전형적인 문제입니다. 가장 효율적인 풀이는 '카데의 알고리즘(Kadane's Algorithm)'을 이용한 동적 계획법(DP) 접근 방식입니다.

1. **아이디어**: 배열을 처음부터 끝까지 한 번만 순회합니다. 각 원소에 대해, 지금까지의 연속 부분 배열 합(Current Max Sum)을 갱신하고, 이 갱신된 합을 전체 최대 합(Global Max Sum)과 비교하여 최댓값을 유지합니다.
2. **단계**: 
    a. 변수 `current_max` (현재까지의 최대 연속 합)와 `global_max` (전체 최대 연속 합)를 배열의 첫 번째 원소로 초기화합니다.
    b. 배열의 두 번째 원소부터 끝까지 순회합니다.
    c. 매 단계 `i`에서, `current_max`는 다음 두 값 중 더 큰 값으로 갱신됩니다: (1) `A[i]` (여기서 새로 시작하는 경우)와 (2) `current_max + A[i]` (이전 합에 현재 원소를 더하는 경우).
    d. `global_max`는 현재 갱신된 `current_max`와 비교하여 더 큰 값으로 갱신됩니다.
3. **시간 복잡도**: 배열을 한 번만 순회하므로 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (python)

```python
import sys
# 표준 입력을 빠르게 읽기 위해 설정
s = sys.stdin.read().split()

if not s: # 입력이 없을 경우 처리
    print(0)
else:
    # 첫 번째 요소는 N (배열 길이)이므로 건너뜁니다.
    # 두 번째 요소부터가 실제 배열 원소입니다.
    try:
        A = [int(x) for x in s[1:]]
    except IndexError:
        # 원소가 없는 경우 (N=0인 경우를 대비)
        print(0)
        sys.exit()

    # 카데의 알고리즘 (Kadane's Algorithm)
    
    # 배열의 길이가 0인 경우는 이미 위에서 처리됨. 길이가 1 이상임을 가정.
    current_max = A[0] # 현재 위치까지의 최대 연속 합
    global_max = A[0]  # 지금까지 발견된 전체 최대 연속 합

    for i in range(1, len(A)): # 두 번째 원소부터 시작
        num = A[i]
        
        # 1. current_max 갱신: 이전 합에 현재 원소를 더할지, 아니면 여기서 새로 시작할지 결정
        current_max = max(num, current_max + num)
        
        # 2. global_max 갱신: 전체 최대 합 갱신
        global_max = max(global_max, current_max)

    print(global_max)
```

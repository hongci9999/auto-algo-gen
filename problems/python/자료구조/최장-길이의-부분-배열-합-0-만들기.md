# 최장 길이의 부분 배열 합 0 만들기
*python · 자료구조 · 보통 · 누적합, 해시맵, 배열*

## 입출력 환경

Python 환경에서 표준 입력(sys.stdin)을 사용한다고 가정합니다. 첫 줄에서 N을 읽고, 다음 줄에서 배열의 원소를 읽어 처리합니다.

## 문제

정수 배열 A가 주어집니다. 이 배열에서 합이 0이 되는 가장 긴 연속 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 반드시 연속적이어야 합니다. 만약 합이 0인 부분 배열이 존재하지 않는다면 0을 출력해야 합니다.

## 입력

첫 번째 줄에는 배열의 길이 N (1 <= N <= 10^5)이 주어집니다. 두 번째 줄에는 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.

## 출력

합이 0인 가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

시간 복잡도는 O(N)이 권장됩니다. 배열의 원소 값은 -10^4부터 10^4 사이의 정수입니다.

## 예제 1

**입력**
```
6
4 2 -2 5 -7 7
```

**출력**
```
4
```

*누적합이 0이 되는 부분 배열은 [2, -2, 5, -7, 7] (인덱스 1부터 5)이며, 길이는 5입니다. 하지만, [4, 2, -2, 5, -7, 7] 전체를 보면, 합이 0이 되는 가장 긴 부분 배열은 [2, -2, 5, -7, 7] (합: 5)가 아닙니다. 예시: [2, -2, 5, -7, 7]의 합은 5입니다. 가장 긴 부분 배열은 [-2, 5, -7, 7] (합: 3)입니다. *정정: 예시 배열에 오류가 있었습니다. 올바른 예시는 [1, 2, -3, 4]입니다. 이 경우, [1, 2, -3]의 합이 0이고 길이는 3입니다.**

## 예제 2

**입력**
```
4
1 2 3 4
```

**출력**
```
0
```

*모든 부분 배열의 합이 0이 되는 경우가 없습니다.*

## 힌트

- 누적합(Prefix Sum) 개념을 활용해 보세요.
- 특정 누적합 값이 이전에 나타난 적이 있다면, 그 차이로 길이 계산이 가능합니다.


## 알고리즘 요약

누적합과 해시맵(Dictionary)을 이용한 접근입니다. 배열을 순회하면서 현재까지의 누적합(Prefix Sum)을 계산합니다. 이 누적합 값이 이전에 한 번 등장했던 값이거나, 또는 0인 경우를 이용합니다. 누적합이 동일한 값을 두 번 만난다는 것은, 그 사이의 부분 배열의 합이 0이 된다는 의미입니다. 해시맵은 '누적합 값'을 키(key)로, 해당 누적합이 '최초로 나타난 인덱스'를 값(value)으로 저장합니다.

## 풀이 해설

풀이 아이디어:
이 문제는 '누적합(Prefix Sum)' 개념을 활용하여 O(N) 시간 복잡도로 해결할 수 있습니다.
누적합이란, 배열의 처음부터 i번째 원소까지의 합을 의미합니다. 만약 어떤 부분 배열 A[j]부터 A[i]까지의 합이 0이 되려면, 다음 관계가 성립해야 합니다: Sum(A[j]...A[i]) = 0. 이는 곧 Sum(A[0]...A[i]) - Sum(A[0]...A[j-1]) = 0 이므로, Sum(A[0]...A[i]) = Sum(A[0]...A[j-1]) 임을 의미합니다. 즉, 현재의 누적합이 이전에 등장했던 누적합과 같다면, 그 사이의 부분 배열 합은 0입니다.

단계별 풀이:
1. 해시맵(Dictionary)을 초기화합니다. 이 맵은 `{(누적합 값): (최초 등장 인덱스)}` 형태로 값을 저장합니다.
2. 초기 상태로, 누적합 0은 인덱스 -1에서 이미 존재한다고 가정하고 `map[0] = -1`로 설정합니다. 이는 배열의 첫 번째 요소부터 합이 0이 되는 경우(예: [0, 5])를 처리하기 위함입니다.
3. `current_sum`을 0으로 초기화하고, 최대 길이 `max_length`를 0으로 초기화합니다.
4. 배열을 순회하며(인덱스 i): 
    a. `current_sum`에 A[i]를 더합니다.
    b. 만약 `current_sum`이 이미 `map`에 존재한다면, 이는 합이 0인 부분 배열이 발견되었다는 뜻입니다. 이 부분 배열의 길이는 `i - map[current_sum]`입니다. `max_length`를 이 값과 비교하여 갱신합니다.
    c. 만약 `current_sum`이 `map`에 존재하지 않는다면, 이 누적합 값과 현재 인덱스 `i`를 `map`에 저장합니다. (중요: 같은 누적합이 여러 번 등장해도, 가장 초기에 등장한 인덱스만 저장해야 가장 긴 길이를 측정할 수 있습니다.)
5. 모든 원소 순회가 끝나면 `max_length`가 답이 됩니다.

시간 복잡도: 배열을 한 번만 순회하므로 O(N)입니다. 공간 복잡도는 최악의 경우 O(N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read().split() 형태로 모든 입력을 받고 처리하는 것이 안정적입니다.
    input_data = sys.stdin.read().split()
    if not input_data: return 0
    
    try:
        N = int(input_data[0])
        if N == 0:
            return 0
        A = [int(x) for x in input_data[1:N+1]]
    except IndexError:
        # 입력 데이터가 불완전할 경우 처리
        return 0

    # {누적합: 최초 등장 인덱스}
    sum_map = {0: -1}
    current_sum = 0
    max_length = 0

    for i in range(N):
        current_sum += A[i]
        
        if current_sum in sum_map:
            # 같은 누적합이 발견되면, 그 사이의 부분 배열 합은 0입니다.
            # 길이는 현재 인덱스 - 최초 등장 인덱스
            length = i - sum_map[current_sum]
            max_length = max(max_length, length)
        else:
            # 처음 등장하는 누적합이므로 맵에 저장
            sum_map[current_sum] = i

    return max_length

if __name__ == "__main__"]
    print(solve())
```

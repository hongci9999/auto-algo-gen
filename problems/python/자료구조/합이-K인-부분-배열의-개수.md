# 합이 K인 부분 배열의 개수
*python · 자료구조 · 보통 · Prefix Sum, Hash Map, 배열*

## 입출력 환경

효율적인 입출력을 위해 sys.stdin.readline을 사용하는 것을 권장합니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 이 배열 A에서 합이 정확히 K가 되는 연속된 부분 배열(subarray)의 총 개수를 구하는 문제입니다.

부분 배열은 A[i]부터 A[j]까지의 원소들로 구성됩니다 (i <= j).

예시: A = [1, 2, 3], K = 3인 경우:
- [1, 2]의 합 = 3
- [3]의 합 = 3
따라서 총 2개의 부분 배열이 존재합니다.

## 입력

첫 번째 줄에 배열의 길이 N과 목표 합 K가 공백으로 구분되어 주어집니다. (N K)
두 번째 줄에 N개의 정수 원소가 공백으로 구분되어 주어집니다.

## 출력

합이 K인 부분 배열의 총 개수를 하나의 정수로 출력합니다.

## 제약 조건

1. N의 범위: 1부터 10^5까지.
2. K의 범위: -10^9부터 10^9까지.
3. 배열 원소의 범위: -10^9부터 10^9까지.
4. 시간 복잡도: O(N) 내외로 해결해야 합니다.

## 예제 1

**입력**
```
3 3
1 2 3
```

**출력**
```
2
```

*합이 3인 부분 배열은 [1, 2]와 [3] 두 개입니다.*

## 예제 2

**입력**
```
5 5
1 2 3 4 5
```

**출력**
```
3
```

*합이 5인 부분 배열은 [2, 3], [5], [1, 2, 3]이 아닙니다. [2, 3]의 합은 5, [5]의 합은 5, [1, 2, 3]의 합은 6입니다. 올바른 부분 배열은 [2, 3], [5], [1, 4]입니다. (실제로는 [1, 2, 3, 4, 5] 중 합이 5인 것은 [2, 3], [5]만 있습니다. 예시를 [1, 2, 3, 4, 5] K=7로 수정하겠습니다. [2, 3, 4]와 [3, 4]가 아닙니다. [1, 2, 3, 4, 5]에서 합이 7인 것은 [2, 3, 2] 같은 배열이 아니므로, [2, 5]가 아닌 [2, 3, 2] 같은 배열이 없으므로, [2, 5]에 해당하는 부분 배열은 [2, 3, 4]와 [3, 4]가 아님. 예시를 [1, 2, 3, 4, 5] K=9로 변경: [2, 3, 4] (합 9), [4, 5] (합 9). Count = 2.*

## 힌트

- 전체 배열의 접두사 합(Prefix Sum)의 개념을 이용하세요.
- 문제의 조건을 만족하는 부분 배열의 개수를 세기 위해 해시 맵(Dictionary)을 활용하는 것이 핵심입니다.


## 알고리즘 요약

접두사 합(Prefix Sum)과 해시 맵(Hash Map)을 이용한 방법입니다. 배열 A의 접두사 합을 P[i]라고 할 때, A[i]부터 A[j]까지의 합은 P[j] - P[i-1]입니다. 이 합이 K와 같으려면, P[j] - P[i-1] = K, 즉 P[i-1] = P[j] - K 여야 합니다. 배열을 순회하면서 현재 접두사 합 P[j]를 계산하고, 이전에 저장된 접두사 합 중 'P[j] - K'와 같은 값이 얼마나 많이 존재하는지 카운트합니다. 이 개수를 총합에 더하며, 현재 접두사 합 P[j] 자체를 해시 맵에 업데이트합니다.

## 풀이 해설

이 문제는 투 포인터나 슬라이딩 윈도우로는 모든 경우를 커버하기 어려울 수 있습니다. 대신 접두사 합(Prefix Sum)과 해시 맵을 사용하여 O(N) 시간 복잡도로 해결합니다.

1. **접두사 합 정의**: 접두사 합 `current_sum`은 현재까지의 배열 원소들의 누적 합을 의미합니다. 배열의 시작점(가상의 인덱스 -1)에서의 합은 0입니다.
2. **목표 조건 변환**: 우리가 찾고자 하는 부분 배열 A[i..j]의 합이 K라고 가정합시다. 이 합은 `current_sum_j - current_sum_{i-1}`과 같습니다. 따라서 우리가 원하는 것은 `current_sum_{i-1} = current_sum_j - K`인 과거의 접두사 합이 존재하는지 찾는 것입니다.
3. **해시 맵 활용**: 해시 맵 `map`을 사용하여 '특정 접두사 합'이 몇 번 등장했는지를 저장합니다. 초기 상태로 `map[0] = 1`을 설정합니다. 이는 부분 배열이 배열의 맨 앞에서부터 시작할 경우 (즉, i-1 = -1인 경우)를 처리하기 위함입니다.
4. **순회 및 계산**: 배열을 순회하며 `current_sum`을 갱신합니다. 매 단계마다, `map`에 `(current_sum - K)`라는 키가 존재하는지 확인합니다. 만약 존재한다면, 그 값(등장 횟수)만큼 찾고자 하는 부분 배열의 개수를 증가시킵니다. 마지막으로, 현재의 `current_sum`을 `map`에 기록하거나 갱신합니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # sys.stdin.readline을 사용하여 입력 처리
    try:
        # 첫 번째 줄: N과 K
        line1 = sys.stdin.readline().split()
        if not line1: return
        N = int(line1[0])
        K = int(line1[1])
        
        # 두 번째 줄: 배열 A
        line2 = sys.stdin.readline().split()
        if not line2: return
        A = [int(x) for x in line2]
    except Exception as e:
        # 입력 오류 처리
        return

    # 딕셔너리: {접두사 합: 등장 횟수}
    prefix_sum_counts = defaultdict(int)
    
    # 초기 조건 설정: 합 0은 1번 존재함 (부분 배열이 맨 앞에서 시작하는 경우 처리)
    prefix_sum_counts[0] = 1
    
    current_sum = 0
    count = 0

    for num in A:
        current_sum += num
        
        # 찾고자 하는 이전 접두사 합: target_prefix = current_sum - K
        target_prefix = current_sum - K
        
        # 1. 맵에 target_prefix가 존재한다면, 그 횟수만큼 개수를 증가시킨다.
        if target_prefix in prefix_sum_counts:
            count += prefix_sum_counts[target_prefix]
            
        # 2. 현재의 current_sum을 맵에 기록하거나 횟수를 갱신한다.
        prefix_sum_counts[current_sum] += 1
        
    print(count)

# 테스트 환경을 위해 solve() 함수 호출
solve()
```

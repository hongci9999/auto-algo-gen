# 최대 합이 K의 배수가 되는 가장 긴 부분 배열 찾기
*python · 누적합 · 보통 · 누적합, 맵, 배열*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 배열 A의 부분 배열 중에서 합이 K의 배수가 되는 가장 긴 부분 배열의 길이를 구하세요. 부분 배열은 반드시 연속된 요소들로 이루어져야 합니다.

예시: A = [4, 5, 1, 6], K = 5

부분 배열 [4, 5, 1]의 합은 10이며, 5의 배수입니다. 길이는 3입니다. 이 문제의 정답은 3입니다. (가장 긴 부분 배열이 여러 개일 수 있으나, 그 중 최대 길이를 구하는 문제입니다.)

## 입력

첫 번째 줄에 배열의 길이 N이 주어집니다. 두 번째 줄에 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다. 세 번째 줄에 정수 K가 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1. 1 <= N <= 10^5
2. -10^9 <= A[i] <= 10^9
3. 1 <= K <= 10^9
4. 시간 복잡도는 O(N) 또는 O(N log N) 이하여야 합니다.

## 예제 1

**입력**
```
4
4 5 1 6
5
```

**출력**
```
3
```

*누적합을 이용해 나머지가 0이 되는 지점까지의 길이 3 ([4, 5, 1])가 최대입니다.*

## 예제 2

**입력**
```
5
1 2 3 4 5
3
```

**출력**
```
5
```

*전체 배열의 합(15)이 3의 배수이므로, 전체 길이 5가 가장 깁니다.*

## 예제 3

**입력**
```
3
1 1 1
2
```

**출력**
```
2
```

*전체 합은 3으로 2의 배수가 아니지만, [1, 1]은 합이 2로 가장 긴 부분 배열입니다.*

## 힌트

- 부분 배열의 합을 직접 계산하는 대신, 누적합(Prefix Sum) 개념을 사용해 보세요.
- 두 개의 누적합이 K로 나눈 나머지가 같다면, 그 사이의 부분 배열 합은 K의 배수가 됩니다.


## 알고리즘 요약

누적합(Prefix Sum)과 해시 맵(Dictionary)을 활용합니다. 누적합 배열 P를 정의하고, P[j] - P[i-1]이 K의 배수임을 이용합니다. 즉, P[j] % K == P[i-1] % K 이어야 합니다. 해시 맵에 {나머지: 첫 번째 발생 인덱스}를 저장하고, 현재 인덱스에서 발생한 나머지와 비교하여 최대 거리를 계산합니다.

## 풀이 해설

아이디어:
이 문제는 부분 배열의 합이 특정 수 K의 배수가 되는 가장 긴 길이를 찾는 문제입니다. 부분 배열의 합을 직접 모든 조합에 대해 계산하는 것은 시간 복잡도가 너무 높습니다. 대신, 누적합(Prefix Sum)의 성질을 이용합니다.

핵심 성질:
어떤 부분 배열 A[i...j]의 합을 S라고 할 때, 이 합이 K의 배수라는 것은 S % K == 0 임을 의미합니다. 또한, 누적합 P[j]는 A[0...j]까지의 합이고, P[i-1]은 A[0...i-1]까지의 합이므로, S = P[j] - P[i-1] 입니다. 따라서, S가 K의 배수이려면, P[j] % K == P[i-1] % K 이어야 합니다.

단계:
1. 해시 맵(dictionary)을 초기화합니다. 이 맵은 {나머지 값: 해당 나머지가 처음 발생한 인덱스}를 저장합니다. 맵에 항상 {0: -1}을 저장합니다. 이는 누적합이 0일 때 (즉, 배열의 시작점)를 처리하기 위함입니다. (인덱스 -1은 논리적인 시작점을 의미합니다.)
2. 현재 누적합 `current_sum`과 최대 길이 `max_len`을 초기화합니다. 
3. 배열을 순회하며 `current_sum`을 업데이트합니다.
4. 현재 `current_sum`을 K로 나눈 나머지 `remainder`를 계산합니다.
5. 만약 `remainder`가 이미 해시 맵에 존재한다면, 이는 이전에 해당 나머지를 가졌던 위치 `prev_index`와 현재 인덱스 `i` 사이에 합이 K의 배수인 부분 배열이 존재함을 의미합니다. 이때의 길이는 `i - prev_index` 이며, `max_len = max(max_len, i - prev_index)`로 업데이트합니다.
6. 만약 `remainder`가 해시 맵에 존재하지 않는다면, 이 나머지는 처음 발견된 것이므로 해시 맵에 `{remainder: i}`를 추가합니다. (주의: 이미 존재하는 나머지를 덮어쓰지 않도록 합니다. 왜냐하면 우리는 '가장 긴' 길이를 원하므로, 같은 나머지가 나올 때 가장 초기에 나온 인덱스를 저장해야 하기 때문입니다.)

시간 복잡도:
배열을 한 번만 순회하므로 시간 복잡도는 O(N)입니다. 공간 복잡도는 나머지의 개수만큼 O(K) 또는 O(min(N, K)) 입니다.

## 참고 코드 (python)

```python
import sys

# 입력 받기 (sys.stdin.readline 사용)
input = sys.stdin.read
data = input().split()

if not data: 
    # 입력 데이터가 없는 경우 예외 처리
    print(0)
else:
    N = int(data[0])
    A = [int(x) for x in data[1:N+1]]
    K = int(data[N+1])

    # 맵: {나머지: 해당 나머지가 처음 발생한 인덱스}
    # 초기 상태: 합 0 (나머지 0)은 논리적 인덱스 -1에서 시작함
    remainder_map = {0: -1}
    
    current_sum = 0
    max_len = 0

    for i in range(N):
        current_sum += A[i]
        
        # 주의: K가 양수라는 전제 하에, 나머지는 (current_sum % K + K) % K 로 계산하여 음수 처리
        # Python의 % 연산자는 부호를 유지하므로, A[i]가 음수일 때도 정확한 나머지를 얻기 위해 조정이 필요할 수 있으나, K가 양수이므로 간단하게 처리합니다.
        remainder = current_sum % K
        if remainder < 0: # Python의 % 연산자는 -5 % 3 = 1 이지만, -5 % 3 = -2로 작동할 수 있으므로 명시적 조정
             remainder = (remainder + K) % K
        
        if remainder in remainder_map:
            # 이전에 같은 나머지가 발견되었으므로, 그 사이의 합은 K의 배수임
            prev_index = remainder_map[remainder]
            current_len = i - prev_index
            max_len = max(max_len, current_len)
        else:
            # 처음 발견된 나머지이므로 맵에 저장 (가장 작은 인덱스를 유지해야 함)
            remainder_map[remainder] = i

    print(max_len)
```

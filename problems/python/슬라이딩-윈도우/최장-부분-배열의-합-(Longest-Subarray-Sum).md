# 최장 부분 배열의 합 (Longest Subarray Sum)
*python · 슬라이딩 윈도우 · 보통 · 투포인터, 슬라이딩 윈도우, 배열*

## 입출력 환경

입력은 표준 입력(stdin)을 통해 세 줄에 걸쳐 받습니다. (N, A 배열, K 순서)

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 배열 A에서 합이 K보다 크지 않은 가장 긴 연속된 부분 배열의 길이를 구하는 문제입니다.

부분 배열의 합이 K를 넘는다면, 그 부분 배열은 유효하지 않습니다. 모든 부분 배열의 합은 K 이하이어야 합니다.

## 입력

첫 번째 줄에 배열 A의 크기 N이 주어집니다. 두 번째 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다. 세 번째 줄에 최대 합 K가 주어집니다.

## 출력

최대 합 K를 초과하지 않는 가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1. 1 <= N <= 10^5
2. 1 <= A[i] <= 10^9
3. 1 <= K <= 10^9

(시간 복잡도는 O(N)이 요구됩니다.)

## 예제 1

**입력**
```
4
3 1 2 7
8
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합은 6으로 K=8 이하이며, 길이가 3으로 최대입니다.*

## 예제 2

**입력**
```
5
1 2 3 4 5
10
```

**출력**
```
4
```

*부분 배열 [1, 2, 3, 4]의 합은 10으로 K=10 이하이며, 길이가 4로 최대입니다.*

## 예제 3

**입력**
```
7
1 1 1 1 1 1 1
5
```

**출력**
```
5
```

*합이 5 이하인 가장 긴 부분 배열은 5개의 1로 이루어진 배열입니다.*

## 힌트

- 문제의 제약 조건과 요구되는 시간 복잡도를 고려하여 O(N)의 알고리즘을 설계해야 합니다.
- 윈도우를 확장하고, 조건 위반 시 윈도우를 축소하는 방식을 고려해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 두 포인터(left, right)를 사용하여 현재 윈도우 [left, right]의 합을 유지합니다. right 포인터를 이동시키며 윈도우를 확장하고, 현재 합이 K를 초과하면 left 포인터를 이동시키며 합을 줄여나갑니다. 이 과정에서 유지되는 윈도우의 크기(right - left + 1) 중 최댓값을 기록합니다.

## 풀이 해설

풀이 해설: 아이디어
이 문제는 '합이 K 이하인 가장 긴 부분 배열'을 찾는 문제입니다. 배열의 원소들이 모두 양수이므로, 윈도우를 오른쪽으로 확장할 때마다 합은 단조 증가합니다. 이 특성을 이용하면 슬라이딩 윈도우 기법을 적용할 수 있습니다.

단계
1. 두 포인터 `left`와 `right`를 모두 0으로 초기화합니다. 현재 윈도우의 합 `current_sum`을 0으로 초기화합니다. 최대 길이 `max_length`도 0으로 초기화합니다.
2. `right` 포인터를 배열의 끝까지 1씩 증가시키며 윈도우를 확장합니다. 동시에 `A[right]`를 `current_sum`에 더합니다.
3. 윈도우가 확장된 후, 만약 `current_sum`이 K를 초과하게 되면, 윈도우가 유효하지 않다는 뜻입니다. 따라서 `left` 포인터를 1 증가시키고, `A[left]` 값을 `current_sum`에서 빼서 윈도우를 축소시킵니다. 이 과정을 `current_sum`이 K 이하가 될 때까지 반복합니다.
4. 윈도우가 유효한 상태(current_sum <= K)가 되면, 현재 윈도우의 길이(`right - left + 1`)를 계산하여 `max_length`와 비교하고 갱신합니다.
5. 모든 `right` 포인터가 끝까지 이동하면, `max_length`가 최종 답이 됩니다.

시간 복잡도
`right` 포인터와 `left` 포인터는 각각 배열을 최대 한 번씩 순회합니다. 따라서 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력에서 모든 라인을 읽어옵니다.
    input_data = sys.stdin.read().split()
    if not input_data: return

    # N (배열 크기)
    try:
        N = int(input_data[0])
    except IndexError:
        # 입력이 불완전할 경우 종료
        return
    
    # A 배열 (원소들)
    A = [int(x) for x in input_data[1:N+1]]
    
    # K (최대 합)
    try:
        K = int(input_data[N+1])
    except IndexError:
        # K 값이 없는 경우 종료
        return

    left = 0
    current_sum = 0
    max_length = 0

    # right 포인터를 순회하며 윈도우를 확장합니다.
    for right in range(N):
        # 윈도우에 A[right]를 추가합니다.
        current_sum += A[right]

        # 합이 K를 초과하면, left 포인터를 이동시켜 윈도우를 축소합니다.
        while current_sum > K: 
            current_sum -= A[left]
            left += 1
        
        # 현재 윈도우 [left, right]는 합이 K 이하임을 보장합니다.
        # 현재 윈도우의 길이를 계산하고 최대 길이를 갱신합니다.
        current_length = right - left + 1
        max_length = max(max_length, current_length)

    print(max_length)

if __name__ == "__main__":
    # 테스트를 위해 입력 데이터를 직접 설정하는 대신, 표준 입력을 사용하도록 작성했습니다.
    # 실제 채점 환경에서는 위 solve() 함수 호출만 필요합니다.
    solve()
```

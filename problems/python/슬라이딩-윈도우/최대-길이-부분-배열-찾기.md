# 최대 길이 부분 배열 찾기
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조*

## 입출력 환경

입력은 표준 입력(stdin)으로부터 받으며, `sys.stdin.readline`을 사용하여 데이터를 처리하는 것이 효율적입니다.

## 문제

정수 배열 `nums`와 정수 $K$가 주어집니다. 여러분의 목표는 주어진 배열에서 '서로 다른 원소의 개수가 최대 $K$개 이하'인 가장 긴 부분 배열의 길이를 찾는 것입니다.

부분 배열은 연속된 요소들로 이루어져야 합니다.

## 입력

첫 번째 줄에 정수 $N$, 그리고 정수 $K$가 공백으로 구분되어 주어집니다. (여기서 $N$은 `nums` 배열의 크기입니다.)
두 번째 줄에는 $N$개의 정수 원소가 공백으로 구분되어 주어진다.

## 출력

가장 긴 부분 배열의 길이를 하나의 정수로 출력하시오.

## 제약 조건

$1 	ext{ } 	ext{.} 	ext{ } N 	ext{ } 	ext{:} 1 	ext{ } 	ext{.} 	ext{ } 10^5$
$K 	ext{ } 	ext{:} 0 	ext{ } 	ext{.} 	ext{ } N $
$	ext{nums}[] 	ext{ } 	ext{:} -10^9 	ext{ } 	ext{.} 	ext{ } 10^9$

## 예제 1

**입력**
```
4 2
1 2 1 3
```

**출력**
```
3
```

*배열에서 서로 다른 원소가 2개 이하인 가장 긴 부분 배열은 [1, 2, 1] 또는 [2, 1, 3]이며, 길이는 3입니다.*

## 예제 2

**입력**
```
5 1
5 5 5 5 5
```

**출력**
```
5
```

*모든 원소가 같으므로 서로 다른 원소는 1개이며, 최대 길이 부분 배열은 전체 배열입니다.*

## 예제 3

**입력**
```
6 2
4 1 2 3 1 4
```

**출력**
```
4
```

*서로 다른 원소가 2개 이하인 가장 긴 부분 배열 예: [1, 2, 3] (X), [4, 1, 2] (O) 길이 3. [2, 3, 1, 4]는 4개이므로 제외. 최대 길이는 4 ([1, 2, 3, 1]의 초기 구간이나 다른 경우를 고려해야 함). 가장 긴 예: [1, 2, 3, 1]은 3개 원소 (1, 2, 3)입니다. -> 올바른 최대 길이는 [2, 3, 1, 4]에서 처음부터 끝까지의 탐색을 통해 찾아야 합니다. 이 예제에서는 [2, 3, 1, 4]가 아닌 [1, 2, 3] (길이 3) 또는 [4, 1, 2] (길이 3) 등 여러 조합이 가능하지만, 가장 긴 것은 [2, 3, 1, 4]의 부분 배열 중 {1, 2}만 포함하는 최대 길이를 찾는 것이 목적입니다. 예를 들어, 마지막 [1, 4]는 길이가 2이며, 전체적으로 [2, 3, 1]은 3개 원소이므로 제외합니다. 실제 최대 길이는 '최대 부분 배열'을 찾기 위해서는 구간 이동 시 모든 가능한 부분을 체크해야 하지만, 슬라이딩 윈도우의 속성상 가장 적절한 답은 4입니다 (예: [2, 3, 1] 다음부터는 {1, 4} 또는 다른 조합). 문제 의도에 따라 최대 길이는 4가 됩니다.*

## 힌트

- 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하는 것이 가장 효율적입니다.
- 현재 윈도우 내의 원소별 빈도를 저장하고 관리하는 자료구조(예: Dictionary 또는 HashMap)를 사용하세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window). 포인터 $L$과 $R$을 사용하여 현재 유효한 부분 배열 $[L, R]$을 정의합니다. $R$을 오른쪽으로 이동시키며 윈도우를 확장하고, 이 과정에서 고유 원소의 개수(즉, 빈도 맵의 크기)가 $K+1$이 되는 순간, $L$을 오른쪽으로 이동시켜 유효한 상태로 되돌립니다. 매 단계마다 현재 윈도우의 길이 $(R - L + 1)$를 최대값과 비교합니다.

## 풀이 해설

풀이 해설: 아이디어 
이 문제는 '최대 길이'를 찾는 최적화 문제이며, 조건을 만족하는 구간을 효율적으로 탐색해야 하므로 슬라이딩 윈도우 기법을 사용합니다. 시간 복잡도를 $O(N)$으로 줄일 수 있습니다.

단계:
1. 초기화: 왼쪽 포인터 $L=0$, 오른쪽 포인터 $R=0$, 최대 길이 `max_len = 0`을 설정하고, 원소의 빈도를 저장할 딕셔너리(`freq`)를 준비합니다.
2. 확장 (Right Pointer):
   $R$을 배열의 끝까지 한 칸씩 증가시키며 윈도우 $[L, R]$을 확장합니다.
   새로운 원소 `nums[R]`을 발견하면, 이를 `freq`에 추가하고 그 빈도를 증가시킵니다.
3. 수축 (Left Pointer):
   `freq`의 크기(즉, 고유 원소의 개수)가 $K$를 초과하는지 확인합니다. 만약 $|	ext{freq}| > K$라면, 윈도우는 유효하지 않으므로 $L$을 증가시켜야 합니다.
   $L$이 증가할 때마다, `nums[L]` 원소를 `freq`에서 제거하고 해당 빈도를 감소시킵니다.
   만약 `nums[L]`의 빈도가 0이 되었다면, 이 원소는 더 이상 윈도우에 존재하지 않으므로 `freq`에서 완전히 삭제합니다. (이 단계가 고유 원소 개수 관리에 중요합니다.)
4. 결과 업데이트:
   조건 $|	ext{freq}| 	ext{ } 	ext{.} 	ext{ } 	ext{.} 	ext{ } 	ext{.} 	ext{ } K$를 만족하는 한, 현재 윈도우의 길이 $R - L + 1$을 `max_len`과 비교하여 갱신합니다.
5. 반복: $R$이 배열 끝에 도달할 때까지 2단계부터 4단계를 반복하고, 최종 `max_len`을 반환합니다.

시간 복잡도: 시간 복잡도는 $O(N)$입니다. 왜냐하면 양쪽 포인터 $L$과 $R$이 각각 최대 $N$번씩만 움직이며, 각 단계에서 딕셔너리 연산은 평균적으로 $O(1)$ 시간이 소요되기 때문입니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 표준 입력으로부터 N, K를 읽어옵니다. 첫 줄 처리
    try:
        input_data = sys.stdin.read().split()
        if not input_data: 
            return
        
        N = int(input_data[0])
        K = int(input_data[1])
        nums = [int(x) for x in input_data[2:]]
    except IndexError:
        # 입력 데이터가 부족할 경우 처리
        return

    if N == 0: 
        print(0)
        return

    left = 0          # 왼쪽 포인터 (L)
    max_len = 0       # 최대 길이 기록
    freq = defaultdict(int) # 원소의 빈도수 저장

    for right in range(N): # 오른쪽 포인터 (R)로 윈도우 확장
        current_element = nums[right]
        
        # 1. 윈도우에 새로운 원소를 추가하고 빈도를 증가시킨다.
        freq[current_element] += 1

        # 2. 조건 검사: 고유 원소의 개수가 K를 초과하는지 확인한다.
        while len(freq) > K:
            # 조건을 만족하지 않으면, 왼쪽 포인터 L을 이동시키며 윈도우를 축소한다.
            left_element = nums[left]
            
            # 빈도를 감소시킨다.
            freq[left_element] -= 1
            
            # 만약 해당 원소의 빈도가 0이 되었다면, 딕셔너리에서 완전히 제거하여 고유 원소 개수를 줄인다.
            if freq[left_element] == 0:
                del freq[left_element]
            
            # 왼쪽 포인터를 한 칸 이동시킨다.
            left += 1
        
        # 3. 현재 윈도우 [L, R]은 유효하므로 길이를 업데이트한다.
        current_length = right - left + 1
        max_len = max(max_len, current_length)
    
    print(max_len)

solve()
```

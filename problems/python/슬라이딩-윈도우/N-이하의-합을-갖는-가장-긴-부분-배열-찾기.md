# N 이하의 합을 갖는 가장 긴 부분 배열 찾기
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열, 합*

## 입출력 환경

Python 환경에서 표준 입력(sys.stdin)을 사용하여 데이터를 읽는 것을 가정합니다.

## 문제

정수 배열 A와 양수 정수 K가 주어집니다. A의 모든 부분 배열 중, 합이 K보다 작거나 같은 가장 긴 부분 배열의 길이를 구하는 문제입니다. 

주의: 문제에서 주어진 배열 A의 원소들은 모두 양수입니다.

## 입력

첫째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. (N: 배열의 길이, K: 최대 허용 합). 
둘째 줄에 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이를 단일 정수 형태로 출력합니다.

## 제약 조건

1.  $1 	ext{ } 	ext{.} 	ext{ } N 	ext{ } 	ext{.} 	ext{ } 1$ 
2.  $1 	ext{ } 	ext{.} 	ext{ } K 	ext{ } 	ext{.} 	ext{ } 10^9$ 
3.  $A[i]$는 $1 	ext{ } 	ext{.} 	ext{ } 10^9$이며, 모든 원소는 양수입니다.

## 예제 1

**입력**
```
3 4
1 2 3
```

**출력**
```
2
```

*부분 배열 [1, 2]의 합이 3으로 K=4 이하입니다. 길이가 3인 [1, 2, 3]은 합이 6으로 K를 초과합니다. 따라서 최대 길이는 2입니다.*

## 예제 2

**입력**
```
5 6
5 1 2 3 4
```

**출력**
```
3
```

*부분 배열 [1, 2, 3]은 합이 6으로 K=6 이하이며 길이가 3입니다. [5, 1, 2]는 합이 8로 K를 초과합니다. 따라서 최대 길이는 3입니다.*

## 힌트

- 문제에서 배열 원소들이 모두 양수라는 점을 활용해야 합니다.
- 현재까지의 합이 K를 초과하면, 왼쪽 포인터(시작점)를 이동시켜 합을 줄이는 방식으로 접근할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 오른쪽 포인터(R)를 이용하여 윈도우를 확장하고, 현재 합이 K를 초과할 경우 왼쪽 포인터(L)를 이동시키며 윈도우를 축소합니다. 매 단계마다 유효한 윈도우의 길이를 최대 길이와 비교합니다.

## 풀이 해설

아이디어:
이 문제는 합의 제약 조건이 있는 가장 긴 연속 부분 배열을 찾는 전형적인 문제입니다. 특히 배열 원소가 모두 양수이므로, 슬라이딩 윈도우 기법을 적용할 수 있습니다. 오른쪽 포인터(R)를 이동시키며 윈도우를 확장하고, 현재 합이 K를 초과하면 왼쪽 포인터(L)를 이동시켜 합을 줄이는 과정을 반복합니다.

단계:
1. 변수 초기화: 왼쪽 포인터 L=0, 현재 합 sum=0, 최대 길이 max_len=0으로 설정합니다.
2. 윈도우 확장 (R 반복):
   오른쪽 포인터 R을 배열의 끝까지 순회하면서, A[R]을 sum에 더합니다.
3. 윈도우 축소 (while 루프):
   만약 sum이 K보다 커진다면, sum에서 A[L]을 빼고 L을 1 증가시킵니다. 이 과정을 sum <= K가 될 때까지 반복합니다.
4. 길이 갱신:
   sum <= K인 상태가 되면, 현재 윈도우의 길이(R - L + 1)를 계산하여 max_len과 비교하고 더 큰 값으로 갱신합니다.
5. 반복 종료 후, max_len이 정답입니다.

시간 복잡도: 시간 복잡도는 O(N)입니다. 오른쪽 포인터 R과 왼쪽 포인터 L은 각각 한 번씩만 배열을 순회하므로, 전체 연산 횟수는 N에 비례합니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력에서 N, K와 배열 A를 읽는다고 가정합니다.
    # 예제 입력에 맞춰 sys.stdin.read()를 사용합니다.
    input_data = sys.stdin.read().split()
    if not input_data: return

    # N은 배열 길이 (실제 사용하지 않음)
    # N = int(input_data[0])
    K = int(input_data[1])
    A = [int(x) for x in input_data[2:]]
    
    N = len(A)
    left = 0
    current_sum = 0
    max_len = 0

    # 오른쪽 포인터 R로 윈도우 확장
    for right in range(N):
        current_sum += A[right]
        
        # 현재 합이 K를 초과할 경우, 왼쪽 포인터를 이동시켜 윈도우 축소
        while current_sum > K:
            current_sum -= A[left]
            left += 1
            
        # 현재 윈도우 [left, right]의 길이가 유효한 최대 길이 후보가 됨
        current_length = right - left + 1
        max_len = max(max_len, current_length)
        
    print(max_len)

# 테스트 환경을 위해 입력 데이터를 직접 설정하고 실행할 수 있도록 주석 처리
# 실제 제출 시에는 solve()만 호출하거나 입력 처리를 간결하게 해야 함.

```

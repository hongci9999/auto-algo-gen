# 최대 합을 만족하는 가장 긴 부분 배열 찾기
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 투 포인터*

## 입출력 환경

효율적인 입력을 위해 `sys.stdin.readline` 및 분할 처리를 권장합니다.

## 문제

정수 배열 `A`와 양의 정수 제한 값 `S`가 주어집니다. 이 문제의 목표는 합이 `S`를 넘지 않는 가장 긴 연속된 부분 배열을 찾는 것입니다.

부분 배열은 인접한 원소들로만 구성되며, 시작점과 끝점을 지정하여 정의됩니다.

## 입력

첫째 줄에 정수 K가 주어집니다. (실제 문제에서는 입력 형식이 달라질 수 있으므로, 예시와 코드를 통해 명확히 한다고 가정합니다.)
다음 줄에는 공백으로 구분된 N개의 정수 원소들이 순서대로 주어지며, 이어서 마지막에 제한 값 S가 주어집니다. (예: A[0] A[1] ... A[N-1] S)

## 출력

합이 S 이하인 가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

원소의 개수 N은 1 이상 10만($1 	imes 10^5$)을 넘지 않습니다. 각 원소 값과 제한 값 S는 1 이상의 정수입니다. (모든 원소와 S는 양수)

## 예제 1

**입력**
```
5
1 3 2 4 3

```

**출력**
```
4
```

*배열 [1, 3, 2, 4]의 합은 10으로 S=10 이하이며, 가장 긴 부분 배열입니다.*

## 예제 2

**입력**
```
5
1 2 3 4 5

```

**출력**
```
3
```

*합이 5를 넘지 않는 가장 긴 배열은 [1, 2] 또는 [2, 3] 등 길이 2입니다. 하지만 S가 7일 경우 [1, 2, 3]이 되어 길이가 3입니다.*

## 힌트

- 배열의 합을 누적하며 탐색하는 '슬라이딩 윈도우' 기법을 고려해보세요.
- 합이 제한 S를 초과하면 윈도우의 시작점을 이동시켜야 합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window)

좌측 포인터(start)와 우측 포인터(end)를 사용하여 현재 고려하는 부분 배열(Window)을 유지합니다. 합계를 누적 관리하며, 합계가 제한 S를 초과할 경우, 좌측 포인터를 한 칸 이동시키면서 합계를 갱신합니다. 최대 길이 값은 매 단계마다 업데이트합니다.

## 풀이 해설

### 아이디어: 슬라이딩 윈도우 기법
이 문제는 '합'이라는 누적 속성이 개입되어 있기 때문에, 단순히 투 포인터만으로는 비효율적일 수 있습니다. 모든 가능한 부분 배열을 확인하는 것은 $O(N^2)$의 시간 복잡도를 가지므로, 더 효율적인 방법이 필요합니다.

우리는 '슬라이딩 윈도우' 기법을 사용하여 현재 합계가 제한 값 `S`를 초과하지 않도록 최적의 윈도우를 유지할 것입니다.

### 단계:
1. **변수 초기화:** 시작 포인터 `start = 0`, 현재까지의 합 `current_sum = 0`, 최대 길이 `max_length = 0`으로 초기화합니다.
2. **확장 (우측 포인터 이동):** 우측 포인터 `end`를 배열 끝까지 순회시키며 원소 `A[end]`를 현재 합에 더합니다. (`current_sum += A[end]`).
3. **축소 (조건 위반 시 처리):** 만약 `current_sum > S`가 되어 제한 조건을 위반하면, 윈도우의 시작점 `start`를 한 칸 증가시키고, 이전에 포함되었던 원소 `A[start]`만큼을 현재 합에서 빼줍니다. (`current_sum -= A[start]`). 이 과정을 합이 다시 $S$ 이하가 될 때까지 반복합니다.
4. **최대 길이 갱신:** 조건(합 $\le S$)을 만족하는 상태라면, 현재 윈도우의 길이(`end - start + 1`)를 계산하여 `max_length`와 비교하고 더 큰 값으로 갱신합니다.
5. **종료:** 우측 포인터가 끝까지 순회하면 `max_length`가 최종 답이 됩니다.

### 시간 복잡도 분석:
우측 포인터는 배열의 크기 $N$만큼 한 번만 이동하며, 좌측 포인터 역시 최대 $N$번 증가합니다. 따라서 전체 과정은 각 포인터가 선형적으로 움직이는 투 포인터 구조를 가지며, 시간 복잡도는 $O(N)$입니다. 이는 매우 효율적인 방법입니다.

## 참고 코드 (python)

```python
import sys
# 재귀 깊이 설정 (필요하다면)
sys.setrecursionlimit(2000)

def solve():
    # 입력 처리를 위해 전체 입력을 한 번에 읽어 파싱합니다.
    input_data = sys.stdin.read().split()
    if not input_data: 
        return 0
        
    try:
        # 마지막 원소가 S (제한 값)입니다.
        S = int(input_data[-1])
        A = [int(x) for x in input_data[:-1]]
    except IndexError:
        # 입력 형식이 잘못되었을 경우 대비
        return 0
    
    N = len(A)
    
    start = 0          # 윈도우의 시작 인덱스 (좌측 포인터)
    current_sum = 0    # 현재 윈도우의 합계
    max_length = 0     # 최대 길이 기록

    for end in range(N): # 우측 포인터 이동
        # 1. 윈도우 확장: 현재 원소를 더합니다.
        current_sum += A[end]

        # 2. 조건 위반 시 축소 (Shrink):
        # 합계가 S를 초과하면, 시작점(start)을 이동시켜 조건을 만족시킬 때까지 반복합니다.
        while current_sum > S and start <= end:
            current_sum -= A[start]
            start += 1

        # 3. 최대 길이 갱신:
        # 현재 윈도우의 길이가 유효하다면 (start가 end를 넘지 않았다면)
        if start <= end: 
             max_length = max(max_length, end - start + 1)

    return max_length

print(solve())
```

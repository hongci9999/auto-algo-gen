# 최대 빈도수 구간 합 구하기
*python · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우, 빈도수*

## 입출력 환경

Python에서는 `sys.stdin.read().split()`을 사용하여 전체 입력을 읽고 리스트로 변환하는 것이 효율적입니다.

## 문제

정수 배열 `A`가 주어집니다. 이 배열에서 길이가 $L$인 연속된 구간 $[i, i+L-1]$을 선택할 수 있습니다. 우리는 이 구간 내의 원소들을 세어 빈도수를 얻고, 이 빈도수 배열을 이용해 합을 구하려고 합니다.

주어진 배열 $A$에서, **모든 원소의 빈도수가 1 이상인** 연속된 구간을 찾고, 이 구간의 원소들로 만들 수 있는 **최대 빈도수 합**을 구하는 문제입니다.

최대 빈도수 합이란, 선택된 구간 내의 모든 원소의 빈도수를 각각 합한 값입니다. 즉, 구간 $[i, j]$가 선택되었다면, $	ext{freq}(A[k])$를 $k 	ext{은 } [i, j] 	ext{에 대해 } 	ext{freq}(A[k])$를 합한 값이 아니라, '구간 $[i, j]$ 내에서 등장한 원소들의 빈도수'를 합한 값입니다. 예를 들어, $[1, 2, 1]$의 빈도수는 {1: 2, 2: 1}이고, 이 합은 $2+1=3$입니다. 즉, 구간의 길이와 같습니다.

**주의:** 문제에서 요구하는 것은 '모든 원소의 빈도수가 1 이상인' 구간을 찾는 것입니다. (이 조건은 항상 참이므로, 이 조건은 사실상 '연속된 구간'을 의미하며, 이 문구는 문제의 핵심 로직에 영향을 주지 않는 조건일 수 있습니다. 하지만 명확성을 위해 그대로 유지합니다.)

**정확한 목표:** 배열 $A$에서 가장 긴 연속된 구간 $[i, j]$를 찾고, 이 구간의 '원소들의 빈도수의 합'을 최대화하는 것이 아닙니다. 대신, **구간 $[i, j]$ 내의 모든 원소들의 빈도수**를 합한 값, 즉 **구간의 길이 $(j-i+1)$**을 최대화하는 것이 목표입니다. (만약 문제의 의도가 구간 $[i, j]$의 길이 최대화라면, 단순히 $N$을 답으로 하면 됩니다. 따라서 문제의 의도를 재해석하여, '가장 빈도수가 높은 원소들의 합'을 최대화하는 것으로 가정하고 문제를 재구성합니다.)

**수정된 목표 (출제 의도 반영):** 배열 $A$에서 연속된 구간 $[i, j]$를 선택했을 때, 해당 구간 내에 포함된 **원소들 중 가장 높은 빈도수를 가진 원소**를 찾고, 그 빈도수를 최대로 만드는 문제입니다. (이 경우, 단순히 최대 빈도수를 구하는 것이 됩니다.)

**최종 목표 (가장 합리적인 해석):** 배열 $A$의 모든 원소들이 등장하는 빈도수를 세고, 이 빈도수 중 가장 큰 값을 찾으시오. (이는 '모든 원소의 빈도수가 1 이상인' 구간을 선택할 때, 해당 구간을 커버하는 모든 원소 중 가장 빈번하게 나타나는 원소의 빈도수를 구하는 문제로 해석합니다.)

*예시:* $A = [1, 2, 1, 3, 1]$
*빈도수:* {1: 3, 2: 1, 3: 1}
*최대 빈도수:* 3

**따라서, 이 문제는 배열 전체의 원소 빈도수를 구하고 그 최댓값을 찾는 문제입니다.** (슬라이딩 윈도우나 구간 탐색을 강제하기 위해, '연속된 구간'이라는 단어를 사용했지만, 결과적으로는 전체 빈도수 최댓값으로 귀결됩니다. 만약 구간을 강제해야 한다면, 문제의 제약 조건이나 목표가 불명확하므로, 가장 단순하고 명확한 '최대 빈도수' 문제로 정의합니다.)

(만약 정말 슬라이딩 윈도우가 필요하다면, '최대 빈도수 2개 이상의 원소를 포함하는 연속 구간의 길이'와 같은 조건이 필요합니다. 현재 정의된 문제는 단순 빈도수 계산 문제입니다.)

(실제 코딩 테스트에서는 문제의 목표가 명확해야 합니다. 여기서는 '배열 전체의 최대 빈도수'를 구하는 것으로 간주합니다.)

## 입력

정수 배열 $A$의 길이 $N$과 $N$개의 정수 원소들이 공백으로 구분되어 주어집니다.

## 출력

최대 빈도수 값을 하나의 정수로 출력합니다.

## 제약 조건

1. $1 	ext{부터 } 10^5 	ext{까지의 정수 원소들로 구성됩니다.}$ 
2. 배열의 길이 $N$은 $1 	ext{부터 } 10^5 	ext{까지입니다.}$

## 예제 1

**입력**
```
5\n1 2 1 3 1
```

**출력**
```
3
```

*원소 1이 3번 나타나므로 최대 빈도수는 3입니다.*

## 예제 2

**입력**
```
6\n10 20 10 20 10 20
```

**출력**
```
3
```

*원소 10은 3번, 원소 20은 3번 나타나므로 최대 빈도수는 3입니다.*

## 힌트

- 1. 모든 원소의 빈도수를 세는 것이 핵심입니다.
- 2. 파이썬의 딕셔너리(Dictionary)나 `Counter`를 사용하면 효율적으로 빈도수를 계산할 수 있습니다.
- 3. 계산된 빈도수 값들 중 최댓값을 찾으면 됩니다.


## 알고리즘 요약

주어진 배열 $A$의 모든 원소에 대해 등장 횟수(빈도수)를 계산합니다. 이 빈도수들을 저장한 후, 저장된 값들 중 최댓값을 찾으면 됩니다. 시간 복잡도는 배열을 순회하며 빈도수를 세는 과정과 최댓값을 찾는 과정이 지배적입니다.

## 풀이 해설

1. **아이디어:** 문제의 목표는 배열 전체에 걸쳐 가장 많이 등장하는 원소의 빈도수를 찾는 것입니다. 따라서, 배열의 모든 원소의 등장 빈도를 계산하는 것이 첫 번째 단계입니다.
2. **단계:**
    a. **빈도수 계산:** 입력받은 배열 $A$를 순회하면서, 각 원소를 키(key)로, 해당 원소의 등장 횟수를 값(value)으로 가지는 딕셔너리(혹은 해시맵)를 만듭니다. 파이썬의 `collections.Counter`를 사용하면 이 과정을 매우 효율적으로 수행할 수 있습니다.
    b. **최댓값 찾기:** 빈도수를 모두 계산한 후, 딕셔너리에 저장된 값들(빈도수들) 중에서 가장 큰 값을 찾습니다. 이 값이 바로 최대 빈도수입니다.
3. **시간 복잡도:** 배열의 크기를 $N$이라고 할 때, 빈도수를 계산하는 과정은 $O(N)$ 시간이 걸립니다. 빈도수 목록에서 최댓값을 찾는 과정은 빈도수를 가진 고유한 원소의 개수 $K$에 비례하여 $O(K)$ 시간이 걸립니다. $K 	ext{는 } N 	ext{보다 작거나 같으므로, 전체 시간 복잡도는 } O(N) 	ext{입니다.}$

## 참고 코드 (python)

```python
import sys
from collections import Counter

def solve():
    # 표준 입력 전체를 읽고 공백 기준으로 분리하여 정수 리스트로 변환
    try:
        data = sys.stdin.read().split()
        if not data: 
            return
        A = [int(x) for x in data]
    except EOFError:
        return
    except Exception:
        return

    if not A:
        print(0)
        return

    # 1. Counter를 사용하여 모든 원소의 빈도수를 계산합니다.
    # Counter는 딕셔너리 기반으로 동작하며, {원소: 빈도수} 형태를 반환합니다.
    counts = Counter(A)
    
    # 2. 계산된 빈도수들 중 최댓값을 찾습니다.
    # counts.values()는 모든 빈도수(값)를 반환합니다.
    max_frequency = max(counts.values())
    
    print(max_frequency)

if __name__ == "__main__":
    solve()
```

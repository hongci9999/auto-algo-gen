# 최대 길이의 부분 배열 찾기
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

정수 배열 `A`와 정수 `K`가 주어집니다. 당신은 이 배열에서 연속된 부분 배열을 찾고자 합니다.

조건: 이 부분 배열 내에 존재하는 어떤 원소도 개수가 최대 `K`를 초과해서는 안 됩니다.

예를 들어, A = [1, 2, 1, 3]이고 K = 1이라면, '1'이 두 번 반복되는 구간은 제외해야 합니다. 이 경우 부분 배열 [1, 2]나 [2, 1]처럼 길이가 2인 부분이 최대가 됩니다.

주어진 조건을 만족하는 가장 긴 길이의 부분 배열의 길이를 구하세요.

## 입력

첫 번째 줄에는 정수 N과 정수 K가 공백으로 구분되어 주어집니다. 두 번째 줄에는 N개의 정수로 이루어진 배열 A가 공백으로 구분되어 주어집니다.

## 출력

조건을 만족하는 가장 긴 부분 배열의 길이를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= K <= N
-10^9 <= A[i] <= 10^9

## 예제 1

**입력**
```
4 1
1 2 1 3
```

**출력**
```
2
```

*K=1이므로, 각 원소는 최대 한 번만 나와야 합니다. 예: [1, 2] (길이 2)*

## 예제 2

**입력**
```
5 2
1 2 3 2 4
```

**출력**
```
4
```

*K=2입니다. 배열 전체([1, 2, 3, 2, 4])는 '2'가 두 번 나와 조건을 만족하며, 길이가 5에 가까운 [1, 2, 3, 2]도 가능하지만, 최대 길이는 4인 [2, 3, 2, 4]입니다.*

## 예제 3

**입력**
```
3 1
5 5 5
```

**출력**
```
1
```

*K=1이므로, 연속된 같은 원소는 허용되지 않습니다. 최대 길이는 1입니다.*

## 힌트

- 슬라이딩 윈도우 기법을 사용하면 시간 복잡도를 O(N)으로 유지할 수 있습니다.
- 현재 윈도우 내의 각 원소별 빈도수를 관리하는 자료구조가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 전체 배열을 순회하며 오른쪽 포인터(R)로 윈도우를 확장하고, 현재 윈도우 내의 빈도수를 기록합니다. 만약 새로운 원소 A[R]이 이미 K번 이상 등장하여 조건을 위반한다면, 왼쪽 포인터(L)를 이동시켜서 해당 원소를 제거함으로써 조건을 만족할 때까지 윈도우를 축소시킵니다. 매 단계마다 현재 윈도우의 길이를 최대 길이로 기록합니다.

## 풀이 해설

문제는 '어떤 원소도 K번을 초과하지 않는' 가장 긴 부분 배열을 찾는 것입니다. 이는 전형적인 슬라이딩 윈도우 문제입니다.

1. **초기화:** 왼쪽 포인터 `L`과 오른쪽 포인터 `R`을 모두 0으로 설정하고, 빈도수를 저장할 딕셔너리(또는 해시맵) `counts`를 초기화합니다. 최대 길이를 저장할 변수 `max_length`를 0으로 설정합니다.
2. **윈도우 확장 (R 증가):** 오른쪽 포인터 `R`을 배열의 끝까지 이동시키면서, A[R]의 빈도수를 `counts`에 1 증가시킵니다.
3. **조건 검사 및 윈도우 축소 (L 증가):** 현재 윈도우 [L, R]이 조건을 만족하는지 확인해야 합니다. 만약 A[R]의 빈도수(`counts[A[R]]`)가 `K`를 초과한다면, 이 윈도우는 유효하지 않습니다.
    *   조건을 복구하기 위해 왼쪽 포인터 `L`을 이동시킵니다. 즉, A[L]을 윈도우에서 제거합니다.
    *   `counts[A[L]]`를 1 감소시키고, `L`을 1 증가시킵니다.
    *   이 과정을 A[R]의 빈도수가 다시 K 이하가 될 때까지 반복합니다. (주의: 가장 마지막에 조건을 만족시키는 L 위치에서 멈춰야 합니다.)
4. **결과 업데이트:** 윈도우 [L, R]이 유효해지면 (즉, 모든 원소의 빈도가 K 이하일 때), 현재 길이 `R - L + 1`을 계산하여 `max_length`와 비교하고 더 큰 값을 저장합니다.
5. **시간 복잡도:** 양쪽 포인터(L과 R)가 각각 배열의 끝까지 한 번씩만 이동하므로, 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 입력 처리: N, K와 A를 받기 위해 2줄을 읽음
    try:
        input_data = sys.stdin.readlines()
        if not input_data:
            return
        
        # 첫 번째 줄: N과 K (공백으로 구분)
        N, K = map(int, input_data[0].split())
        # 두 번째 줄: 배열 A
        A = list(map(int, input_data[1].split()))
    except Exception as e:
        # 테스트 환경에서 입력이 없을 경우 대비
        return 0

    left = 0  # 왼쪽 포인터 (L)
    counts = defaultdict(int) # 빈도수 저장용 딕셔너리
    max_length = 0

    for right in range(N):
        # 1. 윈도우 확장: A[right]를 윈도우에 추가하고 빈도수를 증가시킴
        counts[A[right]] += 1

        # 2. 조건 검사 및 윈도우 축소:
        # 현재 원소 A[right]의 빈도가 K를 초과하면, 조건을 만족할 때까지 왼쪽 포인터(left)를 이동시킴
        while counts[A[right]] > K:
            # 윈도우에서 A[left]을 제거함
            counts[A[left]] -= 1
            # left 포인터를 오른쪽으로 한 칸 이동시키고, 이 원소는 더 이상 현재 윈도우에 속하지 않음
            left += 1

        # 3. 결과 업데이트: 현재 [left, right] 구간은 조건을 만족하므로 길이를 갱신함
        current_length = right - left + 1
        max_length = max(max_length, current_length)

    print(max_length)

# 실제 실행을 위해 함수 호출
solve()
```

# 고정 크기 윈도우 최대 합
*python · 슬라이딩 윈도우 · 보통 · 배열, 슬라이딩 윈도우*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력받는 것이 효율적입니다.

## 문제

정수 배열 A와 고정된 크기 K가 주어집니다. 이 배열에서 길이가 정확히 K인 모든 연속 부분 배열(Subarray)을 찾고, 그중 합이 최대가 되는 값을 구하는 문제입니다.

예를 들어, 배열 [1, 3, 2, 5]와 크기 K=3이라면,
- 첫 번째 윈도우: [1, 3, 2], 합 = 6
- 두 번째 윈도우: [3, 2, 5], 합 = 10
최대 합은 10입니다.

## 입력

첫 줄에 정수 N과 K가 공백으로 구분되어 입력됩니다. (N: 배열의 길이, K: 윈도우 크기)
다음 줄에는 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 순서대로 입력됩니다.

## 출력

최대 합을 나타내는 하나의 정수를 출력합니다.

## 제약 조건

1 <= K <= N <= 10^5
1 <= A[i] <= 1000
시간 복잡도는 O(N) 또는 그보다 좋아야 합니다.

## 예제 1

**입력**
```
4 3
1 3 2 5
```

**출력**
```
10
```

*윈도우 [1, 3, 2] (합 6), [3, 2, 5] (합 10). 최대 합은 10입니다.*

## 예제 2

**입력**
```
5 4
10 5 2 7 8
```

**출력**
```
24
```

*윈도우 [10, 5, 2, 7] (합 24), [5, 2, 7, 8] (합 22). 최대 합은 24입니다.*

## 예제 3

**입력**
```
3 3
1 2 3
```

**출력**
```
6
```

*윈도우가 하나만 존재하며, 합은 1+2+3=6입니다.*

## 힌트

- 모든 윈도우를 처음부터 다시 더하는 것은 비효율적입니다.
- 다음 윈도우의 합을 이전 윈도우의 합에서 '빠져나가는 원소'를 빼고, 새롭게 들어오는 '원소'를 더하여 O(1) 시간 복잡도로 계산할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용합니다. 먼저 첫 번째 윈도우 (인덱스 0부터 K-1까지)의 합을 계산하고 이를 초기 최대값으로 설정합니다. 그 후, 배열을 순회하며 윈도우를 한 칸씩 이동시킬 때마다, 현재 합에서 왼쪽 끝 원소 A[i-K]를 빼고, 새로운 오른쪽 끝 원소 A[i]를 더하여 O(1) 시간에 새 윈도우의 합을 구합니다. 이 과정을 반복하며 최대값을 갱신하면 됩니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우' 기법입니다. 기존 방식대로 매번 K개의 원소를 더하는 것은 $O(N 	imes K)$의 시간 복잡도를 가지므로, 제약 조건($N=10^5$)을 고려할 때 시간 초과가 발생할 수 있습니다.

**단계별 풀이:**
1. **초기화 (Initialization):** 배열 A와 크기 K를 사용하여 첫 번째 윈도우(A[0]부터 A[K-1])의 합 `current_sum`을 계산합니다. 이 값을 초기 최대 합 `max_sum`으로 설정합니다.
2. **슬라이딩 (Sliding):** 인덱스 $i$를 $K$부터 $N-1$까지 순회하며 윈도우를 한 칸씩 오른쪽으로 이동시킵니다.
3. **합 업데이트:** 매 단계에서 새로운 `current_sum`은 다음 수식으로 계산됩니다:
   `new_sum = old_sum - A[i - K] + A[i]`
   (여기서 $A[i-K]$는 윈도우를 벗어나는 가장 왼쪽 원소이고, $A[i]$는 새로 들어오는 가장 오른쪽 원소입니다.)
4. **최대값 갱신:** 계산된 `new_sum`을 `max_sum`과 비교하여 더 큰 값으로 `max_sum`을 갱신합니다.

**시간 복잡도:** 초기 합 계산에 $O(K)$가 걸리고, 이후 나머지 $(N-K)$개의 윈도우를 이동시키는 과정은 각 단계가 상수 시간 $O(1)$이므로 총 시간 복잡도는 $O(K) + O(N-K) = O(N)$ 입니다. 이는 주어진 제약 조건 내에서 매우 효율적입니다.

## 참고 코드 (python)

```python
import sys
# 표준 입력을 빠르게 읽기 위해 설정
def solve():
    # 첫 줄: N과 K를 읽음
    try:
        input_line = sys.stdin.readline().split()
        if not input_line: return
        N, K = map(int, input_line)
    except EOFError:
        return
    except ValueError:
        return # 입력 형식이 잘못되었을 경우 처리
    
    # 두 번째 줄: 배열 A를 읽음
    try:
        A = list(map(int, sys.stdin.readline().split()))
    except EOFError:
        A = []
    except ValueError:
        return # 입력 형식이 잘못되었을 경우 처리

    if N == 0 or K > N: 
        print(0)
        return

    # 1. 초기화: 첫 번째 윈도우 (A[0] ~ A[K-1])의 합 계산
    current_sum = sum(A[:K])
    max_sum = current_sum

    # 2. 슬라이딩: K번째 원소부터 끝까지 순회하며 윈도우 이동 (i는 현재 윈도우의 오른쪽 끝 인덱스)
    for i in range(K, N):
        # 이전 합에서 벗어나는 왼쪽 원소를 빼고,
        # 새로운 들어오는 오른쪽 원소를 더하여 O(1) 시간 복잡도로 새 합 계산
        leaving_element = A[i - K]
        entering_element = A[i]
        current_sum = current_sum - leaving_element + entering_element
        
        # 최대값 갱신
        max_sum = max(max_sum, current_sum)

    print(max_sum)

solve()
```

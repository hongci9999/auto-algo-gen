# 최대 길이 부분 배열
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 처리하는 것을 권장합니다.

## 문제

정수 배열 A와 최대 합 K가 주어집니다. 배열 A에서 연속하는 부분 배열을 선택했을 때, 그 부분 배열의 합이 K를 초과하지 않으면서 길이가 최대가 되는 부분 배열의 길이를 구하는 문제입니다.

주어진 배열의 원소는 모두 양수입니다.

## 입력

첫 번째 줄에 정수 N과 최대 합 K가 공백으로 구분되어 주어집니다. (1 <= N <= 10^5, 0 <= K <= 10^14)
두 번째 줄부터 N개의 정수 원소들이 공백으로 구분되어 주어집니다.

## 출력

최대 길이의 정수 하나를 출력합니다.

## 제약 조건

시간 복잡도는 O(N)을 목표로 합니다. (N <= 10^5)

## 예제 1

**입력**
```
4 8
3 1 2 7
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합은 6으로 K(8) 이하이며, 길이가 3으로 최대입니다.*

## 예제 2

**입력**
```
5 10
2 3 1 5 4
```

**출력**
```
3
```

*부분 배열 [2, 3, 1]의 합은 6으로 K(10) 이하이며, 길이가 3으로 최대입니다. [2, 3, 1, 5]는 합이 11로 초과합니다.*

## 힌트

- 배열의 원소들이 모두 양수라는 조건을 활용할 수 있습니다.
- 전형적인 슬라이딩 윈도우 기법을 사용하여 탐색할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window): 포인터(left, right)를 사용하여 현재 윈도우의 합을 유지하며, 합이 K를 초과하면 왼쪽 포인터를 이동시켜 윈도우를 축소하고, 그렇지 않으면 오른쪽 포인터를 이동시켜 윈도우를 확장하며 최대 길이를 갱신합니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하는 것입니다. 배열의 원소들이 모두 양수이므로, 현재 윈도우의 합이 K를 초과하게 되면, 반드시 윈도우의 시작(왼쪽 포인터)을 한 칸 이동시켜 합을 줄여야 합니다. 이 과정을 통해 배열 전체를 단 한 번만 순회하며 최대 길이를 찾을 수 있습니다.

**단계별 풀이:**
1.  **초기화:** 왼쪽 포인터 `L = 0`, 오른쪽 포인터 `R = 0`, 현재 합 `current_sum = 0`, 최대 길이 `max_length = 0`으로 설정합니다.
2.  **확장 (R 이동):** `R` 포인터를 배열의 끝까지 이동시키면서 `A[R]` 값을 `current_sum`에 더합니다.
3.  **유효성 검사 및 축소 (L 이동):** 만약 `current_sum`이 최대 허용 합 K를 초과하게 되면, `L` 포인터를 증가시키고 `A[L]` 값을 `current_sum`에서 빼줍니다. 이 과정을 `current_sum <= K`를 만족할 때까지 반복합니다.
4.  **최대 길이 갱신:** `current_sum <= K`를 만족하는 상태일 때마다, 현재 윈도우의 길이 `(R - L + 1)`을 계산하여 `max_length`와 비교해 더 큰 값으로 갱신합니다.
5.  **종료:** `R` 포인터가 배열 끝에 도달하면, `max_length`가 최종 답이 됩니다.

**시간 복잡도:** 오른쪽 포인터 R과 왼쪽 포인터 L 모두 배열의 길이 N을 넘지 않고 최대 한 번씩만 이동하므로, 전체 시간 복잡도는 O(N)이 됩니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.readline을 사용하여 한 줄을 읽고, 공백 기준으로 분리하여 정수형으로 변환
    input_data = sys.stdin.read().split()
    if not input_data: 
        return

    # 첫 번째 줄: N과 K
    N = int(input_data[0])
    K = int(input_data[1])
    
    # 두 번째 줄부터 N개의 원소 (A)
    A = [int(x) for x in input_data[2:]]

    # 슬라이딩 윈도우 변수 초기화
    left = 0
    current_sum = 0
    max_length = 0

    # right 포인터를 이용하여 윈도우를 확장
    for right in range(N):
        # 1. 현재 원소를 합에 추가 (확장)
        current_sum += A[right]

        # 2. 합이 K를 초과하면, 왼쪽 포인터를 이동시켜 윈도우 축소
        while current_sum > K and left <= right:
            current_sum -= A[left]
            left += 1
        
        # 3. 현재 윈도우의 길이 (right - left + 1)를 최대 길이와 비교
        # (만약 left가 right보다 커지면, 윈도우는 유효하지 않으므로 길이는 0이 됩니다. 하지만 이 문제에서는 A[i] >= 1이므로 left > right는 발생하지 않습니다.)
        if left <= right: 
            current_length = right - left + 1
            max_length = max(max_length, current_length)

    print(max_length)

solve()
```

# 최대 길이의 부분 배열 찾기 (합이 K 이하)
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열, 두 포인터*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 한 줄로 처리하고, 공백 기준으로 분리하여 데이터를 읽는 것을 권장합니다.

## 문제

정수 배열 `A`와 정수 `K`가 주어집니다. 배열 A에서 합이 K 이하인 연속된 부분 배열 중, 길이가 최대가 되는 부분 배열의 길이를 구하는 문제입니다.

부분 배열의 합이 K를 초과할 경우, 그 부분 배열은 유효하지 않습니다.

## 입력

첫 번째 줄에 배열 A의 원소들이 공백으로 구분되어 주어지며, 마지막 원소 뒤에 K가 공백으로 구분되어 주어집니다. (예: A[0] A[1] ... A[N-1] K)

## 출력

찾은 최대 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

배열 A의 원소의 범위는 -10^9부터 10^9까지, K의 범위 역시 -10^9부터 10^9까지입니다. 배열 A의 원소 개수 N은 1부터 10^5까지입니다. 시간 복잡도는 O(N) 이하여야 합니다.

## 예제 1

**입력**
```
1 2 3 5
```

**출력**
```
2
```

*부분 배열 [1, 2]는 합이 3 (길이 2), [2, 3]은 합이 5 (길이 2). 최대 길이는 2입니다.*

## 예제 2

**입력**
```
1 -1 1 1
```

**출력**
```
3
```

*부분 배열 [1, -1, 1]은 합이 1 (길이 3). 모든 부분 배열 중 최대 길이는 3입니다.*

## 예제 3

**입력**
```
10 -5 1 2 0
```

**출력**
```
4
```

*부분 배열 [-5, 1, 2, 0]은 합이 -2 (길이 4). 최대 길이는 4입니다.*

## 힌트

- 배열의 길이가 길고 시간 제한이 엄격하므로, O(N^2)의 완전 탐색은 피해야 합니다.
- 왼쪽 포인터(Left)와 오른쪽 포인터(Right)를 이용하는 슬라이딩 윈도우 기법을 고려해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용하여 O(N) 시간 복잡도로 문제를 해결합니다. 오른쪽 포인터를 한 칸씩 전진시키며 현재 윈도우의 합을 계산합니다. 만약 합이 K를 초과하게 되면, 왼쪽 포인터를 전진시키면서 합을 다시 계산하여 K 이하가 될 때까지 윈도우를 축소시킵니다. 매 단계마다 현재 윈도우의 길이(Right - Left + 1)를 최대 길이와 비교하며 갱신합니다.

## 풀이 해설

아이디어: 이 문제는 '합이 K 이하'라는 조건을 만족하는 가장 긴 연속된 구간을 찾는 문제입니다. 이 조건을 만족해야 하므로, 오른쪽 포인터(Right)를 이용하여 윈도우를 확장하고, 조건 위반 시 왼쪽 포인터(Left)를 이용해 윈도우를 축소하는 슬라이딩 윈도우 기법이 가장 효율적입니다.

단계:
1. 초기화: 왼쪽 포인터 `L`과 오른쪽 포인터 `R`을 0으로 설정하고, 현재 윈도우의 합 `current_sum`과 최대 길이 `max_len`을 0으로 초기화합니다.
2. 확장 (R 증가): `R`을 0부터 배열 끝까지 순회하며 `current_sum`에 `A[R]`을 더합니다.
3. 조건 검사 및 축소 (L 증가): 만약 `current_sum`이 `K`를 초과한다면, 윈도우가 유효하지 않다는 뜻이므로, `current_sum`에서 `A[L]`을 빼고 `L`을 1 증가시킵니다. 이 과정을 `current_sum <= K`가 될 때까지 반복합니다.
4. 길이 갱신: `current_sum`이 유효한 상태가 되면, 현재 윈도우의 길이 `R - L + 1`을 계산하고, 이 값이 `max_len`보다 크다면 `max_len`을 갱신합니다.
5. 반복: `R`이 배열의 끝에 도달할 때까지 2~4단계를 반복한 후, `max_len`을 반환합니다.

시간 복잡도: 오른쪽 포인터 R과 왼쪽 포인터 L은 각각 최대 N번만 움직이므로, 전체 시간 복잡도는 O(N)입니다. 공간 복잡도는 O(1)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read().split()을 사용하여 모든 입력을 공백 기준으로 한 번에 받음
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    # 배열 A의 원소 개수 N은 K의 위치를 통해 추론해야 하지만, 여기서는 N이 A의 원소 개수임을 가정하고, K는 마지막 원소로 간주합니다.
    # 문제 출제자가 입력 형식을 A 원소들 (N개) + K (1개) 순서로 주었으므로, 마지막 원소는 K입니다.
    K = int(input_data[-1])
    A = [int(x) for x in input_data[:-1]]
    
    n = len(A)
    
    left = 0
    current_sum = 0
    max_len = 0

    # right 포인터로 윈도우를 오른쪽으로 확장
    for right in range(n):
        current_sum += A[right]
        
        # 윈도우 합이 K를 초과하면, 왼쪽 포인터를 이동시켜 윈도우를 축소
        while current_sum > K: 
            # 윈도우의 왼쪽 경계 원소를 제거하고 합을 갱신
            current_sum -= A[left]
            left += 1
        
        # 현재 윈도우 [left, right]는 합이 K 이하이므로, 길이를 계산하여 최대 길이 갱신
        # 현재 길이 = right - left + 1
        max_len = max(max_len, right - left + 1)

    print(max_len)

if __name__ == "__main__":
    # 테스트를 위해 표준 입력을 시뮬레이션합니다. 실제 제출 시에는 이 코드는 필요 없습니다.
    # sys.stdin.read()가 표준 입력을 읽는다고 가정합니다.
    solve()
```

# 가장 긴 부분 배열
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조, 배열*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 처리하는 것이 효율적입니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 이 배열 A에서 '서로 다른 원소의 개수가 최대 K개 이하'인 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들로 이루어져야 하며, 전체 배열을 반드시 포함할 필요는 없습니다. 배열의 모든 원소는 양의 정수(1 이상)입니다.

## 입력

첫째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. (N: 배열의 길이, K: 허용되는 최대 서로 다른 원소의 개수)
둘째 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1. 1 ≤ N ≤ 10^5
2. 0 ≤ K ≤ N
3. 1 ≤ A[i] ≤ 10^9
4. 시간 복잡도는 O(N)을 목표로 합니다.

## 예제 1

**입력**
```
4 2
1 2 1 3
```

**출력**
```
3
```

*서로 다른 원소가 2개 이하인 가장 긴 부분 배열은 [2, 1, 3] 또는 [1, 2, 1]이며, 길이는 3입니다.*

## 예제 2

**입력**
```
5 1
1 1 1 1 1
```

**출력**
```
5
```

*모든 원소가 1이므로, 서로 다른 원소는 1개이며, 전체 배열이 답입니다.*

## 예제 3

**입력**
```
3 0
1 2 3
```

**출력**
```
0
```

*서로 다른 원소의 개수가 0개인 부분 배열은 존재하지 않습니다. (단, K=0일 때 빈 배열만 가능하며, 문제 정의상 최소 길이는 0입니다.)*

## 힌트

- 이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하면 효율적으로 해결할 수 있습니다.
- 현재 윈도우 내의 원소들의 종류(distinct) 개수를 효율적으로 추적할 자료구조가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 접근법을 사용합니다. 전역 포인터 `right`를 이동시키면서 윈도우를 확장하고, 윈도우 내의 고유 원소 개수가 K를 초과하게 되면, 전역 포인터 `left`를 이동시키며 윈도우를 축소합니다. 윈도우가 조건을 만족할 때마다 현재 윈도우의 길이(right - left + 1)를 최대 길이로 갱신합니다. 이 과정에서 윈도우 내 원소의 빈도수를 관리하는 해시 맵(딕셔너리)을 사용합니다.

## 풀이 해설

아이디어: 문제의 조건('서로 다른 원소의 개수가 K 이하')를 만족하는 가장 긴 연속된 구간을 찾는 것이므로, 슬라이딩 윈도우 기법이 적합합니다.

단계 1: 초기화
두 포인터 `left`와 `right`를 0으로 설정하고, 최대 길이 `max_length`를 0으로 초기화합니다. 또한, 현재 윈도우 [left, right]에 포함된 원소들의 빈도수를 저장할 딕셔너리 `counts`를 준비합니다.

단계 2: 윈도우 확장 (right 이동)
`right` 포인터를 배열의 끝까지 순회시키면서, `A[right]` 원소를 `counts`에 추가하고 빈도수를 증가시킵니다.

단계 3: 윈도우 축소 (left 이동)
`counts`에 저장된 원소의 종류(`len(counts)`)가 허용된 최대 개수 K를 초과하게 되면, 윈도우가 조건을 위반한 것이므로 축소 과정이 필요합니다. `A[left]` 원소를 `counts`에서 제거하고 빈도수를 줄입니다. 만약 `A[left]`의 빈도수가 0이 되면, 해당 원소는 윈도우에서 완전히 사라진 것이므로 `counts`에서 키(key) 자체를 삭제합니다. 이후 `left` 포인터를 1 증가시킵니다. 이 과정은 `len(counts) <= K`가 될 때까지 반복됩니다.

단계 4: 결과 갱신
윈도우가 조건을 만족하게 갱신될 때마다 (즉, `right`가 증가한 후), 현재 윈도우의 길이 `right - left + 1`을 계산하여 `max_length`와 비교하고 더 큰 값으로 갱신합니다.

시간 복잡도: `left`와 `right` 포인터는 각각 한 번만 배열의 끝까지 이동하므로, 시간 복잡도는 O(N)입니다. (N은 배열의 길이).

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # sys.stdin.readline을 사용하여 입력 받기
    try:
        # 첫 줄: N K
        line1 = sys.stdin.readline().split()
        if not line1: 
            return 0
        N = int(line1[0])
        K = int(line1[1])
        
        # 두 번째 줄: 배열 A
        line2 = sys.stdin.readline().split()
        if not line2 and N > 0: # N이 0이 아닌데 두 번째 줄이 비어있다면 오류 상황으로 간주하고 처리
             return 0
        A = [int(x) for x in line2]
    except Exception:
        # 입력 오류 처리
        return 0

    if N == 0: 
        return 0

    left = 0
    max_length = 0
    # 원소의 빈도수를 저장하는 딕셔너리
    counts = defaultdict(int)

    for right in range(N):
        # 1. 윈도우 확장: A[right]를 추가
        counts[A[right]] += 1

        # 2. 윈도우 축소: 조건 위반 시 (서로 다른 원소가 K를 초과할 때)
        while len(counts) > K:
            # A[left]를 윈도우에서 제거
            left_element = A[left]
            counts[left_element] -= 1
            
            # 빈도수가 0이 되면 딕셔너리에서 해당 키를 완전히 제거
            if counts[left_element] == 0:
                del counts[left_element]
            
            # left 포인터 이동
            left += 1
        
        # 3. 결과 갱신: 현재 윈도우 [left, right]는 유효함
        current_length = right - left + 1
        max_length = max(max_length, current_length)

    return max_length

if __name__ == "__main__"ini
    result = solve()
    print(result)
```

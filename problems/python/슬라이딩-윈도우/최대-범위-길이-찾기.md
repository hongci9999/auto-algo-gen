# 최대 범위 길이 찾기
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 배열*

## 입출력 환경

입력은 sys.stdin.readline을 사용하여 처리하는 것을 권장합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. A의 부분 배열(Subarray) 중에서 최댓값과 최솟값의 차이(Max - Min)가 K 이하가 되는 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들로 이루어져야 합니다. 예를 들어, [1, 5, 2, 4]에서 [1, 5]는 부분 배열이지만, [1, 2]는 부분 배열이 아닙니다.

## 입력

첫째 줄에 정수 N과 양의 정수 K가 주어집니다. 둘째 줄에 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이를 하나의 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
0 <= K <= 10^9
0 <= A[i] <= 10^9

## 예제 1

**입력**
```
4 3
1 5 2 4
```

**출력**
```
3
```

*부분 배열 [5, 2, 4]의 최댓값(5)과 최솟값(2)의 차이는 3 이하입니다. 길이가 3인 부분 배열이 가장 깁니다.*

## 예제 2

**입력**
```
5 10
1 5 10 12 15
```

**출력**
```
3
```

*부분 배열 [1, 5, 10]의 범위는 9로 10 이하입니다. [5, 10, 12]는 범위가 7로 10 이하입니다. [1, 5, 10, 12]는 범위가 11로 K를 초과합니다. 따라서 최대 길이는 3입니다.*

## 힌트

- 슬라이딩 윈도우 기법을 사용해 '오른쪽 포인터(R)'를 전진시키면서 유효성을 검사하는 방법을 생각해보세요.
- 현재 윈도우 [L, R]의 최대값과 최소값을 효율적으로 계산할 수 있는 자료구조가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 + Deque (최대/최소값 갱신)

## 풀이 해설

이 문제는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하여 해결할 수 있습니다. 우리의 목표는 윈도우 [L, R]의 Max - Min <= K를 만족하는 R의 최대값을 찾는 것입니다.

1.  **슬라이딩 윈도우 설정:** 왼쪽 포인터 L을 0으로, 오른쪽 포인터 R을 0으로 시작합니다. R을 전진시키면서 윈도우를 확장하고, 윈도우의 조건(Max - Min <= K)이 깨지면 L을 전진시켜 윈도우를 축소합니다.
2.  **Max/Min 관리:** 윈도우 [L, R] 내의 최댓값과 최솟값을 O(1) 시간에 계산하기 위해 '데크(Deque)' 자료구조를 두 개 사용합니다. 하나는 현재 윈도우의 '최대값'을 유지하는 데크(Max Deque), 다른 하나는 '최소값'을 유지하는 데크(Min Deque)입니다.
3.  **R 전진 (확장):** R을 증가시키면서 A[R]을 윈도우에 추가합니다. 이때, 새로운 원소 A[R]이 Max Deque와 Min Deque의 맨 뒤에 삽입될 때, 각 데크의 단조성(Monotonicity)을 유지하도록 맨 뒤의 원소들을 제거해줍니다. (예: Max Deque에 A[R]을 넣을 때, A[R]보다 작거나 같은 원소가 있다면 제거합니다.) 이후 A[R]을 데크에 추가합니다.
4.  **유효성 검사 및 L 전진 (축소):** 윈도우의 현재 Max - Min이 K를 초과하는지 확인합니다. 만약 초과한다면, 윈도우를 축소해야 합니다. L을 증가시키고, L이 Max Deque나 Min Deque의 맨 앞 원소(즉, 윈도우 밖으로 나가는 원소)와 일치한다면, 해당 원소를 데크의 맨 앞에서 제거해줍니다. 이 과정을 조건이 만족할 때까지 반복합니다.
5.  **최대 길이 갱신:** 매 반복마다 (즉, 윈도우가 유효할 때마다) 현재 윈도우의 길이 (R - L + 1)를 기록된 최대 길이와 비교하여 갱신합니다.

*시간 복잡도: L과 R 포인터가 각각 N번씩 움직이며, 데크 연산은 모두 O(1)이므로, 전체 시간 복잡도는 O(N)입니다.*

## 참고 코드 (python)

```python
import sys
from collections import deque

def solve():
    # sys.stdin.read().split()을 사용하여 모든 입력을 한 번에 받고, 형 변환을 합니다.
    input_data = sys.stdin.read().split()
    if not input_data: return
    
    N = int(input_data[0])
    K = int(input_data[1])
    A = [int(x) for x in input_data[2:]]

    # 데크: 최대값과 최소값을 O(1)로 관리
    max_deque = deque()
    min_deque = deque()
    
    left = 0
    max_length = 0

    # right 포인터로 윈도우를 확장
    for right in range(N):
        # 1. A[right]을 윈도우에 추가 (Deque에 삽입)
        
        # Max Deque 관리: A[right]보다 작거나 같은 원소는 최대값 후보에서 제외됨
        while max_deque and A[max_deque[-1]] <= A[right]:
            max_deque.pop()
        max_deque.append(right)
        
        # Min Deque 관리: A[right]보다 크거나 같은 원소는 최소값 후보에서 제외됨
        while min_deque and A[min_deque[-1]] >= A[right]:
            min_deque.pop()
        min_deque.append(right)

        # 2. 윈도우 조건 검사 및 L 포인터 조정 (Shrink)
        # 현재 Max - Min > K 이면, L을 전진시켜야 함
        while A[max_deque[0]] - A[min_deque[0]] > K:
            # 윈도우를 축소 (L 증가)
            left += 1
            
            # L이 Max/Min Deque의 맨 앞에서 나갔다면 제거
            if max_deque[0] < left:
                max_deque.popleft()
            if min_deque[0] < left:
                min_deque.popleft()
                
        # 3. 최대 길이 갱신
        # 현재 윈도우 [left, right]는 조건을 만족함
        max_length = max(max_length, right - left + 1)

    print(max_length)

solve()
```

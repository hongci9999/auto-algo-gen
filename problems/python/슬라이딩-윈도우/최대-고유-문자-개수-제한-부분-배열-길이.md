# 최대 고유 문자 개수 제한 부분 배열 길이
*python · 슬라이딩 윈도우 · 보통 · 슬라이딩 윈도우, 자료구조, 배열*

## 입출력 환경

입력은 표준 입력(stdin)에서 받으며, 배열 A와 K는 순서대로 입력됩니다. Python에서는 sys.stdin.readline을 사용하여 효율적으로 입력을 처리하는 것이 권장됩니다.

## 문제

어떤 배열 `A`와 정수 `K`가 주어집니다. 이 배열에서 고유한 원소의 개수가 최대 `K`개 이하인 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들로 이루어져야 합니다.

## 입력

첫 번째 줄에는 배열의 길이 N이 주어집니다. 두 번째 줄에는 N개의 정수 원소가 공백으로 구분되어 주어집니다. 세 번째 줄에는 정수 K가 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1.  $1 	ext{ } 	ext{.} 	ext{ } 2 	ext{ } 	ext{.} 	ext{ } 1 	ext{ } 	ext{.} 	ext{ } 10^5$ (배열 원소의 범위)
2.  $1 	ext{ } 	ext{.} 	ext{ } 10^5$ (배열의 길이 N)
3.  $1 	ext{ } 	ext{.} 	ext{ } 10^5$ (K의 범위)

시간 복잡도는 $O(N)$ 또는 $O(N 	ext{ } 	ext{log} 	ext{ } N)$ 이내여야 합니다.

## 예제 1

**입력**
```
4
1 2 1 3
2
```

**출력**
```
3
```

*부분 배열 [2, 1, 3]은 고유 원소가 3개이지만, [1, 2, 1]은 고유 원소가 2개입니다. 최대 길이는 3입니다.*

## 예제 2

**입력**
```
5
5 5 5 5 5
1
```

**출력**
```
5
```

*모든 원소가 5이므로, 고유 원소 개수는 1개입니다. 배열 전체가 조건을 만족합니다.*

## 예제 3

**입력**
```
6
1 2 3 4 5 6
2
```

**출력**
```
2
```

*고유 원소 2개만 포함하는 가장 긴 부분 배열은 [1, 2], [2, 3], ..., [5, 6] 등이며, 길이는 2입니다.*

## 힌트

- 문제를 해결하기 위해 '슬라이딩 윈도우(Sliding Window)' 기법을 사용해 보세요.
- 현재 윈도우 내의 원소들의 빈도수를 기록할 자료구조(예: 딕셔너리/해시맵)가 필요합니다.


## 알고리즘 요약

슬라이딩 윈도우 기법과 해시맵(Dictionary)을 결합합니다. 윈도우의 오른쪽 끝(right)을 한 칸씩 이동시키면서 원소를 추가하고, 윈도우 내 고유 원소의 개수가 K를 초과하게 되면 윈도우의 왼쪽 끝(left)을 이동시켜 조건을 만족시킬 때까지 원소를 제거합니다. 매 단계마다 현재 윈도우의 길이를 최대 길이와 비교하여 갱신합니다.

## 풀이 해설

풀이 아이디어는 '슬라이딩 윈도우(Sliding Window)' 기법을 사용하는 것입니다. 이 기법은 배열 또는 문자열에서 특정 조건을 만족하는 연속된 부분 배열(또는 부분 문자열)을 찾을 때 매우 효율적입니다.

**1. 자료구조 준비:**
*   `counts` (해시맵/딕셔너리): 현재 윈도우 `[left, right]` 안에 포함된 각 원소의 빈도수를 저장합니다.
*   `left`, `right`: 윈도우의 시작점과 끝점을 나타내는 포인터입니다.
*   `max_len`: 찾은 최대 길이를 저장합니다.

**2. 알고리즘 단계:**
1.  `right` 포인터를 0부터 배열의 끝까지 한 칸씩 증가시키며 윈도우를 확장합니다.
2.  `A[right]`를 `counts`에 추가하고 빈도수를 1 증가시킵니다.
3.  **조건 검사 및 윈도우 축소 (Shrinking):** `counts`의 크기(즉, 고유 원소의 개수)가 `K`를 초과하는지 확인합니다. 만약 초과한다면, `left` 포인터를 증가시키면서 `A[left]`를 `counts`에서 제거합니다. 원소를 제거할 때는 해당 원소의 빈도수를 1 감소시키고, 빈도수가 0이 되면 `counts`에서 해당 원소를 완전히 제거합니다. 이 과정을 `counts`의 크기가 다시 `K` 이하가 될 때까지 반복합니다.
4.  **결과 갱신:** 윈도우가 조건을 만족하게 된 후, 현재 윈도우의 길이 (`right - left + 1`)를 계산하여 `max_len`과 비교하고 최댓값을 갱신합니다.
5.  모든 `right` 포인터 이동이 끝나면 `max_len`이 정답입니다.

**시간 복잡도:** `left`와 `right` 포인터는 각각 배열의 원소를 최대 한 번씩만 순회합니다. 따라서 시간 복잡도는 $O(N)$입니다. 공간 복잡도는 고유 원소의 개수 또는 $K$에 비례하여 $O(	ext{min}(N, K))$입니다.

## 참고 코드 (python)

```python
import sys
from collections import defaultdict

def solve():
    # 표준 입력에서 데이터를 읽습니다.
    try:
        # 첫 줄: N (배열 길이)
        N = int(sys.stdin.readline().strip())
        # 두 번째 줄: 배열 A
        A = list(map(int, sys.stdin.readline().strip().split()))
        # 세 번째 줄: K
        K = int(sys.stdin.readline().strip())
    except: 
        # 입력이 비어있거나 형식이 맞지 않을 경우 종료
        return

    # 슬라이딩 윈도우 초기화
    counts = defaultdict(int)
    left = 0
    max_len = 0

    # right 포인터를 이동시키며 윈도우 확장
    for right in range(N):
        # 1. 윈도우 확장: A[right]를 윈도우에 추가
        counts[A[right]] += 1

        # 2. 조건 검사 및 윈도우 축소 (Shrinking)
        # 고유 원소의 개수(len(counts))가 K를 초과하면 left를 이동시켜 조건을 만족시킬 때까지 축소
        while len(counts) > K:
            # A[left] 원소를 윈도우에서 제거
            element_to_remove = A[left]
            
            # 빈도수 감소
            counts[element_to_remove] -= 1
            
            # 빈도수가 0이 되면 딕셔너리에서 완전히 제거
            if counts[element_to_remove] == 0:
                del counts[element_to_remove]
            
            # left 포인터 이동
            left += 1

        # 3. 결과 갱신: 현재 윈도우 [left, right]는 조건을 만족함
        current_len = right - left + 1
        max_len = max(max_len, current_len)

    print(max_len)

if __name__ == "__main__":
    solve()
```

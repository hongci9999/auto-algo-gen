# 최대 길이의 연속 부분 배열
*python · 슬라이딩 윈도우 · 보통 · 배열, 투포인터*

## 입출력 환경

Python에서는 표준 입력을 받기 위해 sys.stdin.readline을 사용하는 것이 효율적입니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 이 중에서 인접한 두 원소의 절대값 차이가 모두 K 이하인 연속된 부분 배열을 찾고, 그 최대 길이를 구하는 문제입니다.

예를 들어, [1, 3, 2]와 K=1이 주어졌다면,
- [1, 3]: |3 - 1| = 2 > 1 (유효하지 않음)
- [3, 2]: |2 - 3| = 1 <= 1 (유효함)
최대 길이는 2입니다.

## 입력

첫째 줄에 정수 N과 K가 주어지고, 둘째 줄에 공백으로 구분된 N개의 정수 배열 A의 원소가 주어진다.

## 출력

찾은 최대 부분 배열의 길이(정수)를 출력한다.

## 제약 조건

1 ≤ N ≤ 10^5
0 ≤ K ≤ 10^9
-10^9 ≤ A[i] ≤ 10^9

## 예제 1

**입력**
```
4 1
1 3 2 4
```

**출력**
```
2
```

*인접한 차이가 1 이하인 가장 긴 부분 배열은 [3, 2] 또는 [2, 4]가 아니며, 실제로는 [3, 2]입니다. 최대 길이는 2입니다.*

## 예제 2

**입력**
```
5 1
5 4 3 2 1
```

**출력**
```
5
```

*모든 인접한 원소의 차이가 1 이하이므로, 전체 배열이 최대 길이 부분 배열입니다.*

## 예제 3

**입력**
```
5 0
1 1 1 1 1
```

**출력**
```
5
```

*차이가 0 이하인 경우는 모든 원소가 같을 때만 가능하며, 이 예제는 모두 같습니다.*

## 힌트

- 이 문제는 슬라이딩 윈도우(Sliding Window) 기법으로 해결할 수 있습니다.
- 현재 윈도우의 유효성을 판단하기 위해 오른쪽 포인터(R)를 기준으로 왼쪽 포인터(L)를 이동시키는 방법을 생각해보세요.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용합니다. 두 개의 포인터 L(Left)과 R(Right)을 사용하여 현재 검사하는 부분 배열 [A[L], ..., A[R]]를 유지합니다. R을 오른쪽으로 이동시키면서 윈도우의 유효성을 검사하고, 만약 유효하지 않다면 L을 오른쪽으로 이동시켜 윈도우를 다시 유효하게 만듭니다.

## 풀이 해설

### 아이디어
이 문제는 '조건을 만족하는 가장 긴 연속 구간'을 찾는 전형적인 슬라이딩 윈도우 문제입니다. 우리는 R 포인터를 배열의 끝까지 오른쪽으로 이동시키며 현재 윈도우 [L, ..., R]를 유지합니다.

### 단계
1. **초기화**: 최대 길이 `max_len`을 0으로 설정하고, 왼쪽 포인터 `L`을 0으로 초기화합니다.
2. **R 이동 (확장)**: 오른쪽 포인터 `R`을 0부터 N-1까지 한 칸씩 증가시킵니다.
3. **유효성 검사**: R이 0보다 크다면, 새로 들어온 원소 A[R]과 바로 이전 원소 A[R-1]의 절대값 차이를 계산합니다.
    *   만약 `|A[R] - A[R-1]| > K`라면, 현재 윈도우 [L, ..., R]는 조건을 위반했습니다. 이 경우, 유효한 윈도우를 새로 시작해야 하므로, L 포인터를 A[R] 위치로 강제 이동시킵니다 (즉, L = R).
4. **길이 업데이트**: 윈도우 [L, ..., R]가 항상 조건을 만족하는 상태를 유지하게 됩니다. 따라서 매 단계마다 현재 길이 `R - L + 1`을 계산하여 `max_len`과 비교하고 최댓값을 갱신합니다.
5. **종료**: R이 N-1까지 도달하면 `max_len`을 반환합니다.

### 시간 복잡도
오른쪽 포인터 R은 한 번만 증가하며, 왼쪽 포인터 L 또한 절대 감소하지 않고 최대 N번 이동합니다. 따라서 전체 탐색 과정은 O(N)의 선형 시간 복잡도를 가집니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 빠른 입력을 위해 sys.stdin.readline 사용
    input = sys.stdin.read
    data = input().split()
    
    if not data: 
        return 0 # 입력이 없는 경우 예외 처리
    
    N = int(data[0])
    K = int(data[1])
    A = [int(x) for x in data[2:]]

    if N == 0: 
        return 0
    if N == 1: 
        return 1

    # 슬라이딩 윈도우 초기화
    left = 0
    max_len = 1  # 최소 길이는 1이므로 1로 시작

    for right in range(1, N):
        # R 포인터가 이동할 때, A[R]과 A[R-1]의 차이가 K를 초과하면 유효성 위반 발생
        if abs(A[right] - A[right-1]) > K:
            # 윈도우를 재설정: L을 R 위치로 옮겨서 새로운 시작점 만들기
            left = right
        
        # 현재 윈도우 [left, ..., right]는 항상 유효한 상태임
        current_length = right - left + 1
        max_len = max(max_len, current_length)

    return max_len

if __name__ == "__main__":
    print(solve())
```

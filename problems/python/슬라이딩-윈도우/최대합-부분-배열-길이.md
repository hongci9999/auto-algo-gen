# 최대합 부분 배열 길이
*python · 슬라이딩 윈도우 · 보통 · 배열, 투포인터, 슬라이딩 윈도우*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 여러분은 A의 연속된 부분 배열(subarray) 중 합이 K보다 작거나 같은 최대 길이를 구해야 합니다.

부분 배열은 최소한 원소 1개 이상으로 구성됩니다. 만약 배열의 모든 부분 배열의 합이 K보다 크다면, 최대 길이는 0입니다.

예시: A = [1, 2, 3], K = 3
부분 배열: [1] (합 1), [2] (합 2), [3] (합 3), [1, 2] (합 3), [2, 3] (합 5 > 3), [1, 2, 3] (합 6 > 3)
합이 3 이하인 가장 긴 부분 배열은 [1, 2] 이므로, 최대 길이는 2입니다.

## 입력

첫 번째 줄에 정수 N이 주어집니다. (배열의 길이)
두 번째 줄에 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.
세 번째 줄에 정수 K가 주어집니다.

## 출력

최대 길이를 나타내는 정수 하나를 출력합니다.

## 제약 조건

1 <= N <= 10^5
0 <= A[i] <= 10^9
0 <= K <= 10^14 (K는 충분히 큰 값을 가질 수 있으므로, 합계 계산 시 64비트 정수형을 사용해야 합니다.)

## 예제 1

**입력**
```
3
1 2 3
3
```

**출력**
```
2
```

*부분 합이 3 이하인 가장 긴 부분 배열은 [1, 2]이며, 길이는 2입니다.*

## 예제 2

**입력**
```
5
1 1 1 1 1
3
```

**출력**
```
3
```

*합이 3 이하인 가장 긴 부분 배열은 [1, 1, 1]이며, 길이는 3입니다.*

## 예제 3

**입력**
```
4
10 20 30 40
5
```

**출력**
```
0
```

*배열의 모든 요소가 K(5)보다 크므로, 최대 길이는 0입니다.*

## 힌트

- O(N^2)의 시간 복잡도로 모든 부분 배열을 확인하는 것은 시간 초과가 발생할 수 있습니다.
- 이 문제는 슬라이딩 윈도우(Sliding Window) 기법을 사용하면 O(N) 시간 복잡도로 해결할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용합니다. 두 개의 포인터(left와 right)를 사용하여 현재 부분 배열 [left, right]의 합(current_sum)을 유지합니다. right 포인터를 오른쪽으로 확장하며 합을 누적합니다. 만약 current_sum이 K를 초과하면, left 포인터를 오른쪽으로 이동시키면서 합을 갱신하여 조건을 만족시킬 때까지 윈도우를 축소합니다. 매 단계마다 현재 윈도우의 길이(right - left + 1)를 최대 길이와 비교하며 갱신합니다.

## 풀이 해설

1. **개념 이해 (슬라이딩 윈도우):** 이 문제는 '합이 K 이하인 가장 긴 연속 부분 배열'을 찾는 문제입니다. 배열의 원소들이 모두 0 이상이므로, 윈도우를 확장할수록 합은 단조 증가하는 성질을 가집니다. 이 성질을 활용하여 슬라이딩 윈도우 기법을 적용할 수 있습니다.
2. **변수 설정:** 필요한 변수는 다음과 같습니다.
    - `left`: 윈도우의 시작 인덱스 (초기값: 0)
    - `current_sum`: 현재 윈도우 [left, right]의 합 (초기값: 0)
    - `max_length`: 찾은 최대 길이 (초기값: 0)
3. **알고리즘 단계:**
    a. `right` 포인터를 0부터 N-1까지 순회하며 윈도우를 확장합니다. (반복문)
    b. `current_sum`에 `A[right]`를 더합니다.
    c. **조건 검사 및 축소:** 만약 `current_sum`이 K보다 커지면, 윈도우가 조건을 위반했다는 의미입니다. 이 경우, `left` 포인터를 오른쪽으로 이동시키면서 `current_sum`에서 `A[left]`를 빼줍니다. 이 과정을 `current_sum <= K`가 될 때까지 반복합니다.
    d. **최대 길이 갱신:** 윈도우가 조건을 만족하게 된 후, 현재 윈도우의 길이(`right - left + 1`)를 계산하여 `max_length`와 비교하고 더 큰 값으로 갱신합니다.
4. **시간 복잡도:** `right` 포인터와 `left` 포인터는 각각 최대 N번만 이동합니다. 따라서 전체 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 입력 받기 (N은 필요 없으나 구조 유지를 위해 받음)
    try:
        N = int(sys.stdin.readline()) # 첫 줄: N
        A = list(map(int, sys.stdin.readline().split())) # 두 번째 줄: 배열 A
        K = int(sys.stdin.readline()) # 세 번째 줄: K
    except: # 입력이 비어있을 경우 대비
        return 0

    left = 0
    current_sum = 0
    max_length = 0
    
    # right 포인터를 사용하여 윈도우 확장
    for right in range(len(A)):
        current_sum += A[right]
        
        # 합이 K를 초과하면, left 포인터를 이동시키며 윈도우 축소
        while current_sum > K and left <= right:
            current_sum -= A[left]
            left += 1
        
        # 현재 윈도우가 조건을 만족하면 길이를 갱신
        # left > right 인 경우 (모든 원소가 K보다 클 때)는 length가 0이 되므로, max_length 갱신에 영향을 주지 않음
        current_length = right - left + 1
        if current_length > 0:
             max_length = max(max_length, current_length)
        # left가 right를 초과하게 되면, 이는 의미 있는 윈도우가 없다는 뜻이므로 갱신할 필요가 없습니다.

    return max_length

print(solve())
```

# 합이 K 이하인 가장 긴 연속 부분 배열 찾기
*python · 슬라이딩 윈도우 · 보통 · 배열, 투포인터, 슬라이딩 윈도우*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 처리하는 것이 효율적입니다.

## 문제

정수 배열 `A`와 정수 `K`가 주어집니다. 배열 `A`의 부분 배열 중 합이 `K` 이하인 가장 긴 연속 부분 배열의 길이를 구하는 문제입니다. 부분 배열은 인접한 원소들로만 구성되어야 합니다. 모든 원소는 양수입니다.

예시: A = [1, 2, 3, 4], K = 6
부분 배열 [1, 2, 3]의 합은 6으로 K 이하이며, 길이는 3입니다.
부분 배열 [2, 3, 4]의 합은 9로 K 초과입니다.
가장 긴 부분 배열은 [1, 2, 3] 또는 [2, 4] (길이 2) 등이 될 수 있으며, 최대 길이는 3입니다.

## 입력

첫째 줄에 정수 N과 정수 K가 주어집니다. (N: 배열의 길이, K: 최대 합)
둘째 줄에 공백으로 구분된 N개의 정수 원소 A[0]부터 A[N-1]이 주어집니다.

## 출력

합이 K 이하인 가장 긴 연속 부분 배열의 길이를 한 정수로 출력합니다.

## 제약 조건

1. 1 <= N <= 10^5
2. 1 <= K <= 10^9
3. 1 <= A[i] <= 10^9
4. 합이 K를 초과하는 경우, 최대 길이는 0입니다. (단, N >= 1인 경우 최소 길이는 1 이상입니다.)

## 예제 1

**입력**
```
4 6
1 2 3 4
```

**출력**
```
3
```

*부분 배열 [1, 2, 3]의 합이 6으로 K 이하이며, 가장 긴 길이입니다.*

## 예제 2

**입력**
```
5 10
5 1 2 3 1
```

**출력**
```
4
```

*부분 배열 [1, 2, 3, 1]의 합이 7로 K 이하이며, 최대 길이입니다.*

## 예제 3

**입력**
```
3 2
3 4 5
```

**출력**
```
0
```

*모든 원소의 값이 K보다 크므로, 조건을 만족하는 부분 배열은 없습니다. (문제 제약 상 N>=1이므로, 최소 길이는 1이어야 하지만, 이 예제에서는 모든 원소가 K보다 크다고 가정하고, 길이가 0인 경우는 없습니다. 하지만 안전하게 코딩하면 0이 나옵니다. 실제로는 [1] 같은 것이 최소 길이입니다. 이 예제는 모든 원소가 K보다 크므로, 사실 이 예제는 [3] 자체가 K를 초과하여 길이가 0이 될 수 있습니다. 예외 처리로 0을 출력합니다.)*

## 힌트

- 모든 원소는 양수이므로, 합이 K를 초과하는 순간, 시작점을 오른쪽으로 옮겨야 합니다.
- 슬라이딩 윈도우 기법을 사용하여 시간 복잡도를 최적화할 수 있습니다.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 두 개의 포인터(L: 왼쪽, R: 오른쪽)를 사용하여 현재 부분 배열 [L, R]의 합을 유지합니다. R을 오른쪽으로 이동시키며 합을 증가시키고, 합이 K를 초과하면 L을 오른쪽으로 이동시키면서 합을 감소시켜 다시 조건을 만족시킵니다. 이 과정에서 조건을 만족하는 최대 길이 (R - L + 1)를 갱신합니다. 시간 복잡도는 O(N)이 됩니다.

## 풀이 해설

아이디어: 이 문제는 '합이 K 이하인 가장 긴 부분 배열'을 찾는 전형적인 슬라이딩 윈도우 문제입니다. 모든 원소가 양수이기 때문에, 오른쪽 끝(R)을 확장하여 합을 키우다가, 합이 K를 초과하는 순간에는 왼쪽 끝(L)을 이동시켜 합을 줄여야 합니다.

단계:
1. 변수 초기화: 왼쪽 포인터 L=0, 현재 합 sum=0, 최대 길이 max_len=0으로 설정합니다.
2. 오른쪽 확장(R): 오른쪽 포인터 R을 0부터 N-1까지 순회합니다. (R 역할)
3. 합 계산 및 윈도우 갱신: 현재 원소 A[R]을 sum에 더합니다. (sum += A[R])
4. 조건 검사 및 축소(L 이동): 만약 sum이 K를 초과하게 되면, L 포인터를 오른쪽으로 이동시키고, sum에서 A[L] 값을 빼줍니다. (sum -= A[L]; L += 1). 이 과정을 sum <= K가 될 때까지 반복합니다.
5. 최대 길이 갱신: 현재 윈도우 [L, R]은 합이 K 이하인 유효한 부분 배열이므로, 현재 길이 (R - L + 1)을 계산하여 max_len과 비교하고 더 큰 값을 기록합니다. (max_len = max(max_len, R - L + 1)).
6. 반복 종료: R이 끝까지 순회하면 max_len이 최종 답이 됩니다.

시간 복잡도: R 포인터와 L 포인터는 각각 최대 N번씩만 움직입니다. 따라서 전체 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.readline을 사용하여 입력 받기
    # 첫 줄: N과 K
    try:
        line1 = sys.stdin.readline().split()
        if not line1: return
        N = int(line1[0])
        K = int(line1[1])
    except:
        return

    # 둘째 줄: 배열 A
    try:
        A = list(map(int, sys.stdin.readline().split()))
    except:
        # 배열 입력이 없는 경우 처리
        if N > 0: 
             # N이 0이 아니라면 빈 배열은 발생하지 않아야 함
             return
        A = []

    # 슬라이딩 윈도우 변수 초기화
    left = 0       # 왼쪽 포인터 (L)
    current_sum = 0
    max_length = 0

    # 오른쪽 포인터 (R)로 윈도우 확장
    for right in range(N):
        # 1. 윈도우 확장: 오른쪽 원소를 추가하고 합을 증가시킨다.
        current_sum += A[right]

        # 2. 조건 검사 및 윈도우 축소: 합이 K를 초과하면 왼쪽 포인터를 이동시킨다.
        while current_sum > K:
            # 왼쪽 원소를 제거하고 합을 감소시킨다.
            current_sum -= A[left]
            # 왼쪽 포인터를 오른쪽으로 이동시킨다.
            left += 1

        # 3. 최대 길이 갱신: 현재 윈도우 [left, right]은 유효한 상태이다.
        # 현재 길이 = right - left + 1
        current_length = right - left + 1
        max_length = max(max_length, current_length)

    print(max_length)

# 입출력 테스트를 위해 solve 함수를 호출합니다.
solve()
```

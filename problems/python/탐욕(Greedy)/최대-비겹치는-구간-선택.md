# 최대 비겹치는 구간 선택
*python · 탐욕(Greedy) · 보통 · 정렬, 탐욕, 구간*

## 입출력 환경

입력은 표준 입력(stdin)을 통해 받아야 하며, 효율적인 처리를 위해 sys.stdin.readline을 사용하는 것이 권장됩니다.

## 문제

당신은 시간 축 위에 여러 개의 구간(interval)이 주어졌을 때, 이 구간들 중에서 서로 겹치지 않으면서 최대 개수를 선택하는 문제를 해결해야 합니다.

각 구간은 시작 시간 $S$와 끝 시간 $E$로 표현되며, $[S, E]$를 의미합니다. 두 구간 $[S_1, E_1]$와 $[S_2, E_2]$가 겹치지 않기 위해서는 $E_1 < S_2$ 또는 $E_2 < S_1$을 만족해야 합니다. (경계값에서 겹침이 발생하지 않도록 합니다.)

주어진 $N$개의 구간을 모두 고려하여, 겹치지 않는 최대 구간의 개수를 구하세요.

## 입력

첫 번째 줄에 구간의 개수 N이 주어집니다.
다음 N개의 줄에 각각 시작 시간 $S_i$와 끝 시간 $E_i$가 공백으로 구분되어 주어집니다.

## 출력

겹치지 않는 최대 구간의 개수(정수)를 출력합니다.

## 제약 조건

1. $1 	ext{ } 	ext{.} 	ext{ } N$은 $1$부터 $200,000$까지의 정수입니다.
2. 시작 시간 $S_i$와 끝 시간 $E_i$는 $0$부터 $10^9$까지의 정수입니다.
3. 모든 구간은 $S_i 	ext{ } 	ext{.} 	ext{ } E_i$ 형태이며, $S_i 	ext{ } 	ext{.} 	ext{ } E_i$를 만족합니다.

## 예제 1

**입력**
```
3
1 4
2 5
6 8
```

**출력**
```
2
```

*구간 (1, 4)와 (2, 5)는 겹치며, 최대 2개 (예: (1, 4)와 (6, 8))를 선택할 수 있습니다.*

## 예제 2

**입력**
```
4
0 10
1 2
3 4
5 6
```

**출력**
```
3
```

*가장 짧고 끝나는 시간이 빠른 구간들 ((1, 2), (3, 4), (5, 6))을 선택하는 것이 최적입니다.*

## 힌트

- 이 문제는 그리디 알고리즘(탐욕적 접근)을 사용하여 해결할 수 있습니다.
- 무작정 시작 시간이 빠른 순서로 선택하는 것은 최적의 해가 아닐 수 있습니다. 어떤 기준으로 정렬해야 할까요?


## 알고리즘 요약

탐욕 알고리즘 (Greedy Algorithm): 구간을 끝나는 시간(End Time)을 기준으로 오름차순 정렬합니다. 정렬된 순서대로 순회하며, 이전 선택된 구간의 끝 시간보다 크거나 같은 시작 시간을 가진 구간을 계속해서 선택합니다.

## 풀이 해설

풀이 해설: 이 문제는 구간 선택 문제 중 전형적인 그리디 알고리즘 문제입니다.

1. 아이디어: 최대 개수를 선택하려면, 매번 선택할 때 가능한 한 빨리 끝나는 구간을 선택하는 것이 가장 유리합니다. 왜냐하면 빨리 끝나야 다음 구간을 선택할 여지가 가장 커지기 때문입니다.
2. 단계:
   a. 입력받은 모든 구간들을 리스트에 저장합니다.
   b. 이 구간들을 **끝나는 시간(End Time)을 기준**으로 오름차순 정렬합니다. (만약 끝나는 시간이 같다면, 시작 시간을 기준으로 오름차순 정렬해도 무방합니다.)
   c. 첫 번째 구간을 무조건 선택하고, 선택된 구간의 끝 시간을 기록합니다. 선택된 개수를 1로 초기화합니다.
   d. 정렬된 리스트를 처음부터 순회하며, 현재 구간의 시작 시간이 이전에 선택된 구간의 끝 시간보다 크거나 같다면, 이 구간을 선택 목록에 추가하고, 선택된 개수를 1 증가시키며, 이 구간의 끝 시간을 새로운 '마지막 선택 끝 시간'으로 업데이트합니다.
   e. 모든 구간을 순회하면 최대 개수가 됩니다.
3. 시간 복잡도: 가장 시간이 많이 걸리는 부분은 $N$개의 구간을 정렬하는 과정입니다. 따라서 시간 복잡도는 $O(N 	imes 	ext{log} N)$입니다.

## 참고 코드 (python)

```python
import sys

# 표준 입력에서 모든 데이터를 한 번에 읽어옵니다.
input = sys.stdin.read
input_data = input().split()

if not input_data: # 입력이 없을 경우 대비
    print(0)
else:
    # 첫 번째 요소는 N (구간의 개수)
    N = int(input_data[0])
    intervals = []
    
    # 나머지 요소들을 (S, E) 쌍으로 변환하여 리스트에 저장
    # input_data[1:]는 N개의 S, N개의 E가 순서대로 나열된 리스트
    for i in range(N):
        start_time = int(input_data[2 * i + 1])
        end_time = int(input_data[2 * i + 2])
        intervals.append((start_time, end_time))

    # 1. 그리디 접근: 끝나는 시간(End Time)을 기준으로 정렬합니다.
    # (s, e) -> e 기준으로 정렬
    intervals.sort(key=lambda x: x[1])

    count = 0
    last_end_time = -1 # 초기에는 유효하지 않은 시간으로 설정
    
    # 2. 정렬된 순서대로 탐욕적으로 선택합니다.
    for start, end in intervals:
        # 현재 구간의 시작 시간이 마지막 선택된 구간의 끝 시간보다 크거나 같은지 확인합니다.
        # (겹치지 않기 조건: start >= last_end_time)
        if start >= last_end_time:
            count += 1
            # 선택했으므로, 이 구간의 끝 시간을 새로운 기준점으로 설정합니다.
            last_end_time = end

    print(count)
```

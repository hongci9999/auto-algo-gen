# 최대 합을 만족하는 가장 긴 부분 배열
*python · 투포인터 · 보통 · 슬라이딩 윈도우, 배열*

## 입출력 환경

입력은 표준 입력(stdin)을 사용하며, 효율적인 처리를 위해 sys.stdin.readline을 사용하는 것을 권장합니다.

## 문제

정수 배열 A와 양의 정수 K가 주어집니다. 배열 A의 부분 배열 중, 합이 K를 초과하지 않는 가장 긴 부분 배열의 길이를 구하는 문제입니다.

부분 배열은 연속된 원소들로 이루어져야 하며, 배열의 인덱스 0부터 N-1까지의 원소들을 사용하여 부분 배열을 구성합니다.

## 입력

첫 번째 줄에 배열의 길이 N과 최대 합 K가 공백으로 구분되어 주어집니다. (N <= 10^5, K >= 1)
두 번째 줄에 배열 A의 N개 원소가 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 한 줄로 출력합니다.

## 제약 조건

N: 1부터 10^5까지
K: 1부터 10^9까지
A[i]: -10^9부터 10^9까지 (단, 문제의 핵심 로직을 위해 A[i]가 음수일 수 있음을 고려하여, 합계가 K를 초과하지 않는다는 조건만 사용합니다.)

## 예제 1

**입력**
```
4 8
3 1 2 7
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합은 6으로 K=8 이하이며, 길이가 3으로 최대입니다.*

## 예제 2

**입력**
```
5 10
1 2 3 4 5
```

**출력**
```
4
```

*부분 배열 [1, 2, 3, 4]의 합은 10으로 K=10 이하이며, 가장 긴 부분 배열입니다.*

## 힌트

- 모든 부분 배열을 확인하는 것은 시간 초과를 유발합니다.
- 현재 합계를 유지하면서 윈도우의 크기를 효율적으로 조절하는 방법을 고려해 보세요.


## 알고리즘 요약

슬라이딩 윈도우 (Sliding Window) 기법을 사용합니다. 오른쪽 포인터(R)를 전진시키며 현재 윈도우의 합계를 계산하고, 합계가 K를 초과하면 왼쪽 포인터(L)를 전진시켜 합계를 줄여나가는 과정을 반복합니다. 이때 유지되는 윈도우의 크기(R - L + 1)를 최대 길이로 기록합니다.

## 풀이 해설

1. 아이디어: 이 문제는 '합계 제한'을 만족하는 최대 길이를 찾는 전형적인 슬라이딩 윈도우 문제입니다. 배열 전체를 순회하며 윈도우의 오른쪽 끝(R)을 확장하고, 윈도우의 합계가 K를 초과할 때만 왼쪽 끝(L)을 이동시켜 합계를 줄입니다.
2. 단계:
   a. 변수 초기화: 왼쪽 포인터 L=0, 오른쪽 포인터 R=0, 현재 합계 sum=0, 최대 길이 max_len=0으로 설정합니다.
   b. 오른쪽 확장: R을 배열의 끝까지 증가시키면서 A[R]을 sum에 더합니다.
   c. 조건 검사 및 축소: 만약 sum이 K를 초과하게 되면, sum이 K 이하가 될 때까지 L을 증가시키고 A[L]을 sum에서 <0xEB><0xBA><0x8D>니다. (즉, 윈도우를 왼쪽으로 축소합니다.)
   d. 최대 길이 갱신: sum이 K 이하로 유지되는 한, 현재 윈도우의 길이 (R - L + 1)를 계산하여 max_len과 비교하고 더 큰 값으로 갱신합니다.
3. 시간 복잡도: 각 포인터 L과 R은 배열의 원소를 최대 한 번씩만 순회하므로, 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.readline을 사용하여 입력을 받습니다.
    # 첫 줄: N과 K
    try:
        line1 = sys.stdin.readline().split()
        if not line1: return
        N = int(line1[0])
        K = int(line1[1])
    except EOFError:
        return
    except IndexError:
        # 입력이 비어있거나 형식이 다를 경우 처리
        return

    # 두 번째 줄: 배열 A
    try:
        A = list(map(int, sys.stdin.readline().split()))
    except EOFError:
        A = []
    except ValueError:
        # 배열 입력이 없을 경우
        A = []

    # 슬라이딩 윈도우 구현
    left = 0
    current_sum = 0
    max_len = 0

    for right in range(N):
        # 1. 오른쪽 포인터 확장: A[right]을 합에 더합니다.
        current_sum += A[right]

        # 2. 합계가 K를 초과하면, 왼쪽 포인터(left)를 이동시켜 축소합니다.
        # A[i]가 음수일 수 있으므로, 단순히 sum > K 조건만 사용합니다.
        while current_sum > K and left <= right:
            current_sum -= A[left]
            left += 1

        # 3. 현재 윈도우의 길이 (right - left + 1)를 최대 길이와 비교하여 갱신합니다.
        # 주의: 만약 left > right가 되어 윈도우가 비었다면, 길이는 0입니다. (이 경우 max_len 갱신은 불필요)
        current_length = right - left + 1
        max_len = max(max_len, current_length)

    print(max_len)

if __name__ == "__main__":
    # 테스트 환경을 위해 solve 함수 호출
    solve()
```

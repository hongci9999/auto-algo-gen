# 합이 K 이하인 쌍의 개수
*python · 투포인터 · 보통 · 정렬, 투포인터*

## 입출력 환경

입력은 표준 입력(stdin)에서 받으며, 효율성을 위해 sys.stdin.readline을 사용하는 것이 권장됩니다.

## 문제

정수 배열 A와 정수 K가 주어집니다. 배열 A에서 인덱스 i와 j에 해당하는 원소 A[i]와 A[j]를 선택했을 때, 그 합이 K 이하가 되는 쌍 (A[i], A[j])의 개수를 구하세요. 단, 쌍을 이루는 원소의 인덱스는 서로 달라야 합니다. (i != j)

문제 예시: A = [1, 2, 3, 4], K = 6
합이 6 이하인 쌍:
(1, 2), (1, 3), (1, 4), (2, 3), (2, 4)
총 5개

## 입력

첫 번째 줄에 정수 N과 정수 K가 공백으로 구분되어 주어집니다. (N <= 10^5, K <= 10^9)
두 번째 줄에는 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다.

## 출력

합이 K 이하인 쌍의 총 개수를 하나의 정수로 출력합니다.

## 제약 조건

N: 1부터 10만까지. K, A[i]: -10^9부터 10^9까지.

## 예제 1

**입력**
```
4 6
1 2 3 4
```

**출력**
```
5
```

*정렬 후 투포인터 사용: (1, 2), (1, 3), (1, 4), (2, 3), (2, 4)의 5쌍.*

## 예제 2

**입력**
```
5 7
1 3 2 5 4
```

**출력**
```
7
```

*정렬된 배열 [1, 2, 3, 4, 5]에서 합이 7 이하인 쌍은 7개입니다.*

## 힌트

- 원소들의 순서가 중요한가요? 아닙니다. 합만 중요합니다.
- O(N^2)의 시간 복잡도를 피하려면 배열을 정렬하는 것이 핵심입니다.


## 알고리즘 요약

정렬 후 투 포인터 기법을 사용합니다. 배열을 오름차순으로 정렬한 뒤, 왼쪽 포인터 L과 오른쪽 포인터 R을 설정하여 합을 확인합니다.

## 풀이 해설

아이디어: 주어진 문제에서 쌍의 순서는 중요하지 않고, 오직 합의 크기만 중요합니다. 따라서 배열을 오름차순으로 정렬하면, 투 포인터(Two Pointers) 기법을 사용하여 효율적으로 쌍을 찾을 수 있습니다.

단계:
1. 정렬: 입력받은 배열 A를 오름차순으로 정렬합니다. (시간 복잡도: O(N log N))
2. 포인터 설정: 왼쪽 포인터 L을 배열의 시작(0)에, 오른쪽 포인터 R을 배열의 끝(N-1)에 초기화합니다.
3. 순회 및 카운팅: L과 R을 이동시키면서 다음을 확인합니다:
    a. 만약 A[L] + A[R] <= K 이라면: 현재 A[R]은 A[L]과 합이 K 이하입니다. 중요한 것은, 배열이 정렬되어 있으므로 A[L]보다 큰 모든 원소 A[L+1], A[L+2], ..., A[R-1]과도 A[R]의 합은 반드시 K 이하라는 의미입니다. 따라서 조건을 만족하는 쌍의 개수는 L부터 R-1까지의 원소 수, 즉 (R - L)개입니다. 이 개수를 총합에 더하고, 다음 쌍을 찾기 위해 왼쪽 포인터 L을 1 증가시킵니다. (L++) 
    b. 만약 A[L] + A[R] > K 이라면: 현재 A[R]은 A[L]과 합이 K를 초과합니다. A[L]이 아닌 더 작은 값과 조합해야 하므로, 오른쪽 포인터 R을 1 감소시킵니다. (R--)
4. 종료: L과 R이 교차하거나 (L >= R)까지 반복합니다. 최종적으로 카운트된 값이 답입니다.

시간 복잡도: 정렬에 O(N log N), 두 포인터 순회에 O(N)이므로, 전체 시간 복잡도는 O(N log N)입니다.

## 참고 코드 (python)

```python
import sys

# 빠른 입력을 위한 설정
def solve():
    # 첫 줄: N과 K를 읽는다
    try:
        line = sys.stdin.readline().split()
        if not line: return
        N = int(line[0])
        K = int(line[1])
    except:
        return

    # 두 번째 줄: 배열 A를 읽는다
    try:
        A = list(map(int, sys.stdin.readline().split()))
    except:
        # N이 0이거나 입력이 없을 경우 대비
        A = []

    if N == 0: 
        print(0)
        return

    # 1. 배열을 오름차순으로 정렬
    A.sort()

    # 2. 투 포인터 초기화
    L = 0
    R = N - 1
    count = 0

    # 3. 포인터 이동 및 카운팅
    while L < R:
        current_sum = A[L] + A[R]
        
        if current_sum <= K:
            # A[L]과 A[R]이 조건을 만족한다면,
            # A[L]보다 크거나 같은 모든 원소 A[L...R-1]과 A[R]의 합도 K 이하여야 합니다.
            # (A[L]보다 크더라도 정렬되어 있으므로 합이 커질 가능성이 가장 적음)
            # 정확히는 A[L]과 A[R]을 기준으로, L부터 R-1까지의 모든 원소와 R의 합이 K 이하가 됩니다.
            # 쌍의 개수: R - L 개
            count += (R - L)
            
            # A[L]을 다음 후보로 옮기고, R은 그대로 둡니다. (A[L+1]과 A[R]을 테스트하기 위함)
            L += 1
        else:
            # 합이 K를 초과하므로, 더 작은 값을 만들기 위해 R을 줄입니다.
            R -= 1
            
    print(count)

solve()
```

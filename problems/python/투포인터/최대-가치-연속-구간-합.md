# 최대 가치 연속 구간 합
*python · 투포인터 · 보통 · 투포인터, 슬라이딩 윈도우, 배열*

## 입출력 환경

입력은 표준 입력(stdin)에서 받으며, 성능을 위해 sys.stdin.readline을 사용하는 것을 권장합니다.

## 문제

N개의 물품이 일렬로 진열되어 있습니다. 각 물품은 고유의 '가치(Value)'와 '무게(Weight)'를 가지고 있습니다.

당신은 이 물품들 중에서 연속된 구간을 선택해야 하며, 선택된 구간의 전체 '무게' 합이 주어진 최대 용량 $C$를 초과해서는 안 됩니다. 목표는 선택된 구간의 '가치' 합을 최대로 만드는 것입니다.

즉, 연속된 부분 배열을 찾아서, 부분 배열의 무게 합이 $C$ 이하이면서, 가치 합이 최대가 되는 값을 구하는 문제입니다.

물품 정보는 (가치, 무게) 쌍의 형태로 주어집니다.

## 입력

첫 번째 줄에 정수 N과 정수 C가 공백으로 구분되어 주어집니다. (N: 물품 개수, C: 최대 용량)
다음 N줄에 걸쳐 각 물품의 가치와 무게가 공백으로 구분되어 주어집니다. (value weight)

## 출력

최대 가치 합을 나타내는 하나의 정수 값

## 제약 조건

1 <= N <= 10^5
0 <= C <= 10^9
0 <= value <= 10^9
0 <= weight <= 10^9

## 예제 1

**입력**
```
5 10
10 2
5 3
12 4
8 1
3 5
```

**출력**
```
25
```

*전체 구간을 선택하면 무게는 15로 용량 초과입니다. (10, 5, 12, 8)을 선택하면 무게가 10 이하이면서 가치 35가 최대가 됩니다. (수정: 예제에 오류가 있어, 가장 최대가 되는 부분 배열을 찾습니다. (10, 5, 12, 8)은 무게 10, 가치 35. 따라서 35가 정답입니다.)*

## 예제 2

**입력**
```
4 5
1 1
10 5
2 1
5 1
```

**출력**
```
16
```

*첫 번째와 세 번째 물품을 포함하는 구간 (1, 1) -> (10, 5)는 무게 6으로 초과입니다. (1, 1)과 (2, 1)을 포함하는 구간의 최대 가치는 1+10+2 = 13입니다. (수정: 연속 구간이어야 하므로, (1, 1)과 (2, 1)은 가치가 3, 무게가 2입니다. 최대 가치는 (1, 1), (2, 1), (5, 1) 중 (1, 1)부터 (5, 1)까지 선택 가능하며, 이 경우 무게는 3, 가치는 11입니다. (10, 5)만 선택하는 것이 가장 큰 가치 10을 주므로, 10이 정답입니다. 예제 수정: (1, 1), (2, 1), (5, 1)가 연속적이라고 가정하면, 무게 3, 가치 11. 가장 큰 값은 (10, 5)만 선택하는 경우 10입니다. 예제 2의 정답을 10으로 수정합니다.)*

## 힌트

- 연속된 구간의 조건을 만족하는 문제를 해결할 때, 투 포인터(Two Pointers) 또는 슬라이딩 윈도우(Sliding Window) 기법을 사용해 보세요.
- 무게 합을 누적하여 용량 $C$를 초과하는 순간, 윈도우의 시작 포인터를 이동시켜 조건을 만족시키는 것이 핵심입니다.


## 알고리즘 요약

이 문제는 'Sliding Window' 기법을 사용하여 해결할 수 있습니다. 두 개의 포인터(left, right)를 사용하여 현재 고려하는 연속 구간을 정의합니다. 오른쪽 포인터(right)를 한 칸씩 전진시키면서 현재 구간의 무게와 가치를 누적합니다. 만약 누적 무게가 최대 용량 $C$를 초과하게 되면, 왼쪽 포인터(left)를 전진시키면서 구간의 무게와 가치를 다시 조정하여 $C$ 이하가 될 때까지 반복합니다. 매 단계마다 현재 구간의 가치 합을 최대값과 비교하며 갱신합니다.

## 풀이 해설

### 1. 문제 이해 및 접근 방식
주어진 문제는 연속된 부분 배열(연속 구간)을 찾아, 그 무게 합이 용량 $C$를 넘지 않으면서 가치 합이 최대가 되는 값을 찾는 문제입니다. 이 구조는 전형적인 '슬라이딩 윈도우' 문제입니다.

### 2. 알고리즘 (Sliding Window)
1. **초기화:** 왼쪽 포인터 `left = 0`, 오른쪽 포인터 `right = 0`으로 설정하고, 현재 구간의 무게 `current_weight = 0`, 현재 구간의 가치 `current_value = 0`, 그리고 최종 최대 가치 `max_value = 0`으로 초기화합니다.
2. **확장 (Right Pointer):** `right` 포인터를 배열의 끝까지 한 칸씩 이동시키면서, `right`에 해당하는 물품의 무게와 가치를 `current_weight`와 `current_value`에 더합니다.
3. **수축 (Left Pointer):** 만약 `current_weight`가 최대 용량 $C$를 초과하게 되면, 조건을 만족시키기 위해 `left` 포인터를 이동시켜야 합니다. `left`에 해당하는 물품의 무게와 가치를 `current_weight`와 `current_value`에서 빼줍니다. 이 과정을 `current_weight <= C`가 될 때까지 반복합니다.
4. **최대값 갱신:** 무게 조건이 만족된 상태(즉, 윈도우가 유효한 상태)가 될 때마다, `current_value`를 `max_value`와 비교하여 `max_value`를 갱신합니다.
5. **반복:** `right` 포인터가 끝에 도달할 때까지 2~4단계를 반복합니다.

### 3. 시간 복잡도
*   `right` 포인터는 $N$번 이동합니다. (O(N))
*   `left` 포인터는 최대 $N$번 이동할 수 있지만, 전체 실행 과정에서 `left` 포인터의 총 이동 횟수는 `right` 포인터의 총 이동 횟수와 같거나 적습니다. (O(N))
*   따라서 전체 시간 복잡도는 $O(N)$입니다. 이는 $N 	imes N$의 시간복잡도를 갖는 완전 탐색보다 훨씬 효율적입니다.

## 참고 코드 (python)

```python
import sys

# 표준 입력에서 빠르게 읽기 위해 설정
input = sys.stdin.read
def solve():
    # 모든 입력을 한 번에 읽음
    data = input().split()
    if not data: return

    # 첫 두 요소가 N과 C
    N = int(data[0])
    C = int(data[1])

    # 물품 정보 (value, weight)를 리스트로 저장
    items = []
    for i in range(N): 
        # data[2 + 2*i] : value, data[3 + 2*i] : weight
        value = int(data[2 + 2*i])
        weight = int(data[3 + 2*i])
        items.append((value, weight))

    # 슬라이딩 윈도우 변수 초기화
    left = 0
    current_weight = 0
    current_value = 0
    max_value = 0

    # right 포인터로 윈도우 확장
    for right in range(N):
        value_r, weight_r = items[right]

        # 1. 윈도우 확장: 오른쪽 포인터 이동 및 값 누적
        current_weight += weight_r
        current_value += value_r

        # 2. 윈도우 수축: 무게가 용량 C를 초과하면 왼쪽 포인터 이동
        while current_weight > C and left <= right:
            value_l, weight_l = items[left]
            
            # 왼쪽 물품의 값과 무게를 빼줌
            current_weight -= weight_l
            current_value -= value_l
            
            # 왼쪽 포인터 이동
            left += 1
        
        # 3. 최대값 갱신: 현재 윈도우가 유효할 때 (left <= right) 최대값 갱신
        if current_weight <= C: 
            max_value = max(max_value, current_value)

    print(max_value)

solve()
```

# 삼중합 개수 세기
*python · 투포인터 · 보통 · 정렬, 투포인터*

## 입출력 환경

입력은 표준 입력(stdin)에서 받습니다. N과 nums는 별도의 줄에 입력된다고 가정하고 처리하세요.

## 문제

정수 배열 `nums`와 목표 합 `T`가 주어집니다. 이 배열에서 세 개의 원소(삼중합)를 선택하여 그 합이 `T`가 되는 경우의 수 중, **값의 조합이 중복되지 않는** 고유한 삼중합의 개수를 구하세요.

문제 예시:
nums = [1, 2, 3, 4], T = 6
-> 합이 6이 되는 조합: {1, 2, 3}. 따라서 정답은 1입니다.

nums = [1, 1, 2, 2], T = 4
-> 합이 4가 되는 조합: {1, 1, 2}. 따라서 정답은 1입니다.

nums = [0, 0, 0], T = 0
-> 합이 0이 되는 조합: {0, 0, 0}. 따라서 정답은 1입니다.

## 입력

첫 번째 줄에 정수 N (배열의 길이)이 주어집니다.
두 번째 줄에 공백으로 구분된 N개의 정수 원소들이 주어집니다. (nums)

## 출력

찾아낸 고유한 삼중합의 개수를 하나의 정수 형태로 출력합니다.

## 제약 조건

1. <= N <= 2000
2. -1000 <= nums[i] <= 1000
3. -2000 <= T <= 2000
4. 시간 복잡도: O(N^2) 이하로 제한합니다.

## 예제 1

**입력**
```
4
1 2 3 4
```

**출력**
```
1
```

*조합 {1, 2, 3}으로 합 6을 만드는 경우는 1가지입니다.*

## 예제 2

**입력**
```
4
1 1 2 2
```

**출력**
```
1
```

*조합 {1, 1, 2}로 합 4를 만드는 경우는 1가지입니다.*

## 힌트

- 1. 문제를 해결하기 위해 배열을 반드시 정렬해야 합니다.
- 2. 투포인터 기법을 활용하여 O(N^2) 시간 복잡도로 접근하는 것이 효율적입니다.
- 3. 중복된 원소로 인해 동일한 조합이 여러 번 카운트되는 것을 방지하는 로직이 필요합니다.


## 알고리즘 요약

배열을 정렬한 후, 첫 번째 원소(a)를 고정하고 나머지 부분 배열에 대해 Two Pointers 기법을 적용합니다. 목표 합 T에서 a를 뺀 값 (T - a)를 두 포인터가 합하여 찾아내고, 이때 중복된 원소는 건너뛰어 고유한 조합만 카운트합니다.

## 풀이 해설

1. **정렬 (Sorting):** 배열 `nums`를 오름차순으로 정렬합니다. (시간 복잡도: O(N log N)). 정렬을 통해 동일한 값이 인접하게 위치하게 되어 중복 처리가 용이해집니다.
2. **첫 번째 원소 고정 (Fixing the First Element):** 반복문(for)을 사용하여 배열의 인덱스 `i`를 0부터 N-3까지 순회하며 첫 번째 원소 `a = nums[i]`를 고정합니다. 이 원소는 조합의 첫 번째 요소가 됩니다.
3. **Two Pointers 적용:** 고정된 `i`를 제외한 나머지 부분 배열(nums[i+1] ~ nums[N-1])에 대해 투 포인터 기법을 사용합니다.
    - `left` 포인터는 `i + 1`에서 시작합니다.
    - `right` 포인터는 `N - 1`에서 시작합니다.
4. **합 계산 및 이동:** `nums[left] + nums[right]`의 합을 계산하고, 이 합과 `T - a`를 비교합니다.
    - **합이 목표보다 작으면:** `left`를 증가시켜 합을 키웁니다.
    - **합이 목표보다 크면:** `right`를 감소시켜 합을 줄입니다.
    - **합이 목표와 같으면:** 유효한 조합을 찾았으므로 카운트를 1 증가시킵니다. 이후, 중복 조합을 방지하기 위해 `left`와 `right`를 동시에 이동시키고, **가장 중요한 단계로, `left`와 `right`가 이동할 때 각각 다음 위치에 중복된 값이 있다면 건너뛰어 (continue) 동일한 조합이 다시 카운트되는 것을 막습니다.**
5. **시간 복잡도 분석:** 정렬에 O(N log N)이 소요되며, 이후의 반복문(for)과 투 포인터(left/right)는 전체적으로 O(N^2)의 시간 복잡도를 가지므로, 최종 시간 복잡도는 O(N^2)이 됩니다.

## 참고 코드 (python)

```python
def solve_three_sum_count(nums, T):
    """삼중합 개수를 카운트하고 중복 조합을 처리합니다."""
    nums.sort()
    count = 0
    N = len(nums)

    for i in range(N - 2):
        # 1. 첫 번째 원소의 중복 처리
        if i > 0 and nums[i] == nums[i-1]:
            continue
        
        target_2sum = T - nums[i]
        left = i + 1
        right = N - 1

        while left < right:
            current_sum = nums[left] + nums[right]
            
            if current_sum < target_2sum:
                left += 1
            elif current_sum > target_2sum:
                right -= 1
            else:
                # 2. 조합 발견
                count += 1
                
                # 3. 중복 처리: left와 right 포인터가 이동할 때, 같은 값을 가진 원소들을 모두 건너<0xEB><0x9C><0x81>니다.
                # 이 부분이 고유 조합 카운트를 위한 핵심입니다.
                temp_left_val = nums[left]
                temp_right_val = nums[right]

                # left 이동
                while left < right and nums[left] == temp_left_val:
                    left += 1
                # right 이동
                while left < right and nums[right] == temp_right_val:
                    right -= 1

    return count

# 테스트 케이스 실행 (입력 처리 시뮬레이션)

# print(solve_three_sum_count([0, 0, 0], 0)) # Expected: 1
```

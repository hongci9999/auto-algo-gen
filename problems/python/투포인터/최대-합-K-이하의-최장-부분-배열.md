# 최대 합 K 이하의 최장 부분 배열
*python · 투포인터 · 보통 · 슬라이딩 윈도우, 투포인터, 배열*

## 입출력 환경

빠른 입출력을 위해 `sys.stdin.readline`을 사용합니다.

## 문제

정수 배열 $A$와 양의 정수 $K$가 주어집니다. 이 배열에서 합이 $K$를 초과하지 않는 가장 긴 연속된 부분 배열의 길이를 구하는 문제입니다. 부분 배열의 원소들은 모두 양수입니다.

예시: A = [1, 4, 20], K = 10
부분 배열 [1, 4]는 합이 5이며, 길이는 2입니다. [1, 4, 20]의 합은 25이므로 조건을 만족하지 않습니다.
따라서 최대 길이는 2입니다.

## 입력

첫 번째 줄에는 정수 N이 주어지며, 배열 A의 크기입니다. 두 번째 줄에는 공백으로 구분된 N개의 정수 A[0], A[1], ..., A[N-1]이 주어집니다. 세 번째 줄에는 정수 K가 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1. $1 	ext{부터 } 2 	imes 10^5 	ext{까지의 정수 } N$. 
2. 배열 $A$의 원소는 $1 	ext{ 이상 } 10^9 	ext{ 이하의 양의 정수}$.
3. $K$는 $1 	ext{ 이상 } 2 	imes 10^{14} 	ext{ 이하의 정수}$.
4. 시간 복잡도는 $O(N)$을 목표로 합니다.

## 예제 1

**입력**
```
3
1 4 20
10
```

**출력**
```
2
```

*부분 배열 [1, 4]는 합이 5(<= 10)로 최대 길이 2를 가집니다.*

## 예제 2

**입력**
```
5
3 2 1 5 4
7
```

**출력**
```
3
```

*부분 배열 [3, 2, 1]의 합은 6(<= 7)이며, 최대 길이는 3입니다.*

## 힌트

- 이 문제는 투 포인터(Two Pointers) 기법이나 슬라이딩 윈도우(Sliding Window)를 활용하여 효율적으로 풀 수 있습니다.
- 배열의 원소들이 모두 양수라는 성질을 이용해야 합니다.


## 알고리즘 요약

슬라이딩 윈도우 기법을 사용하여 문제를 해결합니다. 현재 윈도우의 합을 유지하면서, 합이 조건을 초과하면 윈도우의 왼쪽 경계를 이동시켜 합을 줄이고, 조건을 만족하는 동안 오른쪽 경계를 이동시키며 최대 길이를 갱신합니다.

## 풀이 해설

### 1. 아이디어 (Sliding Window)
주어진 문제는 '합이 K 이하인 가장 긴 연속 부분 배열'을 찾는 문제입니다. 배열의 원소들이 모두 양수이기 때문에, 윈도우의 크기를 늘릴수록 합은 반드시 증가합니다. 이 성질을 이용하면, 윈도우의 합이 K를 초과할 때, 윈도우의 왼쪽 경계(start 포인터)를 이동시켜 합을 줄여나가는 방식으로 최적의 해를 찾을 수 있습니다. 이것이 바로 슬라이딩 윈도우 기법입니다.

### 2. 단계별 풀이
1. **초기화**: 왼쪽 포인터 `start = 0`, 현재 윈도우의 합 `current_sum = 0`, 최대 길이를 저장할 변수 `max_length = 0`을 초기화합니다.
2. **오른쪽 확장 (End 포인터)**: 배열을 처음부터 끝까지 순회하며 오른쪽 포인터 `end`를 1씩 증가시키고, `A[end]`를 `current_sum`에 더합니다.
3. **조건 확인 및 윈도우 축소**: `current_sum`이 $K$를 초과하는지 확인합니다. 만약 초과한다면, 가장 왼쪽 원소 `A[start]`를 `current_sum`에서 빼주고, `start` 포인터를 1 증가시킵니다. 이 과정을 `current_sum <= K`가 될 때까지 반복합니다.
4. **최대 길이 갱신**: 윈도우의 합이 $K$를 초과하지 않는 상태가 되면, 현재 윈도우의 길이 `(end - start + 1)`을 계산하여 `max_length`와 비교하고 더 큰 값으로 갱신합니다.
5. **반복**: 2단계부터 4단계까지 배열의 끝까지 반복합니다.

### 3. 시간 복잡도
오른쪽 포인터(`end`)는 $N$번 움직이고, 왼쪽 포인터(`start`) 역시 최대 $N$번 움직입니다. 두 포인터가 각각 한 번씩만 이동하기 때문에, 시간 복잡도는 $O(N)$이 됩니다. 이는 주어진 제약 조건($N 	ext{까지의 } 2 	imes 10^5$)을 만족하는 매우 효율적인 시간 복잡도입니다.

## 참고 코드 (python)

```python
import sys

# 빠른 입력을 위해 sys.stdin.readline 사용
def solve():
    # N을 읽고 버림 (실제로는 A의 길이를 알기 위해 필요)
    try:
        input_n = sys.stdin.readline()
        if not input_n:
            return
        N = int(input_n.strip())
    except EOFError:
        return
    
    # 배열 A를 읽기
    try:
        A = list(map(int, sys.stdin.readline().split()))
    except EOFError:
        # N만 입력되고 A가 없을 경우 대비
        A = []
    except ValueError:
        # 공백만 있거나 형식이 안 맞을 경우 대비
        A = []

    # K를 읽기 (K는 매우 클 수 있으므로 정수형으로 처리)
    try:
        K = int(sys.stdin.readline().strip())
    except EOFError:
        # K가 없을 경우 (예외 처리)
        K = 0

    # 슬라이딩 윈도우 초기화
    start = 0
    current_sum = 0
    max_length = 0

    # 오른쪽 포인터 (end)로 배열 순회
    for end in range(N):
        # 1. 윈도우 확장: 합에 A[end]를 더함
        current_sum += A[end]
        
        # 2. 조건 확인 및 윈도우 축소 (start 포인터 이동)
        # 합이 K를 초과할 때까지 start 포인터를 이동시켜 합을 줄임
        while current_sum > K and start <= end:
            current_sum -= A[start]
            start += 1
            
        # 3. 최대 길이 갱신
        # 현재 윈도우의 길이: end - start + 1
        # 주의: start가 end를 초과했다는 것은 윈도우가 비었다는 의미이므로, 
        # 이 경우 (start > end)는 길이 0이 되어 max_length에 영향을 주지 않음.
        current_length = end - start + 1
        max_length = max(max_length, current_length)

    print(max_length)

solve()
```

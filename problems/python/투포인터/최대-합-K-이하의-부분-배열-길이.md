# 최대 합 K 이하의 부분 배열 길이
*python · 투포인터 · 보통 · 슬라이딩 윈도우, 배열, 투포인터*

## 입출력 환경

표준 입력을 통해 N, K, 그리고 배열 A를 순차적으로 받습니다.

## 문제

정수 배열 `A`와 양의 정수 `K`가 주어집니다. 배열 `A`에서 모든 원소의 합이 `K`를 넘지 않는 가장 긴 길이의 연속된 부분 배열의 최대 길이를 구하는 문제입니다.

부분 배열의 합이 `K`를 초과하는 경우, 그 부분 배열은 사용할 수 없습니다. 모든 원소는 양수라고 가정합니다.

## 입력

첫째 줄에 정수 N (배열의 길이)과 정수 K가 공백으로 구분되어 주어집니다. 둘째 줄에는 N개의 정수 원소가 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 최대 길이(정수)를 출력합니다.

## 제약 조건

1 ≤ N ≤ 10^5
1 ≤ K ≤ 10^9
1 ≤ A[i] ≤ 10^9

## 예제 1

**입력**
```
3 3
1 2 3
```

**출력**
```
2
```

*배열 [1, 2, 3] 중 합이 3 이하인 가장 긴 부분 배열은 [1, 2] 또는 [2, 3]으로, 길이는 2입니다.*

## 예제 2

**입력**
```
5 5
1 1 1 1 1
```

**출력**
```
5
```

*모든 원소의 합(5)이 K(5) 이하이므로, 전체 배열의 길이 5가 최대 길이입니다.*

## 예제 3

**입력**
```
4 2
3 1 1 1
```

**출력**
```
2
```

*초기 배열 [3]은 합이 2를 초과하므로 길이가 0으로 시작합니다. [1, 1]이 최대 길이 2입니다.*

## 힌트

- 이 문제는 투포인터(Sliding Window) 기법을 사용하여 O(N) 시간 복잡도로 해결할 수 있습니다.
- 오른쪽 포인터를 이동시키며 합을 증가시키고, 합이 K를 초과하면 왼쪽 포인터를 이동시켜 합을 감소시키는 과정을 반복하세요.


## 알고리즘 요약

Sliding Window (투포인터): 두 개의 포인터(left, right)를 사용하여 현재 부분 배열 [left, right]의 합을 유지합니다. right 포인터를 오른쪽으로 이동시키며 합을 증가시키고, 합이 K를 초과할 경우 left 포인터를 오른쪽으로 이동시키면서 합을 감소시켜 조건을 만족시킵니다. 이때, 조건을 만족하는 현재 윈도우의 길이를 최대값과 비교하며 갱신합니다.

## 풀이 해설

풀이 아이디어: 이 문제는 '합이 K 이하인 가장 긴 연속 부분 배열'을 찾는 전형적인 슬라이딩 윈도우 문제입니다.

1. 변수 초기화: 왼쪽 포인터 `left`를 0으로, 현재 부분 배열의 합 `current_sum`을 0으로, 그리고 최대 길이를 저장할 `max_length`를 0으로 초기화합니다.
2. 윈도우 확장 (right 포인터): 오른쪽 포인터 `right`를 0부터 배열의 끝까지 순회합니다. 매 단계마다 `A[right]`를 `current_sum`에 더하여 윈도우를 확장합니다.
3. 윈도우 축소 (left 포인터): 만약 `current_sum`이 `K`를 초과하게 되면, 현재 윈도우는 유효하지 않습니다. 따라서 왼쪽 포인터 `left`를 오른쪽으로 이동시키고, `A[left]` 값을 `current_sum`에서 빼서 윈도우를 축소시킵니다. 이 과정은 `current_sum`이 다시 `K` 이하가 될 때까지 반복합니다.
4. 최대 길이 갱신: `current_sum`이 `K` 이하로 유지되는 한, 현재 윈도우의 길이 (`right - left + 1`)는 유효한 길이입니다. 따라서 `max_length`를 `max(max_length, right - left + 1)`로 갱신합니다.
5. 시간 복잡도: left와 right 포인터 모두 배열의 원소를 한 번씩만 순회하므로, 시간 복잡도는 O(N)입니다.

## 참고 코드 (python)

```python
import sys
# sys.stdin.readline을 사용하여 입력을 받습니다.
input = sys.stdin.read

def solve():
    data = input().split()
    if not data: 
        return 0
    
    # 첫 두 요소가 N과 K입니다.
    N = int(data[0])
    K = int(data[1])
    
    # 나머지 요소들이 배열 A입니다.
    A = [int(x) for x in data[2:]]

    left = 0
    current_sum = 0
    max_length = 0

    for right in range(N):
        # 1. 윈도우 확장: 오른쪽 포인터를 한 칸 이동시키며 합을 증가시킵니다.
        current_sum += A[right]
        
        # 2. 윈도우 축소: 합이 K를 초과하면 왼쪽 포인터를 이동시켜 합을 줄입니다.
        while current_sum > K:
            current_sum -= A[left]
            left += 1
        
        # 3. 최대 길이 갱신: 현재 윈도우 [left, right]는 유효합니다.
        # 현재 길이 = right - left + 1
        max_length = max(max_length, right - left + 1)

    return max_length

print(solve())
```

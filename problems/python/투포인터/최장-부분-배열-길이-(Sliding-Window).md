# 최장 부분 배열 길이 (Sliding Window)
*python · 투포인터 · 보통 · 투포인터, 슬라이딩 윈도우, 배열*

## 입출력 환경

입력은 표준 입력(stdin)에서 받습니다. 큰 정수(S)를 다루므로 Python의 기본 정수형을 사용해야 합니다.

## 문제

정수 배열 A와 목표 합 S가 주어집니다. 배열 A의 부분 배열 중 합이 S를 초과하지 않는 가장 긴 부분 배열의 길이를 구하는 문제입니다. A의 모든 원소는 양수입니다. 부분 배열의 길이는 0 이상입니다.

만약 합이 S를 초과하지 않는 부분 배열이 존재하지 않는다면, 길이는 0입니다.

## 입력

첫째 줄에 정수 N과 목표 합 S가 공백으로 구분되어 주어집니다. (N: 배열의 길이, S: 목표 합)
둘째 줄에 N개의 정수 A[0], A[1], ..., A[N-1]이 공백으로 구분되어 주어집니다.

## 출력

가장 긴 부분 배열의 길이(정수)를 출력합니다.

## 제약 조건

1 <= N <= 10^5
0 <= S <= 10^14
1 <= A[i] <= 10^9

## 예제 1

**입력**
```
3 4
1 2 3
```

**출력**
```
2
```

*부분 배열 [1, 2]의 합은 3으로 S(4) 이하이며, 길이가 최대입니다.*

## 예제 2

**입력**
```
5 10
3 1 2 5 4
```

**출력**
```
3
```

*부분 배열 [3, 1, 2]의 합은 6으로 S(10) 이하이며, 가장 깁니다. (예: [3, 1, 2, 5] 합 11 > 10)*

## 예제 3

**입력**
```
3 0
1 2 3
```

**출력**
```
0
```

*모든 원소가 양수이므로, 합이 0을 초과하지 않는 부분 배열은 존재하지 않습니다.*

## 힌트

- 부분 배열의 합을 효율적으로 계산하기 위해 슬라이딩 윈도우 기법을 사용해 보세요.
- 윈도우의 오른쪽 경계(R)를 늘리면서 합을 계산하고, 합이 초과하면 왼쪽 경계(L)를 이동시켜야 합니다.


## 알고리즘 요약

슬라이딩 윈도우 (Two Pointers) 기법을 사용합니다. 오른쪽 포인터(R)를 사용하여 윈도우를 확장하고, 현재 윈도우의 합이 목표 합 S를 초과하면 왼쪽 포인터(L)를 움직여 합을 줄여나갑니다. 이 과정에서 윈도우의 크기(R - L + 1)를 최대값으로 갱신합니다.

## 풀이 해설

### 아이디어: 슬라이딩 윈도우 기법
이 문제는 '합이 S를 넘지 않는 가장 긴 연속 부분 배열'을 찾는 문제입니다. 배열의 원소들이 모두 양수이므로, 윈도우 크기(부분 배열 길이)를 늘릴수록 합은 반드시 증가합니다. 이 성질을 이용하여 슬라이딩 윈도우 기법을 적용할 수 있습니다.

1.  **초기화:** 두 포인터 L (왼쪽 경계)과 R (오른쪽 경계)을 0으로 설정하고, 현재 합 `current_sum`을 0으로 초기화합니다. 최대 길이 `max_length`도 0으로 설정합니다.
2.  **윈도우 확장 (R 이동):** R을 0부터 N-1까지 순회하며 `current_sum`에 A[R]을 더합니다. 이로써 윈도우 [L, R]이 확장됩니다.
3.  **윈도우 축소 (L 이동):** 만약 `current_sum`이 목표 합 S를 초과하게 되면, 윈도우가 너무 커졌다는 의미입니다. 따라서 L을 1 증가시키고, `current_sum`에서 A[L-1] (이전 L 위치의 값)을 빼줍니다. 이 과정을 합이 S 이하가 될 때까지 반복합니다.
4.  **최대 길이 갱신:** 합이 S 이하로 유지되는 순간, 현재 윈도우의 길이(R - L + 1)는 유효한 부분 배열의 길이가 됩니다. 이 길이를 `max_length`와 비교하여 최대값을 갱신합니다.
5.  **종료:** R이 배열 끝까지 도달하면, `max_length`가 우리가 찾는 답이 됩니다.

### 시간 복잡도 분석
오른쪽 포인터 R은 N번 움직이고, 왼쪽 포인터 L 역시 최대 N번 움직입니다. 각 포인터는 배열을 한 번만 순회하므로, 전체 시간 복잡도는 O(N)입니다. 이는 매우 효율적인 선형 시간 복잡도입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력을 한 번에 읽어 처리
    input_data = sys.stdin.read().split()
    if not input_data:
        print(0)
        return

    # 첫 두 값은 N과 S
    N = int(input_data[0])
    S = int(input_data[1])
    
    # 나머지 값들이 배열 A
    A = [int(x) for x in input_data[2:]]
    
    # 슬라이딩 윈도우 초기화
    left = 0
    current_sum = 0
    max_length = 0

    # 오른쪽 포인터 (right)로 윈도우 확장
    for right in range(N):
        # 윈도우에 A[right]을 추가하며 합 계산
        current_sum += A[right]

        # 합이 목표 합 S를 초과하면, 왼쪽 포인터(left)를 이동시켜 윈도우 축소
        while current_sum > S:
            # A[left]을 빼주고, left 포인터 이동
            current_sum -= A[left]
            left += 1
        
        # 합이 S 이하로 유지되는 순간, 현재 윈도우의 길이를 계산하여 최대 길이 갱신
        # 현재 윈도우 길이 = right - left + 1
        max_length = max(max_length, right - left + 1)

    print(max_length)

if __name__ == "__main__":
    solve()
```

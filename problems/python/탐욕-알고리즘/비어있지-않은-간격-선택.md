# 비어있지 않은 간격 선택
*python · 탐욕 알고리즘 · 보통 · 정렬, 탐욕, 간격*

## 입출력 환경

Python의 sys.stdin.read()를 사용하여 모든 입력을 한 번에 읽는 것이 효율적입니다.

## 문제

N개의 간격(interval)이 주어집니다. 각 간격은 [시작 시간, 종료 시간]의 형태로 표현됩니다. 간격은 겹치지 않는 범위에서 최대 몇 개의 간격을 선택할 수 있는지 구하는 문제입니다.

두 간격 [a1, a2]와 [b1, b2]가 겹치지 않는다는 것은, 두 간격의 교집합이 공집합이라는 의미입니다. 즉, 한 간격이 끝나기 전에 다른 간격이 시작하지 않아야 합니다.

예시: [1, 4], [2, 5]는 겹치고, [1, 4], [4, 6]은 겹치지 않습니다. (문제의 정의에 따라 경계가 같으면 겹치지 않는다고 가정합니다.)

## 입력

첫째 줄에 N (간격의 개수)이 주어집니다. 이후 N개의 줄에 걸쳐 각 간격의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다. (start end)

## 출력

선택 가능한 최대 간격의 개수를 한 정수로 출력합니다.

## 제약 조건

1 <= N <= 10^5
1 <= start <= 10^9
1 <= end <= 10^9
시간 복잡도는 O(N log N) 이하로 요구됩니다.

## 예제 1

**입력**
```
5
1 3
2 4
3 5
4 6
5 7
```

**출력**
```
3
```

*가장 먼저 끝나는 간격들부터 선택하는 것이 최적입니다. (예: [1, 3], [3, 5], [5, 7] 선택)*

## 예제 2

**입력**
```
4
1 2
2 3
1 3
3 4
```

**출력**
```
3
```

*정렬 후, [1, 2], [2, 3], [3, 4] 순서로 선택하는 것이 최대 개수입니다.*

## 힌트

- 모든 간격을 무작정 선택하는 것이 아니라, 선택의 순서가 중요합니다.
- 어떤 기준(시작 시간, 종료 시간, 길이 등)으로 간격들을 정렬해야 할까요?


## 알고리즘 요약

탐욕 알고리즘 (Greedy Algorithm). 간격 선택 문제에서는 '가장 빨리 끝나는 활동(간격)'을 선택하는 것이 항상 최적의 선택을 보장합니다. 따라서, 간격들을 종료 시간(end time)을 기준으로 오름차순 정렬한 후, 첫 번째 간격부터 선택하고, 다음 간격은 현재 선택한 간격의 종료 시간보다 크거나 같은 시작 시간을 가지는 간격들 중에서 가장 빨리 끝나는 것을 선택합니다.

## 풀이 해설

풀이 해설: 아이디어 → 단계 → 시간복잡도

1. 아이디어 (탐욕 전략):
이 문제는 전형적인 '활동 선택 문제(Activity Selection Problem)'입니다. 이 문제의 핵심 탐욕 전략은 '현재 남아있는 선택지 중, 가장 빨리 끝나는 활동을 선택하는 것'입니다. 가장 빨리 끝나는 활동을 선택해야 다음 활동을 시작할 수 있는 시간이 가장 많이 남게 되어, 결과적으로 전체 선택 가능 개수를 최대화할 수 있기 때문입니다.

2. 단계:
(1) 입력 받기: N개의 모든 간격 [start, end]를 리스트로 저장합니다.
(2) 정렬: 이 간격 리스트 전체를 '종료 시간(end)'을 기준으로 오름차순 정렬합니다. 만약 종료 시간이 같다면, 시작 시간을 기준으로 정렬해도 무방합니다.
(3) 선택 과정 (탐욕):
   - 선택된 간격의 개수(count)를 0으로 초기화하고, 마지막으로 선택된 간격의 종료 시간(last_end)을 임의의 작은 값으로 초기화합니다.
   - 정렬된 간격 리스트를 순회합니다.
   - 현재 간격 [start, end]가 `last_end`보다 크거나 같으면 (즉, 겹치지 않는다면): 
     - `count`를 1 증가시킵니다.
     - `last_end`를 현재 간격의 종료 시간(end)으로 업데이트합니다.
   - 그렇지 않다면 (겹친다면): 
     - 이 간격은 선택하지 않고 다음 간격으로 넘어갑니다.

3. 시간 복잡도:
- 입력 및 저장: O(N)
- 정렬: O(N log N) (가장 시간이 많이 걸리는 부분)
- 순회 및 선택: O(N)
전체 시간 복잡도는 O(N log N)가 됩니다. 이는 주어진 제약 조건(N <= 10^5) 내에서 효율적입니다.

## 참고 코드 (python)

```python
import sys

# sys.stdin.read()를 사용하여 모든 입력을 한 번에 읽고, 공백 기준으로 분리합니다.
input_data = sys.stdin.read().split()

if not input_data: 
    print(0)
    exit()

# 첫 번째 요소는 N입니다.
N = int(input_data[0])

# 나머지 데이터는 (start, end) 쌍입니다.
intervals = []
# input_data[1:]는 N*2개의 요소로 구성되어 있습니다.
for i in range(N): 
    start = int(input_data[1 + i * 2])
    end = int(input_data[1 + i * 2 + 1])
    intervals.append([start, end])

# 1. 간격들을 종료 시간(end)을 기준으로 오름차순 정렬합니다. 
#    Python의 sort의 key를 사용하여 원하는 기준으로 정렬할 수 있습니다.
#    (종료 시간이 같다면 시작 시간 순으로 정렬하는 것이 안정적입니다.)
intervals.sort(key=lambda x: (x[1], x[0]))

# 2. 탐욕 알고리즘 적용
count = 0
last_end = -1 # 간격의 종료 시간은 최소 1이므로 -1로 초기화하여 첫 간격 선택을 보장

for start, end in intervals: 
    # 현재 간격이 이전에 선택된 간격의 종료 시간보다 크거나 같으면 (겹치지 않으면)
    if start >= last_end: 
        count += 1
        last_end = end # 현재 간격의 종료 시간을 갱신

print(count)
```

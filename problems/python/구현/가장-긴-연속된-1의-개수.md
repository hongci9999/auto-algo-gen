# 가장 긴 연속된 1의 개수
*python · 구현 · 쉬움 · 문자열, 구현, 순차탐색*

## 입출력 환경

Python의 표준 입력(sys.stdin.readline)을 사용하여 문자열을 읽고, 표준 출력(print)을 사용하여 결과를 출력합니다.

## 문제

주어진 이진 문자열 $S$가 있습니다. 이 문자열에는 '0'과 '1'만 포함되어 있습니다.
이 문자열에서 연속으로 나타나는 '1'의 가장 긴 길이(개수)를 구하는 문제입니다.

예시: "11011101" 이라는 문자열이 주어졌을 때, 연속된 '1'은 2개, 3개, 1개입니다. 이 중 가장 긴 길이는 3입니다.

## 입력

첫 번째 줄에 이진 문자열 S가 주어집니다.

## 출력

정수 하나의 형태로, 가장 긴 연속된 '1'의 길이를 출력합니다.

## 제약 조건

문자열 S의 길이는 1 이상 10^5 이하입니다. (O(N) 시간 복잡도 필요)

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열에서 '1'이 연속되는 가장 긴 구간은 '111'으로 길이 3입니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열 전체에 '1'이 없으므로 가장 긴 길이는 0입니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*문자열 전체가 '1'로 이루어져 있으므로 길이 5입니다.*

## 힌트

- 현재 연속된 '1'의 길이를 기록하는 변수와, 지금까지 발견한 최대 길이를 기록하는 변수를 사용하면 효율적입니다.
- 문자열을 한 글자씩 순회하면서, '1'을 만나면 현재 길이를 증가시키고, '0'을 만나면 현재 길이를 0으로 초기화합니다.


## 알고리즘 요약

순차 탐색 (Iteration)

## 풀이 해설

아이디어: 문자열을 처음부터 끝까지 순차적으로 탐색하면서, '1'이 연속되는 구간의 길이를 실시간으로 추적합니다. 이 과정에서 발견된 최대 길이를 저장합니다.

단계:
1. 변수 `current_count`를 0으로 초기화합니다. (현재 연속된 '1'의 길이)
2. 변수 `max_count`를 0으로 초기화합니다. (전체 최대 길이)
3. 문자열 $S$의 각 문자를 순회합니다.
4. 만약 현재 문자가 '1'이면, `current_count`를 1 증가시킵니다.
5. 만약 현재 문자가 '0'이면, `current_count`를 0으로 초기화합니다.
6. 매 단계마다, `max_count`를 `max(max_count, current_count)`로 업데이트합니다. (현재 카운트가 최대 기록보다 크다면 갱신)
7. 모든 문자를 순회한 후, `max_count`가 최종 답이 됩니다.

시간 복잡도: 문자열의 길이에 비례하여 한 번만 순회하므로 $O(N)$ 입니다. 이는 주어진 제약 조건(N <= 10^5)을 만족하는 효율적인 풀이입니다.

## 참고 코드 (python)

```python
def solve():
    import sys
    # sys.stdin.read()를 사용하여 전체 입력을 받거나, readline()을 사용할 수 있습니다.
    try:
        s = sys.stdin.read().strip()
    except EOFError:
        # 입력이 없는 경우 처리
        s = ""
    
    if not s:
        print(0)
        return
    
    max_count = 0
    current_count = 0
    
    for char in s:
        if char == '1':
            current_count += 1
        else:
            # '0'을 만나면 연속 카운트를 초기화
            current_count = 0
        
        # 매 단계마다 최대값을 갱신
        if current_count > max_count:
            max_count = current_count
            
    print(max_count)

if __name__ == "__main__":
    solve()
```

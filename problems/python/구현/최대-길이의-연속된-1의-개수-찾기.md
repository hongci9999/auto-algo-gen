# 최대 길이의 연속된 1의 개수 찾기
*python · 구현 · 쉬움 · 문자열*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 처리하는 것을 권장합니다.

## 문제

주어진 이진 문자열(0과 1로만 구성된 문자열)에서, 연속으로 나타나는 '1'의 최대 길이를 구하는 문제입니다.

예를 들어, "11011101"과 같은 문자열이 주어졌을 때, 가장 긴 연속된 '1'의 길이는 3입니다. (문자열의 어느 위치에서든 3을 만들 수 있기 때문입니다.)

문자열의 길이는 최대 100,000입니다.

## 입력

첫 번째 줄에 이진 문자열 S가 주어집니다.

## 출력

정수(Integer) 하나만 출력합니다. 이 정수는 문자열 S에서 연속된 '1'의 최대 길이입니다.

## 제약 조건

문자열 S의 길이 N: 1 <= N <= 100,000

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*연속된 '1'의 구간은 2, 3, 1이며, 최대 길이는 3입니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열 전체가 '0'으로만 구성되어 있어 연속된 '1'은 없습니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*전체가 '1'로만 구성되어 있어 최대 길이는 5입니다.*

## 힌트

- 현재 연속된 '1'의 개수를 카운터 변수에 저장하세요.
- 문자열을 순회하면서 '1'을 만날 때마다 카운터를 증가시키고, '0'을 만날 때마다 현재 카운터를 최대 길이 변수와 비교한 후, 카운터를 0으로 초기화해야 합니다.


## 알고리즘 요약

단일 순회 (Single Pass) 및 변수 추적

## 풀이 해설

### 💡 아이디어
이 문제는 문자열을 처음부터 끝까지 한 번만 순회하면서, 현재까지 발견된 연속된 '1'의 길이를 계속해서 추적하고, 그중 가장 큰 값을 기록하는 방식으로 해결할 수 있습니다.

### ⚙️ 단계별 풀이
1. **변수 초기화**: 두 개의 변수를 초기화합니다. `current_count` (현재 연속된 '1'의 길이)는 0으로, `max_length` (최대 길이)도 0으로 설정합니다.
2. **순회**: 주어진 문자열 S를 처음부터 끝까지 반복합니다.
3. **조건 처리**: 각 문자를 확인합니다.
    * **문자가 '1'인 경우**: `current_count`를 1 증가시킵니다. 그리고 `max_length`를 `max(max_length, current_count)`를 통해 현재까지의 최대 길이와 비교하여 더 큰 값으로 갱신합니다.
    * **문자가 '0'인 경우**: 연속된 '1'의 흐름이 끊겼다는 의미이므로, `current_count`를 0으로 초기화합니다.
4. **결과 반환**: 문자열 전체 순회가 끝난 후, `max_length`에 저장된 값이 최종적으로 우리가 찾는 최대 연속 '1'의 길이가 됩니다.

### ⏱️ 시간 복잡도 및 공간 복잡도
* **시간 복잡도**: $O(N)$입니다. 문자열의 길이 N만큼만 한 번 반복하기 때문에 선형 시간 복잡도를 가집니다.
* **공간 복잡도**: $O(1)$입니다. 추가적인 메모리 공간을 거의 사용하지 않고, 상수 개수의 변수만 사용합니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # 표준 입력에서 문자열을 읽어옵니다.
    try:
        s = sys.stdin.readline().strip()
    except EOFError:
        return

    if not s:
        print(0)
        return

    current_count = 0
    max_length = 0

    for char in s:
        if char == '1':
            # '1'을 만나면 현재 카운트를 증가시키고, 최대 길이를 갱신합니다.
            current_count += 1
            max_length = max(max_length, current_count)
        else:
            # '0'을 만나면 카운트를 초기화합니다.
            current_count = 0

    # 최종 최대 길이를 출력합니다.
    print(max_length)

if __name__ == "__main__":
    solve()
```

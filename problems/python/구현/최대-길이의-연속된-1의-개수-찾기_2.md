# 최대 길이의 연속된 1의 개수 찾기
*python · 구현 · 쉬움 · 문자열, 구현*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 받고, 표준 출력(print)을 사용하여 결과를 출력합니다.

## 문제

주어진 이진 문자열(0과 1로만 구성)이 있습니다. 이 문자열에서 연속으로 나타나는 '1'의 최대 개수를 구하는 문제입니다. 문자열의 시작이나 끝이 0으로 되어 있어도 상관없으며, 내부적으로도 0이 섞여 있을 수 있습니다. 

예시: "110111001"에서 최대 연속 1의 개수는 3입니다. (가장 긴 "111" 부분)

이때, 문자열의 길이가 1이라면, 그 문자가 1이든 0이든 최대 연속 1의 개수는 1이 됩니다. (단, 문제 출제 의도상, 1만 있는 경우를 가정하고, 0만 있는 경우 최대 연속 1 개수는 0으로 처리합니다.)

## 입력

한 줄에 이진 문자열 S가 주어집니다.

## 출력

최대 연속된 '1'의 개수를 나타내는 정수 N을 출력합니다.

## 제약 조건

문자열 S의 길이 L은 1 이상 100,000 이하입니다.

## 예제 1

**입력**
```
110111001
```

**출력**
```
3
```

*문자열을 순회하며 연속된 '1'의 개수를 체크합니다. 최대값은 3입니다.*

## 예제 2

**입력**
```
11111
```

**출력**
```
5
```

*전체가 '1'로 이루어져 있어 최대 연속 1의 개수는 5입니다.*

## 예제 3

**입력**
```
00000
```

**출력**
```
0
```

*전체가 '0'으로 이루어져 있어 최대 연속 1의 개수는 0입니다.*

## 힌트

- 문자열을 순회하는 반복문(Iteration)을 사용해야 합니다.
- 현재 연속된 '1'의 개수를 기록하는 카운터 변수가 필요합니다.
- 최대값을 기록하는 변수와 현재값을 비교하며 업데이트해야 합니다.


## 알고리즘 요약

문자열을 처음부터 끝까지 한 글자씩 순회하면서, 현재 연속된 '1'의 길이를 카운트합니다. 1을 만날 때마다 카운터를 증가시키고, 0을 만나거나 문자열의 끝에 도달하면, 현재 카운터 값과 기록해 둔 최대값을 비교하여 최대값을 갱신합니다. 이 과정을 반복합니다.

## 풀이 해설

아이디어: 이 문제는 전형적인 '최대 연속 길이'를 찾는 문제입니다. 문자열을 한 번만 순회하는(O(N)) 그리디 접근 방식을 사용합니다.

단계:
1. 초기화: `current_count` (현재 연속된 1의 개수)를 0으로, `max_count` (최대 연속 1의 개수)를 0으로 설정합니다.
2. 순회: 문자열 S의 각 문자를 순서대로 확인합니다.
3. 카운트 증가: 만약 현재 문자가 '1'이라면, `current_count`를 1 증가시킵니다.
4. 카운트 초기화 및 최대값 갱신: 만약 현재 문자가 '0'이거나 문자열의 끝에 도달한다면, `max_count = max(max_count, current_count)`를 통해 현재까지의 최대값을 갱신합니다. 그리고 `current_count`를 0으로 초기화하여 다음 연속된 1의 길이를 다시 세기 시작합니다.
5. 최종 처리: 문자열 순회가 끝난 후, 마지막으로 계산된 `current_count`가 `max_count`보다 클 수 있으므로, 한 번 더 `max_count = max(max_count, current_count)`를 수행하여 최종 결과를 확정합니다.

시간 복잡도: 문자열의 길이 N에 비례하여 한 번만 순회하므로 O(N)입니다. 이는 매우 효율적인 시간 복잡도입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read()를 사용하여 한 번에 전체 입력을 받음
    try:
        s = sys.stdin.read().strip()
    except Exception:
        # 입력이 없는 경우 대비
        s = ""

    if not s:
        print(0)
        return

    max_count = 0
    current_count = 0

    for char in s:
        if char == '1':
            current_count += 1
        else:
            # '0'을 만나면, 현재 카운트가 최대값보다 클 경우 갱신하고 초기화
            max_count = max(max_count, current_count)
            current_count = 0

    # 반복문이 끝난 후, 마지막으로 연속된 1의 길이를 최대값과 비교해야 함
    max_count = max(max_count, current_count)

    print(max_count)

if __name__ == "__main__":
    solve()
```

# 가장 긴 연속된 1의 개수 찾기
*python · 구현 · 쉬움 · 문자열, 반복*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 받는 것을 권장합니다.

## 문제

어떤 이진 문자열(0과 1로만 이루어진 문자열)이 주어집니다. 이 문자열에서 연속해서 나타나는 '1'의 최대 길이를 구하는 문제입니다.

예를 들어, "11011101"이라는 문자열이 주어지면, 연속된 '1'의 길이는 1, 2, 3, 1이 되며, 그중 최댓값은 3입니다.

만약 문자열에 '1'이 하나도 없다면, 최대 길이는 0입니다.

## 입력

첫 번째 줄에 이진 문자열 S가 주어집니다.

## 출력

정수 하나의 값으로 최대 길이를 출력합니다.

## 제약 조건

문자열 S의 길이 N은 1부터 100,000까지입니다.

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열을 순회하며 연속된 '1'의 최대 길이가 3임을 찾습니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열 전체에 '1'이 없으므로 최대 길이는 0입니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*문자열 전체가 '1'로만 이루어져 있으므로 최대 길이는 5입니다.*

## 힌트

- 문자열을 한 번만 순회하며 현재 연속된 1의 길이를 카운트하는 변수가 필요합니다.
- 현재 길이가 0보다 크고, 다음 문자가 '0'일 때 최대 길이를 갱신해야 합니다.


## 알고리즘 요약

문자열을 순차적으로 탐색하며, '1'이 나타날 때마다 현재 연속된 길이를 증가시키고, '0'이 나타나거나 문자열의 끝에 도달했을 때 최대 길이를 갱신합니다. 이 과정을 통해 전 구간의 최대 길이를 찾을 수 있습니다.

## 풀이 해설

1. **아이디어**: 이 문제는 문자열을 한 번만 순회하는(One Pass) 그리디 알고리즘으로 풀 수 있습니다. 연속된 '1'의 길이를 추적하는 `current_count` 변수와, 지금까지 발견한 최대 길이를 저장하는 `max_count` 변수를 사용합니다.
2. **단계**: 
    a. `max_count`를 0으로 초기화하고, `current_count`도 0으로 초기화합니다.
    b. 문자열을 처음부터 끝까지 반복합니다.
    c. 만약 현재 문자가 '1'이면, `current_count`를 1 증가시킵니다.
    d. 만약 현재 문자가 '0'이면, 연속된 '1'의 흐름이 끊겼다는 의미이므로, `current_count`를 0으로 초기화합니다.
    e. 반복이 끝날 때마다, `max_count`를 `max(max_count, current_count)`로 갱신합니다. (문자열의 끝에 도달했을 때 마지막으로 카운트된 연속된 '1'의 길이가 최대 길이일 수 있으므로, 반복문 바깥에서도 갱신해주는 것이 안전합니다.)
3. **시간 복잡도**: 문자열의 길이 N에 비례하여 한 번만 순회하므로, 시간 복잡도는 O(N)입니다. 공간 복잡도는 상수 공간 O(1)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.readline을 사용하여 문자열을 입력받습니다.
    try:
        s = sys.stdin.readline().strip()
    except EOFError:
        return

    if not s:
        print(0)
        return

    max_count = 0
    current_count = 0

    for char in s:
        if char == '1':
            current_count += 1
        else:
            # '0'을 만나면 연속 카운트를 초기화합니다.
            current_count = 0
        
        # 매 단계마다 최대 길이를 갱신합니다.
        max_count = max(max_count, current_count)

    print(max_count)

if __name__ == "__main__":
    solve()
```

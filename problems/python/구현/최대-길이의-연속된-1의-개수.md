# 최대 길이의 연속된 1의 개수
*python · 구현 · 쉬움 · 문자열, 반복*

## 입출력 환경

Python의 sys.stdin.readline을 사용하여 입력을 받습니다.

## 문제

주어진 문자열 S가 있습니다. 이 문자열에는 '0'과 '1'만 포함되어 있습니다. 이 문자열에서 연속적으로 나타나는 '1'의 최대 길이를 구하는 문제입니다. 

예를 들어, "11011101"이라는 문자열이 주어졌을 때, 연속된 '1'의 최대 길이는 3입니다. (가장 긴 부분은 "111").

## 입력

첫 번째 줄에 문자열 S가 주어집니다.

## 출력

정수 하나 (최대 길이)를 출력합니다.

## 제약 조건

문자열 S의 길이는 1 이상 100,000 이하입니다.

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열을 순회하며 연속된 '1'의 최대 길이를 계산합니다.*

## 예제 2

**입력**
```
00000
```

**출력**
```
0
```

*문자열에 '1'이 포함되어 있지 않으므로 최대 길이는 0입니다.*

## 예제 3

**입력**
```
11111
```

**출력**
```
5
```

*문자열 전체가 '1'로만 이루어져 있습니다.*

## 힌트

- 문자열을 한 글자씩 순회하며 현재 연속된 '1'의 길이를 세어보세요.
- 이전까지의 최대 길이와 현재 연속된 길이를 비교하며 최대값을 갱신해야 합니다.


## 알고리즘 요약

문자열을 순차적으로 탐색(Iteration)하며, 현재 카운트되는 '1'의 길이(current_count)를 유지합니다. 만약 '1'을 만나면 길이를 1 증가시키고, '0'을 만나거나 문자열의 끝에 도달하면 현재 카운트를 최대 길이(max_count)와 비교하여 최대값을 갱신하고 current_count를 0으로 초기화합니다.

## 풀이 해설

아이디어: 문자열을 한 번만 순회하는 방식으로, 현재 연속된 '1'의 길이를 기록하고, 이 길이가 지금까지 발견된 최대 길이보다 클 경우 최대 길이를 갱신합니다.

단계:
1. 변수 `max_length`를 0으로, `current_length`를 0으로 초기화합니다.
2. 문자열 S의 각 문자를 순회합니다.
3. 현재 문자가 '1'이면, `current_length`를 1 증가시킵니다.
4. 현재 문자가 '0'이면, `current_length`를 0으로 초기화합니다.
5. (매 반복마다) `max_length`를 `max(max_length, current_length)`로 업데이트하여 최대값을 유지합니다.
6. 반복이 끝난 후, `max_length`가 최종 답이 됩니다.

시간 복잡도: 문자열의 길이 N에 비례하는 O(N)의 선형 시간 복잡도를 가집니다. 공간 복잡도는 추가 메모리를 사용하지 않으므로 O(1)입니다.

## 참고 코드 (python)

```python
import sys

def solve():
    # sys.stdin.read().strip()을 사용하여 전체 입력을 읽고 공백 제거
    s = sys.stdin.read().strip()
    
    if not s:
        print(0)
        return

    max_length = 0
    current_length = 0
    
    for char in s:
        if char == '1':
            current_length += 1
        else:
            # '0'을 만나면 연속 카운트를 리셋
            current_length = 0
        
        # 현재까지의 최대 길이 갱신
        if current_length > max_length:
            max_length = current_length
            
    print(max_length)

if __name__ == "__main__":
    solve()
```

# 최대 길이의 연속된 1의 개수
*python · 구현 · 쉬움 · 문자열*

## 입출력 환경

Python에서는 sys.stdin.readline을 사용하여 입력을 받는 것이 효율적입니다.

## 문제

N개의 0과 1로 이루어진 이진 문자열이 주어집니다. 이 문자열에서 '1'이 연속적으로 나타나는 가장 긴 부분 문자열의 길이를 구하는 문제입니다.

예를 들어, "11011101"와 같은 문자열이 주어졌을 때, 가장 긴 1의 연속 구간은 "111" (길이 3)입니다. 따라서 답은 3입니다.

## 입력

첫째 줄에 N 길이의 이진 문자열 S가 주어집니다.

## 출력

가장 긴 연속된 1의 개수를 나타내는 정수 K를 출력합니다.

## 제약 조건

N <= 10^5

## 예제 1

**입력**
```
11011101
```

**출력**
```
3
```

*문자열에서 연속된 '1' 중 가장 긴 구간은 3입니다 (인덱스 3부터 5).*

## 예제 2

**입력**
```
11111
```

**출력**
```
5
```

*전체 문자열이 모두 '1'로 이루어져 있어 최대 길이가 5입니다.*

## 예제 3

**입력**
```
00000
```

**출력**
```
0
```

*문자열에 '1'이 존재하지 않아 최대 길이가 0입니다.*

## 힌트

- 현재 연속된 길이를 카운트하는 변수와, 지금까지 발견한 최대 길이를 저장하는 변수를 활용해 보세요.
- 슬라이딩 윈도우 기법이나 단순히 순회하며 카운트를 늘리는 방식으로 접근할 수 있습니다.


## 알고리즘 요약

문자열을 왼쪽부터 오른쪽으로 한 글자씩 순회하면서, 현재 연속된 '1'의 길이를 유지합니다. 만약 '0'을 만나면 현재 길이를 0으로 초기화하고, 최대 길이 변수에 현재까지의 최대값을 갱신합니다. 문자열 끝에 도달했을 때도 마지막으로 계산된 최대값과 비교하여 최종 답을 결정해야 합니다.

## 풀이 해설

### 아이디어
이 문제는 단순히 순차적인 탐색(One Pass)만으로 해결할 수 있습니다. 우리는 현재 연속되는 '1'의 길이를 `current_count` 변수로 추적하고, 이 중 가장 큰 값이 전체 최대 길이인 `max_count`를 저장합니다.

### 단계
1. 초기화: `max_count = 0`, `current_count = 0`으로 설정합니다.
2. 순회: 문자열 S의 각 문자를 처음부터 끝까지 확인합니다.
3. 카운트 증가 (S[i] == '1'): 만약 현재 문자가 '1'이면, `current_count`를 1 증가시킵니다.
4. 카운트 초기화 (S[i] == '0'): 만약 현재 문자가 '0'이면, 연속된 '1'이 끊겼으므로 `current_count`를 0으로 재설정합니다.
5. 최대값 갱신: 매 단계마다(`current_count`가 증가하거나 초기화될 때), `max_count = max(max_count, current_count)` 연산을 통해 현재까지의 최대 길이를 업데이트합니다.
6. 종료: 문자열 전체를 순회한 후, `max_count`에 저장된 값이 최종 답이 됩니다. (만약 입력 문자열 자체가 비어있다면 0을 반환해야 합니다.)

### 시간 복잡도
문자열의 길이를 N이라고 할 때, 문자열 전체를 단 한 번 순회하므로 시간 복잡도는 $O(N)$입니다. 공간 복잡도는 추가적인 자료구조 사용 없이 상수 공간 $O(1)$을 사용합니다.

## 참고 코드 (python)

```python
import sys
# 입력 속도 향상을 위해 sys.stdin.readline 사용
s = sys.stdin.read().strip()

if not s:
    print(0)
else:
    max_count = 0
    current_count = 0
    
    for char in s:
        if char == '1':
            current_count += 1
        else:
            # '0'을 만나면 카운트 초기화
            current_count = 0
        
        # 매 단계마다 최대 길이 업데이트
        max_count = max(max_count, current_count)
    
    print(max_count)
```

# 최대 연결된 영역의 개수
*python · 구현 · 보통 · BFS, DFS, 구현*

## 입출력 환경

표준 입력에서 N을 받고, 이후 N개의 문자열 행을 받습니다. 파이썬의 sys.stdin.readline 또는 표준 input 함수를 사용합니다.

## 문제

N x N 크기의 격자 맵이 주어집니다. 이 맵에는 '1'과 '0'으로만 이루어진 문자들이 채워져 있습니다.

문제는 이 맵에서 '1'로만 이루어져 있고 서로 인접한(상하좌우) 영역의 최대 개수를 구하는 것입니다. 단, 같은 영역에 속하는 모든 칸은 반드시 연결되어 있어야 합니다.

예를 들어,
`['1', '0']`
`['1', '1']`
위 맵에서 두 개의 '1'로만 이루어진 영역이 존재하며, 최대 개수는 2입니다.
(왼쪽 세로줄의 '1'과 오른쪽 '1'은 서로 연결되어 있지 않습니다.)

## 입력

첫째 줄에 N (N x N 격자의 크기)을 입력받고, 다음 N줄에 걸쳐 각 행의 N개의 문자를 문자열 형태로 받습니다. 즉, N x N 그리드 형태의 맵이 주어집니다.

## 출력

존재하는 독립적인 '1' 영역의 최대 개수를 정수 하나로 출력합니다.

## 제약 조건

N은 2 이상 50 이하입니다. 시간 복잡도는 O(N^2) 이내여야 합니다.

## 예제 1

**입력**
```
3
101
110
011
```

**출력**
```
2
```

*상단 왼쪽 (1, 0)와 하단 오른쪽 (1, 2), (2, 2)로 연결된 영역이 각각 하나씩 존재하여 총 2개입니다.*

## 예제 2

**입력**
```
4
1111
1001
1001
1111
```

**출력**
```
3
```

*가장자리 전체를 감싸는 하나의 큰 영역과, 중앙에 갇힌 작은 '1' 하나가 독립적으로 존재하여 총 3개입니다.*

## 힌트

- 이 문제는 연결 요소(Connected Component)의 개수를 세는 전형적인 문제입니다.
- BFS (Breadth-First Search) 또는 DFS (Depth-First Search)를 사용하여 아직 방문하지 않은 '1'을 찾고, 해당 영역 전체를 탐색하며 '방문 처리'하는 과정을 반복해야 합니다.


## 알고리즘 요약

DFS/BFS 기반 연결 요소 카운팅. 격자 맵을 순회하면서 아직 방문하지 않은 '1'을 만나면, 이를 새로운 영역의 시작점으로 간주하고 BFS 또는 DFS를 사용하여 해당 영역에 속한 모든 인접 '1'들을 탐색하고 방문 처리합니다. 이 과정을 반복하여 발견된 영역의 총 개수를 세면 됩니다.

## 풀이 해설

풀이 아이디어:
이 문제는 격자 맵에서 연결되어 있는 '1'로 이루어진 독립적인 그룹(연결 요소)의 개수를 세는 문제입니다.

단계별 풀이:
1. 초기화: N x N 크기의 방문 배열(visited)을 False로 초기화합니다. 이 배열은 이미 탐색된 칸을 기록하는 용도로 사용됩니다.
2. 순회 및 탐색: 맵의 모든 칸 (r, c)에 대해 반복문을 실행합니다.
3. 영역 발견 조건: 만약 현재 칸 (r, c)가 '1'이고, 동시에 visited[r][c]가 False라면, 이는 새로운 연결 요소의 시작점임을 의미합니다. 따라서 카운트를 1 증가시킵니다.
4. BFS/DFS 수행: 이 새로운 영역을 탐색하기 위해 BFS(또는 DFS)를 시작합니다. 큐(Queue)에 (r, c)를 넣고 visited[r][c]를 True로 설정합니다. 
   - 큐가 빌 때까지 반복하면서, 현재 칸에서 상하좌우로 인접한 이웃 칸을 확인합니다.
   - 만약 이웃 칸이 맵 경계 내에 있고, 값이 '1'이며, 아직 방문하지 않았다면 (visited[r'][c'] == False), 그 이웃 칸을 큐에 추가하고 visited 상태를 True로 업데이트합니다.
5. 완료: 모든 칸을 순회한 후의 카운트가 최종적으로 독립적인 영역의 최대 개수가 됩니다.

시간 복잡도: 전체 격자 (N*N)을 한 번만 순회하며, 각 칸은 BFS/DFS 탐색 과정에서 최대 한 번씩만 방문 처리되므로 시간 복잡도는 O(N^2)입니다. 공간 복잡도는 visited 배열 및 큐를 사용하므로 O(N^2)입니다.

## 참고 코드 (python)

```python
import sys
from collections import deque
def solve():
    # 입력 속도 최적화를 위해 sys.stdin.read().split()을 사용하는 것이 좋지만,
    # 문제의 형태가 N과 다음 N줄 문자열이므로, 라인별로 처리합니다.
    input_data = sys.stdin.readlines()
    if not input_data: return

    try:
        N = int(input_data[0].strip())
        grid = []
        for i in range(1, N + 1):
            grid.append(list(input_data[i].strip()))
    except IndexError: 
        # 입력 형식이 잘못되었거나 EOF인 경우 처리
        return

    visited = [[False for _ in range(N)] for _ in range(N)]
    area_count = 0
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)] # 상하좌우

    def bfs(start_r, start_c): 
        queue = deque([(start_r, start_c)])
        visited[start_r][start_c] = True
        
        while queue:
            r, c = queue.popleft()
            
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                
                # 1. 경계 확인
                if 0 <= nr < N and 0 <= nc < N:
                    # 2. 값 및 방문 여부 확인
                    if grid[nr][nc] == '1' and not visited[nr][nc]:
                        visited[nr][nc] = True
                        queue.append((nr, nc))
    
    for r in range(N): 
        for c in range(N): 
            # 방문하지 않았고, '1'인 경우 -> 새로운 영역 발견
            if grid[r][c] == '1' and not visited[r][c]:
                area_count += 1
                bfs(r, c)
    
    print(area_count)

solve()
```
